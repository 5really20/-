## 3.1 概述

**门电路（logic gate）：实现基本逻辑运算的电路，是数字电路的最小单元。**

### 3.1.1 门电路分类

| 分类方式 | 类型 | 特点 |
|---|---|---|
| 按器件 | **双极型**（BJT） | TTL、ECL、I²L。**速度快**，功耗大，集成度低 |
| | **单极型**（MOS） | PMOS、NMOS、CMOS。**功耗低**（静态几乎不耗电），集成度高 |
| | 混合 | Bi-CMOS：输入级 CMOS + 输出级 BJT，兼顾两者 |
| 按输出结构 | 普通推拉输出 | 输出阻抗低，不能线与 |
| | **OC / OD 输出** | 集电极/漏极开路，**可以线与**，需外接上拉电阻 |
| | **三态输出（TS）** | 高电平、低电平、**高阻 Z** 三种状态，用于总线 |
| 按逻辑系列 | 4000 系列 CMOS | 工作电压 3~18V，速度慢 |
| | 74HC / 74HCT | 高速 CMOS，HCT 可与 TTL 电平兼容 |
| | 74LS / 74ALS | 低功耗肖特基 TTL（老系列） |
| | 74 系列（标准 TTL） | 已基本淘汰 |

> **重点**：**现在的实际工程中，CMOS 是绝对主流**（74HC 系列、CPLD/FPGA 内部都是 CMOS）。TTL 只在老旧设备、部分接口场景中出现。但**考试仍然要考 TTL 的参数和接口**，因为它的原理最典型。

### 3.1.2 开关电路的基本概念

**数字电路的开关：BJT 工作在「截止」和「饱和」两个状态；MOS 管工作在「截止」和「可变电阻区」。**

**理想开关的四个条件**：
1. 接通时，**压降为 0**（相当于短路）；
2. 断开时，**电流为 0**（相当于开路）；
3. 状态转换**瞬间完成**，无过渡时间；
4. 状态转换由**控制信号**完成，且控制信号不消耗功率。

实际器件无法完全满足，因此产生各种非理想特性：**导通压降 V_CES ≈ 0.3V（TTL）或 0（CMOS 理想）**、**存在开关时间**、**存在漏电流**。

## 3.2 半导体二极管门电路

### 3.2.1 半导体二极管的开关特性

**二极管：正向导通时压降约 0.7V（硅管）或 0.3V（锗管），反向截止时电流极小。**

```
        ┌───────►│───────┐
   P ───┤  阳极   阴极   ├─── N
        └────────────────┘

等效电路：
  导通（正偏）：  ──┤├── +0.7V ──→  等效为 0.7V 电池串联
  截止（反偏）：  ──X──            等效为断开
```

**开关时间**：二极管从导通到截止需要**反向恢复时间 t_re**（一般几十 ns），这是限制二极管门电路速度的原因。

### 3.2.2 二极管与门

```
        +VCC (+5V)
          │
          R
          │
    A ──►│─┬──── Y
           │
    B ──►│─┘
    （两个二极管，阳极分别接 A、B，阴极连在一起作为 Y，再经 R 接 +VCC）
```

**工作原理**（设二极管导通压降 0.7V，逻辑 1 = 5V，逻辑 0 = 0V）：

| A | B | 导通的二极管 | Y 电位 | Y |
|---|---|---|---|---|
| 0V | 0V | 两个都导通 | 0 + 0.7 = **0.7V** | 0 |
| 0V | 5V | A 管导通 | **0.7V** | 0 |
| 5V | 0V | B 管导通 | **0.7V** | 0 |
| 5V | 5V | 无（仅漏电） | ≈ **5V** | 1 |

**结论：有 0 出 0，全 1 出 1 → 与门。**

> **重点：二极管与门的缺点**
> ① **输出高电平比输入低 0.7V**（电平偏移），多级级联后信号会衰减到无法识别；
> ② **带负载能力差**（输出电流由二极管提供）；
> ③ **速度慢**；
> ④ 电平和逻辑电平不匹配。
> **所以二极管门只用于分立电路，不能作为集成电路的构建单元。**

### 3.2.3 二极管或门

```
    A ──│◄─┬──── Y
           │
    B ──│◄─┘
           │
           R
           │
          GND
    （二极管阴极接 A、B，阳极连在一起为 Y，再经 R 接地）
```

| A | B | 导通的二极管 | Y 电位 | Y |
|---|---|---|---|---|
| 0V | 0V | 无 | **0V** | 0 |
| 0V | 5V | B 管导通 | 5 − 0.7 = **4.3V** | 1 |
| 5V | 0V | A 管导通 | **4.3V** | 1 |
| 5V | 5V | 两个都导通 | **4.3V** | 1 |

**结论：有 1 出 1，全 0 出 0 → 或门。同样存在 0.7V 电平偏移。**

## 3.3 CMOS 门电路

### 3.3.1 MOS 管的开关特性

**MOS 管（Metal-Oxide-Semiconductor，金属-氧化物-半导体场效应管）是电压控制器件：栅极电压 V_GS 控制漏源之间的通断。**

| 类型 | 导通条件 | 等效 | 符号特征 |
|---|---|---|---|
| **N 沟道增强型（NMOS）** | V_GS > V_TN（正阈值，约 +2V） | 导通时≈短路到地 | 箭头**向内** |
| **P 沟道增强型（PMOS）** | V_GS < V_TP（负阈值，约 −2V） | 导通时≈短路到 V_DD | 箭头**向外** |

**关键结论（务必记住）**：
```
NMOS：栅极加高电平 → 导通（开关接地）   「高导通」
PMOS：栅极加低电平 → 导通（开关接电源） 「低导通」
```

> **重点**：CMOS 的**静态功耗几乎为零**——因为 NMOS 与 PMOS 总是**一个导通一个截止**，电源到地之间没有直流通路。只有在**状态切换瞬间**两个管子会短暂同时导通，产生**动态功耗 `P = C·V_DD²·f`**。这就是为什么 CPU 频率越高越热。

### 3.3.2 CMOS 反相器

**电路结构：一个 PMOS 和一个 NMOS 串联，栅极连在一起作为输入，漏极连在一起作为输出。**

```
            VDD
             │
        ┌────┴────┐
        │  PMOS   │  ← 栅极接低电平 (Vi=0) 时导通
        └────┬────┘
             │
     Vi ─────┼───── Vo
             │
        ┌────┴────┐
        │  NMOS   │  ← 栅极接高电平 (Vi=1) 时导通
        └────┬────┘
             │
            GND
```

**工作原理：**

| Vi | PMOS | NMOS | Vo | 说明 |
|---|---|---|---|---|
| 0（低） | **导通** | 截止 | **≈ V_DD（高）** | 输出被 PMOS 拉到 VDD |
| 1（高） | 截止 | **导通** | **≈ 0（低）** | 输出被 NMOS 拉到地 |

**结论：Vo = Vi'，实现非运算。且两种状态下电源到地之间都没有直流通路 → 静态功耗极小。**

**电压传输特性（VTC）与关键参数：**

```
   Vo
 VDD ┤━━━━━━━━━┓
     │         ┃
     │         ┃  ← 转折区，斜率很陡（CMOS 抗干扰强的原因）
     │         ┃
   0 ┤         ┗━━━━━━━━━
     └──┬────┬──────┬────┬──► Vi
        0   VIL   VIH   VDD

   V_IL ≈ 0.3 V_DD    （输入低电平上限）
   V_IH ≈ 0.7 V_DD    （输入高电平下限）
   V_th ≈ 0.5 V_DD    （阈值电压）
```

**电流特性**：
- **输入电流 ≈ 0**（栅极是绝缘的氧化层，只有极小的漏电流 I_I < 1μA）。
- **输出电流能力有限**，典型 I_OH = I_OL = 0.5~4 mA。

### 3.3.3 其他基本 CMOS 逻辑门

**规律（**核心记忆点**）：**
```
NMOS 网络负责「拉低」→ 实现「与」关系时用 NMOS 串联
PMOS 网络负责「拉高」→ 实现「与」关系时用 PMOS 并联
两个网络互为对偶（串 ↔ 并）
```

**CMOS 与非门（NAND）**：
```
            VDD
        ┌────┴────┬────────┐
        │  PMOS   │  PMOS  │   ← 两个 PMOS 并联
        └────┬────┴────┬───┘
             │         │
   A ────────┘         │
             ┌─────────┴─── Y = (A·B)'
   B ────────┘
        ┌────┴────┐
        │  NMOS   │  ← 两个 NMOS 串联，都导通才接地
        └────┬────┘
        ┌────┴────┐
        │  NMOS   │
        └────┬────┘
            GND
```
- A = 0 → 上方的 PMOS（受 A 控制）导通 → Y 被拉高
- A = B = 1 → 两个 NMOS 都导通 → Y 被拉低
- 逻辑：`Y = (A·B)'` ✓

**CMOS 或非门（NOR）**：两 PMOS 串联、两 NMOS 并联 → `Y = (A+B)'`

**CMOS 与门 / 或门**：**CMOS 没有直接的与门和或门**！
```
与门 = 与非门 + 反相器      （2 级，延迟翻倍）
或门 = 或非门 + 反相器
```
> **重点**：**这就是为什么实际电路里「与非门最便宜」**——CMOS 与非门只需 4 个 MOS 管，而与门需要 6 个。所以逻辑函数要变换成**与非-与非式**来实现（见第 2 章 2.9）。

**CMOS 门电路管数对照：**

| 门 | MOS 管数 | 延迟（相对） |
|---|---|---|
| 反相器 | 2 | 1 |
| 与非门（2 输入） | 4 | 1.5 |
| 或非门（2 输入） | 4 | 2（PMOS 串联电阻大，比与非门慢） |
| 与门 | 6 | 2.5 |
| 或门 | 6 | 3 |
| 异或门 | 8~10 | 3 |

### 3.3.4 CMOS 传输门（Transmission Gate）

**传输门：由一个 NMOS 和一个 PMOS 并联组成，两个栅极加互补的控制信号。**

```
            C  (控制信号)
             │
        ┌────┴────┐
        │  PMOS   │
   ─────┤         ├─────   （双向导通）
        │  NMOS   │
        └────┬────┘
             │
            C'  (反相控制信号)
```

**功能表：**

| C | C' | 状态 | 说明 |
|---|---|---|---|
| 1 | 0 | **导通** | 双向传输，输入输出可互换 |
| 0 | 1 | **断开** | 高阻 |

**为什么需要 NMOS + PMOS 并联？**
- 单用 NMOS：传输高电平时，当输出升到 `V_DD − V_TN` 时 V_GS 不再满足导通条件，**高电平传不完整**。
- 单用 PMOS：传输低电平时，当输出降到 `|V_TP|` 时**低电平传不完整**。
- **并联后**：传输高电平时 PMOS 充分导通；传输低电平时 NMOS 充分导通 → **全摆幅传输**。

**用途**：构成**多路选择器、双向开关、锁存器与触发器的内部结构**（第 5 章）。

### 3.3.5 CMOS 门电路的不同输出结构

#### （一）漏极开路输出门（OD 门，Open-Drain）

**把 CMOS 推拉输出级的 PMOS 去掉，只留 NMOS，漏极开路。**

```
           内部
        ┌────────┐
   A ───┤ 逻辑    ├───  NMOS 漏极（开路）
   B ───┤ 网络    │      │
        └────────┘      └──── Y
                             │
                            [R]  ← 外接上拉电阻（必须）
                             │
                            VDD
```

**关键特性：**
1. **必须外接上拉电阻 R**，否则输出高电平无法确定。
2. **可以实现「线与」**：把多个 OD 门的输出直接连在一起，再共用一个上拉电阻。

```
   OD门1 ──┐
           ├──── 公共输出 Y ──[R]── VDD
   OD门2 ──┘

   Y = Y₁ · Y₂    ← 只要有一个门输出低，Y 就是低（线与）
```

**上拉电阻 R 的选择（会算即可）：**
```
下限（保证输出低电平时不超过 V_OL(max)）：
        V_DD − V_OL(max)
  R_min ≥ ─────────────────
           I_OL(max) − m·I_IL

上限（保证输出高电平时不低于 V_OH(min)）：
        V_DD − V_OH(min)
  R_max ≤ ─────────────────
          n·I_OZ + m·I_IH

其中 n = 并联的 OD 门数（漏电流 I_OZ 之和）、m = 被驱动的负载门输入端总数
```
> **口诀**：**R 太小 → 低电平抬高（灌电流不够）；R 太大 → 高电平跌落 + 速度慢**。

**用途**：① **线与**；② **驱动高电压负载**（如继电器、LED、12V 器件）；③ **总线**（多个 OD 门挂一条总线，但速度慢，现在多用三态门）。

#### （二）三态输出门（TS 门，Three-State）

**在普通门的基础上加一个使能端 EN，使输出具有「高电平、低电平、高阻（Z）」三种状态。**

```
        ┌───────────┐
   A ───┤           │
   B ───┤  逻辑网络  ├──── Y
        │           │
   EN ──┤ 使能控制   │
        └───────────┘
```

**功能表（以 EN 高电平有效、低有效写 EN' 为例）：**

| EN | 输出 Y |
|---|---|
| 1 | `Y = (A·B)'`（正常工作） |
| 0 | **高阻态 Z**（输出与电路断开） |

**双向三态门符号：**
```
        ┌───────┐
   A ───┤  ▷    ├─── B        EN = 1 时 A → B 导通
        │       │             EN = 0 时 A、B 断开（高阻）
   EN ──┤       │
        └───────┘
```

**用途（总线结构的核心）：**
```
       三态门1        三态门2        三态门3
   D₁ ──┤▷├──┐    D₂ ──┤▷├──┐   D₃ ──┤▷├──┐
   EN₁ ──────┤    EN₂ ──────┤   EN₃ ──────┤
             │              │             │
             └──────────────┴─────────────┴──── 总线
```
**任一时刻只能有一个 EN 有效**，否则多个门同时驱动总线会**烧毁器件**（输出冲突）。

> **重点：三态门 vs OD 门**
> | 比较 | OD 门 | 三态门 |
> |---|---|---|
> | 输出状态 | **低、高（高电平靠外接上拉电阻提供，输出阻抗高）** | 低、高、**高阻** |
> | 是否需要上拉电阻 | **需要** | **不需要** |
> | 速度 | 慢（上拉电阻限制了上升时间） | **快** |
> | 能否线与 | **能** | 不能（会冲突） |
> | 主要用途 | 线与、驱动高电压负载 | **总线（分时共享）** |

### 3.3.6 CMOS 门电路的重要技术参数

**（一）电压参数（用下标区分输入/输出、高/低）**

| 参数 | 名称 | 含义 | 典型值（V_DD = 5V） |
|---|---|---|---|
| **V_OH(min)** | 输出高电平下限 | 输出为 1 时的**最低**保证电压 | 4.4 V |
| **V_OL(max)** | 输出低电平上限 | 输出为 0 时的**最高**保证电压 | 0.33 V |
| **V_IH(min)** | 输入高电平下限 | 被识别为 1 的**最低**输入电压 | 3.5 V |
| **V_IL(max)** | 输入低电平上限 | 被识别为 0 的**最高**输入电压 | 1.5 V |
| **V_T** | 阈值电压 | 输出翻转的输入电压 | 2.5 V |

**（二）噪声容限（Noise Margin）—— 会计算**

**噪声容限：输入端允许叠加的、不致使输出发生错误的最大噪声电压。**

```
高电平噪声容限：  V_NH = V_OH(min) − V_IH(min)
低电平噪声容限：  V_NL = V_IL(max) − V_OL(max)
```

`例（用上表数据）：`
```
V_NH = 4.4 − 3.5 = 0.9 V
V_NL = 1.5 − 0.33 = 1.17 V
```
**含义**：在输出高电平上叠加不超过 0.9V 的正向噪声，接收端仍能正确识别为高电平。

> **重点**：**噪声容限越大，抗干扰能力越强**。CMOS 的 V_NH、V_NL 都在 1V 左右，而 TTL 只有 0.4V —— 这就是 **CMOS 抗干扰能力优于 TTL** 的量化依据。提高 V_DD 可以增大噪声容限。

**（三）电流参数与扇出**

| 参数 | 名称 | 含义 |
|---|---|---|
| **I_OH** | 输出高电平电流 | 输出为高时，**向外流出**的电流（拉电流，source） |
| **I_OL** | 输出低电平电流 | 输出为低时，**向内灌入**的电流（灌电流，sink） |
| **I_IH** | 输入高电平电流 | 输入为高时，流入输入端的电流 |
| **I_IL** | 输入低电平电流 | 输入为低时，流出输入端的电流 |

**扇出（Fan-out）：一个门的输出能驱动同类门输入的个数。**

```
高电平扇出：N_OH = I_OH(max) / I_IH(max)
低电平扇出：N_OL = I_OL(max) / I_IL(max)
实际扇出 N = min(N_OH, N_OL)
```

`例：某 CMOS 门 I_OH = 0.4mA，I_IH = 1μA；I_OL = 0.4mA，I_IL = 1μA`
```
N_OH = 0.4mA / 1μA = 400
N_OL = 0.4mA / 1μA = 400
N = 400    （但实际受限于电容负载和速度，一般取 50 以内）
```

`例：某 TTL 门 I_OH = 0.4mA，I_IH = 20μA；I_OL = 8mA，I_IL = 0.4mA`
```
N_OH = 0.4mA / 20μA = 20
N_OL = 8mA / 0.4mA = 20
N = 20     （TTL 典型扇出 = 20）
```

> **重点**：**CMOS 的扇出远大于 TTL**（因为 CMOS 输入电流极小，是 μA 级；TTL 输入电流是 mA 级）。这是 CMOS 容易驱动大量负载的原因。

### 3.3.7 CMOS 数字集成电路的各种系列

| 系列 | 工作电压 | 传输延迟 t_pd | 特点 |
|---|---|---|---|
| **4000 系列** | 3~18 V | 约 100 ns | 最早，速度慢，但电压范围宽 |
| **74HC** | 2~6 V | 约 10 ns | 高速 CMOS，主流；**电平与 TTL 不兼容**（V_IH=3.5V > TTL 的 2.4V） |
| **74HCT** | 4.5~5.5 V | 约 10 ns | **T 表示与 TTL 电平兼容**（V_IH = 2.0V），可直接替换 TTL |
| **74AC / 74ACT** | 2~6 V | 约 5 ns | 改进型，速度更快、驱动更强 |
| **74AHC / AHCT** | 2~5.5 V | 约 5 ns | 先进高速 CMOS |
| **74LVC** | 1.65~3.6 V | 约 4 ns | **低电压系列**，用于 3.3V 系统 |

> **重点**：**74HC 与 74HCT 的区别只在输入电平**。HC 的 V_IH = 0.7×V_DD = 3.5V，而 TTL 输出的 V_OH 只有 2.4~3.4V，**用 TTL 驱动 HC 可能失败**；HCT 的 V_IH = 2.0V，可以直接接 TTL 输出。**这是接口题的核心考点。**

### 3.3.8 CMOS 电路的正确使用（可靠性）

1. **多余输入端不能悬空**。CMOS 输入阻抗极高，悬空端电位不定，会因静电或感应电压导致**两个管子同时导通，功耗剧增甚至烧毁**。
   - 处理办法：与门/与非门的多余输入接 **V_DD（高电平）**；或门/或非门的多余输入接 **GND（低电平）**。
2. **输入电压必须限制在 `GND ≤ Vi ≤ V_DD`**，超出会触发内部保护二极管导通，大电流烧毁器件。
3. **防静电（ESD）**：CMOS 栅极氧化层很薄（纳米级），人体静电可击穿。存放用防静电袋，操作时接地。
4. **电源不能接反，先接电源后接信号**。
5. **驱动大负载（如 LED、继电器）必须加缓冲或晶体管**，输出电流通常只有几 mA。

## 3.4 TTL 逻辑门电路

### 3.4.1 双极型三极管的开关特性

**BJT（Bipolar Junction Transistor，双极型三极管）是电流控制器件：基极电流 I_B 控制集电极电流 I_C。**

**三个工作区：**

| 工作区 | 条件 | 特点 | 数字电路中的用途 |
|---|---|---|---|
| **截止区** | V_BE < 0.5V | I_C ≈ 0，相当于**断开** | 表示逻辑 1（输出被拉高） |
| **放大区** | V_BE ≈ 0.7V，I_C = βI_B | I_C 随 I_B 线性变化 | **过渡区，应尽快穿过** |
| **饱和区** | V_BE ≈ 0.7V，V_CE = V_CES ≈ 0.3V | I_C 不随 I_B 变化 | 相当于**闭合**，表示逻辑 0 |

> **重点**：数字电路中 BJT **只作开关用**，工作在截止区或饱和区，**绝不停在放大区**（否则功耗大、速度慢）。
> **开关时间**：开通时间 t_on = 延迟时间 t_d + 上升时间 t_r；关断时间 t_off = 存储时间 t_s + 下降时间 t_f。其中**存储时间 t_s 最长**，是限制 TTL 速度的主因，改进方法是**抗饱和**（加肖特基二极管钳位）。

### 3.4.2 TTL 反相器的电路结构和工作原理

**TTL（Transistor-Transistor Logic，晶体管-晶体管逻辑）反相器由三部分组成：**

```
                        VCC (+5V)
                          │
              ┌───────────┴───────────┐
              │       输入级           │
   A ───┬─────┤ 多发射极三极管 T₁      │
        │     │  （相当于二极管与门）    │
       [R₁]   └───────────┬───────────┘
                          │
              ┌───────────┴───────────┐
              │       中间级           │
              │  T₂ 分相器（同时产生   │
              │   两个互补信号）       │
              └───────────┬───────────┘
                          │
              ┌───────────┴───────────┐
              │       输出级           │
              │  T₃（上拉）/ T₄（下拉）│
              │  推拉输出（图腾柱）     │
              └───────────┬───────────┘
                          │
                         Y
```

**工作过程（简要）：**

| A | T₁ | T₂ | T₃ | T₄ | Y | 说明 |
|---|---|---|---|---|---|---|
| **低（0.2V）** | T₁ 深饱和，T₂ 截止 | 截止 | **导通** | 截止 | **高（≈3.6V）** | T₂ 无电流，T₃ 由 R 拉高导通 |
| **高（3.6V）** | T₁ 倒置，T₂ 导通 | 导通（饱和） | 截止 | **导通** | **低（≈0.3V）** | T₂ 饱和使 T₄ 导通，拉低输出 |

**结论：`Y = A'`，实现非运算。**

**TTL 反相器的特点**：
- **推拉输出（图腾柱输出）**：T₃ 和 T₄ 总是一个导通一个截止，输出阻抗低，**驱动能力强、速度快**。
- **但不能线与**：若把两个推拉输出接在一起，一个输出高（T₃ 导通）一个输出低（T₄ 导通），会形成 **VCC→T₃→T₄→GND 的低阻通路，大电流烧毁管子**。这正是需要 OC 门的原因。

**TTL 与非门**：把输入级的**多发射极三极管做成 2 个（或多个）发射极**，就得到与非门。
```
   A ──┤
        ├── T₁ 的两个发射极
   B ──┤
```
**原理**：任一发射极接低电平，都会把 T₁ 拉入深饱和，T₂ 截止，输出高 → `Y = (A·B)'` ✓

### 3.4.3 TTL 反相器的静态输入特性和输出特性

**（一）输入特性（V_I 与 I_I 的关系）**

```
   I_I (mA)
     │
  1.4 ┤           ┌─────────  ← V_I > 1.3V 后，T₁ 倒置工作，电流急剧上升
      │          ╱
    0 ┤─────────╱───────────► V_I (V)
      │        ╱  1.3V
 -1.0 ┤──┐    ╱
      │  └───╱   ← V_I 在 0.2~1.3V 之间为转折区
 -1.6 ┤ (V_I = 0V 时，I_IL = −1.6mA，称为输入短路电流 I_IS)
      └──────────────────────
```

| 参数 | 含义 | 典型值 |
|---|---|---|
| **I_IL** | 输入低电平电流（**流出**输入端） | −1.6 mA（74 系列）/ −0.4 mA（74LS） |
| **I_IH** | 输入高电平电流（**流入**输入端） | 40 μA |
| **I_IS** | 输入短路电流（V_I = 0 时的 I_IL） | −1.6 mA |

**（二）电压传输特性（VTC）—— 门电路最重要的一条曲线**

**电压传输特性**：输出电压随输入电压变化的曲线 `V_O = f(V_I)`。它把门的**逻辑功能**和**电气特性**连在一起，是理解噪声容限、开门/关门电平的关键。

**TTL 反相器的典型 VTC（实测形状）：**
```
   V_O (V)
   3.6 ┤●●●●●●●●┐
       │   AB 段  │
   3.0 ┤         └──┐
       │            │  BC 段（转折区，很陡）
   2.4 ┤            └──┐
       │               │
   1.4 ┤               ┼ ← V_th（阈值电压）≈ 1.4 V
       │               │
   0.8 ┤               └──┐
       │                  │  CD 段
   0.4 ┤                  └──────●●●●●●
       │                       DE 段（饱和区）
   0.0 └──┬────┬────┬────┬────┬────► V_I (V)
         0.8  1.0  1.3  1.4  1.6
          ↑                   ↑
      V_OFF(关门电平)     V_ON(开门电平)
```

**四段与三个关键电平：**

| 段 | V_I 范围 | V_O | 管子状态 | 说明 |
|---|---|---|---|---|
| **AB** | 0 ~ 0.6 V | ≈ 3.6 V（高） | T₂、T₄ 截止，T₃ 饱和 | **截止区**，输出稳定为高 |
| **BC** | 0.6 ~ 1.3 V | 3.6 → 0.4 V | T₂ 开始导通 | **转折区**，输出随输入急剧变化 |
| **CD** | 1.3 ~ 1.4 V | 0.4 → 0.2 V | T₂、T₄ 都导通 | 接近饱和 |
| **DE** | > 1.4 V | ≈ 0.2 V（低） | T₄ 深饱和 | **饱和区**，输出稳定为低 |

| 关键电平 | 定义 | TTL 典型值 |
|---|---|---|
| **V_OFF（关门电平）** | 保证输出为**合格高电平**（≥ V_OH(min) = 2.4 V）所允许的**最大**输入低电平 | **0.8 V**（就是 V_IL(max)） |
| **V_ON（开门电平）** | 保证输出为**合格低电平**（≤ V_OL(max) = 0.4 V）所允许的**最小**输入高电平 | **2.0 V**（就是 V_IH(min)） |
| **V_th（阈值电压）** | VTC 上 **V_O = V_I** 的那一点（曲线与 45° 线的交点） | **≈ 1.4 V** |

> **★ 三个电平怎么记**：**V_OFF 就是 V_IL(max)、V_ON 就是 V_IH(min)** —— 它们不是新参数，只是从 VTC 的角度重新命名。
> **★ 0.8 ~ 2.0 V 是不允许区**：输入电平落在这个区间时，输出既不是合格高电平也不是合格低电平（逻辑上"不确定"）。数字电路的输入必须被驱动到 0.8 V 以下或 2.0 V 以上。
> **★ 为什么叫"关门/开门"**：V_I < V_OFF 时门"关"（T₄ 截止，输出高）；V_I > V_ON 时门"开"（T₄ 饱和，输出低）。
> **★ 转折区越陡越好**：BC 段越陡，V_OFF 与 V_ON 拉得越开，噪声容限越大。**CMOS 的转折区比 TTL 更陡**，这就是 CMOS 噪声容限更大的根本原因。
> **★ 考试定位**：本小节属"电气特性"，**考试以逻辑功能为主**，但 **V_OFF/V_ON/V_th 三个名字与 0.8 V、2.0 V、1.4 V 三个数值要能对应上**（常以填空/选择形式出现）。

**（三）输出特性**

**输出高电平（拉电流）**：输出为高时，电流从输出端**流出**，进入负载门的输入端。此时 T₃ 导通、T₄ 截止。

**输出低电平（灌电流）**：输出为低时，电流从负载门**流入**输出端。此时 T₄ 导通。

| 参数 | 含义 | 典型值（74 系列） |
|---|---|---|
| **V_OH(min)** | 输出高电平下限 | **2.4 V**（I_OH = −400 μA 时） |
| **V_OL(max)** | 输出低电平上限 | **0.4 V**（I_OL = 16 mA 时） |
| **I_OH(max)** | 高电平最大输出电流 | −400 μA |
| **I_OL(max)** | 低电平最大输出电流 | 16 mA |
| **V_IH(min)** | 输入高电平下限 | **2.0 V** |
| **V_IL(max)** | 输入低电平上限 | **0.8 V** |

**TTL 的噪声容限（必会计算）：**
```
V_NH = V_OH(min) − V_IH(min) = 2.4 − 2.0 = 0.4 V
V_NL = V_IL(max) − V_OL(max) = 0.8 − 0.4 = 0.4 V
```
> **重点**：**TTL 的噪声容限只有 0.4V**，而 CMOS 有 1V 左右。**这是 CMOS 抗干扰能力更强的量化证据**，务必记住这两个 0.4。

### 3.4.4 其他类型的 TTL 门电路

#### （一）集电极开路门（OC 门，Open-Collector）

**把推拉输出级的上拉部分（T₃ 及二极管）去掉，只留 T₄，其集电极开路。**

```
           内部逻辑
   A ───┬───┤        ├──── T₄ 集电极（开路）
   B ───┘   │        │        │
            └────────┘        └──── Y
                                   │
                                  [R] ← 外接上拉电阻
                                   │
                                  VCC
```

**特性与 OD 门相同**：① 需外接上拉电阻；② **可实现线与**；③ 可驱动高电压负载（VCC 可高于 5V，如 12V 驱动继电器）。

**线与逻辑**：`Y = Y₁ · Y₂ · …`（任一输出为低，公共输出即为低）

**上拉电阻计算（与 OD 门公式相同）：**
```
        V_CC − V_OL(max)              V_CC − V_OH(min)
R_min ≥ ─────────────────    R_max ≤ ─────────────────
          I_OL(max) − nI_IL          nI_OH + mI_IH
```

**常用 OC 门型号**：74LS01（OC 与非门）、74LS03、74LS05（OC 反相器，可驱动 LED/继电器）。

#### （二）三态输出门（TS 门）

TTL 三态门的输出结构与普通门相同，但增加了**使能控制**：使能无效时，T₃ 和 T₄ **同时截止**，输出呈高阻。

**常用型号**：74LS125（四三态缓冲器，低有效使能）、74LS126（四三态缓冲器，高有效使能）、74LS244（八三态缓冲器）、74LS245（八三态双向总线收发器）。

**功能表（74LS125 为例）：**

| EN' | A | Y |
|---|---|---|
| 0 | 0 | 0 |
| 0 | 1 | 1 |
| **1** | × | **高阻 Z** |

#### （三）其他

| 门型 | 结构特点 | 用途 |
|---|---|---|
| **与或非门** | 输出级前面是「两组与门 + 一个或非」 | TTL 特有，可直接实现 `Y = (AB + CD)'` |
| **异或门** | 由 4 个与非门组成 | 加法器、比较器 |
| **施密特触发门** | 输入级带正反馈 | **波形整形**（第 7 章） |

### 3.4.5 TTL 数字集成电路的各种系列

| 系列 | 名称 | t_pd | 功耗/门 | 特点 |
|---|---|---|---|---|
| **74**（标准） | 标准 TTL | 10 ns | 10 mW | 已淘汰 |
| **74L** | 低功耗 TTL | 33 ns | 1 mW | 速度慢，已淘汰 |
| **74H** | 高速 TTL | 6 ns | 22 mW | 功耗大，已淘汰 |
| **74S** | 肖特基 TTL | 3 ns | 19 mW | 抗饱和，快但功耗大 |
| **74LS** | 低功耗肖特基 | **9 ns** | **2 mW** | **最经典，教材常用** |
| **74ALS** | 先进低功耗肖特基 | 4 ns | 1 mW | 速度快、功耗低 |
| **74AS** | 先进肖特基 | 1.5 ns | 8 mW | 很快 |
| **74F** | 快速 TTL | 3 ns | 4 mW | 折中 |

> **重点**：**「LS」= 低功耗肖特基（Low-power Schottky）**。系列名里的字母越多、越靠后，一般是越新的改进型。**数字越大不代表越新**（74 系列是反例）。**同一系列内部可以直接互连**；**跨系列互连**（如 74LS 驱动 74HC、或 74HC 驱动 74LS）时**必须检查电平与驱动能力是否匹配**（常见问题：74LS 的 V_OH(min) = 2.4 V 可能达不到 74HC 要求的 3.5 V），必要时加接口电路（见 3.7 节）。

### 3.4.6 TTL 电路的正确使用

1. **多余输入端的处理**：
   - 与门/与非门：多余端接 **V_CC**（或接高电平）；也可**并联使用**（接在一起，但会增加输入电容、降低速度）。
   - 或门/或非门：多余端接 **GND**。
   - **TTL 输入端悬空在电气上等效于接高电平**（因为多发射极三极管悬空时 T₂ 会导通）——但**工程上禁止悬空**（易受干扰）。
   > **对比记忆**：**TTL 悬空 ≈ 高电平；CMOS 悬空 = 危险（可能烧毁）**。这是常考对比题。
2. **输出端不能直接接 V_CC 或 GND**（会短路烧毁）。
3. **两个普通推拉输出不能并联**（会冲突），需要线与必须用 OC 门。
4. **电源 V_CC = 5V ± 5%**，即 4.75~5.25V 之间。
5. **电源与地之间要加 0.1μF 去耦电容**，位置尽量靠近芯片。

## 3.5 ECL 集成电路（自学，考试少考）

**ECL（Emitter-Coupled Logic，发射极耦合逻辑）：用 BJT 工作在「放大区/非饱和区」，靠电流切换实现逻辑。**

| 特点 | 说明 |
|---|---|
| **速度最快** | t_pd 可低至 0.1~1 ns（因为 BJT 不进入饱和，无存储时间） |
| **功耗最大** | 每门几十 mW（电流源常开，静态就耗电） |
| **噪声容限小** | 只有 0.2~0.3V，抗干扰差 |
| **输出电平特殊** | −0.8V（逻辑 1）/ −1.6V（逻辑 0），**是负电源系统**（V_EE = −5.2V） |
| **不能与 TTL/CMOS 直接接口** | 需专用电平转换器 |

**用途**：超高速场合（如高速计数器、频率合成器），现在基本被高速 CMOS 取代。

## 3.6 Bi-CMOS 电路

**Bi-CMOS：把 CMOS 和双极型器件做在同一芯片上——输入级和内部逻辑用 CMOS（低功耗、高集成度），输出级用 BJT（大驱动电流）。**

| 优点 | 说明 |
|---|---|
| 驱动能力强 | BJT 输出可提供几十 mA，能直接驱动总线 |
| 静态功耗低 | 内部逻辑是 CMOS |
| 速度快 | BJT 输出级的上升/下降时间短 |

**典型应用**：微处理器的总线驱动、大容量存储器的输出缓冲。

## 3.7 不同类型数字集成电路间的接口

**接口的核心问题：一个电路的输出电平（V_OH、V_OL）能否满足另一个电路的输入要求（V_IH、V_IL），以及驱动电流是否足够。**

**接口成功的四个条件：**
```
① V_OH(驱动) ≥ V_IH(负载)        电平要够高
② V_OL(驱动) ≤ V_IL(负载)        电平要够低
③ |I_OH(驱动)| ≥ n·|I_IH(负载)|  高电平拉电流能力足够
④ I_OL(驱动) ≥ n·|I_IL(负载)|    低电平灌电流能力足够
```

### 3.7.1 CMOS 与 TTL 的接口

**（一）TTL 驱动 CMOS（74HC）——有问题！**
```
TTL 输出：V_OH(min) = 2.4 V
74HC 输入：V_IH(min) = 3.5 V   （V_DD = 5V 时）
2.4 < 3.5  → 不满足条件①，接口失败！
```
**解决方案：**
1. **改用 74HCT 系列**（V_IH = 2.0V），直接兼容 ✓ **最常用**
2. **加一个上拉电阻 R 到 V_DD**：
```
   TTL输出 ──┬─── 74HC输入
             │
            [R = 2~10kΩ]
             │
            V_DD (+5V)
```
   TTL 输出高时，R 把电平拉高到接近 V_DD。但必须核算 TTL 的 I_OH 是否够（一般可以，因为 CMOS 的 I_IH ≈ 0）。
3. **用专用的电平转换器**（如 74LS07 + 上拉，或 74HCT 缓冲器）。

**（二）CMOS 驱动 TTL —— 通常没问题，但要算驱动能力**
```
74HC 输出：V_OH(min) = 4.4 V ≥ TTL 的 V_IH(min) = 2.0 V  ✓
           V_OL(max) = 0.33 V ≤ TTL 的 V_IL(max) = 0.8 V  ✓
```
**主要问题是驱动电流**：74HC 的 I_OL 只有约 4 mA，而 TTL 的 I_IL 是 0.4~1.6 mA。
```
N_OL = I_OL / I_IL = 4mA / 0.4mA = 10  （驱动 74LS 可以带 10 个输入）
```
**解决方案**（当需要驱动更多 TTL 负载时）：
1. **用 74HC 系列中的缓冲器/驱动器**（如 74HC244、74HC245，I_OL 达 24 mA）
2. **并联多个 CMOS 门**（但会增大输入电容）
3. **加晶体管驱动级**

### 3.7.2 用 CMOS 或 TTL 驱动其他负载

**（一）驱动 LED**

```
   TTL输出 ──[R]──►│── GND        ← 拉电流方式（LED 亮 = 输出高）
                                   TTL 的 I_OH 只有 0.4mA，太弱，不推荐

   TTL输出 ────────►│──[R]── VCC   ← 灌电流方式（LED 亮 = 输出低）
                                   TTL 的 I_OL 有 16mA，可以驱动
```
**限流电阻计算**：
```
       V_CC − V_F(LED) − V_OL
  R = ────────────────────────
              I_LED

  例：V_CC = 5V，红色 LED 的 V_F = 1.8V，V_OL = 0.3V，I_LED = 10mA
  R = (5 − 1.8 − 0.3) / 0.01 = 290 Ω   → 取标称值 300Ω
```
> **重点**：**用灌电流方式驱动 LED**（低电平点亮），因为大多数数字电路的**灌电流能力远大于拉电流能力**（TTL：16mA vs 0.4mA）。

**（二）驱动继电器 / 大电流负载**

```
   V_CC ──┬──────────────┐
          │            ┌─┴─┐
        ┌─┴─┐          │ ▲ │  ← 续流二极管（与线圈反向并联，泄放反电动势）
        │线圈│          └─┬─┘
        └─┬─┘            │
          └──────┬───────┘
                 │ 集电极 (C)
   数字输出 ─[R]──┤ 基极 (B)   ┌────────┐
                 └────────────►│ 三极管  ├── 发射极 (E) ── GND
                               └────────┘
   （基极支路只接数字输出和基极，**不能接地**；发射极才接地）
```

**（三）驱动高电压负载**

用 **OC 门 / OD 门**，把上拉电阻接到更高的电源：
```
   OC门输出 ──┬── 负载
              │
             [R]
              │
             +12V      ← 上拉电源可以高于 5V
```

## 典型例题

**例 3.1**（题型：MOS 管开关状态判断）
某 CMOS 反相器 V_DD = 5V，NMOS 阈值 V_TN = 2V，PMOS 阈值 V_TP = −2V。判断下列情况下两个管子的状态和输出电压：
（1）Vi = 0V；（2）Vi = 5V；（3）Vi = 2.5V。

**解**：
（1）Vi = 0V：
- NMOS：V_GS = 0 − 0 = 0V < V_TN = 2V → **截止**
- PMOS：V_GS = 0 − 5 = −5V < V_TP = −2V → **导通**
- 输出被 PMOS 拉向 V_DD → **Vo ≈ 5V（高电平）**

（2）Vi = 5V：
- NMOS：V_GS = 5 − 0 = 5V > 2V → **导通**
- PMOS：V_GS = 5 − 5 = 0V > V_TP = −2V → **截止**
- 输出被 NMOS 拉向地 → **Vo ≈ 0V（低电平）**

（3）Vi = 2.5V：
- NMOS：V_GS = 2.5V > 2V → **微弱导通**
- PMOS：V_GS = 2.5 − 5 = −2.5V < −2V → **微弱导通**
- **两个管子同时导通**，产生从 V_DD 到 GND 的直流通路 → **Vo 处于不确定的中间值（约 2.5V）**，功耗剧增。

**答案**：（1）Vo ≈ 5V；（2）Vo ≈ 0V；（3）两管同时导通，输出不定，**这是必须避免的「转折区」状态**。

**为什么这样做**：CMOS 反相器的正常工作要求输入**要么接近 V_DD、要么接近 GND**，不能停在阈值附近。这就是数字信号要求**上升/下降时间尽可能短**的原因——长时间停留在转折区会大幅增加功耗。

**例 3.2**（题型：OD 门上拉电阻计算）
三个 OD 门线与后驱动 4 个 CMOS 输入端。已知 V_DD = 5V，V_OL(max) = 0.33V，V_OH(min) = 4.4V，每个 OD 门的 I_OL(max) = 8mA，输出高电平时漏电流 I_OZ = 5μA；每个负载输入的 I_IL = 1μA，I_IH = 1μA。求上拉电阻 R 的取值范围。

**解**：
```
【下限】输出低电平时，最坏情况只有一个 OD 门导通，其余门截止（漏电 5μA 各流入）
       灌入 R 的电流 + 各漏电流 + 负载的 I_IL = I_OL 承担的电流
       大致预估：R_min ≈ (V_DD − V_OL(max)) / I_OL(max)
       = (5 − 0.33) / 8mA = 4.67V / 0.008A = 584 Ω

       严格公式（含漏电流）：
       R_min ≥ (V_DD − V_OL(max)) / [I_OL(max) − m·I_IL]
       m = 4（4 个负载输入）
       = 4.67 / (0.008 − 4×1μA) = 4.67 / (0.008 − 0.000004) ≈ 584.3 Ω
       取 R_min ≈ 585 Ω

【上限】输出高电平时，所有 OD 门截止，R 提供电流给负载的 I_IH 和各门的漏电流
       R_max ≤ (V_DD − V_OH(min)) / (m·I_OZ + n·I_IH)
       m = 3（3 个截止的 OD 门漏电），n = 4（4 个负载输入）
       = (5 − 4.4) / (3×5μA + 4×1μA)
       = 0.6V / (15 + 4)μA
       = 0.6 / 19×10⁻⁶
       = 31579 Ω ≈ 31.6 kΩ

综合：585 Ω ≤ R ≤ 31.6 kΩ
```

**答案**：R 的取值范围是 **585 Ω ~ 31.6 kΩ**，工程上取**中间偏小值**（如 4.7 kΩ），兼顾速度与功耗。

**为什么这样做**：R 太小 → 输出低电平时灌电流被 R 分流，可能拉不到 V_OL 以下；R 太大 → 输出高电平时 R 上的压降大，加上漏电流拉低电平。**取中间值是为了同时满足两个极端条件，同时兼顾上升时间（RC 充放电速度）。**

**例 3.3**（题型：噪声容限计算与比较）
已知某 TTL 门和某 CMOS 门（V_DD = 5V）的参数如下，分别计算噪声容限并比较抗干扰能力。

| 参数 | TTL | CMOS |
|---|---|---|
| V_OH(min) | 2.4 V | 4.4 V |
| V_OL(max) | 0.4 V | 0.33 V |
| V_IH(min) | 2.0 V | 3.5 V |
| V_IL(max) | 0.8 V | 1.5 V |

**解**：
```
【TTL】
V_NH = V_OH(min) − V_IH(min) = 2.4 − 2.0 = 0.4 V
V_NL = V_IL(max) − V_OL(max) = 0.8 − 0.4 = 0.4 V

【CMOS】
V_NH = 4.4 − 3.5 = 0.9 V
V_NL = 1.5 − 0.33 = 1.17 V
```

**答案**：TTL 的 V_NH = V_NL = **0.4 V**；CMOS 的 V_NH = **0.9 V**、V_NL = **1.17 V**。
**CMOS 的噪声容限约为 TTL 的 2~3 倍，抗干扰能力明显更强。**

**为什么这样做**：噪声容限 = 「驱动门保证的最低输出高电平」−「负载门要求的最高识别下限」，即**发送端最差输出与接收端最差要求之间的余量**。这个余量越大，能容忍的干扰就越大。

**例 3.4**（题型：扇出计算）
某 74LS 系列门电路参数：I_OH(max) = −0.4 mA，I_OL(max) = 8 mA，I_IH(max) = 20 μA，I_IL(max) = 0.4 mA。求该门的扇出系数。

**解**：
```
高电平扇出：N_OH = |I_OH(max)| / I_IH(max)
            = 0.4 mA / 20 μA
            = 400 μA / 20 μA
            = 20

低电平扇出：N_OL = I_OL(max) / I_IL(max)
            = 8 mA / 0.4 mA
            = 20
```

**答案**：扇出系数 **N = min(N_OH, N_OL) = 20**。即一个输出最多驱动 20 个同类门的输入端。

**为什么这样做**：输出既要满足「高电平时能给负载提供足够电流」，又要满足「低电平时能吸收负载的电流」。**两个条件必须同时满足，所以取小值。**

> **注意**：工程上不会真的带满 20 个（因为还要考虑电容负载导致的延迟增大），一般只用到扇出的 60%~70%。

**例 3.5**（题型：接口判断与设计）
某系统需要用一个 **74HC** 器件的输出驱动一个 **74LS** 器件的输入。已知：
- 74HC：V_OH(min)=4.4V，V_OL(max)=0.33V，I_OH=−4mA，I_OL=4mA
- 74LS：V_IH(min)=2.0V，V_IL(max)=0.8V，I_IH=20μA，I_IL=0.4mA

判断能否直接接口，最多能驱动几个 74LS 输入。

**解**：
```
【电平检查】
① V_OH(HC) = 4.4V ≥ V_IH(LS) = 2.0V  ✓
② V_OL(HC) = 0.33V ≤ V_IL(LS) = 0.8V  ✓
电平兼容。

【电流检查】
N_OH = 4mA / 20μA = 200
N_OL = 4mA / 0.4mA = 10
N = min(200, 10) = 10
```

**答案**：**可以直接接口**（电平兼容），最多驱动 **10 个** 74LS 输入端，受限于**低电平灌电流能力**（I_OL）。

**为什么这样做**：CMOS 的 V_OL 很低、V_OH 很高，电平上与 TTL 完全兼容；瓶颈在**电流**——因为 TTL 输入的低电平电流较大（0.4mA），而 CMOS 输出的灌电流能力较小。

**扩展**：若需要驱动超过 10 个输入，可**加一级 74LS 缓冲器**，或用 **74HC244/245** 这类大驱动能力的芯片。

**例 3.6**（题型：三态门总线分析）
下图中三个三态门共享一条总线，输出分别为 D₁、D₂、D₃，使能端为 EN₁、EN₂、EN₃（均为高有效）。问：
（1）要在总线上得到 D₂ 的值，三个使能端应如何设置？
（2）若 EN₁ 和 EN₂ 同时为 1，会发生什么？
（3）总线空闲（无任何门驱动）时，总线处于什么状态？

```
   D₁ ──┤▷├──┐
   EN₁ ──────┤
              │
   D₂ ──┤▷├──┼──── 总线
   EN₂ ──────┤
              │
   D₃ ──┤▷├──┘
   EN₃ ──────┘
```

**解**：
（1）要输出 D₂：**EN₂ = 1，EN₁ = 0，EN₃ = 0**。此时门 2 导通，门 1、门 3 输出高阻，总线电平由 D₂ 决定。

（2）EN₁ = 1 且 EN₂ = 1：两个门同时驱动总线。若 D₁ = 1（门 1 输出高，上管导通到 V_DD）、D₂ = 0（门 2 输出低，下管导通到 GND），则形成 **V_DD → 门1上管 → 总线 → 门2下管 → GND** 的低阻通路，**大电流流过，可能烧毁两个门**。这称为**总线冲突（bus contention）**。

（3）所有 EN 都为 0 时，三个门都是高阻，总线**浮空**。此时电平不确定，容易受干扰。工程上要加**上拉或下拉电阻**（如 10kΩ）把总线拉到确定电平。

**答案**：（1）EN₂=1，EN₁=EN₃=0；（2）总线冲突，可能烧毁器件；（3）高阻浮空，需加上拉/下拉电阻。

**为什么这样做**：三态门的价值在于**分时共享一根线**（总线）。规则是：**任一时刻至多一个门被使能**。这条规则由控制器（第 6 章的时序电路）保证。

**例 3.7**（题型：TTL 多余输入端处理）
一个 74LS00（四 2 输入与非门）只用了 1 个输入 A，另一个输入 B 悬空。分析这样做的后果，并给出正确处理方式。

**解**：
```
【TTL 悬空的电气效果】
TTL 的输入端是多发射极三极管的发射极。悬空时，该发射极没有电流流出，
T₁ 不会深饱和，效果相当于该输入接高电平（1）。

所以 Y = (A·B)' 中 B 等效为 1，Y = (A·1)' = A'。
功能上「看起来正确」。
```
**但存在问题**：
1. **悬空端极易受外界干扰**（空间电磁场、邻近信号串扰），电平可能抖动，导致输出误翻转。
2. **悬空端输入阻抗高**，会成为天线接收噪声。
3. 在生产环境中，悬空引脚可能因静电损坏。

**正确处理方式**（三种，任选其一）：
```
方式①：接高电平（推荐）
   A ──┤
        ├─ 与非门 ── Y = A'
   B ──┤
   B 接 V_CC（通过 1kΩ 电阻限流更安全）

方式②：与 A 并联
   A ──┬─┤
       │  ├─ 与非门 ── Y = A'
   A ──┴─┤
   （两个输入接在一起，用 A 驱动）
   缺点：输入电容加倍，速度略降

方式③：把多余输入**经一个 1~10 kΩ 电阻接到 V_CC**（也可以直接接 V_CC）
   —— 串电阻是为了万一输入端的钳位二极管击穿时限流，工程上更稳妥
```

**答案**：TTL 输入端悬空**电气上等效为高电平**，功能上「能用」，但**工程上禁止悬空**，应接 V_CC（或与有效输入并联）。

**为什么这样做**：数字电路的可靠性要求每个输入都有**确定的电平**。悬空 = 不确定 = 隐患。

> **对比提醒**：**CMOS 悬空更危险**——CMOS 输入阻抗高达 10¹² Ω，悬空时栅极电位由极小的漏电流决定，可能停在阈值附近，导致**NMOS 和 PMOS 同时导通**，静态功耗从 μW 级飙升到 mW 级，长时间可烧毁。**所以 CMOS 的多余输入端必须明确接 V_DD 或 GND。**

**例 3.8**（题型：LED 驱动电路设计）
用一个 74LS 门驱动一个红色 LED（V_F = 1.8V，I_LED = 10 mA），V_CC = 5V。已知该门 I_OL(max) = 8mA，I_OH(max) = 0.4mA，V_OL = 0.3V。设计驱动电路并计算限流电阻。

**解**：
```
【方案比较】
方案一（拉电流，高电平点亮）：
   需要 I_OH ≥ 10mA，但只有 0.4mA → 不可行 ✗

方案二（灌电流，低电平点亮）：
   需要 I_OL ≥ 10mA，有 8mA → 10mA > 8mA，超限 ✗
   改为 I_LED = 6mA（在 8mA 以内）→ 可行 ✓

【电阻计算】（灌电流方式，LED 接在输出与 V_CC 之间）
       V_CC − V_F − V_OL
  R = ────────────────────
             I_LED
       (5 − 1.8 − 0.3) V     2.9 V
    = ────────────────── = ─────── = 483 Ω
            6 mA            0.006 A
```

**答案**：采用**灌电流方式**（LED 阳极经限流电阻接 V_CC，阴极接门输出），限流电阻 **R ≈ 483 Ω，取标称值 470 Ω 或 510 Ω**，LED 电流约 6 mA。

**电路：**
```
   V_CC (+5V)
     │
    [R = 470Ω]
     │
    LED ▼（阳极在上，阴极在下）
     │
   门输出 ──┤▷├──  （输出低电平时 LED 亮）
```

**为什么这样做**：数字电路输出的**灌电流能力远大于拉电流能力**（本门：8mA vs 0.4mA）。设计驱动电路时优先选**低电平有效**的接法。同时，LED 电流不能超过 I_OL(max)，否则输出低电平会被抬高（V_OL 超标），导致后级误判。

## 易错点提醒

1. **CMOS 与门/或门的存在性搞错** → **CMOS 没有单级的与门和或门**。与门 = 与非门 + 反相器（6 个 MOS 管），或门 = 或非门 + 反相器。**这是「与非门最便宜」的根本原因**，也是逻辑式要变换成与非-与非式的原因。
2. **PMOS 的导通条件记反** → **NMOS 高电平导通，PMOS 低电平导通**（栅源电压相对于源极）。把 PMOS 说成「高电平导通」是经典错误。
3. **忽略 CMOS 的静态功耗与动态功耗区别** → **静态功耗 ≈ 0**（总是一管导通一管截止）；功耗主要来自**切换瞬间的动态功耗 `P = C·V_DD²·f`**。所以频率越高功耗越大。
4. **噪声容限公式方向记反** → **`V_NH = V_OH(min) − V_IH(min)`，`V_NL = V_IL(max) − V_OL(max)`**。记忆法：**都是「输出保证值」减「输入要求值」**。V_OH 和 V_IH 比（高的那个减），V_IL 和 V_OL 比（高的那个减）。**记住「大的减小的」**。
5. **扇出取大值** → **扇出 = min(高电平扇出, 低电平扇出)**，必须取**小**值，因为两个条件都要满足。
6. **把 OD/OC 门和三态门的作用搞混** →
   - **OC/OD 门**：为了**线与**和**驱动高电压负载**，需要上拉电阻，高电平靠外部电阻提供。
   - **三态门**：为了**总线分时共享**，不需要上拉电阻，能输出真正的高电平。
   - 三态门**不能线与**（会冲突），OC/OD 门**可以线与**。
7. **推拉输出直接并联** → **普通推拉（图腾柱）输出的两个门绝对不能并联**，会形成低阻通路烧毁。要线与必须用 OC/OD 门。
8. **TTL 悬空当高电平、CMOS 也照做** → **TTL 悬空电气上≈高电平（但工程上禁止）；CMOS 悬空是危险状态（会烧毁）**。这个对比是常考简答题。
9. **接口只检查电平不检查电流** → 接口有**四个条件**：`V_OH ≥ V_IH`、`V_OL ≤ V_IL`、`|I_OH| ≥ nI_IH`、`I_OL ≥ nI_IL`。**电平对了不代表能驱动**（例 3.5 就是电平兼容但驱动数受限）。
10. **74HC 与 74HCT 不加区分** → 关键差异在**输入高电平门限**：HC 是 3.5V，HCT 是 2.0V。**TTL 驱动 HC 会失败，驱动 HCT 可以**。
11. **二极管门电路可以级联** → **不能！** 每级有 0.7V 电平偏移，级联后信号衰减到无法识别。这是二极管门被淘汰的原因。
12. **忽略传输门的必要性** → 单用 NMOS 传输高电平会有 `V_DD − V_TN` 的损失，单用 PMOS 传输低电平会有 `|V_TP|` 的损失。**必须 NMOS + PMOS 并联**才能全摆幅传输。
13. **以为 ECL 是 CMOS** → ECL 是**双极型**（Emitter-Coupled Logic），特点是**最快但功耗最大**，输出是**负电平**（−0.8V/−1.6V），需负电源。

## 本章小结

1. 门电路分双极型（TTL、ECL，快但耗电）和单极型（CMOS，省电、集成度高）。
2. **二极管与门/或门**：结构简单但**有 0.7V 电平偏移，不能级联**。
3. **CMOS 反相器**：PMOS + NMOS 串联，`Vo = Vi'`，静态功耗几乎为零。**NMOS 高电平导通，PMOS 低电平导通**。
4. **CMOS 门规律**：NMOS 网络拉低、PMOS 网络拉高，两网**互为对偶（串↔并）**。与非门 = PMOS 并联 + NMOS 串联；或非门相反。
5. **CMOS 无单级与门/或门**，都需要与非/或非门 + 反相器。这是「与非门最便宜」的原因。
6. **传输门** = NMOS + PMOS 并联，双向传输、全摆幅，用于多路选择器和锁存器。
7. **OD/OC 门**：输出开路，需外接上拉电阻，**可实现线与**，能驱动高电压负载。R 有上下限，公式见 3.3.5。
8. **三态门**：输出有高、低、**高阻 Z** 三态，用于**总线分时共享**；任一时刻只能使能一个，否则总线冲突。
9. **静态参数**：`V_NH = V_OH(min) − V_IH(min)`、`V_NL = V_IL(max) − V_OL(max)`。**TTL 都是 0.4V，CMOS 约 1V**（CMOS 抗干扰更强）。
10. **扇出**：`N = min(I_OH/I_IH, I_OL/I_IL)`，**取小值**。TTL 典型 20，CMOS 可达数百。
11. **系列**：74HC（V_IH=3.5V）、**74HCT（V_IH=2.0V，与 TTL 兼容）**、74LS（经典 TTL）。
12. **接口四条件**：`V_OH ≥ V_IH`、`V_OL ≤ V_IL`、`|I_OH| ≥ nI_IH`、`I_OL ≥ nI_IL`。**TTL 驱动 74HC 不兼容，改用 74HCT 或加上拉电阻。**
13. **多余输入端**：TTL 悬空≈高电平（但禁止悬空）；**CMOS 悬空会烧毁，必须接 V_DD 或 GND**。

> **一句话记住本章**：**逻辑门就是「用电控制的开关」——CMOS 用互补的 MOS 管对搭出最省电的门，TTL 用三极管搭出最快的门；而 OD 门和三态门解决的是「多个输出怎么共享一根线」这个工程问题。**

## 自测题

**1.** CMOS 反相器中，当输入为高电平时，哪个管子导通？输出是什么电平？

**2.** 为什么 CMOS 门电路要实现「与」逻辑时，NMOS 网络用串联、PMOS 网络用并联？

**3.** 已知某 CMOS 门 V_DD = 5V，V_OH(min) = 4.9V，V_OL(max) = 0.1V，V_IH(min) = 3.5V，V_IL(max) = 1.5V。求 V_NH 和 V_NL。

**4.** 某门的 I_OH(max) = 0.5mA，I_OL(max) = 10mA，I_IH = 25μA，I_IL = 0.5mA。求扇出系数。

**5.** OC 门与三态门都能接总线，它们各自适合什么场合？为什么三态门不适合线与？

**6.** 一个 74LS 输出要驱动一个 74HC 输入（V_IH = 3.5V），而 74LS 的 V_OH(min) = 2.4V。说明为什么不兼容，并给出两种解决办法。

**7.** TTL 门的多余输入端为什么不能悬空？悬空在电气上等效于什么？CMOS 呢？

**8.** 用灌电流方式驱动 LED：V_CC = 5V，V_F = 2.0V，V_OL = 0.3V，要求 I_LED = 8mA。求限流电阻。

**9.** 某 CMOS 传输门只用一个 NMOS 管传输 5V 高电平，V_TN = 2V。输出电压最高能到多少？为什么？

**10.** 判断：CMOS 门电路的静态功耗很大，因为 NMOS 和 PMOS 总是同时导通。

---

### 自测题答案

**1.** 输入为高电平时，**NMOS 导通**（V_GS = 5V > V_TN），PMOS 截止（V_GS = 0V，不满足 < V_TP）。输出**低电平（≈0V）**。

**2.** 「与」逻辑要求**所有输入都为 1 时输出才满足条件**。
- 拉低网络（NMOS）：只有当**所有** NMOS 都导通，输出才能被拉到地 → 必须**串联**。
- 拉高网络（PMOS）：只要**任一** PMOS 导通，输出就能被拉到 V_DD；要让「所有输入为 1」时输出不被拉高，即每个输入为 1 时对应的 PMOS 都应截止，只有**所有 PMOS 都截止**才不拉高 → 需要**并联**（因为 PMOS 是低电平导通，输入为 1 时它截止）。
- 两者的通断条件互为对偶，所以**串↔并**对应。

**3.**
```
V_NH = V_OH(min) − V_IH(min) = 4.9 − 3.5 = 1.4 V
V_NL = V_IL(max) − V_OL(max) = 1.5 − 0.1 = 1.4 V
```

**4.**
```
N_OH = I_OH / I_IH = 0.5mA / 25μA = 500μA / 25μA = 20
N_OL = I_OL / I_IL = 10mA / 0.5mA = 20
N = min(20, 20) = 20
```
**扇出系数为 20。**

**5.**
- **OC/OD 门**适合：① **线与**（多个输出直接相连实现「与」）；② **驱动高电压/大电流负载**（上拉电源可高于 V_DD）。
- **三态门**适合：**总线分时共享**（多个门挂一根总线，任一时刻只使能一个），速度快、无需上拉电阻。
- **三态门不能线与的原因**：三态门输出高电平时上管导通到 V_DD，输出低电平时下管导通到 GND。若两个三态门同时使能且输出相反，就会形成 **V_DD→上管→输出线→下管→GND** 的低阻通路，产生大电流，**烧毁器件**。而 OC/OD 门没有上管，输出高电平完全靠外部上拉电阻，不存在这种直流通路，所以能安全地线与。

**6.**
- **不兼容原因**：74LS 输出的最低保证高电平 `V_OH(min) = 2.4V`，而 74HC 要求输入至少 `V_IH(min) = 3.5V`。`2.4V < 3.5V`，**高电平可能不足以被识别为 1**，导致逻辑错误。
- **解决办法一**：改用 **74HCT** 系列（V_IH = 2.0V），可直接兼容。
- **解决办法二**：在 74LS 输出与 74HC 输入之间加**上拉电阻**（2~10 kΩ）接到 V_DD，把高电平拉高到接近 5V（因为 74HC 输入电流极小，几乎不在电阻上产生压降）。
- （补充办法三：加一级 74HCT 缓冲器。）

**7.**
- **TTL 多余输入端不能悬空的原因**：悬空端极易**接收外界电磁干扰**，电平可能抖动，导致输出误翻转；且悬空引脚的输入阻抗高，相当于一根天线。
- **悬空在电气上等效于接高电平**（因为 TTL 输入是多发射极三极管，悬空的发射极无电流流出，效果与接高电平相同）。
- **CMOS**：悬空**更危险**。CMOS 输入阻抗高达 10¹² Ω，悬空时栅极电位不确定，可能停在阈值附近，导致 **NMOS 和 PMOS 同时导通**，静态功耗激增，长时间可烧毁器件。**CMOS 多余输入必须明确接 V_DD（与/与非门）或 GND（或/或非门）。**

**8.**
```
       V_CC − V_F − V_OL
  R = ────────────────────
             I_LED
       (5 − 2.0 − 0.3) V     2.7 V
    = ────────────────── = ─────── = 337.5 Ω
             8 mA           0.008 A
```
**R ≈ 337.5 Ω，取标称值 330 Ω（此时 I_LED ≈ 8.2 mA，略超）或 360 Ω（I_LED ≈ 7.5 mA，更安全）**。推荐 **360 Ω**。

**9.** 用单个 NMOS 传输 5V 高电平，**输出电压最高只能到 `V_DD − V_TN = 5 − 2 = 3 V`**。
原因：NMOS 导通的条件是 `V_GS > V_TN`。当输出（源极）电位升高到 `V_out` 时，`V_GS = V_G − V_out = 5 − V_out`。要维持导通需要 `5 − V_out > 2`，即 `V_out < 3V`。当 `V_out` 接近 3V 时，NMOS 进入临界导通，**无法继续把输出拉高**，高电平被「削顶」。
**解决办法**：并联一个 PMOS 构成传输门。传输高电平时 PMOS 的源极电位低（相对栅极），能充分导通，从而传输完整的 5V。

**10.** **错误。**
CMOS 门电路的**静态功耗极小**（μW 级），因为稳态时 NMOS 和 PMOS **总是一个导通、一个截止**，电源到地之间**没有直流通路**。
「两个管子同时导通」只发生在**输入电平处于阈值附近（转折区）**的短暂瞬间，以及**状态切换的过渡过程**中。由此产生的功耗是**动态功耗** `P = C·V_DD²·f`，它与**工作频率 f 成正比**——频率越高，切换越频繁，功耗越大。
