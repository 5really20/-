## 5.5 存储器

### 5.5.1 存储器的基本结构

**存储器（Memory）：由大量存储单元组成的阵列，每个存储单元存放 1 位二进制数据。**

**基本结构框图：**
```
                    ┌───────────────────────────────┐
                    │           存储器               │
                    │                               │
   A₀~Aₙ₋₁ ────────►│  ┌──────────┐   ┌─────────┐  │
     (地址)         │  │  地址     │   │  存储   │  │
                    │  │  译码器   ├──►│  矩阵   │  │
                    │  └──────────┘   │(2ⁿ个字×m位)│
                    │                 └────┬────┘  │
   CS' ────────────►│  ┌──────────┐        │       │
   (片选)           │  │  读写     │◄───────┤       │
   WE' ────────────►│  │  控制电路 │        │       │
   (写允许)         │  └──────────┘        │       │
                    │                      ▼       │
   D₀~Dₘ₋₁ ◄────────┤         (数据输入/输出)       │
     (数据)         │                               │
                    └───────────────────────────────┘
```

**各部分作用：**

| 部件 | 作用 |
|---|---|
| **地址译码器** | 把 n 位地址译成 2ⁿ 根字线，**选中其中一个存储单元**（或一行） |
| **存储矩阵** | 2ⁿ 个字 × m 位的存储单元阵列 |
| **读写控制电路** | 根据 `CS'`（片选）和 `WE'`（写允许）决定**读**还是**写** |

**存储容量的表示方法：**
```
   容量 = 字数 × 每字位数
   例：1024 × 4 位 = 1K × 4
       读作「1024 个字，每个字 4 位」
       总存储单元数 = 1024 × 4 = 4096 个
```

**常用容量单位：**
```
   1K = 2¹⁰ = 1024
   1M = 2²⁰ = 1 048 576
   1G = 2³⁰ = 1 073 741 824
```

**地址线与字数的关系（重要）：**
```
   n 根地址线 → 2ⁿ 个字
   10 根地址线 → 2¹⁰ = 1K 个字
   11 根地址线 → 2¹¹ = 2K 个字
   16 根地址线 → 2¹⁶ = 64K 个字
```

### 5.5.2 静态随机存取存储器（SRAM）

**SRAM（Static Random Access Memory）：静态随机存取存储器。**

**存储单元（6 管单元）：用两个反相器交叉耦合 + 两个门控管。**

```
              V_DD
               │
        ┌──────┴──────┐
        │             │
     ┌──┴──┐       ┌──┴──┐
     │ T₃  │       │ T₄  │     ← 两个反相器交叉耦合（双稳态）
     └──┬──┘       └──┬──┘
        │             │
        ├───Q      Q'─┤
        │             │
     ┌──┴──┐       ┌──┴──┐
     │ T₁  │       │ T₂  │     ← 门控管（受字线控制）
     └──┬──┘       └──┬──┘
        │             │
   位线 B ────────  位线 B'
        │             │
        └──（字线 W 控制 T₁、T₂ 的栅极）──┘
```

**工作原理：**
- **字线 W = 0**：T₁、T₂ 截止，单元与位线隔离，**数据保持**（靠双稳态自锁）。
- **字线 W = 1**：T₁、T₂ 导通，单元与位线接通。
  - **读**：位线 B 和 B' 上出现与 Q 互补的电压，经读出放大器输出。
  - **写**：把要写的数据送到位线 B 和 B'（互补），强制双稳态翻转。

**SRAM 的特点：**
```
   ① 用双稳态电路存储 → 只要不断电，数据永久保持
   ② 不需要刷新
   ③ 速度快（读/写时间 10~100 ns）
   ④ 单元面积大（6 个管子）→ 集成度低、成本高
   ⑤ 功耗较大（静态有电流）
   ⑥ 用途：高速缓存（Cache）、小容量高速存储
```

**同步 SRAM（Synchronous SRAM）：** 在 SRAM 内部集成地址寄存器和数据寄存器，**读写操作与时钟同步**。优点是可以做成流水线（Pipeline），速度更快。

### 5.5.3 动态随机存取存储器（DRAM）

**DRAM（Dynamic Random Access Memory）：动态随机存取存储器。**

**存储单元（1 管 + 1 电容）：**
```
        字线 W
           │
        ┌──┴──┐
        │  T  │    ← 门控管（MOS）
        └──┬──┘
           │
           ├────── 位线 B
           │
          ─┴─
          ───  C_S    ← 存储电容（约 20~30 fF）
          ─┬─
           │
          GND
```

**工作原理：**
- **写入**：字线 W = 1（选中），数据从位线 B 经 T 存入电容 C_S（充电=1，放电=0）。
- **读出**：字线 W = 1，电容上的电荷通过 T 送到位线上，由**灵敏放大器（Sense Amplifier）**检测位线的微小电压变化。

> **重点**：**DRAM 为什么必须刷新？**
> 电容 C_S 会通过漏电流缓慢放电。典型情况下，**经过 2 ms 左右电荷就会损失到无法辨认**。因此必须在 **2 ms 之内**把每个单元读出一次并重新写入（**刷新，Refresh**）。
> 所以 DRAM 的正确名称是「**动态**」——数据不能永久保持。

**DRAM 的刷新方式：**

| 方式 | 做法 | 优缺点 |
|---|---|---|
| **集中刷新** | 在 2 ms 内的某个时间段集中刷新所有行，其余时间正常读写 | 有**"死时间"**（刷新期间不能访问），但结构简单 |
| **分散刷新** | 把刷新分散到每个读/写周期之后（每个存取周期 = 读/写 + 刷新） | **无死时间**，但**存取周期加倍**（速度减半） |
| **异步刷新** | 把 2 ms 分成若干段，每段刷新一行（如 2 ms / 128 行 = 每 15.6 μs 刷新一行） | **折中方案，最常用** |

**DRAM 的特点：**
```
   ① 单元面积小（1 管 + 1 电容）→ 集成度最高、成本最低
   ② 需要刷新（每 2 ms 一遍）
   ③ 速度较慢（读/写时间 40~100 ns）
   ④ 读出是破坏性的（必须读后重写）
   ⑤ 用途：主内存（Memory）
```

**SRAM 与 DRAM 对比表（考试常考）：**

| 比较项 | **SRAM** | **DRAM** |
|---|---|---|
| **存储原理** | 双稳态（触发器） | **电容电荷** |
| **单元管数** | 6 管 | **1 管 + 1 电容** |
| **需要刷新** | **不需要** | **需要（2 ms 内一遍）** |
| **读出是否破坏** | 非破坏性 | **破坏性（需重写）** |
| **速度** | **快**（10~100 ns） | 慢（40~100 ns） |
| **集成度** | 低 | **高** |
| **功耗** | 大（静态电流） | 小 |
| **成本** | 高 | **低** |
| **典型用途** | **Cache（高速缓存）** | **主存（内存条）** |

> **记忆口诀**：**「S 是 Static（静态）——不用刷新但费管子；D 是 Dynamic（动态）——要刷新但省管子」。**

### 5.5.4 只读存储器（ROM）

**ROM（Read-Only Memory）：只读存储器。** 正常工作时只能读出，不能写入（或写入需要特殊条件）。

#### （一）掩膜 ROM（Mask ROM）

**数据在制造时由掩膜决定，用户不能修改。**

**结构：地址译码器 + 存储矩阵（二极管或三极管阵列）**

**存储矩阵的两种表示：**
```
   有管子 = 存 1（或 0），无管子 = 存 0（或 1）

        W₀ ──┬──┤>o──┐
             │      │
        W₁ ──┼──────┼──┤>o──┐
             │      │      │
             ▼      ▼      ▼
        D₀    █      ○     █       █ = 有管子（存 1）
        D₁    ○      █     █       ○ = 无管子（存 0）
        D₂    █      █     ○
        D₃    ○      ○     █
```

**特点**：**成本最低（大批量时）、速度较快、不可改写**。适用于**固定程序或字库**。

#### （二）PROM（Programmable ROM，可编程 ROM）

**出厂时全是 1（或全是 0），用户可以用专用编程器烧断熔丝，一次性写入。**

```
   熔丝（Fuse）结构：
        W ──┬──[熔丝]──┬── D
            │          │
            └──（三极管/二极管）
   编程：熔丝烧断 → 该位变为 0（不可恢复）
```

**特点**：**只能编程一次（OTP, One-Time Programmable）**。

#### （三）EPROM（Erasable PROM，可擦除可编程 ROM）

**用浮栅 MOS 管（FAMOS）存储电荷，可用紫外线擦除。**

```
   浮栅 MOS 管结构：
        ┌──────────────┐
        │  控制栅（CG） │
        ├──────────────┤
        │  浮栅（FG）   │ ← 注入的电荷被"困"在这里
        ├──────────────┤
   S ───┤  沟道        ├─── D
        └──────────────┘
```

**特点：**
- **写入**：用较高电压把电荷注入浮栅（需要专门的 EPROM 编程器）。
- **擦除**：用**紫外线（UV）**照射芯片窗口 **15~30 分钟**，电荷被激发跑掉。
- **可重复擦写**（约 100~1000 次）。
- **石英窗口芯片，封装成本高**。

#### （四）EEPROM（E²PROM，电可擦除可编程 ROM）

**用电信号擦除，不需要紫外线。**

**特点：**
- **可以在线（In-System）擦写**，不需要拆下芯片。
- 擦写电压只需 5V（部分芯片需要 12V 编程电压）。
- **擦写速度慢**（ms 级），**擦写次数有限**（10⁴~10⁶ 次）。
- **可按字节擦写**。

#### （五）Flash Memory（闪速存储器）

**在 EEPROM 基础上发展起来，兼具高集成度和电可擦除的优点。**

```
   特点：
   ① 用电擦除，但以"块（Block）"为单位，不是按字节
   ② 集成度接近 DRAM，成本低
   ③ 擦写次数 10⁴~10⁵ 次
   ④ 断电后数据不丢失（非易失性）
   ⑤ 读速度快，写/擦速度慢
   应用：U 盘、SSD、手机存储、BIOS 芯片
```

**ROM 家族总结对比表（★★★）：**

| 类型 | 能否写入 | 擦除方式 | 擦写次数 | 速度 | 典型用途 |
|---|---|---|---|---|---|
| **掩膜 ROM** | **不能**（出厂固化） | 不可擦 | — | 快 | 大批量固定程序、字库 |
| **PROM** | **一次** | 不可擦 | **1 次** | 快 | 小批量、一次性产品 |
| **EPROM** | 可重复 | **紫外线（15~30 min）** | 100~1000 | 快 | 开发阶段（已淘汰） |
| **EEPROM** | 可重复 | **电擦除（按字节）** | 10⁴~10⁶ | **慢** | 参数存储、配置数据 |
| **Flash** | 可重复 | **电擦除（按块）** | 10⁴~10⁵ | 读快写慢 | **U 盘、SSD、BIOS** |

> **重点**：ROM 的名字叫"只读"，但**除了掩膜 ROM，其他都是可以写入的**。区别在于**是否可擦除、用什么方式擦除、能擦多少次**。

### 5.5.5 存储器的容量扩展（★★★ 必考）

**实际需要的容量往往与单片芯片不符，需要用多片芯片组合成所需容量。**

#### （一）位扩展（Bit Expansion）

**当「字数够、位数不够」时使用。**

**做法：把多片芯片的地址线、片选线、读写控制线全部并联；数据线分别引出。**

**例**：用 `1K × 4` 的芯片组成 `1K × 8` 的存储器。

**分析：**
```
   需要的字数：1K   → 单片就是 1K ✓（字数够）
   需要的位数：8    → 单片只有 4  → 需要 8/4 = 2 片
   采用位扩展
```

**连线图：**
```
                   ┌──────────────┐
                   │  1K × 4      │
   A₀~A₉ ─────┬───►│ A₀~A₉       │
              │    │              │
   CS' ───────┼───►│ CS'          │
              │    │         D₀~D₃├────► 数据总线 D₀~D₃
   WE' ───────┼───►│ WE'          │
              │    └──────────────┘
              │    ┌──────────────┐
              │    │  1K × 4      │
              └───►│ A₀~A₉       │
                   │              │
              ┌───►│ CS'          │
              │    │         D₀~D₃├────► 数据总线 D₄~D₇
              └───►│ WE'          │
                   └──────────────┘

   地址线 A₀~A₉：两片**并联**（同时选中同一地址）
   片选 CS'：两片**并联**（同时选中）
   读写 WE'：两片**并联**
   数据线：芯片 1 提供 D₀~D₃，芯片 2 提供 D₄~D₇（**分开**）
```

**结论**：**位扩展时，地址线、片选、读写线全部并联；数据线分段使用。需要的芯片数 = 目标位数 ÷ 单片位数 = 8/4 = **2 片**。**

#### （二）字扩展（Word Expansion）

**当「位数够、字数不够」时使用。**

**做法：把多片芯片的数据线、读写控制线并联；用高位地址经译码器产生片选信号。**

**例**：用 `1K × 8` 的芯片组成 `4K × 8` 的存储器。

**分析：**
```
   需要的位数：8   → 单片就是 8 ✓（位数够）
   需要的字数：4K  → 单片只有 1K  → 需要 4K/1K = 4 片
   需要地址线：4K 需要 log₂(4096) = 12 根地址线 A₀~A₁₁
   单片需要地址线：1K 需要 log₂(1024) = 10 根 A₀~A₉
   → 多出的 2 根 A₁₀、A₁₁ 用来做**片选译码**
```

**连线图：**
```
                          ┌──────────────┐
                          │ 2-4 译码器    │
   A₁₁ ──────────────────►│ A₁          │      ← 高位地址接译码器高位
   A₁₀ ──────────────────►│ A₀          │      ← 低位地址接译码器低位
                          │              │
                          │ Y₀ Y₁ Y₂ Y₃  │
                          └──┬──┬──┬──┬──┘
                             │  │  │  │
   A₀ ~ A₉ ──────────────────┼──┼──┼──┼─────────────────┐
   D₀ ~ D₇ ◄─────────────────┼──┼──┼──┼──────────────┐  │
   WE' ──────────────────────┼──┼──┼──┼───────────┐  │  │
                          ┌──▼┐┌──▼┐┌──▼┐┌──▼┐     │  │  │
                          │1K×8││1K×8││1K×8││1K×8│   │  │  │
                          │ #0 ││ #1 ││ #2 ││ #3 │   │  │  │
                          └───┘└───┘└───┘└───┘       │  │  │
                           片0   片1   片2   片3     │  │  │
                          (0~3FF)(400~7FF)(800~BFF)(C00~FFF)
```

**地址分配表：**

| 芯片 | A₁₁ | A₁₀ | 地址范围（十六进制） | 片选信号 |
|---|---|---|---|---|
| **#0** | 0 | 0 | 000 ~ 3FF | Y₀ |
| **#1** | 0 | 1 | 400 ~ 7FF | Y₁ |
| **#2** | 1 | 0 | 800 ~ BFF | Y₂ |
| **#3** | 1 | 1 | C00 ~ FFF | Y₃ |

**结论**：**字扩展时，数据线、读写线全部并联；地址线低位（A₀~A₉）并联，高位（A₁₀、A₁₁）经译码器产生片选。需要的芯片数 = 目标字数 ÷ 单片字数 = 4K/1K = **4 片**。**

#### （三）字位同时扩展

**当「字数、位数都不够」时使用。**

**例**：用 `1K × 4` 的芯片组成 `4K × 8` 的存储器。

**分析：**
```
   位数：需要 8，单片 4 → 位方向需要 8/4 = 2 组
   字数：需要 4K，单片 1K → 字方向需要 4K/1K = 4 组
   总片数 = 2 × 4 = **8 片**
   地址线总数：4K 需要 12 根 A₀~A₁₁
     其中 A₀~A₉ 接各片的地址输入（片内寻址）
          A₁₀、A₁₁ 经 2-4 译码器产生片选
```

**连线框图：**
```
                       ┌──────────────┐
   A₁₀,A₁₁ ───────────►│ 2-4 译码器    │
                       └──┬──┬──┬──┬──┘
                          │  │  │  │
              ┌───────────┘  │  │  └───────────┐
              │      ┌───────┘  └───────┐      │
              ▼      ▼                  ▼      ▼
         ┌──────────────┐          ┌──────────────┐
         │  第 0 组      │          │  第 3 组      │
         │ ┌────┐┌────┐ │          │ ┌────┐┌────┐ │
   A₀~A₉ │ │1K×4││1K×4│ │   ...    │ │1K×4││1K×4│ │
   ──────┼►│ #0 ││ #1 │ │          │ │ #6 ││ #7 │ │
         │ │D₀~₃││D₄~₇│ │          │ │D₀~₃││D₄~₇│ │
         │ └────┘└────┘ │          │ └────┘└────┘ │
         └──────────────┘          └──────────────┘
             片选 = Y₀                  片选 = Y₃
             地址 000~3FF               地址 C00~FFF

   规律：**每一组内部是"位扩展"（数据线分段），组与组之间是"字扩展"（片选不同）**
```

**片上地址分配：**

| 组 | A₁₁ | A₁₀ | 片 #（低/高 4 位） | 地址范围 |
|---|---|---|---|---|
| **组 0** | 0 | 0 | #0（D₀~D₃）+ #1（D₄~D₇） | 000 ~ 3FF |
| **组 1** | 0 | 1 | #2 + #3 | 400 ~ 7FF |
| **组 2** | 1 | 0 | #4 + #5 | 800 ~ BFF |
| **组 3** | 1 | 1 | #6 + #7 | C00 ~ FFF |

> **★ 容量扩展三步法（通用解题套路）：**
> ```
> ① 算片数：总片数 = (目标字数 / 单片字数) × (目标位数 / 单片位数)
> ② 分地址：目标地址线数 n = log₂(目标字数)
>           片内地址线数 k = log₂(单片字数)
>           → A₀ ~ A_{k-1} 并联到所有芯片（片内寻址）
>           → A_k ~ A_{n-1} 送译码器产生片选
> ③ 连数据：位方向分组，每组内的芯片数据线拼接成完整的字宽
> ```

---

### 5.5.6 用存储器实现组合逻辑函数（★ 必考）

**核心原理：ROM 的地址译码器就是一个「最小项发生器」，存储矩阵就是一个「或阵列」。**

**ROM 的结构本质上就是一个「与阵列（固定）+ 或阵列（可编程）」：**
```
   A₀ ──┬──[非门]──┬───────────────────────┐
        │          │                       │
   A₁ ──┼──[非门]──┼───────────┐           │
        │          │           │           │
        ▼          ▼           ▼           ▼
   ┌─────────────────────────────────────────────┐
   │           地址译码器（与阵列，固定）           │
   │  产生 2ⁿ 根字线 W₀ ~ W_{2ⁿ-1}                │
   │  Wᵢ = 1  ⟺  地址 = i  ⟺  第 i 个最小项 mᵢ = 1│
   └────────┬────┬────┬────┬────────────────────┘
            │    │    │    │
            ▼    ▼    ▼    ▼
   ┌─────────────────────────────────────────────┐
   │           存储矩阵（或阵列，可编程）           │
   │  D_j = Σ (被选中的 Wᵢ)                       │
   └────┬────┬────┬──────────────────────────────┘
        ▼    ▼    ▼
       D₀   D₁   D₂   ...
```

> **重点**：**ROM 的每一个输出位 D_j 都是若干个最小项之和**。所以：
> ```
>   只要把逻辑函数写成最小项之和的形式 Y = Σm(...)，
>   就可以用 ROM 直接实现：
>     ① 地址端 A 接输入变量
>     ② 输出端 D 接函数输出
>     ③ 在存储矩阵中，把 Y = Σm(...) 包含的那些字线对应的存储单元"存 1"
> ```

**例：用 ROM 实现全加器。**

全加器：`S = Σm(1,2,4,7)`，`C_o = Σm(3,5,6,7)`

**连线：**
```
   A ──┐
   B ──┼──► ROM 地址端 A₂A₁A₀      ┌──► D₀ = S
   Cᵢ──┘      (8 × 2 的 ROM)       └──► D₁ = C_o

   存储矩阵的内容（字线 W₀~W₇ 对应地址 000~111）：
   ┌────┬──────┬──────┐
   │地址│ D₁D₀ │ 含义  │
   ├────┼──────┼──────┤
   │ 000│  00  │      │
   │ 001│  01  │ S=1  │
   │ 010│  01  │ S=1  │
   │ 011│  10  │ C_o=1│
   │ 100│  01  │ S=1  │
   │ 101│  10  │ C_o=1│
   │ 110│  10  │ C_o=1│
   │ 111│  11  │ S=C=1│
   └────┴──────┴──────┘
```

**点阵图（存储矩阵的电路表示）：**
```
         W₀  W₁  W₂  W₃  W₄  W₅  W₆  W₇
          │   │   │   │   │   │   │   │
   D₀ ────┼───█───█───┼───█───┼───┼───█───   (S)
          │   │   │   │   │   │   │   │
   D₁ ────┼───┼───┼───█───┼───█───█───█───   (C_o)
          │   │   │   │   │   │   │   │
   注：█ 表示该处有连接（存 1），┼ 表示无连接（存 0）
```

> **★ 两个重要结论：**
> ① **n 个输入变量的逻辑函数，用 ROM 实现时只需要 ROM 的地址线 ≥ n**。多余的地址线接地（或接 0），对应的存储单元按最小项填 1。
> ② **一片 ROM 可以同时实现多个逻辑函数**（把 m 个函数的真值表并排写入，D₀~D_{m-1} 分别输出），**这是 ROM 相比逻辑门的最大优势**。

**为什么用 ROM 实现组合逻辑？**
```
   优点：① 一片芯片可实现任意多输出函数，不需要化简
        ② 更改逻辑只需重新写入 ROM，不改硬件连线
        ③ 适合实现复杂的、无法有效化简的函数
   缺点：① 速度较慢
        ② 规模大时成本高（只能利用 2ⁿ 个字中的一部分）
```

## 典型例题

**例 5.1**（题型：容量计算）
某存储器芯片有 12 根地址线和 4 根数据线，求其容量。

**解**：
```
地址线 12 根 → 字数 = 2¹² = 4096 = 4K
数据线 4 根  → 每字 4 位
容量 = 4K × 4 位 = 4096 × 4 = 16384 位 = 16K 位
```
**答案**：容量为 **4K × 4 位**（即 **16 Kbit**）。

**为什么这样做**：**n 根地址线对应 2ⁿ 个字**；**m 根数据线对应每个字 m 位**。容量 = 2ⁿ × m 位（或直接读作「2ⁿ 字 × m 位」）。

---

**例 5.2**（题型：位扩展设计与计算）
用 `2K × 4` 的 RAM 芯片组成 `2K × 16` 的存储器，需要多少片？画出连线图。

**解**：

**步骤 1：算片数**
```
   字数：需要 2K，单片 2K → 字数够 ✓
   位数：需要 16，单片 4 → 位方向需要 16/4 = 4 组
   总片数 = 4 片
   → 这是**位扩展**
```

**步骤 2：连线**
```
                    ┌──────────────┐
                    │   2K × 4     │
   A₀~A₁₀ ─────┬───►│ A₀~A₁₀      │
               │    │         D₀~D₃├──► 数据总线 D₀~D₃
   CS' ────────┼───►│ CS'          │
   WE' ────────┼───►│ WE'          │
               │    └──────────────┘
               │    ┌──────────────┐
               ├───►│   2K × 4     │
               │    │         D₀~D₃├──► 数据总线 D₄~D₇
               ├───►│ CS'          │
               ├───►│ WE'          │
               │    └──────────────┘
               │    ┌──────────────┐
               ├───►│   2K × 4     │
               │    │         D₀~D₃├──► 数据总线 D₈~D₁₁
               ├───►│ CS'          │
               ├───►│ WE'          │
               │    └──────────────┘
               │    ┌──────────────┐
               └───►│   2K × 4     │
                    │         D₀~D₃├──► 数据总线 D₁₂~D₁₅
                    │ CS'          │
                    │ WE'          │
                    └──────────────┘
```

**答案**：需要 **4 片**。
**连线要点**：**地址线 A₀~A₁₀、片选 `CS'`、写允许 `WE'` 全部并联**；**数据线分段使用**（第 1 片接 D₀~D₃，第 2 片接 D₄~D₇，第 3 片接 D₈~D₁₁，第 4 片接 D₁₂~D₁₅）。

**为什么这样做**：位扩展的目的是**加宽字长**——所有芯片同时被选中（同一地址），各自提供字的不同位。

---

**例 5.3**（题型：字扩展设计与计算）
用 `1K × 8` 的 RAM 芯片组成 `8K × 8` 的存储器，需要多少片？画出连线图并写出地址分配表。

**解**：

**步骤 1：算片数与地址线**
```
   位数：需要 8，单片 8 → 位数够 ✓
   字数：需要 8K，单片 1K → 字方向需要 8K/1K = 8 组 → 8 片
   → 这是**字扩展**

   总地址线：8K = 8192 → log₂(8192) = 13 根（A₀ ~ A₁₂）
   片内地址线：1K = 1024 → log₂(1024) = 10 根（A₀ ~ A₉）
   用于片选的地址线：A₁₀、A₁₁、A₁₂ 共 3 根 → 需要 3-8 译码器
```

**步骤 2：连线**
```
                       ┌────────────┐
   A₁₀ ───────────────►│ A（1 脚）  │  ← 低位接 A
   A₁₁ ───────────────►│ B（2 脚）  │  ← 中位接 B
   A₁₂ ───────────────►│ C（3 脚）  │  ← 高位接 C（74138 的 C 是最高位）
                       │ Y₀..Y₇     │
                       └─┬─┬─┬─┬─┬─┬─┬─┬─┘
                         │ │ │ │ │ │ │ │
   A₀ ~ A₉ ──────────────┼─┼─┼─┼─┼─┼─┼─┼──────────┐
   D₀ ~ D₇ ◄─────────────┼─┼─┼─┼─┼─┼─┼─┼───────┐  │
   WE' ──────────────────┼─┼─┼─┼─┼─┼─┼─┼────┐  │  │
                       ┌─▼┐┌─▼┐┌─▼┐┌─▼┐┌─▼┐┌─▼┐┌─▼┐┌─▼┐
                       │#0││#1││#2││#3││#4││#5││#6││#7│
                       └──┘└──┘└──┘└──┘└──┘└──┘└──┘└──┘
```

**步骤 3：地址分配表**

| 芯片 | A₁₂ | A₁₁ | A₁₀ | 地址范围 | 片选 |
|---|---|---|---|---|---|
| **#0** | 0 | 0 | 0 | 0000 ~ 03FF | Y₀ |
| **#1** | 0 | 0 | 1 | 0400 ~ 07FF | Y₁ |
| **#2** | 0 | 1 | 0 | 0800 ~ 0BFF | Y₂ |
| **#3** | 0 | 1 | 1 | 0C00 ~ 0FFF | Y₃ |
| **#4** | 1 | 0 | 0 | 1000 ~ 13FF | Y₄ |
| **#5** | 1 | 0 | 1 | 1400 ~ 17FF | Y₅ |
| **#6** | 1 | 1 | 0 | 1800 ~ 1BFF | Y₆ |
| **#7** | 1 | 1 | 1 | 1C00 ~ 1FFF | Y₇ |

**答案**：需要 **8 片**，需要 **13 根地址线**（A₀~A₁₂），其中 **A₀~A₉ 并联到所有芯片**，**A₁₀~A₁₂ 送 3-8 译码器产生片选**。

**为什么这样做**：字扩展的目的是**增加字数**——数据线并联（所有芯片共享数据总线），但同一时刻**只有一个芯片被片选有效**（其余芯片的输出呈高阻）。

> **注意**：**字扩展时必须保证同一时刻只有一个芯片被选中**，否则多个芯片同时驱动数据总线会造成**总线冲突**（与第 3 章的三态门总线原理相同）。这就是**必须用译码器产生片选**的原因。

**例 5.4**（题型：字位同时扩展）
用 `2K × 8` 的 RAM 芯片组成 `16K × 32` 的存储器，需要多少片？需要多少根地址线？如何分配？

**解**：

**步骤 1：算片数**
```
   字数：需要 16K，单片 2K → 字方向 16K/2K = 8 组
   位数：需要 32，单片 8  → 位方向 32/8 = 4 组
   总片数 = 8 × 4 = **32 片**
```

**步骤 2：算地址线**
```
   总地址线：16K = 16384 → log₂(16384) = 14 根（A₀ ~ A₁₃）
   片内地址线：2K = 2048 → log₂(2048) = 11 根（A₀ ~ A₁₀）
   用于片选的地址线：14 − 11 = 3 根（A₁₁、A₁₂、A₁₃）→ 3-8 译码器
```

**步骤 3：连接方式**
```
   ① **位方向**（4 组）：每组 4 片芯片，数据线分段拼接
      芯片 a → D₀ ~ D₇
      芯片 b → D₈ ~ D₁₅
      芯片 c → D₁₆ ~ D₂₃
      芯片 d → D₂₄ ~ D₃₁
   ② **字方向**（8 组）：每组用一个片选信号（Y₀ ~ Y₇）
      同一组的 4 片芯片**共用同一个片选**
   ③ A₀ ~ A₁₀ 并联到所有 32 片
   ④ WE' 并联到所有 32 片
```

**结构图：**
```
                     A₁₁,A₁₂,A₁₃
                          │
                    ┌─────▼─────┐
                    │ 3-8 译码器 │
                    └──┬─┬─┬─┬─┬─┬─┬─┬─┘
                       │ │ │ │ │ │ │ │
          Y₀ ──────────┘ │ │ │ │ │ │ └────────── Y₇
                         │ │ │ │ │ │
              ┌──────────▼─▼─▼─▼─▼─▼──────────┐
              │  每一组 = 4 片 2K×8（位扩展）    │
              │  ┌────┐┌────┐┌────┐┌────┐      │
              │  │#0a ││#0b ││#0c ││#0d │ ← 组0 │
              │  │D₀~₇││D₈~₁₅││D₁₆~₂₃││D₂₄~₃₁│  │
              │  └────┘└────┘└────┘└────┘      │
              │  ... 共 8 组                    │
              └────────────────────────────────┘
```

**地址分配（部分）：**

| 组 | A₁₃ | A₁₂ | A₁₁ | 地址范围 | 片选 |
|---|---|---|---|---|---|
| **组 0** | 0 | 0 | 0 | 0000 ~ 07FF | Y₀ |
| **组 1** | 0 | 0 | 1 | 0800 ~ 0FFF | Y₁ |
| **组 2** | 0 | 1 | 0 | 1000 ~ 17FF | Y₂ |
| … | … | … | … | … | … |
| **组 7** | 1 | 1 | 1 | 3800 ~ 3FFF | Y₇ |

**答案**：需要 **32 片**（8 组 × 4 片）；需要 **14 根地址线**（A₀~A₁₃），其中 **A₀~A₁₀ 并联作片内寻址**，**A₁₁~A₁₃ 送 3-8 译码器产生 8 个片选**；每组内 4 片数据线分段拼接（位扩展），8 组之间用不同片选（字扩展）。

**为什么这样做**：**字位同时扩展 = 先分组（字扩展），组内再分位（位扩展）**。这是通用套路，任何容量扩展题都可以这么拆。

**例 5.5**（题型：用 ROM 实现组合逻辑函数）
用一片 ROM 实现下列逻辑函数：
```
   Y₁ = Σm(0, 2, 4, 6)
   Y₂ = Σm(1, 2, 5, 6)
```

**解**：

**步骤 1：确定 ROM 规格**
```
   输入变量：A、B、C（3 个）→ 地址线 3 根 → 2³ = 8 个字
   输出函数：2 个 → 数据线 2 根
   → 需要 **8 × 2** 的 ROM
```

**步骤 2：列出真值表（存储矩阵内容）**

| 地址 A B C | 最小项 | Y₁ | Y₂ | 存储内容 D₁D₀ |
|---|---|---|---|---|
| 0 0 0 | m₀ | **1** | 0 | 0 1 |
| 0 0 1 | m₁ | 0 | **1** | 1 0 |
| 0 1 0 | m₂ | **1** | **1** | 1 1 |
| 0 1 1 | m₃ | 0 | 0 | 0 0 |
| 1 0 0 | m₄ | **1** | 0 | 0 1 |
| 1 0 1 | m₅ | 0 | **1** | 1 0 |
| 1 1 0 | m₆ | **1** | **1** | 1 1 |
| 1 1 1 | m₇ | 0 | 0 | 0 0 |

**步骤 3：连线图**
```
   A ──┬───────────────────────┐
       │                       │
   B ──┼───────────────────────┤  ROM   ┌──► D₀ = Y₁
       │                       │ 8 × 2  │
   C ──┴───────────────────────┤        └──► D₁ = Y₂
                               │
   CS' ────────────────────────┤ (片选，接 0 有效)
                               │
                               └─ 存储矩阵按上表写入
```

**步骤 4：观察化简结果（验证）**
```
   Y₁ = Σm(0,2,4,6) = C'          （所有 C=0 的最小项）
   Y₂ = Σm(1,2,5,6) = B⊕C ？验证：
        B⊕C = B'C + BC'
        m₁ = 001 (B=0,C=1) ✓
        m₂ = 010 (B=1,C=0) ✓
        m₅ = 101 (B=0,C=1) ✓
        m₆ = 110 (B=1,C=0) ✓
        → Y₂ = B ⊕ C  ✓
```

**答案**：用 **8 × 2 的 ROM** 实现，地址端接 A（高位）、B、C（低位），D₀ 输出 Y₁、D₁ 输出 Y₂；存储矩阵按真值表写入（共 8 个字，每字 2 位）。

**为什么这样做**：**ROM 的地址译码器天然产生全部最小项**，所以**只要把函数写成标准最小项之和形式，不需要化简**就能直接实现。这是 ROM 实现组合逻辑的核心思想——**用容量换化简工作**。

**例 5.6**（题型：ROM 实现多输出函数的容量选择）
某组合逻辑电路有 4 个输入 A、B、C、D 和 3 个输出。用 ROM 实现需要多大容量？若改用 `16 × 4` 的 ROM 能否实现？

**解**：

**步骤 1：算所需容量**
```
   输入 4 个 → 地址线 4 根 → 2⁴ = 16 个字
   输出 3 个 → 数据线 3 根
   → 需要 **16 × 3** 的 ROM
```

**步骤 2：判断 `16 × 4` 是否可用**
```
   16 × 4 的 ROM：
     字数 16 ≥ 16  ✓
     位数 4  ≥ 3   ✓
   → **可以用**，但有 1 位浪费（D₃ 不用，可悬空或接地）
   实际使用时，把 3 个输出接到 D₀、D₁、D₂，D₃ 空置
```

**步骤 3：如果想用 `8 × 8` 的 ROM 呢？**
```
   字数 8 < 16  ✗  **不够**（4 个输入需要 16 个字）
   → 不能用，除非用 2 片 8×8 做字扩展
```

**答案**：需要的容量是 **16 × 3**（即 16 个字、每字 3 位）。**`16 × 4` 的 ROM 可以实现**（1 位冗余，D₃ 空置）。**`8 × 8` 的 ROM 不能单独实现**（字数不够）。

**为什么这样做**：**ROM 的容量要求是"字数必须 ≥ 2^(输入变量数)"，且"位数必须 ≥ 输出函数个数"**。字数或位数任一不足都不能用。**字数不足 → 字扩展；位数不足 → 位扩展。**

---

**例 5.7**（题型：DRAM 刷新计算）
某 DRAM 芯片的存储矩阵为 128 × 128（即 128 行、128 列），要求刷新周期为 2 ms。求：
（1）用**集中刷新**时，刷新的"死时间"是多少（设存取周期 t_RC = 0.5 μs）？
（2）用**异步刷新**时，两次刷新操作的间隔是多少？

**解**：

**（1）集中刷新**
```
   需要刷新的行数 = 128 行
   每行刷新一次需要一个存取周期 = 0.5 μs
   集中刷新总时间 = 128 × 0.5 μs = 64 μs
   → 在这 64 μs 内 CPU 不能访问存储器 → "死时间" = 64 μs

   死时间占比 = 64 μs / 2000 μs = 3.2%
```

**（2）异步刷新**
```
   刷新周期 = 2 ms = 2000 μs
   分成 128 段，每段刷新一行
   两次刷新的间隔 = 2000 μs / 128 = 15.625 μs
   → 即每 15.625 μs 刷新一行，2 ms 内正好刷新完 128 行
```

**答案**：（1）集中刷新的死时间为 **64 μs**（占刷新周期的 3.2%）；（2）异步刷新的间隔为 **15.625 μs**。

**为什么这样做**：
- **集中刷新**把 2 ms 内的所有行在**一段时间内连续刷完**，这段时间叫"死时间"（或"访存死区"）。
- **异步刷新**把 2 ms **均分**给每一行，每隔 `2 ms / 行数` 刷新一行，**死时间被分散**（每次只占 0.5 μs），对 CPU 影响最小。

> **注意单位换算**：`2 ms = 2000 μs`。计算时要统一单位，这是常错的地方。

**例 5.8**（题型：存储器芯片选择与地址线分析）
某微机系统需要 `64K × 8` 的存储器。现有 `16K × 8` 的芯片若干。
（1）需要多少片？
（2）共需多少根地址线？如何分配？
（3）若改用 `16K × 4` 的芯片，需要多少片？

**解**：

**（1）用 `16K × 8` 的芯片**
```
   字数：64K / 16K = 4 组
   位数：8 / 8 = 1 组
   总片数 = 4 × 1 = **4 片**
   → 字扩展
```

**（2）地址线分配**
```
   总地址线：64K = 65536 → log₂(65536) = 16 根（A₀ ~ A₁₅）
   片内地址线：16K = 16384 → log₂(16384) = 14 根（A₀ ~ A₁₃）
   片选地址线：16 − 14 = 2 根（A₁₄、A₁₅）→ 2-4 译码器
```

| 芯片 | A₁₅ | A₁₄ | 地址范围 | 片选 |
|---|---|---|---|---|
| #0 | 0 | 0 | 0000H ~ 3FFFH | Y₀ |
| #1 | 0 | 1 | 4000H ~ 7FFFH | Y₁ |
| #2 | 1 | 0 | 8000H ~ BFFFH | Y₂ |
| #3 | 1 | 1 | C000H ~ FFFFH | Y₃ |

**（3）改用 `16K × 4` 的芯片**
```
   字数：64K / 16K = 4 组（字方向）
   位数：8 / 4 = 2 组（位方向）
   总片数 = 4 × 2 = **8 片**
   地址线分配不变（A₀~A₁₃ 片内，A₁₄~A₁₅ 片选）
   数据线：每组 2 片，一片接 D₀~D₃，另一片接 D₄~D₇
```

**答案**：（1）**4 片**；（2）需要 **16 根地址线**，A₀~A₁₃ 并联到所有芯片作片内寻址，A₁₄、A₁₅ 经 2-4 译码器产生 4 个片选；（3）改用 `16K × 4` 需要 **8 片**。

**为什么这样做**：
```
   片数 = (目标字数 / 单片字数) × (目标位数 / 单片位数)
        = (64K/16K) × (8/8) = 4 × 1 = 4 片     （第一种芯片）
        = (64K/16K) × (8/4) = 4 × 2 = 8 片     （第二种芯片）
```
**地址线根数只由总容量决定**，与用哪种芯片无关：**64K 就一定需要 16 根地址线**。

## 易错点提醒

1. **容量表示法写错** → 必须写成 **`字数 × 位数`** 的形式。`4K × 4` 表示 **4096 个字、每字 4 位**，总位数是 `4K × 4 = 16K 位`。**不要把 `4K × 4` 理解成 `16K` 个字。**
2. **地址线根数算错** → **n 根地址线对应 2ⁿ 个字**。反过来，**知道字数求地址线数要用 log₂**。`1K` 需要 **10** 根，`4K` 需要 **12** 根，`64K` 需要 **16** 根。**牢记：1K=2¹⁰、4K=2¹²、16K=2¹⁴、64K=2¹⁶。**
3. **位扩展和字扩展的连线搞反** → **位扩展是"数据线分开、其余并联"**（加宽字长）；**字扩展是"数据线并联、片选分开"**（增加字数）。**记住：什么不够就扩展什么方向。**
4. **字扩展时忘记用译码器** → 字扩展**必须**用译码器产生片选，**绝不能把几个片选直接接地或接高电平同时选中**，否则数据总线冲突。这是最容易丢分的地方。
5. **字位同时扩展时片数算错** → **片数 = (字数方向组数) × (位数方向组数)**，不是相加。例如 16K×32 用 2K×8：`(16K/2K) × (32/8) = 8 × 4 = 32 片`。
6. **SRAM 和 DRAM 的特点搞混** → **SRAM 不用刷新、速度快、管子多、贵**（用于 Cache）；**DRAM 必须刷新（2 ms）、速度慢、管子少、便宜**（用于主存）。**口诀：「S 静态不用刷，D 动态必须刷」。**
7. **以为 DRAM 刷新是"读出数据"** → 刷新操作**只是读出并立即重写**，**不进行数据输出**，也不改变存储内容。刷新是**按行进行**的，一次刷新一整行。
8. **混淆"存取周期"和"刷新周期"** → **存取周期 t_RC** 是完成一次读或写所需的时间（几十到几百 ns）；**刷新周期**是必须把所有行刷新一遍的最长时间（典型 **2 ms**）。**刷新间隔 = 刷新周期 / 行数**。
9. **ROM 的类型特点记错** → **掩膜 ROM 出厂固化、不能改**；**PROM 只能烧写一次**；**EPROM 用紫外线擦（15~30 min）**；**EEPROM 电擦写（按字节）**；**Flash 电擦写（按块，速度快、容量大）**。**关键区别是"用什么擦、能擦几次"。**
10. **以为 ROM 只能读** → **只有掩膜 ROM 真正只能读**。PROM、EPROM、EEPROM、Flash 都能写入（在特定条件下）。**"只读"指的是正常工作时只执行读操作。**
11. **用 ROM 实现逻辑函数时画蛇添足去化简** → **不需要化简！** ROM 的地址译码器天然产生全部最小项，**直接把函数写成 Σm(...) 形式，把对应的位置存 1 即可**。化简反而是多余的（虽然化简后能帮助检查）。
12. **忘记 ROM 可以实现多输出函数** → 一片 ROM 有 m 根数据线，**就能同时实现 m 个逻辑函数**。这是 ROM 相比门电路的最大优势，**千万不要为每个函数单独用一片 ROM**。
13. **ROM 容量选择时只看字数** → **字数必须 ≥ 2^(输入变量数)，位数必须 ≥ 输出函数个数，两者都要满足**。`8 × 8` 的 ROM 不能实现 4 输入的逻辑函数（字数 8 < 16）。
14. **DRAM 刷新计算单位不统一** → `2 ms = 2000 μs`。计算刷新间隔时必须把刷新周期和存取周期**换算成同一单位**。`2000 μs / 128 = 15.625 μs`。
15. **地址范围计算错误** → `1K` 个字的地址范围是 `0 ~ 3FFH`（因为 `1023 = 3FFH`），**不是 `0 ~ FFFH`**。`4K` 是 `0 ~ FFFH`，`16K` 是 `0 ~ 3FFFH`，`64K` 是 `0 ~ FFFFH`。**记法：K 数除以 1K 再乘 400H。**
16. **以为存储器的地址线可以随意省略** → **地址线、数据线、控制线必须严格按容量对应**。若某根地址线不接，则该地址线所对应的两个地址会**映射到同一个存储单元**（地址重叠），导致错误。

## 本章小结

1. **存储器的基本结构**：**地址译码器**（n 位地址 → 2ⁿ 根字线，产生全部最小项）+ **存储矩阵**（2ⁿ 个字 × m 位）+ **读写控制电路**（`CS'` 片选、`WE'` 写允许）。
2. **容量 = 字数 × 位数**；**n 根地址线 → 2ⁿ 个字**，**m 根数据线 → m 位字长**。
3. **SRAM**：6 管双稳态单元，**不需要刷新**，速度快，集成度低，成本高，**用于 Cache**。
4. **DRAM**：1 管 + 1 电容，**必须每 2 ms 刷新一遍**，读出是破坏性的（需重写），集成度高，成本低，**用于主存**。刷新方式：集中刷新（有死时间）、分散刷新（周期加倍）、**异步刷新（最常用）**。
5. **ROM 家族**：

   | 类型 | 写入 | 擦除 | 次数 |
   |---|---|---|---|
   | 掩膜 ROM | 出厂固化 | 不可擦 | — |
   | PROM | 一次（烧熔丝） | 不可擦 | 1 |
   | EPROM | 可重复 | **紫外线 15~30 min** | 100~1000 |
   | EEPROM | 可重复 | **电擦除（按字节）** | 10⁴~10⁶ |
   | **Flash** | 可重复 | **电擦除（按块）** | 10⁴~10⁵ |

6. **容量扩展三步法**：
   ```
   ① 算片数 = (目标字数/单片字数) × (目标位数/单片位数)
   ② 分地址 = 低 log₂(单片字数) 位并联作片内寻址
              高 log₂(目标字数)−log₂(单片字数) 位送译码器产生片选
   ③ 连数据 = 位方向分组，组内数据线拼接成完整字宽
   ```
   - **位扩展**：地址线、片选、读写线**全并联**；**数据线分段**。
   - **字扩展**：数据线、读写线**全并联**；**地址线高位经译码器产生片选**。
   - **字位同时扩展**：先按字分组（组间用不同片选），组内再按位拼接。
7. **用 ROM 实现组合逻辑函数**：**ROM 的地址译码器 = 最小项发生器，存储矩阵 = 或阵列**。把函数写成 `Y = Σm(...)`，在对应的存储单元存 1 即可，**不需要化简**。一片 ROM 可同时实现多个输出函数。
8. **常见容量与地址线对照**：

   | 容量 | 地址线 | 地址范围 |
   |---|---|---|
   | 1K | 10 | 000H ~ 3FFH |
   | 4K | 12 | 000H ~ FFFH |
   | 16K | 14 | 0000H ~ 3FFFH |
   | 64K | 16 | 0000H ~ FFFFH |

> **一句话记住本章**：**存储器就是"地址译码器 + 存储阵列 + 读写控制"——SRAM 用触发器存（不用刷新、快、贵），DRAM 用电容存（要刷新、慢、便宜），ROM 用"有无管子"存（断电不丢）；容量不够时，位数不够做位扩展（数据线分段），字数不够做字扩展（高位地址译码产生片选），两个都不够就"先分组再分位"。**

### 自测题答案

**1.**
```
   14 根地址线 → 2¹⁴ = 16384 = 16K 个字
   8 根数据线 → 每字 8 位
   容量 = 16K × 8 位 = 128 Kbit
```
**答案**：**16K × 8 位**（即 128 Kbit）。

**2.** 
- **SRAM 存储单元**：**6 管单元**——两个反相器交叉耦合（双稳态）+ 两个门控管。用**双稳态电路**存储数据。
- **DRAM 存储单元**：**1 管 + 1 电容**——一个门控 MOS 管 + 一个存储电容 C_S。用**电容上的电荷**存储数据。

**DRAM 必须刷新的原因**：电容 C_S 会通过**漏电流**缓慢放电。典型情况下经过 **2 ms 左右**电荷就会损失到无法可靠辨别的程度。因此必须在 **2 ms 之内**把每个存储单元读出一次并**立即重新写入**（刷新），把电荷补充回来。所以 DRAM 的数据不能永久保持，必须周期性刷新。

**3.**
```
   字数：32K / 4K = 8 组（字扩展）
   位数：8 / 8 = 1 组
   总片数 = 8 × 1 = **8 片**

   总地址线：32K = 32768 = 2¹⁵ → 15 根（A₀ ~ A₁₄）
   片内地址线：4K = 4096 = 2¹² → 12 根（A₀ ~ A₁₁）
   用于片选：15 − 12 = **3 根**（A₁₂、A₁₃、A₁₄）→ 3-8 译码器
```
**答案**：**8 片**；需要 **15 根**地址线；其中 **3 根**（A₁₂~A₁₄）用于片选。

**4.**
```
   字数：4K / 1K = 4 组（字方向）
   位数：8 / 4 = 2 组（位方向）
   总片数 = 4 × 2 = **8 片**

   地址线：4K = 2¹² → 12 根
   片内：1K = 2¹⁰ → 10 根（A₀~A₉）
   片选：12 − 10 = 2 根（A₁₀、A₁₁）→ 2-4 译码器
```
**连接方式简图**：
```
   A₁₀,A₁₁ ──►[2-4 译码器]──► Y₀,Y₁,Y₂,Y₃（4 个片选）

   组 0（Y₀）: 片#0 接 A₀~A₉, CS'=Y₀, D₀~D₃
               片#1 接 A₀~A₉, CS'=Y₀, D₄~D₇
   组 1（Y₁）: 片#2 接 A₀~A₉, CS'=Y₁, D₀~D₃
               片#3 接 A₀~A₉, CS'=Y₁, D₄~D₇
   组 2（Y₂）: 片#4 / #5 同上
   组 3（Y₃）: 片#6 / #7 同上

   WE' 并联到所有 8 片
```
**答案**：**8 片**——**先按字分 4 组（每组一个片选用不同芯片），组内再按位分 2 片（数据线分别接 D₀~D₃ 和 D₄~D₇）**。

**5.** **字扩展的目的是增加字数**——多个芯片**共享同一条数据总线**。若不用译码器，可能出现两种情况：
① **多个片选同时有效** → 多个芯片同时驱动数据总线 → **总线冲突**（输出端直接相连，可能损坏芯片）；
② **片选随意接地** → 该芯片总是被选中 → 多个芯片同时输出，同样冲突。

**用译码器的作用**：由高位地址经译码器产生**互斥**的片选信号，**保证任一时刻只有一个芯片被选中**（其余芯片输出呈高阻），从而避免总线冲突。**这也是各芯片的地址范围互不重叠、分别对应一段唯一地址空间的原因。**

**6.**

| 类型 | 写入方式 | 擦除方式 | 可擦次数 |
|---|---|---|---|
| **掩膜 ROM** | **制造时由掩膜决定**，用户不能写入 | 不可擦除 | — |
| **PROM** | 用户用编程器**烧断熔丝** | 不可擦除 | **1 次** |
| **EPROM** | 用编程器**高压注入浮栅电荷** | **紫外线照射 15~30 min** | 100~1000 |
| **EEPROM** | **电信号写入**（可在线） | **电信号擦除（按字节）** | 10⁴~10⁶ |
| **Flash** | **电信号写入** | **电信号擦除（按块）** | 10⁴~10⁵ |

**7.**
```
   输入变量 A、B、C 共 3 个 → 地址线 3 根 → 2³ = **8 个字**
   输出函数 2 个 → 数据线 **2 根**
   → 需要 **8 × 2** 的 ROM
```
**验证**：`Y₁ = Σm(0,1,3,5,7)`，`Y₂ = Σm(1,2,4,6)`，都在 m₀~m₇ 范围内，8 个字够用。
**答案**：**8 × 2 的 ROM**。

**8.** **（1）集中刷新**
```
   需要刷新的行数 = 256 行
   每行刷新需要一个存取周期 = 0.4 μs
   死时间 = 256 × 0.4 μs = **102.4 μs**
   占比 = 102.4 / 2000 = 5.12%
```
**（2）异步刷新**
```
   刷新周期 = 2 ms = 2000 μs
   刷新间隔 = 2000 μs / 256 = **7.8125 μs**
```
**答案**：（1）死时间 **102.4 μs**；（2）异步刷新间隔 **7.8125 μs**。

**9.** **原因有两点：**
① **ROM 的地址译码器天然产生全部最小项**。n 位地址经译码后得到 2ⁿ 根字线，每根字线对应一个最小项。**所以任何用最小项之和表示的函数，都能"直接照搬"到存储矩阵上**，不需要先化简。
② **存储矩阵的每一位都是独立的**——每个交叉点有管子就是 1、没管子就是 0。**写入的内容就是真值表本身**。化简反而会增加"把化简后的表达式重新展开成最小项"的工作量。

**唯一需要做的是**：把逻辑函数写成标准最小项之和 `Y = Σm(...)`，然后在存储矩阵中把对应位置存 1。**这正是 ROM 相比门电路的优势——用容量换取化简工作量，且一片 ROM 可同时实现多个输出。**

**10.** 
```
   2K = 2¹¹ → 地址线需要 **11 根**
   8 根数据线 → 可以同时输出 **8 个**逻辑函数
```
**用它实现 4 输入 4 输出的逻辑函数是否可行？**
- **字数**：4 个输入需要 **2⁴ = 16 个字**，ROM 有 **2K = 2048 个字** → **16 ≤ 2048，字数够** ✓
- **位数**：4 个输出需要 **4 位**，ROM 有 **8 位** → **4 ≤ 8，位数够** ✓
→ **可行**，但有大量浪费：只用了 2048 个字中的 16 个（占 0.78%），8 位中的 4 位。
```
   未用的 11 − 4 = 7 根地址线接地（或接固定电平），使地址只落在 00000000000 ~ 00000001111
   未用的 D₄~D₇ 悬空
```
**答案**：需要 **11 根**地址线；可同时实现 **8 个**输出函数；**可以实现 4 输入 4 输出的逻辑函数**（字数 16 ≤ 2048、位数 4 ≤ 8，都满足），但**容量利用率极低**（只用 16/2048 = 0.78% 的字）。实际工程中应选择更小容量的 ROM（如 `16 × 8`）以降低成本。
