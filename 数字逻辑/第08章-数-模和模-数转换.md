## 8.1 概述

**为什么需要 D/A 和 A/D？**

```
   现实世界的信号（温度、声音、压力、图像）都是**模拟量**（连续变化）
   而计算机、数字系统只能处理**数字量**（离散的 0 和 1）
   
   → 需要两个"翻译官"：
     **A/D 转换器（ADC）**：模拟 → 数字（输入通道，如麦克风接计算机）
     **D/A 转换器（DAC）**：数字 → 模拟（输出通道，如计算机接音箱）
```

**系统结构框图：**

```
   模拟输入 ──►┌─────┐  数字  ┌──────────┐  数字  ┌─────┐──► 模拟输出
              │ A/D │──────►│ 数字计算机│──────►│ D/A │
              └─────┘        │ 或数字系统│        └─────┘
                             └──────────┘
              （传感器）                        （执行机构）
```

**D/A 转换器的结构框图：**

```
     D₀ ─┐
     D₁ ─┤                                          ┌──────┐
     D₂ ─┼──►┌─────────────┐    ┌───────────┐      │ 运算 │
      ⋮   │   │  数字寄存器  │───►│  模拟开关  │──┬──►│ 放大器│──► v_O
   D_{n-1}┤   └─────────────┘    │  电阻网络  │  │   └──────┘
          │                       └───────────┘  │
          │                             ▲        │
          │                             │        │
          └───────────────────────► **V_REF（基准电压）**
```

**四个组成部分：**
| 部件 | 作用 |
|---|---|
| **数字寄存器** | 暂存输入的数字量（保证转换期间输入稳定） |
| **模拟开关** | 由数字位控制，决定每一位是否接入网络 |
| **电阻网络** | 实现**二进制加权**（把不同的位变成不同的电流/电压） |
| **求和运算放大器** | 把各支路电流相加并转换成电压输出 |

**A/D 转换器的结构框图：**

```
   模拟输入 v_I ──►┌────┐   ┌────┐   ┌────┐   ┌────┐  数字输出
                   │取样│──►│保持│──►│量化│──►│编码│──────►
                   └────┘   └────┘   └────┘   └────┘
                     ▲                             ▲
                     │                             │
                 取样脉冲 CP                    **V_REF**
```

**四个步骤（★ 必记）：**
```
   ① **取样（Sampling）**：在取样脉冲控制下，把连续变化的模拟量变成离散时间的样值
   ② **保持（Hold）**：把取样得到的样值保持一段时间，供后续电路转换
   ③ **量化（Quantization）**：把保持的样值归整到最接近的量化电平（这一步引入量化误差）
   ④ **编码（Encoding）**：把量化后的电平用二进制代码表示
```

> **重点**：**取样必须满足取样定理**：
> ```
>   **f_s ≥ 2·f_{i(max)}**
>   即取样频率必须大于等于输入信号最高频率分量的 2 倍，
>   否则会产生"频谱混叠"，无法恢复原信号。
>   工程上一般取 f_s = (3~5)·f_{i(max)}
> ```
> 例：音频信号最高频率 20 kHz，取样频率至少 40 kHz，实际 CD 用 **44.1 kHz**。

## 8.2 D/A 转换器的电路结构和工作原理

### 8.2.1 权电阻网络 D/A 转换器

**电路结构：**

```
                 R_f
              ┌──[===]──┐
              │         │
              │    ┌────┴────┐
              │    │    −    │
              │    │   │\    │
              │    │   │ \   │
              │    │   │  >──┼──── v_O
              │    │   │ /   │
              │    │   │/    │
              │    │    +    │
              │    └────┬────┘
              │         │
              │        GND
              │
    V_REF ──┬─┴─┐  ┌─┴─┐  ┌─┴─┐        ┌─┴───┐
            │ R │  │2R │  │4R │  ...   │2ⁿ⁻¹R│
            └─┬─┘  └─┬─┘  └─┬─┘        └─┬───┘
      S_{n-1}─┘ S_{n-2}─┘ S_{n-3}─┘      S₀──┘
          ▲        ▲        ▲              ▲
          │        │        │              │
       D_{n-1}  D_{n-2}  D_{n-3}          D₀
       （最高位 MSB 的电阻最小 R，最低位 LSB 的电阻最大 2ⁿ⁻¹R）
```

**核心思想**：**每一位的权值不同，就用不同的电阻值来实现**——最高位（MSB）的电阻最小，通过的电流最大；最低位（LSB）的电阻最大，电流最小。

**输出电压公式推导：**
```
   当 Dᵢ = 1 时，第 i 位的开关接 V_REF，该支路电流流入运放虚地；
   当 Dᵢ = 0 时开关接地，该支路电流为 0。

   第 i 位的电阻（i = 0 是最低位 LSB，i = n−1 是最高位 MSB）：
     Rᵢ = 2^(n−1−i)·R
   所以第 i 位接通时的电流：
     Iᵢ = V_REF / Rᵢ = V_REF / (2^(n−1−i)·R)

   运放反相输入端是虚地，各支路电流互不影响，总电流为：
     I = Σ Iᵢ·Dᵢ = (V_REF/R)·Σ Dᵢ·2^(i−n+1)

   输出电压：
     v_O = −I·R_f

   取 **R_f = R/2**：
     v_O = −(V_REF/2)·Σ Dᵢ·2^(i−n+1)
         = −(V_REF/2ⁿ)·Σ Dᵢ·2^i
   **v_O = −(V_REF/2ⁿ)·(D_{n-1}·2^(n-1) + D_{n-2}·2^(n-2) + … + D₀·2⁰)**
```

按常规的书写方式（D₀ 为最低位 LSB，D_{n-1} 为最高位 MSB），取 R_f = R/2：

**★ 输出电压公式（必背）：**
```
   **v_O = −(V_REF/2ⁿ)·(D_{n-1}·2^{n-1} + D_{n-2}·2^{n-2} + … + D₁·2¹ + D₀·2⁰)**
   
   更紧凑的写法：
   **v_O = −(V_REF/2ⁿ)·Σ_{i=0}^{n-1} Dᵢ·2ⁱ**
```

**优缺点：**
```
   ✅ 优点：结构简单，所用电阻元件少（n 位只需 n 个电阻）
   ❌ 缺点：
     ① **电阻阻值范围太宽**：n 位时需要 R, 2R, 4R, …, 2ⁿ⁻¹R
        例如 n = 10 时，最大电阻是最小电阻的 2⁹ = 512 倍
        若最小电阻 2R = 10 kΩ，则最大电阻是 5.12 MΩ
        → **难以在集成电路中制造**（阻值范围大、精度难保证）
     ② **各位电流相差悬殊**：对开关的要求不同
     ③ **精度受电阻精度影响大**
   → 实际中很少使用，主要用于理解原理
```

### 8.2.2 倒 T 形电阻网络 D/A 转换器（★ 重点）

**这是实际应用最广的 D/A 转换器结构。**

**电路结构（★ 必须会画）：**

```
                                 R_f
                          ┌─────[===]─────┐
                          │               │
                          │        ┌──────┴──────┐
                          │        │      −      │
                          │        │     │\      │
                          │        │     │ \     │
                          │        │     │  >─────┼──── v_O
                          │        │     │ /     │
                          │        │     │/      │
                          │        │      +      │
                          │        └──────┬──────┘
                          │               │
                          │              GND
                          │
        ┌────2R────┬────2R────┬────2R────┬─ … ─┬────2R────┐
        │          │          │          │      │         │
       2R          2R         2R         2R     2R        2R   ← 竖排电阻
        │          │          │          │      │         │
        ├──────────┼──────────┼──────────┼ … ───┼─────────┤
        │          │          │          │      │         │
       S₀         S₁         S₂         S₃    S_{n-2}   S_{n-1}
      ┌─┴─┐      ┌─┴─┐      ┌─┴─┐                        ┌─┴─┐
      │   │      │   │      │   │                        │   │
      └─┬─┘      └─┬─┘      └─┬─┘                        └─┬─┘
     V_REF/0    V_REF/0    V_REF/0                      V_REF/0
```

**更清晰的标准画法（倒 T 形网络）：**

```
                            R_f = R
                    ┌───────[===]───────┐
                    │                   │
                    │           ┌───────┴───────┐
                    │           │       −       │
                    │           │      │\       │
                    │           │      │ \      │
         I_Σ ───────┼───────────┤      │  >─────┼──── v_O
                    │           │      │ /      │
                    │           │      │/       │
                    │           │       +       │
                    │           └───────┬───────┘
                    │                  GND
                    │
        ┌───2R───┬──┴─2R───┬───2R───┬─── … ──┬───2R───┐
        │        │         │        │        │        │
       ═╧═      ═╧═       ═╧═      ═╧═      ═╧═      ═╧═
       2R        2R        2R       2R       2R       2R
        │        │         │        │        │        │
        ├────────┴─────────┴────────┴────────┴────────┤
        │        │         │        │        │        │
      ┌─┴─┐    ┌─┴─┐     ┌─┴─┐    ┌─┴─┐    ┌─┴─┐   ┌─┴─┐
      │ S₀│    │ S₁│     │ S₂│    │ S₃│    │   │   │S_{n-1}│
      └─┬─┘    └─┬─┘     └─┬─┘    └─┬─┘    └─┬─┘   └─┬─┘
        │        │         │        │        │        │
      D₀=1时    D₁=1时                ...            D_{n-1}=1时
      接V_REF   接V_REF                            接V_REF
      D=0接地   D=0接地                            D=0接地
```

**关键特点（★ 理解这三点就理解了倒 T 形网络）：**
```
   ① **只有两种电阻值：R 和 2R**（这是它最大的优势——易于集成制造）
   ② **无论开关接 V_REF 还是接地，各 2R 支路的电流都不变**
      （因为倒 T 形网络中，每个节点向右看的等效电阻都是 R，
        而开关的切换只是把电流从"地"切换到"虚地"，
        由于虚地电位 = 0 = 地电位，所以支路电流不变）
   ③ **从任一节点向左（向运放方向）看的等效电阻都是 R**
      → 可以逐节点用戴维南等效，最终得到总电流
```

**输出电压公式推导：**
```
   从最左边（靠近运放）的节点开始，逐级向左推算电流：
   
   最左节点（MSB 侧，D_{n-1} 对应）：
     该节点向右看的等效电阻 = 2R ∥ 2R = R
     其上游（再往左）的等效电阻也是 R
     ...
   
   结论（标准推导结果）：
   第 i 位支路的电流为 Iᵢ = V_REF/(2R) · (1/2^(n-1-i))  （Dᵢ = 1 时）
   
   总电流 I_Σ = (V_REF/2R) · (D_{n-1}/2⁰ + D_{n-2}/2¹ + … + D₀/2^(n-1))
              = (V_REF/(2ⁿ·R)) · (D_{n-1}·2^{n-1} + … + D₀·2⁰)
   
   取 **R_f = R**：
   **v_O = −I_Σ·R_f = −(V_REF/2ⁿ)·(D_{n-1}·2^{n-1} + … + D₀·2⁰)**
```

**★ 输出电压公式（必背）：**
```
   **v_O = −(V_REF/2ⁿ)·Σ_{i=0}^{n-1} Dᵢ·2ⁱ**
   
   另一常用写法（先用十进制表示数字量 D）：
   **v_O = −(V_REF/2ⁿ)·D**，其中 D = 输入数字量对应的十进制数
```

**与权电阻网络对比：**

| 对比项 | 权电阻网络 | **倒 T 形电阻网络** |
|---|---|---|
| **电阻种类** | n 种（R, 2R, 4R, …, 2ⁿ⁻¹R） | **只有 2 种（R 和 2R）** |
| **阻值范围** | 极大（2ⁿ 倍） | **很小（2 倍）** |
| **集成难度** | 难 | **易** ★ |
| **各位电流** | 相差悬殊 | **各支路电流按 1/2 递减，比较均匀** |
| **开关要求** | 各开关电流不同 | **各开关电流相同**（都流过 2R） |
| **输出公式** | 同 | **同** |
| **实际应用** | 很少 | **广泛** ★ |

> **重点**：**倒 T 形网络的最大优势是"只有 R 和 2R 两种电阻"，极大地降低了集成电路的制造难度。** 这是它取代权电阻网络的**唯一但决定性**的理由。

### 8.2.3 权电流型 D/A 转换器

**为什么要用权电流型？**
```
   倒 T 形网络的缺点：**开关不是理想器件**
   实际模拟开关有导通电阻 r_on，且各开关的 r_on 不完全相同
   → r_on 与 2R 串联，使各支路电流偏离理论值 → **产生转换误差**
   
   另外，当数字量变化时，开关切换会使**节点电压波动**，影响精度
```

**权电流型 D/A 转换器的核心思想：**
```
   **用恒流源代替电阻网络**，每一位对应一个恒流源：
   **I_{n-1} = I/2（最高位 MSB），I_{n-2} = I/4，…，I₀ = I/2ⁿ（最低位 LSB）**
   （下标越大电流越大：**D_{n-1} 是 MSB，配最大的恒流源 I/2**）
```

**电路结构：**

```
                               R_f
                        ┌─────[===]─────┐
                        │               │
                        │        ┌──────┴──────┐
                        │        │      −      │
                        │        │     │\      │
                        │        │     │ \     │
                        │        │     │  >─────┼──── v_O
                        │        │     │ /     │
                        │        │     │/      │
                        │        │      +      │
                        │        └──────┬──────┘
                        │               │
                        │              GND
                        │
          ┌─────────────┼───────────────┐
          │             │               │
        ┌─┴─┐         ┌─┴─┐          ┌─┴─┐
        │I/2│         │I/4│   ...    │I/2ⁿ│   ← 恒流源（权电流）
        └─┬─┘         └─┬─┘          └─┬─┘
          │             │               │
       ┌───┴───┐     ┌───┴───┐      ┌──┴──┐
       │S_{n-1}│     │S_{n-2}│      │ S₀  │
       └───┬───┘     └───┬───┘      └──┬──┘
           │             │             │
        D_{n-1}       D_{n-2}         D₀
         (MSB)                       (LSB)
```

**输出电压：**
```
   **v_O = −R_f·(D_{n-1}·I/2 + D_{n-2}·I/4 + … + D₀·I/2ⁿ)**
        = −(R_f·I/2ⁿ)·Σ Dᵢ·2ⁱ
```

**优点：**
```
   ① **各支路电流恒定，不受开关导通电阻影响**（恒流源的输出电流与负载无关）
   ② **开关只起"通断"作用**，不参与电流大小的决定 → 精度高
   ③ **转换速度快**（各支路电流恒定，没有节点电压建立时间）
   → **高速高精度 D/A 转换器都采用权电流型结构**
```

### 8.2.4~8.2.6 其他结构与双极性输出

**开关树型 D/A 转换器**（树形开关 + 电阻分压）：
```
   用 2ⁿ 个电阻串联分压得到 2ⁿ 个电压，再用开关树选择其中一个输出
   特点：只用一种电阻值，但需要大量开关（2^(n+1) − 2 个）
```

**权电容网络 D/A 转换器**：
```
   用二进制权值的电容代替电阻
   特点：CMOS 工艺中电容比电阻容易做准 → 适合集成
        但电容充放电需要时间，速度较慢
```

**★ 具有双极性输出的 D/A 转换器：**

**问题**：前面的 D/A 只能输出单一极性的电压（0 ~ −V_REF·(2ⁿ−1)/2ⁿ）。但很多场合需要**双极性输出**（正负都有），例如音频信号。

**解决方法**：**在求和放大器输入端加入一个偏移电流**。

```
   方法一：在运放输入端加一个偏移电阻 R_B 接 −V_REF（或 +V_REF）
   
      使得当输入数字量为"100…0"（最高位为 1、其余为 0）时，
      输出恰好为 0，从而实现**偏移二进制码**的双极性输出
   
      输出范围：**−V_REF·2^(n−1)/2ⁿ ~ +V_REF·(2^(n−1) − 1)/2ⁿ**
      （以 0 为中点；**总跨度仍是 (2ⁿ−1)/2ⁿ·V_REF**，加偏移只搬移零点、不改变跨度）
```

**常用编码对比：**
| 输入数字量（4 位） | 偏移二进制码输出 | 二进制补码输出 |
|---|---|---|
| 0000 | −(8/16)V_REF | 0 |
| 0001 | −(7/16)V_REF | +(1/16)V_REF |
| 0111 | −(1/16)V_REF | +(7/16)V_REF |
| 1000 | 0 | −(8/16)V_REF |
| 1111 | +(7/16)V_REF | −(1/16)V_REF |

> **怎么看这张表**：
> - **偏移二进制码**：`v_O = (D − 2^(n−1))·Δ`，其中 D 是无符号数值、Δ = V_REF/2ⁿ。所以 0000 → `(0−8)Δ = −8Δ`、1000 → `(8−8)Δ = 0`、1111 → `(15−8)Δ = +7Δ`。
> - **二进制补码**：`v_O = D_补·Δ`，D_补 是补码对应的**有符号数值**。所以 0000 → 0、0111 → +7Δ、1111（= −1）→ **−1Δ**、1000（= −8）→ **−8Δ**。
> - 两种码的**输出跨度相同**（都是 16Δ 中的 15Δ = (2ⁿ−1)/2ⁿ·V_REF），**零点位置不同**：偏移二进制码在 1000，补码在 0000。
> - 两者的换算关系：**偏移二进制码 = 补码的最高位取反**。

> **重点**：**双极性输出的关键是"偏移"**——通过加入固定偏移量把单极性输出"搬到"零点两侧。**最高位（MSB）实际上变成了"符号位"**（偏移二进制码中 MSB=1 表示正）。

## 8.3 D/A 转换器的转换精度与转换速度

### 8.3.1 转换精度

**① 分辨率（Resolution）★ 最重要**

**定义**：**D/A 转换器能分辨的最小输出电压变化量，即输入数字量变化 1 个 LSB 时输出电压的变化量。**

```
   **Δ = V_REF / 2ⁿ**   （n 为位数，V_REF 为基准电压）
   
   也常用**相对值**表示（满量程的百分数）：
   **分辨率 = 1/(2ⁿ − 1) × 100%**
```

> **重点**：**分辨率只由位数 n 决定，与 V_REF 的具体值无关（谈相对分辨率时）。**
> ```
>   位数越多 → 分辨率越高（Δ 越小）
>   n = 8 时，分辨率 = 1/255 ≈ 0.39%
>   n = 10 时，分辨率 = 1/1023 ≈ 0.098%
>   n = 12 时，分辨率 = 1/4095 ≈ 0.024%
> ```
> **考试常考：给出 n 和 V_REF，求最小输出电压（1 个 LSB 对应的电压）。**

**② 转换误差（精度）**

**定义**：**实际输出电压与理论输出电压之差，通常用 LSB 的倍数表示。**

```
   常见的误差来源：
   **失调误差（零点误差）**：输入全 0 时输出不为 0
   **增益误差（满量程误差）**：满量程输出偏离理论值
   **线性误差**：中间码的输出偏离理想直线
   **微分线性误差**：相邻码之间的电压差不等于 1 个 LSB
```

**转换误差的表示**：**"±(1/2)LSB"、"±1LSB"** 等。
```
   例：某 8 位 D/A 的转换误差为 ±1/2 LSB
       表示最大误差为 ±(1/2)×(V_REF/256)
```

**③ 建立时间（Settling Time）**

**定义**：**从输入数字量发生变化到输出电压稳定到规定误差范围内（通常 ±1/2 LSB）所需的时间。**

### 8.3.2 转换速度

**转换速度主要取决于建立时间。**

```
   建立时间越短 → 转换速度越快
   高速 D/A 的建立时间：**几十 ns ~ 几 μs**
   低速 D/A 的建立时间：可达几十 μs
```

**影响转换速度的因素：**
```
   ① **开关的动作速度**
   ② **运算放大器的压摆率（Slew Rate）** ← 主要瓶颈
   ③ **电阻网络和分布电容的 RC 时间常数**
```

**D/A 转换器的分类（按速度）：**
| 类型 | 建立时间 | 特点 |
|---|---|---|
| 低速型 | > 100 μs | 用于慢速控制 |
| 中速型 | 1 ~ 100 μs | 一般用途 |
| **高速型** | < 1 μs | **权电流型**，用于视频、通信 |
| 超高速型 | < 100 ns | ECL 工艺 |

**常用集成 D/A 转换器：**
| 型号 | 位数 | 建立时间 | 特点 |
|---|---|---|---|
| **DAC0832** | 8 | 1 μs | 最经典的 8 位 D/A，内部有双缓冲寄存器 |
| **DAC0808** | 8 | 150 ns | 电流输出型 |
| **AD7524** | 8 | 500 ns | CMOS |
| **AD7541** | 12 | 1 μs | 12 位 |
| **AD565** | 12 | 200 ns | 高速 12 位 |

## 8.4 A/D 转换的基本原理

**A/D 转换的四个步骤（★ 必记）：**

```
   模拟输入 ──►┌────┐   ┌────┐   ┌────┐   ┌────┐
               │取样│──►│保持│──►│量化│──►│编码│──► 数字输出
               └────┘   └────┘   └────┘   └────┘
                  ▲                          ▲
             取样脉冲 CP                    V_REF
```

**① 取样（Sampling）**

在取样脉冲控制下，把连续变化的模拟量变成**离散时间**的样值。

```
   v_I ──►┌──────┐   ┌──────┐
          │ 开关 ├───┤  C   │──► v_O
          └──┬───┘   └──────┘
             │
          取样脉冲
   
   取样脉冲为高时：开关闭合，C 充电到 v_I
   取样脉冲为低时：开关断开，C 保持电压
```

**② 保持（Hold）**

把取样得到的样值保持一段时间，供量化和编码使用。**实际电路中通常用"取样-保持电路"一体化实现。**

**③ 量化（Quantization）★ 核心**

**定义**：**把取样保持得到的电压值归整（舍入）到规定的量化电平上。**

```
   量化单位（量化台阶）：
   **Δ = V_REF / 2ⁿ**（把满量程 V_REF 分成 2ⁿ 个等级）
   
   量化方法有两种：
   
   **方法一（只舍不入）**：
     0 ~ Δ 范围内的电压 → 量化为 0
     Δ ~ 2Δ 范围内的电压 → 量化为 Δ
     ...
     最大量化误差 = **Δ**（1 个量化单位）
   
   **方法二（四舍五入）**：
     0 ~ Δ/2 → 0
     Δ/2 ~ 3Δ/2 → Δ
     ...
     最大量化误差 = **Δ/2**（半个量化单位）★ 更常用
```

**④ 编码（Encoding）**

把量化后的电平用**二进制代码**表示。n 位二进制代码可以表示 2ⁿ 个量化电平。

> **重点：量化误差**
> ```
>   **量化误差是 A/D 转换的固有误差，无法消除**（因为用有限位数的数字量表示连续量，
>   必然有舍入）。**只能通过增加位数 n 来减小。**
>   
>   最大量化误差：
>     只舍不入法：**±Δ = ±V_REF/2ⁿ**
>     四舍五入法：**±Δ/2 = ±V_REF/2^(n+1)**
> ```

## 8.5 取样-保持电路

**基本取样-保持电路：**

```
        ┌───────┐
   v_I ─┤       │
        │  开关  ├───┬──────► v_O
   取样 ─┤  (S)  │   │
   脉冲 └───────┘   │
                  ┌─┴─┐
                  │ C │
                  └─┬─┘
                   GND
```

**问题**：电容 C 上的电压在保持期间会因为**漏电流**而缓慢下降，且**输出端的负载会消耗电荷**。

**改进的取样-保持电路（带缓冲放大器）：**

```
        ┌───────┐        ┌───────┐
   v_I ─┤  A₁   ├───┬────┤  A₂   ├─── v_O
        │(缓冲) │   │    │(缓冲) │
        └───────┘   │    └───────┘
                  ┌─┴─┐
              S ──┤ C │
                  └─┬─┘
                   GND
```

**集成取样-保持电路：LF198 / LF298 / LF398**

| 参数 | 数值 |
|---|---|
| **采集时间** | 10 μs（到 0.01% 精度） |
| **保持电压下降率** | 30 mV/s（典型） |
| **输入电阻** | 10¹⁰ Ω |
| **电源** | ±5 V ~ ±18 V |

**应用**：
```
   ① A/D 转换器的前置电路（保证转换期间输入不变）
   ② 多路模拟信号的采集（分时取样多路信号）
   ③ 峰值检波、模拟延时
```

## 8.6 A/D 转换器的电路结构和工作原理

### 8.6.1 并联比较型 A/D 转换器（★ 最快）

**核心思想**：**用 2ⁿ − 1 个比较器同时比较，一次就能得到结果。**

**3 位并联比较型 A/D 转换器电路：**

```
                                    ┌──────────────────────────┐
                                    │      编码器（优先）       │
                                    └──────────────────────────┘
                                                  ▲
   V_REF                                        （7 个比较器输出）
     │        ┌───┐                              │
     ├── R ───┤ C₇│──────────────────────────────┘
     │        └───┘  (+/−)                    
     │        ┌───┐                            
     ├── R ───┤ C₆│───────────────────────────┐ 
     │        └───┘                           │
     │        ┌───┐                           │
     ├── R ───┤ C₅│─────────────────────────┐ │
     │        └───┘                         │ │
     │        ┌───┐                         │ │
     ├── R ───┤ C₄│───────────────────────┐ │ │
     │        └───┘                       │ │ │
     │        ┌───┐                       │ │ │
     ├── R ───┤ C₃│─────────────────────┐ │ │ │
     │        └───┘                     │ │ │ │
     │        ┌───┐                     │ │ │ │
     ├── R ───┤ C₂│───────────────────┐ │ │ │ │
     │        └───┘                   │ │ │ │ │
     │        ┌───┐                   │ │ │ │ │
     ├── R ───┤ C₁│─────────────────┐ │ │ │ │ │
     │        └───┘                 │ │ │ │ │ │
     │                               │ │ │ │ │ │
    GND                              ▼ ▼ ▼ ▼ ▼ ▼ ▼
                                  编码器（7 → 3）
                                       │ │ │
                                       D₂D₁D₀（3 位输出）
   
   7 个比较器的参考电压（从下往上 C₁ → C₇，C₁ 最靠近 GND）：
   **C₁: V_REF/8,  C₂: 2V_REF/8,  C₃: 3V_REF/8,  C₄: 4V_REF/8,
     C₅: 5V_REF/8,  C₆: 6V_REF/8,  C₇: 7V_REF/8**
   
   → 通式：**第 k 个比较器的阈值 V_k = k·V_REF/8（k = 1, 2, …, 7）**
   → 最高的阈值是 **7V_REF/8 < V_REF**，不可能出现 9V_REF/8 这种超过 V_REF 的值
   （分压电阻链是 8 个 R 串联，相邻抽头之间恰好差 V_REF/8）
```

**工作原理：**
```
   ① 分压电阻链产生 2ⁿ − 1 个参考电压
      （3 位时需要 7 个参考电压：V_REF/8, 2V_REF/8, …, 7V_REF/8）
   ② 输入 v_I 同时送到 2ⁿ − 1 个比较器，与各自的参考电压比较
   ③ 所有 v_I 大于参考电压的比较器输出为 1，其余为 0
   ④ 编码器把"温度计码"转换成二进制码
```

**★ 核心结论：**
```
   **n 位并联比较型 A/D 需要 2ⁿ − 1 个比较器和 2ⁿ 个分压电阻**
   
   n = 3 时：7 个比较器，8 个电阻
   n = 4 时：15 个比较器，16 个电阻
   n = 8 时：**255 个比较器**，256 个电阻（！）
   n = 10 时：**1023 个比较器**（！）
```

**优缺点：**
```
   ✅ **转换速度最快**（所有比较器同时工作，只需一次比较时间 + 编码时间）
      典型转换时间：**几十 ns ~ 几百 ns**
   ❌ **元件数量随位数指数增长**（n = 8 就要 255 个比较器）
      → 只能用于**低位数、超高速**的场合
```

**应用**：**示波器、数字视频、雷达、高速数据采集**（一般 4~8 位）。

**★★ 考试重点：给定位数求比较器个数（或反过来）。**
```
   n 位 → 2ⁿ − 1 个比较器
   有 15 个比较器 → 2ⁿ − 1 = 15 → 2ⁿ = 16 → **n = 4 位**
```

### 8.6.2 流水线型 A/D 转换器（了解）

```
   把多级并联比较型电路"串"起来，每级只转换几位
   第 1 级转换高几位，把余量放大后送第 2 级转换……
   → 速度快（各级流水工作），元件少（不需要 2ⁿ − 1 个比较器）
   → 广泛用于高速高精度场合（如 12 位 100 MSPS）
```

### 8.6.3 逐次逼近型 A/D 转换器（★ 最常用）

**核心思想**：**从最高位开始，逐位试探，与输入比较，"大就留、小就改"，像用天平称重。**

**结构框图：**

```
   ┌──────────────────────────────────────────────────────┐
   │                                                      │
   │   ┌──────────────┐         ┌──────────────┐          │
   │   │ 逐次逼近寄存器 │◄────────┤  控制逻辑     │          │
   │   │（SAR）        │         │（时序控制）   │          │
   │   └───────┬──────┘         └───────▲──────┘          │
   │           │ 数字量 D                 │                 │
   │           ▼                          │                 │
   │   ┌──────────────┐                   │                 │
   │   │   D/A 转换器  │                   │                 │
   │   └───────┬──────┘                   │                 │
   │           │ v_A（D/A 输出）           │                 │
   │           ▼                          │                 │
   │        ┌──┴──┐                       │                 │
   v_I ────►│比较器│───────────────────────┘                 │
            └─────┘   （v_I > v_A 则保留，否则清除）          │
   └──────────────────────────────────────────────────────┘
```

**工作原理（以 4 位、V_REF = 16 V、v_I = 13 V 为例）：**

```
   步骤   SAR 中的数字量   D/A 输出 v_A    比较        动作
   ─────────────────────────────────────────────────────────
   ①     1000             8 V            v_I > v_A   保留最高位
   ②     1100             12 V           v_I > v_A   保留次高位
   ③     1110             14 V           v_I < v_A   清除第 3 位
   ④     1101             13 V           v_I = v_A   保留最低位
   ─────────────────────────────────────────────────────────
   结果：**1101 = 13** ✓（13/16 × 16 V = 13 V）
```

**★ 核心结论：**
```
   ① **n 位逐次逼近型 A/D 需要 n 个时钟周期完成一次转换**
      （每一位一个周期）
   ② **转换时间 = n × T_CP**（T_CP 为时钟周期）
   ③ **转换时间固定**，与输入电压的大小无关
```

**优缺点：**
```
   ✅ **速度快**（n 位只需 n 个时钟周期，比双积分快得多）
   ✅ **精度高**（可以达到 12~16 位）
   ✅ **元件少**（只需 1 个比较器 + 1 个 D/A + 逻辑控制）
   ❌ 抗干扰能力不如双积分型
   ❌ 对 D/A 转换器的精度要求高（D/A 的误差直接影响结果）
```

**应用**：**最广泛使用**的 A/D 结构，用于数据采集、单片机 ADC、通用测量。

**★ 常用集成逐次逼近型 ADC：**

| 型号 | 位数 | 转换时间 | 特点 |
|---|---|---|---|
| **ADC0809** | 8 | 100 μs | 8 通道，最经典的 8 位 ADC |
| **ADC0804** | 8 | 100 μs | 单通道 |
| **AD574** | 12 | 25 μs | 12 位，高精度 |
| **ADC1210** | 12 | 100 μs | 12 位 |

### 8.6.4 双积分型 A/D 转换器（★ 精度最高，抗干扰最强）

**核心思想**：**先把输入电压积分一段时间（固定），再用基准电压反向积分（时间可变），用第二次积分的时间来度量输入电压。**

**结构框图：**

```
                                       ┌───────┐
                                       │       │
   ┌──────┐    ┌──────────┐            │  积分器 │
   │      │    │          │      ┌─────┤  (A₁)  ├───┬──►┌─────┐
v_I ─┤ 开关 ├───►│  R      ├──────┘     │       │   │   │比较器│──► 控制逻辑
   │  S₁  │    │          │            └───────┘   │   │     │
   └──┬───┘    └──────────┘                        │   └─────┘
      │                                        ┌───┴───┐
  −V_REF ──► S₂                                │   C   │──► 计数器
      │                                        └───┬───┘
      │                                            │
      └──────────► 控制逻辑 ◄───────────────────────┘
```

**工作原理（两个积分阶段）：**

```
   ① **第一次积分（对输入电压积分，固定时间 T₁）**：
      开关接 v_I，积分器从 0 开始积分，积分时间固定为 **T₁ = 2ⁿ·T_C**
      （T_C = 时钟周期，n = 计数器位数）
      
      积分结束时输出：
      **v_O1 = −(1/RC)·∫₀^{T₁} v_I dt = −(v_I·T₁)/(RC)**
      （设 v_I 在积分期间为常数）

   ② **第二次积分（对基准电压反相积分，时间 T₂ 可变）**：
      开关接 **−V_REF**，积分器输出从 v_O1 开始**回升**（因为积分方向相反）
      当输出回到 0 时，比较器动作，停止计数
      
      **v_O2 = v_O1 + (V_REF·T₂)/(RC) = 0**
      → **(V_REF·T₂)/(RC) = (v_I·T₁)/(RC)**
      → **T₂ = (v_I/V_REF)·T₁**

   ③ **输出结果**：
      第二次积分期间，计数器对时钟脉冲计数，计数值为 **N₂ = T₂/T_C**
      
      **N₂ = (v_I/V_REF)·T₁/T_C = (v_I/V_REF)·2ⁿ**
      
      → **数字输出 D = N₂ = 2ⁿ·v_I/V_REF**
```

**★★★ 核心公式：**
```
   **D = (v_I / V_REF) · 2ⁿ**
   
   或者：**v_I = (D/2ⁿ)·V_REF**
   
   转换时间：**T = T₁ + T₂(max) = 2ⁿ·T_C + 2ⁿ·T_C = 2^(n+1)·T_C**
   （最坏情况是 T₂ 也取满量程）
   典型值：**T = (2~3)·2ⁿ·T_C**... 实际上标准为 **T₁ + T₂max = 2·2ⁿ·T_C = 2^(n+1)·T_C**
```

**为什么要用 2ⁿ·T_C 作为第一次积分时间？**
```
   因为计数器有 n 位，最多计 2ⁿ 个数
   → 第一次积分时间 T₁ = 2ⁿ·T_C 正好让计数器计满
   → 第二次积分的计数结果 N₂ = (v_I/V_REF)·2ⁿ 自动落在 0 ~ 2ⁿ 范围内
   → 与 n 位数字输出一一对应 ✓
```

**★ 为什么双积分型 A/D 的精度与 R、C 无关？（核心考点）**
```
   因为公式 T₂ = (v_I/V_REF)·T₁ 中，**R 和 C 都被约掉了**！
   
   推导：v_O1 = −(v_I·T₁)/(RC)
        v_O2 = v_O1 + (V_REF·T₂)/(RC) = 0
        → (V_REF·T₂)/(RC) = (v_I·T₁)/(RC)
        → **V_REF·T₂ = v_I·T₁**（RC 消失！）
        → T₂ = (v_I/V_REF)·T₁
   
   → **R 和 C 的精度、温漂都不影响转换结果** ✓
   → 这是双积分型 A/D 精度极高的根本原因
```

**★ 为什么双积分型 A/D 抗干扰能力强？**
```
   第一次积分的时间 T₁ = 2ⁿ·T_C 是**固定的**
   如果选择 T₁ 为**工频干扰周期（20 ms，即 50 Hz）的整数倍**，
   则工频干扰在积分期间的正负半周相互抵消 → **积分结果为 0**
   → 对 50 Hz 工频干扰有极强的抑制能力 ✓
   
   实际产品通常选择 T₁ = 20 ms 或 100 ms（工频周期的整数倍）
```

**优缺点：**
```
   ✅ **精度极高**（可达 16~22 位）
   ✅ **抗干扰能力最强**（对工频干扰抑制好）
   ✅ **电路简单，成本低**
   ✅ **精度不受 R、C 影响**
   ❌ **转换速度最慢**（n 位需要 2^(n+1) 个时钟周期）
      例如 n = 10、T_C = 1 μs → T = 2^11 × 1 μs = 2.048 ms
   ❌ 不适合快速变化的信号
```

**应用**：**数字电压表、万用表、精密测量仪器**（这些场合速度要求不高，但精度要求高）。

**常用集成双积分型 ADC：**
| 型号 | 位数 | 特点 |
|---|---|---|
| **ICL7106/7107** | 3½ 位（约 11 位） | 万用表专用，直接驱动 LCD/LED |
| **ICL7135** | 4½ 位（约 14 位） | 高精度万用表 |
| **MC14433** | 3½ 位 | 通用 |

### 8.6.5~8.6.6 其他类型（了解）

**Σ-Δ（Sigma-Delta）型 A/D**：
```
   用"过采样 + 噪声整形 + 数字滤波"实现高分辨率
   特点：**分辨率极高（16~24 位）**，速度中等
   应用：**音频（CD、MP3）、精密测量**
```

**V-F 变换型 A/D**：
```
   先把电压转换成频率，再用计数器测频
   特点：抗干扰好，适合远距离传输（频率信号不易受干扰）
```

**★ 四种 A/D 转换器对比（★★★ 必考）：**

| 类型 | 转换速度 | 精度 | 抗干扰 | 元件数 | 典型应用 |
|---|---|---|---|---|---|
| **并联比较型** | **最快**（ns~μs） | 低（≤8 位） | 差 | **最多（2ⁿ−1 个比较器）** | 示波器、视频 |
| **逐次逼近型** | **较快**（μs~百 μs） | 中高（8~16 位） | 中 | 少 | **通用数据采集** ★最常用 |
| **双积分型** | **最慢**（ms~百 ms） | **最高**（16~22 位） | **最强** | 少 | **数字电压表** |
| **Σ-Δ 型** | 慢 | **极高**（16~24 位） | 强 | 中 | **音频、精密测量** |

## 8.7 A/D 转换器的转换精度与转换速度

### 8.7.1 转换精度

**① 分辨率（Resolution）★**

```
   **Δ = V_REF / 2ⁿ**（能分辨的最小输入电压变化量）
   或者用**位数 n 直接表示**（n 位分辨率）
   相对分辨率 = **1/(2ⁿ − 1) × 100%**
```

**② 转换误差**

```
   包括：**量化误差**（固有，±Δ/2）、**失调误差**、**增益误差**、**线性误差**
   通常用 **LSB 的倍数**表示
```

**③ 量化误差**

```
   **只舍不入法**：最大误差 = **±1 LSB = ±V_REF/2ⁿ**
   **四舍五入法**：最大误差 = **±(1/2) LSB = ±V_REF/2^(n+1)**

   → **量化误差是原理性误差，不能通过提高电路精度消除，只能增加位数**
```

### 8.7.2 转换速度

**转换时间的定义**：**完成一次转换所需的时间。**

```
   **并联比较型**：**T ≈ t_c + t_e**（一次比较时间 + 编码时间）→ 最快
   **逐次逼近型**：**T = n·T_CP**（n 位需要 n 个时钟周期）
   **双积分型**：**T = 2^(n+1)·T_C**（最慢，且与输入有关）
```

**★ 三种主要 A/D 的转换时间对比（考题常见）：**
```
   例：n = 8 位，时钟频率 f_C = 1 MHz（T_C = 1 μs）
   
   ① 逐次逼近型：**T = n·T_C = 8 × 1 μs = 8 μs**
   ② 双积分型：**T = 2^(n+1)·T_C = 2⁹ × 1 μs = 512 μs**（约 0.5 ms）
   ③ 并联比较型：**T ≈ 几十 ns**（几乎只需比较器延迟）
   
   → 速度排序：**并联比较型 > 逐次逼近型 > 双积分型**
```

**★ 分辨率与转换速度的矛盾：**
```
   **位数越多，分辨率越高，但转换时间越长**（逐次逼近、双积分）
   **并联比较型的位数受元件数限制**（2ⁿ − 1 个比较器）
   
   → 实际选择时要在**精度**和**速度**之间权衡
```

## 典型例题

**例 8.1**（题型：D/A 输出电压计算）

某 8 位倒 T 形电阻网络 D/A 转换器，V_REF = 10 V，R_f = R。求：
（1）输入数字量为 10000000 时的输出电压；
（2）输入数字量为 11111111 时的输出电压；
（3）输入数字量为 00000001 时的输出电压；
（4）分辨率（最小输出电压变化量）。

**解**：

**公式：`v_O = −(V_REF/2ⁿ)·D`**，其中 n = 8、2⁸ = 256、D 为输入数字量对应的十进制数。

**（1）输入 10000000**
```
   D = 2⁷ = 128
   v_O = −(10/256) × 128 = −0.0390625 × 128 = **−5 V**
```

**（2）输入 11111111**
```
   D = 2⁸ − 1 = 255
   v_O = −(10/256) × 255 = −0.0390625 × 255 = −9.9609375 V
       ≈ **−9.96 V**
   
   （注意：满量程输出不是 −10 V，而是 −(255/256)×10 V = −9.96 V，
    因为 n 位最大数字量是 2ⁿ−1 而不是 2ⁿ）
```

**（3）输入 00000001**
```
   D = 1
   v_O = −(10/256) × 1 = −0.0390625 V
       ≈ **−39.06 mV**
```

**（4）分辨率**
```
   Δ = V_REF/2ⁿ = 10/256 = 0.0390625 V ≈ **39.06 mV**
   
   或用相对值：1/(2⁸−1) = 1/255 = 0.392%
```

**答案**：（1）**−5 V**；（2）**−9.96 V**；（3）**−39.06 mV**；（4）**Δ ≈ 39.06 mV**（相对分辨率 0.392%）。

**为什么这样做**：
```
   ★ 倒 T 形 D/A 的输出公式 **v_O = −(V_REF/2ⁿ)·D** 是必背的
   ★ **易错点：满量程不是 −V_REF，而是 −V_REF·(2ⁿ−1)/2ⁿ**
     例如 8 位时满量程是 −(255/256)V_REF ≈ −0.996V_REF
     （因为 D 最大是 2ⁿ−1，不是 2ⁿ）
   ★ 分辨率就是 1 个 LSB 对应的电压：**Δ = V_REF/2ⁿ**
     注意：分辨率的分母是 **2ⁿ**（不是 2ⁿ−1）
     而相对分辨率的分母是 **2ⁿ−1**（这是容易混的地方）
```

**例 8.2**（题型：D/A 分辨率与位数计算）

某 D/A 转换器的满量程输出电压为 10 V（即输入全 1 时输出 −10 V 的绝对值），要求分辨率优于 5 mV。问至少需要多少位？

**解**：

**由分辨率要求确定位数：**
```
   分辨率 Δ = V_REF/2ⁿ ≤ 5 mV
   
   注意：这里给的是满量程输出电压 10 V，对应的是 (2ⁿ−1) 个量化台阶
   严格来说：满量程 = Δ × (2ⁿ − 1) = 10 V
   
   所以：Δ = 10/(2ⁿ − 1) ≤ 5 mV = 0.005 V
   → 2ⁿ − 1 ≥ 10/0.005 = 2000
   → 2ⁿ ≥ 2001
```

**试算：**
```
   2¹⁰ = 1024 < 2001  ✗
   2¹¹ = 2048 ≥ 2001  ✓
   → **n = 11 位**
```

**验证：**
```
   n = 11 时，Δ = 10/(2¹¹ − 1) = 10/2047 = 4.885 mV < 5 mV ✓
   n = 10 时，Δ = 10/(2¹⁰ − 1) = 10/1023 = 9.775 mV > 5 mV ✗
```

**答案**：**至少需要 11 位**。

**为什么这样做**：
```
   ★ 若题目给的 V_REF = 10 V（基准电压），则：
       Δ = V_REF/2ⁿ = 10/2ⁿ ≤ 0.005 → 2ⁿ ≥ 2000 → n ≥ 11
       结果同样是 11 位（因为 2¹⁰ = 1024、2¹¹ = 2048）
   
   ★ 若题目给的是"满量程输出"，严格用 (2ⁿ−1)：
       本题 2ⁿ − 1 ≥ 2000 → n = 11
   
   ★ 两种算法在本题中结果相同，但**概念上要分清**：
       - **Δ = V_REF/2ⁿ** 是"1 个 LSB 的电压"
       - **满量程 = Δ·(2ⁿ−1) = V_REF·(2ⁿ−1)/2ⁿ**
   
   ★ 位数与分辨率的经验值（考试常查）：
     ```
     n = 8  → 分辨率 0.39%（约 1/256）
     n = 10 → 分辨率 0.098%（约 1/1024）
     n = 12 → 分辨率 0.024%（约 1/4096）
     n = 16 → 分辨率 0.0015%（约 1/65536）
     ```
```

**例 8.3**（题型：并联比较型 A/D 的比较器数目）

（1）一个 6 位并联比较型 A/D 转换器需要多少个比较器？多少个分压电阻？
（2）某并联比较型 A/D 转换器用了 31 个比较器，它的分辨率是多少位？
（3）若 V_REF = 8 V，求（2）中 A/D 的量化单位。

**解**：

**（1）6 位并联比较型**
```
   比较器个数 = 2ⁿ − 1 = 2⁶ − 1 = 64 − 1 = **63 个**
   分压电阻个数 = 2ⁿ = 2⁶ = **64 个**
```

**（2）31 个比较器**
```
   2ⁿ − 1 = 31
   2ⁿ = 32
   → **n = 5 位**
```

**（3）量化单位**
```
   Δ = V_REF/2ⁿ = 8/2⁵ = 8/32 = **0.25 V**
```

**答案**：（1）**63 个比较器，64 个分压电阻**；（2）**5 位**；（3）**Δ = 0.25 V**。

**为什么这样做**：
```
   ★ 并联比较型的核心结论：**n 位需要 2ⁿ − 1 个比较器、2ⁿ 个电阻**
   ★ 记忆方法：
     比较器是"两个电阻之间夹一个"，电阻有 2ⁿ 个就有 2ⁿ − 1 个"间隙"
     → 比较器个数 = 电阻个数 − 1 = 2ⁿ − 1
   
   ★ 这个结论说明并联比较型的元件数**随位数指数增长**：
     ```
     n = 4  → 15 个比较器   （可用）
     n = 6  → 63 个比较器   （可用）
     n = 8  → 255 个比较器  （已经很多）
     n = 10 → 1023 个比较器 （不现实）
     n = 12 → 4095 个比较器 （不可能）
     ```
   → **所以并联比较型只用于 8 位以下的高速场合**
```

**例 8.4**（题型：逐次逼近型 A/D 的转换过程）

某 8 位逐次逼近型 A/D 转换器，V_REF = 10 V，时钟频率 f_C = 500 kHz。输入电压 v_I = 6.4 V。求：
（1）转换完成后输出的二进制码（写出逐次逼近的过程）；
（2）一次转换所需的时间。

**解**：

**（1）逐次逼近过程**

量化单位：Δ = V_REF/2⁸ = 10/256 = 0.0390625 V
（为了方便，下面用"数字量对应的电压" = (D/256)×10 V 来判断）

```
   步骤  SAR 数字量   D/A 输出 v_A          比较          动作
   ─────────────────────────────────────────────────────────────
   ①     1000 0000    (128/256)×10 = 5.000 V   v_I=6.4 > 5.0   保留 D₇=1
   ②     1100 0000    (192/256)×10 = 7.500 V   v_I=6.4 < 7.5   清除 D₆=0
   ③     1010 0000    (160/256)×10 = 6.250 V   v_I=6.4 > 6.25  保留 D₅=1
   ④     1011 0000    (176/256)×10 = 6.875 V   v_I=6.4 < 6.875 清除 D₄=0
   ⑤     1010 1000    (168/256)×10 = 6.5625 V  v_I=6.4 < 6.5625 清除 D₃=0
   ⑥     1010 0100    (164/256)×10 = 6.40625 V v_I=6.4 < 6.40625 清除 D₂=0
   ⑦     1010 0010    (162/256)×10 = 6.328125 V v_I=6.4 > 6.328 保留 D₁=1
   ⑧     1010 0011    (163/256)×10 = 6.3671875 V v_I=6.4 > 6.367 保留 D₀=1
   ─────────────────────────────────────────────────────────────
   最终结果：**1010 0011**
```

**验证：**
```
   D = 1010 0011₂ = 128 + 32 + 2 + 1 = 163
   v_A = (163/256) × 10 = 6.3671875 V
   量化误差 = |6.4 − 6.3671875| = 0.0328 V < Δ = 0.0391 V ✓
```

**（2）转换时间**
```
   T_CP = 1/f_C = 1/(500×10³) = 2 × 10⁻⁶ s = 2 μs
   
   n 位逐次逼近型需要 n 个时钟周期：
   **T = n × T_CP = 8 × 2 μs = 16 μs**
```

**答案**：（1）输出二进制码为 **1010 0011**（十进制 163）；（2）转换时间 **T = 16 μs**。

**为什么这样做**：
```
   ★ 逐次逼近的规则（**"大就留，小就改"**）：
     ① 从最高位开始，先置 1
     ② D/A 输出电压 v_A，与 v_I 比较
     ③ **若 v_I ≥ v_A：保留这一位的 1**
        **若 v_I < v_A：把这一位改回 0**
     ④ 继续下一位，直到最低位
   
   ★ 一次转换需要 **n 个时钟周期**（每一位一个周期）
     → **转换时间与输入电压的大小无关**（固定值）
   
   ★ 逐次逼近法的实质是**二分搜索**：
     第一步排除一半范围，第二步再排除一半……
     n 步后精度达到 1/2ⁿ ✓
```

**例 8.5**（题型：双积分型 A/D 的计算）

某双积分型 A/D 转换器中，计数器为 10 位，时钟频率 f_C = 100 kHz，V_REF = 5 V。输入电压 v_I = 3 V。求：
（1）第一次积分时间 T₁；
（2）第二次积分时间 T₂；
（3）输出的数字量；
（4）一次转换的总时间；
（5）若 R = 100 kΩ、C = 0.1 μF，说明 R、C 的误差是否影响转换结果。

**解**：

**（1）第一次积分时间**
```
   T₁ = 2ⁿ·T_C = 2¹⁰ × (1/100×10³) = 1024 × 10 × 10⁻⁶ s
      = 1024 × 10 μs = **10.24 ms**
```

**（2）第二次积分时间**
```
   公式：**T₂ = (v_I/V_REF)·T₁**
   
   T₂ = (3/5) × 10.24 ms = 0.6 × 10.24 ms = **6.144 ms**
```

**（3）输出的数字量**
```
   计数器的计数值：
   N₂ = T₂/T_C = 6.144×10⁻³ / (10×10⁻⁶) = 614.4
   
   （取整为 **614**，对应二进制 1001100110）
   
   或用公式：**D = (v_I/V_REF)·2ⁿ = (3/5) × 1024 = 614.4 ≈ 614**
```

**（4）一次转换的总时间**
```
   最坏情况（输入为满量程 V_REF 时）：
   T_max = T₁ + T₂max = 2ⁿ·T_C + 2ⁿ·T_C = 2^(n+1)·T_C
        = 2¹¹ × 10 μs = 2048 × 10 μs = **20.48 ms**
   
   本题的实际转换时间：
   T = T₁ + T₂ = 10.24 + 6.144 = **16.384 ms**
```

**（5）R、C 的影响**
```
   **R、C 的误差完全不影响转换结果！**
   
   证明：
     第一次积分：v_O1 = −(v_I·T₁)/(RC)
     第二次积分：v_O2 = v_O1 + (V_REF·T₂)/(RC) = 0
     → (V_REF·T₂)/(RC) = (v_I·T₁)/(RC)
     → **V_REF·T₂ = v_I·T₁**（RC 被约掉！）
     → T₂ = (v_I/V_REF)·T₁
   
   → **转换结果只与 v_I、V_REF、T₁ 有关，与 R、C 的具体值无关**
   → 这是双积分型 A/D 精度高的根本原因（R、C 的精度和温漂都不影响结果）
```

**答案**：（1）T₁ = **10.24 ms**；（2）T₂ = **6.144 ms**；（3）输出数字量 **D ≈ 614**（对应 3 V）；（4）实际转换时间 **16.384 ms**，最坏情况 **20.48 ms**；（5）**R、C 的误差不影响转换结果**（因为 RC 在推导中被约掉）。

**为什么这样做**：
```
   ★ 双积分型 A/D 的三个核心公式（必背）：
     ```
     D = (v_I/V_REF)·2ⁿ       （输出数字量）
     T₁ = 2ⁿ·T_C              （第一次积分时间，固定）
     T₂ = (v_I/V_REF)·T₁      （第二次积分时间，与 v_I 成正比）
     T = 2^(n+1)·T_C          （最坏情况转换时间）
     ```
   
   ★ 为什么 T₁ 要取 2ⁿ·T_C？
     因为计数器是 n 位，最大计数值是 2ⁿ
     让第一次积分正好计满 2ⁿ 个数，则第二次积分的计数结果
     自然落在 0~2ⁿ 范围内，与 n 位输出一一对应 ✓
   
   ★ **转换时间与输入电压有关**（T₂ 随 v_I 变化），
     这与逐次逼近型（时间固定）不同。**取最坏情况（v_I = V_REF）来标称转换时间。**
```

**例 8.6**（题型：A/D 转换器类型选择）

某数据采集系统需要采集 0~5 V 的直流信号，要求：
（1）分辨率为 1 mV，转换速度 100 kSPS（每秒 10 万次）；
（2）分辨率为 4½ 位（约 1/20000），但对 50 Hz 工频干扰抑制要好，速度要求不高；
（3）采集 20 MHz 的视频信号，8 位精度。

分别应选用哪种 A/D 转换器？并计算（1）中需要的位数和（2）中的转换时间量级。

**解**：

**（1）分辨率 1 mV、速度 100 kSPS**

**位数计算：**
```
   量化单位 Δ = 5/2ⁿ ≤ 1 mV = 0.001 V
   → 2ⁿ ≥ 5/0.001 = 5000
   
   2¹² = 4096 < 5000  ✗
   2¹³ = 8192 ≥ 5000  ✓
   → **n = 13 位**（工程上取 **14 位或 16 位** 更保险）
```

**速度检查：**
```
   100 kSPS → 每次转换时间 ≤ 10 μs
   逐次逼近型：T = n·T_CP
   若 n = 14、T_CP = 0.5 μs → T = 7 μs ≤ 10 μs ✓
   若 n = 16、T_CP = 0.5 μs → T = 8 μs ≤ 10 μs ✓
```

**选用类型：** **逐次逼近型**（速度与精度兼顾，最常用）。

**（2）4½ 位、抗工频干扰、速度不高**

```
   4½ 位 ≈ 精度 1/20000 ≈ 14.3 位
   要求抗 50 Hz 工频干扰 → **双积分型**（唯一能对工频干扰形成"积分对消"的结构）
```

**转换时间估算：**
```
   若用 MC14433 类电路，典型转换时间：
   **约 100 ms**（对应约 10 次/秒的转换速率）
   
   或按公式：n = 14、T_C = 50 μs → T = 2¹⁵ × 50 μs = 1.638 s
   （实际产品通过优化把时间压到 100~300 ms）
   
   若取工频周期整数倍：T₁ = 20 ms（50 Hz 的一个周期）
   → 转换速率约 10~25 次/秒
```

**选用类型：** **双积分型**（精度最高、抗工频干扰最强）。

**（3）20 MHz 视频信号、8 位**

```
   带宽 20 MHz → 取样频率至少 40 MHz（取样定理），实际取 50 MHz 以上
   → 转换时间必须 ≤ 20 ns
   
   逐次逼近型：T = n·T_CP = 8 × T_CP ≤ 20 ns → T_CP ≤ 2.5 ns（太苛刻）
   双积分型：毫秒级，完全不可能
   → 只能选 **并联比较型（或流水线型）**
```

**选用类型：** **并联比较型**（或流水线型）。

**答案**：
```
   （1）**逐次逼近型**，需要 **13 位以上**（工程上用 14~16 位）
   （2）**双积分型**，转换时间量级 **100 ms**
   （3）**并联比较型**（或流水线型）
```

**为什么这样做**：
```
   ★ **A/D 类型选择的三条准则**：
     ```
     ① **要高速（> 1 MSPS）** → **并联比较型 / 流水线型**
     ② **要通用（速度精度兼顾）** → **逐次逼近型** ★ 最常用
     ③ **要高精度 + 抗干扰（速度慢无妨）** → **双积分型**
     ```
   
   ★ **关键判据是"抗工频干扰"**：
     只有**双积分型**能通过"积分整周期对消"来抑制 50 Hz 干扰
     → 数字电压表、万用表都用双积分型 ✓
   
   ★ **取样定理是高速场合的硬约束**：
     视频 20 MHz 带宽 → 必须 > 40 MSPS → 排除所有慢速结构
```

**例 8.7**（题型：A/D 与 D/A 综合计算）

某 8 位 A/D 转换器的满量程输入为 5 V，采用四舍五入量化方式。求：
（1）量化单位 Δ；
（2）最大量化误差；
（3）输入 2.5 V 时的输出数字量；
（4）输入 2.503 V 和 2.497 V 时输出是否相同？说明原因。

**解**：

**（1）量化单位**
```
   Δ = 5/2⁸ = 5/256 = 0.01953125 V ≈ **19.53 mV**
```

**（2）最大量化误差**
```
   四舍五入法：**最大误差 = ±(1/2)Δ = ±9.77 mV**
   （只舍不入法则是 ±Δ = ±19.53 mV）
```

**（3）输入 2.5 V**
```
   D = v_I/Δ = 2.5/0.01953125 = 128
   → 输出数字量为 **1000 0000**（十进制 128）
   
   验证：量化电平 = 128 × 0.01953125 = 2.5 V ✓
```

**（4）2.503 V 和 2.497 V**
```
   2.503 V：D = 2.503/0.01953125 = 128.15 → 四舍五入 → **128**
   2.497 V：D = 2.497/0.01953125 = 127.85 → 四舍五入 → **128**
   
   → **两者输出相同，都是 128（1000 0000）**
```

**原因**：
```
   因为 A/D 转换器是**离散量化**的：
   - 2.5 V 是第 128 个量化电平的**中心**
   - 量化区间是 [127.5Δ, 128.5Δ] = [2.4902 V, 2.5098 V]
   - 2.497 V 和 2.503 V 都落在这个区间内
   → 都量化为 128 ✓
   
   **A/D 转换器无法分辨同一量化区间内的不同电压值**，这就是量化误差的来源。
```

**答案**：（1）Δ ≈ **19.53 mV**；（2）最大量化误差 **±9.77 mV**；（3）输出 **1000 0000（128）**；（4）**两者输出相同（都是 128）**，因为它们落在同一个量化区间 [2.4902 V, 2.5098 V] 内。

**为什么这样做**：
```
   ★ 四舍五入量化的**判决电平**在相邻量化电平的**中点**：
     第 k 个量化电平对应区间 **[kΔ − Δ/2, kΔ + Δ/2)**
   ★ 最大量化误差 = **±Δ/2**（四舍五入）
                       或 **±Δ**（只舍不入）
   ★ 量化误差是 **A/D 转换的固有误差，无法消除**，
     只能通过**增加位数 n** 来减小（n 每增加 1 位，误差减半）
```

**例 8.8**（题型：D/A 双极性输出）

某 8 位 D/A 转换器 V_REF = 10 V，采用偏移二进制码实现双极性输出。求：
（1）输入 0000 0000、1000 0000、1111 1111 时的输出电压；
（2）输出电压范围；
（3）若改用二进制补码，输入 1000 0000 对应什么电压？

**解**：

**（1）偏移二进制码的输出电压**

偏移二进制码的规律：**最高位（MSB）为符号位**（1 表示正、0 表示负），输出电压为：
```
   v_O = (D − 2^(n−1))·Δ，其中 Δ = V_REF/2ⁿ = 10/256 = 0.0390625 V
```

```
   ① 输入 0000 0000（D = 0）：
      v_O = (0 − 128) × 0.0390625 = −128 × 0.0390625 = **−5 V**
   
   ② 输入 1000 0000（D = 128）：
      v_O = (128 − 128) × 0.0390625 = **0 V**  ← 零点
   
   ③ 输入 1111 1111（D = 255）：
      v_O = (255 − 128) × 0.0390625 = 127 × 0.0390625 = 4.9609375 V
          ≈ **+4.96 V**
```

**（2）输出电压范围**
```
   从 −5 V 到 +4.96 V
   即 **−(2^(n−1))·Δ ~ +(2^(n−1) − 1)·Δ**
   理论对称范围：**−V_REF/2 ~ +V_REF/2**（即 ±5 V）
   实际正半轴最大是 +4.96 V（因为最大的正数字量是 127）
```

**（3）二进制补码**

二进制补码中，**1000 0000 表示 −128**：
```
   v_O = −128 × Δ = −128 × 0.0390625 = **−5 V**
   
   （补码的输出关系：v_O = D_补·Δ，其中 D_补 为补码对应的有符号数值）
   
   验证：
     补码 0111 1111 = +127 → v_O = 127 × 0.0390625 = +4.96 V
     补码 0000 0000 = 0    → v_O = 0 V
     补码 1111 1111 = −1   → v_O = −0.039 V
     补码 1000 0000 = −128 → v_O = −5 V
   → 输出范围 **−5 V ~ +4.96 V**（与偏移二进制码的输出范围相同，但**编码方式不同**）
```

**答案**：（1）0000 0000 → **−5 V**；1000 0000 → **0 V**；1111 1111 → **+4.96 V**；（2）范围 **−5 V ~ +4.96 V**；（3）补码 1000 0000 → **−5 V**。

**为什么这样做**：
```
   ★ **偏移二进制码**：把单极性输出的范围"平移"一半
     ```
     v_O = (D − 2^(n−1))·Δ
     零点对应 D = 2^(n−1) = 100…0
     ```
   
   ★ **二进制补码**：MSB 是符号位，直接按有符号数解释
     ```
     v_O = D_补·Δ（D_补 是有符号数）
     零点对应 D = 000…0
     ```
   
   ★ **两者的区别（易混）**：
     ```
     同一个二进制码 1000 0000：
       偏移二进制码 → 0 V（这是"零点"）
       二进制补码   → −5 V（这是"最负值"）
     
     两者的输出范围相同（都是 −5 V ~ +4.96 V），
     但**同一个码对应的电压相差 2^(n−1)·Δ = 5 V**
     ```
   ★ 双极性输出的实现：**在运放输入端加偏移电流**（用一个电阻接 −V_REF）
```

## 易错点提醒

1. **把 D/A 的满量程输出写成 −V_REF** → **满量程 = −V_REF·(2ⁿ−1)/2ⁿ**，因为最大数字量是 **2ⁿ−1** 而不是 2ⁿ。例如 8 位、V_REF = 10 V 时满量程是 **−9.96 V**，不是 −10 V。
2. **分辨率的分母写错** → **Δ = V_REF/2ⁿ**（1 个 LSB 的电压，分母是 **2ⁿ**）；而**相对分辨率 = 1/(2ⁿ−1)**（分母是 **2ⁿ−1**）。两个分母不同，考试要注意题目问的是哪个。
3. **以为 D/A 的分辨率与 V_REF 无关** → **绝对分辨率 Δ = V_REF/2ⁿ 与 V_REF 有关**（V_REF 越大，Δ 越大）；**相对分辨率 1/(2ⁿ−1) 只与位数 n 有关**。
4. **权重电阻网络的电阻值搞反** → **最高位（MSB）对应的电阻值最小**（电流最大），**最低位（LSB）对应的电阻值最大**。记法："**权大的电阻小**"（因为要产生大电流）。
5. **以为倒 T 形网络只用 R 和 2R 是为了省钱** → 真正的原因是**便于集成制造**（电阻种类少、阻值范围小，芯片上容易做准）。**这才是它取代权电阻网络的决定性理由。**
6. **忘记倒 T 形网络的输出是负值** → 因为用的是**反相输入的运算放大器**，输出 v_O = **−(V_REF/2ⁿ)·D**，**有负号**。
7. **以为 A/D 转换不需要取样定理** → **取样必须满足 f_s ≥ 2·f_{i(max)}**，否则产生**频谱混叠**。工程上取 3~5 倍。
8. **混淆量化误差的两种量化方式** → **只舍不入**：最大误差 **±Δ**；**四舍五入**：最大误差 **±Δ/2**。**四舍五入法的误差只有一半**，所以更常用。
9. **以为量化误差可以通过提高电路精度消除** → **量化误差是原理性误差**（用有限位表示连续量的必然结果），**只能靠增加位数 n 减小**，不能通过提高器件精度消除。
10. **并联比较型的比较器个数算错** → **n 位需要 2ⁿ − 1 个比较器**（不是 2ⁿ 个），分压电阻是 **2ⁿ** 个。记忆：**电阻比比较器多一个**。
11. **逐次逼近型的转换时间算错** → **T = n·T_CP**（n 位需要 n 个时钟周期）。注意是 **n 个**，不是 2n 个或 n+1 个。
12. **以为逐次逼近型的转换时间与输入电压有关** → **无关**！无论输入大小，都是 n 个时钟周期。（双积分型才与输入有关。）
13. **双积分型 A/D 的转换时间公式记错** → 最坏情况 **T = 2^(n+1)·T_C = T₁ + T₂max = 2ⁿT_C + 2ⁿT_C**；第一次积分时间 **T₁ = 2ⁿ·T_C**。
14. **以为双积分型 A/D 的精度取决于 R、C 的精度** → **R、C 完全不影响结果**！推导中 `V_REF·T₂ = v_I·T₁`，RC 被约掉了。**这是双积分型精度高的根本原因，也是最常考的概念题。**
15. **不知道双积分型为什么抗工频干扰** → 因为**第一次积分时间是固定的 T₁**，若取 T₁ 为**工频周期（20 ms）的整数倍**，则工频干扰在积分期间正负半周相互抵消 → 积分结果为 0。**数字电压表都用双积分型就是因为这个。**
16. **A/D 类型选错场合** → 三条准则：
    ```
    高速（视频、示波器）→ **并联比较型**
    通用（数据采集）    → **逐次逼近型** ★
    高精度抗干扰（万用表）→ **双积分型**
    ```
17. **以为 A/D 转换的位数越多越好** → 位数越多分辨率越高，但**转换时间越长**（逐次逼近和双积分）、**元件数指数增长**（并联比较）。要**在精度和速度之间权衡**。
18. **忘记 D/A 后面要接运算放大器** → D/A 转换器通常输出**电流**，需要**运算放大器转换成电压**（I-V 转换）。输出电压公式中的 R_f 就是这个反馈电阻。
19. **权电流型 D/A 的优点说不清** → 关键是**"恒流源不受开关导通电阻影响"**，所以**精度高、速度快**。倒 T 形网络的致命弱点是开关的导通电阻 r_on 会引入误差。
20. **双极性输出时编码方式混淆** → **偏移二进制码**：零点对应 100…0，MSB 是符号位（1 正 0 负）；**二进制补码**：零点对应 00…0，MSB 也是符号位但含义不同。**同一个码在两种编码下对应的电压相差 2^(n−1)·Δ。**

## 本章小结

1. **D/A 和 A/D 是数字系统与模拟世界的桥梁**：D/A 用于输出通道，A/D 用于输入通道。
2. **D/A 转换器的四个组成部分**：数字寄存器、模拟开关、电阻网络、求和运算放大器。**核心思想是按二进制权值加权求和**。
3. **★ 两种主要 D/A 结构对比**：

   | 结构 | 电阻种类 | 输出公式 | 特点 |
   |---|---|---|---|
   | **权电阻网络** | n 种（R~2ⁿ⁻¹R） | **v_O = −(V_REF/2ⁿ)·D** | 阻值范围大，难集成，少用 |
   | **倒 T 形网络** | **2 种（R、2R）** | **v_O = −(V_REF/2ⁿ)·D** | **易集成，广泛使用** ★ |
   | **权电流型** | 用恒流源 | **v_O = −(R_f·I/2ⁿ)·D** | **精度高、速度快**，用于高速高精度 |

4. **★ D/A 的两个关键指标**：
   ```
   **分辨率 Δ = V_REF/2ⁿ**（1 个 LSB 的电压）；相对分辨率 = 1/(2ⁿ−1)
   **转换速度**取决于建立时间（主要是运放的压摆率）
   ```
   **易错：满量程输出 = −V_REF·(2ⁿ−1)/2ⁿ，不是 −V_REF！**

5. **A/D 转换的四个步骤**：**取样 → 保持 → 量化 → 编码**。
   ```
   **取样定理：f_s ≥ 2·f_{i(max)}**（否则频谱混叠）
   **量化误差**：只舍不入 ±Δ；四舍五入 **±Δ/2**（更常用）
   ```
6. **★ 四种 A/D 转换器对比（必考）**：

   | 类型 | 转换时间 | 精度 | 抗干扰 | 比较器数 | 典型应用 |
   |---|---|---|---|---|---|
   | **并联比较型** | **最快**（ns） | 低（≤8 位） | 差 | **2ⁿ−1** | 视频、示波器 |
   | **逐次逼近型** | **T = n·T_CP** | 中高（8~16 位） | 中 | 1 | **通用采集** ★ |
   | **双积分型** | **T = 2^(n+1)·T_C** | **最高**（16~22 位） | **最强** | 1 | **数字电压表** |
   | **Σ-Δ 型** | 慢 | **极高** | 强 | 1 | 音频、精密测量 |

7. **★ 并联比较型的元件数**：**n 位需要 2ⁿ − 1 个比较器、2ⁿ 个分压电阻**（元件数随位数指数增长，只用于 8 位以下的高速场合）。

8. **★ 逐次逼近型**：
   ```
   规则："**大就留，小就改**"（从 MSB 开始逐位试探，类似二分搜索）
   **转换时间 T = n·T_CP**（固定，与输入大小无关）
   **最常用的 A/D 结构**（速度与精度兼顾）
   ```

9. **★ 双积分型的三大特点（核心考点）**：
   ```
   ① **输出公式 D = (v_I/V_REF)·2ⁿ**，第一次积分时间 **T₁ = 2ⁿ·T_C**（固定）
   ② **精度不受 R、C 影响**（推导中 RC 被约掉：V_REF·T₂ = v_I·T₁）
   ③ **抗工频干扰**（T₁ 取工频周期的整数倍，干扰正负半周对消）
   → 精度极高但速度最慢，用于数字电压表、万用表
   ```

10. **双极性输出的实现**：在运放输入端加**偏移电流**（偏移二进制码）。**零点对应 100…0**，输出范围 ±V_REF/2 附近。**同一码在偏移二进制码和补码下对应的电压相差 2^(n−1)·Δ。**

> **一句话记住本章**：**"D/A 就是把二进制权值用电阻网络加起来（倒 T 形只用 R 和 2R，输出 v_O = −(V_REF/2ⁿ)·D）；A/D 就是用已知量去比未知量——并联比较型用 2ⁿ−1 个比较器一次比完（最快）、逐次逼近型用 1 个比较器比 n 次（最常用、T = n·T_CP）、双积分型用积分比两次（精度最高、抗工频干扰、RC 不影响结果、T = 2^(n+1)·T_C）"。**

**11.** 比较并联比较型、逐次逼近型、双积分型三种 A/D 的转换速度和精度，各适合什么场合？

**12.** 某 12 位 D/A 转换器，V_REF = 10 V。若输入数字量为 800H（十六进制），求输出电压（按倒 T 形网络、R_f = R 计算）。

---

### 自测题答案

**1.**
```
   分辨率 Δ = V_REF/2ⁿ = 5/2¹⁰ = 5/1024 = **4.883 mV**
   
   满量程输出电压 = −(V_REF/2ⁿ)·(2ⁿ − 1) = −(5/1024) × 1023
                  = −4.9951 V ≈ **−4.995 V**
   
   （注意：**不是 −5 V**，因为最大数字量是 2¹⁰−1 = 1023）
```

**答案**：分辨率 **Δ ≈ 4.883 mV**，满量程输出电压 **−4.995 V**。

**2.** **三个原因：**
```
   ① **只用两种阻值的电阻：R 和 2R**
      而权电阻网络需要 R, 2R, 4R, …, 2ⁿ⁻¹R 共 n 种
      n = 10 时最大电阻是最小的 512 倍，集成电路中难以实现
      （芯片面积大、光刻精度难以保证、温度系数不一致）
   
   ② **阻值范围小（只有 2 倍）**，便于匹配和制造
   
   ③ **各支路电流比较均匀**（按 1/2 递减），对模拟开关的要求一致
      而权电阻网络中各支路电流相差 2ⁿ 倍，对开关要求不同
```
**结论**：**"只有 R 和 2R 两种电阻"是倒 T 形网络取代权电阻网络的决定性原因。**

**3.** **权电流型用恒流源代替电阻网络**（各位的电流为 I/2, I/4, …, I/2ⁿ）。

**优点：**
```
   ① **恒流源的输出电流与负载无关**，所以**模拟开关的导通电阻 r_on 不影响电流大小**
      → 克服了倒 T 形网络因开关导通电阻引入误差的缺点
   ② **开关只起通断作用**，不参与决定电流大小 → **精度高**
   ③ **各支路电流恒定**，切换到运放时不需重新建立电流 → **速度快**
   ④ 便于用电流源实现温度的补偿
```
**因为高速高精度 D/A 都要求"开关不引入误差"和"快速建立"，所以都采用权电流型结构。**

**4.**
**四个步骤：**
```
   ① **取样**：把连续时间的模拟量变成离散时间的样值
   ② **保持**：把样值保持一段时间，供量化和编码使用
   ③ **量化**：把样值归整到最接近的量化电平（引入量化误差）
   ④ **编码**：把量化电平用二进制代码表示
```
**取样定理：**
```
   **f_s ≥ 2·f_{i(max)}**
   
   即取样频率必须不小于输入信号最高频率分量的 2 倍。
   否则会因频谱混叠而无法恢复原信号。
   工程上一般取 f_s = (3~5)·f_{i(max)}。
   
   例：音频 20 kHz → 取样至少 40 kHz，CD 实际用 44.1 kHz
```

**5.** **量化误差是 A/D 转换中用有限位数的数字量表示连续模拟量时产生的固有误差，无法消除。**

```
   **只舍不入法**（把不足一个量化单位的电压舍去）：
     量化区间：0 ~ Δ → 0，Δ ~ 2Δ → Δ，…
     **最大量化误差 = ±Δ = ±V_REF/2ⁿ**
   
   **四舍五入法**（把样值归整到最接近的量化电平）：
     量化区间：0 ~ Δ/2 → 0，Δ/2 ~ 3Δ/2 → Δ，…
     **最大量化误差 = ±Δ/2 = ±V_REF/2^(n+1)** ★ 更常用
```
**结论**：**四舍五入法的最大误差只有只舍不入法的一半**，所以实际中都用四舍五入。

**6.**
```
   比较器个数 = 2ⁿ − 1 = 2⁸ − 1 = 256 − 1 = **255 个**
   分压电阻个数 = 2ⁿ = 2⁸ = **256 个**
```
**说明**：**8 位并联比较型需要 255 个比较器**，元件数太多，所以并联比较型只用于 **8 位以下**的高速场合（一般 4~6 位）。

（记忆：**电阻比比较器多一个**）

**7.**
```
   ① 量化单位：Δ = V_REF/2ⁿ = 5/256 = 0.01953125 V
   
   ② 输出数字量：
      D = v_I/Δ = 3 / 0.01953125 = 153.6
      四舍五入 → **D = 154**（对应二进制 1001 1010）
      
      验证：154 × 0.01953125 = 3.0078 V，量化误差 0.0078 V < Δ/2 = 0.00977 V ✓
   
   ③ 转换时间：
      T_CP = 1/f_C = 1/(1×10⁶) = 1 μs
      **T = n·T_CP = 8 × 1 μs = 8 μs**
```

**答案**：输出数字量 **154（1001 1010）**，转换时间 **8 μs**。

**8.**
```
   ① 时钟周期：T_C = 1/f_C = 1/(200×10³) = 5 μs
   
   ② 第一次积分时间（固定）：
      **T₁ = 2ⁿ·T_C = 2¹⁰ × 5 μs = 1024 × 5 μs = 5.12 ms**
   
   ③ 第二次积分时间：
      **T₂ = (v_I/V_REF)·T₁ = (1/4) × 5.12 ms = 1.28 ms**
   
   ④ 输出数字量：
      **D = (v_I/V_REF)·2ⁿ = (1/4) × 1024 = 256**
      （对应二进制 0100 0000）
      
      验证：N₂ = T₂/T_C = 1.28×10⁻³ / 5×10⁻⁶ = 256 ✓
   
   ⑤ 最坏情况转换时间（v_I = V_REF 时）：
      **T = 2^(n+1)·T_C = 2¹¹ × 5 μs = 2048 × 5 μs = 10.24 ms**
      
      本题实际转换时间：T = T₁ + T₂ = 5.12 + 1.28 = 6.4 ms
```

**答案**：**T₁ = 5.12 ms**，**T₂ = 1.28 ms**，输出数字量 **D = 256**，最坏情况转换时间 **T = 10.24 ms**。

**9.** **因为 R、C 在推导过程中被约掉了。**

```
   推导：
   ① 第一次积分（时间 T₁，对 v_I 积分）：
      v_O1 = −(1/RC)·∫₀^{T₁} v_I dt = −(v_I·T₁)/(RC)
   
   ② 第二次积分（时间 T₂，对 −V_REF 积分）：
      v_O2 = v_O1 + (1/RC)·∫₀^{T₂} V_REF dt = −(v_I·T₁)/(RC) + (V_REF·T₂)/(RC)
   
   ③ 积分结束时 v_O2 = 0：
      −(v_I·T₁)/(RC) + (V_REF·T₂)/(RC) = 0
      → (V_REF·T₂)/(RC) = (v_I·T₁)/(RC)
      → **V_REF·T₂ = v_I·T₁**    ← **RC 被约掉了！**
      → **T₂ = (v_I/V_REF)·T₁**
   
   → 转换结果只与 v_I、V_REF、T₁ 有关，**与 R、C 的具体数值无关**
```

**意义**：**R、C 的精度、温度漂移、老化都不影响转换精度**。这是双积分型 A/D 能达到很高精度（16~22 位）的根本原因。**只要 V_REF 准确、时钟频率稳定，转换精度就有保证。**

**10.** **因为第一次积分时间是固定的 T₁，且可以取为工频周期的整数倍。**

```
   原理：
   设输入信号为 v_I + v_noise，其中 v_noise 是 50 Hz 工频干扰
   第一次积分的结果：
   v_O1 = −(1/RC)·∫₀^{T₁} (v_I + v_noise) dt
       = −(v_I·T₁)/(RC) − (1/RC)·∫₀^{T₁} v_noise dt
   
   如果 T₁ 正好是工频周期的整数倍（如 T₁ = 20 ms = 1 个工频周期）：
   则 ∫₀^{T₁} v_noise dt = 0    ← **正弦波在整周期内的积分为 0**
   → 干扰项被完全抵消 ✓
   ```
   
   实际产品中：
   - 取 **T₁ = 20 ms**（50 Hz 的一个周期）→ 抑制 50 Hz 干扰
   - 或取 T₁ = 100 ms（5 个周期）→ 同时抑制 50 Hz 及其谐波
   ```
   
   **对比**：逐次逼近型是"瞬时比较"，工频干扰会直接影响比较结果；
   双积分型是"积分平均"，干扰在积分中被对消。
   → **这是双积分型 A/D 抗干扰能力最强的根本原因。**
```

**11.**

| 类型 | 转换速度 | 精度 | 抗干扰 | 适用场合 |
|---|---|---|---|---|
| **并联比较型** | **最快**（ns~μs 级） | 低（≤8 位） | 差 | **超高速**：示波器、数字视频、雷达 |
| **逐次逼近型** | **较快**（μs~百 μs） | 中高（8~16 位） | 中 | **通用**：数据采集、单片机 ADC、测量 |
| **双积分型** | **最慢**（ms~百 ms） | **最高**（16~22 位） | **最强** | **高精度**：数字电压表、万用表 |

**速度排序**：**并联比较型 > 逐次逼近型 > 双积分型**
**精度排序**：**双积分型 > 逐次逼近型 > 并联比较型**

**转换时间公式（n 位、时钟周期 T_C）**：
```
   并联比较型：**T ≈ 几十 ns**（一次比较时间，与 n 无关）
   逐次逼近型：**T = n·T_CP**（与输入无关）
   双积分型：  **T = 2^(n+1)·T_C**（最坏情况；与 T_C 和 n 有关）
```

**12.**
```
   800H = 1000 0000 0000₂ = 2048（十进制）
   n = 12，2^n = 4096
   Δ = V_REF/2ⁿ = 10/4096 = 0.00244140625 V
   
   v_O = −(V_REF/2ⁿ)·D = −(10/4096) × 2048
       = −0.00244140625 × 2048
       = **−5 V**
```
**答案**：输出电压 **v_O = −5 V**。

**说明**：**800H 正好是 12 位数字量的"半量程"（最高位为 1、其余为 0）**，所以输出正好是满量程的一半：
```
   满量程 = −(V_REF/2ⁿ)·(2ⁿ−1) = −(10/4096)×4095 = −9.998 V
   半量程 = −(10/4096)×2048 = −5 V ✓
```

**验算方法（快速）**：
```
   12 位数字量中最高位的权值是 2¹¹ = 2048
   800H 表示 2048，是整个范围的 2048/4096 = 1/2
   → 输出 = −(1/2)×V_REF = −5 V ✓
```
