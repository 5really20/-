> 湖北大学 计算机科学与技术专业｜课程编码 373H01｜3.5 学分 / 64 学时（48 讲授 + 16 实验）｜第 3 学期｜专业核心必修

## 一、这门课在专业里是什么位置

**数字逻辑是计算机专业的「硬件第一课」，它把「0 和 1」变成「能算的机器」。**

一句话定位：**这门课教你用逻辑门搭出加法器、寄存器和计数器，是《计算机组成原理》的直接地基。**

- **往上看（先修）**：先修《电路理论基础》（373H03，3.5 学分/64 学时，第 2 学期）。本课程只需要「电压、电流、开关」的程度，不考复杂电路计算。
- **往下看（后续）**：《计算机组成原理》（本专业核心课程）里的一切硬件模块，本课程都已讲过：
  - CPU 的 **ALU** ← 第 4 章加法器 + 数值比较器
  - **寄存器堆 / PC / IR** ← 第 5 章触发器 + 寄存器
  - **存储器层次** ← 第 5 章 SRAM/DRAM/ROM/Flash
  - **控制器 / 时序** ← 第 6 章状态转换图 + 状态机
  - **总线** ← 第 3 章三态门与接口
- **横向交叉**：《模拟电路》讲连续信号（放大、滤波），本课程讲离散信号（0/1）；两门课在第 8 章 A/D、D/A 转换器处握手。

> **重点**：这门课不是「背多分」课程。它的特点是**规则少、题型固定、练了就得分**。全书核心只有三件事：**化简**（第 2 章）、**分析**（第 4、6 章）、**设计**（第 4、6 章）。

## 五、考试重点分布

按分值从高到低排（各校略有浮动，但比例稳定）：

| 章节 | 大致占分 | 常见题型 |
|---|---|---|

| 第 4 章 组合逻辑电路 | **20%~25%** | 分析题、设计题、用 74HC138/74HC151 实现逻辑函数、竞争-冒险判断 |

| 第 5 章 触发器 | **10%~15%** | 特性方程、波形图绘制（给 CP 和输入画输出）、触发器功能转换、空翻现象 |
| 第 7 章 555 | **6%~10%** | 三种模式的公式计算（tw、T、f、占空比）、画波形 |
| 第 8 章 A/D、D/A | **6%~10%** | 分辨率/精度/转换时间计算、R-2R 网络输出电压、逐次逼近过程 |
| 第 5 章 存储器 | **5%~8%** | 容量扩展（片数、连线）、用存储器实现逻辑函数 |
| 第 1、3 章 | **各 3%~5%** | 数制与补码转换；门电路参数与接口（以小分值题为主） |
| 附录 C PLD/FPGA | **0%~5%** | 概念题；部分班级不考 |

### 四大必考题型（套路见[附录 B](附录B-易错点与题型总结.md)）

1. **化简题**：公式法 + 卡诺图法，含无关项、多输出函数。
2. **分析题**：组合电路给图求功能；时序电路给图求状态图与功能。
3. **设计题**：给功能要求 → 设计组合/时序电路；或用 MSI 器件（译码器、数据选择器）实现。
4. **计数题**：任意进制计数器（置零法 / 置数法），含 N 进制、起止状态、模值计算。

> **重点**：把这四类题各练 10 道，及格线以上稳拿。计算类章节（555、A/D、存储器扩展）是「看一眼就会、不看就忘」的题，考前一周务必过一遍公式。

```
                    ├─→ 第2章 逻辑代数基础（化简）──→ 第4章 组合逻辑 ──┐
第3章 门电路 ───────┘            ↑                                  │
                                 │                                  ▼
                     第5章(一) 锁存器与触发器 ──→ 第6章 时序逻辑 ──→ 综合设计
                                                                    ▲
                     第5章(二) 存储器 ──→ 附录C PLD/FPGA ───────────┘

```

- **第 1、2 章是工具**，必须一次学透，后面每道题都要用。
- **第 3 章可以「跳读」**：只记结论（三态门、OC/OD 门、参数含义），内部结构看懂框图即可。计科专业考试以逻辑功能为主。
- **第 4、6 章是主干**，占分一半以上，要反复练。
- **第 5 章（一）是第 6 章的前提**，触发器不熟，时序电路一定看不懂。
- **第 5 章（二）、附录 C、第 7、8 章相对独立**，可以放在最后集中突击。

## 七、符号约定（全书统一）

| 符号 | 含义 | 本笔记写法 |
|---|---|---|
| 与 | 逻辑乘 | `Y = A·B` 或 `Y = AB` |
| 或 | 逻辑加 | `Y = A + B` |
| 非 | 逻辑反 | `Y = A'`（也写作 `A̅`，本笔记统一用 `A'`） |
| 与非 / 或非 | — | `Y = (AB)'`、`Y = (A+B)'` |
| 异或 / 同或 | — | `Y = A ⊕ B`、`Y = A ⊙ B` |
| 最小项 | n 变量最小项 | `m_i`（下标 i 是使该最小项为 1 的十进制值） |
| 最大项 | n 变量最大项 | `M_i`（下标 i 是使该最大项为 0 的十进制值） |
| 任意项 / 约束项 | 无关项 | `Σd(...)` 或 `Σm(...) + Σd(...)` |
| 上升沿 / 下降沿 | 边沿触发 | `↑` / `↓`，或写 `CP↑`、`CP↓` |
| 有效电平 | 低有效上加横线 | 本笔记写 `CS'`（低有效）、`CS`（高有效） |

4. **逻辑验证可以自己写程序跑。** 「用最少的门实现某函数」这类题，用 Python 穷举所有接线方式比空想可靠得多——穷举几十万种组合对计算机只是一瞬间的事。
