## 7.1 概述

**矩形脉冲（Rectangular Pulse）：数字电路中最基本的信号形式。**

**四个参数：**
```
              t_w（脉冲宽度）
        ├──────────────────┤
        │                  │
   ┌────┘                  └────┐
   │                            │
───┘                            └───
   ▲                            ▲
   │◄─────── T（周期）──────────►│
   │         t_r        t_f
   │      （上升沿）（下降沿）
```

| 参数 | 符号 | 含义 |
|---|---|---|
| **周期** | T | 一个完整波形的时间 |
| **频率** | f = 1/T | 单位时间内的脉冲个数 |
| **脉冲宽度** | t_w | 脉冲持续为高的时间 |
| **上升时间** | t_r | 从 0.1V_m 升到 0.9V_m 的时间 |
| **下降时间** | t_f | 从 0.9V_m 降到 0.1V_m 的时间 |
| **占空比** | q = t_w / T | 高电平占整个周期的比例 |

**获得矩形脉冲的两种途径：**
```
   ① **产生**：用多谐振荡电路**直接产生**矩形波（不需要输入信号）
   ② **整形**：用施密特触发电路 / 单稳态电路**把不理想的波形变换成规则矩形波**
```

**三种电路的对比（★★★ 核心）：**

| 电路 | 稳态数 | 有无输入 | 输出特点 | 主要用途 |
|---|---|---|---|---|
| **施密特触发电路** | **2 个稳态** | **有输入** | 输出跟随输入，但有**回差** | **整形、变换、幅度鉴别** |
| **单稳态电路** | **1 个稳态 + 1 个暂稳态** | **有触发输入** | 每触发一次输出**一个固定宽度**的脉冲 | **定时、延时、脉冲展宽** |
| **多谐振荡电路** | **0 个稳态**（无稳态） | **无输入** | **自激振荡**，输出连续矩形波 | **产生时钟信号** |

> **记忆法**：
  ```
    施密特 = **两个**稳态（像一个有"记忆"的比较器，靠回差避免抖动）
    单稳态 = **一个**稳态（触发后暂时离开，自动回来）
    多谐   = **零个**稳态（"多谐"指含丰富谐波，因为它是方波）
  ```

## 7.2 施密特触发电路

### 7.2.1 结构和工作原理

**施密特触发电路（Schmitt Trigger）：具有回差特性的双稳态电路。**

**核心特征：输出电压的翻转依赖于输入电压，但**上升过程和下降过程的翻转阈值不同**——这叫回差（Hysteresis）。**

**电压传输特性（★ 必须会画）：**
```
   V_O
    ▲
 V_OH┤    ┌───────────────────┐
    │    │                   │
    │    │                   │
    │────┘                   │
    │                        │
 V_OL    ┌───────────────────┘
    │    │
    │    │
    └────┴────┬─────────┬──────► V_I
             V_T−      V_T+
             (下限)    (上限)
          ◄── ΔV_T ──►
            回差电压

   输入上升时：V_I 升到 V_T+ 才翻转为低
   输入下降时：V_I 降到 V_T− 才翻转为高
```

**三个关键参数：**
```
   **上限触发电平 V_T+**：输入上升时使输出翻转的电平
   **下限触发电平 V_T−**：输入下降时使输出翻转的电平
   **回差电压 ΔV_T = V_T+ − V_T−**
```

> **重点：回差的作用**
  ```
    若没有回差（V_T+ = V_T−），当输入信号上叠加了噪声时：
      输入在阈值附近微小波动 → 输出**反复翻转**（抖动）
    有了回差之后：
      只要噪声幅度 < ΔV_T，输入在阈值附近波动时输出**保持稳定**
    → **回差是抗干扰的关键**
  ```
> **代价**：回差使触发器的**灵敏度降低**（需要更大的输入变化才能翻转）。**回差越大抗干扰越强，但鉴别精度越低。**

**施密特触发电路的逻辑符号：**
```
        ┌───────┐
   V_I ─┤       ├─ V_O
        │  ▷    │
        │（回差）│
        └───────┘
   符号中的「▷」或迟滞符号表示有回差特性
```

### 7.2.2 用门电路组成的施密特触发电路

**用两个 CMOS 反相器 + 分压电阻构成：**

```
              R₁
        ┌───[===]───┐
        │           │
   V_I ─┼───┤ o─────┼──┬──── V_O
        │   (G₁)    │  │
        │           │  │
        │      R₂   │  │
        └───[===]───┘  │
            │          │
           GND         └─── 输出
```

**工作原理：**
```
   ① V_I = 0（低电平）：
      G₁ 输出高 → G₂ 输出低 → V_O = 0（设经过两级反相后 V_O ≈ 0）
      反馈电阻 **R₁** 把 V_O 反馈到 G₁ 的输入（**R₁ = 反馈电阻（V_O → A）、R₂ = 输入电阻（V_I → A）**）

   ② V_I 上升：由于反馈作用，G₁ 的输入电压 V_A = (V_I·R₂ + V_O·R₁)/(R₁+R₂)
      此时 V_O = 0，故 V_A = V_I·R₂/(R₁+R₂)
      当 V_A 达到 G₁ 的阈值 V_th 时，G₁ 翻转
      → 此时对应的 V_I 就是**上限触发电平 V_T+**
      **V_T+ = V_th·(R₁ + R₂)/R₂ = V_th·(1 + R₁/R₂)**

   ③ V_I 下降：此时 V_O = V_DD，故 V_A = V_I·R₂/(R₁+R₂) + V_DD·R₁/(R₁+R₂)
      同样在 V_A = V_th 时翻转，解出**下限触发电平**
      **V_T− = V_th·(R₁ + R₂)/R₂ − V_DD·R₁/R₂ = V_th·(1 + R₁/R₂) − V_DD·R₁/R₂**

   ④ 回差电压（两式相减，V_th 项抵消）
      **ΔV_T = V_T+ − V_T− = V_DD·R₁/R₂**
```

**关键结论：**
```
   **调节 R₁ 和 R₂ 的比值可以改变回差电压 ΔV_T**
   R₁/R₂ 越大 → 回差越大
```

> **注意**：不同教材对具体公式的推导细节有差异，**考试中通常直接给出 V_T+、V_T− 的公式，要求计算 ΔV_T 或判断电路能否正常工作**。核心要抓住：**ΔV_T 由 R₁、R₂ 的比值决定**。

**用 TTL 门电路构成的施密特触发电路：**
```
   与 CMOS 类似，但需要二极管电平偏移（因为 TTL 的阈值在 1.4V 附近）
   实际工程中直接用**集成施密特触发器**（如 74HC14 六反相器、74HC132 四与非门）
```

**集成施密特触发器：**

| 型号 | 功能 | 特点 |
|---|---|---|
| **74HC14** | 六反相器（施密特输入） | 最常用 |
| **74HC132** | 四 2 输入与非门（施密特输入） | 带逻辑功能 |
| **74HC13** | **双 4 输入**与非门（施密特输入） | 输入数多，适合多输入场合 |
| **74HC18** | 六反相器 | 老型号 |

### 7.2.3 施密特触发电路的应用

**① 波形变换（把正弦波、三角波变成矩形波）**
```
   V_I (正弦波)          V_O (矩形波)
      ╱╲                  ┌────┐    ┌────┐
     ╱  ╲                 │    │    │    │
    ╱    ╲        ────────┘    └────┘    └────
   ╱      ╲
   ─────────
   → 只要输入幅度超过 V_T+ 和 V_T−，输出就是规则的矩形波 ✓
```

**② 脉冲整形（把边沿差的波形变成陡直的矩形波）**
```
   输入（有噪声、边沿缓慢）：
   ╱‾‾‾╲__╱‾‾╲___╱‾‾‾‾╲__
   → 输出（干净的矩形波）：
   ┌───┐  ┌──┐   ┌────┐
   ┘   └──┘  └───┘    └──
   → 回差滤掉了噪声引起的抖动 ✓
```

**③ 幅度鉴别（从一串幅度不同的脉冲中选出幅度足够大的）**
```
   输入（幅度不等的脉冲）：
     ┌─┐   ┌───┐  ┌─┐   ┌─────┐
   ──┘ └───┘   └──┘ └───┘     └──
    小     大     小     大
   → 输出（只有幅度超过 V_T+ 的脉冲才能通过）：
   ────────┐     ┌─────────────┐
           └─────┘             └──
   → 实现了"幅度鉴别" ✓
```

**④ 构成多谐振荡电路**（见 7.4.4）

**⑤ 消除机械开关的抖动**
```
   机械开关闭合瞬间会产生多次通断（抖动，持续几 ms）
   → 用施密特触发器可以把它整形成一个干净的跳变 ✓
```

> **重点**：**施密特触发器的三个典型应用必须记住：波形变换、脉冲整形、幅度鉴别。**

## 7.3 单稳态电路

### 7.3.1 用门电路组成的单稳态电路

**单稳态电路（Monostable Circuit）：只有一个稳态，被触发后进入暂稳态，经过一段时间后自动返回稳态。**

**核心特征：输出脉冲宽度 t_w 只由电路的 R、C 参数决定，与触发脉冲的宽度无关。**

**用与非门 + RC 微分电路构成（微分型单稳态）：**

```
        ┌─────┐        ┌─────┐
   V_I ─┤ &   │        │ &   │
        │     ├───┬────┤     ├─── V_O
   V_A ─┤     │   │    │     │
        └─────┘   │    └──┬──┘
                  │       │
              ┌───┴───┐   │
              │   C   │   │
              └───┬───┘   │
                  │       │
              ┌───┴───┐   │
              │   R   │   │
              └───┬───┘   │
                  │       │
                 GND      └────（反馈）
```

**工作原理（三步）：**
```
   ① **稳态**：V_I = 0（无触发），门 1 输出高，电容 C 充电到稳态，门 2 输出低（V_O = 0）
      → **稳态是 V_O = 0**

   ② **触发进入暂稳态**：V_I 出现正脉冲 → 门 1 输出变低 → 电容 C 通过 R 开始充电
      → 门 2 的输入暂时为低 → 门 2 输出变高（V_O = 1）
      → **输出跳变为高，进入暂稳态**

   ③ **自动返回稳态**：电容 C 充电，门 2 输入电压逐渐升高
      当达到门 2 的阈值 V_th 时，门 2 输出翻转回低（V_O = 0）
      → **自动返回稳态**，同时通过反馈加速这一过程

   输出脉冲宽度由 RC 充电时间决定：
   **t_w = R·C·ln(V_∞ − V_0)/(V_∞ − V_th)**
   对于 CMOS 门（V_th = V_DD/2，V_∞ = V_DD，V_0 = 0）：
   **t_w = RC·ln2 ≈ 0.7RC**
```

**主要特点：**
```
   ① 输出脉宽由 R、C 决定，与触发信号无关
   ② 每触发一次输出一个脉冲（若触发信号持续，不会连续输出——需要"再触发"功能才行）
   ③ 有"死区时间"（恢复时间）：暂稳态结束后电容需要时间恢复到稳态才能再次触发
```

### 7.3.2 集成单稳态电路

**常用集成单稳态触发器：**

| 型号 | 功能 | 特点 |
|---|---|---|
| **74121** | 单路**不可**重复触发单稳态 | 经典器件，带内部定时电阻 R_int |
| **74122** | 单路**可**重复触发单稳态 | 触发期间再触发会延长脉宽 |
| **74123** | 双路**可**重复触发单稳态 | 最常用 |
| **74221** | 双路**不可**重复触发单稳态 | — |
| **74HC123** | 双路**可**重复触发单稳态（CMOS 版） | 与 74123 引脚兼容 |
| **74HC221** | 双路**不可**重复触发单稳态（CMOS 版） | 带复位端 |
| **74HC4538** | 双路精密**可**重复触发单稳态 | 脉宽精度高 |

> **型号记忆法**：**末位是 1 → 不可重复触发（74121、74HC221）；末位是 2 或 3 → 可重复触发（74122、74123、74223）**。最常用的是 **74123 / 74HC123（双路可重复触发）** 和 **74121（单路不可重复触发）**。

**74HC123 的引脚与功能：**
```

   触发输入：A'（下降沿有效）、B（上升沿有效）
   复位输入：R_D'（低有效，立即结束输出脉冲）
   定时端：   C_ext（外接电容）、R_ext/C_ext（外接电阻）
   输出：     Q（正脉冲）、Q'（负脉冲）

   输出脉宽：**t_w ≈ 0.7·R_ext·C_ext**（R_ext ≥ 5 kΩ，C_ext ≥ 10 pF）
```

**可再触发（Retriggerable）与不可再触发（Non-retriggerable）的区别：**
```
   **可再触发**（74HC123）：
     在输出脉冲期间再给一个触发脉冲 → 输出脉冲**重新开始计时**（被延长）
     ┌────┐
     │    │
   ──┘    └──────────────
        ↑触发    ↑再触发
        ┌────────┐
        │        │
   ─────┘        └────────
        ← 脉宽被延长 →

   **不可再触发**（74121、74HC221）：
     在输出脉冲期间再触发 → **无效**，输出脉冲宽度不变
```

**单稳态电路的应用：**
```
   ① **定时**：产生固定宽度的控制脉冲
   ② **延时**：把输入脉冲延迟一个固定时间输出
   ③ **脉冲展宽**：把窄脉冲变成宽脉冲（如把 1 μs 变成 1 ms）
   ④ **脉冲整形**：把不规则波形整形成规则脉冲
   ⑤ **消除抖动**：机械开关的抖动只触发一次
   ⑥ **频率分频**：把频率高的脉冲变成频率低的
```

## 7.4 多谐振荡电路

### 7.4.1 对称式多谐振荡电路

**多谐振荡电路（Astable Multivibrator）：没有稳态，两个状态都是暂稳态，电路自动在两个暂稳态之间反复翻转。**

**为什么叫"多谐"？** 因为输出是方波，**含有丰富的高次谐波**。

**用两个 CMOS 反相器 + 耦合电容构成（对称式）：**

```
        ┌───────┐        ┌───────┐
        │       ├───┬────┤       ├─── V_O1
   ┌────┤  G₁   │   │    │  G₂   │
   │    └───────┘   │    └───┬───┘
   │                │        │
   │            ┌───┴───┐    │
   │            │   C₁  │    │
   │            └───┬───┘    │
   │                │        │
   │            ┌───┴───┐    │
   └────────────┤  R₁   ├────┘
                └───────┘
   （另一侧对称，R₂、C₂）
```

**工作原理：**
```
   ① 两个反相器通过电容耦合形成正反馈
   ② 电容充放电使反相器的输入电压在两个阈值之间来回变化
   ③ 电路在 G₁ 输出高 / G₂ 输出低 与 G₁ 输出低 / G₂ 输出高 之间反复翻转
   ④ 振荡周期：**T ≈ 2·R·C·ln2 ≈ 1.4RC**（对称式）
```

### 7.4.2 非对称式多谐振荡电路

**用一个反相器 + 一个 RC 支路 + 一个电阻构成：**

```
        ┌───────┐
   ┌────┤  G₁   ├─── V_O
   │    └───────┘
   │        ▲
   │        │
   │    ┌───┴───┐
   │    │   R_F │（反馈电阻，使 G₁ 工作在放大区）
   │    └───┬───┘
   │        │
   │    ┌───┴───┐
   └────┤   C   │
        └───┬───┘
            │
        ┌───┴───┐
        │   R_S │
        └───┬───┘
            │
           V_O （输出经 R_S 反馈）
```

**特点**：`R_F` 使反相器工作在**电压传输特性的转折区**（放大区），从而具有放大能力并形成正反馈。振荡周期同样由 RC 决定。

### 7.4.3 环形振荡电路

**用奇数个（≥3）反相器首尾相接构成环形。**

```
   ┌───────────────────────────────────────┐
   │                                       │
   │   ┌────┐    ┌────┐    ┌────┐         │
   └──►│ G₁ ├───►│ G₂ ├───►│ G₃ ├────┬────┘
       └────┘    └────┘    └────┘    │
                                    V_O（输出）
   （3 个反相器，形成正反馈环路）
```

**为什么必须用奇数个反相器？**
```
   设 G₁ 输入为 0：
     G₁ 输出 = 1 → G₂ 输出 = 0 → G₃ 输出 = 1
     反馈到 G₁ 输入 = 1 ≠ 原来的 0 → **状态不能稳定** → 继续翻转
   
   设 G₁ 输入为 1：
     同理得到反馈 = 0 ≠ 1 → 继续翻转
   
   → **奇数个反相器形成的环路没有稳定状态**，必然振荡 ✓
   
   若用偶数个：反馈回来的值与原来相同 → 稳定，不振荡 ✗
```

**振荡周期：**
```
   **T = 2·n·t_pd**
   其中 n = 反相器个数（奇数），t_pd = 每个门的平均传输延迟

   例：3 个反相器，每个 t_pd = 10 ns
       T = 2 × 3 × 10 ns = 60 ns
       f = 1/60 ns ≈ 16.7 MHz
```

**特点：**
```
   ① 结构最简单（只需 3 个反相器）
   ② **频率稳定性差**（受温度、电源电压、器件离散性影响大）
   ③ 频率较高时用（几 MHz 到几十 MHz）
   ④ **改进**：在环路中串入 RC 延时环节可以降低频率并提高稳定性
```

### 7.4.4 用施密特触发电路构成的多谐振荡电路

**用施密特反相器 + RC 反馈构成，是最简单可靠的多谐振荡电路之一。**

```
        ┌───────────┐
   ┌────┤  施密特    ├─── V_O
   │    │  反相器    │
   │    └───────────┘
   │          │
   │      ┌───┴───┐
   │      │   R   │
   │      └───┬───┘
   │          │
   └──────────┤   C
              │
             GND
```

**工作原理：**
```
   ① 设 V_O = V_OH（高），电容 C 通过 R 充电，V_C 上升
   ② V_C 升到 **V_T+** 时，施密特反相器翻转，V_O 变为 V_OL（低）
   ③ 电容 C 通过 R 放电，V_C 下降
   ④ V_C 降到 **V_T−** 时，施密特反相器翻转，V_O 变回 V_OH（高）
   ⑤ 回到 ①，**周而复始**

       V_O ──┐       ┌───────┐       ┌───
             └───────┘       └───────┘
       V_C ╱╲    ╱╲    ╱╲    ╱╲
          ╱  ╲  ╱  ╲  ╱  ╲  ╱  ╲
         ╱    ╲╱    ╲╱    ╲╱    ╲
       （在 V_T+ 和 V_T− 之间充放电）
```

**振荡周期：**
```
   **T = RC·ln[(V_DD − V_T−)/(V_DD − V_T+)] + RC·ln(V_T+/V_T−)**
   简化形式（当 V_T− = V_T+/2 时）：**两项都等于 RC·ln2**
     第 1 项（充电段）：代入 V_T+ = 2V_DD/3、V_T− = V_DD/3
        ln[(V_DD − V_DD/3)/(V_DD − 2V_DD/3)] = ln[(2/3)/(1/3)] = ln2
     第 2 项（放电段）：ln(V_T+/V_T−) = ln[(2V_DD/3)/(V_DD/3)] = ln2
   **T = 2RC·ln2 ≈ 1.4RC**
```
> **易错**：只算一项就会漏掉**一半周期**，写成 `T ≈ 0.7RC` —— 那是**半个周期**，不是周期。
> **注意**：具体公式与施密特触发器的 V_T+、V_T− 有关，**考试中若给出 V_T+ 和 V_T−，就代入精确公式**。

**特点**：**结构极简（一个施密特反相器 + 一个 RC）**，频率稳定度比环形振荡器好（因为振荡阈值由施密特特性决定，不受电源电压微小波动影响）。

### 7.4.5 石英晶体多谐振荡电路

**石英晶体（Quartz Crystal）：利用压电效应，在特定频率上具有极高的 Q 值（品质因数）。**

**石英晶体的阻抗特性：**
```
   |Z|
    ▲
    │╲                      ╱
    │ ╲                    ╱
    │  ╲                  ╱
    │   ╲                ╱
    │    ╲              ╱
    │     ╲            ╱
    │      ╲          ╱
    │       ╲________╱
    │            │
    └────────────┴──────────► f
                f_s
        （串联谐振频率：此处阻抗最小，曲线是一个"低谷"）
   → 只有在 f_s 附近晶体才呈现极低阻抗，其他频率阻抗极高
   → 电路只能在 f_s 处振荡
```

**电路结构：**
```
        ┌───────┐
   ┌────┤  G₁   ├───┬─── V_O
   │    └───────┘   │
   │                │
   │    ┌───────┐   │
   └────┤ 晶体   ├───┘
        └───────┘
   （或用 CMOS 反相器 + 石英晶体 + 两个小电容）
```

**为什么频率稳定度极高？**
```
   ① 石英晶体的 **Q 值极高**（可达 10⁴~10⁶，LC 回路只有几百）
   ② 晶体的谐振频率由**晶片的几何尺寸和切割方式**决定，**几乎不受温度、电源电压影响**
   ③ 电路的振荡频率**被晶体"锁定"**在 f_s 上
   → **频率稳定度可达 10⁻⁶ ~ 10⁻¹¹**（远高于 RC 振荡器的 10⁻² ~ 10⁻³）
```

**应用：**
```
   ① 计算机的时钟发生器（配合 PLL 倍频）
   ② 电子表（32.768 kHz 晶体，因为 2¹⁵ = 32768，便于分频得到 1 Hz）
   ③ 通信设备的基准频率源
```

**四种多谐振荡电路对比：**

| 电路类型 | 频率范围 | 稳定度 | 结构复杂度 | 典型用途 |
|---|---|---|---|---|
| **对称式（门电路+RC）** | 几 Hz ~ 几 MHz | 差（10⁻²） | 中 | 一般时钟 |
| **非对称式** | 几 Hz ~ 几 MHz | 差 | 简单 | 一般时钟 |
| **环形振荡器** | 几十 MHz ~ 几百 MHz | 差 | **最简单** | 高频时钟 |
| **施密特+RC** | 几 Hz ~ 几 MHz | 中 | 简单 | 通用 |
| **石英晶体** | 几十 kHz ~ 几百 MHz | **极高（10⁻⁶~10⁻¹¹）** | 中 | **精密时钟** |

## 7.5 555 定时器及其应用（★★★ 核心）

### 7.5.1 555 定时器的电路结构与功能

**555 定时器：一种模拟-数字混合的中规模集成电路，只需外接少量 R、C 就能构成施密特、单稳态、多谐振荡三种电路。**

**内部结构（★ 必须会画）：**
```
                          V_CC
                            │
                          ┌─┴─┐
                          │5kΩ│  ← 三个 5kΩ 电阻串联分压
                          ├───┤     所以叫"555"
                          │   │
                     ┌────┤   ├──── V_CC·(2/3) = 6 脚（TH 阈值输入）
                     │    │5kΩ│
              ┌──────┘    ├───┤
              │           │   │
              │      ┌────┤   ├──── V_CC·(1/3) = 2 脚（TR' 触发输入）
              │      │    │5kΩ│
              │      │    ├───┤
              │      │    │   │
              │      │    └─┬─┘
              │      │      │
              │      │     GND
              │      │
              │      │   ┌──────────┐
              │      └──►│ 比较器 C₁ │──┐
              │          │ (上)     │  │
        6 脚──┼─────────►│ +        │  │  ┌───────────┐
        (TH)  │          └──────────┘  ├─►│           │
              │                        │  │  SR 锁存器 │──┬──► 输出缓冲 ──► 3 脚（V_O）
              │          ┌──────────┐  │  │           │  │
        2 脚──┼─────────►│ 比较器 C₂ │──┘  │           │  │
        (TR')│          │ (下)      │     └─────┬─────┘  │
              │      ┌──►│ +        │           │        │
              │      │   └──────────┘           │        │
              │      │                          │        │
              │   ┌──┴──┐                    ┌──┴──┐     │
        4 脚──┼──►│ R_D' │（复位，低有效）      │  T  │     │
        (R_D')│   └─────┘                    │ 放电管│    │
              │                              └──┬──┘     │
              │                                 │        │
        7 脚──┼─────────────────────────────────┘        │
        (DIS) │   （放电端）                              │
              │                                           │
              └───────────────────────────────────────────┘
                    5 脚（CO）：控制电压端，可外接电压改变阈值
```

**引脚功能表（★ 必背）：**

| 引脚 | 名称 | 功能 |
|---|---|---|
| **1** | **GND** | 接地（电源负极） |
| **2** | **TR'（Trigger）** | **触发输入**，低有效。低于 V_CC/3 时使输出为高 |
| **3** | **V_O（Output）** | **输出端** |
| **4** | **R_D'（Reset）** | **复位端，低有效**。为低时输出强制为低（优先级最高） |
| **5** | **CO（Control Voltage）** | **控制电压端**。可外接电压改变比较器阈值（不用时接 0.01 μF 到地） |
| **6** | **TH（Threshold）** | **阈值输入**。高于 2V_CC/3 时使输出为低 |
| **7** | **DIS（Discharge）** | **放电端**。内部放电管（三极管）的集电极，用于外接定时电容放电 |
| **8** | **V_CC** | 电源正极（**4.5 V ~ 16 V**，典型 5 V） |

**内部三个 5kΩ 电阻的作用：**
```
   分压得到两个基准电压：
     **2V_CC/3** → 比较器 C₁ 的"−"端（6 脚 TH 比较用）
     **V_CC/3**   → 比较器 C₂ 的"+"端（2 脚 TR' 比较用）
```

**工作原理（功能表）：**

| **R_D'（4 脚）** | **TH（6 脚）** | **TR'（2 脚）** | **输出 V_O（3 脚）** | **放电管 T** |
|---|---|---|---|---|
| **0** | × | × | **0**（强制复位） | **导通** |
| 1 | **> 2V_CC/3** | × | **0** | **导通** |
| 1 | **< 2V_CC/3** | **< V_CC/3** | **1** | **截止** |
| 1 | < 2V_CC/3 | > V_CC/3 | **保持** | 保持 |

**读表要点：**
```
   ① **R_D' = 0 时无条件复位**（优先级最高）
   ② **TH 高于 2V_CC/3 → 输出为低、放电管导通**（"高阈值触发复位"）
   ③ **TR' 低于 V_CC/3 → 输出为高、放电管截止**（"低触发置位"）
   ④ 两个条件都不满足时**保持**
```

> **记忆口诀**：**「高电位（TH）复位，低电位（TR'）置位，复位端最高优先」。**
  ```
    TH (6脚) > 2/3 V_CC  → 输出 0（放电管导通，电容放电）
    TR'(2脚) < 1/3 V_CC  → 输出 1（放电管截止，电容充电）
  ```

**555 的等效逻辑图（简化记忆版）：**
```
        V_CC
          │
        ┌─┴─┐
        │ R │
        ├───┼──── 2V_CC/3 ──► C₁(−)
        │ R │
        ├───┼──── V_CC/3   ──► C₂(+)
        │ R │
        └─┬─┘
         GND

   6脚 TH ──► C₁(+)，C₁ 输出接 SR 锁存器的 R 端
   2脚 TR'──► C₂(−)，C₂ 输出接 SR 锁存器的 S 端
   4脚 R_D'──► 直接复位 SR 锁存器
   SR 锁存器 Q ──► 输出缓冲 ──► 3脚
   SR 锁存器 Q'──► 放电管 T 的基极 ──► 7脚
```

### 7.5.2 用 555 定时器接成的施密特触发电路

**接线：把 2 脚和 6 脚接在一起作为输入端，7 脚悬空（或接一个上拉电阻）。**

```
                ┌──────────┐
                │          │
     V_I ───────┤2 (TR')   │
                │          │
     V_I ───────┤6 (TH)    │
                │          │
                │       3  ├──── V_O
                │          │
                │       7  ├────（悬空或接上拉电阻）
                │          │
                │       4  ├──── 接 V_CC
                │          │
                │       5  ├─┬── 0.01μF ── GND
                │          │ │
                │       8  ├─┴── V_CC
                │       1  ├──── GND
                └──────────┘
```

**工作原理：**
```
   ① V_I 从 0 上升：
      当 V_I < V_CC/3 时，TR' 有效 → 输出高
      当 V_CC/3 < V_I < 2V_CC/3 时，保持（取决于之前的状态）
      当 V_I > 2V_CC/3 时，TH 有效 → 输出变低
      → **上限触发电平 V_T+ = 2V_CC/3**

   ② V_I 从高下降：
      当 V_I > 2V_CC/3 时，输出低
      当 V_CC/3 < V_I < 2V_CC/3 时，保持
      当 V_I < V_CC/3 时，TR' 有效 → 输出变高
      → **下限触发电平 V_T− = V_CC/3**

   ③ **回差电压：ΔV_T = 2V_CC/3 − V_CC/3 = V_CC/3**
```

**重要公式：**
```
   **V_T+ = 2V_CC/3**
   **V_T− = V_CC/3**
   **ΔV_T = V_CC/3**
```

> **重点**：**在 5 脚（CO）外接电压 V_CO 可以改变触发电平：**
  ```
    V_T+ = V_CO
    V_T− = V_CO/2
    ΔV_T = V_CO/2
    （不接时 V_CO = 2V_CC/3，回到原来的公式）
  ```
> **这是 555 作施密特触发器的灵活之处——回差可调。**

**例：V_CC = 5V 时**
```
   V_T+ = 2 × 5/3 = 3.33 V
   V_T− = 5/3 = 1.67 V
   ΔV_T = 5/3 = 1.67 V
```

### 7.5.3 用 555 定时器接成的单稳态电路

**接线：2 脚接触发输入，6 脚和 7 脚接在一起接定时电容 C，R 接在 V_CC 和 7 脚之间。**

```
                    V_CC
                      │
                    ┌─┴─┐
                    │ R │（定时电阻）
                    └─┬─┘
                      │
        ┌─────────────┼─────────────┐
        │             │             │
        │          7 (DIS)          │
        │             │             │
        │          6 (TH)           │
        │             │             │
        │          ┌──┴──┐          │
        │          │  C  │（定时电容）
        │          └──┬──┘          │
        │            GND            │
        │                           │
   V_I ─┤2 (TR')            3 (V_O) ├──── V_O
        │                           │
        │4 (R_D') ──── V_CC         │
        │                           │
        │5 (CO) ──┬── 0.01μF ── GND │
        │         │                 │
        │8 (V_CC) ┴─────────────────┘
        │1 (GND) ──── GND
        └───────────────────────────┘
```

**工作原理（三步）：**
```
   ① **稳态**：无触发信号（V_I = 1，即 2 脚为高）
      → 内部放电管 T **导通** → 电容 C 被短路 → V_C ≈ 0
      → 6 脚 TH = 0 < 2V_CC/3，且 2 脚 TR' 无效
      → **输出 V_O = 0**（低电平）
      → **稳态是输出低**

   ② **触发进入暂稳态**：2 脚出现负脉冲（V_I < V_CC/3）
      → C₂ 比较器输出有效 → SR 锁存器置位
      → **输出 V_O = 1（高电平）**，同时**放电管 T 截止**
      → 电容 C 通过 R 从 V_CC 开始充电（V_C 从 0 上升）

   ③ **自动返回稳态**：电容电压 V_C 上升到 **2V_CC/3** 时
      → 6 脚 TH 有效 → SR 锁存器复位
      → **输出 V_O 跳回 0（低）**，同时**放电管 T 重新导通**
      → 电容 C 迅速放电到 0，电路回到稳态，准备下次触发

   输出脉冲宽度（暂稳态持续时间）：
      电容充电公式：V_C(t) = V_CC·(1 − e^(−t/RC))
      令 V_C(t_w) = 2V_CC/3：
      V_CC·(1 − e^(−t_w/RC)) = 2V_CC/3
      1 − e^(−t_w/RC) = 2/3
      e^(−t_w/RC) = 1/3
      −t_w/RC = ln(1/3) = −ln3
      **t_w = RC·ln3 ≈ 1.1·RC**
```

**★★★ 核心公式（必背）：**
```
   **t_w = R·C·ln3 ≈ 1.1·R·C**
```

**波形图：**
```
                  t_w
        ├──────────────────┤
   V_I ─┐
        └────────────────────────────
        ↑触发（负脉冲）

   V_O      ┌──────────────┐
   ─────────┘              └─────────

   V_C                    ╱‾‾╲
   （电容电压）          ╱      ╲
   2V_CC/3 ─ ─ ─ ─ ─ ─╱─ ─ ─ ─ ─╲─ ─ ─
                      ╱            ╲
   ────────────────╱                ╲──
        ↑开始充电          ↑到 2/3 时翻转，电容放电
```

> **重点**：
  ```
    ① **输出脉宽只由 R、C 决定**，与触发脉冲的宽度、幅度无关
    ② 触发脉冲必须是**负脉冲**（因为 2 脚低有效），且**宽度要小于 t_w**
       （否则输出会一直保持高，直到触发脉冲结束）
    ③ 触发脉冲之间必须有足够的**恢复时间**（电容放电完毕），
       一般要求恢复时间 ≥ 3RC... 实际上只需很短的放电时间（放电管导通电阻很小）
  ```

**应用举例：**
```
   ① 定时：t_w = 1.1RC = 10 s，用 R = 910 kΩ、C = 10 μF
      计算：1.1 × 910×10³ × 10×10⁻⁶ = 10.01 s ✓
   ② 脉冲展宽：把 1 μs 的窄脉冲变成 1 ms 的宽脉冲
   ③ 消除抖动：开关抖动只触发一次
   ④ 分频：把高频脉冲变成低频（每触发一次输出一个脉冲）
```

### 7.5.4 用 555 定时器接成的多谐振荡电路

**接线：把 2 脚和 6 脚接在一起，接到定时电容 C 上；R₁ 接 V_CC 和 7 脚之间，R₂ 接 7 脚和 6 脚之间。**

```
                          V_CC
                            │
                          ┌─┴─┐
                          │R₁ │
                          └─┬─┘
                            │
        ┌───────────────────┼───────────────┐
        │                   │               │
        │                7 (DIS)           │
        │                   │               │
        │                 ┌─┴─┐             │
        │                 │R₂ │             │
        │                 └─┬─┘             │
        │                   │               │
        │                   ├──── 6 (TH)    │
        │                   │               │
        │                 ┌─┴─┐             │
        │                 │ C │             │
        │                 └─┬─┘             │
        │                  GND              │
        │                                   │
        │        2 (TR') ───┘（与 6 脚连在一起）
        │                                   │
        │4 (R_D') ──── V_CC                 │
        │                        3 (V_O) ───┼──── V_O
        │5 (CO) ──┬── 0.01μF ── GND         │
        │         │                         │
        │8 (V_CC) ┴─────────────────────────┘
        │1 (GND) ──── GND
        └───────────────────────────────────┘
```

**工作原理（充放电两个阶段）：**
```
   ① **充电阶段**（输出高）：
      上电后电容 C 电压为 0 → 2 脚 TR' < V_CC/3 → 输出 V_O = 1、放电管截止
      电容 C 通过 **R₁ + R₂** 从 V_CC 充电（V_C 从 V_CC/3 向 2V_CC/3 上升）

   ② **放电阶段**（输出低）：
      当 V_C 达到 **2V_CC/3** 时 → 6 脚 TH 有效 → 输出 V_O = 0、放电管导通
      电容 C 通过 **R₂** 经 7 脚对地放电（V_C 从 2V_CC/3 向 V_CC/3 下降）

   ③ 当 V_C 降到 **V_CC/3** 时 → 2 脚 TR' 有效 → 输出变回高、放电管截止
      → 回到 ①，**周而复始**
```

**波形图：**
```
              t_w1（充电）      t_w2（放电）
        ├────────────────┤├──────────────┤
   V_O  ┌────────────────┐┌──────────────┐
   ─────┘                └┘              └────
        （高）            （低）

   V_C
   2V_CC/3 ─ ─╱‾‾‾‾‾‾╲─ ─ ─ ─╱‾‾‾‾‾‾╲─ ─
              ╱        ╲      ╱        ╲
   V_CC/3 ─ ─╱─ ─ ─ ─ ─╲─ ─ ─╱─ ─ ─ ─ ─╲─ ─
            ╱            ╲  ╱            ╲
   ────────╱              ╲╱              ╲──
        ← 充电（R₁+R₂）→← 放电（R₂）→
```

**★★★ 核心公式（必背）：**

**充电时间（输出高电平时间）：**
```
   t_w1 = (R₁ + R₂)·C·ln2 ≈ 0.7·(R₁ + R₂)·C
   （推导：V_C 从 V_CC/3 充到 2V_CC/3，时间常数 τ = (R₁+R₂)C
          V_C(t) = V_CC − (V_CC − V_CC/3)·e^(−t/τ) = V_CC − (2V_CC/3)·e^(−t/τ)
          令 V_C = 2V_CC/3：V_CC − (2V_CC/3)e^(−t/τ) = 2V_CC/3
          (2/3)e^(−t/τ) = 1/3 → e^(−t/τ) = 1/2 → t = τ·ln2）
```

**放电时间（输出低电平时间）：**
```
   t_w2 = R₂·C·ln2 ≈ 0.7·R₂·C
   （推导：V_C 从 2V_CC/3 放到 V_CC/3，时间常数 τ = R₂C
          V_C(t) = (2V_CC/3)·e^(−t/τ)
          令 V_C = V_CC/3：(2/3)e^(−t/τ) = 1/3 → t = τ·ln2）
```

**振荡周期与频率：**
```
   **T = t_w1 + t_w2 = (R₁ + 2R₂)·C·ln2 ≈ 0.7·(R₁ + 2R₂)·C**
   **f = 1/T ≈ 1.43 / [(R₁ + 2R₂)·C]**
```

**占空比：**
```
   **q = t_w1 / T = (R₁ + R₂) / (R₁ + 2R₂)**
```

> **重点：为什么 q 永远大于 50%？**
  ```
    因为 R₁ 总是存在的：
      q = (R₁ + R₂)/(R₁ + 2R₂)
      R₁ → 0 时：q → R₂/(2R₂) = 1/2 = 50%
      R₁ → ∞ 时：q → 1 = 100%
    → **q 的范围是 50% ~ 100%，永远不可能小于 50%**
  ```
> **（这是 555 多谐振荡电路的固有缺陷：无法直接产生占空比小于 50% 的方波。）**

**★ 如何获得 50% 占空比的方波？**

```
   **方法一：在 R₂ 两端并联一个二极管**
   
        V_CC
          │
        ┌─┴─┐
        │R₁ │
        └─┬─┘
          │
       7 (DIS)
          │
        ┌─┴─┐
        │R₂ │
        └─┬─┘
          │
          ├──── 6 (TH)
          │
        ┌─┴─┐
        │ C │      在 R₂ 两端并联二极管 D（方向：**阳极接 7 脚、阴极接电容端 6 脚侧**）
        └─┬─┘      → 充电时电流经 R₁ 和 D（绕过 R₂）→ 充电时间常数 = R₁C
        GND        → 放电时电流经 R₂（D 截止）→ 放电时间常数 = R₂C
   
   取 **R₁ = R₂ = R**：
     充电时间 t_w1 = R·C·ln2
     放电时间 t_w2 = R·C·ln2
     → **q = 50%** ✓
     → T = 2RC·ln2 ≈ 1.4RC
   ```

```
   **方法二：输出接一个 T' 触发器（二分频）**
   
   555 输出（q ≠ 50%）──► T' 触发器（每来一个脉冲翻转）──► 输出（q = 50%）
   
   → 因为二分频后，高电平和低电平的时间变得相等
   → 但频率减半
   ```

```
   **方法三：用两个二极管 + 电位器（可调占空比）**
   用二极管把充电路径和放电路径完全分开，分别用不同的电阻
   → 占空比可以连续调节（甚至小于 50%）
```

**例 7.1**（题型：555 单稳态电路参数计算）

用 555 定时器构成单稳态电路，要求输出脉冲宽度 t_w = 5 s。已知定时电容 C = 10 μF，求定时电阻 R。

**解**：

**公式：`t_w = R·C·ln3 ≈ 1.1·R·C`**

代入数值：
```
   5 = 1.1 × R × 10 × 10⁻⁶
   R = 5 / (1.1 × 10 × 10⁻⁶)
     = 5 / (1.1 × 10⁻⁵)
     = 4.545 × 10⁵ Ω
     = 454.5 kΩ
```

**取标准值 R = 470 kΩ**，此时：
```
   t_w = 1.1 × 470×10³ × 10×10⁻⁶ = 5.17 s
   （略大于 5 s，误差 3.4%，在工程允许范围内）
```

**若要求精确的 5 s**，取 R = 430 kΩ + 24 kΩ：
```
   t_w = 1.1 × 454×10³ × 10×10⁻⁶ = 4.994 s ≈ 5 s ✓
```

**答案**：**R ≈ 454.5 kΩ**，取标准值 **470 kΩ**（此时 t_w ≈ 5.17 s），或取 **430 kΩ + 24 kΩ** 串联获得更精确的 5 s。

**为什么这样做**：
```
   ① 555 单稳态的脉宽公式 **t_w = RC·ln3 ≈ 1.1RC** 是必背公式
      （ln3 = 1.0986 ≈ 1.1）
   ② **电容不宜太小**（小于 1000 pF 时分布电容影响大，误差大），
      一般 C 取 0.01 μF ~ 1000 μF
   ③ **电阻不宜太大**（大于 10 MΩ 时漏电流影响大），一般 R 取 1 kΩ ~ 10 MΩ
   ④ 计算结果要**取标准系列值**（E24 系列：1.0, 1.1, 1.2, 1.3, 1.5, 1.6, 1.8, 2.0, 2.2, 2.4, 2.7, 3.0, 3.3, 3.6, 3.9, 4.3, 4.7, 5.1, 5.6, 6.2, 6.8, 7.5, 8.2, 9.1）
```

**例 7.2**（题型：555 多谐振荡电路计算）

用 555 定时器构成多谐振荡电路，已知 V_CC = 5 V，R₁ = 10 kΩ，R₂ = 20 kΩ，C = 0.1 μF。求：
（1）充电时间 t_w1、放电时间 t_w2；
（2）振荡周期 T 和频率 f；
（3）占空比 q；
（4）若要得到 50% 占空比，应如何修改电路？

**解**：

**（1）充电时间和放电时间**
```
   t_w1 = (R₁ + R₂)·C·ln2 = (10 + 20)×10³ × 0.1×10⁻⁶ × 0.693
        = 30×10³ × 0.1×10⁻⁶ × 0.693
        = 3×10⁻³ × 0.693
        = 2.079 × 10⁻³ s
        ≈ **2.08 ms**

   t_w2 = R₂·C·ln2 = 20×10³ × 0.1×10⁻⁶ × 0.693
        = 2×10⁻³ × 0.693
        ≈ **1.386 ms**
```

**（2）周期和频率**
```
   T = t_w1 + t_w2 = 2.079 + 1.386 = 3.465 ms
   
   或直接用公式：
   T = (R₁ + 2R₂)·C·ln2 = (10 + 40)×10³ × 0.1×10⁻⁶ × 0.693
     = 50×10³ × 0.1×10⁻⁶ × 0.693
     = 3.465 × 10⁻³ s
     ≈ **3.47 ms**

   f = 1/T = 1/(3.465×10⁻³) = 288.6 Hz ≈ **289 Hz**
```

**（3）占空比**
```
   q = t_w1 / T = 2.079 / 3.465 = 0.600 = **60%**
   
   或直接用公式：
   q = (R₁ + R₂)/(R₁ + 2R₂) = (10 + 20)/(10 + 40) = 30/50 = **60%** ✓
```

**（4）获得 50% 占空比的方法**
```
   在 R₂ 两端并联一个二极管（**阳极接 7 脚、阴极接 6 脚侧**），并取 **R₁ = R₂ = R**
   
   设保持振荡频率不变，则需 T 不变：
     原 T = 50 kΩ × C × ln2 = 3.465 ms
     新 T = 2RC·ln2
     → 2R = 50 kΩ → **R = 25 kΩ**
   
   取 R₁ = R₂ = 25 kΩ（标准值可取 24 kΩ，此时 T = 2×24×10³×0.1×10⁻⁶×0.693 = 3.33 ms，f ≈ 300 Hz）
   
   此时：
     t_w1 = R₁C·ln2 = 24×10³ × 0.1×10⁻⁶ × 0.693 = 1.663 ms
     t_w2 = R₂C·ln2 = 同上 = 1.663 ms
     q = 1.663/3.327 = **50%** ✓
```

**答案**：（1）t_w1 ≈ **2.08 ms**，t_w2 ≈ **1.39 ms**；（2）T ≈ **3.47 ms**，f ≈ **289 Hz**；（3）q = **60%**；（4）**在 R₂ 两端并联二极管并使 R₁ = R₂**（保持 R₁+2R₂ 不变以维持频率）。

**为什么这样做**：
```
   ★ 555 多谐振荡的三个公式（必背）：
     **t_w1 = 0.7(R₁ + R₂)C**     （充电，输出高）
     **t_w2 = 0.7·R₂·C**           （放电，输出低）
     **T = 0.7(R₁ + 2R₂)C**        （周期）
     **q = (R₁+R₂)/(R₁+2R₂)**      （占空比）
   
   ★ 注意：**q 永远 ≥ 50%**，因为充电必须经过 R₁+R₂ 而放电只经过 R₂，
     充电路径的电阻总是更大。
   
   ★ 要获得 50%，必须让充放电路径的电阻相等 → 用二极管把 R₂ "旁路"掉
```

**例 7.3**（题型：555 施密特触发电路计算）

用 555 定时器构成施密特触发电路，V_CC = 12 V。求：
（1）上限触发电平 V_T+、下限触发电平 V_T−、回差电压 ΔV_T；
（2）若在 5 脚外接 6 V 电压，重新求上述三个参数；
（3）某输入信号的幅度为 3 V（峰峰值 6 V，以 6 V 为中心），能否可靠触发？

**解**：

**（1）5 脚不接外部电压**
```
   V_T+ = 2V_CC/3 = 2 × 12/3 = **8 V**
   V_T− = V_CC/3 = 12/3 = **4 V**
   ΔV_T = V_T+ − V_T− = 8 − 4 = **4 V**
   （或 ΔV_T = V_CC/3 = 4 V）
```

**（2）5 脚外接 V_CO = 6 V**
```
   V_T+ = V_CO = **6 V**
   V_T− = V_CO/2 = **3 V**
   ΔV_T = V_CO/2 = **3 V**
```

**（3）判断输入信号能否触发**
```
   设输入信号以 6 V 为中心，峰峰值 6 V（即从 3 V 到 9 V）
   
   情况（1）：V_T+ = 8 V, V_T− = 4 V
     输入最高 9 V > 8 V ✓（能触发上限翻转）
     输入最低 3 V < 4 V ✓（能触发下限翻转）
     → **能可靠触发** ✓
   
   情况（2）：V_T+ = 6 V, V_T− = 3 V
     输入最高 9 V > 6 V ✓
     输入最低 3 V ≥ 3 V（**临界**）
     → 在临界点附近，可能因噪声无法可靠触发 → **不太可靠** ⚠
   
   分析：情况（2）的回差为 3 V，而输入信号从中心 6 V 出发，
        向下只需要降到 3 V 就能触发（刚好达到），
        实际中若信号略有衰减就无法触发。
   → **建议情况（2）下增大输入幅度或减小外接的 V_CO**
```

**答案**：（1）V_T+ = **8 V**，V_T− = **4 V**，ΔV_T = **4 V**；（2）V_T+ = **6 V**，V_T− = **3 V**，ΔV_T = **3 V**；（3）在情况（1）下**能可靠触发**（输入 3~9 V 完全覆盖 4~8 V 的回差窗口）；在情况（2）下**处于临界状态，不够可靠**（输入下限 3 V 恰好等于 V_T−）。

**为什么这样做**：
```
   ★ 555 作施密特触发器的关键公式：
     5 脚不接：**V_T+ = 2V_CC/3，V_T− = V_CC/3，ΔV_T = V_CC/3**
     5 脚接 V_CO：**V_T+ = V_CO，V_T− = V_CO/2，ΔV_T = V_CO/2**
   
   ★ 判断能否触发的准则：
     **输入信号的最大值必须 > V_T+，最小值必须 < V_T−**
     且要留有一定余量（一般要求余量 > 0.5 V，以抵抗噪声）
```

**例 7.4**（题型：施密特触发电路判断与波形变换）

某施密特触发器的 V_T+ = 3 V，V_T− = 2 V。输入波形为正弦波，幅度从 0 到 4 V（即以 2 V 为中心，峰峰值 4 V）。画出输出波形。

**解**：

**分析：**
```
   V_T+ = 3 V, V_T− = 2 V, ΔV_T = 1 V
   输入 V_I(t) 以 2 V 为中心，峰值 4 V，谷值 0 V
```

**判断触发点：**
```
   ① 输入上升阶段：V_I 从 0 V 上升到 4 V
      → 在 V_I = **3 V (V_T+)** 处，输出翻转为低 ✓
   
   ② 输入下降阶段：V_I 从 4 V 下降到 0 V
      → 在 V_I = **2 V (V_T−)** 处，输出翻转为高 ✓
   
   ③ 输入在 2 V 与 3 V 之间的区域：
      → 输出**保持**（这就是回差的作用）
```

**波形图：**
```
   V_I
   4V ─ ─ ─ ─ ─ ─ ─╱‾‾╲─ ─ ─ ─ ─ ─
                  ╱      ╲
   3V ─ ─ ─ ─ ─ ─╱─ ─ ─ ─ ╲─ ─ ─ ─   ← V_T+（翻转点）
                ╱          ╲
   2V ─ ─ ─ ─ ─╱─ ─ ─ ─ ─ ─╲─ ─ ─   ← V_T−（翻转点）
              ╱              ╲
   0V ─ ─ ─ ─╱─ ─ ─ ─ ─ ─ ─ ─╲─ ─
             ↑                ↑
          （V_T− 处输出变高）  （V_T+ 处输出变低）
           实际是：从左往右，V_I 上升到 3V 时输出变低
                   V_I 下降到 2V 时输出变高

   V_O
   ─────┐                    ┌─────────
        └────────────────────┘
        ↑（V_I 升到 3V）      ↑（V_I 降到 2V）
```

**答案**：输出波形为**矩形波**。输入从 0 V 上升的过程中，在 **V_I = 3 V** 处输出从高翻转为低；输入从 4 V 下降的过程中，在 **V_I = 2 V** 处输出从低翻转为高。输出与输入同频率，但**输出是规则的矩形波**（实现了"波形变换"）。

```
   完整的一个周期：
   V_I:  0 → 1 → 2 → 3 → 4 → 3 → 2 → 1 → 0
   V_O:  1 → 1 → 1 → 0 → 0 → 0 → 1 → 1 → 1
                      ↑           ↑
                  （翻转为低）  （翻转为高）
```

**为什么这样做**：
```
   ★ 画施密特触发器输出波形的核心方法：
     ① 找出 V_T+ 和 V_T−
     ② **输入上升**时对比 **V_T+**（超过则输出翻转为低）
     ③ **输入下降**时对比 **V_T−**（低于则输出翻转为高）
     ④ 在 V_T− 和 V_T+ 之间，输出**保持不变**
   
   ★ 注意：**输入上升和下降对应不同的阈值**，这是与普通比较器的根本区别。
     普通比较器只有一个阈值，输入在阈值附近波动会导致输出抖动；
     施密特触发器有了回差，就能避免这个问题。
```

**例 7.5**（题型：单稳态电路的应用——脉冲展宽）

某传感器输出的脉冲宽度只有 2 μs，需要展宽到 1 ms 才能被单片机识别。用 555 单稳态电路实现，求 R、C 参数。

**解**：

**公式：`t_w = 1.1·R·C = 1 ms`**

**选择合适的 C：**
```
   考虑到单片机的应用场合，取 C = 0.1 μF（较为常用，误差适中）
   → R = t_w / (1.1·C) = 1×10⁻³ / (1.1 × 0.1×10⁻⁶)
        = 1×10⁻³ / (1.1×10⁻⁷)
        = 9.09 × 10³ Ω
        = 9.09 kΩ
```

**取标准值 R = 9.1 kΩ**，验证：
```
   t_w = 1.1 × 9.1×10³ × 0.1×10⁻⁶ = 1.001 × 10⁻³ s = 1.001 ms ✓
   （误差 0.1%，完全满足要求）
```

**电路：**
```
                             V_CC = 5V
                               │
                            ┌──┴──┐
                            │9.1kΩ│
                            └──┬──┘
                               │
        ┌──────────────────────┼──────────────┐
        │                   7 (DIS)           │
        │                      │               │
        │                   6 (TH)            │
        │                      │               │
        │                   ┌──┴──┐            │
        │                   │0.1μF│            │
        │                   └──┬──┘            │
        │                     GND              │
        │                                      │
   传感器 ─┤2 (TR')                    3 (V_O) ├──── 单片机
   （2μs负脉冲）│                              │
        │4 (R_D') ── V_CC                    │
        │5 (CO) ─┬─ 0.01μF ─ GND             │
        │        │                            │
        │8 (V_CC)┴────────────────────────────┘
        │1 (GND) ── GND
        └──────────────────────────────────────┘
```

**答案**：**C = 0.1 μF，R = 9.1 kΩ**（t_w ≈ 1.001 ms）。

**为什么这样做**：
```
   ★ 设计 555 单稳态电路的步骤：
     ① 由 t_w 要求确定 RC 乘积：RC = t_w/1.1
     ② **先选 C**（一般取 0.01 μF ~ 100 μF，优先选常用值）
     ③ 再算 R，取标准值（1 kΩ ~ 10 MΩ）
   
   ★ 注意事项：
     ① 触发脉冲宽度 **必须小于 t_w**（否则输出会一直保持高直到触发结束）
     ② 触发脉冲的**幅度必须使 2 脚低于 V_CC/3**
     ③ 若触发信号是宽脉冲，需先用**微分电路**变成窄脉冲
     ④ 4 脚（R_D'）不用时**必须接 V_CC**（不能悬空，否则可能误复位）
     ⑤ 5 脚不用时**接 0.01 μF 到地**（滤除电源噪声）
```

**例 7.6**（题型：555 多谐振荡电路设计）

设计一个 555 多谐振荡电路，要求输出频率 f = 1 kHz，占空比 q = 2/3（约 66.7%）。求 R₁、R₂、C。

**解**：

**步骤 1：由占空比求 R₁ 与 R₂ 的关系**
```
   q = (R₁ + R₂)/(R₁ + 2R₂) = 2/3
   3(R₁ + R₂) = 2(R₁ + 2R₂)
   3R₁ + 3R₂ = 2R₁ + 4R₂
   R₁ = R₂
```

**步骤 2：由频率求 RC**
```
   T = 1/f = 1/1000 = 1×10⁻³ s = 1 ms
   T = 1.1(R₁ + 2R₂)C  （取 ln2 ≈ 0.7，则 0.7 = 1/1.43；
                          更精确地：T = 0.693(R₁ + 2R₂)C）
   
   代入 R₁ = R₂ = R：
   T = 0.693 × (R + 2R) × C = 0.693 × 3R × C = 2.079·RC
   
   1×10⁻³ = 2.079 × R × C
   RC = 1×10⁻³ / 2.079 = 4.81 × 10⁻⁴
```

**步骤 3：选电容并求电阻**
```
   取 **C = 0.1 μF = 1×10⁻⁷ F**：
   R = 4.81×10⁻⁴ / 1×10⁻⁷ = 4810 Ω = 4.81 kΩ
   
   取标准值 **R = 4.7 kΩ**（此时 f 略高）
   或 **R = 4.7 kΩ**，调整 C：
     验证：T = 2.079 × 4.7×10³ × 0.1×10⁻⁶ = 9.77×10⁻⁴ s
           f = 1/9.77×10⁻⁴ = 1023 Hz（误差 2.3%）
```

**步骤 4：精确设计（用标准值组合）**
```
   取 R₁ = R₂ = 4.7 kΩ，C = 0.1 μF：
     T = 2.079 × 4.7×10³ × 1×10⁻⁷ = 9.77×10⁻⁴ s
     f = 1023 Hz  （偏高 2.3%）
   
   若要更精确，取 R₁ = R₂ = 4.3 kΩ + 300 Ω（用两电阻串联）：
     R = 4.6 kΩ
     T = 2.079 × 4.6×10³ × 1×10⁻⁷ = 9.56×10⁻⁴ s
     f = 1046 Hz  （更偏了）
   
   实际上取 R₁ = R₂ = 4.8 kΩ（4.7k + 100Ω）：
     T = 2.079 × 4.8×10³ × 1×10⁻⁷ = 9.98×10⁻⁴ s
     f = 1002 Hz ✓ （误差 0.2%）
```

**验证占空比：**
```
   q = (R₁ + R₂)/(R₁ + 2R₂) = (4.8+4.8)/(4.8+9.6) = 9.6/14.4 = 2/3 = 66.7% ✓
```

**答案**：**C = 0.1 μF，R₁ = R₂ = 4.8 kΩ**（4.7 kΩ + 100 Ω），此时 f ≈ 1002 Hz、q = 66.7%。

**为什么这样做**：
```
   ★ 设计 555 多谐振荡电路的步骤：
     ① **由占空比 q 确定 R₁ 与 R₂ 的关系**：
          q = (R₁+R₂)/(R₁+2R₂)
     ② **由频率 f 确定 RC 的乘积**：
          T = 0.693(R₁ + 2R₂)C
     ③ 先选 C，再算 R
     ④ 取标准值并验证
   
   ★ 重要结论：
     q = 50% ⟺ **R₁ = 0**（由 q = (R₁+R₂)/(R₁+2R₂) 令 q = 0.5 解得；但 R₁ = 0 等于把 7 脚直接接 V_CC，不可能实现，所以基本电路**永远做不到 50%**，必须用二极管方案或二分频）
     q = 2/3 ⟺ **R₁ = R₂**
     q = 75% ⟺ **R₁ = 2R₂**
     q 越大 ⟺ R₁/R₂ 越大
   
   ★ 注意：**555 的占空比永远大于 50%**，这是由充放电路径不对称造成的。
```

**例 7.7**（题型：环形振荡器计算）

用 5 个 CMOS 反相器构成环形振荡器，每个反相器的平均传输延迟 t_pd = 20 ns。求振荡周期和频率。

**解**：

**公式：`T = 2·n·t_pd`**

代入 n = 5、t_pd = 20 ns：
```
   T = 2 × 5 × 20 ns = 200 ns
   f = 1/T = 1/(200×10⁻⁹) = 5 × 10⁶ Hz = 5 MHz
```

**答案**：**T = 200 ns，f = 5 MHz**。

**为什么这样做**：
```
   ★ 环形振荡器的公式 **T = 2·n·t_pd** 的来源：
     一个完整的振荡周期需要信号**绕环路两周**：
       第一周：信号从初始状态传到环路末端（n 个门，延迟 n·t_pd）
       第二周：反转后的信号再传一圈（再延迟 n·t_pd）
     → T = 2·n·t_pd
   
   ★ 为什么必须用奇数个反相器？
     偶数个反相器会形成"两级反相 = 不变"的环路 → 稳定，不振荡
     奇数个反相器形成"每绕一圈就反相一次" → 永远不稳定 → 振荡
   
   ★ **环形振荡器的缺点**：
     ① 频率受温度、电源电压、工艺影响很大（t_pd 不稳定）
     ② 频率不能太低（若需要低频，需要很多级反相器，不现实）
     ③ 频率可以通过改变反相器级数或加 RC 环节来调节
```

**例 7.8**（题型：三种电路的识别与选择）

下列各应用场合，应分别选用哪种脉冲电路（施密特触发电路 / 单稳态电路 / 多谐振荡电路）？
（1）把边沿缓慢、带有噪声的信号变成干净的矩形波；
（2）产生单片机系统的时钟信号；
（3）把 1 μs 的窄脉冲展宽为 100 μs；
（4）从一串幅度不等的脉冲中选出幅度较大者；
（5）产生一个固定宽度的延时脉冲。

**解**：

| 应用 | 选用电路 | 理由 |
|---|---|---|
| **（1）波形整形** | **施密特触发电路** | **回差特性可以滤除噪声**（只要噪声幅度 < ΔV_T） |
| **（2）产生时钟** | **多谐振荡电路** | **无稳态，能自发产生连续振荡**，不需要输入信号 |
| **（3）脉冲展宽** | **单稳态电路** | **输出脉宽由 RC 决定，与触发脉冲宽度无关**，可以任意设置 |
| **（4）幅度鉴别** | **施密特触发电路** | **只有幅度超过 V_T+ 的脉冲才能通过** |
| **（5）延时脉冲** | **单稳态电路** | **暂稳态时间由 RC 决定**，可精确控制延时 |

**答案**：（1）施密特触发电路；（2）多谐振荡电路；（3）单稳态电路；（4）施密特触发电路；（5）单稳态电路。

**为什么这样做**：
```
   ★ **三种电路的选择准则（必背）**：
   
   ① **需要"输出跟随输入但有整形效果"** → **施密特触发电路**
      典型应用：波形变换、脉冲整形、幅度鉴别、消除抖动
      （特征：**有输入信号**，输出是输入的"干净版"）
   
   ② **需要"一个固定宽度的输出脉冲"** → **单稳态电路**
      典型应用：定时、延时、脉冲展宽、频率分频
      （特征：**有触发输入**，输出脉宽只由 RC 决定）
   
   ③ **需要"自发产生周期性脉冲"** → **多谐振荡电路**
      典型应用：产生时钟、产生测试信号
      （特征：**没有输入信号**，自己振荡）
   
   ★ 记忆口诀：
     施密特——"**整形**"（两个稳态，跟着输入走）
     单稳态——"**定时**"（一个稳态，触发一次输出一个固定脉冲）
     多谐——"**产生**"（零个稳态，自己振荡）
```

## 易错点提醒

1. **混淆三种电路的稳态数** → **施密特 2 个稳态**、**单稳态 1 个稳态 + 1 个暂稳态**、**多谐振荡 0 个稳态**。这是最基础的概念，答题时不能搞错。
2. **以为施密特触发器只有一个阈值** → 施密特触发器有**两个阈值**：**V_T+（输入上升时用）** 和 **V_T−（输入下降时用）**。**普通比较器才只有一个阈值。**
3. **V_T+ 和 V_T− 的大小关系搞反** → 必然有 **V_T+ > V_T−**（上限触发电平高于下限触发电平），**ΔV_T = V_T+ − V_T− > 0**。若算出负数，一定是概念错了。
4. **画施密特触发器输出波形时用错阈值** → **输入上升过程对比 V_T+**（超过就翻转为低）；**输入下降过程对比 V_T−**（低于就翻转为高）。**两个过程必须用不同的阈值**——这是施密特触发器的核心。
5. **555 单稳态的公式记成 0.7RC** → **555 单稳态的脉宽是 t_w = RC·ln3 ≈ 1.1RC**（因为电容从 0 充到 2V_CC/3，比值是 1/3）。**而多谐振荡的充放电时间是 0.7RC 量级**（因为是在 V_CC/3 和 2V_CC/3 之间充放电，比值是 1/2）。**两个 ln 值不同（ln3 vs ln2），不要混用！**
6. **555 多谐振荡的周期公式写成 0.7(R₁+R₂)C** → 正确公式是 **`T = 0.7(R₁ + 2R₂)C`**（注意是 **2R₂**）。因为充电经过 **R₁+R₂**、放电经过 **R₂**，总和是 **R₁ + R₂ + R₂ = R₁ + 2R₂**。
7. **占空比公式写错** → **`q = t_w1/T = (R₁ + R₂)/(R₁ + 2R₂)`**。**注意分子是 R₁+R₂（充电路径电阻），分母是 R₁+2R₂（总电阻）**。
8. **以为 555 可以产生占空比小于 50% 的方波** → **555 的占空比范围是 50% ~ 100%**，**永远 ≥ 50%**。因为充电必须经过 R₁+R₂，而放电只经过 R₂，充电电阻总是不小于放电电阻。**要得到 50%，必须在 R₂ 两端并联二极管**。
9. **555 的 4 脚（R_D'）悬空** → **4 脚不用时必须接 V_CC（高电平）**。悬空时可能被干扰拉低，导致电路误复位。**这是最常见的实际接线错误。**
10. **555 的 5 脚（CO）悬空** → **5 脚不用时应接 0.01 μF 电容到地**，用于滤除电源噪声。若不接，触发电平会受电源波动影响。
11. **忘记 555 的 2 脚是"低有效"** → **2 脚（TR'）在电压低于 V_CC/3 时有效**。所以要触发单稳态电路，必须加**负脉冲**（或让信号降到 V_CC/3 以下）。若加正脉冲则不会触发。
12. **触发脉冲宽度大于 t_w** → **单稳态电路的触发脉冲宽度必须小于输出脉宽 t_w**，否则输出会一直保持高电平直到触发脉冲结束。**若触发信号是宽脉冲，必须先微分变成窄脉冲。**
13. **环形振荡器用偶数个反相器** → **必须用奇数个反相器（≥3）**。偶数个反相器形成的环路是稳定的（每两级反相回到原值），不会振荡。
14. **环形振荡器的周期公式记成 n·t_pd** → 正确是 **`T = 2·n·t_pd`**（信号绕环路两周才完成一个周期）。
15. **以为石英晶体振荡器的频率可以随意选** → 石英晶体的频率**由晶片的切割尺寸决定，是固定的**，不能像 RC 振荡器那样随意调节。要得到不同频率必须换晶体。**但可以用分频或 PLL 倍频得到其他频率。**
16. **用 RC 振荡器做精密时基** → **RC 振荡器的频率稳定度只有 10⁻² 量级**（受温度、电源、器件误差影响大），**绝对不能用于需要精确定时的场合**（如时钟、计时）。**必须用石英晶体振荡器（稳定度 10⁻⁶~10⁻¹¹）。**
17. **以为多谐振荡器需要输入信号** → **多谐振荡器是"无稳态"电路，不需要任何输入信号**，加上电源就开始振荡。这是它与施密特（需要输入）、单稳态（需要触发）的根本区别。
18. **计算时 ln2 和 ln3 的取值不一致** → 建议统一取 **ln2 ≈ 0.693 ≈ 0.7**、**ln3 ≈ 1.099 ≈ 1.1**。**同一题中要用同一个近似值**，否则结果会自相矛盾（考试时若题目给了近似值就按题目来）。
19. **555 的输出能力忽略** → 555 的输出电流可达 **200 mA**（灌电流），可以直接驱动 LED、小继电器等负载。但**不能直接驱动大功率负载**。
20. **忘记 555 的电源范围** → 555 的工作电压范围是 **4.5 V ~ 16 V**（双极型），CMOS 型的 7555 是 **2 V ~ 18 V**，且**功耗更低**（适合电池供电）。

## 本章小结

1. **矩形脉冲的四个参数**：周期 T、脉宽 t_w、上升时间 t_r、下降时间 t_f；**占空比 q = t_w/T**。
2. **三种电路的稳态数（★ 必记）**：

> | 电路 | 稳态数 | 输入 | 用途 |
> |---|---|---|---|
> | **施密特触发电路** | **2 个稳态** | 有输入 | **整形、变换、幅度鉴别** |
> | **单稳态电路** | **1 个稳态 + 1 个暂稳态** | 有触发 | **定时、延时、展宽** |
> | **多谐振荡电路** | **0 个稳态** | 无输入 | **产生时钟** |

3. **施密特触发电路**：有**回差特性**，`ΔV_T = V_T+ − V_T−`。
   ```
   输入上升 → 对比 V_T+（超过则翻转为低）
   输入下降 → 对比 V_T−（低于则翻转为高）
   ```
> **回差的作用是抗干扰**（噪声幅度 < ΔV_T 时输出不抖动）。
> **用门电路构成时 ΔV_T 由 R₁/R₂ 的比值决定（R₁/R₂ 越大回差越大）。**
4. **单稳态电路**：触发一次输出**一个固定宽度的脉冲**。
   ```
   用门电路 + RC：t_w ≈ 0.7RC
   集成单稳态（74HC123）：t_w ≈ 0.7·R_ext·C_ext
   ```
> **输出脉宽与触发脉冲无关**；分为**可再触发**和**不可再触发**两类。
5. **多谐振荡电路**：
   ```
   环形振荡器（奇数个反相器）：**T = 2·n·t_pd**
   施密特 + RC：**T = 2RC·ln2 ≈ 1.4RC**（当 V_T− = V_T+/2 时；两项各贡献 RC·ln2）
   石英晶体：**频率由晶体决定，稳定度 10⁻⁶~10⁻¹¹（最高）**
   ```
6. **★ 555 定时器的引脚与功能**：
   ```
   1-GND  2-TR'（低有效触发）  3-V_O（输出）  4-R_D'（低有效复位）
   5-CO（控制电压）  6-TH（阈值）  7-DIS（放电）  8-V_CC
   ```
> 内部：**三个 5 kΩ 电阻分压**（得 2V_CC/3 和 V_CC/3）+ **两个比较器** + **SR 锁存器** + **放电管** + 输出缓冲。
   ```
   功能口诀：**「高电位（TH 2V_CC/3）复位，低电位（TR'<V_CC/3）置位，R_D' 最高优先」**
   ```
7. **★ 555 的三种应用电路与公式（必背）**：

> | 电路 | 接法 | 关键公式 |
> |---|---|---|
> | **施密特** | 2、6 脚接在一起作输入 | **V_T+ = 2V_CC/3，V_T− = V_CC/3，ΔV_T = V_CC/3**；<br>5 脚接 V_CO 时：**V_T+ = V_CO，V_T− = V_CO/2** |
> | **单稳态** | 2 脚触发，6、7 脚接 C，R 接 V_CC 与 7 脚 | **t_w = R·C·ln3 ≈ 1.1·R·C** |
> | **多谐振荡** | 2、6 脚接 C，R₁ 接 V_CC-7 脚，R₂ 接 7-6 脚 | **t_w1 = 0.7(R₁+R₂)C**（高）<br **t_w2 = 0.7·R₂·C**（低）<br **T = 0.7(R₁+2R₂)C**<br **f ≈ 1.43/[(R₁+2R₂)C]**<br **q = (R₁+R₂)/(R₁+2R₂)** |

8. **555 占空比的固有缺陷**：**q 永远 ≥ 50%**（因为充电路径含 R₁+R₂，放电路径只含 R₂）。
> **获得 50% 的方法**：**在 R₂ 两端并联二极管并使 R₁ = R₂**（或用 T' 触发器二分频）。
9. **石英晶体振荡器**：**Q 值极高（10⁴~10⁶）**，频率由晶体几何尺寸决定，**稳定度 10⁻⁶~10⁻¹¹**，用于时钟、计时等精密场合。电子表用 **32.768 kHz** 晶体（= 2¹⁵，便于分频得 1 Hz）。
10. **实用接线注意**：555 的 **4 脚必须接 V_CC（不能悬空）**；**5 脚接 0.01 μF 到地**；**电容取 0.01 μF~1000 μF，电阻取 1 kΩ~10 MΩ**。

> **一句话记住本章**：**"零个稳态的是多谐（自己振），一个稳态的是单稳态（触发一次给一个固定宽度的脉冲），两个稳态的是施密特（跟着输入走但有回差，所以能整形抗噪）"；而 555 就是这三种电路的万能实现——记住三个公式：施密特的 `V_T+ = 2V_CC/3`、单稳态的 `t_w = 1.1RC`、多谐的 `T = 0.7(R₁+2R₂)C` 与 `q = (R₁+R₂)/(R₁+2R₂)`。**

### 自测题答案

**1.**
| 电路 | 稳态数 | 主要用途 |
|---|---|---|
| **施密特触发电路** | **2 个稳态** | **波形变换、脉冲整形、幅度鉴别、消除抖动** |
| **单稳态电路** | **1 个稳态 + 1 个暂稳态** | **定时、延时、脉冲展宽、分频** |
| **多谐振荡电路** | **0 个稳态**（无稳态） | **产生时钟信号、测试信号** |

**区别的关键**：**施密特需要输入信号**（输出跟随输入）；**单稳态需要触发信号**（输出脉宽由 RC 决定）；**多谐振荡不需要任何输入**（自激振荡）。

**2.** **回差电压 ΔV_T = V_T+ − V_T−**，即上限触发电平与下限触发电平之差。

**作用**：**抗干扰**。当输入信号上叠加了噪声时，如果只有一个阈值，输入在阈值附近波动会导致输出反复翻转（抖动）。有了回差之后，只要**噪声幅度小于 ΔV_T**，输入在 V_T− 到 V_T+ 之间波动时输出就保持不变，从而得到干净的输出波形。

**过大的问题**：**灵敏度降低**，需要更大的输入变化才能触发翻转，对小信号可能无法触发；对**幅度鉴别**应用来说，分辨率变差（只能区分幅度差大于 ΔV_T 的信号）。

**过小的问题**：**抗干扰能力差**，噪声容易引起误触发，失去了回差的意义。

**结论**：**ΔV_T 应根据输入信号的噪声幅度来选**——一般取 `ΔV_T = (2~5) × 噪声幅度`。

**3.**
```
   V_T+ = 4 V, V_T− = 1.5 V
   输入从 0 V 升到 5 V：
     → 在 V_I = **4 V（V_T+）** 处，输出**从高翻转为低**
   输入从 5 V 降到 0 V：
     → 在 V_I = **1.5 V（V_T−）** 处，输出**从低翻转为高**
```
**答案**：**输入上升时在 4 V 处输出变低；输入下降时在 1.5 V 处输出变高。**

波形：
```
   V_I  0 ──► 4 ──► 5 ──► 1.5 ──► 0
   V_O  1  →  0  →  0  →  1  →  1
                 ↑             ↑
            （升到 4V 翻转） （降到 1.5V 翻转）
```

**4.**
```
   t_w = R·C·ln3 ≈ 1.1·R·C
       = 1.1 × 100×10³ × 1×10⁻⁶
       = 1.1 × 0.1
       = 0.11 s
       = **110 ms**
```
**答案**：输出脉冲宽度 **t_w = 110 ms**。

**5.**
**（1）充电时间、放电时间**
```
   t_w1 = 0.7(R₁ + R₂)C = 0.7 × (5 + 10)×10³ × 0.01×10⁻⁶
        = 0.7 × 15×10³ × 1×10⁻⁸
        = 0.7 × 1.5×10⁻⁴
        = 1.05×10⁻⁴ s = **0.105 ms**

   t_w2 = 0.7·R₂·C = 0.7 × 10×10³ × 0.01×10⁻⁶
        = 0.7 × 10×10³ × 1×10⁻⁸
        = 0.7 × 1×10⁻⁴
        = 0.7×10⁻⁴ s = **0.07 ms**
```
**（2）周期和频率**
```
   T = t_w1 + t_w2 = 0.105 + 0.07 = **0.175 ms**
   
   或用公式：T = 0.7(R₁ + 2R₂)C = 0.7 × (5 + 20)×10³ × 0.01×10⁻⁶
                            = 0.7 × 25×10³ × 1×10⁻⁸
                            = 1.75×10⁻⁴ s = 0.175 ms ✓
   
   f = 1/T = 1/(0.175×10⁻³) = 5714 Hz ≈ **5.7 kHz**
```
**（3）占空比**
```
   q = t_w1/T = 0.105/0.175 = 0.6 = **60%**
   
   或用公式：q = (R₁+R₂)/(R₁+2R₂) = (5+10)/(5+20) = 15/25 = 0.6 ✓
```
**答案**：（1）t_w1 = **0.105 ms**，t_w2 = **0.07 ms**；（2）T = **0.175 ms**，f ≈ **5.7 kHz**；（3）q = **60%**。

**6.** 
**原因**：555 多谐振荡电路的**充电和放电路径不对称**：
```
   充电时：电容 C 通过 **R₁ + R₂** 从 V_CC 充电（经过两个电阻）
   放电时：电容 C 只通过 **R₂** 放电（R₁ 被 7 脚的放电管"短路"掉）
   
   → 充电电阻 (R₁+R₂) 总是**大于**放电电阻 R₂
   → 充电时间 t_w1 = 0.7(R₁+R₂)C 总是**大于**放电时间 t_w2 = 0.7R₂C
   → 高电平时间   低电平时间
   → **q = (R₁+R₂)/(R₁+2R₂) > 1/2**
   
   极限分析：
     R₁ → 0 时：q → R₂/(2R₂) = **50%**（但 R₁ = 0 会使 7 脚直接接 V_CC，不能工作）
     R₁ → ∞ 时：q → **100%**
```
**得到 50% 的方法**：
```
   **方法一（最常用）：在 R₂ 两端并联一个二极管**
     二极管方向：**阳极接 7 脚（R₁、R₂ 的连接点）、阴极接 6 脚侧（电容端）**
       —— 判断方法：**充电时电流从 7 脚节点流向电容节点**（V_CC → R₁ → 7 脚 → R₂ → 6 脚 → C），
          二极管要在这条路径上导通，所以**阳极在 7 脚、阴极在电容端**。
          放电时电流方向相反（C → 6 脚 → R₂ → 7 脚 → 地），二极管截止 ✓
     → 充电时：电流经 R₁ 和二极管（绕过 R₂）→ 充电时间常数 = **R₁C**
     → 放电时：二极管截止，电流经 R₂ 放电 → 放电时间常数 = **R₂C**
     → 取 **R₁ = R₂ = R**：
          t_w1 = R·C·ln2, t_w2 = R·C·ln2
          → **q = 50%** ✓
          T = 2RC·ln2 ≈ 1.4RC

   **方法二：用 T' 触发器二分频**
     555 输出 → T' 触发器 → 输出
     → 每个脉冲使触发器翻转一次，高电平和低电平时间变得相等
     → **q = 50%**，但频率减半

   **方法三：用两个二极管 + 电位器**
     把充电路径和放电路径完全分开，用不同电阻控制
     → 占空比可以连续调节，甚至可以**小于 50%**
```

**7.** **三个 5 kΩ 电阻串联在 V_CC 和 GND 之间，起分压作用**，为两个比较器提供基准电压：
```
   上面两个电阻之间：**2V_CC/3**  → 接比较器 C₁ 的"−"端（对应 6 脚 TH）
   下面两个电阻之间：**V_CC/3**    → 接比较器 C₂ 的"+"端（对应 2 脚 TR'）
```
**由此确定的两个阈值：**
```
   **TH（6 脚）> 2V_CC/3 时**：比较器 C₁ 输出高 → 复位 SR 锁存器 → **输出低、放电管导通**
   **TR'（2 脚）< V_CC/3 时**：比较器 C₂ 输出高 → 置位 SR 锁存器 → **输出高、放电管截止**
```
**"555"这个型号名就来源于这三个 5 kΩ 电阻。**

**8.** 
- **4 脚是 R_D'（复位端），低电平有效**。为低电平时**强制输出为低**（优先级最高，不受其他输入影响）。
> **不使用时应接 V_CC（高电平），绝对不能悬空**——悬空时容易受干扰被拉低，导致电路误复位，使整个电路工作不稳定。这是最常见的实际接线错误。

- **5 脚是 CO（控制电压端）**。它直接连到内部两个 5 kΩ 电阻的分压点，**可以外接电压来改变两个比较器的基准电压**，从而改变触发电平：
  ```
   不接外部电压时：V_T+ = 2V_CC/3，V_T− = V_CC/3
   外接 V_CO 时：  V_T+ = V_CO，V_T− = V_CO/2
  ```
> **不使用时应接一个 0.01 μF 的电容到地**，用于滤除电源噪声和干扰，使触发电平稳定。若 5 脚悬空，触发电平会随电源波动而漂移。

**9.**
```
   T = 2·n·t_pd = 2 × 5 × 15 ns = 150 ns
   f = 1/T = 1/(150×10⁻⁹) = 6.67 × 10⁶ Hz = **6.67 MHz**
```
**答案**：振荡频率约为 **6.67 MHz**。

**为什么必须用奇数个反相器**：
```
   ① **奇数个反相器形成"反相"的环路**：设 G₁ 输入为 0，经过 n 个反相器
      （n 为奇数）后输出为 1，反馈回 G₁ 输入为 1，与假设的 0 矛盾
      → 状态不稳定 → 电路必然连续翻转 → **振荡** ✓
   
   ② **偶数个反相器形成"同相"的环路**：经过偶数级反相后输出与原输入相同，
      反馈回来后与原来的状态一致 → **电路稳定，不会振荡** ✗
```
**注意**：环形振荡器的周期公式是 **T = 2·n·t_pd**（**不是 n·t_pd**），因为一个完整周期需要信号绕环路**两周**。

**10.** **原因有三点：**
```
   ① **石英晶体的 Q 值极高**：可达 10⁴~10⁶，而 LC 回路的 Q 值只有几百，
      而 RC 振荡器根本没有高 Q 的谐振元件。
      Q 值越高，振荡频率越不容易受外界影响。

   ② **振荡频率由晶体的物理尺寸决定**：石英晶体利用**压电效应**，
      其串联谐振频率 f_s 由晶片的**几何尺寸和切割方式**决定。
      这些参数**几乎不受温度和电源电压的影响**（温度系数极小）。

   ③ **石英晶体在 f_s 处阻抗极低，其他频率阻抗极高**：
      电路被"锁定"在 f_s 上振荡，其他频率成分被强烈抑制，
      所以输出频率非常纯净、稳定。
```
**对比**：
```
   RC 振荡器的频率由 RC 时间常数决定，
   而 R 和 C 都随温度变化（电阻温度系数、电容介质损耗），
   且门电路的阈值电压也随电源电压变化
   → 稳定度只有 **10⁻² ~ 10⁻³**
   
   石英晶体振荡器的稳定度可达 **10⁻⁶ ~ 10⁻¹¹**（相差好几个数量级）
```
**所以**：**需要精确定时的场合（时钟、计时、通信基准）必须用石英晶体振荡器。**

**11.** **施密特触发电路的三个典型应用：**
```
   ① **波形变换**：把正弦波、三角波等周期信号变换成矩形波。
      只要输入信号的幅度超过 V_T+ 和 V_T−，输出就是规则的矩形波。

   ② **脉冲整形**：把边沿缓慢、带有噪声的不规则波形整形成陡直的矩形波。
      回差特性可以滤除幅度小于 ΔV_T 的噪声，消除输出的抖动。

   ③ **幅度鉴别**：从一串幅度不等的脉冲中，选出幅度足够大的脉冲。
      只有幅度超过 V_T+ 的脉冲才能使输出翻转，幅度不足的脉冲无效。
```
**其他应用**：**消除机械开关的抖动**、**构成多谐振荡电路**（在 7.4.4 中讲过）。

**12.**
**（1）C = 100 μF 时求 R**
```
   t_w = 1.1·R·C = 10 s
   R = 10 / (1.1 × 100×10⁻⁶)
     = 10 / (1.1×10⁻⁴)
     = 9.09 × 10⁴ Ω
     = **90.9 kΩ**
   取标准值 **91 kΩ**，验证：t_w = 1.1 × 91×10³ × 100×10⁻⁶ = 10.01 s ✓
```
**（2）R = 1 MΩ 时求 C**
```
   t_w = 1.1·R·C = 10 s
   C = 10 / (1.1 × 1×10⁶)
     = 10 / (1.1×10⁶)
     = 9.09 × 10⁻⁶ F
     = **9.09 μF**
   取标准值 **10 μF**，验证：t_w = 1.1 × 1×10⁶ × 10×10⁻⁶ = 11 s
   （略大，若需精确 10 s，可用 9.1 μF 或调整 R 为 909 kΩ）
```
**答案**：（1）C = 100 μF 时 **R ≈ 90.9 kΩ**（取 91 kΩ）；（2）R = 1 MΩ 时 **C ≈ 9.09 μF**（取 9.1 μF 可得到更精确的 10 s）。

**注意**：实际选用时还要考虑**电容的漏电流**（电解电容漏电大，会影响定时精度）。**若要求长时间精确延时（如 10 s 以上），推荐用较小的 C 和较大的 R**（例如 C = 1 μF、R = 9.1 MΩ），但 R 不宜超过 10 MΩ（否则漏电流影响显著）。**若要求高精度，应该用石英晶体振荡器 + 计数器方案，而不是 RC 定时。**
