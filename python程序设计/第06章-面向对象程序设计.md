## 6.1 概述

### 6.1.1 面向对象程序设计思路

**面向对象 = 把数据和操作数据的方法打包成一个整体（对象），用对象之间的协作来组织程序。**

| 对比项 | 面向过程 | 面向对象 |
|---|---|---|
| 组织单位 | **函数** | **类 / 对象** |
| 数据与操作 | 分离（数据传进函数） | **封装在一起** |
| 扩展方式 | 加函数、加分支 | 加类、继承、重写 |
| 适合 | 小工具、算法题 | 中大型系统、GUI、游戏 |

**三大特征**：

| 特征 | 含义 | Python 中的体现 |
|---|---|---|
| **封装** encapsulation | 把数据和方法包起来，隐藏内部细节 | 类、`_x`/`__x`、`@property` |
| **继承** inheritance | 子类复用并扩展父类 | `class Dog(Animal)` |
| **多态** polymorphism | 同一接口，不同实现 | 父类引用调用子类重写的方法 |

### 6.1.2 面向对象程序组成

```
类（class）      = 模板 / 图纸        →  Student
对象（object）   = 实例 / 具体产物    →  s1 = Student("张三", 92)
属性（attribute）= 对象的数据        →  s1.name, s1.score
方法（method）   = 对象的操作        →  s1.show()
```

**类比**：类是**月饼模具**，对象是用它压出来的**月饼**；一个模具可以压出无数个月饼，每个月饼的馅可以不同。

### 6.1.3 面向对象程序设计任务

1. **找名词** → 候选的类（学生、课程、订单、图书）。
2. **找动词** → 候选的方法（借书、还书、计算总价）。
3. **定属性** → 每个类需要记录什么数据。
4. **定关系** → 谁继承谁、谁包含谁（组合）。

## 6.2 类和对象

### 6.2.1 类定义

```python
class 类名:
    """类的文档字符串"""
    类属性 = 值

    def __init__(self, 参数):
        self.实例属性 = 参数

    def 方法名(self):
        ...
```

```python
class Student:
    """学生类"""
    school = "湖北大学"                 # 类属性：所有实例共享

    def __init__(self, name, score):
        self.name = name                # 实例属性：每个实例独有
        self.score = score

    def show(self):
        return f"{self.name} {self.score}"

s1 = Student("张三", 92)
s2 = Student("李四", 85)
print(s1.show(), s2.show())             # 张三 92 李四 85
print(s1.school, Student.school)        # 湖北大学 湖北大学
print(s1.__dict__)                      # {'name': '张三', 'score': 92}
print(Student.__doc__)                  # 学生类
print(Student.__name__)                 # Student
```

> **类名用大驼峰 `StudentInfo`，方法名用小写下划线 `get_name`** —— 这是 PEP 8 的约定，也是「一眼区分类和函数」的关键。

**`__init__` 是初始化方法，不是构造函数**：对象创建时自动调用，用来给实例属性赋初值。**它不能有返回值**（写 `return` 会报 `TypeError: __init__() should return None`）。

**`self` 是什么？** `self` 是**实例本身**的引用，由 Python 在调用时自动传入。

```python
s1.show()               # Python 实际执行的是 Student.show(s1)
print(Student.show(s1)) # 张三 92     两种写法等价
```

> **为什么必须写 `self`？** 因为一个类只有一个 `show` 函数对象，而它要服务于所有实例。`self` 就是「这次调用是哪个对象在调用我」的答案。**`self` 不是关键字，改成 `this` 语法也合法，但请一律用 `self`。**

### 6.2.2 对象创建和使用

```python
s = Student("王五", 78)     # 创建对象（自动调用 __init__）
print(s.name)               # 王五       访问属性
s.score = 88                # 修改属性
s.city = "武汉"              # 动态添加属性（Python 允许，但不推荐）
print(s.score, s.city)      # 88 武汉
del s.city                  # 删除属性
print(hasattr(s, "city"))   # False      判断属性是否存在
```

**属性检查的四个内置函数**：

| 函数 | 作用 | 例子 |
|---|---|---|
| `hasattr(obj, "x")` | 是否有属性/方法 | `hasattr(s, "name")` → `True` |
| `getattr(obj, "x", 默认)` | 取属性 | `getattr(s, "age", 0)` → `0` |
| `setattr(obj, "x", v)` | 设属性 | `setattr(s, "age", 18)` |
| `delattr(obj, "x")` | 删属性 | `delattr(s, "age")` |

## 6.3 类的成员

### 6.3.1 成员类型

| 成员类型 | 定义位置 | 归属 | 访问方式 |
|---|---|---|---|
| **实例属性** | `__init__` 里 `self.x = v` | 每个实例一份 | `obj.x` |
| **类属性** | 类体里直接赋值 | 整个类共享一份 | `obj.x` / `类名.x` |
| **实例方法** | `def m(self)` | 操作实例 | `obj.m()` |
| **类方法** | `@classmethod def m(cls)` | 操作类 | `obj.m()` / `类名.m()` |
| **静态方法** | `@staticmethod def m()` | 与实例无关的工具函数 | `obj.m()` / `类名.m()` |
| **私有成员** | `_x`（约定） / `__x`（名称改写） | 不建议外部访问 | 见下 |

**实例属性 vs 类属性（高频考点）**：

```python
class Dog:
    legs = 4                    # 类属性

    def __init__(self, name):
        self.name = name

d1 = Dog("旺财")
d2 = Dog("小黑")

d1.legs = 3                     # 给【实例】赋值 → 在 d1 上新建实例属性
print(d1.legs, d2.legs, Dog.legs)   # 3 4 4

Dog.legs = 5                    # 改【类】属性
print(d1.legs, d2.legs, Dog.legs)   # 3 5 5   ← d1 有自己的一份，不受影响
```

> **规则**：**读**属性时「先找实例，找不到再找类」；**写** `obj.x = v` 永远是**给实例新建/修改**，绝不会改到类属性。要改类属性必须写 `类名.x = v`。

**私有成员**：

```python
class Account:
    def __init__(self, balance):
        self.__balance = balance        # 双下划线开头 → 私有

    def get_balance(self):
        return self.__balance

a = Account(100)
print(a.get_balance())      # 100
print(a._Account__balance)  # 100     ← 名称改写后仍可访问，但强烈不建议
print("__balance" in a.__dict__)    # False   ← 字典里存的是 _Account__balance
```

| 写法 | 名称 | 外部能访问吗 | 说明 |
|---|---|---|---|
| `x` | 公开 | 能 | 正常成员 |
| `_x` | 单下划线 | 能 | **约定**：请勿直接访问（内部使用） |
| `__x` | 双下划线 | **不能直接访问** | 被改写成 `_类名__x` |
| `__x__` | 前后双下划线 | 能 | 系统保留（魔术方法），**不要自己造** |

> **注意**：Python 的「私有」是**名称改写（name mangling）**，不是强制访问控制。它只是防误用，不是安全机制。

### 6.3.2 内置成员

| 内置成员 | 含义 | 例子输出 |
|---|---|---|
| `__name__` | 类名 | `Student` |
| `__doc__` | 文档字符串 | `学生类` |
| `__dict__` | 属性字典 | `{'name': '张三', 'score': 92}` |
| `__module__` | 所在模块 | `__main__` |
| `__bases__` | 父类元组 | `(<class 'object'>,)` |
| `__class__` | 所属类 | `<class '__main__.Student'>` |

## 6.4 类的方法

### 6.4.1 方法类型

**三种方法对比（必背）：**

| 对比项 | 实例方法 | 类方法 `@classmethod` | 静态方法 `@staticmethod` |
|---|---|---|---|
| 第一个参数 | `self`（实例） | `cls`（类） | 无 |
| 装饰器 | 无 | `@classmethod` | `@staticmethod` |
| 能访问实例属性 | ✓ | ✗ | ✗ |
| 能访问类属性 | ✓ | ✓ | 需写类名 |
| 典型用途 | 操作对象数据 | **替代构造器**、工厂方法 | 工具函数、与类逻辑相关但独立 |

```python
class Circle:
    pi = 3.14159

    def __init__(self, r):
        self.r = r

    def area(self):                     # 实例方法
        return Circle.pi * self.r ** 2

    @classmethod
    def from_diameter(cls, d):          # 类方法：常用于"另一种构造方式"
        return cls(d / 2)

    @staticmethod
    def is_valid(r):                    # 静态方法：纯工具函数
        return r > 0

c = Circle.from_diameter(10)
print(c.r, round(c.area(), 2))          # 5.0 78.54
print(Circle.is_valid(-1))              # False
print(Circle.is_valid(3))               # True
```

> **为什么用类方法做「替代构造器」？** 因为 `cls` 会自动适配子类——`SubCircle.from_diameter(10)` 会返回 `SubCircle` 实例，而不是写死的 `Circle`。**用 `Circle(...)` 写死就失去了这个好处。**

### 6.4.2 属性

**`@property` 把方法变成「像属性一样访问」，从而在读取/赋值时插入校验逻辑。**

```python
class Temperature:
    def __init__(self, celsius=0):
        self._celsius = celsius

    @property
    def celsius(self):                  # getter
        return self._celsius

    @celsius.setter
    def celsius(self, v):               # setter：可以加校验
        if v < -273.15:
            raise ValueError("低于绝对零度")
        self._celsius = v

    @property
    def fahrenheit(self):               # 只读计算属性：没有 setter
        return self._celsius * 9 / 5 + 32

t = Temperature(25)
print(t.celsius, t.fahrenheit)          # 25 77.0
t.celsius = 30                          # 走 setter，不是直接赋值
print(t.celsius, t.fahrenheit)          # 30 86.0

t.celsius = -300
# ValueError: 低于绝对零度
```

**三个关键点**：

1. **getter 和 setter 必须同名**（都叫 `celsius`），setter 用 `@celsius.setter`。
2. **只定义 getter 就是只读属性**，赋值会报 `AttributeError: property 'fahrenheit' of 'Temperature' object has no setter`。
3. **`_celsius` 用单下划线**：内部真实存储，对外只暴露 `celsius` 属性。

> **与 Java 的对比**：Java 要写 `getCelsius()` / `setCelsius()` 并在调用处写括号；Python 用 `@property` 后，调用处写 `t.celsius`（无括号），更简洁。**先按属性访问写调用方代码，需要校验时再加 `@property`，接口不用改** —— 这是 Python 的推荐做法。

### 6.4.3 特殊方法

**特殊方法（魔术方法）以双下划线开头和结尾，由 Python 在特定语法下自动调用。** 它们让自定义对象「看起来像内置类型」。

| 特殊方法 | 触发时机 | 例子 |
|---|---|---|
| `__init__(self, …)` | 创建对象 | `Student("张三", 92)` |
| `__str__(self)` | `print(obj)`、`str(obj)` | 面向用户的可读文本 |
| `__repr__(self)` | 交互式显示、容器内显示 | 面向开发者的准确文本 |
| `__eq__(self, o)` | `obj == o` | 自定义「相等」 |
| `__lt__(self, o)` | `obj < o`，也让 `sorted` 可用 | 自定义排序规则 |
| `__add__(self, o)` | `obj + o` | 向量相加 |
| `__len__(self)` | `len(obj)` | 容器长度 |
| `__getitem__(self, i)` | `obj[i]` | 下标访问 |
| `__setitem__(self, i, v)` | `obj[i] = v` | 下标赋值 |
| `__contains__(self, x)` | `x in obj` | 成员判断 |
| `__call__(self, …)` | `obj(...)` | 让对象可调用 |
| `__del__(self)` | 对象被回收 | 析构（**不要依赖它**） |

```python
class Vector:
    def __init__(self, x, y):
        self.x, self.y = x, y

    def __str__(self):                  # print 用
        return f"Vector({self.x}, {self.y})"

    def __repr__(self):                 # 容器/交互式用
        return f"Vector({self.x!r}, {self.y!r})"

    def __add__(self, other):
        return Vector(self.x + other.x, self.y + other.y)

    def __eq__(self, other):
        return (self.x, self.y) == (other.x, other.y)

    def __abs__(self):
        return (self.x ** 2 + self.y ** 2) ** 0.5

    def __len__(self):
        return 2

    def __getitem__(self, i):
        return (self.x, self.y)[i]

    def __call__(self, k):              # 让对象像函数一样被调用
        return Vector(self.x * k, self.y * k)

v1, v2 = Vector(1, 2), Vector(3, 4)
print(v1)                   # Vector(1, 2)      ← __str__
print(v1 + v2)              # Vector(4, 6)      ← __add__
print(v1 == Vector(1, 2))   # True              ← __eq__
print(v1 == v2)             # False
print(abs(Vector(3, 4)))    # 5.0               ← __abs__
print(len(v1), v1[0], v1[1])    # 2 1 2         ← __len__ / __getitem__
print(v1(3))                # Vector(3, 6)      ← __call__
print([v1, v2])             # [Vector(1, 2), Vector(3, 4)]   ← 列表用 __repr__
```

> **`__str__` 与 `__repr__` 的区别（易错）**：`print(obj)` 用 `__str__`；但**把对象放进列表再打印列表，用的是 `__repr__`**（因为列表的 `__str__` 就是逐个调用元素的 `__repr__`）。所以两个都建议实现：`__str__` 给人看，`__repr__` 给调试看（最好是 `eval` 能重建对象的字符串）。

## 6.5 类的继承和多态

### 6.5.1 继承

**继承：子类自动拥有父类的属性和方法，并可扩展或重写。**

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return "..."

    def intro(self):
        return f"我是{self.name}，我说{self.speak()}"    # 调用 self.speak() → 多态

class Dog(Animal):                      # Dog 继承 Animal
    def __init__(self, name, breed):
        super().__init__(name)          # 调用父类构造器
        self.breed = breed

    def speak(self):                    # 重写（override）
        return "汪汪"

class Cat(Animal):
    def speak(self):
        return "喵喵"

for a in [Dog("旺财", "柴犬"), Cat("咪咪")]:
    print(a.intro())
# 我是旺财，我说汪汪
# 我是咪咪，我说喵喵
```

**`super()` 的两个作用**：

1. 调用父类的 `__init__`，**保证父类的初始化逻辑不被跳过**（漏掉会出现 `AttributeError`）。
2. 调用父类被重写的方法：`super().speak()`。

```python
print(Dog.__mro__)
# (<class '__main__.Dog'>, <class '__main__.Animal'>, <class 'object'>)
print(isinstance(Dog("d", "x"), Animal))    # True    是"是一个"关系
print(issubclass(Dog, Animal))              # True
print(issubclass(Animal, Dog))              # False
```

**关于 `object`**：Python 3 中所有类都隐式继承 `object`，所以 `class A:` 与 `class A(object):` 等价。

**多重继承与 MRO**：

```python
class A:
    def hi(self):
        return "A"
class B(A):
    def hi(self):
        return "B"
class C(A):
    def hi(self):
        return "C"
class D(B, C):              # 多继承
    pass

print(D().hi())                             # B
print([c.__name__ for c in D.__mro__])      # ['D', 'B', 'C', 'A', 'object']
```

> **MRO（Method Resolution Order）**：Python 用 **C3 线性化**算法算出一条父类查找顺序。`D(B, C)` 的顺序是 `D → B → C → A → object`，所以 `hi()` 找到 `B.hi`。**实践建议：能用单继承 + 组合就别用多继承**，多继承的 MRO 容易出乎意料。

### 6.5.2 多态

**多态：同一个方法调用，作用在不同对象上产生不同结果。** 实现条件是「**子类重写父类方法 + 父类引用指向子类对象**」。

```python
class Employee:
    def __init__(self, name, base):
        self.name, self.base = name, base

    def salary(self):                   # 父类接口
        return self.base

    def __str__(self):
        return f"{self.name}: {self.salary()}"

class Manager(Employee):
    def __init__(self, name, base, bonus):
        super().__init__(name, base)
        self.bonus = bonus

    def salary(self):                   # 重写
        return self.base + self.bonus

class Sales(Employee):
    def __init__(self, name, base, amount, rate=0.1):
        super().__init__(name, base)
        self.amount, self.rate = amount, rate

    def salary(self):
        return round(self.base + self.amount * self.rate, 2)

staff = [Employee("张三", 5000), Manager("李四", 8000, 3000), Sales("王五", 3000, 50000)]
for e in staff:
    print(e)
# 张三: 5000
# 李四: 11000
# 王五: 8000.0
print(sum(e.salary() for e in staff))   # 24000.0
```

> **注意 `8000.0` 和 `24000.0`**：`round()` 返回的是 **float**，所以 `Sales.salary()` 的结果是浮点数，求和后也成了 `24000.0`。要整数就 `int(round(...))`。
>
> **多态的价值**：`for e in staff: print(e)` 这一行代码**不需要知道每个对象的具体类型**，也不用写 `if 是经理…elif 是销售…`。以后新增 `Director` 类，这个循环一个字都不用改——**这就是「对扩展开放、对修改关闭」**。

**鸭子类型（duck typing）**：Python 不检查类型，只看对象**有没有那个方法**。

```python
class Duck:
    def speak(self):
        return "嘎嘎"
class Robot:
    def speak(self):
        return "滴滴"

def make_it_speak(obj):         # 不检查类型，只要有 speak() 就行
    return obj.speak()

print(make_it_speak(Duck()), make_it_speak(Robot()))    # 嘎嘎 滴滴
```

> 「如果它走起来像鸭子、叫起来像鸭子，那它就是鸭子。」Python 的多态**不依赖继承**，这比 Java 更灵活，但也意味着错误只能在运行时发现。

## 6.6 抽象类和抽象方法

**抽象类：不能实例化、只用来被继承的类。抽象方法：只声明不实现、强制子类必须实现的方法。**

```python
from abc import ABC, abstractmethod

class Shape(ABC):                       # 继承 ABC 就是抽象类
    @abstractmethod
    def area(self):                     # 抽象方法：没有实现
        pass

    def describe(self):                 # 普通方法可以有实现
        return f"面积是 {self.area():.2f}"

class Rect(Shape):
    def __init__(self, w, h):
        self.w, self.h = w, h

    def area(self):                     # 必须实现，否则 Rect 也无法实例化
        return self.w * self.h

print(Rect(3, 4).describe())            # 面积是 12.00

Shape()
# TypeError: Can't instantiate abstract class Shape without an implementation
#            for abstract method 'area'
```

**三个要点**：

1. 抽象类**可以有普通方法和属性**（`describe`），这些被子类继承。
2. 子类**必须实现全部抽象方法**，否则子类也是抽象的、不能实例化。
3. 抽象类的作用是**定义接口契约**：`describe` 里调用 `self.area()` 时，它确信子类一定实现了 `area`。

> **`ABC` 与 Java `abstract class` 的对比**：Python 的抽象是**运行时检查**（`Shape()` 时才报错），Java 是编译期检查。所以 Python 里写错要跑起来才知道。

## 6.7 典型案例——书籍出租管理系统

**需求**：图书有书号、书名、总册数；系统支持入库、借书、还书、查看可借数量。

```python
class Book:
    def __init__(self, bid, title, total):
        self.bid = bid
        self.title = title
        self.total = total
        self.borrowed = 0                   # 已借出册数

    @property
    def available(self):                    # 计算属性：可借 = 总数 - 已借
        return self.total - self.borrowed

    def __str__(self):
        return f"[{self.bid}] {self.title} 可借 {self.available}/{self.total}"


class Library:
    def __init__(self):
        self.books = {}                     # 书号 → Book 对象

    def add(self, book):
        self.books[book.bid] = book

    def borrow(self, bid):
        b = self.books.get(bid)
        if b is None:
            return "书号不存在"
        if b.available <= 0:
            return f"《{b.title}》已全部借出"
        b.borrowed += 1
        return f"借出《{b.title}》成功"

    def give_back(self, bid):
        b = self.books.get(bid)
        if b is None or b.borrowed <= 0:
            return "无法归还"
        b.borrowed -= 1
        return f"归还《{b.title}》成功"


lib = Library()
lib.add(Book("B01", "Python程序设计", 2))
lib.add(Book("B02", "数据结构", 1))

print(lib.borrow("B01"))    # 借出《Python程序设计》成功
print(lib.borrow("B01"))    # 借出《Python程序设计》成功
print(lib.borrow("B01"))    # 《Python程序设计》已全部借出
print(lib.give_back("B01")) # 归还《Python程序设计》成功
print(lib.borrow("B01"))    # 借出《Python程序设计》成功
print(lib.borrow("B99"))    # 书号不存在

for b in lib.books.values():
    print(b)
# [B01] Python程序设计 可借 0/2
# [B02] 数据结构 可借 1/1
```

**设计要点**：

| 设计决策 | 理由 |
|---|---|
| `Library.books` 用**字典**而不是列表 | 按书号查找是 **O(1)**，列表要 O(n) |
| `available` 用 `@property` 而不是存一个变量 | 避免「可借数」和「已借数」不同步的 bug |
| 借还逻辑写在 `Library` 而不是 `Book` | 借还涉及库存校验，属于「图书馆」的职责 |
| 失败时 `return` 提示字符串而不是抛异常 | 业务上「借不到」是正常情况，不是异常 |

**例 6.1**（题型：读程序写结果——类属性与实例属性）

```python
class Dog:
    legs = 4
    def __init__(self, name):
        self.name = name

d1 = Dog("旺财")
d2 = Dog("小黑")
d1.legs = 3
print(d1.legs, d2.legs, Dog.legs)
Dog.legs = 5
print(d1.legs, d2.legs, Dog.legs)
```

**解**：`d1.legs = 3` 是给**实例**新建属性，只影响 `d1`；`Dog.legs = 5` 改的是**类**属性，`d2` 没有自己的 `legs`，所以跟着变成 5，而 `d1` 已有自己的 3，不受影响。

**答案**：

```
3 4 4
3 5 5
```

**例 6.2**（题型：读程序写结果——私有属性与继承）

```python
class A:
    def __init__(self):
        self.__x = 1
    def get(self):
        return self.__x
    def show(self):
        return "A"

class B(A):
    def __init__(self):
        super().__init__()
        self.__x = 2
    def show(self):
        return "B" + super().show()

b = B()
print(b.get(), b.show(), b._A__x, b._B__x)
```

**解**：`__x` 会被名称改写成 `_类名__x`，所以父类的 `self.__x` 是 `_A__x`，子类的 `self.__x` 是 `_B__x`——**两者互不影响**。`b.get()` 是父类方法，读的是 `_A__x = 1`。`b.show()` 先返回 `"B"` 再拼接 `super().show()` 的 `"A"`。

**答案**：`1 BA 1 2`

**例 6.3**（题型：编程题——property 与类方法）

定义 `Circle` 类：用半径构造，提供**只读**属性 `area`、类方法 `from_diameter`（按直径构造）、静态方法 `is_valid`（判断半径是否合法）。

```python
class Circle:
    pi = 3.14159

    def __init__(self, r):
        self.r = r

    @property
    def area(self):                     # 只读属性
        return Circle.pi * self.r ** 2

    @classmethod
    def from_diameter(cls, d):
        return cls(d / 2)

    @staticmethod
    def is_valid(r):
        return r > 0

c = Circle.from_diameter(10)
print(c.r, round(c.area, 2))            # 5.0 78.54
print(Circle.is_valid(-1))              # False
print(round(Circle(2).area, 2))         # 12.57
```

**解**：`@property` 让 `c.area` 无需括号；`@classmethod` 用 `cls` 而不是写死 `Circle`，子类调用也正确；`@staticmethod` 与实例无关，只是逻辑上属于这个类。

**答案**：`5.0 78.54`、`False`、`12.57`。

**例 6.4**（题型：编程题——特殊方法）

为 `Student` 类实现 `__str__`、`__repr__`、`__eq__`、`__lt__`，使对象能被 `print`、能比较相等、能直接 `sorted`（按分数从高到低）。

```python
class Student:
    def __init__(self, name, score):
        self.name, self.score = name, score

    def __str__(self):
        return f"{self.name}({self.score})"

    def __repr__(self):
        return f"Student({self.name!r}, {self.score})"

    def __eq__(self, other):
        return self.score == other.score

    def __lt__(self, other):            # 分数高的"小于"分数低的 → 降序
        return self.score > other.score

ss = [Student("张三", 92), Student("李四", 85), Student("王五", 95)]
print([str(s) for s in sorted(ss)])     # ['王五(95)', '张三(92)', '李四(85)']
print(sorted(ss))                       # [Student('王五', 95), Student('张三', 92), Student('李四', 85)]
print(ss[0] == Student("x", 92))        # True
print(ss[0] == ss[1])                   # False
```

**解**：`sorted` 只要求实现 `__lt__`。**注意打印列表用的是 `__repr__` 而不是 `__str__`** —— 所以第二行输出的是 `Student('王五', 95)` 这种形式，要用 `__str__` 得显式 `str(s)`。

**答案**：见注释。**实现 `__eq__` 后对象按「值」比较，不再按「身份」比较。**

**例 6.5**（题型：编程题——继承与多态）

设计员工工资体系：普通员工拿底薪，经理拿底薪 + 津贴，销售拿底薪 + 提成。用多态计算总工资。

```python
class Employee:
    def __init__(self, name, base):
        self.name, self.base = name, base

    def salary(self):
        return self.base

    def __str__(self):
        return f"{self.name}: {self.salary()}"

class Manager(Employee):
    def __init__(self, name, base, bonus):
        super().__init__(name, base)
        self.bonus = bonus

    def salary(self):
        return self.base + self.bonus

class Sales(Employee):
    def __init__(self, name, base, amount, rate=0.1):
        super().__init__(name, base)
        self.amount, self.rate = amount, rate

    def salary(self):
        return round(self.base + self.amount * self.rate, 2)

staff = [Employee("张三", 5000), Manager("李四", 8000, 3000), Sales("王五", 3000, 50000)]
for e in staff:
    print(e)
print(sum(e.salary() for e in staff))
```

**解**：`super().__init__(name, base)` 复用父类初始化，避免重复写 `self.name = name`。`for e in staff` 循环里调用 `e.salary()` 时，Python 按**实际对象类型**查找方法，这就是多态。

**答案**：

```
张三: 5000
李四: 11000
王五: 8000.0
24000.0
```

（`8000.0` 是因为 `round()` 返回 float；要整数写 `int(round(...))`。）

**例 6.6**（题型：编程题——抽象类与多态排序）

用抽象类 `Shape` 派生圆、矩形、三角形，实现 `area()`，并让它们**能直接排序**、输出总面积。

```python
import math
from abc import ABC, abstractmethod

class Shape(ABC):
    def __init__(self, name):
        self.name = name

    @abstractmethod
    def area(self): ...

    def __str__(self):
        return f"{self.name}: {self.area():.2f}"

    def __lt__(self, other):                # 让 sorted 可用
        return self.area() < other.area()

class Circ(Shape):
    def __init__(self, r):
        super().__init__("圆")
        self.r = r
    def area(self):
        return math.pi * self.r ** 2

class Rect(Shape):
    def __init__(self, w, h):
        super().__init__("矩形")
        self.w, self.h = w, h
    def area(self):
        return self.w * self.h

class Tri(Shape):
    def __init__(self, a, b, c):
        super().__init__("三角形")
        self.a, self.b, self.c = a, b, c
    def area(self):                         # 海伦公式
        s = (self.a + self.b + self.c) / 2
        return math.sqrt(s * (s - self.a) * (s - self.b) * (s - self.c))

shapes = [Circ(1), Rect(3, 4), Tri(3, 4, 5)]
for s in sorted(shapes, reverse=True):
    print(s)
print(f"{sum(s.area() for s in shapes):.2f}")
```

**解**：抽象类定义统一接口 `area`；`__lt__` 比较面积使 `sorted` 可用；`__str__` 里的 `{self.area():.2f}` 让每个子类输出自己的面积。三角形用**海伦公式**（已知三边求面积）。

**答案**：

```
矩形: 12.00
三角形: 6.00
圆: 3.14
21.14
```

**例 6.7**（题型：编程题——封装与自定义异常）

实现 `BankAccount` 类：余额私有，存款必须为正数，取款不能超额；超额时抛自定义异常 `InsufficientError`。

```python
class InsufficientError(Exception):
    pass

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance

    @property
    def balance(self):
        return self.__balance

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款必须为正数")
        self.__balance += amount
        return self.__balance

    def withdraw(self, amount):
        if amount > self.__balance:
            raise InsufficientError(f"余额不足：当前 {self.__balance}")
        self.__balance -= amount
        return self.__balance

acc = BankAccount("张三", 100)
print(acc.deposit(50), acc.withdraw(30))    # 150 120
try:
    acc.withdraw(1000)
except InsufficientError as e:
    print("异常：", e)                        # 异常： 余额不足：当前 120
print(acc.balance)                          # 120
```

**解**：`__balance` 私有，外部只能通过 `balance` 只读属性查看，**防止直接改余额**。校验失败用**异常**而不是返回错误码，调用方可以用 `try/except` 集中处理。自定义异常继承 `Exception` 即可。

**答案**：`150 120`；捕获到 `余额不足：当前 120`；最终余额 `120`。

## 易错点提醒

1. **定义实例方法时忘了写 `self`。**
   - 错在哪：`def show():` 后调用 `s.show()` → `TypeError: show() takes 0 positional arguments but 1 was given`。
   - 正确做法：实例方法第一个参数必须是 `self`（名字可以改，但别改）。
2. **`__init__` 里写 `return`。**
   - 错在哪：`TypeError: __init__() should return None, not 'int'`。
   - 正确做法：`__init__` 只负责初始化，不返回任何值。
3. **以为 `obj.类属性 = v` 会改到类属性。**
   - 错在哪：这只在实例上新建同名属性，其它实例和类本身都不变。
   - 正确做法：要改类属性写 `类名.属性 = v`。
4. **子类 `__init__` 忘了调 `super().__init__()`。**
   - 错在哪：父类定义的实例属性不存在，调用父类方法时 `AttributeError`。
   - 正确做法：子类 `__init__` 第一句就写 `super().__init__(父类参数)`。
5. **以为 `__str__` 在所有场合都生效。**
   - 错在哪：`print([obj1, obj2])` 打印的是 `__repr__` 的结果，看起来像 `<__main__.Student object at 0x...>`。
   - 正确做法：同时实现 `__repr__`；调试输出用 `f"{obj!r}"`。
6. **`@property` 的 getter 和 setter 名字不一致。**
   - 错在哪：`AttributeError: property 'x' of 'X' object has no setter`，或 setter 根本没被调用。
   - 正确做法：setter 必须写成 `@getter同名.setter`。
7. **把 `@classmethod` 和 `@staticmethod` 混用。**
   - 错在哪：静态方法里写 `cls` → `NameError`；类方法里想访问实例属性 → `AttributeError`。
   - 正确做法：需要类（如做替代构造器）用 `@classmethod`；完全独立用 `@staticmethod`。
8. **多继承顺序写反。**
   - 错在哪：`D(B, C)` 与 `D(C, B)` 的 MRO 不同，重名方法解析结果不同。
   - 正确做法：`print(D.__mro__)` 确认查找顺序；能用单继承就别用多继承。
9. **抽象类里忘写 `@abstractmethod`。**
   - 错在哪：方法变成了普通空方法，子类不实现也能实例化，接口约束失效。
   - 正确做法：抽象方法必须加 `@abstractmethod` 装饰器，且类要继承 `ABC`。
10. **依赖 `__del__` 做资源清理。**
    - 错在哪：对象回收时机不确定（循环引用、解释器退出时不保证调用），文件句柄/连接可能泄漏。
    - 正确做法：用 `with` 上下文管理器（`__enter__`/`__exit__`）或显式 `close()`。

## 本章小结

- **类是模板，对象是实例**；`self` 是实例本身，由 Python 自动传入，所以 `s.show()` 等价于 `Student.show(s)`。
- **实例属性归对象，类属性归类**：读时「先实例后类」，`obj.x = v` 只影响该实例；改类属性要写 `类名.x = v`。
- `_x` 是**约定私有**，`__x` 会被**名称改写**成 `_类名__x` —— 是防误用，不是安全机制。
- 三种方法：**实例方法（`self`）/ 类方法（`cls`，常做替代构造器）/ 静态方法（无参数，工具函数）**。
- **`@property` 把方法变成属性访问**，getter/setter 同名，只写 getter 就是只读属性。
- **特殊方法让自定义对象支持内置语法**：`__str__`/`__repr__`（打印）、`__eq__`/`__lt__`（比较与排序）、`__add__`（运算）、`__len__`/`__getitem__`（容器）、`__call__`（可调用）。
- **`print` 列表用 `__repr__`**，`print` 单个对象用 `__str__` —— 两个都实现最稳。
- **继承用 `super().__init__()`** 复用父类初始化；`__mro__` 决定多继承的查找顺序。
- **多态 = 子类重写 + 父类引用指向子类对象**，让调用方不必写 `if 类型…`，新增子类不改老代码。
- **抽象类（`ABC` + `@abstractmethod`）不能实例化**，用来强制子类实现接口；Python 还支持更灵活的**鸭子类型**。

> **一句话记住本章**：类是图纸对象是月饼，`self` 是实例自己，类属性共享实例属性独有，双下划线靠改名私有，`super()` 接父类，重写加多态让循环不用改。

7. 子类 `__init__` 里为什么必须调用 `super().__init__(...)`？
8. 多态的实现条件是什么？用一句话说明它的好处。
9. `D(B, C)` 中 `B`、`C` 都定义了 `hi()`，`D().hi()` 调用的是哪一个？怎么确认？
10. 抽象类能实例化吗？子类不实现抽象方法会怎样？

**参考答案**

1. `self` 是**当前实例本身**的引用，由 Python 在调用时自动传入。`s.show()` 等价于 `Student.show(s)`。
2. 实例属性属于**每个对象**，类属性属于**类**，所有实例共享。`obj.x = 1` **不会**改变类属性，它只是在该实例上新建/修改一个同名实例属性。
3. 存成 `_Account__balance`。这叫**名称改写（name mangling）**，用于避免子类意外覆盖父类的私有成员。
4. 实例方法：无装饰器，第一参数 `self`；类方法：`@classmethod`，第一参数 `cls`；静态方法：`@staticmethod`，无特殊第一参数。
5. 把方法包装成「属性式访问」，可在读取和赋值时插入逻辑（校验、计算、只读保护）。只定义 getter 时属性**只读**，赋值会抛 `AttributeError: ... has no setter`。
6. `print(obj)` 用 `__str__`；`print([obj])` 打印容器，容器用元素的 `__repr__`。
7. 因为父类的实例属性是在父类 `__init__` 里创建的，不调用就不会存在，之后调用父类方法会 `AttributeError`。
8. 条件：**子类重写父类方法 + 父类引用（或统一接口）指向子类对象**。好处：调用方无需判断具体类型，新增子类时老代码不用修改。
9. 调用 `B.hi()`（按 MRO 顺序 `D → B → C → A → object` 找到第一个）。用 `print(D.__mro__)` 确认。
10. 抽象类**不能实例化**（`TypeError: Can't instantiate abstract class ...`）。子类若不实现全部抽象方法，它本身也仍是抽象类，同样不能实例化。
