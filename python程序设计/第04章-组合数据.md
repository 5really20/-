## 4.1 概述

**Python 的组合数据类型按「数据组织方式」分成三类：**

| 类别 | 说明 | 代表 |
|---|---|---|
| **序列** sequence | 元素**有序**、可用整数下标访问 | `str`、`list`、`tuple`、`range` |
| **映射** mapping | 键值对，用**键**访问 | `dict` |
| **集合** set | **无序**、元素**唯一** | `set`、`frozenset` |

### 四件套对比表（必背）

| 维度 | 列表 list | 元组 tuple | 字典 dict | 集合 set |
|---|---|---|---|---|
| 写法 | `[1, 2, 3]` | `(1, 2, 3)` | `{"a": 1}` | `{1, 2, 3}` |
| 可变性 | **可变** | **不可变** | **可变** | **可变** |
| 有序性 | 有序（有下标） | 有序（有下标） | 3.7+ 按插入顺序 | **无序** |
| 元素要求 | 任意对象 | 任意对象 | 键必须**可哈希** | 元素必须**可哈希** |
| 能否重复 | 能 | 能 | 键唯一 | **自动去重** |
| 查找复杂度 | O(n) | O(n) | **O(1)** | **O(1)** |
| 典型场景 | 有序数据集合、堆栈 | 固定记录、多返回值 | 映射关系、计数统计 | 去重、成员判断 |

```python
lst = [1, 2, 2, 3]          # 列表：允许重复
tup = (1, 2, 2, 3)          # 元组：允许重复
dic = {"a": 1, "b": 2}      # 字典：键唯一
st = {1, 2, 2, 3}           # 集合：自动去重
print(lst, tup, dic, st)    # [1, 2, 2, 3] (1, 2, 2, 3) {'a': 1, 'b': 2} {1, 2, 3}
print(len(st))              # 3
```

> **为什么字典和集合查找是 O(1)？** 它们内部是**哈希表**：用 `hash(键)` 直接算出存储位置，一次定位，无需逐个比较。代价是**键必须是可哈希的（hashable）**，所以 `{[1,2]: "x"}` 会报 `TypeError: unhashable type: 'list'`。
>
> ⚠️ **「可哈希」与「不可变」是相关但不等价的两个概念**，两个方向都有反例：
>
> | 方向 | 反例 | 说明 |
> |---|---|---|
> | 不可变，却**不可哈希** | `hash((1, [2, 3]))` → `TypeError` | 元组本身不可变，但里面套了列表 |
> | 可变，却**可哈希** | 自定义类实例 | 默认按 `id` 算哈希，改属性后仍是合法键 |
>
> ```python
> class Point:
>     def __init__(self): self.x = 1
>
> p = Point()
> print(isinstance(hash(p), int))   # True   自定义类实例默认可哈希（按 id）
> p.x = 999                         # 改成可变状态后……
> print({p: "v"}[p])                # v      仍然能当键，查找成功
> ```
>
> 准确说法：**「可哈希」要求「哈希值在对象存活期间不变、且相等的对象哈希值相等」**。不可变类型天然满足，所以常用不可变类型当键；但一个对象只要不重写 `__eq__`/`__hash__`，即使属性可变也照样可哈希。

## 4.2 列表

### 列表创建

```python
a = [1, 2, 3]                   # 字面量
b = []                          # 空列表
c = list("abc")                 # ['a', 'b', 'c']
d = list(range(5))              # [0, 1, 2, 3, 4]
e = [0] * 5                     # [0, 0, 0, 0, 0]
f = [i ** 2 for i in range(5)]  # [0, 1, 4, 9, 16]  列表推导式
g = [1, "a", 3.5, [2, 3]]       # 元素类型可以不同（与 C 数组最大区别）
print(a, b, c, d, e, f, g)
```

> **与 C 的对比**：C 的数组**长度固定、元素类型必须相同**；Python 列表**长度可变、元素类型随意**，本质是「动态数组 + 存的是对象引用」。

### 列表访问

```python
lst = [10, 20, 30, 40, 50]
print(lst[0], lst[-1])      # 10 50
print(lst[1:3])             # [20, 30]   左闭右开
print(lst[::2])             # [10, 30, 50]
print(lst[::-1])            # [50, 40, 30, 20, 10]  反转（返回新列表）
print(lst[10:20])           # []         切片越界不报错
print(lst[10])              # IndexError: list index out of range

lst[0] = 100                # 列表可以改元素
print(lst)                  # [100, 20, 30, 40, 50]

# 切片赋值：可以改变长度！
lst[1:3] = [200, 300, 400]
print(lst)                  # [100, 200, 300, 400, 40, 50]
lst[1:3] = []               # 删除切片
print(lst)                  # [100, 400, 40, 50]
```

**切片的高级用法**：

```python
a = [0, 1, 2, 3, 4, 5]
print(a[1:4])       # [1, 2, 3]
print(a[:3])        # [0, 1, 2]
print(a[3:])        # [3, 4, 5]
print(a[-3:])       # [3, 4, 5]     最后三个
print(a[:-1])       # [0, 1, 2, 3, 4]  去掉最后一个
print(a[::-1])      # [5, 4, 3, 2, 1, 0]  反转
print(a[5:1:-1])    # [5, 4, 3, 2]  倒着切片
print(a[::2])       # [0, 2, 4]
```

### 列表复制和删除

**先分清「别名」「浅拷贝」「深拷贝」——这是本章第一个大坑。**

```python
import copy

a = [1, 2, [3, 4]]

b = a                   # 别名：同一个对象
c = a[:]                # 浅拷贝
d = a.copy()            # 浅拷贝（同 a[:]）
e = list(a)             # 浅拷贝
f = copy.deepcopy(a)    # 深拷贝

a[0] = 99
a[2].append(5)          # 修改内层列表
print(a)    # [99, 2, [3, 4, 5]]
print(b)    # [99, 2, [3, 4, 5]]   ← 别名：全跟着变
print(c)    # [1, 2, [3, 4, 5]]    ← 浅拷贝：外层没变，内层跟着变！
print(d)    # [1, 2, [3, 4, 5]]
print(f)    # [1, 2, [3, 4]]       ← 深拷贝：完全独立
```

| 方式 | 语法 | 外层独立 | 内层独立 |
|---|---|---|---|
| 别名 | `b = a` | ✗ | ✗ |
| 浅拷贝 | `a.copy()` / `a[:]` / `list(a)` | ✓ | ✗ |
| 深拷贝 | `copy.deepcopy(a)` | ✓ | ✓ |

**删除的四种方式**：

```python
lst = [1, 2, 3, 4, 5]
del lst[0]              # 按【下标】删除
print(lst)              # [2, 3, 4, 5]

lst.remove(3)           # 按【值】删除第一个匹配项，值不存在报 ValueError
print(lst)              # [2, 4, 5]

x = lst.pop()           # 弹出【末尾】并返回
print(x, lst)           # 5 [2, 4]
y = lst.pop(0)          # 弹出【指定下标】
print(y, lst)           # 2 [4]

lst.clear()             # 清空
print(lst)              # []

del lst                 # 删除变量本身
```

> **坑**：`lst.pop(10)` → `IndexError`；`lst.remove(99)`（不存在）→ `ValueError`；`lst.remove()` 少了参数 → `TypeError`。三者异常类型不同，选择题常考。

### 列表运算

| 运算 | 含义 | 例子 | 结果 |
|---|---|---|---|
| `+` | 拼接（**新建列表**） | `[1,2] + [3]` | `[1, 2, 3]` |
| `*` | 重复 | `[0] * 3` | `[0, 0, 0]` |
| `in` | 成员判断 | `3 in [1,2,3]` | `True` |
| `==` | 逐元素比值 | `[1,2] == [1,2]` | `True` |
| `+=` | **原地扩展**（等价 extend） | `a += [3]` | 原列表被改 |

```python
a = [1, 2]
b = a + [3]
print(a, b)         # [1, 2] [1, 2, 3]   a 没变

c = [1, 2]
c += [3]            # 等价 c.extend([3])，原地改
print(c)            # [1, 2, 3]

print([1, 2] * 2)   # [1, 2, 1, 2]
print(2 in [1, 2, 3])       # True
print([1, 2] < [1, 3])      # True   逐元素比较
```

### 列表统计

```python
nums = [3, 1, 4, 1, 5, 9, 2, 6]
print(len(nums))        # 8
print(max(nums), min(nums))     # 9 1
print(sum(nums))        # 31
print(sum(nums) / len(nums))    # 3.875   平均值
print(nums.count(1))    # 2       统计出现次数
print(nums.index(4))    # 2       第一个匹配项的下标；不存在报 ValueError
```

### 列表元素查找和排序

**列表方法总表（11 个，必背）**：

| 方法 | 作用 | 返回值 | 是否原地改 |
|---|---|---|---|
| `append(x)` | 末尾追加**一个**元素 | `None` | ✓ |
| `extend(iter)` | 末尾追加**一批**元素 | `None` | ✓ |
| `insert(i, x)` | 在下标 i 处插入 | `None` | ✓ |
| `remove(x)` | 删除第一个值为 x 的元素 | `None` | ✓ |
| `pop([i])` | 弹出并返回元素（默认末尾） | 被弹出的元素 | ✓ |
| `clear()` | 清空 | `None` | ✓ |
| `index(x)` | 查找下标 | 下标 | ✗ |
| `count(x)` | 统计个数 | 个数 | ✗ |
| `sort(key, reverse)` | 排序 | **`None`** | ✓ |
| `reverse()` | 反转 | `None` | ✓ |
| `copy()` | 浅拷贝 | 新列表 | ✗ |

```python
lst = [3, 1, 4]
lst.append(5)           # [3, 1, 4, 5]
lst.extend([6, 7])      # [3, 1, 4, 5, 6, 7]
lst.insert(0, 0)        # [0, 3, 1, 4, 5, 6, 7]
print(lst)
```

**`sort()` 与 `sorted()` 的区别（高频考点）**：

| 对比项 | `lst.sort()` | `sorted(lst)` |
|---|---|---|
| 作用对象 | **只能是列表** | **任意可迭代对象** |
| 是否改变原对象 | **原地排序，改变** | 不改，**返回新列表** |
| 返回值 | **`None`** | 排好序的新列表 |
| 适用 | `lst = [...]` 后直接排 | `sorted("cba")`、`sorted(dict)` |

```python
nums = [3, 1, 4, 1, 5]
result = nums.sort()
print(result)       # None   ← 坑！sort() 返回 None
print(nums)         # [1, 1, 3, 4, 5]

nums2 = [3, 1, 4]
new = sorted(nums2)
print(new, nums2)   # [1, 3, 4] [3, 1, 4]   sorted 不动原列表

print(sorted([3, 1, 2], reverse=True))      # [3, 2, 1]
print(sorted("cba"))                        # ['a', 'b', 'c']
print(sorted([3, 1, 2], key=abs))           # [1, 2, 3]
```

> **致命坑**：`nums = nums.sort()` 会让 `nums` 变成 `None`，接下来 `len(nums)` 直接 `TypeError`。要原地排序写 `nums.sort()`（不接收返回值），要新列表写 `nums = sorted(nums)`。

**`key` 参数：指定「按什么排序」**

```python
words = ["banana", "Apple", "cherry", "date"]
print(sorted(words))                        # ['Apple', 'banana', 'cherry', 'date']  大写字母排前面
print(sorted(words, key=str.lower))         # 忽略大小写
print(sorted(words, key=len))               # ['date', 'Apple', 'banana', 'cherry']  按长度

students = [("张三", 92, 18), ("李四", 85, 20), ("王五", 92, 19)]
print(sorted(students, key=lambda s: s[1]))             # 按成绩升序
print(sorted(students, key=lambda s: (-s[1], s[2])))    # 成绩降序，同龄按年龄升序
# [('张三', 92, 18), ('王五', 92, 19), ('李四', 85, 20)]

# 字典排序
scores = {"张三": 92, "李四": 85, "王五": 78}
print(sorted(scores.items(), key=lambda kv: kv[1], reverse=True))
# [('张三', 92), ('李四', 85), ('王五', 78)]
print(dict(sorted(scores.items(), key=lambda kv: kv[1])))   # 按值排序后重建字典
```

> **为什么 `key=lambda s: s[1]` 里不用写 `s.sort()`？** 因为 `sort`/`sorted` 会把每个元素传给 `key` 函数，用它的返回值作为比较依据。**注意 `key` 只调用一次／元素（不是每次比较都调用），所以效率很高。**

## 4.3 元组

### 元组创建

```python
t1 = (1, 2, 3)
t2 = 1, 2, 3                # 括号可省
t3 = ()                     # 空元组
t4 = (5,)                   # 单元素必须有逗号！
t5 = tuple([1, 2, 3])       # 从列表转
t6 = tuple("abc")           # ('a', 'b', 'c')

print(type(t2))             # <class 'tuple'>
print(type((5)))            # <class 'int'>  ← 坑！(5) 只是加括号的 5
print(type(t4))             # <class 'tuple'>
print(t5, t6)               # (1, 2, 3) ('a', 'b', 'c')
```

> **坑**：`t = (5)` 得到的是 `int`，`t = (5,)` 才是元组。**单元素元组的逗号不能省。**

### 元组访问

```python
t = (10, 20, 30, 40)
print(t[0], t[-1])      # 10 40
print(t[1:3])           # (20, 30)  切片返回的仍是元组
print(t[::-1])          # (40, 30, 20, 10)
print(20 in t)          # True
t[0] = 1                # TypeError: 'tuple' object does not support item assignment
```

**元组的「不可变」只到第一层**：

```python
t = (1, [2, 3])
t[1].append(4)          # 合法！元组里的列表本身可以改
print(t)                # (1, [2, 3, 4])
t[1] = [9]              # TypeError：不能换掉元组里的引用
```

### 元组复制和删除

```python
t = (1, 2, 3)
u = t                   # 元组不可变，无需拷贝——直接指向同一个对象就绝对安全
print(t is u)           # True

del t                   # 只能删除整个元组变量，不能删元素
# del t[0]              # TypeError: 'tuple' object doesn't support item deletion
```

### 元组运算

| 运算 | 例子 | 结果 |
|---|---|---|
| `+` | `(1,2) + (3,)` | `(1, 2, 3)` |
| `*` | `(1,) * 3` | `(1, 1, 1)` |
| `in` | `2 in (1,2)` | `True` |
| 解包 | `a, b = (1, 2)` | `a=1, b=2` |

```python
print((1, 2) + (3,))        # (1, 2, 3)
print((1,) * 3)             # (1, 1, 1)

# 解包（最重要的用法）
point = (3, 5)
x, y = point
print(x, y)                 # 3 5

first, *rest = (1, 2, 3, 4)
print(first, rest)          # 1 [2, 3, 4]   ← 注意 *rest 得到的是【列表】

a, b = 1, 2
a, b = b, a                 # 交换本质是元组解包
print(a, b)                 # 2 1
```

> **元组的三大优势**：① 比列表**更快、更省内存**；② **可哈希，能作字典的键或集合的元素**；③ 作为「不会变的记录」表达意图更清晰（如坐标 `(x, y)`）。
>
> ```python
> loc = {(0, 0): "原点", (1, 2): "点A"}     # 元组作键，合法
> # d = {[0, 0]: "原点"}                    # 列表作键 → TypeError: unhashable type: 'list'
> ```
>
> ⚠️ 第 ② 条有**前提**：**只有元素全部可哈希，元组才可哈希**。元组里只要套了一个列表，它立刻变成不可哈希——这正是上一节 `t = (1, [2, 3])` 那个例子的后果：
>
> ```python
> print(hash((1, 2, 3)))     # 529344067295497451   可哈希
> t = (1, [2, 3])            # 元组里套了列表
> print(hash(t))             # TypeError: unhashable type: 'list'
> print({(1, [2]): "x"})     # TypeError: unhashable type: 'list'
> ```
>
> 一句话：**「元组不可变」只到第一层，所以「元组能当键」也只到第一层**。

### 元组统计

```python
t = (3, 1, 4, 1, 5)
print(len(t), max(t), min(t), sum(t))   # 5 5 1 14
print(t.count(1), t.index(4))           # 2 2
```

**元组只有两个方法：`count()` 和 `index()`**（因为不可变，没有增删改的方法）。

**函数返回多个值，本质就是返回元组**（第 5 章详述）：

```python
def min_max(nums):
    return min(nums), max(nums)         # 实际返回 (1, 9)

lo, hi = min_max([3, 1, 9, 5])
print(lo, hi)                           # 1 9
print(min_max([3, 1, 9, 5]))            # (1, 9)
```

## 4.4 字典

### 字典创建

```python
d1 = {"name": "张三", "age": 18}
d2 = dict(name="张三", age=18)              # 关键字形式，键会自动变字符串
d3 = dict([("a", 1), ("b", 2)])             # 从键值对序列
d4 = dict(zip(["a", "b"], [1, 2]))          # 与 zip 配合
d5 = {}.fromkeys(["a", "b"], 0)             # {'a': 0, 'b': 0}
d6 = {}                                     # 空字典
d7 = {x: x ** 2 for x in range(3)}          # {0: 0, 1: 1, 2: 4}  字典推导式
print(d1, d2, d3, d4, d5, d7)
```

> **坑**：`{}` 是**空字典**，不是空集合！空集合必须写 `set()`。

**字典的键必须可哈希**（注意：可哈希 ≠ 不可变，见 4.1 末尾的说明）：

```python
ok = {1: "a", "b": 2, (1, 2): "c", True: "d"}    # 合法
# bad = {[1, 2]: "x"}      # TypeError: unhashable type: 'list'

# 注意 True 和 1 哈希值相同，会互相覆盖！
d = {1: "int", True: "bool"}
print(d)            # {1: 'bool'}   ← True 把 1 的值覆盖了
print(len(d))       # 1
```

### 字典操作（增删改查）

| 操作 | 语法 | 说明 |
|---|---|---|
| 查 | `d[k]` | 键不存在 → **`KeyError`** |
| 查（安全） | `d.get(k, default)` | 不存在返回 `default`（默认 `None`） |
| 查（带默认写入） | `d.setdefault(k, default)` | 不存在则**插入**并返回默认值 |
| 增/改 | `d[k] = v` | 键存在就改，不存在就加 |
| 删 | `del d[k]` / `d.pop(k)` | 键不存在 → `KeyError` |
| 删（安全） | `d.pop(k, default)` | 不存在返回默认值 |
| 删最后一个 | `d.popitem()` | 返回 `(k, v)` |
| 合并 | `d.update(d2)` | 用 d2 覆盖更新 d |
| 清空 | `d.clear()` | —— |

```python
d = {"name": "张三", "age": 18}
print(d["name"])                # 张三
print(d.get("score"))           # None     键不存在，不报错
print(d.get("score", 0))        # 0        指定默认值
print(d.setdefault("score", 60))    # 60    顺便插入
print(d)                        # {'name': '张三', 'age': 18, 'score': 60}

d["age"] = 19                   # 改
d["city"] = "武汉"               # 增
print(d)                        # {'name': '张三', 'age': 19, 'score': 60, 'city': '武汉'}

del d["city"]
x = d.pop("score")
print(x, d)                     # 60 {'name': '张三', 'age': 19}
print(d.pop("不存在", "默认值"))  # 默认值
```

> **`get` 与 `setdefault` 的分工**：`get` 只读不写，适合「查不到就给个临时默认值」；`setdefault` 会**写回字典**，适合「初始化分组容器」：
>
> ```python
> groups = {}
> for word in ["apple", "avocado", "banana", "blueberry"]:
>     groups.setdefault(word[0], []).append(word)     # 一行完成「分组容器初始化 + 追加」
> print(groups)
> # {'a': ['apple', 'avocado'], 'b': ['banana', 'blueberry']}
> ```

### 字典复制和删除

```python
import copy

d = {"a": 1, "b": [2, 3]}
e = d                       # 别名
f = d.copy()                # 浅拷贝
g = copy.deepcopy(d)        # 深拷贝

d["a"] = 99
d["b"].append(4)
print(e)    # {'a': 99, 'b': [2, 3, 4]}
print(f)    # {'a': 1, 'b': [2, 3, 4]}   ← 浅拷贝：内层仍共享
print(g)    # {'a': 1, 'b': [2, 3]}     ← 深拷贝：完全独立
```

> **浅拷贝陷阱的通用记法**：**浅拷贝只复制「最外面一层容器」，里面装的还是同一批内层对象。**

### 字典的遍历（四种方式）

```python
d = {"a": 1, "b": 2, "c": 3}

for k in d:                     # 方式一：直接遍历（拿到键）
    print(k, end=" ")           # a b c

for k in d.keys():              # 方式二：显式遍历键
    print(k, end=" ")

for v in d.values():            # 方式三：遍历值
    print(v, end=" ")           # 1 2 3

for k, v in d.items():          # 方式四：遍历键值对（最常用）
    print(f"{k}={v}", end=" ")  # a=1 b=2 c=3
```

> **坑**：**遍历字典时不能增删键**，会报 `RuntimeError: dictionary changed size during iteration`。要删就遍历副本：
>
> ```python
> d = {"a": 1, "b": 2, "c": 3}
> for k in list(d.keys()):        # 用 list() 复制一份键
>     if d[k] % 2 == 1:
>         del d[k]
> print(d)                        # {'b': 2}
> ```

**字典的三个视图对象**：

```python
d = {"a": 1, "b": 2}
print(d.keys())         # dict_keys(['a', 'b'])
print(d.values())       # dict_values([1, 2])
print(d.items())        # dict_items([('a', 1), ('b', 2)])
print(list(d.keys()))   # ['a', 'b']   要列表得转换
print("a" in d)         # True        判断键，不是值
print(1 in d)           # False       1 是值不是键
```

## 4.5 集合

### 集合创建

```python
s1 = {1, 2, 3}
s2 = set()                  # 空集合（不能写 {}！）
s3 = set([1, 2, 2, 3])      # {1, 2, 3}  自动去重
s4 = set("hello")           # {'h', 'e', 'l', 'o'}
s5 = {x % 3 for x in range(10)}     # {0, 1, 2}  集合推导式
print(s1, s2, s3, s4, s5)
print(type({}))             # <class 'dict'>  ← 坑
```

**集合的两大特性：无序 + 不重复。**

```python
nums = [1, 2, 2, 3, 3, 3]
print(set(nums))                        # {1, 2, 3}
print(list(set(nums)))                  # [1, 2, 3]  最快的去重方式
print(len(set(nums)))                   # 3
```

### 集合访问

**集合没有下标，不能切片，只能遍历或判断成员。**

```python
s = {3, 1, 2}
# print(s[0])       # TypeError: 'set' object is not subscriptable
for x in s:
    print(x, end=" ")       # 1 2 3（顺序不保证）
print()
print(2 in s)               # True
print(sorted(s))            # [1, 2, 3]  要排序得先转列表
```

### 集合复制和删除

| 方法 | 作用 | 元素不存在时 |
|---|---|---|
| `add(x)` | 添加元素 | —— |
| `remove(x)` | 删除元素 | **`KeyError`** |
| `discard(x)` | 删除元素 | **不报错**（推荐） |
| `pop()` | **随机**弹出并返回一个元素 | 空集合 → `KeyError` |
| `clear()` | 清空 | —— |
| `copy()` | 浅拷贝 | —— |

```python
s = {1, 2, 3}
s.add(4)
print(s)                # {1, 2, 3, 4}
s.discard(99)           # 不报错
print(s)                # {1, 2, 3, 4}
# s.remove(99)          # KeyError: 99
print(s.pop())          # 随机弹出一个（如 1）
print(s)                # 剩下的元素
```

> **小技巧**：`s.add([1,2])` 会报 `TypeError: unhashable type: 'list'`，因为列表不可哈希。要往集合里放多个值，用 `s.update([1, 2])`。

### 集合运算

| 运算 | 运算符 | 方法 | 含义 |
|---|---|---|---|
| 并集 | `a \| b` | `a.union(b)` | 两者所有元素 |
| 交集 | `a & b` | `a.intersection(b)` | 公共元素 |
| 差集 | `a - b` | `a.difference(b)` | 在 a 不在 b |
| 对称差 | `a ^ b` | `a.symmetric_difference(b)` | 只在一个里出现 |
| 子集判断 | —— | `a.issubset(b)` | a 是否被 b 包含 |
| 超集判断 | —— | `a.issuperset(b)` | a 是否包含 b |
| 是否无交集 | —— | `a.isdisjoint(b)` | 交集为空返回 True |

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)        # {1, 2, 3, 4, 5, 6}   并
print(a & b)        # {3, 4}               交
print(a - b)        # {1, 2}               差
print(b - a)        # {5, 6}
print(a ^ b)        # {1, 2, 5, 6}         对称差

print({1, 2}.issubset(a))       # True
print(a.issuperset({1, 2}))     # True
print(a.isdisjoint({9, 10}))    # True
```

**经典应用：用集合快速统计「两门课都选的学生」「只选了一门的学生」**

```python
python_stu = {"张三", "李四", "王五"}
java_stu = {"李四", "王五", "赵六"}

print("都选了：", python_stu & java_stu)        # 顺序不保证，例如 {'王五', '李四'}
print("只选一门：", python_stu ^ java_stu)      # 顺序不保证，例如 {'张三', '赵六'}
print("总人数：", len(python_stu | java_stu))   # 4
```

### 集合统计

```python
s = {3, 1, 4, 1, 5}
print(len(s))           # 4   自动去重（1 只算一次）
print(max(s), min(s), sum(s))   # 5 1 13
print(1 in s, 9 in s)   # True False   成员判断 O(1)
```

> **性能提示**：判断「某元素是否在一批数据里」，用集合比用列表快得多（O(1) vs O(n)）。实测（10 万个元素，目标故意放最后 = 最坏情况）：**单次判断列表约 0.4～0.8 ms，集合不到 1 µs，相差几千倍**；换算成 **10 万次判断，列表要几十秒（实测 80.59 s），集合只要 0.0082 s**。
>
> ```python
> import time
> N = 100000
> lst, st, target = list(range(N)), set(range(N)), N - 1
> t0 = time.perf_counter()
> for _ in range(100000): target in lst     # 10 万次列表查找
> t1 = time.perf_counter()
> for _ in range(100000): target in st      # 10 万次集合查找
> t2 = time.perf_counter()
> print(f"列表 {t1-t0:.2f}s，集合 {t2-t1:.4f}s")   # 列表 80.59s，集合 0.0082s
> ```
>
> ⚠️ 顺带记住：集合无序，**`print` 出来的元素顺序每次运行都可能不同**（受哈希种子影响）。所以**永远不要依赖集合的打印顺序**，也不要把它当固定输出写进注释——写「顺序不保证」即可。

## 4.7 典型案例

### 4.7.1 查找

**① 顺序查找**：从头到尾逐个比较，O(n)。

```python
def seq_search(lst, target):
    for i, x in enumerate(lst):
        if x == target:
            return i            # 返回下标
    return -1                   # 找不到

print(seq_search([5, 3, 8, 1], 8))      # 2
print(seq_search([5, 3, 8, 1], 9))      # -1
```

**② 二分查找**：要求数据**已经有序**，每次砍一半，O(log n)。

```python
def binary_search(lst, target):
    low, high = 0, len(lst) - 1
    while low <= high:
        mid = (low + high) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

data = [1, 3, 5, 7, 9, 11, 13]
print(binary_search(data, 7))       # 3
print(binary_search(data, 8))       # -1
```

| 算法 | 时间复杂度 | 前提 |
|---|---|---|
| 顺序查找 | O(n) | 无 |
| 二分查找 | **O(log n)** | **必须有序** |

> 10 亿个有序数据，顺序查找平均 5 亿次比较，二分查找只需 **30 次**。

### 4.7.2 排序

**① 冒泡排序**：相邻两个比较，大的往后冒。

```python
def bubble_sort(lst):
    n = len(lst)
    for i in range(n - 1):
        swapped = False
        for j in range(n - 1 - i):        # 每轮把最大的送到末尾
            if lst[j] > lst[j + 1]:
                lst[j], lst[j + 1] = lst[j + 1], lst[j]
                swapped = True
        if not swapped:                   # 本轮没交换 → 已经有序，提前结束
            break
    return lst

print(bubble_sort([5, 2, 9, 1, 5, 6]))    # [1, 2, 5, 5, 6, 9]
```

**② 选择排序**：每轮从未排序部分选出最小值放到前面。

```python
def select_sort(lst):
    n = len(lst)
    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if lst[j] < lst[min_idx]:
                min_idx = j
        lst[i], lst[min_idx] = lst[min_idx], lst[i]
    return lst

print(select_sort([5, 2, 9, 1, 6]))       # [1, 2, 5, 6, 9]
```

| 排序算法 | 平均时间 | 空间 | 稳定性 |
|---|---|---|---|
| 冒泡排序 | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(1) | 不稳定 |
| `sort()` / `sorted()`（Timsort） | **O(n log n)** | O(n) | 稳定 |

> **考试写作要求**：手写冒泡/选择排序是常考题；**实际开发一行 `sorted()` 搞定**，且它更快、更稳定。

### 4.7.3 推导式

**推导式 = 「一行生成一个新容器」的语法糖，比循环 + append 更快更短。**

**① 列表推导式**：`[表达式 for 变量 in 可迭代对象 if 条件]`

```python
print([x ** 2 for x in range(6)])               # [0, 1, 4, 9, 16, 25]
print([x for x in range(10) if x % 2 == 0])     # [0, 2, 4, 6, 8]
print([ch.upper() for ch in "abc"])             # ['A', 'B', 'C']
print([[i * j for j in range(1, 4)] for i in range(1, 4)])   # 嵌套推导式
# [[1, 2, 3], [2, 4, 6], [3, 6, 9]]

words = ["hello", "world", "python"]
print([w.capitalize() for w in words])          # ['Hello', 'World', 'Python']
print([w for w in words if len(w) > 5])         # ['python']

# 等价写法对比
result = []
for x in range(10):
    if x % 2 == 0:
        result.append(x ** 2)
print(result)                                    # [0, 4, 16, 36, 64]
print([x ** 2 for x in range(10) if x % 2 == 0]) # 完全等价，但一行
```

**② 字典推导式**：`{键表达式: 值表达式 for ... if ...}`

```python
print({x: x ** 2 for x in range(4)})            # {0: 0, 1: 1, 2: 4, 3: 9}
print({v: k for k, v in {"a": 1, "b": 2}.items()})   # 键值互换 {1: 'a', 2: 'b'}
words = ["apple", "banana", "cherry"]
print({w: len(w) for w in words})               # {'apple': 5, 'banana': 6, 'cherry': 6}
```

**③ 集合推导式**：

```python
print({x % 3 for x in range(10)})               # {0, 1, 2}
print({len(w) for w in ["a", "bb", "cc", "ddd"]})   # {1, 2, 3}
```

**④ 生成器表达式**：把 `[]` 换成 `()`，**惰性求值、一次性的**。

```python
g = (x ** 2 for x in range(5))
print(g)                # <generator object <genexpr> at 0x...>
print(next(g))          # 0
print(next(g))          # 1
print(list(g))          # [4, 9, 16]   ← 前面的 0、1 已经被取走了

# 只能遍历一次
g2 = (x for x in range(3))
print(sum(g2))          # 3
print(sum(g2))          # 0    ← 坑！生成器已经耗尽
```

| 对比项 | 列表推导式 `[...]` | 生成器表达式 `(...)` |
|---|---|---|
| 求值时机 | 立即全部算出 | **用到才算（惰性）** |
| 内存占用 | 全部元素占内存 | **几乎不占内存** |
| 可遍历次数 | 无限次 | **只能一次** |
| 适用 | 需要反复使用、需要下标 | 一次性的海量数据处理 |

```python
# 求和时用生成器更省内存（数据量大时差别巨大）
print(sum(x ** 2 for x in range(100)))          # 328350
print(max(len(w) for w in ["a", "abc", "ab"]))  # 3
```

### 4.7.4 列表作为堆栈和队列使用

**① 堆栈（Stack）：后进先出 LIFO**，用 `append()` + `pop()`。

```python
stack = []
stack.append(1)
stack.append(2)
stack.append(3)
print(stack)            # [1, 2, 3]
print(stack.pop())      # 3    弹出末尾
print(stack.pop())      # 2
print(stack)            # [1]
print(len(stack) == 0)  # 判断空栈
```

**② 队列（Queue）：先进先出 FIFO**，用 `collections.deque`。

```python
from collections import deque

q = deque()
q.append(1)             # 入队（尾部）
q.append(2)
q.append(3)
print(q.popleft())      # 1    出队（头部）
print(q.popleft())      # 2
print(q)                # deque([3])

# deque 也可以当堆栈用（两端操作都是 O(1)）
d = deque([1, 2, 3])
d.appendleft(0)
d.pop()
print(d)                # deque([0, 1, 2])
```

> **坑**：用 `list` 当队列是**错误示范**——`lst.pop(0)` 要移动后面所有元素，是 O(n)。所以队列要用 `deque`。**`deque` 两端插入删除都是 O(1)。**

### 4.7.5 基于组合数据的游戏角色管理

用「列表套字典」管理角色：增、删、查、改、排序、统计。

```python
roles = [
    {"name": "亚瑟", "hp": 3200, "level": 15, "job": "战士"},
    {"name": "后羿", "hp": 2800, "level": 12, "job": "射手"},
    {"name": "安琪拉", "hp": 2400, "level": 18, "job": "法师"},
]

# 1) 查询：按名字找角色
def find_role(name):
    for r in roles:
        if r["name"] == name:
            return r
    return None

print(find_role("后羿"))        # {'name': '后羿', 'hp': 2800, ...}

# 2) 修改：升级 + 加血
r = find_role("后羿")
if r:
    r["level"] += 1
    r["hp"] += 200
print(r["level"], r["hp"])      # 13 3000

# 3) 排序：按等级从高到低
rank = sorted(roles, key=lambda r: r["level"], reverse=True)
for i, r in enumerate(rank, 1):
    print(f"第{i}名：{r['name']}（{r['job']}）Lv.{r['level']}")
# 第1名：安琪拉（法师）Lv.18
# 第2名：亚瑟（战士）Lv.15
# 第3名：后羿（射手）Lv.13

# 4) 统计：每个职业的人数（字典计数法）
count = {}
for r in roles:
    count[r["job"]] = count.get(r["job"], 0) + 1
print(count)                    # {'战士': 1, '射手': 1, '法师': 1}

# 5) 删除：按名字移除
roles = [r for r in roles if r["name"] != "亚瑟"]
print([r["name"] for r in roles])    # ['后羿', '安琪拉']
```

**字符串词频统计（第 6 章会深化，这里先给最小可用版）**：

```python
text = "the quick brown fox jumps over the lazy dog the fox"
words = text.split()

```

## 典型例题

**例 4.1**（题型：读程序写结果——浅拷贝与二维列表）

```python
a = [[0] * 2] * 2
a[0][0] = 9
print(a)
b = [[0] * 2 for _ in range(2)]
b[0][0] = 9
print(b)
```

**解**：`[[0]*2]*2` 是**同一个内层列表**被引用两次，改一处影响全部；列表推导式每次新建一行。

**答案**：

```
[[9, 0], [9, 0]]
[[9, 0], [0, 0]]
```

**例 4.2**（题型：读程序写结果——list.sort 的返回值）

```python
nums = [3, 1, 2]
res = nums.sort(reverse=True)
print(nums, res)
nums2 = [3, 1, 2]
res2 = sorted(nums2, reverse=True)
print(nums2, res2)
```

**解**：`sort()` **原地排序并返回 `None`**；`sorted()` 不动原列表，返回新列表。

**答案**：

```
[3, 2, 1] None
[3, 1, 2] [3, 2, 1]
```

**例 4.3**（题型：编程题——去重与保序）

给定列表 `[3, 1, 3, 2, 1, 5]`，分别输出：① 去重后的结果（保持首次出现的顺序）；② 用集合去重的结果（顺序可能不同）。

```python
data = [3, 1, 3, 2, 1, 5]

# 方法一：用字典按键保序去重（Python 3.7+ 字典保序）
print(list(dict.fromkeys(data)))    # [3, 1, 2, 5]

# 方法二：手动收集 + 集合判重（O(n)）
seen, result = set(), []
for x in data:
    if x not in seen:
        seen.add(x)
        result.append(x)
print(result)                       # [3, 1, 2, 5]

# 方法三：直接用集合（最快，但顺序不保证）
print(set(data))                    # {1, 2, 3, 5}
```

**解**：三种方法的取舍——`set()` 最快但丢顺序；`dict.fromkeys()` 一行搞定且保序；手动法最直观。

**答案**：保序结果为 `[3, 1, 2, 5]`。

**例 4.4**（题型：编程题——字典统计与排序）

输入一行英文句子，统计每个单词出现的次数，按次数从高到低输出（次数相同按字典序）。

```python
text = input("句子：")      # 输入：a b c a b a（**一整行**一次输入，单词之间用空格分隔）
counter = {}
for w in text.lower().split():
    counter[w] = counter.get(w, 0) + 1

for w, c in sorted(counter.items(), key=lambda kv: (-kv[1], kv[0])):
    print(f"{w}: {c}")
# a: 3
# b: 2
# c: 1
```

**解**：`counter.get(w, 0) + 1` 是「字典计数」的标准写法；排序的 `key` 用**元组 `(-次数, 单词)`**，先按次数降序（取负号把降序转成升序），次数相同再按单词升序。

**答案**：`a: 3`、`b: 2`、`c: 1`。

**例 4.5**（题型：编程题——成绩管理综合）

已知成绩字典 `{"张三": 92, "李四": 58, "王五": 76}`，输出：① 平均分；② 最高分姓名；③ 不及格名单；④ 按成绩降序排列的 `(姓名, 成绩)` 列表。

```python
scores = {"张三": 92, "李四": 58, "王五": 76}

avg = sum(scores.values()) / len(scores)
print(f"平均分：{avg:.2f}")             # 平均分：75.33

top = max(scores, key=scores.get)
print("最高分：", top, scores[top])      # 最高分： 张三 92

fail = [name for name, s in scores.items() if s < 60]
print("不及格：", fail)                  # 不及格： ['李四']

rank = sorted(scores.items(), key=lambda kv: kv[1], reverse=True)
print(rank)     # [('张三', 92), ('王五', 76), ('李四', 58)]
```

**解**：`max(scores, key=scores.get)` 是「按值取键」的惯用法——`max` 遍历字典的**键**，`key=scores.get` 告诉它「用对应的值来比较」。

**答案**：平均 75.33；最高分张三 92；不及格 `['李四']`；排序结果见上。

**例 4.6**（题型：编程题——矩阵操作）

不使用第三方库，实现两个矩阵相加与矩阵转置，并求每行的最大值。

```python
a = [[1, 2, 3], [4, 5, 6]]
b = [[7, 8, 9], [1, 2, 3]]

# 相加：双重推导式
add = [[a[i][j] + b[i][j] for j in range(len(a[0]))] for i in range(len(a))]
print(add)              # [[8, 10, 12], [5, 7, 9]]

# 转置
trans = [[row[i] for row in a] for i in range(len(a[0]))]
print(trans)            # [[1, 4], [2, 5], [3, 6]]

# 每行最大值
print([max(row) for row in a])      # [3, 6]

# 全矩阵最大值及其位置
mx = max(max(row) for row in a)
pos = [(i, j) for i, row in enumerate(a) for j, v in enumerate(row) if v == mx]
print(mx, pos)          # 6 [(1, 2)]
```

**解**：矩阵相加要求 `a`、`b` 行列数相同；转置用嵌套推导式或 `zip(*a)`；「最大值位置」用 `enumerate` 双重遍历配合条件筛选。

**答案**：相加 `[[8, 10, 12], [5, 7, 9]]`，转置 `[[1, 4], [2, 5], [3, 6]]`，每行最大 `[3, 6]`。

**例 4.7**（题型：编程题——约瑟夫环 / 队列应用）

n 个人围成一圈报数，报到 m 的人出列，求出列顺序（n=5, m=3）。

```python
from collections import deque

n, m = 5, 3
q = deque(range(1, n + 1))
out = []
while q:
    q.rotate(-(m - 1))          # 把第 m 个人转到队首（正数右移，负数左移）
    out.append(q.popleft())
print(out)                      # [3, 1, 5, 2, 4]
```

**解**：用 `deque` 模拟圆环。`rotate(-(m-1))` 把队首往前推 `m-1` 位，此时队首就是报数到 `m` 的人，`popleft()` 出列。**这是队列的经典应用，比手写下标循环简洁得多。**

**答案**：出列顺序 `[3, 1, 5, 2, 4]`。

## 易错点提醒

1. **把 `b = a` 当成复制列表。**
   - 错在哪：`b = a` 只是增加一个别名，改 `b` 会影响 `a`。
   - 正确做法：浅拷贝用 `a.copy()` / `a[:]` / `list(a)`；有嵌套结构用 `copy.deepcopy(a)`。
2. **用 `[[0]*n]*m` 初始化二维列表。**
   - 错在哪：`m` 行指向同一个列表，改一行等于改所有行。
   - 正确做法：`[[0] * n for _ in range(m)]`。
3. **`nums = nums.sort()` 把列表变成 `None`。**
   - 错在哪：`sort()` 原地排序，返回 `None`。
   - 正确做法：原地排序就写 `nums.sort()` 不接返回值；要新列表用 `nums = sorted(nums)`。
4. **遍历列表时删除元素。**
   - 错在哪：删除后后面元素前移，循环索引却继续加 1，会跳过元素。
   - 正确做法：遍历副本 `for x in lst[:]`，或用推导式重建 `lst = [x for x in lst if 条件]`。
5. **`{}` 当成空集合。**
   - 错在哪：`type({})` 是 `<class 'dict'>`，`s = {}` 后 `s.add(1)` 报 `AttributeError`。
   - 正确做法：空集合写 `set()`。
6. **字典用 `d[k]` 访问不存在的键。**
   - 错在哪：直接 `KeyError` 使程序崩溃。
   - 正确做法：不确定就用 `d.get(k, 默认值)`；计数场景用 `d[k] = d.get(k, 0) + 1`。
7. **用列表（或集合）作字典的键。**
   - 错在哪：`TypeError: unhashable type: 'list'`。
   - 正确做法：改用元组 `(1, 2)` 或字符串作键。
8. **在 `for` 循环里对字典增删键。**
   - 错在哪：`RuntimeError: dictionary changed size during iteration`。
   - 正确做法：先 `list(d.keys())` 生成副本再遍历，或先收集要删的键、循环结束后统一删。
9. **误以为生成器可以反复遍历。**
   - 错在哪：`sum(g)` 之后再 `sum(g)` 得 0，因为生成器已耗尽。
   - 正确做法：需要多次使用就改成列表推导式存下来。
10. **`s.remove(x)` 与 `s.discard(x)` 混用。**
    - 错在哪：集合的 `remove` 在元素不存在时抛 `KeyError`，而列表的 `remove` 抛 `ValueError`。
    - 正确做法：不确定元素是否存在时用 `discard()`。

## 本章小结

- 组合数据分三类：**序列**（`str`/`list`/`tuple`）、**映射**（`dict`）、**集合**（`set`）。
- 四件套核心差异：**列表元组有序可重复，字典集合哈希查找 O(1)，集合自动去重，元组不可变可作键**。
- **`b = a` 是别名，`a[:]`/`a.copy()` 是浅拷贝（内层仍共享），`copy.deepcopy` 才完全独立**。
- 切片左闭右开、越界不报错；`[::-1]` 反转；**切片赋值能改变列表长度**。
- **`sort()` 原地排序返回 `None`，`sorted()` 返回新列表**；`key` 决定排序依据，元组 `key` 可实现多级排序。
- 字典三件套：**`d[k]` 会抛 `KeyError`、`d.get(k, 默认)` 安全、`d.setdefault` 会写回**；计数用 `d.get(k, 0) + 1`。
- 集合用 `| & - ^` 做并交差对称差；`remove` 抛异常、`discard` 静默。
- **推导式一行生成容器；生成器表达式惰性求值、只能遍历一次**。
- **`[[0]*n]*m` 是陷阱，二维列表必须用推导式初始化**；堆栈用 `append/pop`，队列用 `deque`。
- 顺序查找 O(n)、二分查找 O(log n)（要求有序）；手写冒泡/选择是 O(n²)，实战直接用 `sorted`。

> **一句话记住本章**：列表可变元组不可变，字典集合靠哈希，`sort` 返回 `None`，浅拷贝只拷一层，二维列表必须用推导式。
