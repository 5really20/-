## 14.1 网络协议

### 14.1.1 互联网协议族

**协议（protocol）是通信双方约定的规则集合。** 网络通信被分成多层，每层只解决一个问题——这就是**分层思想**（与第5章"模块化"是同一个思路）。

| OSI 七层 | TCP/IP 四层 | 这一层解决什么 | 典型协议 |
|---|---|---|---|
| 应用层 / 表示层 / 会话层 | **应用层** | 数据是什么业务 | HTTP、FTP、SMTP、DNS |
| 传输层 | **传输层** | 数据到哪个程序 | **TCP、UDP** |
| 网络层 | **网络层** | 数据到哪台机器 | **IP**、ICMP |
| 数据链路层 / 物理层 | **网络接口层** | 数据怎么在物理介质上走 | 以太网、Wi-Fi |

**两个核心概念**：

- **IP 地址**：定位"哪一台机器"。`IPv4` 是 4 段 0~255 的数字（如 `10.190.95.244`），`127.0.0.1` 是**本机回环地址（localhost）**——数据不出网卡，永远指向自己。
- **端口（port）**：定位"机器上的哪个程序"。范围 **0~65535**，其中 0~1023 是**知名端口**（well-known ports），需要管理员权限才能监听。

| 端口 | 服务 | 端口 | 服务 |
|---|---|---|---|
| 20/21 | FTP | 443 | HTTPS |
| 22 | SSH | 3306 | MySQL |
| 25 | SMTP（发邮件） | 6379 | Redis |
| 80 | HTTP | 27017 | MongoDB |

> **重点**：**IP + 端口才能唯一确定一个网络程序**。就像"IP 是楼号、端口是房间号"——只知道楼号找不到人。

**本机信息查询实测**：

```python
import socket
print(socket.gethostname())                  # DESKTOP-Q8HVMO2
print(socket.gethostbyname("localhost"))     # 127.0.0.1
print(socket.gethostbyname_ex("localhost"))  # ('DESKTOP-Q8HVMO2', [], ['127.0.0.1'])
print(socket.gethostbyname(socket.gethostname()))   # 10.190.95.244（本机局域网 IP）
print(socket.has_ipv6)                       # True
print(socket.getaddrinfo("localhost", 80, socket.AF_INET, socket.SOCK_STREAM)[:1])
# [(<AddressFamily.AF_INET: 2>, <SocketKind.SOCK_STREAM: 1>, 0, '', ('127.0.0.1', 80))]
```

### 14.1.2 TCP/IP

**TCP 与 UDP 是传输层的两大协议**，这是本章最重要的一张对比表：

| 对比项 | TCP | UDP |
|---|---|---|
| 连接 | **面向连接**（先三次握手） | **无连接**（直接发） |
| 可靠性 | **可靠**：丢包重传、按序到达 | 不可靠：丢包就丢了 |
| 速度 | 慢（有确认与重传开销） | 快 |
| 数据形式 | **字节流**（没有边界） | **数据报**（一包一个边界） |
| 一对多 | 只能一对一 | 支持广播、组播 |
| 典型应用 | 网页、文件传输、邮件 | 视频直播、语音、DNS、游戏 |
| Python 常量 | `SOCK_STREAM`（值 1） | `SOCK_DGRAM`（值 2） |

**TCP 三次握手**（建立连接的过程）：

```
客户端                                服务端
  |---------- SYN  (我想连接) --------->|
  |<----- SYN + ACK (同意，我也想连) ----|
  |---------- ACK  (确认) ------------->|   连接建立
```

> **注意**：**TCP 是"字节流"，没有消息边界**。`send("abc")` 和 `send("def")` 可能被接收方一次 `recv` 读成 `"abcdef"`，也可能被拆成 `"ab"`、`"cdef"`。**所以自定义协议时必须自己定边界**（固定长度、或"长度前缀"、或换行分隔）。这是 socket 编程最常见的坑。

**HTTP 是应用层协议，建立在 TCP 之上**，采用"**请求—响应**"模型：客户端发一个请求，服务端回一个响应，然后连接关闭（或复用）。常用状态码：

| 状态码 | 含义 | 说明 |
|---|---|---|
| **200** | OK | 请求成功 |
| 301 / 302 | 永久 / 临时重定向 | 地址变了，去 `Location` 头里的新地址 |
| 400 | Bad Request | 请求格式错误 |
| **403** | Forbidden | 服务器拒绝（没权限） |
| **404** | Not Found | 资源不存在 |
| 500 | Internal Server Error | 服务器内部出错 |
| 503 | Service Unavailable | 服务暂时不可用 |

**GET 与 POST 的区别**：

| 对比项 | GET | POST |
|---|---|---|
| 参数位置 | **URL 里**（`?a=1&b=2`） | **请求体里** |
| 长度限制 | 有（URL 长度限制） | 无 |
| 可见性 | 明文可见，会被记进日志 | 相对隐蔽（**但 HTTP 不加密，照样能被抓**） |
| 幂等性 | 幂等（重复请求结果一样） | 非幂等（可能重复下单） |
| 用途 | **获取数据** | **提交数据** |

## 14.2 套接字（Socket）编程

### 14.2.1 套接字简介

**套接字（socket）是操作系统提供的网络编程接口**——它把复杂的 TCP/IP 协议栈封装成"打开—读写—关闭"这样的文件式操作。**你可以把 socket 当成"网络上的文件句柄"**。

**创建 socket 需要两个参数**：地址族 + 套接字类型。

| 参数 | 常用值 | 含义 |
|---|---|---|
| 地址族 | `AF_INET` | IPv4（值 2） |
| | `AF_INET6` | IPv6 |
| 类型 | `SOCK_STREAM` | **TCP**（值 1） |
| | `SOCK_DGRAM` | **UDP**（值 2） |

```python
import socket
print(socket.AF_INET, socket.SOCK_STREAM, socket.SOCK_DGRAM)   # 2 1 2
print(socket.SOMAXCONN)      # 2147483647（listen 的默认排队上限）
```

**服务端与客户端的固定套路**（背下来）：

| 步骤 | 服务端 | 客户端 |
|---|---|---|
| 1 | `s = socket.socket(...)` | `s = socket.socket(...)` |
| 2 | `s.bind((host, port))` 绑定地址 | —— |
| 3 | `s.listen(5)` 开始监听 | —— |
| 4 | `conn, addr = s.accept()` **阻塞等待** | `s.connect((host, port))` 连接 |
| 5 | `conn.recv(n)` / `conn.sendall(b)` | `s.sendall(b)` / `s.recv(n)` |
| 6 | `conn.close()`；`s.close()` | `s.close()` |

### 14.2.2 基于 TCP 的套接字编程

**服务端（echo_server.py）**：

```python
import socket

HOST, PORT = "127.0.0.1", 8888
srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)   # 允许立即重用端口
srv.bind((HOST, PORT))
srv.listen(5)                     # 最多 5 个连接排队等待
print(f"服务端已启动 {HOST}:{PORT}")

conn, addr = srv.accept()         # 阻塞，直到有客户端连上
print("客户端来自", addr)          # 客户端来自 ('127.0.0.1', 58283)
with conn:                        # with 会在退出时自动 close
    while True:
        data = conn.recv(1024)    # 最多收 1024 字节
        if not data:              # 空字节串 = 对方关闭了连接
            break
        conn.sendall(b"[ECHO]" + data)   # sendall 保证全部发完
srv.close()
```

**客户端（echo_client.py）**：

```python
import socket

cli = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
cli.connect(("127.0.0.1", 8888))
print("本地端口", cli.getsockname())     # 本地端口 ('127.0.0.1', 58283) ← 由系统随机分配

cli.sendall("你好 Python".encode("utf-8"))
print(cli.recv(1024).decode("utf-8"))    # [ECHO]你好 Python

cli.sendall(b"hello")
print(cli.recv(1024))                    # b'[ECHO]hello'

cli.shutdown(socket.SHUT_WR)             # 告诉对方"我不再发送了"
print(cli.recv(1024))                    # b''  ← 服务端收到空数据后 break 并关闭
cli.close()
```

**四个必须理解的点**：

1. **`recv` 返回 `b""`（空字节串）表示"对方已关闭连接"**——这是循环结束的条件。**它和"没有数据可读"不是一回事**：没有数据时 `recv` 会**阻塞等待**，不会返回 `b""`。
2. **`sendall` vs `send`**：`send` 返回实际发送的字节数，**可能只发了一部分**；`sendall` 内部循环直到全部发完。**一律用 `sendall`**。
3. **网络传输的是 `bytes`，不是 `str`**。发送前 `.encode("utf-8")`，收到后 `.decode("utf-8")`。忘了编码会报 `TypeError: a bytes-like object is required, not 'str'`。
4. **`SO_REUSEADDR`**：不加它时，服务端刚关闭又立刻重启会报 `OSError: [WinError 10048] 通常每个套接字地址只允许使用一次`。**调试时必加**。

**`connect` 后客户端端口是系统随机分配的**（实测服务端在 `58281`，客户端自动得到 `58283`）——这叫**临时端口（ephemeral port）**，范围通常是 49152~65535。

### 14.2.3 基于 UDP 的套接字编程

**UDP 不需要 `listen`/`accept`/`connect`**，直接 `sendto`/`recvfrom`：

```python
import socket

# 服务端
us = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
us.bind(("127.0.0.1", 9999))
data, addr = us.recvfrom(1024)          # 阻塞等待，同时拿到对方地址
print("来自", addr, "的数据", data)      # 来自 ('127.0.0.1', 60699) 的数据 b'ping'
us.sendto(b"UDP-ACK:" + data, addr)     # 回给对方
us.close()

# 客户端
uc = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
uc.sendto(b"ping", ("127.0.0.1", 9999))
print(uc.recvfrom(1024)[0])             # b'UDP-ACK:ping'
uc.close()
```

**UDP 的三个特点**：① **无连接**，所以客户端不需要 `connect`；② **保留消息边界**——发一次 `ping`，收一次就是 `ping`，不会粘连；③ **不可靠**，收不到就永远收不到，**要自己实现超时重传**（`s.settimeout(3)` + `try/except socket.timeout`）。

## 14.3 Web 编程

### 14.3.1 Web 编程概述

**URL（Uniform Resource Locator，统一资源定位符）的五个部分**：

```
https://www.example.com:8080/path/to/page?x=1&y=2#frag
└─┬─┘   └──────┬───────┘└┬─┘└─────┬─────┘└──┬──┘└─┬─┘
scheme       netloc     port     path      query  fragment
 协议      主机(域名)    端口     路径      查询参数   锚点
```

```python
import urllib.parse
pr = urllib.parse.urlparse("https://www.example.com:8080/path?x=1#frag")
print(pr)
# ParseResult(scheme='https', netloc='www.example.com:8080', path='/path',
#             params='', query='x=1', fragment='frag')
print(pr.scheme, pr.netloc, pr.path, pr.query)   # https www.example.com:8080 /path x=1
```

> **注意**：**`#fragment`（锚点）不会发给服务器**——它只是浏览器内部用来定位页面位置的。

**URL 编码（百分号编码）**：URL 里只能出现 ASCII 字符，中文和空格必须转义。

```python
import urllib.parse
print(urllib.parse.quote("你好"))                    # %E4%BD%A0%E5%A5%BD
print(urllib.parse.quote("中文 空格"))                # %E4%B8%AD%E6%96%87%20%E7%A9%BA%E6%A0%BC
print(urllib.parse.unquote("%E4%BD%A0%E5%A5%BD"))    # 你好
print(urllib.parse.urlencode({"kw": "爬虫", "page": 1}))
# kw=%E7%88%AC%E8%99%AB&page=1
print(urllib.parse.parse_qs("a=1&b=2&b=3"))          # {'a': ['1'], 'b': ['2', '3']}
print(urllib.parse.urljoin("http://x.com/a/b.html", "../c.html"))
# http://x.com/c.html   ← 相对地址转绝对地址，爬虫必备
```

**`urljoin` 是爬虫的关键工具**：网页里的链接常常是相对地址（`../c.html`、`/a.html`），必须用 `urljoin(当前页地址, 相对地址)` 才能得到可访问的绝对地址。

**用 `urllib.request` 发请求**（标准库，无需安装）：

```python
import urllib.request

# ① 最简单的 GET
with urllib.request.urlopen("http://127.0.0.1:8000/index.html", timeout=5) as r:
    print(r.status, r.reason)                     # 200 OK
    print(r.headers.get("Content-Type"))          # text/html
    print(r.headers.get("Content-Length"))        # 124
    html = r.read().decode("utf-8")

# ② 加自定义请求头（伪装浏览器 UA，反爬第一步）
req = urllib.request.Request(
    "http://127.0.0.1:8000/index.html",
    headers={"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) TestBot"})
with urllib.request.urlopen(req, timeout=5) as r:
    print(r.status)                               # 200

# ③ POST 提交表单
import urllib.parse
data = urllib.parse.urlencode({"user": "zhang", "pwd": "123"}).encode("utf-8")
req = urllib.request.Request("http://127.0.0.1:8000/login", data=data)
with urllib.request.urlopen(req, timeout=5) as r:
    print(r.status)
```

**异常处理**（**爬虫必须写**）：

```python
import urllib.request, urllib.error
try:
    urllib.request.urlopen("http://127.0.0.1:8000/nope.html", timeout=5)
except urllib.error.HTTPError as e:
    print("HTTPError:", e.code, e.reason)          # HTTPError: 404 File not found
except urllib.error.URLError as e:
    print("URLError:", type(e.reason).__name__, e.reason)   # URLError: TimeoutError timed out
```

| 异常 | 触发场景 | 处理建议 |
|---|---|---|
| `HTTPError` | 服务器**有响应**但状态码是错误（404/403/500） | 检查 URL 或换 UA；**它是 `URLError` 的子类**，要放在前面捕获 |
| `URLError` | 连不上（DNS 失败、超时、拒绝连接） | 重试 + `time.sleep` |
| `socket.timeout` | 超时（`URLError` 的 `reason` 常是它） | 加长 `timeout` 或重试 |

**`requests` 库**（第三方，`pip install requests`，**比 urllib 好用得多**；**本机 Anaconda 已自带，不用装**）：

```python
import requests

r = requests.get("https://www.example.com", timeout=5,
                 headers={"User-Agent": "Mozilla/5.0"})
print(r.status_code)          # 200
print(r.encoding)             # ISO-8859-1  ← requests 猜的，中文站常猜错！
r.encoding = "utf-8"          # 手动指定，或 r.apparent_encoding 自动猜
print(r.text[:50])            # 返回 str
print(r.content[:20])         # 返回 bytes
print(r.json())               # 若响应是 JSON，直接解析成 dict

# 中文乱码的标准修法
r.encoding = r.apparent_encoding      # 用 chardet 猜出来的编码
```

| 对比项 | `urllib` | `requests` |
|---|---|---|
| 安装 | 标准库，自带 | **Anaconda 已自带**（实测）；否则 `pip install requests` |
| 写法 | 要构造 `Request` 对象 | `requests.get(url)` 一行 |
| 编码处理 | 自己 `decode` | `.text` + `.encoding` |
| 会话/ Cookie | 要 `HTTPCookieProcessor` | `requests.Session()` |
| 结论 | 应急可用 | **爬虫首选** |

**`robots.txt` 与法律边界**（**这一节是必考的态度题**）：

`robots.txt` 是网站根目录下的一个文本文件，用来自律地声明"哪些路径允许/禁止爬虫访问"：

```
User-agent: *
Disallow: /private/
Allow: /
```

**用标准库 `urllib.robotparser` 判断**：

```python
import urllib.robotparser
rp = urllib.robotparser.RobotFileParser()
rp.set_url("http://127.0.0.1:8000/robots.txt")
rp.read()
print(rp.can_fetch("*", "http://127.0.0.1:8000/private/x.html"))   # False
print(rp.can_fetch("*", "http://127.0.0.1:8000/index.html"))       # True
```

> **重点**：**`robots.txt` 是"君子协定"，没有强制力**，但**违反它可能构成不正当竞争甚至犯罪**。合规爬虫的四条底线：
> 1. **遵守 `robots.txt`**，禁止的路径绝不抓；
> 2. **控制频率**，每次请求之间 `time.sleep(1)` 以上，别把人家服务器打垮（**DoS 攻击是刑事犯罪**）；
> 3. **不抓个人隐私、不抓付费内容、不绕过登录和验证码**；
> 4. **数据只用于学习研究，不商用、不转卖**。
>
> **《刑法》第285条（非法获取计算机信息系统数据罪）、第286条（破坏计算机信息系统罪）**，以及《数据安全法》《个人信息保护法》都适用。**实验课上只爬自己搭的本地服务器或明确开放的公开数据。**

### 14.3.2 Django

**Web 框架**把"接收 HTTP 请求 → 处理 → 返回响应"的重复劳动封装起来。Python 三大框架：

| 框架 | 特点 | 适合 |
|---|---|---|
| **Django** | 大而全（自带 ORM、后台管理、表单、认证） | 内容型网站、管理系统 |
| Flask | 微框架，自由灵活 | 小型 API、快速原型 |
| FastAPI | 异步、自动生成 API 文档 | 高性能 API 服务 |

**Django 的 MTV 模式**（与常见 MVC 的对应）：

| Django | 对应 MVC | 职责 |
|---|---|---|

### 14.4.1 简单嗅探器

**嗅探器（sniffer）** 抓取流经网卡的原始数据包。**Python 标准库做不到**（需要原始套接字权限），实际要用 `scapy`。

```python
# 需要 pip install scapy，且必须以管理员/root 运行
from scapy.all import sniff, IP, TCP

def show(pkt):
    if IP in pkt and TCP in pkt:
        print(f"{pkt[IP].src}:{pkt[TCP].sport} -> "
              f"{pkt[IP].dst}:{pkt[TCP].dport}  len={len(pkt)}")

sniff(prn=show, count=10, filter="tcp")     # 抓 10 个 TCP 包
```

> **⚠️ 法律警告**：**嗅探只能在自己的网络、自己的设备上做**。抓取他人网络流量违反《网络安全法》第27条，可能构成犯罪。**实验课上只抓本机回环地址（127.0.0.1）的包。**

**不用第三方库的替代做法**：把本章的 TCP 服务端改造成"记录所有请求的服务器"，就相当于在应用层做了一次"嗅探"：

```python
import socket

srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
srv.bind(("127.0.0.1", 8888))
srv.listen(5)
print("记录服务器已启动")
conn, addr = srv.accept()
with conn:
    while (data := conn.recv(1024)):        # 海象运算符（3.8+）
        print(f"[{addr[1]}] 收到 {len(data)} 字节: {data[:60]!r}")
        conn.sendall(b"OK")
srv.close()
```

### 14.4.2 多线程端口扫描

**需求**：扫描 `127.0.0.1` 的常见端口，用多线程加速（第13章的知识）。

```python
import socket, threading

def scan(host, port, timeout=0.3, result=None):
    """能连上就返回 True"""
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(timeout)                    # 必须设超时，否则会等很久
    try:
        s.connect((host, port))
        if result is not None:
            result.append(port)
        return True
    except (socket.timeout, ConnectionRefusedError, OSError):
        return False
    finally:
        s.close()                            # 无论成败都要关

def scan_range(host, ports, workers=50):
    result, lock = [], threading.Lock()
    def job(p):
        if scan(host, p):
            with lock:
                result.append(p)
    threads = [threading.Thread(target=job, args=(p,)) for p in ports]
    for t in threads: t.start()
    for t in threads: t.join()
    return sorted(result)

if __name__ == "__main__":
    ports = list(range(1, 1025))
    print(scan_range("127.0.0.1", ports))
```

**本机实测**：扫描 `21, 22, 80, 443, 3306, 8080` 六个端口，结果 **`[]`（全部未开放）**——本机没跑这些服务。（**换一批端口结果就不一样**：同一次测试里扫 1~1024 全段，本机扫到了 `135` 和 `445` 这两个 Windows 系统服务端口，见例 14.4。）

**三个要点**：① **必须设 `settimeout`**，否则连不通的端口会长时间挂起；② **必须 `s.close()`**（写在 `finally` 里），否则大量 socket 不释放会导致"打开文件过多"；③ **用多线程**（I/O 密集，第13章结论）把 1024 个端口的扫描时间从几十秒压到 1 秒内。

> **⚠️ 法律警告**：**未经授权扫描他人主机的端口是违法行为**（《网络安全法》第27条"非法侵入他人网络、干扰他人网络正常功能"）。**只扫自己的机器或明确授权的靶场。**

### 14.4.3 用网络爬虫爬取全国城市天气信息

**需求**：从天气网站抓取多个城市的天气，解析出城市名与温度，保存为 JSON。这里用**本地模拟服务器**演示完整流程（**合规、可复现**）。

```python
import urllib.request, urllib.parse, urllib.error
import json, time, re
from html.parser import HTMLParser

BASE = "http://127.0.0.1:8000"       # 换成真实站点时注意 robots.txt

class WeatherParser(HTMLParser):
    """解析 <div class="city" data-temp="23">北京</div> 这类结构"""
    def __init__(self):
        super().__init__()
        self.items = []
    def handle_starttag(self, tag, attrs):
        d = dict(attrs)
        if tag == "div" and d.get("class") == "city":
            self._cur = d.get("data-temp")
    def handle_data(self, data):
        if getattr(self, "_cur", None) is not None and data.strip():
            self.items.append((data.strip(), self._cur))
            self._cur = None

def fetch(url, retry=3):
    """带重试与礼貌延迟的抓取"""
    headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) EduBot/1.0"}
    for i in range(retry):
        try:
            req = urllib.request.Request(url, headers=headers)
            with urllib.request.urlopen(req, timeout=5) as r:
                return r.read().decode("utf-8", errors="ignore")
        except urllib.error.HTTPError as e:
            print(f"HTTP {e.code}，不重试"); return None
        except urllib.error.URLError as e:
            print(f"第 {i+1} 次失败：{e.reason}")
            time.sleep(1 * (i + 1))        # 退避重试：1s, 2s, 3s
    return None

def crawl(cities):
    result = []
    for city in cities:
        url = f"{BASE}/weather?" + urllib.parse.urlencode({"city": city})
        html = fetch(url)
        if html is None:
            continue
        parser = WeatherParser()
        parser.feed(html)
        result.extend(parser.items)
        time.sleep(1)                      # ★ 礼貌延迟，必须写
    return result

if __name__ == "__main__":
    data = crawl(["北京", "上海", "武汉"])
    print(data)                            # [('北京', '23'), ('上海', '26'), ('武汉', '25')]
    with open("weather.json", "w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, indent=2)
```

**若用 `requests` + `BeautifulSoup`（更常见，需安装）**：

```python
import requests, time
from bs4 import BeautifulSoup

def crawl_bs4(cities):
    out = []
    headers = {"User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) EduBot/1.0"}
    for city in cities:
        r = requests.get("http://127.0.0.1:8000/weather",
                         params={"city": city}, headers=headers, timeout=5)
        r.encoding = r.apparent_encoding        # 防中文乱码
        soup = BeautifulSoup(r.text, "html.parser")
        for div in soup.find_all("div", class_="city"):
            out.append((div.get_text(strip=True), div.get("data-temp")))
        time.sleep(1)
    return out

print(crawl_bs4(["北京", "上海"]))    # [('北京', '23'), ('上海', '26')]
```

**`BeautifulSoup` 四个核心方法**：

| 方法 | 作用 | 返回 |
|---|---|---|
| `soup.find("div")` | 找**第一个**匹配标签 | `Tag` 或 `None` |
| `soup.find_all("div", class_="city")` | 找**全部**匹配标签 | `ResultSet`（可当列表） |
| `tag.get_text(strip=True)` | 取标签内的纯文本 | `str` |
| `tag.get("href")` / `tag["href"]` | 取属性值 | `str` 或 `None` |

**例 14.1**（题型：读程序写结果 —— socket 常量与地址）

```python
import socket
print(socket.AF_INET, socket.SOCK_STREAM, socket.SOCK_DGRAM)
print(socket.gethostbyname("localhost"))
print(socket.gethostbyname_ex("localhost"))
```

**解**：`AF_INET` 是 IPv4 地址族的枚举值 **2**；`SOCK_STREAM`（TCP）是 **1**，`SOCK_DGRAM`（UDP）是 **2**。`gethostbyname("localhost")` 把主机名解析成 IPv4 地址，`localhost` 固定解析为回环地址 **127.0.0.1**。`gethostbyname_ex` 返回三元组 `(主机名, 别名列表, IP 列表)`，本机别名为空，所以是 `('DESKTOP-Q8HVMO2', [], ['127.0.0.1'])`。

**答案**：`2 1 2` / `127.0.0.1` / `('DESKTOP-Q8HVMO2', [], ['127.0.0.1'])`（主机名因机器而异）。

**例 14.2**（题型：读程序写结果 —— URL 解析）

```python
import urllib.parse
pr = urllib.parse.urlparse("https://www.example.com:8080/path?x=1&y=2#frag")
print(pr.scheme, pr.netloc, pr.path)
print(pr.query, pr.fragment)
print(urllib.parse.parse_qs(pr.query))
print(urllib.parse.urljoin("http://x.com/a/b.html", "../c.html"))
```

**解**：`urlparse` 把 URL 拆成六个字段。`scheme` 是协议 `https`；`netloc` 是主机加端口 `www.example.com:8080`；`path` 是路径 `/path`；`query` 是查询串 `x=1&y=2`；`fragment` 是锚点 `frag`。`parse_qs` 把查询串解析成字典，**值统一是列表**（因为参数可以重复），所以是 `{'x': ['1'], 'y': ['2']}`。`urljoin` 用当前页 `http://x.com/a/b.html` 解析相对地址 `../c.html`：`b.html` 的目录是 `/a/`，`..` 回到根 `/`，所以结果是 `http://x.com/c.html`。

**答案**：`https www.example.com:8080 /path` / `x=1&y=2 frag` / `{'x': ['1'], 'y': ['2']}` / `http://x.com/c.html`。

**例 14.3**（题型：编程题 —— TCP 时间服务器）

**题目**：写一个 TCP 服务端，客户端连上后，服务端返回当前时间字符串（格式 `YYYY-MM-DD HH:MM:SS`），然后关闭连接。再写客户端读取并打印。

**解**：

```python
# server_time.py
import socket, datetime

srv = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)
srv.bind(("127.0.0.1", 8889))
srv.listen(5)
print("时间服务器启动")
conn, addr = srv.accept()
with conn:
    now = datetime.datetime.now().strftime("%Y-%m-%d %H:%M:%S")
    conn.sendall(now.encode("utf-8"))      # 必须编码成 bytes
srv.close()

# client_time.py
import socket
cli = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
cli.connect(("127.0.0.1", 8889))
print(cli.recv(1024).decode("utf-8"))       # 2026-10-08 03:10:19
cli.close()
```

**答案**：客户端打印形如 `2026-10-08 03:10:19` 的时间串。**要点**：① **`sendall` 必须传 `bytes`**，用 `.encode("utf-8")` 转换；② 服务端发完就 `close()`，客户端 `recv` 能收到数据，**再收一次会得到 `b""`**；③ 只服务一个客户端就结束，要服务多个客户端需要**循环 `accept`**，要同时服务多个需要**每个连接开一个线程**（第13章）。

**例 14.4**（题型：编程题 —— 多线程端口扫描）

**题目**：写函数 `scan_range(host, start, end, workers=100)`，用多线程扫描 `host` 上 `start` 到 `end` 的端口，返回所有开放端口的升序列表。

**解**：

```python
import socket, threading

def scan(host, port, timeout=0.3):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(timeout)
    try:
        s.connect((host, port))
        return True
    except (socket.timeout, ConnectionRefusedError, OSError):
        return False
    finally:
        s.close()

def scan_range(host, start, end, workers=100):
    ports = list(range(start, end + 1))
    result, lock = [], threading.Lock()
    queue = list(ports)

    def worker():
        while True:
            with lock:
                if not queue:
                    return
                p = queue.pop(0)
            if scan(host, p):
                with lock:
                    result.append(p)

    ts = [threading.Thread(target=worker) for _ in range(min(workers, len(ports)))]
    for t in ts: t.start()
    for t in ts: t.join()
    return sorted(result)

if __name__ == "__main__":
    print(scan_range("127.0.0.1", 1, 1024))    # []  ← 本机实测这 1024 个端口都没开
```

**答案**：本机 `127.0.0.1` 的 1~1024 端口实测返回 **`[135, 445]`**——这是 **Windows 默认开启的 RPC（135）和 SMB/文件共享（445）系统服务端口**。**要点**：① 用**任务队列 + 固定数量工作线程**的模型，比"一个端口一个线程"更省资源（1024 个线程开销太大）；② 从队列取任务必须加锁，否则两个线程会拿到同一个端口；③ `finally` 里 `close()` 防止 socket 泄漏；④ **必须设 `settimeout`**，否则未开放端口会等待系统默认超时（可能几十秒）。

> **⚠️ 这个结果随环境变化，别背数字**：在 Windows 上通常会扫到 `135`、`445` 这类系统服务端口（本机实测就是 `[135, 445]`）；在 Linux 上可能是 `22`、`111`；在受限网络、开了防火墙或容器里则可能是**空列表**。**重点看代码逻辑对不对，而不是这个列表的内容**——把同一段代码拿到另一台机器上跑出不同结果，是完全正常的。

**例 14.5**（题型：编程题 —— 合规爬虫）

**题目**：写函数 `safe_fetch(url)`，要求：① 先检查 `robots.txt` 是否允许抓取，不允许就返回 `None` 并提示；② 带自定义 UA；③ 带超时与 3 次退避重试；④ 自动处理编码。

**解**：

```python
import urllib.request, urllib.parse, urllib.error, urllib.robotparser
import time

UA = "Mozilla/5.0 (Windows NT 10.0; Win64; x64) EduBot/1.0"

def allowed(url, ua="*"):
    """检查 robots.txt 是否允许抓取"""
    pr = urllib.parse.urlparse(url)
    robots_url = f"{pr.scheme}://{pr.netloc}/robots.txt"
    rp = urllib.robotparser.RobotFileParser()
    rp.set_url(robots_url)
    try:
        rp.read()
    except Exception:
        return True                     # 没有 robots.txt 视为允许
    return rp.can_fetch(ua, url)

def safe_fetch(url, retry=3):
    if not allowed(url):
        print(f"robots.txt 禁止抓取：{url}")
        return None
    req = urllib.request.Request(url, headers={"User-Agent": UA})
    for i in range(retry):
        try:
            with urllib.request.urlopen(req, timeout=5) as r:
                raw = r.read()
                enc = r.headers.get_content_charset() or "utf-8"
                return raw.decode(enc, errors="ignore")
        except urllib.error.HTTPError as e:
            print(f"HTTP {e.code}，不重试")
            return None
        except urllib.error.URLError as e:
            print(f"第 {i+1} 次失败：{e.reason}")
            time.sleep(i + 1)           # 退避：1s, 2s, 3s
    return None

if __name__ == "__main__":
    print(safe_fetch("http://127.0.0.1:8000/private/x.html"))
    # robots.txt 禁止抓取：http://127.0.0.1:8000/private/x.html
    # None
```

**答案**：对 `/private/x.html` 输出 `robots.txt 禁止抓取：...` 并返回 `None`（实测 `can_fetch` 为 `False`）；对 `/index.html` 返回页面 HTML（实测 `can_fetch` 为 `True`）。**要点**：① **`robots.txt` 在站点根目录**，所以要从 URL 里取出 `scheme://netloc` 再拼 `/robots.txt`；② **读不到 `robots.txt` 时按"允许"处理**是常见惯例，但更稳妥的是按"禁止"；③ **`HTTPError` 不重试**（4xx 是客户端错误，重试无用），**`URLError` 才重试**；④ **退避重试**（1s、2s、3s）比固定间隔更礼貌。

**例 14.6**（题型：编程题 —— HTML 解析）

**题目**：不安装任何第三方库，用标准库 `html.parser` 写一个解析器，从 HTML 中提取所有 `<a href="...">` 的地址和 `<title>` 文本。

**解**：

```python
from html.parser import HTMLParser

class LinkParser(HTMLParser):
    def __init__(self):
        super().__init__()
        self.title = ""
        self.links = []
        self._in_title = False
    def handle_starttag(self, tag, attrs):
        d = dict(attrs)
        if tag == "title":
            self._in_title = True
        if tag == "a" and "href" in d:
            self.links.append(d["href"])
    def handle_endtag(self, tag):
        if tag == "title":
            self._in_title = False
    def handle_data(self, data):
        if self._in_title:
            self.title += data

html = ("<html><head><title>测试页</title></head><body><h1>你好</h1>"
        "<a href='/a.html'>A</a><a href='/b.html'>B</a></body></html>")
p = LinkParser()
p.feed(html)
print(p.title)     # 测试页
print(p.links)     # ['/a.html', '/b.html']
```

**答案**：`测试页` 和 `['/a.html', '/b.html']`（均为实测）。**要点**：① 要**继承 `HTMLParser` 并重写 `handle_starttag`/`handle_endtag`/`handle_data`** 三个方法；② **`title` 的文本在 `handle_data` 里**，要用一个 `_in_title` 标志位记录"当前是否在 title 标签内"；③ 属性以 `(名, 值)` 元组列表传入，用 `dict(attrs)` 转成字典更好用；④ **提取到的链接是相对地址**，要用 `urljoin` 转成绝对地址才能继续抓取。

## 易错点提醒

1. **`send`/`recv` 忘了编码转换** → 错：`TypeError: a bytes-like object is required, not 'str'`。对：发送 `.encode("utf-8")`，接收 `.decode("utf-8")`。
2. **用 `send` 而不是 `sendall`** → 错：`send` 可能只发一部分数据，对方收到的是残缺内容。对：**一律用 `sendall`**。
3. **以为 `recv` 返回 `b""` 表示"暂时没数据"** → 错：`recv` 没数据时会**阻塞**，返回 `b""` 只表示**对方关闭了连接**。对：用 `b""` 作为循环退出条件；不想阻塞就用 `settimeout` + 捕获 `socket.timeout`。
4. **以为 TCP 有消息边界** → 错：TCP 是字节流，两次 `send` 可能被一次 `recv` 读成一条。对：自己定协议边界（长度前缀、换行分隔、固定长度）。
5. **服务端没加 `SO_REUSEADDR`** → 错：重启时报 `OSError: [WinError 10048] 通常每个套接字地址只允许使用一次`。对：`srv.setsockopt(socket.SOL_SOCKET, socket.SO_REUSEADDR, 1)`。
6. **`bind` 用了已被占用的端口** → 错：`OSError: [WinError 10048]`。对：换端口，或先查出谁占用了（`netstat -ano | findstr :8888`）。
7. **端口扫描/爬虫没设超时** → 错：一个连不通的地址能让程序挂起几十秒，扫描 1000 个端口要跑几十分钟。对：`s.settimeout(0.3)` / `urlopen(url, timeout=5)`。
8. **socket 用完不关** → 错：连接和文件描述符泄漏，跑一会儿就报"打开文件过多"。对：`with conn:` 或 `try/finally` 里 `close()`。
9. **只捕获 `URLError` 而没先捕获 `HTTPError`** → 错：`HTTPError` 是 `URLError` 的**子类**，宽泛的会把它一起吞掉，拿不到状态码。对：**`HTTPError` 写在前面**。
10. **爬中文网页出现乱码** → 错：`requests` 猜的编码（常是 `ISO-8859-1`）不对。对：`r.encoding = r.apparent_encoding`，或显式 `r.encoding = "utf-8"`。
11. **忘了 `time.sleep` 礼貌延迟** → 错：短时间内高频请求会把对方服务器打垮，**可能构成破坏计算机信息系统罪**。对：每次请求间隔至少 1 秒。
12. **不检查 `robots.txt` 就爬** → 错：可能违反网站规则甚至法律。对：先用 `urllib.robotparser` 判断，禁止的路径绝不抓。
13. **`find_all("div", class="city")` 报语法错误** → 错：`class` 是 Python 关键字。对：写成 **`class_="city"`**。
14. **`accept()` 只调用一次就以为能服务多个客户端** → 错：`accept` 返回一个连接，处理完就结束了。对：把 `accept` 放进 `while True` 循环，并且**每个连接开一个线程**才能并发服务。
15. **在公网随意扫端口、抓包** → 错：违反《网络安全法》第27条，可能承担刑事责任。对：**只在自己拥有或明确授权的环境中做实验**。

## 本章小结

- **分层是网络的核心思想**：OSI 七层对应 TCP/IP 四层；**IP 定位机器，端口定位程序**（0~65535，1023 以下是知名端口）。
- **TCP 面向连接、可靠、字节流**（`SOCK_STREAM`，值 1）；**UDP 无连接、不可靠、保留消息边界**（`SOCK_DGRAM`，值 2）。网页用 TCP，直播和 DNS 用 UDP。
- **socket 编程套路**：服务端 `socket → bind → listen → accept → recv/sendall → close`；客户端 `socket → connect → sendall/recv → close`。**`recv` 返回 `b""` 表示对方关闭**；**`sendall` 而不是 `send`**；**发送前编码、接收后解码**。
- **URL 五个部分**：`scheme://netloc:port/path?query#fragment`；中文和空格要**百分号编码**（`quote`/`urlencode`）；相对链接用 **`urljoin`** 转绝对地址。
- **HTTP 请求—响应模型**，常用状态码 200/301/403/404/500；**GET 参数在 URL、POST 参数在请求体**。
- **`urllib` 是标准库应急方案，`requests` 是爬虫首选**；异常要先捕 `HTTPError` 再捕 `URLError`；中文乱码用 `r.encoding = r.apparent_encoding` 修。
- **合规红线**：遵守 `robots.txt`（`urllib.robotparser` 判断）、`time.sleep` 礼貌延迟、不抓隐私与付费内容、不商用、**不扫描或嗅探未授权的网络**。
- **Django 用 MTV 模式**：Model（ORM 数据）+ Template（页面）+ View（逻辑）+ URL 路由；`makemigrations → migrate → runserver` 三步跑起来。

> **一句话记住本章**：**socket 是"网络上的文件"（服务端 bind-listen-accept、客户端 connect，收发都要 encode/decode）；爬虫要先用 `robotparser` 问一句"能不能抓"，再带上 UA、timeout 和 `time.sleep` 礼貌地去抓。**

12. 写一段代码，把 `"http://x.com/a/b.html"` 和 `"../c.html"` 拼成绝对地址。

**参考答案**

1. `AF_INET` 是 **IPv4 地址族**（值 2）；`SOCK_STREAM` 是 **TCP**（值 1），用于可靠传输（网页、文件、邮件）；`SOCK_DGRAM` 是 **UDP**（值 2），用于追求速度、允许丢包的场景（直播、语音、DNS、游戏）。
2. ① **连接**：TCP 面向连接（三次握手），UDP 无连接；② **可靠性**：TCP 丢包重传、按序到达，UDP 不保证；③ **数据形式**：TCP 是字节流（无边界），UDP 是数据报（有边界）；④ **速度与范围**：UDP 更快且支持广播/组播。网页必须**一个字节都不能错**（缺一个字符页面就坏了），所以用可靠的 TCP。
3. 服务端：`socket()` → `bind()` → `listen()` → `accept()` → `recv()`/`sendall()` → `close()`。客户端**没有 `bind`（通常）、没有 `listen`、没有 `accept`**，改成 `connect()`：`socket()` → `connect()` → `sendall()`/`recv()` → `close()`。
4. 表示**对方已经关闭了连接**（收到了 TCP 的 FIN）。**它和"暂时没数据"完全不同**：暂时没数据时 `recv` 会**一直阻塞等待**，直到有数据或对方关闭；要避免阻塞必须 `settimeout()`。
5. `send` 返回**实际发送的字节数**，可能小于要求发送的长度（缓冲区满时只发一部分）；`sendall` 内部循环发送直到全部发完，失败则抛异常。**一律用 `sendall`**。
6. 服务端关闭后，TCP 连接会进入 `TIME_WAIT` 状态并占用该端口一段时间。不加 `SO_REUSEADDR` 时，立刻重启服务端会报 `OSError: [WinError 10048] 通常每个套接字地址只允许使用一次`。加上它就能立即重用端口，**调试时必加**。
7. `scheme=https`（协议）、`netloc=www.example.com:8080`（主机加端口）、`path=/path`（路径）、`query=x=1`（查询参数）、`fragment=frag`（锚点）。**`fragment`（锚点）不会发送给服务器**——它只供浏览器在页面内定位。
8. 结果是 **`%E4%BD%A0%E5%A5%BD`**。URL 规范只允许出现 ASCII 字符，中文、空格等必须转成 `%` 加十六进制字节（UTF-8 编码后每个字节一个 `%XX`）。空格通常编码为 `%20`。
9. **`HTTPError` 是 `URLError` 的子类**。`HTTPError` 表示"服务器有响应但状态码是错误"（404/403/500），能拿到 `code` 和 `reason`；`URLError` 表示"根本连不上"（DNS 失败、超时、拒绝连接）。捕获时 **`HTTPError` 必须写在前面**，否则会被 `URLError` 一起吞掉，拿不到状态码。
10. ① **遵守 `robots.txt`**，禁止的路径不抓；② **控制频率**（`time.sleep` 至少 1 秒），不把对方服务器打垮；③ **不抓隐私、付费内容，不绕过登录和验证码**；④ **只用于学习研究，不商用不转卖**。`robots.txt` **没有强制力**（是君子协定），但违反它可能构成不正当竞争甚至触犯《刑法》第285/286条。
11. **M**odel 模型（对应 MVC 的 Model，负责数据与 ORM）、**T**emplate 模板（对应 MVC 的 View，负责页面呈现）、**V**iew 视图（对应 MVC 的 Controller，负责处理请求与业务逻辑），再加 **URL 路由**负责分派。
