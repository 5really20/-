## 8.1 概述

**正则表达式解决的是"模糊查找"问题**。`"abc" in text` 只能找固定的子串，但如果你想找「所有手机号」「所有金额」「所有邮箱」，就需要描述"**模式**"。

**四个典型用途**：

| 用途 | 函数 | 例子 |
|---|---|---|
| **查找** | `findall` / `search` | 从文本里挑出所有邮箱 |
| **替换** | `sub` | 把手机号中间四位打码 |
| **切分** | `split` | 按「逗号/分号/空格」任意一种切分 |
| **校验** | `fullmatch` | 检查用户输入是不是合法手机号 |

**为什么正则字符串前面要加 `r`？**

```python
import re

print(re.findall(r"\d+", "a12b345"))    # ['12', '345']   ← 正确写法
print(re.findall("\d+", "a12b345"))     # ['12', '345']   ← 碰巧也对
print(r"\d+", "\d+", len(r"\d+"), len("\d+"))
# \d+ \d+ 3 3        ← \d 不是合法转义，Python 保留了反斜杠
print(len(r"\b"), len("\b"))
# 2 1               ← 不加 r 时 \b 被解释成"退格符"！
```

> **结论：正则表达式一律写原始字符串 `r"..."`。** 不加 `r` 时，Python 会**先做一次字符串转义**，`\b`（词边界）会变成退格符、`\n` 会变成换行，正则引擎拿到的就不是你想要的模式了。**这是一个不报错但结果诡异的坑。**

## 8.2 正则表达式语法

### 字符类 `[]`

**`[]` 表示"括号里任意一个字符"**。

| 写法 | 含义 | 匹配例子 |
|---|---|---|
| `[abc]` | a 或 b 或 c | `"b"` |
| `[a-z]` | 任意小写字母 | `"q"` |
| `[a-zA-Z0-9]` | 字母或数字 | `"K"`、`"7"` |
| `[^abc]` | **除** a、b、c 之外的任意字符 | `"x"` |
| `[0-9.]` | 数字或点号 | `"3"`、`"."` |

```python
import re

print(re.findall(r"[aeiou]", "hello world"))        # ['e', 'o', 'o']
print(re.findall(r"[^aeiou ]", "hello world"))      # ['h', 'l', 'l', 'w', 'r', 'l', 'd']
print(re.findall(r"[a-z]+", "abc123DEF"))           # ['abc']
```

> **`[]` 内部的三个特殊规则**：① **`^` 放在开头才表示"取反"**，放中间就是普通字符；② `]` 要放**第一位**才是普通字符（`[]]` 匹配 `]`）；③ **`[]` 里的大部分元字符失去特殊含义**，如 `[.]` 就是匹配一个点号，不需要转义。

### 预定义字符类（必背）

| 符号 | 含义 | ASCII 近似写法 | 注意 |
|---|---|---|---|
| `\d` | 一个数字 | `[0-9]` | **str 模式下是 Unicode 语义**，能匹配 `٣` 等非 ASCII 数字；要退回 ASCII 加 `re.ASCII` |
| `\D` | 一个非数字 | `[^0-9]` | —— |
| `\w` | 单词字符 | `[a-zA-Z0-9_]` | **包含下划线**；**str 模式下默认能匹配中文**（见下方坑①） |
| `\W` | 非单词字符 | `[^a-zA-Z0-9_]` | —— |
| `\s` | 空白字符 | `[ \t\n\r\f\v]` | 含空格、制表、换行；**默认还含全角空格 `\u3000`** |
| `\S` | 非空白字符 | —— | —— |
| `.` | **任意字符（不含换行）** | —— | 想含换行要加 `re.S` |

```python
print(re.findall(r"\w+", "hello, world_1!"))    # ['hello', 'world_1']
print(re.findall(r"\s", "a b\tc"))              # [' ', '\t']   共 2 个
print(re.findall(r".", "a\nb"))                 # ['a', 'b']    ← 点号不含换行
print(re.findall(r".", "a\nb", re.S))           # ['a', '\n', 'b']

# ★ \w 的 Unicode 语义（最容易搞错的一条）
print(re.findall(r"\w+", "中文abc"))            # ['中文abc']   ← 中文也算单词字符！
print(re.findall(r"\w+", "中文abc", re.ASCII))  # ['abc']       ← 加 re.ASCII 才退回 ASCII
print(re.findall(rb"\w+", "中文abc".encode()))  # [b'abc']      ← bytes 模式才是 ASCII 语义
print(re.findall(r"\d+", "٣"))                  # ['٣']         ← 阿拉伯-印度数字也算 \d
print(re.findall(r"\d+", "٣", re.ASCII))        # []            ← 加 re.ASCII 后不匹配
```

> **两个高频坑**：
>
> ① **`\w` 在 str 模式下默认是 Unicode 语义，能匹配中文**（`re.compile(r"\w").flags == 32 == re.UNICODE`），所以 `re.findall(r"\w+", "中文abc")` 得到 `['中文abc']` 而**不是** `['abc']`。**只有显式加 `re.ASCII` 才退回 ASCII 语义**（`['abc']`）；`bytes` 模式（`rb"\w+"`）本身就是 ASCII 语义。同理 `\d` 也不是严格的 `[0-9]`（能匹配 `٣`），`\s` 还包含全角空格。
>
> **实际后果**：想写「只允许字母数字下划线」的用户名校验，**绝不能用 `\w+`**——`re.fullmatch(r"\w+", "a中文中")` 会返回 Match（通过校验！）。必须写成显式的 ASCII 字符类：
>
> ```python
> print(re.fullmatch(r"\w+", "a中文中"))              # <re.Match ...>   ← 中文混进来了，校验失效
> print(re.fullmatch(r"[A-Za-z0-9_]+", "a中文中"))    # None             ← 正确写法，拦住中文
> print(re.fullmatch(r"\w+", "a中文中", re.ASCII))    # None             ← 加 re.ASCII 也可以
> ```
>
> 要**匹配**中文时反而不用特意做什么，`\w` 本来就认；只想要汉字本身则用 `[\u4e00-\u9fa5]`。
>
> ② **`.` 不匹配换行**，处理多行 HTML 时必须加 `re.S`。

### 量词

| 量词 | 含义 | 例子 |
|---|---|---|
| `*` | 前面的东西出现 **0 次或多次** | `ab*` 匹配 `a`、`ab`、`abbb` |
| `+` | **1 次或多次** | `ab+` 匹配 `ab`、`abbb`（**不含 `a`**） |
| `?` | **0 次或 1 次** | `ab?` 匹配 `a`、`ab` |
| `{n}` | 恰好 n 次 | `a{3}` |
| `{n,}` | 至少 n 次 | `a{2,}` |
| `{n,m}` | n 到 m 次 | `a{2,3}` |

```python
print(re.findall(r"ab*", "a ab abb abbb"))      # ['a', 'ab', 'abb', 'abbb']
print(re.findall(r"ab+", "a ab abb abbb"))      # ['ab', 'abb', 'abbb']
print(re.findall(r"ab?", "a ab abb abbb"))      # ['a', 'ab', 'ab', 'ab']
print(re.findall(r"a{2,3}", "a aa aaa aaaa"))   # ['aa', 'aaa', 'aaa']
```

> **`*` 与 `+` 只差一个字符，结果差别很大**：`ab*` 里的 `b` 可有可无，所以 `"a"` 也能匹配；`ab+` 要求至少一个 `b`，所以 `"a"` 被跳过。**校验"至少一个数字"要用 `\d+`，不能用 `\d*`（`\d*` 连空串都算匹配）。**

> **`a{2,3}` 对 `"aaaa"` 的结果是 `'aaa'`**：正则从左往右匹配，一次吃掉 3 个 `a`，剩下 1 个不够 2 个，丢弃。

### 边界

| 符号 | 含义 |
|---|---|
| `^` | 字符串开头（加 `re.M` 后是**每行**开头） |
| `$` | 字符串结尾（加 `re.M` 后是**每行**结尾） |
| `\b` | **单词边界**（单词与非单词字符之间） |
| `\B` | 非单词边界 |
| `\A` / `\Z` | 整个字符串的开头 / 结尾（不受 `re.M` 影响） |

```python
print(re.findall(r"^ab", "ab\nab", re.M))            # ['ab', 'ab']
print(re.findall(r"\bcat\b", "cat category cat."))   # ['cat', 'cat']  ← 不匹配 category
print(re.findall(r"\Bcat", "cat concat"))            # ['cat']         ← 只要 concat 里的
```

> **`\bcat\b` 为什么能排除 `category`？** 因为 `category` 里 `cat` 后面紧跟 `e`（单词字符），不构成**边界**。**做「整词匹配」时必须加 `\b`**，否则 `cat` 会匹配到 `category`、`concatenate` 里。

### 分组与反向引用

**`()` 把一部分模式括起来，当作一个整体，并"记住"匹配到的内容。**

| 写法 | 含义 |
|---|---|
| `(abc)+` | `abc` 整体重复 |
| `(a\|b)` | a 或 b |
| `(?:abc)` | **非捕获组**：只分组不记忆，省内存 |
| `\1` `\2` | **反向引用**：引用第 1、2 个分组匹配到的内容 |
| `(?P<name>...)` | **命名分组**，用 `group("name")` 取值 |

```python
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", "2025-09-01")
print(m.group(), m.group(1), m.groups())
# 2025-09-01 2025 ('2025', '09', '01')

m2 = re.search(r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", "2025-09-01")
print(m2.group("y"), m2.groupdict())
# 2025 {'y': '2025', 'm': '09', 'd': '01'}

print(re.search(r"(ab)+", "ababab").group())        # ababab
print(re.search(r"(a)(b)\2\1", "abba").group())     # abba   反向引用
```

**三个取值方法的区别**：

| 方法 | 返回 | 例子（对 `2025-09-01`） |
|---|---|---|
| `group()` / `group(0)` | **整个匹配** | `'2025-09-01'` |
| `group(n)` | 第 n 个分组 | `group(1)` → `'2025'` |
| `groups()` | **所有分组组成的元组** | `('2025', '09', '01')` |
| `groupdict()` | 命名分组的字典 | `{'y': '2025', ...}` |
| `span()` | 匹配的起止下标 | `(0, 10)` |

> **坑：分组数不对会 `IndexError: no such group`。** 数分组的方法是「**数左括号**」（`(?:` 不算）。写复杂正则时建议用**命名分组**，可读性高且不易数错。

### 贪婪与非贪婪

**默认是贪婪匹配：量词会尽可能多地吃字符。**

```python
print(re.findall(r"<.*>", "<a><b>"))     # ['<a><b>']   ← 贪婪：一口吃到底
print(re.findall(r"<.*?>", "<a><b>"))    # ['<a>', '<b>']  ← 非贪婪：吃最少
```

| 写法 | 类型 | 行为 |
|---|---|---|
| `*` `+` `?` `{n,m}` | **贪婪**（默认） | 尽可能**多**匹配 |
| `*?` `+?` `??` `{n,m}?` | **非贪婪** | 尽可能**少**匹配 |

> **实用建议**：解析 HTML 时 `.*` 常常"跨标签"匹配，把 `<a>...</a><a>...</a>` 整段吃掉。**只要模式里出现 `.*`，就下意识改成 `.*?`**，或者更稳妥地用 `[^>]*` 这种"排除型字符类"（不依赖非贪婪，性能更好）。**但要注意：`.*?` 也不是万能的，嵌套标签仍需要专门的 HTML 解析器（如 BeautifulSoup）。**

### 或 `|` 与转义

```python
print(re.findall(r"cat|dog", "cat dog cow"))     # ['cat', 'dog']
print(re.findall(r"\.", "a.b.c"))                # ['.', '.']   转义点号
print(re.findall(r"3\.14", "3.14 3a14"))         # ['3.14']     不转义会连 3a14 也匹配
```

> **必须转义的字符（共 14 个）**：`. ^ $ * + ? { } [ ] \ | ( )`。**其中最常忘的是 `.`**——`re.findall(r"\d.\d", "1.2 1a2")` 会把 `1a2` 也匹配出来。**`|` 的作用范围是整个表达式**，`cat|dog food` 表示「`cat` 或 `dog food`」，要限定范围必须用 `(cat|dog) food`。

## 8.3 使用正则表达式模块处理字符串

### 8.3.1 Re 模块中的常用函数

| 函数 | 作用 | 返回值 | 匹配范围 |
|---|---|---|---|
| `re.match(p, s)` | 从**开头**匹配 | `Match` 或 `None` | **只在开头** |
| `re.search(p, s)` | 扫描**任意位置**找第一个 | `Match` 或 `None` | 全文找第一个 |
| `re.fullmatch(p, s)` | **整个字符串**必须完全匹配 | `Match` 或 `None` | 必须全长 |
| `re.findall(p, s)` | 找出**所有**匹配 | **字符串列表** | 全文 |
| `re.finditer(p, s)` | 找出所有匹配 | **Match 迭代器** | 全文 |
| `re.sub(p, repl, s, count)` | 替换 | 新字符串 | 全文 |
| `re.split(p, s, maxsplit)` | 按模式切分 | 字符串列表 | 全文 |
| `re.compile(p, flags)` | 预编译 | `Pattern` 对象 | —— |

```python
import re

print(re.match(r"\d+", "abc123"))               # None      ← 开头不是数字
print(re.match(r"\d+", "123abc").group())       # 123
print(re.search(r"\d+", "abc123def456").group())# 123       ← 第一个
print(re.findall(r"\d+", "abc123def456"))       # ['123', '456']
print(re.fullmatch(r"\d+", "123abc"))           # None      ← 有剩余字符
print(re.fullmatch(r"\d+", "123") is not None)  # True
```

> **`match` / `search` / `fullmatch` 三者的区别（必考）**：`match` 要求**从第 0 个字符开始**匹配（后面可以有多余字符）；`search` 允许**从任意位置**开始；`fullmatch` 要求**整个字符串恰好匹配完**。
>
> **校验场景一律用 `fullmatch`**（或 `match` + `$`）。**用 `match(r"\d+", "123abc")` 校验会通过**，因为它只看开头——这是表单校验最经典的漏洞。

**`findall` 与 `finditer` 的选择**：

```python
print([m.span() for m in re.finditer(r"\d+", "a12b345")])
# [(1, 3), (4, 7)]          ← finditer 能拿到位置
print([m.group() for m in re.finditer(r"\d+", "a12b345")])
# ['12', '345']

# 有分组时 findall 只返回分组内容
print(re.findall(r"(\d)(\d)", "12 34"))     # [('1', '2'), ('3', '4')]
print(re.findall(r"\d\d", "12 34"))         # ['12', '34']
```

> **坑：`findall` 遇到分组会改变返回值。** 有 **1 个**分组时返回**分组内容**的列表；有**多个**分组时返回**元组**列表；没有分组时返回整体匹配。**这个行为经常让人拿到意想不到的结果**——需要整体匹配又想分组时，用 `finditer` + `m.group(0)`。

**`sub` 替换的三种用法**：

```python
print(re.sub(r"\d+", "#", "a1b22c333"))                  # a#b#c#
print(re.sub(r"\d+", "#", "a1b22", count=1))             # a#b22
print(re.sub(r"(\w+)@(\w+)\.com", r"\2@\1", "user@example.com"))
# example@user          ← \1 \2 引用分组

# 用函数做动态替换
print(re.sub(r"\d", lambda m: str(int(m.group()) * 2), "a1b2"))   # a2b4
```

> **`sub` 的第二个参数**：普通字符串里 `\1` 表示分组引用；**如果替换文本本身要含反斜杠，用 `r""` 并注意转义**。用**函数**做替换时，函数收到 `Match` 对象，返回值就是替换内容——这是「手机号打码」「金额加千分位」的关键技巧。

**`split` 切分**：

```python
print(re.split(r"[,;\s]+", "a,b; c  d"))    # ['a', 'b', 'c', 'd']
print(re.split(r"(\d)", "a1b2c"))           # ['a', '1', 'b', '2', 'c']
```

> **`split` 用捕获组时会保留分隔符**（上例中数字被保留）。这在「既要切分又要保留分隔符」时很有用，但不知道这一点就会困惑结果为什么多了元素。

**标志位 flags**：

| 标志 | 全称 | 作用 |
|---|---|---|
| `re.I` | IGNORECASE | **忽略大小写** |
| `re.M` | MULTILINE | **`^` `$` 匹配每行**开头结尾 |
| `re.S` | DOTALL | **`.` 也匹配换行** |
| `re.X` | VERBOSE | 允许正则里写注释和空格 |

```python
print(re.findall(r"python", "Python PYTHON", re.I))      # ['Python', 'PYTHON']
print(re.findall(r"^\w+", "abc\ndef", re.M))             # ['abc', 'def']
print(re.sub(r"\s+", " ", "a   b\n\tc"))                 # a b c
```

> **`re.sub(r"\s+", " ", s)` 是文本清洗的第一招**：把任意多个空白（含换行、制表）压成一个空格。

**`compile` 预编译**：

```python
p = re.compile(r"\d+")
print(p.pattern, p.findall("x9"))       # \d+ ['9']
```

> **什么时候用 `compile`？** 同一个正则**重复使用很多次**时（例如循环几万次），预编译能避免重复解析模式串，**有性能收益**。只用一次就直接 `re.xxx()`——**Python 内部有缓存，不必为了"优化"而强行 compile**。

### 8.3.2 常用正则表达式

**这些模式建议直接背下来**：

| 用途 | 正则 | 说明 |
|---|---|---|
| 手机号（中国大陆） | `^1[3-9]\d{9}$` | 1 开头，第 2 位 3~9，共 11 位 |
| 邮箱 | `^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$` | 简化版，够用 |
| 身份证号（18 位） | `^\d{17}[\dXx]$` | 最后一位可能是 X |
| 邮政编码 | `^\d{6}$` | —— |
| 日期（YYYY-MM-DD） | `^\d{4}-\d{2}-\d{2}$` | 只校验格式，不校验合法性 |
| 时间（HH:MM:SS） | `^\d{2}:\d{2}:\d{2}$` | —— |
| IPv4 | `^(\d{1,3}\.){3}\d{1,3}$` | 简化版，不校验 0~255 |
| 整数 | `^-?\d+$` | 允许负号 |
| 浮点数 | `^-?\d+(\.\d+)?$` | 小数部分可选 |
| 中文字符 | `[\u4e00-\u9fa5]` | 常用汉字区间 |
| URL | `https?://[\w./-]+` | 简化版 |
| 金额 | `\d+\.\d{2}` | 两位小数 |

```python
print(re.findall(r"1[3-9]\d{9}", "电话13812345678和13900000000"))
# ['13812345678', '13900000000']
print(re.match(r"1[3-9]\d{9}$", "13812345678") is not None)     # True
print(re.findall(r"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}", "a@b.com x@y.cn 无效@"))
# ['a@b.com', 'x@y.cn']
print(re.findall(r"\d+\.?\d*", "共 12.5 元和 30 元"))            # ['12.5', '30']
```

> **正则校验的边界（重要认知）**：**正则只能校验"格式"，不能校验"真实性"**。`^\d{4}-\d{2}-\d{2}$` 会放过 `2025-99-99`；`^1[3-9]\d{9}$` 会放过不存在的号码。**日期合法性要用 `datetime.strptime` 真解析一次**：
>
> ```python
> import datetime
> def valid_date(s):
>     try:
>         datetime.datetime.strptime(s, "%Y-%m-%d")
>         return True
>     except ValueError:
>         return False
> print(valid_date("2025-99-99"), valid_date("2025-09-01"))   # False True
> ```

## 8.4 典型案例

### 8.4.1 提取并汇总字符串中的费用

**问题**：从一段含多种金额写法的文本里提取所有费用并求和。

```python
import re

text = """
本次采购明细如下：
办公用品：￥128.50 元
打印纸：$30.00
交通费：45 元
餐费：￥12.50 元
优惠：-20 元
"""

# 思路：先统一符号，再提取数字
nums = re.findall(r"[-+]?\d+\.?\d*", text)
print(nums)
# ['128.50', '30.00', '45', '12.50', '-20']

amounts = [float(n) for n in nums]
print("共", len(amounts), "笔，合计", round(sum(amounts), 2), "元")
# 共 5 笔，合计 196.0 元

# 更精确：只提取"带货币符号"或"空格+数字+元"的金额
pat = re.compile(r"[￥$](\d+\.?\d*)|\s(\d+)\s*元")
pairs = pat.findall(text)
print(pairs)
# [('128.50', ''), ('30.00', ''), ('12.50', '')]   ← 只有 3 条！
```

> **两个要点**：① **模式里有两个分组时 `findall` 返回元组列表**，每个元组里总有一个是空串（因为两个分支只会命中一个），处理时写 `a or b` 合并；② 上例**漏掉了 `交通费：45 元`**——因为模式里第二个分支要求数字前是 `\s`（空白），而原文中 `45` 前面是全角冒号 `：`，不是空白。**这说明"金额提取"的难点不在数字本身，而在前缀符号的多样性。**
>
> **更稳的写法是「可选前缀 + 数字」一步到位**：
>
> ```python
> print(re.findall(r"[￥$]?\s*-?\d+\.?\d*", text))
> # ['￥128.50', '$30.00', '45', '￥12.50', '-20']    ← 连符号一起抓到
> print([re.sub(r"[￥$]", "", x) for x in re.findall(r"[￥$]?\s*-?\d+\.?\d*", text)])
> # ['128.50', '30.00', '45', '12.50', '-20']         ← 再去掉符号
> ```

### 8.4.2 校验字符串合法性

**问题**：写一个注册信息校验函数，检查用户名、手机号、邮箱、密码。

```python
import re

def check_username(s):
    """4~16 位，字母开头，只能含字母数字下划线"""
    # ⚠️ 不能用 \w：str 模式下 \w 是 Unicode 语义，会把中文也放进来
    return bool(re.fullmatch(r"[A-Za-z][A-Za-z0-9_]{3,15}", s))

def check_phone(s):
    """中国大陆手机号"""
    return bool(re.fullmatch(r"1[3-9]\d{9}", s))

def check_email(s):
    return bool(re.fullmatch(r"[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}", s))

def check_password(s):
    """8~20 位，必须同时含字母和数字，不能有空格"""
    if not re.fullmatch(r"\S{8,20}", s):
        return False
    return bool(re.search(r"[A-Za-z]", s)) and bool(re.search(r"\d", s))

tests = [
    ("用户名", check_username, ["abc", "zhang_01", "1abc", "ab", "a中文中"]),
    ("手机号", check_phone, ["13812345678", "12812345678", "1381234567"]),
    ("邮箱", check_email, ["a@b.com", "x@y.cn", "无效@", "a@b"]),
    ("密码", check_password, ["abc12345", "abcdefgh", "12345678", "abc 1234"]),
]
for name, fn, cases in tests:
    print(name, [fn(c) for c in cases])
# 用户名 [False, True, False, False, False]
# 手机号 [True, False, False]
# 邮箱 [True, True, False, False]
# 密码 [True, False, False, False]
```

> **关键点**：① 校验必须用 **`fullmatch`**（或 `^...$`），用 `match` 会放过 `"13812345678abc"`；② `bool()` 把 `Match`/`None` 转成 `True`/`False`，便于返回布尔值；③ **「必须同时含字母和数字」这类"组合条件"用两个 `search` 相与**，硬写成一个正则反而难读；④ 用户名的字符类必须写 **`[A-Za-z0-9_]`**，写成 `\w` 会因 Unicode 语义放过中文（见 8.2 的坑①）。

### 8.4.3 解析网页内容

**问题**：从一段 HTML 里提取所有链接、去标签取纯文本、提取标题。

```python
import re

html = """
<html><head><title>Python 教程</title></head>
<body>
<h1>第一章</h1>
<a href="http://example.com/a">链接A</a>
<a href='https://example.com/b'>链接B</a>
<p>正文段落 <b>加粗</b> 内容</p>
</body></html>
"""

print(re.findall(r'<a href="([^"]+)"', html))
# ['http://example.com/a']          ← 只找到双引号的那种

print(re.findall(r"""<a href=["']([^"']+)["']""", html))
# ['http://example.com/a', 'https://example.com/b']

print(re.findall(r"<title>(.*?)</title>", html, re.S))
# ['Python 教程']

print(re.sub(r"<[^>]+>", "", html).strip()[:40])
# 输出是带换行的（用 repr 看得最清楚）：
print(repr(re.sub(r"<[^>]+>", "", html).strip()))
# 'Python 教程\n\n第一章\n链接A\n链接B\n正文段落 加粗 内容'

print(re.sub(r"\s+", " ", re.sub(r"<[^>]+>", "", html)).strip()[:50])
# Python 教程 第一章 链接A 链接B 正文段落 加粗 内容
```

**三个技巧**：

| 技巧 | 写法 | 作用 |
|---|---|---|
| 匹配两种引号 | `["']([^"']+)["']` | HTML 属性单双引号混用 |
| **排除型字符类** | `[^"]+` 代替 `.*?` | **更稳、更快**，不会跨标签 |
| 去标签 | `re.sub(r"<[^>]+>", "", html)` | 拿纯文本 |

> **必须知道的局限**：**正则不适合解析 HTML**。HTML 不是正则语言，嵌套标签、注释、CDATA 都会让正则失效。**生产环境一律用 BeautifulSoup 或 lxml**（第 14 章会讲）。**正则只适合"结构简单、格式统一"的抽取**，比如从一段日志里抓 IP、从一段文本里抓手机号。

## 典型例题

**例 8.1**（题型：读程序写结果——基础函数对比）

```python
import re

print(re.match(r"\d+", "abc123"))
print(re.match(r"\d+", "123abc").group())
print(re.search(r"\d+", "abc123def456").group())
print(re.findall(r"\d+", "abc123def456"))
print(re.fullmatch(r"\d+", "123abc"))
print(re.fullmatch(r"\d+", "123") is not None)
```

**解**：`match` 只在**开头**匹配，`"abc123"` 开头不是数字 → `None`；`"123abc"` 开头有数字 → `123`。`search` 找**第一个** → `123`。`findall` 找**全部** → 两个。`fullmatch` 要求**整串匹配**，`"123abc"` 有剩余 → `None`；`"123"` 恰好匹配 → `True`。

**答案**：

```
None
123
123
['123', '456']
None
True
```

**例 8.2**（题型：读程序写结果——量词与贪婪）

```python
import re

print(re.findall(r"ab*", "a ab abb abbb"))
print(re.findall(r"ab+", "a ab abb abbb"))
print(re.findall(r"ab?", "a ab abb abbb"))
print(re.findall(r"a{2,3}", "a aa aaa aaaa"))
print(re.findall(r"<.*>", "<a><b>"))
print(re.findall(r"<.*?>", "<a><b>"))
```

**解**：`*` 是 0 次或多次，`b` 可有可无，所以 `"a"` 也匹配；`+` 要求至少 1 个 `b`，跳过 `"a"`；`?` 最多 1 个 `b`，`"abb"` 只取到 `"ab"`。`a{2,3}` 对 `"aaaa"` 从左往右吃 3 个，剩 1 个不够，得 `'aaa'`。`<.*>` 贪婪，一口吃到底；`<.*?>` 非贪婪，吃最少。

**答案**：

```
['a', 'ab', 'abb', 'abbb']
['ab', 'abb', 'abbb']
['a', 'ab', 'ab', 'ab']
['aa', 'aaa', 'aaa']
['<a><b>']
['<a>', '<b>']
```

**例 8.3**（题型：编程题——分组提取与格式转换）

从 `"2025-09-01"` 提取年月日，输出成 `"2025年09月01日"`；再把 `"user@example.com"` 改成 `"example@user"`。

```python
import re

s = "2025-09-01"
m = re.search(r"(\d{4})-(\d{2})-(\d{2})", s)
print(m.groups())                                   # ('2025', '09', '01')
print(f"{m.group(1)}年{m.group(2)}月{m.group(3)}日")
# 2025年09月01日
print(re.sub(r"(\d{4})-(\d{2})-(\d{2})", r"\1年\2月\3日", s))
# 2025年09月01日

print(re.sub(r"(\w+)@(\w+)\.com", r"\2@\1", "user@example.com"))
# example@user

m2 = re.search(r"(?P<y>\d{4})-(?P<m>\d{2})-(?P<d>\d{2})", s)
print(m2.group("y"), m2.groupdict())
# 2025 {'y': '2025', 'm': '09', 'd': '01'}
```

**解**：`()` 是**捕获组**，`group(n)` 取第 n 组，`groups()` 一次拿到所有组。`sub` 的替换串里 `\1` `\2` 引用分组内容，实现**位置交换**。命名分组用 `(?P<name>...)` 定义，用 `group("name")` 或 `groupdict()` 取值，**分组多时强烈推荐**。

**答案**：见注释。

**例 8.4**（题型：编程题——手机号打码与文本清洗）

把文本中所有手机号中间四位替换成 `****`；把连续空白压缩成一个空格。

```python
import re

text = "联系人：13812345678，备用 13900000000。   备注：   测试   数据"

masked = re.sub(r"(1[3-9]\d)\d{4}(\d{4})", r"\1****\2", text)
```

写函数校验：用户名（4~16 位，字母开头）、手机号、邮箱、强密码（8~20 位，含字母和数字）。

```python

print(check_username("zhang_01"), check_username("1abc"), check_username("ab"), check_username("a中文中"))
```

**例 8.6**（题型：编程题——日志解析与统计）

从日志文本中提取所有 IP 和状态码，统计每个 IP 的访问次数。

```python
import re
from collections import Counter

log = """
192.168.1.10 - - [01/Sep/2025:10:00:01] "GET /index.html HTTP/1.1" 200 1024
192.168.1.11 - - [01/Sep/2025:10:00:02] "POST /login HTTP/1.1" 302 512
192.168.1.10 - - [01/Sep/2025:10:00:03] "GET /style.css HTTP/1.1" 200 2048
192.168.1.12 - - [01/Sep/2025:10:00:04] "GET /missing HTTP/1.1" 404 128
192.168.1.10 - - [01/Sep/2025:10:00:05] "GET /api/data HTTP/1.1" 500 64
"""

ips = re.findall(r"\b(?:\d{1,3}\.){3}\d{1,3}\b", log)
print(ips)
# ['192.168.1.10', '192.168.1.11', '192.168.1.10', '192.168.1.12', '192.168.1.10']

codes = re.findall(r'"\s(\d{3})\s', log)
print(codes)                                # ['200', '302', '200', '404', '500']

# [('192.168.1.10', 3), ('192.168.1.11', 1), ('192.168.1.12', 1)]

```

**例 8.7**（题型：编程题——HTML 内容提取）

从 HTML 片段提取标题、所有链接、去标签后的纯文本。


## 易错点提醒

1. **正则字符串不加 `r` 前缀。**
   - 错在哪：`"\b"` 被 Python 解释成**退格符**（长度 1），正则引擎收到的不是"词边界"，匹配结果诡异且不报错。
   - 正确做法：正则一律写 `r"..."`。
2. **校验时用 `match` 而不是 `fullmatch`。**
   - 错在哪：`match(r"1[3-9]\d{9}", "13812345678abc")` 返回 `Match`（只看开头），非法输入被判为合法。
   - 正确做法：用 `re.fullmatch()`，或写成 `re.match(r"^...$", s)`。
3. **`\w` 以为等价 `[a-zA-Z0-9_]`（两个方向都会错）。**
   - 错在哪：① **`\w` 在 str 模式下是 Unicode 语义**，`re.fullmatch(r"\w+", "a中文中")` 会**通过**，用它写「只允许字母数字下划线」的用户名校验会失效；② 反过来以为 `\w` 能匹配一切，则 `\w` **不含空格、标点**。
   - 正确做法：**要限制成 ASCII 就显式写字符类**（`[A-Za-z0-9_]`）或加 `re.ASCII`；要匹配中文用 `[\u4e00-\u9fa5]`。
4. **`.` 不匹配换行。**
   - 错在哪：跨行抓 HTML 或日志时，`<title>(.*)</title>` 在多行文本上匹配不到。
   - 正确做法：加 `re.S`，或用 `[\s\S]*?`。
5. **贪婪匹配吃掉太多。**
   - 错在哪：`<.*>` 对 `"<a><b>"` 得到 `'<a><b>'` 而不是两个标签。
   - 正确做法：改非贪婪 `.*?`，或更稳地用排除型字符类 `[^>]*`。
6. **该转义的 `.` 没转义。**
   - 错在哪：`\d.\d` 里的 `.` 是"任意字符"，`"1a2"` 也被匹配。
   - 正确做法：字面量点号写 `\.`；记住需转义的 **14** 个字符 `. ^ $ * + ? { } [ ] \ | ( )`。
7. **`findall` 有分组时返回值变了。**
   - 错在哪：`re.findall(r"(\d)(\d)", "12 34")` 得到 `[('1','2'), ('3','4')]` 而不是 `['12','34']`。
   - 正确做法：需要整体匹配就用 `finditer` + `m.group(0)`，或把分组改成非捕获组 `(?:...)`。
8. **用 `$` 校验却忘了它允许末尾换行。**
   - 错在哪：Python 的 `$` 在字符串末尾有 `\n` 时也能匹配上（`re.match(r"^\d+$", "123\n")` 成功）。
   - 正确做法：严格校验用 **`fullmatch`** 或 `\Z`。
9. **用正则校验日期合法性。**
   - 错在哪：`^\d{4}-\d{2}-\d{2}$` 会放过 `2025-99-99`。
   - 正确做法：正则只筛格式，再用 `datetime.datetime.strptime()` 真解析一次并捕获 `ValueError`。
10. **用正则解析 HTML。**
    - 错在哪：HTML 有嵌套标签、注释、单双引号混用，正则无法正确处理嵌套，稍复杂就失效。
    - 正确做法：结构简单的片段可用正则抽取；**正式解析用 BeautifulSoup / lxml**。

## 本章小结

- **正则用"模式"描述一类字符串**，四大用途：查找、替换、切分、校验。
- **正则字符串必须加 `r` 前缀**，否则 `\b`、`\n` 会先被 Python 当转义符处理掉。
- **字符类** `[abc]`、`[a-z]`、`[^abc]`；**预定义类** `\d` `\w` `\s` 及其大写反义；`.` 默认**不匹配换行**。
- **量词** `*`(0+) `+`(1+) `?`(0/1) `{n,m}`；**默认贪婪**，加 `?` 变非贪婪。
- **边界** `^` `$` `\b` `\B`；`\bcat\b` 才能做整词匹配（排除 `category`）。
- **分组** `()` 捕获、`(?:)` 非捕获、`(?P<name>)` 命名；`\1` 反向引用。
- **七个核心函数**：`match`（只匹配开头）、`search`（找第一个）、`fullmatch`（整串）、`findall`（全部，**有分组会改变返回值**）、`finditer`（带位置的迭代器）、`sub`（替换，可传函数）、`split`（切分，有捕获组会保留分隔符）。
- **四个标志位**：`re.I` 忽略大小写、`re.M` 多行、`re.S` 让 `.` 匹配换行、`re.X` 详细模式。
- **校验必须用 `fullmatch`**；正则只能校验**格式**，合法性（如日期）要配合 `strptime` 真解析。
- **常用模式**：手机号 `^1[3-9]\d{9}$`、邮箱 `^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$`（**别用 `\w`**，见 8.2 坑④）、身份证 `^\d{17}[\dXx]$`。
- **正则不适合解析 HTML**，复杂解析用 BeautifulSoup。

> **一句话记住本章**：正则加 `r` 前缀，`.` 不含换行、`\w` 不含空格；默认贪婪加 `?` 变懒；校验用 `fullmatch` 别用 `match`；`findall` 碰上有分组会返回元组。

## 自测题

1. 为什么正则表达式字符串前面要加 `r`？不加会有什么后果？举例说明。
2. `\d`、`\w`、`\s` 分别匹配什么？它们的等价的字符类写法是什么？
3. `match`、`search`、`fullmatch` 三者在匹配范围上有什么区别？做表单校验该用哪个？
4. `ab*`、`ab+`、`ab?` 三个模式对字符串 `"a ab abb"` 的 `findall` 结果分别是什么？
5. `re.findall(r"<.*>", "<a><b>")` 和 `re.findall(r"<.*?>", "<a><b>")` 的结果分别是什么？为什么不同？
6. `\bcat\b` 为什么不会匹配到 `"category"` 里的 `cat`？
7. `re.findall(r"(\d)(\d)", "12 34")` 的结果是什么？和 `re.findall(r"\d\d", "12 34")` 有什么不同？
8. `re.I`、`re.M`、`re.S` 三个标志位各有什么作用？
9. 写出中国大陆手机号的正则，并说明为什么校验时必须用 `fullmatch` 或加 `$`。
10. `re.sub(r"(\w+)@(\w+)\.com", r"\2@\1", "user@example.com")` 的结果是什么？`\1` `\2` 是什么含义？
11. 为什么说「正则不适合解析 HTML」？

**参考答案**

1. 因为不加 `r` 时 Python 会先对字符串做一次**转义处理**：`"\b"` 会被解释成**退格符**（`len("\b")` 是 1，`len(r"\b")` 是 2），`"\n"` 变成真正的换行符，正则引擎拿到的模式就错了。**加 `r` 后反斜杠原样保留，正则引擎才能看到 `\b`、`\d` 这些元字符。**
2. `\d` 匹配一个数字；`\w` 匹配一个单词字符（字母、数字、下划线）；`\s` 匹配一个空白字符（空格、`\t`、`\n`、`\r`、`\f`、`\v`）。大写形式 `\D`、`\W`、`\S` 是它们的**反义**。⚠️ 注意 `[0-9]`、`[a-zA-Z0-9_]` 只是它们的 **ASCII 近似**：**str 模式下三者都是 Unicode 语义**（`\w` 能匹配中文，`\d` 能匹配 `٣`），要退回 ASCII 必须加 `re.ASCII`。
3. `match` 要求**从字符串第 0 个字符开始**匹配，后面允许有多余字符；`search` 允许从**任意位置**开始，返回第一个匹配；`fullmatch` 要求**整个字符串恰好匹配完**。**表单校验必须用 `fullmatch`**（或 `^...$`），否则 `match(r"1[3-9]\d{9}", "13812345678abc")` 会误判为合法。
4. `ab*` → `['a', 'ab', 'abb']`（`b` 可有可无）；`ab+` → `['ab', 'abb']`（至少一个 `b`，跳过 `"a"`）；`ab?` → `['a', 'ab', 'ab']`（最多一个 `b`，`"abb"` 只取到 `"ab"`）。
5. 分别是 `['<a><b>']` 和 `['<a>', '<b>']`。因为 `*` **默认是贪婪匹配**，会尽可能多地吃字符，`.*` 一直吃到最后一个 `>`；加 `?` 变成**非贪婪**，吃到第一个 `>` 就停。
6. 因为 `\b` 表示**单词边界**（单词字符与非单词字符之间）。在 `"category"` 里 `cat` 后面紧跟的是 `e`（也是单词字符），**不构成边界**，所以 `\bcat\b` 匹配不上；而 `"cat "`、`"cat."` 中 `cat` 后面是空格/标点，构成边界，能匹配。
7. `re.findall(r"(\d)(\d)", "12 34")` → `[('1', '2'), ('3', '4')]`（有**两个分组**时返回**元组列表**，每个元组是各组的内容）；`re.findall(r"\d\d", "12 34")` → `['12', '34']`（**没有分组**时返回整体匹配的字符串列表）。有 1 个分组时返回该分组内容的字符串列表。
8. `re.I`（IGNORECASE）**忽略大小写**；`re.M`（MULTILINE）让 `^` 和 `$` 匹配**每一行的开头和结尾**而不只是整串的首尾；`re.S`（DOTALL）让 **`.` 也能匹配换行符**。
9. `^1[3-9]\d{9}$`（正则写法 `r"1[3-9]\d{9}"` 配合 `fullmatch`）。必须用 `fullmatch` 或加 `$`，因为 **`match` 只检查开头**：`"13812345678abc"` 的开头确实符合手机号模式，用 `match` 会返回 `Match` 对象，把非法输入判为合法。加 `$`（或 `fullmatch`）才要求后面不能有多余字符。
10. 结果是 `'example@user'`。替换串里的 **`\1` 表示第 1 个分组的内容（`user`），`\2` 表示第 2 个分组的内容（`example`）**，所以 `\2@\1` 把用户名和域名交换了位置。注意替换串里用 `\1` 引用分组，而**模式串里用 `\1` 表示反向引用**，两者含义不同但写法一样。
11. 因为 HTML 是**嵌套结构**，而正则（有限自动机）本质上**无法处理任意深度的嵌套**。具体问题：① `<div><div>...</div></div>` 这类嵌套标签，正则无法配对；② 属性值有单引号、双引号、无引号三种写法；③ 注释 `<!-- -->`、`<script>` 里的字符串可能包含看起来像标签的内容；④ 换行、大小写、可选闭合标签让模式越来越复杂直到无法维护。**正确做法是用专门的解析器**（BeautifulSoup、lxml），它们会把 HTML 解析成树结构。正则只适合结构简单、格式统一的片段抽取（如从日志里抓 IP）。
