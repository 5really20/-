## 12.1 wxPython 库简介

**GUI（Graphical User Interface，图形用户界面）** 是用窗口、按钮、菜单等图形元素与用户交互的界面。**GUI 程序的结构和前面所有章节都不一样**：

| 对比项 | 命令行程序（第1~11章） | GUI 程序（本章） |
|---|---|---|
| 执行方式 | 从上到下顺序执行，执行完就退出 | 启动后进入**事件循环**，一直等用户操作 |
| 程序入口 | 第一行代码 | **事件处理函数**（用户点按钮时才被调用） |
| 输入来源 | `input()` 一次读一行 | 各种控件的当前值，**随时可能变** |
| 结束方式 | 代码跑完 | 用户关窗口（或调用 `destroy`） |
| 调试方式 | 打印变量 | 打印 + 界面反馈（状态栏、消息框） |

**主流 Python GUI 库对比**：

| 库 | 是否需安装 | 特点 | 适用 |
|---|---|---|---|
| **tkinter** | **否，标准库自带** | 简单、够用、文档多 | 教学、小工具、实验 |
| **wxPython** | 需 `pip install wxPython` | **教材选用**；控件贴近操作系统原生外观 | 桌面应用 |
| PyQt5 / PySide6 | 需安装 | 功能最强、Qt Designer 可视化设计 | 大型商业软件 |
| Kivy | 需安装 | 支持触摸与移动端 | 跨平台触屏应用 |

**wxPython 的安装与最小程序**（需先 `pip install wxPython`）：

```python
import wx

class MyFrame(wx.Frame):                       # ① 继承 wx.Frame 定义窗体
    def __init__(self):
        super().__init__(None, title="第一个窗口", size=(300, 200))
        panel = wx.Panel(self)                 # ② 面板：所有控件的容器
        wx.StaticText(panel, label="你好，wxPython！", pos=(20, 20))
        wx.Button(panel, label="点我", pos=(20, 60))
        self.Centre()

class MyApp(wx.App):                           # ③ 继承 wx.App 定义应用
    def OnInit(self):
        self.frame = MyFrame()
        self.frame.Show()
        return True

if __name__ == "__main__":
    app = MyApp()
    app.MainLoop()                             # ④ 进入事件循环，程序"停"在这里
```

**tkinter 的等价最小程序**（**可直接运行，无需安装**）：

```python
import tkinter as tk

root = tk.Tk()                     # ① 创建主窗口
root.title("第一个窗口")
root.geometry("300x200")           # 宽x高，注意是小写字母 x

tk.Label(root, text="你好，tkinter！").pack()      # ② 创建控件并放入窗口
tk.Button(root, text="点我").pack()

root.mainloop()                    # ③ 进入事件循环
```

> **重点**：**`mainloop()` 是一个"死循环"**，程序停在这一行，直到窗口被关闭才返回。所以 `mainloop()` 之后的代码在关窗口前不会执行——初学最常见的困惑就是"为什么 `print` 没输出"。

**tkinter 的三个根部件**（概念与 wxPython 的 Frame/Panel 一一对应）：

| tkinter | wxPython 对应 | 作用 |
|---|---|---|
| `Tk()` | `wx.App` + `wx.Frame` | 主窗口（一个程序只能有一个） |
| `Toplevel()` | `wx.Frame` | 弹出子窗口（可有多个） |
| `Frame()` | `wx.Panel` | 容器，用来分组和布局控件 |

## 12.2 事件处理

**事件（event）是用户或系统产生的动作**（点击、按键、移动鼠标、窗口关闭）。**事件驱动编程的三个概念**：

```
事件源（控件）  ──触发──▶  事件（Event 对象）  ──交给──▶  事件处理函数（回调）
  Button                    EVT_BUTTON                     on_click(event)
```

**wxPython 用 `Bind` 绑定事件**：

```python
class MyFrame(wx.Frame):
    def __init__(self):
        super().__init__(None, title="事件处理", size=(300, 200))
        panel = wx.Panel(self)
        self.label = wx.StaticText(panel, label="点击次数：0", pos=(20, 20))
        btn = wx.Button(panel, label="点我", pos=(20, 60))
        btn.Bind(wx.EVT_BUTTON, self.on_click)      # ① 绑定：事件源 + 事件类型 + 处理函数
        self.count = 0

    def on_click(self, event):                      # ② 处理函数必须接收 event 参数
        self.count += 1
        self.label.SetLabel(f"点击次数：{self.count}")
```

**tkinter 用 `command=` 或 `bind()` 绑定**，两种方式有明确分工：

```python
import tkinter as tk

root = tk.Tk()
label = tk.Label(root, text="点击次数：0")
label.pack()
count = {"n": 0}

def on_click():
    count["n"] += 1
    label.config(text=f"点击次数：{count['n']}")

btn = tk.Button(root, text="点我", command=on_click)   # command：只传函数名，不加括号
btn.pack()

btn.invoke()          # 用代码"模拟点击"（真实运行时由用户点）
btn.invoke()
print(count["n"], label["text"])     # 2 点击次数：2
root.destroy()
```

> **重点**：**`command=on_click` 后面绝对不能加括号**。写 `command=on_click()` 表示"现在就调用它，把返回值当回调"，结果是**程序一启动就执行一次**，之后点按钮反而没反应。这是 GUI 编程第一大坑。

**`command` 与 `bind` 的区别**：

| 方式 | 写法 | 特点 |
|---|---|---|
| `command=` | `Button(..., command=f)` | 只在**默认触发时机**（按钮被点击）调用，**回调不接收参数** |
| `bind()` | `w.bind("<Button-1>", f)` | 可绑定任意事件（键盘、鼠标、焦点），**回调必须接收 `event` 参数** |

```python
hits = []
entry = tk.Entry(root)
entry.bind("<Return>", lambda ev: hits.append(ev.keysym))   # 回车键
# 真实运行时用户按回车触发；代码里用 event_generate 模拟
```

**常用事件类型对照表**：

| 动作 | wxPython 事件 | tkinter 事件 |
|---|---|---|
| 点击按钮 | `wx.EVT_BUTTON` | `command=` 或 `"<Button-1>"` |
| 关闭窗口 | `wx.EVT_CLOSE` | `"<Destroy>"` / `WM_DELETE_WINDOW` |
| 键盘按下 | `wx.EVT_KEY_DOWN` | `"<Key>"`、`"<Return>"` |
| 鼠标移动 | `wx.EVT_MOTION` | `"<Motion>"` |
| 选中列表项 | `wx.EVT_LISTBOX` | `"<<ListboxSelect>>"` |
| 定时触发 | `wx.CallLater` | `after(毫秒, 函数)` |

**`after` 定时器**（**GUI 里不要用 `time.sleep`**，它会把整个界面冻住）：

```python
done = []
root.after(10, lambda: done.append("定时到了"))     # 10 毫秒后执行一次
root.update()                                       # 处理一次待办事件
import time; time.sleep(0.05); root.update()
print(done)          # ['定时到了']
```

> **重点**：**事件处理函数里不能写耗时操作**（大循环、`time.sleep`、网络请求）。GUI 是单线程的，处理函数不返回，界面就不刷新，用户看到的是"程序卡死"。正确做法：用 `after` 分批处理，或把耗时任务丢给 `threading`（第13章）。

## 12.3 常用控件

**教材 12.3 的七类控件，下面逐一给出 wxPython 与 tkinter 的对照写法，tkinter 部分均附真实运行结果。**

### 12.3.1 窗体

**窗体（Frame）是顶层窗口**，`wx.Frame` / `tk.Tk()`。常用属性：

| 操作 | wxPython | tkinter |
|---|---|---|
| 设置标题 | `frame.SetTitle("标题")` | `root.title("标题")` |
| 设置大小 | `frame.SetSize((300, 200))` | `root.geometry("300x200")` |
| 居中 | `frame.Centre()` | `root.eval('tk::PlaceWindow . center')` |
| 固定大小 | `frame.SetWindowStyle(wx.DEFAULT_FRAME_STYLE & ~wx.RESIZE_BORDER)` | `root.resizable(False, False)` |
| 关闭窗口 | `frame.Destroy()` | `root.destroy()` |

```python
root = tk.Tk()
root.title("测试")
print(root.title())          # 测试
root.geometry("300x200")
print(root.geometry())       # 1x1+...   ← 还没 update，几何信息尚未生效
root.destroy()
```

> **注意**：窗口刚创建时 `geometry()` 返回的是初始值（`1x1`），**要先调 `root.update_idletasks()` 才能拿到真实尺寸**。这是布局调试时的常见困惑。

### 12.3.2 按钮、标签和文本框

| 控件 | wxPython | tkinter | 主要取值方法 |
|---|---|---|---|
| 标签 | `wx.StaticText` | `tk.Label` | `label["text"]` |
| 单行文本 | `wx.TextCtrl` | `tk.Entry` | `entry.get()` / `entry.delete(0, tk.END)` |
| 多行文本 | `wx.TextCtrl(style=wx.TE_MULTILINE)` | `tk.Text` | `text.get("1.0", "end-1c")` |
| 按钮 | `wx.Button` | `tk.Button` | `btn.invoke()` |

```python
root = tk.Tk()
lbl = tk.Label(root, text="你好"); lbl.pack()
print(lbl["text"], lbl.winfo_class())        # 你好 Label

var = tk.StringVar(value="初始")              # 变量绑定：改 var 就等于改界面
e = tk.Entry(root, textvariable=var); e.pack()
var.set("改过了")
print(var.get(), e.get())                    # 改过了 改过了

txt = tk.Text(root, height=3, width=20); txt.pack()
txt.insert("1.0", "第一行\n第二行")
print(repr(txt.get("1.0", "end-1c")))        # '第一行\n第二行'
root.destroy()
```

> **重点**：**`Text` 的 `get` 必须给两个参数**（起始、结束位置），`"1.0"` 表示第 1 行第 0 列，`"end-1c"` 表示"末尾减一个字符"（因为 `Text` 会自动多出一个换行符，不减就会多一个 `\n`）。而 `Entry` 直接 `get()` 不带参数。

### 12.3.3 单选按钮、复选框

**单选按钮（RadioButton）** 一组里只能选一个，靠**共用同一个变量**实现互斥；**复选框（CheckButton）** 各自独立，变量是布尔值。

```python
root = tk.Tk()
v1 = tk.BooleanVar(value=True)
tk.Checkbutton(root, text="同意", variable=v1).pack()
print(v1.get())            # True
v1.set(False); print(v1.get())     # False

v2 = tk.StringVar(value="A")
for t in ("A", "B"):
    tk.Radiobutton(root, text=t, variable=v2, value=t).pack()   # 同一个 variable → 互斥
print(v2.get())            # A
root.destroy()
```

| 概念 | wxPython | tkinter |
|---|---|---|
| 单选按钮 | `wx.RadioButton`（同组自动互斥） | `tk.Radiobutton(variable=同一个Var, value=本项的值)` |
| 复选框 | `wx.CheckBox` | `tk.Checkbutton(variable=tk.BooleanVar())` |
| 取值 | `GetValue()` | `var.get()` |

### 12.3.4 列表框、组合框

**列表框（ListBox）** 把选项全列出来，可多选；**组合框（ComboBox）** 平时收起、点击才展开，省地方。

```python
from tkinter import ttk
root = tk.Tk()
lb = tk.Listbox(root)
for x in ["苹果", "香蕉", "橘子"]:
    lb.insert(tk.END, x)                  # tk.END 表示追加到末尾
lb.selection_set(1)                       # 选中下标 1
print(lb.size(), lb.get(0))               # 3 苹果
print(lb.curselection(), lb.get(lb.curselection()[0]))   # (1,) 香蕉

combo = ttk.Combobox(root, values=["计科2201", "计科2202"], state="readonly")
combo.current(1)
print(combo.get())                        # 计科2202
root.destroy()
```

| 操作 | wxPython | tkinter Listbox |
|---|---|---|
| 添加 | `Append(项)` | `insert(tk.END, 项)` |
| 获取全部 | `GetStrings()` | `get(0, tk.END)` |
| 取选中项 | `GetSelection()` | `curselection()` → **返回元组** |
| 清空 | `Clear()` | `delete(0, tk.END)` |

> **注意**：`curselection()` 返回的是**下标元组**，如 `(1,)`，要再 `lb.get(...)` 一次才拿到文本。**没有选中时返回空元组 `()`**，直接 `[0]` 会 `IndexError`，必须先判断。

### 12.3.5 菜单

**菜单（Menu）分三级：菜单栏（MenuBar）→ 菜单（Menu）→ 菜单项（MenuItem）**。

```python
root = tk.Tk()
mb = tk.Menu(root)                        # ① 菜单栏
m1 = tk.Menu(mb, tearoff=0)               # ② 一个菜单；tearoff=0 去掉可撕下的虚线
m1.add_command(label="打开", command=lambda: None)
m1.add_separator()                        # 分隔线
m1.add_command(label="退出", command=root.destroy)
mb.add_cascade(label="文件", menu=m1)      # ③ 把菜单挂到菜单栏
root.config(menu=mb)                      # ④ 把菜单栏挂到窗口
print(m1.index("end"), m1.entrycget(0, "label"))   # 2 打开
root.destroy()
```

| 概念 | wxPython | tkinter |
|---|---|---|
| 菜单栏 | `wx.MenuBar()` | `tk.Menu(root)` |
| 菜单 | `wx.Menu()` | `tk.Menu(mb)` |
| 菜单项 | `Append(id, "文本")` | `add_command(label=..., command=...)` |
| 分隔线 | `AppendSeparator()` | `add_separator()` |
| 子菜单 | `AppendSubMenu()` | `add_cascade()` |

### 12.3.6 工具栏、状态栏

**工具栏（ToolBar）** 放常用命令的图标按钮，**状态栏（StatusBar）** 在窗口底部显示提示信息。

| 控件 | wxPython | tkinter |
|---|---|---|
| 工具栏 | `wx.ToolBar` + `AddTool` | 用 `Frame` + 一排 `Button` 模拟（tkinter 无原生工具栏） |
| 状态栏 | `wx.StatusBar` + `SetStatusText` | 用 `Label` 放在底部模拟 |

```python
root = tk.Tk()
status = ttk.Label(root, text="共 0 本书", relief="sunken", anchor="w")
status.pack(side="bottom", fill="x")      # ① 先 pack 底部，再放其它控件
status.config(text="共 2 本书，总价 114.80 元")
print(status["text"])                     # 共 2 本书，总价 114.80 元
root.destroy()
```

> **技巧**：**状态栏要"先 pack 到底部"**。tkinter 的 `pack` 按调用顺序分配空间，如果先 pack 了中间的列表再 pack 状态栏，状态栏会被挤到列表下面而不是窗口底部。

### 12.3.7 对话框

**对话框（Dialog）** 是弹出的小窗口，用于提示、警告、报错、让用户选文件。

| 用途 | wxPython | tkinter |
|---|---|---|
| 普通提示 | `wx.MessageBox("内容", "标题", wx.OK)` | `messagebox.showinfo("标题", "内容")` |
| 警告 | `wx.MessageBox(..., wx.ICON_WARNING)` | `messagebox.showwarning(...)` |
| 错误 | `wx.MessageBox(..., wx.ICON_ERROR)` | `messagebox.showerror(...)` |
| 是/否 | `wx.MessageBox(..., wx.YES_NO)` | `messagebox.askyesno(...)` 返回 `True`/`False` |
| 选文件 | `wx.FileDialog` | `filedialog.askopenfilename()` |
| 选颜色 | `wx.ColourDialog` | `colorchooser.askcolor()` |

```python
from tkinter import messagebox, filedialog
print(callable(messagebox.showinfo), callable(filedialog.askopenfilename))   # True True
```

> **重点**：**`messagebox` 会阻塞程序**，直到用户点了按钮才返回。所以它**不能放在循环里**（会弹出无数次），也**不适合用来调试**（用 `print` 或状态栏代替）。

## 12.4 布局

**布局（layout）决定控件在窗口里的位置和大小。** 三种方式：**绝对定位**（给坐标，窗口一缩放就乱）、**Sizer/几何管理器**（按规则自动算，推荐）、**嵌套容器**（用 Frame/Panel 分组）。

**wxPython 的两大 Sizer**：

| Sizer | 作用 | 典型用法 |
|---|---|---|
| `wx.BoxSizer` | **按行或列排列**，可设比例 | 左侧列表 + 右侧详情 |
| `wx.GridSizer` | **按网格排列**，行列等宽 | 表单、计算器按键 |

```python
# wxPython：垂直 BoxSizer
sizer = wx.BoxSizer(wx.VERTICAL)
sizer.Add(self.label, 0, wx.ALL, 5)      # 参数：控件, 比例, 边框方式, 边框宽度
sizer.Add(self.list, 1, wx.EXPAND | wx.ALL, 5)   # 比例 1 = 占据剩余空间
panel.SetSizer(sizer)
```

**tkinter 的三种几何管理器**：

| 管理器 | 定位方式 | 适合 | 关键参数 |
|---|---|---|---|
| `pack()` | **按顺序堆叠**（上/下/左/右） | 简单的上下结构 | `side`、`fill`、`expand`、`padx` |
| `grid()` | **网格**（行列） | 表单、表格 | `row`、`column`、`sticky`、`columnspan` |
| `place()` | **绝对坐标** | 精确摆放（少用） | `x`、`y`、`relx`、`rely` |

**`pack` 与 `grid` 不能在同一容器里混用**——混用会**立刻抛异常**（不是界面错乱，也不会卡死）：

```
_tkinter.TclError: cannot use geometry manager grid inside . which already has slaves managed by pack
```

所以必须在**同一个容器里统一用一种**布局管理器；确实需要两种时，用 `Frame` 把窗口分区，每个区内部各用一种。

```python
root = tk.Tk()
f = tk.Frame(root); f.pack(fill="both", expand=True)
tk.Label(f, text="左上").grid(row=0, column=0, sticky="w")
tk.Label(f, text="右上").grid(row=0, column=1, sticky="e")
f.columnconfigure(1, weight=1)          # 第 1 列可伸缩 → 把"右上"推到右边
print(f.grid_size(), f.winfo_children()[0]["text"])   # (2, 1) 左上
root.destroy()
```

**`grid` 的三个关键参数**：

- **`sticky`**：控件在格子里的对齐方式，用罗盘方位组合：`"n"`上、`"s"`下、`"w"`左、`"e"`右，如 `"ew"` 表示左右拉伸填满。
- **`columnconfigure(i, weight=1)`**：让第 `i` 列可伸缩。**不设 `weight` 时所有列都按内容宽度排，窗口拉大时控件不会跟着变宽**——这是"界面拉伸后很难看"的头号原因。
- **`padx`/`pady`**：外边距；`ipadx`/`ipady` 是内边距。

**布局经验三条**：① **先用 `Frame` 分区，再在每区里布局**，比在一个容器里堆十几个控件容易得多；② 表单用 `grid`，上下结构用 `pack`；③ 给需要伸缩的行列设 `weight`。

## 12.5 典型案例——专利管理系统

**教材 12.5 用 wxPython 做了一个专利管理系统**，核心是"**列表 + 表单 + 增删改查**"这个几乎所有管理系统的通用结构。下面给出同一套结构的 **tkinter 可运行版**（把"专利"换成更贴近学生的"图书"，逻辑完全一致），代码已实跑验证。

**界面结构**：

```
┌─────────────────────────────────┐
│ 录入                            │   ← LabelFrame：表单区（grid 布局）
│  书名 [__________]              │
│  作者 [__________]              │
│  价格 [__________]              │
│        [ 添加 ]                 │
├─────────────────────────────────┤
│ 书名    | 作者    | 价格        │   ← Treeview：列表区（可选中）
│ Python  | 王雷春  | 69.80       │
│ 数据结构| 严蔚敏  | 45.00       │
├─────────────────────────────────┤
│        [ 删除选中 ]             │
│ 共 2 本书，总价 114.80 元        │   ← 状态栏
└─────────────────────────────────┘
```

```python
import tkinter as tk
from tkinter import ttk, messagebox

class BookApp:
    def __init__(self, root):
        self.root = root
        self.root.title("图书管理")
        self.root.geometry("420x300")
        self.books = []                       # 数据：[[书名, 作者, 价格], ...]

        # ---------- 表单区 ----------
        frm = ttk.LabelFrame(root, text="录入")
        frm.pack(fill="x", padx=8, pady=6)
        self.v_title = tk.StringVar()
        self.v_author = tk.StringVar()
        self.v_price = tk.StringVar()
        for i, (lab, var) in enumerate([("书名", self.v_title),
                                        ("作者", self.v_author),
                                        ("价格", self.v_price)]):
            ttk.Label(frm, text=lab).grid(row=i, column=0, sticky="e", padx=4, pady=2)
            ttk.Entry(frm, textvariable=var).grid(row=i, column=1, sticky="ew", padx=4)
        frm.columnconfigure(1, weight=1)      # 输入框那一列可伸缩
        ttk.Button(frm, text="添加", command=self.add).grid(
            row=3, column=0, columnspan=2, pady=4)

        # ---------- 列表区 ----------
        cols = ("title", "author", "price")
        self.tree = ttk.Treeview(root, columns=cols, show="headings", height=6)
        for c, t in zip(cols, ("书名", "作者", "价格")):
            self.tree.heading(c, text=t)
            self.tree.column(c, width=120, anchor="center")
        self.tree.pack(fill="both", expand=True, padx=8)

        ttk.Button(root, text="删除选中", command=self.delete).pack(pady=6)
        self.status = ttk.Label(root, text="共 0 本书")
        self.status.pack()

    def add(self):
        t = self.v_title.get().strip()
        a = self.v_author.get().strip()
        p = self.v_price.get().strip()
        if not t:                                   # ① 校验：书名必填
            messagebox.showwarning("提示", "书名不能为空")
            return
        try:
            price = float(p)                        # ② 校验：价格必须是数字
        except ValueError:
            messagebox.showerror("错误", f"价格必须是数字：{p}")
            return
        self.books.append([t, a, price])            # ③ 改数据
        self.tree.insert("", "end", values=(t, a, f"{price:.2f}"))   # ④ 改界面
        for v in (self.v_title, self.v_author, self.v_price):
            v.set("")                               # ⑤ 清空输入框
        self.refresh()

    def delete(self):
        sel = self.tree.selection()
        if not sel:
            messagebox.showinfo("提示", "请先选中一行")
            return
        idx = self.tree.index(sel[0])               # 界面行号 ↔ 数据下标
        self.tree.delete(sel[0])
        del self.books[idx]
        self.refresh()

    def refresh(self):
        total = sum(b[2] for b in self.books)
        self.status.config(text=f"共 {len(self.books)} 本书，总价 {total:.2f} 元")

if __name__ == "__main__":
    root = tk.Tk()
    BookApp(root)
    root.mainloop()                # 真实运行时进入事件循环
```

**用代码"模拟用户操作"来测试界面**（**不必手点**，这是 GUI 程序可测试的关键技巧）：

```python
root = tk.Tk()

app.add()
```

**这套结构的设计要点**（换成"专利管理""学生管理""库存管理"都照搬）：

| 要点 | 做法 | 为什么 |
|---|---|---|
| **数据与界面分离** | 数据存 `self.books`，界面另存一份 | 界面只是数据的"投影"，业务逻辑不依赖控件 |
| **数据下标 ↔ 界面行号一致** | `self.tree.index(sel[0])` 取行号再 `del self.books[idx]` | 两边顺序必须同步，否则删错行 |
| **先校验再改数据** | 校验不通过就 `return`，什么都不动 | 保证数据和界面永远一致 |
| **统一刷新入口** | 所有改动最后都调 `self.refresh()` | 状态栏不会忘记更新 |
| **输入框用 `StringVar`** | `v.get()` / `v.set("")` | 清空、赋值比直接操作控件简单 |
| **列表用 `Treeview`** | `show="headings"` + `columns` | 比 `Listbox` 多列显示更整齐 |

## 典型例题

**例 12.1**（题型：读程序写结果 —— 事件绑定）

```python
import tkinter as tk
root = tk.Tk()
n = {"v": 0}
def f():
    n["v"] += 1
b = tk.Button(root, text="按", command=f())
print(n["v"])
root.destroy()
```

**解**：注意 `command=f()` —— **这里写的是调用 `f()` 的结果，而不是 `f` 本身**。所以创建按钮时就立刻执行了一次 `f`，`n["v"]` 变成 1；而 `f()` 返回 `None`，`command=None` 表示没有回调，之后点按钮不会有任何反应。

**答案**：打印 `1`。**正确写法是 `command=f`（不加括号）。**

**例 12.2**（题型：读程序写结果 —— `Text` 的取值）

```python
import tkinter as tk
root = tk.Tk()
t = tk.Text(root)
t.insert("1.0", "abc")
print(repr(t.get("1.0", "end")))
print(repr(t.get("1.0", "end-1c")))
root.destroy()
```

**解**：`Text` 组件的内容末尾**总是自动带一个换行符**（Tk 的约定）。`insert("1.0", "abc")` 之后，内部内容其实是 `"abc\n"`。所以 `get("1.0", "end")` 取到 `"abc\n"`；`get("1.0", "end-1c")` 表示"末尾往前一个字符"，正好去掉那个自动换行，得到 `"abc"`。

**答案**：

```
'abc\n'
'abc'
```

**例 12.3**（题型：编程题 —— 简易计算器）

**题目**：写一个 tkinter 程序，两个输入框 + 一个「相加」按钮 + 一个结果标签；输入非法时用 `messagebox` 报错。

**解**：

```python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
root.title("加法器")
a = tk.StringVar(); b = tk.StringVar()
result = tk.StringVar(value="结果：")

tk.Label(root, text="加数 1").grid(row=0, column=0, sticky="e", padx=4, pady=4)
tk.Entry(root, textvariable=a).grid(row=0, column=1, padx=4)
tk.Label(root, text="加数 2").grid(row=1, column=0, sticky="e", padx=4, pady=4)
tk.Entry(root, textvariable=b).grid(row=1, column=1, padx=4)

def calc():
    try:
        r = float(a.get()) + float(b.get())
    except ValueError:
        messagebox.showerror("错误", "请输入数字")
        return
    result.set(f"结果：{r:g}")          # :g 自动去掉多余的小数点

tk.Button(root, text="相加", command=calc).grid(row=2, column=0, columnspan=2, pady=6)
tk.Label(root, textvariable=result).grid(row=3, column=0, columnspan=2)

# 模拟操作
a.set("3.5"); b.set("2")
calc()
print(result.get())        # 结果：5.5
a.set("abc"); b.set("1")
calc()                     # 弹出错误框，结果不变
print(result.get())        # 结果：5.5
root.destroy()
```

**答案**：合法输入得到 `结果：5.5`；非法输入弹错误框，结果标签保持上一次的值不变。**思路要点**：① `float()` 只包在 `try` 里，`result.set` 放在 `try` 外；② 用 `f"{r:g}"` 而不是 `f"{r}"`，`3.5+2=5.5` 显示为 `5.5`，若是整数结果也不会显示成 `5.0`；③ 标签用 `textvariable=result` 绑定变量，改 `result` 就自动更新界面。

**例 12.4**（题型：编程题 —— 布局）

**题目**：用 `grid` 做一个登录界面：第一行「用户名」+ 输入框，第二行「密码」+ 输入框（显示为 `*`），第三行跨两列放「登录」按钮；并让输入框那一列随窗口拉伸。

**例 12.5**（题型：编程题 —— 列表框与删除确认）

**题目**：做一个待办事项列表：输入框 + 「添加」按钮把内容加到 `Listbox`；「删除选中」按钮删除当前选中项，删除前用 `askyesno` 确认；底部状态栏显示剩余条数。

**解**：

```python
import tkinter as tk
from tkinter import messagebox

root = tk.Tk()
v = tk.StringVar()
entry = tk.Entry(root, textvariable=v); entry.pack(fill="x", padx=6, pady=6)
lb = tk.Listbox(root); lb.pack(fill="both", expand=True, padx=6)
status = tk.Label(root, text="共 0 项", anchor="w")
status.pack(side="bottom", fill="x")        # 状态栏先占住底部

def refresh():
    status.config(text=f"共 {lb.size()} 项")

def add():
    s = v.get().strip()
    if not s:
        messagebox.showwarning("提示", "内容不能为空"); return
    lb.insert(tk.END, s)
    v.set("")
    refresh()

def delete():
    sel = lb.curselection()
    if not sel:                              # 空元组 → 没选中
        messagebox.showinfo("提示", "请先选中一项"); return
    if messagebox.askyesno("确认", f"确定删除「{lb.get(sel[0])}」？"):
        lb.delete(sel[0])
        refresh()

tk.Button(root, text="添加", command=add).pack()
tk.Button(root, text="删除选中", command=delete).pack()

# 模拟
v.set("写作业"); add()
v.set("复习 Python"); add()
print(lb.size(), status["text"])       # 2 共 2 项
lb.selection_set(0)
lb.delete(0); refresh()
print(lb.get(0, tk.END), status["text"])   # ('复习 Python',) 共 1 项
root.destroy()
```

**答案**：添加两项后状态栏显示 `共 2 项`；删除第一项后列表剩 `('复习 Python',)`、状态栏显示 `共 1 项`。**要点**：① **`curselection()` 返回元组，为空表示没选中**，必须先判断再取下标；② 状态栏用 `pack(side="bottom")` **先占底部**；③ 所有会改变列表条数的地方都要调 `refresh()`。

**例 12.6**（题型：编程题 —— 用 after 做倒计时）

**题目**：写一个 10 秒倒计时标签，每秒减 1，到 0 时显示「时间到」。

**解**：

```python
import tkinter as tk

root = tk.Tk()
label = tk.Label(root, text="10", font=("Arial", 24))
label.pack(padx=20, pady=20)

def tick(n):
    if n < 0:
        label.config(text="时间到")
        return
    label.config(text=str(n))
    root.after(1000, tick, n - 1)      # 1000 毫秒后再调一次 tick，参数接着传

tick(10)
root.mainloop()
```

**答案**：标签从 10 每秒递减，减到 0 后下一次进入 `n = -1` 分支显示「时间到」。**思路要点**：① **用 `after` 而不是 `time.sleep`**——`after` 把控制权还给事件循环，界面不卡；② `root.after(1000, tick, n - 1)` 的第三、四个参数会原样传给 `tick`；③ 递归调用 `after` 形成"每秒一次"的循环，**必须要有终止条件**，否则永远不会停。

## 易错点提醒

1. **`command=f()` 加了括号** → 错：程序启动时就执行一次，之后点按钮没反应。对：`command=f`，**只写函数名**。
2. **事件处理函数忘了接收参数** → 错：`bind("<Return>", handler)` 时 `handler` 必须能接收一个 `event` 参数，写成 `def handler():` 会报 `TypeError`。对：`def handler(event):`（用不到就写 `lambda ev: ...`）。
3. **在事件处理函数里写 `time.sleep` 或大循环** → 错：界面整个冻住，用户以为程序死了。对：用 `after` 分批执行，或交给线程。
4. **`mainloop()` 后面写代码期待它执行** → 错：`mainloop()` 是事件循环，关窗口前不返回。对：所有初始化写在 `mainloop()` 之前，收尾逻辑用 `root.protocol("WM_DELETE_WINDOW", ...)` 挂到关闭事件上。
5. **`pack` 和 `grid` 混用在同一个容器里** → 错：**会立刻抛 `_tkinter.TclError: cannot use geometry manager grid inside . which already has slaves managed by pack`**（不会卡死，是立刻报错）。对：**一个容器只用一种**；需要混用就加 `Frame` 分区。
6. **忘了 `columnconfigure(i, weight=1)`** → 错：窗口拉大时控件不跟着变宽，右边留一大片空白。对：给需要伸缩的行/列设 `weight`。
7. **`Text.get()` 不带参数** → 错：`TypeError`，`Text` 的 `get` 必须给起始和结束位置。对：`text.get("1.0", "end-1c")`。
8. **`Listbox.curselection()` 没判断就取下标** → 错：没选中时返回空元组 `()`，`[0]` 抛 `IndexError`。对：先 `if not sel: return`。
9. **删除列表项时界面和数据不同步** → 错：只 `tree.delete(...)` 忘了 `del self.books[idx]`，之后数据全错位。对：两边一起改，并且**先取行号再删**（删完行号会变）。
10. **用 `messagebox` 在循环里报错** → 错：弹出成百上千个窗口，程序无法操作。对：循环里把错误收集到列表，循环结束后一次性显示。
11. **`mainloop()` 之前忘了创建控件** → 错：窗口一片空白。对：按「建窗口 → 建控件 → 布局 → `mainloop()`」的顺序写。
12. **用 `place()` 绝对坐标做整体布局** → 错：换个分辨率或系统缩放，控件就跑偏或重叠。对：整体布局用 `pack`/`grid`，只在个别装饰性元素上用 `place`。

## 本章小结

- GUI 程序是**事件驱动**的：启动后进入事件循环，用户操作触发事件，事件交给回调函数处理，**程序入口是回调而不是第一行代码**。
- 控件与函数的连接方式：tkinter 的 `command=`（按钮默认事件，回调无参数）和 `bind()`（任意事件，回调带 `event` 参数）；wxPython 统一用 `Bind(事件类型, 处理函数)`。
- **`command=` 后面不加括号**；**`mainloop()` 是死循环**；**事件处理函数里不能写耗时操作**——这三条是 GUI 编程的三条铁律。
- 常用控件在 tkinter 中：`Label`/`Entry`/`Text`/`Button`/`Checkbutton`/`Radiobutton`/`Listbox`/`Combobox`/`Menu`/`messagebox`；在 wxPython 中对应 `StaticText`/`TextCtrl`/`Button`/`CheckBox`/`RadioButton`/`ListBox`/`ComboBox`/`Menu`/`MessageBox`。
- 布局用几何管理器：tkinter 的 `pack`（顺序堆叠）/`grid`（网格）/`place`（绝对坐标），wxPython 的 `BoxSizer`/`GridSizer`。**同一容器不混用 `pack` 和 `grid`**，需要伸缩的行列要设 `weight`。
- 管理类程序（专利/图书/学生管理）都是同一套结构：**表单录入 → 校验 → 改数据 → 刷新列表与状态栏**，并且**数据与界面分开维护、两边同步**。

> **一句话记住本章**：**建窗口、放控件、绑事件、进 `mainloop()`；回调里只做"取值—校验—改数据—刷新界面"，耗时活儿交给 `after` 或线程。**

9. 为什么布局时常常要写 `root.columnconfigure(1, weight=1)`？不写会有什么现象？
10. 写一个 tkinter 程序：一个输入框、一个「统计」按钮、一个标签；点按钮后统计输入框里字符的个数并显示在标签上（输入框为空时提示）。

**参考答案**

1. 命令行程序**顺序执行**，从上到下跑完就退出；GUI 程序启动后进入**事件循环**（`mainloop()`），一直等待用户操作，**真正的程序入口是事件处理函数（回调）**，主流程只是"建界面 + 进循环"。
2. `command=f` 把函数对象本身交给按钮，**点击时才调用**；`command=f()` 是**立刻调用 `f`**，把它的返回值（通常是 `None`）当作回调，结果是程序启动时执行一次，之后点按钮没反应。
3. `command=` 只用于控件的默认事件（按钮点击、菜单项选择），回调**不接收参数**；`bind(事件, 函数)` 可以绑定任意事件（键盘、鼠标、焦点变化等），回调**必须接收一个 `event` 参数**（用不到就写 `lambda ev: ...`）。
4. 只有在**窗口被关闭、`mainloop()` 返回之后**才执行。在此之前程序一直停在事件循环里。
5. 因为 GUI 是单线程的，`time.sleep(5)` 会让事件循环停止处理任何事件，界面完全冻结（Windows 上还会显示"未响应"）。替代方案：用 `root.after(毫秒, 函数)` 把任务拆成多批执行；耗时的 IO/计算则交给 `threading` 或 `multiprocessing`。
6. **不能混用**，同一个容器里混用会**立刻抛 `TclError`**（`cannot use geometry manager grid inside . which already has slaves managed by pack`），不会卡死。需要两种布局时，用 `Frame` 把窗口分成几个区域，每个区域内各用一种管理器。
7. `end` 表示文本末尾，但 Tk 的 `Text` 内容末尾**总是自动带一个换行符**；`end-1c` 表示"末尾往前一个字符"，正好去掉那个自动换行，取到用户真正输入的内容。不加 `-1c` 会多出一个 `\n`。
8. 返回**选中项下标的元组**（如 `(1,)`）；**没有选中时返回空元组 `()`**。直接写 `curselection()[0]` 在没选中时会抛 `IndexError: tuple index out of range`，必须先判断 `if not sel: return`。
9. `weight` 决定该列（或行）是否随窗口一起伸缩。不写时默认 `weight=0`，所有列都按内容宽度固定排布，**窗口拉大后控件不会变宽，右边会留一大片空白**，界面显得很别扭。
10. 参考实现：
    ```python
    import tkinter as tk
    from tkinter import messagebox

    root = tk.Tk()
    v = tk.StringVar()
    result = tk.StringVar(value="字符数：")
    tk.Entry(root, textvariable=v).pack(padx=10, pady=8, fill="x")
    tk.Label(root, textvariable=result).pack()

    def count():
        s = v.get()
        if not s:
            messagebox.showinfo("提示", "请输入内容")
            return
        result.set(f"字符数：{len(s)}")

    tk.Button(root, text="统计", command=count).pack(pady=6)

    # 模拟
    v.set("Python 程序设计"); count()
    print(result.get())          # 字符数：11
    root.destroy()
    ```
    要点：① 标签用 `textvariable=result` 绑定，改变量即改界面；② 空输入先用 `messagebox` 提示再 `return`，不更新结果；③ `len(s)` 统计的是**字符数**（`"Python 程序设计"` = 6 个字母 + 1 个空格 + 4 个汉字 = **11**），不是字节数（UTF-8 编码是 6 + 1 + 12 = 19 字节）。
