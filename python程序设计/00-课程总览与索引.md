> 湖北大学 计算机科学与技术专业｜课程编码 **374D15**｜**3 学分 / 64 学时**｜建议修读学期：**第 3 学期**｜课程性质：**专业方向选修课**
> 本索引把 15 章教学篇笔记 + 2 个拓展章 + 2 个附录串成一条完整的学习路线，可当作预习地图、复习提纲和上机速查手册。

## 这门课在专业里的位置

**一句话**：Python 是计算机应用与云计算/大数据两个方向共同的"**工具底座**"——上承《高级语言程序设计》建立的编程思维，下接《数据结构》《数据库原理》《机器学习》等课程与各类课程设计。

- **不是第一门语言课**。先修课是 **《高级语言程序设计》（372C03，3.5 学分 / 64 学时，第 1 学期）**，通常按 C 语言讲授。**本课程默认你已经会：变量、分支、循环、函数、数组**——所以进度会明显快于零基础教学，重点放在 Python 特有的部分（组合数据、推导式、异常、标准库、第三方库生态）。
- **同专业另有独立的《面向对象程序设计》课程**。本课程的**第 6 章只是入门**（类、继承、多态、抽象类），系统的 OOP 设计要到那门课深入；**第 16 章拓展**可作为衔接材料提前读。
- **实验占一半学时（32 学时）**。这意味着这门课**不是听懂就行**，必须动手跑通每一个例子。**本笔记所有代码块都给出了真实运行结果，可以直接当上机指导书用。**
- **对后续方向的支撑**：数据分析/人工智能方向依赖 **NumPy / Pandas / Matplotlib / Scikit-learn**（第 7 章、第 15 章）；Web 与后端方向依赖 **网络编程 / 数据库 / 多线程**（第 11、13、14 章）；而**第 8 章正则、第 9 章文件访问**是任何方向做数据处理都绕不开的基本功。

**四条落地提醒**：

1. **版本差异**：本机 3.14.7 满足"3.12 及以上"的要求，除**个别在 3.14 中被移除的弃用项**（如 `sqlite3.version`）外可直接运行教材案例。遇到"教材能跑我不能跑"，先查是不是版本弃用问题。
2. **数据库一律用内置 `sqlite3`**。本机**没有** MySQL / MongoDB，第 11 章的 MySQL 与 MongoDB 段落是**对照知识**（了解即可），**所有实验请全部用 `sqlite3`** —— 它是标准库自带的，不需要安装任何服务器，也不用手动启动服务。
3. **GUI 实验用 `tkinter`**。第 12 章教材主线是 wxPython（需 `pip install wxpython`），本笔记每处都给了 **tkinter 等价写法**；tkinter 随 Python 自带，**上机时优先用它**，能省掉一次环境配置。
4. **第三方库分两类**（第 14、15 章会用到）：

| 类别 | 库 | 处理方式 |
|---|---|---|
| **Anaconda 已自带**（实测，无需安装） | `numpy`、`pandas`、`matplotlib`、`scikit-learn`、`Pillow`、`openpyxl`、**`requests`**、**`beautifulsoup4`**、`flask`、`scipy`、`seaborn`、`statsmodels`、`sympy`、`plotly`、`jupyter` | 直接 `import`；万一报 `ModuleNotFoundError` 再用下面的命令装 |
| **需要 `pip install`**（Anaconda 未自带，实测确认） | `jieba`、`wordcloud`、`pymysql`、`pymongo`、`wxpython`、`pyinstaller`、`tensorflow`、`python-docx`、`python-pptx`、`XlsxWriter`、`lxml` | `pip install jieba wordcloud` 等 |

> **这一栏是实测出来的，不是猜的**：直接查了本机 Anaconda 的包目录 `D:\dev\Anaconda\Lib\site-packages`，**去掉 `*.dist-info` 元数据目录后共 375 个顶层包**（你自己复核时也请这样数：`Get-ChildItem D:\dev\Anaconda\Lib\site-packages -Directory | Where-Object Name -notlike '*.dist-info'`，直接数目录会多出 377 个元数据目录、数成 800 个条目）。**特别注意 `requests` 和 `beautifulsoup4` 是 Anaconda 自带的**——第 14 章爬虫的两个主力库**不用装就能用**；真正要装的是**中文分词 `jieba` 和词云 `wordcloud`**（第 7、15 章）。`sqlite3`、`tkinter` 属于标准库，不在 `site-packages` 里，随 Python 自带，永远不用装。

```bash
# 本课程真正需要装的库（中文分词 + 词云，第7、15章用）
pip install jieba wordcloud

# 第11章若要连 MySQL / MongoDB（本机没装数据库服务器，这两节仅作对照知识）
pip install pymysql pymongo

# 第12章若要按教材用 wxPython（本笔记每处都给了 tkinter 等价写法，可以不装）
pip install wxpython

# 一次装多个
pip install jieba wordcloud pymysql

# 国内加速：换成清华镜像（一次配置，长期生效）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple

# 查看已装了什么
pip list

# 确认 pip 到底装进了哪个解释器（Anaconda 用户最容易在这里出错）
python -c "import sys; print(sys.executable)"
```

> **Anaconda 用户注意**：如果 `pip` 装完仍 `import` 不到，多半是**装到了另一个 Python 环境**。用 `import sys; print(sys.executable)` 确认当前解释器路径，再决定是用 `pip` 还是 `conda install`。PyCharm 里则要在 **Settings → Project → Python Interpreter** 选中同一个解释器。

## Python 与 C 的核心差异对照表

> **这张表是这门课最重要的"心理准备"**——你已经会用 C 写程序，学 Python 最大的障碍不是语法，而是**用 C 的思维写 Python**。

| 维度 | C 语言 | Python | 为什么 / 坑在哪 |
|---|---|---|---|
| **类型系统** | **静态类型**，变量声明时确定类型 | **动态类型**（运行时才确定），但**强类型**（不会隐式乱转） | C 里 `int x` 后 x 只能是整数；Python 里 `x = 1` 之后可以 `x = "abc"`。**类型属于对象，不属于变量**——变量只是"标签" |
| **变量声明** | 必须先声明 `int a;` | **无需声明**，赋值即创建 | 忘了"未定义变量"会在运行时报 `NameError` 而不是编译期报错 |
| **语句块** | 用 `{ }` 包裹 | **用缩进表示**（4 个空格） | 缩进是**语法的一部分**，不是风格问题。混用 Tab 和空格报 `TabError` |
| **语句结束** | 必须有 `;` | **不需要分号**（写了也不报错，但不推荐） | 一行写多条语句才用 `;` |
| **编译方式** | 编译成机器码后执行 | **解释执行**（`.py` → 字节码 `.pyc` → 虚拟机） | 所以运行慢（通常慢 10~100 倍），但开发快、跨平台 |
| **内存管理** | 手动 `malloc`/`free` | **自动垃圾回收（GC）**，引用计数 + 循环检测 | 不用管内存，但**要理解"引用"**：`a = b` 不是复制而是共享同一个对象（第2章 2.4） |
| **一切皆对象** | 只有结构体和基本类型 | **连函数、类、模块、整数都是对象** | `type(1)` 返回 `<class 'int'>`；函数可以赋值、传参、返回（第5章 5.1） |
| **数组 / 容器** | 定长数组 `int a[10]`，无内置字典 | **列表 `list`（可变长）、元组 `tuple`（不可变）、字典 `dict`（哈希表）、集合 `set`** | Python 的 `list` 是"动态数组"，能混装不同类型；`dict`/`set` 查找是 **O(1)**，`list` 是 O(n) |
| **字符串** | `char[]`，以 `\0` 结尾，**可变** | `str`，**不可变**，Unicode 字符序列 | C 里 `s[0] = 'H'` 合法；Python 里报 `TypeError`。**循环里 `s += x` 是 O(n²)，要用 `"".join()`**（第2章 2.3） |
| **切片** | 无（要自己写循环或 `memcpy`） | **`s[a:b:c]` 一步完成**，支持负数下标与步长 | `s[::-1]` 直接反转字符串；切片**越界不报错**，下标越界才报 `IndexError`（第2章 2.3.2） |
| **列表推导式** | 无（要写 for 循环 + 手动扩容） | **`[x*x for x in range(10) if x % 2 == 0]`** | 一行替代五六行，且**比 for+append 快**（第4章 4.7.3） |
| **整数** | `int` 通常 32 位，会溢出（UB） | **`int` 任意精度**，不会溢出 | `2 ** 100` 能精确算出 `1267650600228229401496703205376`（第2章 2.2.1） |
| **除法** | `/` 是整数除法（截断） | **`/` 返回 float，`//` 才是整除**（向下取整） | `6 / 3` 得 `2.0`；`-7 // 2` 得 `-4`（不是 `-3`）（第2章 2.5） |
| **布尔类型** | C99 才有 `_Bool`，本质是整数 | `bool` 是 **`int` 的子类**，`True == 1` | 但 `type(True) == int` 是 `False`；`sum([True, True])` 得 `2`（第2章 2.2.4） |
| **函数参数** | **值传递**（要改外部变量得传指针） | **传对象引用**：改内容会传出去，改名字传不出去 | `def f(lst): lst.append(1)` 会影响外部；`def f(lst): lst = [9]` 不会（第5章 5.3.1） |
| **默认参数** | 无此概念 | 默认值**在定义时只求值一次** | **`def f(a=[])` 是经典陷阱**：多次调用共享同一个列表（第5章 5.3） |
| **函数返回值** | 只能返回一个值 | **可以"返回多个"**（本质是元组） | `return a, b` 实际返回 `(a, b)`（第5章 5.2.2） |
| **作用域** | 块作用域 `{ }` | **函数作用域 + LEGB 规则**，没有块作用域 | `for` 循环里定义的变量**循环外仍能用**；函数内赋值会让变量变局部（第5章 5.6） |
| **指针** | 核心概念，`*p`、`&x`、指针运算 | **没有指针**，但有"引用"；`id()` 看地址 | 想判断"是不是同一个对象"用 `is`，比值用 `==`（第2章 2.4） |
| **结构体** | `struct` | **类 `class`** 或 `@dataclass` | Python 的类比 struct 强大得多（能带方法、能继承）（第6章、第16章） |
| **错误处理** | 返回错误码 / `errno` / `goto` | **异常机制** `try/except/finally` | 异常是**控制流**的一部分，`for` 循环结束也是靠 `StopIteration`（第10章） |
| **库生态** | 标准库小，第三方库需手动编译链接 | **"内置电池"+ PyPI 生态**（40 万+ 包），`pip install` 即用 | 数据分析用 NumPy/Pandas、爬虫用 requests、AI 用 sklearn（第7、15章） |
| **命名规范** | `snake_case` 函数、`UPPER` 宏 | `snake_case` 函数/变量、**`PascalCase` 类**、`UPPER_CASE` 常量、`_private` 私有 | 见 PEP 8（第1章 1.4.3、第17章 17.12） |

> **一句话总结**：**用 C 的思维写 Python，最常见的四种翻车是——以为变量有类型、以为参数是值传递、以为 `sort()` 有返回值、以为 `input()` 返回数字。**

**高频考点清单（按出现频率排序）**：

2. **字符串处理编程题**——切片反转、统计字符、格式化输出、`join`/`split`。

## 如何使用本套笔记

**每章的固定结构**（九大板块，可直接当复习清单）：

1. **引言引用块**——对应教材章节、建议学时、重要度评级。
2. **本章知识地图**——全章结构一览，预习时先看这里。
3. **学习目标**——4~8 条"能……"，复习时逐条自测。
4. **正文小节 `N.x`**——**与教材小节编号对齐**，每个知识点按"**先给结论 → 再解释 → 再给例子**"组织，代码块都带真实输出注释。
5. **典型例题**——每章 6~7 道，含"读程序写结果"与"编程题"，给完整思路与答案。
6. **易错点提醒**——每章 10 条以上，格式为"**错在哪 → 正确做法**"。
7. **本章小结**——10 行以内 + 一句话记住本章。
8. **自测题**——每章 10 道左右，附参考答案。
9. **两个附录**——附录A 查语法，附录B 查错题与题型。

**三种典型用法**：

- **预习**：只读"知识地图 + 学习目标 + 各节的加粗结论"，20 分钟过一章。
- **复习**：读"本章小结 + 易错点提醒"，然后做"典型例题"和"自测题"。
- **上机**：打开附录A 和附录B 第三部分（检查清单），遇到报错查附录B 的"常见报错 → 快速定位"表。

**笔记中的约定**：

- 带 ★ 的是**考试与上机高频**，带 ⚠️ 的是**易错点**。
- 代码注释中的 `# 输出：...` 是**真实运行结果**（Python 3.12 实测），不是示意。
- 公式一律用 Unicode 符号单独成行（如 `S = 2πr² + 2πrh`），不使用 LaTeX。
- 术语首次出现给出中英文对照，如"**推导式（comprehension）**"。
- 表格列数不超过 6 列，方便在手机与平板上阅读。

> **最后一句**：这门课 64 学时里有 32 学时是实验，**光看笔记不写代码一定学不会**。请把每一章的代码块都敲进 PyCharm 跑一遍——**亲眼看到报错，比记住十条规则更管用。**
