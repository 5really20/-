## 7.1 概述

**三个概念的区别**：

| 概念 | 英文 | 形态 | 例子 |
|---|---|---|---|
| **模块** module | `.py` 文件 | 一个文件 | `random.py`、`mymod.py` |
| **包** package | 目录 + `__init__.py` | 一组模块 | `numpy/`、`myproj/` |
| **库** library | 模块/包的集合 | 完成某类任务 | NumPy、Pandas、requests |

**模块的四种来源**：**内置**（`sys`、`math`，用 C 写的）→ **标准库**（`random`、`os`，随 Python 安装）→ **第三方**（需 `pip install`）→ **自定义**（自己写的 `.py`）。

### import 的五种形式

```python
# ① 导入整个模块（最推荐：来源清晰）
import math
print(math.sqrt(16))        # 4.0

# ② 导入整个模块并起别名（长名字常用）
import numpy as np
print(np.array([1, 2]))     # [1 2]

# ③ 从模块导入指定成员
from math import sqrt, pi
print(sqrt(16), pi)         # 4.0 3.141592653589793

# ④ 从模块导入成员并起别名（避免重名）
from math import sqrt as sq
print(sq(16))               # 4.0

# ⑤ 导入全部成员（不推荐）
from math import *
print(sqrt(16))             # 4.0
```

| 形式 | 调用写法 | 优点 | 缺点 |
|---|---|---|---|
| `import math` | `math.sqrt(16)` | **来源清晰**，不污染名字 | 每次要写模块名 |
| `import numpy as np` | `np.array(...)` | 简洁 + 清晰 | —— |
| `from math import sqrt` | `sqrt(16)` | 简洁 | 名字冲突时难排查 |
| `from math import *` | `sqrt(16)` | 最简洁 | **可能覆盖同名变量/函数，严禁在项目里用** |

> **坑：`from math import *` 之后如果自己定义 `def sqrt(x)`，会覆盖导入的函数。** 更隐蔽的是它可能覆盖你之前定义的变量名，而且没人知道 `sqrt` 到底从哪来。**只有交互式试验和教材演示才用 `*`。**

### 模块搜索路径

`import xxx` 时，Python 按以下**顺序**查找：

1. **内置模块**（`sys`、`builtins` 等，直接命中，不查磁盘）
2. **`sys.path` 列表中的路径**，依次为：
   - ① **当前脚本所在目录**（交互式下是当前工作目录）
   - ② 环境变量 `PYTHONPATH` 中的目录
   - ③ **标准库目录**（`Lib/`）
   - ④ **第三方库目录**（`Lib/site-packages/`）

```python
import sys
for p in sys.path:
    print(p)
# D:\others\nothing            ← 脚本所在目录排在最前
# C:\...\python312.zip
# C:\...\DLLs
# C:\...\Lib
# C:\...\Lib\site-packages     ← 第三方库都装在这
```

> **经典坑**：**把自己的文件命名为 `random.py` 或 `json.py`，会让标准库同名模块被"顶掉"**，报出莫名其妙的错误（`AttributeError: module 'random' has no attribute 'randint'`）。因为当前目录优先级最高，你的 `random.py` 抢先被加载了。**自建模块一律加前缀或起独特名字**，如 `my_random.py`。

### `__name__ == "__main__"` 的作用

每个模块都有一个 `__name__` 变量：

- **直接运行该文件时**，`__name__` 的值是 `"__main__"`；
- **被别的文件 import 时**，`__name__` 的值是**模块名**。

```python
# mymod.py
PI = 3.14159

def add(a, b):
    return a + b

def main():
    print("mymod main", add(1, 1))

if __name__ == "__main__":      # 只有直接运行时才执行
    main()
```

```python
# 直接运行 python mymod.py  → 输出：mymod main 2
# 在别的文件 import mymod  → 什么都不打印，只拿到 PI 和 add
import _mymod
print(_mymod.add(1, 2), _mymod.PI)      # 3 3.14159
```

> **为什么必须写这一句？** ① 让模块**既能当脚本运行、又能当库被导入**；② 避免 `import` 时意外执行测试代码；③ 单元测试、`multiprocessing`（Windows）都要求有这个保护。**这是 Python 工程化最基础的一行代码。**

### 包的结构

```
myproj/                    ← 包（目录）
├── __init__.py            ← 包的初始化文件（可为空，但必须有）
├── utils.py               ← 模块
└── data/                  ← 子包
    ├── __init__.py
    └── loader.py
```

```python
from myproj import utils            # 导入包里的模块
from myproj.utils import helper     # 导入模块里的函数
from myproj.data.loader import read # 导入子包里的函数
```

> **`__init__.py` 的作用**：① 标识这是一个包（Python 3.3+ 起可省略，但**强烈建议保留**）；② 可以在里面写 `from .utils import helper` 简化外部导入路径；③ 定义 `__all__` 控制 `from myproj import *` 导入哪些名字。

## 7.2 常用标准库模块

### 7.2.1 Turtle

**Turtle（海龟绘图）**：用一只「海龟」在画布上爬行来绘图，是理解「程序控制图形」最直观的工具。

| 函数 | 作用 |
|---|---|
| `forward(d)` / `fd(d)` | 前进 d 像素 |
| `backward(d)` | 后退 d 像素 |
| `left(a)` / `right(a)` | 左转/右转 a 度 |
| `goto(x, y)` | 移动到坐标 (x, y) |
| `penup()` / `pendown()` | 抬笔（不留痕）/ 落笔 |
| `pensize(w)` / `pencolor(c)` | 笔宽 / 笔色 |
| `fillcolor(c)` / `begin_fill()` / `end_fill()` | 填充色 / 开始填充 / 结束填充 |
| `circle(r, extent)` | 画半径为 r、角度 extent 的圆弧 |
| `speed(n)` / `hideturtle()` | 速度 0~10 / 隐藏海龟 |
| `done()` | 进入事件循环（**绘图最后一句必写**） |

```python
import turtle

t = turtle.Turtle()
t.speed(0)                      # 0 是最快
for i in range(5):              # 画五角星
    t.forward(150)
    t.right(144)                # 外角 180 - 36 = 144
t.hideturtle()
turtle.done()                   # 弹出窗口显示一个五角星
```

```python
import turtle

t = turtle.Turtle()
t.pensize(2)
colors = ["red", "orange", "yellow", "green", "blue", "purple"]
for i in range(60):             # 螺旋线
    t.pencolor(colors[i % 6])
    t.forward(i * 4)
    t.right(59)
turtle.done()                   # 弹出窗口显示彩色螺旋线
```

> **注意**：`turtle.done()` 会**阻塞**程序直到关闭窗口；如果写在脚本里忘了关窗口，命令行会一直不返回。用 `turtle.bye()` 可直接关闭。

### 7.2.2 Random

| 函数 | 作用 | 返回值 |
|---|---|---|
| `random()` | [0.0, 1.0) 之间的浮点数 | `float` |
| `randint(a, b)` | [a, b] **闭区间**的整数 | `int` |
| `randrange(a, b, step)` | [a, b) 按步长的整数 | `int` |
| `uniform(a, b)` | [a, b] 的浮点数 | `float` |
| `choice(seq)` | 随机选**一个**元素 | 元素类型 |
| `choices(seq, weights, k)` | 按权重选 k 个（**可重复**） | `list` |
| `sample(seq, k)` | 选 k 个**不重复**元素 | `list` |
| `shuffle(lst)` | **就地**打乱列表 | `None` |
| `seed(n)` | 设定随机种子（结果可复现） | `None` |
| `gauss(mu, sigma)` | 正态分布随机数 | `float` |

```python
import random

random.seed(1)                          # 固定种子 → 每次运行结果相同
print(random.random())                  # 0.13436424411240122
print(random.randint(1, 6))             # 1

random.seed(1)                          # 重新播种 → 序列从头开始
print(random.randrange(0, 10, 2))       # 2
print(random.choice("abc"))             # c
print(random.sample(range(10), 3))      # [1, 4, 9]

lst = [1, 2, 3, 4, 5]
random.shuffle(lst)
print(lst)                              # [3, 4, 5, 1, 2]
```

> **`random` 是伪随机**：由种子经过确定性算法算出，**不是真随机**。`seed()` 固定后结果完全可复现——这在**调试和实验对比**时非常有用（成绩抽奖程序、模拟实验都要固定种子）。**安全用途（生成密码、令牌）必须用 `secrets` 模块，不能用 `random`。**

### 7.2.3 Time 和 Datetime

**`time` 面向「时间戳 / 性能计时」，`datetime` 面向「日期运算与格式化」。**

| 模块 | 常用函数 | 说明 |
|---|---|---|
| `time` | `time()` | 当前时间戳（秒，float） |
| | `time.perf_counter()` | **高精度计时器**（测性能首选） |
| | `time.sleep(s)` | 暂停 s 秒 |
| | `time.strftime(fmt, t)` | 时间元组 → 字符串 |
| `datetime` | `datetime.date(y, m, d)` | 日期对象 |
| | `datetime.datetime(y, m, d, h, mi, s)` | 日期时间对象 |
| | `datetime.timedelta(days=…)` | 时间间隔 |
| | `datetime.now()` | 当前日期时间 |
| | `strftime(fmt)` | 格式化为字符串 |
| | `strptime(s, fmt)` | 字符串解析为日期 |

```python
import time, datetime

print(time.time() > 0)                          # True   当前时间戳
print(type(time.localtime()).__name__)          # struct_time
print(time.strftime("%Y-%m-%d %H:%M:%S", time.localtime(0)))
# 1970-01-01 08:00:00      ← 时间戳 0 是 UTC 1970-01-01 00:00，东八区显示为 08:00

d1 = datetime.date(2025, 1, 1)
d2 = datetime.date(2025, 12, 31)
print((d2 - d1).days)                           # 364    两个日期相差天数
print(d1.strftime("%Y年%m月%d日"))               # 2025年01月01日
print(d1.strftime("%Y-%m-%d %A"))               # 2025-01-01 Wednesday
print(d1 + datetime.timedelta(days=100))        # 2025-04-11
print(datetime.datetime.strptime("2025-09-01 10:30", "%Y-%m-%d %H:%M"))
# 2025-09-01 10:30:00
```

**常用格式符表（必背）**：

| 符号 | 含义 | 例子 |
|---|---|---|
| `%Y` | 四位年 | 2025 |
| `%m` | 两位月 | 09 |
| `%d` | 两位日 | 01 |
| `%H` `%M` `%S` | 时 分 秒（24 小时制） | 10 30 00 |
| `%A` / `%a` | 星期全称 / 缩写 | Wednesday / Wed |
| `%j` | 一年中的第几天 | 244 |

> **`%Y` 与 `%y` 的区别**：`%Y` 是 4 位年（2025），`%y` 是 2 位年（25）。**`%y` 的两位年有隐含的世纪规则**：`69~99` 解析成 `1969~1999`，`00~68` 解析成 `2000~2068`（实测 `strptime("25","%y")` → `2025-01-01`、`strptime("68","%y")` → `2068-01-01`、`strptime("69","%y")` → **`1969-01-01`**、`strptime("99","%y")` → `1999-01-01`）。**所以用 `%y` 解析"69"会悄悄变成 1969 年**——这是处理 Excel 导入日期时最常见的 bug。反过来用 `%Y` 去解析两位年则直接报错（`strptime("25","%Y")` → `ValueError: time data '25' does not match format '%Y'`），不会静默出错。**结论：年份一律用 `%Y`。**

> **两个易错点**：① `datetime.date` 与 `datetime.datetime` **比较时表现不同**——`==` 返回 `False`（**不报错**），`<` / `>` 才抛 `TypeError: '<' not supported between instances of 'datetime.date' and 'datetime.datetime'`；要比较先把 `datetime` 取 `.date()`；② `timedelta` 只能与 `date`/`datetime` 运算，**`date + date` 是错误用法**。

### 7.2.4 Os

**`os` 提供操作系统接口：路径操作、目录操作、环境变量。**

| 函数 | 作用 | 例子输出 |
|---|---|---|
| `os.getcwd()` | 当前工作目录 | `D:\others\nothing` |
| `os.path.join(a, b)` | **拼路径（跨平台安全）** | `a\b\c.txt` |
| `os.path.exists(p)` | 路径是否存在 | `True` |
| `os.path.isdir(p)` / `isfile(p)` | 是否目录 / 文件 | `True` |
| `os.path.basename(p)` | 取文件名 | `b.txt` |
| `os.path.dirname(p)` | 取目录名 | `D:\a` |
| `os.path.splitext(p)` | 拆扩展名 | `('data', '.csv')` |
| `os.path.abspath(p)` | 转绝对路径 | `D:\...` |
| `os.listdir(p)` | 列出目录内容 | `['a.txt', 'data']` |
| `os.makedirs(p, exist_ok=True)` | **递归创建目录** | —— |
| `os.rmdir(p)` / `os.remove(p)` | 删空目录 / 删文件 | —— |
| `os.walk(p)` | **递归遍历目录树** | 生成器 |

```python
import os

print(os.getcwd()[:3])                                  # D:\
print(os.path.join("a", "b", "c.txt"))                  # a\b\c.txt
print(os.path.exists(r"D:\others\nothing"))             # True
print(os.path.splitext("data.csv"))                     # ('data', '.csv')
print(os.path.basename(r"D:\a\b.txt"))                  # b.txt
print(os.path.dirname(r"D:\a\b.txt"))                   # D:\a

p = os.path.join(r"D:\others\nothing", "_tmpdir")
os.makedirs(p, exist_ok=True)       # 目录已存在也不报错
print(os.path.exists(p))            # True
os.rmdir(p)
print(os.path.exists(p))            # False
```

**递归遍历目录树（统计所有 `.py` 文件）**：

```python
import os

total = 0
for root, dirs, files in os.walk(r"D:\others\nothing"):
    for f in files:
        if f.endswith(".py"):
            total += 1
            print(os.path.join(root, f))
print("共", total, "个 .py 文件")
```

> **坑：用字符串拼接路径。** `"D:\a" + "\\" + "b.txt"` 在 Windows 能跑，到 Linux 就错（分隔符是 `/`）。**一律用 `os.path.join()`**，它会自动用当前系统的分隔符。更好的现代写法是 `pathlib.Path`：
>
> ```python
> from pathlib import Path
> p = Path("D:/others/nothing") / "data" / "a.txt"
> print(p.name, p.suffix, p.parent, p.exists())
> ```

> **`os.makedirs` 与 `os.mkdir` 的区别**：`mkdir` 只能建**一级**目录，父目录不存在就报错；`makedirs` 会**递归创建**所有中间目录。**加上 `exist_ok=True` 才不会在目录已存在时报 `FileExistsError`。**

### 7.2.5 Sys

| 函数/属性 | 作用 | 说明 |
|---|---|---|
| `sys.argv` | 命令行参数列表 | `argv[0]` 是脚本名 |
| `sys.path` | 模块搜索路径 | 可 `append` 加入自定义目录 |
| `sys.version` / `version_info` | Python 版本 | `(3, 12)` |
| `sys.platform` | 操作系统标识 | `win32` / `linux` / `darwin` |
| `sys.maxsize` | 最大整数 | `9223372036854775807` |
| `sys.getrecursionlimit()` | 递归深度上限 | `1000` |
| `sys.exit(code)` | 退出程序 | `0` 表示正常 |
| `sys.stdin` / `stdout` / `stderr` | 标准流对象 | 可重定向 |

```python
import sys

print(sys.version_info[:2])     # (3, 12)
print(sys.platform)             # win32
print(sys.maxsize)              # 9223372036854775807

# 命令行参数：python script.py 10 20
if len(sys.argv) > 1:
    print(sys.argv[1:])         # ['10', '20']   ← 都是字符串！
```

> **坑：`sys.argv` 里的元素全是字符串**，做数值运算前必须 `int()` / `float()` 转换。另外**没有参数时访问 `sys.argv[1]` 会 `IndexError`**，所以要先判断 `len(sys.argv) > 1`。

### 7.2.6 Timeit

**`timeit` 专门用来做「微基准测试」，比手写 `time.time()` 更准确**（自动多次运行、禁用垃圾回收干扰）。

```python
import timeit

# 语句方式：测一段代码字符串
t1 = timeit.timeit("[x**2 for x in range(100)]", number=1000)
t2 = timeit.timeit("lst=[]\nfor x in range(100): lst.append(x**2)", number=1000)
print(round(t1, 4), round(t2, 4))       # 0.003 0.0033   ← 列表推导式略快

# setup 方式：先准备环境再测
t3 = timeit.timeit(stmt="a+b", setup="a=1;b=2", number=100000)
print(round(t3, 4))                     # 0.0037

# repeat 方式：重复多轮取最小值（更能反映真实性能）
print(min(timeit.repeat("[x for x in range(100)]", number=1000, repeat=5)) > 0)  # True
```

| 参数 | 含义 |
|---|---|
| `stmt` | 要测的代码（**字符串**） |
| `setup` | 运行前执行的准备代码 |
| `number` | 每次测量执行多少遍 |
| `repeat` | 测量多少轮（配合 `min()` 取最小值） |

> **为什么用 `min()` 而不是平均值？** 因为外部干扰（系统调度、GC）只会让某轮**变慢**，不会变快。**最小值最接近代码的真实速度。**

### 7.2.7 Zlib

**`zlib` 提供 DEFLATE 无损压缩，用于压缩数据流。**

```python
import zlib

raw = "Python程序设计" * 10
data = raw.encode("utf-8")
comp = zlib.compress(data)                  # 默认级别 6
print(len(data), len(comp))                 # 180 31     ← 压缩到 17%
print(zlib.decompress(comp).decode("utf-8") == raw)     # True

print(zlib.crc32(b"hello"))                 # 907060870   校验和
```

| 函数 | 作用 |
|---|---|
| `zlib.compress(data, level)` | 压缩字节串，level 0~9 |
| `zlib.decompress(data)` | 解压 |
| `zlib.crc32(data)` | 计算 CRC32 校验和 |
| `zlib.compressobj()` | 流式压缩（大文件分块用） |

> **坑：`zlib` 只能处理 `bytes`，不能直接处理 `str`。** 必须先 `s.encode("utf-8")`，解压后要 `.decode("utf-8")`。重复字符串压缩率极高（180 → 31 字节），**但已经是压缩包的文件（jpg/png/zip）再压缩几乎不会变小**。

### 7.3.1 NumPy

**NumPy（Numerical Python）是 Python 科学计算的基石**，核心是 **ndarray（N 维数组）**：**同类型、定长、支持向量化运算**。

**安装与导入**：

```python
# 命令行：pip install numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
import numpy as np
```

**① ndarray 与 list 的三点区别**

| 对比项 | `list` | `ndarray` |
|---|---|---|
| 元素类型 | 可以不同 | **必须相同**（统一 dtype） |
| 运算含义 | `[1,2]*2` → `[1,2,1,2]` | `a*2` → **每个元素乘 2** |
| 性能 | 慢（逐元素对象） | **快几十倍**（连续内存 + C 实现） |

```python
import numpy as np

a = np.array([[1, 2, 3], [4, 5, 6]])
print(a.shape, a.ndim, a.size, a.dtype)     # (2, 3) 2 6 int64
print(a + 10)                               # 每个元素 +10
# [[11 12 13]
#  [14 15 16]]
```

**② 创建数组的常用函数**

| 函数 | 作用 | 例子 |
|---|---|---|
| `np.array(list)` | 从列表创建 | `np.array([1,2,3])` |
| `np.arange(start, stop, step)` | 等差序列 | `np.arange(0,10,2)` → `[0 2 4 6 8]` |
| `np.linspace(start, stop, n)` | **等分 n 个点** | `np.linspace(0,1,5)` → `[0. 0.25 0.5 0.75 1.]` |
| `np.zeros(shape)` | 全 0 | `np.zeros((2,2))` |
| `np.ones(shape)` | 全 1 | `np.ones(3)` |
| `np.full(shape, v)` | 全 v | `np.full(3, 7)` |
| `np.eye(n)` | 单位矩阵 | `np.eye(3)` |
| `np.random.rand(n)` | [0,1) 随机数 | —— |

```python
print(np.arange(0, 10, 2).tolist())             # [0, 2, 4, 6, 8]
print(np.linspace(0, 1, 5).tolist())            # [0.0, 0.25, 0.5, 0.75, 1.0]
print(np.zeros((2, 2)).tolist())                # [[0.0, 0.0], [0.0, 0.0]]
print(np.ones(3).tolist())                      # [1.0, 1.0, 1.0]
```

> **`arange` 与 `linspace` 的区别（易混）**：`arange` 给的是**步长**，元素个数由区间算出（可能因浮点误差多一个少一个）；`linspace` 给的是**元素个数**，步长自动算（**默认包含终点**）。**画图取横坐标一律用 `linspace`**，因为你需要确定的点数。

**③ 索引、切片、布尔索引**

```python
a = np.array([[1, 2, 3], [4, 5, 6]])
print(a[0, 1])                  # 2        二维索引用逗号，不用 a[0][1]
print(a[:, 1].tolist())         # [2, 5]   取所有行的第 1 列
print(a[1, :2].tolist())        # [4, 5]
print(a.T.tolist())             # [[1, 4], [2, 5], [3, 6]]   转置

print((a > 3).tolist())         # [[False, False, False], [True, True, True]]
print(a[a > 3].tolist())        # [4, 5, 6]     布尔索引：直接筛出满足条件的元素
```

> **关键差异**：`a[:, 1]` 是**列切片**，`list` 做不到这一点；`a[a > 3]` 这种**布尔索引**也是 `list` 没有的能力，它在数据分析里用来做条件筛选。

**④ 广播（broadcasting）与统计**

```python
a = np.array([[1, 2, 3], [4, 5, 6]])
b = np.array([10, 20, 30])          # 形状 (3,)
print((a + b).tolist())             # [[11, 22, 33], [14, 25, 36]]
# 广播：b 自动"扩展"到每一行

print(a.sum(), a.sum(axis=0).tolist(), a.sum(axis=1).tolist())
# 21 [5, 7, 9] [6, 15]      axis=0 按列求和，axis=1 按行求和
print(a.mean(), a.max(), a.min(), a.std())
# 3.5 6 1 1.707825127659933
print(np.sqrt(np.array([4, 9])).tolist())       # [2.0, 3.0]   向量化开方
print(np.dot([1, 2], [3, 4]))                   # 11           点积
```

> **广播规则（一句话）**：从**最后一个维度**往前对齐，维度相等或其中一个是 1 就能运算，否则报 `ValueError: operands could not be broadcast together`。
>
> **`axis` 记法（最容易错）**：**`axis=0` 是"沿着行的方向压下去"，结果是每列一个值；`axis=1` 是"沿着列的方向压过去"，结果是每行一个值。** 记忆口诀：**`axis=i` 表示"消掉第 i 个维度"**。上例 `a` 形状是 (2, 3)：`axis=0` 消掉行 → 结果 3 个（每列的和）；`axis=1` 消掉列 → 结果 2 个（每行的和）。

**⑤ 向量化：为什么 NumPy 快**

```python
import numpy as np, timeit

n = 1_000_000
t1 = timeit.timeit(lambda: [x ** 2 for x in range(n)], number=1)
t2 = timeit.timeit(lambda: np.arange(n) ** 2, number=1)
print(f"list: {t1:.4f}s  numpy: {t2:.4f}s  快 {t1/t2:.1f} 倍")
# list: 0.0780s  numpy: 0.0034s  快 22.7 倍
# ⚠️ 计时数字每跑一次都不一样：同一台机器连跑 5 次得到 list 0.076~0.090s、
#    numpy 0.0031~0.0043s、快 17.8~27.0 倍。**看量级（快一个数量级），别背具体数字。**
```

> **为什么快？** ① ndarray 在内存中是**连续的同类型数据块**，CPU 缓存友好；② 循环在 **C 层**执行，没有 Python 解释器的逐元素开销；③ 可借助 SIMD 指令并行。**NumPy 的第一原则：能用数组运算就不要写 for 循环。**

### 7.3.2 Pandas

**Pandas 建立在 NumPy 之上，提供带标签的数据结构，是数据分析的主力工具。**

| 结构 | 维度 | 类比 |
|---|---|---|
| **Series** | 一维 | 带标签的数组（一列） |
| **DataFrame** | 二维 | Excel 表格 / 数据库表 |

```python
import pandas as pd

# ① Series
s = pd.Series([85, 92, 78], index=["张三", "李四", "王五"], name="成绩")
print(s["李四"], s.mean(), s.max())         # 92 85.0 92
print(s[s > 80].tolist())                   # [85, 92]

# ② DataFrame
df = pd.DataFrame({
    "姓名": ["张三", "李四", "王五"],
    "Python": [92, 85, 78],
    "数学": [88, 90, 70],
})
print(df.shape, list(df.columns))           # (3, 3) ['姓名', 'Python', '数学']
df["总分"] = df["Python"] + df["数学"]       # 新增列（按列运算，无需循环）
print(df["总分"].tolist())                  # [180, 175, 148]
print(df["总分"].mean())                    # 167.66666666666666
```

**常用操作表**：

| 操作 | 写法 | 说明 |
|---|---|---|
| 查看前 n 行 | `df.head(3)` | 默认 5 行 |
| 行列信息 | `df.shape` / `df.columns` / `df.dtypes` | 形状 / 列名 / 类型 |
| 描述统计 | `df.describe()` | 计数、均值、分位数 |
| 选列 | `df["Python"]` / `df[["姓名","数学"]]` | 一列 Series / 多列 DataFrame |
| 条件筛选 | `df[df["总分"] > 160]` | **布尔索引** |
| 排序 | `df.sort_values("总分", ascending=False)` | 按列排序 |
| 分组统计 | `df.groupby("班级")["总分"].mean()` | 分组聚合 |
| 读写文件 | `pd.read_csv(p)` / `df.to_csv(p, index=False)` | CSV |
| 转成字典/列表 | `df.to_dict("records")` | —— |

```python
# 条件筛选 + 排序 + 取值
print(df[df["总分"] > 160]["姓名"].tolist())         # ['张三', '李四']
print(df.sort_values("总分", ascending=False)["姓名"].tolist())
# ['张三', '李四', '王五']
print(df.groupby("姓名")["总分"].sum().to_dict())
# {'张三': 180, '李四': 175, '王五': 148}
```

> **坑：`df["总分"] > 160` 得到的是一个布尔 Series，不是 True/False**，必须整体作为下标传给 `df[...]`。写 `if df["总分"] > 160:` 会报 `ValueError: The truth value of a Series is ambiguous`——要判断「是否存在满足条件的行」写 `if (df["总分"] > 160).any():`。

> **Pandas 的「链式赋值」警告**：`df[df["总分"]>160]["等级"] = "优"` 会报 `SettingWithCopyWarning`，且可能不生效。正确写法是 `df.loc[df["总分"] > 160, "等级"] = "优"`。

**⑤ 中文乱码的解决（必考）**

**默认字体不含中文，标题和图例会显示成方框（□□□）。** 实测默认 `font.sans-serif` 是 `['DejaVu Sans', 'Bitstream Vera Sans', ...]`，画一个中文标题会连打 **9 条 `Glyph xxxxx (\N{CJK UNIFIED IDEOGRAPH-...}) missing from font(s) DejaVu Sans.`** 警告（每个不同的汉字一条）；设好字体后警告降到 **0 条**。**看到 `Glyph ... missing` 就知道是字体问题，不用猜。** 加两行全局设置即可：

```python
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]    # 指定中文字体（Windows 自带黑体）
plt.rcParams["axes.unicode_minus"] = False      # 解决负号显示成方框的问题

plt.plot([1, 2, 3], [-1, -2, -3])
plt.title("中文标题测试")
plt.show()                  # 标题正常显示中文，纵轴负号正常
```

| 平台 | 可用中文字体名 |
|---|---|
| Windows | `SimHei`（黑体）、`Microsoft YaHei`（微软雅黑） |
| macOS | `Arial Unicode MS`、`Heiti TC` |
| Linux | `WenQuanYi Micro Hei`（需先安装） |

> **两条设置缺一不可**：只设字体不设 `axes.unicode_minus = False`，**负号仍会显示成方框**——因为 **matplotlib 默认的负号不是 ASCII 的连字符 `-`（U+002D），而是 Unicode 减号 `−`（U+2212）**，它**不属于 `font.sans-serif` 管辖的字体范围**，所以设了中文字体也没用。实测：画 `[-1, -2, -3]` 后取纵轴刻度文本，**11 个刻度全部含 U+2212，含 ASCII `-` 的有 0 个**。
> **注意这两行必须在绘图之前设置。**

**⑥ 保存图片**

```python
plt.savefig("chart.png", dpi=300, bbox_inches="tight")   # 保存到文件
plt.show()
```

> **顺序坑（实测过，是真坑）**：`savefig()` 必须写在 `show()` **之前**。
>
> **为什么？** `show()` 会**阻塞**程序，直到你**把弹出的窗口关掉**才返回；而**窗口一关，那张图就被销毁了**，此时再 `savefig` 只会得到一张**纯白的空白图**。实测（`TkAgg` 后端，4×3 英寸的折线图）：`show` 之前保存 → **14044 字节**、非白像素占 5.24%；关窗之后再保存 → **2397 字节**、平均灰度 255.0、**非白像素占 0.0%**（全白）。
>
> **注意别被误导**：如果你在**没有图形界面**的环境（服务器、`matplotlib.use("Agg")`、某些 Jupyter 配置）下跑，`show()` 其实什么都不做（只打一条 `UserWarning: FigureCanvasAgg is non-interactive`），这时"写在 `show` 之后"也**不会**变白——**所以这个坑时灵时不灵，但正确写法只有一种：`savefig` 在前。**

### 7.3.5 Jieba

**Jieba（结巴分词）是中文分词库**，中文没有空格分隔词语，必须先分词才能做词频统计、词云。

**安装**：`pip install jieba`

```python
import jieba

text = "Python是一门简洁优雅的编程语言，适合数据分析和人工智能开发。"

print(list(jieba.cut(text)))            # 精确模式（默认）：适合文本分析
# ['Python', '是', '一门', '简洁', '优雅', '的', '编程语言', '，', '适合', '数据分析', '和', '人工智能', '开发', '。']

print(list(jieba.cut(text, cut_all=True)))      # 全模式：列出所有可能的词，有冗余
# ['Python', '是', '一门', '简洁', '优雅', '的', '编程', '编程语言', '语言', '，', '适合', '合数',
#  '数据', '数据分析', '分析', '和', '人工', '人工智能', '智能', '能开', '开发', '。']

print(list(jieba.cut_for_search(text)))         # 搜索引擎模式：长词再切分
# ['Python', '是', '一门', '简洁', '优雅', '的', '编程', '语言', '编程语言', '，', '适合', '数据',
#  '分析', '数据分析', '和', '人工', '智能', '人工智能', '开发', '。']

print(jieba.lcut(text)[:3])                     # lcut = 直接返回 list（日常最常用）
# ['Python', '是', '一门']
```

**三种模式的差别，用一句短文本看得最清楚**（上面长文本的输出太长，不容易比）：

```python
t = "我来到北京清华大学"

print(list(jieba.cut(t)))                 # 精确模式：4 个词，最干净
# ['我', '来到', '北京', '清华大学']

print(list(jieba.cut(t, cut_all=True)))   # 全模式：7 个，把长词也切碎，有冗余
# ['我', '来到', '北京', '清华', '清华大学', '华大', '大学']
#                                        ↑「华大」是把「清华大学」错切出来的产物

print(list(jieba.cut_for_search(t)))      # 搜索模式：7 个，长词切碎后再补回长词本身
# ['我', '来到', '北京', '清华', '华大', '大学', '清华大学']
#                                        ↑ 比全模式多了完整的「清华大学」，便于检索命中
```

> **怎么选**：**做词频统计、词云一律用精确模式（`jieba.lcut`）**；全模式和搜索模式只用于「尽量不漏掉任何可能的检索词」的搜索场景，直接拿去做词频会把同一个词算成好几个。

**自定义词典（处理专业名词/人名）**：

```python
import jieba

print(jieba.lcut("我在湖北大学学Python"))     # 默认词典不认识「湖北大学」，被切成两个词
# ['我', '在', '湖北', '大学', '学', 'Python']

jieba.add_word("湖北大学")                    # 添加一个自定义词
print(jieba.lcut("我在湖北大学学Python"))     # 现在完整保留了
# ['我', '在', '湖北大学', '学', 'Python']

# 也可以从文件批量加载：每行一个词，后面可再跟词频和词性（用空格分隔）
# userdict.txt 的内容示例（自己新建一个同名文本文件即可）：
#     湖北大学 100 n
#     数据科学 50 n
#     黄鹤楼
with open("userdict.txt", "w", encoding="utf-8") as f:   # 先把文件造出来
    f.write("湖北大学 100 n\n数据科学 50 n\n黄鹤楼\n")

jieba.load_userdict("userdict.txt")           # 加载后，词典里的词不会再被切开
print(jieba.lcut("我在湖北大学学数据科学"))
# ['我', '在', '湖北大学', '学', '数据科学']
print(jieba.lcut("武汉黄鹤楼很美"))
# ['武汉', '黄鹤楼', '很', '美']
```

> **`add_word` 与 `load_userdict` 的区别**：`add_word("词")` 加一个；`load_userdict("文件名")` 从文件批量加，**必须传一个真实存在的文件路径，否则报 `FileNotFoundError: [Errno 2] No such file or directory: 'userdict.txt'`**——第一次用这个函数的人几乎都会踩。

> **词频统计的标准套路**：`jieba.lcut(text)` → `collections.Counter` → 过滤单字和标点 → `most_common(10)`。**词云（wordcloud）就是把词频喂给 `WordCloud` 类生成图片**：`pip install wordcloud` 后，`WordCloud(font_path="C:/Windows/Fonts/simhei.ttf").generate(text)`——**注意必须指定 `font_path` 为中文 TTF，否则词云全是方框。**

### 7.3.6 Pyinstaller

**Pyinstaller 把 Python 脚本打包成可执行文件（exe），让没装 Python 的电脑也能运行。**

**安装**：`pip install pyinstaller`

**基本用法**：

```bash
pyinstaller -F -w -i app.ico main.py
```

| 参数 | 作用 |
|---|---|
| `-F` / `--onefile` | 打包成**单个** exe（默认是文件夹） |
| `-w` / `--windowed` | 不显示控制台窗口（**GUI 程序必加**） |
| `-i app.ico` | 指定图标 |
| `-n 名称` | 指定生成的 exe 名 |
| `--hidden-import=模块` | 强制导入未被自动发现的模块 |
| `--add-data "src;dest"` | 打包额外数据文件（Windows 用 `;` 分隔） |

**输出目录**：

```
项目/
├── build/          ← 临时文件，可删
├── dist/           ← 成品（exe 或文件夹）
└── main.spec       ← 打包配置，可改后 pyinstaller main.spec 复用
```

**四个常见坑**：

| 问题 | 原因 | 解决 |
|---|---|---|
| exe 体积 100MB+ | 打包了整个解释器和依赖 | 用虚拟环境 `venv` 只装必需的包再打包 |
| 双击闪退 | 程序报错但窗口一闪而过 | 先**不加 `-w`** 打包，用命令行运行看错误信息 |
| 找不到数据文件 | 打包后路径变了 | 用 `sys._MEIPASS` 获取临时解压目录 |
| 杀毒软件报警 | PyInstaller 引导程序常被误判 | 添加信任，或改用 Nuitka |

> **`-F` 的代价**：单文件 exe 每次运行都要把内容解压到临时目录，**启动比文件夹模式慢**。给老师交作业用 `-F` 方便，正式发布建议文件夹模式。

## 7.4 自定义模块

**任何 `.py` 文件都是一个模块**，模块名就是文件名（不含 `.py`）。

**步骤 ①：写模块文件 `mymath.py`**

```python
"""自定义数学工具模块"""

PI = 3.14159

def circle_area(r):
    """计算圆面积"""
    return PI * r ** 2

def _internal():            # 单下划线开头：内部函数，不建议外部使用
    return "internal"

def main():
    print("自测：", circle_area(1))

if __name__ == "__main__":  # 只有直接运行本文件时才执行
    main()
```

**步骤 ②：在同一个目录下导入使用**

```python

```

**步骤 ③：模块不在同一目录时，把目录加进 `sys.path`**

```python

```

**`__all__` 控制 `import *` 的范围**：


### 7.5.1 使用 Turtle 绘制表面填充正方体

**思路**：正方体在平面上的投影由**三个四边形**组成——正面（正方形）、顶面（平行四边形）、右侧面（平行四边形）。用 `goto()` 按坐标连线并填充即可。

```python
import turtle

t = turtle.Turtle()
t.speed(0)
t.hideturtle()

def poly(points, color):
    """按顶点列表画填充多边形"""
    t.fillcolor(color)
    t.begin_fill()
    t.penup()
    t.goto(points[0])
    t.pendown()
    for p in points[1:]:
        t.goto(p)
    t.goto(points[0])           # 回到起点闭合
    t.end_fill()

front = [(-120, -120), (0, -120), (0, 0), (-120, 0)]     # 正面：正方形
top   = [(-120, 0), (0, 0), (60, 60), (-60, 60)]         # 顶面：平行四边形
right = [(0, -120), (60, -60), (60, 60), (0, 0)]         # 右侧面：平行四边形

poly(front, "#4da6ff")          # 正面用中间色
poly(top, "#8ecbff")            # 顶面用浅色（受光面）
poly(right, "#2d7fd3")          # 侧面用深色（背光面）

turtle.done()                   # 弹出窗口显示一个三面填充的立体正方体
```

**要点**：**三个面用深浅不同的同色系**才能产生立体感；`goto()` 画多边形**最后一定要回到起点**才能正确闭合填充。

### 7.5.2 使用 NumPy 和 Matplotlib 分析股票

**思路**：用 NumPy 生成/读入收盘价序列 → 计算**日收益率**和**移动平均线** → 用 Matplotlib 画双轴图。

```python
import numpy as np
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

np.random.seed(42)
days = 60
# 模拟股价：从 100 开始，每天涨跌 2%
returns = np.random.normal(0.001, 0.02, days)
close = 100 * np.cumprod(1 + returns)

# 日收益率
daily_ret = np.diff(close) / close[:-1]

# 5 日移动平均线（用卷积实现，无需循环）
ma5 = np.convolve(close, np.ones(5) / 5, mode="valid")

print(f"起始价 {close[0]:.2f}  最新价 {close[-1]:.2f}")
print(f"最高 {close.max():.2f}  最低 {close.min():.2f}")
print(f"平均日收益率 {daily_ret.mean():.4%}  波动率 {daily_ret.std():.4%}")
print(f"最大单日跌幅 {daily_ret.min():.4%}")
# 起始价 101.09  最新价 87.33
# 最高 110.32  最低 82.18
# 平均日收益率 -0.2314%  波动率 1.8090%
# 最大单日跌幅 -3.8193%
# ⚠️ 注意：close[0] 不是 100.00 而是 101.09 —— 因为 close[0] = 100×(1+returns[0])，
#    第一天就已经涨了。同理「最新价 87.33 < 起始价」说明这 60 天整体是【跌】的，
#    「模拟股价：从 100 开始，每天涨跌 2%」里的 100 只是基准价，不是起始价。

plt.figure(figsize=(10, 5))
plt.plot(close, label="收盘价", color="#2d7fd3")
plt.plot(range(4, days), ma5, label="5日均线", color="orange", linestyle="--")
plt.title("模拟股票走势")
plt.xlabel("交易日")
plt.ylabel("价格")
plt.legend()
plt.grid(True)
plt.show()      # 弹出窗口显示一条波动【下降】的折线（100 → 87.33）+ 一条平滑的橙色均线
```

**要点**：`np.cumprod(1 + returns)` 一行算出**累计收益**；`np.convolve` 用卷积实现移动平均，避免 for 循环；`daily_ret.std()` 就是**波动率**，是金融里衡量风险的标准指标。

### 7.5.3 使用 Pandas 分析股票交易数据

**思路**：把数据装进 DataFrame → 新增计算列 → 筛选/排序/分组。

```python
import pandas as pd

df = pd.DataFrame({
    "日期": pd.date_range("2025-01-01", periods=6, freq="D"),
    "开盘": [100.0, 102.5, 101.0, 103.5, 105.0, 104.0],
    "收盘": [102.5, 101.0, 103.5, 105.0, 104.0, 106.5],
    "成交量": [1200, 1500, 900, 1800, 1100, 2000],
})

df["涨跌"] = df["收盘"] - df["开盘"]
df["涨跌幅"] = (df["涨跌"] / df["开盘"] * 100).round(2)
df["成交额"] = (df["收盘"] * df["成交量"]).round(2)

print(df[["日期", "收盘", "涨跌幅", "成交额"]].to_string(index=False))
#        日期    收盘  涨跌幅      成交额
# 2025-01-01 102.5  2.50  123000.0
# 2025-01-02 101.0 -1.46  151500.0
# 2025-01-03 103.5  2.48   93150.0
# 2025-01-04 105.0  1.45  189000.0
# 2025-01-05 104.0 -0.95  114400.0
# 2025-01-06 106.5  2.40  213000.0

print("平均收盘价：", round(df["收盘"].mean(), 2))          # 平均收盘价： 103.75
print("最高收盘价：", df["收盘"].max())                     # 最高收盘价： 106.5
print("最大成交额：", df["成交额"].max())                   # 最大成交额： 213000.0
print("上涨天数：", (df["涨跌"] > 0).sum())                 # 上涨天数： 4
print(df.loc[df["成交额"].idxmax(), "日期"])                # 2025-01-06 00:00:00
print(df.loc[df["成交额"].idxmax(), "日期"].strftime("%Y-%m-%d"))   # 2025-01-06
print(df[df["涨跌幅"] > 2]["日期"].dt.strftime("%m-%d").tolist())
# ['01-01', '01-03', '01-06']
```

> **⚠️ `df["日期"]` 是 `datetime64` 列，取出来的单个值是 `Timestamp` 对象，直接 `print` 会带上 `00:00:00`**（实测输出 `2025-01-06 00:00:00`），**不是** `2025-01-06`。想去掉时间部分就用 `.strftime("%Y-%m-%d")`（实测 `2025-01-06`），或者 `.dt.date`。整列要格式化就用 `df["日期"].dt.strftime(...)` —— `datetime64` 列必须走 `.dt` 访问器，直接 `df["日期"].strftime(...)` 会报 `AttributeError`。

**要点**：**Pandas 里所有计算都是"按列"的**，不需要循环；`(df["涨跌"] > 0).sum()` 统计满足条件的行数（`True` 当 1 相加）；`idxmax()` 返回最大值的**索引**，配合 `df.loc[]` 就能拿到那一行的任意列。

### 7.5.4 使用图像处理库处理和显示图像

**思路**：用 Pillow（PIL）打开图片 → 查看信息 → 转灰度 → 缩放 → 保存。

```python
from PIL import Image, ImageDraw

# ① 创建一张图片并画图
im = Image.new("RGB", (60, 40), (255, 255, 255))    # 白底
d = ImageDraw.Draw(im)
d.rectangle([10, 10, 30, 30], fill=(255, 0, 0))     # 画一个红色方块

print(im.size, im.mode)                     # (60, 40) RGB
print(im.getpixel((15, 15)))                # (255, 0, 0)    方块内是红色
print(im.getpixel((0, 0)))                  # (255, 255, 255) 角落是白色

# ② 转灰度
gray = im.convert("L")
print(gray.mode, gray.getpixel((15, 15)), gray.getpixel((0, 0)))
# L 76 255        ← 红色按亮度公式 0.299R+0.587G+0.114B 转成灰度 76

# ③ 缩放
small = im.resize((30, 20))
print(small.size)                           # (30, 20)

# ④ 保存与读取
im.save("_t.png")
print(im.format)                            # None   ← 内存中创建的图片没有 format
with Image.open("_t.png") as im2:           # with 自动关闭文件句柄
    print(im2.size, im2.format)             # (60, 40) PNG
```

**要点与坑**：

| 坑 | 说明 | 正确做法 |
|---|---|---|
| `im.format` 是 `None` | 只有**从文件读入**的图片才有 `format` | 需要格式信息就用 `Image.open()` 读 |
| 删不掉刚读的图片 | `Image.open()` **懒加载**，文件句柄没关 | 用 `with Image.open(...) as im:` 或手动 `.close()` |
| 改完像素没保存 | PIL 的修改在内存里 | 改完必须 `im.save(path)` |
| 缩放后变形 | `resize` 不保持比例 | 先算比例或用 `Image.thumbnail()` |

> **PIL 的常用能力**：`crop()` 裁剪、`rotate()` 旋转、`transpose()` 翻转、`convert("L")` 灰度、`filter()` 滤镜、`ImageFont` 加水印文字。**做课设的"图片转字符画"就是"转灰度 → 按灰度映射到字符集 → 逐行拼接字符串"三步。**

**例 7.4**（题型：编程题——自定义模块与包）

写一个模块 `stats.py`，提供 `mean`、`median`、`std` 三个函数，并用 `__main__` 保护自测代码。

```python
# stats.py
"""简易统计模块"""

def mean(nums):
    """平均值"""
    return sum(nums) / len(nums)

def median(nums):
    """中位数"""
    s = sorted(nums)
    n = len(s)
    mid = n // 2
    return s[mid] if n % 2 else (s[mid - 1] + s[mid]) / 2

def std(nums):
    """总体标准差"""
    m = mean(nums)
    return (sum((x - m) ** 2 for x in nums) / len(nums)) ** 0.5

def main():
    data = [1, 2, 3, 4, 5]
    print(mean(data), median(data), round(std(data), 4))

if __name__ == "__main__":
    main()
```

```python
# 在另一个文件中使用
import stats

data = [85, 92, 78, 90, 66]
print(stats.mean(data))                 # 82.2
print(stats.median(data))               # 85
print(round(stats.std(data), 4))        # 9.4319
```

**解**：`median` 要先排序，**偶数个元素取中间两个的平均**；`std` 用总体公式（除以 n），样本标准差要除以 n−1。`if __name__ == "__main__":` 让模块既能直接运行自测、又能被导入使用。

**答案**：`82.2`、`85`、`9.4319`。**验算 `std`**：均值 `82.2`，各数偏差 `2.8 / 9.8 / −4.2 / 7.8 / −16.2`，平方和 `444.8`，除以 `n=5` 得 `88.96`，开方 = **9.4319**（这是**总体标准差**；若用 `statistics.stdev` 的样本公式除以 `n−1=4`，得到的是 `10.5451`，两者别混）。

```python
plt.rcParams["font.sans-serif"] = ["SimHei"]
plt.rcParams["axes.unicode_minus"] = False

quarters = ["第一季度", "第二季度", "第三季度", "第四季度"]
sales = [120, 185, 150, 210]

plt.figure(figsize=(8, 5))
bars = plt.bar(quarters, sales, color="#4da6ff")
plt.title("2025 年各季度销售额")
plt.xlabel("季度")
plt.ylabel("销售额（万元）")
plt.ylim(0, 240)

for b, v in zip(bars, sales):               # 柱顶标数值
    plt.text(b.get_x() + b.get_width() / 2, v + 3, str(v), ha="center")

plt.savefig("sales.png", dpi=300, bbox_inches="tight")
plt.show()      # 弹出窗口显示 4 根蓝色柱子，柱顶标有 120/185/150/210
```

**解**：`plt.rcParams` 两行必须在**绘图之前**设置；`b.get_x() + b.get_width()/2` 算柱子中心的横坐标，`ha="center"` 让文字水平居中；`savefig` 要在 `show` **之前**调用。

**答案**：生成 `sales.png`，并弹出图形窗口。

## 易错点提醒

1. **把自己的文件命名成 `random.py`、`json.py` 等标准库名。**
   - 错在哪：当前目录优先级最高，标准库同名模块被顶掉，`import random` 后没有 `randint`。
   - 正确做法：自建模块加前缀（`my_random.py`）或起独特名字；出问题先 `print(random.__file__)` 看加载的是谁。
2. **在项目里写 `from xxx import *`。**
   - 错在哪：可能覆盖已有变量/函数，且看不出名字来源，排查极难。
   - 正确做法：用 `import xxx` 或 `from xxx import 具体名字`。
3. **忘了写 `if __name__ == "__main__":`。**
   - 错在哪：别人 `import` 你的模块时，测试代码被自动执行，产生意外输出甚至死循环。
   - 正确做法：所有「只有直接运行才该执行」的代码都放进这个判断里。
4. **用字符串拼接路径。**
   - 错在哪：`"D:\a" + "\" + "b.txt"` 在 Windows 能跑，换平台就错；`\t`、`\n` 还会被当成转义字符。
   - 正确做法：`os.path.join(a, b)` 或 `pathlib.Path(a) / b`。
5. **`os.mkdir` 建多级目录。**
   - 错在哪：父目录不存在时 `FileNotFoundError`；目录已存在时 `FileExistsError`。
   - 正确做法：`os.makedirs(p, exist_ok=True)`。
6. **以为 `sys.argv` 里是数字。**
   - 错在哪：全是**字符串**，直接参与算术会 `TypeError`；没传参时访问 `argv[1]` 会 `IndexError`。
   - 正确做法：先 `len(sys.argv) > 1` 判断，再 `int(sys.argv[1])` 转换。
7. **混淆 NumPy 的 `axis=0` 与 `axis=1`。**
   - 错在哪：`a.sum(axis=0)` 以为在按行求和，结果拿到的是按列的和。
   - 正确做法：记住 **`axis=i` 表示"消掉第 i 个维度"**；形状 (2,3) 的数组，`axis=0` 得 3 个值，`axis=1` 得 2 个值。
8. **对 Pandas 的 Series 直接用 `if` 判断。**
   - 错在哪：`ValueError: The truth value of a Series is ambiguous`。
   - 正确做法：用 `.any()` / `.all()` / `.empty`，或 `len(series) > 0`。
9. **Matplotlib 中文显示成方框。**
   - 错在哪：默认字体不含中文；只设字体时**负号**仍是方框。
   - 正确做法：`plt.rcParams["font.sans-serif"] = ["SimHei"]` **加上** `plt.rcParams["axes.unicode_minus"] = False`，且写在绘图前。
10. **`savefig()` 写在 `show()` 之后。**
    - 错在哪：`show()` 已清空当前图形，保存出来是一张白图。
    - 正确做法：先 `savefig()` 再 `show()`。

## 本章小结

- **模块 = `.py` 文件，包 = 目录 + `__init__.py`，库 = 模块/包的集合**；来源分内置、标准库、第三方、自定义四类。
- `import` 五种形式中，**`import xxx` 和 `import xxx as y` 最推荐**，`from xxx import *` 禁止在项目里用。
- 模块查找顺序：**内置 → 当前脚本目录 → `PYTHONPATH` → 标准库 → `site-packages`**；因此自建模块**不能与标准库重名**。
- **`if __name__ == "__main__":`** 让模块「既能当脚本又能当库」，是工程化的第一行代码。
- **turtle** 靠 `forward/left/goto` 爬行绘图，`begin_fill`/`end_fill` 填充，末尾必须 `done()`。
- **random** 是伪随机，`seed()` 可复现；`randint` 闭区间、`randrange` 左闭右开、`sample` 不重复、`choices` 可重复。
- **time** 管时间戳与计时（`perf_counter`），**datetime** 管日期运算（`timedelta`）与格式化（`strftime`/`strptime`）。
- **os** 管路径与目录（**一律 `os.path.join`**，多级目录用 `makedirs(exist_ok=True)`），**sys** 管解释器（`argv` 全是字符串、`path` 是搜索路径）。
- **NumPy** 的核心是 ndarray：**同类型、连续内存、向量化、广播**；`axis=0` 消掉行维度、`axis=1` 消掉列维度；**能用数组运算就别写 for**。
- **Pandas** 的 Series 是一维带标签数组、DataFrame 是二维表；按列运算、布尔索引筛选、`groupby` 分组、`sort_values` 排序。
- **Matplotlib** 画折线/散点/柱状/饼图；中文必须设 `font.sans-serif` **和** `axes.unicode_minus`；`savefig` 在 `show` 之前。
- **Jieba** 中文分词（`lcut` 精确模式、`add_word` 加自定义词），**Pyinstaller** 打包（`-F` 单文件、`-w` 无控制台、`-i` 图标）。
- **Pillow** 处理图像：`new`/`open`/`convert`/`resize`/`save`，注意 `Image.open` 要 `with` 关闭句柄。

> **一句话记住本章**：模块是文件包是目录，`import` 从当前目录开始找，`__main__` 保护测试代码；NumPy 向量化、Pandas 按列算、Matplotlib 中文要设字体、打包用 `pyinstaller -F -w`。

**参考答案**

1. 模块是单个 `.py` 文件；包是包含 `__init__.py` 的目录（可含多个模块）；库是完成某类任务的一组模块/包的集合。包必须包含 `__init__.py`（Python 3.3+ 技术上可省，但约定必须保留）。
2. ① `import math`；② `import numpy as np`；③ `from math import sqrt`；④ `from math import sqrt as sq`；⑤ `from math import *`。**第 ⑤ 种应当避免**，它会污染命名空间、覆盖同名变量且看不出名字来源。
3. 顺序：内置模块 → 当前脚本所在目录 → `PYTHONPATH` → 标准库目录 → `site-packages`。因为**当前目录优先级高于标准库**，命名成 `random.py` 会让你的文件顶掉标准库的 `random`，`import random` 后拿不到 `randint`。
4. 作用是让文件**既能直接运行（执行自测代码）、又能被导入（不执行自测代码）**。直接运行时 `__name__` 是 `"__main__"`；被导入时是**模块名**（如 `"mymod"`）。
5. `randint(1, 6)` 是**闭区间** [1, 6]，可能取到 6；`randrange(1, 6)` 是**左闭右开** [1, 6)，最大取到 5。
6. 用 `perf_counter()`。它是**单调递增的高精度计时器**，不受系统时间调整（NTP 校时、用户改时间）影响；`time()` 返回的是墙上时钟，可能被回拨导致出现负的耗时。
7. `mkdir` 只能创建**一级**目录，父目录不存在会报 `FileNotFoundError`；`makedirs` 会**递归创建**所有中间目录。`exist_ok=True` 让目录已存在时**不抛 `FileExistsError`**，使脚本可以重复运行。
8. `np.arange(0, 10, 2)` → `[0 2 4 6 8]`（按步长 2 取，不含终点 10）；`np.linspace(0, 10, 5)` → `[0. 2.5 5. 7.5 10.]`（等分 5 个点，**包含终点**）。
9. `axis=0` 消掉第 0 维（行）→ 返回 **4** 个值（每列的和）；`axis=1` 消掉第 1 维（列）→ 返回 **3** 个值（每行的和）。
10. 需要 `plt.rcParams["font.sans-serif"] = ["SimHei"]` 和 `plt.rcParams["axes.unicode_minus"] = False`。因为**负号用的是 Unicode 减号（U+2212）而不是 ASCII 连字符**，它不属于 `font.sans-serif` 管辖范围，必须单独关掉「用 Unicode 负号」这个行为，否则负号仍是方框。
11. 有影响。**必须先 `savefig()` 再 `show()`**。`show()` 会显示并清空当前图形，之后保存只能得到一张空白图。
