## 怎么用这份表

```

   ② 写代码时不确定标志位会不会被改 → 看「标志位」列
   ③ 考试前突击 → 只看每类开头的「高频」标记和 A.7 的 4 张必考表
   ④ 调试时忘了 Debug 命令 → 查 A.10
```

**「标志位影响」列的读法（重要）：**

表中的「标志位影响」列用文字直接写明该指令改了哪些标志位、没改哪些，**大部分行不需要背记号**。个别表（A.1 数据传送类、A.4 串操作类、A.6 处理器控制类）为了紧凑，沿用了下面这套极简记号：

| 记号 | 含义 |
|---|---|
| **`*`** | 该指令**会影响**这个标志位（结果按该指令的语义设置，需要时查正文） |
| **`-`** | 该指令**不影响**这个标志位（保持原值） |
| **`?`** | 结果**未定义**（不要依赖它的值） |

> **★ 三个记号的区别是本附录最容易看漏的地方**：**`*` = 会变**（但要自己判断变成什么）、**`-` = 不变**（值保持原样）、**`?` = 变了但没定义**（Intel 不保证是什么，你也不能依赖）。**比如 `popf` 的标志位列写「全部 `*`」意思是「按栈里弹出的值全部重设」；而 `daa` 的 `OF` 列写「未定义」意思是「这一位执行后是垃圾值」。**

**遇到不确定的标志位，记住三条通用规律：**

```
   ① 逻辑运算（and/or/xor/test）一定把 CF 和 OF 清零
   ② 移位指令的 CF 一定等于【最后移出的那一位】
   ③ not 和所有数据传送类指令【完全不影响】标志位
```

**九个标志位的缩写（8086 的 FLAGS 共 9 个有效位）：**

```
   CF  进位标志（Carry）      —— 无符号数进位/借位
   PF  奇偶标志（Parity）     —— 结果低 8 位中 1 的个数为偶则 1
   AF  辅助进位（Auxiliary）  —— 低 4 位向高 4 位进位（BCD 用）
   ZF  零标志（Zero）         —— 结果为 0 则 1
   SF  符号标志（Sign）       —— 结果最高位（仅对有符号有意义）
   TF  陷阱标志（Trap）       —— 单步调试
   IF  中断标志（Interrupt）  —— 可屏蔽中断总开关
   DF  方向标志（Direction）  —— 串操作方向
   OF  溢出标志（Overflow）   —— 有符号数溢出
```

## A.1 数据传送类指令

**这一类指令的共同特点：只搬数据，不改数据内容。除 `popf`/`sahf` 外都不影响标志位。**

| 指令 | 格式 | 功能 | 标志位 | 例子 |
|---|---|---|---|---|
| **`mov`** | `mov 目的, 源` | 把源操作数送入目的（**源不变**） | `-` | `mov ax, 1234h` |
| **`push`** | `push 源` | `(SP)=(SP)−2`，再把源（**字**）写入 `SS:SP` | `-` | `push ax` |
| **`pop`** | `pop 目的` | 先从 `SS:SP` 读出**字**到目的，再 `(SP)=(SP)+2` | `-` | `pop bx` |
| **`pushf`** | `pushf` | 把标志寄存器 `FLAGS` 压栈 | `-` | `pushf` |
| **`popf`** | `popf` | 从栈弹出**字**送入 `FLAGS` | **全部 `*`** | `popf` |
| **`xchg`** | `xchg 操作数1, 操作数2` | 交换两个操作数的内容 | `-` | `xchg ax, bx` |
| **`xlat`** | `xlat`（无操作数） | `AL = DS:[BX + AL]`（查字节表） | `-` | `xlat` |
| **`lea`** | `lea 目的, 源` | 把源操作数的**偏移地址**送目的（等价 `offset`） | `-` | `lea bx, [si+2]` |
| **`lds`** | `lds 目的, 源` | 取远指针到 `DS` 和目的寄存器 | `-` | `lds si, fp`（`fp dd ?`） |
| **`les`** | `les 目的, 源` | 取远指针到 `ES` 和目的寄存器 | `-` | `les di, fp` |
| **`lahf`** | `lahf` | 把 `FLAGS` 低 8 位送入 `AH` | `-` | `lahf` |
| **`sahf`** | `sahf` | 把 `AH` 送入 `FLAGS` 低 8 位 | `CF/PF/AF/ZF/SF *` | `sahf` |
| **`in`** | `in AL/AX, 端口` | 从端口读**字节/字**到 `AL`/`AX` | `-` | `in al, 60h` |
| **`out`** | `out 端口, AL/AX` | 把 `AL`/`AX` 写到端口 | `-` | `out 70h, al` |

**★★ `push` / `pop` 的五条硬规定（必考）★★**

```
   ① push 的操作数必须是【字】（16 位），不能是 8 位、不能是立即数
        push al      ✗ 非法（8 位）
        push 1       ✗ 非法（立即数）
        push word ptr ds:[0]  ✓  （★ 必须加 ds:，写 push [0] 报 A2001）
        push word ptr fp      ✓  （用标号更好）
        push cs      ✓   （push 段寄存器合法）
        pushf        ✓
   
   ② pop 的操作数不能是 CS
        pop cs       ✗ 非法（CS 只能通过 jmp/call/ret 改）
        pop ds       ✓
   
   ③ push sp 压入的 SP 值【随 CPU 型号不同】（★ 依据 Intel 文档，非本机实测）
        8086/8088     压入的是【减 2 之后】的新 SP 值
        80286 及以后   压入的是【减 2 之前】的旧 SP 值
        ★ 结论：这段代码不可移植，任何机器上都不要依赖 push sp 的结果
   
   ④ push 和 pop 的次数、顺序必须严格配平（逆序弹出）
        push ax / push bx  →  必须先 pop bx 再 pop ax
   
   ⑤ push/pop 只影响 SP，不影响任何标志位
```

## A.2 算术运算类指令

| 指令 | 格式 | 功能 | 标志位影响 | 例子 |
|---|---|---|---|---|
| **`add`** | `add 目的, 源` | `目的 = 目的 + 源` | 六个全影响：`CF` `OF` `ZF` `SF` `PF` `AF` | `add ax, bx` |
| **`adc`** | `adc 目的, 源` | `目的 = 目的 + 源 + CF` | 六个全影响（进位参与运算） | `adc ax, bx` |
| **`inc`** | `inc 目的` | `目的 = 目的 + 1` | `OF` `ZF` `SF` `PF` `AF`；**不影响 `CF`** | `inc bx` |
| **`sub`** | `sub 目的, 源` | `目的 = 目的 − 源` | 六个全影响 | `sub ax, bx` |
| **`sbb`** | `sbb 目的, 源` | `目的 = 目的 − 源 − CF` | 六个全影响（借位参与运算） | `sbb ax, bx` |
| **`dec`** | `dec 目的` | `目的 = 目的 − 1` | `OF` `ZF` `SF` `PF` `AF`；**不影响 `CF`** | `dec cx` |
| **`neg`** | `neg 目的` | `目的 = 0 − 目的`（求补） | 六个全影响（`CF` 仅当操作数非 0 时置 1） | `neg ax` |
| **`cmp`** | `cmp 目的, 源` | **做减法但不保存结果**，只设标志位 | 六个全影响（与 `sub` 完全相同） | `cmp al, bl` |
| **`mul`** | `mul 源`（无符号） | 8 位：`AX = AL × r/m8`<br>16 位：`DX:AX = AX × r/m16` | **只定义 `CF`、`OF`**（积的高半部非 0 则两者置 1）；`ZF` `SF` `PF` `AF` **未定义** | `mul bl` |
| **`imul`** | `imul 源`（有符号） | 同 `mul`，但按**有符号**处理 | **只定义 `CF`、`OF`**；其余**未定义** | `imul bl` |
| **`div`** | `div 源`（无符号） | 8 位：`AL = AX ÷ r/m8` 的商，`AH =` 余数<br>16 位：`AX = DX:AX ÷ r/m16` 的商，`DX =` 余数 | **全部未定义**（不要依赖除法后的标志位） | `div bl` |
| **`idiv`** | `idiv 源`（有符号） | 同 `div`，按**有符号**处理 | **全部未定义** | `idiv bl` |
| **`daa`** | `daa` | `AL` 的 BCD 加法调整 | `CF` `ZF` `SF` `PF` `AF`；**`OF` 未定义**（依据 Intel SDM，不是「不影响」） | `daa` |
| **`das`** | `das` | `AL` 的 BCD 减法调整 | `CF` `ZF` `SF` `PF` `AF`；**`OF` 未定义**（依据 Intel SDM） | `das` |
| **`aaa` / `aas`** | `aaa` / `aas` | ASCII 加法/减法调整 | `CF` `AF`；**`OF` `SF` `ZF` `PF` 全部未定义**（依据 Intel SDM） | `aaa` |

> **重点：`daa`/`das`/`aaa`/`aas` 之后的 `OF` 是「未定义」（`?`），不是「不影响」（`-`）。** 这两个记号在本表开头有严格定义：**`-` = 该指令根本不碰这一位，值保持原样**；**`?` = 该指令执行后这一位的值是未定义的，Intel 不保证是什么，你也不能依赖**。DAA/DAS 之后 `OF` 属于后者；AAA/AAS 之后连 `SF`/`ZF`/`PF` 也是未定义。**考试如果问「执行 `daa` 后 `OF` 是多少」，正确回答是「未定义、不可预测」，不是「保持原来的值」。**

**★★ `mul` / `div` 的位宽变化（最容易记混）★★**

```
                     8 位运算                        16 位运算
   ┌──────────────────────────────┐   ┌──────────────────────────────────┐
   mul  │  AL × r/m8  → AX          │   │  AX × r/m16 → DX:AX              │
        │  ★ 位宽【翻倍】            │   │  ★ 位宽【翻倍】                   │
   ─────┼──────────────────────────┘   └──────────────────────────────────┘
   div  │  AX ÷ r/m8  → AL(商) AH(余) │   │  DX:AX ÷ r/m16 → AX(商) DX(余)   │
        │  ★ 位宽【减半】            │   │  ★ 位宽【减半】                   │
   └────┴──────────────────────────┘   └──────────────────────────────────┘

   ★★ 三条铁律 ★★
   ① 16 位除法前【必须】mov dx, 0（除非被除数本就是 32 位），
      否则 DX 里的垃圾会让结果错得离谱。
   ② div 的商超出目的寄存器范围会触发【除法溢出】（0 号中断），
      例如 mov ax,1000h / mov bh,1 / div bh → 1000H 装不进 AL（上限 FFH）。
   ③ mul 只对 CF 和 OF 有定义（乘积高半部分非 0 则 CF=OF=1）；
      其余标志位未定义。div 影响【全部标志位但不定义】，不要依赖。
```

**`inc` / `dec` 为什么不影响 CF？**

```
   ★ 因为 CF 的职责是「多字节运算的进位/借位传递」，而 inc/dec 通常用在
     循环计数上（如 inc bx 遍历数组）。如果 inc 改了 CF，就会破坏外层
     多字节加法（adc）链。
   ★ 记忆：inc/dec 是「单字节/单字的加减 1」，不参与多字节进位链，
     所以只改 OF/SF/ZF/AF/PF，唯独不动 CF。
```

## A.3 逻辑运算与移位类指令

| 指令 | 格式 | 功能 | 标志位影响 | 例子 |
|---|---|---|---|---|
| **`and`** | `and 目的, 源` | 按位与（**清零某些位**） | `CF = 0`、`OF = 0`；`SF` `ZF` `PF` 受影响；`AF` 未定义 | `and al, 11011111b` |
| **`or`** | `or 目的, 源` | 按位或（**置位某些位**） | `CF = 0`、`OF = 0`；`SF` `ZF` `PF` 受影响；`AF` 未定义 | `or al, 00100000b` |
| **`xor`** | `xor 目的, 源` | 按位异或（**翻转某些位**） | `CF = 0`、`OF = 0`；`SF` `ZF` `PF` 受影响；`AF` 未定义 | `xor al, al`（清零） |
| **`not`** | `not 目的` | 按位取反（**不改标志位！**） | **六个全部不影响** | `not al` |
| **`test`** | `test 目的, 源` | **做与运算但不保存结果**，只设标志位 | 同 `and`：`CF = 0`、`OF = 0`；`SF` `ZF` `PF` 受影响 | `test al, 01h` |
| **`shl`** | `shl 目的, 1` 或 `shl 目的, cl` | **逻辑左移**：每移 1 位 = **×2**，低位补 0 | `CF` = 最后移出的那一位；`OF` 仅移 1 位时有意义；`SF` `ZF` `PF` 受影响；`AF` 未定义 | `shl al, 1` |
| **`shr`** | `shr 目的, 1` 或 `shr 目的, cl` | **逻辑右移**：每移 1 位 = **÷2**（无符号），高位补 0 | 同 `shl` | `shr ah, cl` |
| **`sal`** | `sal 目的, 1/cl` | 算术左移（**与 `shl` 完全相同**） | 同 `shl` | `sal al, 1` |
| **`sar`** | `sar 目的, 1/cl` | **算术右移**：高位补**符号位**（保持负数不变号） | 同 `shl` | `sar al, 1` |
| **`rol`** | `rol 目的, 1/cl` | 循环左移（移出位回到低位，**也进 CF**） | `CF` = 最后移出位；`OF` 仅移 1 位时有意义；**不影响 `SF` `ZF` `PF` `AF`** | `rol al, 1` |
| **`ror`** | `ror 目的, 1/cl` | 循环右移 | 同 `rol` | `ror al, 1` |
| **`rcl`** | `rcl 目的, 1/cl` | 带进位循环左移（**CF 参与循环**） | 同 `rol` | `rcl al, 1` |
| **`rcr`** | `rcr 目的, 1/cl` | 带进位循环右移 | 同 `rol` | `rcr al, 1` |

**★★ 移位指令的两个陷阱 ★★**

```
   ① 8086 只支持两种移位次数：
        shl al, 1        ✓（立即数只能是 1）
        shl al, cl       ✓（次数放 CL）
        shl al, 4        ✗ 非法！（8086 上）
      
      ★ 要移 4 位必须：mov cl, 4 / shl al, cl
   
   ② 移位后 CF = 【最后一次移出的那一位】
        mov al, 10000001b
        shl al, 1        ; AL=00000010b，CF=1（最高位那个 1 被移出）
      
      ★ OF 只在「移位次数 = 1」时有意义（表示符号位是否改变）；
        移位次数 > 1 时 OF 未定义。
```

**大小写转换的位掩码（第 7 章经典）：**

```
   'A' = 41H = 0100 0001b
   'a' = 61H = 0110 0001b
              ↑
          只差第 5 位（20H）
   
   ★ 大写 → 小写：or  al, 0010 0000b      （把第 5 位置 1）
   ★ 小写 → 大写：and al, 1101 1111b      （把第 5 位清 0）
   ★ 字母大小写互换：xor al, 0010 0000b
   
   ★ 数字字符转数字：and al, 0000 1111b   （'5'=35H → 05H）
   ★ 数字转数字字符：or  al, 0011 0000b   （05H → '5'=35H）
                     或 add al, 30h
```

## A.4 串操作类指令

**★★ 串操作的三条固定规则（必记）★★**

```
   ① 源操作数固定用 DS:SI（段可用段前缀改，如 es:）
   ② 目的操作数固定用 ES:DI（【不可】用段前缀改成别的段！）
   ③ 每执行一次，SI 和 DI 自动调整：
        DF = 0（cld）→ SI/DI 【加】上元素长度（正向）
        DF = 1（std）→ SI/DI 【减】上元素长度（反向）
      ★ 字节操作 ±1，字操作 ±2
```

| 指令 | 机器码 | 功能 | 标志位 | 例子 |
|---|---|---|---|---|
| **`movsb`** | `A4` | `ES:[DI] = DS:[SI]`，然后 `SI±1`、`DI±1` | `-` | `movsb` |
| **`movsw`** | `A5` | `ES:[DI] = DS:[SI]`，然后 `SI±2`、`DI±2` | `-` | `movsw` |
| **`cmpsb`** | `A6` | 比较 `DS:[SI]` 与 `ES:[DI]`（做减法不存结果），`SI±1`、`DI±1` | 全部 `*` | `cmpsb` |
| **`cmpsw`** | `A7` | 比较**字**，`SI±2`、`DI±2` | 全部 `*` | `cmpsw` |
| **`scasb`** | `AE` | 比较 `AL` 与 `ES:[DI]`，`DI±1` | 全部 `*` | `scasb` |
| **`scasw`** | `AF` | 比较 `AX` 与 `ES:[DI]`，`DI±2` | 全部 `*` | `scasw` |
| **`lodsb`** | `AC` | `AL = DS:[SI]`，`SI±1` | `-` | `lodsb` |
| **`lodsw`** | `AD` | `AX = DS:[SI]`，`SI±2` | `-` | `lodsw` |
| **`stosb`** | `AA` | `ES:[DI] = AL`，`DI±1` | `-` | `stosb` |
| **`stosw`** | `AB` | `ES:[DI] = AX`，`DI±2` | `-` | `stosw` |
| **`cld`** | `FC` | `DF = 0`（正向，地址递增） | `DF=0` | `cld` |
| **`std`** | `FD` | `DF = 1`（反向，地址递减） | `DF=1` | `std` |
| **`rep`** | `F3` | 前缀：`CX ≠ 0` 时重复，**每轮 CX 减 1** | `-` | `rep movsb` |
| **`repe`/`repz`** | `F3` | 前缀：`CX ≠ 0` **且 ZF = 1** 时重复 | `-` | `repe cmpsb` |
| **`repne`/`repnz`** | `F2` | 前缀：`CX ≠ 0` **且 ZF = 0** 时重复 | `-` | `repne scasb` |

**常用组合速查：**

| 想做这件事 | 标准写法 |
|---|---|
| **复制 CX 字节** | `cld` / `rep movsb` |
| **复制 CX 个字（2×CX 字节）** | `cld` / `rep movsw` |
| **把 AL 填入 CX 字节（内存初始化）** | `cld` / `rep stosb` |
| **找第一个等于 AL 的字节** | `cld` / `repne scasb`（找到时 `ZF=1`、`DI` 指向下一字节） |
| **比较两个字符串是否相同** | `cld` / `repe cmpsb`（全同则 `ZF=1` 且 `CX=0`） |
| **求字符串长度（以 0 结尾）** | `mov al,0` / `repne scasb`（`DI` 减 1 即长度） |

**★★ `rep movsb` 的两个陷阱 ★★**

```
   ① CX = 0 时【一次也不执行】（先判断后减，与 loop 的「先减后判」不同！）
   ② 【重叠区域必须反向复制】：
        若 目的地址 > 源地址 且两者有重叠 → 必须 std 反向复制
      
        例：把 0:200 起的 6 字节复制到 0:202（目的比源高）
            正向复制会把还没读的数据覆盖掉！
            → std / mov si,5 / mov di,7 / mov cx,6 / rep movsb
      
        原因：正向复制时 DI 追上了 SI，把还没搬走的源数据写坏了。
```

## A.5 控制转移类指令

### A.5.1 无条件转移 `jmp`

| 形式 | 格式 | 转移范围 | 机器码特征 | 例子 |
|---|---|---|---|---|
| **段内短转移** | `jmp short 标号` | IP 相对位移 **−128 ~ +127** | `EB 位移8` | `jmp short s` |
| **段内近转移** | `jmp near ptr 标号` | IP 相对位移 **−32768 ~ +32767** | `E9 位移16` | `jmp near ptr s` |
| **段间转移（直接）** | `jmp far ptr 标号` | 任意（改 **CS:IP**） | `EA 偏移16 段16` | `jmp far ptr s` |
| **段内间接（寄存器）** | `jmp 16位寄存器` | 任意（**IP = 寄存器值**） | `FF /4` | `jmp ax` |
| **段内间接（内存，字）** | `jmp word ptr 内存` | 任意（**IP = 字**） | `FF /4` | `jmp word ptr [bx]` |
| **段间间接（内存，双字）** | `jmp dword ptr 内存` | 任意（**低字→IP，高字→CS**） | `FF /5` | `jmp dword ptr [bx]` |

**★★ 位移的计算（段内转移的核心公式）★★**

```
   ★★★ 位移 = 标号处的偏移 − jmp 指令【后第一个字节】的偏移 ★★★
   
   例：
        偏移    机器码        汇编
        0       B8 00 00      mov ax, 0
        3       EB 03         jmp short s        ← jmp 占 2 字节，后一字节偏移 = 5
        5       05 01 00      add ax, 1
        8       ...       s:  （标号 s 在偏移 8 处）
   
   ★ 位移 = 8 − 5 = 3  →  机器码 EB 03   ✓
   
   反向跳：
        位移 = FDH = −3（8 位补码）
        ★ 即从当前位置向后跳 3 字节
   
   ★ 「后第一个字节的偏移」= jmp 指令起始偏移 + jmp 指令长度
     jmp short 占 2 字节；jmp near ptr 占 3 字节
```

### A.5.2 条件转移指令（★★★ 全表 ★★★）

**所有条件转移都是「段内短转移」（8 位位移，范围 −128~+127），操作码是 `70H ~ 7FH`（共 16 条），格式统一为 `jXX 标号`。**

> **★ 注意：条件转移的机器码是 `70H~7FH`，不是 `EB`。** `EB` 是 **`jmp short`（无条件段内短转移）** 的操作码——两者都是「2 字节、8 位位移」，格式一样，**但操作码完全不同**：`jmp short` 恒为 `EB`，条件转移按条件取 `70H`~`7FH` 中的一个（如 `je` = `74`、`jne` = `75`、`ja` = `77`、`jb` = `72`）。**考试给机器码让你反推指令时，这一步最容易看错。**

**（一）单个标志位判断（无符号/有符号通用）**

| 指令 | 含义 | 检测的标志 |
|---|---|---|
| **`jz` / `je`** | 结果为零 / 相等 | **`ZF = 1`** |
| **`jnz` / `jne`** | 结果非零 / 不相等 | **`ZF = 0`** |
| **`jc` / `jb` / `jnae`** | 有进位 / 低于 / 不高于等于（**无符号**） | **`CF = 1`** |
| **`jnc` / `jnb` / `jae`** | 无进位 / 不低于（**无符号**） | **`CF = 0`** |
| **`js`** | 结果为负（**有符号**） | **`SF = 1`** |
| **`jns`** | 结果非负（**有符号**） | **`SF = 0`** |
| **`jo`** | 溢出（**有符号**） | **`OF = 1`** |
| **`jno`** | 未溢出（**有符号**） | **`OF = 0`** |
| **`jp` / `jpe`** | 低 8 位中 1 的个数为偶 | **`PF = 1`** |
| **`jnp` / `jpo`** | 低 8 位中 1 的个数为奇 | **`PF = 0`** |

**（二）★★★ 无符号 vs 有符号 比较转移对照表（必考）★★★**

| 比较关系 | **无符号数（A/B）** | **有符号数（G/L）** | 检测的标志 |
|---|---|---|---|
| **大于** | **`ja`**（above） | **`jg`**（greater） | `CF=0 且 ZF=0` / `SF=OF 且 ZF=0` |
| **大于等于** | **`jae`** / `jnb` | **`jge`** / `jnl` | `CF=0` / `SF=OF` |
| **小于** | **`jb`**（below） | **`jl`**（less） | `CF=1` / `SF≠OF` |
| **小于等于** | **`jbe`** / `jna` | **`jle`** / `jng` | `CF=1 或 ZF=1` / `SF≠OF 或 ZF=1` |
| **等于** | `je` | `je` | `ZF=1` |
| **不等于** | `jne` | `jne` | `ZF=0` |

```
   ★★★ 记忆口诀 ★★★
   
      A / B 开头（Above / Below）→ 【无符号】→ 看 CF
      G / L 开头（Greater / Less）→ 【有符号】→ 看 SF 和 OF
      E / N 开头（equal / not）  → 两者通用 → 看 ZF
   
   ★ 为什么会有两套？
     因为同一串二进制，按无符号和有符号读出来的大小可能相反：
         AL = 0FFH、BL = 01H
         无符号看：FFH = 255 > 1 = 01H        → ja 成立
         有符号看：FFH = −1  < 1 = 01H        → jl 成立
     
     ★ 所以「谁大谁小」取决于你怎么解释这些位，
       指令本身不区分——必须由【程序员】选对指令。
```

**经典反例（考试最爱考）：**

```asm
    mov al, 0FFh            ; AL = 1111 1111b
    mov bl, 01h             ; BL = 0000 0001b
    cmp al, bl              ; 做 FFH − 01H = FEH，只设标志位

    ; 标志位：CF = 0（无符号没借位）、ZF = 0、SF = 1（FEH 最高位是 1）、OF = 0
    
    ja  L1      ; ★ 转移！CF=0 且 ZF=0 → 无符号 255 > 1 成立
    jg  L2      ; ★ 不转移！SF=1、OF=0，SF≠OF → 有符号 −1 > 1 不成立
    jb  L3      ; ★ 不转移！CF=0
    jl  L4      ; ★ 转移！SF≠OF → 有符号 −1 < 1 成立
```

### A.5.3 循环指令与子程序调用

| 指令 | 格式 | 功能 | 转移范围 | 机器码 | 例子 |
|---|---|---|---|---|---|
| **`loop`** | `loop 标号` | **`(CX)=(CX)−1`，若 `CX ≠ 0` 则转移**（★ 先减后判） | 短（−128~+127） | `E2` | `loop s` |
| **`loope`/`loopz`** | `loope 标号` | `(CX)=(CX)−1`，若 `CX≠0` **且 `ZF=1`** 则转移 | 短 | `E1` | `loope s` |
| **`loopne`/`loopnz`** | `loopne 标号` | `(CX)=(CX)−1`，若 `CX≠0` **且 `ZF=0`** 则转移 | 短 | `E0` | `loopne s` |
| **`jcxz`** | `jcxz 标号` | **若 `CX = 0` 则转移**（★ 不改变 CX） | 短 | `E3` | `jcxz s` |
| **`call`** | `call 标号` | 段内近调用：**压 IP**，转标号 | 近 | `E8 位移16` | `call sub1` |
| **`call`** | `call far ptr 标号` | 段间调用：**压 CS 再压 IP** | 任意 | `9A 偏移16 段16` | `call far ptr sub2` |
| **`call`** | `call 16位寄存器` | **压 IP**，`IP = 寄存器值` | 任意 | `FF /2` | `call ax` |
| **`call`** | `call word ptr 内存` | **压 IP**，`IP = 字` | 任意 | `FF /2` | `call word ptr [bx]` |
| **`call`** | `call dword ptr 内存` | **压 CS 再压 IP**，新入口从双字内存取（低字 = 偏移 → IP，高字 = 段 → CS） | 任意 | `FF /3` | `call dword ptr [bx]` |
| **`ret`** | `ret` | **`pop IP`**（段内返回） | — | `C3` | `ret` |
| **`ret`** | `ret n` | **`pop IP` 然后 `(SP)=(SP)+n`**（弹出参数） | — | `C2 n16` | `ret 8` |
| **`retf`** | `retf` | **`pop IP` 再 `pop CS`**（段间返回） | — | `CB` | `retf` |
| **`retf`** | `retf n` | `retf` 后再 `(SP)=(SP)+n` | — | `CA n16` | `retf 4` |
| **`iret`** | `iret` | **`pop IP`、`pop CS`、`popf`**（中断返回，弹 3 个字） | — | `CF` | `iret` |
| **`int`** | `int n` | 触发 `n` 号中断（见 A.8） | 任意 | `CD n8` | `int 21h` |
| **`into`** | `into` | **`OF = 1` 时**触发 4 号中断 | 任意 | `CE` | `into` |
| **`int 3`** | `int 3` | 触发 3 号中断（断点） | 任意 | `CC` | `int 3` |

**★★ `loop` / `jcxz` / `rep` 三者的「先减后判 vs 先判后减」★★**

```
   loop 标号：     CX = CX − 1  →  判断 CX ≠ 0  →  转移
                   ★【先减后判】→ CX = 0 时循环 65536 次（从 0000H 回绕到 FFFFH）
   
   jcxz 标号：     判断 CX = 0   →  转移
                   ★【只判断，不改 CX】→ 通常与 loop 配对实现「可能一次都不做」的循环
   
   rep movsb：     判断 CX ≠ 0   →  执行一次  →  CX = CX − 1  →  再判断
                   ★【先判后减】→ CX = 0 时一次都不执行
   
   ★ 结论：想「不管怎样至少做一次」用 loop + 先摆好 CX；
           想「可能一次都不做」用 jcxz 先跳过去，或用 rep 前缀。
```

**`call`/`ret` 与 `int`/`iret` 的配对关系（★★ 必记 ★★）**

| 转移指令 | 压栈内容 | 压栈字节数 | 配对返回指令 | 返回时弹出 |
|---|---|---|---|---|
| **`call 标号`**（段内） | IP | 2 | **`ret`** | IP |
| **`call far ptr`**（段间） | CS、IP | 4 | **`retf`** | IP、CS |
| **`int n`**（中断） | **FLAGS、CS、IP** | **6** | **`iret`** | IP、CS、**FLAGS** |

```
   ★★★ 口诀 ★★★
   
        call      →  ret    （压 1 个字、弹 1 个字）
        call far  →  retf   （压 2 个字、弹 2 个字）
        int       →  iret   （压 3 个字、弹 3 个字）
   
   ★ 用错了什么后果？
        int 后用 ret  ：弹了 IP 就返回，栈上还留着 CS 和 FLAGS（栈失衡）
        int 后用 retf ：弹了 IP、CS 就返回，栈上留下 FLAGS
        call 后用 iret：多 pop 一个 FLAGS，把栈上别的数据吃掉了
```

## A.7 四张必考表格

### 表 1 ★★★ `mov` 操作数合法组合表 ★★★

**四种操作数类型：`reg`（通用寄存器）、`sreg`（段寄存器）、`mem`（内存）、`idata`（立即数）**

| 目的 ↓ ＼ 源 → | **`reg`** | **`sreg`** | **`mem`** | **`idata`** |
|---|---|---|---|---|
| **`reg`** | ✓ `mov ax,bx` | ✓ `mov ax,ds` | ✓ `mov ax,ds:[0]` | ✓ `mov ax,0` |
| **`sreg`** | ✓ `mov ds,ax` | **✗ 非法** | ✓ `mov ds,ds:[0]` | **✗ 非法** |
| **`mem`** | ✓ `mov ds:[0],ax` | ✓ `mov ds:[0],ds` | **✗ 非法** | ✓ `mov word ptr ds:[0],1` |
| **`idata`** | **✗ 非法** | **✗ 非法** | **✗ 非法** | **✗ 非法** |

> **★ 表里的 `ds:[0]` 全部是「MASM 源程序写法」**。之所以不写裸的 `[0]`，是因为 **MASM 把 `[数字]` 当常量**：作源操作数时静默变成 `mov ax,0`（机器码 `B8 0000`），作目的操作数时直接报 `error A2001: immediate operand not allowed`。**考试答题可以写 `[0]`（教材和 DEBUG 都这么写），但真正上机必须加段前缀或用标号。**

**四条非法规则（口诀）：**

```
   ① 【两个内存】之间不能直接传送      mov ds:[0], ds:[2]  ✗
   ② 【两个段寄存器】之间不能直接传送  mov ds, es          ✗
   ③ 【立即数】不能直接送【段寄存器】  mov ds, 1           ✗  （必须 mov ax,1 / mov ds,ax）
   ④ 【立即数】不能作【目的】          mov 1, ax           ✗  （立即数不是容器）
```

**补充规则（也常考）：**

| 写法 | 合法性 | 说明 |
|---|---|---|
| `mov cs, ax` | **✗** | **CS 不能作 `mov` 的目的**（只能通过 `jmp`/`call`/`ret`/`int` 改） |
| `mov ax, cs` | ✓ | CS 作源是合法的 |
| `mov ss, ax` | ✓ | SS 可作目的 |
| `pop cs` | **✗** | 不能 pop CS |
| `push cs` | ✓ | push 段寄存器合法 |
| `mov ds, ds:[0]` | ✓ | 内存 → 段寄存器合法（同样要加 `ds:`） |
| `xchg ax, ds` | **✗** | `xchg` 不能用段寄存器 |

**`[ ]` 内可用的寄存器与合法配对（★★ 必考 ★★）**

```
   ★ 可参与寻址的【只有 4 个】：BX、BP、SI、DI
        （AX、CX、DX、SP 都不能出现在 [ ] 中！）

        [bx+si]   [bx+di]   [bp+si]   [bp+di]

        [bx+bp]      ✗ 两个都是「基址寄存器」

```

**段寄存器的默认对应（★★ 必考陷阱 ★★）**

| 寻址方式中出现的寄存器 | **默认段寄存器** | 可否用段前缀改 |
|---|---|---|
| 只有 `[idata]` | **DS** | ✓ |
| 含 `BX`、`SI`、`DI`（**不含 BP**） | **DS** | ✓ |
| **含 `BP`**（如 `[bp]`、`[bp+si]`、`[bp+di+idata]`） | **★ SS（栈段）** | ✓ |

| 取指令 | **CS:IP** | ✗ |
| `push`/`pop` | **SS:SP** | ✗ |

**★ 最容易考的陷阱：**

```asm
    ; 假设 SS = 2000H，DS = 1000H，BP = 0010H
    mov ax, [bp]            ; ★ 物理地址 = 2000H×16 + 0010H = 20010H（用 SS！）
    mov ax, [bx]            ; ★ 物理地址 = 1000H×16 + (BX) （用 DS）
    mov ax, [bp+si]         ; ★ 含 BP → 用 SS
    mov ax, [bx+si]         ; ★ 不含 BP → 用 DS
```

| | `SS` | ✗ | 栈段（配合 `SP`） |
| | `ES` | ✗ | 附加段（串操作目的段） |
| **指令指针** | `IP` | ✗ | 下一条指令的偏移（**不能直接 `mov`！**） |
| **标志寄存器** | `FLAGS`/`PSW` | ✗ | 9 个有效标志位 |

```
   ★★★ 三条最常考的「不能」★★★
   
   ① IP 不能用 mov 改 → 只能通过 jmp / call / ret / int / iret 改
   ② CS 不能用 mov 改 → 只能通过 jmp far / call far / retf / int / iret 改
   ③ SP/BP/SI/DI 不能拆成 8 位 → 只有 AX/BX/CX/DX 能拆
   
   ★★ 物理地址公式（贯穿全书）★★
        物理地址 = 段地址 × 16 + 偏移地址

```

### A.8.1 中断向量表

```
   ★ 位置：0000:0000 起，共 1024 字节 = 256 项 × 4 字节
   ★ 每项结构：低 2 字节 = 偏移 IP，高 2 字节 = 段地址 CS
   ★ n 号中断：IP 在 n×4，CS 在 n×4+2

**★★★ 中断过程 6 步（必背）★★★**

```

   ★ 栈上的 6 个字节（从低地址到高地址）：

**`t` 与 `p` 的关键区别（★★ 最常考 ★★）**

```
   ★ t（Trace）：执行【一条】指令，然后停下来显示寄存器
        —— 遇到 loop 会一条一条地走完 100 次循环（累死）
        —— 遇到 call/int 会【进入】子程序内部
   
   ★ p（Proceed）：执行【一条】指令，但把 loop / call / int / rep
        当作【一整步】执行完再停
        —— 遇到 loop 直接跑完整个循环（省事）
        —— 遇到 call 不进入子程序内部
   
   ★ 记忆：想看循环内部用 t，想跳过循环/子程序用 p。
```

**DEBUG 显示标志位的顺序（★★ 必记 ★★）**

```
   ★★★ 固定顺序：OF DF IF SF ZF AF PF CF ★★★
   
   例：NV UP EI PL NZ NA PO NC
   
   NV = OF=0（No oVerflow）      UP = DF=0（UP，正向）
   EI = IF=1（Enable Interrupt） PL = SF=0（PLus，正）
   NZ = ZF=0（Not Zero）         NA = AF=0（Not Auxiliary）
   PO = PF=0（Parity Odd，奇校验） NC = CF=0（No Carry）
```

> **★ 上面这一行 `PO` 最容易写错**：`PO` 是 **Parity Odd（奇校验，低 8 位中 1 的个数为奇数）→ `PF = 0`**；`PE` 才是 `PF = 1`。**下面那张表是权威，例子里如果和表冲突以表为准。**

| 标志位 | 值为 0 | 值为 1 |
|---|---|---|
| **OF** | `NV`（No oVerflow） | `OV`（Overflow） |
| **DF** | `UP`（递增） | `DN`（递减） |
| **IF** | `DI`（Disable） | `EI`（Enable） |
| **SF** | `PL`（Plus，正） | `NG`（Negative，负） |
| **ZF** | `NZ`（Not Zero） | `ZR`（Zero） |
| **AF** | `NA`（Not Auxiliary） | `AC`（Auxiliary Carry） |
| **PF** | `PO`（Parity Odd） | `PE`（Parity Even） |
| **CF** | `NC`（No Carry） | `CY`（Carry） |

```
   ★ 唯一可靠的记忆规律：以 N 开头的都是「标志位 = 0」
        NV(0)  NG(0)  NZ(0)  NA(0)  NC(0)   —— 五个全对
   
   ⚠ 不要用「以 N/D/U 开头就是 0」这条（网上常见，但会错 4 处）：
        DN(DF=1)  ← D 开头却是 1（DowN）
        NG(SF=1)  ← N 开头却是 1（NeGative，不是 Not）
        PL(SF=0)  ← P 开头却是 0（PLus）
        PO(PF=0)  ← P 开头却是 0（Parity Odd）
   
   ★ 稳妥办法：只背「值为 1」的这 8 个 ——
        OV  DN  EI  NG  ZR  AC  PE  CY
     其余 8 个（NV UP DI PL NZ NA PO NC）自然都是 0。
```

## A.11 常见编译与连接错误速查

| 错误信息 | 原因 | 解决 |
|---|---|---|
| `error A2008: syntax error : mov` | 语法错（**本机实测：报出的行号就是准确出错行**） | 直接看报出的那一行是否漏了操作数、逗号、拼写 |
| `error A2075: jump destination too far : by xx byte(s)` | **相对转移超出位移范围**（`jmp short` / `loop` / `jcxz` / 显式写了 `short` 的条件转移） | 用「反条件 + `jmp near ptr`」改写（见第 9 章）。**★ 本机实测：`je` 跨 200 字节且不带 `short` 时 MASM 6.11 会自动扩展、不报错；加 `OPTION NOLJMP` 才报 `by 73 byte(s)`（200 − 127 = 73）** |
| `error A2071: initializer magnitude too large for specified size` | 数据超过类型范围 | `db 300` ✗ → 改 `dw 300`（**本机实测确认此错误号与文字**） |
| `error A2048: nondigit in number` | **数字里出现非法数字** | 十六进制要以 `H` 结尾且以数字开头；**`123B` 会被当成二进制数**（`B` 是二进制后缀）而报此错（**本机实测 `mov ax, 1010b2` / `mov ax, 123B` 均报 A2048**） |
| `error A2006: undefined symbol : FFFH` | **十六进制漏了前导 0** | `FFFH` 被当符号名 → 写 `0FFFH`（**本机实测确认**） |
| `error A2088: END directive required at end of file` | **源程序末尾缺 `end`** | 补 `end` 或 `end start`（**本机实测确认**） |
| `error A2005: symbol redefinition : abc` | **同一个标号被定义了两次** | 改名（**本机实测确认**；`A2004: symbol type conflict` 是「符号类型冲突」，比重复定义少见） |
| `error A2044: invalid character in file` | **文件编码不是 ANSI/GBK**（保存成了 UTF-8） | 用记事本另存为 **ANSI** |
| `fatal error A1000: cannot open file` | 文件不存在或路径错 | 检查文件名 |
| `unresolved external symbol _foo` | **混合编程时命名修饰不匹配** | 汇编模块加 `.model flat, c`，或检查 `@n` 的参数字节数 |
| `LINK : fatal error L1101: invalid object module` | `.obj` 损坏或格式不对 | 重新汇编；32 位要用 `ml /c /coff` |
| `Divide overflow` | **`div` 的商超出目的寄存器** 或除数为 0 | 除前检查除数、`mov dx,0`；或改用 16 位除法 |

**汇编全流程（每次都用）：**

```
   ┌─────────────┐   ┌─────────────┐   ┌─────────────┐   ┌──────────┐
   │  编写源码    │──►│  masm 1.asm;│──►│ link 1.obj; │──►│  执行 1  │
   │  1.asm      │   │  → 1.obj    │   │  → 1.exe    │   │          │
   │ （记事本ANSI）│   │  （目标文件）│   │ （可执行文件）│   │          │
   └─────────────┘   └─────────────┘   └─────────────┘   └──────────┘
                                                          
   ★ 一步到位：ml 1.asm
   ★ 分号「;」表示「后面所有提问都用默认值」，可以省掉一串回车
   ★ 报错格式：1.asm(7) : error A2008: syntax error : mov
                                 ↑ 括号里是行号
```
