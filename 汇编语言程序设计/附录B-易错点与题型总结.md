## B.1 易错点大全（65 条）

### 一、寄存器与物理地址（第 2、3 章）

**★ 1. 以为「段地址 × 16 + 偏移地址」里的 ×16 是随便乘的。**
**错在哪**：记成「×10」或「左移 8 位」。
**正确做法**：**`物理地址 = 段地址 × 16 + 偏移地址`**。×16 等价于**左移 4 位**，等价于**十六进制后面补一个 0**。例：`DS=1000H`、偏移 `0010H` → 物理地址 = `10000H + 0010H = 10010H`。

**★ 2. 以为一个物理地址只能由一个「段:偏移」表示。**
**错在哪**：算出 `10010H` 就认为只能写成 `1000:0010`。
**正确做法**：**同一物理地址有无穷多种段:偏移表示**（只要段地址变化、偏移相应变化即可）。`10010H` 可以写成 `1000:0010`、`1001:0000`、`0FFF:0020`……**这也是第 5 章 `0:200` 与 `0020:0` 等价的原因。**

**★ 3. 以为 `mov cs, ax` 或 `mov ip, 0` 可以改 CS/IP。**
**错在哪**：写了非法指令还不知道。
**正确做法**：**CS 和 IP 都不能用 `mov` 修改**。CS 只能通过 `jmp far ptr`/`call far ptr`/`retf`/`int`/`iret` 改；IP 只能通过 `jmp`/`call`/`ret`/`int`/`iret` 改。

**★ 4. 把 `SP`/`BP`/`SI`/`DI` 当成能拆 8 位的寄存器。**
**错在哪**：写了 `mov sh, 1` 或 `mov sil, 2`。
**正确做法**：**只有 `AX`/`BX`/`CX`/`DX` 能拆成 H/L 两半**（`AH`/`AL`、`BH`/`BL`、`CH`/`CL`、`DH`/`DL`）。**`SP`/`BP`/`SI`/`DI` 是纯 16 位，不能拆。**

**5. 以为「段」是内存里真实存在的一块区域。**
**错在哪**：认为段与段不能重叠、段有边界。
**正确做法**：**段是「逻辑划分」，由程序员自己定义**，段之间可以重叠、可以任意起始。**一个段最大 64KB** 只是「偏移量是 16 位」的结果。

**★ 6. 记错 8086 的寄存器个数。**
**错在哪**：只记得 8 个通用寄存器。
**正确做法**：**8086 有 14 个 16 位寄存器**：通用 `AX/BX/CX/DX`（4）+ 指针与变址 `SP/BP/SI/DI`（4）+ 段 `CS/DS/SS/ES`（4）+ `IP`（1）+ `FLAGS`（1）。

### 二、内存访问与栈（第 3 章）

**★ 7. 以为 `mov ds, 1000h` 合法。**
**错在哪**：立即数直接送段寄存器。
**正确做法**：**立即数不能直接送段寄存器**，必须经通用寄存器中转：
```asm
    mov ax, 1000h
    mov ds, ax          ; ★ 必须两步
```

**★ 8. 把 `push`/`pop` 的顺序搞反，导致「交换失败」或「两个寄存器变成同一个值」。**
**错在哪**：想用栈交换 `AX` 和 `BX`，却把弹出顺序写反（或重复弹同一个寄存器）。
```asm
    ; ✗ 错误写法：重复弹出到同一个寄存器
    push ax
    push bx
    pop  ax             ; AX ← 原 BX
    pop  ax             ; AX ← 原 AX（把上一步的结果覆盖了！）
                        ; 结果：AX = 原 AX、BX 还是原 BX，等于什么也没干；
                        ; 若写成 pop ax / pop ax 之后再 pop bx，BX 根本没被恢复
```
**正确做法**：**「后进先出」——`push` 的顺序与 `pop` 的顺序必须严格相反。**
```asm
    ; ✓ 正确写法：push ax / push bx → pop bx / pop ax 才是「原样恢复」
    push ax
    push bx
    pop  bx             ; BX ← 原 BX（恢复）
    pop  ax             ; AX ← 原 AX（恢复）
```
**★ 而「交换」恰恰要用相反的顺序**——这一点最容易绕晕，请对照记：
```asm
    ; ✓ 用栈交换 AX 和 BX（这是标准写法！）
    push ax             ; 栈：…, AX
    push bx             ; 栈：…, AX, BX  ← BX 在栈顶
    pop  ax             ; AX ← BX（拿到的是后压进去的 BX 原值）
    pop  bx             ; BX ← AX（拿到的是先压进去的 AX 原值）
                        ; 结果：AX 和 BX 的值互换了 ✓
```
**★ 一句话总结**：
| 目标 | `pop` 顺序 | 原因 |
|---|---|---|
| **原样恢复**两个寄存器 | **与 `push` 相反**（`push ax`/`push bx` → `pop bx`/`pop ax`） | 后进先出，各回各家 |
| **交换**两个寄存器 | **与 `push` 相同**（`push ax`/`push bx` → `pop ax`/`pop bx`） | 后压的先弹出，正好互换 |
**另外**：交换两个寄存器最直接的写法是 **`xchg ax, bx`** 一条指令（见附录 A.1），不必绕栈。**`push`/`pop` 换值的写法只在「需要同时保护现场又要换值」时才用。**

**★ 9. 算出 `push` 后 SP 变大。**
**错在哪**：认为栈向高地址生长。
**正确做法**：**8086 的栈向低地址生长**。**`push ax`：先 `(SP)=(SP)−2`，再写入内存**；**`pop ax`：先从内存读出，再 `(SP)=(SP)+2`**。

**★ 10. `SP = 0000H` 时执行 `push` 会怎样？**
**错在哪**：以为会报错或停止。
**正确做法**：**8086 完全不检查栈越界，SP 会从 `0000H` 回绕成 `FFFEH`**，数据被写到 `SS:FFFEH`——**如果那不属于你的栈空间，就会覆盖别的数据（可能崩溃）**。

**11. 以为 `push` 可以压立即数或 8 位寄存器。**
**错在哪**：写 `push 1` 或 `push al`。
**正确做法**：**`push`/`pop` 只操作「字」（16 位）**。`push 1` ✗、`push al` ✗、`push ax` ✓、`push word ptr ds:[0]` ✓（★ 裸的 `push [0]` 报 `A2001`，必须加段前缀或用标号 `push word ptr fp`）。

**12. 以为 `pop cs` 合法。**
**正确做法**：**`pop cs` 非法**（CS 不能用 pop 改）。`pop ds`/`pop es`/`pop ss` 都合法。

### 三、源程序格式与流程（第 4 章）

**★ 13. 源程序末尾漏了 `end`。**
**错在哪**：`error A2088: END directive required at end of file`。
**正确做法**：**每个源程序末尾必须有 `end`**；有多个段且要指定入口时写 **`end start`**（`start` 是入口标号）。

**★ 14. 把 `assume` 当成「真的设置了段寄存器」。**
**错在哪**：写了 `assume ds:data` 就不再 `mov ds, ax`，运行时取到垃圾数据。
**正确做法**：**`assume` 只是伪指令，只在汇编期告诉汇编器「哪个标号在哪个段」，不产生机器码、不设置任何寄存器**。**必须手工 `mov ax, data` / `mov ds, ax`。**

**★ 15. 忘了程序返回，程序「跑飞」。**
**错在哪**：代码执行完没有返回 DOS，CPU 继续往下执行垃圾指令。
**正确做法**：**每个程序末尾必须有**：
```asm
    mov ax, 4c00h
    int 21h             ; ★ AH=4CH 是功能号（返回 DOS），AL=00H 是返回码
```

**★ 16. 源文件保存成 UTF-8，汇编报错。**
**错在哪**：`error A2044: invalid character in file`。
**正确做法**：**汇编源文件必须保存为 ANSI（GBK）编码**，不能用 UTF-8。

**★ 17. 报错行号和实际错误行对不上。**
**错在哪**：以为「MASM 报的行号总要减 1」，于是对着上一行找半天找不到错。
**正确做法**：**MASM 6.11 报出的行号就是准确的出错行**——**本机实测**：源程序第 4 行写成 `mov bx`（漏操作数）→ 报 `e3.asm(4): error A2008: syntax error : in instruction`；第 3 行写成 `mov ax,`（多余逗号）→ 报 `e1.asm(3): error A2008: syntax error : ,`。**看到 `1.asm(7)` 就直接看第 7 行。**
**但有两类例外**：
| 报错 | 行号指向 | 真正要检查什么 |
|---|---|---|
| `A2088: END directive required at end of file` | **文件最后一行** | 整个文件缺 `end`/`end start`（结构问题，不是最后一行本身） |
| `A2074: cannot access label through segment registers` | 用到该标号的那一行 | **前面缺了 `assume 段寄存器:段名` 声明** |
**一句话**：**行号先信；如果那一行看起来没错，再往前找「声明 / 结构」层面的原因。**

**18. 以为 `.obj` 可以直接运行。**
**正确做法**：**`.asm` → `masm` → `.obj` → `link` → `.exe` → 执行**。**`.obj` 只是目标文件，不能运行**。`link` 的三大作用是**合并段、补入库代码、生成可执行格式并重定位**。

**19. 不理解为什么 `DS` 和 `CS` 相差 `10H`。**
**正确做法**：**DOS 装入程序时，先在内存开头建立一个 256 字节（`100H`）的 PSP（程序段前缀）**，程序本体从 PSP 之后开始，所以 `CS = DS + 10H`（`100H` 字节 ÷ 16 = `10H`）。

### 四、loop 与 [bx]（第 5 章）

**★ 20. 以为 `loop` 是「先判断后减 1」。**
**错在哪**：摆好 `CX=n` 以为循环 n 次，实际结果对但边界情况搞错。
**正确做法**：**`loop 标号` 的执行过程是「`(CX)=(CX)−1`，若 `CX≠0` 则转移」——先减后判**。

**★ 21. `CX = 0` 时 `loop` 循环多少次？**
**错在哪**：答「0 次」。
**正确做法**：**`CX = 0` 时先减 1 变成 `FFFFH`，所以循环 65536 次**（回绕）。这是必考陷阱。

**★ 22. 分不清 Debug 和 MASM 对 `[立即数]` 的处理。**
**错在哪**：`mov ax, [0]` 在 MASM 里被当成 `mov ax, 0`（取常量 0，**不报错，静默出错**——实测机器码是 `B8 0000`），在 Debug 里却是「取 `DS:0` 的内容」；而 `mov [6], ax` 在 MASM 里直接报 **`error A2001: immediate operand not allowed`**。
**正确做法**：**MASM 把 `[数字]` 当常量，Debug 把 `[数字]` 当内存地址。** 要真正访问内存，写 **`mov bx, 0` + `mov ax, [bx]`**，或 **`mov ax, ds:[0]`**（加段前缀），或**用数据标号**（`mov ax, fp`，最推荐）。**这是「DEBUG 语法 vs MASM 语法」最大的一处差异，凡是用裸数字偏移的地方都要检查一遍。**

**★ 23. 用 `[bx]` 遍历内存时忘了 `inc bx`，死循环。**
**正确做法**：**`[bx]` 的偏移在 BX 里，BX 不会自己变**。遍历必须写 `mov al,[bx]` … `inc bx` … `loop s`。

**★ 24. 段前缀 `ds:` 漏写，取到错误的段。**
**正确做法**：**`[bx]`/`[si]`/`[di]` 默认段是 `DS`**；**含 `BP` 时默认段是 `SS`**；**串操作的目的 `DI` 固定用 `ES` 且不能用段前缀改**。**用 `ES:DI` 作目的复制数据时，必须先 `mov ax, 0` / `mov es, ax` 把 ES 设置好。**

**★ 25. 用 `mov es, 0` 设置 ES。**
**错在哪**：立即数不能进段寄存器。
**正确做法**：`mov ax, 0` / `mov es, ax`。

**26. 把数据复制到 `0:200` 却写成 `200:0`。**
**正确做法**：**`0:200` 的物理地址 = `0×16 + 200H = 200H`**；**要写成「段:偏移」就是 `0020H:0`**（因为 `0020H × 16 = 200H`）。两个写法等价，别混。

**★ 27. 在 `0:200` 之外乱写数据。**
**正确做法**：**安全空间是 `0:200 ~ 0:2FF`（256 字节）**。`0:000 ~ 0:1FF` 是 DOS 在用的中断向量区，**往里写会破坏系统**。

### 五、多段与寻址方式（第 6、7、8 章）

**★ 28. 在代码段里访问代码段内定义的数据，忘了加 `cs:`。**
**错在哪**：
```asm
    codesg segment
      dw 1,2,3,4,5,6,7,8
    start:
      mov ax, [bx]        ; ✗ 默认用 DS，取到的是别的段的数据
```
**正确做法**：**数据在代码段里，必须用 `cs:` 前缀**：`mov ax, cs:[bx]`。

**★ 29. 用栈时 `SP` 初值设成 0 或设成栈空间的低地址端。**
**错在哪**：`mov sp, 0` 或 `mov sp, 0`（栈空间起始偏移）。
**正确做法**：**`SP` 必须指向栈空间的「高地址端 + 1」**。若栈空间是段偏移 `0~1FH`（32 字节），则 **`SP = 20H`**（不是 `1FH`，也不是 `0`）。因为**第一次 push 会先减 2**。

**★ 30. `mov ss, ax` 之后隔了好几条指令才 `mov sp, ...`。**
**错在哪**：虽然 8086 会抑制一条指令的中断，但间隔太长仍可能被中断打断，导致「新 SS + 旧 SP」。
**正确做法**：**`mov ss, ax` 必须紧跟 `mov sp, 立即数`**（第 12 章讲过：8086 会在这两条指令之间抑制中断）。

**★ 31. `dw 10 dup (0)` 与 `db 10 dup (0)` 混用。**
**正确做法**：**`db` 每项 1 字节、`dw` 每项 2 字节、`dd` 每项 4 字节**。`dw 10 dup(0)` 占 **20 字节**，`db 10 dup(0)` 占 **10 字节**。预留栈空间 `dw 16 dup(0)` 是 32 字节。

**★ 32. `mov ax, 0` 与 `xor ax, ax` 分不清。**
**正确做法**：两者都清零 `AX`，但 **`mov` 不影响标志位，`xor` 会把 `CF` 和 `OF` 清 0、并设置 `SF`/`ZF`/`PF`**。要保留标志位用 `mov`；要顺便清 `CF` 用 `xor`。

**★ 33. `[bx+si]` 之类的寻址里出现非法配对。**
**错在哪**：写 `[bx+bp]`、`[si+di]`、`[ax]`、`[bx+si+di]`。
**正确做法**：**只能用 `BX`/`BP`/`SI`/`DI` 四个寄存器参与寻址，合法配对只有 4 种**：`[bx+si]`、`[bx+di]`、`[bp+si]`、`[bp+di]`。

**★ 34. 忘了含 `BP` 时默认段是 `SS`。**
**错在哪**：算 `[bp+si]` 的物理地址时用了 `DS`。
**正确做法**：**只要 `[ ]` 里出现 `BP`，默认段就是 `SS`**（`[bp]`、`[bp+si]`、`[bp+di+idata]`）。其余情况默认 `DS`。

**★ 35. 多重循环里内层也用 `loop`，导致外层循环次数爆炸。**
**错在哪**：
```asm
    mov cx, 5
  s1: ...
      mov cx, 3
    s2: ...
      loop s2
      loop s1           ; ✗ CX 已被内层改成 0，再减 1 变 FFFFH → 循环 65536 次
```
**正确做法**：**`loop` 只认 `CX`，多层循环必须换寄存器或备份 CX**：
```asm
    mov cx, 5
  s1: mov dx, 3         ; ★ 内层用 DX 计数
    s2: ... 
        dec dx
        jnz s2
      loop s1
```
或者在进入内层前 **`push cx`**、内层结束后 **`pop cx`**。

**★ 36. 立即数送内存时没写 `byte ptr`/`word ptr`。**
**错在哪**：`mov ds:[0], 1` 编译报错。
**正确做法**：**没有寄存器提示长度时，必须显式指明**：`mov byte ptr ds:[0], 1`、`mov word ptr ds:[0], 1`。（注意这里**两个坑叠在一起**：既要 `ptr` 指明长度，又要 `ds:` 说明这是内存而不是常量。）

**★ 两个坑各自报什么错？本机 MASM 6.11 实测（别记混）：**

| 写法 | 缺了什么 | 实测报错 | 为什么 |
|---|---|---|---|
| `mov [0], 1` | **缺 `ds:`** | **`error A2001: immediate operand not allowed`** | `[0]` 被当成常量 0 → 变成 `mov 0, 1`，**立即数做了目的操作数** |
| `mov byte ptr [0], 1` | **缺 `ds:`** | **`error A2001: immediate operand not allowed`** | 同上——**加了 `ptr` 也没用，`[0]` 还是常量** |
| `mov ds:[0], 1` | **缺 `ptr`** | **`error A2070: invalid instruction operands`** | `ds:[0]` 确实是内存操作数了，**但「写 1 个字节还是 2 个字节」无法确定** |
| `mov byte ptr ds:[0], 1` | —— | ✓ 通过 | 两个信息都齐了 |
| `mov [6], ax` | **缺 `ds:`** | **`error A2001: immediate operand not allowed`** | `[6]` 是常量 → `mov 6, ax` |
| `mov ds:[6], ax` | —— | ✓ 通过（**有 `ax` 提示长度，不用 `ptr`**） | 源操作数是寄存器，长度已确定 |

**口诀**：**少了 `ds:` 报 `A2001`（「立即数不能当目的」）；少了 `ptr` 报 `A2070`（「操作数非法」——其实是指长度不明）。** 顺带注意最后一行：**源操作数是寄存器时不需要 `ptr`**，因为寄存器本身就说明了长度。

**★ 37. `mul` 和 `div` 的操作数位宽搞错。**
**正确做法**：
```
   mul r/m8   →  AX = AL × r/m8          （8 位 × 8 位 = 16 位）
   mul r/m16  →  DX:AX = AX × r/m16      （16 位 × 16 位 = 32 位）
   div r/m8   →  AL = AX ÷ r/m8 的商，AH = 余数
   div r/m16  →  AX = DX:AX ÷ r/m16 的商，DX = 余数
```

**★ 38. 16 位除法前忘了 `mov dx, 0`。**
**错在哪**：`mov ax, 1000h` / `div bx`，DX 里是垃圾 → 结果错或除法溢出。
**正确做法**：**16 位除法前必须 `mov dx, 0`**（除非被除数本来就是 32 位）。

**★ 39. 认为 `div`「除数为 0」才溢出。**
**错在哪**：忽略了「商超出目的寄存器范围」也会溢出。
**正确做法**：**两种触发条件都会引发 0 号中断（除法错误）**：① 除数为 0；② **商装不进目的寄存器**（如 `1000H ÷ 1 = 1000H` 装不进 `AL` 的 `FFH` 上限）。

**40. 以为 `mul`/`div` 会像 `add` 一样影响全部标志位。**
**正确做法**：**`mul` 只对 `CF` 和 `OF` 有定义**（乘积高半部分非 0 则 `CF=OF=1`）；**`div` 后的标志位全部「未定义」**，不要依赖。

**41. 把 `db 'abc'` 写成「一个字符串变量」。**
**正确做法**：**`db 'abc'` 等价于 `db 61H, 62H, 63H`**，就是 3 个字节，**没有长度信息、没有结尾符**（DOS 的 9 号功能才需要 `'$'` 结尾）。

### 六、转移指令与子程序（第 9、10 章）

**★ 42. 算 `jmp short` 的位移时减错了基准。**
**错在哪**：用「标号 − jmp 起始地址」。
**正确做法**：**位移 = 标号处偏移 − `jmp` 指令「后第一个字节」的偏移**。`jmp short` 占 2 字节、`jmp near ptr` 占 3 字节。

**★ 43. 条件转移跳得太远。**
**错在哪**：以为「跳得远就报错」或者「反正汇编器会管」，两种极端都不对。
**正确做法**：**8086 机器指令里所有条件转移（`jz`/`ja`/`jb`…）都只有 8 位位移的短转移形式，范围只有 −128~+127**——**指令系统里没有「长距离条件转移」这条指令**。**但 MASM 6.11 默认会自动扩展**：本机实测 `je` 跨 200 字节 → **`exit=0` 通过**，列表文件里被展开成 `75 03`（`jne $+5`）+ `E9 00C8`（`jmp` 位移 200）两条。**加了 `OPTION NOLJMP`（或 MASM 5.0，即王爽教材的版本）才报 `error A2075: jump destination too far : by 73 byte(s)`**（`200 − 127 = 73`）。
**所以考试和编程都按下面这样写**——主动改写，不依赖汇编器特性：
```asm
    jz  far_label       ; ✗ 8086 没有长条件转移，超界时靠汇编器自动扩展（不可移植）
    ; 改成：
    jnz skip            ; ★ 反条件（短跳，只跳过下面一条）
    jmp near ptr far_label
  skip:
```
**★ 反过来记**：**显式写了 `short` 的（`jmp short s`、`jz short far_label`）超界一定报 `A2075`**——那是你在命令汇编器「必须用短位移」，它没有回旋余地（第 9.10 节的 `db 128 dup (0)` 例子就是这种）。

**★ 44. `ret` 和 `retf` 用混。**
**错在哪**：段内调用用 `retf`，或段间调用用 `ret`。
**正确做法**：**`ret` 只弹 IP（段内）；`retf` 先弹 IP 再弹 CS（段间）**。**配对规则：`call 标号` → `ret`；`call far ptr` → `retf`。**

**★ 45. `call dword ptr 内存` 时，忘了内存里要先放「偏移」再放「段」。**
**错在哪**：写反了顺序。
**正确做法**：**双字内存里，低字是偏移（→IP），高字是段（→CS）**。所以：
```asm
    dw offset far_sub       ; ★ 先偏移
    dw seg far_sub          ; ★ 再段地址
```
**这与中断向量表的结构完全一致。**

**★ 46. 子程序用了主程序正在用的寄存器，破坏了外层循环。**
**错在哪**：主程序 `CX=5` 做外层循环，子程序内部 `mov cx, 100`，返回后主程序 `loop` 变成 65536 次。
**正确做法**：**子程序必须保护它用到的、而调用者可能依赖的寄存器**：
```asm
  sub1:
      push cx             ; ★ 进入时保存
      push ax
      ...                 ; 子程序体
      pop ax              ; ★ 逆序恢复
      pop cx
      ret
```
**需要保护的通常是 `AX`/`BX`/`CX`/`DX`/`SI`/`DI`；`BP` 如果用来做栈帧也要保护。**

**★ 47. 栈传参时参数偏移算错。**
**正确做法**：**标准栈帧**：
```asm
  sub1:
      push bp
      mov  bp, sp
      mov  ax, [bp+4]     ; ★ 第 1 个参数（[bp+0]=旧 BP，[bp+2]=返回地址）
      mov  bx, [bp+6]     ; ★ 第 2 个参数
      ...
      pop  bp
      ret
```
调用方 **从右到左压栈**：`push 参数2` / `push 参数1` / `call sub1` / `add sp, 4`。

**★ 48. 用 `ret n` 时算错了 n。**
**正确做法**：**`ret n` 的 n 是「参数字节总数」**。两个 16 位参数 → `ret 4`。**`ret n` 由被调用者清理参数（相当于 stdcall）**；不用 `ret n` 就由调用者写 `add sp, n`（相当于 cdecl）。

**★ 49. 以为 `jcxz` 会改 `CX`。**
**正确做法**：**`jcxz 标号` 只判断 `CX` 是否为 0，不修改 `CX`**。而 `loop` 是**先减 1 再判断**。

### 七、标志寄存器、中断与端口（第 11~15 章）

**★ 50. 把 `CF` 和 `OF` 混为一谈。**
**错在哪**：看到「溢出」就以为是 `OF`。
**正确做法**：**`CF` 是「无符号」视角的进位/借位；`OF` 是「有符号」视角的溢出**。经典对照：
```
   mov al, 0FFh / add al, 1   →  CF=1, OF=0   （无符号 255+1 溢出，有符号 −1+1=0 不溢出）
   mov al, 7Fh  / add al, 1   →  CF=0, OF=1   （无符号 127+1 无进位，有符号 127+1=128 溢出）
```

**★ 51. 无符号比较用了 `jg`/`jl`，有符号比较用了 `ja`/`jb`。**
**错在哪**：这是最高频的错。
**正确做法**：**`A`/`B` 开头（`ja`/`jb`/`jae`/`jbe`）→ 无符号，看 `CF`；`G`/`L` 开头（`jg`/`jl`/`jge`/`jle`）→ 有符号，看 `SF` 和 `OF`；`E`/`N`（`je`/`jne`）→ 两者通用，看 `ZF`。**

**52. `inc`/`dec` 会影响 `CF`。**
**正确做法**：**`inc` 和 `dec` 唯独不影响 `CF`**（只改 `OF`/`SF`/`ZF`/`AF`/`PF`），因为它们常用于循环计数，不能破坏多字节加法的进位链。

**★ 53. `int n` 与 `call far ptr` 分不清。**
**正确做法**：**`int n` 比 `call far ptr` 多压一个 `FLAGS`（共 6 字节）**，并且**自动清 `TF` 和 `IF`**，入口地址从**中断向量表**取，返回用 **`iret`**（弹 3 个字）。

**54. 中断处理程序用 `ret` 返回。**
**正确做法**：**必须用 `iret`**。用 `ret` 只弹了 IP，栈上留着 CS 和 FLAGS → **栈失衡，系统很快崩溃**。

**55. 中断处理程序忘了保护寄存器，或忘了 `iret` 前的逆序恢复。**
**正确做法**：**中断处理程序必须「push 用到的全部寄存器 → 处理 → 逆序 pop → iret」**，比普通子程序纪律更严（因为它打断的是任意代码）。

**56. 改中断向量时忘了 `cli`/`sti`。**
**正确做法**：**改向量表要 `cli` 包住**（防止改到一半来了中断，`CS`/`IP` 不配对）：
```asm
    cli
    mov word ptr es:[9*4], 204h
    mov word ptr es:[9*4+2], 0
    sti
```

**★ 57. 改写 `int 9` 键盘中断后，忘了调用原例程，键盘全失灵。**
**错在哪**：自己处理了扫描码却没送回键盘缓冲区，所有读键盘的程序都收不到键。
**正确做法**：**处理完后必须调用原 `int 9` 例程**：
```asm
    pushf                        ; ★ 因为原例程末尾是 iret，要弹 FLAGS
    call dword ptr cs:[200h]     ; ★ 原例程入口（段:偏移，4 字节）
```

**58. 忘了「写显存」的地址公式。**
**正确做法**：**显存段 `B800H`，每个字符占 2 字节（低字节字符、高字节属性）**。
**偏移 = (行号 × 80 + 列号) × 2 = 行号 × 160 + 列号 × 2**（行列都从 0 开始）。

**★ 59. 端口号大于 `FFH` 时直接写在指令里。**
**正确做法**：**端口号 > `FFH` 必须放在 `DX` 里**；**数据只能用 `AL`/`AX`**：
```asm
    in  al, 60h         ; ✓ 端口号 ≤ FFH，可直接写
    in  al, dx          ; ✓ 端口号 > FFH 时必须用 DX
    in  ax, 60h         ; ✓ 读一个字
    mov dx, 3f8h
    in  al, dx          ; ✓
```

**★ 60. 读 CMOS 时顺序搞反。**
**正确做法**：**先向 `70H`（地址端口）写单元地址，再从 `71H`（数据端口）读**：
```asm
    mov al, 9           ; ★ 年单元的地址是 9
    out 70h, al         ; ★ 先送地址
    in  al, 71h         ; ★ 再读数据
```
**时间单元：0=秒、2=分、4=时、7=日、8=月、9=年。**

**★ 61. 忘了 CMOS 里的时间是 BCD 码。**
**正确做法**：**读出的是 BCD 码**（`26H` 表示十进制 26，不是 38）。要转成可显示的 ASCII，需**拆成十位和个位**：
```asm
    mov ah, al
    mov cl, 4
    shr ah, cl          ; ★ 高 4 位 = 十位
    and al, 00001111b   ; ★ 低 4 位 = 个位
    add ah, 30h         ; ★ 转 ASCII（数字 + 30H = 对应字符）
    add al, 30h
```
**★ 62. `shl al, 4` 在 8086 上编译不过。**
**错在哪**：以为移位次数可以直接写立即数。
**正确做法**：**8086 只支持 `shl al, 1` 和 `shl al, cl`**。要移 4 位必须 `mov cl, 4` / `shl al, cl`（见第 14 章 14.3 节）。

**★ 63. 串操作忘了设置 `ES:DI` 或忘了 `cld`。**
**正确做法**：**串操作前必须做四件事**：① `mov ax, 段地址` / `mov ds, ax`（源）、`mov es, ax`（目的）；② `mov si, 源偏移` / `mov di, 目的偏移`；③ **`cld`（正向）或 `std`（反向）**；④ `mov cx, 次数`。
**`rep movsb` 在 `CX=0` 时一次也不执行**（与 `loop` 的「先减后判」不同）。

**★ 64. 复制重叠数据时用了正向复制，数据被覆盖。**
**正确做法**：**当「目的地址 > 源地址」且两者重叠时，必须用 `std` 反向复制**：
```asm
    std                         ; ★ 反向
    mov si, 5                   ; 从源的最后往前
    mov di, 7
    mov cx, 6
    rep movsb
```

**★ 65. 忘了 `int 21h` 9 号功能的字符串必须以 `'$'` 结尾。**
**正确做法**：**`int 21h` 的 9 号功能靠 `'$'` 判断结束**，忘写会一直显示到内存里遇到下一个 `$`。**（`int 16h` 键盘、`int 10h` 显示的字符串不需要 `$`。）**

## B.2 手写代码题型套路（7 类）

### 套路 1：循环求和 / 求最值 / 统计

**固定模板（遍历内存的一段字节）：**

```asm
    ; ===== 求 FFFF:0 ~ FFFF:B 共 12 个字节的和，结果放 DX =====
    assume cs:code
    code segment
    start:
        mov ax, 0ffffh
        mov ds, ax              ; ★ 数据段的段地址
        mov bx, 0               ; ★ 偏移用 BX
        mov dx, 0               ; ★ 累加器
        mov cx, 12              ; ★ 循环次数放 CX
    s:
        mov al, [bx]            ; ★ 取一个字节
        mov ah, 0               ; ★★ 零扩展！不写这句高 8 位是垃圾
        add dx, ax              ; ★ 加到累加器
        inc bx                  ; ★★ 别忘 inc bx
        loop s
        mov ax, 4c00h
        int 21h
    code ends
    end start
```

**★★ 三个必写的点：① `mov cx, 次数`；② `inc bx` 或 `inc si`；③ 8 位数据参与 16 位运算时必须 `mov ah, 0` 零扩展。**

**求最值的改写：**

```asm
        mov al, [bx]            ; 取第一个元素作初值
        mov ah, 0
        mov dx, ax              ; DX = 当前最大值
    s:
        mov al, [bx]
        mov ah, 0
        cmp ax, dx
        jbe next                ; ★ 无符号比较用 jbe；有符号用 jle
        mov dx, ax              ; 更新最大值
    next:
        inc bx
        loop s
```

**统计个数的改写（统计某字符出现次数）：**

```asm
        mov cx, 长度
        mov si, 0
        mov dx, 0               ; DX = 计数器
    s:
        cmp byte ptr [si], 'a'  ; ★ 两个操作数都不是寄存器，必须用 byte ptr 指明长度
        jne next
        inc dx
    next:
        inc si
        loop s
```

### 套路 2：字符串处理（大小写转换 / 复制 / 反转）

**★ 大小写转换的核心（只差第 5 位 `20H`）：**

```asm
    ; 大写 → 小写：or  al, 00100000b
    ; 小写 → 大写：and al, 11011111b
```

**完整模板（把 `DS:BX` 处 `CX` 个字符全部转大写）：**

```asm
    ; ===== 入口参数：BX = 字符串首地址，CX = 长度 =====
    to_upper:
        push ax                 ; ★ 保护子程序用到的寄存器
        push si
        mov si, 0
    tu_s:
        mov al, [bx+si]         ; ★ 用 [bx+si] 遍历
        cmp al, 'a'
        jb  tu_next             ; ★ 小于 'a' 不是小写字母
        cmp al, 'z'
        ja  tu_next             ; ★ 大于 'z' 不是小写字母
        and al, 11011111b       ; ★★ 小写 → 大写
        mov [bx+si], al
    tu_next:
        inc si
        loop tu_s
        pop si                  ; ★ 逆序恢复
        pop ax
        ret
```

**反转字符串模板（用双指针）：**

```asm
    ; ===== DS:SI 处 CX 个字节原地反转（SI 指向串首，DI 指向串尾）=====
        push bx                 ; ★ 下面要借 BL 做中转，先保护 BX
        mov si, 0               ; 头指针
        mov di, cx
        dec di                  ; 尾指针（指向最后一个字符）
    rev:
        cmp si, di
        jae rev_done            ; ★ 无符号比较：指针相遇就停
        mov al, [si]
        mov bl, [di]
        mov [si], bl            ; ★ 交换
        mov [di], al
        inc si
        dec di
        jmp rev
    rev_done:
        pop bx                  ; ★ 恢复 BX
```

> **★ 注意 `jae`（无符号「高于等于」）而不是 `jge`**：`si`/`di` 是**地址偏移**，地址比较永远按**无符号**看——用 `jge` 在地址超过 `7FFFH` 时会判错。**凡是指针/地址比较，一律用 `ja`/`jb`/`jae`/`jbe`。**

**★★ 循环结束条件不要用 `loop`（因为 `CX` 没在递减），要用 `cmp` + 条件转移。**

### 套路 3：子程序（参数传递的三种方式）

**方式一：用寄存器传参（最简单，参数少时用）**

```asm
    ; ===== 子程序：计算 DS:BX 处 CX 个字节的和，返回在 DX =====
    sum_bytes proc
        push ax
        push bx
        push cx
        mov dx, 0
    sb_s:
        mov al, [bx]
        mov ah, 0               ; ★ 零扩展
        add dx, ax
        inc bx
        loop sb_s
        pop cx
        pop bx
        pop ax
        ret
    sum_bytes endp
    ; 调用：mov bx, 0 / mov cx, 12 / call sum_bytes
```

**方式二：用栈传参（参数多时用，标准栈帧）**

```asm
    ; ===== 子程序：add_two，两个参数，返回在 AX =====
    ; 调用方：push 参数2 / push 参数1 / call add_two / add sp, 4
    add_two proc
        push bp
        mov  bp, sp
        mov  ax, [bp+4]         ; ★ 第 1 个参数
        add  ax, [bp+6]         ; ★ 第 2 个参数
        pop  bp
        ret
    add_two endp
```

**方式三：用共享内存（约定好地址，不用传参）**

```asm
    ; 调用方把参数写在 data 段的固定位置
    ; 子程序直接访问 [bx]（BX = 数据段基址）
```

**三种方式对比：**

| 方式 | 优点 | 缺点 | 适用 |
|---|---|---|---|
| **寄存器** | 最简单、最快 | 寄存器数量有限，只能传 2~4 个 | 参数少 |
| **栈** | 参数不限个数、支持递归 | 要维护栈帧，偏移容易算错 | 参数多、递归 |
| **共享内存** | 不受寄存器限制 | 模块间耦合、不利于复用 | 简单场景 |

**★★ 子程序三条纪律：① 保护用到的寄存器（进入时 push、退出时逆序 pop）；② 用 `ret`（段内）；③ 入口/出口参数在注释里写清楚。**

### 套路 4：中断处理程序（编写 + 安装）

**★★★ 五步法完整模板 ★★★**

```asm
    ; ===== 安装一个自己的 0 号中断处理程序（除零时显示提示）=====
    assume cs:code
    code segment
    start:
        ; ---- ① 设置自己的栈（中断可能在任何时刻发生）----
        mov ax, cs
        mov ss, ax
        mov sp, 256             ; ★ 栈顶指向偏移 256（王爽教材 实验12 的写法）

        ; ---- ② 把中断例程搬移到 0:204 ----
        mov ax, 0
        mov es, ax              ; ★ 目的段 ES = 0
        mov si, offset do0      ; ★ 源偏移（例程在本程序代码段里）
        mov di, 204h            ; ★★ 目的偏移 = 204H，不是 200H！
                                ;    因为 0:200~0:203 要留给「原向量」
        mov cx, offset do0end - offset do0   ; ★★ 自动计算长度（不用手数）
        cld                     ; ★ 正向复制（DF = 0）
        rep movsb               ; ★ 复制 CX 个字节：DS:SI → ES:DI

        ; ---- ③ 保存原来的 0 号中断向量到 0:200（4 字节）----
        push es:[0*4]           ; 原向量的偏移（2 字节）
        pop  es:[200h]          ; → 存到 0:200
        push es:[0*4+2]         ; 原向量的段（2 字节）
        pop  es:[202h]          ; → 存到 0:202

        ; ---- ④ 设置新的中断向量指向 0:204（cli/sti 包住）----
        cli                     ; ★ 改向量期间关中断，防止改到一半来中断
        mov word ptr es:[0*4], 204h          ; ★ 新例程入口偏移 = 204H
        mov word ptr es:[0*4+2], 0           ; ★ 新例程入口段 = 0
        sti                     ; ★ 改完开中断

        ; ---- ⑤ 故意触发除法错误，验证例程 ----
        mov ax, 1000h
        mov bh, 1
        div bh                  ; 1000H ÷ 1 = 1000H 装不进 AL（>FFH）→ 除法溢出

        mov ax, 4c00h           ; ★ 正常情况下执行不到这里（0 号例程会返回 DOS）
        int 21h

    ; ===== 中断处理程序本体（会被整段复制到 0:204）=====
    do0:
        jmp short do0start      ; ★ 跳过下面的数据（占 2 字节）
        db 'overflow!', 0       ; ★ 字符串：复制后位于 0:206（204H + 2）
    do0start:
        push ax                 ; ★ 保护现场（例程要用到的每个寄存器都要保护）
        push bx
        push cx
        push ds
        push es
        push si
        push di

        mov ax, cs              ; ★★ 关键一：例程装在 0:204，中断发生时 CS = 0
        mov ds, ax              ;     所以用 CS 给 DS 赋值，DS 也就成了 0
                                ;     —— 不设 DS，[si] 就取不到 0:206 的字符串
        mov si, 206h            ; ★★ 字符串在 0:206（204H + jmp 的 2 字节）

        mov ax, 0b800h          ; ★★ 关键二：ES 必须指向【显存段】
        mov es, ax              ;     —— 不能设成 0！设成 0 就是往中断向量表里写
        mov di, 160*12 + 40*2   ; ★ 显存偏移 = 行×160 + 列×2（第 12 行、第 40 列）
        mov cx, 9               ; 'overflow!' 共 9 个字符
    do0_s:
        mov al, [si]            ; ★ 从 DS:SI 读字符（DS 已设为 0）
        mov es:[di], al         ; ★ 写字符到 ES:DI（ES 已设为 B800H）
        mov byte ptr es:[di+1], 02h   ; ★ 属性字节：黑底绿字
        inc si
        add di, 2               ; ★★ 每个字符占 2 字节（字符 + 属性）
        loop do0_s

        pop di                  ; ★ 逆序恢复现场（与 push 顺序严格相反）
        pop si
        pop es
        pop ds
        pop cx
        pop bx
        pop ax
        iret                    ; ★★ 必须用 iret（依次弹 IP、CS、FLAGS）
    do0end:
        nop                     ; ★ 只用来给 do0end 一个地址，本身没有作用

    code ends
    end start
```

> **★★ 这个模板有三个「一写就错」的地方，本机 MASM 6.11 实测确认 ★★**
>
> | # | 易错写法 | 后果 | 正确写法 |
> |---|---|---|---|
> | ① | 例程装到 `0:200`，同时又「把原向量存到 `0:200`」 | **两者互相覆盖**：原向量把例程开头 4 字节（`jmp short` + 字符串前 2 字节）冲掉，例程一执行就跑飞 | **例程装 `0:204`、原向量存 `0:200`、新向量指 `0:204`**，三者错开 |
> | ② | 例程里 `mov ax, 0` / `mov es, ax`，然后用 `mov es:[di], al` 写显存 | **ES = 0，实际是往中断向量表里写字符**，屏幕上什么也看不见，还可能破坏系统 | **写显存必须 `mov ax, 0b800h` / `mov es, ax`** |
> | ③ | 例程里 `mov al, [si]` 读字符串，却从没设过 `DS` | 用的是被中断程序留下的 `DS`，**读到的根本不是 `0:206` 的 `'overflow!'`**，屏幕上是乱码 | **`mov ax, cs` / `mov ds, ax`**（中断时 `CS` 正是 0），或直接 `mov ax, 0` / `mov ds, ax` |
>
> **一句话记住**：**读例程里的字符串用 `DS`（指向 0），写显存用 `ES`（指向 `B800H`）——这一对段寄存器在本模板里是「分工」的，绝不能都用 0。**
>
> **★ 偏移核对（复制到 `0:204` 之后）**：
>
> | 内容 | 段:偏移 | 算式 |
> |---|---|---|
> | 原 0 号向量（偏移 2 字节） | `0:200` | 备份区 |
> | 原 0 号向量（段 2 字节） | `0:202` | 备份区 |
> | `do0:` 入口（新向量指向这里） | `0:204` | 复制起点 |
> | `jmp short do0start` | `0:204`~`0:205` | 占 2 字节 |
> | 字符串 `'overflow!', 0` | **`0:206`** | `204H + 2` |
> | `do0start:` 例程主体 | `0:210` | `206H + 10`（9 字符 + 1 个 0） |
>
> **★ 关于栈**：模板沿用王爽教材 实验12 的 `mov ss, cs` / `mov sp, 256`，栈落在本程序代码段偏移 256 以上的位置——实模式下那块内存照样可写，够用。**更规范的做法是单独开一个栈段**（`stack segment db 128 dup(0)`，见第 15 章的五步法），考试两种写法都接受。

**★★★ 六个关键点（漏一个就出错）★★★**

| 序号 | 关键点 | 为什么 |
|---|---|---|
| ① | **`mov cx, offset do0end - offset do0`** | 用 `offset` 相减自动算长度，改代码不用改数字 |
| ② | **`jmp short do0start` 跳过字符串** | 数据与代码混排，不跳过会把字符串当指令执行 |
| ③ | **字符串在安装后的地址是 `0:206`** | 例程装在 `0:204`（`0:200~0:203` 留给备份的原向量），`jmp short` 占 2 字节 ⟹ 字符串在 `204H + 2 = 206H`。**别照搬「`0:200` 起装」的老数字**——起点一变，字符串地址跟着变（起点 + 2） |
| ④ | **写显存偏移 = `行×160 + 列×2`** | 每行 80 字符 × 2 字节 = 160 |
| ⑤ | **`add di, 2`（不是 `inc di`）** | 每个字符在显存里占 2 字节（字符 + 属性） |
| ⑥ | **`iret`（不是 `ret`）** | 中断时压了 FLAGS/CS/IP 共 6 字节 |

**保护现场/恢复现场的模板：**

```asm
    do0start:
        push ax                 ; ┐
        push bx                 ; │ 用到的寄存器全部保存
        push cx                 ; │
        push ds                 ; │
        push es                 ; ┘
        ; …… 处理 ……
        pop es                  ; ┐
        pop ds                  ; │ ★★ 必须【逆序】弹出！
        pop cx                  ; │
        pop bx                  ; │
        pop ax                  ; ┘
        iret
```

### 套路 5：查表法（直接定址表）

**★ 核心思想：用一次内存访问代替一长串 `cmp`/`je` 分支。**

**模板一：字节表（字符映射）**

```asm
    ; ===== 把 0~9 转成对应 ASCII 字符 =====
    data segment
        table db '0123456789'       ; ★ 表：下标 i → 字符 '0'+i
    data ends

    code segment
    start:
        mov ax, data
        mov ds, ax
        mov bx, 7                   ; ★ 要转换的数字
        mov al, table[bx]           ; ★★ 查表：AL = '7' = 37H
        ; …… 使用 AL ……
    code ends
```

**模板二：字表（根据功能号调用子程序）**

```asm
    ; ===== 根据 AH 里的功能号调用不同的子程序 =====
    data segment
        table dw sub1, sub2, sub3   ; ★ 表里存的是【子程序的偏移】
                                    ;   下标 0 → sub1，1 → sub2，2 → sub3
    data ends

    code segment
    start:
        mov ax, data
        mov ds, ax
        mov ah, 2                   ; ★ 功能号（本例要调用 sub3，下标 = 2）
        cmp ah, 2                   ; ★★ 越界检查：表里最大下标是 2，不是 3！
        ja  sret                    ; ★★ 功能号 > 2 直接返回（否则会读表外的垃圾地址）
        mov bx, offset table
        mov al, 2
        mul ah                      ; ★★ 下标 × 元素长度（字表 → ×2）：AX = 2 × AH
        add bx, ax
        call word ptr [bx]          ; ★★ 间接调用（从表里取地址）
    sret:
        mov ax, 4c00h
        int 21h

    sub1: nop
          ret                       ; ; ...（子程序主体写在这里）
    sub2: nop
          ret
    sub3: nop
          ret                       ; 本例会执行这个

    code ends
    end start
```

> **★ 越界检查的边界值一定要数准。** `table dw sub1, sub2, sub3` 有 **3 个表项**，合法下标是 **0、1、2**，所以检查必须是 **`cmp ah, 2` / `ja sret`**。
> **写成 `cmp ah, 3` / `ja sret` 是典型的「差一错误（off-by-one）」**：`AH = 3` 会顺利通过检查，然后 `2 × 3 = 6` 作为偏移去访问表外的内存，**取到一个垃圾地址并 `call` 过去，程序立刻跑飞**——而且这种错在汇编期、链接期都不会报，只在运行时炸。
> **口诀：越界检查的上界 = 表项个数 − 1。** 表项个数不确定时，用 `表项个数 equ 3` 定义常量，写成 `cmp ah, 表项个数-1`，以后加表项只改一处。

**★★★ 查表三步法 ★★★**

```
   ① 算偏移：   偏移 = 下标 × 元素长度
                 字节表（db）→ ×1；字表（dw）→ ×2；双字表（dd）→ ×4
   ② 加基址：   BX = 表基址 + 偏移
   ③ 取值/调用：mov al, [bx]        /  call word ptr [bx]
   
   ★★ 别忘了【越界检查】！下标超出表范围会访问到表外的垃圾数据。
```

**模板三：定长字符串表（把月份号转成月份名）**

```asm
    data segment
        table db 'Jan$Feb$Mar$Apr$May$Jun$'
              db 'Jul$Aug$Sep$Oct$Nov$Dec$'   ; ★ 每项 4 字节，定长
    data ends

    ; 查第 7 个月的名字：
        mov ax, 7
        dec ax                      ; ★ 下标从 0 开始，所以要减 1
        mov cx, 4
        mul cx                      ; ★ 7-1=6，6 × 4 = 24
        mov bx, offset table
        add bx, ax                  ; ★ BX 指向 'Jul$'
```

### 套路 6：端口与 CMOS（读时间 / 控制硬件）

**★★ 读 CMOS 时间的完整模板 ★★★**

```asm
    ; ===== 从 CMOS RAM 读出「时:分:秒」并显示在屏幕第 12 行第 40 列 =====
    assume cs:code
    code segment
    start:
        ; ---- 读【时】（CMOS 单元 4）----
        mov al, 4
        out 70h, al                 ; ★ 先向 70H 送单元地址
        in  al, 71h                 ; ★ 再从 71H 读数据（BCD 码）

        ; ---- 拆 BCD 并转 ASCII ----
        mov ah, al
        mov cl, 4
        shr ah, cl                  ; ★ 高 4 位 = 十位
        and al, 00001111b           ; ★ 低 4 位 = 个位
        add ah, 30h                 ; ★ 数字 + 30H = ASCII 字符
        add al, 30h

        ; ---- 显示到显存 ----
        mov bx, 0b800h
        mov es, bx                  ; ★ 显存段
        mov di, 160*12 + 40*2       ; ★ 第 12 行第 40 列
        mov es:[di], ah             ; 十位
        mov byte ptr es:[di+1], 02h ; ★ 属性：黑底绿字
        mov es:[di+2], al           ; 个位
        mov byte ptr es:[di+3], 02h

        ; ---- 显示 ':' 分隔符 ----
        mov byte ptr es:[di+4], ':'
        mov byte ptr es:[di+5], 02h

        ; ---- 读【分】（单元 2）----
        mov al, 2
        out 70h, al
        in  al, 71h
        mov ah, al
        shr ah, cl
        and al, 00001111b
        add ah, 30h
        add al, 30h
        mov es:[di+6], ah
        mov byte ptr es:[di+7], 02h
        mov es:[di+8], al
        mov byte ptr es:[di+9], 02h
        mov byte ptr es:[di+10], ':'
        mov byte ptr es:[di+11], 02h

        ; ---- 读【秒】（单元 0）----
        mov al, 0
        out 70h, al
        in  al, 71h
        mov ah, al
        shr ah, cl
        and al, 00001111b
        add ah, 30h
        add al, 30h
        mov es:[di+12], ah
        mov byte ptr es:[di+13], 02h
        mov es:[di+14], al
        mov byte ptr es:[di+15], 02h

        mov ax, 4c00h
        int 21h
    code ends
    end start
```

**★★★ 五个关键点 ★★★**

| 序号 | 关键点 |
|---|---|
| ① | **`out 70h, al` 先送地址，`in al, 71h` 再读数据**（顺序不能反） |
| ② | **时间单元：0=秒、2=分、4=时、7=日、8=月、9=年** |
| ③ | **读出的是 BCD 码**（`26H` = 十进制 26，不是 38） |
| ④ | **拆 BCD：`shr ah, cl`（cl=4）取十位，`and al, 00001111b` 取个位** |
| ⑤ | **转 ASCII：`add al, 30h`**（数字 + `30H` = 对应字符） |

**其他端口操作模板：**

```asm
    ; ===== 读键盘扫描码（60H 端口）=====
    in al, 60h

    ; ===== 端口号 > FFH 必须用 DX =====
    mov dx, 3f8h
    in  al, dx
    out dx, al
```

**★ 屏幕上显示带颜色的字符（`int 10h` 9 号功能）**

```asm
        mov ah, 2                       ; ★ 先设置光标位置
        mov bh, 0                       ; 页号
        mov dh, 5                       ; 行号（从 0 开始）
        mov dl, 12                      ; 列号
        int 10h

        mov ah, 9                       ; ★ 再显示字符
```

**★ 读键盘（`int 16h`）**

```asm
    ; ---- 读一个字符（没有按键就等）----
        mov ah, 0

    ; ---- 查询缓冲区是否有字符（不删除）----

        jz  no_key                      ; ★ ZF=1 → 没有按键

```

**★ 读磁盘扇区（`int 13h` 2 号功能）**

```asm
        mov ax, 0
        mov es, ax                      ; ★ 缓冲区段地址
```

## B.4 考试要点速记（最后一小时看这个）

### 必背公式

| 内容 | 公式 |
|---|---|
| **物理地址** | **`物理地址 = 段地址 × 16 + 偏移地址`** |
| **物理地址反推段:偏移** | 段地址 = 物理地址 ÷ 16 取整，偏移 = 余数（或有无数种组合） |
| **栈操作** | **`push`：`(SP)=(SP)−2` 再写；`pop`：先读再 `(SP)=(SP)+2`** |
| **jmp 位移** | **位移 = 标号偏移 − jmp 后第一个字节的偏移** |
| **中断向量地址** | **`n` 号：IP 在 `n×4`，CS 在 `n×4+2`** |
| **显示字符串** | **`DS:DX` 指向，以 `'$'` 结尾，`AH=9`，`int 21h`** |
| **程序返回** | **`mov ax, 4c00h` / `int 21h`** |
| **显存偏移** | **`行×160 + 列×2`**（段 `B800H`） |
| **读 CMOS** | **`out 70h, 单元地址` → `in al, 71h`** |
| **BCD 拆位** | **`shr ah, cl`(cl=4) 取十位，`and al, 0Fh` 取个位，`add al, 30h` 转 ASCII** |
| **查表偏移** | **偏移 = 下标 × 元素长度（db→1、dw→2、dd→4）** |
| **数据长度** | **`db` = 1 字节、`dw` = 2 字节、`dd` = 4 字节** |

### 必背对照表（三张）

**① 跳转指令：无符号 vs 有符号**

| 关系 | 无符号 | 有符号 | 标志 |
|---|---|---|---|
| 大于 | `ja` | `jg` | CF=0且ZF=0 / SF=OF且ZF=0 |
| 大于等于 | `jae` | `jge` | CF=0 / SF=OF |
| 小于 | `jb` | `jl` | CF=1 / SF≠OF |
| 小于等于 | `jbe` | `jle` | CF=1或ZF=1 / SF≠OF或ZF=1 |
| 等于 | `je` | `je` | ZF=1 |

**② `call`/`ret` 与 `int`/`iret`**

| 指令 | 压栈 | 字节 | 配对返回 |
|---|---|---|---|
| `call 标号` | IP | 2 | `ret` |
| `call far ptr` | CS、IP | 4 | `retf` |
| `int n` | FLAGS、CS、IP | 6 | `iret` |

**③ `mov` 非法组合**

| 非法写法 | 原因 |
|---|---|
| `mov ds:[0], ds:[2]` | 两个内存不能直接传 |
| `mov ds, es` | 两个段寄存器不能直接传 |
| `mov ds, 1` | 立即数不能进段寄存器 |
| `mov 1, ax` | 立即数不能作目的 |
| `mov cs, ax` | CS 不能作目的 |
| `pop cs` | 不能 pop CS |
| `mov ip, 0` | IP 不能用 mov 改 |

### 必须写对的三件事（代码题拿分关键）

```
   ① 程序框架完整：
        assume cs:code, ds:data, ss:stack
        三个 segment ... ends 成对
        end start    ← ★★ 别忘！
        mov ax, 4c00h / int 21h   ← ★★ 别忘！
   
   ② 数据段的段地址要真正装入 DS：
        mov ax, data
        mov ds, ax      ← ★★ assume 不会帮你做！
   
   ③ 循环三件套：
        mov cx, 次数    ← ★★
        inc bx / inc si ← ★★
        loop 标号
```

### 最后检查清单（交卷前逐条对）

```
   □ 每个段都有 segment 和 ends，名字相同
   □ 末尾有 end（或 end start）
   □ 有 mov ax,4c00h / int 21h
   □ assume 声明的段都真正装了段寄存器（mov ax,xxx / mov ds,ax）
   □ 用栈的地方 SP 指向了高地址端 + 1
   □ 循环里 CX 没有被内外层冲突使用
   □ 8 位数据做 16 位运算前做了 mov ah,0
   □ 16 位除法前有 mov dx,0
   □ 无符号比较用 ja/jb，有符号比较用 jg/jl
   □ 立即数送内存写了 byte ptr / word ptr
   □ 子程序保护的寄存器 push/pop 数量相同、顺序相反
   □ 中断处理程序结尾是 iret（不是 ret）
   □ 写显存时 add di,2（不是 inc di）
   □ int 21h 9 号功能的字符串以 '$' 结尾
   □ 用 [bp] 时记得默认段是 SS
   □ 一个 [ ] 里的寄存器配对合法（只能是 bx/bp/si/di 的 4 种组合）
```
