# 汇编语言程序设计 · 课程总览与索引

> 湖北大学 计算机科学与技术专业｜专业核心必修｜课程编码 **373C14**｜**3.5 学分 / 64 学时**（48 讲授 + 16 实验）｜建议修读学期：**第 3 学期**

## 一句话定位

**这是计科专业唯一一门「离 CPU 最近」的课**：C 语言告诉你「怎么描述算法」，汇编语言告诉你「CPU 到底怎么执行你的算法」。学完它，你才知道 `int a[10]` 为什么占 20 字节、函数调用为什么要压栈、`while` 循环为什么能停下来——后面《计算机组成原理》《操作系统》《编译原理》的全部地基都在这里，考研 408 的「计算机组成原理」也大量依赖它。

### 三版教材章节目录对照表

## 六、学习建议

1. **必须动手**。这门课「看懂」和「会写」之间的差距，比其他任何课都大。每章的完整程序都要自己在 `D:\Netease\masm` 里敲一遍跑通。
2. **Debug 是你的第二本教材**。用 `t` 单步执行，每执行一条就看一次 `r` 的寄存器变化——这是理解所有指令最快的路。
3. **背表格**。合法组合表、寻址方式总表、标志位影响表、跳转指令对照表——这四张表吃透了，考试至少 60 分。
4. **画图**。栈的变化、内存的布局、中断过程，全部画成 ASCII 图。画一遍胜过读十遍。
5. **程序阅读题用表格法**。逐条指令记录寄存器，不要心算。

## 八、符号与约定

| 符号 / 写法 | 含义 |
|---|---|
| `(ax)` | 寄存器 AX 的内容 |
| `(20000H)` | 内存单元 20000H 处的内容 |
| `((ds)*16+(bx))` | 内存单元「DS×16+BX」处的内容 |
| `SA` | 段地址（Segment Address） |
| `EA` | 偏移地址（Effective Address，有效地址） |
| `idata` | 立即数（immediate data） |
| `n` | 中断类型码 |
| `H` 后缀 | 十六进制，如 `2000H`（**必须以数字开头**，`FFFH` 要写 `0FFFH`） |
| `B` 后缀 | 二进制，如 `11011111B`（**注意 `B` 是后缀，所以十六进制 `123B` 会被当成二进制而报错**） |
| `D` 后缀 | 十进制，如 `123D`（**不写后缀时默认就是十进制**） |

> **关于重要度**：本笔记各表格里的 **`★` 数量表示重要度，5 星为最高**（如 `★★★★★` 表示必考、`★★★☆☆` 表示一般掌握）。这与上表的「符号约定」无关，特此说明。

> **一句话记住整门课**：**CPU 只认段地址和偏移地址，一切内存访问都是 `段寄存器 × 16 + 偏移地址`；一切控制流都是改 CS:IP。**
