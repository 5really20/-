# 第零部分：股票与股市的本质

## 第 1 章 股票到底是什么

### 1.1 一句话定义

**股票（Stock / Share）是股份有限公司签发的、证明股东所持股份的凭证，代表对公司的部分所有权。**

把它拆开看有三层含义：

1. **所有权凭证**：你买了 100 股某公司股票（公司总股本 1 亿股），你就拥有这家公司 100 万分之一的资产和利润索取权。你不需要去公司上班，也不需要管理它，但公司赚钱了你有份。
2. **收益凭证**：公司分红，你按持股比例拿钱；公司升值，你手里的股票也升值。
3. **风险凭证**：公司亏损、破产，你的股票可能变得一文不值，且**清偿顺序排在所有债权人之后**——这是股票风险高于债券的根本原因。

### 1.2 股票和另外几种"纸"的区别

这是新手最容易混淆的地方，一张表说清：

| 品种 | 本质 | 你是什么身份 | 收益来源 | 风险 | 期限 |
|---|---|---|---|---|---|
| **股票** | 所有权凭证 | 股东（老板之一） | 分红 + 股价涨跌 | 高，可能亏光 | 永久，公司不清算就不还本 |
| **债券** | 债权凭证 | 债权人（债主） | 票面利息 + 到期还本 | 较低，但会违约 | 有到期日 |
| **基金** | 集合投资份额 | 基金持有人 | 基金净值涨跌 | 取决于基金类型 | 开放式可随时申赎 |
| **存款** | 银行负债 | 存款人 | 利息 | 极低（有存款保险） | 活期/定期 |
| **期货** | 标准化合约 | 合约买方/卖方 | 标的物价格变动 | 极高（带杠杆） | 有交割月 |
| **期权** | 权利合约 | 权利方/义务方 | 权利金与行权差价 | 买方最多亏权利金，卖方风险大 | 有到期日 |

记忆口诀：**股票是"入股当老板"，债券是"借钱当债主"，基金是"凑钱请人代管"，期货期权是"赌价格方向的合约"。**

### 1.3 一张股票包含哪些权利

普通股股东通常拥有以下权利（具体以公司章程和《公司法》为准）：

- **分红权（收益分配权）**：公司有可分配利润时，按持股比例分现金或送股。
- **表决权**：出席股东大会，对重大事项（选举董事、合并分立、修改章程等）投票。A 股一般"一股一票"。
- **知情权**：查阅公司章程、股东名册、股东大会记录、财务会计报告等。
- **优先认购权**：公司增发新股时，老股东通常可按比例优先认购（配股）。
- **剩余财产分配权**：公司清算时，清偿完债务后的剩余财产按比例分配（实务中往往所剩无几）。
- **诉讼权**：董事高管损害公司利益时，符合条件的股东可提起派生诉讼。

**没有的权利（新手常见误解）**：
- 没有"保本"权利。股票不是存款，公司没有义务让你回本。
- 没有"退股"权利。你不能要求公司把股票买回去（除非公司回购），只能去二级市场卖给别人。
- 没有"固定收益"权利。分红多少由公司董事会提议、股东大会决定，可以一分不分。

### 1.4 股票的分类（按权利差异）

| 分类 | 含义 | 在中国的情况 |
|---|---|---|
| **普通股** | 标准股票，享有表决权与分红权 | A 股绝大多数是普通股 |
| **优先股** | 优先于普通股分红、优先分配剩余财产，但通常**没有表决权** | 中国有优先股制度（如银行发行的优先股），普通投资者较少接触 |
| **A 股** | 人民币普通股票，境内上市、人民币计价交易 | 上交所、深交所、北交所 |
| **B 股** | 人民币特种股票，以外币计价（沪市美元、深市港币） | 历史遗留，现已边缘化 |
| **H 股** | 内地注册公司在香港上市的股票 | 港交所 |
| **红筹股** | 境外注册、主要业务在内地、在香港上市 | 港交所 |
| **N 股 / S 股** | 在纽交所 / 新加坡上市的内地企业股票 | 海外 |
| **存托凭证（DR）** | 在境外发行、代表境内股票的凭证 | 如 CDR（中国存托凭证） |

### 1.5 股票的"价格"从哪来

新手最困惑的问题：**为什么同一家公司，昨天 10 元今天 12 元？**

答案是：**股票价格由二级市场的买卖双方撮合决定，是"边际定价"——最后一笔成交价就是全市场的报价。**

- 只要有一个人愿意用 12 元买、有人愿意 12 元卖，成交价就是 12 元，于是**所有持有者的股票市值都按 12 元重估**。
- 所以股价短期由"供求 + 情绪 + 资金"决定，长期才由"公司盈利能力"决定。
- 这就是为什么"好公司"也会大跌（市场恐慌、资金撤离），"烂公司"也会暴涨（题材炒作、资金推动）。

**关键推论**：股价 ≠ 公司价值。股价是市场对公司的"当下投票结果"，价值是公司未来现金流的折现。两者的差额就是"估值高低"，也是价值投资者研究的东西（详见第 12 章）。

### 1.6 股票市场存在的意义

很多人以为股市就是"赌场"，其实它有三个正经功能：

1. **融资功能**：企业通过发行股票拿到不用还本的资金，用于扩张、研发、还债。
2. **定价功能**：市场通过交易给企业资产定价，价格信号引导资源配置。
3. **流动性功能**：早期投资人、创始人、员工持股可以变现退出，资本才能循环再投。
4. **（衍生）治理功能**：股价表现形成对管理层的市场约束；股东可以通过投票、诉讼参与治理。

**对个人投资者的意义**：股票是普通人少数能参与分享"企业成长"的渠道之一。长期看，股权投资是跑赢通胀概率较高的资产类别；但短期看，它波动剧烈，可能让人亏钱。

## 第 2 章 股市的来历：从荷兰东印度公司到你手机里的 App

### 2.1 股票的诞生（1602 年）

- **1602 年，荷兰东印度公司（VOC）** 在阿姆斯特丹成立，被认为是世界上第一家发行真正意义上"可转让股票"的股份有限公司。它把远洋贸易的高风险分散给众多投资人，投资人可以随时把股份转让给别人。
- **1609 年，阿姆斯特丹证券交易所**成立，被认为是世界上第一家现代证券交易所。
- 在此之前，意大利城邦（威尼斯、热那亚）已有类似"债权份额"的交易，但都不如荷兰这套制度完整。

### 2.2 关键制度演进

| 年份 | 事件 | 意义 |
|---|---|---|
| 1602 | 荷兰东印度公司发行股票 | 股份公司 + 有限责任的雏形 |
| 1609 | 阿姆斯特丹证券交易所 | 二级市场诞生 |
| 1720 | 英国"南海泡沫"、法国"密西西比泡沫" | 人类最早的两次股市大崩盘，催生早期监管 |
| 1792 | 24 名经纪人在华尔街梧桐树下签订《梧桐树协议》 | 纽交所前身 |
| 1817 | 纽约证券交易所正式成立 | 现代交易所制度 |
| 1896 | 道琼斯工业平均指数发布 | 指数化观察市场的开端 |
| 1929 | 美国股市大崩盘，随后大萧条 | 催生 1933 年《证券法》、1934 年《证券交易法》、SEC |
| 1952 | 马科维茨提出现代投资组合理论 | 投资从"手艺"变成"科学" |
| 1973 | 布莱克-斯科尔斯期权定价公式 | 衍生品定价革命 |
| 1975 | 美国佣金自由化 | 折扣券商兴起，交易成本大降 |
| 1990 | 上海证券交易所、深圳证券交易所成立 | 中国现代资本市场起点 |
| 2006 | 中国金融期货交易所（中金所）在上海成立，启动沪深 300 股指期货仿真交易（2010-04-16 股指期货正式上市） | 中国进入做空时代 |
| 2014 | 沪港通开通 | 内地与香港市场互联互通 |
| 2019 | 科创板设立并试点注册制 | 中国注册制改革起点 |
| 2023 | 全面注册制落地 | A 股发行制度根本性变革 |

### 2.3 中国股市简史（新手必知的几个节点）

- **1990-11-26**：上海证券交易所成立，**1990-12-19** 正式开业；**1990-12-01** 深圳证券交易所开始试营业，**1991-07-03** 正式开业。
- **1992 年**：邓小平南巡讲话后股市大发展；同年 8 月发生"8·10 事件"（深圳新股认购抽签表舞弊），催生证监会。
- **1992-10**：中国证监会成立。
- **1999 年**：《证券法》实施。
- **2005–2006 年**：股权分置改革，解决"大小非"流通问题，是 A 股最重要的一次制度补课。
- **2009-10**：创业板开板。
- **2010-03**：融资融券试点启动；**2010-04**：沪深 300 股指期货上市。
- **2014-11**：沪港通开通；**2016-12**：深港通开通。
- **2019-07**：科创板开市，试点注册制。
- **2020-08**：创业板注册制改革。
- **2021-11**：北京证券交易所开市。
- **2023-02**：全面注册制正式实施。
- **2024-04**：新"国九条"发布，强调强监管、防风险、促高质量发展。

### 2.4 为什么要了解历史

因为**今天的很多规则是历史事故的补丁**：
- 涨跌停板 → 来自 1990 年代股市暴涨暴跌的教训；
- T+1 交收 → 来自 1990 年代防止过度投机的考虑；
- 注册制 → 来自核准制下"上市难、壳资源炒作"的教训；
- 退市新规 → 来自"只进不出、垃圾股横行"的教训。

**理解了规则背后的"事故"，你就理解了规则为什么长这样。**

## 第 3 章 股票市场的参与者与运转链条

### 3.1 市场全景图

```
          【一级市场：发行】
 企业 ──IPO/增发──> 投行(保荐承销) ──> 投资者(打新/配售)
                                            │
                                            ▼
          【二级市场：交易】
 投资者A ──委托──> 券商 ──报单──> 交易所撮合 ──成交──> 中国结算登记
    ▲                                  │
    └────────── 行情/清算/交收 ◄────────┘
                                            │
          【监管】
      证监会 ──监管──> 交易所、券商、上市公司、基金、会计师事务所...
```

### 3.2 主要参与角色详解

#### （1）发行人：上市公司

- 通过发行股票融资的企业。
- 义务：**信息披露**（定期报告 + 临时公告）、**规范治理**、**回报股东**。
- 中国上市公司数量：截至 2025 年末，A 股上市公司约 5400 家左右（含北交所），总市值约 100 万亿元量级。（具体数字以交易所每月统计为准）

#### （2）投资者

| 类型 | 说明 |
|---|---|
| **个人投资者（散户）** | 以自然人身份开户交易。A 股个人投资者账户数已超 2 亿户，交易额占比长期在 60%–80%（近年机构化趋势下有所下降）。 |
| **机构投资者** | 公募基金、私募基金、保险资金、社保基金、养老金、QFII/RQFII、券商自营、银行理财等。 |
| **产业资本** | 上市公司大股东、董监高、并购基金。 |
| **境外投资者** | 通过沪深港通（陆股通）、QFII/RQFII 进入 A 股。 |

**新手定位**：你是"个人投资者"，信息、资金、研究能力都处于弱势，**唯一优势是"可以长期持有、可以不作为"**。这一点后面会反复强调。

#### （3）中介机构

| 机构 | 干什么 | 新手何时接触 |
|---|---|---|
| **证券公司（券商）** | 经纪（开户交易）、投行（保荐承销）、资管、研究、自营 | 开户、交易、买理财 |
| **基金公司** | 发行管理公募/私募基金 | 买基金 |
| **商业银行** | 第三方存管（你的钱实际存在银行） | 开户时绑定银行卡 |
| **托管银行** | 保管基金资产、监督投资 | 间接 |
| **会计师事务所** | 审计上市公司财报 | 看财报时看"审计意见" |
| **律师事务所** | 出具法律意见书 | 看 IPO/重组公告 |
| **评级机构** | 债券评级 | 买债券/可转债 |
| **财经媒体/资讯商** | 行情、数据、新闻 | 天天用 |

#### （4）市场组织者与基础设施

| 机构 | 职责 |
|---|---|
| **上海证券交易所（SSE）** | 主板 + 科创板；股票、债券、基金、衍生品交易 |
| **深圳证券交易所（SZSE）** | 主板 + 创业板 |
| **北京证券交易所（BSE）** | 服务创新型中小企业 |
| **中国证券登记结算公司（中国结算）** | 证券登记、存管、清算、交收 |
| **全国股转系统（新三板）** | 非上市公众公司股份转让 |
| **中国证券金融公司（证金公司）** | 转融通、维护市场稳定 |
| **中国证券业协会** | 行业自律 |
| **中国证券投资基金业协会** | 基金行业自律 |
| **中国期货业协会** | 期货行业自律 |
| **中证指数公司 / 国证指数公司** | 编制指数 |

#### （5）监管机构

- **中国证监会（CSRC）**：国务院直属机构，统一监管全国证券期货市场。
- **证监会派出机构**：36 个证监局，属地监管。
- **中国人民银行、国家金融监督管理总局**：分别负责货币政策/支付清算、银行保险监管，与股市有交叉。
- **财政部、税务总局**：印花税等税政。
- **公安部证券犯罪侦查局**：打击证券犯罪。

### 3.3 一只股票的"生命周期"

```
改制设立 → 辅导备案 → 申报受理 → 审核注册 → 发行承销 → 上市交易
    → 持续信息披露 → 再融资/并购重组 → 分红/回购 → 退市/转板
```

新手最需要关心的是中间三段：**上市交易 → 持续披露 → 退市**。

### 3.4 股市的"三层价格"

| 层次 | 含义 | 例子 |
|---|---|---|
| **发行价** | 公司 IPO 时确定的发行价格 | 某新股发行价 20 元/股 |
| **二级市场价格** | 上市后每天竞价形成的价格 | 开盘 25 元，收盘 26 元 |
| **内在价值** | 分析师估算的公司每股价值 | DCF 估出来 22 元 |

**三者经常不一致**，这就是"打新套利""估值回归""泡沫破裂"的来源。

### 3.5 股市的"温度计"：指数

- **指数**是反映一篮子股票整体价格变动的统计指标。
- 中国主要指数：上证综合指数（000001）、深证成指（399001）、沪深 300（000300）、中证 500（000905）、中证 1000（000852）、创业板指（399006）、科创 50（000688）、北证 50（899050）。
- 海外主要指数：道琼斯工业平均指数、标普 500、纳斯达克综合指数、恒生指数、日经 225、德国 DAX、英国富时 100。
- **指数是怎么编出来的**：三个要素——① **选样**（按市值、成交额、行业代表性从全市场筛出成份股）；② **加权**（市值加权最常见，市值越大权重越高；另有等权重、流通市值加权、股息率加权等）；③ **计算与修正**（按权重加总股价变动，遇分红送股、成份股调整时用"除数修正法"保持指数连续）。
- **价格指数 vs 全收益指数**：价格指数只反映股价变动（分红消失在除权里）；全收益指数把分红再投资计入，长期看全收益指数每年多出 2%–3%（大致相当于 A 股的平均股息率）。
- **四种常见加权方式**：

| 加权方式 | 规则 | 特点 |
|---|---|---|
| 市值加权 | 权重与总市值/流通市值成正比 | 最主流（沪深 300、标普 500），大公司主导 |
| 等权重 | 每只成份股权重相同 | 更分散、偏小盘，需定期再平衡 |
| 股息率加权 | 股息率越高权重越大 | 红利指数，偏价值风格 |
| 基本面加权 | 按营收/利润/净资产加权 | 避免"越贵越买" |

> 一句话：**买指数 = 买一套规则**。同样 300 只股票，等权重和市值加权的长期收益可以差很多。

# 第一部分 市场结构：钱是怎么从你口袋流到公司，又怎么流回来

## 第 4 章 一级市场：企业怎么"卖股票"

### 4.1 一级市场 vs 二级市场

| | 一级市场（发行市场） | 二级市场（交易市场） |
|---|---|---|
| 交易对象 | 新发行的股票 | 已发行的老股票 |
| 交易双方 | 发行人 ↔ 投资者 | 投资者 ↔ 投资者 |
| 钱去哪了 | **流入公司**（用于发展） | **流入卖方口袋**（公司拿不到） |
| 价格 | 发行价（事先确定） | 市场竞价（随时变动） |
| 参与者 | 发行人、投行、机构、打新散户 | 所有开户投资者 |
| 场所 | 无固定场所（承销发行） | 交易所 |

**一句话**：一级市场是"批发"，二级市场是"零售转手"。公司只在"批发"时拿到钱，之后你我在"零售"环节互相博弈。

### 4.2 IPO（首次公开发行）完整流程

以 A 股为例（全面注册制下）：

| 阶段 | 做什么 | 耗时（参考） |
|---|---|---|
| 1. 改制与辅导 | 有限公司改股份公司；券商/会计师/律师进场辅导 | 1–3 年 |
| 2. 辅导验收 | 证监局验收辅导工作 | 数月 |
| 3. 申报受理 | 向交易所提交招股说明书等申请文件 | — |
| 4. 审核问询 | 交易所多轮问询，回复；上市委审议 | 6–18 个月 |
| 5. 证监会注册 | 交易所审核通过后报证监会注册 | 20 个工作日左右 |
| 6. 发行承销 | 路演、询价/定价、申购、配售 | 2–4 周 |
| 7. 登记上市 | 中国结算登记，交易所安排上市 | 1–2 周 |

**关键文件：招股说明书（Prospectus）**
- 内容：公司业务、行业、财务、风险因素、募资用途、股东结构、关联交易等。
- 新手价值：这是了解一家新公司**最详实的一份材料**，比任何研报都原始。重点看"风险因素""募资用途""主要客户与供应商""毛利率与同行对比"。

### 4.3 发行的几种定价方式

| 方式 | 说明 | 中国现状 |
|---|---|---|
| **固定价格发行** | 事先定死价格 | 较少 |
| **询价发行** | 向机构投资者询价，按报价确定发行价 | A 股主流（注册制下） |
| **累计投标询价** | 国际上最主流，按需求曲线定价 | 港股、美股主流 |
| **直接定价** | 发行人与主承销商商定 | 小额发行可用 |

**"打新"是什么**：在新股发行时申购，中签后按发行价买入，上市首日卖出赚差价。
- **A 股打新需要市值配售**：沪市每 1 万元市值对应 1 个申购单位（1000 股），深市每 5000 元市值对应 1 个申购单位（500 股），两市实际都是"1 万元市值约等于 1000 股额度"；北交所不要求市值，按申购资金比例配售（全额缴款申购）。
- **注册制下打新不再"稳赚"**：2021 年后出现多只新股上市首日破发，"无脑打新"时代结束。

### 4.4 上市之后还能怎么"再融资"

| 方式 | 通俗解释 | 对老股东的影响 |
|---|---|---|
| **增发（定向增发/定增）** | 向特定对象（通常机构）发新股募资 | 股本增加，每股收益被稀释；但若募投项目好则长期有利 |
| **配股** | 向全体老股东按持股比例配售新股，价格通常打折 | 不参与就被稀释，所以"配股"往往被视为利空/被迫掏钱 |
| **可转债** | 发行可转换公司债券，未来可转成股票 | 转股后稀释；不转则还本付息 |
| **可交换债（EB）** | 大股东用自己持有的股票作抵押发债 | 转股是老大股东减持，不增加总股本 |
| **GDR** | 在境外（如瑞士、伦敦）发行存托凭证 | 增加总股本，引入境外投资者 |
| **分拆上市** | 把子公司单独拿去上市 | 母公司持股价值重估 |

### 4.5 并购重组与"借壳"

- **并购（M&A）**：一家公司买另一家公司的股权或资产。
- **重组**：资产置换、剥离、注入等结构性调整。
- **借壳上市**：非上市公司通过收购一家已上市公司（"壳"）的控制权，再把自身资产注入，实现间接上市。
  - 注册制后，借壳（重组上市）审核标准**等同 IPO**，壳资源价值大幅下降。
  - "炒壳"是 A 股历史上的著名投机模式，现已大幅退潮。

### 4.6 退市：出口在哪

**退市类型**（以 A 股现行规则为准）：

| 类型 | 触发情形（简化） |
|---|---|
| **交易类强制退市** | 连续 20 个交易日收盘价低于 1 元（面值退市）；连续 20 个交易日市值低于 5 亿元（主板）/3 亿元（创业板等）；连续 20 个交易日股东人数低于 2000 人；连续 120 个交易日成交量过低 |
| **财务类强制退市** | 净利润为负且营收低于 3 亿元（主板）/1 亿元（创业板、科创板）；期末净资产为负；财报被出具无法表示意见或否定意见 |
| **规范类强制退市** | 未按期披露年报/半年报；信息披露或规范运作存在重大缺陷；半数以上董事无法保证财报真实 |
| **重大违法强制退市** | 欺诈发行、财务造假、涉及国家安全/公共安全等 |
| **主动退市** | 公司自愿申请，如私有化、被吸收合并 |

**退市流程**：先"退市风险警示"（*ST）→ 触及条件后停牌 → 交易所决定终止上市 → **退市整理期（15 个交易日）**→ 摘牌 → 转入**全国股转系统退市板块**（"老三板"）继续转让（流动性极差）。

**新手警示**：
- 2024 年 4 月证监会发布《关于严格执行退市制度的意见》，"应退尽退"成为基调；2024 年 A 股退市 52 家，创历史峰值，2025 年约 30 家。
- **不要赌"ST 股重组翻身"**，注册制+严退市环境下，这个策略的胜率已大幅下降。

### 4.7 分红、送股、转增、回购

| 方式 | 本质 | 你的账户变化 | 是否要交税 |
|---|---|---|---|
| **现金分红（派息）** | 公司把利润以现金发给股东 | 现金增加，股价除息下调 | 是（差别化红利税，见第 9 章） |
| **送股（送红股）** | 用未分配利润转为股本，按比例送 | 股数增加，股价除权下调 | 是（按面值计税） |
| **转增股本** | 用资本公积转为股本 | 股数增加，股价除权下调 | **否**（不是利润分配） |
| **回购注销** | 公司用现金在二级市场买回并注销股票 | 总股本减少，每股价值提升 | 否（对股东友好） |
| **回购用于股权激励** | 买回后发给员工 | 总股本不变，但可能摊薄 | 视情况 |

**关键概念：除权除息**
- **除息**：分红后，股价按分红金额下调。例：股价 10 元，每股派 0.5 元，除息后理论价 9.5 元。
- **除权**：送股/转增/配股后，股价按比例下调。例：10 送 10，股价 10 元 → 理论价 5 元，股数翻倍。
- **结论**：分红送股本身**不创造价值**，只是把左口袋的钱挪到右口袋（还要交税）。真正创造价值的是公司持续赚钱的能力。

### 5.2 A 股各板块对比（新手最该背的一张表）

### 5.3 交易所内部：订单怎么变成成交

```
你下单 → 券商风控校验 → 券商报盘 → 交易所交易主机（撮合引擎）
                                          │
        ┌─────────────────────────────────┤
        │ 价格优先、时间优先               │
        ▼                                 ▼
   成交回报 → 券商 → 你的 App 显示成交 → 中国结算 T+1 清算交收
```

**撮合原则（全球通用）**：
1. **价格优先**：买单出价高的先成交，卖单要价低的先成交。
2. **时间优先**：同价位，先报单的先成交。

**集合竞价与连续竞价**：
- **集合竞价**：在一段时间内收集所有委托，最后一次性撮合出一个价格。
- **连续竞价**：逐笔撮合，随时成交。

### 5.4 交易时间（A 股）

| 时段 | 时间 | 内容 |
|---|---|---|
| 开盘集合竞价 | 9:15–9:20 | 可申报、**可撤单** |
| | 9:20–9:25 | 可申报、**不可撤单** |
| | 9:25 | 产生开盘价 |
| | 9:25–9:30 | 可申报，不撮合（"静默期"） |
| 上午连续竞价 | 9:30–11:30 | 正常交易 |
| 下午连续竞价 | 13:00–14:57 | 正常交易 |
| 收盘集合竞价 | 14:57–15:00 | 产生收盘价（沪深主板、创业板、科创板） |
| 大宗交易 | 15:00–15:30 | 大额协议转让 |

**港股**：9:00–9:30 开市前时段，9:30–12:00、13:00–16:00 连续交易，16:00–16:10 收市竞价。
**美股**：美东时间 9:30–16:00（夏令时对应北京时间 21:30–次日 4:00，冬令时 22:30–次日 5:00），另有盘前盘后交易。

### 5.5 T+1、T+0 与交收制度

| 概念 | 含义 | 中国 A 股 | 港股 | 美股 |
|---|---|---|---|---|
| **T+0 交易** | 当天买入当天可卖 | **不允许**（股票）；ETF/可转债/期货可以 | 允许 | 允许（但受 PDT 限制） |
| **T+1 交易** | 当天买入次日才能卖 | 股票实行 T+1 | — | — |
| **T+1 交收** | 成交后第 1 个交易日完成券款对付 | 资金 T+1 可取（卖出当天可用于买，次日可取现） | — | 2024-05-28 起美股改为 **T+1 交收** |
| **T+2 交收** | 成交后第 2 个交易日完成交收 | — | 港股 T+2 交收（交易本身 T+0） | — |

**新手最常踩的坑**：
- "我今天买的股票今天不能卖"——A 股 T+1。
- "我今天卖了股票，钱怎么不能马上取？"——卖出后资金**当天可以继续买股票**，但**取现要 T+1**。
- "港股当天买可以当天卖，但钱要两天后才到账"——港股 T+0 交易、T+2 交收。

### 5.6 涨跌停板与熔断

- **涨跌停板**：单日价格波动的上限/下限。A 股主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST/*ST 股票 ±5%（主板）。
- **ST 股**：被实施"其他风险警示"（ST）或"退市风险警示"（*ST）的股票，涨跌幅受限、需签署风险揭示书才能买。
- **熔断机制**：指数跌幅达到阈值时暂停交易。A 股 2016 年 1 月 1 日实施熔断（-5% 停 15 分钟、-7% 全天休市），**4 个交易日后即 2016-01-08 暂停**，成为史上最短命制度。美股有三级熔断（-7%、-13%、-20%）。
- **临时停牌**：科创板/创业板新股上市前 5 日盘中涨跌 30%、60% 各停牌 10 分钟。

### 5.7 融资融券（两融）

| 概念 | 含义 |
|---|---|
| **融资** | 向券商借钱买股票（看涨加杠杆） |
| **融券** | 向券商借股票卖出（看跌做空） |
| **保证金比例** | 融资买入时自有资金占比下限 |
| **维持担保比例** | （现金 + 证券市值）/（融资额 + 融券市值 + 利息费用），低于 130% 会被**强制平仓** |
| **标的证券** | 只有被列入两融标的的股票才能做两融 |

**最新政策（重要）**：
- 2026-11-22 沪深北交易所发布通知（上证发〔2026〕108 号），**融资保证金比例下限由 100% 降回 80%**，2026-11-30 起施行；此前 2026-01-14 的《关于调整融资保证金比例的通知》（上证发〔2026〕5 号）将下限由 80% 上调至 100%。
- 通俗理解：**80% 意味着你有 100 万本金，最多可融资买入 125 万的股票**（100/0.8）；100% 则只能买 100 万。比例越低，杠杆越高，风险越大。
- 两融开户门槛：20 个交易日日均资产 ≥ 50 万元 + 半年交易经验。

### 5.8 转融通与股票质押

- **转融通**：证金公司把自有或借入的证券/资金转借给券商，券商再借给客户。2024 年起转融券业务已大幅收紧（2024-07-11 起暂停转融券业务）。
- **股票质押**：股东把股票质押给银行/券商融资。质押比例过高、股价大跌时可能被强平，是重要的"爆雷"风险点。

## 第 6 章 全球主要股票市场对比

### 6.1 三大市场核心差异

| 维度 | A 股 | 港股 | 美股 |
|---|---|---|---|
| 主要交易所 | 上交所、深交所、北交所 | 香港交易所（HKEX） | 纽交所（NYSE）、纳斯达克（NASDAQ） |
| 货币 | 人民币 | 港币 | 美元 |
| 交易制度 | T+1 | T+0 | T+0 |
| 交收 | T+1 | T+2 | T+1（2024-05-28 起） |
| 涨跌幅 | 主板 ±10%、双创 ±20%、北交所 ±30% | **无涨跌幅限制** | **无涨跌幅限制**，但有熔断 |
| 最小单位 | 100 股（科创板 200 股起） | 每手股数不一（如 100/500/2000 股） | 1 股 |
| 做空 | 受限（融券） | 较成熟（窝轮、牛熊证、借券） | 成熟（期权、借券） |
| 印花税 | 卖出 0.05%（单边） | **买卖双边各 0.1%** | 无联邦印花税（有 SEC 费等） |
| 监管 | 中国证监会 | 香港证监会（SFC）+ 港交所 | SEC + FINRA + 各交易所 |
| 投资者结构 | 散户占比高 | 机构+内地资金占比高 | 机构占比最高 |

> 港股印花税自 2023-11-17 起由 0.13% 下调至 0.1%，买卖双方各付。以香港税务局/港交所最新公布为准。

### 6.2 港股通与陆股通

- **沪港通/深港通**：内地与香港市场互联互通机制，2014-11-17 沪港通开通，2016-12-05 深港通开通。
- **陆股通（北向）**：境外资金经香港买 A 股。
- **港股通（南向）**：内地资金经内地券商买港股。
- **门槛**：个人投资者港股通需 50 万元日均资产 + 2 年经验。
- **额度**：每日额度、总额度机制（现行取消总额度限制，保留每日额度）。
- **标的**：港股通标的为恒生综合指数成份股等，不含创业板股票等。

### 6.3 美股的特殊规则

- **PDT 规则（Pattern Day Trader）**：账户资产 < 25,000 美元的融资账户，5 个交易日内不得进行 4 次及以上"日内回转交易"（当天买当天卖），否则账户被限制。
- **盘前盘后**：盘前 4:00–9:30，盘后 16:00–20:00（美东），流动性差、价差大。
- **股息税**：非美国居民持有美股，股息通常被预扣 30%（中美税收协定下为 10%，需填 W-8BEN）。
- **ADR**：美国存托凭证，如阿里（BABA）、京东（JD）等中概股多以 ADR 形式在美上市。

### 6.4 交易成本横向对比（散户视角）

| 成本项 | A 股 | 港股 | 美股 |
|---|---|---|---|
| 佣金 | 万分之 1–万分之 3（券商可调，最低 5 元/笔常见） | 万分之 2–万分之 5，最低约 50–100 港币 | 0 佣金（主流互联网券商）或每股 0.005 美元 |
| 印花税 | **卖出 0.05%** | **双边 0.1%** | 无联邦印花税（有 SEC 费、FINRA 交易活动费等，费率按财年调整） |
| 过户费 | 0.001%（双向） | 无（含在交易费内） | 无 |
| 交易征费/交易费 | 经手费 0.00341%（双向） | 交易费 0.00565% + 交易征费 0.0027%（双向） | 交易所费用极低 |
| 结算费 | 无（已含） | 0.002%（双向，最低 2 港币，最高 100 港币） | 无 |
| 股息税 | 差别化（持股期限挂钩，见第 9 章） | 无（但 H 股股息可能代扣 10%） | 30% 或协定税率 |

> 上表为量级参考，**实际费率以你开户券商的费率表和交易所公告为准**。高频交易者尤其要注意"最低佣金"对成本的放大效应。

# 第二部分 实战操作：从开户到下单

## 第 7 章 开户：进入市场的第一步

### 7.1 开户前必须知道的四件事

1. **炒股必须通过持牌证券公司**。任何"代客理财""老师带你炒股""内部渠道"都是高风险甚至诈骗。
2. **A 股开户免费，且可以开多个**：目前一个自然人可在多家券商开立 A 股账户（沪市最多 3 个、深市最多 3 个，具体以中国结算规则为准）。
3. **佣金可以谈**。默认费率往往较高（万分之 2.5–万分之 3），开户前找客户经理谈，资金量大或交易频繁可谈到万分之 1 甚至更低。
4. **开户要开"资金账户"+"证券账户"**：证券账户在中国结算登记（沪市 A 股账户、深市 A 股账户），资金账户在券商；钱通过**第三方存管**放在银行，券商不能挪用。

### 7.2 开户流程（线上，约 10–20 分钟）

| 步骤 | 内容 | 注意事项 |
|---|---|---|
| 1 | 下载券商 App 或去营业部 | 认准证监会批准的持牌机构（可在证监会官网/中国证券业协会查） |
| 2 | 身份认证 | 身份证正反面 + 人脸识别 |
| 3 | 填写资料 | 职业、收入、投资经验、风险测评 |
| 4 | **风险测评** | 决定你能买什么（保守型不能买高风险产品） |
| 5 | 签署协议 | 开户协议、风险揭示书、交易规则确认 |
| 6 | 绑定银行卡 | 三方存管，建议用大行一类卡 |
| 7 | 设置密码 | 交易密码、资金密码（别设成生日） |
| 8 | 视频见证/回访 | 部分券商需要 |
| 9 | 等待开通 | 通常 T+1 交易日可用 |

### 7.3 特殊权限开通（门槛）

| 权限 | 门槛（简化） | 说明 |
|---|---|---|
| **创业板** | 2 年交易经验 + 10 万元日均资产（20 个交易日） | 首次开通需临柜或线上双录 |
| **科创板** | 2 年经验 + 50 万元日均资产 | 同上 |
| **北交所** | 2 年经验 + 50 万元日均资产 | 同上 |
| **可转债** | 2 年经验 + 10 万元日均资产 | 2022 年起新增门槛 |
| **融资融券** | 20 日日均 50 万元 + 半年经验 | 风险极高 |
| **股指期货** | 50 万元 + 知识测试 + 交易经历 | 中金所 |
| **期权** | 50 万元 + 测试 + 模拟交易 | 上交所/深交所 |
| **港股通** | 50 万元日均资产 | 沪深港通 |
| **新三板** | 基础层 200 万 / 创新层 100 万（法人另有标准） | 2020 年分层改革后 |

> 门槛会调整，以券商和交易所最新规则为准。

### 7.4 账户结构图解

```
你的银行卡（三方存管）
      │  银证转账（交易日 8:30–16:00，各家不同）
      ▼
   资金账户（券商）
      │
      ├── 可用资金（可买股票）

      └── 冻结资金（挂单未成交）
      │
      ▼
   证券账户（中国结算登记）
      ├── 沪市 A 股账户
      ├── 深市 A 股账户
      └── 基金账户等
```

### 7.5 新手开户避坑清单

- ❌ 不要相信"保本保收益""稳赚不赔"的承诺（违法）。
- ❌ 不要把账户借给他人（违法，可能构成"出借证券账户"）。
- ❌ 不要用来路不明的"荐股群""直播间"推荐的 App 开户（可能是虚拟盘诈骗）。
- ❌ 不要一上来就开通所有高风险权限。
- ✅ 先用**模拟盘**练手（券商 App 基本都有）。
- ✅ 用小额资金实盘，先体会"真金白银的心跳"。

## 第 8 章 下单：委托类型与盘口语言

### 8.1 委托（Order）的类型

| 委托类型 | 含义 | 优点 | 缺点 |
|---|---|---|---|
| **限价委托** | 指定价格，只有达到或优于该价格才成交 | 价格可控 | 可能不成交 |
| **市价委托** | 不指定价格，按市场最优价立即成交 | 快速成交 | 价格不可控（尤其流动性差时） |
| **本方最优** | 以本方（买/卖）最优报价为限价 | 兼顾速度与价格 | 复杂，新手少用 |
| **对手方最优** | 以对手方最优报价成交 | 快速 | 可能滑点 |
| **五档即时成交剩余撤销** | 吃掉对手方五档，剩余撤单 | 快速部分成交 | 复杂 |
| **全额成交或撤销（FOK）** | 必须全部成交，否则整单撤销 | 保证成交数量 | 可能全部失败 |

**新手建议**：**一律用限价委托**。市价委托在极端行情（跌停/涨停/流动性枯竭）可能以极差价格成交。

### 8.2 盘口：五档行情怎么看

```
卖五  10.05   1200 手
卖四  10.04    800 手
卖三  10.03   2300 手
卖二  10.02    500 手
卖一  10.01    300 手   ← 最低卖价（你要买，就从这个价开始成交）
------------------------------------
买一  10.00    600 手   ← 最高买价（你要卖，就从这个价开始成交）
买二   9.99    900 手
买三   9.98   1500 手
买四   9.97    400 手
买五   9.96   2000 手
```

**关键概念**：
- **买一/卖一**：当前最高买价 / 最低卖价，二者之差叫**买卖价差（Spread）**。
- **盘口挂单量**：反映短期供求，但**可以被"幌骗"（挂大单再撤单）**，不可完全相信。
- **内盘/外盘**：以卖方报价成交的叫**内盘**（主动卖出），以买方报价成交的叫**外盘**（主动买入）。外盘 > 内盘通常表示买盘积极（但也不是绝对）。
- **量比**：当前每分钟成交量 / 过去 5 日每分钟平均成交量，>1 表示放量。
- **换手率**：成交量 / 流通股本，反映交易活跃度。
- **委比**：(委买手数 − 委卖手数) / (委买 + 委卖) × 100%，范围 −100% 到 +100%。

### 8.3 下单时要填的字段

| 字段 | 说明 | 新手注意 |
|---|---|---|
| 证券代码 | 6 位数字（A 股） | 别输错，输错可能买到完全不同的股票 |
| 买卖方向 | 买入 / 卖出 | — |
| 价格 | 限价委托必填 | 参考买一/卖一 |
| 数量 | A 股 100 股整数倍（科创板 200 股起可 1 股递增） | 卖出可以不足 100 股（零股一次性卖出） |
| 有效期 | 当日有效（A 股默认） | 收盘未成交自动作废 |

### 8.4 订单生命周期

```
已报（待成交） → 部分成交 → 全部成交
       │
       └──→ 已撤单 / 废单（价格越界、数量不符、无权限等）
```

**废单常见原因**：
- 价格超出涨跌停范围；
- 数量不是 100 股整数倍（买入）；
- 账户资金/持仓不足；
- 未开通对应板块权限；
- 股票停牌；
- 超出单笔申报上限。

### 8.5 特殊交易方式

| 方式 | 门槛 | 说明 |
|---|---|---|
| **大宗交易** | 单笔数量/金额达标（A 股通常 30 万股或 200 万元起，具体看板块） | 盘后协议转让，价格可折价，常见于机构调仓、大股东减持 |
| **盘后固定价格交易** | 科创板、创业板 | 15:05–15:30 按收盘价成交 |
| **ETF 申赎** | 一篮子股票/现金 | 一级市场申购赎回，二级市场买卖 |
| **可转债转股** | 持有可转债 | 按转股价转换为股票 |
| **要约收购** | 持股达 30% 触发 | 强制/自愿要约，散户可接受要约卖出 |

### 8.6 交易心态：下单前的"三问"

1. **我为什么买它？**（理由能不能用三句话说清，且不包含"别人说"）
2. **如果我错了，我在哪里认错？**（止损位）
3. **这笔钱如果亏 30%，会影响我的生活/学业吗？**（仓位管理）

答不上来，就不要下单。

## 第 9 章 交易成本：你还没赚钱就先付了多少

### 9.1 A 股交易费用全清单

以买入 10 万元、卖出 10 万元某沪市主板股票、佣金万分之 2.5 为例：

| 费用 | 费率 | 收取方向 | 买入 10 万 | 卖出 10 万 |
|---|---|---|---|---|
| **佣金** | 万分之 2.5（0.025%），最低 5 元 | 双向 | 25 元 | 25 元 |
| **印花税** | 0.05%（0.5‰） | **仅卖出** | 0 | 50 元 |
| **过户费** | 0.001%（0.01‰） | 双向 | 1 元 | 1 元 |
| **交易经手费** | 0.00341%（0.0341‰） | 双向 | 3.41 元 | 3.41 元 |
| **证管费** | 0.002%（0.02‰） | 双向 | 2 元 | 2 元 |
| **合计** | — | — | **约 31.41 元** | **约 81.41 元** |

**一次完整买卖（10 万元）总成本约 112.82 元，占本金 0.113%。**

> 说明：
> - **佣金通常已包含券商代收的经手费与证管费**（即"含规费佣金"）。上表把各项拆开列示，是为了让你看清钱花在哪里；如果你的券商报的是"净佣金"，则需在佣金之外再加经手费和证管费。最终以交割单为准。
> - 佣金费率因券商而异，最低 5 元/笔的规定各券商略有差异（部分券商已取消最低 5 元）。
> - **经手费 0.00341%** 来自上交所 2026 年 1 月公布的收费标准（含科创板盘后固定价格交易），深交所费率相近。
> - **印花税 0.05% 单边（卖出方）** 依据 2023-08-28 起减半征收的政策，基金、债券不征。
> - 过户费由中国结算收取，2022-04-29 起降为成交金额的 0.001%，双向收取。
> - 以上为**价税合计数**口径，实际扣费以券商交割单为准。

### 9.2 印花税的历史与现状

| 时间 | 政策变化（历史资料的税率口径不完全统一，下表按"每次交易、单方"理解，仅作脉络参考） |
|---|---|
| 1990-07 | 深圳率先开征证券交易印花税，买卖双方各 0.3% |
| 1991-10 | 上海开征，买卖双方各 0.3% |
| 1997-05 | 上调至 0.5% |
| 1998-06 | 下调至 0.4% |
| 2001-11 | 下调至 0.2% |
| 2005-01 | 下调至 0.1% |
| 2007-05-30 | 上调至 0.3%（"5·30 大跌"的导火索） |
| 2008-04-24 | 下调至 0.1%（仍为双边征收） |
| 2008-09-19 | **改为单边征收，只对出让方（卖出方）征 0.1%** |
| 2023-08-28 | **减半征收，现行 0.05%（单边卖出）** |

**为什么关注印花税**：它是唯一"国家直接拿走"的交易成本，调整印花税是监管层调节市场情绪的经典工具（"政策底"信号之一）。

### 9.3 股息红利差别化个人所得税

A 股个人投资者持股期限不同，分红税率不同：

| 持股期限 | 税率 | 说明 |
|---|---|---|
| ≤ 1 个月 | **20%** | 全额计入应纳税所得额 |
| 1 个月 ~ 1 年 | **10%** | 减按 50% 计入 |
| > 1 年 | **0%** | 暂免征收 |

**关键细节**：
- 税率按**"先进先出"**原则计算持股期限。
- 分红时**先不扣税**，卖出时按持股期限补扣。所以"分红后立刻卖"会被扣 20%。
- **这条规则强烈鼓励长期持有**，是"长期主义"在税制上的体现。

### 9.4 其他可能成本

| 成本 | 说明 |
|---|---|
| **融资利息** | 年化 5%–8%（券商不同），按日计息 |
| **融券费用** | 年化 8%–10% 甚至更高，券源紧张时更贵 |
| **基金申赎费** | 股票基金申购 1.5%（打折后 0.15%），赎回 0.5%（持有 2 年以上常免） |
| **基金管理费** | 主动股票基金约 1.2%–1.5%/年，指数基金 0.15%–0.5%/年 |
| **基金托管费** | 约 0.05%–0.25%/年 |
| **港股印花税** | 双边 0.1%（2023-11-17 起） |
| **港股交易征费** | 0.0027%（SFC）+ 交易费 0.00565%（HKEX）+ 结算费 0.002% |
| **美股 SEC 费** | 卖出金额的 0.00278%（2024 财年口径）；该费率每财年按 SEC 规定调整，2025 年曾一度降至 0，以 SEC 最新公告为准 |
| **美股 FINRA 交易活动费** | 卖出股数 × 0.000166 美元（上限 8.30 美元） |
| **汇率成本** | 跨境投资换汇的买卖价差（约 0.3%–1%） |
| **机会成本** | 最容易被忽略的成本——钱套在烂股票上，错过了别的机会 |

### 9.5 成本的复利效应（重要）

假设年化收益 10%，交易成本每年吃掉 1%：
- 10 年后：10 万变 **23.6 万**（无成本）vs **21.6 万**（有成本）——差 2 万。
- 20 年后：**61.2 万** vs **51.2 万**——差 10 万。
- 30 年后：**158.6 万** vs **121.0 万**——差 37.6 万。

**结论**：**降低交易频率、压低佣金、避免频繁申赎，是普通人最容易做到的"确定性收益"。**

# 第三部分 分析能力：从"看热闹"到"看门道"

## 第 10 章 看盘：K 线、均线与技术指标

### 10.1 K 线（蜡烛图）怎么读

一根 K 线记录一个周期（日/周/月/分钟）内的四个价格：

| 元素 | 含义 |
|---|---|
| **开盘价** | 周期开始的第一笔成交价 |
| **收盘价** | 周期结束的最后一笔成交价 |
| **最高价** | 周期内最高成交价 |
| **最低价** | 周期内最低成交价 |
| **实体** | 开盘价与收盘价之间的矩形 |
| **上影线** | 实体上方到最高价的细线 |
| **下影线** | 实体下方到最低价的细线 |

**颜色约定（中国市场）**：
- **红色（阳线）**：收盘价 > 开盘价，上涨。
- **绿色（阴线）**：收盘价 < 开盘价，下跌。
- ⚠️ **欧美市场相反**：绿涨红跌。看外盘图表时要注意。

**常见 K 线形态**（记住名字即可，不必迷信）：

| 形态 | 特征 | 通常被解读为 |
|---|---|---|
| 大阳线 | 实体长，几乎无影线 | 强势上涨 |
| 大阴线 | 实体长阴 | 强势下跌 |
| 十字星 | 开盘≈收盘，上下影线长 | 多空胶着，可能变盘 |
| 锤子线 | 下影线长，实体小，在低位 | 可能见底 |
| 上吊线 | 下影线长，实体小，在高位 | 可能见顶 |
| 吞没形态 | 后一根 K 线完全包住前一根 | 反转信号 |
| 早晨之星/黄昏之星 | 三根 K 线组合 | 底部/顶部反转 |

**新手提醒**：K 线形态是"概率游戏"，不是"必然规律"。单根 K 线的预测力很弱，必须结合**位置（高位/低位）、成交量、趋势**一起看。

### 10.2 均线（MA）

- **定义**：过去 N 个交易日收盘价的算术平均，逐日滚动计算。
- **常用周期**：MA5（周线）、MA10、MA20（月线）、MA60（季线）、MA120（半年线）、MA250（年线）。
- **用法**：
  - 价格在均线上方 → 趋势偏强；下方 → 偏弱。
  - 短期均线上穿长期均线 → **金叉**（看涨信号）；下穿 → **死叉**（看跌信号）。
  - 多条均线纠缠 → 震荡；发散 → 趋势。
- **缺陷**：均线是**滞后指标**，在震荡市里频繁发出假信号（"被均线反复打脸"）。

### 10.3 成交量与量价关系

| 量价组合 | 常见解读 |
|---|---|
| 价涨量增 | 健康上涨，资金认可 |
| 价涨量缩 | 上涨乏力，可能见顶 |
| 价跌量增 | 恐慌抛售，可能加速下跌 |
| 价跌量缩 | 抛压减轻，可能筑底 |
| 地量地价 | 极度萎缩，往往是底部区域的特征之一 |
| 天量天价 | 极度狂热，往往是顶部区域的特征之一 |

**成交量指标**：
- **VOL**：成交量柱状图。
- **换手率** = 成交量 / 流通股本 × 100%。一般 <1% 清淡，1%–3% 正常，3%–10% 活跃，>10% 过热。
- **量比** = 当前每分钟均量 / 过去 5 日每分钟均量。

### 10.4 常用技术指标

| 指标 | 全称 | 用途 | 新手是否该用 |
|---|---|---|---|
| **MACD** | 指数平滑异同移动平均线 | 判断趋势与动能，金叉死叉、顶底背离 | 了解即可 |
| **KDJ** | 随机指标 | 判断超买超卖（>80 超买，<20 超卖） | 了解即可 |
| **RSI** | 相对强弱指标 | 超买超卖（>70 / <30） | 了解即可 |
| **BOLL** | 布林带 | 价格通道，判断波动区间 | 了解即可 |
| **OBV** | 能量潮 | 量价配合 | 少用 |
| **DMI** | 趋向指标 | 判断趋势强度 | 少用 |

**核心观点**：**技术指标是对价格和成交量的二次加工，不产生新信息。** 新手最容易被"指标组合""神奇公式"收割。建议：**理解 2–3 个（均线、成交量、MACD）即可，不要沉迷。**

### 10.5 分时图与盘口异动

- **分时图**：当日每分钟价格连线 + 均价线（黄线）。
  - 白线在黄线上方且同步上行 → 强势。
  - 白线快速拉升但黄线跟不上 → 可能是脉冲式拉高，警惕。
- **集合竞价异动**：9:20 之后的撤单受限，此时的挂单更能反映真实意图。
- **尾盘异动**：14:57–15:00 收盘集合竞价的成交，往往反映主力意图（"尾盘拉升/砸盘"）。
- **龙虎榜**：交易所公布的异动股票买卖前五名营业部，可观察游资/机构动向（但滞后一天）。

### 10.6 常用行情软件与数据源

| 类型 | 代表 | 特点 |
|---|---|---|
| 免费行情 | 同花顺、东方财富、雪球、腾讯自选股 | 日常够用 |
| 券商 App | 华泰涨乐财富通、中信信 e 投、国君君弘等 | 交易必备 |
| 专业终端 | Wind、Choice、iFinD | 机构/研究员用，年费数万元 |
| 官方数据 | 上交所/深交所/北交所官网、中国结算、证监会 | 最权威，免费 |
| 财报原文 | 巨潮资讯网（cninfo） | 上市公司公告指定披露平台 |
| 宏观数据 | 国家统计局、中国人民银行、海关总署 | 判断大环境 |

### 10.7 技术分析的形态与理论（了解即可，不必当真理）

#### （1）趋势线与支撑压力

- **趋势线**：连接两个以上的低点（上升趋势）或高点（下降趋势）画出的直线。被触及的次数越多越有效。
- **支撑位**：价格跌到这里买盘集中、容易止跌的位置（前期低点、密集成交区、重要均线、整数关口）。
- **压力位（阻力位）**：价格涨到这里卖盘集中、容易受阻回落的位置（前期高点、密集成交区、套牢盘区）。
- **关键原则**：**支撑跌破后往往变成压力，压力突破后往往变成支撑**。
- **重要提醒**：支撑和压力是**区间**，不是精确的点。不要指望"跌到 10.00 元一定反弹"。

#### （2）常见形态

| 形态 | 特征 | 通常被解读为 |
|---|---|---|
| **头肩顶** | 三个高点，中间最高（头），两侧较低且大致对称（肩） | 顶部反转，跌破"颈线"确认 |
| **头肩底** | 三个低点，中间最低 | 底部反转 |
| **双顶（M 头）** | 两次冲高到相近位置均失败 | 见顶信号 |
| **双底（W 底）** | 两次探底到相近位置均获得支撑 | 见底信号 |
| **三角形整理** | 高点逐步降低、低点逐步抬高，振幅收敛 | 方向选择前的蓄势，突破方向决定后市 |
| **旗形/矩形** | 快速涨跌后进入窄幅横盘 | 中继形态，多半延续原趋势 |
| **缺口（Gap）** | 相邻两根 K 线之间出现没有成交的价格区间 | 突破缺口（有力）/ 持续缺口 / 衰竭缺口（力竭） |
| **岛形反转** | 缺口 + 横盘 + 反向缺口，像一座孤岛 | 强反转信号 |

#### （3）几大经典理论（当历史知识了解）

- **道氏理论（Dow Theory）**：技术分析鼻祖。核心观点——市场趋势分主要趋势（数月到数年）、次要趋势（数周到数月）、短暂波动；**趋势会持续到出现明确的反转信号**；成交量必须验证趋势；收盘价最重要。
- **波浪理论（Elliott Wave）**：价格按"5 浪上涨 + 3 浪下跌"的循环演进。**主观性极强**——同一张图十个人能数出十种浪型，事后解释力强、事前预测力弱。
- **江恩理论（Gann Theory）**：用时间周期、角度线、几何比例预测价格与转折点。神秘色彩重，缺乏严格统计验证。
- **缠论（中国本土）**：用"笔 → 线段 → 中枢"的结构化解构走势。学习成本极高，且**难以证伪**，新手不建议投入时间。

#### （4）一句忠告

技术分析能帮你**理解市场情绪和交易节奏**，但**不能预测未来**。所有"必胜形态""神奇指标"都是事后挑选出来的幸存者。对新手来说，把时间花在理解公司上，回报率远高于研究 K 线组合。

## 第 11 章 基本面分析：读懂一家公司

### 11.1 三大财务报表

#### （1）资产负债表（Balance Sheet）

**恒等式：资产 = 负债 + 所有者权益**

| 项目 | 含义 | 新手关注点 |
|---|---|---|
| **流动资产** | 现金、应收账款、存货等一年内可变现的资产 | 货币资金是否充裕；应收账款是否暴涨（可能虚增收入） |
| **非流动资产** | 固定资产、在建工程、无形资产、商誉 | **商誉**过高有减值风险（并购后遗症） |
| **流动负债** | 短期借款、应付账款等一年内要还的 | 短期借款 vs 货币资金，看偿债压力 |
| **非流动负债** | 长期借款、应付债券 | 有息负债规模与利率 |
| **所有者权益** | 股本、资本公积、未分配利润等 | 净资产是"家底" |

**关键指标**：
- **资产负债率** = 总负债 / 总资产。制造业一般 <60% 较健康，房地产/金融另论。
- **流动比率** = 流动资产 / 流动负债，>2 较安全，<1 有短期偿债压力。
- **速动比率** = (流动资产 − 存货) / 流动负债，>1 较好。
- **净资产（股东权益）** 为负 → 资不抵债，退市风险。

#### （2）利润表（Income Statement）

**核心逻辑：收入 − 成本费用 = 利润**

| 项目 | 含义 |
|---|---|
| **营业收入** | 卖产品/服务收到的钱（不含增值税） |
| **营业成本** | 直接成本（原材料、人工、制造费用） |
| **毛利** = 营业收入 − 营业成本 | 产品竞争力 |
| **毛利率** = 毛利 / 营业收入 | 越高越有定价权 |
| **期间费用** | 销售费用、管理费用、研发费用、财务费用 |
| **营业利润** | 主业+投资等综合经营成果 |
| **利润总额** | 营业利润 + 营业外收支 |
| **净利润** | 利润总额 − 所得税 |
| **归母净利润** | 净利润中属于母公司股东的部分（**看这个，不是净利润**） |
| **扣非净利润** | 扣除政府补贴、资产处置等非经常性损益后的净利润（**最能反映主业**） |

**关键指标**：
- **净利率** = 净利润 / 营业收入。
- **ROE（净资产收益率）** = 归母净利润 / 平均净资产。**巴菲特最看重的指标**，长期 >15% 属优秀。
- **ROA** = 净利润 / 总资产，衡量资产使用效率。
- **EPS（每股收益）** = 归母净利润 / 总股本。
- **三费费率** = (销售+管理+财务费用) / 营业收入，反映管理效率。

#### （3）现金流量表（Cash Flow Statement）

**核心逻辑：利润是观点，现金是事实。**

| 项目 | 含义 | 健康状态 |
|---|---|---|
| **经营活动现金流净额** | 主业实际收到的现金 | **正数且 ≥ 净利润**（利润含金量高） |
| **投资活动现金流净额** | 买设备、投资、并购等 | 扩张期为负正常 |
| **筹资活动现金流净额** | 借款、发股、分红、回购 | 视阶段而定 |
| **现金及现金等价物净增加额** | 三者之和 | 不应长期为负 |

**关键比值**：
- **净现比** = 经营活动现金流净额 / 净利润。长期 <1 说明"赚的是纸面利润"（应收账款堆积）。
- **自由现金流（FCF）** = 经营活动现金流 − 资本开支。**企业真正能自由支配的钱**，是 DCF 估值的基础。

### 11.2 财务分析的核心方法

#### （1）三张表的勾稽关系

```
净利润（利润表） → 影响未分配利润（资产负债表）
经营活动现金流（现金流量表） ← 净利润 ± 营运资本变动 ± 非现金项目
现金净增加（现金流量表） → 影响货币资金（资产负债表）
```

**新手技巧**：看财报先看"三张表能不能对上"，尤其是**净利润与经营现金流的背离**——这是财务造假最常见的破绽。

#### （2）杜邦分析（ROE 拆解）

```
ROE = 净利率 × 总资产周转率 × 权益乘数
    = (净利润/营收) × (营收/总资产) × (总资产/净资产)
```

三种赚钱模式：
- **高净利率**：茅台型（品牌溢价）。
- **高周转率**：沃尔玛型（薄利多销）。
- **高杠杆**：银行/地产型（借钱生钱，风险也高）。

#### （3）同行业对比与历史对比

- **纵向**：和自己过去 5–10 年比，看趋势（毛利率是否下滑？应收是否变差？）。
- **横向**：和同行比，看竞争力（为什么它毛利率比别人高 10 个点？可持续吗？）。
- **只看一年数据是没用的**，至少看 3–5 年。

### 11.3 财务造假的常见信号（新手防雷清单）

| 信号 | 说明 |
|---|---|
| 净利润高但经营现金流长期为负 | 赚的是"白条" |
| 应收账款增速远超营收增速 | 可能提前确认收入或虚构销售 |
| 存货异常增长 | 可能滞销或虚构存货 |
| 毛利率显著高于同行且无法解释 | 可能有猫腻 |
| 商誉占净资产比例过高 | 减值地雷 |
| 大股东高比例质押 | 股价下跌易爆仓 |
| 频繁更换审计机构 | 危险信号 |
| 审计意见为"保留意见""无法表示意见" | **直接回避** |
| 关联交易占比高 | 可能利益输送 |
| 一边高额分红一边大额融资 | 逻辑矛盾 |

### 11.4 行业分析框架

#### （1）行业生命周期

```
导入期 → 成长期 → 成熟期 → 衰退期
（高风险）（高增长）（稳现金流）（低估值陷阱）
```

#### （2）波特五力模型

1. **现有竞争者**的激烈程度；
2. **新进入者**的威胁（壁垒高低）；
3. **替代品**的威胁；
4. **上游供应商**的议价能力；
5. **下游客户**的议价能力。

#### （3）商业模式三问

- **它卖什么？**（产品/服务）
- **卖给谁？**（客户结构，是否依赖单一大客户）
- **凭什么持续赚钱？**（护城河：品牌、专利、网络效应、成本优势、牌照、转换成本）

#### （4）护城河（Moat）的五种来源

| 类型 | 例子 |
|---|---|
| 无形资产（品牌/专利/牌照） | 茅台、片仔癀、银行牌照 |
| 转换成本 | 企业软件（用惯了难换）、微信 |
| 网络效应 | 淘宝、微信、滴滴 |
| 成本优势 | 规模效应、独特资源、区位优势 |
| 有效规模 | 细分市场容量小，只容得下一两家 |

### 11.5 公司治理与"人"的因素

- **股权结构**：一股独大 vs 分散；是否有实控人；国资/民企/外资。
- **管理层**：履历、持股、薪酬、历史承诺兑现情况。
- **关联交易与资金占用**：大股东是否把上市公司当"提款机"。
- **分红历史**：长期稳定分红说明现金流真实、愿意回报股东。
- **减持与质押**：大股东频繁减持/高质押是负面信号。
- **ESG**：环境、社会、治理，长期资金越来越看重。

## 第 12 章 估值：贵还是便宜

### 12.1 常用估值指标

| 指标 | 公式 | 适用 | 解读 |
|---|---|---|---|
| **PE（市盈率）** | 股价 / EPS = 总市值 / 归母净利润 | 盈利稳定的成熟企业 | 越低越便宜（但要和同行/历史比） |
| **PE-TTM** | 股价 / 最近四个季度 EPS | 同上 | 比静态 PE 更及时 |
| **PB（市净率）** | 股价 / 每股净资产 = 总市值 / 净资产 | 银行、地产、周期股 | <1 可能"破净"，但不一定便宜 |
| **PS（市销率）** | 总市值 / 营业收入 | 亏损但高增长的企业（如 SaaS、创新药） | 需结合毛利率看 |
| **PEG** | PE / 净利润增速 | 成长股 | <1 通常认为低估（彼得·林奇） |
| **EV/EBITDA** | 企业价值 / 息税折旧摊销前利润 | 重资产、跨国比较 | 剔除资本结构与折旧影响 |
| **股息率** | 每股分红 / 股价 | 高分红蓝筹 | 与国债收益率比较 |
| **DCF（现金流折现）** | 未来自由现金流折现之和 | 所有能预测现金流的资产 | 理论上最严谨，实务中假设敏感 |

### 12.2 估值的三种视角

#### （1）绝对估值：DCF

```
企业价值 = Σ [FCF_t / (1+r)^t] + 终值/(1+r)^n
```

- **r**：折现率（通常用 WACC，8%–12%）。
- **终值**：通常用永续增长模型（g 取 2%–3%）。
- **问题**：对假设极度敏感。r 从 10% 变 9%，估值可能差 20%+。
- **新手用法**：理解思想即可——**今天的钱比明天的钱值钱；公司的价值等于它未来能产生的所有现金的现值。**

#### （2）相对估值：可比公司/历史分位

- **横向**：和同行比 PE/PB（如茅台 vs 五粮液）。
- **纵向**：看自己过去 5–10 年 PE 的分位数（当前 PE 处于历史 20% 分位 = 相对便宜）。
- **陷阱**：整个行业泡沫时，"同行都贵"不代表不贵。

#### （3）资产视角：清算价值/重置成本

- **PB < 1**：市值低于净资产，可能是"烟蒂股"（格雷厄姆式投资），也可能是资产质量差（如地产存货虚高）。
- **NAV**：房地产、资源类公司常用重估净资产。

### 12.3 估值的常见误区

| 误区 | 真相 |
|---|---|
| "PE 低就是便宜" | 可能是周期顶部（盈利即将下滑）或商业模式衰退 |
| "PE 高就是贵" | 高成长公司 PE 天然高，要看 PEG |
| "破净就是安全" | 资产可能是"纸面资产"（应收账款、存货减值） |
| "用 PE 估银行" | 银行要用 PB + ROE，因为利润受拨备调节 |
| "用 PE 估周期股" | 周期股要在 PE 高时买（盈利低谷）、PE 低时卖（盈利高峰） |
| "估值能精确到小数点" | 估值是区间思维，宁要模糊的正确，不要精确的错误 |

### 12.4 市场整体估值：判断"牛熊位置"

| 指标 | 含义 | 用法 |
|---|---|---|
| **全 A 市盈率中位数** | 全部 A 股 PE 中位数 | 历史分位判断市场冷热 |
| **股债性价比（ERP）** | 沪深 300 盈利收益率 − 10 年国债收益率 | 差值越高，股票相对债券越有吸引力 |
| **破净股比例** | 破净公司数 / 全部公司数 | 比例极高往往是底部特征 |
| **新开户数/基金发行量** | 散户入场热度 | 极度火热往往是顶部特征 |
| **两市成交额** | 市场活跃度 | 地量见地价，天量见天价 |
| **巴菲特指标** | 总市值 / GDP | 100% 左右合理，过高警惕 |

## 第 13 章 风险管理：活下去比赚得快重要

### 13.1 风险的种类

| 风险类型 | 含义 | 例子 |
|---|---|---|
| **系统性风险** | 影响整个市场，无法通过分散消除 | 金融危机、疫情、加息、战争 |
| **非系统性风险** | 个股/行业特有，可通过分散降低 | 业绩暴雷、造假、行业政策 |
| **流动性风险** | 想卖卖不掉或只能贱卖 | 小盘股、停牌、跌停板 |
| **信用风险** | 对手方违约 | 债券违约、券商挪用 |
| **操作风险** | 自己搞错 | 下错单、密码泄露、追涨杀跌 |
| **杠杆风险** | 借钱放大亏损 | 两融爆仓、场外配资 |
| **政策风险** | 监管政策变化 | 教培"双减"、平台反垄断 |
| **汇率风险** | 跨境投资的汇率波动 | 人民币升值吃掉美股收益 |
| **通胀风险** | 购买力下降 | 现金长期贬值 |

### 13.2 波动率与最大回撤

- **波动率（Volatility）**：收益率的标准差，衡量价格波动幅度。A 股个股年化波动率常在 30%–50%。
- **最大回撤（Max Drawdown）**：从历史最高点到最低点的跌幅。**这是最贴近真实体验的风险指标**——你能不能扛住 50% 的浮亏不割肉？
- **夏普比率** = (收益 − 无风险利率) / 波动率，衡量"每承担一单位风险换来多少超额收益"，>1 较好。
- **卡玛比率** = 年化收益 / 最大回撤。

**关键认知**：
- 跌 50% 后要涨 100% 才回本。
- 跌 30% 后要涨 43% 才回本。
- 跌 20% 后要涨 25% 才回本。
- **亏损的数学不对称性，是仓位管理最重要的理由。**

### 13.3 仓位管理与资金管理

#### （1）仓位（Position Sizing）

| 概念 | 说明 |
|---|---|
| **总仓位** | 股票市值 / 总资产。新手建议不超过 30%–50% 的可投资产 |
| **单只个股上限** | 不超过总仓位的 10%–20%（避免单票黑天鹅） |
| **行业集中度** | 单一行业不超过 30% |
| **金字塔加仓** | 越涨越加，仓位越重成本越高（风险大） |
| **倒金字塔减仓** | 越涨越卖，锁定利润 |

#### （2）止损与止盈

| 方式 | 说明 | 优缺点 |
|---|---|---|
| **固定比例止损** | 亏 8%–10% 无条件卖出 | 简单，但可能被"洗"出去 |
| **技术位止损** | 跌破关键支撑位卖出 | 更贴合走势，需判断 |
| **基本面止损** | 买入逻辑破坏就卖（如业绩变脸） | 最根本，但反应慢 |
| **时间止损** | 持有一段时间没按预期走就卖 | 提高资金效率 |
| **移动止盈** | 从最高点回撤 X% 就卖 | 保住利润 |
| **目标价止盈** | 到达估值目标就卖 | 可能卖早 |

**新手最容易犯的错：截断利润、让亏损奔跑**（赚钱就跑，亏钱死扛）。正确做法相反：**让利润奔跑，快速认错。**

#### （3）凯利公式与"不要 all in"

- 凯利公式：`f = (bp − q) / b`（f 下注比例，b 赔率，p 胜率，q = 1−p）。
- 实务中常用**半凯利**甚至更保守，因为我们对胜率的估计往往过于乐观。
- **永远不要用影响生活的钱炒股**（学费、房租、看病钱）。

### 13.4 分散化与相关性

- **分散化（Diversification）**：持有相关性低的资产，降低组合波动。
- **有效分散**：不同行业、不同市值、不同市场（A 股/港股/美股）、不同资产（股/债/黄金/现金）。
- **伪分散**：买 10 只白酒股 = 只买了 1 个行业；买 10 只科技主题基金 = 高度重叠。
- **相关性**：股灾时"所有资产同跌"（相关性趋近 1），这是分散化失效的时刻——所以要留**现金**和**真正负相关**的资产（如国债、黄金）。

### 13.5 心理陷阱（行为金融学）

| 偏差 | 表现 | 对策 |
|---|---|---|
| **损失厌恶** | 亏钱的痛苦是赚钱快乐的 2 倍，导致死扛 | 预设止损，机械执行 |
| **锚定效应** | 死盯买入价，"回本就走" | 只看未来价值，不看成本 |
| **确认偏误** | 只看支持自己观点的信息 | 主动找反方观点 |
| **过度自信** | 赚几次就觉得自己是天才 | 记录每笔交易的胜率 |
| **从众心理** | 追涨杀跌，听消息炒股 | 建立自己的决策清单 |
| **处置效应** | 赚一点就跑，亏了死拿 | 让利润奔跑 |
| **后见之明** | "我早就知道会涨" | 写投资日记，校验预测 |
| **心理账户** | 把赚来的钱当"白来的"乱花 | 所有钱一视同仁 |
| **沉没成本** | 因为已经亏了所以不肯卖 | 只看未来现金流 |
| **FOMO** | 怕错过，追高买入 | 错过不亏钱，买错才亏钱 |

### 13.6 杠杆：新手的第一杀手

- **杠杆倍数 = 总资产 / 自有资金**。2 倍杠杆下，标的跌 50% 你就归零。
- **两融爆仓机制**：维持担保比例低于 130% 会被通知补仓，不补则强制平仓（通常还来不及反应）。
- **场外配资违法**：不受监管，跑路、虚拟盘、强平纠纷频发。
- **结论**：**新手绝对不要用杠杆。** 用闲钱、用自有资金、慢慢变富。

### 13.7 黑天鹅与尾部风险

- **黑天鹅**：低概率、高影响、事后可解释的事件（如 2020 年疫情、2022 年俄乌冲突）。
- **应对**：
  - 不用杠杆（避免被迫离场）；
  - 保留现金（危机时是期权）；
  - 分散（但知道分散在极端时刻会失效）；
  - 长期视角（时间是优质资产的盟友）。

# 第四部分 术语总表：股票概念全字典

> 本部分按"主题 + 拼音/字母"编排，可作为随时查阅的字典。每个词条给出**一句话定义 + 关键提示**。

## 第 14 章 基础概念术语（A–Z）

### A

**A 股**
人民币普通股票，境内公司发行、在境内交易所上市、以人民币认购和交易的股票。代码 6 位：沪市 600/601/603/605、深市 000/001/002/003、创业板 300/301、科创板 688/689、北交所 920/83/87/88 开头。

**ADR（美国存托凭证）**
American Depositary Receipt，美国银行发行的、代表外国公司股票的凭证。中概股多以 ADR 在美上市（如 BABA、JD、PDD）。ADR 与普通股可按比例转换。

**AH 股**
同一家公司在 A 股和 H 股同时上市的股票。因两地投资者结构、流动性、汇率不同，**同一家公司 A 股和 H 股价格常有差异**（AH 溢价/折价）。

**安全边际（Margin of Safety）**
格雷厄姆提出的核心概念：**买入价格显著低于估算的内在价值**，为估值错误和意外事件留出缓冲。安全边际越大，亏损概率越低。

**暗盘**
新股上市前一天的场外交易市场（香港等地有此制度），反映市场对新股的预期。A 股无暗盘。

**阿尔法（Alpha）**
投资组合中**与市场无关的超额收益**。α > 0 说明跑赢了基准，α < 0 说明跑输。基金业绩归因里常说"赚的是 α 还是 β"——**β 是市场给的钱，α 是管理能力赚的钱**。

### B

**B 股**
人民币特种股票，以外币（沪市美元、深市港币）计价交易，面向境外投资者（2001 年后境内个人也可用外汇买卖）。已边缘化，多数公司通过 B 转 H、回购等方式退出。

**白马股**
长期业绩优良、信息透明、分红稳定的知名公司股票。特点是**确定性高、估值通常不便宜**。与"黑马股"相对。

**板（Board）**
股票市场的分层板块，如主板、创业板、科创板、北交所。不同板块的定位、上市标准、交易规则不同。

**保证金（Margin）**
融资融券中投资者需自有的资金比例。融资保证金比例 80% 意味着买 100 元股票自有资金至少 80 元。

**报单（Order）**
投资者向券商发出的买卖指令，含证券代码、方向、价格、数量。

**备兑开仓**
持有标的股票的同时卖出认购期权，用股票覆盖履约义务，赚取权利金。

**逼空（Short Squeeze）**
做空者被迫买入平仓，推动股价进一步上涨，形成"空头踩踏"。经典案例：2021 年 GameStop（GME）。

**标的（Underlying）**
衍生品合约所对应的基础资产（股票、指数、商品等）。

**波动率（Volatility）**
收益率的标准差，衡量价格波动幅度。年化波动率 30% 表示"大多数时候一年内价格波动幅度在 ±30% 左右"。

**补仓（Averaging Down）**
在已有持仓亏损时继续买入，摊低平均成本。**双刃剑**：判断对了是"越跌越买"，判断错了是"越陷越深"。

**不可撤销委托**
一经报出不能撤单的委托。如 A 股 9:20–9:25 集合竞价期间的委托。

**贝塔（Beta）**
衡量个股或组合**相对大盘的波动敏感度**。β = 1 表示与大盘同涨同跌；β > 1 表示涨跌都被放大（如券商、有色）；β < 1 表示更抗跌（如公用事业）。**β 衡量系统性风险，α 衡量超额能力。**

### C

**财务造假**
通过虚构收入、隐瞒负债、关联交易非关联化等手段粉饰报表。识别信号见第 11.3 节。

**仓位（Position）**
持有的股票市值占总投资资金的比例。空仓（0%）、半仓（50%）、满仓（100%）。

**场外市场（OTC）**
交易所之外的交易市场，如新三板、区域性股权市场、券商柜台市场。

**拆股（Stock Split）**
把一股拆成多股，股价同比例下降。**不改变股东权益**，只是降低单股价格、提高流动性。A 股较少见，美股常见（如苹果多次拆股）。

**长线投资**
持有周期以年计的投资方式，追求企业成长与复利，弱化短期波动。

**抄底**
在股价下跌过程中买入，预期见底。**新手最危险的动作之一**——"底部"往往是事后才知道的。

**成本价（Cost Basis）**
买入股票的平均成本，含手续费。注意：**成本价只影响你的心理，不影响股票未来涨跌**。

**成交量（Volume）**
一定时间内成交的股票数量（股/手）。A 股行情软件常以"手"为单位（1 手 = 100 股）。

**成交额（Turnover Value）**
一定时间内成交的金额（元）。

**成长股（Growth Stock）**
营收/利润增速显著高于行业平均的公司股票。特点是**估值高、波动大**，看重未来。

**除权（Ex-Rights）**
送股、转增、配股后，股价按比例下调。除权后 K 线会出现"跳空缺口"，需用"前复权"查看真实走势。

**除息（Ex-Dividend）**
现金分红后，股价按分红金额下调。

**存托凭证（DR）**
Depositary Receipt，在境外代表境内股票的凭证。中国有 CDR（如科创板存托凭证）。

**筹码**
市场上可以流通的股票份额。"**筹码集中**"指少数账户持有大量流通股、抛压小、容易拉升；"筹码分散"则相反。行情软件的"筹码分布图"显示不同价位上的持仓成本，用来判断上方套牢盘和下方获利盘的密集区。

**次新股**
上市时间较短的股票（口语一般指上市 1 年内，无严格定义）。特点：**流通盘小、没有历史套牢盘、股性活跃、容易被炒作**；但首发限售股解禁时往往面临集中抛压。

### D

**大盘（Broad Market）**
指整个市场的整体表现，常用上证指数、沪深 300 等衡量。"大盘涨"通常指指数涨。

**大宗交易**
达到规定最低限额的买卖双方场外协商、交易所确认的批量交易，通常有折价。

**戴维斯双击/双杀**
双击：**盈利增长 + 估值提升**同时发生，股价暴涨。双杀：盈利下滑 + 估值下杀，股价暴跌。

**道氏理论（Dow Theory）**
技术分析鼻祖，核心观点：市场以趋势运行（主要/次要/短暂趋势），趋势会持续直到明确反转信号。

**低估值陷阱（Value Trap）**
看起来便宜（低 PE/PB）但基本面持续恶化的股票，买进去长期不涨甚至继续跌。

**跌停板**
当日价格跌幅达到下限。A 股主板 −10%，创业板/科创板 −20%，北交所 −30%；ST 股在主板为 −5%，创业板/科创板的 ST 股仍为 −20%。

**定向增发（定增）**
向不超过 35 名特定投资者非公开发行股票，通常折价发行、有锁定期。**定增价格往往被视为"机构成本线"**。

**动量效应（Momentum）**
过去涨得好的股票短期倾向于继续涨，过去跌得差的倾向于继续跌。量化策略的重要因子。

**对冲（Hedge）**
通过建立相反方向的头寸降低风险。如持有股票同时买入认沽期权。

**多头（Bull / Long）**
看涨的一方，或持有买入头寸。

### E

**二级市场**
已发行股票的流通交易市场，即交易所。投资者之间互相买卖，钱不进公司。

**ETF（交易型开放式指数基金）**
Exchange Traded Fund，在交易所上市交易的指数基金，可像股票一样买卖，也可申赎。**新手最推荐的投资工具之一**：费率低、分散、透明。

**ETF 联接基金**
场外基金，把钱投到对应 ETF，方便没有证券账户的投资者。

### F

**发行价**
IPO 时确定的股票发售价格。与上市首日开盘价的差额就是"打新收益"来源。

**分红（Dividend）**
公司把部分利润以现金或股票形式分配给股东。现金分红叫"派息"，股票分红叫"送股"。

**分拆（Spin-off）**
把子公司独立出去上市，母公司与子公司分别定价。

**风险敞口（Exposure）**
投资组合对某类风险的暴露程度。如"高杠杆敞口""单一行业敞口"。

**浮亏/浮盈**
持仓尚未卖出时的账面亏损/盈利。**只有卖出才兑现**，但浮亏也是真实的经济损失。

**复利（Compound Interest）**
利滚利。年化 10%，7.2 年翻倍（72 法则）。**复利是长期投资最大的武器，也是交易成本最大的敌人。**

**复权（Adjustment）**
把分红送股造成的价格跳空修复，使 K 线连续。**前复权**（以最新价为基准向前调整，最常用）、**后复权**（以上市价为基准向后调整）。

**分级基金**
把一只基金拆成 A、B 两类份额：A 拿约定收益（类债券），B 借 A 的钱加杠杆承担剩余盈亏。**2018 年资管新规要求整改，2020 年底已全部转型或清盘，A 股目前不存在分级基金**，只需作为历史名词了解。

**封闭式基金**
份额固定、成立后封闭运作（通常 5 年以上）的基金。封闭期内**不能申购赎回，只能在交易所像股票一样买卖**，因此交易价格常出现折价或溢价。

**防御股（Defensive Stock）**
需求刚性强、业绩受经济周期影响小的公司股票，如公用事业、食品饮料、医药商业。特点是**熊市相对抗跌、牛市弹性偏小**。与"周期股"相对。

### G

**杠杆（Leverage）**
借入资金放大投资规模。2 倍杠杆 = 自有 1 元操作 2 元。放大收益的同时放大亏损。

**港股通**
内地投资者通过沪深交易所买卖港股的机制，需 50 万元资产门槛。

**个股期权**
以单只股票为标的的期权，A 股目前仅有个别 ETF 期权和股指期权，个股期权尚未全面推出。

**公募基金**
向不特定公众募集、信息披露透明的基金，受证监会监管。

**股东（Shareholder）**
持有公司股份的人。A 股股东权利见第 1.3 节。

**股东大会**
公司最高权力机构，决定重大事项。分为年度股东大会和临时股东大会。

**股本（Share Capital）**
公司发行在外的股份总数。**总股本**（全部股份）、**流通股本**（可自由交易的股份）、**限售股本**（有锁定期）。

**股息率（Dividend Yield）**
每股分红 / 股价。与存款利率、国债收益率对比判断吸引力。

**估值（Valuation）**
对资产内在价值的估算。方法见第 12 章。

**股票回购（Buyback）**
公司用自有资金在二级市场买回自己的股票，可注销（提升每股价值）或用于股权激励。

**股权登记日**
分红、配股、股东大会表决时，登记在册的股东享有相应权利的截止日。**在登记日收盘时持有股票才算数**。

**除权除息日**
股权登记日的下一个交易日，当天买入不再享有分红/配股权利。

**关键审计事项（KAM）**
审计报告中披露的重点审计领域，是发现财务风险的重要线索。

**光头光脚（Marubozu）**
没有上下影线的大阳线或大阴线，表示单边强势。见第 10.1 节。

**国家队**
指证金公司、汇金公司、社保基金等具有稳定市场职责的国有资金。

**股权质押**
股东把自己持有的股票质押给银行/券商融资，**不转移所有权但会锁定股份**。质押比例过高、股价大幅下跌时可能触及平仓线被强制卖出，是典型的"爆雷"风险点（详见第 5.8 节）。

### H

**H 股**
内地注册公司在香港上市的股票，以港币计价。

**红筹股**
境外注册、主要业务在内地的公司在香港上市的股票。

**护城河（Moat）**
企业可持续的竞争优势，见第 11.4 节。

**换手率（Turnover Rate）**
成交量 / 流通股本 × 100%，衡量交易活跃度。

**回购（Repurchase）**
公司用自有资金或借款在二级市场买回自己的股份，可注销（减少总股本、提升每股收益）或用于员工持股/股权激励。**回购注销是比现金分红更省税的回报股东方式**。

**沪股通**
沪港通中境外资金经香港买卖上交所股票的通道，与深股通合称"陆股通"（北向资金）。

**回调（Pullback）**
上涨趋势中的**短期下跌**，幅度通常在 10%–20% 以内，不改变原有趋势。与之相对的是"**反转**"（趋势本身改变）。新手最常见的亏损来源之一：把回调当反转割肉，把反转当回调抄底。区分办法是看**基本面逻辑有没有变**。

**货币基金**
投资短期国债、银行存款、同业存单等短期工具的基金，**风险极低、流动性好**（多为 T+0/T+1 赎回），收益接近无风险利率。余额宝的本质就是货币基金。适合放短期要用的钱。

**混合基金**
同时投资股票和债券的基金，股票仓位区间由基金合同约定（如 0–95%、30–80%、60–95%）。风险收益介于股票基金和债券基金之间，**仓位区间是挑选混合基金时最该看的一项**。

**合同负债**
新收入准则下的科目：公司**已收或应收客户对价、但尚未向客户转让商品**的部分（旧准则对应"预收账款"）。**合同负债增长通常预示未来收入增长**（订单已到手、钱已收到），是看财报时值得关注的前瞻指标。

### I

**IPO（首次公开发行）**
Initial Public Offering，企业第一次向公众发行股票并在交易所上市。详见第 4.2 节。

**IRR（内部收益率）**
使投资项目净现值为零的折现率，常用于评估项目或基金的历史收益水平。

### J

**基本面（Fundamentals）**
公司的经营与财务实质，包括收入、利润、资产、行业地位、管理层等。与技术面相对。

**机构投资者**
以机构名义投资的资金，如公募、私募、保险、社保、QFII。

**集合竞价**
在一段时间内集中收集委托，最后一次性撮合。A 股开盘（9:15–9:25）和收盘（14:57–15:00）采用。

**绩优股**
业绩优良、盈利能力强的公司股票。

**夹板（Box）**
股价在上下两个价位之间反复震荡的形态。

**价值股（Value Stock）**
估值低（低 PE/PB）、分红高的成熟公司股票。与成长股相对。

**减持（Reduction）**
大股东、董监高卖出所持股票。**需提前公告**，是重要负面信号（但不绝对）。

**建仓**
开始买入某只股票，建立初始仓位。

**交割（Settlement）**
交易完成后证券与资金的转移过程。

**交收（Settlement）**
同"交割"，A 股 T+1 交收、港股 T+2、美股 T+1。

**场内/场外**
场内指在交易所挂牌交易（股票、ETF、可转债）；场外指交易所之外（银行理财、场外基金、新三板）。场内流动性好、价格透明，场外反之。

**金叉/死叉**
短期均线上穿长期均线为金叉（看涨），下穿为死叉（看跌）。

**举牌**
投资者持有某上市公司股份达到 5% 时，必须在 3 日内公告，且此后每增减 5% 都需公告。**"举牌线"是重要博弈点**。

**均线（MA）**
移动平均线，见第 10.2 节。

**基金定投**
在固定时间投入固定金额买基金（如每月 1000 元）。作用是**平摊成本、弱化择时、强制储蓄**，适合工薪族和在校学生。**注意：定投的标的应是长期向上的宽基指数**；定投单只个股或强周期行业基金，可能越投越亏。

**基石投资者（Cornerstone Investor）**
**港股 IPO** 中的制度：在公开发售前承诺按发行价认购、并接受 6 个月锁定期的大型机构（主权基金、知名资管等）。作用是给发行背书、稳定上市首日股价。**A 股没有基石投资者制度，对应的是"战略配售"。**

### K

**开盘价**
交易日第一笔成交价（A 股由集合竞价产生）。

**看跌/看涨**
预期价格下跌/上涨。

**可转债（Convertible Bond）**
可转换为股票的债券，兼具债性与股性。**下有债底、上不封顶**，是"进可攻退可守"的品种，但有强制赎回条款。

**空头（Bear / Short）**
看跌的一方，或持有卖出头寸。

**恐慌指数（VIX）**
衡量标普 500 期权隐含波动率的指数，被称为"恐慌指数"。VIX 飙升通常伴随市场大跌。

**扣非净利润**
扣除政府补助、资产处置等非经常性损益后的净利润，最能反映主营业务盈利能力。

**开放式基金**
份额不固定、投资者可以随时**按当日净值申购或赎回**的基金。绝大多数公募基金（含 ETF 联接基金）都是开放式。与之相对的是封闭式基金。

### L

**蓝筹股（Blue Chip）**
规模大、业绩稳、知名度高的公司股票，如银行、白酒龙头。

**老鼠仓**
利用未公开信息先于客户/公司建仓，属于违法行为。

**利空/利多**
对股价不利/有利的消息。

**量价关系**
成交量与价格变动的配合关系，见第 10.3 节。

**零股**
不足 100 股的股票（如送股产生）。卖出时**可以一次性卖出零股**，买入必须是 100 股整数倍（科创板 200 股起）。

**流动性（Liquidity）**
资产快速变现而不显著影响价格的能力。大盘股流动性好，小盘股/停牌股流动性差。

**龙头股**
行业内市值最大、最具代表性的公司股票，往往是板块行情的风向标。

**陆股通（北向资金）**
境外资金通过香港买 A 股的通道。常被视为"聪明钱"，但其构成复杂，不宜盲目跟随。

**LOF（上市型开放式基金）**
Listed Open-Ended Fund，**既能场外按净值申购赎回、又能在交易所像股票一样买卖**的基金。因为存在"净值"和"交易价"两个价格，当两者偏离时可套利，所以 LOF 的折溢价通常很小。

### M

**买方/卖方**
买入方/卖出方。

**买入评级/卖出评级**
券商研报对股票的推荐等级（买入、增持、中性、减持、卖出）。

**每股收益（EPS）**
归母净利润 / 总股本。

**每股净资产（BPS）**
净资产 / 总股本。

**面值（Par Value）**
股票票面金额，A 股通常为 1 元。**面值退市**指股价连续 20 个交易日低于 1 元。

**明晟指数（MSCI）**
国际指数公司，其指数被全球资金跟踪。A 股纳入 MSCI 带来被动资金流入。

**牛市（Bull Market）**
市场整体持续上涨的行情，通常涨幅 >20%。

**市值管理**
上市公司通过**回购、分红、投资者关系、并购重组**等合规方式维护和提升市值的经营行为。**必须区分**：合规的市值管理是正当的公司治理；以"市值管理"为名联合资金、操纵股价则是违法的"伪市值管理"，证监会重点打击。

### N

**内幕交易**
利用未公开重大信息进行交易，违法。

**逆回购**
央行向市场投放流动性的操作；在股票账户里，"国债逆回购"是把闲钱借出去赚利息（安全、流动性好）。

**牛市/熊市**
市场整体持续上涨（涨幅通常 >20%）/ 持续下跌（跌幅通常 >20%）的行情。牛市里也有下跌的股票，熊市里也有上涨的股票，**"结构性行情"是常态**。

### O

**OTC（场外交易）**
Over-the-Counter，不在交易所集中撮合、由买卖双方协议成交的市场，如新三板、券商柜台市场、美国 OTC Markets。

**Option（期权）**
见"期权"。

### P

**盘口**
买卖五档挂单与成交明细，见第 8.2 节。

**配股**
向全体老股东按持股比例配售新股，价格通常低于市价。**不参与会被稀释**。

**破发**
新股上市首日跌破发行价。

**破净**
股价低于每股净资产（PB < 1）。

**市盈率（PE）**
股价 / 每股收益，或总市值 / 净利润。见第 12.1 节。

**市净率（PB）**
股价 / 每股净资产，或总市值 / 净资产。

**市销率（PS）**
总市值 / 营业收入。

**私募基金**
向合格投资者非公开募集的基金，门槛 100 万元起，信息披露要求低。

**平仓线**
融资融券中，维持担保比例跌破的警戒线（通常 **130%**）。跌破后券商会通知补仓（追保），不补则在下一个交易日**强制平仓**。这是杠杆最危险的地方——你往往来不及反应。

### Q

**期货（Futures）**
标准化合约，约定未来某时以某价买卖标的物。带杠杆、有到期日、可做多做空。

**期权（Options）**
赋予买方在未来以约定价格买卖标的的权利（非义务）。买方付权利金，卖方收权利金承担义务。

**权益乘数**
总资产 / 净资产，杜邦分析中的杠杆因子。

**趋势（Trend）**
价格的中长期运动方向（上升、下降、横盘）。

**全流通**
所有股份均可上市交易（股改后 A 股基本实现）。

### R

**融资（Margin Financing）**
借钱买股票。

**融券（Securities Lending）**
借股票卖出，做空。

**日 K 线**
以一个交易日为周期绘制的 K 线。

**ROE（净资产收益率）**
归母净利润 / 平均净资产，衡量股东资金的使用效率。**长期 ROE > 15% 是优秀公司的标志**。

**ROA（总资产收益率）**
净利润 / 总资产。

**融资余额**
市场（或个股）尚未偿还的融资买入金额，是衡量**杠杆资金活跃度与市场情绪**的常用指标。融资余额上升通常说明借钱做多的资金在增加；快速下降则常伴随去杠杆、被动平仓。交易所每个交易日公布沪深两市融资融券余额。

### S

**ST 股**
被实施"其他风险警示"的股票，涨跌幅限制 5%（主板），需签署风险揭示书。

**\*ST 股**
被实施"退市风险警示"的股票，有退市风险。

**散户**
以自然人身份参与市场的个人投资者，与"机构投资者"相对。A 股散户交易额占比长期在 60%–80%，是市场波动的重要来源，也是"七亏二平一赚"说法的主角。

**商誉（Goodwill）**
并购时支付的溢价超过被收购方净资产公允价值的差额。**商誉减值是大雷**。

**上证指数**
上海证券交易所综合股价指数，代码 000001，反映沪市整体走势。

**深证成指**
深交所成份股指数，代码 399001。

**沪深 300**
沪深两市 300 只大盘蓝筹股组成的指数，代码 000300，是 A 股最具代表性的宽基指数。

**市梦率**
调侃"没有盈利、只能靠梦想估值"的公司（如早期互联网、AI 概念）。**不是正式指标**。

**收益率（Return）**
投资收益 / 投入本金。

**私募（PE/VC 语境）**
向特定合格投资者非公开募集的基金，或指私募股权投资。门槛 100 万元起，信息披露要求低于公募。

**缩量**
成交量明显减少。

**锁定期（Lock-up）**
限售股/定增股的禁售期。解禁日往往带来抛压。

**折算率**
融资融券中，担保物（股票）**折算成保证金的比率**，通常在 0–70% 之间。波动大、流动性差、被风险警示的股票折算率低甚至为 0。折算率越低，同样的股票能融到的钱越少。

### T

**T+0 / T+1 / T+2**
见第 5.5 节。

**抬轿子**
为他人拉高股价的俗称，常指被套资金或庄家行为。

**套牢**
买入后股价下跌，亏损且不愿卖出。

**题材股**
因某个概念（如 AI、机器人、低空经济）而被炒作，业绩未必支撑股价。

**停牌**
股票暂停交易。原因包括重大事项、重组、异常波动核查等。

**通缩/通胀**
物价总体下降/上升。

**头寸（Position）**
持仓。

**退市**
股票终止上市，见第 4.6 节。

### U

**ETF 申购赎回清单（PCF）**
ETF 每日公布的、用于一级市场申购赎回的一篮子证券与现金清单，是套利机制的基础。

**Underlying（标的）**
见"标的"。

### V

**VIX（恐慌指数）**
芝加哥期权交易所编制的标普 500 隐含波动率指数，VIX > 30 通常代表市场恐慌，<15 代表平静。

**VIE 架构（协议控制）**
Variable Interest Entity，境外上市主体通过一系列协议控制境内运营实体的架构。中概股常用，**政策与法律风险较高**，是投资中概股必须理解的底层结构。

### W

**外盘/内盘**
以卖方报价成交为内盘（主动卖），以买方报价成交为外盘（主动买）。

**委比/委差**
衡量买卖盘力量对比的指标。

**尾盘**
交易日最后半小时（14:30–15:00）。

**无风险利率**
理论上无违约风险的收益率，常用国债收益率或银行存款利率。

**五档**
买卖各五档报价。

**微盘股**
市值极小的股票（通常指全市场市值排名后 400–500 名，多数在几十亿元以下）。特点：**流动性差、波动剧烈、量化资金抱团明显**。2024 年初的微盘股流动性踩踏就是典型风险案例——跌起来没有承接盘。

### X

**洗盘**
主力通过打压股价制造恐慌，清洗浮筹。

**系统性风险**
影响整个市场的风险（利率、汇率、战争、金融危机），无法通过分散化消除，只能靠仓位、现金和对冲来缓解。与"非系统性风险"相对。

**现金分红**
以现金形式分红。

**限售股**
有锁定期、暂不能上市流通的股份（如 IPO 前股东持股）。

**小盘股**
市值较小的公司股票，通常 <100 亿元，波动大、流动性差。

**新股（IPO）**
首次公开发行的股票。

**熊市（Bear Market）**
市场整体持续下跌的行情，通常跌幅 >20%。

**非系统性风险**
个股或行业特有的风险（业绩暴雷、财务造假、单一客户流失、行业政策突变），可通过分散投资降低。理论上，持有 10–20 只不同行业的股票可消除大部分非系统性风险。

**仙股**
股价极低的股票（香港通常指 1 港元以下；A 股口语指 1–2 元以下）。多出现在长期亏损、股本被极度稀释的公司。**A 股有面值退市规则：连续 20 个交易日收盘价低于 1 元即终止上市**，所以低价不等于便宜。

### Y

**一级市场**
发行市场，见第 4 章。

**溢价/折价**
价格高于/低于参照价值。如 AH 溢价、定增折价、大宗交易折价。

**印花税**
证券交易税，A 股现行卖出单边 0.05%，见第 9.2 节。

**盈利预告**
上市公司在定期报告前披露的业绩预计，分"预增、预减、扭亏、首亏"等。

**游资**
短线投机资金，常炒作题材股，手法凶悍。

**有效市场假说（EMH）**
Fama 提出：弱式（价格反映历史信息）、半强式（反映公开信息）、强式（反映所有信息）。**A 股远未达到强式有效**，这是主动投资存在空间的原因。

**右侧交易**
等趋势确立后再买入（追涨），胜率较高但成本高。与"左侧交易"（抄底）相对。

**压力位（阻力位）**
价格上涨到某一区域时**卖压集中、容易受阻回落**的位置（前期高点、密集成交区、重要均线、整数关口）。与"支撑位"相对。支撑与压力是**区间**而非精确的点，且**压力被有效突破后往往转为支撑**。

**妖股**
短期涨幅惊人、走势完全脱离基本面的股票，通常由游资接力炒作。特点是**涨得莫名其妙、跌起来毫不留情**（连续跌停、无法卖出）。新手在妖股上亏的钱，往往比在正常股票上多得多。

**预收账款**
旧收入准则科目：公司**先收钱、后发货**形成的负债。2020 年新收入准则实施后，大部分已改列"合同负债"。看财报时两者可合并理解——**增长代表订单充足、产品抢手**（如高端白酒）。

### Z

**债券基金**
主要投资国债、金融债、企业债的基金，风险收益低于股票基金。**注意：债基也会亏**——利率上行时债券价格下跌（久期越长跌得越多），持仓债券违约时更会直接损失本金。

**账面价值（Book Value）**
会计账簿上记录的资产或净资产价值。对股东而言即**净资产 = 总资产 − 总负债**。它与"内在价值""市场价值"是三回事：土地按 20 年前成本入账、专利按 0 计价，都会让账面价值严重偏离真实价值。

**支撑位**
价格下跌到某一区域时**买盘集中、容易止跌反弹**的位置（前期低点、密集成交区、重要均线、整数关口）。跌破后往往转为压力位。判断支撑要看**成交量是否萎缩**（抛压是否枯竭）。

**止损**
亏损达到预设幅度时卖出，控制风险。

**止盈**
盈利达到目标时卖出，锁定收益。

**指数（Index）**
反映一篮子股票整体走势的统计指标。

**中证 500 / 中证 1000**
中盘/小盘股指数，代码 000905 / 000852。

**周期性行业**
业绩随经济周期大幅波动的行业（如钢铁、煤炭、航运、地产）。

**注册制**
以信息披露为核心、不对企业投资价值做实质判断的发行制度。2023 年 A 股全面实施。

**庄家**
能够影响股价的大资金（现代监管下已难以为所欲为，但仍存在）。

**资本化 vs 费用化**
同一笔支出，计入资产（**资本化**，未来分期摊销，当期利润高）还是计入当期费用（**费用化**，当期利润低）。研发支出、借款利息都存在这个选择。**资本化比例异常升高是调节利润的常见手段**，看到"研发资本化率"远高于同行要警惕。

**资产重组**
见第 4.5 节。

**做市商制度**
由具备实力的机构持续提供双边报价、维持流动性的制度。科创板 2022 年起引入做市商，做市商可赚取买卖价差。

**做多/做空**
买入看涨/卖出看跌。

**做市商（Market Maker）**
为市场提供双边报价、维持流动性的机构。A 股科创板有做市商制度。

## 第 16 章 财务与估值术语

| 术语 | 解释 |
|---|---|
| **资产负债表** | 反映某一时点资产、负债、所有者权益的报表 |
| **利润表** | 反映一定期间收入、成本、利润的报表 |
| **现金流量表** | 反映一定期间现金流入流出的报表 |
| **营业收入** | 主营与其他业务收入合计 |
| **营业成本** | 与收入对应的直接成本 |
| **毛利/毛利率** | 收入−成本 / 毛利率=毛利÷收入 |
| **期间费用** | 销售、管理、研发、财务费用 |
| **营业利润** | 主业经营成果 |
| **利润总额** | 营业利润 + 营业外收支 |
| **净利润** | 利润总额 − 所得税 |
| **归母净利润** | 归属于母公司股东的净利润 |
| **扣非净利润** | 扣除非经常性损益后的净利润 |
| **少数股东损益** | 子公司中不属于母公司的利润部分 |
| **非经常性损益** | 政府补助、资产处置、公允价值变动等一次性项目 |
| **每股收益（EPS）** | 归母净利润 / 总股本 |
| **稀释每股收益** | 考虑可转债、期权等潜在稀释后的 EPS |
| **净资产（所有者权益）** | 总资产 − 总负债 |
| **每股净资产（BPS）** | 净资产 / 总股本 |
| **ROE** | 归母净利润 / 平均净资产 |
| **ROA** | 净利润 / 总资产 |
| **ROIC** | 息前税后利润 / 投入资本 |
| **毛利率** | 毛利 / 营业收入 |
| **净利率** | 净利润 / 营业收入 |
| **资产负债率** | 总负债 / 总资产 |
| **流动比率** | 流动资产 / 流动负债 |
| **速动比率** | (流动资产−存货) / 流动负债 |
| **利息保障倍数** | 息税前利润 / 利息费用 |
| **应收账款周转率** | 营业收入 / 平均应收账款 |
| **存货周转率** | 营业成本 / 平均存货 |
| **总资产周转率** | 营业收入 / 平均总资产 |
| **经营现金流** | 经营活动产生的现金流量净额 |
| **自由现金流（FCF）** | 经营现金流 − 资本开支 |
| **净现比** | 经营现金流 / 净利润 |
| **资本开支（Capex）** | 购建固定资产、无形资产支付的现金 |
| **商誉** | 并购溢价 |
| **递延所得税** | 会计与税法差异形成的未来税负 |
| **审计意见** | 无保留/带强调事项/保留/无法表示/否定 |
| **杜邦分析** | ROE = 净利率 × 周转率 × 权益乘数 |
| **PE / PB / PS / PEG** | 见第 12.1 节 |
| **EV/EBITDA** | 企业价值 / 息税折旧摊销前利润 |
| **DCF** | 现金流折现估值 |
| **WACC** | 加权平均资本成本 |
| **股息率** | 每股分红 / 股价 |
| **分红率（派息率）** | 分红总额 / 净利润 |
| **EBIT / EBITDA** | 息税前利润 / 息税折旧摊销前利润 |
| **同比/环比** | 与去年同期比 / 与上一期比 |
| **预告/快报/正式报告** | 业绩预告（早）、业绩快报（较快）、定期报告（正式详细） |
| **一季报/中报/三季报/年报** | 4 月底 / 8 月底 / 10 月底 / 次年 4 月底前披露 |

| **认沽期权（Put）** | 卖出的权利 |

| **行权价** | 期权约定的买卖价格 |
| **实值/平值/虚值** | 期权立即行权是否有价值 |
| **隐含波动率（IV）** | 期权价格反推的市场预期波动率 |
| **希腊字母** | Delta、Gamma、Theta、Vega、Rho，衡量期权风险 |
| **窝轮（Warrant）** | 香港的权证，分认购证/认沽证 |
| **牛熊证** | 香港的杠杆产品，有强制收回机制 |
| **可转债** | 可转换公司债券 |
| **可交换债（EB）** | 可交换成他人股票的债券 |
| **REITs** | 不动产投资信托基金，投资于基础设施/商业地产等 |
| **CDR** | 中国存托凭证 |
| **GDR** | 全球存托凭证 |
| **ABS** | 资产支持证券 |
| **回购（Repo）** | 国债逆回购是常见的现金管理工具 |
| **打新基金** | 专门参与新股申购的基金 |
| **量化基金** | 用数学模型选股/交易的基金 |
| **指数增强** | 在跟踪指数基础上做小幅偏离以获取超额收益 |
| **FOF/MOM** | 基金中的基金 / 管理人的管理人 |
| **雪球产品** | 带敲入敲出条款的场外衍生品，**风险极高，新手远离** |
| **场外配资** | 非持牌机构提供杠杆资金，**违法** |
| **虚拟盘** | 不真正报单的模拟交易平台，常见于诈骗 |

# 第五部分 从新手到入门：方法、路径与避坑

## 第 19 章 主要投资流派

### 19.1 五大流派对比

| 流派 | 代表人物 | 核心逻辑 | 持有期 | 适合谁 |
|---|---|---|---|---|
| **价值投资** | 格雷厄姆、巴菲特、芒格 | 买"价格 < 价值"的公司，赚企业成长与估值修复的钱 | 3–10 年+ | 有耐心、能读财报 |
| **成长投资** | 费雪、彼得·林奇 | 买高成长公司，容忍高估值，赚业绩增长的钱 | 1–5 年 | 对行业有洞察 |
| **趋势/技术** | 利弗莫尔、欧奈尔 | 顺势而为，赚价格趋势的钱 | 天–月 | 纪律强、能止损 |
| **量化投资** | 西蒙斯、Fama-French | 用数据和模型捕捉统计规律 | 分钟–月 | 有编程/数学背景 |
| **指数被动** | 博格（先锋基金） | 承认跑不赢市场，买下整个市场 | 10 年+ | **绝大多数普通人** |

### 19.2 为什么"指数基金"是普通人的最优解

**核心论据**：

1. **主动基金长期跑输指数的概率很高**。美国 SPIVA 报告长期显示：15 年期约 90% 的主动股票基金跑输标普 500。中国主动基金的超额收益也在收窄（2021 年后尤其明显）。
2. **成本是确定的，超额收益是不确定的**。指数基金管理费 0.15%–0.5%，主动基金 1.2%–1.5%，加上换手成本，长期差距巨大。
3. **幸存者偏差**：你看到的"明星基金经理"是幸存者，清盘的产品你看不到。
4. **你不需要成为专家**：买沪深 300 + 中证 500 + 标普 500 + 纳指的组合，就已经战胜了 80% 的散户。

**新手指数基金清单（举例，非推荐）**：
- 宽基：沪深 300ETF、中证 500ETF、中证 1000ETF、创业板 ETF、科创 50ETF
- 海外：标普 500ETF（QDII）、纳指 ETF（QDII）、恒生 ETF
- 策略：红利 ETF、低波 ETF

**定投（Dollar-Cost Averaging）**：固定时间投入固定金额，平摊成本、平滑波动、强制储蓄。**适合工薪族和在校学生**。

### 19.3 巴菲特的几条核心原则（新手可直接用）

1. **不亏钱**（Rule No.1: Never lose money. Rule No.2: Never forget Rule No.1）——本质是强调安全边际。
2. **买你看得懂的公司**——能力圈原则。
3. **以合理价格买入优秀公司，胜过以便宜价格买入平庸公司**——从格雷厄姆到芒格的进化。
4. **别人贪婪我恐惧，别人恐惧我贪婪**——逆向思维。
5. **如果你不打算持有 10 年，就不要持有 10 分钟**——长期主义。
6. **潮水退去才知道谁在裸泳**——杠杆与风险。

## 第 20 章 新手学习路径（6 个月计划）

### 20.1 总体节奏

```
第 1 个月：建立概念框架（读本文 + 1 本入门书）
第 2 个月：模拟盘 + 读财报（练手，不动真钱）
第 3 个月：小额实盘（不超过 5000 元），记录交易日志
第 4–6 个月：建立自己的投资体系（选股/选基标准 + 仓位规则）
```

### 20.2 分阶段具体动作

#### 第 1 阶段：概念（1 个月）

- ✅ 读完本文，把不理解的词标出来，逐个查。
- ✅ 读 1–2 本经典入门书（书单见 20.3）。
- ✅ 开通券商账户（先不开高风险权限），熟悉 App。
- ❌ 不要实盘，不要听消息买股。

#### 第 2 阶段：模拟 + 读财报（1 个月）

- ✅ 用券商模拟盘操作，记录每笔交易的**买入理由、预期、结果**。
- ✅ 挑 3 家你熟悉的公司（如茅台、宁德时代、比亚迪、招行），从巨潮资讯网下载最新年报，重点看：营收/利润趋势、经营现金流、ROE、应收账款、商誉。
- ✅ 学会看懂"三张表"的勾稽关系。
- ✅ 用同花顺/东方财富对比同行 PE、PB、ROE。

#### 第 3 阶段：小额实盘（1 个月）

- ✅ 投入**亏光也不影响生活**的金额（建议 1000–5000 元）。
- ✅ 只买 1–3 只你研究过的股票，或直接买宽基 ETF。
- ✅ 每笔交易写日志：为什么买？如果跌 10% 怎么办？如果涨 20% 怎么办？
- ✅ 月末复盘：胜率多少？亏损的原因是什么？

#### 第 4–6 阶段：构建体系

- ✅ 确定自己的**投资目标**（保值？增值？多久用钱？）
- ✅ 确定**资产配置**（股/债/现金比例）
- ✅ 确定**选股或选基标准**（如 ROE>15%、负债率<50%、PE 历史分位<50%）
- ✅ 确定**买入/卖出规则**（分批建仓、止损止盈）
- ✅ 确定**再平衡规则**（每年调整一次）

## 第 21 章 常见骗局与避坑指南

### 21.1 十大典型骗局

| 骗局 | 手法 | 识别方法 |
|---|---|---|
| **荐股诈骗** | "老师"免费荐股，先给甜头，再诱导进"内部群"、买"会员"，最后推荐接盘票或虚拟盘 | 任何承诺收益的荐股都违法；正规投顾不得承诺收益 |
| **虚拟盘** | 让你在假 App 上交易，行情真实但你的单子从未进交易所，钱进了骗子口袋 | 只在券商官方 App 交易；核对 App 下载渠道；小额出金测试 |
| **原始股骗局** | 声称"某公司即将上市，原始股低价转让" | 非上市公司股权转让受限；"稳赚"的原始股 99% 是骗局 |
| **场外配资** | 提供 5–10 倍杠杆，收取高额利息，行情不利时强平 | 场外配资违法；杠杆是新手第一杀手 |
| **杀猪盘** | 通过社交软件建立感情，诱导投资虚假平台 | 网恋对象谈投资 = 诈骗 |
| **股票群/直播间** | 群里有大量"托儿"晒盈利截图，营造氛围 | 截图可伪造；真赚钱的人不需要拉你 |
| **内幕消息** | 声称有"内部消息"，收费或让你接盘 | 内幕交易违法；真内幕不会告诉你 |
| **代客理财** | 声称"专业操盘"，承诺保本分成 | 无牌照代客理财违法；亏损后跑路 |
| **假冒券商/客服** | 假网站、假 App、假客服电话 | 只从官方渠道下载；官方客服不会要你的密码 |
| **元宇宙/区块链/AI 概念股** | 蹭热点，讲故事，无实际业务 | 看财报：有没有真实收入？客户是谁？ |

### 21.2 合法与非法边界（记住这几条）

- ✅ 合法：持牌券商开户交易、买公募基金、买银行理财、买国债。
- ❌ 违法：场外配资、代客理财（无牌照）、承诺收益、内幕交易、操纵市场、出借账户。
- ⚠️ 灰色：社交平台荐股（无投顾牌照）、"股神"授课收费。

### 21.3 自我保护清单

1. **只用官方渠道**：券商官网/官方 App 下载，核对备案信息。
2. **不向任何人透露**：交易密码、资金密码、短信验证码、身份证照片。
3. **不出借账户**：出借证券账户违法，且可能被用于洗钱。
4. **不信"保本高收益"**：金融学第一定律——收益与风险成正比。
5. **小额测试出金**：在陌生平台投入前，先小额入金并尝试提现。
6. **遇骗立即报警**：保留聊天记录、转账记录，拨打 110 或国家反诈中心 96110。
7. **查牌照**：证监会官网"监管对象"栏目可查机构与人员资质。

### 21.4 新手最容易犯的 10 个错误

1. **不做功课就买**——听朋友/大 V/群友推荐。
2. **满仓单一股票**——把鸡蛋放一个篮子。
3. **追涨杀跌**——涨了怕错过，跌了怕继续跌。
4. **频繁交易**——手续费+印花税吃掉收益。
5. **不止损**——"套牢就当长期投资"。
6. **加杠杆**——融资、配资、借钱炒股。
7. **用生活费/学费炒股**——压力下必然做错决策。
8. **迷信技术指标/内幕消息**——寻找"圣杯"。
9. **不看财报**——只看 K 线和概念。
10. **不记录不复盘**——同样的错误犯十年。

## 第 22 章 常见问题 FAQ（新手 50 问）

### 开户与账户

**Q1：炒股需要多少钱？**
A：A 股最低买 100 股，理论上几百元就能开始（买低价股）。但建议至少准备 5000–10000 元，否则手续费占比过高。**更重要的是：只用闲钱。**

**Q2：学生可以开户吗？**
A：年满 18 周岁、有完全民事行为能力即可开户，学生身份不影响。但**不建议用生活费/学费炒股**。

**Q3：可以开几个账户？**
A：目前一个自然人最多可在 3 家券商开立沪市 A 股账户、3 家深市 A 股账户（具体以中国结算规则为准）。

**Q4：开户收费吗？**
A：开户免费。交易才收费。

**Q5：不想炒股，只想买基金，需要开户吗？**
A：买场外基金（支付宝、天天基金、银行 App）不需要证券账户；买场内 ETF 需要。

**Q6：账户长期不用会怎样？**
A：可能被列为"休眠账户"，需临柜或线上激活。不会自动销户。

**Q7：可以注销账户吗？**
A：可以，需清空持仓和资金后办理。

### 交易规则

**Q8：为什么今天买的股票今天不能卖？**
A：A 股股票实行 T+1 交易制度。

**Q9：卖了股票的钱什么时候能取？**
A：当天可继续买股票，**T+1 才能取现**（转到银行卡）。

**Q10：100 股必须是 100 的整数倍吗？**
A：买入必须是 100 股整数倍（科创板 200 股起、之后 1 股递增；北交所 100 股起、之后 1 股递增）。卖出可以卖零股。

**Q11：涨跌停是多少？**
A：主板 ±10%，创业板/科创板 ±20%，北交所 ±30%，ST 股 ±5%（主板）。

**Q12：为什么我的委托被废单？**
A：价格超出涨跌停、数量不符、资金不足、无权限、停牌等。见第 8.4 节。

**Q13：集合竞价能撤单吗？**
A：9:15–9:20 可以撤，9:20–9:25 不能撤。

**Q14：什么是"价格笼子"？**
A：科创板/创业板对限价申报价格的限制，防止异常报价。买入申报价不得高于基准价的 102%，卖出不得低于 98%（具体以规则为准）。

**Q15：A 股可以做空吗？**
A：可以通过融券做空（需开通两融、有券源），或买入认沽期权（需期权权限）。普通散户做空工具很少。

**Q16：可以做 T+0 吗？**
A：股票不可以；ETF、可转债、期货可以。有一种"变相 T+0"叫"做 T"：先持有底仓，日内低买高卖同一只股票（先买后卖或先卖后买），但受 T+1 限制。

### 费用与税

**Q17：买卖一次股票要交多少费用？**
A：佣金（双向，万分之 1–3）+ 印花税（卖出 0.05%）+ 过户费（双向 0.001%）+ 经手费/证管费（很小）。10 万元买卖一轮约 100 元出头。见第 9 章。

**Q18：分红要交税吗？**
A：要。持股 ≤1 个月 20%，1 个月–1 年 10%，>1 年免征。

**Q19：印花税能免吗？**
A：不能，卖出时自动扣。

**Q20：佣金可以谈到多少？**
A：资金量大或交易频繁可谈至万分之 1 甚至更低，部分券商免最低 5 元。开户前先问清。

### 股票与公司

**Q21：股票跌了，公司会退钱吗？**
A：不会。股票是所有权凭证，公司没有回购义务（除非公司主动回购）。

**Q22：公司退市了，我的股票怎么办？**
A：转入全国股转系统退市板块（老三板）继续转让，但流动性极差，通常大幅折价。

**Q23：公司破产了，股票还有价值吗？**
A：清偿顺序：债权人 → 优先股 → 普通股。普通股往往血本无归。

**Q24：什么是"10 送 10"？**
A：每 10 股送 10 股，股数翻倍、股价减半，总市值不变。

**Q25：分红后股价为什么跌了？**
A：除息。分红金额从股价中扣除，你的总资产不变（还要交税）。

**Q26：什么是"高送转"？**
A：大比例送股/转增。本质是股本拆分，不创造价值，但常被炒作。监管已对高送转加强问询。

**Q27：怎么看一家公司好不好？**
A：看 5 点：① 营收利润是否持续增长；② ROE 是否 >15%；③ 经营现金流是否匹配利润；④ 负债率是否可控；⑤ 是否有护城河。见第 11 章。

**Q28：财报在哪里看？**
A：巨潮资讯网（官方指定）、交易所官网、券商 App、同花顺/东方财富 F10。

**Q29：财报什么时候出？**
A：一季报 4 月底前，半年报 8 月底前，三季报 10 月底前，年报次年 4 月底前。

**Q30：审计意见重要吗？**
A：非常重要。"无法表示意见"或"否定意见"是重大风险信号，直接回避。

### 估值与买卖

**Q31：PE 多少算便宜？**
A：没有绝对标准。要和①自身历史分位②同行业③成长性（PEG）比。银行 5 倍 PE 正常，白酒 30 倍也可能合理。

**Q32：什么是"好公司好价格"？**
A：好公司（高 ROE、有护城河）+ 好价格（估值合理或低估）。**好公司买贵了也会亏钱。**

**Q33：什么时候该卖？**
A：三种情况：① 买入逻辑破坏（业绩变脸、护城河消失）；② 估值严重高估；③ 有更好的机会（机会成本）。

**Q34：止损设多少合适？**
A：常见 8%–10%，或跌破关键支撑位。没有标准答案，关键是**事先设定并执行**。

**Q35：亏了要不要补仓？**
A：只有在"基本面没变、估值更便宜、仓位还有空间"时才补。**不要为了摊低成本而补仓。**

### 市场与宏观

**Q36：大盘涨我的股票一定涨吗？**
A：不一定。个股与大盘的相关性约 0.5–0.7，结构性行情中经常"指数涨、个股跌"。

**Q37：牛市什么时候来？**
A：没人能准确预测。**不要预测，要准备**——低估时多买，高估时少买。

**Q38：美联储加息对 A 股有什么影响？**
A：一般利空：外资流出、人民币贬值压力、全球风险偏好下降。但影响是间接的、有时滞的。

**Q39：什么是"北向资金"？**
A：经香港买 A 股的资金（陆股通）。曾被视为"聪明钱"，但构成复杂（含量化、对冲），不宜盲目跟随。**注意：北向资金的实时数据 2024 年 5 月已停止盘中披露，2024 年 8 月起改为按季度公布，"跟着北向资金买"的策略已基本失效。**

**Q40：注册制对散户有什么影响？**
A：① 新股供给增加，打新不再稳赚；② 壳资源贬值，炒壳退潮；③ 退市加速，"踩雷"风险上升；④ 更需要对个股基本面做判断。

### 心理与策略

**Q41：为什么我总是追高杀跌？**
A：人性。对策：制定交易计划、写交易日志、用定投代替择时。

**Q42：模拟盘赚钱，实盘亏钱，为什么？**
A：模拟盘没有真实情绪和损失厌恶，实盘会恐惧/贪婪。

**Q43：要不要听大 V 推荐？**
A：可以听逻辑，不要听结论。**任何"荐股"都要警惕利益关系**（抬轿子、接盘）。

**Q44：长期持有一定赚钱吗？**
A：不一定。长期持有**优质资产**才赚钱；长期持有垃圾股会归零。日本日经指数 1989 年高点用了 34 年才收复。

**Q45：定投一定能赚钱吗？**
A：定投降低择时风险，但**不保证盈利**。标的长期向上才有效（如宽基指数）。

### 其他

**Q46：什么是"打新"？**
A：申购新股。A 股需市值配售，中签后缴款。注册制下可能破发。

**Q47：什么是"可转债打新"？**
A：申购新发行的可转债，无需市值、无需预缴款，中签后缴款。曾是"免费彩票"，2023 年后破发增多。

**Q48：股票和基金哪个好？**
A：没有绝对好坏。**新手建议从宽基指数基金开始**，用少量资金试水个股。

**Q49：学炒股要看什么书？**
A：见第 20.3 节书单。**先读入门，再读经典，不要一上来读《金融炼金术》。**

**Q50：炒股能发财吗？**
A：少数人能通过投资实现财富增值，但**绝大多数散户长期跑输指数**。把炒股当"财富管理的一部分"而非"暴富捷径"，是成熟的第一步。
