## 学习目标

1. **能**区分「估计量」（随机变量）与「估计值」（具体数字），并解释点估计要解决什么问题。
2. **能**用**矩估计法**求参数估计量，并理解其「替换原理」。
3. **能**熟练写出**似然函数**，用取对数求导法求**最大似然估计**，并能处理**均匀分布**这类不能用求导的非正则情形。
4. **能**验证一个估计量的**无偏性**，并在两个无偏估计中比较**有效性**（比方差）。
5. **能**说清**置信度 1−α** 的正确含义（是说「区间构造方法」可靠，不是「参数落在该区间的概率」）。
6. **能**用**枢轴量法**推导并写出四种常见情形的置信区间。
7. **能**熟练查 `z`、`t`、`χ²`、`F` 四种表，并**根据题目条件选择正确的统计量**——这是本章拿分关键。
8. **能**根据置信区间是否包含 0，对「两总体均值是否有差异」作出初步判断（与第 7 章假设检验衔接）。
9. **能**分析样本容量 n 与置信区间长度的关系，理解「精度」与「成本」的权衡。

## 6.1 点估计问题概述

### 6.1.1 问题的提法

**参数估计（Parameter Estimation）**：总体分布的形式已知（如「正态」「泊松」），但含有一个或多个**未知参数** `θ`。利用样本 `X₁, …, Xₙ` 对 `θ` 作出推断。

**点估计（Point Estimation）**：构造一个统计量 `θ̂ = θ̂(X₁, …, Xₙ)`，用它的观测值 `θ̂(x₁, …, xₙ)` 作为 `θ` 的近似值。

- `θ̂(X₁, …, Xₙ)` 称为 `θ` 的**估计量（Estimator）**——它是**随机变量**；
- `θ̂(x₁, …, xₙ)` 称为 `θ` 的**估计值（Estimate）**——它是**一个具体数字**。

> **重点**：做题时先写估计量（带大写的 `Xᵢ`），再把观测值代进去算估计值（小写）。题目给具体数据时，最后一步必须算出数字。

**点 vs 区间**：点估计给出「一个数」，但**不可能恰好等于真值**，且不告诉你有多准。区间估计给出「一个范围 + 可靠程度」。这正是 6.3 节要解决的问题。

### 6.1.2 估计量的评选标准

**① 无偏性（Unbiasedness）**

**定义**：若 `E(θ̂) = θ` 对一切 `θ` 成立，则称 `θ̂` 是 `θ` 的**无偏估计量**。

**直观**：「瞄准了靶心」——虽然每次打的位置有偏差，但**平均而言**正中目标，不系统性地偏高或偏低。

**核心结论（第 5 章已证）**：

| 估计量 | 估计目标 | 是否无偏 | 说明 |
|---|---|---|---|
| `X̄` | `μ` | ✅ `E(X̄) = μ` | 无论总体分布 |
| `S² = 1/(n−1)Σ(Xᵢ−X̄)²` | `σ²` | ✅ `E(S²) = σ²` | 这就是用 n−1 的理由 |
| `B₂ = 1/n Σ(Xᵢ−X̄)²` | `σ²` | ❌ `E(B₂) = (n−1)σ²/n` | 系统性**低估**方差 |
| `A_k = (1/n)ΣXᵢ^k` | `E(X^k)` | ✅ | 样本矩是总体矩的无偏估计 |
| `S` | `σ` | ❌ `E(S) < σ` | 但 n 大时近似无偏 |

> **重点**：**无偏性是关于「平均」的性质，不是关于「某一次」的性质**。一个无偏估计在某次具体抽样中可能偏离很远。评价估计量要在**重复抽样**的意义下看。

> **口径说明（两套分母并存，都要会）**：本笔记中 `S² = 1/(n−1)Σ(Xᵢ−X̄)²` 与 `B₂ = 1/n Σ(Xᵢ−X̄)²` 这两个量**都是规范的，只是用途不同**：
> - **评价估计量（无偏性、有效性）时用 `S²`**——分母 `n−1` 才无偏，这是第 5 章的定义，也是后面 t 检验、F 检验里一律出现的量。
> - **矩估计的定义式按「样本二阶中心矩」`B₂`（分母 `n`）**——因为矩估计就是「用样本矩替换总体矩」，而二阶中心矩的定义式分母是 `n`。所以矩估计给出的 `σ̂² = B₂` **是有偏的**。
> - **最大似然估计的 `σ̂²` 分母也是 `n`**（由求导解出），同样有偏。
>
> 一句话：**「无偏」用 `S²`，「矩估计 / MLE 的定义式」用 `1/n`。** 题目若问「求 σ² 的矩估计」，答 `B₂`；若问「求 σ² 的无偏估计」，答 `S²`。

**② 有效性（Efficiency）**

**定义**：设 `θ̂₁` 与 `θ̂₂` 都是 `θ` 的无偏估计量，若 `D(θ̂₁) < D(θ̂₂)` 对一切 `θ` 成立，则称 `θ̂₁` **比 `θ̂₂` 更有效**。

**直观**：「瞄得准 + 手更稳」。两个射手平均都打中靶心，但一个弹着点集中、一个散得很开——集中的更有效。

**重要例子**：用不同的加权平均估计 `μ`。设 `X₁, X₂, X₃` 是样本，取
- `μ̂₁ = (1/3)(X₁ + X₂ + X₃)`，`D(μ̂₁) = σ²/3 ≈ 0.3333σ²`
- `μ̂₂ = (1/2)X₁ + (1/3)X₂ + (1/6)X₃`，`D(μ̂₂) = (1/4 + 1/9 + 1/36)σ² = (14/36)σ² ≈ 0.3889σ²`

两者都无偏（系数和为 1），但 `μ̂₁` 方差更小，**更有效**。其实可以证明：在所有「系数和为 1 的线性无偏估计」中，`X̄` 的方差最小（这就是「最小方差无偏估计 MVUE」的思想）。

**③ 一致性（相合性，Consistency）**

**定义**：若对任意 `ε > 0`，有 `lim_{n→∞} P(|θ̂ₙ − θ| < ε) = 1`，则称 `θ̂ₙ` 是 `θ` 的**一致估计量**（相合估计量）。

**直观**：「样本量越大越准，最终必准」。这是大数定律的直接推论。

**常见一致估计**：`X̄`（辛钦大数定律）、`A_k`、`B₂`、`S²`、最大似然估计（在正则条件下）。

> **三者的层次**：无偏性、有效性针对**固定 n**；一致性针对 **n → ∞**。样本量趋于无穷时「能收敛到真值」是估计量最起码的要求。**一致性是最基本的要求，无偏性其次，有效性是进一步的优选。**

## 6.2 点估计的常用方法

### 6.2.1 矩估计法（Method of Moments）

**基本思想（替换原理）**：样本矩依概率收敛于相应的总体矩（大数定律保证）。因此**用样本矩替换总体矩**即可得到参数的估计。

**操作步骤**：

① 求出总体的前 k 阶原点矩 `μ_k(θ) = E(X^k)`，其中 k 等于待估参数的个数；
② 令 `μ_k(θ) = A_k = (1/n)Σᵢ₌₁ⁿ Xᵢ^k`，得到 k 个方程；
③ 解方程组，得到 `θ̂₁, …, θ̂ₖ`。

**常见情形**：

| 待估参数 | 方程 | 估计量 |
|---|---|---|
| 一个参数 `θ` | `μ₁(θ) = X̄` | 由 `E(X) = X̄` 解出 |
| 两个参数 `θ₁, θ₂`（如正态的 μ, σ²） | `E(X) = X̄`，`E(X²) = A₂` | `μ̂ = X̄`，`σ̂² = B₂`（或直接 `μ̂ = X̄`，`σ̂² = S²`） |

> **重点**：矩估计**只用到矩的信息**，因此：
> ① 计算简单，不需要知道分布的完整形式，只需要知道前几阶矩；
> ② 但**可能不唯一**（如 `U(0,θ)` 用一阶矩得 `θ̂ = 2X̄`，用二阶矩得 `θ̂ = √(3A₂)`，两者不同）；
> ③ 也可能**不合理**（例如矩估计可能给出负的方差）。
> 最大似然估计通常更受青睐，因为它用上了分布的**全部信息**。

### 6.2.2 最大似然估计法（Maximum Likelihood Estimation, MLE）

**基本思想**：「**已经发生的事，一定有让它最容易发生的那个参数值**」。既然样本 `x₁, …, xₙ` 已经出现了，那就选择让这组样本出现**概率最大**的参数值作为估计。

**似然函数（Likelihood Function）**：

| 类型 | 似然函数 |
|---|---|
| 连续型（密度 `f(x; θ)`） | `L(θ) = Πᵢ₌₁ⁿ f(xᵢ; θ)` |
| 离散型（分布律 `p(x; θ)`） | `L(θ) = Πᵢ₌₁ⁿ p(xᵢ; θ)` |

**最大似然估计量（MLE）**：使 `L(θ)` 达到最大值的 `θ̂`：

`L(θ̂) = max_θ L(θ)`

**求解步骤（标准四步法）**：

① **写似然函数** `L(θ) = Π f(xᵢ; θ)`；
② **取对数** `ln L(θ) = Σ ln f(xᵢ; θ)`（**为什么取对数**：把乘积变成求和，求导更容易；且 `ln` 是单调增函数，不改变最大值点的位置）；
③ **求导并令其为零**：`d ln L(θ)/dθ = 0`，解出驻点；
④ **验证最大值**（通常由问题的实际背景即可确认，考试一般不必严格验证）。

**多参数情形**：解方程组 `∂ ln L/∂θ₁ = 0`，`∂ ln L/∂θ₂ = 0`。

> **重点（非正则情形）**：当参数出现在**示性函数的边界**上时（例如 `U(0, θ)` 的 θ 决定了 x 的**取值范围**），`ln L` 对 θ 的导数**不为零**，求导法失效。此时必须**回到 `L(θ)` 本身分析单调性**，在 θ 的允许范围内找最大值点。这是 MLE 最经典的「陷阱题」，几乎每次考试都会出现。

**不变性原理（Invariance Property）**：若 `θ̂` 是 `θ` 的 MLE，`g(·)` 是任意函数，则 `g(θ̂)` 是 `g(θ)` 的 MLE。

> **用途**：求 `σ` 的 MLE 时不必重新做一遍，直接对 `σ²` 的 MLE 开方即可。例：正态总体 `σ̂² = (1/n)Σ(Xᵢ − X̄)²`，则 `σ̂ = √[(1/n)Σ(Xᵢ − X̄)²]`。
> **注意**：`1/θ̂` 也是 `1/θ` 的 MLE（取 `g(t) = 1/t`）。这是 MLE 相对矩估计的一大优势。

## 6.3 置信区间

### 6.3.1 基本概念

**置信区间（Confidence Interval）**：设总体含未知参数 `θ`，`X₁, …, Xₙ` 是样本。若有两个统计量 `θ̂_L` 与 `θ̂_U`（`θ̂_L < θ̂_U`），使

`P( θ̂_L < θ < θ̂_U ) = 1 − α`

则称随机区间 `(θ̂_L, θ̂_U)` 为 `θ` 的**置信度为 `1 − α` 的置信区间**。`1 − α` 称为**置信度（置信水平）**，`α` 称为**显著性水平**。

> **重点（最容易被问到的概念题）**：`P(θ̂_L < θ < θ̂_U) = 1 − α` 的正确解读是——
> **「在重复抽样中，用这个构造方法产生的区间有 `1 − α` 的比例会包含真值 θ」**。
>
> **错误解读**：「θ 落在 `(10.07, 10.33)` 内的概率是 0.95」。**为什么错**：θ 是**未知的常数**（不是随机变量），它要么在区间里，要么不在，没有「概率」可言。随机的只是**区间本身**（因为端点是统计量）。这是本章最经典的概念辨析题。

**常用置信度**：`1 − α = 0.90`（`z_{0.05} = 1.645`）、`0.95`（`z_{0.025} = 1.96`）、`0.99`（`z_{0.005} = 2.58`）。

**精度与置信度的矛盾**：想要**更高**的置信度，区间就要**更宽**（信息量更少）；想要**更窄**的区间，就要**降低**置信度。唯一的破解办法是**增大样本容量 n**（区间长度 ∝ `1/√n`）。

### 6.3.2 枢轴量法（四步法）

**枢轴量（Pivotal Quantity）**：一个既含待估参数 `θ`、又含样本，但**不含其他未知参数**的函数 `G(X₁, …, Xₙ; θ)`，且其**分布已知且不依赖于 θ**。

**构造置信区间的四个步骤**：

① **找枢轴量** `G`，其分布已知（正态、t、χ²、F 之一）；
② **定常数 a、b**，使 `P(a < G < b) = 1 − α`（通常取对称形式使区间最短）；
③ **等价变形**：把 `a < G < b` 化成 `θ̂_L < θ < θ̂_U`；
④ **写出置信区间** `(θ̂_L, θ̂_U)`。

> **关键技巧**：变形时要时刻记住 `θ` 是**要解出来的未知数**，其余（`X̄`、`S`、`n`、`α`）都是「已知的」。变形过程中**不等式两边同乘一个可能为负的量要变号**——在 σ² 的区间估计中，因为要取倒数，左右端点必须**交换位置**（见 6.4.2）。

### 6.3.3 单侧置信区间

有时我们只关心参数的一个方向（例如「平均寿命**至少**是多少」），此时用**单侧置信区间**：

| 类型 | 形式 | 含义 |
|---|---|---|
| **单侧置信下限** | `( θ̂_L , +∞ )` | 有 `1−α` 的把握说 `θ > θ̂_L` |
| **单侧置信上限** | `( −∞ , θ̂_U )` | 有 `1−α` 的把握说 `θ < θ̂_U` |

**构造方法**：把双侧的 `α/2` 改为 `α`。例如 σ 已知时：
- 双侧：`X̄ ± z_{α/2} · σ/√n`
- 单侧下限：`X̄ − z_α · σ/√n`
- 单侧上限：`X̄ + z_α · σ/√n`

> **注意**：单侧用的分位点是 `z_α` 而不是 `z_{α/2}`，且 **`z_α < z_{α/2}`**——因为 `α > α/2`，尾巴面积更大，临界点自然更靠左。例如 `z_{0.05} = 1.645 < z_{0.025} = 1.96`。**单侧区间比双侧区间更「紧」**，这是为「只关心一个方向」付出的信息代价换来的。

## 6.4 正态总体的置信区间

### 6.4.1 区间估计选择表（考试拿分关键，必须背下来）

设总体 `X ~ N(μ, σ²)`，样本容量 n，样本均值 `X̄`，样本方差 `S²`，置信度 `1 − α`。

| 待估参数 | 已知条件 | 枢轴量及其分布 | 置信区间（置信度 1−α） |
|---|---|---|---|
| **μ** | σ² **已知** | `(X̄−μ)/(σ/√n) ~ N(0,1)` | `X̄ ± z_{α/2} · σ/√n` |
| **μ** | σ² **未知** | `(X̄−μ)/(S/√n) ~ t(n−1)` | `X̄ ± t_{α/2}(n−1) · S/√n` |
| **σ²** | μ 未知 | `(n−1)S²/σ² ~ χ²(n−1)` | `( (n−1)S²/χ²_{α/2}(n−1),　(n−1)S²/χ²_{1−α/2}(n−1) )` |
| **μ₁−μ₂** | σ₁²、σ₂² **已知** | `[(X̄−Ȳ)−(μ₁−μ₂)]/√(σ₁²/n₁+σ₂²/n₂) ~ N(0,1)` | `(X̄−Ȳ) ± z_{α/2}·√(σ₁²/n₁ + σ₂²/n₂)` |
| **μ₁−μ₂** | σ₁²=σ₂² **未知** | `[(X̄−Ȳ)−(μ₁−μ₂)]/[S_w√(1/n₁+1/n₂)] ~ t(n₁+n₂−2)` | `(X̄−Ȳ) ± t_{α/2}(n₁+n₂−2)·S_w·√(1/n₁+1/n₂)` |
| **σ₁²/σ₂²** | μ₁、μ₂ 未知 | `(S₁²/σ₁²)/(S₂²/σ₂²) ~ F(n₁−1, n₂−1)` | `( S₁²/S₂² · 1/F_{α/2}(n₁−1,n₂−1),　S₁²/S₂² · 1/F_{1−α/2}(n₁−1,n₂−1) )` |

其中**合并方差** `S_w² = [(n₁−1)S₁² + (n₂−1)S₂²] / (n₁ + n₂ − 2)`。

> **选择决策树（三步）**：
> ① **估什么？** 均值 `μ`（或均值差）→ 用 Z 或 t；方差 `σ²`（或方差比）→ 用 χ² 或 F。
> ② **σ 知不知道？** 已知 → **Z（正态）**；未知 → **t**（单总体）或 **F**（方差比）。
> ③ **单总体还是两总体？** 单 → 自由度 `n−1`；两总体合并 → 自由度 `n₁+n₂−2`；方差比 → `(n₁−1, n₂−1)`。
>
> **一句话**：**「均值看 Z/t，方差看 χ²/F；σ 已知用 Z，σ 未知用 t」**。

### 6.4.2 正态总体均值 μ 的置信区间

**情形 A：σ² 已知**

由第 5 章定理 1，`(X̄−μ)/(σ/√n) ~ N(0,1)`。取
`P( −z_{α/2} < (X̄−μ)/(σ/√n) < z_{α/2} ) = 1 − α`
变形（两边乘 `σ/√n`，再移项）：
`X̄ − z_{α/2}·σ/√n < μ < X̄ + z_{α/2}·σ/√n`
故 **`μ` 的置信区间为**

`( X̄ − z_{α/2} · σ/√n ,　X̄ + z_{α/2} · σ/√n )`

记作 `X̄ ± Δ`，其中 **`Δ = z_{α/2} σ/√n` 称为「误差限」或「允许误差」**。

**情形 B：σ² 未知（实际中最常见）**

用 `S` 替代 `σ`，由第 5 章定理 3，`(X̄−μ)/(S/√n) ~ t(n−1)`。同理得

`( X̄ − t_{α/2}(n−1) · S/√n ,　X̄ + t_{α/2}(n−1) · S/√n )`

> **重点对比**：
> - σ 已知时用 `z_{α/2}`（查正态表），**与 n 无关**；
> - σ 未知时用 `t_{α/2}(n−1)`（查 t 表），**依赖于 n，且 `t_{α/2}(n−1) > z_{α/2}`**（因为用 S 代替 σ 引入了额外不确定性）。
> - n 很大时 `t_{α/2}(n−1) ≈ z_{α/2}`（如 `t_{0.025}(45) = 2.0141 ≈ 1.96`），此时两者结果接近。

**误差限与样本容量的关系**：由 `Δ = z_{α/2} σ/√n` 反解，

`n = ( z_{α/2} σ / Δ )²`

**结论：要把误差限减半，样本量要增大到 4 倍**（因为 `Δ ∝ 1/√n`）。这是抽样调查成本估算的基本公式。

### 6.4.3 正态总体方差 σ² 的置信区间

由第 5 章定理 2，`(n−1)S²/σ² ~ χ²(n−1)`。取
`P( χ²_{1−α/2}(n−1) < (n−1)S²/σ² < χ²_{α/2}(n−1) ) = 1 − α`
**变形（关键一步）**：不等式取倒数会**翻转方向**，故

`1/χ²_{α/2}(n−1) < σ²/[(n−1)S²] < 1/χ²_{1−α/2}(n−1)`

两边同乘 `(n−1)S²`：

`σ² ∈ ( (n−1)S² / χ²_{α/2}(n−1) ,　(n−1)S² / χ²_{1−α/2}(n−1) )`

> **重点**：**分子相同，分母一大一小**。因为 `χ²_{1−α/2} < χ²_{α/2}`（左上分位点更小），所以左端点对应**大**的分母（区间较窄的一端），右端点对应**小**的分母。写反是最常见的错误。
> **σ 的区间**：由不变性，把 σ² 区间的两个端点**开平方**即可。

### 6.4.4 两正态总体均值差 μ₁ − μ₂ 的置信区间

**情形 A：σ₁²、σ₂² 均已知**

`( (X̄−Ȳ) − z_{α/2}·√(σ₁²/n₁ + σ₂²/n₂) ,　(X̄−Ȳ) + z_{α/2}·√(σ₁²/n₁ + σ₂²/n₂) )`

**情形 B：σ₁² = σ₂² = σ² 但未知**

`( (X̄−Ȳ) ± t_{α/2}(n₁+n₂−2) · S_w · √(1/n₁ + 1/n₂) )`

> **实用判据（与第 7 章衔接）**：若 `μ₁ − μ₂` 的置信区间**包含 0**，则不能认为两总体均值有显著差异；若不包含 0，则可认为有显著差异（区间全正 ⟹ `μ₁ > μ₂`；全负 ⟹ `μ₁ < μ₂`）。

### 6.4.5 两正态总体方差比 σ₁²/σ₂² 的置信区间

由 `(S₁²/σ₁²)/(S₂²/σ₂²) ~ F(n₁−1, n₂−1)`，取
`P( F_{1−α/2}(n₁−1,n₂−1) < (S₁²/S₂²)·(σ₂²/σ₁²) < F_{α/2}(n₁−1,n₂−1) ) = 1 − α`
解出 `σ₁²/σ₂²` 得

`σ₁²/σ₂² ∈ ( (S₁²/S₂²) / F_{α/2}(n₁−1, n₂−1) ,　(S₁²/S₂²) / F_{1−α/2}(n₁−1, n₂−1) )`

（若需要的 `F_{1−α/2}` 表上没有，用 `F_{1−α/2}(n₁−1, n₂−1) = 1/F_{α/2}(n₂−1, n₁−1)` 换算——**记得交换自由度**。）

## 典型例题

**例 6.1**（题型：矩估计——连续型）
设总体 X 的概率密度为 `f(x) = (θ + 1)x^θ`（0 < x < 1），其余为 0，其中 `θ > −1` 为未知参数。`X₁, …, Xₙ` 为样本，求 `θ` 的矩估计量。

**解**：
**第一步——算总体一阶原点矩**（只有一个参数，只需一阶矩）：
`E(X) = ∫_0^1 x · (θ+1)x^θ dx = (θ+1) ∫_0^1 x^(θ+1) dx = (θ+1) · [x^(θ+2)/(θ+2)]_0^1 = (θ+1)/(θ+2)`
**第二步——令总体矩 = 样本矩**：
`(θ+1)/(θ+2) = X̄`
**第三步——解出 θ**：
`θ + 1 = X̄(θ + 2)` ⟹ `θ + 1 = X̄θ + 2X̄` ⟹ `θ(1 − X̄) = 2X̄ − 1`
`θ̂ = (2X̄ − 1)/(1 − X̄)`

**答案**：`θ̂ = (2X̄ − 1)/(1 − X̄)`。

> **合理性检验**：题面已给 `θ > −1`，而 `E(X) = (θ+1)/(θ+2)` 在 `θ > −1` 上**单调递增**，取值范围是 **(0, 1)**：`θ → −1⁺` 时趋于 0，`θ = 0` 时得 1/2，`θ → ∞` 时趋于 1。所以样本均值 `X̄` 只要落在 (0, 1) 内即可，对应的 `θ̂ = (2X̄−1)/(1−X̄)` 必然满足 `θ̂ > −1`——因为 `θ̂ > −1 ⟺ 2X̄ − 1 > −(1 − X̄) ⟺ X̄ > 0`，而 `X̄ ∈ (0,1)` 恒成立。**参数空间与样本取值范围自动相容，不需要额外限制。**

---

**例 6.2**（题型：最大似然估计——离散型）
设总体 `X ~ B(1, p)`（即一次伯努利试验），`X₁, …, Xₙ` 为样本，求 `p` 的最大似然估计量。

**解**：
**第一步——写似然函数**（离散型用分布律）：
`X` 的分布律为 `P(X = x) = p^x (1 − p)^(1−x)`（x = 0 或 1）。故
`L(p) = Πᵢ₌₁ⁿ p^(xᵢ) (1 − p)^(1−xᵢ) = p^(Σxᵢ) (1 − p)^(n − Σxᵢ)`
**第二步——取对数**：
`ln L(p) = (Σxᵢ) ln p + (n − Σxᵢ) ln(1 − p)`
**第三步——求导令零**：
`d ln L/dp = (Σxᵢ)/p − (n − Σxᵢ)/(1 − p) = 0`
两边乘 `p(1−p)`：
`(Σxᵢ)(1 − p) − (n − Σxᵢ)p = 0` ⟹ `Σxᵢ − pΣxᵢ − np + pΣxᵢ = 0` ⟹ `Σxᵢ = np`
`p̂ = (1/n) Σᵢ₌₁ⁿ Xᵢ = X̄`
**第四步——验证**：`d² ln L/dp² = −(Σxᵢ)/p² − (n−Σxᵢ)/(1−p)² < 0`，故为极大值点。

**答案**：`p̂ = X̄`。

> **特殊情形**：若题目说「抽检 n 件产品，其中 k 件次品」，则 `p̂ = k/n`。这与矩估计结果一致。
> **一般情形**：`X ~ B(m, p)` 时，`p̂ = X̄/m`（用不变性原理可快速得到）。

---

**例 6.3**（题型：最大似然估计——指数分布）
设总体 `X ~ E(λ)`，密度为 `f(x) = λe^(−λx)`（x > 0），`λ > 0` 未知。`X₁, …, Xₙ` 为样本，求 `λ` 的最大似然估计量与矩估计量，并比较。

**解（MLE）**：
① `L(λ) = Πᵢ₌₁ⁿ λ e^(−λxᵢ) = λⁿ e^(−λ Σxᵢ)`
② `ln L(λ) = n ln λ − λ Σᵢ₌₁ⁿ xᵢ`
③ `d ln L/dλ = n/λ − Σxᵢ = 0` ⟹ `λ̂ = n / Σᵢ₌₁ⁿ Xᵢ = 1 / X̄`
④ `d² ln L/dλ² = −n/λ² < 0`，确为极大值点。

**解（矩估计）**：
`E(X) = 1/λ`。令 `1/λ = X̄`，得 `λ̂ = 1/X̄`。

**结论**：两者**完全一致**——这是指数分布的特殊之处（因为它属于指数族，矩估计与 MLE 常常重合）。

**答案**：MLE 与矩估计均为 `λ̂ = 1/X̄ = n / ΣXᵢ`。

> **数值实例**：若 5 个元件的寿命观测值为 100, 120, 80, 150, 50（小时），则 `Σxᵢ = 500`，`λ̂ = 5/500 = 0.01`，即平均寿命估计为 `1/λ̂ = 100` 小时。

---

**例 6.4**（题型：最大似然估计——非正则情形，均匀分布）
设总体 `X ~ U(0, θ)`，`θ > 0` 未知。`X₁, …, Xₙ` 为样本，求 `θ` 的最大似然估计量与矩估计量，并说明二者的差别。

**解（MLE）**：
① 密度 `f(x; θ) = 1/θ`（0 < x < θ），其余为 0。
似然函数：
`L(θ) = Πᵢ₌₁ⁿ (1/θ) · I(0 < xᵢ < θ)`
**关键**：所有 `xᵢ` 都必须满足 `0 < xᵢ < θ`，这等价于 `θ > max(x₁, …, xₙ) = x₍ₙ₎`（记为最大次序统计量）。故

`L(θ) = θ^(−n)`（θ > x₍ₙ₎）；`L(θ) = 0`（θ ≤ x₍ₙ₎）

② **为什么不能用求导法**：`d ln L/dθ = −n/θ < 0` 恒成立，说明 `L(θ)` 在 `(x₍ₙ₎, +∞)` 上**严格单调递减**，没有驻点。
③ **回到单调性分析**：`L(θ)` 递减，故取 θ 的**最小允许值**时 L 最大：
`θ̂ = x₍ₙ₎ = max(X₁, …, Xₙ)`

**解（矩估计）**：
`E(X) = (0 + θ)/2 = θ/2`。令 `θ/2 = X̄`，得 `θ̂_矩 = 2X̄`。

**两者比较**：

| 方法 | 估计量 | 特点 |
|---|---|---|
| MLE | `max(X₁,…,Xₙ)` | **一定 ≤ θ**（因为所有观测值都 ≤ θ），但系统性**偏低**（有偏） |
| 矩估计 | `2X̄` | **无偏**（`E(2X̄) = 2E(X) = θ`），但**可能大于 θ**（大约一半的概率） |

**答案**：MLE 为 `θ̂ = max(X₁, …, Xₙ)`；矩估计为 `θ̂ = 2X̄`。

> **重要启示**：
> ① **MLE 不一定无偏**（本例 MLE 的期望是 `nθ/(n+1) < θ`——可验证：`E[X₍ₙ₎] = nθ/(n+1)`）；
> ② **MLE 不一定从求导而来**——当参数控制取值范围时，必须分析单调性；
> ③ **无偏也不一定更好**：MLE 虽然偏低（期望只有 `nθ/(n+1)`），但它**永远 ≥ 样本最大值**，估计值本身不会自相矛盾；而 `2X̄` 虽然无偏，却**可能小于样本最大值**（此时连已有的观测都装不下），也可能远大于它，**单个样本上的波动明显更大**。实际中常用的折中是 `θ̂ = (n+1)/n · X₍ₙ₎`——既无偏，又保留了 MLE「一定不小于样本最大值」的合理性。

**例 6.5**（题型：无偏性与有效性的比较，证明题）
设总体 X 的 `E(X) = μ`，`D(X) = σ²`，`X₁, X₂, X₃` 为样本。考虑 `μ` 的两个估计量：
`μ̂₁ = (1/3)(X₁ + X₂ + X₃)`，　`μ̂₂ = (1/2)X₁ + (1/3)X₂ + (1/6)X₃`
① 验证二者都是 μ 的无偏估计；② 比较有效性，指出哪个更好。

**证明与计算**：
① **无偏性**（只需算期望，用线性性）：
`E(μ̂₁) = (1/3)(μ + μ + μ) = μ` ✓
`E(μ̂₂) = (1/2)μ + (1/3)μ + (1/6)μ = (1/2 + 1/3 + 1/6)μ = 1 · μ = μ` ✓
（**一般规律**：只要系数之和为 1，线性组合就是 μ 的无偏估计。）

② **方差比较**（需要独立性把方差相加）：
`D(μ̂₁) = (1/9)(σ² + σ² + σ²) = 3σ²/9 = σ²/3 ≈ 0.3333σ²`
`D(μ̂₂) = (1/2)²σ² + (1/3)²σ² + (1/6)²σ² = (1/4 + 1/9 + 1/36)σ²`
通分（公分母 36）：`= (9 + 4 + 1)/36 · σ² = 14σ²/36 = 7σ²/18 ≈ 0.3889σ²`
因为 `0.3333σ² < 0.3889σ²`，即 `D(μ̂₁) < D(μ̂₂)`，
故 **`μ̂₁` 比 `μ̂₂` 更有效**。

**答案**：两者都无偏；`μ̂₁` 更有效。

> **推广结论**：可以证明（柯西-施瓦茨不等式），在所有形如 `ΣcᵢXᵢ`（`Σcᵢ = 1`）的线性无偏估计中，**等权平均 `X̄` 的方差最小**。等权对应「各次观测同样可靠」，任何偏权都会放大总方差。这就是「多测几次取算术平均」在统计上最优的原因。

**例 6.6**（题型：σ 已知时均值的置信区间）
某厂生产的零件长度 `X ~ N(μ, σ²)`，由长期经验知 `σ = 0.2`（cm）。现随机抽取 9 个零件，测得样本均值 `X̄ = 10.2`（cm）。求 μ 的置信度为 0.95 的置信区间。

**解**：
**情形判断**：总体正态，**σ 已知**（0.2），故用 **Z 区间**。
`n = 9`，`σ = 0.2`，`X̄ = 10.2`，`1 − α = 0.95` ⟹ `α = 0.05`，`α/2 = 0.025`。
查标准正态表：`z_{0.025} = 1.96`（因为 `Φ(1.96) = 0.975`）。
**计算误差限**：
`σ/√n = 0.2/√9 = 0.2/3 = 0.06667`
`Δ = z_{α/2} · σ/√n = 1.96 × 0.06667 = 0.1307`
**写出区间**：
`μ ∈ (10.2 − 0.1307, 10.2 + 0.1307) = (10.069, 10.331)`

**答案**：μ 的 95% 置信区间为 **(10.069, 10.331)**（cm）。

> **正确解读**：在重复抽样中，用这个构造方法作出的区间约有 95% 会覆盖真实的 μ。**不能说「μ 落在 (10.069, 10.331) 内的概率是 0.95」**——μ 是常数。

**例 6.7**（题型：σ 未知时均值的置信区间，t 区间）
仍设零件长度 `X ~ N(μ, σ²)`，但 σ **未知**。随机抽取 10 个零件，测得 `X̄ = 10.2`，样本标准差 `S = 0.2`。求 μ 的置信度为 0.95 的置信区间，并与例 6.6 比较。

**解**：
**情形判断**：总体正态，**σ 未知**，故用 **t 区间**。
`n = 10`，自由度 `n − 1 = 9`，`α/2 = 0.025`。
查 t 分布表：`t_{0.025}(9) = 2.2622`。
**计算误差限**：
`S/√n = 0.2/√10 = 0.2/3.1623 = 0.06325`
`Δ = t_{α/2}(n−1) · S/√n = 2.2622 × 0.06325 = 0.1431`
**写出区间**：
`μ ∈ (10.2 − 0.1431, 10.2 + 0.1431) = (10.057, 10.343)`

**与例 6.6 比较**：

| 项目 | 例 6.6（σ 已知） | 例 6.7（σ 未知） |
|---|---|---|
| 临界值 | `z_{0.025} = 1.96` | `t_{0.025}(9) = 2.2622` |
| 标准误 | `σ/√n = 0.06667`（n = 9） | `S/√n = 0.06325`（n = 10） |
| 误差限 | 0.1307 | 0.1431 |
| 区间长度 | 0.2614 | 0.2862 |

**例 6.7 的区间更宽**，唯一原因是**临界值变大**：`t_{0.025}(9) = 2.2622 > z_{0.025} = 1.96`（比值 1.1542）——用样本标准差 `S` 替代真值 `σ` 引入了额外的不确定性，必须用更宽的临界值来补偿。注意**标准误反而更小**（`0.1431/2.2622 = 0.06325` 对 `0.1307/1.96 = 0.06667`，比值 0.9487，因为例 6.7 的 `n = 10` 比例 6.6 的 `n = 9` 更大），两个比值相乘 `1.1542 × 0.9487 = 1.0951`，正好得到 `0.1307 × 1.0951 = 0.1431` ✓。

**答案**：μ 的 95% 置信区间为 **(10.057, 10.343)**（cm）；比 σ 已知时更宽。

**例 6.8**（题型：正态总体方差的置信区间）
从某正态总体中抽取容量 `n = 16` 的样本，测得样本方差 `S² = 0.04`。求总体方差 `σ²` 与标准差 `σ` 的置信度为 0.95 的置信区间。

**解**：
**情形判断**：问的是**方差 σ²**，用 **χ² 区间**。
`n = 16`，自由度 `n − 1 = 15`，`α/2 = 0.025`，`1 − α/2 = 0.975`。
查 χ² 分布表：
`χ²_{0.025}(15) = 27.488`（右尾面积 0.025）
`χ²_{0.975}(15) = 6.262`（右尾面积 0.975）
**计算分子**：`(n − 1)S² = 15 × 0.04 = 0.6`
**写出 σ² 的区间**（分子相同，分母「大配小、小配大」）：
- 左端点 = `(n−1)S² / χ²_{α/2}(n−1) = 0.6 / 27.488 = 0.02183`
- 右端点 = `(n−1)S² / χ²_{1−α/2}(n−1) = 0.6 / 6.262 = 0.09582`

`σ² ∈ (0.02183, 0.09582)`

**σ 的区间（对 σ² 区间的两个端点直接开平方）**：
`σ ∈ (√0.02183, √0.09582) = (0.1477, 0.3095)`

> **为什么能直接开平方**：`σ = √(σ²)` 在 `σ² > 0` 上是**严格单调增**函数，所以 `σ² ∈ (L, U) ⟺ σ ∈ (√L, √U)`，置信度不变。（注意这是**函数的单调性**在起作用，不是最大似然估计的「不变性原理」——不变性原理讲的是 `g(θ̂)` 是 `g(θ)` 的 MLE，属于点估计范畴。）

**答案**：`σ²` 的 95% 置信区间为 **(0.02183, 0.09582)**；`σ` 的为 **(0.1477, 0.3095)**。

> **注意区间的不对称性**：点估计 `S² = 0.04` 并不在区间正中间（左端距 0.04 为 0.0182，右端距 0.04 为 0.0558）。原因是 **χ² 分布是右偏的**，其倒数分布也是偏的。这与均值的置信区间（关于 `X̄` 对称）形成对比——**记住「均值区间对称，方差区间不对称」**。

**例 6.9**（题型：两正态总体均值差的置信区间）
两台机床加工同一种零件，直径分别服从 `N(μ₁, σ²)` 与 `N(μ₂, σ²)`（方差相等但未知）。从第一台抽取 9 件，测得 `X̄ = 20.1`，`S₁ = 0.3`；从第二台抽取 11 件，测得 `Ȳ = 19.8`，`S₂ = 0.4`。求 `μ₁ − μ₂` 的置信度为 0.95 的置信区间，并据此判断两台机床加工的零件**平均直径**是否有显著差异。

**解**：
**情形判断**：两正态总体，`σ₁² = σ₂²` 未知，故用**合并方差的 t 区间**。
① **计算合并方差**：
`S_w² = [(n₁−1)S₁² + (n₂−1)S₂²] / (n₁+n₂−2) = [8 × 0.09 + 10 × 0.16] / (9 + 11 − 2)`
`= (0.72 + 1.60)/18 = 2.32/18 = 0.12889`
`S_w = √0.12889 = 0.35901`
② **计算标准误**：
`√(1/n₁ + 1/n₂) = √(1/9 + 1/11) = √(0.11111 + 0.09091) = √0.20202 = 0.44947`
`S_w · √(1/n₁ + 1/n₂) = 0.35901 × 0.44947 = 0.16137`
③ **查表**：自由度 `n₁ + n₂ − 2 = 18`，`t_{0.025}(18) = 2.1009`。
**误差限**：
`Δ = 2.1009 × 0.16137 = 0.33902`
④ **点估计**：`X̄ − Ȳ = 20.1 − 19.8 = 0.3`
⑤ **区间**：
`μ₁ − μ₂ ∈ (0.3 − 0.339, 0.3 + 0.339) = (−0.039, 0.639)`

**判断**：区间 **包含 0**，故不能认为 `μ₁ ≠ μ₂`，即**两台机床加工的零件平均直径没有显著差异**（在 95% 置信水平下）。

**答案**：`μ₁ − μ₂` 的 95% 置信区间为 **(−0.039, 0.639)**；无显著差异。

> **衔接第 7 章**：这个结论可以表述为「在显著性水平 α = 0.05 下，不能拒绝 `H₀: μ₁ = μ₂`」。**置信区间包含 0 ⟺ 双侧检验不拒绝 `H₀`**，这是两大推断方法的深刻联系（吴赣昌版第 6、7 章的桥梁）。

**例 6.10**（题型：样本容量的确定）
某总体 `X ~ N(μ, σ²)`，已知 `σ = 10`。若要以 95% 的置信度使 μ 的置信区间长度不超过 4，至少需要抽取多少个样本？

**解**：
**区间长度公式**：`L = 2Δ = 2 z_{α/2} σ/√n`（因为双侧区间是对称的）。
要求 `L ≤ 4`，即 `2 z_{α/2} σ/√n ≤ 4` ⟹ `z_{α/2} σ/√n ≤ 2`。
代入 `z_{0.025} = 1.96`，`σ = 10`：
`1.96 × 10/√n ≤ 2` ⟹ `19.6/√n ≤ 2` ⟹ `√n ≥ 9.8` ⟹ `n ≥ 96.04`
**为什么向上取整**：n 必须是整数，且必须满足不等式，故取 `n = 97`。

**答案**：至少需要 **97** 个样本。

> **成本启示**：若要求区间长度不超过 2（精度提高一倍），则 `√n ≥ 19.6`，`n ≥ 384.16`，需 **385** 个样本——**样本量增至约 4 倍**。这就是「精度翻倍、成本四倍」规律（`n ∝ 1/Δ²`）。实际调查设计中，「误差 ±3%、置信度 95%」对应 `n ≈ 1067`，正是这个公式算出来的。

## 易错点提醒

1. **把置信度的含义解释错**。
   **错在**：「参数 θ 落在该区间内的概率是 0.95」。
   **正确做法**：θ 是**未知常数**，不是随机变量。正确说法是「**用这个构造方法作出的区间，在重复抽样中约有 95% 会覆盖 θ**」。随机的是区间，不是参数。

2. **最大似然估计忘记「取对数」或忘记说明为什么可以取**。
   **错在**：直接对 `L(θ) = Πf(xᵢ;θ)` 求导。
   **正确做法**：**先取对数**把乘积变和，再求导。要说明「因为 `ln` 是单调增函数，`L` 与 `ln L` 有相同的最大值点」。

3. **均匀分布 MLE 硬套求导法**。
   **错在**：对 `L(θ) = θ^(−n)` 求导令零，得到「无解」就卡住了。
   **正确做法**：识别出这是**非正则情形**——参数出现在取值范围的边界。**回到 L(θ) 本身分析单调性**：`θ^(−n)` 关于 θ 递减，故在允许范围 `θ > max(xᵢ)` 的最小值处取最大，即 `θ̂ = max(x₁,…,xₙ)`。

4. **样本方差与 MLE 的方差混淆**。
   **错在**：把正态总体 `σ²` 的 MLE 写成 `S² = 1/(n−1)Σ(Xᵢ−X̄)²`。
   **正确做法**：正态总体 `σ²` 的 **MLE 是 `(1/n)Σ(Xᵢ − X̄)²`（分母 n）**，它是**有偏的**；而 `S² = 1/(n−1)Σ(Xᵢ−X̄)²` 是**无偏估计**。题目若问「最大似然估计」，必须写分母 n 的那个。

5. **置信区间选择统计量时搞错 σ 是否已知**。
   **错在**：题目给了 `S`（样本标准差）却用 `z` 查表。
   **正确做法**：**看到 `S` 就用 t，看到 `σ` 才用 z**。`σ` 是**总体的、已知的常数**；`S` 是**样本算出来的**。题目若只说「测得样本标准差 0.2」，那就是 σ 未知，用 t。

6. **σ² 的置信区间端点写反**。
   **错在**：写成 `((n−1)S²/χ²_{1−α/2}, (n−1)S²/χ²_{α/2})`。
   **正确做法**：`χ²_{1−α/2}(n−1) < χ²_{α/2}(n−1)`，**分母大的给出小的端点**。正确形式是
   `( (n−1)S²/χ²_{α/2}(n−1), (n−1)S²/χ²_{1−α/2}(n−1) )`——**左端用 α/2 分位点，右端用 1−α/2 分位点**（与均值的区间「左小右大」顺序相反，因为这里分母的位置反了）。

7. **忘记 `S_w²` 的权重是自由度**。
   **错在**：写成 `S_w² = (S₁² + S₂²)/2`（简单平均）。
   **正确做法**：`S_w² = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2)`——**按自由度加权**。样本量大的那组信息更多，权重应更大。

8. **单侧置信区间的临界值仍用 α/2**。
   **错在**：求 95% 单侧下限时用 `z_{0.025} = 1.96`。
   **正确做法**：单侧用 `z_α`，即 `z_{0.05} = 1.645`。**单侧区间比双侧窄**。

9. **把「无偏」当成「每次都对」**。
   **错在**：认为无偏估计的每次取值都接近真值。
   **正确做法**：无偏性说的是**平均而言**恰好。一个无偏估计单次可能偏离很远。要看「稳不稳」还得看**方差**（有效性）。

10. **最大似然估计与矩估计结果不同时以为算错了**。
    **错在**：两种方法给出不同答案就怀疑自己。
    **正确做法**：**两者本来就常常不同**（如 `U(0,θ)`：MLE 得 `max(Xᵢ)`，矩估计得 `2X̄`）。它们基于不同的原理，都可能正确。题目问哪种方法就用哪种。

11. **置信区间长度与 n 的关系记错**。
    **错在**：以为「样本量加倍，区间长度减半」。
    **正确做法**：`Δ ∝ 1/√n`。**样本量加倍，区间长度只缩短到约 71%（1/√2）**；要长度减半，样本量需增至 4 倍。

12. **两总体区间估计时误用单总体公式**。
    **错在**：把两样本合并成一个样本算 `X̄` 和 `S`。
    **正确做法**：两总体均值差要用 `(X̄ − Ȳ)`、`S_w`、`√(1/n₁ + 1/n₂)` 的组合，自由度是 `n₁+n₂−2`。**两组数据来自不同的总体，绝不可混在一起平均。**

## 本章小结

- **点估计**就是用一个统计量 `θ̂` 去近似未知参数 `θ`；**估计量是随机变量，估计值是数字**。
- **评选标准**：**无偏性**（`E(θ̂) = θ`，平均打中）、**有效性**（无偏中方差最小）、**一致性**（n→∞ 时收敛到 θ）。
- `X̄` 是 `μ` 的无偏估计；`S²`（分母 `n−1`）是 `σ²` 的无偏估计；`B₂`（分母 `n`）不是。
- **矩估计**：令 `E(X) = X̄`（多参数时再令 `E(X²) = A₂`）解方程。简单但可能不唯一、不合理。
- **最大似然估计**：`L(θ) = Πf(xᵢ;θ)` → 取对数 → 求导令零 → 解出 `θ̂`。**参数控制取值范围时不能用求导法**，要分析单调性。
- **不变性原理**：`g(θ̂)` 是 `g(θ)` 的 MLE（如 `σ̂ = √(σ̂²)`）。
- **置信区间** `(θ̂_L, θ̂_U)` 满足 `P(θ̂_L < θ < θ̂_U) = 1 − α`。**正确解读**：重复抽样中约 `1−α` 比例的区间覆盖 θ；**θ 不是随机的**。
- **枢轴量法四步**：找枢轴量 → 定常数 → 等价变形 → 写区间。
- **四大区间公式**（必须背）：
  - σ 已知估 μ：`X̄ ± z_{α/2}·σ/√n`
  - σ 未知估 μ：`X̄ ± t_{α/2}(n−1)·S/√n`
  - 估 σ²：`( (n−1)S²/χ²_{α/2}(n−1), (n−1)S²/χ²_{1−α/2}(n−1) )`
  - 估 μ₁−μ₂（σ₁²=σ₂² 未知）：`(X̄−Ȳ) ± t_{α/2}(n₁+n₂−2)·S_w·√(1/n₁+1/n₂)`
- **精度与样本量**：`Δ = z_{α/2}σ/√n`，故 `n = (z_{α/2}σ/Δ)²`。**精度翻倍需样本量四倍**。
- **区间是否含 0** 是判断「两均值有无显著差异」的快捷方法（与第 7 章假设检验等价）。
- **一句话记住本章**：**点估计给一个数（用 MLE 或矩法），区间估计给一个范围（用 Z/t/χ²/F 四把尺子）；而选哪把尺子只看两件事——估的是均值还是方差、σ 知道不知道。**

## 自测题

1. 设总体 `X ~ P(λ)`（泊松分布），`X₁, …, Xₙ` 为样本。求 `λ` 的矩估计量与最大似然估计量。
2. 设总体 X 的密度为 `f(x) = θx^(θ−1)`（0 < x < 1，θ > 0），求 θ 的矩估计量。
3. 设总体 `X ~ U(0, θ)`，样本观测值为 2.1, 3.5, 1.8, 4.2, 2.9。求 θ 的最大似然估计值与矩估计值。
4. 设总体 `X ~ N(μ, σ²)`，`X₁, …, Xₙ` 为样本。求 `μ` 与 `σ²` 的最大似然估计量（注意 σ² 的分母）。
5. 设 `X₁, X₂` 是来自总体 `X` 的样本，`E(X) = μ`，`D(X) = σ²`。验证 `μ̂₁ = (1/2)(X₁ + X₂)` 与 `μ̂₂ = (1/3)X₁ + (2/3)X₂` 都是 μ 的无偏估计，并比较有效性。
6. 某正态总体 `σ = 2` 已知，抽取 `n = 16` 的样本，`X̄ = 12`。求 μ 的 95% 置信区间。
7. 某正态总体 σ 未知，抽取 `n = 9` 的样本，`X̄ = 12`，`S = 2`。求 μ 的 95% 置信区间（`t_{0.025}(8) = 2.3060`）。
8. 某正态总体抽取 `n = 10` 的样本，`S² = 0.25`。求 `σ²` 的 95% 置信区间（`χ²_{0.025}(9) = 19.023`，`χ²_{0.975}(9) = 2.700`）。
9. 若要求 μ 的 95% 置信区间长度不超过 1，已知 `σ = 5`，至少需抽取多少个样本？
10. 两独立正态总体方差相等但未知。`n₁ = 10`，`X̄ = 5.2`，`S₁² = 0.4`；`n₂ = 12`，`Ȳ = 4.8`，`S₂² = 0.6`。求 `μ₁ − μ₂` 的 95% 置信区间（`t_{0.025}(20) = 2.0860`），并判断差异是否显著。

### 自测题答案

1. **矩估计**：`E(X) = λ`，令 `λ = X̄`，得 `λ̂ = X̄`。
   **MLE**：`L(λ) = Π λ^(xᵢ) e^(−λ)/xᵢ! = λ^(Σxᵢ) e^(−nλ) / Πxᵢ!`
   `ln L = (Σxᵢ)ln λ − nλ − ln(Πxᵢ!)`
   `d ln L/dλ = (Σxᵢ)/λ − n = 0` ⟹ `λ̂ = (1/n)ΣXᵢ = X̄`。
   两者一致。
2. `E(X) = ∫_0^1 x·θx^(θ−1)dx = θ∫_0^1 x^θ dx = θ/(θ+1)`
   令 `θ/(θ+1) = X̄` ⟹ `θ = X̄θ + X̄` ⟹ `θ̂ = X̄/(1 − X̄)`。
3. **MLE**：`θ̂ = max(xᵢ) = 4.2`。
   **矩估计**：`E(X) = θ/2 = X̄`，`X̄ = (2.1+3.5+1.8+4.2+2.9)/5 = 14.5/5 = 2.9`，
   `θ̂_矩 = 2 × 2.9 = 5.8`。
4. `L(μ, σ²) = (2πσ²)^(−n/2) exp[ −(1/(2σ²))Σ(xᵢ − μ)² ]`
   `ln L = −(n/2)ln(2π) − (n/2)ln σ² − (1/(2σ²))Σ(xᵢ − μ)²`
   对 μ 求偏导：`(1/σ²)Σ(xᵢ − μ) = 0` ⟹ **`μ̂ = X̄`**
   对 σ² 求偏导：`−n/(2σ²) + (1/(2σ⁴))Σ(xᵢ − μ)² = 0` ⟹ **`σ̂² = (1/n)Σ(Xᵢ − X̄)²`**
   （**注意分母是 n，不是 n−1**，故 `σ̂²` 是**有偏**的；`S²` 才是无偏的。）
5. `E(μ̂₁) = (1/2)(μ + μ) = μ` ✓；`E(μ̂₂) = (1/3)μ + (2/3)μ = μ` ✓
   `D(μ̂₁) = (1/4)(σ² + σ²) = σ²/2 = 0.5σ²`
   `D(μ̂₂) = (1/9)σ² + (4/9)σ² = 5σ²/9 ≈ 0.5556σ²`
   因为 `0.5σ² < 0.5556σ²`，故 **`μ̂₁`（等权平均）更有效**。
6. `σ = 2`，`n = 16`，`z_{0.025} = 1.96`。
   `σ/√n = 2/4 = 0.5`，`Δ = 1.96 × 0.5 = 0.98`
   区间：`(12 − 0.98, 12 + 0.98) = (11.02, 12.98)`
7. `n = 9`，`S = 2`，`t_{0.025}(8) = 2.3060`。
   `S/√n = 2/3 = 0.6667`，`Δ = 2.3060 × 0.6667 = 1.5373`
   区间：`(12 − 1.537, 12 + 1.537) = (10.463, 13.537)`
8. `n = 10`，自由度 9，`(n−1)S² = 9 × 0.25 = 2.25`。
   左端点 `= 2.25/19.023 = 0.1183`
   右端点 `= 2.25/2.700 = 0.8333`
   区间：`σ² ∈ (0.1183, 0.8333)`；`σ ∈ (0.3439, 0.9129)`
9. `L = 2z_{α/2}σ/√n ≤ 1` ⟹ `√n ≥ 2 × 1.96 × 5 = 19.6` ⟹ `n ≥ 384.16`
   取 **n = 385**。
10. `S_w² = [(10−1)(0.4) + (12−1)(0.6)]/(10+12−2) = (3.6 + 6.6)/20 = 10.2/20 = 0.51`
    `S_w = √0.51 = 0.71414`
    `√(1/10 + 1/12) = √(0.1 + 0.08333) = √0.18333 = 0.42817`
    `S_w × 0.42817 = 0.30580`
    `Δ = t_{0.025}(20) × 0.30580 = 2.0860 × 0.30580 = 0.63790`
    点估计 `= 5.2 − 4.8 = 0.4`
    区间：`μ₁ − μ₂ ∈ (0.4 − 0.638, 0.4 + 0.638) = (−0.238, 1.038)`
    **区间包含 0**，故在 95% 置信水平下**不能认为两总体均值有显著差异**。
