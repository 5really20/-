## 10.1 随机过程的基本概念

### 10.1.1 从随机变量到随机过程

第 2~3 章研究的是**有限个**随机变量（`X`、`(X, Y)`）。但很多现象需要**用一整个时间轴上的随机变量族**来描述：

- 某网站**一天中每个时刻**的访问请求数；
- 某只股票**每个交易日**的收盘价；
- 通信信道中**每个时刻**的噪声电压。

这些对象的共同点是：**固定一个时刻 `t`，它是一个随机变量；固定一次试验结果，它是一条随时间变化的曲线。**

**定义（随机过程，Stochastic Process）**：设 `T` 是一个参数集（通常代表时间），若对每个 `t ∈ T`，`X(t)` 都是一个随机变量，则称随机变量族

`{ X(t), t ∈ T }`

为一个**随机过程**。

- `T` 称为**参数集**（或指标集）。`T = {0, 1, 2, …}` 时称**离散参数过程**（随机序列）；`T = [0, +∞)` 时称**连续参数过程**。
- `X(t)` 所有可能取值的集合称为**状态空间** `S`。`S` 离散时称**离散状态过程**，`S` 连续时称**连续状态过程**。

> **两种视角（理解随机过程的关键）**：
> - **固定 `t`**：`X(t)` 是一个**随机变量**（如「今天 12:00 的访问量」）；
> - **固定一次试验（一个样本点 `ω`）**：`X(t, ω)` 是 `t` 的一条**确定性函数曲线**，称为该过程的一个**样本函数**（或**轨道**、**实现**）。
>
> **一个随机过程 = 一族样本函数的集合 + 每条曲线出现的概率**。这与「随机变量 = 样本空间到实数的映射」是同一思想的高维推广。

### 10.1.2 随机过程的分类

| 参数集 `T` | 状态空间 `S` | 名称 | 典型例子 |
|---|---|---|---|
| 离散 | 离散 | **离散参数离散状态过程**（随机序列 / 链） | 马尔可夫链、伯努利过程、赌徒输赢 |
| 离散 | 连续 | 离散参数连续状态过程 | AR(1) 时间序列、每日股票收益率 |
| 连续 | 离散 | **连续参数离散状态过程**（计数过程） | 泊松过程、排队系统、放射性衰变 |
| 连续 | 连续 | **连续参数连续状态过程** | 维纳过程（布朗运动）、通信噪声 |

> **记忆口诀**：**先看时间是「跳着走」还是「连着走」，再看取值是「数得清」还是「数不清」。**

### 10.1.3 有限维分布函数族

**定义**：对任意 `n ≥ 1` 和任意 `t₁ < t₂ < … < tₙ ∈ T`，定义 n 维分布函数

`F(x₁, …, xₙ; t₁, …, tₙ) = P{ X(t₁) ≤ x₁, …, X(tₙ) ≤ xₙ }`

所有这些分布函数的全体 `{ F(x₁, …, xₙ; t₁, …, tₙ) : n ≥ 1 }` 称为该过程的**有限维分布函数族**。

**为什么重要**：**有限维分布函数族完整地刻画了一个随机过程**——知道它，就知道过程的一切概率性质。这与第 3 章「联合分布函数完整刻画 `(X, Y)`」是同一个道理。

**两条相容性条件**（了解即可，考试不考）：
① **对称性**：把 `(tᵢ, xᵢ)` 的次序任意调换，`F` 不变；
② **相容性**：对任意 `m < n`，`F(x₁, …, x_m, +∞, …, +∞; t₁, …, tₙ) = F(x₁, …, x_m; t₁, …, t_m)`。

（**柯尔莫哥洛夫存在定理**：任一满足对称性与相容性的有限维分布函数族，必存在一个随机过程以它为有限维分布族。这是随机过程理论的基石。）

### 10.1.4 随机过程的数字特征

**① 均值函数（Mean Function）**

`μ_X(t) = E[X(t)]`

**② 方差函数（Variance Function）**

`D_X(t) = Var[X(t)] = E{[X(t) − μ_X(t)]²}`

**③ 自相关函数（Autocorrelation Function）**

`R_X(s, t) = E[X(s) · X(t)]`

**④ 自协方差函数（Autocovariance Function）**

`C_X(s, t) = Cov[X(s), X(t)] = E{[X(s) − μ_X(s)][X(t) − μ_X(t)]}`

**四者关系（必记）**：

`C_X(s, t) = R_X(s, t) − μ_X(s) · μ_X(t)`

特别地，取 `s = t`：

`D_X(t) = C_X(t, t) = R_X(t, t) − μ_X(t)²`

> **它与第 4 章的关系**：`D(X) = E(X²) − [E(X)]²` 这个公式，在随机过程里变成了 `D_X(t) = R_X(t,t) − μ_X(t)²`。**把「某个随机变量」换成「时刻 `t` 的随机变量」，公式一字不改。** 这不是新知识，而是旧知识在时间维度上的展开。
>
> **为什么用 `R` 而不是 `C` 作为核心工具**：当过程是**零均值**时（`μ_X(t) ≡ 0`），`C_X(s,t) = R_X(s,t)`，两者重合。信号处理中常先**去均值**，之后 `R` 就足够用了。所以教材和工程文献里 `R` 出现得更多。

## 10.2 泊松过程与维纳过程

### 10.2.1 泊松过程

**① 计数过程**

**定义**：若 `N(t)` 表示在时间区间 `[0, t]` 内**某事件发生的次数**，则 `{ N(t), t ≥ 0 }` 称为**计数过程（Counting Process）**。它必须满足：
- `N(t) ≥ 0` 且取整数值；
- `s < t` 时 `N(s) ≤ N(t)`（**单调不减**——次数只会增加）；
- `N(t) − N(s)` 表示区间 `(s, t]` 内事件发生的次数。

**② 泊松过程的定义**

**定义**：计数过程 `{ N(t), t ≥ 0 }` 若满足下列三条，则称为强度为 `λ` 的**泊松过程（Poisson Process）**：

① `N(0) = 0`；
② **独立增量性**：任意 `n` 个互不重叠的时间区间上的增量 `N(t₁) − N(t₀)`、`N(t₂) − N(t₁)`、… **相互独立**；
③ **平稳增量性**：对任意 `s < t`，增量 `N(t) − N(s)` 的分布只依赖于**区间长度** `t − s`，且

`N(t) − N(s) ~ P( λ(t − s) )`

即 `P{ N(t) − N(s) = k } = [λ(t − s)]ᵏ · e^{−λ(t − s)} / k!`，`k = 0, 1, 2, …`

特别地，取 `s = 0` 并用 `N(0) = 0`：

**`N(t) ~ P(λt)`，即 `P{ N(t) = k } = (λt)ᵏ · e^{−λt} / k!`，`k = 0, 1, 2, …`**

> **三条条件的直观含义**：
> - **① 从零开始计数**；
> - **② 独立增量**：已经发生的次数**不影响**未来的发生规律（**无记忆性**在计数层面的体现）；
> - **③ 平稳增量**：**「什么时候开始数」不影响分布**——上午 9 点开始的 1 小时和下午 3 点开始的 1 小时，请求次数的分布完全相同。
>
> **`λ` 的含义**：**单位时间内的平均发生次数**（强度 / 速率），量纲是「次/单位时间」。

**③ 数字特征**

`E[N(t)] = λt`，　`D[N(t)] = λt`

（因为 `N(t) ~ P(λt)`，而泊松分布的期望与方差都等于参数 `λt`。）

**④ 到达间隔与到达时刻**

设 `T₁` 为第一次事件发生的等待时间，`T₂` 为第一次到第二次之间的间隔，一般地 `Tₙ` 为第 `n−1` 次到第 `n` 次事件之间的时间间隔（称为**到达间隔时间**）。

**定理一（间隔服从指数分布）**：`T₁, T₂, T₃, …` **相互独立**，且都服从参数为 `λ` 的**指数分布**：

`Tₙ ~ E(λ)`，密度 `f(t) = λe^{−λt}`（`t > 0`），`E(Tₙ) = 1/λ`，`D(Tₙ) = 1/λ²`

**定理二（到达时刻服从 Γ 分布）**：设 `Wₙ = T₁ + T₂ + … + Tₙ` 为**第 `n` 次事件发生的时刻**，则

`Wₙ ~ Γ(n, λ)`，密度 `f_{Wₙ}(t) = λ(λt)^{n−1} e^{−λt} / (n − 1)!`（`t > 0`），`E(Wₙ) = n/λ`

> **这两条定理是泊松过程的「灵魂」**，务必牢记：
> - **间隔 → 指数分布**（`n = 1` 的 Γ 分布就是指数分布）；
> - **第 n 次到达时刻 → Γ 分布**（`n` 个独立同分布的指数分布之和）。
>
> **与第 2 章的联系**：指数分布是唯一具有**无记忆性**的连续分布，这正是泊松过程独立增量性的必然结果。Γ 分布是可加性的直接体现（第 2 章已证：独立的 `Γ(α₁, λ)` 与 `Γ(α₂, λ)` 之和是 `Γ(α₁ + α₂, λ)`）。
>
> **工程上最常用的两条**：
> - **平均间隔 = `1/λ`**（如 `λ = 3` 次/分钟 ⇒ 平均每 20 秒一次）；
> - **`P(T > t) = e^{−λt}`**（如「至少 1 分钟没有请求」的概率 = `e^{−3} = 0.0498`）。

**⑤ 典型应用**

| 领域 | 事件 | 强度 `λ` |
|---|---|---|
| 通信 | 网络请求到达 | 请求数/秒 |
| 排队论 | 顾客到达 | 人/分钟 |
| 物理学 | 放射性衰变 | 衰变数/秒 |
| 生物学 | 神经元放电 | 脉冲数/秒 |
| 可靠性 | 元件故障（早期失效后） | 故障数/千小时 |

> **泊松过程的适用范围（重要）**：它要求事件**「稀有、独立、速率恒定」**。因此**不适用**于：
> - **有高峰期的流量**（早高峰请求速率是凌晨的几十倍，平稳增量性不成立）——此时应用**非齐次泊松过程**（`λ(t)` 随 `t` 变化）；
> - **成批到达的事件**（一次请求带来多个连接）——应用**复合泊松过程**；
> - **有强相关的事件**（地震后的余震）——应用**自激过程**（Hawkes 过程）。
> **考试时若题目说「服从泊松过程」，就一定可以直接用公式；但在实际建模中，先检验这三条是否成立。**

### 10.2.2 维纳过程（布朗运动）

**定义**：随机过程 `{ W(t), t ≥ 0 }` 若满足

① `W(0) = 0`；
② **独立增量性**：不重叠区间上的增量相互独立；
③ **平稳增量性**：对任意 `s < t`，

`W(t) − W(s) ~ N( 0, σ²(t − s) )`

则称它为**维纳过程（Wiener Process）**，也称**布朗运动（Brownian Motion）**。当 `σ² = 1` 时称**标准维纳过程**。

**数字特征**：

`μ_W(t) = E[W(t)] = 0`，　`D_W(t) = Var[W(t)] = σ²t`

**自协方差函数**（设 `s ≤ t`，标准情形 `σ² = 1`）：

`C_W(s, t) = Cov[W(s), W(t)] = min(s, t)`

**推导思路**（理解为什么是 `min(s, t)`）：设 `s ≤ t`，则
`Cov[W(s), W(t)] = Cov[ W(s), W(s) + (W(t) − W(s)) ]`
`= Cov[W(s), W(s)] + Cov[ W(s), W(t) − W(s) ]`
`= Var[W(s)] + 0 = s = min(s, t)`
（**为什么第二项为 0**：由独立增量性，`W(s)` 只依赖 `[0, s]` 上的增量，而 `W(t) − W(s)` 依赖 `(s, t]`，两者独立，故协方差为 0。）

> **维纳过程的三条直观特征**（与泊松过程的对比是本节的考点）：

| 特征 | 泊松过程 `N(t)` | 维纳过程 `W(t)` |
|---|---|---|
| 状态空间 | 离散（非负整数） | 连续（实数） |
| 路径形态 | **阶梯函数**（跳跃式上升） | **连续但处处不可微**（锯齿状抖动） |
| 增量分布 | 泊松 `P(λ(t−s))` | 正态 `N(0, σ²(t−s))` |
| 均值 | `λt`（随时间增长） | `0`（始终在 0 附近摆动） |
| 方差 | `λt` | `σ²t` |
| 典型来源 | 计数事件 | 大量微小独立扰动的累积 |

> **共同的深刻之处**：**两者的方差都与时间成正比（`λt` 与 `σ²t`）**，因而**标准差与 `√t` 成正比**。这带来一个著名结论：**随机游走的典型位移是 `√t` 量级，而不是 `t` 量级**。
> **应用**：这解释了为什么「扩散过程需要 `t²` 的时间才能走 `t` 的距离」（扩散方程），也是**为什么 `√n` 会出现在中心极限定理与所有标准误公式里**的原因——它们本质上是同一个事实的不同侧面。

**布朗运动的由来**：1827 年植物学家 Robert Brown 观察到悬浮在液体中的花粉微粒做**永不停止的无规则抖动**；1905 年爱因斯坦用分子碰撞解释之；1923 年维纳给出了严格的数学定义。它是**金融数学**中 Black-Scholes 期权定价公式的核心——股价常被建模为**几何布朗运动** `S(t) = S(0)·exp( (μ − σ²/2)t + σW(t) )`。

## 10.3 马尔可夫链

### 10.3.1 定义与马尔可夫性

**定义**：设随机序列 `{ X_n, n = 0, 1, 2, … }` 的状态空间 `S` 为有限集或可列集（如 `S = {0, 1, 2, …}`）。若对任意 `n ≥ 0` 和任意状态 `i₀, i₁, …, i_{n−1}, i, j`，都有

`P{ X_{n+1} = j | X_n = i, X_{n−1} = i_{n−1}, …, X₀ = i₀ } = P{ X_{n+1} = j | X_n = i }`

则称 `{ X_n }` 为**马尔可夫链（Markov Chain）**，上述性质称为**马尔可夫性**或**无后效性**。

> **一句话理解**：**「未来只取决于现在，与如何走到现在无关」。**
>
> **生活类比——下棋**：下一步怎么走，只取决于**当前棋盘的局势**（现在），而不取决于你是从哪一步走过来的（过去）。因此**棋局是一个马尔可夫链**。
> **反例——考试复习**：你明天能记住多少，不仅取决于今天学了什么（现在），还取决于**前几天的复习累积**（过去）。**这不是马尔可夫链**，需要扩展状态（把「前几天学了什么」也编进状态里）。

> **「无后效性」≠「与过去无关」**：注意，`X_n` 本身是**通过历史演化来的**，它已经「记住了」过去的信息。无后效性说的是：**一旦 `X_n` 已知，更早的历史对预测未来再无额外信息量**。这在信息论里就是条件独立：`X_{n+1} ⊥ (X_{n−1}, X_{n−2}, …) | X_n`。

**时齐（齐次）马尔可夫链**：若 `P{ X_{n+1} = j | X_n = i }` **与 `n` 无关**，则称链是**时齐的（homogeneous）**，记

`p_ij = P{ X_{n+1} = j | X_n = i }`

称为**一步转移概率**。教材与本章讨论的都是时齐链。

### 10.3.2 转移矩阵及其性质

把所有 `p_ij` 排成矩阵（状态可列时是无穷阶，有限状态时是 `N × N`）：

```
        ┌                        ┐
        │  p₀₀  p₀₁  p₀₂  ...    │
P   =   │  p₁₀  p₁₁  p₁₂  ...    │
        │  p₂₀  p₂₁  p₂₂  ...    │
        │  ...  ...  ...  ...    │
        └                        ┘
```

`P` 称为**转移概率矩阵**（简称**转移矩阵**）。

**两条基本性质（必须会验证）**：

① **非负性**：`p_ij ≥ 0`（对一切 `i, j`）；
② **行和为 1**：`Σ_j p_ij = 1`（对每个 `i`）。

> **为什么行和为 1**：从状态 `i` 出发，**下一步必然转移到某个状态**（包括停留在 `i`），所以对 `j` 求和得到的是「必然事件的概率」，等于 1。
>
> **⚠️ 最常见的错误**：**行和为 1，不是列和为 1**。
> **记忆方法**：`p_ij` 读作「从 `i` **出发**到 `j`」，`i` 是**起点**。**起点固定（行固定），终点走遍所有可能（列求和）**，所以是**行和**为 1。
> **速查**：若一个矩阵每行加起来都是 1，它就是合法的转移矩阵；若每列加起来是 1，那它是**转置**了（对应「逆向链」）。

**初始分布与绝对分布**：

设初始分布为 `π(0) = (π₀(0), π₁(0), …)`，其中 `πᵢ(0) = P{X₀ = i}`。记 `π(n)` 为第 `n` 步的**绝对分布**（`πⱼ(n) = P{X_n = j}`），则

`π(1) = π(0) P`，　`π(2) = π(1) P = π(0) P²`，　…，　`π(n) = π(0) Pⁿ`

### 10.3.3 n 步转移概率与 C-K 方程

**定义**：`p_ij⁽ⁿ⁾ = P{ X_{m+n} = j | X_m = i }` 称为**n 步转移概率**（时齐性保证它与 `m` 无关）。

**切普曼-柯尔莫哥洛夫方程（Chapman-Kolmogorov 方程）**：

`p_ij⁽ᵐ⁺ⁿ⁾ = Σ_k p_ik⁽ᵐ⁾ · p_kj⁽ⁿ⁾`

用矩阵写就是极其简洁的

**`P⁽ᵐ⁺ⁿ⁾ = P⁽ᵐ⁾ · P⁽ⁿ⁾`，　特别地　`P⁽ⁿ⁾ = Pⁿ`**

> **C-K 方程的直观解释（全概率公式的矩阵版）**：
> 「从 `i` 出发走 `m + n` 步到 `j`」可以按**中途第 `m` 步落在哪个状态 `k`** 来分类：先走 `m` 步到 `k`，再从 `k` 走 `n` 步到 `j`，对所有的 `k` 求和。这正是**全概率公式**（第 1 章 1.4.3 节）。
>
> **它的巨大威力**：**求 n 步转移概率 = 求矩阵的 n 次幂**。这把概率问题转化成了线性代数问题，也是 PageRank 算法能在大规模图上高效计算的原因。
>
> **⚠️ 注意**：`P⁽ⁿ⁾ = Pⁿ` 中的 `Pⁿ` 是**矩阵乘法**（`n−1` 次矩阵相乘），**不是**矩阵元素的逐项 `n` 次方！`p_ij⁽ⁿ⁾ ≠ (p_ij)ⁿ`，这是最常犯的错误。

### 10.3.4 遍历性与平稳分布

**定义（遍历性 / 各态历经性）**：若对一切 `i, j`，极限

`lim_{n→∞} p_ij⁽ⁿ⁾ = π_j`

存在且**与起点 `i` 无关**，则称该链具有**遍历性**。此时 `π = (π₀, π₁, …)` 称为**极限分布**。

**定义（平稳分布）**：若概率分布 `π = (π₀, π₁, …)` 满足

**`π = π P`**　且　`Σ_j π_j = 1`，`π_j ≥ 0`

则称 `π` 为该链的**平稳分布**（或**不变分布**）。

**核心结论**：**对不可约、非周期、正常返的马尔可夫链，平稳分布存在且唯一，并且它就等于极限分布**（即 `π_j = lim_{n→∞} p_ij⁽ⁿ⁾`）。

**平稳分布的含义**：
- **「平稳」**：若初始分布取为 `π`，则 `π(1) = πP = π`，即**分布不再随时间改变**；
- **「极限」**：无论从哪个状态出发，**长期来看处于状态 `j` 的概率都是 `π_j`**；
- **「频率」**：`π_j` 也是**长期运行中处于状态 `j` 的时间比例**。

**求解平稳分布的标准流程（四步）**：

① 写出方程组 `π = πP`，即对每个 `j`：`π_j = Σ_i π_i p_ij`；
② **丢掉其中一个方程**（因为行和为 1 导致这些方程线性相关，全用会无解）；
③ 补上**归一化方程** `Σ_j π_j = 1`；
④ 解线性方程组，得到 `π`。

> **为什么要丢掉一个方程**：`π = πP` 意味着 `π(P − I) = 0`，即 `π` 是 `P'` 的**特征值 1 对应的特征向量**。由行和为 1 可知 `P·1 = 1`（全 1 向量是特征向量），故 `P − I` **必有零特征值**，矩阵**奇异**，方程组**线性相关**，必须靠归一化条件补足。
>
> **这是考试最容易卡住的地方**：**忘了丢掉一个方程**，就会解出「`0 = 0`」而卡住，或者虽能解出一族解却定不出唯一的概率分布。

> **马尔可夫链在计算机领域的三大应用**：
> - **PageRank**：把网页看作状态，链接看作转移，`π_j` 就是网页 `j` 的排名权重；
> - **MCMC（马尔可夫链蒙特卡洛）**：构造一个以目标分布为平稳分布的马尔可夫链，跑足够多步后采样，从而对**无法解析求积的复杂分布**做贝叶斯推断；
> - **强化学习（MDP）**：把「状态 + 动作」看作马尔可夫链，策略评估就是求它的平稳分布下的期望回报。

## 10.4 平稳随机过程

### 10.4.1 严平稳与宽平稳

**定义一（严平稳 / 狭义平稳）**：若对任意 `n ≥ 1`、任意 `t₁, …, tₙ ∈ T` 和任意实数 `τ`，`( X(t₁), …, X(tₙ) )` 与 `( X(t₁+τ), …, X(tₙ+τ) )` 有相同的联合分布，则称 `{ X(t) }` 为**严平稳过程**。

> **含义**：**概率规律不随时间的平移而改变**。把整条时间轴左右平移，统计特性完全一样。

**定义二（宽平稳 / 弱平稳 / 二阶平稳）**：若 `{ X(t) }` 的**二阶矩存在**，且满足

① **均值是常数**：`μ_X(t) = μ_X`（与 `t` 无关）；
② **自相关函数只依赖时间差**：`R_X(s, t) = R_X(t − s) = R_X(τ)`（记 `τ = t − s`），

则称它为**宽平稳过程**。

**两者的关系**：

| 比较项 | 严平稳 | 宽平稳 |
|---|---|---|
| 要求 | 所有有限维分布平移不变 | **只要求一、二阶矩**平移不变 |
| 条件强度 | 强 | 弱 |
| 包含关系 | 严平稳 **+ 二阶矩存在** ⟹ 宽平稳 | 宽平稳 **⇏** 严平稳 |

> **唯一的例外（重要）**：**若过程是正态过程（高斯过程），则宽平稳 ⟺ 严平稳**。因为正态分布完全由均值向量和协方差矩阵决定，而宽平稳恰好保证了这两者平移不变，从而所有有限维分布都平移不变。
>
> **为什么工程上几乎只用宽平稳**：**严平稳需要验证所有维数的联合分布，实践中根本做不到**；而宽平稳只需要均值、方差、自相关函数这三个**可以用样本估计出来**的量。**所以「平稳」在工程语境下默认指宽平稳。**

### 10.4.2 自相关函数的性质

设 `{ X(t) }` 是宽平稳过程，`R(τ) = E[X(t) X(t + τ)]`（为简化，设 `μ_X = 0`；若均值非零，改用 `C(τ)`）。则：

**① 偶函数**：`R(−τ) = R(τ)`

**② `R(0)` 是非负实数且为最大值**：`R(0) = E[X²(t)] = D_X + μ_X² ≥ 0`，且

`|R(τ)| ≤ R(0)`

**③ 非负定性**：对任意 `n`、任意 `t₁, …, tₙ` 和任意实数 `a₁, …, aₙ`，

`Σᵢ Σⱼ aᵢ aⱼ R(tᵢ − tⱼ) ≥ 0`

（了解即可。它的意义是：**不是随便一个函数都能当自相关函数**。）

> **性质②的证明（用柯西-施瓦茨不等式）**：
> 对任意实数 `τ`，由柯西-施瓦茨不等式（第 4 章 4.3 节已用）：
> `|R(τ)| = |E[X(t) X(t + τ)]| ≤ √( E[X²(t)] · E[X²(t + τ)] ) = √( R(0) · R(0) ) = R(0)` ∎
>
> **物理含义**：`R(0)` 是过程的**平均功率**（`E[X²]`），而 `R(τ)` 衡量的是**间隔 `τ` 的两个时刻取值的相似程度**。`|R(τ)| ≤ R(0)` 说的是：**「自己和自己」的相关性最强**，任何时间间隔上的相关性都不会超过它。

**自相关函数与「过程的记忆」**：
- `R(τ)` 随 `τ` 增大而**快速衰减到 0** ⟹ 过程**记忆很短**，相邻时刻几乎不相关（如白噪声，`R(τ) = 0` 对一切 `τ ≠ 0`）；
- `R(τ)` 随 `τ` 缓慢衰减 ⟹ 过程**记忆很长**（如股票价格、气温）；
- `R(τ)` **周期性振荡** ⟹ 过程含**周期成分**（如通信中的载波信号）。

### 10.4.3 各态历经性

**问题的提出**：宽平稳过程的均值 `μ_X` 与自相关函数 `R(τ)` 都是**统计平均**（对概率分布的期望）。但实际中我们**只有一条样本轨道**（如只有一段股票价格记录），**无法做多次重复试验**。那怎么办？

**定义（各态历经性 / 遍历性，Ergodicity）**：若时间平均以概率 1 等于统计平均，即

`⟨X(t)⟩ = lim_{T→∞} (1/T) ∫₀ᵀ X(t) dt = E[X(t)] = μ_X`

则称该过程**具有均值各态历经性**。

同理，若 `⟨X(t) X(t+τ)⟩ = R(τ)`，则称具有**自相关各态历经性**。

> **一句话理解**：**「一条足够长的轨道，就能代表整个过程的统计规律」**——时间维度的平均可以替代样本维度的平均。
>
> **这为什么极其重要**：它把「**无法实现的多次重复试验**」换成了「**一次足够长的观测**」。因此工程中才能用**一段录音**估计语音的统计特性、用**一段股价历史**估计收益率波动率。
>
> **生活类比——抛硬币**：理论上抛无穷多次硬币，正面频率 → 1/2（统计平均）。各态历经性说的是：**你只需要一枚硬币连续抛无穷多次**（时间平均），结果同样是 1/2——**而不是需要无穷多枚硬币各抛一次**。
>
> **不满足各态历经的典型例子**：`X(t) = A`（`A` 是一个随机变量，与 `t` 无关，如 `A ~ N(0,1)`）。它是宽平稳的（均值 0、`R(τ) = E[A²] = 1` 是常数），但**一条轨道就是常数 `A` 本身**，时间平均恒等于 `A`，一般 `≠ 0`。**所以平稳 ≠ 各态历经。**

### 10.4.4 功率谱密度

**维纳-辛钦定理（Wiener-Khinchin Theorem）**：若宽平稳过程 `{X(t)}` 的自相关函数 `R(τ)` 绝对可积，即 `∫|R(τ)|dτ < ∞`，则 `R(τ)` 的傅里叶变换存在，称为**功率谱密度（Power Spectral Density, PSD）**：

**`S(ω) = ∫_{−∞}^{+∞} R(τ) e^{−iωτ} dτ`**

其逆变换为

**`R(τ) = (1/(2π)) ∫_{−∞}^{+∞} S(ω) e^{iωτ} dω`**

**两条重要性质**：

① `S(ω) ≥ 0` 且 `S(−ω) = S(ω)`（偶函数、非负）；
② `R(0) = E[X²(t)] = (1/(2π)) ∫_{−∞}^{+∞} S(ω) dω` —— **总功率等于谱密度的积分**。

> **直观理解**：`R(τ)` 从**时间域**描述过程，`S(ω)` 从**频率域**描述过程，**两者是同一信息的两副面孔**。
> - `S(ω)` 在某频率 `ω₀` 处有大的峰值 ⟹ 信号中**含有强的 `ω₀` 频率成分**（如 50 Hz 工频干扰）；
> - `S(ω)` 在整个频段平坦 ⟹ **白噪声**（各频率成分功率均等，如同白光包含所有颜色的光）。
>
> **「白噪声」名字的来历**：`R(τ) = σ²δ(τ)`（`δ` 是狄拉克函数），其傅里叶变换 `S(ω) = σ²` 是**常数**——「所有频率等功率」，类比白光「所有可见光等强度」，故名。

## 10.5 时间序列分析

### 10.5.1 基本概念

**定义**：按时间顺序排列的随机变量序列 `{ X_t, t = 0, ±1, ±2, … }` 称为**时间序列**。若它（宽）平稳，则称**平稳时间序列**。

**白噪声（White Noise）**：若 `{ ε_t }` 满足
`E(ε_t) = 0`，`Var(ε_t) = σ²`（常数），`Cov(ε_t, ε_s) = 0`（`t ≠ s`），

则称 `{ ε_t }` 为**白噪声序列**，记 `ε_t ~ WN(0, σ²)`。

> **白噪声是时间序列分析的「原子」**：所有平稳时间序列都可以看成**白噪声通过某个线性滤波器**的输出。这与「任何信号都可以分解为不同频率成分」是同一思想。

### 10.5.2 AR(1) 模型：最简单也最重要

**一阶自回归模型 AR(1)**：

**`X_t = φ X_{t−1} + ε_t`**，`ε_t ~ WN(0, σ²)`

**含义**：**今天的值 = 昨天值的一个比例 + 今天的随机扰动**。`φ` 称为**自回归系数**。

**① 平稳条件**：**`|φ| < 1`**

> **推导思路（把 AR(1) 反复展开）**：
> `X_t = φX_{t−1} + ε_t = φ(φX_{t−2} + ε_{t−1}) + ε_t = φ²X_{t−2} + φε_{t−1} + ε_t`
> `= … = φᵏ X_{t−k} + Σ_{j=0}^{k−1} φʲ ε_{t−j}`
> 当 `k → ∞` 时，`φᵏ X_{t−k}` 要**收敛到 0**（初始影响消失），必须 `|φ| < 1`。
> 此时 `X_t = Σ_{j=0}^{∞} φʲ ε_{t−j}`（称为 **MA(∞) 表示**），是**过去所有扰动按几何衰减加权之和**。
>
> **`|φ| ≥ 1` 会怎样**：**`φ = 1` 是随机游走**（`X_t = X_{t−1} + ε_t`），方差随时间**无限增长**，**非平稳**（这正是股价的常用模型）；`|φ| > 1` 则**爆炸式发散**。

**② 均值与方差**（`|φ| < 1` 时）

`E(X_t) = 0`（因 `E(ε_t) = 0`），

`Var(X_t) = σ² / (1 − φ²)`

> **方差的推导**（用第 4 章的性质，注意 `X_{t−1}` 与 `ε_t` 独立）：
> `Var(X_t) = Var(φX_{t−1} + ε_t) = φ² Var(X_{t−1}) + Var(ε_t) = φ² Var(X_t) + σ²`
> 平稳性保证 `Var(X_{t−1}) = Var(X_t)`，解方程得 `Var(X_t)(1 − φ²) = σ²`，故 `Var(X_t) = σ²/(1 − φ²)`。∎
>
> **直觉**：`|φ|` 越接近 1，分母 `1 − φ²` 越小，**方差越大**——因为扰动会**累积**（今天的扰动会影响未来很多天）。

**③ 自相关函数**：

`ρ(k) = Corr(X_t, X_{t+k}) = φᵏ`，`k = 0, 1, 2, …`

> **推导**（以 `k = 1` 为例）：两边同乘 `X_{t−1}` 取期望
> `E(X_t X_{t−1}) = φE(X_{t−1}²) + E(ε_t X_{t−1}) = φγ(0) + 0`
> 即 `γ(1) = φγ(0)`，故 `ρ(1) = γ(1)/γ(0) = φ`。
> 一般地 `γ(k) = φγ(k−1)`，递推得 `γ(k) = φᵏ γ(0)`，即 `ρ(k) = φᵏ`。∎
>
> **关键特征**：**AR(1) 的自相关函数按几何速度衰减**。这是识别 AR(1) 的招牌（见 10.5.3 节的定阶表）。
> **`|φ| < 1` 保证 `ρ(k) = φᵏ → 0`**，即**相隔越远的两个时刻越不相关**——这正符合「平稳」的直觉。

### 10.5.3 AR(p)、MA(q)、ARMA(p, q)

| 模型 | 表达式 | 参数含义 | 平稳条件 | ACF 特征 | PACF 特征 |
|---|---|---|---|---|---|
| **AR(p)** | `X_t = φ₁X_{t−1} + … + φ_pX_{t−p} + ε_t` | 依赖**过去的值** | 特征方程根在单位圆外 | **拖尾**（几何/振荡衰减） | **p 步截尾** |
| **MA(q)** | `X_t = ε_t + θ₁ε_{t−1} + … + θ_qε_{t−q}` | 依赖**过去的扰动** | **总是平稳**（有限项和） | **q 步截尾** | **拖尾** |
| **ARMA(p, q)** | `X_t = φ₁X_{t−1} + … + φ_pX_{t−p} + ε_t + θ₁ε_{t−1} + … + θ_qε_{t−q}` | 两者兼有 | 只看 AR 部分 | **拖尾** | **拖尾** |

> **「截尾」与「拖尾」**：
> - **截尾**：`ρ(k)` 在 `k > q` 后**严格等于 0**（突然断掉）；
> - **拖尾**：`ρ(k)` 一直**按指数或振荡方式衰减**，永不为 0（缓慢拖下去）。
>
> **这条定阶规则是 Box-Jenkins 方法的核心**：**看样本 ACF 和 PACF 图，哪个截尾就把阶数定在哪里。**

**MA(1) 的一个漂亮结论**（考试常考）：`X_t = ε_t + θε_{t−1}`，则

`γ(0) = σ²(1 + θ²)`，`γ(1) = θσ²`，`γ(k) = 0`（`k ≥ 2`）

故 `ρ(1) = θ/(1 + θ²)`，`ρ(k) = 0`（`k ≥ 2`）。

> **注意**：`ρ(1) = θ/(1+θ²)` 这个函数在 `θ = 1` 时取最大值 `1/2`，而且它满足 **`ρ(1; θ) = ρ(1; 1/θ)`**——把 `θ` 换成 `1/θ` 得到的是同一个值（因 `(1/θ)/(1 + 1/θ²) = θ/(θ² + 1)`）。也就是说**同一个自相关函数对应两个不同的 `θ`**（如 `θ = 0.5` 与 `θ = 2` 都给出 `ρ(1) = 0.4`）。这就是 MA 模型**可逆性（invertibility）**条件 `|θ| < 1` 的由来：在这两个 `θ` 中规定只取模小于 1 的那一个，模型才唯一。

### 10.5.4 建模四步法

**Box-Jenkins 建模流程**：

① **模型识别（定阶）**：计算样本 ACF 与样本 PACF，按 10.5.3 节的定阶表确定 `p`、`q`；
② **参数估计**：用最小二乘或极大似然估计 `φ`、`θ`、`σ²`（R 中 `arima(x, order = c(p, d, q))`）；
③ **诊断检验**：检查残差 `ε̂_t` 是否为白噪声（Ljung-Box 检验 `Box.test(res, type = "Ljung-Box")`，p > 0.05 说明残差已无信息，模型充分）；
④ **预测**：用拟合的模型外推（R 中 `predict(fit, n.ahead = 5)`）。

> **③ 为什么最关键**：**残差里如果还有规律，说明模型没把信息提取干净**。所有统计建模都是这个逻辑——**把可解释的部分榨干，剩下的必须是纯噪声**。这与第 8 章回归的**残差分析**（例 8.4）完全同构。
>
> **ARIMA(p, d, q)**：若序列非平稳，先做 `d` 次差分使其平稳，再建 ARMA。**`d = 1` 就对应随机游走（`φ = 1`）情形**，股价、汇率常用。
> **与机器学习的对比**：ARIMA 是**线性、可解释、参数少**的经典方法；RNN / LSTM / Transformer 是**非线性、参数多**的现代方法。**小样本、强可解释性要求下 ARIMA 仍常胜出**——这是「经典统计未被深度学习淘汰」的典型例证。

**例 10.1**（题型：随机过程数字特征的计算）
设随机过程 `X(t) = A cos(ωt) + B sin(ωt)`，其中 `A, B` 相互独立，且 `E(A) = E(B) = 0`，`D(A) = D(B) = σ²`，`ω` 为常数。求 `μ_X(t)`、`D_X(t)` 与 `R_X(s, t)`。

**解**：
**① 均值函数**（用期望的线性性，不需要独立性）：
`μ_X(t) = E[A cos(ωt) + B sin(ωt)] = cos(ωt)·E(A) + sin(ωt)·E(B) = 0`

**② 方差函数**：
`D_X(t) = Var[A cos(ωt) + B sin(ωt)]`
由 `A, B` **独立**，协方差为 0，故
`= cos²(ωt)·D(A) + sin²(ωt)·D(B) = σ²[cos²(ωt) + sin²(ωt)] = σ²`

**③ 自相关函数**（注意 `μ_X ≡ 0`，故 `R_X = C_X`）：
`R_X(s, t) = E[X(s) X(t)]`
`= E{ [A cos(ωs) + B sin(ωs)] · [A cos(ωt) + B sin(ωt)] }`
`= E(A²) cos(ωs)cos(ωt) + E(AB) cos(ωs)sin(ωt) + E(AB) sin(ωs)cos(ωt) + E(B²) sin(ωs)sin(ωt)`

由 `E(A) = 0` 得 `E(A²) = D(A) + [E(A)]² = σ² + 0 = σ²`，同理 `E(B²) = σ²`；
由 `A, B` 独立且均值为 0 得 `E(AB) = E(A)E(B) = 0`。故
`R_X(s, t) = σ²[cos(ωs)cos(ωt) + sin(ωs)sin(ωt)] = σ² cos( ω(t − s) )`

**答案**：`μ_X(t) = 0`；`D_X(t) = σ²`；`R_X(s, t) = σ² cos(ω(t − s))`。

> **三个结论的解读**：
> - `μ_X(t) = 0` 与 `t` 无关 ✓ 满足宽平稳第①条；
> - `D_X(t) = σ²` 是常数（方差有限）✓；
> - `R_X(s, t) = σ² cos(ω(t − s))` **只依赖时间差 `τ = t − s`**（令 `τ = t − s`，`R(τ) = σ² cos(ωτ)`）✓ 满足宽平稳第②条。
>
> **所以这是一个宽平稳过程**（且是正态过程时为严平稳）。
> **注意 `R(τ) = σ² cos(ωτ)` 是周期性振荡的**——按 10.4.2 节的判据，**这说明过程含有频率为 `ω` 的周期成分**。这与 `X(t)` 的表达式里显含 `cos(ωt)`、`sin(ωt)` 完全吻合。**这正是「自相关函数的形状反映了过程的周期性」的直观例证。**

**例 10.2**（题型：泊松过程的基本计算）
某网站访问请求数服从泊松过程，平均每分钟 3 次请求。求：
① 5 分钟内恰好有 12 次请求的概率；
② 相邻两次请求的平均间隔时间；
③ 从零时刻起，等待第 4 次请求的平均时间；
④ 相邻两次请求间隔超过 1 分钟的概率。

**解**：
已知 `λ = 3`（次/分钟）。

**①** 5 分钟内的请求数 `N(5) ~ P(λt) = P(15)`，故
`P{N(5) = 12} = 15¹² · e^{−15} / 12!`
计算：`15¹² = 129746337890625`，`12! = 479001600`，故
`15¹²/12! = 129746337890625/479001600 = 270868.3`
又 `e^{−15} = 3.059023 × 10^{−7}`，故
`P = 270868.3 × 3.059023 × 10^{−7} = 0.08286`

**②** 到达间隔 `T ~ E(λ)`，`E(T) = 1/λ = 1/3` 分钟 = **20 秒**

**③** 第 4 次到达时刻 `W₄ ~ Γ(4, 3)`，`E(W₄) = n/λ = 4/3` 分钟 = **80 秒**
（**也可直接理解**：4 个平均间隔之和 = `4 × 20 = 80` 秒。）

**④** `P(T > 1) = ∫₁^∞ 3e^{−3t} dt = e^{−3} = 0.0498`

**答案**：① 0.0829；② 20 秒；③ 80 秒；④ 0.0498。

> **①的校验方法（考场速算技巧）**：`N(5) ~ P(15)`，其均值是 15。查泊松表得 `P{N=15} = 0.1024`。而
> `P(N=12)/P(N=15) = [15¹²/12!]/[15¹⁵/15!] = (13 × 14 × 15)/15³ = 2730/3375 = 0.8089`
> 故 `P(N=12) = 0.1024 × 0.8089 = 0.0828` ✓ **与直接计算一致**。
> **这个技巧很实用**：**先查表得到均值附近的概率，再用比值公式换算**，可以避免手算巨大的阶乘。

**例 10.3**（题型：泊松过程的间隔与到达时刻分布）
承例 10.2（`λ = 3` 次/分钟）。求：
① 第 2 次请求在 1 分钟之后才到达的概率；
② 前 2 分钟内没有任何请求的概率。

**解**：
**①** `W₂ ~ Γ(2, 3)`，密度 `f(t) = 3(3t)^{2−1}e^{−3t}/(2−1)! = 9te^{−3t}`（`t > 0`）。

`P(W₂ > 1) = ∫₁^∞ 9te^{−3t} dt`

用分部积分（`u = t`，`dv = 9e^{−3t}dt`，`v = −3e^{−3t}`）：
`∫ 9te^{−3t}dt = −3te^{−3t} + ∫3e^{−3t}dt = −3te^{−3t} − e^{−3t} + C`

故 `P(W₂ > 1) = [−3te^{−3t} − e^{−3t}]₁^∞ = 0 − (−3e^{−3} − e^{−3}) = 4e^{−3} = 4 × 0.049787 = 0.19915`

**②** `N(2) ~ P(λt) = P(6)`，故
`P{N(2) = 0} = 6⁰ e^{−6}/0! = e^{−6} = 0.002479`

**答案**：① `4e^{−3} = 0.1991`；② `e^{−6} = 0.0025`。

> **①的另一种解法（更巧，也更体现「泊松过程」的本质）**：
> 事件「`W₂ > 1`」等价于「在 `[0, 1]` 内**至多发生 1 次**事件」，即 `N(1) ≤ 1`。
> `N(1) ~ P(3)`，故
> `P{N(1) ≤ 1} = P{N(1)=0} + P{N(1)=1} = e^{−3} + 3e^{−3} = 4e^{−3} = 0.1991` ✓
>
> **这个方法避免了对 Γ 密度积分**，是考场上更快更稳的路线。**关键转换**：
> **「第 `n` 次到达时刻 `> t`」 ⟺ 「`[0, t]` 内发生次数 `< n`」**
> 即 `Wₙ > t ⟺ N(t) ≤ n − 1`。**这是泊松过程最常用的恒等变换，务必掌握。**

**例 10.4**（题型：维纳过程计算）
设 `{ W(t), t ≥ 0 }` 是参数 `σ² = 2` 的维纳过程。求：
① `W(3)` 的分布；
② `P{ W(3) > 2 }`；
③ `Cov[W(2), W(5)]`；
④ 增量 `W(5) − W(2)` 的分布。

**解**：
**①** 由定义 `W(t) ~ N(0, σ²t)`，故
`W(3) ~ N(0, 2 × 3) = N(0, 6)`，标准差 `√6 = 2.4495`

**②** 标准化：`P{W(3) > 2} = P{ Z > 2/√6 } = P{Z > 0.8165} = 1 − Φ(0.8165)`
查标准正态表得 `Φ(0.82) = 0.7939`，`Φ(0.81) = 0.7910`，线性插值：
`Φ(0.8165) ≈ 0.7910 + 0.65 × (0.7939 − 0.7910) = 0.7910 + 0.0019 = 0.7929`
故 `P{W(3) > 2} = 1 − 0.7929 = 0.2071`

**③** 由 `C_W(s, t) = σ²·min(s, t)`，得
`Cov[W(2), W(5)] = 2 × min(2, 5) = 2 × 2 = 4`

**④** 由平稳增量性，`W(5) − W(2) ~ N(0, σ²(5 − 2)) = N(0, 6)`

**答案**：① `N(0, 6)`；② 0.2071；③ 4；④ `N(0, 6)`。

> **③与④的对照（考点）**：题目刻意让两者都等于 6 与 4，需要看清问的是什么：
> - **③问的是协方差**，答案是 `σ²·min(s,t) = 2 × 2 = 4`；
> - **④问的是增量的方差**，答案是 `σ²(t − s) = 2 × 3 = 6`。
>
> **两者恰好都涉及 `2` 和 `3`，极易混淆**。**记法**：
> - **协方差用 `min(s, t)`**（因为要「取较短的区间」——两者的共同部分是 `[0, min(s,t)]`）；
> - **增量的方差用 `t − s`**（区间的**长度**）。
>
> **④的直觉**：`W(5) − W(2)` 与 `W(3)` **同分布**（都是长度 3 的区间上的增量、都从 0 出发），这正是**平稳增量性**的直接体现。

**例 10.5**（题型：马尔可夫链的 n 步转移概率）
某系统有两个状态：0（正常）、1（故障）。每天的状态按下述规律转移：正常时第二天仍正常的概率为 0.6，转为故障的概率为 0.4；故障时第二天转为正常的概率为 0.3，仍故障的概率为 0.7。
① 写出转移矩阵 `P`；
② 若今天正常，求后天正常的概率；
③ 若今天正常的概率为 0.5，求 2 天后处于状态 0 的概率。

**解**：
**①** 状态 0 出发：`p₀₀ = 0.6`，`p₀₁ = 0.4`；状态 1 出发：`p₁₀ = 0.3`，`p₁₁ = 0.7`。故

```
P = ┌  0.6  0.4 ┐
    └  0.3  0.7 ┘
```

**验证行和**：`0.6 + 0.4 = 1` ✓，`0.3 + 0.7 = 1` ✓

**②** 后天正常 = 2 步转移概率 `p₀₀⁽²⁾`，由 C-K 方程用 `P²` 的 (0,0) 元素：

`p₀₀⁽²⁾ = p₀₀p₀₀ + p₀₁p₁₀ = 0.6 × 0.6 + 0.4 × 0.3 = 0.36 + 0.12 = 0.48`

（**为什么这样算**：「从 0 走 2 步回到 0」有两条路径——`0 → 0 → 0` 和 `0 → 1 → 0`，由全概率公式相加。）

**③** 初始分布 `π(0) = (0.5, 0.5)`，则 `π(2) = π(0)P²`。

先求 `P²`（完整矩阵）：
`P² = ┌ 0.6 0.4 ┐ ┌ 0.6 0.4 ┐ = ┌ 0.6×0.6+0.4×0.3   0.6×0.4+0.4×0.7 ┐ = ┌ 0.48  0.52 ┐`
`     └ 0.3 0.7 ┘ └ 0.3 0.7 ┘   └ 0.3×0.6+0.7×0.3   0.3×0.4+0.7×0.7 ┘   └ 0.39  0.61 ┘`

验证行和：`0.48 + 0.52 = 1` ✓，`0.39 + 0.61 = 1` ✓

故 `π₀(2) = 0.5 × 0.48 + 0.5 × 0.39 = 0.24 + 0.195 = 0.435`

**答案**：① 见上；② `p₀₀⁽²⁾ = 0.48`；③ `π₀(2) = 0.435`。

> **②与③的区别（易混点）**：
> - **②是条件概率**：已知今天在状态 0，问后天在状态 0 —— 用的是 `P²` 的**第 0 行第 0 列**；
> - **③是无条件概率**：只知道今天的**分布**，问后天的**分布** —— 用的是 `π(0)P²`。
>
> **一句话区分**：**②给定起点（用矩阵的某一行）；③给定起点的分布（用行向量乘矩阵）。**
>
> **注意 `p₀₀⁽²⁾ = 0.48 < p₀₀ = 0.6`**：这说明可靠性**随时间衰减**（从 0.6 掉到 0.48）。若继续算下去会趋于平稳分布的 `π₀ = 3/7 ≈ 0.4286`（见例 10.6）。**这就是「遗忘初始状态」的过程。**

**例 10.6**（题型：平稳分布的求解——考试必考）
承例 10.5，求该马尔可夫链的平稳分布。

**解**：
设平稳分布为 `π = (π₀, π₁)`，满足 `π = πP` 且 `π₀ + π₁ = 1`。

**① 写出方程组** `π = πP`：
`π₀ = 0.6π₀ + 0.3π₁`　……(i)
`π₁ = 0.4π₀ + 0.7π₁`　……(ii)

**② 丢掉一个方程**（(i) 与 (ii) 线性相关），保留 (i)：
由 (i)：`π₀ − 0.6π₀ = 0.3π₁`，即 `0.4π₀ = 0.3π₁`，故 `π₁ = (0.4/0.3)π₀ = (4/3)π₀`

**③ 代入归一化条件** `π₀ + π₁ = 1`：
`π₀ + (4/3)π₀ = 1` ⟹ `(7/3)π₀ = 1` ⟹ `π₀ = 3/7`

**④ 求 `π₁`**：`π₁ = (4/3) × (3/7) = 4/7`

**验算**（用丢掉的方程 (ii)）：
`0.4 × (3/7) + 0.7 × (4/7) = 1.2/7 + 2.8/7 = 4.0/7 = 4/7 = π₁` ✓

**答案**：`π = (3/7, 4/7) ≈ (0.4286, 0.5714)`。

> **平稳分布的现实含义**：**长期来看，系统处于正常状态的时间比例为 3/7 ≈ 42.86%，处于故障状态的时间比例为 4/7 ≈ 57.14%**。
>
> **与例 10.5③ 的呼应**：例 10.5③ 算出 `π₀(2) = 0.435`，而平稳值是 `0.4286`——**只走了 2 步就已经很接近极限了**（本例的链收敛很快）。再走一步要用 **`P³`** 的第 0 行（不能再用 `P²`）：`π₀(3) = (P³)₀₀·0.5 + (P³)₁₀·0.5 = 0.444×0.5 + 0.417×0.5 = 0.4305`，`π₀(4) = 0.42915`，确实在向 `3/7 = 0.428571` 收敛 ✓
>
> **丢掉方程的合法性（严格说明）**：`π(P − I) = 0`。由 `P·1 = 1`（行和为 1），`P` 有特征值 1，故 `P − I` 奇异（对本例这个 2×2 的 `P`，`P − I` 的两行成比例，**秩为 1**），两个方程必然线性相关，**必须**丢掉一个、用 `Σπ_j = 1` 替补。**若两个都保留，得到的是无穷多解（一维解族 `π = t(3, 4)`，`t` 任意实数）——它包含平凡的 `π = 0`，但远不止 `π = 0`；只有加上归一化条件 `Σπ_j = 1` 才能从中定出唯一的概率分布 `π = (3/7, 4/7)`。**

**例 10.7**（题型：证明题——自相关函数性质）
设 `{X(t)}` 是宽平稳过程，均值为 0，自相关函数 `R(τ) = E[X(t)X(t+τ)]`。证明：
① `R(−τ) = R(τ)`；
② `|R(τ)| ≤ R(0)`。

**证明**：
**①** 由宽平稳性，`R(τ) = E[X(t)X(t+τ)]` 与 `t` 的选取无关。故可令 `t' = t + τ`（即把时间原点平移 `τ`），得

`R(−τ) = E[X(t)X(t − τ)] = E[X(t' + τ)X(t')] = E[X(t')X(t' + τ)] = R(τ)`

（**为什么可以平移**：这正是宽平稳的定义——自相关函数**只依赖时间差**，与绝对时刻无关。）∎

**②** 对任意实数 `τ`，由**柯西-施瓦茨不等式**（`|E(UV)| ≤ √(E(U²)·E(V²))`，见第 4 章 4.3 节）：

`|R(τ)| = |E[ X(t) · X(t + τ) ]| ≤ √( E[X²(t)] · E[X²(t + τ)] )`

由宽平稳性，`E[X²(t)] = R(0)` 对一切 `t` 成立（因为 `R(t − t) = R(0)`），故

`|R(τ)| ≤ √( R(0) · R(0) ) = R(0)` ∎

（**注意**：这里用了均值 `μ = 0`，故 `R(0) = E[X²(t)] = D[X(t)] ≥ 0`，开方有意义。若均值非零，应把 `R` 换成协方差函数 `C(τ)`，结论 `|C(τ)| ≤ C(0) = D_X` 同样成立。）

**答案**：证明见上。

> **②的物理意义再强调**：`R(0) = E[X²(t)]` 是过程的**平均功率**。结论说的是：**任何时间间隔上的相关性都不超过「零间隔」（即自己与自己）的相关性**。
>
> **类比**：这和第 4 章「`|ρ_{XY}| ≤ 1`」是同一件事——**`R(τ)/R(0)` 正是 `X(t)` 与 `X(t+τ)` 的相关系数**（在均值 0 时）。**相关系数的绝对值不超过 1，所以归一化的自相关函数也不超过 1。** 新旧知识在这里完全打通。

**例 10.8**（题型：AR(1) 模型的平稳性与自相关函数）
设平稳时间序列 `{X_t}` 满足 `X_t = 0.6 X_{t−1} + ε_t`，其中 `ε_t ~ WN(0, 1)`（即 `σ² = 1`）。
① 判断该模型的平稳性；
② 求 `Var(X_t)`；
③ 求 `ρ(1)`、`ρ(2)`、`ρ(3)`；
④ 若 `X_{t−1} = 5`，预测 `X_t` 与 `X_{t+2}` 的期望值。

**解**：
**①** `φ = 0.6`，`|φ| = 0.6 < 1`，故**模型平稳** ✓

**②** `Var(X_t) = σ²/(1 − φ²) = 1/(1 − 0.36) = 1/0.64 = 1.5625`
标准差 `√1.5625 = 1.25`

**③** `ρ(k) = φᵏ = 0.6ᵏ`：
`ρ(1) = 0.6`
`ρ(2) = 0.6² = 0.36`
`ρ(3) = 0.6³ = 0.216`

**④ 预测公式**：对 AR(1) 模型，由 `E(ε_{t+k}) = 0` 反复迭代可得

**`E(X_{t+k} | X_t = x) = φᵏ x`**

**先数清步数**：`X_{t−1}` 到 `X_t` 相隔 **1** 步，到 `X_{t+2}` 相隔 **3** 步。

`E(X_t | X_{t−1} = 5) = φ¹ × 5 = 0.6 × 5 = 3`

`E(X_{t+2} | X_{t−1} = 5) = φ³ × 5 = 0.216 × 5 = 1.08`

**分步验算**（确认步数没数错）：
`E(X_t | X_{t−1}=5) = 0.6 × 5 = 3`
`E(X_{t+1} | X_{t−1}=5) = 0.6 × 3 = 1.8`
`E(X_{t+2} | X_{t−1}=5) = 0.6 × 1.8 = 1.08` ✓ **与通式一致。**

**答案**：① 平稳（`|0.6| < 1`）；② `Var(X_t) = 1.5625`；③ `ρ(1) = 0.6`、`ρ(2) = 0.36`、`ρ(3) = 0.216`；④ `E(X_t) = 3`，`E(X_{t+2}) = 1.08`。

> **④的直觉（均值回复）**：预测值 `3 → 1.8 → 1.08 → 0.648 → …` **按 0.6 的比例逐步衰减到 0**（该序列的长期均值）。这就是**均值回复（mean reversion）**：**偏离均值越远，回归越快**。
>
> **对股价建模的启示**：若股价真有均值回复，就能「低买高卖」稳定获利。**但大量实证研究表明股价更像随机游走（`φ ≈ 1`），均值回复极弱**——这正是**有效市场假说**的统计表述，也是为什么 `AR(1)` 在金融中常被 `ARIMA(0,1,0)`（即随机游走）取代。

## 易错点提醒

1. **把「随机过程」当成一个随机变量**。
   **错在**：求 `D[X(t)]` 时只算一个数就完事，忽略它是 `t` 的函数。
   **正确做法**：随机过程的数字特征都是 **`t` 的函数**（`μ_X(t)`、`D_X(t)`）或 **两个时刻的函数**（`R_X(s, t)`）。**只有宽平稳过程的 `μ` 才是常数、`R` 才只依赖 `τ`。**

2. **混淆自相关函数 `R` 与自协方差函数 `C`**。
   **错在**：题目给了非零均值，却直接用 `R(τ)` 当作相关性的度量。
   **正确做法**：**`C_X(s,t) = R_X(s,t) − μ_X(s)μ_X(t)`**。只有 `μ_X ≡ 0` 时两者才相等。**均值非零时必须用 `C`**，否则「相关性」里混进了均值的影响。

3. **误认为泊松过程的 `N(t)` 服从 `P(λ)`**。
   **错在**：`λ = 3` 就写 `N(5) ~ P(3)`。
   **正确做法**：**`N(t) ~ P(λt)`**，参数里**必须带上时间**。`λ = 3`、`t = 5` 时是 `N(5) ~ P(15)`。**忘了乘 `t` 是最常见的低级错误。**

4. **把泊松过程的 `λ` 当成「平均间隔」**。
   **错在**：`λ = 3` 次/分钟，就说「平均间隔 3 分钟」。
   **正确做法**：**`λ` 是速率（次/单位时间），平均间隔是 `1/λ`**。`λ = 3` 次/分钟 ⇒ 平均间隔 `1/3` 分钟 = **20 秒**。**两者互为倒数，量纲相反。**

5. **混淆「第 n 次到达时刻」与「第 n 个间隔」**。
   **错在**：求 `W₃` 的分布时写成 `Γ(3, λ)` 之后又乘错平均间隔，或把 `Wₙ` 与 `Tₙ` 混为一谈。
   **正确做法**：**`Tₙ ~ E(λ)`（指数），`Wₙ = T₁ + … + Tₙ ~ Γ(n, λ)`**。`E(Tₙ) = 1/λ`，**`E(Wₙ) = n/λ`**。**注意 `Wₙ` 用了 `n`，`Tₙ` 不用。**

6. **忘记 `Wₙ > t ⟺ N(t) ≤ n − 1` 这个转换**。
   **错在**：硬算 Γ 分布的积分，费时且易错。
   **正确做法**：**「第 `n` 次到达时刻超过 `t`」等价于「`[0, t]` 内发生次数不到 `n` 次」**，即 `Wₙ > t ⟺ N(t) ≤ n − 1`。用泊松分布求和，**这是考场上最快的路线**（见例 10.3①）。

7. **维纳过程里把 `min(s, t)` 和 `t − s` 用混**。
   **错在**：求 `Cov[W(2), W(5)]` 时算成 `σ² × 3`。
   **正确做法**：**协方差用 `min(s, t)`；增量的方差用 `t − s`**。`Cov[W(2), W(5)] = σ²·min(2,5) = 2σ²`；`Var[W(5) − W(2)] = σ²(5−2) = 3σ²`。**两者都不是对方。**

8. **转移矩阵写成「列和为 1」**。
   **错在**：把 `p_ij` 理解为「从 `j` 到 `i`」，于是行列颠倒。
   **正确做法**：**`p_ij` = 「从 `i` **出发**到 `j`」，`i` 是行、`j` 是列，故「行和为 1」**。
   **自检方法**：算完矩阵后，**每一行加起来看是否等于 1**。若每列加起来是 1，说明**矩阵被转置了**。

9. **用 `Pⁿ` 时把矩阵乘法当成元素逐项乘方**。
   **错在**：认为 `p₀₀⁽²⁾ = (p₀₀)² = 0.6² = 0.36`。
   **正确做法**：**`P⁽ⁿ⁾ = Pⁿ` 是矩阵的 n 次幂**，必须做矩阵乘法。`p₀₀⁽²⁾ = p₀₀p₀₀ + p₀₁p₁₀ = 0.36 + 0.12 = 0.48 ≠ 0.36`（例 10.5②）。
   **记住：`p_ij⁽ⁿ⁾ ≠ (p_ij)ⁿ`，这两者毫无关系。**

10. **解平稳分布时不丢方程**。
    **错在**：把 `π = πP` 的全部方程加上归一化条件一起解。
    **正确做法**：**必须丢掉一个**（因为方程组线性相关，全用会得到无穷多解，无法定出唯一的概率分布）。流程是：写方程 → **丢掉一个** → 补 `Σπ_j = 1` → 解。
    **验算方法**：把解代回**被丢掉的那个方程**，看是否成立。

11. **混淆「平稳」与「各态历经」**。
    **错在**：认为宽平稳过程一定可以用时间平均估计均值。
    **正确做法**：**平稳 ≠ 各态历经**。反例：`X(t) = A`（`A ~ N(0,1)` 与 `t` 无关）是宽平稳的，但一条轨道恒等于常数 `A`，时间平均 `= A ≠ 0 = E[X(t)]`。**各态历经是比平稳更强的要求，需要额外验证。**

12. **认为「宽平稳 ⟹ 严平稳」**。
    **错在**：验证了均值和自相关函数就宣布过程严平稳。
    **正确做法**：**宽平稳一般推不出严平稳**（宽平稳只约束一、二阶矩，对高阶分布无任何要求）。**唯一例外是正态过程**——此时宽平稳 ⟺ 严平稳。

13. **AR(1) 的平稳条件写成 `φ < 1`**。
    **错在**：漏掉绝对值，认为 `φ = −0.8` 不平稳。
    **正确做法**：**平稳条件是 `|φ| < 1`**。`φ = −0.8` 是平稳的（只是自相关函数**交替变号**：`ρ(1) = −0.8`、`ρ(2) = 0.64`、`ρ(3) = −0.512`，呈锯齿状衰减）。**负自回归也是自回归。**

14. **AR(1) 方差公式记成 `σ²/(1 − φ)`**。
    **错在**：漏掉平方。
    **正确做法**：**`Var(X_t) = σ²/(1 − φ²)`**。推导：`Var = φ²Var + σ²` ⟹ `Var(1 − φ²) = σ²`。
    **自检**：`φ → 1` 时分母 `→ 0`，方差 `→ ∞`，**符合「随机游走方差随时间无限增长」的直觉** ✓。若写成 `1 − φ`，`φ = 0.6` 时得 `σ²/0.4 = 2.5`，与正确值 `1/0.64 = 1.5625` 不同。

15. **预测时步数数错**。
    **错在**：`E(X_{t+2}|X_{t−1} = 5)` 算成 `φ² × 5`。
    **正确做法**：**数清相隔几步**。`X_{t−1}` 到 `X_{t+2}` 相隔 **3** 步，故是 `φ³ × 5 = 0.216 × 5 = 1.08`。
    **记法**：**通式是 `E(X_{t+k}|X_t = x) = φᵏx`，其中 `k` = 终点的下标 − 起点的下标。**

16. **把「统计显著」或「模型拟合好」当成「预测准确」**。
    **错在**：`R² = 0.99` 就认为预测一定准。
    **正确做法**：**拟合优度高只说明模型解释了**历史数据**的变异，不代表对未来有预测力**。这与第 8 章易错点 12、第 9 章易错点 14 是同一个道理。**时间序列尤其如此**——`R²` 高常常只是因为有**趋势项**（两边都随时间增长），一旦做差分（`ARIMA` 的 `d`）`R²` 会大幅下降，但那才是**真实的预测能力**。**必须做样本外验证（out-of-sample test）。**

## 本章小结

- **随机过程**：一族依赖于参数 `t` 的随机变量 `{X(t), t ∈ T}`。按「参数集 × 状态空间」分为四类。
- **数字特征**：均值函数 `μ_X(t)`、方差函数 `D_X(t)`、自相关函数 `R_X(s,t)`、自协方差函数 `C_X(s,t)`，且 **`C = R − μ(s)μ(t)`**。
- **泊松过程**三条：`N(0) = 0`、独立增量、平稳增量，且 **`N(t) ~ P(λt)`**、`E = D = λt`。
- **泊松过程两大定理**：**到达间隔 `Tₙ ~ E(λ)` 且独立**；**第 n 次到达时刻 `Wₙ ~ Γ(n, λ)`**。`E(Tₙ) = 1/λ`、`E(Wₙ) = n/λ`。
- **关键恒等式**：**`Wₙ > t ⟺ N(t) ≤ n − 1`**。
- **维纳过程**：`W(t) − W(s) ~ N(0, σ²(t−s))`，`W(t) ~ N(0, σ²t)`，**`Cov[W(s), W(t)] = σ²·min(s,t)`**。
- **泊松与维纳的共同点**：方差都与时间成正比（`λt`、`σ²t`），**标准差都正比于 `√t`**。
- **马尔可夫性**：**「未来只取决于现在」**。转移矩阵 **`p_ij ≥ 0` 且行和为 1**。
- **C-K 方程**：**`P⁽ⁿ⁾ = Pⁿ`（矩阵的 n 次幂）**，`π(n) = π(0)Pⁿ`。
- **平稳分布**：解 **`π = πP`** 且 `Σπ_j = 1`。**必须丢掉一个方程**。含义：`π_j` = 长期处于状态 `j` 的时间比例。
- **严平稳 vs 宽平稳**：严平稳 + 二阶矩存在 ⟹ 宽平稳；**正态过程时两者等价**。
- **自相关函数三条性质**：`R(−τ) = R(τ)`；**`|R(τ)| ≤ R(0)`**（柯西-施瓦茨）；非负定性。
- **各态历经性**：时间平均 = 统计平均。**平稳推不出各态历经。**
- **维纳-辛钦定理**：`S(ω) = ∫R(τ)e^{−iωτ}dτ`，时间域与频率域互为傅里叶变换。
- **AR(1)**：`X_t = φX_{t−1} + ε_t`，平稳条件 **`|φ| < 1`**，`Var = σ²/(1 − φ²)`，**`ρ(k) = φᵏ`**。
- **定阶口诀**：**AR(p) 的 ACF 拖尾、PACF 截尾；MA(q) 反之；ARMA 都拖尾。**
- **一句话记住本章**：**概率论研究「一个随机变量」，随机过程研究「一条随机的时间曲线」——泊松过程数「来了几次」（间隔指数、到达 Γ），维纳过程记「漂到哪儿了」（增量正态、协方差取 min），马尔可夫链只关心「下一步去哪」（矩阵幂、平稳分布），而平稳过程与时间序列的核心工具就是自相关函数这一个东西。**

### 自测题答案

1. **定义**：设 `T` 是参数集，若对每个 `t ∈ T`，`X(t)` 都是随机变量，则称 `{X(t), t ∈ T}` 为随机过程。

   | 过程 | 参数集 | 状态空间 | 分类 |
   |---|---|---|---|
   | ① 每日收盘价 | 离散（天） | 连续（价格） | 离散参数连续状态过程 |
   | ② 呼叫次数 | 连续（时间） | 离散（非负整数） | 连续参数离散状态过程（计数过程） |
   | ③ 噪声电压 | 连续（时间） | 连续（电压值） | 连续参数连续状态过程 |

2. **① 均值**：`μ_X(t) = E(A + Bt) = 1 + 2t`

   **② 方差**（`A, B` 独立故协方差为 0）：
   `D_X(t) = Var(A + Bt) = D(A) + t²D(B) = 3 + 4t²`

   **③ 自相关函数**：
   `R_X(s, t) = E[(A + Bs)(A + Bt)] = E(A²) + tE(AB) + sE(AB) + stE(B²)`
   由 `E(A²) = D(A) + [E(A)]² = 3 + 1 = 4`，`E(B²) = 4 + 4 = 8`，`E(AB) = E(A)E(B) = 1 × 2 = 2`，
   `R_X(s,t) = 4 + 2t + 2s + 8st = 4 + 2(s + t) + 8st`

   **注意**：`R_X(s,t)` **不能写成只依赖 `t − s` 的形式**（含 `s + t` 与 `st`），且 `μ_X(t) = 1 + 2t` **随 `t` 变化**，故**该过程不是宽平稳的**。

3. `λ = 20` 人/小时 = `1/3` 人/分钟。
   **①** `N(30) ~ P(λt)`，`t = 30` 分钟，`λt = 20 × 0.5 = 10`（人）。故
   `P{N(30) = 8} = 10⁸e^{−10}/8! = 100000000 × 4.53999 × 10^{−5}/40320`
   `= 4539.99/40320 = 0.11260`
   **②** 平均间隔 `= 1/λ = 1/20` 小时 = **3 分钟**
   **③** 6 分钟 = 0.1 小时，`P(T > 0.1) = e^{−20 × 0.1} = e^{−2} = 0.1353`
   （或按分钟算：`λ = 1/3` 人/分钟，6 分钟对应 `λt = 2`，`P = e^{−2} = 0.1353` ✓ **两种算法结果一致**。）

4. `W₅ ~ Γ(5, λ)`，`E(W₅) = 5/λ = 5/20` 小时 = **0.25 小时 = 15 分钟**
   （也可直接看：5 个平均间隔之和 `= 5 × 3 = 15` 分钟 ✓。）

5. 标准维纳过程：`W(t) ~ N(0, t)`。
   **①** `W(4) ~ N(0, 4)`，`σ = 2`。`P{W(4) > 1} = 1 − Φ(1/2) = 1 − Φ(0.5) = 1 − 0.6915 = 0.3085`
   **②** `Cov[W(1), W(4)] = min(1, 4) = 1`（`σ² = 1`）
   **③** `Var[W(4) − W(1)] = σ²(4 − 1) = 1 × 3 = 3`
   **⚠️ 注意②与③的区别**：② 用 `min(s,t)`，③ 用 `t − s`。**不要用混。**

6. **① 验证**：`0.5 + 0.5 = 1` ✓，`0.2 + 0.8 = 1` ✓，且所有元素非负 ✓，故是合法转移矩阵。
   **②**
   ```
   P² = ┌ 0.5 0.5 ┐ ┌ 0.5 0.5 ┐ = ┌ 0.5×0.5+0.5×0.2   0.5×0.5+0.5×0.8 ┐ = ┌ 0.35  0.65 ┐
        └ 0.2 0.8 ┘ └ 0.2 0.8 ┘   └ 0.2×0.5+0.8×0.2   0.2×0.5+0.8×0.8 ┘   └ 0.26  0.74 ┘
   ```
   验证行和：`0.35 + 0.65 = 1` ✓，`0.26 + 0.74 = 1` ✓
   **③** `p₀₀⁽²⁾ = 0.35`

7. 设 `π = (π₀, π₁)`，`π = πP`：
   `π₀ = 0.5π₀ + 0.2π₁`　……(i)
   `π₁ = 0.5π₀ + 0.8π₁`　……(ii)

   **丢掉 (ii)**，由 (i)：`π₀ − 0.5π₀ = 0.2π₁` ⟹ `0.5π₀ = 0.2π₁` ⟹ `π₁ = 2.5π₀ = (5/2)π₀`

   代入 `π₀ + π₁ = 1`：`π₀ + 2.5π₀ = 1` ⟹ `3.5π₀ = 1` ⟹ `π₀ = 1/3.5 = 2/7`

   `π₁ = (5/2) × (2/7) = 5/7`

   **验算 (ii)**：`0.5 × (2/7) + 0.8 × (5/7) = 1/7 + 4/7 = 5/7 = π₁` ✓

   **平稳分布 `π = (2/7, 5/7) ≈ (0.2857, 0.7143)`**。
   **现实含义**：系统长期运行中，处于状态 0 的时间比例约为 **28.57%**，处于状态 1 的时间比例约为 **71.43%**。（若状态 0 是「正常」、1 是「故障」，则**长期可用率只有 2/7 ≈ 28.6%**——这个系统需要改进。）

   **与第 6 题③的呼应**：`p₀₀⁽²⁾ = 0.35`，已明显向 `π₀ = 0.2857` 靠近。

8. **① 偶函数**：`R(−τ) = σ²e^{−a|−τ|} = σ²e^{−a|τ|} = R(τ)` ✓
   **② `|R(τ)| ≤ R(0)`**：`R(0) = σ²e⁰ = σ²`；`|R(τ)| = σ²e^{−a|τ|}`。因 `a > 0`，`|τ| ≥ 0` 时 `e^{−a|τ|} ≤ 1`，故 `|R(τ)| ≤ σ² = R(0)` ✓
   **记忆长短**：`R(τ) = σ²e^{−a|τ|}` **按指数速度衰减**。
   - `a` **越大** ⟹ 衰减**越快** ⟹ 过程**记忆越短**（相关性只保持很短的时间）；
   - `a` **越小** ⟹ 衰减**越慢** ⟹ 过程**记忆越长**（如 `a = 0.01` 时，即使 `τ = 100` 仍有 `e^{−1} = 0.368` 的相关性）。
   **典型对应**：这种指数型自相关正是 **AR(1) 模型**的连续时间版本（Ornstein-Uhlenbeck 过程），也常用来刻画**湍流速度、利率、气温波动**。

9. **① `φ = 0.9`**：`|0.9| < 1`，**平稳**。`Var = 1/(1 − 0.81) = 1/0.19 = 5.2632`
   **② `φ = −0.5`**：`|−0.5| = 0.5 < 1`，**平稳**。`Var = 1/(1 − 0.25) = 1/0.75 = 1.3333`
   （**注意**：负 `φ` 也是平稳，只是自相关**交替变号**：`ρ(1) = −0.5`、`ρ(2) = 0.25`、`ρ(3) = −0.125`。）
   **③ `φ = 1`**：`|1| = 1`，**不满足 `|φ| < 1`，非平稳**。此时 `X_t = X_{t−1} + ε_t` 是**随机游走**，`Var(X_t) = tσ² = t` 随时间**无限增长**（第 `t` 步的方差等于 `t`），**不存在有限的平稳方差**。
   （**补充**：`Var = 1/(1 − 0.81) = 5.26` 远大于 `Var = 1/(1 − 0.25) = 1.33`，说明 **`|φ|` 越大波动越剧烈**——扰动累积得更久。）

10. **问题一：`φ̂ = 0.98` 意味着极强的持续性，但它本身是「非平稳临界」的强烈信号**。`φ = 0.98` 时 `Var = σ²/(1 − 0.9604) = σ²/0.0396 ≈ 25σ²`，方差极大；更重要的是，**`φ̂` 的抽样分布在小样本下严重偏向 1 下方**（**Dickey-Fuller 偏倚**），`φ̂ = 0.98` 很可能在统计上**无法拒绝 `φ = 1`（随机游走）**。**正确的做法是先做单位根检验（ADF 检验），而不是直接用 AR(1) 拟合。**

    **问题二：`R² = 0.96` 在时间序列里具有极大的误导性**。股价序列有强趋势（两边都随时间增长），回归的 `R²` 自然很高——**但这反映的是「共同趋势」，不是预测能力**。第 8 章易错点已指出：**`R²` 高不等于预测准**。时间序列里更极端的例子是：**用「昨天的价格」预测「今天的价格」，`R²` 可以高达 0.99，但误差仍然是价格的 1~2%**——听起来不大，但对日收益率来说已完全淹没真实信号。

    **问题三：收益率 ≠ 价格，且「可预测」在金融上极其可疑**。若真是**日收益率**，`φ̂ = 0.98` 意味着自相关高达 0.98，这与**有效市场假说**和**大量实证研究**（日收益率自相关通常在 0.05 以下，甚至不显著）严重矛盾。**更可能是数据或代码出错**：常见原因包括
    - **误用了价格而非收益率**；
    - **数据未做平稳化**（未差分）；
    - **数据泄漏**（用未来的信息构造特征）；
    - **重叠窗口/重复计算**导致人为的自相关。

    **正确表述**：「基于 AR(1) 拟合，`φ̂ = 0.98`；但该系数接近单位根，需用 ADF 检验判断是否为随机游走。同时 `R²` 高主要来自趋势的贡献，**必须做样本外预测检验**（如滚动预测并计算 RMSE），才能评估真实预测能力。」
    **教训**：**永远先做样本外验证，再看拟合指标**——这条规则对 ARIMA、对回归、对深度学习模型都同样适用。
