# 附录B · 易错点与题型总结

> **用法**：做题卡壳时按「题型」查套路；考前错题复盘时按「易错点」逐条自检。
> **核心主张**：**这门课 90% 的失分不是「算错」，而是「选错方法」和「踩中概念陷阱」。** 本附录把这两件事分别做成两张清单。

# 第一部分 · 高频易错点总清单

## B1 概念辨析类（最致命，考选择题与判断题）

| # | 易混淆的两组概念 | 区别要点 | 典型反例 |
|---|---|---|---|
| 1 | **互斥 vs 独立** | 互斥：`P(AB)=0`（不能同时发生）；独立：`P(AB)=P(A)P(B)`（互不影响） | 只有当 `P(A)=0` 或 `P(B)=0` 时两者才同时成立 |
| 2 | **两两独立 vs 相互独立** | 相互独立要求**四个等式**全成立 | 三事件两两独立但 `P(ABC) ≠ P(A)P(B)P(C)` |
| 3 | **不相关 vs 独立** | 独立 ⟹ 不相关；**不相关 ⇏ 独立** | `X ~ U(−1,1)`，`Y = X²`：`ρ = 0` 但完全依赖 |
| 4 | **不相关 vs 不线性相关** | `ρ = 0` 只说明**没有线性关系** | 同上，`Y = X²` 有强非线性关系 |
| 5 | **分布函数连续 vs 随机变量连续** | 分布函数连续 ≠ 连续型（还有奇异型） | 康托尔分布：`F` 连续但不可写成积分 |
| 6 | **`f(x)` 是概率 vs 密度** | `f(x)` **不是概率**，可以大于 1 | `U(0, 0.5)` 的密度 `f(x) = 2 > 1` |
| 7 | **`P(X = a) = 0` vs 不可能事件** | 连续型中 `P(X=a)=0`，但 `{X=a}` **不是**不可能事件 | 几何概型中「落在一个点上」概率为 0 但可能发生 |
| 8 | **频率 vs 概率** | 频率是**试验结果**（随机），概率是**客观属性**（确定） | 抛 10 次得 7 次正面，频率 0.7 ≠ 概率 0.5 |
| 9 | **`H₀` 与「想证明的结论」** | **把想证明的放 `H₁`**，`H₀` 里必须有等号 | 「证明新工艺更好」应设 `H₁: μ > μ₀` |
| 10 | **「接受 `H₀`」vs「证明 `H₀`」** | 接受只是「证据不足」，不是「证明成立」 | 样本太小必然接受 `H₀` |
| 11 | **统计显著 vs 实际重要** | 样本量极大时，微小差异也会「显著」 | `n = 10⁶` 时 0.1% 的差异也显著 |
| 12 | **相对风险 vs 绝对风险** | 新闻常说「风险翻倍」，实际可能从 0.01% 涨到 0.02% | 必须看**基数** |
| 13 | **置信区间的随机性** | `θ` 是常数，**随机的是区间** | 不能说「`θ` 落入区间的概率是 0.95」 |
| 14 | **`R²` 高 vs 预测准** | `R²` 只说明拟合了**历史数据**的变异 | 时序数据 `R²` 高常只因共同趋势 |
| 15 | **均值区间 vs 个体预测区间** | 个体区间根号里多一项 `1`，**永远更宽** | 混用会高估预测精度 |

## B2 计算操作类（失分最集中的地方）

| # | 错误做法 | 正确做法 | 位置 |
|---|---|---|---|

## B3 表述与严谨性类（证明题与解答题扣分点）

1. **「概率为 0」≠「不可能」，「概率为 1」≠「必然」**（连续型情形）。
2. **写分布函数必须说明分段区间**，不能只给一个表达式。
3. **用全概率公式前必须验证「划分」**：`B₁, …, Bₙ` 两两互斥且并为 `Ω`。
4. **条件概率要求分母不为零**：写 `P(B|A)` 前应确认 `P(A) > 0`。
5. **`E(X)` 存在要求绝对收敛**：`Σ|xᵢ|pᵢ < ∞` 或 `∫|x|f(x)dx < ∞`（柯西分布是反例）。
6. **证独立性要验证所有 `(x,y)`**，不能只验证几个特殊点。
7. **假设检验结论要写完整**：「在显著性水平 `α = 0.05` 下，拒绝 `H₀`，认为……」，不能只写「拒绝」。
8. **区间估计结论要带上置信度**：「`μ` 的 95% 置信区间为 (a, b)」。
9. **证明题不要跳步**，尤其是「由……得……」这类推理，要写出依据（用了哪个定理/性质）。
10. **数值结果要保留合适位数**：一般保留 4 位小数或 2 位小数，且**中间过程不要提前四舍五入**。

## B4 应试心理与策略类

| # | 陷阱 | 对策 |
|---|---|---|
| 1 | 在难题上死磕，导致简单题没时间 | **先易后难**：第一遍只做「一眼会」的题 |
| 2 | 看到「证明」就跳过 | 证明题通常 6~12 分，**写多少得多少**，绝不空着 |
| 3 | 计算到一半发现不对就全部划掉重写 | **保留步骤**，通常有步骤分 |
| 4 | 忘记查表数值 | **熟记 `z_{0.05} = 1.645`、`z_{0.025} = 1.96`、`t_{0.025}(4) = 2.7764` 等常用值** |
| 5 | 检验方向写反 | 落笔前先问：**「我想证明什么？它应该在 `H₁`。」** |
| 6 | 单位不统一（分钟 vs 小时） | **做题第一步统一单位**（泊松过程的 `λ` 与 `t` 必须匹配） |

# 第二部分 · 九大题型解题套路

## 题型一 · 古典概型与几何概型计数

**识别特征**：题目出现「任取」「随机抽取」「等可能」「至少有一个」「恰好有 k 个」。

**解题四步**：

1. **设事件**：用字母把题目里的每句话翻译成事件（如 `A = {至少有一件次品}`）。
2. **定概型**：判断是古典（有限、等可能）还是几何（区域、等可能）。
3. **算两个数**：
   - 古典：`P(A) = k/n`，**先算分母 `n`（样本空间大小），再算分子 `k`**；
   - 几何：`P(A) = μ(A)/μ(Ω)`，**画出区域图**。
4. **优选对立事件**：看到「至少有一个」，**先想 `P(Ā) = 1 − P(A)`**。

**计数工具选择表**：

| 关键词 | 工具 | 说明 |
|---|---|---|
| 「任取 k 个」「不放回」 | `C(n, k)` | **组合**（顺序无关） |
| 「排队」「依次抽取」「有序」 | `A(n, k)` | **排列**（顺序有关） |
| 「可重复」「分房」「生日」 | `nᵐ` | **可重复排列** |
| 「分成 m 堆」 | `n!/[m₁!…]` | 分组 |
| 「随机取 k 件，恰有 j 件次品」 | `C(M,j)C(N−M,k−j)/C(N,k)` | **超几何概型** |

**四大经典模型**：

| 模型 | 样本空间 `n` | 说明 |
|---|---|---|
| **抽球模型** | `C(N, k)` | 不放回，用超几何 |
| **分房模型** | `Nⁿ` | n 个人住 N 间房 |
| **生日问题** | `365ⁿ`；「至少两人同生日」用 `1 − A(365,n)/365ⁿ` | 对立事件 |
| **会面问题** | 几何概型，`1 − (1 − t/T)²` | 画正方形区域 |

**范例（第1章例 1.3、例 1.4）**：抽签公平性 —— 无论第几个抽，中签概率都是 `M/N`（用全概率公式可证）。**直觉上「先抽占便宜」是错的。**

## 题型二 · 全概率公式与贝叶斯公式

**识别特征**：题目出现「分几批」「由几个车间生产」「先验」「已知结果反推原因」。

**解题四步**：

1. **设「划分」**：找到样本空间的一个划分 `B₁, …, Bₙ`（**互斥 + 并起来是全部**）。这通常是「来源」「原因」「批次」「类别」。
2. **设「结果」事件 `A`**：这是题目问的那个「现象」。
3. **写出已知概率**：
   - **先验** `P(Bᵢ)`（各来源的占比）；
   - **条件概率** `P(A|Bᵢ)`（各来源产生该现象的概率）。
4. **选公式**：
   - 问「**结果发生的总概率**」→ **全概率**：`P(A) = Σᵢ P(Bᵢ)P(A|Bᵢ)`；
   - 问「**已知结果，反推是某个原因的概率**」→ **贝叶斯**：`P(Bⱼ|A) = P(Bⱼ)P(A|Bⱼ)/P(A)`。

**画树状图（强烈推荐）**：

```
                  ┌── A   P(B₁)P(A|B₁)
        ┌── B₁ ───┤
        │         └── Ā
  起点 ─┤
        │         ┌── A   P(B₂)P(A|B₂)
        └── B₂ ───┤
                  └── Ā
```

**树状图的用法**：**各「叶子的概率」相乘，同层的叶子概率相加**。全概率公式 = 把所有「结果 A」的叶子相加；贝叶斯 = 用某一片叶子除以所有 A 叶子之和。

**同类问题的两大变体**：

| 变体 | 划分方式 | 典型场景 |
|---|---|---|
| **多阶段试验** | 按**前一次试验的结果**划分 | 连续两次抽球、先掷骰子再抽球 |
| **假阳性/假阴性** | 划分 = {有病, 无病}；结果 = {检测阳性} | 医学检测、垃圾邮件过滤、欺诈检测 |

**核心陷阱（第1章例 1.6）**：**假阳性悖论**。检测准确率 99%，但若患病率只有 0.1%，则检测阳性者真正患病的概率可能只有 9% 左右。
**原因**：**基数效应**——健康人基数极大，即使误诊率低，误诊的**绝对人数**也可能超过真正患病的**绝对人数**。
**计算**：`P(病|阳) = 0.001×0.99 / (0.001×0.99 + 0.999×0.01) = 0.00099/0.01098 = 0.0902`
**教训**：**永远要把「比率」换算成「人数」再判断。**

**易错点**：
- ⚠️ 忘了验证「划分」（`Bᵢ` 必须互斥且完备）；
- ⚠️ 贝叶斯公式的分母忘了展开成全概率；
- ⚠️ 把 `P(A|B)` 与 `P(B|A)` 搞反（**这是最经典的方向性错误**）。

## 题型三 · 随机变量分布函数与概率密度的确定

**识别特征**：给出 `F(x)` 求 `f(x)`，或给出 `f(x)` 求 `F(x)`，或「求常数 A」使某个函数成为分布函数/密度。

**子类型 A：已知 `f(x)` 含待定常数，求常数**

1. 用**规范性**：`∫_{−∞}^{+∞} f(x)dx = 1`，解出常数。
2. 再验证 `f(x) ≥ 0`。

**子类型 B：已知 `F(x)` 含待定常数，求常数**

用**四条性质**：`F(−∞)=0`、`F(+∞)=1`、**单调不减**、**右连续**。
> **⚠️ 右连续是关键**（常在分段点处用）：`lim_{x→a⁺} F(x) = F(a)`。

**子类型 C：判断某函数能否为分布函数**

逐条检查四条性质。**最常出错的是「单调不减」和「右连续」。**
**快速杀手锏**：**矩形公式**（二维情形）——`P(a < X ≤ b, c < Y ≤ d) = F(b,d) − F(a,d) − F(b,c) + F(a,c)` **必须 ≥ 0**。若不满足，**一定不是联合分布函数**（见第 3 章 **3.1.1 节的函数性质 4（矩形公式）**）。

**子类型 D：由 `F(x)` 求 `f(x)` 或由 `f(x)` 求 `F(x)`**

| 方向 | 方法 | 注意事项 |
|---|---|---|
| `F → f` | 分段求导 | **分段点处的值可任意指定**（不影响积分） |
| `f → F` | 分段积分，`F(x) = ∫_{−∞}^{x} f(t)dt` | **每段要累加前面各段的积分**，别忘写常数使其连续 |

**子类型 E：求 `P(a < X ≤ b)`**

`P(a < X ≤ b) = F(b) − F(a)`
**离散型另算**：`P(a < X ≤ b) = Σ_{a < xᵢ ≤ b} pᵢ`
**连续型可随意开闭**：`P(a<X<b) = P(a≤X≤b) = F(b)−F(a)`（端点概率为 0）

**易错点**：
- ⚠️ 分段积分时忘加前一段的值，导致 `F(x)` 不连续；
- ⚠️ 离散型忘了「右连续」——`F(x) = Σ_{xᵢ ≤ x} pᵢ` 是**取等号**；
- ⚠️ 连续型中写出 `P(X = a) = f(a)`（**`f(a)` 不是概率**）。

## 题型四 · 随机变量函数的分布

**识别特征**：给出 `X` 的分布，求 `Y = g(X)` 的分布。

**解题四步（分布函数法，通用）**：

1. **求 `Y` 的取值范围**（先定范围，能避开很多错误）；
2. **写 `F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y)`**；
3. **解不等式** `g(X) ≤ y`，化为关于 `X` 的事件，用 `F_X` 表示；
4. **对 `y` 求导**得 `f_Y(y)`（**注意分段讨论**）。

**当 `g` 严格单调时的捷径（公式法）**：

`f_Y(y) = f_X(h(y)) · |h'(y)|`，其中 `h = g⁻¹`（**别忘绝对值**）

**当 `g` 非单调时**：**必须用分布函数法**，把 `g(X) ≤ y` 拆成若干段区间之和。

**三个必考结论**：

| 变换 | 结论 |
|---|---|
| `X ~ N(μ, σ²)`，`Y = aX + b`（`a ≠ 0`） | **`Y ~ N(aμ + b, a²σ²)`**（**标准差取绝对值**） |
| `X ~ N(0,1)`，`Y = X²` | `Y ~ χ²(1)` |
| `X ~ U(0,1)`，`Y = −2ln X` | `Y ~ χ²(2)`（即 `E(1/2)`） |

**二维情形（`Z = X + Y`）**：

- **卷积公式（`X, Y` 独立）**：`f_Z(z) = ∫_{−∞}^{+∞} f_X(x) f_Y(z − x)dx`
- **画图定限是关键**：先在 `xOy` 平面上画出区域 `{(x,y) : 0 < x < ∞, 0 < z−x < ∞}`，再按 `z` 的取值**分段**积分。

**`max` / `min`（`X, Y` 独立，**这是送分题，务必背熟**）**：

```
F_max(z) = F_X(z) · F_Y(z)
F_min(z) = 1 − [1 − F_X(z)][1 − F_Y(z)]
```

**典型应用**：串联系统寿命 = `min(X₁,…,Xₙ)`；并联系统寿命 = `max(X₁,…,Xₙ)`。

**易错点**：
- ⚠️ 公式法忘写 `|h'(y)|` 的绝对值；
- ⚠️ `Y = X²` 时忘记 `y < 0` 的部分概率为 0；
- ⚠️ 卷积公式的积分上下限忘记由「`f_X(x) ≠ 0` 且 `f_Y(z−x) ≠ 0`」共同确定；
- ⚠️ `max`/`min` 公式要求 `X, Y` **独立**（不独立时不能用）。

## 题型五 · 二维随机变量（联合、边缘、条件、独立性）

**识别特征**：给出 `f(x,y)` 或 `p_{ij}` 的表格，问边缘分布、条件分布、独立性、概率。

**解题五步**：

1. **求常数**：用 `ΣᵢΣⱼ p_{ij} = 1` 或 `∫∫ f(x,y)dxdy = 1`。
2. **定定义域**：**把定义域在坐标系中画出来**（矩形？三角形？圆形？）。**这一步最容易被跳过，也最容易出错。**
3. **求边缘分布**：
   - 离散：**行和给 `X`，列和给 `Y`**；
   - 连续：**积掉谁就得到另一个的边缘** —— `f_X(x) = ∫ f(x,y)dy`（**注意积分限由定义域决定**）。
4. **判独立性**：
   - 通法：验证 `f(x,y) = f_X(x)f_Y(y)`（对一切 `x, y`）或 `p_{ij} = p_X(xᵢ)p_Y(yⱼ)`（对一切 `i,j`）；
   - **快速判据**：`f(x,y)` 可写成 `g(x)h(y)` 且**定义域是矩形** ⟹ 独立。
   - **反判据**：若定义域**不是矩形**（三角形、圆形），**一定不独立**。
5. **求条件分布**：`f_{Y|X}(y|x) = f(x,y)/f_X(x)`（分母不为 0），再求条件概率或条件期望。

**离散型表格题的速算技巧**：

```
         Y=0   Y=1   Y=2   │ p_{X}(xᵢ)   ← 行和
X=0      0.1   0.2   0.1   │   0.4
X=1      0.2   0.3   0.1   │   0.6
─────────────────────────┼──────────
p_{Y}(yⱼ) 0.3   0.5   0.2   │   1.0
           ↑ 列和
```

**独立性检查**：看 `p_{ij}` 是否等于「行和 × 列和」。例如 `p₀₀ = 0.1`，而 `p_X(0)·p_Y(0) = 0.4 × 0.3 = 0.12 ≠ 0.1`，**故不独立**。
**速判技巧**：**若表格中任意两行成比例，则独立**（因为 `p_{ij} = p_X(xᵢ)p_Y(yⱼ)` 意味着每行都是 `p_Y` 的倍数）。

**易错点**：
- ⚠️ 求边缘密度时积分限写错（忘记由定义域约束）；
- ⚠️ 判独立时只看「能否分离变量」，**忘了检查定义域是否为矩形**；
- ⚠️ 由 `ρ = 0` 直接断言独立（**只有二维正态才成立**）；
- ⚠️ 条件分布的**分母写错**（用 `f_X(x)` 而不是 `f_Y(y)`）。

## 题型六 · 数字特征的计算与证明

**识别特征**：求 `E(X)`、`D(X)`、`Cov(X,Y)`、`ρ_{XY}`，或证明某估计量无偏/有效。

**解题四步**：

1. **判断类型**，选公式：

| 类型 | `E(X)` | `D(X)` |
|---|---|---|
| 离散 | `Σ xᵢpᵢ` | `Σ (xᵢ−E(X))²pᵢ` |
| 连续 | `∫ x f(x)dx` | `∫ (x−E(X))²f(x)dx` |
| **已知分布类型** | **直接查分布表** | **直接查分布表** |
| **`Y = g(X)`** | `E[g(X)] = ∫ g(x)f(x)dx` | —— |

2. **优先用性质，别硬算**：
   - `D(X) = E(X²) − [E(X)]²`（**最常用**）；
   - `D(CX) = C²D(X)`；
   - `E(X+Y) = E(X) + E(Y)`（**永远不需要独立**）；
   - `D(X+Y) = D(X) + D(Y) + 2Cov(X,Y)`；
   - **`D(X+Y) = D(X) + D(Y)` 当且仅当不相关**。
3. **求协方差**：`Cov(X,Y) = E(XY) − E(X)E(Y)`，其中 `E(XY) = ∫∫ xy f(x,y)dxdy`。
4. **求相关系数**：`ρ = Cov(X,Y)/√(D(X)D(Y))`，并**检验 `|ρ| ≤ 1`**。

**几类高频问题的固定套路**：

| 问题形态 | 套路 |
|---|---|
| **`E[min(X,Y)]` / `E[max(X,Y)]`** | 先用 `max + min = X + Y` 与 `max − min = \|X−Y\|` 的关系化简 |
| **`X` 的分布未知，只给 `E(X)`、`D(X)`** | 用**切比雪夫不等式**给出概率上界 |
| **求「至少」「至多」的概率上界** | 切比雪夫不等式 |
| **`N` 个产品中有 `M` 个次品，不放回取 `n` 个的次品数** | 超几何分布，期望 `nM/N` |
| **把 `X` 拆成指示变量之和** | **`X = Σ Iᵢ`，则 `E(X) = ΣP(Iᵢ=1)`**（**极其实用**） |

> **「指示变量法」是求期望的最强技巧**：例：`n` 个人随机拿帽子，求「拿到自己帽子的人数」的期望。
> 设 `Iᵢ = 1` 表示第 `i` 人拿到自己的帽子，则 `X = ΣIᵢ`，`P(Iᵢ=1) = 1/n`，故 **`E(X) = n × (1/n) = 1`**。
> **不需要独立性！期望的线性性无条件成立。** 这是「不需要独立」这一性质最有价值的应用。

**无偏性证明的标准格式**：

> 要证 `θ̂` 是 `θ` 的无偏估计，只需**计算 `E(θ̂)`**，看是否等于 `θ`。
> **常用工具**：`E(X̄) = μ`、`E(S²) = σ²`、`E(Xᵢ) = μ`。

**易错点**：
- ⚠️ `E(X²) = [E(X)]²`（**最常见的错误**）；
- ⚠️ `D(2X) = 2D(X)`（**应为 `4D(X)`**）；
- ⚠️ `E(XY) = E(X)E(Y)` 无条件使用；
- ⚠️ 积分区域写错导致 `E(XY)` 算错；
- ⚠️ 用 `D(X+Y) = D(X)+D(Y)` 却没验证不相关。

## 题型七 · 大数定律与中心极限定理的应用

**识别特征**：题目出现「大量」「n 个独立同分布」「近似服从」「用正态近似求概率」「至少需要多少样本」。

**解题四步**：

1. **找 `n`、`μ`、`σ²`**：`n` 是独立的随机变量个数，`μ = E(Xᵢ)`，`σ² = D(Xᵢ)`。
2. **写近似分布**：
   - **和的近似**：`ΣXᵢ ≈ N(nμ, nσ²)`；
   - **均值的近似**：`X̄ ≈ N(μ, σ²/n)`。
3. **标准化**：`Z = (ΣXᵢ − nμ)/(σ√n) ≈ N(0,1)` 或 `Z = (X̄ − μ)/(σ/√n) ≈ N(0,1)`。
4. **查表算概率**；若题目问「至少需要多少 n」，则**解不等式**并**向上取整**。

**二项分布的正态近似（最常考）**：

`X ~ B(n, p)`，当 `np > 10` 且 `n(1−p) > 10` 时：

`(X − np)/√(np(1−p)) ≈ N(0, 1)`

**⚠️ 必须加连续性修正**：

| 要求的概率 | 修正后的近似 |
|---|---|
| `P(X ≤ k)` | `Φ((k + 0.5 − np)/√(np(1−p)))` |
| `P(X ≥ k)` | `1 − Φ((k − 0.5 − np)/√(np(1−p)))` |
| `P(a ≤ X ≤ b)` | `Φ((b+0.5−np)/√…) − Φ((a−0.5−np)/√…)` |

> **为什么要加 0.5**：**二项分布是离散的（取值跳跃），正态是连续的**。把「`X ≤ k`」这个离散区间扩展到连续区间「`X ≤ k + 0.5`」，才能让近似更准。**漏掉修正会导致系统性偏差。**

**近似方法选择表**：

| 条件 | 方法 |
|---|---|
| `n ≤ 20` | **直接算二项分布**（`C(n,k)pᵏ(1−p)^{n−k}`） |
| `n` 大、`p` 小（`np ≤ 10`，经验上 `p ≤ 0.1`） | **泊松近似 `P(np)`** |
| `n` 大、`np` 与 `n(1−p)` 都 > 10 | **正态近似**（**加连续性修正**） |

**样本容量问题的标准解法**：

> 题目：「用中心极限定理确定 `n`，使 `P(|X̄ − μ| < ε) ≥ 1 − α`」
>
> 1. `P(|X̄ − μ| < ε) = P(|Z| < ε√n/σ) ≥ 1 − α`；
> 2. 故 `ε√n/σ ≥ z_{α/2}`；
> 3. 解出 **`n ≥ (z_{α/2}σ/ε)²`**，**向上取整**。

**易错点**：
- ⚠️ 忘记乘 `√n` 或漏掉 `σ`；
- ⚠️ 把 `D(X̄)` 写成 `σ²`（**应为 `σ²/n`**）；
- ⚠️ 二项近似忘记连续性修正；
- ⚠️ **样本容量算出小数不向上取整**（`n` 必须是整数，且不能比要求小）；
- ⚠️ 泊松近似与正态近似用错场景。

## 题型八 · 参数估计

**识别特征**：题目出现「求矩估计」「求最大似然估计」「求置信区间」「判断无偏性」。

### 8.1 矩估计（替换原理）

1. 写出**总体矩** `E(X)`（含未知参数，有几个参数写几阶矩）；
2. **令 `E(X) = X̄`、`E(X²) = A₂ = (1/n)ΣXᵢ²`**……列出方程组；
3. 解方程组得估计量。

**一个参数**：`E(X) = X̄` 一个方程就够了。

### 8.2 最大似然估计（MLE）四步法

1. **写似然函数**：

| 类型 | `L(θ)` |
|---|---|
| 连续型 | `L(θ) = Πᵢ₌₁ⁿ f(xᵢ; θ)` |
| 离散型 | `L(θ) = Πᵢ₌₁ⁿ P(X = xᵢ; θ)` |

2. **取对数**：`ln L(θ) = Σᵢ ln f(xᵢ; θ)`（**把乘积变成求和**）；
3. **求导令零**：`d ln L(θ)/dθ = 0`，解出 `θ̂`；
4. **验证最大**（二阶导 < 0，或由问题性质保证）。

**⚠️ 非正则情形（必考陷阱）**：若**支撑集依赖于未知参数**（如 `X ~ U(0,θ)`、`X ~ U(θ, θ+1)`），**不能用求导法**！

> **`X ~ U(0, θ)` 的 MLE 推导**：
> `L(θ) = Π (1/θ) = 1/θⁿ`，但**仅当所有 `0 < xᵢ < θ` 时成立**，即 **`θ > max(xᵢ) = x₍ₙ₎`**。
> 故 `L(θ) = 1/θⁿ`（`θ > x₍ₙ₎`），这是 `θ` 的**单调递减**函数，在 `θ` 最小处取最大。
> **所以 `θ̂ = x₍ₙ₎ = max(X₁, …, Xₙ)`。**
>
> **⚠️ 混淆对比**：`U(0,θ)` 的**矩估计**是 `θ̃ = 2X̄`（因为 `E(X) = θ/2`）。**两者完全不同，考试常同时问。**

### 8.3 估计量的评选

| 标准 | 验证方法 |
|---|---|
| **无偏性** | 计算 `E(θ̂)`，看是否 `= θ` |
| **有效性** | 计算两个无偏估计量的方差，**方差小的更有效** |
| **一致性** | 用大数定律或切比雪夫不等式证 `θ̂ₙ →P θ` |

**常用无偏性结论（可直接引用）**：`E(X̄) = μ`；`E(S²) = σ²`；`E(X̄₁ − X̄₂) = μ₁ − μ₂`。

### 8.4 区间估计

**四步法**：

1. **明确待估参数和已知条件**（估 `μ` 还是 `σ²`？`σ` 已知吗？几个总体？）—— **查选择表**（见附录A A6.3）；
2. **构造枢轴量**（含待估参数，但**不含其他未知参数**，且分布已知）；
3. **由 `P(a < G < b) = 1 − α` 反解出 `θ` 的范围**；
4. **代入样本值**，写出区间。

**记忆口诀**：

> **估均值：σ 已知用 Z，σ 未知用 t。**
> **估方差：用 χ²，端点「大配小」。**
> **两个方差比：用 F，「大配小」。**

**⚠️ `σ²` 区间端点的「大配小」推导**：由 `P(χ²_{1−α/2} < (n−1)S²/σ² < χ²_{α/2}) = 1−α`，解出 `σ²` 得
`(n−1)S²/χ²_{α/2} < σ² < (n−1)S²/χ²_{1−α/2}`
**下限配的是大的分位点 `χ²_{α/2}`，上限配的是小的 `χ²_{1−α/2}`**（因为 `σ²` 在分母上，取倒数后大小关系反转）。

**易错点**：
- ⚠️ 似然函数忘记取对数，直接对乘积求导；
- ⚠️ 非正则情形（`U(0,θ)`）错误地用求导法；
- ⚠️ 矩估计与 MLE 结果混用（**两者常常不同**）；
- ⚠️ **σ 未知时仍用 `z` 分位点**（必须用 `t(n−1)`）；
- ⚠️ `σ²` 区间端点忘记「大配小」；
- ⚠️ 置信区间的解释错误（说成「`θ` 落入区间的概率」）。

## 题型九 · 假设检验

**识别特征**：题目出现「检验」「是否显著」「能否认为」「判断是否可以接受」。

**解题五步法（固定模板，照抄即可）**：

**第 1 步：提出假设。** 把**想证明的结论放在 `H₁`**，`H₀` **必须含等号**。

| 题目说法 | `H₀` | `H₁` |
|---|---|---|
| 「是否显著**高于**」 | `μ = μ₀` | `μ > μ₀` |
| 「是否显著**低于**」 | `μ = μ₀` | `μ < μ₀` |
| 「是否**有显著差异**」 | `μ = μ₀` | `μ ≠ μ₀` |
| 「是否**符合标准**」 | `μ = μ₀` | `μ ≠ μ₀` |

**第 2 步：选检验统计量。** **查选择表**（附录A A7.2）：

> **口诀：单总体看「σ 已知否」，双总体看「σ 已知否 + 方差齐性否 + 是否配对」。**

**第 3 步：在 `H₀` 下确定分布**（`N(0,1)` / `t(n−1)` / `χ²(n−1)` / `F(n₁−1, n₂−1)`）。

**第 4 步：由 `α` 定拒绝域。** **拒绝域的位置由 `H₁` 决定**：

| `H₁` | 拒绝域 |
|---|---|
| `μ > μ₀` | `T > t_α` |
| `μ < μ₀` | `T < −t_α` |
| `μ ≠ μ₀` | `\|T\| > t_{α/2}` |

**第 5 步：代入数值，作判断，写完整结论。**

> **标准结论句式**：「因为 `T = 2.000 > t_{0.05}(15) = 1.7531`，`p = 0.0319 < 0.05`，所以在显著性水平 `α = 0.05` 下**拒绝 `H₀`**，认为该厂元件平均寿命**显著高于** 1000 小时。」
>
> **三条纪律（照抄这个句式前务必检查）**：
> ① **临界值要和检验方向匹配**。单侧（`H₁: μ > μ₀`）用 `t_α(15) = t_{0.05}(15) = 1.7531`；双侧（`H₁: μ ≠ μ₀`）才用 `t_{α/2}(15) = t_{0.025}(15) = 2.1315`。**本例若按双侧判据，`2.000 < 2.1315`，结论是不能拒绝**——同一个 `T` 值在两个方向下结论相反，这是最容易翻车的地方。
> ② **p 值要和检验方向匹配**。`p = 0.0319` 是**单侧** p 值；同一批数据的**双侧** p 值是 `0.0639`。写成 `p = 0.0319 < 0.05` 却用双侧判据，是自相矛盾。
> ③ **「显著高于 / 低于」是单侧结论用语**，只能配单侧检验；双侧检验只能说「**有显著差异**」。

**检验统计量速查（最常用四类）**：

| 场景 | 统计量 | 分布 |
|---|---|---|
| 单总体均值，**σ 已知** | `Z = (X̄ − μ₀)/(σ/√n)` | `N(0,1)` |
| 单总体均值，**σ 未知** | `T = (X̄ − μ₀)/(S/√n)` | `t(n−1)` |
| 单总体方差 | `χ² = (n−1)S²/σ₀²` | `χ²(n−1)` |
| 两总体均值，**方差齐** | `T = (X̄−Ȳ)/(S_w√(1/n₁+1/n₂))` | `t(n₁+n₂−2)` |
| 两总体方差比 | `F = S₁²/S₂²` | `F(n₁−1, n₂−1)` |
| **配对数据** | **先作差 `Dᵢ = Xᵢ − Yᵢ`，再对 `D` 做单样本 `t` 检验** | `t(n−1)` |
| 大样本（`n ≥ 30`），σ 未知 | `Z = (X̄ − μ₀)/(S/√n)` | 近似 `N(0,1)` |

**分布拟合检验（χ² 检验）的独立套路**：

1. `H₀`：总体服从 `F₀(x)`；
2. 分 `k` 个**互不相交**的区间；
3. **若有未知参数先估计出来**（设 `r` 个），再算理论概率 `pᵢ`；
4. 算 `χ² = Σ(fᵢ − npᵢ)²/(npᵢ)`；
5. **自由度 `k − r − 1`**，**拒绝域在右侧**；
6. **`npᵢ < 5` 的区间必须先合并**。

**易错点**：
- ⚠️ **`H₁` 写成了想推翻的结论**（**方向反了，结论就完全反了**）；
- ⚠️ `H₀` 里没有等号；
- ⚠️ **拒绝域的位置写反**（由 `H₁` 决定，不是由 `H₀`）；
- ⚠️ σ 未知时用 `z` 而不是 `t`；
- ⚠️ 配对数据用两独立样本检验；
- ⚠️ `χ²` 拟合检验自由度写成 `k − 1`（漏了 `r`）；
- ⚠️ `χ²` 拟合检验用了双侧；
- ⚠️ 结论只说「拒绝」不说「在什么水平下、认为什么成立」；
- ⚠️ 把「接受 `H₀`」说成「证明了 `H₀` 成立」。

## 加餐题型 · 方差分析与回归分析

**识别特征**：给出多组试验数据问「有无显著差异」；给出 `(xᵢ, yᵢ)` 数据求回归方程。

### 方差分析（动手就三步）

1. **算 `C = G²/n`**（`G` 为全部数据之和，`n` 为数据总个数）；
2. **算三个平方和**：`ST = ΣΣX_{ij}² − C`；`SA = Σ(Tᵢ²/nᵢ) − C`；`SE = ST − SA`；
3. **填表算 `F`**：

| 来源 | 平方和 | 自由度 | 均方 | F |
|---|---|---|---|---|
| 因素 | `SA` | `k − 1` | `SA/(k−1)` | `MS_A/MS_E` |
| 误差 | `SE` | `n − k` | `SE/(n−k)` | —— |
| 总和 | `ST` | `n − 1` | —— | —— |

4. **比较 `F` 与 `F_α(k−1, n−k)`**（**拒绝域永远在右侧**）。

### 一元线性回归（公式链，按顺序算）

```
Σx, Σy, Σx², Σy², Σxy, x̄, ȳ
        ↓
Lxx = Σx² − nx̄²    Lyy = Σy² − nȳ²    Lxy = Σxy − nx̄ȳ
        ↓
β̂₁ = Lxy/Lxx        β̂₀ = ȳ − β̂₁x̄        （验算：直线过 (x̄, ȳ)）
        ↓
U = β̂₁·Lxy          Q_e = Lyy − U        （验算：U + Q_e = Lyy，Q_e ≥ 0）
        ↓
σ̂² = Q_e/(n−2)      R² = U/Lyy           r = Lxy/√(Lxx·Lyy)（验算：R² = r²）
        ↓
F = U/(Q_e/(n−2))   t = β̂₁/√(σ̂²/Lxx)    （验算：F = t²）
        ↓
预测：ŷ₀ = β̂₀ + β̂₁x₀
```

**必做的两个合理性检查**（避免数据或计算错误）：

- **`U + Q_e = Lyy`** 且 **`Q_e ≥ 0`**（`Q_e < 0` 一定错）；
- **`R² = r²`** 且 **`F = t²`**（两两互验，只要有一个不符就是算错了）。

**均值区间 vs 个体区间**：

| 类型 | 标准误中的根号 | 宽窄 |
|---|---|---|
| 均值 `E(Y\|x₀)` | `√(1/n + (x₀−x̄)²/Lxx)` | **窄** |
| 个体 `Y₀` | `√(1 + 1/n + (x₀−x̄)²/Lxx)` | **宽** |

**易错点**：
- ⚠️ `df_E` 写成 `n − 1`（应为 `n − k`）；
- ⚠️ 双因素无重复时去算交互作用；
- ⚠️ `σ̂²` 分母写成 `n − 1`（应为 `n − 2`）；
- ⚠️ 用 `R²` 比较模型（应用调整 `R²`）；
- ⚠️ 混淆均值区间与个体预测区间；
- ⚠️ 外推到数据范围之外（**回归方程只在观测范围内有效**）。
