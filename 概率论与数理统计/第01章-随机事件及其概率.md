## 学习目标

1. **能**写出给定随机试验的样本空间，并正确用集合表示随机事件。
2. **能**熟练运用德摩根律把「至少一个发生」「全都发生」等文字语言翻译成事件运算式。
3. **能**由概率的三条公理推出逆事件公式、减法公式、加法公式并用于计算。
4. **能**判断一个问题是否属于古典概型，并用排列组合算出 `P(A) = k / n`。
5. **能**区分条件概率 `P(B|A)` 与积事件概率 `P(AB)`，会用乘法公式拆解多步试验。
6. **能**识别完备事件组，正确使用全概率公式与贝叶斯公式（含先验、后验概率的含义）。
7. **能**判断事件的独立性，并区分「互斥」与「独立」这两个完全不同的概念。
8. **能**用二项概率公式解决 n 重伯努利试验中「恰发生 k 次」「至少发生 k 次」的问题。

## 1.1 随机事件

### 1.1.1 随机试验

**随机试验（Random Experiment）E 的三个特征**：

1. **可重复性**：可以在相同条件下重复进行；
2. **可观测性**：每次试验的可能结果不止一个，且试验前能事先明确试验的所有可能结果；
3. **不确定性**：每次试验前不能确定哪一个结果会出现。

> **重点**：三条缺一不可。例如「明天是否下雨」不可重复（不满足 1）；「测量某物体的长度」结果唯一确定（不满足 2）。

**为什么要抽象出「随机试验」**：整个概率论研究的对象就是随机试验。把它抽象成三句话，是为了后面能用**集合**去描述它——样本空间就是结果的集合，事件就是子集。

**典型随机试验举例**：

| 试验 E | 试验结果 | 是否满足三特征 |
|---|---|---|
| E₁：抛一枚硬币 | 正面、反面 | 满足 |
| E₂：掷一颗骰子 | 1,2,3,4,5,6 | 满足 |
| E₃：记录电话交换台一分钟内接到的呼叫次数 | 0,1,2,… | 满足 |
| E₄：在一批灯泡中任取一只测寿命 | t ≥ 0 | 满足 |
| E₅：抛硬币直到出现正面为止 | 正、反正、反反正、… | 满足（可列无限个结果） |

---

### 1.1.2 样本空间与随机事件

**样本点（Sample Point）ω**：随机试验 E 的每一个可能结果。
**样本空间（Sample Space）S（或 Ω）**：全体样本点组成的集合，`S = {ω}`。

**随机事件（Random Event）**：样本空间 S 的子集，用大写字母 A、B、C 表示。
**事件 A 发生 ⟺ 试验结果 ω ∈ A。**

三个特殊事件：

- **基本事件**：只含一个样本点的单点集 `{ω}`；
- **必然事件**：S 本身（每次试验必然发生），`P(S) = 1`；
- **不可能事件**：空集 ∅（每次试验都不发生），`P(∅) = 0`。

> **重点**：必然事件、不可能事件严格来说不是「随机」事件（结果确定），但为了运算统一，把它们也当作事件处理。

### 1.1.3 事件间的关系与运算

| 关系/运算 | 记号 | 含义 | 概率含义 |
|---|---|---|---|
| 包含 | A ⊂ B | A 发生必导致 B 发生 | P(A) ≤ P(B) |
| 相等 | A = B | A ⊂ B 且 B ⊂ A | P(A) = P(B) |
| 和（并） | A ∪ B | A、B 至少有一个发生 | P(A∪B) |
| 积（交） | A ∩ B（简记 AB） | A、B 同时发生 | P(AB) |
| 差 | A − B | A 发生而 B 不发生 | A − B = A − AB = A·B̄ |
| 互斥（互不相容） | AB = ∅ | A、B 不能同时发生 | P(AB) = 0 |
| 对立（互逆） | B = Ā | A∪B = S 且 AB = ∅ | P(Ā) = 1 − P(A) |

**运算律**：

- 交换律：`A ∪ B = B ∪ A`，`AB = BA`
- 结合律：`(A ∪ B) ∪ C = A ∪ (B ∪ C)`，`(AB)C = A(BC)`
- 分配律：`A(B ∪ C) = AB ∪ AC`，`A ∪ (BC) = (A∪B)(A∪C)`
- 幂等律：`A ∪ A = A`，`AA = A`
- **德摩根律（对偶律，De Morgan's Law）**：
  - `(A ∪ B)̄ = Ā · B̄`　　「至少一个发生」的对立 = 「全都不发生」
  - `(AB)̄ = Ā ∪ B̄`　　「全都发生」的对立 = 「至少一个不发生」
  - n 元推广：`(A₁∪A₂∪…∪Aₙ)̄ = Ā₁Ā₂…Āₙ`，`(A₁A₂…Aₙ)̄ = Ā₁∪Ā₂∪…∪Āₙ`

> **重点**：德摩根律只需记一句——**「横线进出，并交互换」**。横线断开时 ∪ 变 ∩、∩ 变 ∪。这是考试中把文字叙述翻译成事件式子的核心工具。

### 1.1.4 文字语言的集合翻译表（做题必备）

| 文字叙述 | 事件表示 |
|---|---|
| A、B 至少有一个发生 | A ∪ B |
| A、B 同时发生 | AB |
| A 发生而 B 不发生 | A − B = AB̄ |
| A、B 恰有一个发生 | AB̄ ∪ ĀB |
| A、B 至多有一个发生 | AB̄ ∪ ĀB ∪ ĀB̄ = (AB)̄ |
| A、B 至少有一个不发生 | Ā ∪ B̄ = (AB)̄ |
| A、B 都不发生 | ĀB̄ = (A∪B)̄ |
| n 个事件 A₁,…,Aₙ 至少一个发生 | A₁∪A₂∪…∪Aₙ |
| n 个事件全不发生 | Ā₁Ā₂…Āₙ |

**例**：设 A、B、C 表示三个事件。用 A、B、C 表示「A 发生，B、C 至少有一个不发生」。
**解**：「B、C 至少有一个不发生」= B̄ ∪ C̄，与 A 同时发生，故为 `A(B̄ ∪ C̄) = AB̄ ∪ AC̄`。

## 1.2 随机事件的概率

### 1.2.1 频率

**频率（Frequency）**：在相同条件下做了 n 次试验，事件 A 发生了 n_A 次，则

`f_n(A) = n_A / n`

**频率的三条性质**：`f_n(A) ≥ 0`；`f_n(S) = 1`；若 A₁, A₂, …, A_k 两两互斥，则 `f_n(A₁∪…∪A_k) = f_n(A₁) + … + f_n(A_k)`。

**频率稳定性**：n 很大时，频率 `f_n(A)` 会在某个常数附近摆动并趋于稳定，这个常数就是 A 的概率。布丰（Buffon）投针、抛硬币实验都验证了这一点：

| 试验者 | 抛掷次数 n | 正面次数 n_A | 频率 f_n(A) |
|---|---|---|---|
| 德摩根 | 2048 | 1061 | 0.5181 |
| 布丰 | 4040 | 2048 | 0.5069 |
| 皮尔逊 | 12000 | 6019 | 0.5016 |
| 皮尔逊 | 24000 | 12012 | 0.5005 |

### 1.2.2 概率的公理化定义

**定义**：设 S 是样本空间，若对每个事件 A 都赋予一个实数 `P(A)`，且满足：

1. **非负性**：`P(A) ≥ 0`
2. **规范性**：`P(S) = 1`
3. **可列可加性**：若 A₁, A₂, … 两两互斥，则 `P(A₁∪A₂∪…) = P(A₁) + P(A₂) + …`

则称 `P(A)` 为事件 A 的**概率（Probability）**。这三条称为**概率公理**（柯尔莫哥洛夫 1933 年提出）。

### 1.2.3 由公理推出的重要性质（必背）

`P(∅) = 0`

**有限可加性**：若 A₁,…,A_k 两两互斥，则 `P(A₁∪…∪A_k) = P(A₁) + … + P(A_k)`

**逆事件公式**：`P(Ā) = 1 − P(A)`

**减法公式**：`P(A − B) = P(A) − P(AB)`；当 B ⊂ A 时 `P(A − B) = P(A) − P(B)`

**单调性**：若 A ⊂ B，则 `P(A) ≤ P(B)`，且 `P(B − A) = P(B) − P(A)`

**加法公式（必考）**：

`P(A ∪ B) = P(A) + P(B) − P(AB)`

`P(A∪B∪C) = P(A) + P(B) + P(C) − P(AB) − P(AC) − P(BC) + P(ABC)`

一般地（容斥原理）：

`P(A₁∪…∪Aₙ) = ΣP(Aᵢ) − ΣP(AᵢAⱼ) + ΣP(AᵢAⱼA_k) − … + (−1)^(n−1) P(A₁A₂…Aₙ)`

**有界性**：`0 ≤ P(A) ≤ 1`

> **重点**：加法公式的直觉是「先各自算，重复算的交集减掉」。两个事件减 1 次交集；三个事件减 3 次两两交集后，三交部分被减多了，要加回来 1 次。

## 1.3 古典概型与几何概型

**古典概型（Classical Probability Model）的两个条件**：

1. 样本空间只含**有限个**样本点：`S = {ω₁, ω₂, …, ω_n}`；
2. 每个样本点出现的可能性**相同**（等可能）。

在古典概型中，若事件 A 包含 k 个样本点，则

`P(A) = k / n = A 所含样本点数 / S 中样本点总数`

**计数工具（做题必备）**：

- 加法原理：完成一件事有 m 类办法，第 i 类有 nᵢ 种，则共 `n₁+n₂+…+n_m` 种。
- 乘法原理：分 m 个步骤，第 i 步有 nᵢ 种，则共 `n₁×n₂×…×n_m` 种。
- 排列（不放回、讲顺序）：`A(n,m) = n(n−1)…(n−m+1) = n! / (n−m)!`
- 全排列：`A(n,n) = n!`
- 组合（不放回、不讲顺序）：`C(n,m) = n! / [m!(n−m)!]`
- 可重复排列：从 n 个不同元素中有放回取 m 个排成一列，共 `n^m` 种。
- 常用值：`C(10,3) = 120`，`C(5,2) = 10`，`A(4,2) = 12`。

**三种典型模型（几乎每年都考）**：

| 模型 | 描述 | 样本点总数 |
|---|---|---|
| 摸球模型 | 袋中 a 个白球 b 个红球，任取 n 个 | C(a+b, n) |
| 分房模型 | n 个人随机住进 N 个房间 | N^n |
| 生日模型 | n 个人生日随机分布在 365 天 | 365^n |

**超几何概型（不放回抽样）通用公式**：N 件产品中有 M 件次品，从中任取 n 件，其中恰有 k 件次品的概率为

`P = C(M, k) · C(N−M, n−k) / C(N, n)`

其中 `k` 需满足 `max(0, n−N+M) ≤ k ≤ min(n, M)`，否则概率为 0。

### 1.3.1 几何概型

**几何概型（Geometric Probability Model）**：样本空间是某个可度量的区域（长度、面积、体积），且样本点在其中**均匀分布**。此时

`P(A) = A 的度量 / S 的度量`

> **重点**：几何概型与古典概型的关键区别是**样本点无限**。二者共同点是「等可能」。考试中几何概型几乎只考平面上两个变量的区域面积比。

**经典模型——会面问题**：甲、乙两人约定在 0 到 T 时之间在某地会面，先到者等候 t 分钟后离去（t < T）。求两人能会面的概率。

**解**：设甲、乙到达时刻分别为 x、y，则样本空间是正方形 `S = {(x,y) | 0 ≤ x ≤ T, 0 ≤ y ≤ T}`，面积 `T²`。
会面条件为 `|x − y| ≤ t`，对应 S 中夹在两条直线 `y = x + t` 与 `y = x − t` 之间的带状区域。
其**对立区域**是两个腰长为 `T − t` 的等腰直角三角形，面积 `2 × (1/2)(T − t)² = (T − t)²`。
故 `P(会面) = [T² − (T − t)²] / T² = 1 − (1 − t/T)²`。

取 `T = 60`、`t = 20`：`P = 1 − (1 − 1/3)² = 1 − 4/9 = 5/9 ≈ 0.5556`。

## 1.4 条件概率

### 1.4.1 条件概率的定义

**条件概率（Conditional Probability）**：设 A、B 是两个事件，且 `P(A) > 0`，则称

`P(B|A) = P(AB) / P(A)`

为「在事件 A 发生的条件下事件 B 发生的条件概率」。

**直观理解**：条件概率就是**把样本空间从 S 压缩到 A**，再看 B 在其中占多大比例。原来 B 的「份额」是 `P(B) = |B|/|S|`，现在是 `|AB|/|A|`。

**条件概率也是概率**：固定 A，`P(·|A)` 满足三条公理，因此所有概率性质对条件概率都成立，例如：

- `P(B̄|A) = 1 − P(B|A)`
- `P(B∪C|A) = P(B|A) + P(C|A) − P(BC|A)`

### 1.4.2 乘法公式

由定义式两边乘 `P(A)` 即得：

**乘法公式（Multiplication Rule）**：

`P(AB) = P(A) · P(B|A)`　（要求 P(A) > 0）

`P(AB) = P(B) · P(A|B)`　（要求 P(B) > 0）

**三事件推广**：`P(ABC) = P(A) · P(B|A) · P(C|AB)`（要求 P(AB) > 0）

**n 事件推广**：`P(A₁A₂…Aₙ) = P(A₁)P(A₂|A₁)P(A₃|A₁A₂)…P(Aₙ|A₁A₂…Aₙ₋₁)`

> **重点**：乘法公式用于**多步试验**——「第一步怎样，然后第二步怎样」。凡是题目出现「第一次…第二次…」的连续抽取（尤其是不放回抽取），就应立刻想到乘法公式。

### 1.4.3 全概率公式

**划分（完备事件组，Partition）**：设 B₁, B₂, …, Bₙ 满足

1. 两两互斥：`BᵢBⱼ = ∅`（i ≠ j）；
2. 并起来是全集：`B₁∪B₂∪…∪Bₙ = S`；
3. 每个都有正概率：`P(Bᵢ) > 0`。

则称 B₁, …, Bₙ 是样本空间 S 的一个**划分**。

**全概率公式（Law of Total Probability）**：设 B₁, …, Bₙ 是划分，A 为任一事件，则

`P(A) = Σᵢ P(Bᵢ) · P(A|Bᵢ) = P(B₁)P(A|B₁) + … + P(Bₙ)P(A|Bₙ)`

**怎么用（由因推果）**：事件 A 能通过多条「途径」发生，先按途径把 S 划分，再用加权平均算 A 的总概率。

**直观类比**：一个工厂有三条生产线（B₁, B₂, B₃），各自产量占比就是权重，各自的次品率是条件概率，总次品率就是加权平均。

### 1.4.4 贝叶斯公式

**贝叶斯公式（Bayes' Formula）**：设 B₁, …, Bₙ 是划分，`P(A) > 0`，则

`P(Bₖ|A) = P(Bₖ)P(A|Bₖ) / Σᵢ P(Bᵢ)P(A|Bᵢ) = P(Bₖ)P(A|Bₖ) / P(A)`

- `P(Bₖ)` 称为**先验概率（Prior Probability）**：试验前对「原因 Bₖ」的信念。
- `P(Bₖ|A)` 称为**后验概率（Posterior Probability）**：观察到结果 A 之后，对「原因 Bₖ」的重新评估。

> **重点**：全概率是「已知各原因，求结果」；贝叶斯是「已知结果，反推原因」。两者分母完全相同，贝叶斯只是把分子换成了某一项。

## 1.5 事件的独立性

### 1.5.1 两事件独立

**定义**：设 A、B 是两事件，若

`P(AB) = P(A) · P(B)`

则称 A 与 B **相互独立（Mutually Independent）**。

**等价说法**：当 `P(A) > 0` 时，A 与 B 独立 ⟺ `P(B|A) = P(B)`。即「A 发生与否不影响 B 发生的概率」。

**独立性的性质**：

- 若 A 与 B 独立，则 `A 与 B̄`、`Ā 与 B`、`Ā 与 B̄` 都独立。
- 必然事件 S、不可能事件 ∅ 与任何事件都独立。
- `P(A) = 0` 或 `P(A) = 1` 时，A 与任何事件都独立。

**证明（A 与 B 独立 ⟹ A 与 B̄ 独立）**：
因为 `A = AB ∪ AB̄` 且 `AB` 与 `AB̄` 互斥，
所以 `P(A) = P(AB) + P(AB̄)`；
由独立性 `P(AB) = P(A)P(B)`，得
`P(AB̄) = P(A) − P(A)P(B) = P(A)[1 − P(B)] = P(A)P(B̄)`，
故 A 与 B̄ 独立。∎

### 1.5.2 互斥 vs 独立（最易混淆）

| 对比项 | 互斥（互不相容） | 相互独立 |
|---|---|---|
| 定义式 | `AB = ∅` | `P(AB) = P(A)P(B)` |
| 几何图像 | 两个集合不重叠 | 一个集合在另一个中占比不变 |
| 概率推论 | `P(A∪B) = P(A)+P(B)` | `P(AB) = P(A)P(B)` |
| 关系 | 若 `P(A) > 0` 且 `P(B) > 0`，两者**不可能同时成立** | 同左 |
| 直观 | 有 A 就没 B | A 的信息对 B 毫无帮助 |

> **重点**：若 `P(A) > 0`、`P(B) > 0`，则「互斥」与「独立」是**矛盾**的：互斥意味着 A 一发生 B 就绝不发生，这恰恰是「影响极大」。只有当 `P(A) = 0` 或 `P(B) = 0` 时二者才可能同时成立。

### 1.5.3 三事件相互独立

**定义**：三个事件 A、B、C 相互独立，需**同时**满足 4 个等式：

`P(AB) = P(A)P(B)`，`P(AC) = P(A)P(C)`，`P(BC) = P(B)P(C)`（两两独立）

`P(ABC) = P(A)P(B)P(C)`（三三独立）

**两两独立推不出相互独立**（反例见例 1.7）。

### 1.5.4 n 重伯努利试验与二项概率公式

**伯努利试验（Bernoulli Trial）**：试验只有两个可能结果 A（成功）与 Ā（失败），记 `P(A) = p`，`P(Ā) = 1 − p`。

**n 重伯努利试验**：将伯努利试验独立重复 n 次。

**二项概率公式**：n 重伯努利试验中，事件 A 恰发生 k 次的概率为

`Pₙ(k) = C(n,k) · p^k · (1 − p)^(n−k)`，　k = 0, 1, 2, …, n

**「至少发生 k 次」**：`P(X ≥ k) = Σ_{j=k}^{n} C(n,j) p^j (1−p)^(n−j) = 1 − Σ_{j=0}^{k−1} C(n,j) p^j (1−p)^(n−j)`

> **重点**：求「至少一次」「至少一个」时，永远优先用 `1 − P(一次都没有)`，比逐项相加快得多。

## 典型例题

**例 1.1**（题型：古典概型——摸球模型）
袋中有 10 个球，其中 6 个白球、4 个红球。从中任取 3 个球，求：① 恰有 2 个白球的概率；② 至少有 1 个红球的概率。

**解**：
样本点总数（10 个球取 3 个，不讲顺序）`n = C(10,3) = 10×9×8 / (3×2×1) = 120`。
① 「恰有 2 个白球」即「2 白 1 红」，**为什么用乘积**：选白球与选红球是两个独立步骤（乘法原理）。
`k = C(6,2) × C(4,1) = 15 × 4 = 60`，故 `P = 60 / 120 = 1/2 = 0.5`。
② 直接算「至少 1 红」要分 1 红、2 红、3 红三种情况，**用对立事件更快**：
「至少 1 红」的对立是「0 红」即「3 白」，其个数为 `C(6,3) = 20`，概率 `20/120 = 1/6`。
故 `P(至少 1 红) = 1 − 1/6 = 5/6 ≈ 0.8333`。

**答案**：① 0.5；② 5/6 ≈ 0.8333。

**例 1.2**（题型：古典概型——生日模型 / 分房模型）
① 某班有 40 人，求至少有两人生日相同的概率（一年按 365 天计）。
② 将 4 封信随机投入 3 个邮筒，求「每个邮筒至少有一封信」的概率。

**解**：
① **为什么用对立事件**：「至少两人生日相同」情况极多（可能是两人、三人…），而其对立面「所有人两两生日都不同」只有一种整齐结构。
每人的生日有 365 种选法，样本点总数 `n = 365^40`。
「40 人生日互不相同」的排列数为 `365 × 364 × 363 × … × 326`（共 40 个因子）。
`P(互不相同) = (365/365)(364/365)…(326/365) ≈ 0.109`（查常用数值表）。
故 `P(至少两人生日相同) = 1 − 0.109 = 0.891`。

② 每封信可进 3 个邮筒中任一个，样本点总数 `n = 3^4 = 81`。
「每个邮筒至少 1 封」= 4 封信分到 3 个筒且无空筒，**必是 2+1+1 的分法**：
先选出装 2 封的那个邮筒：3 种；再从 4 封信中选 2 封给这个筒：`C(4,2) = 6` 种；剩下 2 封分给剩下 2 个筒：`2! = 2` 种。
有利样本点 `k = 3 × 6 × 2 = 36`。
故 `P = 36 / 81 = 4/9 ≈ 0.4444`。

**答案**：① 约 0.891；② 4/9 ≈ 0.4444。

**例 1.3**（题型：概率性质与加法公式）
已知 `P(A) = 0.5`，`P(B) = 0.4`，`P(AB) = 0.2`。求：① `P(A∪B)`；② `P(A − B)`；③ `P(ĀB̄)`；④ `P(Ā ∪ B̄)`。

**解**：
① 直接用加法公式：`P(A∪B) = P(A) + P(B) − P(AB) = 0.5 + 0.4 − 0.2 = 0.7`。
② **为什么用减法公式**：`A − B` 表示 A 发生而 B 不发生，`A − B = A − AB`。
`P(A − B) = P(A) − P(AB) = 0.5 − 0.2 = 0.3`。
③ `ĀB̄ = (A∪B)̄`（德摩根律），故 `P(ĀB̄) = 1 − P(A∪B) = 1 − 0.7 = 0.3`。
④ `Ā ∪ B̄ = (AB)̄`（德摩根律），故 `P(Ā∪B̄) = 1 − P(AB) = 1 − 0.2 = 0.8`。

**答案**：① 0.7；② 0.3；③ 0.3；④ 0.8。

**例 1.4**（题型：条件概率与乘法公式——不放回抽取）
袋中有 5 个白球、3 个红球，不放回地依次取 3 个球。求：① 第三次才取到红球的概率；② 前两次都是白球且第三次是红球的概率。

**解**：
记 `Aᵢ` = 「第 i 次取到白球」，`Rᵢ` = 「第 i 次取到红球」。
① 「第三次才取到红球」= 「前两次都是白球，第三次是红球」，即 `A₁A₂R₃`。
**为什么用乘法公式**：这是一个三步试验，每一步的概率依赖于前面已取走了什么。
`P(A₁) = 5/8`（8 球中 5 白）。
`P(A₂|A₁) = 4/7`（已取走 1 个白球，剩 7 球中 4 白）。
`P(R₃|A₁A₂) = 3/6`（已取走 2 个白球，剩 6 球中 3 红）。
故 `P(A₁A₂R₃) = (5/8) × (4/7) × (3/6) = 60 / 336 = 5/28 ≈ 0.1786`。

② 题面与①实为同一事件（「前两次白、第三次红」即「第三次才取到红球」）。
但若理解为「不管前两次具体颜色，只要求前两次是白球」——仍与①一致，答案相同。

> 若把①改成「第三次取到红球」（前两次颜色不限），则要用全概率公式：
> `P(R₃) = P(R₁R₂R₃) + P(R₁A₂R₃) + P(A₁R₂R₃) + P(A₁A₂R₃)`
> `= (3/8)(2/7)(1/6) + (3/8)(5/7)(2/6) + (5/8)(3/7)(2/6) + (5/8)(4/7)(3/6)`
> `= 6/336 + 30/336 + 30/336 + 60/336 = 126/336 = 3/8`。
> 结果等于 `P(R₁) = 3/8`，这正是抽签的**公平性**：不放回抽取时，第 i 次取到红球的概率与次序无关。

**答案**：5/28 ≈ 0.1786。

**例 1.5**（题型：全概率公式 + 贝叶斯公式——产品次品）
某厂有甲、乙两条生产线，甲线产量占总产量的 70%，乙线占 30%。已知甲线次品率为 2%，乙线次品率为 5%。
① 从总产品中任取一件，求它是次品的概率；
② 若已抽到一件次品，求它来自甲线的概率。

**解**：
记 `B₁` = 「产品来自甲线」，`B₂` = 「产品来自乙线」，`A` = 「抽到次品」。
**为什么 B₁、B₂ 是完备事件组**：产品只能来自甲或乙（并集为 S），且不会同时来自两条线（互斥），`P(Bᵢ) > 0`，三条全满足。

① 用全概率公式（由因推果）：
`P(A) = P(B₁)P(A|B₁) + P(B₂)P(A|B₂) = 0.7 × 0.02 + 0.3 × 0.05`
`= 0.014 + 0.015 = 0.029`

② 用贝叶斯公式（由果溯因），分母正是①算出的 `P(A)`：
`P(B₁|A) = P(B₁)P(A|B₁) / P(A) = 0.014 / 0.029 = 14/29 ≈ 0.4828`

**答案**：① 2.9%；② 14/29 ≈ 48.28%。

> **解读**：甲线产量是乙线的 2.33 倍，但次品率只有乙线的 0.4 倍。抽到次品后，来自甲线的后验概率（48.28%）从先验概率（70%）大幅下降到不足一半——「观察到的证据」把信念往乙线方向拉。

**例 1.6**（题型：贝叶斯公式——疾病检测假阳性）
某地区某种疾病的发病率为 0.0004。一种检测方法对患者的检出率为 0.99（即患者被判阳性的概率），对非患者的误诊率为 0.005（即非患者被判阳性的概率）。某人检测结果为阳性，求他确实患病的概率。

**解**：
记 `C` = 「患病」，`A` = 「检测阳性」。已知 `P(C) = 0.0004`，`P(A|C) = 0.99`，`P(A|C̄) = 0.005`。
**为什么先算分母**：贝叶斯公式分母是全概率，必须先展开算出来。
`P(A) = P(C)P(A|C) + P(C̄)P(A|C̄)`
`= 0.0004 × 0.99 + 0.9996 × 0.005`
`= 0.000396 + 0.004998 = 0.005394`
再由贝叶斯公式：
`P(C|A) = 0.000396 / 0.005394 ≈ 0.0734`

**答案**：约 7.34%。

> **解读（反直觉但极其重要）**：检出率高达 99%，阳性后真正患病的概率却只有 7.34%。原因是**基数效应**：非患者的人数（99.96%）远远多于患者（0.04%），即使误诊率只有 0.5%，误诊出的「假阳性」绝对数量也压倒了真阳性（4998 vs 396，相差约 12.6 倍）。这正是大规模筛查需要「二次复核」的统计学依据。

**例 1.7**（题型：证明题——两两独立 ≠ 相互独立）
设样本空间 `S = {ω₁, ω₂, ω₃, ω₄}`，每个样本点等可能（概率均为 1/4）。定义
`A = {ω₁, ω₂}`，`B = {ω₁, ω₃}`，`C = {ω₁, ω₄}`。
证明：A、B、C 两两独立，但不相互独立。

**证明**：
先算各概率：`P(A) = P(B) = P(C) = 2/4 = 1/2`。

**两两独立**：
`AB = {ω₁}`，`P(AB) = 1/4`；而 `P(A)P(B) = (1/2)(1/2) = 1/4`，故 `P(AB) = P(A)P(B)`，A 与 B 独立。
同理 `AC = {ω₁}`，`P(AC) = 1/4 = P(A)P(C)`，A 与 C 独立。
同理 `BC = {ω₁}`，`P(BC) = 1/4 = P(B)P(C)`，B 与 C 独立。
所以 A、B、C 两两独立。

**但不相互独立**：
`ABC = {ω₁}`，`P(ABC) = 1/4`；
而 `P(A)P(B)P(C) = (1/2)³ = 1/8`。
因为 `1/4 ≠ 1/8`，故 `P(ABC) ≠ P(A)P(B)P(C)`，三者不相互独立。∎

**答案**：见证明。

> **为什么重要**：这说明「相互独立」的 4 个等式**不能省掉任何一个**。三个事件的两两独立只保证了两两之间无关联，但可能隐含了「三元整体」的关联。

**例 1.8**（题型：独立性 + 伯努利概型——系统可靠性）
① 甲、乙两人独立地射击同一目标，命中率分别为 0.8 和 0.7。求目标被击中的概率。
② 某型号导弹命中率为 0.6。若发射 5 枚，求至少命中 1 枚的概率；至少命中 2 枚的概率。
③ 一个系统由 4 个元件组成，每个元件正常工作的概率为 0.9，各元件独立。分别求「4 个元件串联」「4 个元件并联」时系统正常工作的概率。

**解**：
① **为什么用对立事件**：目标被击中 = 至少一人命中。
`P(击中) = 1 − P(两人都不中) = 1 − (1 − 0.8)(1 − 0.7) = 1 − 0.2 × 0.3 = 1 − 0.06 = 0.94`
② 这是 n = 5、p = 0.6 的 5 重伯努利试验。
至少命中 1 枚：`P(X ≥ 1) = 1 − P(X = 0) = 1 − C(5,0)(0.6)⁰(0.4)⁵ = 1 − 0.01024 = 0.98976`
至少命中 2 枚：`P(X ≥ 2) = 1 − P(X=0) − P(X=1)`
`P(X=1) = C(5,1)(0.6)¹(0.4)⁴ = 5 × 0.6 × 0.0256 = 0.0768`
`P(X ≥ 2) = 1 − 0.01024 − 0.0768 = 0.91296`
③ **串联**（全部正常才正常）：`P = 0.9⁴ = 0.6561`
**并联**（至少一个正常就正常）：`P = 1 − 0.1⁴ = 1 − 0.0001 = 0.9999`

**答案**：① 0.94；② 0.98976、0.91296；③ 串联 0.6561、并联 0.9999。

> **工程结论**：并联结构用「冗余」把可靠性从 0.6561 提升到 0.9999。这是计算机容错系统（如 RAID1、双机热备）的基本原理：**串联的可靠性是相乘（越乘越小），并联的可靠性用对立事件（越并越大）**。

## 易错点提醒

1. **互斥与独立混为一谈**。
   **错在**：看到 `P(AB) = 0` 就说 A、B 独立。
   **正确做法**：互斥是 `AB = ∅`，独立是 `P(AB) = P(A)P(B)`。当 `P(A) > 0`、`P(B) > 0` 时，互斥必定不独立（因为 `P(A)P(B) > 0 ≠ 0`）。

2. **德摩根律「交并互换」记反**。
   **错在**：写成 `(A∪B)̄ = Ā ∪ B̄`。
   **正确做法**：`(A∪B)̄ = Ā B̄`，`(AB)̄ = Ā ∪ B̄`。口诀「长线断开，并交互换」。检查方法：代入 `A = S, B = ∅` 验证。左式 `(S∪∅)̄ = ∅`，右式若写 `S̄ ∪ ∅̄ = ∅ ∪ S = S ≠ ∅`，立刻发现错了。

3. **把 `P(B|A)` 与 `P(AB)` 混淆**。
   **错在**：题目问「已知第一次取到白球，第二次取到红球的概率」，却答了 `P(A₁R₂)`。
   **正确做法**：`P(B|A)` 的样本空间是 A，数值上等于 `P(AB)/P(A)`，一般**大于** `P(AB)`。若 `P(A) < 1`，必有 `P(B|A) > P(AB)`。可在解题时先写出定义式再代数。

4. **全概率公式用错划分**。
   **错在**：随手取两个事件 B₁、B₂ 就套公式，没验证它们是否互补、是否互斥。
   **正确做法**：使用前逐条核对「两两互斥 + 并集为 S + 概率非零」。常见错误是划分有重叠（如「甲厂产品」与「合格品」），此时不能直接套。

5. **贝叶斯公式分母写成了 `P(A)` 之外的量**。
   **错在**：把分母写成 `P(Bₖ)P(A|Bₖ)`，忘了归一化。
   **正确做法**：分母必须是全概率 `Σᵢ P(Bᵢ)P(A|Bᵢ)`。**验证技巧**：所有后验概率之和必须为 1，即 `Σₖ P(Bₖ|A) = 1`，否则一定算错。

6. **求「至少一个」时逐项相加**。
   **错在**：把「至少一个发生」拆成「恰 1 个 + 恰 2 个 + … + 恰 n 个」硬算，容易漏项。
   **正确做法**：`P(至少一个) = 1 − P(全不发生)`。n 个相互独立事件时尤其快：`1 − ∏(1 − pᵢ)`。

7. **古典概型中分子分母计数口径不一致**。
   **错在**：分母用组合 `C(n,k)`，分子却按排列 `A(n,k)` 数。
   **正确做法**：**分子分母必须使用同一口径**——要么都当组合（不讲顺序），要么都当排列（讲顺序）。判断标准：把样本点「人为打上标签」后，每个样本点是否等可能。

8. **忘记「不放回」对条件概率的影响**。
   **错在**：不放回抽取中，第二次的概率仍用初始总数（如 5/8 写成 5/8）。
   **正确做法**：每次抽取后总数减 1，对应颜色的球数也要减 1，即 `P(A₂|A₁) = 4/7` 而非 5/8。

9. **三事件相互独立只验证两两独立**。
   **错在**：验证了 3 个两两等式就下结论。
   **正确做法**：必须验证全部 4 个等式（含 `P(ABC) = P(A)P(B)P(C)`）。反例见例 1.7。

## 本章小结

- 概率论把随机试验抽象为**样本空间 S**，事件就是 S 的**子集**，事件运算就是集合运算。
- **德摩根律**是文字↔符号翻译的钥匙：「至少一个」↔ 并，「全都」↔ 交，取对立时并交互换。
- 概率由**三条公理**（非负、规范、可列可加）定义，其余性质全部可推出。
- **加法公式** `P(A∪B) = P(A) + P(B) − P(AB)` 是全章计算的主干。
- **古典概型**：有限 + 等可能 ⟹ `P(A) = k/n`，难点在计数（排列组合）。
- **条件概率**把样本空间压缩到 A：`P(B|A) = P(AB)/P(A)`；**乘法公式**用于多步试验。
- **全概率**由因推果：`P(A) = ΣP(Bᵢ)P(A|Bᵢ)`；**贝叶斯**由果溯因：`P(Bₖ|A) = P(Bₖ)P(A|Bₖ)/P(A)`。
- **互斥 ≠ 独立**：前者是 `AB = ∅`，后者是 `P(AB) = P(A)P(B)`，正概率下二者矛盾。
- 求「至少一个」一律走对立事件：`1 − P(全不发生)`。
- **一句话记住本章**：先把文字翻成集合，再用加法公式算概率；「至少一个」取对立，「已知结果」用贝叶斯。

## 自测题

1. 写出「抛一枚硬币 3 次」的样本空间，并用集合表示事件「至少出现 2 次正面」。
2. 设 `P(A) = 0.4`，`P(B) = 0.5`，`P(A|B) = 0.6`，求 `P(A∪B)` 与 `P(B|A)`。
3. 从 1~9 这九个数字中不放回地任取 3 个排成一个三位数，求它是偶数的概率。
4. 某商店出售的灯泡来自两个厂：甲厂占 60%，乙厂占 40%，甲厂灯泡合格率 0.95，乙厂 0.90。求：① 任取一只合格的概率；② 已知取到不合格品，它来自乙厂的概率。
5. 设 A、B 相互独立，`P(A) = 0.3`，`P(B) = 0.6`。求 `P(A∪B)`、`P(ĀB)`、`P(Ā ∪ B̄)`。
6. 一批产品共 100 件，其中有 5 件次品。每次取 1 件，**有放回**地取 3 次，求恰有 1 件次品的概率。（有放回 ⟹ 3 重伯努利试验）
7. 假设 `P(A) > 0`，`P(B) > 0`。证明：若 A 与 B 互斥，则 A 与 B 一定不独立。
8. 甲乙两人轮流投篮，甲先投，命中率均为 0.5。求甲获胜（甲先命中）的概率。
9. 判断正误并说明理由：「若 `P(A) = 0`，则 A 是不可能事件 ∅。」
10. 已知 `P(A) = P(B) = P(C) = 1/4`，`P(AB) = 0`，`P(AC) = P(BC) = 1/16`。求 A、B、C 至少有一个发生的概率。

### 自测题答案

1. `S = {正正正, 正正反, 正反正, 正反反, 反正正, 反正反, 反反正, 反反反}`；事件 `= {正正正, 正正反, 正反正, 反正正}`，含 4 个样本点，概率 `4/8 = 0.5`。
2. 由乘法公式 `P(AB) = P(B)P(A|B) = 0.5 × 0.6 = 0.3`；`P(A∪B) = 0.4 + 0.5 − 0.3 = 0.6`；`P(B|A) = P(AB)/P(A) = 0.3/0.4 = 0.75`。
3. 总数 `A(9,3) = 9 × 8 × 7 = 504`。个位为偶数（2、4、6、8）共 4 种；选定个位后，百位、十位从剩下 8 个数字中取 2 个排列，`A(8,2) = 56` 种。有利数 `4 × 56 = 224`，故 `P = 224/504 = 4/9 ≈ 0.4444`。
4. ① `P = 0.6 × 0.95 + 0.4 × 0.90 = 0.57 + 0.36 = 0.93`；
   ② 不合格率 `P(D) = 1 − 0.93 = 0.07`；`P(乙|D) = 0.4 × 0.10 / 0.07 = 0.04/0.07 = 4/7 ≈ 0.5714`。
   （验证：`P(甲|D) = 0.6 × 0.05/0.07 = 0.03/0.07 = 3/7`，`4/7 + 3/7 = 1` ✓）
5. `P(AB) = 0.3 × 0.6 = 0.18`；`P(A∪B) = 0.3 + 0.6 − 0.18 = 0.72`；
   `P(ĀB) = P(B) − P(AB) = 0.6 − 0.18 = 0.42`；
   `P(Ā∪B̄) = 1 − P(AB) = 1 − 0.18 = 0.82`。
6. n = 3，`p = 5/100 = 0.05`；`P(X = 1) = C(3,1)(0.05)¹(0.95)² = 3 × 0.05 × 0.9025 = 0.135375 ≈ 0.1354`。
7. **证明**：因 A 与 B 互斥，`AB = ∅`，故 `P(AB) = P(∅) = 0`。
   又 `P(A) > 0`、`P(B) > 0`，所以 `P(A)P(B) > 0`。
   于是 `P(AB) = 0 ≠ P(A)P(B)`，故 A 与 B 不独立。∎
8. 甲获胜 = 「甲第 1 次中」∪「甲不中、乙不中、甲第 2 次中」∪ …
   `P = 0.5 + 0.5×0.5×0.5 + (0.5×0.5)²×0.5 + … = 0.5 × [1 + 0.25 + 0.25² + …]`
   `= 0.5 × 1/(1 − 0.25) = 0.5 / 0.75 = 2/3 ≈ 0.6667`。
   （这是等比级数求和，公比 `q = 0.25 < 1` 保证收敛。）
9. **错误**。`P(A) = 0` 只能说明 A 发生的概率为 0，不能说明 A 是空集。
   反例：在区间 [0,1] 上均匀取一点，事件 `A = {0.5}`（取到的点恰好是 0.5），`P(A) = 0`，但 A 显然不是 ∅，是可能发生的。这类事件称为「零概率事件」。
   （同理 `P(A) = 1` 也不意味着 A 就是 S。）
10. 用容斥原理：
    `P(A∪B∪C) = P(A)+P(B)+P(C) − P(AB) − P(AC) − P(BC) + P(ABC)`
    已知 `P(AB) = 0`，而 `ABC ⊂ AB`，故 `P(ABC) = 0`。
    代入：`= 1/4 + 1/4 + 1/4 − 0 − 1/16 − 1/16 + 0 = 3/4 − 2/16 = 3/4 − 1/8 = 5/8 = 0.625`。
