## 4.1 数学期望

### 4.1.1 定义

**数学期望（Mathematical Expectation）**，简称**期望**，又称**均值**，是随机变量取值的「加权平均」。

**离散型**：设 `X` 的分布律为 `P(X = xₖ) = pₖ`，若级数 `Σₖ |xₖ| pₖ` **收敛**，则称

`E(X) = Σₖ xₖ pₖ`

为 X 的数学期望。若 `Σ|xₖ|pₖ = +∞`，则称 X 的期望**不存在**。

**连续型**：设 `X` 的概率密度为 `f(x)`，若积分 `∫_{−∞}^{+∞} |x| f(x) dx` **收敛**，则称

`E(X) = ∫_{−∞}^{+∞} x f(x) dx`

为 X 的数学期望。

> **重点（易错）**：定义中**必须要求绝对收敛**。若只验证 `Σxₖpₖ` 收敛而不验证 `Σ|xₖ|pₖ`，可能得到荒谬结果（著名的**柯西分布** `f(x) = 1/[π(1+x²)]` 就不存在期望，因为 `∫|x|f(x)dx` 发散）。本科考试中大多数分布期望都存在，但概念题会考这一点。

**直观理解**：`E(X)` 是「以概率为权重的重心」。想象在数轴上 xₖ 位置放置质量 pₖ，`E(X)` 就是**质心**。

**为什么叫「期望」**：它最早来自赌博中的「期望收益」——「长期重复试验下，平均每次能得到的收益」。

### 4.1.2 随机变量函数的期望

**定理（无意识统计学家定理）**：设 `Y = g(X)`（g 为连续函数），则

| 类型 | 公式 |
|---|---|
| 离散型 | `E[g(X)] = Σₖ g(xₖ) pₖ` |
| 连续型 | `E[g(X)] = ∫_{−∞}^{+∞} g(x) f(x) dx` |

**二维推广**：

`E[g(X, Y)] = Σᵢ Σⱼ g(xᵢ, yⱼ) p_ij`（离散）；`= ∫∫ g(x, y) f(x, y) dx dy`（连续）

> **重点**：这个定理的价值在于——**求 `E[g(X)]` 时不需要先求出 `g(X)` 的分布**。例如求 `E(X²)`，直接算 `∫x²f(x)dx` 即可，不必先推导 `X²` 服从什么分布。这是本章最大的计算便利。

### 4.1.3 期望的性质

设 `C` 为常数，`X`、`Y` 为随机变量，期望均存在，则：

1. **常数**：`E(C) = C`
2. **数乘**：`E(CX) = C · E(X)`
3. **线性性（加法）**：`E(X + Y) = E(X) + E(Y)`　★**不要求 X、Y 独立**
4. **乘积**：若 X 与 Y **相互独立**，则 `E(XY) = E(X) · E(Y)`　★**反之不成立**
5. **一般线性组合**：`E(aX + bY + c) = aE(X) + bE(Y) + c`

> **重点**：
> ① **线性性质 3 不需要独立性**——这是最容易混淆的一点。无论 X、Y 如何相依，`E(X+Y) = E(X)+E(Y)` 恒成立。
> ② **性质 4 需要独立性**，且**逆命题不成立**：`E(XY) = E(X)E(Y)` 推不出 X、Y 独立（例 4.6 就是反例）。
> ③ 性质 3 可以推广到**任意有限个**随机变量之和：`E(X₁ + … + Xₙ) = E(X₁) + … + E(Xₙ)`，同样不要求独立性。第 2 章推导二项分布期望 `np` 用的就是这条。

**推论（常用技巧）**：把复杂变量**分解为简单变量之和**，再用期望线性性。

## 4.2 方差

### 4.2.1 定义与计算公式

**方差（Variance）**：设 X 的期望 `E(X)` 存在，若 `E[(X − E(X))²]` 存在，则称之为 X 的方差，记作

`D(X) = Var(X) = E[(X − E(X))²]`

**标准差（均方差，Standard Deviation）**：`σ(X) = √D(X)`。

**直观理解**：方差衡量 X 的取值**围绕均值有多分散**。`X − E(X)` 是「偏离量」，平方是为了消除正负抵消，再取期望就是「平均平方偏离」。

**计算捷径（必背，考试中使用率最高）**：

`D(X) = E(X²) − [E(X)]²`

**推导**：`D(X) = E[(X − μ)²] = E(X² − 2μX + μ²) = E(X²) − 2μE(X) + μ² = E(X²) − 2μ² + μ² = E(X²) − μ²`。∎

> **重点**：**几乎所有方差计算题都用这条捷径**：先算 `E(X)`，再算 `E(X²)`，相减。用它避免展开 `(X − μ)²` 的繁琐求和。

### 4.2.2 方差的性质

1. **常数**：`D(C) = 0`（常数没有波动）
2. **平移不变**：`D(X + C) = D(X)`（整体移动不改变分散程度）
3. **数乘**：`D(CX) = C² D(X)`　★**系数要平方**，`D(−X) = D(X)`
4. **一般和差**：`D(X ± Y) = D(X) + D(Y) ± 2Cov(X, Y)`
5. **独立情形**：若 X 与 Y 独立，则 `D(X ± Y) = D(X) + D(Y)`　★**无论加减都是加号**

> **重点**：性质 5 中「**加减都是加号**」是最常考的细节，因为方差是「波动幅度的平方」，两股独立波动叠加只会**增大**总波动。`D(X − Y) = D(X) + D(Y)` 而不是 `D(X) − D(Y)`。

### 4.2.3 切比雪夫不等式

**切比雪夫不等式（Chebyshev's Inequality）**：设 `E(X) = μ`，`D(X) = σ²` 均存在，则对任意 `ε > 0`，

`P(|X − μ| ≥ ε) ≤ σ² / ε²`

等价形式：

`P(|X − μ| < ε) ≥ 1 − σ² / ε²`

**直观理解**：`|X − μ| ≥ ε` 是「严重偏离均值」，`σ²/ε²` 给出这种事件概率的**上界**。偏离超过 `k` 倍标准差（`ε = kσ`）的概率不超过 `1/k²`。

**为什么重要**：它**不依赖 X 的具体分布**，只用到期望与方差，因此是**普适**的估计工具；更重要的是，它是证明**大数定律**的关键工具（见例 4.9）。

> **重点**：切比雪夫不等式的估计非常**保守**（宽松）。例 4.5 中它只给出 `≥ 0.75`，而该二项分布的**精确值**是 `P(41 ≤ X ≤ 59) = 0.9431`（用带连续性修正的正态近似算是 `0.9426`，见例 4.5②），差距很大。考试中若题目要求「用切比雪夫不等式估计」，就必须按不等式算，不要写真实值。

### 4.2.4 常见分布的期望与方差总表（全书最核心的表，务必默写）

| 分布名称 | 记号 | 期望 `E(X)` | 方差 `D(X)` | 备注 |
|---|---|---|---|---|
| **0-1 分布** | `B(1, p)` | `p` | `p(1 − p)` | 方差在 p = 0.5 时最大 |
| **二项分布** | `B(n, p)` | `np` | `np(1 − p)` | n 个 0-1 变量之和 |
| **泊松分布** | `P(λ)` | `λ` | `λ` | **期望 = 方差 = λ**（特征性质） |
| **几何分布** | `G(p)` | `1/p` | `(1 − p)/p²` | 首次成功所需次数 |
| **超几何分布** | `H(N, M, n)` | `nM/N` | `n·(M/N)·(1 − M/N)·(N − n)/(N − 1)` | 二项方差 × 有限总体校正 |
| **均匀分布** | `U(a, b)` | `(a + b)/2` | `(b − a)²/12` | 与区间端点等距 |
| **指数分布** | `E(λ)` | `1/λ` | `1/λ²` | **标准差 = 期望 = 1/λ** |
| **正态分布** | `N(μ, σ²)` | `μ` | `σ²` | 两参数即期望与方差 |
| **χ² 分布** | `χ²(n)` | `n` | `2n` | 自由度 n（第5章） |
| **t 分布** | `t(n)` | `0`（n > 1） | `n/(n − 2)`（n > 2） | n ≤ 1 时期望不存在 |
| **F 分布** | `F(n₁, n₂)` | `n₂/(n₂ − 2)`（n₂ > 2） | `2n₂²(n₁ + n₂ − 2)/[n₁(n₂ − 2)²(n₂ − 4)]`（n₂ > 4） | 取值恒为正 |

> **速记技巧**：
> - **泊松分布**：`E = D = λ`，看到「期望等于方差」立刻想泊松。
> - **指数分布**：`E = σ = 1/λ`，标准差等于期望。
> - **正态与均匀**：参数直接就是期望方差（正态）或由参数算出（均匀）。
> - **二项 vs 超几何**：超几何的方差 = 二项方差乘以 `(N−n)/(N−1)`（**有限总体校正因子**，不放回抽样信息更少、波动更小）。

## 4.3 协方差与相关系数

### 4.3.1 协方差

**协方差（Covariance）**：称

`Cov(X, Y) = E[(X − E(X))(Y − E(Y))]`

为 X 与 Y 的协方差。**计算捷径**：

`Cov(X, Y) = E(XY) − E(X) · E(Y)`

**直观理解**：协方差度量 X 与 Y 的**线性关联方向与强度**。
- `Cov > 0`：X 大于均值时 Y 也倾向于大于均值（**同向变化**）；
- `Cov < 0`：反向变化；
- `Cov = 0`：无**线性**关联（但可能有非线性关联，见例 4.6）。

**四条运算法则**：

1. **对称性**：`Cov(X, Y) = Cov(Y, X)`
2. **自协方差**：`Cov(X, X) = D(X)`
3. **数乘**：`Cov(aX, bY) = ab · Cov(X, Y)`
4. **分配律**：`Cov(X₁ + X₂, Y) = Cov(X₁, Y) + Cov(X₂, Y)`

**重要推论**：`D(X ± Y) = D(X) + D(Y) ± 2Cov(X, Y)`。

> **重点**：协方差的数值**受量纲影响**。若把 X 的单位从「米」换成「厘米」，`Cov` 会放大 100 倍，但关联强度根本没变。这就是要引入**相关系数**的原因。

### 4.3.2 相关系数

**相关系数（Correlation Coefficient）**：

`ρ_XY = Cov(X, Y) / (√D(X) · √D(Y))`

（要求 `D(X) > 0`，`D(Y) > 0`）

**三条性质**：

1. **有界性**：`|ρ_XY| ≤ 1`；
2. **无量纲**：`ρ_XY` 是无量纲的量，不受单位影响；
3. **线性关系的刻画**：`|ρ_XY| = 1` **⟺** 存在常数 a、b（a ≠ 0）使 `P(Y = aX + b) = 1`，即 X 与 Y **以概率 1 成线性关系**；且 `a > 0` 时 `ρ = 1`（正线性相关），`a < 0` 时 `ρ = −1`（负线性相关）。

**相关程度的经验判断**：`|ρ| ≥ 0.8` 强相关，`0.5 ≤ |ρ| < 0.8` 中度相关，`0.3 ≤ |ρ| < 0.5` 弱相关，`|ρ| < 0.3` 基本不相关。

### 4.3.3 不相关与独立

**不相关（Uncorrelated）的定义**：若 `ρ_XY = 0`（等价于 `Cov(X, Y) = 0`），则称 X 与 Y **不相关**。

**核心结论**：

```
        独立  ⟹  不相关          （永远成立）
        不相关  ⇏  独立           （一般反例：Y = X²）
```

| 命题 | 是否成立 |
|---|---|
| X、Y 独立 ⟹ `Cov(X,Y) = 0` | ✅ 永远成立 |
| `Cov(X,Y) = 0` ⟹ X、Y 独立 | ❌ 一般不成立 |
| `(X,Y)` 服从二维正态，`ρ = 0` ⟹ X、Y 独立 | ✅ 成立（**正态独有**） |

> **重点**：「不相关」只排除**线性**关系，独立则排除**一切**关系。`Y = X²` 时 X 与 Y 有完全的确定性依赖，但协方差为 0（因为平方是偶函数，正负偏离相互抵消）。这是本章最经典的考点。

### 4.3.4 矩与协方差矩阵

**矩（Moments）**：

| 名称 | 定义 |
|---|---|
| k 阶**原点矩** | `E(X^k)`（k = 1, 2, …）；一阶原点矩即期望 |
| k 阶**中心矩** | `E[(X − E(X))^k]`；二阶中心矩即方差 |
| k + l 阶**混合矩** | `E(X^k Y^l)` |
| k + l 阶**混合中心矩** | `E[(X − E(X))^k (Y − E(Y))^l]`；1+1 阶即协方差 |

**协方差矩阵**：对 n 维随机向量 `(X₁, …, Xₙ)`，记 `c_ij = Cov(Xᵢ, Xⱼ)`，则称

`C = (c_ij)_{n×n}`

为协方差矩阵。二维情形：

`C = [ D(X)      Cov(X,Y) ; Cov(X,Y)   D(Y) ]`

C 是**对称矩阵**，且是**半正定**的（因为对任意向量 a，`aᵀCa = D(aᵀX) ≥ 0`）。

> **拓展（机器学习衔接）**：PCA 主成分分析、多元正态分布、卡尔曼滤波全部建立在协方差矩阵之上。计算机专业同学进入机器学习课程后会反复用到它。

## 4.4 大数定律与中心极限定理

本节回答两个问题：**大量重复试验的平均结果会稳定吗？**（大数定律）**稳定到哪里、波动多大？**（中心极限定理）

### 4.4.1 依概率收敛

**依概率收敛（Convergence in Probability）**：设 `Y₁, Y₂, …` 是一列随机变量，`c` 为常数，若对任意 `ε > 0` 有

`lim_{n→∞} P(|Yₙ − c| < ε) = 1`

则称 `{Yₙ}` **依概率收敛**于 c，记作 `Yₙ → c (P)` 或 `plim Yₙ = c`。

**直观理解**：n 很大时，`Yₙ` 落在 c 附近任意小邻域内的概率趋于 1。它不保证每次都在，只保证**跑偏的概率趋于 0**。

### 4.4.2 三个大数定律

**① 切比雪夫大数定律**

**条件**：`X₁, X₂, …` **相互独立**，各自期望 `E(Xᵢ) = μᵢ` 与方差 `D(Xᵢ)` 都存在，且**方差一致有界**：存在常数 C 使 `D(Xᵢ) ≤ C`（i = 1, 2, …）。
**结论**：对任意 `ε > 0`，

`lim_{n→∞} P( | (1/n) Σᵢ₌₁ⁿ Xᵢ − (1/n) Σᵢ₌₁ⁿ μᵢ | < ε ) = 1`

即**样本均值依概率收敛于期望的均值**。

**② 伯努利大数定律（频率稳定性的严格表述）**

**条件**：设 `n_A` 是 n 重伯努利试验中事件 A 发生的次数，p 是 A 每次发生的概率。
**结论**：对任意 `ε > 0`，

`lim_{n→∞} P( | n_A / n − p | < ε ) = 1`

即**频率依概率收敛于概率**。

> **意义**：这条定理为概率的**频率解释**提供了数学依据。它说明「抛硬币次数越多，正面频率越接近 0.5」不是直觉，而是可证明的定理。

**③ 辛钦大数定律（条件最弱，最常用）**

**条件**：`X₁, X₂, …` **独立同分布**，且 `E(Xᵢ) = μ` **存在**（**不要求方差存在**）。
**结论**：对任意 `ε > 0`，

`lim_{n→∞} P( | (1/n) Σᵢ₌₁ⁿ Xᵢ − μ | < ε ) = 1`

> **重点**：辛钦大数定律**只要求期望存在**，不要求方差存在，因此适用面最广。考试中若问「独立同分布、期望存在」用哪个大数定律，答**辛钦**。

### 4.4.3 两个中心极限定理

**① 林德伯格-列维定理（独立同分布的中心极限定理）**

**条件**：`X₁, X₂, …` **独立同分布**，`E(Xᵢ) = μ`，`D(Xᵢ) = σ²`（`0 < σ² < +∞`）。
**结论**：对任意实数 x，

`lim_{n→∞} P( (Σᵢ₌₁ⁿ Xᵢ − nμ) / (σ√n) ≤ x ) = Φ(x)`

**实用近似形式（n 较大时）**：

`Σᵢ₌₁ⁿ Xᵢ ≈ N(nμ, nσ²)`，　即　`ΣXᵢ ~ 近似 N(nμ, nσ²)`

由此推出的**样本均值版本**（统计中最常用）：

`X̄ = (1/n)ΣXᵢ ~ 近似 N(μ, σ²/n)`

> **重点**：注意样本均值的方差是 `σ²/n`——**样本量越大，均值波动越小**，且按 `√n` 的速度减小。这是「多测几次取平均能提高精度」的数学依据。

**② 棣莫弗-拉普拉斯定理（二项分布的正态近似）**

**条件**：`X ~ B(n, p)`。
**结论**：对任意实数 x，

`lim_{n→∞} P( (X − np) / √(np(1 − p)) ≤ x ) = Φ(x)`

**实用近似**：`X ~ B(n, p)` 当 n 很大时，`X ~ 近似 N(np, np(1−p))`。

**使用条件（经验判据）**：`np ≥ 5` 且 `n(1−p) ≥ 5`（有的教材要求 ≥ 10）。

> **连续性修正（考试必考细节）**：二项分布是**离散**的，正态是**连续**的。用正态近似时必须把离散点「拓宽半个单位」：
> - `P(X ≤ k) ≈ Φ((k + 0.5 − np)/√(np(1−p)))`
> - `P(X ≥ k) ≈ 1 − Φ((k − 0.5 − np)/√(np(1−p)))`
> - `P(a ≤ X ≤ b) ≈ Φ((b + 0.5 − np)/σ) − Φ((a − 0.5 − np)/σ)`
> 不做修正会带来系统性偏差，这是极常见的失分点。

**三个近似的选择（考试决策表）**：

| 情形 | 方法 | 条件 |
|---|---|---|
| n 大、p 小、`λ = np` 适中 | **泊松近似** | `n ≥ 20`，`p ≤ 0.1`，`λ ≤ 10` |
| n 大、np 与 n(1−p) 都不太小 | **正态近似（带连续性修正）** | `np ≥ 5` 且 `n(1−p) ≥ 5` |
| 上述都不满足 | **直接算二项分布** | n ≤ 20 左右 |

> **一句话记忆**：**「稀有事件用泊松，大样本比例用正态」**。

## 典型例题

**例 4.1**（题型：由密度求期望与方差）
设随机变量 X 的概率密度为 `f(x) = 2x`（0 < x < 1），其余为 0。求 `E(X)`、`E(X²)`、`D(X)`、`σ(X)`。

**解**：
**为什么这样算**：按连续型期望定义直接积分。
`E(X) = ∫_0^1 x · 2x dx = ∫_0^1 2x² dx = [2x³/3]_0^1 = 2/3 ≈ 0.6667`
用函数期望公式（**不必先求 X² 的分布**）：
`E(X²) = ∫_0^1 x² · 2x dx = ∫_0^1 2x³ dx = [2x⁴/4]_0^1 = 1/2 = 0.5`
由捷径公式：
`D(X) = E(X²) − [E(X)]² = 0.5 − (2/3)² = 0.5 − 4/9 = (9 − 8)/18 = 1/18 ≈ 0.0556`
`σ(X) = √(1/18) = 1/(3√2) ≈ 0.2357`

**答案**：`E(X) = 2/3`，`E(X²) = 1/2`，`D(X) = 1/18`，`σ(X) ≈ 0.2357`。

**例 4.2**（题型：常见分布的期望方差与概率计算）
某电子设备的寿命 `X ~ E(λ)`，已知平均寿命为 5 年。求：① λ；② `E(X²)`、`D(X)`、`σ(X)`；③ 该设备能正常工作 10 年以上的概率。

**解**：
① 由 `E(X) = 1/λ = 5`，得 `λ = 0.2`（即 `X ~ E(0.2)`）。
② **为什么用捷径**：指数分布的 `E(X²)` 可直接积分或用公式 `E(X²) = D(X) + [E(X)]²`。
已知指数分布 `D(X) = 1/λ² = 1/0.04 = 25`，`E(X) = 5`，故
`E(X²) = 25 + 25 = 50`
`D(X) = 25`，`σ(X) = 5`
（**注意**：指数分布的标准差等于期望，这是它的特征性质。）
③ `P(X > 10) = 1 − F(10) = e^(−0.2 × 10) = e^(−2)`
查表得 `e^(−2) = 0.1353`。

**答案**：① λ = 0.2；② `E(X²) = 50`，`D(X) = 25`，`σ(X) = 5`；③ 0.1353。

> **拓展思考**：若改为「已经用了 5 年，还能再用 10 年」，由无记忆性答案仍是 `e^(−2) = 0.1353`（见第 2 章例 2.6）。

**例 4.3**（题型：随机变量函数的期望）
设 `X ~ U(0, 1)`。求 `E(X²)`、`E(√X)`、`E(ln X)`、`E(e^X)`。

**解**：
`U(0,1)` 的密度为 `f(x) = 1`（0 < x < 1）。由 `E[g(X)] = ∫_0^1 g(x) · 1 dx`（**无需知道 g(X) 的分布**）：
① `E(X²) = ∫_0^1 x² dx = 1/3 ≈ 0.3333`
② `E(√X) = ∫_0^1 x^(1/2) dx = [2x^(3/2)/3]_0^1 = 2/3 ≈ 0.6667`
③ `E(ln X) = ∫_0^1 ln x dx`。用分部积分：`∫ln x dx = x ln x − x`，
`= [x ln x − x]_0^1 = (1 · 0 − 1) − (0 − 0) = −1`
（**注意**：`lim_{x→0⁺} x ln x = 0`，这是极限的基本结论，必须会。）
④ `E(e^X) = ∫_0^1 e^x dx = [e^x]_0^1 = e − 1 ≈ 1.7183`

**答案**：① 1/3；② 2/3；③ −1；④ e − 1 ≈ 1.7183。

> **易错提示**：`E(ln X) = −1` 是**负数**——期望完全可以为负，不要因为「概率是正的」就以为期望必须为正。

**例 4.4**（题型：离散型方差计算，两种算法对比）
设 X 的分布律为 `P(X = −2) = 0.4`，`P(X = 0) = 0.3`，`P(X = 2) = 0.3`。求 `E(X)`、`D(X)`、`E(3X − 1)`、`D(3X − 1)`。

**解**：
① `E(X) = (−2)(0.4) + 0(0.3) + 2(0.3) = −0.8 + 0 + 0.6 = −0.2`
② `E(X²) = 4(0.4) + 0(0.3) + 4(0.3) = 1.6 + 0 + 1.2 = 2.8`
`D(X) = E(X²) − [E(X)]² = 2.8 − (−0.2)² = 2.8 − 0.04 = 2.76`
（**验证**：用定义逐一算 `(x − μ)²`：
`(−2 + 0.2)²(0.4) = 3.24 × 0.4 = 1.296`；
`(0 + 0.2)²(0.3) = 0.04 × 0.3 = 0.012`；
`(2 + 0.2)²(0.3) = 4.84 × 0.3 = 1.452`；
合计 `1.296 + 0.012 + 1.452 = 2.76` ✓）
③ 由期望线性性（**不需要任何独立性条件**）：
`E(3X − 1) = 3E(X) − 1 = 3(−0.2) − 1 = −1.6`
④ 由方差性质（**平移不变、系数平方**）：
`D(3X − 1) = 3² D(X) = 9 × 2.76 = 24.84`

**答案**：`E(X) = −0.2`，`D(X) = 2.76`，`E(3X−1) = −1.6`，`D(3X−1) = 24.84`。

> **易错对照**：`D(3X − 1) ≠ 3D(X) − 1`，也不等于 `9D(X) − 1`。**常数项对无影响**——这是性质 2「平移不变」的直接体现。

**例 4.5**（题型：切比雪夫不等式估计）
设 `X ~ B(100, 0.5)`。① 用切比雪夫不等式估计 `P(40 < X < 60)`；② 用棣莫弗-拉普拉斯定理计算其近似值；③ 比较并说明原因。

**解**：
① `E(X) = np = 100 × 0.5 = 50`，`D(X) = np(1−p) = 100 × 0.5 × 0.5 = 25`，`σ = 5`。
`P(40 < X < 60) = P(|X − 50| < 10)`
由切比雪夫不等式：`P(|X − μ| < ε) ≥ 1 − σ²/ε² = 1 − 25/100 = 1 − 0.25 = 0.75`
即 `P(40 < X < 60) ≥ 0.75`。
② 由棣莫弗-拉普拉斯定理，`X ~ 近似 N(50, 25)`，`σ = 5`。
**带连续性修正**：`P(40 < X < 60) = P(41 ≤ X ≤ 59) ≈ Φ((59.5 − 50)/5) − Φ((40.5 − 50)/5)`
`= Φ(1.9) − Φ(−1.9) = 2Φ(1.9) − 1 = 2 × 0.9713 − 1 = 0.9426`
③ **比较**：切比雪夫给出「≥ 0.75」，正态近似给出「≈ 0.9426」。

**为什么差距大**：切比雪夫不等式**只利用了期望和方差两个信息**，对 X 的分布形状一无所知，因此必须对**所有可能的分布**都成立——包括那些「概率质量集中在均值附近和在远处」的极端分布。要保证最坏情形也成立，估计就只能很宽松。而二项分布的形状是已知的（接近正态，中间厚、尾部薄），正态近似用上了这个信息，所以精确得多。

**答案**：① ≥ 0.75；② ≈ 0.9426；③ 切比雪夫更保守。

> **考试提示**：若题目明确要求「用切比雪夫不等式估计」，答案就是 0.75，**不要写 0.9426**。

**例 4.6**（题型：协方差与相关系数，不相关但不独立的经典反例）
设 `X ~ U(−1, 1)`，令 `Y = X²`。① 求 `E(X)`、`E(Y)`、`E(XY)`；② 求 `Cov(X, Y)` 与 `ρ_XY`；③ 判断 X 与 Y 是否独立，并说明「不相关」与「独立」的区别。

**解**：
① `X ~ U(−1, 1)` 的密度 `f(x) = 1/2`（−1 < x < 1）。
`E(X) = ∫_{−1}^{1} x · (1/2) dx = 0`（**奇函数在对称区间上积分为 0**，可秒答）
`E(Y) = E(X²) = ∫_{−1}^{1} x² · (1/2) dx = (1/2) · [x³/3]_{−1}^{1} = (1/2)(1/3 + 1/3) = 1/3`
`E(XY) = E(X · X²) = E(X³) = ∫_{−1}^{1} x³ · (1/2) dx = 0`（同样是奇函数积分）
② `Cov(X, Y) = E(XY) − E(X)E(Y) = 0 − 0 × (1/3) = 0`
故 `ρ_XY = 0`，即 X 与 Y **不相关**。
③ **判断独立性**：取事件 `{X > 0.5}` 与 `{Y > 0.5}`。
`P(X > 0.5) = ∫_{0.5}^{1} (1/2) dx = 0.25`
`P(Y > 0.5) = P(X² > 0.5) = P(|X| > 0.7071) = 1 − P(|X| ≤ 0.7071)`
`= 1 − ∫_{−0.7071}^{0.7071}(1/2)dx = 1 − 0.7071 = 0.2929`
`P(X > 0.5, Y > 0.5) = P(X > 0.5 且 X² > 0.5) = P(X > 0.7071) = 1 − 0.7071 = 0.2929`
而 `P(X>0.5) × P(Y>0.5) = 0.25 × 0.2929 = 0.0732`
`0.2929 ≠ 0.0732`，故 **X 与 Y 不独立**。

**结论与解读**：X 与 Y 有**完全的确定性函数关系** `Y = X²`，却满足 `Cov = 0`。原因是协方差只度量**线性**关联：X 在正半轴时 Y 随 X 增大而增大，X 在负半轴时 Y 随 X 增大而减小，两个方向的线性趋势**正好抵消**，净效应为零。

**答案**：① `E(X) = 0`，`E(Y) = 1/3`，`E(XY) = 0`；② `Cov = 0`，`ρ = 0`；③ 不独立。

> **考点总结**：`独立 ⟹ 不相关`（永远成立）；`不相关 ⇏ 独立`（本例为反例）；唯有**二维正态**下两者等价。

**例 4.7**（题型：中心极限定理——独立同分布之和）
某型号电子元件的寿命服从均值为 100 小时、标准差为 100 小时的分布（不必是正态）。现随机抽取 100 个元件，求这 100 个元件的**总寿命**超过 10500 小时的概率（用中心极限定理近似）。

**解**：
设第 i 个元件寿命为 `Xᵢ`，则 `E(Xᵢ) = μ = 100`，`σ(Xᵢ) = 100`，`D(Xᵢ) = σ² = 10000`。
`X₁, …, X₁₀₀` 独立同分布，`n = 100` 较大，适用**林德伯格-列维定理**。
**为什么用总和的近似分布**：
`E(ΣXᵢ) = nμ = 100 × 100 = 10000`
`D(ΣXᵢ) = nσ² = 100 × 10000 = 1000000`
`σ(ΣXᵢ) = √1000000 = 1000`
故 `ΣXᵢ ~ 近似 N(10000, 1000000)`。
标准化：
`P(ΣXᵢ > 10500) ≈ 1 − Φ((10500 − 10000)/1000) = 1 − Φ(0.5)`
查表得 `Φ(0.5) = 0.6915`，
故 `P ≈ 1 − 0.6915 = 0.3085`

**答案**：约 0.3085（即约 30.85%）。

**例 4.8**（题型：棣莫弗-拉普拉斯定理，含连续性修正）
抛一枚均匀硬币 400 次。求正面出现次数在 180 到 220 次之间的概率（用正态近似，含连续性修正）。

**解**：
设 X 为正面出现次数，则 `X ~ B(400, 0.5)`。
`E(X) = np = 400 × 0.5 = 200`，`D(X) = np(1−p) = 400 × 0.5 × 0.5 = 100`，`σ = 10`。
**为什么可以近似**：`np = 200 ≥ 5` 且 `n(1−p) = 200 ≥ 5`，满足条件。
**连续性修正**：`180 ≤ X ≤ 220` 作为整数区间，扩展为连续区间 `[179.5, 220.5]`。

`P(180 ≤ X ≤ 220) ≈ Φ((220.5 − 200)/10) − Φ((179.5 − 200)/10)`
`= Φ(2.05) − Φ(−2.05) = 2Φ(2.05) − 1`
查表得 `Φ(2.05) = 0.9798`，
故 `P ≈ 2 × 0.9798 − 1 = 0.9596`

**答案**：约 0.9596。

> **对比不做修正**：`2Φ(2.0) − 1 = 2 × 0.9772 − 1 = 0.9544`。两者差 0.0052，说明 n = 400 时修正的影响已较小，但**标准答案通常要求修正**，考试时务必写上 `±0.5`。
>
> **拓展（3σ 法则的呼应）**：`200 ± 20` 恰好是 `μ ± 2σ`。**不做连续性修正**的算法给 `2Φ(2.0) − 1 = 0.9544`（四位表值口径；真值 `2Φ(2) − 1 = 0.9545`），而本题结果 0.9596 更大——因为区间 `[180, 220]` 连续化后实际覆盖的是 `[179.5, 220.5]`，比 `μ ± 2σ` 略宽，所以概率略大。
>
> **口径说明**：本笔记中 3σ 法则一律写**四位标准正态表值** `0.6826 / 0.9544 / 0.9974`（第 2 章、第 4 章、附录 A 三处一致），而它们的真值是 `0.6827 / 0.9545 / 0.9973`。**考试按附表查表值写即可。**

**例 4.9**（题型：用切比雪夫不等式证明大数定律，证明题）
用切比雪夫不等式证明**伯努利大数定律**。

**证明**：
设 `X` 为 n 重伯努利试验中事件 A 发生的次数，A 每次发生的概率为 p，则 `X ~ B(n, p)`。
**第一步——把 X 拆成独立 0-1 变量之和**：
令 `Xᵢ = 1`（第 i 次 A 发生），`Xᵢ = 0`（否则），则 `X₁, …, Xₙ` **相互独立**，且
`E(Xᵢ) = p`，`D(Xᵢ) = p(1 − p)`，`X = Σᵢ₌₁ⁿ Xᵢ`，`X/n = (1/n)ΣXᵢ`。
**第二步——求频率的期望与方差**（用到期望线性性，不需要独立性；方差相加需要独立性）：
`E(X/n) = (1/n)·E(X) = (1/n)·np = p`
`D(X/n) = (1/n²)·D(X) = (1/n²)·np(1−p) = p(1−p)/n`
**第三步——对 `X/n` 用切比雪夫不等式**（取 `ε > 0`）：
`P( |X/n − p| ≥ ε ) ≤ D(X/n)/ε² = p(1−p)/(nε²)`
**第四步——放大并取极限**。因 `p(1−p) ≤ 1/4`（关于 p 的二次函数在 p = 1/2 处取最大值），
`p(1−p)/(nε²) ≤ 1/(4nε²)`
当 `n → ∞` 时 `1/(4nε²) → 0`，故
`0 ≤ lim_{n→∞} P(|X/n − p| ≥ ε) ≤ 0`
即 `lim_{n→∞} P(|X/n − p| < ε) = 1`。
这正是伯努利大数定律的结论。∎

**答案**：见证明。

> **证明结构小结（可直接迁移）**：① 把统计量拆成独立变量之和；② 算期望与方差；③ 套切比雪夫不等式；④ 放缩（用 `p(1−p) ≤ 1/4` 或 `D(Xᵢ) ≤ C`）后取极限。这是所有「用切比雪夫证大数定律」题目的通用套路。

**例 4.10**（题型：泊松近似的适用性判断与计算）
某车间有 200 台同型号机床独立工作，每台机床在任一时刻发生故障的概率为 0.01。求：① 任一时刻恰好有 3 台发生故障的概率；② 任一时刻至少 5 台发生故障的概率。

**解**：
设 X 为同时发生故障的机床数，则 `X ~ B(200, 0.01)`。
**方法选择**：`n = 200` 很大，`p = 0.01` 很小，`λ = np = 2` 适中（≤ 10），**应使用泊松近似**（若用正态近似需注意 p 很小，泊松更准）。
`P(X = k) ≈ 2^k e^(−2)/k!`
① `P(X = 3) ≈ 2³e^(−2)/3! = 8 × 0.135335/6 = 0.1804`
② `P(X ≥ 5) = 1 − P(X ≤ 4)`
`P(0) = e^(−2) = 0.1353`
`P(1) = 2e^(−2) = 0.2707`
`P(2) = 4e^(−2)/2 = 0.2707`
`P(3) = 8e^(−2)/6 = 0.1804`
`P(4) = 16e^(−2)/24 = 0.0902`
`Σ = 0.1353 + 0.2707 + 0.2707 + 0.1804 + 0.0902 = 0.9473`
`P(X ≥ 5) = 1 − 0.9473 = 0.0527`

**答案**：① ≈ 0.1804；② ≈ 0.0527。

> **工程解读**：虽然每台机床故障率只有 1%，但 200 台同时运行时期望故障数为 2，出现「至少 5 台同时故障」的概率仍有约 5.3%——**不能忽视**。这说明备件与维修人力的配置必须按分布尾部来规划，而不能只看平均值。这是可靠性工程与排队论的基本思想。

## 易错点提醒

1. **求 `E[g(X)]` 时先求 `g(X)` 的分布**。
   **错在**：为了算 `E(X²)`，先花大力气推出 `X²` 的密度，再积分。
   **正确做法**：**直接用** `E[g(X)] = ∫g(x)f(x)dx` 或 `Σg(xₖ)pₖ`，跳过求分布这一步。这是本章最重要的计算技巧。

2. **以为 `E(X + Y) = E(X) + E(Y)` 需要独立性**。
   **错在**：题目没说独立就不敢拆。
   **正确做法**：**期望的线性性永远成立，与独立性无关**；而 `E(XY) = E(X)E(Y)` **才**需要独立性。

3. **`D(X + Y)` 直接拆成 `D(X) + D(Y)` 而不检查独立性**。
   **错在**：对不独立的 X、Y 直接写 `D(X+Y) = D(X)+D(Y)`。
   **正确做法**：`D(X ± Y) = D(X) + D(Y) ± 2Cov(X,Y)`。**只有独立（或不相关）时** `Cov = 0`，才能简化为 `D(X) + D(Y)`。

4. **`D(2X)` 写成 `2D(X)`**。
   **错在**：把方差的数乘性质当期望的用。
   **正确做法**：`D(CX) = C²D(X)`，系数**必须平方**。`D(2X) = 4D(X)`，`D(−X) = D(X)`。

5. **`D(3X − 1)` 里把常数 −1 也算进去**。
   **错在**：写 `D(3X−1) = 9D(X) − 1`。
   **正确做法**：**常数不影响方差**，`D(X + C) = D(X)`。故 `D(3X−1) = 9D(X)`。

6. **用 `E(XY) = E(X)E(Y)` 反推独立性**。
   **错在**：算出 `E(XY) = E(X)E(Y)` 就判定 X、Y 独立。
   **正确做法**：这只说明**不相关**。要么用定义 `F(x,y) = F_X(x)F_Y(y)` 验证，要么找反例（如 `Y = X²`，X 对称分布）。

7. **混淆「不相关」与「独立」**。
   **错在**：认为两者等价。
   **正确做法**：**独立 ⟹ 不相关**；**不相关 ⇏ 独立**；**二维正态下两者等价**。记「不相关只管线性」。

8. **切比雪夫不等式方向用反**。
   **错在**：写成 `P(|X − μ| ≥ ε) ≥ σ²/ε²` 或 `P(|X−μ| < ε) ≤ 1 − σ²/ε²`。
   **正确做法**：**「偏离大」的上界**是 `σ²/ε²`（如 10%），**「偏离小」的下界**是 `1 − σ²/ε²`（如 90%）。记忆：**「大」配「小界」**。

9. **正态近似忘记连续性修正**。
   **错在**：`P(X ≥ 180) ≈ 1 − Φ((180 − np)/σ)`。
   **正确做法**：`P(X ≥ k) ≈ 1 − Φ((k − 0.5 − np)/σ)`，`P(X ≤ k) ≈ Φ((k + 0.5 − np)/σ)`。**下限减 0.5，上限加 0.5**。

10. **大数定律用错条件**。
    **错在**：题目给「独立同分布、仅知期望存在」，却答「切比雪夫大数定律」。
    **正确做法**：三条定律的条件对比要清楚——**切比雪夫**要求「独立 + 方差一致有界」；**伯努利**要求「n 重伯努利试验」；**辛钦**只要求「独立同分布 + 期望存在」。**条件最弱的是辛钦**。

11. **把 `X̄` 的方差写成 `σ²`**。
    **错在**：认为样本均值与原变量同方差。
    **正确做法**：`D(X̄) = σ²/n`，**要除以 n**。`X̄ ~ 近似 N(μ, σ²/n)`。样本量越大，均值越稳定。

12. **认为期望一定存在**。
    **错在**：看到分布就默认能算 `E(X)`。
    **正确做法**：定义要求 `Σ|xₖ|pₖ < ∞`（离散）或 `∫|x|f(x)dx < ∞`（连续）。**柯西分布** `f(x) = 1/[π(1+x²)]` 的期望不存在——这是概念题的标准反例。

## 本章小结

- **数学期望** `E(X)`：离散 `Σxₖpₖ`、连续 `∫xf(x)dx`，是「以概率为权的加权平均 / 重心」。
- **函数期望公式** `E[g(X)] = Σg(xₖ)pₖ` 或 `∫g(x)f(x)dx`——**不必先求 g(X) 的分布**。
- **期望线性性不需要独立性**；`E(XY) = E(X)E(Y)` 才需要独立性（且不可逆推）。
- **方差** `D(X) = E[(X − E(X))²] = E(X²) − [E(X)]²`，后者是计算捷径。
- **方差性质**：`D(C) = 0`；`D(X + C) = D(X)`；`D(CX) = C²D(X)`；独立时 `D(X ± Y) = D(X) + D(Y)`（**加减都是加号**）。
- **八大分布的期望方差**（必须默写）：`B(1,p)`：p / p(1−p)；`B(n,p)`：np / np(1−p)；`P(λ)`：λ / λ；`G(p)`：1/p / (1−p)/p²；`H(N,M,n)`：nM/N / 见总表；`U(a,b)`：(a+b)/2 / (b−a)²/12；`E(λ)`：1/λ / 1/λ²；`N(μ,σ²)`：μ / σ²。
- **切比雪夫不等式** `P(|X − μ| ≥ ε) ≤ σ²/ε²`，不依赖分布形状，是大数定律的证明工具，但估计保守。
- **协方差** `Cov(X,Y) = E(XY) − E(X)E(Y)`；**相关系数** `ρ = Cov/(σ_Xσ_Y)`，`|ρ| ≤ 1`，`|ρ| = 1 ⟺` 线性关系。
- **独立 ⟹ 不相关；不相关 ⇏ 独立**（反例 `Y = X²`，`X ~ U(−1,1)`）；**二维正态下两者等价**。
- **大数定律**：样本均值（频率）依概率收敛于期望（概率）；**辛钦**条件最弱（独立同分布 + 期望存在）。
- **中心极限定理**：独立同分布之和 `ΣXᵢ ~ 近似 N(nμ, nσ²)`，样本均值 `X̄ ~ 近似 N(μ, σ²/n)`；二项分布 `B(n,p) ~ 近似 N(np, np(1−p))`（**记得连续性修正**）。
- **一句话记住本章**：**期望管「平均」、方差管「波动」、协方差管「线性关联」、大数定律管「收敛」、中心极限定理管「为什么到处是正态」**。

## 自测题

1. 设 `X` 的分布律为 `P(X = 1) = 0.2`，`P(X = 2) = 0.5`，`P(X = 3) = 0.3`。求 `E(X)`、`E(X²)`、`D(X)`、`D(2X + 3)`。
2. 设 `X ~ U(a, b)`，`E(X) = 2`，`D(X) = 1/3`。求 a、b。
3. 设 `X` 的密度为 `f(x) = 3x²`（0 < x < 1）。求 `E(X)`、`D(X)`、`E(1/X)`。
4. 设 `X ~ P(λ)`，已知 `E(X²) = 6`。求 λ 与 `P(X = 0)`。
5. 设 `X ~ B(10, 0.4)`。求 `E(X)`、`D(X)`、`E(3X² + 2)`。（提示：`E(X²) = D(X) + [E(X)]²`）
6. 设 `(X,Y)` 的联合分布律为 `P(X=0,Y=0) = 0.3`，`P(X=0,Y=1) = 0.2`，`P(X=1,Y=0) = 0.1`，`P(X=1,Y=1) = 0.4`。求 `Cov(X,Y)` 与 `ρ_XY`。
7. 设 `X ~ N(2, 9)`，`Y ~ N(1, 16)`，X 与 Y 独立。求 `E(3X − 2Y + 1)` 与 `D(3X − 2Y + 1)`。
8. 设 `X` 的期望为 10、方差为 4。用切比雪夫不等式估计 `P(6 < X < 14)` 的下界。
9. 某批产品次品率 0.05，随机抽取 100 件，用中心极限定理（含连续性修正）求次品数不超过 5 件的概率。
10. 某保险公司有 10000 个独立投保人，每人年内出险概率 0.004。用泊松近似求年内出险人数不超过 50 人的概率（提示：`λ = 40`，可用正态近似处理）。

### 自测题答案

1. `E(X) = 1(0.2) + 2(0.5) + 3(0.3) = 0.2 + 1.0 + 0.9 = 2.1`
   `E(X²) = 1(0.2) + 4(0.5) + 9(0.3) = 0.2 + 2.0 + 2.7 = 4.9`
   `D(X) = 4.9 − 2.1² = 4.9 − 4.41 = 0.49`
   `D(2X + 3) = 4 × 0.49 = 1.96`
2. `(a + b)/2 = 2` ⟹ `a + b = 4`；`(b − a)²/12 = 1/3` ⟹ `(b − a)² = 4` ⟹ `b − a = 2`（取 b > a）。
   解得 **a = 1，b = 3**。
3. `E(X) = ∫_0^1 x · 3x² dx = 3/4 = 0.75`
   `E(X²) = ∫_0^1 x² · 3x² dx = 3/5 = 0.6`
   `D(X) = 0.6 − 0.5625 = 0.0375 = 3/80`
   `E(1/X) = ∫_0^1 (1/x) · 3x² dx = ∫_0^1 3x dx = 3/2 = 1.5`
4. 由 `D(X) = λ`、`E(X) = λ` 及 `E(X²) = D(X) + [E(X)]² = λ + λ²`：
   `λ + λ² = 6` ⟹ `λ² + λ − 6 = 0` ⟹ `(λ+3)(λ−2) = 0` ⟹ **λ = 2**（λ 必须为正）。
   `P(X = 0) = 2⁰e^(−2)/0! = e^(−2) = 0.1353`。
5. `E(X) = 10 × 0.4 = 4`；`D(X) = 10 × 0.4 × 0.6 = 2.4`
   `E(X²) = D(X) + [E(X)]² = 2.4 + 16 = 18.4`
   `E(3X² + 2) = 3E(X²) + 2 = 3 × 18.4 + 2 = 57.2`
6. `E(X) = 0 × 0.5 + 1 × 0.5 = 0.5`（`P(X=0) = 0.5`，`P(X=1) = 0.5`）
   `E(Y) = 0 × 0.4 + 1 × 0.6 = 0.6`（`P(Y=0) = 0.4`，`P(Y=1) = 0.6`）
   `E(XY) = 1 × 1 × 0.4 = 0.4`
   `Cov(X,Y) = 0.4 − 0.5 × 0.6 = 0.4 − 0.3 = 0.1`
   `D(X) = 0.5 − 0.25 = 0.25`，`σ_X = 0.5`；`D(Y) = 0.6 − 0.36 = 0.24`，`σ_Y = √0.24 ≈ 0.4899`
   `ρ_XY = 0.1/(0.5 × 0.4899) = 0.1/0.24495 ≈ 0.4082`
7. `E(3X − 2Y + 1) = 3 × 2 − 2 × 1 + 1 = 6 − 2 + 1 = 5`
   `D(3X − 2Y + 1) = 9D(X) + 4D(Y) = 9 × 9 + 4 × 16 = 81 + 64 = 145`（**系数平方，且独立时加减都是加号**）
8. `ε = 4`（区间 (6,14) 即 `|X − 10| < 4`），`σ² = 4`。
   `P(6 < X < 14) = P(|X − 10| < 4) ≥ 1 − 4/16 = 0.75`
9. 设次品数 `X ~ B(100, 0.05)`。`np = 5`，`np(1−p) = 4.75`，`σ = √4.75 ≈ 2.1794`。
   由棣莫弗-拉普拉斯定理并作连续性修正：
   `P(X ≤ 5) ≈ Φ((5 + 0.5 − 5)/2.1794) = Φ(0.5/2.1794) = Φ(0.2294)`
   查表得 `Φ(0.23) = 0.5910`，更精确插值 `Φ(0.2294) ≈ 0.5907`。
   （**注**：本题 `np = 5` 恰好卡在正态近似边界上；用泊松近似 `λ = 5` 得 `P(X ≤ 5) = e^(−5)(1+5+12.5+20.833+26.042+26.042) = 0.006738 × 91.417 = 0.6160`，更准确。说明 **p 很小、np 不大时泊松近似优于正态近似**。）
10. `X ~ B(10000, 0.004)`，`λ = np = 40`，用泊松近似 `X ~ P(40)`。
    此时 `E(X) = D(X) = 40`，`σ = √40 ≈ 6.3246`。用正态近似（含修正）：
    `P(X ≤ 50) ≈ Φ((50 + 0.5 − 40)/6.3246) = Φ(10.5/6.3246) = Φ(1.6602)`
    查表得 `Φ(1.66) = 0.9515`，
    故 `P ≈ 0.9515`（即约 95%）。
    （**说明**：λ = 40 较大时，泊松分布已相当接近正态分布，这正是中心极限定理的体现。）
