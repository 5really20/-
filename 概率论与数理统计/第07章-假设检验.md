## 学习目标

1. **能**正确设定原假设 `H₀` 与备择假设 `H₁`，并说清「为什么把想推翻的结论放在 `H₀`」。
2. **能**准确说出**第一类错误**（弃真，概率 α）与**第二类错误**（取伪，概率 β）的含义，并针对具体问题说明两类错误的**实际后果**。
3. **能**解释「不拒绝 `H₀`」不等于「接受 `H₀`」——证据不足不等于证明为真。
4. **能**背诵并默写假设检验的**五步法**。
5. **能**根据题目条件（估均值还是方差、σ 是否已知、单侧还是双侧、单总体还是双总体）**选择正确的检验统计量并写出拒绝域**——这是本章拿分关键。
6. **能**熟练计算 Z、t、χ²、F 四种检验统计量的观测值并查表判断。
7. **能**用**大样本 Z 检验**处理总体分布未知的均值检验问题。
8. **能**用 **χ² 拟合优度检验**判断总体是否服从某个指定分布，并正确计算自由度 `k − r − 1`。
9. **能**计算 p 值并用 p 值法作判断。
10. **能**说清假设检验与区间估计的等价关系。

## 7.1 假设检验的基本概念

### 7.1.1 问题的提法

**假设检验（Hypothesis Testing）**：先对总体分布或其中的参数提出一个**假设**，然后根据样本信息，判断这个假设是否成立。

**两类假设**：

- **原假设（零假设，Null Hypothesis）`H₀`**：待检验的假设，通常是「维持现状」「没有差异」「符合标准」；
- **备择假设（对立假设，Alternative Hypothesis）`H₁`**：与 `H₀` 对立的假设，通常是「有变化」「有差异」「想证明的新结论」。

**三种形式的检验**：

| 类型 | `H₀` | `H₁` | 实际含义 |
|---|---|---|---|
| **双侧检验** | `μ = μ₀` | `μ ≠ μ₀` | 关心是否有**差异**（不管方向） |
| **右侧检验** | `μ ≤ μ₀` | `μ > μ₀` | 关心是否**显著变大** |
| **左侧检验** | `μ ≥ μ₀` | `μ < μ₀` | 关心是否**显著变小** |

（右侧检验与左侧检验统称**单侧检验**。）

> **重点——如何设定 `H₀` 与 `H₁`（考试必考的概念题）**：
>
> **原则：「把希望被推翻的、或者需要强证据才能否定的命题放在 `H₀`；把想要证明的新结论放在 `H₁`。」**
>
> **为什么这样设**：假设检验的**判决机制是「拒绝 `H₀`」**——拒绝 `H₀` 时才是有力的结论（因为此时犯错的概率被控制在 α 这个很小的数）。而「不拒绝 `H₀`」只是一个**软弱**的结论（只能说「证据不足」）。
> 所以：**你只有在对 `H₁` 有强证据时才敢拒绝 `H₀`**。为了把「下结论的风险」控制在 α 以内，就要把**你想要下结论的那个方向**放到 `H₁`。
>
> **实用判据**：
> - 题目出现「**是否显著提高/增大/超过**」→ 单侧，`H₁: μ > μ₀`（**把「提高」放 `H₁`**）；
> - 题目出现「**是否显著降低/减少/低于**」→ 单侧，`H₁: μ < μ₀`；
> - 题目出现「**是否有显著差异/是否正常/是否符合标准**」→ 双侧，`H₁: μ ≠ μ₀`。
>
> **为什么等号总在 `H₀`**：检验统计量的分布在 `H₀` 下必须**确定**。只有取等号 `μ = μ₀` 才能算出 `Z = (X̄ − μ₀)/(σ/√n)` 的具体值，从而确定分布。所以**`H₀` 必须含等号**（`=`、`≤`、`≥`），`H₁` 绝不能含等号。

### 7.1.2 两类错误

由于样本是随机的，假设检验的判决**不可能保证百分之百正确**。可能犯两种错误：

| 名称 | 含义 | 概率 | 直观说法 |
|---|---|---|---|
| **第一类错误**（弃真错误） | `H₀` 实际为**真**，却**拒绝**了 `H₀` | `P(拒绝 H₀ \| H₀ 真) = α` | 「冤枉好人」 |
| **第二类错误**（取伪错误） | `H₀` 实际为**假**，却**没有拒绝** `H₀` | `P(不拒绝 H₀ \| H₀ 假) = β` | 「放过坏人」 |

**显著性水平（Significance Level）α**：犯第一类错误的概率上限。只控制 `α` 而不控制 `β` 的检验称为**显著性检验**。

**四条重要性质**：

1. **α 与 β 不能同时减小**（在样本容量 n 固定的前提下）。减小 α 会使拒绝域变小，更难拒绝 `H₀`，于是 `β` 增大。**唯一能同时减小两者的办法是增大样本容量 n**。
2. 通常先**固定 α**（常用的 0.10、0.05、0.01），再在满足该 α 的检验中尽量减小 β。
3. **β 一般不易计算**，因为它依赖于 `H₀` 为假时的**具体参数值**（而不是一个确定的值）。
4. 「**不拒绝 `H₀`」≠「接受 `H₀`」**：不拒绝只说明**样本没有提供足够的证据**去推翻它，不代表它已被证明为真。

> **重点——两类错误的实际后果要会分析**。判断原则是：**哪一类错误造成的损失更大，就把哪一类的概率控制得更小（即 α 取得更小）**。
>
> **例：药品检验**。`H₀`：药品无效；`H₁`：药品有效。
> - 第一类错误（弃真）：药其实无效，却判它有效 → **让病人吃无效药，耽误治疗，后果严重**；
> - 第二类错误（取伪）：药其实有效，却判它无效 → **错失一种好药，损失也大但相对可挽回**。
> 因此通常把 `α` 取得很小（如 0.01），**宁可错杀不可放过**。
>
> **例：无罪推定**。`H₀`：被告无罪；`H₁`：被告有罪。
> - 第一类错误：被告无罪却判有罪 → **冤狱**，后果极严重，所以要求「证据确凿」；
> - 第二类错误：被告有罪却判无罪 → **放纵罪犯**。
> 刑事审判采取「疑罪从无」，本质上是**把 α 压得极低**。

### 7.1.3 检验的步骤与拒绝域

**检验统计量（Test Statistic）**：用于作判断的、只依赖样本的统计量，其分布在一行 `H₀` 成立时**已知**。

**拒绝域（Rejection Region）**：使 `H₀` 被拒绝的统计量取值集合。

**假设检验的五步法（必须背下来）**：

① **提出假设**：根据问题写出 `H₀` 与 `H₁`；
② **选取检验统计量**，并确定在 `H₀` 成立时它的分布；
③ **给定显著性水平 α**，由分布的分位点确定**拒绝域**；
④ **计算检验统计量的观测值**；
⑤ **作判断**：观测值落入拒绝域则**拒绝 `H₀`**，否则**不拒绝 `H₀`**，并结合实际意义作答。

**三种检验的拒绝域（以 Z 检验为例）**：

| 检验类型 | `H₀` | `H₁` | 拒绝域 |
|---|---|---|---|
| **双侧** | `μ = μ₀` | `μ ≠ μ₀` | `\|Z\| > z_{α/2}` |
| **右侧** | `μ ≤ μ₀` | `μ > μ₀` | `Z > z_α` |
| **左侧** | `μ ≥ μ₀` | `μ < μ₀` | `Z < −z_α` |

> **重点——为什么单侧检验用 `z_α` 而不是 `z_{α/2}`**：双侧检验把 α 平均分在两侧尾巴上（每侧 `α/2`），因为**两个方向的变化都算「异常」**；单侧检验只关心一个方向，把整个 α 都放在那一侧，于是**拒绝域更大、更容易拒绝 `H₀`**。
> **数值对比**：`z_{0.05} = 1.645 < z_{0.025} = 1.96`。若统计量观测值等于 1.8，那么**双侧检验不拒绝**（1.8 < 1.96）而**右侧检验拒绝**（1.8 > 1.645）。**单侧检验更有「力量」**（power 更大），代价是「不关心另一方向」——这就是为什么**不能用数据「看一眼」再决定用哪一侧**，必须在看数据之前就定好。

### 7.1.4 p 值法

**p 值（p-value）**：在 `H₀` 成立的条件下，**出现当前样本结果或更极端结果的概率**。

**判据**：**`p < α` ⟺ 拒绝 `H₀`**（因为 p 值越小，说明当前样本在 `H₀` 下越「不可能」发生，越有理由怀疑 `H₀`）。

**常见情形的 p 值**（`Z_obs` 为 Z 统计量的观测值，`Φ` 为标准正态分布函数）：

| 检验类型 | p 值 |
|---|---|
| 右侧 | `p = P(Z > Z_obs) = 1 − Φ(Z_obs)` |
| 左侧 | `p = P(Z < Z_obs) = Φ(Z_obs)` |
| 双侧 | `p = P(\|Z\| > \|Z_obs\|) = 2[1 − Φ(\|Z_obs\|)]` |

> **p 值与 α 的分工**：`α` 是**事先定好的门槛**（决策规则），`p` 是**由数据算出的证据强度**。两者是不同的东西：
> - `p = 0.03` 且 `α = 0.05` → 拒绝；同一份数据若改成 `α = 0.01` → 不拒绝。
> - 报告 p 值的好处是**把判断标准交给读者**，不必预设 α。
> **常见误用**：p 值**不是**「`H₀` 为真的概率」，也**不是**「结论错误的概率」。它只是「在 `H₀` 为真的前提下，观测到这么极端数据的概率」。

### 7.1.5 假设检验与区间估计的关系

**双侧检验 `H₀: μ = μ₀` 的接受域，恰好是 `μ` 的置信度为 `1 − α` 的置信区间。**

> **推导思路**：`P(−z_{α/2} < (X̄−μ₀)/(σ/√n) < z_{α/2}) = 1 − α` 等价于 `μ₀ ∈ (X̄ − z_{α/2}σ/√n, X̄ + z_{α/2}σ/√n)`。
>
> **实用价值**：**第 6 章的置信区间可以「反过来」当检验用**——如果 `μ₀` 落在 `μ` 的 95% 置信区间内，则在 α = 0.05 下不拒绝 `H₀: μ = μ₀`。这正是第 6 章例 6.9 末尾「区间含 0 ⟺ 不拒绝均值相等」的由来。

## 7.2 单正态总体的假设检验

### 7.2.1 单正态总体检验选择表（必须背，考试至少考一道）

设总体 `X ~ N(μ, σ²)`，样本容量 n，样本均值 `X̄`，样本方差 `S²`，显著性水平 α。

| 检验对象 | 已知条件 | `H₀` | 检验统计量及其分布 | 拒绝域（双侧，`H₁: μ≠μ₀` 或 `σ²≠σ₀²`） |
|---|---|---|---|---|
| **均值 μ** | σ² **已知** | `μ = μ₀` | `Z = (X̄ − μ₀)/(σ/√n) ~ N(0,1)` | `\|Z\| > z_{α/2}` |
| **均值 μ** | σ² **未知** | `μ = μ₀` | `T = (X̄ − μ₀)/(S/√n) ~ t(n−1)` | `\|T\| > t_{α/2}(n−1)` |
| **方差 σ²** | μ **未知** | `σ² = σ₀²` | `χ² = (n−1)S²/σ₀² ~ χ²(n−1)` | `χ² > χ²_{α/2}(n−1)` 或 `χ² < χ²_{1−α/2}(n−1)` |

**单侧检验的拒绝域**：

| 检验对象 | `H₁` | 拒绝域 |
|---|---|---|
| 均值 μ（Z 检验） | `μ > μ₀` | `Z > z_α` |
| 均值 μ（Z 检验） | `μ < μ₀` | `Z < −z_α` |
| 均值 μ（t 检验） | `μ > μ₀` | `T > t_α(n−1)` |
| 均值 μ（t 检验） | `μ < μ₀` | `T < −t_α(n−1)` |
| 方差 σ²（χ² 检验） | `σ² > σ₀²` | `χ² > χ²_α(n−1)` |
| 方差 σ²（χ² 检验） | `σ² < σ₀²` | `χ² < χ²_{1−α}(n−1)` |

> **选择决策树（两步）**：
> ① **检验均值还是方差？** 均值 → Z 或 t；方差 → χ²。
> ② **σ 知不知道？** σ 已知 → **Z 检验**（也叫 **U 检验**）；σ 未知 → **t 检验**。
>
> **一句话**：**「均值看 Z/t（σ 已知用 Z、未知用 t），方差看 χ²」。**

### 7.2.2 均值 μ 的检验

**情形 A：σ² 已知——Z 检验（U 检验）**

① `H₀: μ = μ₀`，`H₁` 视题目而定；
② 在 `H₀` 下，`X̄ ~ N(μ₀, σ²/n)`，故 `Z = (X̄ − μ₀)/(σ/√n) ~ N(0,1)`；
③ 双侧拒绝域 `|Z| > z_{α/2}`；
④ 代入 `X̄` 的观测值算 Z；
⑤ 判断。

**情形 B：σ² 未知——t 检验**

把 `σ` 换成 `S`，统计量 `T = (X̄ − μ₀)/(S/√n) ~ t(n−1)`，拒绝域 `|T| > t_{α/2}(n−1)`。

> **为什么要换**：σ 未知时 `(X̄ − μ₀)/(σ/√n)` 算不出来（含未知量），只能用 `S` 顶替。代价是分布从正态变成 t（尾部更厚，临界值更大），所以**同样数据下 t 检验比 Z 检验更难拒绝 `H₀`**——这是对「σ 也不确定」这一额外不确定性的惩罚。

### 7.2.3 方差 σ² 的检验——χ² 检验

① `H₀: σ² = σ₀²`，`H₁: σ² ≠ σ₀²`（或单侧）；
② 由第 5 章定理 2，在 `H₀` 下 `χ² = (n−1)S²/σ₀² ~ χ²(n−1)`（**要求总体正态**）；
③ 双侧拒绝域：`χ² > χ²_{α/2}(n−1)` **或** `χ² < χ²_{1−α/2}(n−1)`。

> **重点——χ² 检验的拒绝域为什么不对称**：χ² 分布**不是对称的**，所以要**两侧各取 α/2**：
> - 右侧 `α/2`：`χ² > χ²_{α/2}(n−1)`（表示样本方差**过大**）；
> - 左侧 `α/2`：`χ² < χ²_{1−α/2}(n−1)`（表示样本方差**过小**）。
> **注意左端用的是 `χ²_{1−α/2}`（小的分位点）**。这与 Z、t 检验中「取绝对值」的对称处理完全不同。

## 7.3 双正态总体的假设检验

### 7.3.1 双正态总体检验选择表

设 `X ~ N(μ₁, σ₁²)`、`Y ~ N(μ₂, σ₂²)`，两总体**相互独立**，样本容量 `n₁`、`n₂`。

| 检验对象 | 已知条件 | `H₀` | 检验统计量及其分布 | 拒绝域（双侧） |
|---|---|---|---|---|
| **μ₁−μ₂** | σ₁²、σ₂² **已知** | `μ₁ = μ₂` | `Z = (X̄−Ȳ)/√(σ₁²/n₁+σ₂²/n₂) ~ N(0,1)` | `\|Z\| > z_{α/2}` |
| **μ₁−μ₂** | σ₁²=σ₂² **未知** | `μ₁ = μ₂` | `T = (X̄−Ȳ)/(S_w√(1/n₁+1/n₂)) ~ t(n₁+n₂−2)` | `\|T\| > t_{α/2}(n₁+n₂−2)` |
| **σ₁²/σ₂²** | μ₁、μ₂ **未知** | `σ₁² = σ₂²` | `F = S₁²/S₂² ~ F(n₁−1, n₂−1)` | `F > F_{α/2}(n₁−1,n₂−1)` 或 `F < F_{1−α/2}(n₁−1,n₂−1)` |

其中合并方差 `S_w² = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2)`。

**F 检验的实用技巧**：为避免查 `F_{1−α/2}`（下侧分位点，一般表上没有），通常**把较大的样本方差放在分子**，即令 `F = max(S₁²,S₂²)/min(S₁²,S₂²)`，则只需与 `F_{α/2}(n_大−1, n_小−1)` 比较（临界值随之取对应的自由度顺序）。

> **成对数据（配对试验）的处理**：若两组数据是**同一个体前后两次测量**（如「同一批病人用药前后的血压」），则**不能**当成两个独立总体！应令 `Dᵢ = Xᵢ − Yᵢ`，把问题化为**单总体** `D ~ N(μ_D, σ_D²)` 的均值检验 `H₀: μ_D = 0`，用 t 检验。
> **为什么**：配对数据中 `Xᵢ` 与 `Yᵢ` **不独立**（同一个体），用两独立样本公式会**高估方差**、掩盖真实差异，导致检验失效。这是最容易踩的坑。

---

## 7.4 关于一般总体数学期望的假设检验

当**总体分布未知**（不一定是正态）时，只要样本容量**足够大**，就可以用**中心极限定理**：

`(X̄ − μ)/(S/√n) ~ 近似 N(0, 1)`（n 很大时）

于是可使用 **Z 检验**：`H₀: μ = μ₀`，`H₁: μ ≠ μ₀`，拒绝域 `|Z| > z_{α/2}`，其中

`Z = (X̄ − μ₀)/(S/√n)`

**大样本的经验门槛**：

| 总体分布 | 建议 n |
|---|---|
| 接近对称、无明显重尾 | `n ≥ 30` |
| 明显偏态或重尾 | `n ≥ 50`（甚至 100） |

> **注意**：这是**近似检验**，α 只是近似等于给定的显著性水平。它**不要求总体正态**，这是它最大的价值——实际中总体的分布几乎总是未知的。

---

## 7.5 分布拟合检验

**目的**：检验总体是否服从**某个指定的分布**（如「是否服从正态分布」「骰子是否均匀」）。这检验的不是某个参数，而是**整个分布形式**。

**χ² 拟合优度检验（Chi-square Goodness-of-Fit Test）的步骤**：

① **提出假设**：`H₀`：总体服从分布 `F₀(x)`；`H₁`：总体不服从 `F₀(x)`；
② **分组**：把样本取值范围分成 k 个互不相交的区间 `I₁, …, I_k`，统计落入各区间的**实际频数** `f₁, …, f_k`（`Σfᵢ = n`）；
③ **计算理论概率与理论频数**：`pᵢ = P(X ∈ Iᵢ)`（在 `H₀` 下计算），`npᵢ` 为**理论频数**；
④ **构造统计量**：

`χ² = Σᵢ₌₁ᵏ (fᵢ − npᵢ)² / (npᵢ)`

⑤ **确定自由度**：`自由度 = k − r − 1`，其中 `r` 是**用样本估计的参数个数**；
⑥ **拒绝域**：`χ² > χ²_α(k − r − 1)`（**永远是单侧右侧检验**，因为 χ² 值越大表示实际与理论偏离越大）。

> **重点（三条最容易错的地方）**：
> ① **自由度不是 k**，而是 `k − r − 1`。那个「`−1`」来自约束 `Σpᵢ = 1`（k 个概率中只有 k−1 个自由）。若 `H₀` 完全指定了分布（无待估参数，如「骰子均匀」），则 `r = 0`，自由度 = `k − 1`；若检验「是否服从正态分布」，需用样本估计 `μ` 与 `σ²`，则 `r = 2`，自由度 = `k − 3`。
> ② **理论频数 `npᵢ` 不能太小**。经验规则：**要求每组的 `npᵢ ≥ 5`**，否则应把相邻组合并（合并后 k 减小，自由度随之重算）。因为 χ² 统计量的分布在 `npᵢ` 很小时不准确。
> ③ **拒绝域在右侧**：χ² 越大说明实际频数与理论频数差得越远，越应拒绝 `H₀`。不要去找左尾。

## 典型例题

**例 7.1**（题型：两类错误的辨析）
某厂声称其产品次品率 `p ≤ 0.01`。质检部门抽取一批产品进行检验，设 `H₀: p ≤ 0.01`，`H₁: p > 0.01`。① 说明第一类错误与第二类错误的具体含义；② 若质检部门希望「不能轻易判定厂家不合格」，应如何调整 α？

**解**：
① **第一类错误（弃真）**：`H₀` 为真（`p ≤ 0.01`，产品**合格**），但检验结果拒绝了 `H₀`，判定为**不合格**。即「**把合格产品误判为不合格**」。
**第二类错误（取伪）**：`H₀` 为假（`p > 0.01`，产品**不合格**），但检验结果没有拒绝 `H₀`，判定为**合格**。即「**把不合格产品误判为合格**」。

② **为什么这样调整**：`P(第一类错误) = α`。「不能轻易判定厂家不合格」意味着**要尽量少地冤枉厂家**，即要**压低第一类错误的概率**，故应**把 α 取得更小**（如从 0.05 降到 0.01）。
代价是：**第二类错误 β 随之增大**——不合格产品更容易蒙混过关（质检更「宽松」）。

**答案**：① 见上；② 应**减小 α**，代价是 β 增大。

> **反过来想**：若质检部门代表**消费者利益**，希望「不让不合格品流入市场」，则应容忍多冤枉厂家一点，把 α 取得大一些，以降低 β（放过不合格品的概率）。**α 的大小是「两类风险」的权衡，不是数学问题，而是决策问题。**

---

**例 7.2**（题型：σ 已知时的均值检验——Z 检验，双侧）
某包装机装糖，每袋标准重量为 500 g。由长期经验知每袋重量服从正态分布且标准差 `σ = 10` g。某日开工后随机抽取 9 袋，测得平均重量 `X̄ = 502` g。问该包装机工作是否正常？（取 α = 0.05）

**解**：
**第一步——提出假设**：题目问「是否正常」，即问「与 500 g 是否有差异」，是**双侧检验**：
`H₀: μ = 500`，`H₁: μ ≠ 500`
**第二步——选统计量**：总体正态，**σ 已知**（10），用 **Z 检验**。在 `H₀` 下
`Z = (X̄ − 500)/(σ/√n) = (X̄ − 500)/(10/3) ~ N(0, 1)`
**第三步——定拒绝域**：`α = 0.05`，`α/2 = 0.025`，查表 `z_{0.025} = 1.96`。
拒绝域为 `|Z| > 1.96`。
**第四步——计算观测值**：
`σ/√n = 10/√9 = 10/3 = 3.3333`
`Z = (502 − 500)/3.3333 = 2/3.3333 = 0.600`
**第五步——判断**：因为 `|Z| = 0.600 < 1.96`，**不在拒绝域内**，故**不拒绝 `H₀`**。

**答案**：在 α = 0.05 下不能认为包装机工作不正常（可以认为每袋平均重量与 500 g 无显著差异）。

> **补充计算 p 值**：`p = 2[1 − Φ(0.600)] = 2(1 − 0.7257) = 2 × 0.2743 = 0.5486`。
> 即：若包装机真的正常，出现「9 袋平均值偏离 500 g 达 2 g 或更多」的概率高达 54.86%。这个 p 值非常大，**毫无理由怀疑 `H₀`**。

---

**例 7.3**（题型：σ 未知时的均值检验——t 检验，单侧）
某厂生产一种电子元件，要求平均寿命**超过** 1000 小时。现随机抽取 16 只，测得样本均值 `X̄ = 1020` 小时，样本标准差 `S = 40` 小时。设元件寿命服从正态分布，问能否认为该批元件的平均寿命显著超过 1000 小时？（取 α = 0.05）

**解**：
**第一步——提出假设**：题目要**证明**「显著超过」，故把「超过」放在 `H₁`（右侧检验）：
`H₀: μ ≤ 1000`（取临界值 `μ₀ = 1000`），`H₁: μ > 1000`
**第二步——选统计量**：总体正态，**σ 未知**（给的是样本标准差 S），用 **t 检验**。
在 `μ = 1000` 时，`T = (X̄ − 1000)/(S/√n) ~ t(n − 1) = t(15)`
**第三步——定拒绝域**：右侧检验，查表 `t_{0.05}(15) = 1.7531`。拒绝域为 `T > 1.7531`。
**第四步——计算观测值**：
`S/√n = 40/√16 = 40/4 = 10`
`T = (1020 − 1000)/10 = 20/10 = 2.000`
**第五步——判断**：因为 `T = 2.000 > 1.7531`，**落入拒绝域**，故**拒绝 `H₀`**。

**答案**：在 α = 0.05 下，可以认为该批元件的平均寿命**显著超过 1000 小时**。

> **注意**：若误用双侧检验（`t_{0.025}(15) = 2.1315`），则 `2.000 < 2.1315`，结论会变成「不能认为超过 1000 小时」。**这说明单侧检验比双侧更容易拒绝 `H₀`**（检验功效更高）——所以必须在看数据之前就根据问题本身确定检验方向，**不能事后挑选对自己有利的那一侧**。

---

**例 7.4**（题型：方差检验——χ² 检验，单侧）
某机床加工一种零件，其直径服从正态分布。工艺要求直径的**标准差不超过** 0.5 mm。现随机抽取 16 件，测得样本标准差 `S = 0.6` mm。问该机床的加工精度是否显著下降？（取 α = 0.05）

**解**：
**第一步——提出假设**：工艺要求 `σ ≤ 0.5`，问「是否显著下降」即「σ 是否显著**变大**」：
`H₀: σ² ≤ 0.25`（即 `σ₀² = 0.25`），`H₁: σ² > 0.25`
**第二步——选统计量**：检验方差，用 **χ² 检验**。在 `σ² = 0.25` 时
`χ² = (n−1)S²/σ₀² ~ χ²(n − 1) = χ²(15)`
**第三步——定拒绝域**：右侧检验，查表 `χ²_{0.05}(15) = 24.996`。拒绝域为 `χ² > 24.996`。
**第四步——计算观测值**：
`(n−1)S² = 15 × 0.36 = 5.40`
`χ² = 5.40/0.25 = 21.60`
**第五步——判断**：因为 `21.60 < 24.996`，**不在拒绝域内**，故**不拒绝 `H₀`**。

**答案**：在 α = 0.05 下不能认为该机床的加工精度显著下降。

> **直觉检验**：`S = 0.6` 比 `σ₀ = 0.5` 大了 20%，看起来「变差了」；但 `S` 是从 16 个样本算出来的，本身有相当大的抽样波动。χ² 检验告诉我们：**在 σ 真的等于 0.5 时，16 个样本的 S 达到 0.6 甚至更大的概率并不小（真实值 0.1187，即约 0.12）**，因此这点「变差」不足以支撑「精度下降」的结论。
>
> **补充**：若 n = 100（`S` 仍为 0.6），则 `χ² = 99 × 0.36/0.25 = 142.56`，而 `χ²_{0.05}(99) ≈ 123.2`，此时会**拒绝 `H₀`**。**样本量越大，同样的偏离越有说服力**。

**例 7.5**（题型：两正态总体均值差的检验——合并方差 t 检验）
两台机床加工同一种零件，直径分别服从 `N(μ₁, σ²)` 与 `N(μ₂, σ²)`（方差相等但未知）。从第一台抽取 10 件，测得 `X̄ = 20.1` mm，`S₁ = 0.3` mm；从第二台抽取 11 件，测得 `Ȳ = 19.8` mm，`S₂ = 0.4` mm。问两台机床加工的零件平均直径是否有显著差异？（取 α = 0.05）

**解**：
**第一步——提出假设**：问「是否有显著差异」，双侧：
`H₀: μ₁ = μ₂`，`H₁: μ₁ ≠ μ₂`
**第二步——选统计量**：两总体正态、方差相等未知，用**合并方差的 t 检验**。在 `H₀` 下
`T = (X̄ − Ȳ) / [S_w √(1/n₁ + 1/n₂)] ~ t(n₁ + n₂ − 2) = t(19)`
**第三步——定拒绝域**：`t_{0.025}(19) = 2.0930`。拒绝域为 `|T| > 2.0930`。
**第四步——计算观测值**：
- 合并方差：
`S_w² = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2) = [9 × 0.09 + 10 × 0.16]/19`
`= (0.81 + 1.60)/19 = 2.41/19 = 0.126842`
`S_w = √0.126842 = 0.35615`
- 标准误：
`√(1/10 + 1/11) = √(0.10000 + 0.09091) = √0.19091 = 0.43693`
`S_w × 0.43693 = 0.35615 × 0.43693 = 0.15561`
- 统计量观测值：
`T = (20.1 − 19.8)/0.15561 = 0.3/0.15561 = 1.928`

**第五步——判断**：因为 `|T| = 1.928 < 2.0930`，**不在拒绝域内**，故**不拒绝 `H₀`**。

**答案**：在 α = 0.05 下不能认为两台机床加工的零件平均直径有显著差异。

> **与第 6 章例 6.9 对照**：那里的置信区间是 `(−0.039, 0.639)`（注意那里 `n₁ = 9, n₂ = 11`，本例改为 `n₁ = 10`）。**区间包含 0 ⟺ 不拒绝 `H₀`**，两个结论在这里完全一致——这不是巧合，而是 7.1.5 节所述等价关系的体现。

---

**例 7.6**（题型：两正态总体方差的检验——F 检验）
继续例 7.5 的数据：`n₁ = 10`，`S₁² = 0.09`；`n₂ = 11`，`S₂² = 0.16`。问两台机床加工的零件直径的**方差**是否有显著差异？（取 α = 0.05，已知 `F_{0.025}(10, 9) = 3.96`）

**解**：
**第一步——提出假设**：双侧（问「是否有差异」）：
`H₀: σ₁² = σ₂²`，`H₁: σ₁² ≠ σ₂²`
**第二步——选统计量**：在 `H₀` 下，`S₁²/S₂² ~ F(n₁−1, n₂−1) = F(9, 10)`。
**第三步——定拒绝域（用「大比小」技巧）**：
`S₂² = 0.16 > S₁² = 0.09`，故令
`F = S₂²/S₁² ~ F(n₂−1, n₁−1) = F(10, 9)`
查表 `F_{0.025}(10, 9) = 3.96`（**注意自由度顺序与「大比小」的分子分母对应**）。拒绝域为 `F > 3.96`。
**第四步——计算观测值**：
`F = 0.16/0.09 = 1.7778`
**第五步——判断**：因为 `1.7778 < 3.96`，**不在拒绝域内**，故**不拒绝 `H₀`**。

**答案**：在 α = 0.05 下不能认为两台机床加工的零件直径方差有显著差异（即例 7.5 中「方差相等」的前提是合理的）。

> **为什么先做 F 检验**：例 7.5 用了「`σ₁² = σ₂²`」这个前提，而例 7.6 正是**在检验这个前提是否成立**。实际数据分析的标准流程就是：**先做 F 检验判断方差是否齐性，再据此选择用合并方差的 t 检验还是近似 t 检验（Welch 检验）**。
>
> **R 语言对应**：`var.test(x, y)` 就是 F 检验；`t.test(x, y, var.equal = TRUE)` 就是合并方差 t 检验，`var.equal = FALSE`（默认）则是 Welch 检验。

**例 7.7**（题型：成对数据的 t 检验）
为比较两种减肥方法的效果，随机选取 8 名志愿者，先测量其体重，采用方法 A 一个月后测一次（记为 X），再恢复原体重后采用方法 B 一个月后测一次（记为 Y），数据如下（单位：kg）。问两种方法的减重效果是否有显著差异？（取 α = 0.05，`t_{0.025}(7) = 2.3646`）

| 志愿者 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| X（方法A） | 72 | 68 | 80 | 75 | 66 | 78 | 70 | 74 |
| Y（方法B） | 70 | 67 | 77 | 74 | 65 | 74 | 69 | 71 |

**解**：
**为什么用成对检验**：同一个人先后接受两种方法，两次数据**不独立**（个体差异被配对抵消），必须用差值法。
令 `Dᵢ = Xᵢ − Yᵢ`（减重量的差）：
`D = 2, 1, 3, 1, 1, 4, 1, 3`

**第一步——提出假设**：
`H₀: μ_D = 0`（两种方法效果无差异），`H₁: μ_D ≠ 0`
**第二步——选统计量**：化为**单总体**均值检验（σ 未知）→ **t 检验**：
`T = (D̄ − 0)/(S_D/√n) ~ t(7)`
**第三步——定拒绝域**：`|T| > t_{0.025}(7) = 2.3646`。
**第四步——计算**：
`D̄ = (2+1+3+1+1+4+1+3)/8 = 16/8 = 2.0`
`ΣDᵢ² = 4 + 1 + 9 + 1 + 1 + 16 + 1 + 9 = 42`
`S_D² = [ΣDᵢ² − nD̄²]/(n − 1) = [42 − 8 × 4]/7 = (42 − 32)/7 = 10/7 = 1.42857`
`S_D = √1.42857 = 1.19523`
`S_D/√n = 1.19523/√8 = 1.19523/2.82843 = 0.42258`
`T = 2.0/0.42258 = 4.7329`
**第五步——判断**：`|T| = 4.7329 > 2.3646`，**落入拒绝域，拒绝 `H₀`**。

**答案**：在 α = 0.05 下，可以认为两种减肥方法的减重效果**有显著差异**（方法 A 平均多减约 2 kg）。

> **如果误用两独立样本检验**：把 X 组的 8 个数与 Y 组的 8 个数当成独立样本，按原始数据实算得 `S₁² ≈ 23.27`、`S₂² ≈ 15.84`、`S_w² ≈ 19.55`、`S_w ≈ 4.42`，则 `T = 2.0/(4.42 × 0.5) ≈ 0.90`，远小于临界值，会得出「无显著差异」的**错误结论**。
> **原因**：个体差异（有人天生胖、有人瘦）带来了巨大方差，把真正的处理效应**淹没**了。**配对设计的作用就是消掉个体差异**——这就是为什么配对试验在医学、农业中如此重要。

---

**例 7.8**（题型：大样本检验，总体分布未知——第 7.4 节）
某城市统计局想了解该市居民人均年收入是否**超过** 20000 元。由于收入分布明显偏态，无法假定正态。现随机调查了 100 位居民，测得样本均值 `X̄ = 20500` 元，样本标准差 `S = 3000` 元。问能否认为该市人均年收入显著超过 20000 元？（取 α = 0.05）

**解**：
**第一步——提出假设**：问「是否显著超过」，右侧：
`H₀: μ ≤ 20000`（取 `μ₀ = 20000`），`H₁: μ > 20000`
**第二步——选统计量**：总体分布未知，但 `n = 100` 属于**大样本**，由**中心极限定理**，
`Z = (X̄ − μ₀)/(S/√n) ~ 近似 N(0, 1)`
**第三步——定拒绝域**：右侧检验，`z_{0.05} = 1.645`。拒绝域为 `Z > 1.645`。
**第四步——计算**：
`S/√n = 3000/√100 = 3000/10 = 300`
`Z = (20500 − 20000)/300 = 500/300 = 1.667`
**第五步——判断**：因为 `1.667 > 1.645`，**落入拒绝域，拒绝 `H₀`**。

**答案**：在 α = 0.05 下，可以认为该市人均年收入**显著超过 20000 元**。

> **注意结论的「勉强程度」**：`Z = 1.667` 只比临界值 `1.645` 大一点点。对应的 p 值为
> `p = 1 − Φ(1.667) = 1 − 0.9522 = 0.0478`
> 虽然 `0.0478 < 0.05` 因而拒绝 `H₀`，但它**非常接近 0.05**。若某位读者把 α 定为 0.01，则结论立刻反转（`0.0478 > 0.01`，不拒绝）。
> **这是「临界数据」的典型情形**：结论对 α 的选择高度敏感。**科学的做法是报告 p 值而不是只报「显著/不显著」**。

**例 7.9**（题型：χ² 拟合优度检验——离散均匀分布）
掷一颗骰子 120 次，各点数出现的次数如下表。问能否认为这颗骰子是均匀的？（取 α = 0.05）

| 点数 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 实际频数 fᵢ | 18 | 25 | 19 | 22 | 16 | 20 |

**解**：
**第一步——提出假设**：
`H₀`：骰子均匀（每个点数出现的概率都是 1/6）；`H₁`：骰子不均匀。
**第二步——分组**：已分 6 组，`k = 6`，`n = 120`。
**第三步——计算理论频数**：`H₀` 下每个点数的概率 `pᵢ = 1/6`，
`npᵢ = 120 × 1/6 = 20`（**每个点数的理论频数都是 20**）
检验 `npᵢ = 20 ≥ 5` ✓，满足经验规则，无需合并组。
**第四步——计算统计量**：
`χ² = Σ(fᵢ − npᵢ)²/(npᵢ)`
`= [(18−20)² + (25−20)² + (19−20)² + (22−20)² + (16−20)² + (20−20)²]/20`
`= [4 + 25 + 1 + 4 + 16 + 0]/20 = 50/20 = 2.50`
**第五步——确定自由度**：`H₀` 完全指定了分布（概率 1/6 不需估计），故 `r = 0`，
`自由度 = k − r − 1 = 6 − 0 − 1 = 5`
**第六步——判断**：查表 `χ²_{0.05}(5) = 11.071`。因为 `2.50 < 11.071`，**不拒绝 `H₀`**。

**答案**：在 α = 0.05 下不能认为骰子不均匀（数据与「均匀骰子」吻合得相当好）。

> **对比直觉**：第 2 点出现了 25 次，比期望的 20 次多 5 次，看着有点多；但第 5 点只有 16 次，两者大致相抵。**χ² 统计量把所有 6 个偏差按理论频数标准化后加总，只有 2.50**——远小于临界值。这说明**单看某一组的偏差会误导，必须整体衡量**。

**例 7.10**（题型：χ² 拟合优度检验——含参数估计的正态性检验）
某工厂测得 100 个零件的长度数据，将其分成 7 个区间统计频数。用样本算得 `X̄ = 10.02`，`S = 0.13`，并据此算出各区间在正态假设下的理论频数。计算得

`χ² = Σ(fᵢ − npᵢ)²/(npᵢ) = 9.20`

问能否认为零件长度服从正态分布？（取 α = 0.05，已知 `χ²_{0.05}(4) = 9.488`，`χ²_{0.05}(6) = 12.592`，`χ²_{0.05}(5) = 11.071`）

**解**：
**第一步——提出假设**：
`H₀`：零件长度服从正态分布；`H₁`：不服从正态分布。
**第二步——确定自由度**：
区间个数 `k = 7`。
估计的参数个数 `r = 2`（用 `X̄` 估计 `μ`，用 `S²` 估计 `σ²`）。
`自由度 = k − r − 1 = 7 − 2 − 1 = 4`
**第三步——查临界值**：`χ²_{0.05}(4) = 9.488`。拒绝域 `χ² > 9.488`。
**第四步——判断**：`χ² = 9.20 < 9.488`，**不拒绝 `H₀`**。

**答案**：在 α = 0.05 下不能拒绝「零件长度服从正态分布」的假设。

> **自由度是本题的核心考点**：很多同学会误用 `k − 1 = 6`，从而查到 `χ²_{0.05}(6) = 12.592`；也有人误用 `k = 7`。
> **记忆法**：`自由度 = 组数 − 从样本估计的参数个数 − 1`。那个「`−1`」永远存在（来自 `Σpᵢ = 1`）；估计了几个参数就再减几。
>
> **注意 `S` 用哪个**：理论上 χ² 拟合检验中估计 `σ²` 应使用**最大似然估计**（分母 n），但 n = 100 时它与 `S²`（分母 n−1）差别极小（差 1%），实际中常用 `S²` 代替，不影响结论。
>
> **实际意义**：正态性检验是很多统计方法（t 检验、方差分析、回归）的**前提**。若这里拒绝了 `H₀`，就不能直接套用 t 检验，需要考虑数据变换（如取对数）或使用非参数方法（如 Wilcoxon 秩和检验）。R 中对应函数为 `shapiro.test(x)`（Shapiro-Wilk 正态性检验，小样本更灵敏）。

## 易错点提醒

1. **把「想要证明的结论」放在 `H₀`**。
   **错在**：题目问「能否认为平均寿命超过 1000」，却写成 `H₀: μ > 1000`。
   **正确做法**：**要证明的（新的、需要证据的）结论放 `H₁`**，即 `H₁: μ > 1000`，`H₀: μ ≤ 1000`。因为只有「拒绝 `H₀`」才是有力的结论，而拒绝的犯错概率被控制在 α 内。

2. **`H₀` 不含等号**。
   **错在**：写成 `H₀: μ > 1000`。
   **正确做法**：`H₀` **必须含等号**（`=`、`≤`、`≥`），否则检验统计量在 `H₀` 下的分布无法确定（算不出 `μ₀` 的具体值）。正确写法：`H₀: μ ≤ 1000`（取临界值 `μ₀ = 1000`）。

3. **把「不拒绝 `H₀`」说成「接受 `H₀`」或「`H₀` 成立」**。
   **错在**：「检验证明包装机正常」。
   **正确做法**：只能说「**没有足够证据认为包装机不正常**」。不拒绝只是「证据不足」，不是「证明为真」。**「缺乏证据证明有罪」不等于「证明无罪」。**

4. **把 α 解释成「`H₀` 为真的概率」或「结论错误的概率」**。
   **错在**：说「α = 0.05 表示 `H₀` 有 5% 的概率是真的」。
   **正确做法**：α 是 `P(拒绝 H₀ | H₀ 真)`——**在 `H₀` 为真的前提下**犯弃真错误的概率，是**事先设定的**控制水平，不是事后概率。同理 p 值也不是「`H₀` 为真的概率」。

5. **单侧检验用 `z_{α/2}` / `t_{α/2}`**。
   **错在**：右侧检验时查 `t_{0.025}(15) = 2.1315`。
   **正确做法**：**单侧用 `α`**（`t_{0.05}(15) = 1.7531`），**双侧才用 `α/2`**。把 α 全部放在关心的那一侧。

6. **χ² 检验的拒绝域只写右侧**。
   **错在**：双侧 `H₁: σ² ≠ σ₀²` 时只写 `χ² > χ²_{α/2}`。
   **正确做法**：双侧要**两个尾巴都写**：`χ² > χ²_{α/2}(n−1)` **或** `χ² < χ²_{1−α/2}(n−1)`。左端用的是 **`χ²_{1−α/2}`（较小的分位点）**。这与正态、t 的「取绝对值」处理不同，因为 χ² 分布**不对称**。

7. **F 检验时忘记「大比小」或自由度顺序错乱**。
   **错在**：算出 `F = 0.09/0.16 = 0.5625` 后去查 `F_{0.025}(9,10)`，发现表上没有左尾分位点就卡住了。
   **正确做法**：**把较大的样本方差放分子**：`F = S₂²/S₁² = 1.7778`，对应自由度 `(n₂−1, n₁−1) = (10, 9)`，查 `F_{0.025}(10, 9) = 3.96`。**分子分母一交换，两个自由度也跟着交换**。

8. **配对数据误用两独立样本检验**。
   **错在**：把「同一批人用药前后的数据」当成两组独立数据。
   **正确做法**：**先做差值 `Dᵢ = Xᵢ − Yᵢ`，化为单总体均值检验**（`H₀: μ_D = 0`）。配对数据的 `Xᵢ`、`Yᵢ` 不独立，用独立样本公式会把个体差异混入误差，**掩盖真实效应**。

9. **分布拟合检验的自由度写成 k 或 k−1**。
   **错在**：把 7 个区间、估计了 2 个参数的情形写成 `χ²(7)` 或 `χ²(6)`。
   **正确做法**：`自由度 = k − r − 1 = 7 − 2 − 1 = 4`。**估计一个参数就损失一个自由度**，另有一个来自 `Σpᵢ = 1`。

10. **分布拟合检验忘记检查理论频数 `npᵢ ≥ 5`**。
    **错在**：某组 `npᵢ = 1.2` 也照样算 χ²。
    **正确做法**：**理论频数小于 5 的组必须与相邻组合并**，合并后重新数 k 并重算自由度。否则 χ² 统计量的分布不准确，结论不可靠。

11. **χ² 拟合检验用左侧拒绝域**。
    **错在**：找 `χ² < χ²_{1−α}` 作为拒绝域。
    **正确做法**：**拟合检验永远是右侧单侧检验**——`χ²` 越大表示实际频数与理论频数偏离越远，越应拒绝 `H₀`。

12. **总体分布未知时直接用 t 检验**。
    **错在**：数据明显偏态（如收入、房价），n 只有 15，却用 t 检验。
    **正确做法**：t 检验**要求总体正态**（小样本时尤其重要）。总体分布未知时：① 若 n 大（≥30 或 ≥50），用**大样本 Z 检验**（中心极限定理）；② 若 n 小且明显非正态，应做**数据变换**或改用**非参数检验**。

13. **样本量不影响结论的误解**。
    **错在**：以为「`S` 比 `σ₀` 大 20% 就说明变差了」。
    **正确做法**：样本量小的时候，`S` 的抽样波动很大，20% 的偏差可能完全是偶然（例 7.4 中 `χ² = 21.6 < 24.996`，不拒绝）。**样本量越大，同样的偏离才越有说服力**。

14. **事后挑选检验方向**。
    **错在**：先算了一下 `X̄ > μ₀`，就说「这是右侧检验」。
    **正确做法**：**检验方向必须由问题本身决定，且在看数据之前确定**。事后根据数据挑方向会**严重放大第一类错误**（实际 α 可能远超设定值），是典型的学术不端行为（p-hacking）。

## 本章小结

- **假设检验**：先设 `H₀`（含等号，通常是要推翻的）与 `H₁`（想证明的），再用样本判断是否拒绝 `H₀`。
- **三类检验形式**：双侧（`≠`）、右侧（`>`）、左侧（`<`）。**方向由问题决定，不能事后挑**。
- **两类错误**：第一类「**弃真**」（概率 `α`）、第二类「**取伪**」（概率 `β`）。**n 固定时二者不能同时减小**，唯一办法是**增大 n**。
- **α 是事先定的门槛，p 是数据给出的证据强度**。`p < α` ⟺ 拒绝 `H₀`。
- **不拒绝 `H₀` ≠ 接受 `H₀`**。只能说「证据不足」。
- **五步法**：提假设 → 选统计量 → 定拒绝域 → 算观测值 → 作判断。
- **单侧用 `α`，双侧用 `α/2`**（`z_{0.05} = 1.645 < z_{0.025} = 1.96`）。
- **单正态总体检验选择表**：
  - σ 已知检 μ → **Z 检验**，`Z = (X̄−μ₀)/(σ/√n)`；
  - σ 未知检 μ → **t 检验**，`T = (X̄−μ₀)/(S/√n) ~ t(n−1)`；
  - 检 σ² → **χ² 检验**，`χ² = (n−1)S²/σ₀² ~ χ²(n−1)`，**双侧要写两个尾巴**。
- **双正态总体检验选择表**：
  - σ 已知检 μ₁−μ₂ → **Z 检验**；
  - σ₁²=σ₂² 未知检 μ₁−μ₂ → **合并方差 t 检验**，`t(n₁+n₂−2)`；
  - 检 σ₁²/σ₂² → **F 检验**，**大比小**避免查下侧分位点。
- **配对数据必须化为单总体均值检验**（先做差），否则会掩盖真实差异。
- **总体分布未知 + 大样本** → 用中心极限定理做 **Z 检验**（近似）。
- **χ² 拟合优度检验**：`χ² = Σ(fᵢ−npᵢ)²/(npᵢ)`，自由度 `k − r − 1`，**永远右侧拒绝**，要求每组 `npᵢ ≥ 5`。
- **假设检验与区间估计等价**：`μ₀` 落在 `μ` 的 `1−α` 置信区间内 ⟺ 不拒绝 `H₀: μ = μ₀`。
- **一句话记住本章**：**假设检验就是「把想推翻的放进被告席（`H₀`）、用 α 控制冤枉的概率、看样本证据够不够把它定罪」；技术上只需认准两条——「均值用 Z/t、方差用 χ²/F」和「单侧查 α、双侧查 α/2」。**

## 自测题

1. 某法庭审理案件，`H₀`：被告无罪；`H₁`：被告有罪。说明第一类错误与第二类错误的具体含义，并解释为什么刑事审判要求「证据确凿」。
2. 设总体 `X ~ N(μ, 4)`，`n = 16`，`X̄ = 5.4`。检验 `H₀: μ = 5` vs `H₁: μ ≠ 5`（α = 0.05，`z_{0.025} = 1.96`）。
3. 设总体 `X ~ N(μ, σ²)`，σ 未知，`n = 9`，`X̄ = 5.4`，`S = 0.8`。检验 `H₀: μ = 5` vs `H₁: μ ≠ 5`（α = 0.05，`t_{0.025}(8) = 2.3060`）。与第 2 题比较结论。
4. 设总体 `X ~ N(μ, σ²)`，`n = 10`，`S² = 0.16`。检验 `H₀: σ² = 0.09` vs `H₁: σ² ≠ 0.09`（α = 0.05，`χ²_{0.025}(9) = 19.023`，`χ²_{0.975}(9) = 2.700`）。
5. 某厂产品抗压强度 `X ~ N(μ, σ²)`，要求 `μ` 不低于 500。抽 25 件，`X̄ = 495`，`S = 12`。检验 `H₀: μ ≥ 500` vs `H₁: μ < 500`（α = 0.05，`t_{0.05}(24) = 1.7109`）。
6. 两独立正态总体方差相等未知。`n₁ = 12`，`X̄ = 30.2`，`S₁² = 1.6`；`n₂ = 14`，`Ȳ = 28.9`，`S₂² = 2.1`。检验 `H₀: μ₁ = μ₂` vs `H₁: μ₁ ≠ μ₂`（α = 0.05，`t_{0.025}(24) = 2.0639`）。
7. 两独立正态总体。`n₁ = 11`，`S₁² = 3.2`；`n₂ = 9`，`S₂² = 1.5`。检验 `H₀: σ₁² = σ₂²` vs `H₁: σ₁² ≠ σ₂²`（α = 0.05，`F_{0.025}(10, 8) = 4.30`）。
8. 掷一枚硬币 100 次，正面出现 58 次。用大样本 Z 检验判断硬币是否均匀（α = 0.05，`z_{0.025} = 1.96`）。提示：这是 0-1 分布的均值检验，`H₀: p = 0.5`。
9. 某机器一天内发生故障的次数记录为：0 次 36 天，1 次 40 天，2 次 18 天，3 次及以上 6 天，共 100 天。检验故障次数是否服从 `P(λ)` 分布，`λ` 由样本估计（`λ̂ = X̄ = 0.94`）。已知理论概率为 `P(0) = 0.3906`、`P(1) = 0.3672`、`P(2) = 0.1726`、`P(≥3) = 0.0696`。取 α = 0.05，`χ²_{0.05}(2) = 5.991`。
10. 某检验 `H₀: μ = 100` vs `H₁: μ > 100`，已知 `σ = 15`，`n = 25`，α = 0.05。若真实 `μ = 108`，求第二类错误的概率 β，以及检验的功效（power）。

### 自测题答案

1. **第一类错误（弃真）**：被告**实际无罪**却判其**有罪**——即**冤狱**。**第二类错误（取伪）**：被告**实际有罪**却判其**无罪**——即**放纵罪犯**。
   「证据确凿」要求把 **α（冤狱概率）压得非常低**。因为冤狱的后果（错杀无辜、不可挽回）远重于放纵（可继续追诉），社会选择「宁可放过一千，不可错杀一个」，即**疑罪从无**。这正是把 α 设为极小值的现实理由。

2. `σ = 2`，`n = 16`，`σ/√n = 2/4 = 0.5`。
   `Z = (5.4 − 5)/0.5 = 0.4/0.5 = 0.800`
   `|Z| = 0.800 < 1.96`，**不拒绝 `H₀`**。不能认为 μ 与 5 有显著差异。

3. `S/√n = 0.8/3 = 0.26667`
   `T = (5.4 − 5)/0.26667 = 0.4/0.26667 = 1.500`
   `|T| = 1.500 < 2.3060`，**不拒绝 `H₀`**。
   **与第 2 题比较**：两题样本均值与假设值相同（差 0.4），但第 2 题 σ 已知（`Z = 0.8`），第 3 题 σ 未知（`T = 1.5`）。第 3 题的统计量值更大（因为 `S = 0.8 < σ = 2`，标准误更小），但临界值也更大（2.3060 > 1.96），结论相同——**都不拒绝**。这说明**临界值与统计量值必须同向比较，不能只看其一**。

4. `n = 10`，`n − 1 = 9`，`σ₀² = 0.09`。
   `χ² = (n−1)S²/σ₀² = 9 × 0.16/0.09 = 1.44/0.09 = 16.00`
   双侧拒绝域：`χ² > 19.023` 或 `χ² < 2.700`。
   因为 `2.700 < 16.00 < 19.023`，**不拒绝 `H₀`**。不能认为方差与 0.09 有显著差异。

5. 左侧检验，`H₁: μ < 500`。拒绝域 `T < −t_{0.05}(24) = −1.7109`。
   `S/√n = 12/√25 = 12/5 = 2.4`
   `T = (495 − 500)/2.4 = −5/2.4 = −2.0833`
   因为 `−2.0833 < −1.7109`，**落入拒绝域，拒绝 `H₀`**。
   可以认为该厂产品的平均抗压强度**显著低于 500**（不合格）。

6. `S_w² = [(12−1)(1.6) + (14−1)(2.1)]/(12+14−2) = (17.6 + 27.3)/24 = 44.9/24 = 1.87083`
   `S_w = √1.87083 = 1.36778`
   `√(1/12 + 1/14) = √(0.083333 + 0.071429) = √0.154762 = 0.393398`
   `S_w × 0.393398 = 1.36778 × 0.393398 = 0.538052`
   `T = (30.2 − 28.9)/0.538052 = 1.3/0.538052 = 2.4161`
   因为 `|T| = 2.4161 > 2.0639`，**落入拒绝域，拒绝 `H₀`**。
   可以认为两总体均值有**显著差异**（`μ₁ > μ₂`）。

7. `S₁² = 3.2 > S₂² = 1.5`，故 `F = S₁²/S₂² = 3.2/1.5 = 2.1333`，自由度 `(11−1, 9−1) = (10, 8)`。
   临界值 `F_{0.025}(10, 8) = 4.30`。
   因为 `2.1333 < 4.30`，**不拒绝 `H₀`**。不能认为两总体方差有显著差异。

8. 0-1 分布，`X̄ = 58/100 = 0.58`，`H₀: p = 0.5`。
   在 `H₀` 下 `D(X) = p(1−p) = 0.5 × 0.5 = 0.25`，`σ = 0.5`，`σ/√n = 0.5/10 = 0.05`。
   `Z = (0.58 − 0.5)/0.05 = 0.08/0.05 = 1.600`
   因为 `|Z| = 1.600 < 1.96`，**不拒绝 `H₀`**。不能认为硬币不均匀。
   （注：若用样本标准差 `S = √(0.58×0.42) = √0.2436 = 0.49356`，得 `Z = 1.621`，结论不变。）

9. `n = 100`，理论频数：`np₀ = 39.06`，`np₁ = 36.72`，`np₂ = 17.26`，`np_{≥3} = 6.96`。
   全部 ≥ 5 ✓。`k = 4`（未合并）。
   实际频数：`f = 36, 40, 18, 6`。
   `χ² = (36−39.06)²/39.06 + (40−36.72)²/36.72 + (18−17.26)²/17.26 + (6−6.96)²/6.96`
   `= 9.3636/39.06 + 10.7584/36.72 + 0.5476/17.26 + 0.9216/6.96`
   `= 0.23971 + 0.29298 + 0.03173 + 0.13241 = 0.69683`
   自由度 `= k − r − 1 = 4 − 1 − 1 = 2`（估计了 1 个参数 `λ`）。
   临界值 `χ²_{0.05}(2) = 5.991`。因为 `0.69683 < 5.991`，**不拒绝 `H₀`**。
   可以认为故障次数服从泊松分布。

10. 右侧检验，拒绝域 `Z > 1.645`，即
    `(X̄ − 100)/(15/5) > 1.645` ⟹ `X̄ − 100 > 1.645 × 3 = 4.935` ⟹ `X̄ > 104.935`
    **接受域**为 `X̄ ≤ 104.935`。
    若真实 `μ = 108`，则 `X̄ ~ N(108, 9)`，`σ(X̄) = 3`。
    `β = P(不拒绝 H₀ | μ = 108) = P(X̄ ≤ 104.935 | μ = 108)`
    `= Φ((104.935 − 108)/3) = Φ(−3.065/3) = Φ(−1.0217)`
    查表 `Φ(1.02) = 0.8461`，`Φ(1.0217) ≈ 0.8466`，故
    `β ≈ 1 − 0.8466 = 0.1534`
    **功效 = 1 − β = 0.8466**。
    即：当真实均值确实是 108 时，这个检验有约 **84.66%** 的把握正确拒绝 `H₀`。
