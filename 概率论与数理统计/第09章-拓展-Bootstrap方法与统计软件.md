## 9.1 Bootstrap 方法

### 9.1.1 问题的提出

第 6、7 章的区间估计与假设检验，全都依赖**统计量的精确分布**：

- `(X̄ − μ)/(σ/√n) ~ N(0,1)` —— 要求总体正态；
- `(X̄ − μ)/(S/√n) ~ t(n−1)` —— 要求总体正态；
- `(n−1)S²/σ² ~ χ²(n−1)` —— 要求总体正态。

**但实际数据往往不满足这些假定**：收入、房价、网页停留时间都是**严重右偏**的；有些统计量（如中位数、相关系数、`R²`）的分布**根本没有解析表达式**。

**1979 年，Bradley Efron 提出了 Bootstrap（自助法）**：既然没法解析求出抽样分布，那就用**计算机模拟**出来。

### 9.1.2 核心思想

**关键洞察**：**样本的经验分布函数 `F_n(x)` 是总体分布 `F(x)` 的一致估计**（格里汶科定理，见第 5 章 5.1.3）。

既然 `F_n` 已经很接近 `F`，那么：

> **「从 `F` 中抽样」的统计量分布 ≈ 「从 `F_n` 中抽样」的统计量分布。**

而**「从 `F_n` 中抽样」在计算机上极其容易实现**——因为 `F_n` 是一个**只在样本点 `x₁, …, xₙ` 上各放 1/n 概率的离散分布**，从它抽样就是**从原始样本中有放回地等概率抽取**。

**Bootstrap 重抽样的操作流程**：

① 手上有原始样本 `x = (x₁, x₂, …, xₙ)`；
② 从 `x` 中**有放回**地随机抽取 n 个值，得到一个 **Bootstrap 样本** `x* = (x*₁, …, x*ₙ)`；
③ 对这个 Bootstrap 样本算出感兴趣的统计量 `θ̂* = θ̂(x*)`；
④ **重复②③共 B 次**（通常 `B = 1000` 或 `10000`），得到 `θ̂*₁, θ̂*₂, …, θ̂*_B`；
⑤ 用这 B 个值的**经验分布**近似 `θ̂` 的抽样分布。

> **重点——「有放回」是全部关键**：有放回意味着每个原始观测值可能被抽到**多次**，也可能**一次都没抽到**。
> - 一个 Bootstrap 样本中，平均约有 `1 − 1/e ≈ 63.2%` 的原始观测值会出现**至少一次**；
> - 约 `1/e ≈ 36.8%` 的原始观测值**完全没被抽到**（这些叫 **out-of-bag 样本**，正是随机森林（Random Forest）中「袋外误差估计」的来源）。
>
> **如果没有放回**，抽出来的就永远是原来那 n 个数的一个排列，`x̄*` 恒等于 `x̄`，**方差为 0，什么都估不出来**。

> **名字的由来**：Bootstrap 本意是「靴子后跟的提带」——借自英语谚语 "pull oneself up by one's own bootstraps"（**靠自己的鞋带把自己拉起来**），寓意**不需要外部信息，仅靠样本自身就能解决问题**。中文译作「自助法」「自举法」。

### 9.1.3 Bootstrap 标准误

**Bootstrap 标准误（Bootstrap Standard Error）**：

`SE_boot = √[ (1/(B − 1)) · Σᵦ₌₁ᴮ ( θ̂*_b − θ̄* )² ]`

其中 `θ̄* = (1/B) Σᵦ θ̂*_b` 是 B 个 Bootstrap 统计量的均值。

**它估计的是什么**：`θ̂` 这个估计量的**真实标准误** `SE(θ̂)`（即 `θ̂` 的抽样分布的标准差）。

**与经典公式的对比**：

| 估计目标 | 经典公式（要求总体正态） | Bootstrap |
|---|---|---|
| `X̄` 的标准误 | `SE = S/√n` | `SE_boot = sd(θ̂*₁, …, θ̂*_B)` |
| 中位数的标准误 | **无解析公式** | `SE_boot` 直接算 |
| 相关系数 `r` 的标准误 | **近似公式复杂** | `SE_boot` 直接算 |
| `R²` 的标准误 | **无解析公式** | `SE_boot` 直接算 |

> **Bootstrap 的最大价值**：**它能给任何统计量算标准误，不需要解析分布**。中位数、相关系数、`R²`、Gini 系数、甚至你自己定义的任意统计量，Bootstrap 一视同仁。这是它成为现代统计与机器学习基石的原因。

### 9.1.4 Bootstrap 置信区间

**方法一：百分位法（Percentile Method）**——最简单、最常用

把 B 个 `θ̂*_b` 从小到大排序，取第 `⌊B·α/2⌋` 个和第 `⌊B·(1−α/2)⌋` 个作为置信区间的下、上端点。

即：**`θ` 的 `1−α` 置信区间 ≈ `(θ̂*_{[Bα/2]}, θ̂*_{[B(1−α/2)]})`**（Bootstrap 分布的 `α/2` 与 `1−α/2` 分位点）。

> **例**：`B = 1000`，`α = 0.05`，则取排序后的第 25 个和第 975 个值作为区间端点。

**方法二：基本 Bootstrap 法（Basic/Reverse Percentile）**

`( 2θ̂ − θ̂*_{[B(1−α/2)]} ,　2θ̂ − θ̂*_{[Bα/2]} )`

**方法三：Bootstrap-t 法（学生化法）**

对每个 Bootstrap 样本再算一个 t 型统计量 `(θ̂* − θ̂)/SE*`，用它的分位点修正。**精度最高但计算量最大**。

> **三种方法的比较**：样本量较大时三者结果接近；**样本量小或分布偏斜时，百分位法可能有偏，Bootstrap-t 法更可靠**。实践中 **BCa 法（Bias-Corrected and accelerated）** 是最推荐的（R 的 `boot.ci(type="bca")`）。

### 9.1.5 适用条件与局限

**Bootstrap 的两条基本假定**：

1. **样本是总体的代表性样本**（即样本独立同分布地来自总体）。若样本本身有偏（如只调查了网民收入），Bootstrap **无法救回来**——它只能反映「样本里的信息」，垃圾进、垃圾出。
2. **观测值之间相互独立**。**时间序列数据不满足这一条**（相邻时刻相关），直接 Bootstrap 会**严重低估标准误**。此时需用**块 Bootstrap（Block Bootstrap）**或**平稳 Bootstrap**。

**Bootstrap 失效的情形**：

| 情形 | 问题 | 对策 |
|---|---|---|
| **样本量过小**（n < 20） | 经验分布严重失真，重抽样样本更失真 | 增大样本，或用参数化 Bootstrap |
| **存在极端离群值** | 有放回抽样可能反复抽到离群值，方差估计虚高 | 先做异常值诊断，或用稳健统计量 |
| **统计量依赖于极值**（如最大值 `max(Xᵢ)`） | Bootstrap 分布会系统性偏低 | 改用极值理论 |
| **时间序列 / 空间相关数据** | 破坏独立性假定 | 块 Bootstrap |
| **待估参数在边界上** | 分布不连续 | 特殊处理 |

## 9.2 统计软件：R 与 Python

### 9.2.1 R 的 `d/p/q/r` 四前缀体系（必背）

R 对每个概率分布提供**四个函数**，前缀含义固定：

| 前缀 | 含义 | 输入 | 输出 | 英文 |
|---|---|---|---|---|
| **`d`** | **密度 / 分布律** | `x`（取值） | `f(x)` 或 `P(X = x)` | **d**ensity |
| **`p`** | **分布函数** | `q`（分位点） | `P(X ≤ q)` | **p**robability |
| **`q`** | **分位点** | `p`（概率） | 满足 `P(X ≤ x) = p` 的 `x` | **q**uantile |
| **`r`** | **随机数** | `n`（个数） | n 个随机数 | **r**andom |

**分布名后缀（常用）**：

| 分布 | 后缀 | 示例 |
|---|---|---|
| 正态 | `norm` | `dnorm(x, mean, sd)` |
| 二项 | `binom` | `dbinom(x, size, prob)` |
| 泊松 | `pois` | `dpois(x, lambda)` |
| 指数 | `exp` | `dexp(x, rate)` |
| 均匀 | `unif` | `dunif(x, min, max)` |
| t | `t` | `dt(x, df)` |
| 卡方 | `chisq` | `dchisq(x, df)` |
| F | `f` | `df(x, df1, df2)` |

**典型用法**：

```r
# ① 概率计算：X ~ N(10, 4)，求 P(X > 12)
1 - pnorm(12, mean = 10, sd = 2)        # sd 是标准差，不是方差！
# ② 分位点：求 z_{0.025}
qnorm(0.975)                             # 1.959964
# ③ 分布律：X ~ B(10, 0.3)，求 P(X = 3)
dbinom(3, size = 10, prob = 0.3)         # 0.2668279
# ④ 随机数：生成 1000 个 N(0,1) 并求均值
mean(rnorm(1000))
```

> **R 的最大陷阱**：`norm` 系列函数的 `sd` 参数是**标准差 `σ`**，而 `dnorm(x, mean, sd)` 的默认值是 `mean = 0, sd = 1`。**很多人误把方差传进去**（如 `sd = 4` 当成 `σ² = 4`），结果全错。**记住：R 里一律用标准差。**

### 9.2.2 R 在数理统计中的核心函数

| 任务 | R 函数 | 说明 |
|---|---|---|
| 单样本均值检验 | `t.test(x, mu = 1000, alternative = "greater")` | σ 未知的 t 检验；`alternative` 取 `"two.sided"` / `"greater"` / `"less"` |
| 两样本均值检验 | `t.test(x, y, var.equal = TRUE)` | **`var.equal = TRUE` 才是合并方差 t 检验**；默认 `FALSE` 是 Welch 检验 |
| 配对检验 | `t.test(x, y, paired = TRUE)` | 等价于 `t.test(x - y)` |
| 方差齐性检验 | `var.test(x, y)` | **F 检验** |
| 单方差检验 | `sigma.test`（`TeachingDemos` 包）或手算 `χ²` | 标准 R 无内置 |
| 方差分析（单因素） | `fit <- aov(y ~ A, data = df); summary(fit)` | 输出方差分析表 |
| 多重比较 | `TukeyHSD(fit)` | Tukey HSD |
| 方差分析（双因素含交互） | `aov(y ~ A * B, data = df)` | `*` 表示含交互项 |
| 一元/多元线性回归 | `fit <- lm(y ~ x1 + x2, data = df); summary(fit)` | 输出系数表、`R²`、F 值 |
| 预测 | `predict(fit, newdata, interval = "prediction")` | `"confidence"` 是均值区间 |
| 正态性检验 | `shapiro.test(x)` | Shapiro-Wilk 检验 |
| 分布拟合检验 | `chisq.test(table(x))` | χ² 拟合优度 |
| Bootstrap | `boot` 包：`boot(data, statistic, R = 1000)` | 通用 Bootstrap 框架 |
| 相关性检验 | `cor.test(x, y)` | Pearson / Spearman / Kendall |

**完整示例（对应第7章例 7.3）**：

```r
x <- c(1068, 972, 1056, 984, 1040, 1000,
       1060, 1060, 1060, 1060, 1060,
       980, 980, 980, 980, 980)          # 16 只元件寿命
# （这组数据是特意构造的，使 X̄ = 1020、S = 40，与第 7 章例 7.3 的前提完全对应）
t.test(x, mu = 1000, alternative = "greater")
# t = 2, df = 15, p-value = 0.03197  →  p < 0.05，拒绝 H₀，平均寿命显著超过 1000
```

**手工 Bootstrap 示例（对应本章 9.1 节）**：

```r
set.seed(123)                                  # 固定随机种子，保证结果可复现
x   <- c(5, 7, 8, 6, 9)
B   <- 1000
boot_mean <- replicate(B, mean(sample(x, length(x), replace = TRUE)))
sd(boot_mean)                                   # Bootstrap 标准误
quantile(boot_mean, c(0.025, 0.975))            # 百分位法 95% 置信区间
```

> **`set.seed()` 是必写的**：Bootstrap 依赖随机数，**不设种子每次结果都不同，别人无法复现你的结论**。这是科研可重复性的基本要求。

### 9.2.3 Python 对应工具

| 库 | 用途 | 关键函数 |
|---|---|---|
| **`numpy`** | 数值计算、随机数 | `np.random.normal`、`np.random.choice(..., replace=True)` |
| **`scipy.stats`** | 概率分布与统计检验 | `norm.pdf/cdf/ppf/rvs`、`t.ppf`、`chi2.ppf`、`f.ppf` |

**Python 中的 `d/p/q/r` 对应关系**：

| R | Python (`scipy.stats.norm`) |
|---|---|
| `dnorm(x, m, s)` | `stats.norm.pdf(x, m, s)` |
| `pnorm(q, m, s)` | `stats.norm.cdf(q, m, s)` |
| `qnorm(p, m, s)` | `stats.norm.ppf(p, m, s)` |
| `rnorm(n, m, s)` | `stats.norm.rvs(m, s, size=n)` |

**Python 手工 Bootstrap**：

```python
import numpy as np
rng = np.random.default_rng(42)
x = np.array([5, 7, 8, 6, 9])
boot_mean = np.array([rng.choice(x, size=len(x), replace=True).mean()
                      for _ in range(1000)])
boot_mean.std(ddof=1)                              # Bootstrap 标准误
np.quantile(boot_mean, [0.025, 0.975])             # 百分位法 95% 置信区间
```

> **`ddof=1` 的坑**：`numpy` 的 `.std()` 默认 `ddof=0`（分母 n），而 R 的 `sd()` 默认分母 `n−1`。**算标准误时必须显式传 `ddof=1`**，否则结果会系统性偏小。这正是第 5 章「`n−1` vs `n`」的实战体现。

## 典型例题

**例 9.1**（题型：Bootstrap 标准误与置信区间的完整计算）
设从某总体中抽取 5 个观测值：`5, 7, 8, 6, 9`。用 Bootstrap 法（说明流程）估计样本均值 `X̄` 的标准误。已知原始样本的均值为 7，样本标准差为 `s = 1.5811`。

**解**：
**① 经典公式的结果（用于对照）**：
`SE = s/√n = 1.5811/√5 = 1.5811/2.23607 = 0.70711`

**② Bootstrap 流程（描述）**：
- **第 1 次**：从 `{5, 7, 8, 6, 9}` 中有放回抽 5 个，例如得到 `{7, 5, 7, 9, 8}`，算均值 `θ̂*₁ = (7+5+7+9+8)/5 = 36/5 = 7.2`
- **第 2 次**：再抽 5 个，例如 `{9, 8, 8, 6, 5}`，均值 `θ̂*₂ = 36/5 = 7.2`
- **第 3 次**：例如 `{5, 6, 7, 8, 9}`，均值 `θ̂*₃ = 35/5 = 7.0`
- ……
- **重复 B = 1000 次**，得到 `θ̂*₁, …, θ̂*₁₀₀₀`

**③ Bootstrap 标准误**：
`SE_boot = √[ (1/(B−1)) Σᵦ (θ̂*_b − θ̄*)² ]`
其中 `θ̄* = (1/1000) Σᵦ θ̂*_b`。

**④ 数值示例（假设 B = 5 次重抽样得到 7.2, 7.2, 7.0, 6.8, 6.8，便于手算演示）**：
`θ̄* = (7.2 + 7.2 + 7.0 + 6.8 + 6.8)/5 = 35.0/5 = 7.0`
`Σ(θ̂*_b − θ̄*)² = 0.2² + 0.2² + 0² + (−0.2)² + (−0.2)² = 0.04 + 0.04 + 0 + 0.04 + 0.04 = 0.16`
`SE_boot = √(0.16/4) = √0.04 = 0.2000`

（**注意**：这个数值只是 5 次重抽样的演示，样本太少不可靠。实际 `B = 1000` 时 `SE_boot` 会接近 **0.6325**——注意**不是**上面经典公式的 0.7071，原因见下。）

**答案**：经典公式给出 `SE = 0.7071`；Bootstrap 用 1000 次重抽样的标准差来估计它。

> **为什么两者应该接近**：本例总体假定为正态时，`X̄` 的精确标准误就是 `σ/√n`，用 `s` 代替 `σ` 得 0.7071。Bootstrap **不假定正态**，它直接用样本自身的重抽样分布来估计。**当总体确实正态、且 n 较大时**，两者应当接近——这正是检验 Bootstrap 程序是否写对的好方法。
>
> **★ 为什么 n 小时两者不相等**：Bootstrap 标准误的极限是 `σ̂ₙ/√n`，`σ̂ₙ` 用**分母 n** 的样本标准差；而经典公式用的是**分母 n−1** 的 `s`。两者相差一个 `√((n−1)/n)` 的因子——本例 n = 5 时是 `√(4/5) ≈ 0.894`，所以 `0.7071 × 0.894 = 0.6325`。**只有当 n 很大时这个因子才趋于 1，两者才基本一致**；n 小时拿两者对比会误判「程序写错了」。
>
> **`B−1` 而不是 `B`**：Bootstrap 标准误是「B 个数的样本标准差」，故分母用 `B − 1`。这与第 5 章样本方差用 `n−1` 完全同理。

**例 9.2**（题型：Bootstrap 百分位法置信区间）
承例 9.1。设 B = 1000 次重抽样得到的 1000 个 Bootstrap 均值已排序，其中第 25 个为 `6.85`，第 975 个为 `7.15`。求 `μ` 的 Bootstrap 95% 百分位法置信区间。

**解**：
**① 确定分位点位置**：
`α = 0.05`，`α/2 = 0.025`，`1 − α/2 = 0.975`
`B·α/2 = 1000 × 0.025 = 25`
`B·(1 − α/2) = 1000 × 0.975 = 975`

**② 取排序后的第 25 个和第 975 个值**：
`θ̂*_{[25]} = 6.85`，`θ̂*_{[975]} = 7.15`

**③ 写出区间**：
`μ ∈ (6.85, 7.15)`

**答案**：Bootstrap 95% 百分位法置信区间为 **(6.85, 7.15)**。

> **与经典 t 区间的对照**：用第 6 章公式，`X̄ ± t_{0.025}(4)·s/√n = 7 ± 2.7764 × 0.70711 = 7 ± 1.9632 = (5.037, 8.963)`。
> **Bootstrap 区间 (6.85, 7.15) 窄得多**！这不是 Bootstrap 更精确，而是**题中给的「第 25 个是 6.85、第 975 个是 7.15」这组数字并非真实重抽样结果**——在 n = 5 这样的小样本下，Bootstrap 分布同样会很宽（因为单个观测值被重复抽到会显著拉动均值）。
> **教学要点**：**n = 5 时 Bootstrap 完全不可靠**（9.1.5 节的第一条失效情形）。Bootstrap 一般要求 **n ≥ 20，最好 n ≥ 50**。

**例 9.3**（题型：R / Python 概率计算）
某元件寿命 `X ~ N(1000, 100²)`（单位：小时）。
① 用 R 写出求 `P(X > 1200)` 的代码；
② 用 R 写出求 `P(900 < X < 1100)` 的代码；
③ 用 R 求 `x` 使 `P(X > x) = 0.05`；
④ 用 Python (`scipy.stats`) 完成①。

**解**：
**① `P(X > 1200)`**：
```r
1 - pnorm(1200, mean = 1000, sd = 100)
```
或等价地（利用对称性）
```r
pnorm(1200, mean = 1000, sd = 100, lower.tail = FALSE)
```
手算验证：`Z = (1200 − 1000)/100 = 2`，`P = 1 − Φ(2) = 1 − 0.9772 = 0.0228`

**② `P(900 < X < 1100)`**：
```r
pnorm(1100, mean = 1000, sd = 100) - pnorm(900, mean = 1000, sd = 100)
```
手算验证：`P(−1 < Z < 1) = 2Φ(1) − 1 = 2 × 0.8413 − 1 = 0.6826`

**③ 求上侧 0.05 分位点**：
```r
qnorm(0.95, mean = 1000, sd = 100)
```
手算验证：`z_{0.05} = 1.645`，`x = 1000 + 1.645 × 100 = 1164.5`
（**注意 `qnorm` 的输入是「左侧累积概率」**，所以上侧 0.05 对应 `qnorm(0.95)`，不是 `qnorm(0.05)`。这是最常犯的错。）

**④ Python**：
```python
from scipy import stats
print(1 - stats.norm.cdf(1200, loc=1000, scale=100))
# 或
print(stats.norm.sf(1200, loc=1000, scale=100))   # sf = survival function = 1 - cdf
```

**答案**：① `1 - pnorm(1200, 1000, 100)` = 0.0228；② 0.6826；③ 1164.5；④ 见上。

> **R 的致命陷阱再强调一次**：`pnorm(1200, mean = 1000, sd = 100)` 中 `sd` 是**标准差 100**，不是方差 10000。**若误写 `sd = 10000`，结果会完全错误**（`1 − Φ(0.02) ≈ 0.492`）。

**例 9.4**（题型：用 R 完成第 7 章的假设检验）
某厂元件寿命要求 `μ > 1000` 小时。抽 16 只，数据录入 R 向量 `x`，测得 `X̄ = 1020`，`S = 40`。写出完整的 R 分析代码（α = 0.05）。

**解**：
```r
x <- c(1068, 972, 1056, 984, 1040, 1000,
       1060, 1060, 1060, 1060, 1060,
       980, 980, 980, 980, 980)   # 同上：特意构造，使 X̄ = 1020、S = 40

# ① 描述性统计
mean(x)      # 1020
sd(x)        # 40
length(x)    # 16

# ② 正态性检验（t 检验的前提）
shapiro.test(x)          # p > 0.05 则不能拒绝正态性假定

# ③ 单侧 t 检验：H₀: μ ≤ 1000  vs  H₁: μ > 1000
t.test(x, mu = 1000, alternative = "greater")

# 输出（实测）：
#   t = 2, df = 15, p-value = 0.03197
#   alternative hypothesis: true mean is greater than 1000
#   95 percent confidence interval:  1002.4695  Inf
#   sample estimates: mean of x = 1020
```

**结果解读**：
- `t = 2`，与第 7 章例 7.3 手算结果 `T = 2.000` **完全一致**；
- `df = 15 = n − 1`，与手算一致；
- `p-value = 0.03197 < 0.05`，**拒绝 `H₀`**，与手算结论一致；
- `95 percent confidence interval: 1002.47 Inf` 是**单侧置信下限**（下限 1002.47，上限为正无穷），对应第 6 章 6.3.3 节的单侧置信区间。

**答案**：见上。核心一行是 `t.test(x, mu = 1000, alternative = "greater")`。

> **`alternative` 参数的三个取值**：
> - `"two.sided"`（默认）→ 双侧检验 `H₁: μ ≠ μ₀`；
> - `"greater"` → 右侧检验 `H₁: μ > μ₀`；
> - `"less"` → 左侧检验 `H₁: μ < μ₀`。
> **务必与第 7 章「把想证明的放 `H₁`」的原则对应起来**，写错这一步结论会完全反转。

**例 9.5**（题型：用 R 完成方差分析与回归，对应第 8 章）
某试验数据存于数据框 `df`，列为 `y`（收率）、`A`（温度，3 个水平）、`x`（含碳量，连续）。
① 写出单因素方差分析的 R 代码并解读输出；
② 写出双因素方差分析（含交互作用）的代码；
③ 写出从含碳量预测收率的回归代码，并求 `x = 0.60` 时的预测区间。

**解**：
**① 单因素方差分析**：
```r
fit_aov <- aov(y ~ A, data = df)
summary(fit_aov)
```
典型输出：
```
            Df Sum Sq Mean Sq F value   Pr(>F)    
A            2 132.17   66.08   12.20 0.002737 ** 
Residuals    9  48.75    5.42                     
```
**逐列解读**（与第 8 章方差分析表一一对应）：

| R 输出列 | 对应教材符号 |
|---|---|
| `Df`（因素行） | `df_A = k − 1 = 2` |
| `Df`（Residuals 行） | `df_E = n − k = 9` |
| `Sum Sq`（因素行） | `SA = 132.17` |
| `Sum Sq`（Residuals 行） | `SE = 48.75` |
| `Mean Sq` | `MS_A = 66.08`、`MS_E = 5.42` |
| `F value` | `F = 12.20` |
| `Pr(>F)` | **p 值 = 0.002737** |

`p = 0.002737 < 0.05`，**拒绝 `H₀`**，温度对收率有显著影响（与第 8 章例 8.1 的手算结论完全一致）。
后续做多重比较：`TukeyHSD(fit_aov)`

**② 双因素方差分析（含交互作用）**：
```r
summary(aov(y ~ A * B, data = df))     # A * B 等价于 A + B + A:B
```
若只想看主效应（对应无重复试验）：
```r
summary(aov(y ~ A + B, data = df))
```

**③ 一元线性回归与预测**：
```r
fit_lm <- lm(y ~ x, data = df)
summary(fit_lm)
# 输出：Estimate 列给出 (Intercept) = 36.9273, x = 53.4545
#       Multiple R-squared: 0.9987,  F-statistic: 6170 on 1 and 8 DF

# 点预测 + 均值置信区间 + 个体预测区间
predict(fit_lm, newdata = data.frame(x = 0.60),
        interval = "prediction", level = 0.95)
# 输出  fit      lwr      upr
#      69.00    68.14    69.86

predict(fit_lm, newdata = data.frame(x = 0.60),
        interval = "confidence", level = 0.95)
# 输出  fit      lwr      upr
#      69.00    68.51    69.49
```

**答案**：见上。

> **`interval` 参数是第 8 章易错点 10 的直接落实**：
> - `interval = "prediction"` → **个体预测区间**（宽，(68.14, 69.86)）；
> - `interval = "confidence"` → **均值置信区间**（窄，(68.51, 69.49)）。
> **记法**：`confidence` 里的 "conf" 对应「信心放在**平均值**上」；`prediction` 是「预测**下一个具体值**」。**很多人在论文里误用 `"confidence"` 去报「单个样本的预测范围」，这是实质性错误。**
>
> **另外**：`predict` 在 `newdata` 超出原始 `x` 范围时会给出警告（外推警告），对应第 8 章易错点 11。

**例 9.6**（题型：Bootstrap 用于无法解析求标准误的统计量）
某研究者想估计「某城市家庭收入**中位数**」的 95% 置信区间。抽取 200 户，得到收入数据（严重右偏）。说明为什么必须用 Bootstrap，并写出完整的分析流程（R 代码）。

**解**：
**为什么必须用 Bootstrap**：
① **中位数的抽样分布没有简单解析形式**——它涉及次序统计量，其分布是复杂的（只有在总体连续且已知密度时可近似用 `1/(4nf(m)²)`，其中 `f(m)` 是中位数处的密度，而 `f(m)` 本身未知）；
② **收入数据严重右偏**，`X̄` 的正态近似很差，而中位数本身就是为了**抵抗偏态**才被选用的；
③ **Bootstrap 不需要任何分布假定**，直接给出中位数的抽样分布。

**完整流程（R 代码）**：
```r
set.seed(2024)
income <- read.csv("income.csv")$income      # 200 户收入

# ① 定义统计量函数（boot 包要求第一个参数是数据，第二个是索引）
med <- function(data, idx) median(data[idx])

# ② 执行 Bootstrap，B = 2000 次
library(boot)
b <- boot(income, med, R = 2000)

# ③ 查看结果
b$t0                    # 原始样本的中位数
sd(b$t)                 # Bootstrap 标准误
boot.ci(b, type = c("perc", "bca"))   # 百分位法与 BCa 法置信区间
```

**结果解读框架**：
- `b$t0`：点估计（原始样本中位数）；
- `sd(b$t)`：Bootstrap 标准误，可直接写进论文「中位数为 X（SE = Y）」；
- `boot.ci(..., type="perc")`：百分位法区间；
- `boot.ci(..., type="bca")`：BCa 法区间，**偏态数据下更可靠，推荐报告**。

**答案**：因为中位数没有简单解析分布且数据严重右偏，必须用 Bootstrap；流程见上。

> **为什么中位数特别适合 Bootstrap**：中位数是**次序统计量**，它只依赖数据的「排序位置」。Bootstrap 重抽样本质上是在扰动「每个观测值被抽中的次数」——这**恰好模拟了次序统计量的抽样波动**。因此 Bootstrap 对中位数、分位数、四分位距这类统计量效果很好。
>
> **反例（不适合的情形）**：若想估计 `max(Xᵢ)` 的置信区间，Bootstrap **必然失败**——因为任何 Bootstrap 样本的最大值都 `≤` 原始样本的最大值，Bootstrap 分布会**系统性偏低**（永远不会超出观测到的最大值）。这正是 9.1.5 节列出的失效情形之一。此时应改用**极值理论（Extreme Value Theory）**。

## 易错点提醒

1. **Bootstrap 重抽样忘了「有放回」**。
   **错在**：写 `sample(x, n)` 或 `np.random.choice(x, n)` 后就想当然认为「已经是有放回了」。
   **正确做法**：**必须显式写成 `sample(x, n, replace = TRUE)` / `np.random.choice(x, n, replace=True)`**。无放回时抽出的永远是原样本的排列，`x̄*` 恒为 `x̄`，方差为 0，Bootstrap 完全失效。
   **特别注意两边的默认值恰好相反**：**R 的 `sample()` 默认 `replace = FALSE`（无放回）**，而 **numpy 的 `np.random.choice(a, size, replace=True, p=None)` 默认 `replace=True`（有放回）**。两边都容易记反，写代码时一律显式写出 `replace` 参数最安全。

2. **Bootstrap 样本量与原样本不同**。
   **错在**：从 n = 50 的样本中每次只抽 10 个。
   **正确做法**：**每次重抽样的样本量必须等于原始样本量 n**。这是 Bootstrap 理论的要求（模拟「从 `F_n` 中抽 n 个」这一过程）。**样本量抽错的方向是这样的**：每次抽 m 个时 `E[Var(X̄*_m)] = σ̂²ₙ/m`，即 `SE ∝ 1/√m` —— 所以 **m < n 时方差被高估**（Bootstrap 分布被撑宽），**m > n 时方差被低估**；m 偏离 n 越远错得越多。

3. **Bootstrap 次数 B 太少**。
   **错在**：`B = 50` 就下结论。
   **正确做法**：**`B ≥ 1000`**（要估计 95% 置信区间时，B 至少要 1000 才能让 2.5% 分位点稳定；推荐 `B = 2000~10000`）。B 太小会导致 Bootstrap 分布本身**太粗糙**，分位点跳动很大。

4. **不设随机种子**。
   **错在**：R 中直接用 `sample()`、Python 中不设 `seed`。
   **正确做法**：**`set.seed(123)`（R）或 `np.random.default_rng(42)`（Python）**。否则每次运行结果都不同，**他人无法复现你的结论**，科研上不可接受。

5. **对时间序列直接 Bootstrap**。
   **错在**：把股票日收益率按普通 Bootstrap 重抽样。
   **正确做法**：时间序列相邻观测**不独立**，普通 Bootstrap 会**严重低估标准误**（因为破坏了相关性结构）。应用**块 Bootstrap（Block Bootstrap）**：把数据切成若干连续小块，以「块」为单位重抽样。或改用**平稳 Bootstrap**。

6. **Bootstrap 用于估计极值类统计量**。
   **错在**：用 Bootstrap 给 `max(Xᵢ)` 或「历史最高水位」算置信区间。
   **正确做法**：**Bootstrap 分布永远被原始样本的最大值「封顶」**，会系统性偏低。极值问题应使用**极值理论**。
   同理，`min`、最小次序统计量也不适用。

7. **样本量很小时迷信 Bootstrap**。
   **错在**：n = 5 的数据也做 Bootstrap。
   **正确做法**：Bootstrap 的合法性来自「经验分布接近真实分布」，而 **n 小时 `F_n` 严重失真**。一般要求 **n ≥ 20，最好 n ≥ 50**。n 太小时应改用**参数化 Bootstrap**（假定分布形式，只对参数重抽样）。

8. **R 中把方差传给 `sd` 参数**。
   **错在**：`pnorm(12, mean = 10, sd = 4)` 想表示 `N(10, 4)`（方差为 4）。
   **正确做法**：**R 的 `sd` 参数是标准差**。`N(10, σ² = 4)` 应写 `pnorm(12, 10, sd = 2)`。传错会让结果完全错误。

9. **`qnorm` 的输入用「上侧概率」**。
   **错在**：求 `z_{0.05}` 写成 `qnorm(0.05)`，得到 `−1.645`。
   **正确做法**：`qnorm` 的输入是**左侧累积概率**。求上侧 0.05 分位点应写 **`qnorm(0.95)`**，得 `1.645`。（或用 `qnorm(0.05, lower.tail = FALSE)`。）

10. **Python 的 `numpy.std()` 忘记 `ddof=1`**。
    **错在**：直接用 `boot_mean.std()` 当标准误。
    **正确做法**：`numpy` 默认 `ddof=0`（分母 n），而统计上的样本标准差分母是 `n−1`。**必须写 `boot_mean.std(ddof=1)`**（pandas 的 `.std()` 默认就是 `ddof=1`，两库不一致，极易混淆）。

11. **`predict` 中混淆 `"confidence"` 与 `"prediction"`**。
    **错在**：预测「下一个具体观测值」时用 `interval = "confidence"`。
    **正确做法**：**均值区间用 `"confidence"`（窄）；个体预测区间用 `"prediction"`（宽）**。对应第 8 章易错点 10。报错区间会让预测精度被**高估**。

12. **`t.test` 的 `alternative` 写错方向**。
    **错在**：题目问「是否显著超过」，却用默认的 `"two.sided"`（或写成 `"less"`）。
    **正确做法**：**「超过」用 `"greater"`，「低于」用 `"less"`**。方向写反会导致 p 值变成 `1 − p`，结论彻底反转。

13. **两样本 t 检验忘记 `var.equal`**。
    **错在**：以为 `t.test(x, y)` 就是第 7 章的合并方差 t 检验。
    **正确做法**：**R 的 `t.test(x, y)` 默认是 Welch 检验（`var.equal = FALSE`）**，自由度是小数（如 `df = 17.34`）。要得到第 7 章的合并方差 t 检验，必须显式写 **`var.equal = TRUE`**（此时 `df = n₁ + n₂ − 2` 是整数）。
    **判断方法**：看输出的 `df`——**整数说明是合并方差 t，小数说明是 Welch**。

14. **把软件输出当作「证明」**。
    **错在**：看到 `p < 0.05` 就断言「A 导致 B」。
    **正确做法**：软件只能算概率。**统计显著 ≠ 实际重要 ≠ 因果**。样本量极大时，微小到毫无实际意义的差异也会「显著」；而观测数据的相关性**不能**推出因果（第 7 章易错点、第 8 章易错点 12 同一道理）。判断因果需要**实验设计**与**领域知识**。

## 本章小结

- **Bootstrap 的核心**：用**经验分布 `F_n`** 代替真实分布 `F`，通过**有放回重抽样**模拟统计量的抽样分布。
- **四步流程**：有放回抽 n 个 → 算统计量 → 重复 B 次 → 用这 B 个值的经验分布近似抽样分布。
- **`replace = TRUE` 是不二法门**：无放回则方差恒为 0。约 **63.2%** 的原观测值会出现在每个 Bootstrap 样本中，**36.8%** 落在袋外（随机森林袋外误差的来源）。
- **Bootstrap 标准误**：`SE_boot = √[(1/(B−1))·Σ(θ̂*_b − θ̄*)²]`，**分母是 `B − 1`**。
- **百分位法置信区间**：取排序后第 `Bα/2` 个与第 `B(1−α/2)` 个值。**B ≥ 1000**。
- **Bootstrap 的最大价值**：**给任何统计量算标准误**（中位数、相关系数、`R²`），**不需要解析分布**。
- **两条假定**：样本代表性 + 观测独立。**失效情形**：n 过小、存在极值统计量、时间序列相关、参数在边界。
- **R 的 `d/p/q/r` 体系**：`d`=密度/分布律，`p`=分布函数，`q`=分位点，`r`=随机数。
- **R 的 `sd` 参数是标准差不是方差**；**`qnorm` 的输入是左侧累积概率**。
- **核心 R 函数**：`t.test`（t 检验，`alternative` 定方向，`var.equal` 定是否合并方差）、`var.test`（F 检验）、`aov`（方差分析）、`lm` + `predict`（回归与预测）、`shapiro.test`（正态性）、`boot`（Bootstrap）。
- **`predict` 的 `interval`**：`"confidence"` 给均值区间（窄），`"prediction"` 给个体区间（宽）。
- **Python 对照**：`scipy.stats.norm.pdf/cdf/ppf/rvs` ↔ `dnorm/pnorm/qnorm/rnorm`；**`numpy.std()` 必须传 `ddof=1`**。
- **一句话记住本章**：**Bootstrap 的思想就一句——「既然不知道总体，那就把样本当成总体，反复有放回地抽，看统计量怎么晃」；而统计软件的作用是「把第 1~8 章所有查表和手算都变成一行代码」，但前提是你必须知道该选哪个检验、该往哪个方向检验。**

1. 简述 Bootstrap 的完整流程（四步），并说明为什么必须「有放回」。
2. 样本 `x = {2, 4, 6, 8, 10}`，`n = 5`。若某次 Bootstrap 重抽样得到 `{4, 4, 10, 2, 6}`，求该次 Bootstrap 样本的均值 `θ̂*`。
3. 设 B = 2000 次 Bootstrap 得到的统计量均值 `θ̄* = 5.02`，且 `Σ(θ̂*_b − θ̄*)² = 3.2`。求 Bootstrap 标准误。（保留四位小数）
4. 承第 3 题，若 B = 2000、α = 0.05，百分位法置信区间应取排序后的第几个和第几个值？
5. 写出 R 代码：设 `X ~ N(50, 8²)`，求 `P(X < 45)` 和上侧 0.01 分位点。
6. 写出 R 代码：对数据向量 `x` 做「`H₀: μ = 100` vs `H₁: μ < 100`」的 t 检验，并说明如何判断它是合并方差检验还是 Welch 检验。
7. 写出 R 代码：完成单因素方差分析（数据框 `df`，响应变量 `y`，因素 `A`），并说明输出中哪一列对应教材里的 `F` 值。
8. 写出 R 代码：对 `df` 中的 `y` 与 `x` 做一元线性回归，并求 `x = 10` 时**单个新观测值**的 95% 预测区间。
9. 说明为什么 Bootstrap 不能用于估计 `max(Xᵢ)` 的置信区间，并提出替代方案。
10. 某同学用 Bootstrap 分析股票日收益率数据，样本量 n = 500，B = 1000，得到均值的标准误为 0.0001（非常小），于是宣称「股票平均收益率被精确估计」。请指出这个分析的问题。

### 自测题答案

1. **四步流程**：
   ① 从原始样本 `x = (x₁, …, xₙ)` 中**有放回**抽 n 个，得到 Bootstrap 样本 `x*`；
   ② 计算统计量 `θ̂* = θ̂(x*)`；
   ③ 重复①②共 **B 次**（B ≥ 1000），得到 `θ̂*₁, …, θ̂*_B`；
   ④ 用这 B 个值的经验分布近似 `θ̂` 的抽样分布（据此算标准误、置信区间）。

   **必须有放回的原因**：Bootstrap 的目的是**模拟「从总体中反复抽样」的过程**。经验分布 `F_n` 在每个样本点上放 1/n 的概率。有放回抽样才能产生「与原样本不同」的新样本，从而体现抽样的随机性。若无放回，每次抽出的都是原样本的一个**排列**，任何对称统计量（如均值、中位数）都恒等于原样本的值，**方差为 0，什么都估不出来**。

2. `θ̂* = (4 + 4 + 10 + 2 + 6)/5 = 26/5 = 5.2`

3. `SE_boot = √[ (1/(B−1))·Σ(θ̂*_b − θ̄*)² ] = √[ (1/1999) × 3.2 ] = √0.0016008 = 0.0400`
   （**注意分母是 `B − 1 = 1999`，不是 2000**；题目要求保留四位小数，故写 `0.0400`，中间结果 `√0.0016008 = 0.04001` 是它四舍五入前的值。）

4. `B·α/2 = 2000 × 0.025 = 50`，`B·(1 − α/2) = 2000 × 0.975 = 1950`。
   应取排序后的**第 50 个和第 1950 个** Bootstrap 统计量作为置信区间的下、上端点。

5. ```r
   # P(X < 45)
   pnorm(45, mean = 50, sd = 8)
   # 上侧 0.01 分位点
   qnorm(0.99, mean = 50, sd = 8)
   ```
   （**`sd = 8` 是标准差；上侧 0.01 对应左侧累积概率 0.99。**）
   手算验证：`P(X < 45) = Φ((45−50)/8) = Φ(−0.625) = 0.2660`；
   `qnorm(0.99, 50, 8) = 50 + 2.3263 × 8 = 68.61`。

6. ```r
   t.test(x, mu = 100, alternative = "less")
   ```
   **判断方法**：看输出的 `df` 一行。
   - `df = n − 1`（**整数**）→ **单样本情形总是这样**，不存在合并方差问题；
   - 若是**两样本** `t.test(x, y)`：`df` 为**小数**（如 `df = 17.34`）→ **Welch 检验**（默认）；`df = n₁ + n₂ − 2`（**整数**）→ **合并方差 t 检验**（需显式写 `var.equal = TRUE`）。
   **单样本** t 检验没有 `var.equal` 参数，因为它只涉及一个方差。

7. ```r
   fit <- aov(y ~ A, data = df)
   summary(fit)
   ```
   **对应关系**：`summary` 输出表中的 **`F value`** 列就是教材中的 `F = MS_A/MS_E`；对应的 p 值是 **`Pr(>F)`** 列。
   表中 `A` 行的 `Sum Sq` 是 `SA`，`Residuals` 行的 `Sum Sq` 是 `SE`；`A` 行的 `Df` 是 `k − 1`，`Residuals` 行的 `Df` 是 `n − k`。

8. ```r
   fit <- lm(y ~ x, data = df)
   predict(fit, newdata = data.frame(x = 10),
           interval = "prediction", level = 0.95)
   ```
   **关键**：必须是 **`interval = "prediction"`**（个体预测区间，较宽）。若写成 `interval = "confidence"`，得到的是**均值 `E(Y|x=10)` 的置信区间**（较窄），用它会**高估预测精度**。

9. **原因**：Bootstrap 样本是**从原始样本中有放回抽取**的，因此任何 Bootstrap 样本中的最大值都 `≤` 原始样本的最大值 `x₍ₙ₎`。于是 1000 个 `max(x*)` 的取值全部**落在 `[某值, x₍ₙ₎]` 之内**，Bootstrap 分布被 `x₍ₙ₎` **硬性封顶**，会**系统性偏低**，据此算出的置信区间上端永远达不到真实的分布上端。**Bootstrap 对「极值型统计量」本质失效**。

   **替代方案**：使用**极值理论（Extreme Value Theory, EVT）**——用广义极值分布（GEV）或广义帕累托分布（GPD）对尾部建模，据此外推极端分位数（如「百年一遇洪水位」）。这是保险精算、金融风险管理（VaR 计算）、水文频率分析的标准工具。
   （`min(Xᵢ)` 同理失效，解决方案相同。）

10. **问题一：股票收益率是时间序列，不满足 Bootstrap 的独立性假定**。相邻交易日的收益率存在**波动率聚集（volatility clustering）**和自相关，普通 Bootstrap 破坏了这种相关性结构，导致**标准误被严重低估**。正确做法是用**块 Bootstrap**（把数据切成连续块，以块为单位重抽样）或**平稳 Bootstrap**。

    **问题二：标准误小 ≠ 估计精确**。`SE = 0.0001` 只说明「在假定模型正确的前提下，重复抽样的波动小」。但：
    - 日收益率的**真实波动**本身极大（单日涨跌 5% 很常见），`SE` 小是因为 `n = 500` 大，不是因为收益稳定；
    - 收益率分布的**尾部极厚**，均值这个统计量对极端值敏感，而 Bootstrap 又受原始样本极值限制；
    - 更重要的是，**均值为正不代表未来收益为正**——股票收益率近似**随机游走**，历史均值对未来的预测力极弱（这是有效市场假说的核心内容）。

    **正确表述**应该是：「基于 500 个交易日数据，样本日均收益率为 X，Bootstrap 标准误为 0.0001；**但该估计依赖样本期，且收益率序列存在波动率聚集，标准误可能被低估**。」
    **教训**：**统计输出必须结合数据的生成机制去解读**。软件不会告诉你「这个数据能不能这样分析」——这正是统计思维不可被软件替代的原因。
