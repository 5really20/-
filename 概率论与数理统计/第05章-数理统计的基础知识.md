## 5.1 数理统计的基本概念

### 5.1.1 总体与样本

**总体（Population）**：研究对象的**全体**。数理统计中把总体看作一个**随机变量 X**，其分布称为**总体分布**。

**个体（Individual）**：总体中的每一个元素。个体是总体 X 的一次观测值。

> **重点**：为什么把总体看作随机变量？因为「某批灯泡的全体寿命」是一个确定的集合，但**随机抽一个**得到的寿命是随机的。用随机变量 X 描述总体，就把统计问题纳入了概率论的框架。

**样本（Sample）**：从总体 X 中**随机抽取**的 n 个个体 `X₁, X₂, …, Xₙ`。n 称为**样本容量**。

**简单随机样本（Simple Random Sample）**：若 `X₁, …, Xₙ` **相互独立**且**与总体 X 同分布**，则称之为简单随机样本。简称**独立同分布（i.i.d.）样本**。

**两条要求（缺一不可）**：

- **独立性**：每次抽取的结果不影响其他次（对应「有放回」或总体足够大）；
- **同分布性**：每次抽取面对的都是同一个总体（对应「同一批产品」）。

**样本的联合分布**：设总体 X 的分布函数为 `F(x)`，密度为 `f(x)`，则简单随机样本的联合分布为

`F(x₁, …, xₙ) = Πᵢ₌₁ⁿ F(xᵢ)`，　`f(x₁, …, xₙ) = Πᵢ₌₁ⁿ f(xᵢ)`

> **重点**：这个「乘积形式」是第 6 章**最大似然估计**的基础——似然函数就是这个联合密度。

**样本的二重性**：抽样前，`X₁, …, Xₙ` 是 n 个**独立同分布的随机变量**；抽样后，得到 n 个**具体的数值** `x₁, …, xₙ`，称为**样本观测值**。做题时要分清自己在哪一层——求分布用大写，代入计算用小写。

### 5.1.2 统计量

**统计量（Statistic）**：设 `X₁, …, Xₙ` 是总体 X 的样本，若样本函数 `g(X₁, …, Xₙ)` **不含任何未知参数**，则称之为统计量。

> **重点**：**「不含未知参数」是统计量的唯一门槛**。若 `μ` 已知，则 `X₁ − μ` 是统计量；若 `μ` 未知，则它不是统计量。这是概念题的必考点。

**常用统计量（必背）**：

| 名称 | 符号 | 定义式 | 说明 |
|---|---|---|---|
| **样本均值** | `X̄` | `X̄ = (1/n) Σᵢ₌₁ⁿ Xᵢ` | 集中位置的度量 |
| **样本方差** | `S²` | `S² = 1/(n−1) · Σᵢ₌₁ⁿ (Xᵢ − X̄)²` | **分母是 n−1**（无偏性） |
| **样本标准差** | `S` | `S = √(S²)` | 与 X 同量纲 |
| **样本 k 阶原点矩** | `A_k` | `A_k = (1/n) Σᵢ₌₁ⁿ Xᵢ^k` | `A₁ = X̄` |
| **样本 k 阶中心矩** | `B_k` | `B_k = (1/n) Σᵢ₌₁ⁿ (Xᵢ − X̄)^k` | `B₂` 的分母是 **n**，≠ S² |

**样本方差的常用变形（计算时更省事）**：

`S² = 1/(n−1) [ Σᵢ₌₁ⁿ Xᵢ² − n X̄² ]`

> **重点（本章第一易错点）**：`S²` 的分母是 `n − 1`，而样本二阶中心矩 `B₂` 的分母是 `n`。二者关系为
> `S² = n/(n − 1) · B₂`
> 很多同学在计算时把 `S²` 写成 `(1/n)Σ(Xᵢ − X̄)²`，这是**错的**。为什么用 `n−1`？因为 `X̄` 用掉了一个自由度，且只有用 `n−1` 才能保证 `E(S²) = σ²`（无偏性，见下）。

### 5.1.3 样本均值与样本方差的数字特征（考试必考）

设总体 X 的 `E(X) = μ`，`D(X) = σ²`，`X₁, …, Xₙ` 是简单随机样本，则：

**① 样本均值的期望与方差**

`E(X̄) = μ`，　`D(X̄) = σ² / n`

**推导**：`E(X̄) = E[(1/n)ΣXᵢ] = (1/n)ΣE(Xᵢ) = (1/n)·nμ = μ`（**用期望线性性，不需要独立性**）。
`D(X̄) = D[(1/n)ΣXᵢ] = (1/n²)ΣD(Xᵢ) = (1/n²)·nσ² = σ²/n`（**这里需要独立性才能把方差相加**）。

**② 样本方差的期望**

`E(S²) = σ²`

**推导**：由 `Σ(Xᵢ − X̄)² = ΣXᵢ² − nX̄²`，
`E[Σ(Xᵢ − X̄)²] = ΣE(Xᵢ²) − nE(X̄²) = n(σ² + μ²) − n(σ²/n + μ²) = nσ² + nμ² − σ² − nμ² = (n−1)σ²`
故 `E(S²) = (n−1)σ²/(n−1) = σ²`。∎

> **重点（三条结论要背下来，并理解含义）**：
> - `E(X̄) = μ`：`X̄` 是 μ 的**无偏估计**，平均而言打得准；
> - `D(X̄) = σ²/n`：n 越大，`X̄` 波动越小（**按 1/n 缩，标准差按 1/√n 缩**）。这就是「多测几次取平均更精确」的数学依据；
> - `E(S²) = σ²`：**分母取 n−1 就是为了这条**。若用 n 作分母，`E(B₂) = (n−1)σ²/n < σ²`，会系统性低估方差——这叫**有偏**。这是「n−1」的唯一理由，也是统计中「自由度」概念的来源。

**③ 经验分布函数（了解）**：`F_n(x) = (1/n) · #{Xᵢ ≤ x}`，即样本中不超过 x 的比例。**格里汶科定理**指出 `F_n(x)` 以概率 1 一致收敛于 `F(x)`——这为「用样本推断总体」提供了根本依据。

**④ 直方图与箱线图（了解）**：直方图用面积表示频率，用于**目测总体分布形状**；箱线图用五数概括（最小值、下四分位数 Q₁、中位数 M、上四分位数 Q₃、最大值）识别**偏态与异常值**。计算机专业的同学在 pandas / matplotlib 中会经常用到（`df.plot.box()`）。

## 5.2 常用统计分布

### 5.2.1 三大分布总表（核心表，必须默写）

| 分布名称 | 记号 | 构造方式（定义） | 参数 | 期望 `E` | 方差 `D` | 取值范围 | 图形特征 |
|---|---|---|---|---|---|---|---|
| **χ² 分布**（卡方） | `χ²(n)` | `X₁,…,Xₙ` 独立同服从 `N(0,1)`，令 `χ² = Σᵢ₌₁ⁿ Xᵢ²` | 自由度 n | `n` | `2n` | `(0, +∞)` | 右偏，n 越大越对称 |
| **t 分布**（学生氏） | `t(n)` | `X ~ N(0,1)`，`Y ~ χ²(n)`，X 与 Y 独立，令 `T = X / √(Y/n)` | 自由度 n | `0`（n > 1） | `n/(n−2)`（n > 2） | `(−∞, +∞)` | 关于 0 **对称**，比正态「矮胖」，尾部厚 |
| **F 分布** | `F(n₁, n₂)` | `U ~ χ²(n₁)`，`V ~ χ²(n₂)`，U 与 V 独立，令 `F = (U/n₁)/(V/n₂)` | 自由度 `(n₁, n₂)` | `n₂/(n₂−2)`（n₂ > 2） | 见第4章总表（n₂ > 4） | `(0, +∞)` | 右偏，取值恒正 |

（表中「典型应用场景」：χ² 分布用于**方差推断**与**拟合优度检验**；t 分布用于**方差未知时的均值推断**（小样本）；F 分布用于**两方差之比的推断**与**方差分析**。）

> **记忆口诀**：
> - **χ² = 标准正态平方和**（「方」起来）
> - **t = 标准正态 ÷ 卡方开方**（「t = 正态 over 卡方」）
> - **F = 两个卡方之比**（「F = 方比的方」）
> 三大分布**同根同源**：都从标准正态出发，是正态总体推断的三大支柱。

### 5.2.2 χ² 分布（Chi-square Distribution）

**定义**：设 `X₁, X₂, …, Xₙ` 相互独立且都服从 `N(0, 1)`，则称

`χ² = X₁² + X₂² + … + Xₙ²`

服从自由度为 n 的 **χ² 分布**，记作 `χ² ~ χ²(n)`。

**概率密度**：

`f(x) = 1 / [2^(n/2) Γ(n/2)] · x^(n/2 − 1) · e^(−x/2)`（x > 0）

（Γ 为伽马函数，本科阶段不要求用此密度计算，一律查表。）

**四条重要性质**：

1. **期望与方差**：`E(χ²) = n`，`D(χ²) = 2n`；
2. **可加性**：若 `χ₁² ~ χ²(n₁)`，`χ₂² ~ χ²(n₂)` 且相互独立，则 `χ₁² + χ₂² ~ χ²(n₁ + n₂)`（**自由度相加**——这是第 6、7 章的关键）；
3. **特例**：`n = 1` 时 `χ²(1)` 就是标准正态的平方（第 2 章例 2.7 的结论）；`n = 2` 时 `χ²(2)` 就是参数 `λ = 1/2` 的指数分布；
4. **n 很大时**近似正态：`χ²(n) ~ 近似 N(n, 2n)`。

> **重点——什么是「自由度」**：自由度 = **独立信息的个数**。n 个独立标准正态变量贡献 n 个独立平方，所以自由度是 n。当 `σ²` 用样本方差 `S²` 替代时，`Σ(Xᵢ − X̄)²` 中因为有 `Σ(Xᵢ − X̄) = 0` 这一条约束，n 个偏差只有 `n − 1` 个是自由的，**自由度就损失了 1**。这就是后面到处出现 `n − 1` 的根本原因。

### 5.2.3 t 分布（Student's t Distribution）

**定义**：设 `X ~ N(0, 1)`，`Y ~ χ²(n)`，且 X 与 Y **相互独立**，则称

`T = X / √(Y / n)`

服从自由度为 n 的 **t 分布**，记作 `T ~ t(n)`。

**四条重要性质**：

1. **对称性**：关于 `t = 0` 对称，即密度满足 `f(−t) = f(t)`；
2. **期望与方差**：`n > 1` 时 `E(T) = 0`；`n > 2` 时 `D(T) = n/(n − 2)`；`n ≤ 1` 时期望不存在，`n ≤ 2` 时方差不存在；
3. **极限性质**：`n → ∞` 时，`t(n)` 的密度趋于标准正态密度。**实用判据**：`n ≥ 45` 时 `t(n) ≈ N(0,1)`（`t_{0.025}(45) = 2.0141`，已接近 1.96）；
4. **分位点对称关系**：`t_{1−α}(n) = −t_α(n)`（**注意**：t 分布是左右对称的，所以「上分位点」和「下分位点」互为相反数）。

> **为什么需要 t 分布**：实际问题中总体方差 `σ²` 通常**未知**，只能用样本标准差 `S` 代替。`S` 本身是随机的，会带来额外的波动，导致统计量**不再是正态**。t 分布正是「正态 ÷ 样本波动」的结果，它比正态尾部更厚（表示不确定性更大）。这正是「小样本推断」的标准工具。
>
> **名字的由来**：t 分布由爱尔兰吉尼斯啤酒厂的统计学家 William S. Gosset 于 1908 年提出，因公司禁止员工发表论文而化名 "Student"，故称**学生氏分布**。

### 5.2.4 F 分布（F Distribution）

**定义**：设 `U ~ χ²(n₁)`，`V ~ χ²(n₂)`，且 U 与 V **相互独立**，则称

`F = (U / n₁) / (V / n₂)`

服从自由度为 `(n₁, n₂)` 的 **F 分布**，记作 `F ~ F(n₁, n₂)`。其中 `n₁` 称为**第一自由度**（分子自由度），`n₂` 称为**第二自由度**（分母自由度）。

**三条重要性质**：

1. **倒数性质**：若 `F ~ F(n₁, n₂)`，则 `1/F ~ F(n₂, n₁)`；
   由此得分位点关系 **`F_{1−α}(n₁, n₂) = 1 / F_α(n₂, n₁)`**　★考试高频；
2. **期望**：`n₂ > 2` 时 `E(F) = n₂/(n₂ − 2)`（**只与分母自由度有关**，与 n₁ 无关）；
3. **与 t 的关系**：若 `T ~ t(n)`，则 `T² ~ F(1, n)`。

> **重点**：F 分布表通常**只给出上侧小概率（α = 0.10, 0.05, 0.025, 0.01）的分位点**。若需要 `F_{0.95}` 这种下侧分位点，必须用倒数性质换算：`F_{0.95}(9, 15) = 1/F_{0.05}(15, 9)`。**注意交换两个自由度**——这是最常见的失分点。

### 5.2.5 上 α 分位点与查表

**上 α 分位点（Upper α Quantile）**：对给定 `0 < α < 1`，称满足

`P(X > x_α) = α`，　即 `P(X ≤ x_α) = 1 − α`

的点 `x_α` 为该分布的**上 α 分位点**。

**符号约定**：`z_α`（标准正态）、`χ²_α(n)`、`t_α(n)`、`F_α(n₁, n₂)`。

**常用分位点速查表（考前必背几个）**：

| 分布 | 记号 | 数值 | 含义 |
|---|---|---|---|
| 标准正态 | `z_{0.05}` | 1.645 | 上侧面积 0.05 |
| 标准正态 | `z_{0.025}` | 1.96 | 上侧面积 0.025 |
| 标准正态 | `z_{0.01}` | 2.33 | 上侧面积 0.01 |
| t(9) | `t_{0.05}(9)` | 1.8331 | 上侧面积 0.05 |
| t(9) | `t_{0.025}(9)` | 2.2622 | 上侧面积 0.025 |
| t(15) | `t_{0.05}(15)` | 1.7531 | 上侧面积 0.05 |
| t(15) | `t_{0.025}(15)` | 2.1315 | 上侧面积 0.025 |
| χ²(9) | `χ²_{0.05}(9)` | 16.919 | 上侧面积 0.05 |
| χ²(9) | `χ²_{0.975}(9)` | 2.700 | 上侧面积 0.975 |
| χ²(10) | `χ²_{0.05}(10)` | 18.307 | 上侧面积 0.05 |
| χ²(10) | `χ²_{0.95}(10)` | 3.940 | 上侧面积 0.95 |
| χ²(15) | `χ²_{0.05}(15)` | 24.996 | 上侧面积 0.05 |
| χ²(15) | `χ²_{0.95}(15)` | 7.261 | 上侧面积 0.95 |
| F(9,15) | `F_{0.05}(9,15)` | 2.59 | 上侧面积 0.05 |
| F(15,9) | `F_{0.05}(15,9)` | 3.01 | 上侧面积 0.05 |
| F(10,10) | `F_{0.05}(10,10)` | 2.98 | 上侧面积 0.05 |

> **三条查表技巧**：
> ① **正态**：`Φ(−x) = 1 − Φ(x)`；
> ② **t 分布**：`t_{1−α}(n) = −t_α(n)`（利用对称性）；
> ③ **F 分布**：`F_{1−α}(n₁,n₂) = 1/F_α(n₂,n₁)`（**交换自由度**）。
> χ² 分布**不对称、取值恒正**，没有上述简化，只能直接查（或插值）。

## 5.3 抽样分布

**抽样分布（Sampling Distribution）**：统计量的分布。本节给出**正态总体**下 `X̄`、`S²` 及其组合的精确分布——这是第 6、7 章全部推断方法的理论基础。

### 5.3.1 单正态总体的四大定理

设总体 `X ~ N(μ, σ²)`，`X₁, …, Xₙ` 是来自 X 的简单随机样本，`X̄` 为样本均值，`S²` 为样本方差。

---

**定理 1（样本均值的分布）**

`X̄ ~ N(μ, σ²/n)`，　等价地　`(X̄ − μ) / (σ/√n) ~ N(0, 1)`

**条件**：总体**正态**（或 n 很大时由中心极限定理近似成立），**σ 已知**。
**直观**：`X̄` 的均值与总体一致，但方差缩小到 `1/n`。

---

**定理 2（样本方差的分布与独立性）**

`(n − 1) S² / σ² ~ χ²(n − 1)`

且 **`X̄` 与 `S²` 相互独立**。

**条件**：总体**正态**（这条对非正态总体不成立！）。
**直观**：`Σ(Xᵢ − X̄)²` 是 n 个偏差的平方和，但有 `Σ(Xᵢ − X̄) = 0` 一条约束，故自由度损失 1。
**用途**：`σ²` 的区间估计与假设检验（第 6、7 章）。

> **重点**：**`X̄` 与 `S²` 独立**是正态总体独有的性质，极其重要（它使 t 分布的构造成为可能）。非正态总体下二者一般不独立。

---

**定理 3（t 统计量）**

`(X̄ − μ) / (S / √n) ~ t(n − 1)`

**条件**：总体**正态**，**σ 未知**（用 S 代替）。
**推导思路**：把定理 1 与定理 2 相除——
`(X̄−μ)/(σ/√n) ~ N(0,1)`，`(n−1)S²/σ² ~ χ²(n−1)`，二者独立，故
`[ (X̄−μ)/(σ/√n) ] / √[ ((n−1)S²/σ²)/(n−1) ] = (X̄−μ)/(S/√n) ~ t(n−1)` ∎

**用途**：**σ 未知时对 μ 的推断**（这是实际中最常见的情形）。

---

**定理 4（两正态总体的抽样分布）**

设 `X ~ N(μ₁, σ₁²)`，`Y ~ N(μ₂, σ₂²)`，两总体**相互独立**，样本容量分别为 `n₁`、`n₂`，样本均值 `X̄`、`Ȳ`，样本方差 `S₁²`、`S₂²`。

**(a) 均值差（σ₁², σ₂² 已知）**：

`[ (X̄ − Ȳ) − (μ₁ − μ₂) ] / √(σ₁²/n₁ + σ₂²/n₂) ~ N(0, 1)`

**(b) 方差比（永远可用）**：

`(S₁² / σ₁²) / (S₂² / σ₂²) = (S₁²/S₂²) · (σ₂²/σ₁²) ~ F(n₁ − 1, n₂ − 1)`

**(c) 均值差（σ₁² = σ₂² 但未知，合并方差）**：

`[ (X̄ − Ȳ) − (μ₁ − μ₂) ] / (S_w √(1/n₁ + 1/n₂)) ~ t(n₁ + n₂ − 2)`

其中**合并方差**

`S_w² = [ (n₁ − 1)S₁² + (n₂ − 1)S₂² ] / (n₁ + n₂ − 2)`

> **重点**：`S_w²` 是两个样本方差的**加权平均**（权重是各自自由度），它把两份信息「合并」起来共同估计共同的 `σ²`。分母的自由度 `n₁ + n₂ − 2` 正是两个自由度之和，因为估计了两个均值 `X̄` 与 `Ȳ`。

### 5.3.2 抽样分布定理选择表（考试拿分关键）

| 推断目标 | 已知条件 | 使用的统计量 | 分布 |
|---|---|---|---|
| 单总体均值 μ | σ **已知**，总体正态 | `(X̄ − μ)/(σ/√n)` | `N(0, 1)` |
| 单总体均值 μ | σ **未知**，总体正态 | `(X̄ − μ)/(S/√n)` | `t(n − 1)` |
| 单总体方差 σ² | 总体正态 | `(n − 1)S²/σ²` | `χ²(n − 1)` |
| 两总体均值差 μ₁−μ₂ | σ₁²、σ₂² **已知** | `[(X̄−Ȳ)−(μ₁−μ₂)]/√(σ₁²/n₁+σ₂²/n₂)` | `N(0, 1)` |
| 两总体均值差 μ₁−μ₂ | σ₁²=σ₂² **未知** | `[(X̄−Ȳ)−(μ₁−μ₂)]/[S_w√(1/n₁+1/n₂)]` | `t(n₁+n₂−2)` |
| 两总体方差比 σ₁²/σ₂² | 总体正态 | `(S₁²/S₂²)·(σ₂²/σ₁²)` | `F(n₁−1, n₂−1)` |

> **使用顺序（决策树）**：
> ① **问的是均值还是方差？** 均值 → 正态或 t；方差 → χ² 或 F。
> ② **问的是单总体还是两总体？** 单 → `N`/`t`/`χ²`；两 → `N`/`t`/`F`。
> ③ **σ 已知还是未知？** 已知用正态（Z），未知用 t。
> ④ **自由度是多少？** 单总体 `n−1`；两总体合并 `n₁+n₂−2`；方差比 `(n₁−1, n₂−1)`。

## 典型例题

**例 5.1**（题型：判断统计量）
设总体 `X ~ N(μ, σ²)`，其中 `μ`、`σ²` 均**未知**。`X₁, X₂, X₃` 是来自 X 的样本。判断下列各量哪些是统计量：
① `X₁ + X₂ + X₃`；② `(X₁ + X₂)/2`；③ `X₁ − μ`；④ `Σᵢ₌₁³ (Xᵢ − X̄)²`；⑤ `X₁/σ`；⑥ `max(X₁, X₂, X₃)`。

**解**：
**判断标准**：统计量是样本的函数，且**不含任何未知参数**。
① 只含 `X₁, X₂, X₃`，**是统计量**。
② 只含 `X₁, X₂`，**是统计量**（注意：统计量不必用上全部样本）。
③ 含未知参数 `μ`，**不是统计量**。
④ 只含样本与 `X̄`（`X̄` 本身是统计量），**是统计量**。
⑤ 含未知参数 `σ`，**不是统计量**。
⑥ 只含样本，**是统计量**（顺序统计量也是一种统计量）。

**答案**：①②④⑥ 是统计量；③⑤ 不是。

> **变式**：若题目改为「μ 已知、σ² 未知」，则③变成统计量（`X₁ − μ` 只含已知的 μ），⑤仍不是。**判断的唯一依据是有没有未知参数，与形式无关。**

---

**例 5.2**（题型：样本均值与方差的数字特征）
设总体 X 的 `E(X) = μ`，`D(X) = σ²`（分布形式不限）。`X₁, …, Xₙ` 是简单随机样本。求 `E(X̄)`、`D(X̄)`、`E(S²)`。

**解**：
① **用期望线性性（不需要独立性）**：
`E(X̄) = E[(1/n)ΣXᵢ] = (1/n)ΣE(Xᵢ) = (1/n)·nμ = μ`
② **必须用独立性把方差相加**：
`D(X̄) = D[(1/n)ΣXᵢ] = (1/n²)·ΣD(Xᵢ) = (1/n²)·nσ² = σ²/n`
③ **关键变形**：先证 `Σ(Xᵢ − X̄)² = ΣXᵢ² − nX̄²`。
`Σ(Xᵢ − X̄)² = Σ(Xᵢ² − 2XᵢX̄ + X̄²) = ΣXᵢ² − 2X̄·ΣXᵢ + nX̄² = ΣXᵢ² − 2X̄·nX̄ + nX̄² = ΣXᵢ² − nX̄²` ✓
于是
`E[Σ(Xᵢ − X̄)²] = ΣE(Xᵢ²) − nE(X̄²)`
其中 `E(Xᵢ²) = D(Xᵢ) + [E(Xᵢ)]² = σ² + μ²`；
由②，`E(X̄²) = D(X̄) + [E(X̄)]² = σ²/n + μ²`。
代入：
`= n(σ² + μ²) − n(σ²/n + μ²) = nσ² + nμ² − σ² − nμ² = (n − 1)σ²`
故 `E(S²) = E[Σ(Xᵢ − X̄)²]/(n − 1) = (n−1)σ²/(n−1) = σ²`

**答案**：`E(X̄) = μ`，`D(X̄) = σ²/n`，`E(S²) = σ²`。

> **为什么要证 `E(S²) = σ²`**：这说明用 `n − 1` 作分母时，样本方差**无偏**地估计总体方差。若分母取 n，则 `E(B₂) = (n−1)σ²/n = σ²·(n−1)/n < σ²`，会系统性**低估**方差。这是「自由度 n−1」存在的全部理由。

**例 5.3**（题型：χ² 分布的构造与自由度）
设 `X₁, X₂, …, X₆` 是来自总体 `N(0, 4)` 的简单随机样本。求常数 a，使 `a · Σᵢ₌₁⁶ Xᵢ²` 服从 χ² 分布，并指出其自由度与期望。

**解**：
**关键是把非标准正态「标准化」**：
`Xᵢ ~ N(0, 4)`，即 `μ = 0`，`σ² = 4`，`σ = 2`。
故 `Xᵢ / 2 ~ N(0, 1)`，且这 6 个变量**相互独立**（因为 `Xᵢ` 独立）。
由 χ² 分布的定义：
`Σᵢ₌₁⁶ (Xᵢ/2)² = (1/4)Σᵢ₌₁⁶ Xᵢ² ~ χ²(6)`
故 `a = 1/4`，自由度为 **6**。
期望 `E = n = 6`（与 a 的值无关，因为这里问的是 `(1/4)ΣXᵢ²` 这个 χ² 变量本身的期望）。

**答案**：`a = 1/4`；自由度 6；期望 6，方差 12。

> **易错**：不能直接说 `ΣXᵢ² ~ χ²(6)`，因为 `Xᵢ ~ N(0,4)` 不是标准正态。**必须先除以 σ 再平方**。

**例 5.4**（题型：χ² 分布的分位点与概率计算）
设 `Y ~ χ²(10)`。① 写出 `χ²_{0.05}(10)` 与 `χ²_{0.95}(10)` 的值；② 求 `P(3.940 < Y < 18.307)`；③ 求常数 c 使 `P(Y > c) = 0.05`。

**解**：
① 查 χ² 分布表（自由度 10）：
`χ²_{0.05}(10) = 18.307`（其右侧面积为 0.05）
`χ²_{0.95}(10) = 3.940`（其右侧面积为 0.95，即左侧面积为 0.05）

② **为什么这样算**：用分位点把区间端点与尾部面积对应起来。
`P(Y > 18.307) = 0.05`，`P(Y > 3.940) = 0.95`
故
`P(3.940 < Y < 18.307) = P(Y > 3.940) − P(Y > 18.307) = 0.95 − 0.05 = 0.90`

③ 由定义 `P(Y > χ²_{0.05}(10)) = 0.05`，故 `c = χ²_{0.05}(10) = 18.307`。

**答案**：① 18.307 与 3.940；② 0.90；③ c = 18.307。

> **注意**：χ² 分布**不对称**，所以 `χ²_{0.95}(10) = 3.940 ≠ −χ²_{0.05}(10)`。这与 t 分布的对称性形成鲜明对比。

**例 5.5**（题型：t 分布的构造与查表）
设 `X ~ N(0, 1)`，`Y ~ χ²(9)`，且 X 与 Y 相互独立。令 `T = X / √(Y/9)`。
① T 服从什么分布？② 求 `P(T > 1.8331)`；③ 求 `P(|T| < 2.2622)`；④ 求 `P(T < −1.8331)`。

**解**：
① **对照 t 分布的定义**：`T = X/√(Y/n)`，其中 `X ~ N(0,1)`、`Y ~ χ²(n)`、X 与 Y 独立。此处 `n = 9`，故 `T ~ t(9)`。

② 由 t 分布上分位点定义，`P(T > t_{0.05}(9)) = 0.05`，而 `t_{0.05}(9) = 1.8331`，故
`P(T > 1.8331) = 0.05`

③ **利用对称性**：`t_{0.025}(9) = 2.2622`，由对称性 `P(T > 2.2622) = 0.025` 且 `P(T < −2.2622) = 0.025`。
`P(|T| < 2.2622) = 1 − 0.025 − 0.025 = 0.95`

④ **对称性直接给出**：`P(T < −1.8331) = P(T > 1.8331) = 0.05`。

**答案**：① `T ~ t(9)`；② 0.05；③ 0.95；④ 0.05。

**例 5.6**（题型：F 分布的倒数性质）
设 `U ~ χ²(9)`，`V ~ χ²(15)`，且 U 与 V 相互独立，`F = (U/9)/(V/15)`。已知 `F_{0.05}(15, 9) = 3.01`。
① F 服从什么分布？② 求 `F_{0.95}(9, 15)`；③ 求 `P(F > 2.59)`。

**解**：
① 由 F 分布的定义，`F ~ F(9, 15)`（分子自由度 9，分母自由度 15）。

② **为什么用倒数性质**：F 分布表只给上侧小概率的分位点（如 0.05），`F_{0.95}` 这类下侧分位点必须换算。
由 `F_{1−α}(n₁, n₂) = 1/F_α(n₂, n₁)`，取 `α = 0.05`：
`F_{0.95}(9, 15) = 1 / F_{0.05}(15, 9) = 1/3.01 = 0.3322`

③ 查表得 `F_{0.05}(9, 15) = 2.59`，由定义 `P(F > F_{0.05}(9,15)) = 0.05`，故
`P(F > 2.59) = 0.05`

**答案**：① `F ~ F(9, 15)`；② 0.3322；③ 0.05。

> **易错警示**：`F_{0.95}(9,15)` 计算时**必须交换自由度**：`1/F_{0.05}(15, 9)`，而不是 `1/F_{0.05}(9, 15) = 1/2.59 = 0.386`。**先交换，再取倒数**。

**例 5.7**（题型：抽样分布定理的应用——σ 已知）
设总体 `X ~ N(50, 36)`，从中抽取容量 `n = 16` 的简单随机样本，`X̄` 为样本均值。求 `P(X̄ > 53)`。

**解**：
**为什么能这样做**：总体正态，由**定理 1**，`X̄ ~ N(μ, σ²/n)`。
`μ = 50`，`σ² = 36`，`σ = 6`，`n = 16`。
`D(X̄) = σ²/n = 36/16 = 2.25`，`σ(X̄) = √2.25 = 1.5`
故 `X̄ ~ N(50, 2.25)`，标准化 `(X̄ − 50)/1.5 ~ N(0, 1)`。
`P(X̄ > 53) = 1 − Φ((53 − 50)/1.5) = 1 − Φ(2)`
查表得 `Φ(2) = 0.9772`，故
`P(X̄ > 53) = 1 − 0.9772 = 0.0228`

**答案**：约 0.0228。

> **对比单次观测**：若只抽 1 个个体，`P(X > 53) = 1 − Φ((53−50)/6) = 1 − Φ(0.5) = 0.3085`。**抽 16 个取平均后，超过 53 的概率从 30.85% 骤降到 2.28%**——这正是 `D(X̄) = σ²/n` 的威力。

**例 5.8**（题型：样本方差的分布——χ² 定理的应用）
设总体 `X ~ N(μ, 4)`，抽取容量 `n = 10` 的样本，`S²` 为样本方差。求 `P(S² > 7.0)`。

**解**：
**为什么用定理 2**：总体正态，问的是**样本方差 S²**，`(n−1)S²/σ² ~ χ²(n−1)`。
`n = 10`，`σ² = 4`，自由度 `n − 1 = 9`。
构造统计量：
`(n−1)S²/σ² = 9S²/4 ~ χ²(9)`
**关键一步——把不等式同步变换**（两边同乘 9/4）：
`P(S² > 7.0) = P(9S²/4 > 9 × 7.0/4) = P(9S²/4 > 15.75) = P(χ²(9) > 15.75)`
**查表并插值**：
`χ²_{0.10}(9) = 14.684`（右尾面积 0.10）
`χ²_{0.05}(9) = 16.919`（右尾面积 0.05）
`15.75` 落在两者之间。线性插值：
`(15.75 − 14.684)/(16.919 − 14.684) = 1.066/2.235 = 0.477`
故右尾面积 `≈ 0.10 − 0.477 × (0.10 − 0.05) = 0.10 − 0.0239 = 0.076`

**答案**：约 0.076。

> **插值口径说明**：χ² 分布的**尾部**曲率较大，用两点线性插值会**系统性高估尾概率**（本例高估约 0.004）。本题真实值是 `P(χ²(9) > 15.75) = 0.0723`。**考试时用插值写到 0.076 即可**（附表只给到 3 位小数，插值是标准做法），但要知道它略偏大。后面的自测题 8 同理。

> **注意**：`S²` 的期望是 `σ² = 4`，而这里问的是 `S² > 7`（远大于期望），所以概率较小（7% 左右）是合理的。若问 `P(S² > 4)`，答案应接近 0.5 但略**小于** 0.5（因为 χ² 分布右偏，中位数小于均值），真实值为 `P(χ²(9) > 9) = 0.4373`。

**例 5.9**（题型：两总体的 F 分布统计量，证明题）
设两个正态总体 `X ~ N(μ₁, σ₁²)`、`Y ~ N(μ₂, σ₂²)` 相互独立。从两总体分别抽取容量为 `n₁ = 10`、`n₂ = 16` 的独立样本，样本方差分别为 `S₁²`、`S₂²`。证明：

`(S₁²/S₂²) · (σ₂²/σ₁²) ~ F(9, 15)`

**证明**：
由**定理 2**（分别对两个总体使用）：
`(n₁ − 1)S₁²/σ₁² = 9S₁²/σ₁² ~ χ²(n₁ − 1) = χ²(9)`
`(n₂ − 1)S₂²/σ₂² = 15S₂²/σ₂² ~ χ²(n₂ − 1) = χ²(15)`
由**两样本相互独立**及正态总体下 `S₁²` 与 `S₂²` 独立，知上述两个 χ² 变量**相互独立**。
由 F 分布的定义，两个独立 χ² 变量各自除以自由度再相除：
`F = [ (9S₁²/σ₁²) / 9 ] / [ (15S₂²/σ₂²) / 15 ] = (S₁²/σ₁²) / (S₂²/σ₂²) = (S₁²/S₂²) · (σ₂²/σ₁²) ~ F(9, 15)`
∎

**答案**：见证明。

> **重要特例**：若 `σ₁² = σ₂²`（未知但相等），则 `S₁²/S₂² ~ F(n₁−1, n₂−1)`。这说明**样本方差之比可以作为总体方差之比的「晴雨表」**——若 `S₁²/S₂²` 离 1 太远，就有理由怀疑 `σ₁² ≠ σ₂²`。这正是第 7 章「两方差相等的检验」的思想。

**例 5.10**（题型：抽样分布定理的综合判断）
设总体 `X ~ N(μ, σ²)`，`X₁, …, X₉` 是样本，`X̄` 与 `S²` 分别为样本均值与样本方差。判断下列统计量各服从什么分布（写出名称与自由度）：
① `(X̄ − μ)/(σ/3)`；② `8S²/σ²`；③ `(X̄ − μ)/(S/3)`；④ `9(X̄ − μ)²/S²`；⑤ `(X̄ − μ)²/(S²/9)`。

**解**：
先明确：`n = 9`，`n − 1 = 8`，`σ(X̄) = σ/√9 = σ/3`。

① 由**定理 1**，`(X̄ − μ)/(σ/√n) = (X̄ − μ)/(σ/3) ~ N(0, 1)`。

② 由**定理 2**，`(n−1)S²/σ² = 8S²/σ² ~ χ²(8)`。

③ 由**定理 3**，`(X̄ − μ)/(S/√n) = (X̄ − μ)/(S/3) ~ t(8)`。

④ 由③，令 `T = (X̄−μ)/(S/3) ~ t(8)`。而
`9(X̄ − μ)²/S² = (X̄−μ)²/(S²/9) = [ (X̄−μ)/(S/3) ]² = T²`
由 F 分布与 t 分布的关系 `T² ~ F(1, n)`，故 `9(X̄ − μ)²/S² ~ F(1, 8)`。

⑤ 注意到 `(X̄ − μ)²/(S²/9) = T²` 与④**完全相同**，故同样 `~ F(1, 8)`。

**答案**：① `N(0,1)`；② `χ²(8)`；③ `t(8)`；④ `F(1, 8)`；⑤ `F(1, 8)`（与④是同一表达式）。

> **解题套路总结**：见到 `(X̄ − μ)` 除以 `σ/√n` → **正态**；见到 `Σ(Xᵢ − X̄)²` 或 `S²` 除以 `σ²` 再乘 `n−1` → **χ²**；见到 `(X̄ − μ)` 除以 `S/√n` → **t**；见到两个方差相除 → **F**。**核心是认清「谁在分子、谁在分母、自由度是多少」。**

## 易错点提醒

1. **样本方差 `S²` 的分母写成 n**。
   **错在**：`S² = (1/n)Σ(Xᵢ − X̄)²`。
   **正确做法**：`S² = 1/(n−1) · Σ(Xᵢ − X̄)²`。分母 `n−1` 是**无偏性**的要求（`E(S²) = σ²`）。分母为 n 的那个量叫**样本二阶中心矩** `B₂`，二者关系为 `S² = n·B₂/(n−1)`。

2. **把非标准正态直接套 χ² 定义**。
   **错在**：`Xᵢ ~ N(0, 4)` 时写 `ΣXᵢ² ~ χ²(6)`。
   **正确做法**：**必须先标准化**：`Xᵢ/σ ~ N(0,1)`，故 `Σ(Xᵢ/σ)² ~ χ²(n)`。本题中 `(1/4)ΣXᵢ² ~ χ²(6)`。

3. **χ² 分布套用 t 分布的对称性**。
   **错在**：写 `χ²_{0.95}(10) = −χ²_{0.05}(10)`。
   **正确做法**：只有**关于 0 对称**的分布（标准正态、t）才有 `x_{1−α} = −x_α`。χ² 与 F 取值恒正、**右偏**，只能用面积关系 `P(χ²_{0.95} < Y < χ²_{0.05}) = 0.90`。

4. **F 分位点换算时忘记交换自由度**。
   **错在**：`F_{0.95}(9, 15) = 1/F_{0.05}(9, 15) = 1/2.59`。
   **正确做法**：`F_{1−α}(n₁, n₂) = 1/F_α(n₂, n₁)`——**两个自由度要换位置**。故 `F_{0.95}(9,15) = 1/F_{0.05}(15,9) = 1/3.01 = 0.3322`。

5. **`t` 分布的自由度写成 n**。
   **错在**：`(X̄ − μ)/(S/√n) ~ t(n)`。
   **正确做法**：分母是 `S/√n`，其自由度为 **`n − 1`**。因为 `S²` 本身消耗了 1 个自由度（估计了 `X̄`）。

6. **`χ²` 分布的自由度写成 n**。
   **错在**：`(n−1)S²/σ² ~ χ²(n)`。
   **正确做法**：`Σ(Xᵢ − X̄)²` 中因有约束 `Σ(Xᵢ − X̄) = 0`，自由度损失 1，故为 `χ²(n−1)`。**记忆法：只要出现 `X̄`（用样本估计了均值），自由度就减 1。**

7. **认为 `(X̄ − μ)/(S/√n)` 服从正态分布**。
   **错在**：用 `Φ` 查表。
   **正确做法**：**分母含随机变量 S** 时不再是正态，而是 **t 分布**。只有分母是完全已知的常数 `σ/√n` 时才是正态。这是第 6、7 章区分 Z 检验与 t 检验的唯一依据。

8. **判断统计量时只看形式不看参数是否已知**。
   **错在**：看到 `X₁ − μ` 就想「含 μ，不是统计量」。
   **正确做法**：要看 μ **是否未知**。μ 已知则 `X₁ − μ` 是统计量（它只含样本与已知常数）。

9. **`D(X̄) = σ²/n` 里的 n 写成 n²**。
   **错在**：`D(X̄) = σ²/n²`。
   **正确做法**：`D[(1/n)ΣXᵢ] = (1/n²)·ΣD(Xᵢ) = (1/n²)·nσ² = σ²/n`。**系数 1/n 平方后是 1/n²，与 n 个 σ² 相乘剩下 1/n**。也可记：`σ(X̄) = σ/√n`。

10. **对非正态总体套用 `(n−1)S²/σ² ~ χ²(n−1)`**。
    **错在**：总体分布任意时也用定理 2。
    **正确做法**：定理 2（以及「`X̄` 与 `S²` 独立」）**要求总体正态**。非正态总体下这些结论不成立；只有 n 很大时 `X̄` 的分布可由中心极限定理近似（但 `S²` 的分布仍无简单形式）。

11. **两总体均值差的 t 统计量自由度写成 `n₁ + n₂`**。
    **错在**：`t(n₁ + n₂)`。
    **正确做法**：合并方差 `S_w²` 的自由度是 `(n₁−1) + (n₂−1) = n₁ + n₂ − 2`（估计了两个均值）。故为 `t(n₁+n₂−2)`。

12. **把「上 α 分位点」与「左侧累积概率」搞混**。
    **错在**：以为 `χ²_{0.05}(10) = 18.307` 意味着 18.307 左侧面积是 0.05。
    **正确做法**：`χ²_α(n)` 表示**右侧**面积为 α。故 18.307 **左侧**面积为 0.95。记忆：**「α 是尾巴，不是脑袋」**。

## 本章小结

- **总体**是一个随机变量 X，**简单随机样本**要求**独立 + 同分布**，联合密度为 `Πf(xᵢ)`。
- **统计量**＝不含未知参数的样本函数。这是唯一判据。
- **样本均值** `X̄ = (1/n)ΣXᵢ`；**样本方差** `S² = 1/(n−1)Σ(Xᵢ − X̄)²`（**分母 n−1**）。
- 三大数字特征：`E(X̄) = μ`、`D(X̄) = σ²/n`、`E(S²) = σ²`（后者说明 `n−1` 保证无偏）。
- **χ² 分布**：n 个独立 `N(0,1)` 的平方和；`E = n`，`D = 2n`；**可加性：自由度相加**；取值 `(0,+∞)`，右偏。
- **t 分布**：`N(0,1) ÷ √(χ²(n)/n)`；关于 0 **对称**；`E = 0`（n>1），`D = n/(n−2)`（n>2）；n→∞ 趋于标准正态。
- **F 分布**：两个独立 χ² 各自除自由度后相除；取值 `(0,+∞)`，右偏；`1/F ~ F(n₂,n₁)`，故 **`F_{1−α}(n₁,n₂) = 1/F_α(n₂,n₁)`（交换自由度）**。
- **分位点**：正态用 `Φ(−x) = 1−Φ(x)`；t 用 `t_{1−α} = −t_α`；F 用**倒数交换自由度**；χ² 只能直查。**α 永远是右尾面积**。
- **抽样分布四大定理（正态总体）**：
  ① `X̄ ~ N(μ, σ²/n)`；
  ② `(n−1)S²/σ² ~ χ²(n−1)`，且 `X̄` 与 `S²` **独立**；
  ③ `(X̄−μ)/(S/√n) ~ t(n−1)`；
  ④ 两总体：均值差用 `N(0,1)`（σ 已知）或 `t(n₁+n₂−2)`（σ 相等未知），方差比用 `F(n₁−1, n₂−1)`。
- **自由度口诀**：**「估计一个参数，损失一个自由度」**。单总体估了 `μ` → `n−1`；两总体估了 `μ₁`、`μ₂` → `n₁+n₂−2`；方差比 → `(n₁−1, n₂−1)`。
- **一句话记住本章**：**统计推断的全部工具就是这三大分布 + 四大定理，而用好它们的关键只有两件事——认清「σ 知不知道」和数对「自由度」。**

## 自测题

1. 设 `X₁, X₂, X₃, X₄` 是来自总体 `X ~ N(μ, σ²)` 的样本（μ、σ² 均未知）。判断下列哪些是统计量：① `X₁ + X₂`；② `X̄ − μ`；③ `Σ(Xᵢ − X̄)²`；④ `X₁² + X₂²`；⑤ `X₁/σ²`。
2. 设总体 `X` 的 `E(X) = 3`，`D(X) = 4`，样本容量 `n = 25`。求 `E(X̄)`、`D(X̄)`、`E(S²)`，以及 `σ(X̄)`。
3. 设 `X₁, …, X₈` 来自 `N(0, 9)`。求常数 a 使 `a·ΣXᵢ² ~ χ²(8)`，并求该 χ² 变量的期望与方差。
4. 设 `Y ~ χ²(15)`。已知 `χ²_{0.05}(15) = 24.996`，`χ²_{0.95}(15) = 7.261`。求 `P(7.261 < Y < 24.996)` 与 `P(Y < 7.261)`。
5. 设 `T ~ t(15)`。已知 `t_{0.05}(15) = 1.7531`，`t_{0.025}(15) = 2.1315`。求 `P(T > 1.7531)`、`P(|T| > 2.1315)`、`P(T < −1.7531)`。
6. 设 `F ~ F(10, 10)`，已知 `F_{0.05}(10,10) = 2.98`。求 `F_{0.95}(10,10)`，并求 `P(F > 2.98)`。
7. 设总体 `X ~ N(20, 25)`，抽取容量 `n = 25` 的样本。求 `P(X̄ > 21.5)`。
8. 设总体 `X ~ N(μ, 16)`，样本容量 `n = 17`，求 `P(S² > 25)`（提示：`(n−1)S²/σ² ~ χ²(16)`，已知 `χ²_{0.05}(16) = 26.296`，`χ²_{0.025}(16) = 28.845`）。
9. 设 `X₁, …, X₁₀` 来自 `N(μ, σ²)`，`μ` 未知。写出 `(X̄ − μ)/(S/√10)` 的分布与自由度；若 `S = 2`，`X̄ = 5`，求 `P(X̄ − μ > 1)` 的表达式（不必算出数值）。
10. 设两独立正态总体 `X ~ N(μ₁, σ²)`、`Y ~ N(μ₂, σ²)`（**方差相等但未知**），`n₁ = 8`，`n₂ = 10`，`S₁² = 4`，`S₂² = 6`。求合并方差 `S_w²` 及其自由度。

### 自测题答案

1. ① 是（只含样本）；② 不是（含未知 μ）；③ 是（`X̄` 本身是统计量）；④ 是；⑤ 不是（含未知 `σ²`）。
2. `E(X̄) = μ = 3`；`D(X̄) = σ²/n = 4/25 = 0.16`；`σ(X̄) = √0.16 = 0.4`；`E(S²) = σ² = 4`。
3. `Xᵢ ~ N(0, 9)`，`σ = 3`，故 `Xᵢ/3 ~ N(0,1)`，
   `Σ(Xᵢ/3)² = (1/9)ΣXᵢ² ~ χ²(8)`，即 **a = 1/9**。
   期望 `= 8`，方差 `= 2 × 8 = 16`。
4. `P(Y > 24.996) = 0.05`，`P(Y > 7.261) = 0.95`。
   `P(7.261 < Y < 24.996) = 0.95 − 0.05 = 0.90`
   `P(Y < 7.261) = 1 − P(Y > 7.261) = 1 − 0.95 = 0.05`
5. `P(T > 1.7531) = 0.05`
   `P(|T| > 2.1315) = P(T > 2.1315) + P(T < −2.1315) = 0.025 + 0.025 = 0.05`
   `P(T < −1.7531) = P(T > 1.7531) = 0.05`（对称性）
6. `F_{0.95}(10, 10) = 1/F_{0.05}(10, 10) = 1/2.98 = 0.3356`（**两个自由度相同，交换后不变**）
   `P(F > 2.98) = 0.05`
7. `μ = 20`，`σ² = 25`，`σ = 5`，`n = 25`。
   `D(X̄) = 25/25 = 1`，`σ(X̄) = 1`，`X̄ ~ N(20, 1)`。
   `P(X̄ > 21.5) = 1 − Φ((21.5 − 20)/1) = 1 − Φ(1.5) = 1 − 0.9332 = 0.0668`
8. `n = 17`，`σ² = 16`，`n − 1 = 16`。
   `(n−1)S²/σ² = 16S²/16 = S² ~ χ²(16)`
   `P(S² > 25) = P(χ²(16) > 25)`
   已知 `χ²_{0.05}(16) = 26.296`，`χ²_{0.025}(16) = 28.845`。
   25 < 26.296，故右尾面积 **> 0.05**。用 `χ²_{0.10}(16) = 23.542` 插值：
   `(25 − 23.542)/(26.296 − 23.542) = 1.458/2.754 = 0.529`
   右尾面积 `≈ 0.10 − 0.529 × 0.05 = 0.10 − 0.0265 = 0.074`
   即 `P(S² > 25) ≈ 0.074`（同例 5.8 的插值口径，真实值 `P(χ²(16) > 25) = 0.0698`，插值略偏大）。
9. **口径说明（先读）**：本题按**教材惯例把 `S` 视为已知常数**处理。严格地讲，正态总体中 `X̄` 与 `S` 相互独立，若**真正条件于 `S = 2`**，则 `(X̄ − μ)/(S/√10) = (X̄ − μ)/0.6325` 服从标准正态，尾概率是 `P(Z > 1.5811) = 0.0569`。两者不同是因为前者把 `S/√10` 当成了固定的 0.6325，后者用的是 t 分布。**考试遇到这类题一律按教材惯例（用 t 分布）作答**，本题答案取 0.074。
   由**定理 3**，`(X̄ − μ)/(S/√10) ~ t(9)`。
   `P(X̄ − μ > 1) = P( (X̄−μ)/(S/√10) > 1/(S/√10) )`
   代入 `S = 2`：`S/√10 = 2/3.1623 = 0.6325`，
   故 `P(X̄ − μ > 1) = P(T > 1/0.6325) = P(T > 1.5811)`，其中 `T ~ t(9)`。
   查表 `t_{0.10}(9) = 1.3830`、`t_{0.05}(9) = 1.8331`，本例插值精度差（尾部曲率大，两点插值给出 0.0780，偏高更多），**宜直接用软件算得 `0.0742 ≈ 0.074`**。
10. `S_w² = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2)`
    `= [7 × 4 + 9 × 6]/(8 + 10 − 2) = (28 + 54)/16 = 82/16 = 5.125`
    自由度 `= n₁ + n₂ − 2 = 16`，故 `(X̄−Ȳ−(μ₁−μ₂))/(S_w√(1/8+1/10)) ~ t(16)`。
