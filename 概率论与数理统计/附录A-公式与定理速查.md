## A1 第 1 章 · 随机事件及其概率

### A1.1 事件运算与德摩根律

| 运算 | 记号 | 含义 | 关键公式 |
|---|---|---|---|
| 并 | `A ∪ B` | A、B 至少一个发生 | —— |
| 交 | `AB` 或 `A ∩ B` | A、B 同时发生 | —— |
| 差 | `A − B` | A 发生而 B 不发生 | `A − B = A B̄` |
| 对立 | `Ā` | A 不发生 | `A ∪ Ā = Ω`，`AĀ = ∅` |
| 互斥 | `AB = ∅` | A、B 不能同时发生 | `P(A ∪ B) = P(A) + P(B)` |

**德摩根律（对偶律）**：

`(A ∪ B)‾ = Ā B̄`　　`(AB)‾ = Ā ∪ B̄`

推广：`(∪ᵢ Aᵢ)‾ = ∩ᵢ Āᵢ`，`(∩ᵢ Aᵢ)‾ = ∪ᵢ Āᵢ`

**常用等价变形**：

`A ∪ B = A ∪ (B − A) = A ∪ (BĀ)`　（拆分法）
`A = AB ∪ AB̄`　（按 B 是否发生拆分，全概率的基础）

### A1.2 概率的性质

| 性质 | 公式 | 条件 |
|---|---|---|
| 规范性 | `P(Ω) = 1` | —— |
| 不可能事件 | `P(∅) = 0` | —— |
| 有限可加性 | `P(∪ᵢ₌₁ⁿ Aᵢ) = Σᵢ P(Aᵢ)` | `Aᵢ` 两两互斥 |
| 逆事件 | `P(Ā) = 1 − P(A)` | —— |
| 单调性 | `P(A) ≤ P(B)` | `A ⊂ B` |
| 减法公式 | `P(B − A) = P(B) − P(AB)` | —— |
| 二事件加法 | `P(A ∪ B) = P(A) + P(B) − P(AB)` | —— |
| 三事件加法 | `P(A∪B∪C) = P(A)+P(B)+P(C) − P(AB) − P(AC) − P(BC) + P(ABC)` | —— |

### A1.3 古典概型与几何概型

**古典概型两条件**：① 样本空间有限；② 每个基本事件等可能。

`P(A) = k/n = A 包含的基本事件数 / 基本事件总数`

**排列组合工具箱**：

| 名称 | 公式 | 典型场景 |
|---|---|---|
| 排列（不重复） | `A(n,m) = n!/(n−m)!` | 排队、名次 |
| 组合 | `C(n,m) = n!/[m!(n−m)!]` | 抽球（不放回）、选人 |
| 可重复排列 | `nᵐ` | 分房、生日、掷骰子 |
| 分组 | `n!/[m₁!m₂!…]` | 分堆、分书 |
| 环形排列 | `(n−1)!` | 圆桌 |

**超几何概型**（`N` 件中 `M` 件次品，取 `n` 件，恰有 `k` 件次品）：

`P = C(M, k) · C(N − M, n − k) / C(N, n)`

**几何概型**（等可能地落在区域 `Ω` 中）：

`P(A) = μ(A的度量) / μ(Ω的度量)`（长度、面积、体积）

**会面问题**（两人在 `[0,T]` 内独立到达，等待 `t` 分钟）：
`P(能见面) = 1 − (1 − t/T)²`（`0 < t < T`）

### A1.4 条件概率、全概率、贝叶斯

`P(B|A) = P(AB) / P(A)`　（要求 `P(A) > 0`）

**乘法公式**：`P(AB) = P(A) · P(B|A) = P(B) · P(A|B)`
推广：`P(A₁A₂…Aₙ) = P(A₁) P(A₂|A₁) P(A₃|A₁A₂) … P(Aₙ|A₁…A_{n−1})`

**全概率公式**（`B₁, …, Bₙ` 为样本空间的一个**划分**）：

`P(A) = Σᵢ₌₁ⁿ P(Bᵢ) P(A|Bᵢ)`

**贝叶斯公式**：

`P(Bⱼ|A) = P(Bⱼ)P(A|Bⱼ) / [ Σᵢ P(Bᵢ)P(A|Bᵢ) ]`

> 术语：`P(Bⱼ)` 称**先验概率**（Prior），`P(Bⱼ|A)` 称**后验概率**（Posterior）。

### A1.5 独立性

**两事件独立**：`P(AB) = P(A)P(B)`

**独立性的推论**：若 `A, B` 独立，则 `A` 与 `B̄`、`Ā` 与 `B`、`Ā` 与 `B̄` **都独立**。

**三事件相互独立**（四个等式缺一不可）：

```
P(AB)  = P(A)P(B)
P(AC)  = P(A)P(C)
P(BC)  = P(B)P(C)
P(ABC) = P(A)P(B)P(C)
```

> **⚠️ 两两独立 ⇏ 相互独立**（前三个成立推不出第四个）。

**互斥 vs 独立（最易混）**：

| 比较项 | 互斥 | 独立 |
|---|---|---|
| 定义式 | `P(AB) = 0` | `P(AB) = P(A)P(B)` |
| 直观 | 不能同时发生 | 一个发生不影响另一个 |
| 同时成立的条件 | **仅当 `P(A) = 0` 或 `P(B) = 0`** | 同左 |

**n 重伯努利试验（二项概率公式）**：每次成功概率为 `p`，则 n 次中恰好成功 k 次

`Pₙ(k) = C(n, k) pᵏ (1 − p)^{n−k}`，`k = 0, 1, …, n`

## A2 第 2 章 · 随机变量及其分布

### A2.1 分布函数

`F(x) = P(X ≤ x)`，`−∞ < x < +∞`

**五条性质**：

| # | 性质 | 说明 |
|---|---|---|
| 1 | `0 ≤ F(x) ≤ 1` | —— |
| 2 | `F(x)` **单调不减** | `x₁ < x₂ ⟹ F(x₁) ≤ F(x₂)` |
| 3 | `F(−∞) = 0`，`F(+∞) = 1` | 规范性 |
| 4 | `F(x)` **右连续** | `F(x + 0) = F(x)` |
| 5 | `P(a < X ≤ b) = F(b) − F(a)` | 计算区间概率 |

**离散型**：`F(x) = Σ_{xᵢ ≤ x} pᵢ`（**阶梯函数**，跳跃高度 = `pᵢ`）
**连续型**：`F(x) = ∫_{−∞}^{x} f(t) dt`，且 `f(x) = F'(x)`（在连续点）

### A2.2 常见分布总表（必背）

| 分布 | 记号 | 分布律 / 密度 | 期望 | 方差 |
|---|---|---|---|---|
| 0-1 分布 | `B(1, p)` | `P(X=1)=p`，`P(X=0)=1−p` | `p` | `p(1−p)` |
| 二项分布 | `B(n, p)` | `C(n,k)pᵏ(1−p)^{n−k}` | `np` | `np(1−p)` |
| 泊松分布 | `P(λ)` | `λᵏe^{−λ}/k!` | `λ` | `λ` |
| 几何分布 | `G(p)` | `(1−p)^{k−1}p` | `1/p` | `(1−p)/p²` |
| 超几何分布 | `H(N,M,n)` | `C(M,k)C(N−M,n−k)/C(N,n)` | `nM/N` | `n·(M/N)(1−M/N)(N−n)/(N−1)` |
| 均匀分布 | `U(a, b)` | `1/(b−a)`，`a<x<b` | `(a+b)/2` | `(b−a)²/12` |
| 指数分布 | `E(λ)` | `λe^{−λx}`，`x>0` | `1/λ` | `1/λ²` |
| 正态分布 | `N(μ, σ²)` | `(1/(√(2π)σ))e^{−(x−μ)²/(2σ²)}` | `μ` | `σ²` |

**上表说明（逐个记牢）**：

- **0-1 分布**：一次试验只有成功/失败两种结果。**是二项分布 `n = 1` 的特例**。典型应用：抛一次硬币、产品是否合格。
- **二项分布 `B(n, p)`**：`n` 重伯努利试验中成功次数。典型应用：n 次射击命中数、n 个产品中次品数。
- **泊松分布 `P(λ)`**：单位时间/面积内稀有事件发生次数。**是二项分布 `n→∞, np→λ` 的极限**。典型应用：呼叫次数、放射性衰变、网页请求。
- **几何分布 `G(p)`**：首次成功所需的试验次数。**具无记忆性**。典型应用：首次命中所需射击次数。
- **超几何分布 `H(N,M,n)`**：**不放回**抽样中的次品数。典型应用：从 N 件产品中不放回抽 n 件。**当 N 很大时近似 `B(n, M/N)`**。
- **均匀分布 `U(a,b)`**：在区间上等可能取值。**是「等可能」的连续版本**。典型应用：随机数生成、舍入误差。
- **指数分布 `E(λ)`**：等待时间 / 寿命。**是唯一具无记忆性的连续分布**：`P(X > s+t | X > s) = P(X > t)`。典型应用：元件寿命、泊松过程的到达间隔。
- **正态分布 `N(μ, σ²)`**：**最重要**。`μ` 决定位置，`σ` 决定胖瘦。典型应用：测量误差、身高体重、考试成绩。

### A2.3 抽样三大分布（χ²、t、F）

| 分布 | 构造 | 自由度 | 期望 | 方差 | 取值范围 |
|---|---|---|---|---|---|
| χ² | `χ² = X₁² + … + Xₙ²`，`Xᵢ ~ N(0,1)` 独立 | `n` | `n` | `2n` | `(0, +∞)` |
| t | `t = X / √(Y/n)`，`X~N(0,1)`，`Y~χ²(n)` 独立 | `n` | `0`（`n>1`） | `n/(n−2)`（`n>2`） | `(−∞, +∞)` |
| F | `F = (U/n₁)/(V/n₂)`，`U~χ²(n₁)`，`V~χ²(n₂)` 独立 | `(n₁, n₂)` | `n₂/(n₂−2)`（`n₂>2`） | 见教材 | `(0, +∞)` |

**χ² 的可加性**：若 `χ₁² ~ χ²(n₁)`、`χ₂² ~ χ²(n₂)` 独立，则 `χ₁² + χ₂² ~ χ²(n₁ + n₂)`

**F 的倒数性质**：若 `F ~ F(n₁, n₂)`，则 `1/F ~ F(n₂, n₁)`

### A2.4 正态分布的计算

**标准化**：`X ~ N(μ, σ²)` ⟹ `Z = (X − μ)/σ ~ N(0, 1)`

`P(X ≤ x) = Φ((x − μ)/σ)`
`P(a < X ≤ b) = Φ((b−μ)/σ) − Φ((a−μ)/σ)`

**对称性**：`Φ(−x) = 1 − Φ(x)`

**上 α 分位点**：`P(X > z_α) = α`，即 `z_α = −z_{1−α}`，`Φ(z_α) = 1 − α`

**3σ 原则**：`P(|X − μ| < σ) = 0.6826`，`P(|X − μ| < 2σ) = 0.9544`，`P(|X − μ| < 3σ) = 0.9974`

（以上是**四位标准正态表值**口径；真值依次为 `0.6827 / 0.9545 / 0.9973`。本笔记第 2、4 章与附录 A 三处口径一致，**考试按附表查表值写**。）

**线性变换**：`aX + b ~ N(aμ + b, a²σ²)`

**可加性**：`X ~ N(μ₁, σ₁²)`、`Y ~ N(μ₂, σ₂²)` 独立 ⟹ `X ± Y ~ N(μ₁ ± μ₂, σ₁² + σ₂²)`

### A2.5 随机变量函数的分布

**离散型**：把 `X` 的取值逐个代入 `g(·)`，**相同的值合并概率**。

**连续型（分布函数法，通用）**：三步
① `F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y)`；
② 解不等式化为关于 `X` 的事件；
③ 用 `F_X` 表示，再对 `y` 求导得 `f_Y(y)`。

**连续型（公式法，要求 `g` 严格单调可导）**：

`f_Y(y) = f_X(h(y)) · |h'(y)|`，其中 `h = g⁻¹`

**两个必记结论**：

| 变换 | 结论 |
|---|---|
| `X ~ N(μ, σ²)`，`Y = aX + b`（`a ≠ 0`） | `Y ~ N(aμ + b, a²σ²)` |
| `X ~ U(0,1)`，`Y = −ln(1−X)/λ` | `Y ~ E(λ)`（**逆变换抽样法**） |

## A3 第 3 章 · 多维随机变量

### A3.1 联合分布

`F(x, y) = P(X ≤ x, Y ≤ y)`

**四条性质**：① `0 ≤ F ≤ 1`；② 对每个变量单调不减；③ 右连续；④ `F(−∞,y)=F(x,−∞)=0`，`F(+∞,+∞)=1`

**矩形公式（判别能否为联合分布函数的利器）**：

`P(a < X ≤ b, c < Y ≤ d) = F(b,d) − F(a,d) − F(b,c) + F(a,c) ≥ 0`

**二维连续型**：`f(x,y) ≥ 0`，`∫∫ f(x,y)dxdy = 1`，`F(x,y) = ∫_{−∞}^{y}∫_{−∞}^{x} f(u,v)dudv`

**二维均匀分布**：`f(x,y) = 1/S_D`（在区域 D 内），其中 `S_D` 为 D 的面积。

**二维正态分布** `N(μ₁, μ₂, σ₁², σ₂², ρ)` 的五条结论：

① 边缘分布仍为正态：`X ~ N(μ₁, σ₁²)`，`Y ~ N(μ₂, σ₂²)`；
② **`X, Y` 独立 ⟺ `ρ = 0`**（**这是正态分布独有的性质**）；
③ 条件分布仍是正态；
④ 线性组合仍为正态；
⑤ 若 `ρ = 0`，则 `X, Y` **既独立又不相关**。

### A3.2 边缘分布与条件分布

| 类型 | 边缘分布 | 条件分布 |
|---|---|---|
| 离散 | `p_{X}(xᵢ) = Σⱼ p_{ij}`（**行和给 X**） | `p_{Y\|X}(yⱼ\|xᵢ) = p_{ij}/p_{X}(xᵢ)` |
| 离散 | `p_{Y}(yⱼ) = Σᵢ p_{ij}`（**列和给 Y**） | `p_{X\|Y}(xᵢ\|yⱼ) = p_{ij}/p_{Y}(yⱼ)` |
| 连续 | `f_X(x) = ∫_{−∞}^{+∞} f(x,y)dy` | `f_{Y\|X}(y\|x) = f(x,y)/f_X(x)` |
| 连续 | `f_Y(y) = ∫_{−∞}^{+∞} f(x,y)dx` | `f_{X\|Y}(x\|y) = f(x,y)/f_Y(y)` |

> **记忆口诀**：**离散「行和给 X、列和给 Y」；连续「积掉谁就得到另一个的边缘」。**

### A3.3 独立性

**判定（三个等价条件，任选其一）**：

① 对一切 `x, y`：`F(x, y) = F_X(x) · F_Y(y)`；
② 离散：对一切 `i, j`：`p_{ij} = p_{X}(xᵢ) · p_{Y}(yⱼ)`；
③ 连续：对一切 `x, y`：`f(x, y) = f_X(x) · f_Y(y)`。

**快速判据（连续型，考场上最实用）**：若联合密度可写成

`f(x, y) = g(x) · h(y)`（`x ∈ A`，`y ∈ B`，**且区域是矩形**）

则 `X, Y` 独立。

> **⚠️ 两个陷阱**：
> ① **可分离还不够，定义域必须是矩形**。`f(x,y) = 8xy`（`0 < x < y < 1`）虽可分离，但区域是三角形，**不独立**。
> ② **不相关 ⇏ 独立**（除二维正态外）。反例：`X ~ U(−1,1)`，`Y = X²`，则 `ρ = 0` 但 `Y` 完全由 `X` 决定。

### A3.4 两个随机变量函数的分布

**① 和的分布（卷积公式）**：`Z = X + Y`

离散：`p_Z(z) = Σᵢ p_X(xᵢ) p_Y(z − xᵢ)`
连续（独立）：`f_Z(z) = ∫_{−∞}^{+∞} f_X(x) f_Y(z − x) dx`

**② max / min 的分布（`X, Y` 独立）**：

```
F_max(z) = P(max(X,Y) ≤ z) = F_X(z) · F_Y(z)
F_min(z)  = P(min(X,Y) ≤ z) = 1 − [1 − F_X(z)][1 − F_Y(z)]
```

**③ 可加性表（`X, Y` 独立）**：

| 分布类型 | 可加性结论 |
|---|---|
| 正态 | `N(μ₁,σ₁²) + N(μ₂,σ₂²) = N(μ₁+μ₂, σ₁²+σ₂²)` |
| 泊松 | `P(λ₁) + P(λ₂) = P(λ₁ + λ₂)` |
| 二项 | `B(n₁,p) + B(n₂,p) = B(n₁+n₂, p)`（**要求 `p` 相同**） |
| χ² | `χ²(n₁) + χ²(n₂) = χ²(n₁ + n₂)` |
| Γ 分布 | `Γ(α₁,λ) + Γ(α₂,λ) = Γ(α₁+α₂, λ)`（**要求 `λ` 相同**） |

> **⚠️ 不可加**：均匀分布、指数分布（**参数相同时也不可加**，但 `n` 个独立同分布的 `E(λ)` 之和是 `Γ(n, λ)`）。

**④ 一般函数的分布（雅可比法）**：设 `(X, Y) → (U, V)` 是一一变换，反解出 `x = x(u,v)`，`y = y(u,v)`，则

`f_{UV}(u, v) = f_{XY}(x(u,v), y(u,v)) · |J|`，其中 `J = ∂(x,y)/∂(u,v)` 是雅可比行列式。

## A4 第 4 章 · 数字特征、大数定律与中心极限定理

### A4.1 数学期望

**离散**：`E(X) = Σᵢ xᵢ pᵢ`（要求 `Σ|xᵢ|pᵢ < ∞`）
**连续**：`E(X) = ∫_{−∞}^{+∞} x f(x) dx`（要求 `∫|x|f(x)dx < ∞`）

**随机变量函数的期望（无意识统计学家定理）**：

`E[g(X)] = Σᵢ g(xᵢ) pᵢ`　或　`E[g(X)] = ∫_{−∞}^{+∞} g(x) f(x) dx`

二维：`E[g(X,Y)] = ∫∫ g(x,y) f(x,y) dx dy`

> **⚠️ 一般 `E[g(X)] ≠ g(E(X))`**（如 `E(X²) ≠ [E(X)]²`）。

**期望的性质**：

| # | 性质 | 是否需要独立 |
|---|---|---|
| 1 | `E(C) = C` | —— |
| 2 | `E(CX) = C·E(X)` | —— |
| 3 | **`E(X + Y) = E(X) + E(Y)`** | **不需要** |
| 4 | `E(XY) = E(X)E(Y)` | **不相关即可**（独立当然更可以；即独立 ⟹ 成立，不相关 ⟹ 也成立） |

推广：`E(Σᵢ aᵢXᵢ + b) = Σᵢ aᵢE(Xᵢ) + b`（**永远不需要独立**）

### A4.2 方差

**定义**：`D(X) = Var(X) = E{[X − E(X)]²}`

**计算捷径（最常用）**：

`D(X) = E(X²) − [E(X)]²`

**性质**：

| # | 性质 | 说明 |
|---|---|---|
| 1 | `D(C) = 0` | 常数无波动 |
| 2 | **`D(CX) = C²D(X)`** | **提出常数要平方** |
| 3 | `D(X + C) = D(X)` | 平移不改变波动 |
| 4 | **`D(X ± Y) = D(X) + D(Y) ± 2Cov(X,Y)`** | 一般情形 |
| 5 | `D(X ± Y) = D(X) + D(Y)` | **需要不相关** |

**切比雪夫不等式**（不需要知道分布）：

`P{|X − E(X)| ≥ ε} ≤ D(X)/ε²`　或　`P{|X − E(X)| < ε} ≥ 1 − D(X)/ε²`

**标准化变量**：`X* = (X − μ)/σ`，则 `E(X*) = 0`，`D(X*) = 1`

### A4.3 协方差与相关系数

**协方差**：`Cov(X, Y) = E{[X − E(X)][Y − E(Y)]} = E(XY) − E(X)E(Y)`

**相关系数**：`ρ_{XY} = Cov(X,Y) / [√(D(X)) · √(D(Y))]`

**性质**：

| # | 性质 |
|---|---|
| 1 | `Cov(X, X) = D(X)` |
| 2 | `Cov(X, Y) = Cov(Y, X)`（对称） |
| 3 | `Cov(aX + b, cY + d) = ac·Cov(X, Y)` |
| 4 | `Cov(X₁ + X₂, Y) = Cov(X₁, Y) + Cov(X₂, Y)` |
| 5 | **`\|ρ_{XY}\| ≤ 1`**（柯西-施瓦茨） |
| 6 | **`\|ρ_{XY}\| = 1` ⟺ `Y = aX + b`（`a ≠ 0`）**，即线性关系 |

**不相关**：`ρ_{XY} = 0` ⟺ `Cov(X,Y) = 0` ⟺ `E(XY) = E(X)E(Y)` ⟺ `D(X+Y) = D(X) + D(Y)`

> **⚠️ 三大关系辨析**：
> - **独立 ⟹ 不相关**（反之不成立）；
> - **不相关 ⇏ 独立**（**例外：二维正态时两者等价**）；
> - **独立 ⟹ `D(X+Y) = D(X)+D(Y)`**，**不相关也成立**。

**方差的和式公式（做题常用）**：

`D(Σᵢ Xᵢ) = Σᵢ D(Xᵢ) + 2Σ_{i<j} Cov(Xᵢ, Xⱼ)`

**矩**：`k` 阶原点矩 `E(Xᵏ)`；`k` 阶中心矩 `E{[X − E(X)]ᵏ}`

### A4.4 大数定律与中心极限定理

**依概率收敛**：`lim_{n→∞} P{|Yₙ − a| < ε} = 1`（对任意 `ε > 0`），记 `Yₙ →P a`

**三个大数定律**：

| 名称 | 条件 | 结论 |
|---|---|---|
| **切比雪夫大数定律** | `Xᵢ` 两两不相关，`D(Xᵢ) ≤ C`（**方差一致有界**） | `(1/n)ΣXᵢ − (1/n)ΣE(Xᵢ) →P 0` |
| **伯努利大数定律** | `n` 重伯努利试验，频率 `fₙ = n_A/n` | `fₙ →P p`（**频率稳定于概率**） |
| **辛钦大数定律** | `Xᵢ` 独立同分布，`E(Xᵢ) = μ` 存在 | `(1/n)ΣXᵢ →P μ` |

**两个中心极限定理**：

| 名称 | 条件 | 结论 |
|---|---|---|
| **林德伯格-列维（独立同分布 CLT）** | `Xᵢ` 独立同分布，`E(Xᵢ)=μ`，`D(Xᵢ)=σ²` | `(ΣXᵢ − nμ)/(σ√n) →d N(0,1)` |
| **棣莫弗-拉普拉斯（二项 CLT）** | `X ~ B(n, p)` | `(X − np)/√(np(1−p)) →d N(0,1)` |

**实用近似式**（`n` 较大时）：

`Σᵢ₌₁ⁿ Xᵢ ≈ N(nμ, nσ²)`，　`X̄ ≈ N(μ, σ²/n)`

**连续性修正（二项分布用正态近似时必加）**：

`P(X ≤ k) ≈ Φ((k + 0.5 − np)/√(np(1−p)))`
`P(X ≥ k) ≈ 1 − Φ((k − 0.5 − np)/√(np(1−p)))`

**泊松近似 vs 正态近似（选择表）**：

| 条件 | 用哪种近似 |
|---|---|
| `n` 大，`p` 小（`np ≤ 10`，经验上 `p ≤ 0.1`） | **泊松近似 `P(np)`** |
| `n` 大，`np` 和 `n(1−p)` 都较大（都 > 10） | **正态近似**（加连续性修正） |
| `n ≤ 20` | 直接算二项分布 |

## A5 第 5 章 · 数理统计的基础知识

### A5.1 基本概念

**总体**（Population）：研究对象的全体。**个体**（Individual）：每个研究对象。
**样本**（Sample）：`X₁, …, Xₙ`，**独立同分布**（i.i.d.）且与总体同分布 —— 称**简单随机样本**。
**统计量**（Statistic）：**不含任何未知参数**的样本函数。

| 名称 | 定义 | 说明 |
|---|---|---|
| 样本均值 | `X̄ = (1/n)Σᵢ Xᵢ` | 最常用 |
| 样本方差 | `S² = (1/(n−1))Σᵢ (Xᵢ − X̄)²` | **分母 `n−1`** |
| 样本标准差 | `S = √(S²)` | —— |
| 样本 k 阶原点矩 | `A_k = (1/n)Σᵢ Xᵢᵏ` | `A₁ = X̄` |
| 样本 k 阶中心矩 | `B_k = (1/n)Σᵢ (Xᵢ − X̄)ᵏ` | `B₂ ≠ S²`（分母不同） |
| 样本极差 | `R = X₍ₙ₎ − X₍₁₎` | —— |

**为什么 `S²` 的分母是 `n − 1`**：因为 `E(S²) = σ²`（**无偏**）。若用 `n`，则 `E[(1/n)Σ(Xᵢ−X̄)²] = (n−1)σ²/n < σ²`，**系统性低估方差**。可理解为：`X̄` 本身占用了 1 个自由度。

### A5.2 常用统计量的分布

**核心结论（设 `X₁, …, Xₙ` 是来自 `N(μ, σ²)` 的简单随机样本）**：

| 统计量 | 分布 | 说明 |
|---|---|---|
| `X̄` | `N(μ, σ²/n)` | `E(X̄) = μ`，`D(X̄) = σ²/n` |
| `(X̄ − μ)/(σ/√n)` | `N(0, 1)` | σ 已知 |
| `(n−1)S²/σ²` | `χ²(n − 1)` | **自由度为 `n − 1`** |
| `(X̄ − μ)/(S/√n)` | `t(n − 1)` | σ 未知 |
| `S²` 与 `X̄` | **相互独立** | 正态总体独有 |

### A5.3 三大分布总表

| 项目 | χ² 分布 | t 分布 | F 分布 |
|---|---|---|---|
| **构造** | `Σᵢ₌₁ⁿ Xᵢ²`，`Xᵢ~N(0,1)` i.i.d. | `X/√(Y/n)`，`X~N(0,1)`、`Y~χ²(n)` 独立 | `(U/n₁)/(V/n₂)`，`U~χ²(n₁)`、`V~χ²(n₂)` 独立 |
| **自由度** | `n` | `n` | `(n₁, n₂)` |
| **期望** | `n` | `0`（`n > 1`） | `n₂/(n₂−2)`（`n₂ > 2`） |
| **方差** | `2n` | `n/(n−2)`（`n > 2`） | 见教材 |
| **范围** | `(0, +∞)` | `(−∞, +∞)` | `(0, +∞)` |
| **图形** | 右偏，`n` 大时趋对称 | 对称，**比正态「厚尾」**，`n→∞` 时趋于 `N(0,1)` | 右偏 |
| **上 α 分位点记号** | `χ²_α(n)` | `t_α(n)` | `F_α(n₁, n₂)` |
| **对称性** | 无 | **`t_{1−α}(n) = −t_α(n)`** | **`F_{1−α}(n₁,n₂) = 1/F_α(n₂,n₁)`** |

### A5.4 正态总体的抽样分布定理（四大定理）

| # | 条件 | 结论 |
|---|---|---|
| 1 | `X₁,…,Xₙ` i.i.d. `N(μ,σ²)` | `X̄ ~ N(μ, σ²/n)`，即 `(X̄−μ)/(σ/√n) ~ N(0,1)` |
| 2 | 同上 | `(n−1)S²/σ² ~ χ²(n−1)`，且 **`X̄` 与 `S²` 独立** |
| 3 | 同上 | `(X̄−μ)/(S/√n) ~ t(n−1)` |
| 4 | 两总体独立：`X~N(μ₁,σ₁²)` 取 `n₁` 个，`Y~N(μ₂,σ₂²)` 取 `n₂` 个 | 见下表 |

**两正态总体情形**：

| 条件 | 统计量 | 分布 |
|---|---|---|
| `σ₁², σ₂²` 都已知 | `[(X̄−Ȳ) − (μ₁−μ₂)] / √(σ₁²/n₁ + σ₂²/n₂)` | `N(0, 1)` |
| `σ₁² = σ₂² = σ²` 未知 | `[(X̄−Ȳ) − (μ₁−μ₂)] / (S_w√(1/n₁ + 1/n₂))` | `t(n₁ + n₂ − 2)` |
| 任意 `σ₁², σ₂²` 未知 | `S₁²/S₂² · σ₂²/σ₁²` | `F(n₁−1, n₂−1)` |

其中**合并方差** `S_w² = [(n₁−1)S₁² + (n₂−1)S₂²] / (n₁ + n₂ − 2)`

## A6 第 6 章 · 参数估计

### A6.1 点估计的两种方法

**① 矩估计法（替换原理）**：用**样本矩**替换**总体矩**。

步骤：① 写出总体矩 `E(X)`、`E(X²)`…（含未知参数）；② 令 `E(X) = X̄`、`E(X²) = A₂`…；③ 解方程组得估计量。

一个参数用一阶矩即可：**`θ̂ = θ̂(X̄)`**。

**② 最大似然估计法（MLE）四步法**：

① 写出**似然函数** `L(θ)`：
连续型 `L(θ) = Πᵢ₌₁ⁿ f(xᵢ; θ)`；离散型 `L(θ) = Πᵢ₌₁ⁿ P(X = xᵢ; θ)`；
② 取**对数** `ln L(θ)`（把乘积变成求和，便于求导）；
③ **求导令零**：`d ln L(θ)/dθ = 0`，解出**驻点**；
④ **验证是最大值**（二阶导 < 0，或由问题本身保证）。

> **⚠️ 非正则情形（必须掌握）**：若似然函数的支撑集依赖于未知参数（如 `X ~ U(0, θ)`），**不能用求导法**。此时 `L(θ)` 关于 `θ` 是**单调的**，应**由单调性结合样本取值范围**确定最大值点。
> **结论**：`X ~ U(0, θ)` 的 MLE 是 **`θ̂ = max(X₁, …, Xₙ) = X₍ₙ₎`**（不是 `2X̄`；**`2X̄` 是矩估计**）。

**③ 不变性原理**：若 `θ̂` 是 `θ` 的 MLE，`g(·)` 是任意函数，则 **`g(θ̂)` 是 `g(θ)` 的 MLE**。

### A6.2 估计量的评选标准

**① 无偏性（Unbiasedness）**：`E(θ̂) = θ` 对一切 `θ` 成立。

**② 有效性（Efficiency）**：在都无偏的前提下，**方差越小越有效**。`D(θ̂₁) < D(θ̂₂)` 称 `θ̂₁` 比 `θ̂₂` 有效。

**③ 一致性（相合性，Consistency）**：`θ̂ₙ →P θ`（`n → ∞`），即 `lim_{n→∞} P{|θ̂ₙ − θ| < ε} = 1`。

**常用无偏估计量**：

| 估计对象 | 估计量 | 是否无偏 |
|---|---|---|
| `μ` | `X̄` | **无偏** |
| `σ²` | `S² = (1/(n−1))Σ(Xᵢ−X̄)²` | **无偏** |
| `σ²` | `B₂ = (1/n)Σ(Xᵢ−X̄)²` | 有偏（`= (n−1)σ²/n`） |
| `p`（0-1 分布） | `X̄` | **无偏** |

### A6.3 区间估计

**置信区间的含义**：反复抽样多次，**约有 `1 − α` 比例的区间包含真值 `θ`**。

> **⚠️ 正确解读**：`θ` 是**常数**（不是随机变量），**随机的是区间**。**不能说「`θ` 落入区间的概率是 `1 − α`」**，只能说「区间覆盖 `θ` 的概率是 `1 − α`」。

**枢轴量法四步**：① 构造含 `θ` 但不含其他未知参数的函数 `G`；② 确定 `G` 的分布；③ 由 `P{a < G < b} = 1 − α` 解出 `θ` 的范围；④ 代入样本值。

**区间估计选择表（考试核心）**：

| 待估参数 | 条件 | 枢轴量 | 分布 | 置信区间 |
|---|---|---|---|---|
| `μ` | **σ 已知** | `(X̄−μ)/(σ/√n)` | `N(0,1)` | `X̄ ± z_{α/2}·σ/√n` |
| `μ` | **σ 未知** | `(X̄−μ)/(S/√n)` | `t(n−1)` | `X̄ ± t_{α/2}(n−1)·S/√n` |
| `σ²` | `μ` 未知 | `(n−1)S²/σ²` | `χ²(n−1)` | `( (n−1)S²/χ²_{α/2}(n−1), (n−1)S²/χ²_{1−α/2}(n−1) )` |
| `μ₁ − μ₂` | 两 `σ` 已知 | —— | `N(0,1)` | `(X̄−Ȳ) ± z_{α/2}√(σ₁²/n₁ + σ₂²/n₂)` |
| `μ₁ − μ₂` | `σ₁²=σ₂²` 未知 | —— | `t(n₁+n₂−2)` | `(X̄−Ȳ) ± t_{α/2}(n₁+n₂−2)·S_w√(1/n₁+1/n₂)` |
| `σ₁²/σ₂²` | `μ₁, μ₂` 未知 | `(S₁²/S₂²)·(σ₂²/σ₁²)` | `F(n₁−1, n₂−1)` | `( S₁²/S₂²·1/F_{α/2}(n₁−1,n₂−1),　S₁²/S₂²·1/F_{1−α/2}(n₁−1,n₂−1) )` |

> **`σ²` 的区间「大配小」**：下限用**大的分位点** `χ²_{α/2}`，上限用**小的分位点** `χ²_{1−α/2}`。道理是 `σ²` 出现在分母上：分位点越大 ⟹ 算出的端点值越小，所以**大的分位点给出下限、小的分位点给出上限**（端点都落在「内侧」才正确，配反了区间会颠倒）。
> **`F` 的区间同理**：下限配 `F_{α/2}`（大），上限配 `F_{1−α/2}`（小）。

**单侧置信区间**：

| 类型 | 区间（σ 未知，估 `μ`） |
|---|---|
| 单侧上限（`μ < ?`） | `(−∞, X̄ + t_α(n−1)·S/√n)` |
| 单侧下限（`μ > ?`） | `(X̄ − t_α(n−1)·S/√n, +∞)` |

**误差限与样本容量**（`σ` 已知，双侧）：

误差限 `Δ = z_{α/2}·σ/√n` ⟹ **`n = (z_{α/2}·σ / Δ)²`**（**向上取整**）

## A7 第 7 章 · 假设检验

### A7.1 基本概念

**假设**：`H₀`（原假设 / 零假设）与 `H₁`（备择假设）。

**设定原则（必背）**：**① 把「想证明的结论」放在 `H₁`；② 等号必须出现在 `H₀` 中。**

**两类错误**：

| 名称 | 含义 | 概率 | 类比 |
|---|---|---|---|
| **第一类错误（弃真）** | `H₀` 真却拒绝 `H₀` | `α`（显著性水平） | 冤枉好人 |
| **第二类错误（取伪）** | `H₀` 假却接受 `H₀` | `β` | 放过坏人 |

> **⚠️ 样本量固定时，`α` 与 `β` 不能同时减小**。要同时减小，只能**增大样本量**。
> **⚠️ 「接受 `H₀`」应表述为「没有足够证据拒绝 `H₀`」**，不等于「证明 `H₀` 成立」。

**假设检验五步法**：
① 提出 `H₀` 与 `H₁`；② 选择检验统计量；③ 在 `H₀` 下确定统计量的分布；④ 由 `α` 确定拒绝域；⑤ 代入样本值，作判断。

**拒绝域的三种形式**：

| 备择假设 | 拒绝域 | 名称 |
|---|---|---|
| `H₁: μ ≠ μ₀` | `\|T\| > 临界值` | **双侧检验** |
| `H₁: μ > μ₀` | `T > 临界值` | **右侧检验** |
| `H₁: μ < μ₀` | `T < 临界值` | **左侧检验** |

> **⚠️ 拒绝域的位置由 `H₁` 决定，不是由 `H₀` 决定。**

**p 值法**：**p 值 = 在 `H₀` 成立下，出现「当前样本或更极端情况」的概率**。
判断：**`p < α` ⟹ 拒绝 `H₀`**。

**假设检验与区间估计的等价性**：`H₀: μ = μ₀` 在水平 `α` 下不被拒绝 ⟺ `μ₀` 落在 `μ` 的 `1 − α` 置信区间内。

### A7.2 检验统计量选择表（考试核心）

**单正态总体**：

| 检验对象 | `H₀` | 条件 | 检验统计量 | 分布 |
|---|---|---|---|---|
| 均值 `μ` | `μ = μ₀` | **σ 已知** | `Z = (X̄ − μ₀)/(σ/√n)` | `N(0,1)` |
| 均值 `μ` | `μ = μ₀` | **σ 未知** | `T = (X̄ − μ₀)/(S/√n)` | `t(n−1)` |
| 方差 `σ²` | `σ² = σ₀²` | `μ` 未知 | `χ² = (n−1)S²/σ₀²` | `χ²(n−1)` |

**双正态总体**：

| 检验对象 | 条件 | 检验统计量 | 分布 |
|---|---|---|---|
| `μ₁ = μ₂` | 两 `σ` **已知** | `Z = (X̄−Ȳ)/√(σ₁²/n₁ + σ₂²/n₂)` | `N(0,1)` |
| `μ₁ = μ₂` | `σ₁² = σ₂²` **未知** | `T = (X̄−Ȳ)/(S_w√(1/n₁+1/n₂))` | `t(n₁+n₂−2)` |
| `μ₁ = μ₂` | **配对数据** | `T = D̄/(S_D/√n)`（`Dᵢ = Xᵢ − Yᵢ`） | `t(n−1)` |
| `σ₁² = σ₂²` | `μ₁, μ₂` 未知 | `F = S₁²/S₂²` | `F(n₁−1, n₂−1)` |

> **⚠️ 配对数据必须化为单总体 t 检验**（先作差 `Dᵢ = Xᵢ − Yᵢ`，再对 `D` 做单样本 t 检验）。**配对数据用两独立样本 t 检验是实质性错误。**

**一般总体（大样本，`n ≥ 30`，教材 7.4 节）**：

| 检验对象 | 检验统计量 | 分布（近似） |
|---|---|---|
| `μ = μ₀`（σ 未知） | `Z = (X̄ − μ₀)/(S/√n)` | `N(0,1)`（由 CLT） |
| `μ₁ = μ₂` | `Z = (X̄−Ȳ)/√(S₁²/n₁ + S₂²/n₂)` | `N(0,1)` |
| `p = p₀`（0-1 分布） | `Z = (X̄ − p₀)/√(p₀(1−p₀)/n)` | `N(0,1)` |

### A7.3 χ² 拟合优度检验（分布拟合检验）

**用途**：检验总体是否服从**某个指定的分布**。

**步骤**：
① `H₀`：总体服从指定的分布 `F₀(x)`；`H₁`：不服从；
② 把样本分成 `k` 个**互不相交**的区间 `A₁, …, A_k`；
③ 计算**理论频数** `npᵢ`（`pᵢ = P(X ∈ Aᵢ)`，用 `F₀` 算；**若 `F₀` 含 `r` 个需估计的未知参数，先估出它们再算 `pᵢ`**）；
④ 计算检验统计量

`χ² = Σᵢ₌₁ᵏ (fᵢ − npᵢ)² / (npᵢ)`，其中 `fᵢ` 是区间 `Aᵢ` 中的**实际频数**

⑤ 在 `H₀` 下 **`χ² ~ χ²(k − r − 1)`**（`r` = 需估计的参数个数）；
⑥ **拒绝域永远在右侧**：`χ² > χ²_α(k − r − 1)`。

**使用条件**：**每个区间的理论频数 `npᵢ ≥ 5`**。若不满足，**合并相邻区间**（合并后 `k` 相应减小）。

> **⚠️ 三个易错点**：① **自由度是 `k − r − 1`**，不是 `k − 1`（`r = 0` 时才是 `k − 1`）；② **拒绝域一定在右侧**（`χ²` 越大说明观测与理论偏离越远）；③ **必须先合并 `npᵢ < 5` 的区间**。

## A8 第 8 章 · 方差分析与回归分析

### A8.1 单因素方差分析

**模型**：`X_{ij} = μ + τᵢ + ε_{ij}`（`i = 1,…,k`，`j = 1,…,nᵢ`），`ε_{ij} ~ N(0, σ²)` 独立。

**三条假定**：① 各总体**正态**；② 各总体**方差相等**（**方差齐性**）；③ 观测**相互独立**。

**要检验的假设**：`H₀: τ₁ = τ₂ = … = τ_k = 0`（各水平均值无差异）vs `H₁: 至少有一个 `τᵢ ≠ 0``

**平方和分解**：

**`ST = SA + SE`**，自由度 **`(n − 1) = (k − 1) + (n − k)`**

**简化计算公式**（令 `C = G²/n`，`G = Σᵢ Σⱼ X_{ij}` 为全部数据之和，`n = Σnᵢ`）：

| 名称 | 公式 |
|---|---|
| 总平方和 | `ST = Σᵢ Σⱼ X_{ij}² − C` |
| 因素平方和 | `SA = Σᵢ (Tᵢ²/nᵢ) − C`（`Tᵢ` = 第 `i` 组数据之和） |
| 误差平方和 | `SE = ST − SA` |

**检验统计量**：**`F = MS_A / MS_E = (SA/(k−1)) / (SE/(n−k)) ~ F(k − 1, n − k)`**

**拒绝域**：**`F > F_α(k − 1, n − k)`（永远在右侧）**

**方差分析表（五列格式，必背）**：

| 来源 | 平方和 | 自由度 | 均方 | F 值 |
|---|---|---|---|---|
| 因素 A | `SA` | `k − 1` | `MS_A = SA/(k−1)` | `F = MS_A/MS_E` |
| 误差 E | `SE` | `n − k` | `MS_E = SE/(n−k)` | —— |
| 总和 T | `ST` | `n − 1` | —— | —— |

### A8.2 双因素方差分析

**无重复试验**（每个 `(Aᵢ, Bⱼ)` 组合只测一次）：

**`ST = SA + SB + SE`**，自由度 **`(ab − 1) = (a − 1) + (b − 1) + (a − 1)(b − 1)`**

| 来源 | 平方和 | 自由度 | F 值 |
|---|---|---|---|
| 因素 A | `SA` | `a − 1` | `F_A = MS_A/MS_E` |
| 因素 B | `SB` | `b − 1` | `F_B = MS_B/MS_E` |
| 误差 E | `SE` | `(a−1)(b−1)` | —— |
| 总和 T | `ST` | `ab − 1` | —— |

> **⚠️ 无重复试验测不出交互作用**（交互作用与误差混杂在一起，都进了 `SE`）。

**有重复试验**（每个组合测 `r` 次）：

**`ST = SA + SB + SA×B + SE`**，自由度 **`(abr − 1) = (a−1) + (b−1) + (a−1)(b−1) + ab(r−1)`**

| 来源 | 自由度 | F 值 |
|---|---|---|
| 因素 A | `a − 1` | `F_A = MS_A/MS_E` |
| 因素 B | `b − 1` | `F_B = MS_B/MS_E` |
| **交互作用 A×B** | `(a−1)(b−1)` | **`F_{A×B} = MS_{A×B}/MS_E`** |
| 误差 E | `ab(r − 1)` | —— |

> **交互作用的判读**：先检验 `H₀: 交互作用不显著`。**若显著，则主效应的解释要谨慎**（主效应可能被交互作用掩盖）。**交互作用图**：折线**平行 ⟹ 无交互**；折线**交叉或扇形张开 ⟹ 有交互**。

### A8.3 一元线性回归

**模型**：`Y = β₀ + β₁x + ε`，`ε ~ N(0, σ²)` 独立。

**最小二乘估计**（令 `Q = Σ(Yᵢ − β₀ − β₁xᵢ)²` 最小）：

| 记号 | 公式 |
|---|---|
| `Lxx` | `Σxᵢ² − n x̄²` |
| `Lyy` | `Σyᵢ² − n ȳ²` |
| `Lxy` | `Σxᵢyᵢ − n x̄ ȳ` |
| **`β̂₁`** | **`Lxy / Lxx`** |
| **`β̂₀`** | **`ȳ − β̂₁ x̄`** |

> **回归直线必过点 `(x̄, ȳ)`**（重要性质，可用于验算）。
> **⚠️ `β̂₀` 一般不能解释为「`x = 0` 时的 `Y`」**，除非 `x = 0` 在数据范围内。

**平方和分解**：**`Lyy = U + Q_e`**

| 名称 | 公式 | 含义 |
|---|---|---|
| 回归平方和 | **`U = β̂₁ · Lxy`** | 回归能解释的部分 |
| 残差平方和 | **`Q_e = Lyy − U`** | 回归不能解释的部分 |

**`σ²` 的无偏估计**：**`σ̂² = Q_e / (n − 2)`**（**自由度 `n − 2`**，因为估了 `β₀`、`β₁` 两个参数）

**显著性检验（三法等价）**：

| 方法 | 统计量 | 分布 | 拒绝域（`H₁: β₁ ≠ 0`） |
|---|---|---|---|
| **F 检验** | `F = U / (Q_e/(n−2))` | `F(1, n−2)` | `F > F_α(1, n−2)` |
| **t 检验** | `t = β̂₁ / √(σ̂²/Lxx)` | `t(n−2)` | `\|t\| > t_{α/2}(n−2)` |
| **相关系数检验** | `r = Lxy/√(Lxx·Lyy)` | 查 `r` 临界值表 | `\|r\| > r_α(n−2)` |

**三者关系（必记）**：**`F = t²`**，且 **`R² = r²`**

**判定系数**：`R² = U/Lyy = 1 − Q_e/Lyy`（`0 ≤ R² ≤ 1`，越大拟合越好）

> **⚠️ `R²` 的陷阱**：`R²` 随自变量个数**单调不减**。**多元回归比较模型必须用调整 `R²`**：`R²_adj = 1 − (1 − R²)(n − 1)/(n − p − 1)`。

**预测区间（`x = x₀`）**：

| 类型 | 标准误 | 区间 |
|---|---|---|
| **均值 `E(Y\|x₀)`** 的置信区间（**窄**） | `σ̂√(1/n + (x₀−x̄)²/Lxx)` | `ŷ₀ ± t_{α/2}(n−2)·标准误` |
| **个体 `Y₀`** 的预测区间（**宽**） | `σ̂√(1 + 1/n + (x₀−x̄)²/Lxx)` | `ŷ₀ ± t_{α/2}(n−2)·标准误` |

> **⚠️ 个体预测区间永远比均值置信区间宽**（根号里多一项 `1`，代表个体的随机误差 `ε`）。**混淆两者是实质性错误。**

### A8.4 多元线性回归

**模型**：`Y = Xβ + ε`，`E(ε) = 0`，`D(ε) = σ²I`

**最小二乘解**：**`β̂ = (X'X)⁻¹ X'Y`**（**正规方程**）

**平方和分解**：`Lyy = U + Q_e`，`U = β̂'X'Y − nȲ²`

**`σ²` 的估计**：`σ̂² = Q_e / (n − p − 1)`（`p` = 自变量个数）

**整体显著性**：`F = (U/p) / (Q_e/(n−p−1)) ~ F(p, n − p − 1)`

**单个系数显著性**：`tⱼ = β̂ⱼ / SE(β̂ⱼ) ~ t(n − p − 1)`

**调整判定系数**：`R²_adj = 1 − (1 − R²)(n − 1)/(n − p − 1)`

> **联系机器学习**：`β̂ = (X'X)⁻¹X'Y` 正是**线性回归的正规方程解**。当 `X'X` 不可逆（多重共线性）时，加 `λI` 得 **`β̂ = (X'X + λI)⁻¹X'Y`**，这就是**岭回归（Ridge Regression）**。

## A9 第 9、10 章（拓展）速查

### A9.1 Bootstrap 方法

**四步流程**：① 从原样本**有放回**抽 `n` 个得 `x*`；② 算统计量 `θ̂*`；③ 重复 `B ≥ 1000` 次；④ 用 `θ̂*₁, …, θ̂*_B` 的经验分布近似抽样分布。

**Bootstrap 标准误**：`SE_boot = √[ (1/(B−1)) Σ_b (θ̂*_b − θ̄*)² ]`（**分母 `B − 1`**）

**百分位法置信区间**：取排序后第 `B·α/2` 个与第 `B·(1−α/2)` 个值。

**关键事实**：约 **63.2%** 的原观测值会出现在每个 Bootstrap 样本中；约 **36.8%** 落在袋外。

**失效情形**：`n < 20`；极值型统计量（`max`、`min`）；时间序列（改用**块 Bootstrap**）；参数在边界。

### A9.2 R 的 d/p/q/r 体系

| 前缀 | 含义 | 输入 → 输出 |
|---|---|---|
| `d` | 密度 / 分布律 | `x` → `f(x)` |
| `p` | 分布函数 | `q` → `P(X ≤ q)` |
| `q` | 分位点 | `p` → 满足 `P(X ≤ x) = p` 的 `x` |
| `r` | 随机数 | `n` → n 个随机数 |

**核心函数**：`t.test`（t 检验）、`var.test`（F 检验）、`aov`（方差分析）、`lm` + `predict`（回归）、`shapiro.test`（正态性）、`chisq.test`（拟合优度）、`boot`（Bootstrap）。

> **三个致命陷阱**：① **`sd` 参数是标准差不是方差**；② **`qnorm` 的输入是左侧累积概率**（求 `z_{0.05}` 用 `qnorm(0.95)`）；③ **`numpy.std()` 必须传 `ddof=1`**。

### A9.3 随机过程

**数字特征**：`μ_X(t) = E[X(t)]`，`D_X(t)`，`R_X(s,t) = E[X(s)X(t)]`，**`C_X(s,t) = R_X(s,t) − μ_X(s)μ_X(t)`**

**泊松过程**（强度 `λ`）：

| 项目 | 结论 |
|---|---|
| `N(t)` 的分布 | `N(t) ~ P(λt)`，`P{N(t)=k} = (λt)ᵏe^{−λt}/k!` |
| 期望与方差 | `E[N(t)] = D[N(t)] = λt` |
| 到达间隔 | `Tₙ ~ E(λ)` 且相互独立，`E(Tₙ) = 1/λ` |
| 第 n 次到达时刻 | `Wₙ = T₁+…+Tₙ ~ Γ(n, λ)`，`E(Wₙ) = n/λ` |
| **关键恒等式** | **`Wₙ > t ⟺ N(t) ≤ n − 1`** |

**维纳过程**（参数 `σ²`）：`W(t) − W(s) ~ N(0, σ²(t−s))`，`W(t) ~ N(0, σ²t)`，**`Cov[W(s), W(t)] = σ²·min(s,t)`**

**马尔可夫链**：

| 项目 | 结论 |
|---|---|
| 马尔可夫性 | `P{X_{n+1}=j\|X_n=i, 过去} = P{X_{n+1}=j\|X_n=i}` |
| 转移矩阵 | `p_ij ≥ 0`，**行和为 1** |
| C-K 方程 | **`P⁽ⁿ⁾ = Pⁿ`**（矩阵乘法），`π(n) = π(0)Pⁿ` |
| 平稳分布 | **`π = πP`** 且 `Σπ_j = 1`（**必须丢掉一个方程**） |

**平稳过程**：

| 项目 | 结论 |
|---|---|
| 宽平稳两条件 | `μ_X(t) = 常数`；`R_X(s,t) = R_X(t−s)` |
| 严 vs 宽 | 严平稳 + 二阶矩存在 ⟹ 宽平稳；**正态过程时等价** |
| 自相关函数性质 | `R(−τ) = R(τ)`；**`\|R(τ)\| ≤ R(0)`**；非负定性 |
| 各态历经性 | 时间平均 = 统计平均（**平稳推不出各态历经**） |
| 维纳-辛钦定理 | `S(ω) = ∫R(τ)e^{−iωτ}dτ` |

**AR(1) 模型** `X_t = φX_{t−1} + ε_t`，`ε_t ~ WN(0, σ²)`：

| 项目 | 结论 |
|---|---|
| 平稳条件 | **`\|φ\| < 1`** |
| 方差 | **`Var(X_t) = σ²/(1 − φ²)`** |
| 自相关函数 | **`ρ(k) = φᵏ`** |
| k 步预测 | **`E(X_{t+k}\|X_t = x) = φᵏx`** |

**AR/MA/ARMA 定阶表**：

| 模型 | ACF | PACF |
|---|---|---|
| **AR(p)** | 拖尾 | **p 步截尾** |
| **MA(q)** | **q 步截尾** | 拖尾 |
| **ARMA(p, q)** | 拖尾 | 拖尾 |
