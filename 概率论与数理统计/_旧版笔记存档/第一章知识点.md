## 一、随机试验与样本空间

**随机试验 E** 的三个特征：

1. 可以在相同条件下重复进行；
2. 每次试验的可能结果不止一个，且能事先明确所有可能结果；
3. 每次试验前不能确定哪个结果会出现。

**基本概念**：

- **样本点 ω**：随机试验的每一个可能结果
- **样本空间 S（或 Ω）**：全体样本点组成的集合
- **随机事件**：样本空间的子集，用大写字母 A、B、C 表示
- **基本事件**：只含一个样本点的单点集
- **必然事件**：S 本身（每次试验必发生）
- **不可能事件**：空集 ∅（每次试验都不发生）

事件 A 发生 ⟺ 试验结果 ω ∈ A。

## 二、事件的关系与运算

| 关系/运算    | 记号                 | 含义                                |
| -------- | ------------------ | --------------------------------- |
| 包含       | A ⊂ B              | A 发生必导致 B 发生                      |
| 相等       | A = B              | A ⊂ B 且 B ⊂ A                     |
| 和（并）     | A ∪ B              | A、B 至少有一个发生                       |
| 积（交）     | A ∩ B（AB）          | A、B 同时发生                          |
| 差        | A − B              | A 发生而 B 不发生，A − B = A − AB = A·B̄ |
| 互斥（互不相容） | AB = ∅             | A、B 不能同时发生                        |
| 对立（互逆）   | A ∪ B = S 且 AB = ∅ | 记 B = Ā，A、B 有且仅有一个发生              |

**运算律**：

- 交换律：A ∪ B = B ∪ A，AB = BA
- 结合律：(A ∪ B) ∪ C = A ∪ (B ∪ C)
- 分配律：A(B ∪ C) = AB ∪ AC；A ∪ (BC) = (A ∪ B)(A ∪ C)
- **德摩根律（对偶律）**：A∪B 的对立 = Ā·B̄；AB 的对立 = Ā ∪ B̄
  - 推广：「至少一个发生」的对立 = 「全都不发生」；「全都发生」的对立 = 「至少一个不发生」

## 三、频率与概率

**频率**：n 次试验中 A 发生 n_A 次，f_n(A) = n_A / n。随 n 增大，频率在某常数附近摆动（**统计规律性**）。

**概率的公理化定义**：P(A) 满足三条公理：

1. **非负性**：P(A) ≥ 0
2. **规范性**：P(S) = 1
3. **可列可加性**：若 A₁, A₂, … 两两互斥，则 P(∪Aᵢ) = ΣP(Aᵢ)

**重要性质**：

- P(∅) = 0
- 有限可加性：互斥事件 A∪B 时 P(A∪B) = P(A) + P(B)
- **逆事件公式**：P(Ā) = 1 − P(A)
- 单调性：A ⊂ B ⟹ P(A) ≤ P(B)，且 P(B − A) = P(B) − P(A)
- **加法公式（必考）**：
  - P(A∪B) = P(A) + P(B) − P(AB)
  - P(A∪B∪C) = P(A)+P(B)+P(C) −P(AB)−P(AC)−P(BC) +P(ABC)
- 0 ≤ P(A) ≤ 1

## 四、古典概型（等可能概型）

**两个条件**：

1. 样本空间只含**有限个**样本点；
2. 每个样本点出现**等可能**。

**公式**：P(A) = A 所含样本点数 k / S 中样本点总数 n

**计数工具**：

- 排列：A(n,m) = n!/(n−m)!
- 组合：C(n,m) = n! / [m!(n−m)!]
- 加法原理 / 乘法原理

常见题型：抽球问题、分房问题、生日问题、超几何分布原型（N 件产品 M 件次品，抽 n 件恰 k 件次品：C(M,k)·C(N−M,n−k) / C(N,n)）。

**几何概型**（部分教材并入本章）：样本点无限但等可能（均匀），P(A) = A 的度量 / S 的度量（长度、面积、体积之比）。典型：会面问题。

## 五、条件概率与乘法公式

**条件概率**：设 P(A) > 0，  
P(B|A) = P(AB) / P(A)

本质：把样本空间压缩到 A 内看 B 发生的比例。条件概率也是概率，满足所有概率性质，如 P(B̄|A) = 1 − P(B|A)。

**乘法公式**：

- P(AB) = P(A)·P(B|A) = P(B)·P(A|B)
- 推广：P(ABC) = P(A)·P(B|A)·P(C|AB)

---

## 六、全概率公式与贝叶斯公式

**划分（完备事件组）**：B₁, B₂, …, Bₙ 两两互斥，且 ∪Bᵢ = S，P(Bᵢ) > 0。

**全概率公式**（由因推果）：  
P(A) = Σᵢ P(Bᵢ)·P(A|Bᵢ)

**贝叶斯公式**（由果溯因，执果求因）：  
P(Bₖ|A) = P(Bₖ)·P(A|Bₖ) / Σᵢ P(Bᵢ)·P(A|Bᵢ)

- P(Bᵢ) 称**先验概率**，P(Bᵢ|A) 称**后验概率**。
- 典型题：产品来自多个厂家的次品率问题、疾病检测假阳性问题。

---

## 七、事件的独立性与伯努利概型

**独立性定义**：P(AB) = P(A)·P(B)，称 A 与 B 相互独立。

- 等价：P(B|A) = P(B)（P(A) > 0 时）
- 若 A 与 B 独立，则 A 与 B̄、Ā 与 B、Ā 与 B̄ 都独立
- 注意：互斥（AB=∅）≠ 独立（除非其中一个概率为 0），两个概念不要混淆

**三个事件相互独立**需同时满足 4 个等式：  
P(AB)=P(A)P(B)、P(AC)=P(A)P(C)、P(BC)=P(B)P(C)、P(ABC)=P(A)P(B)P(C)  
（两两独立推不出相互独立）

**n 重伯努利试验**：重复 n 次，每次只有 A 发生（概率 p）或不发生，各次独立。  
恰发生 k 次的概率（**二项概率公式**）：  
Pₙ(k) = C(n,k)·pᵏ·(1−p)ⁿ⁻ᵏ，k = 0, 1, …, n

## 易错点提醒

1. 对立事件一定互斥，互斥不一定对立。
2. 德摩根律的「交并互换」容易记反：并的对立是立的交。
3. 求「至少一个」优先考虑对立事件：P(至少一个) = 1 − P(全都不)。
4. 条件概率 P(B|A) 中 A 是新样本空间，别和 P(AB) 混淆。
5. 独立用乘法定义，互斥用 AB=∅ 定义，两者判据完全不同。
6. 全概率公式使用前必须先验证 Bᵢ 构成**完备事件组**。
