## 2.1 随机变量

**随机变量（Random Variable）**：设随机试验的样本空间为 `S = {ω}`，若对每一个样本点 `ω ∈ S` 都有一个实数 `X(ω)` 与之对应，则称 `X = X(ω)` 为**随机变量**，常用 X、Y、Z 表示。

**直观理解**：随机变量就是把**试验结果「翻译」成数字**的一个规则。

| 试验 | 样本点 ω | 定义 X(ω) | 随机变量 |
|---|---|---|---|
| 抛硬币 | 正、反 | 正→1，反→0 | `X = 1` 表示正面 |
| 掷骰子 | 1~6 点 | X(ω) = 点数 | X 取 1,2,…,6 |
| 抽检 10 件产品 | 每件合格/次品 | X = 次品数 | X 取 0,1,…,10 |
| 测灯泡寿命 | 每个灯泡 | X = 寿命（小时） | X 取 [0, +∞) |

> **重点**：随机变量是**函数**（从样本空间到实数轴），不是「不确定的数」。它的「随机性」来自 `ω` 的随机性；一旦试验完成，`X(ω)` 就是一个确定的值，称为**样本值**。

**引入随机变量的意义**：把各种千差万别的随机试验统一成「实值函数」后，就能用微积分、求和等分析工具统一处理。这是概率论从「计数」走向「分析」的关键一步。

**分类**：

- **离散型随机变量（Discrete Random Variable）**：全部可能取值是**有限个或可列无限个**（能一个一个列出来）。
- **连续型随机变量（Continuous Random Variable）**：取值充满某个区间，**不能一一列举**。

## 2.2 离散型随机变量及其分布律

### 2.2.1 分布律

**分布律（Probability Distribution）**：设离散型随机变量 X 的所有可能取值为 `x₁, x₂, …`，则 X 取各个值的概率

`pₖ = P(X = xₖ)`，　k = 1, 2, …

称为 X 的分布律，也常写成表格形式：

| X | x₁ | x₂ | … | xₙ | … |
|---|---|---|---|---|---|
| P | p₁ | p₂ | … | pₙ | … |

**两条性质（充要条件）**：

1. **非负性**：`pₖ ≥ 0`，k = 1, 2, …
2. **归一性**：`Σₖ pₖ = 1`

> **重点**：这两条既是性质也是**判定依据**。题目给出含待定常数的分布律时，一律用 `Σpₖ = 1` 求常数。

### 2.2.2 常见离散型分布总表（必背）

| 分布名称 | 记号 | 分布律 `P(X = k)` | 期望 `E(X)` | 方差 `D(X)` | 典型应用场景 |
|---|---|---|---|---|---|
| **0-1 分布**（两点分布） | `B(1, p)` | `P(X=1) = p`，`P(X=0) = 1 − p` | `p` | `p(1 − p)` | 抛硬币、产品合格/不合格、一次试验的成败 |
| **二项分布** | `B(n, p)` | `C(n,k) p^k (1−p)^(n−k)`，k = 0,…,n | `np` | `np(1 − p)` | n 重伯努利试验的成功次数、有放回抽检的次品数 |
| **泊松分布** | `P(λ)` 或 `π(λ)` | `λ^k e^(−λ) / k!`，k = 0,1,2,… | `λ` | `λ` | 单位时间内到达的呼叫数/顾客数、放射性衰变数、稀有事件计数 |
| **几何分布** | `G(p)` | `(1−p)^(k−1) p`，k = 1,2,… | `1/p` | `(1 − p)/p²` | 首次成功所需的试验次数、抽奖直到中奖 |
| **超几何分布** | `H(N, M, n)` | `C(M,k) C(N−M, n−k) / C(N, n)` | `nM/N` | `n·(M/N)·(1−M/N)·(N−n)/(N−1)` | **不放回**抽检中的次品数、产品验收抽样 |

> **重点**：这张表是全书使用频率最高的表之一，**必须做到默写级别**。特别是「二项 ↔ 泊松 ↔ 超几何」三者的区别与联系。

### 2.2.3 逐个展开

**① 0-1 分布（两点分布，Bernoulli Distribution）**

若 X 只取 0 与 1 两个值，`P(X=1) = p`，`P(X=0) = 1 − p`（0 < p < 1），则称 X 服从参数为 p 的 0-1 分布。

`E(X) = 0·(1−p) + 1·p = p`，`D(X) = E(X²) − [E(X)]² = p − p² = p(1 − p)`

它是最基本的分布：**一次伯努利试验的结果**。任何二项分布都是 n 个独立 0-1 分布之和。

**② 二项分布（Binomial Distribution）**

**模型**：n 重伯努利试验中，事件 A 每次发生的概率为 p，令 X 为 n 次试验中 A 发生的总次数，则 `X ~ B(n, p)`。

`P(X = k) = C(n,k) p^k (1 − p)^(n−k)`，　k = 0, 1, 2, …, n

**为什么是组合数**：n 次试验中「哪 k 次成功」有 `C(n,k)` 种选法，每种选法的概率都是 `p^k(1−p)^(n−k)`（独立性保证概率相乘）。

**期望的推导**：把 X 写成 n 个独立 0-1 变量之和 `X = X₁ + X₂ + … + Xₙ`，`E(Xᵢ) = p`，
由期望的线性性质（**不需要独立性**）`E(X) = ΣE(Xᵢ) = np`。
由独立性 `D(X) = ΣD(Xᵢ) = np(1 − p)`。这个「拆成 n 个 0-1 变量」的技巧极其常用。

**注意**：`n = 1` 时 `B(1, p)` 就是 0-1 分布。

**③ 泊松分布（Poisson Distribution）**

`P(X = k) = λ^k e^(−λ) / k!`，　k = 0, 1, 2, …　（λ > 0）

**验证归一性**：`Σ_{k=0}^{∞} λ^k e^(−λ)/k! = e^(−λ) · e^λ = 1` ✓

**应用场景（要记牢，考试常考判断）**：

- 单位时间内某电话交换台接到的呼叫次数；
- 单位时间内到某商店的顾客数；
- 一页书上的印刷错误数；
- 放射性物质在单位时间内放射的粒子数；
- 某地区每年发生的事故数。

**共同特征**：事件是「稀有的、独立的、可以计数的」，且发生的速率恒定。

**泊松定理（泊松近似）**：当 n 很大、p 很小、`λ = np` 适中时，

`C(n,k) p^k (1−p)^(n−k) ≈ λ^k e^(−λ) / k!`

**实用判据**：`n ≥ 10`（工程上常要求 `n ≥ 20` 或 `n ≥ 100`）且 `p ≤ 0.1`，此时 `λ = np`。

**④ 几何分布（Geometric Distribution）**

`P(X = k) = (1 − p)^(k−1) p`，　k = 1, 2, 3, …

**含义**：在独立重复试验中，**第 k 次才首次成功**的概率（前 k−1 次都失败，第 k 次成功）。

**验证归一性**：`Σ_{k=1}^{∞}(1−p)^(k−1)p = p · 1/(1 − (1−p)) = p/p = 1` ✓

**期望的推导**：`E(X) = Σ k(1−p)^(k−1)p = p · d/dq [Σ q^k] |_{q=1−p} = p · 1/(1−q)² = p/p² = 1/p`。

**无记忆性**：`P(X > m + n | X > m) = P(X > n)`。即「已经失败了 m 次」不会让下次更容易成功——这是几何分布独有的性质（连续情形下由指数分布对应）。

**⑤ 超几何分布（Hypergeometric Distribution）**

**模型**：N 件产品中有 M 件次品，从中**不放回**地任取 n 件，令 X 为其中的次品数。

`P(X = k) = C(M, k) · C(N − M, n − k) / C(N, n)`

其中 k 的取值范围为 `max(0, n − N + M) ≤ k ≤ min(n, M)`。

**与二项分布的联系**：同样是「n 次抽取中成功的次数」，区别只在于**是否放回**。
当 N 很大而 n 相对很小（`n/N ≤ 0.1`）时，**不放回近似等同于有放回**，此时超几何分布可用二项分布近似，`p = M/N`：

`C(M,k)C(N−M,n−k)/C(N,n) ≈ C(n,k) p^k (1−p)^(n−k)`

（有限总体校正因子 `(N−n)/(N−1) ≈ 1`，这正是两者方差的关系。）

## 2.3 随机变量的分布函数

**分布函数（Cumulative Distribution Function, CDF）**：设 X 是随机变量，对任意实数 x，称

`F(x) = P(X ≤ x)`，　−∞ < x < +∞

为 X 的分布函数。

**直观理解**：`F(x)` 就是「X 落在 x 左边」的累积概率。它是一个**普通函数**（不再是随机的），因此可以用微积分工具处理。

**三条性质（充要条件）**：

1. **单调不减**：若 `x₁ < x₂`，则 `F(x₁) ≤ F(x₂)`；
2. **有界且极限确定**：`0 ≤ F(x) ≤ 1`，且 `F(−∞) = lim_{x→−∞} F(x) = 0`，`F(+∞) = lim_{x→+∞} F(x) = 1`；
3. **右连续**：`F(x + 0) = F(x)`。

**由 F(x) 计算概率的公式（必背）**：

`P(a < X ≤ b) = F(b) − F(a)`

`P(X > a) = 1 − F(a)`

`P(X < a) = F(a − 0)`（左极限，即 `P(X ≤ a) − P(X = a)`）

`P(X = a) = F(a) − F(a − 0)`

> **重点**：`P(X = a) = F(a) − F(a−0)` 是**判断分布类型的利器**：
> - 若 `F(x)` 在 x = a 处**有跳跃**，则 X 在该点有正概率，X 是**离散型**；
> - 若 `F(x)` 处处**连续**，则 X 是**连续型**，且 `P(X = a) = 0`。

**离散型与分布函数的关系**：`F(x) = Σ_{xₖ ≤ x} pₖ`，即把 x 左边所有点的概率加起来。`F(x)` 是**阶梯函数**，在每个 `xₖ` 处跳跃，跳跃高度就是 `pₖ`。

## 2.4 连续型随机变量及其概率密度

### 2.4.1 概率密度

**概率密度（Probability Density Function, PDF）**：若存在非负可积函数 `f(x)`，使对任意实数 x 有

`F(x) = ∫_{−∞}^{x} f(t) dt`

则称 X 为**连续型随机变量**，`f(x)` 为 X 的**概率密度函数**。

**两条性质（充要条件）**：

1. **非负性**：`f(x) ≥ 0`；
2. **归一性**：`∫_{−∞}^{+∞} f(x) dx = 1`。

**常用公式**：

`P(a < X ≤ b) = F(b) − F(a) = ∫_a^b f(x) dx`

在 `f(x)` 的**连续点**处，`F'(x) = f(x)`。

> **重点（极易错）**：
> ① `f(x)` **不是概率**，它可以大于 1（例如 `U(0, 0.5)` 的密度恒为 2）。只有 `f(x)dx` 才近似是概率。
> ② 连续型随机变量在**任意单点**上的概率为 0：`P(X = a) = 0`。
> ③ 因此连续型情形下，「<」与「≤」没有区别：`P(a < X < b) = P(a ≤ X ≤ b) = F(b) − F(a)`。
> ④ 改变 `f(x)` 在**有限个点**上的值，不影响分布（因为积分值不变）。

### 2.4.2 常见连续型分布总表（必背）

| 分布名称 | 记号 | 概率密度 `f(x)` | 期望 `E(X)` | 方差 `D(X)` | 典型应用场景 |
|---|---|---|---|---|---|
| **均匀分布** | `U(a, b)` | `1/(b−a)`，a < x < b；其余为 0 | `(a + b)/2` | `(b − a)²/12` | 随机数生成、等可能的连续取值、四舍五入误差、公交等车时间 |
| **指数分布** | `E(λ)` | `λ e^(−λx)`，x > 0；x ≤ 0 时为 0 | `1/λ` | `1/λ²` | 元件寿命、服务时间、泊松过程中相邻事件的时间间隔 |
| **正态分布** | `N(μ, σ²)` | `1/(σ√(2π)) · e^(−(x−μ)²/(2σ²))` | `μ` | `σ²` | 测量误差、身高体重、考试成绩、大量独立随机因素之和 |

### 2.4.3 逐个展开

**① 均匀分布（Uniform Distribution）**

`f(x) = 1/(b − a)`（a < x < b），`F(x) = 0`（x < a）；`(x−a)/(b−a)`（a ≤ x < b）；`1`（x ≥ b）。

**直觉**：X 落在 `(a, b)` 内**任何等长的小区间**里的概率都相同。`U(0,1)` 是计算机产生随机数的基础。

**方差推导**：`E(X²) = ∫_a^b x²/(b−a) dx = (b³ − a³)/(3(b−a)) = (b² + ab + a²)/3`，
故 `D(X) = (b² + ab + a²)/3 − ((a+b)/2)² = (b − a)²/12`。

**② 指数分布（Exponential Distribution）**

`f(x) = λ e^(−λx)`（x > 0），`F(x) = 1 − e^(−λx)`（x > 0）。

`E(X) = 1/λ`，`D(X) = 1/λ²`。

**与泊松分布的对偶关系**：若事件按参数 λ 的泊松过程到达，则**两次相邻事件的时间间隔服从 `E(λ)`**。λ 的含义是「单位时间内的平均到达次数」，`1/λ` 就是「平均等待时间」。

**无记忆性（Memoryless Property）**：对任意 `s, t > 0`，

`P(X > s + t | X > s) = P(X > t)`

**证明**：`P(X > s + t | X > s) = P(X > s+t) / P(X > s) = e^(−λ(s+t)) / e^(−λs) = e^(−λt) = P(X > t)`。∎

**直观**：一个已经用了 1000 小时的元件，再用 100 小时的概率与一个全新元件用 100 小时的概率相同——「它不记得自己已经活了多久」。指数分布是**唯一**具有无记忆性的连续分布。

**③ 正态分布（Normal Distribution）—— 全书最重要的分布**

**定义**：若 X 的概率密度为

`f(x) = 1/(σ√(2π)) · e^(−(x−μ)²/(2σ²))`，　−∞ < x < +∞

其中 `μ`、`σ`（σ > 0）为常数，则称 X 服从参数为 μ、σ² 的**正态分布**，记作 `X ~ N(μ, σ²)`。

**图像特征（钟形曲线）**：

```
              ┌─ 峰值在 x = μ，高度 1/(σ√(2π))
              │
        ╱‾‾‾‾‾╲             ← 关于 x = μ 对称
      ╱         ╲
    ╱             ╲
  ╱                 ╲
 ────────────────────────────→ x
        μ−σ  μ  μ+σ
        └─ 拐点在 μ ± σ 处 ─┘
```

- 曲线关于直线 `x = μ` **对称**；
- 在 `x = μ` 处取最大值 `1/(σ√(2π)) ≈ 0.3989/σ`；
- 拐点在 `x = μ ± σ`；
- `x → ±∞` 时以 x 轴为**水平渐近线**；
- **σ 越大曲线越平缓**（数据越分散），σ 越小曲线越尖峭。μ 决定位置，σ 决定形状。

**标准正态分布**：`μ = 0, σ = 1` 时，记 `Z ~ N(0, 1)`，其密度与分布函数分别记为

`φ(x) = 1/√(2π) · e^(−x²/2)`，　`Φ(x) = ∫_{−∞}^{x} φ(t) dt`

**对称性（必背）**：`φ(−x) = φ(x)`，　**`Φ(−x) = 1 − Φ(x)`**

**标准化定理**：若 `X ~ N(μ, σ²)`，则

`Z = (X − μ) / σ ~ N(0, 1)`

**这就是查表计算一切正态概率的钥匙**：

`P(a < X ≤ b) = Φ((b − μ)/σ) − Φ((a − μ)/σ)`

**常用标准正态表值（必须记住几个）**：

| x | 0 | 0.5 | 1.0 | 1.28 | 1.5 | 1.645 | 1.96 | 2.0 | 2.33 | 2.58 | 3.0 |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `Φ(x)` | 0.5000 | 0.6915 | 0.8413 | 0.8997 | 0.9332 | 0.9500 | 0.9750 | 0.9772 | 0.9901 | 0.9951 | 0.9987 |

其中 `Φ(1.96) = 0.975` 与 `Φ(1.645) = 0.95` 在后续区间估计与假设检验中出现频率最高。

> **查表口径说明**：上表按**四位小数的标准正态表**取值（`Φ(2.33) = 0.9901`、`Φ(2.58) = 0.9951`）。由这类表值反算出的概率会带一点末位误差，例如 3σ 法则表值给出 `0.6826 / 0.9544 / 0.9974`，而真值是 `0.6827 / 0.9545 / 0.9973`。**考试按附表查表值写即可**，本笔记三处（第 2 章、第 4 章、附录 A）口径一致。

**上 α 分位点**：称满足 `P(X > z_α) = α` 的点 `z_α` 为标准正态分布的**上 α 分位点**。

由对称性可得 **`z_α = −z_{1−α}`**，且 `Φ(z_α) = 1 − α`。

常用值：`z_{0.05} = 1.645`，`z_{0.025} = 1.96`，`z_{0.01} = 2.33`，`z_{0.005} = 2.58`。

> **重点**：注意区分 `z_α`（上侧面积为 α）与课本附表给出的 `Φ(x)`（左侧面积）。`z_{0.025} = 1.96` 意味着 `Φ(1.96) = 0.975`，即 1.96 左侧面积为 0.975、右侧面积为 0.025。这是全书最容易搞反的地方之一。

**3σ 法则（工程上的「正常范围」）**：

`P(|X − μ| < σ) = P(|Z| < 1) = 2Φ(1) − 1 = 2 × 0.8413 − 1 = 0.6826`

`P(|X − μ| < 2σ) = P(|Z| < 2) = 2Φ(2) − 1 = 2 × 0.9772 − 1 = 0.9544`

`P(|X − μ| < 3σ) = P(|Z| < 3) = 2Φ(3) − 1 = 2 × 0.9987 − 1 = 0.9974`

> **工程结论**：正态变量几乎必然落在 `μ ± 3σ` 内（只有约 0.26% 的例外）。这就是质量控制图、六西格玛管理、异常值检测的统计学基础。

**为什么正态分布无处不在**：第 5 章的中心极限定理指出，**大量相互独立的微小随机因素叠加，其总和近似服从正态分布**。身高受遗传、营养、环境等无数小因素影响，测量误差由无数微小扰动累积——所以都是正态。

## 2.5 随机变量的函数的分布

问题：已知 X 的分布，求 `Y = g(X)` 的分布。

### 2.5.1 离散型情形：列表法

**步骤**：① 列出 X 的所有取值 `x₁, x₂, …` 及其概率；② 算出对应的 `yᵢ = g(xᵢ)`；③ **把取到相同 y 值的概率相加**。

> **重点**：第 ③ 步是易错点。若 `g` 不是一一对应（如 `g(x) = x²`），多个人 x 可能映到同一个 y，必须合并概率。

### 2.5.2 连续型情形之一：分布函数法（万能法）

**步骤**：

① 写出 `F_Y(y) = P(Y ≤ y) = P(g(X) ≤ y)`；
② 把不等式 `g(X) ≤ y` **解成关于 X 的区间**；
③ 用 X 的分布函数或密度算出该区间的概率，得到 `F_Y(y)`；
④ 对 y 求导得 `f_Y(y) = F_Y'(y)`。

**适用范围**：**任何** g，包括非单调的（如 `Y = X²`）。这是最稳妥的方法，考试首选。

### 2.5.3 连续型情形之二：定理法（公式法）

**定理**：设 X 的密度为 `f_X(x)`，`y = g(x)` **严格单调且可导**，其反函数为 `x = h(y)`，则

`f_Y(y) = f_X(h(y)) · |h'(y)|`，　y 在 g 的值域内

> **重点**：公式中的**绝对值**不能丢；适用范围仅限**单调**函数。若 g 不单调，必须回到分布函数法（或把定义域分段，每段用公式再相加）。

**推论（正态的线性变换）**：若 `X ~ N(μ, σ²)`，`Y = aX + b`（a ≠ 0），则

`Y ~ N(aμ + b, a²σ²)`

**证明**：反函数 `h(y) = (y − b)/a`，`|h'(y)| = 1/|a|`。代入定理：

`f_Y(y) = 1/(σ√(2π)) · e^(−((y−b)/a − μ)²/(2σ²)) · 1/|a| = 1/(|a|σ√(2π)) · e^(−(y − (aμ+b))²/(2a²σ²))`

这正是 `N(aμ + b, a²σ²)` 的密度。∎

**特例**：`a = 1/σ`，`b = −μ/σ` 时，`Z = (X−μ)/σ ~ N(0, 1)`，与 2.4.3 的标准化定理一致。

## 典型例题

**例 2.1**（题型：由归一性求待定常数）
设随机变量 X 的分布律为 `P(X = k) = a/2^k`，k = 1, 2, 3, 4。① 求常数 a；② 求 `P(X ≤ 2)`；③ 求 `P(1 < X ≤ 3)`。

**解**：
① **为什么用归一性**：分布律必须满足 `Σpₖ = 1`。
`Σ_{k=1}^{4} a/2^k = a(1/2 + 1/4 + 1/8 + 1/16) = a · 15/16 = 1`
解得 `a = 16/15`。
② `P(X ≤ 2) = P(X=1) + P(X=2) = (16/15)(1/2) + (16/15)(1/4) = 8/15 + 4/15 = 12/15 = 0.8`
③ `P(1 < X ≤ 3) = P(X=2) + P(X=3) = 4/15 + (16/15)(1/8) = 4/15 + 2/15 = 6/15 = 0.4`

**答案**：① `a = 16/15`；② 0.8；③ 0.4。

**例 2.2**（题型：连续型密度求常数、分布函数与概率）
设连续型随机变量 X 的概率密度为

`f(x) = kx`（0 ≤ x < 2）；`f(x) = 0`（其它）

① 求常数 k；② 求分布函数 `F(x)`；③ 求 `P(0.5 < X < 1.5)`。

**解**：
① 由归一性 `∫_{−∞}^{+∞} f(x)dx = ∫_0^2 kx dx = k · [x²/2]_0^2 = k · 2 = 1`，故 `k = 1/2`。
即 `f(x) = x/2`（0 ≤ x < 2）。
② 分段积分（**为什么分段**：密度在 0 与 2 处分段定义，积分上下限随之变化）：
- `x < 0`：`F(x) = 0`
- `0 ≤ x < 2`：`F(x) = ∫_0^x (t/2) dt = x²/4`
- `x ≥ 2`：`F(x) = 1`

③ **两种算法互相验证**：
用密度：`P(0.5 < X < 1.5) = ∫_{0.5}^{1.5} (x/2) dx = [x²/4]_{0.5}^{1.5} = 2.25/4 − 0.25/4 = 0.5`
用分布函数：`P = F(1.5) − F(0.5) = 1.5²/4 − 0.5²/4 = (2.25 − 0.25)/4 = 0.5` ✓

**答案**：① k = 1/2；② 见上；③ 0.5。

**例 2.3**（题型：由分布函数求参数、密度与概率）
设随机变量 X 的分布函数为

`F(x) = 0`（x < 0）；`F(x) = A x²`（0 ≤ x < 1）；`F(x) = 1`（x ≥ 1）

① 求常数 A；② 求概率密度 `f(x)`；③ 求 `P(0.3 < X < 0.7)`；④ 判断 X 是离散型还是连续型。

**解**：
① 用右连续性 `F(1 + 0) = F(1)`：`lim_{x→1⁻} A x² = A = 1`，故 `A = 1`。
② **为什么可以求导**：`F(x)` 在 (0,1) 内可导且连续，故 `f(x) = F'(x) = 2x`（0 < x < 1），其余为 0。
③ `P(0.3 < X < 0.7) = F(0.7) − F(0.3) = 0.7² − 0.3² = 0.49 − 0.09 = 0.40`
④ `F(x)` 在 `x = 0` 与 `x = 1` 处**都连续**（`F(0⁻) = 0 = F(0)`，`F(1⁻) = 1 = F(1)`），无跳跃点，故 `P(X = a) = 0` 对一切 a 成立，X 为**连续型**。

**答案**：① A = 1；② `f(x) = 2x`（0 < x < 1）；③ 0.40；④ 连续型。

**例 2.4**（题型：正态分布标准化计算）
设 `X ~ N(1.5, 4)`。求：① `P(X < 2.5)`；② `P(|X| < 2)`；③ `P(X > 4.5)`；④ 求常数 c 使 `P(X > c) = 0.025`。

**解**：
先明确 `μ = 1.5`，`σ² = 4`，故 `σ = 2`。标准化 `Z = (X − 1.5)/2 ~ N(0,1)`。
① `P(X < 2.5) = Φ((2.5 − 1.5)/2) = Φ(0.5) = 0.6915`
② `P(|X| < 2) = P(−2 < X < 2) = Φ((2 − 1.5)/2) − Φ((−2 − 1.5)/2) = Φ(0.25) − Φ(−1.75)`
**关键一步**：`Φ(−1.75) = 1 − Φ(1.75) = 1 − 0.9599 = 0.0401`
故 `P = 0.5987 − 0.0401 = 0.5586`
③ `P(X > 4.5) = 1 − Φ((4.5 − 1.5)/2) = 1 − Φ(1.5) = 1 − 0.9332 = 0.0668`
④ `P(X > c) = 0.025` ⟺ `P(X ≤ c) = 0.975` ⟺ `Φ((c − 1.5)/2) = 0.975`
查表得 `Φ(1.96) = 0.975`，故 `(c − 1.5)/2 = 1.96`，解得 `c = 1.5 + 3.92 = 5.42`。

**答案**：① 0.6915；② 0.5586；③ 0.0668；④ c = 5.42。

**例 2.5**（题型：二项分布 + 泊松近似）
某厂产品的次品率为 0.02。现从中任取 100 件，求：① 恰有 2 件次品的概率；② 至少有 2 件次品的概率；③ 次品数不超过 4 件的概率。（用泊松近似，结果保留 4 位小数）

**解**：
设 X 为 100 件中的次品数，则 `X ~ B(100, 0.02)`。
**为什么可用泊松近似**：`n = 100` 很大，`p = 0.02` 很小，`λ = np = 100 × 0.02 = 2` 适中，满足泊松定理条件。
① `P(X = 2) = C(100,2)(0.02)²(0.98)^98 ≈ λ²e^(−λ)/2! = 2² × e^(−2)/2`
查表得 `e^(−2) = 0.135335`，故 `P(X=2) ≈ 4 × 0.135335 / 2 = 0.2707`
② **为什么用对立事件**：「至少 2 件」逐项相加快 99 项，而其对立面只有 2 项。
`P(X ≥ 2) = 1 − P(X=0) − P(X=1)`
`P(X=0) ≈ 2⁰e^(−2)/0! = 0.1353`，`P(X=1) ≈ 2¹e^(−2)/1! = 2 × 0.135335 = 0.2707`
`P(X ≥ 2) = 1 − 0.1353 − 0.2707 = 0.5940`
③ `P(X ≤ 4) = P(0) + P(1) + P(2) + P(3) + P(4)`
`P(3) = 2³e^(−2)/3! = 8 × 0.135335/6 = 0.1804`
`P(4) = 2⁴e^(−2)/4! = 16 × 0.135335/24 = 0.0902`
`P(X ≤ 4) = 0.1353 + 0.2707 + 0.2707 + 0.1804 + 0.0902 = 0.9473`

**答案**：① 0.2707；② 0.5940；③ 0.9473。

> **说明**：精确的二项分布计算给出 `P(X=2) = 0.2734`、`P(X≥2) = 0.5967`，泊松近似误差在小数点后第 3 位，工程上完全够用。

**例 2.6**（题型：指数分布与无记忆性）
某电子元件的寿命 `X ~ E(λ)`，已知平均寿命为 1000 小时。求：① 参数 λ；② 该元件能正常工作 1500 小时以上的概率；③ 若已知元件已正常工作 1000 小时，它还能再正常工作 1500 小时以上的概率。

**解**：
① 由 `E(X) = 1/λ = 1000`，得 `λ = 1/1000 = 0.001`。
② `P(X > 1500) = 1 − F(1500) = e^(−λ × 1500) = e^(−1.5)`
查表得 `e^(−1.5) = 0.2231`，故 `P(X > 1500) ≈ 0.2231`。
③ **为什么可以省掉计算**：指数分布具有无记忆性，`P(X > s+t | X > s) = P(X > t)`。
故 `P(X > 2500 | X > 1000) = P(X > 1500) = e^(−1.5) ≈ 0.2231`。
（直接验证：`P(X>2500)/P(X>1000) = e^(−2.5)/e^(−1) = e^(−1.5)` ✓）

**答案**：① λ = 0.001；② 0.2231；③ 0.2231（与②相同）。

**例 2.7**（题型：随机变量的函数的分布——分布函数法，非单调）
设 `X ~ N(0, 1)`，求 `Y = X²` 的概率密度。

**解**：
**为什么用分布函数法**：`y = x²` 在 `(−∞, +∞)` 上**不单调**（±x 映到同一 y），定理法失效。
① 求 `F_Y(y) = P(Y ≤ y) = P(X² ≤ y)`。
- 当 `y ≤ 0` 时，`{X² ≤ y}` 是不可能事件（平方非负），`F_Y(y) = 0`；
- 当 `y > 0` 时，`X² ≤ y ⟺ −√y ≤ X ≤ √y`，故
  `F_Y(y) = P(−√y ≤ X ≤ √y) = Φ(√y) − Φ(−√y) = 2Φ(√y) − 1`
② 求导（**注意链式法则**）：
`f_Y(y) = d/dy [2Φ(√y) − 1] = 2 φ(√y) · 1/(2√y) = φ(√y)/√y`
③ 代入 `φ(√y) = 1/√(2π) · e^(−y/2)`：
`f_Y(y) = 1/(√(2π) · √y) · e^(−y/2) = 1/(√(2πy)) · e^(−y/2)`，　y > 0

**答案**：`f_Y(y) = 1/(√(2πy)) · e^(−y/2)`（y > 0），其余为 0。

> **重要结论**：这正是自由度 1 的 **χ² 分布**的密度，即 `X² ~ χ²(1)`。第 6 章会正式引入 χ² 分布并推广到 n 个变量之和。

**例 2.8**（题型：随机变量的函数的分布——定理法，证明题）
设 `X ~ N(μ, σ²)`，`a`、`b` 为常数且 `a ≠ 0`。证明 `Y = aX + b ~ N(aμ + b, a²σ²)`。

**证明**：
`y = g(x) = ax + b` 严格单调（因 a ≠ 0），值域为 `(−∞, +∞)`。
其反函数 `x = h(y) = (y − b)/a`，导数 `h'(y) = 1/a`，故 `|h'(y)| = 1/|a|`。
由定理法：
`f_Y(y) = f_X(h(y)) · |h'(y)| = 1/(σ√(2π)) · e^(−((y−b)/a − μ)²/(2σ²)) · 1/|a|`
整理指数部分：`((y−b)/a − μ)² = ((y − b − aμ)/a)² = (y − (aμ + b))²/a²`
故 `f_Y(y) = 1/(|a|σ√(2π)) · e^(−(y − (aμ+b))²/(2a²σ²))`
这与 `N(aμ + b, a²σ²)` 的密度形式完全一致，故 `Y ~ N(aμ + b, a²σ²)`。∎

**答案**：见证明。

> **推论（考试高频）**：取 `a = 1/σ`、`b = −μ/σ`，得 `(X − μ)/σ ~ N(0, 1)`；取 `a = −1`、`b = 0`，得 `−X ~ N(−μ, σ²)`。

**例 2.9**（题型：离散型随机变量的函数的分布）
设 X 的分布律为：

| X | −1 | 0 | 1 | 2 |
|---|---|---|---|---|
| P | 0.2 | 0.3 | 0.1 | 0.4 |

求 `Y = X²` 的分布律，并求 `E(Y)`。

- `P(Y = 1) = P(X = −1) + P(X = 1) = 0.2 + 0.1 = 0.3`

|---|---|---|---|

## 易错点提醒

1. **把概率密度 `f(x)` 当成概率**。
   **错在**：认为 `f(x) ≤ 1`，或说「`f(0) = 2` 是不可能的」。
   **正确做法**：`f(x)` 是**密度**不是概率，可以大于 1。例如 `U(0, 0.5)` 的密度恒为 2。只有 `f(x)dx` 才是（近似）概率，且必然有 `∫f(x)dx = 1`。

2. **在连续型里算 `P(X = a)`**。
   **错在**：把 `P(X = a)` 当成 `f(a)`。
   **正确做法**：连续型随机变量 `P(X = a) = 0` 对一切 a 成立。因此 `P(a < X < b) = P(a ≤ X ≤ b) = F(b) − F(a)`，端点开闭无所谓。

3. **`Φ(−x)` 直接查表查不到就放弃**。
   **错在**：以为标准正态表只能查正数。
   **正确做法**：用对称性 `Φ(−x) = 1 − Φ(x)` 转化。例如 `Φ(−1.5) = 1 − 0.9332 = 0.0668`。

4. **分位点 `z_α` 与 `Φ(x)` 混淆**。
   **错在**：把 `z_{0.025}` 写成 0.025 或写成 `Φ(0.025)`。
   **正确做法**：`z_α` 是**上侧面积为 α 的点**，满足 `Φ(z_α) = 1 − α`。故 `z_{0.025} = 1.96`（因为 `Φ(1.96) = 0.975 = 1 − 0.025`）。记忆口诀：**「α 小、z 大」**。

5. **分布函数法求 `Y = g(X)` 时忘记分段讨论 y**。
   **错在**：直接对 `P(g(X) ≤ y)` 求导，忽略 `y ≤ 0` 等边界情形。
   **正确做法**：**先定出 Y 的取值范围**，再分区间讨论。例如 `Y = X²` 必须分 `y ≤ 0`（此时 `F_Y(y) = 0`）与 `y > 0` 两段，最后写成完整的分段函数。

6. **定理法用在非单调函数上**。
   **错在**：对 `Y = X²` 直接用 `f_Y(y) = f_X(√y)·|1/(2√y)|`，漏掉 `x = −√y` 那一支。
   **正确做法**：定理法**只适用于严格单调**的 g。非单调时：① 用分布函数法；② 或把定义域分段，**每一段各算一次再相加**（`f_Y(y) = Σᵢ f_X(hᵢ(y))·|hᵢ'(y)|`）。

7. **泊松近似的条件判断错误**。
   **错在**：`n = 10`、`p = 0.5` 也用泊松近似。
   **正确做法**：必须同时满足「n 大、p 小、`λ = np` 适中（一般 λ ≤ 10）」。`p = 0.5` 时应直接用二项分布（此时分布接近对称）。

8. **分布函数忘记验证右连续**。
   **错在**：已知连续型随机变量的分布函数为 `F(x) = 0`（x < 0）；`F(x) = A x²`（0 ≤ x < 2）；`F(x) = B`（x ≥ 2）。只由 `F(+∞) = 1` 得 `B = 1`，然后**凭感觉让 `F(2⁻)` 接近 1**，随手取 `A = 1/2`，得到 `F(2⁻) = (1/2) × 2² = 2`——**竟然大于 1**，与分布函数必须满足 `0 ≤ F(x) ≤ 1` 直接矛盾，而且在 `x = 2` 处不右连续。
   **正确做法**：分段函数的待定常数要用**连续性条件**（连续型）或**右连续 + 趋于 1**（一般情形）确定。本题由 `F(+∞) = 1` 得 `B = 1`，再由右连续 `F(2⁻) = F(2)` 得 `4A = 1`，故 **`A = 1/4`**。**A 不是可以随便取的**——它由衔接条件唯一确定。

9. **正态分布参数写成 `N(μ, σ)`**。
   **错在**：第二个参数写成标准差。
   **正确做法**：`N(μ, σ²)` 的第二个参数是**方差**。如 `N(1.5, 4)` 表示 `σ² = 4`，`σ = 2`。看到题中的 4 要先开方再标准化。

10. **超几何分布与二项分布混用**。
    **错在**：题目说「不放回抽取」却套二项分布公式。
    **正确做法**：**有放回 / 各次独立 ⟹ 二项分布；不放回 ⟹ 超几何分布**。只有当 `n/N ≤ 0.1` 时才可用二项分布近似超几何分布。

## 本章小结

- **随机变量**是把样本点映射为实数的函数，分**离散型**与**连续型**两大类。
- 离散型用**分布律** `pₖ = P(X = xₖ)` 描述，满足 `pₖ ≥ 0`、`Σpₖ = 1`。
- 连续型用**概率密度** `f(x)` 描述，满足 `f(x) ≥ 0`、`∫f(x)dx = 1`；`f(x)` **不是概率**。
- **分布函数** `F(x) = P(X ≤ x)` 对两类都适用，性质：单调不减、右连续、`F(−∞)=0`、`F(+∞)=1`。
- **五大离散分布**：0-1、二项 `B(n,p)`、泊松 `P(λ)`、几何 `G(p)`、超几何 `H(N,M,n)`。
- **三大连续分布**：均匀 `U(a,b)`、指数 `E(λ)`（无记忆性）、正态 `N(μ,σ²)`（全书核心）。
- 正态计算三板斧：**标准化** `Z = (X−μ)/σ`、**对称性** `Φ(−x) = 1 − Φ(x)`、**查表**。
- 3σ 法则：`P(|X−μ| < σ, 2σ, 3σ) = 0.6826, 0.9544, 0.9974`。
- 求 `Y = g(X)` 的分布：离散型**列表合并同值**；连续型优先用**分布函数法**，单调时可用**定理法** `f_Y(y) = f_X(h(y))|h'(y)|`。
- **一句话记住本章**：离散看分布律、连续看密度，两者统一于分布函数 `F(x)`；正态概率一律先标准化再查表。
