## 学习目标

1. **能**写出二维随机变量的联合分布函数，并用**矩形公式**计算概率。
2. **能**由联合分布律/联合密度完整刻画二维分布，包括求待定常数。
3. **能**熟练地由联合分布求**边缘分布**，并说清「联合决定边缘，边缘决定不了联合」。
4. **能**写出条件分布律与条件概率密度，并用它算条件概率。
5. **能**用三个等价条件判断 X 与 Y 是否**相互独立**，特别是「可分离变量 + 矩形区域」的快速判别法。
6. **能**用卷积公式求 `Z = X + Y` 的分布，并记住正态、泊松、二项分布的**可加性**。
7. **能**求 `M = max(X,Y)` 与 `N = min(X,Y)` 的分布函数，并解释串联/并联系统的可靠性含义。
8. **能**把「二维」结论类推到 n 维，理解独立的 n 个正态变量之和仍为正态。

## 3.1 二维随机变量及其分布

### 3.1.1 二维随机变量与联合分布函数

**二维随机变量（Two-dimensional Random Variable）**：设 E 是随机试验，样本空间 `S = {ω}`，`X = X(ω)` 与 `Y = Y(ω)` 是定义在 S 上的两个随机变量，则称有序对 `(X, Y)` 为**二维随机变量**（或称二维随机向量）。

**联合分布函数（Joint Distribution Function）**：

`F(x, y) = P(X ≤ x, Y ≤ y)`，　−∞ < x, y < +∞

**几何意义**：`F(x, y)` 是随机点 `(X, Y)` 落在以 `(x, y)` 为右上角顶点的**左下方无穷矩形**内的概率。

**四条性质**：

1. **分别单调不减**：对固定的 y，`F(x, y)` 关于 x 单调不减；对固定的 x，关于 y 也单调不减；
2. **有界性与极限**：`0 ≤ F(x, y) ≤ 1`，且
   `F(−∞, y) = 0`，`F(x, −∞) = 0`，`F(−∞, −∞) = 0`，`F(+∞, +∞) = 1`；
3. **右连续**：`F(x, y)` 关于 x、y 均右连续；
4. **矩形公式（非负性）**：对任意 `x₁ < x₂`，`y₁ < y₂`，

`P(x₁ < X ≤ x₂, y₁ < Y ≤ y₂) = F(x₂,y₂) − F(x₁,y₂) − F(x₂,y₁) + F(x₁,y₁) ≥ 0`

> **重点**：矩形公式是**判断一个二元函数能否作为联合分布函数**的关键（「两增两减」口诀：右上角加，左边、下边减）。很多判断题就考这条。

### 3.1.2 二维离散型随机变量

**联合分布律**：若 `(X, Y)` 的所有可能取值是有限个或可列无限个数对 `(xᵢ, yⱼ)`，则

`p_ij = P(X = xᵢ, Y = yⱼ)`，　i, j = 1, 2, …

**两条性质**：① `p_ij ≥ 0`；② `Σᵢ Σⱼ p_ij = 1`。

**表格表示**：

| X \ Y | y₁ | y₂ | y₃ | **p_i·** |
|---|---|---|---|---|
| x₁ | p₁₁ | p₁₂ | p₁₃ | p₁· |
| x₂ | p₂₁ | p₂₂ | p₂₃ | p₂· |
| **p_·j** | p_·₁ | p_·₂ | p_·₃ | 1 |

> **表格读法**：**行和 → X 的边缘分布；列和 → Y 的边缘分布**。这张表是本章最常考的形式，做题时一定要画出「行和列和」两栏。

### 3.1.3 二维连续型随机变量

**联合概率密度**：若存在非负可积二元函数 `f(x, y)` 使

`F(x, y) = ∫_{−∞}^{x} ∫_{−∞}^{y} f(u, v) dv du`

则称 `(X, Y)` 为二维连续型随机变量，`f(x, y)` 为**联合概率密度**。

**性质**：① `f(x, y) ≥ 0`；② `∫_{−∞}^{+∞} ∫_{−∞}^{+∞} f(x, y) dx dy = 1`；③ 在连续点处 `f(x, y) = ∂²F/∂x∂y`。

**求概率**：

`P((X, Y) ∈ D) = ∬_D f(x, y) dx dy`

> **重点**：算二维概率的核心是**确定积分区域 D**，并画出区域图。区域画错，全盘皆错。常见技巧：先固定 x 看 y 的范围（或反之），再定积分上下限。

**二维均匀分布**：若 `(X, Y)` 在平面区域 G 上服从均匀分布，则

`f(x, y) = 1 / A`（(x, y) ∈ G）；`0`（其它）

其中 A 为 G 的面积。此时 `P((X,Y) ∈ D) = D∩G 的面积 / G 的面积`——**几何概型在二维的翻版**。

### 3.1.4 边缘分布

**边缘分布函数**：`F_X(x) = P(X ≤ x) = P(X ≤ x, Y < +∞) = F(x, +∞)`，同理 `F_Y(y) = F(+∞, y)`。

**离散型的边缘分布律**（**对另一变量求和**）：

`p_i· = P(X = xᵢ) = Σⱼ p_ij`，　`p_·j = P(Y = yⱼ) = Σᵢ p_ij`

**连续型的边缘概率密度**（**对另一变量积分**）：

`f_X(x) = ∫_{−∞}^{+∞} f(x, y) dy`，　`f_Y(y) = ∫_{−∞}^{+∞} f(x, y) dx`

> **重点（考试必考的判断）**：**联合分布 ⟹ 边缘分布**（唯一确定），但**边缘分布 ⇏ 联合分布**。给定了 `f_X` 与 `f_Y`，不同的相依结构会给出不同的联合分布。这是本章最容易出判断题的点。

### 3.1.5 二维正态分布

若 `(X, Y)` 的联合密度为

`f(x, y) = 1/(2πσ₁σ₂√(1−ρ²)) · exp{ −1/(2(1−ρ²)) · [ ((x−μ₁)/σ₁)² − 2ρ((x−μ₁)/σ₁)((y−μ₂)/σ₂) + ((y−μ₂)/σ₂)² ] }`

则称 `(X, Y)` 服从参数为 `μ₁, μ₂, σ₁², σ₂², ρ` 的**二维正态分布**，记作

`(X, Y) ~ N(μ₁, μ₂, σ₁², σ₂², ρ)`

**五条重要结论（背下来）**：

1. **边缘分布仍是正态**：`X ~ N(μ₁, σ₁²)`，`Y ~ N(μ₂, σ₂²)`；
2. **ρ = 0 ⟺ X 与 Y 独立**（这是正态分布独有的「不相关即独立」性质！一般分布不成立）；
3. `X + Y ~ N(μ₁ + μ₂, σ₁² + σ₂² + 2ρσ₁σ₂)`；
4. **二维正态的任意线性组合仍为正态**；
5. 两个边缘正态**推不出**联合正态（经典反例，`ρ` 信息丢失）。

## 3.2 条件分布与随机变量的独立性

### 3.2.1 条件分布

**离散型的条件分布律**：当 `P(Y = yⱼ) > 0` 时，

`P(X = xᵢ | Y = yⱼ) = p_ij / p_·j`

固定 j，对 i 求和：`Σᵢ P(X = xᵢ | Y = yⱼ) = (Σᵢ p_ij)/p_·j = p_·j/p_·j = 1` ✓ 确实是分布律。

**连续型的条件概率密度**：当 `f_Y(y) > 0` 时，

`f_{X|Y}(x | y) = f(x, y) / f_Y(y)`

条件分布函数：`F_{X|Y}(x | y) = ∫_{−∞}^{x} f_{X|Y}(u | y) du`。

> **重点**：`f_{X|Y}(x|y)` 中的 y 是**固定的常数**，作为 x 的函数它才是一个概率密度。类比条件概率 `P(B|A) = P(AB)/P(A)`——**联合除以条件变量自己的边缘**。

**乘法公式的密度形式**：`f(x, y) = f_{X|Y}(x|y) · f_Y(y) = f_{Y|X}(y|x) · f_X(x)`。

### 3.2.2 随机变量的独立性

**定义**：若对一切 x, y 都有

`F(x, y) = F_X(x) · F_Y(y)`

则称 X 与 Y **相互独立**。

**三个等价判别条件**：

| 类型 | 独立 ⟺ 的条件 |
|---|---|
| 一般（分布函数） | `F(x, y) = F_X(x) · F_Y(y)`，对一切 x, y 成立 |
| 离散型 | `p_ij = p_i· · p_·j`，对一切 i, j 成立 |
| 连续型 | `f(x, y) = f_X(x) · f_Y(y)`，对几乎一切 x, y 成立 |

**快速判别法（考试神器）**：

若 `f(x, y)` 的非零区域是**矩形**（即 `a < x < b`，`c < y < d`，两个变量各自的范围互相无关），**且** `f(x, y)` 能**分离变量**写成 `g(x) · h(y)` 的形式，则 X 与 Y **独立**。

**反之**：若非零区域**不是矩形**（例如 `0 < y < x < 1`），则**一定不独立**，无需计算。

> **重点**：两个随机变量独立，**必须有各自的取值范围互不影响**。例如 `0 < y < x < 1` 中，y 的上界依赖于 x，X 的信息会影响 Y 的可能范围，自然不独立。

**独立性的重要推论**：

- 若 X、Y 独立，则 `g(X)` 与 `h(Y)` 也独立（g、h 为任意函数）；
- 若 X、Y 独立，则 `f_{X|Y}(x|y) = f_X(x)`——「知道 Y 的值对 X 毫无影响」；
- 独立 ⟹ 不相关（`Cov(X,Y) = 0`），但**不相关 ⇏ 独立**（第 4 章详述）。

**可加性定理（必背）**：设 X、Y 相互独立，则

| 分布类型 | 可加性结论 |
|---|---|
| 正态分布 | `X ~ N(μ₁,σ₁²)`，`Y ~ N(μ₂,σ₂²)` ⟹ `X + Y ~ N(μ₁+μ₂, σ₁²+σ₂²)` |
| 泊松分布 | `X ~ P(λ₁)`，`Y ~ P(λ₂)` ⟹ `X + Y ~ P(λ₁+λ₂)` |
| 二项分布 | `X ~ B(n,p)`，`Y ~ B(m,p)` ⟹ `X + Y ~ B(n+m, p)`（**p 必须相同**） |
| χ² 分布 | `X ~ χ²(n₁)`，`Y ~ χ²(n₂)` ⟹ `X + Y ~ χ²(n₁+n₂)`（第 5 章用） |

> **重点**：**注意二项分布要求 p 相同**。`B(5, 0.3) + B(4, 0.5)` 不是二项分布。正态与泊松则无此限制（正态可加性连方差不同也允许）。

## 3.3 二维随机变量函数的分布

### 3.3.1 Z = X + Y 的分布（卷积公式）

**一般公式**：

`f_Z(z) = ∫_{−∞}^{+∞} f(x, z − x) dx = ∫_{−∞}^{+∞} f(z − y, y) dy`

**当 X 与 Y 独立时（标准卷积公式）**：

`f_Z(z) = ∫_{−∞}^{+∞} f_X(x) · f_Y(z − x) dx`

**使用要点**：被积函数 `f_X(x) f_Y(z − x)` 要求 `x` 与 `z − x` **同时**落在各自的非零区间内。由此解出 x 的**积分上下限**（与 z 有关！），必须**对 z 分段讨论**。

### 3.3.2 M = max(X,Y) 与 N = min(X,Y) 的分布

设 X、Y 相互独立，分布函数分别为 `F_X`、`F_Y`。

**最大值 `M = max(X, Y)`**：`{M ≤ z} ⟺ {X ≤ z 且 Y ≤ z}`（两个都不过 z）

`F_M(z) = P(M ≤ z) = P(X ≤ z, Y ≤ z) = F_X(z) · F_Y(z)`

**最小值 `N = min(X, Y)`**：用对立事件，"至少有一个 ≤ z" 太麻烦，改用 `{N > z} ⟺ {X > z 且 Y > z}`

`F_N(z) = 1 − P(N > z) = 1 − P(X > z, Y > z) = 1 − [1 − F_X(z)][1 − F_Y(z)]`

> **重点**：
> ① 求 min 时**必须用对立事件** `P(N > z)`，不要硬碰 `{N ≤ z}`（那是「至少一个 ≤ z」，要用容斥）。
> ② 工程含义：**串联系统**（任一元件失效则系统失效）的寿命是 `min`；**并联系统**（全部失效才失效）的寿命是 `max`。
> ③ 当 X、Y 独立同分布（都为 F）时，`F_M(z) = [F(z)]ⁿ`，`F_N(z) = 1 − [1 − F(z)]ⁿ`（n 个元件）。

### 3.3.3 二维随机变量变换的一般方法（雅可比法）

设 `(X, Y)` 有联合密度 `f(x, y)`，作变换 `u = g₁(x, y)`，`v = g₂(x, y)`，能唯一解出 `x = x(u, v)`，`y = y(u, v)`，则

`f_{U,V}(u, v) = f(x(u,v), y(u,v)) · |J|`

其中**雅可比行列式**

`J = ∂(x, y)/∂(u, v) = | ∂x/∂u  ∂x/∂v ; ∂y/∂u  ∂y/∂v |`

> **说明**：吴赣昌版第 3 章重点在**卷积法与 max/min 法**，雅可比法了解即可（考研数学一要求掌握）。本科期末以卷积与 max/min 为主。

## 典型例题

**例 3.1**（题型：由联合分布律求常数、边缘分布与独立性）
设二维随机变量 `(X, Y)` 的联合分布律为：

| X \ Y | 1 | 2 |
|---|---|---|
| 0 | 0.1 | 0.2 |
| 1 | 0.3 | a |

① 求 a；② 求 X、Y 的边缘分布律；③ 求 `P(X + Y ≤ 2)`；④ 判断 X 与 Y 是否独立。

**解**：
① **为什么这样做**：联合分布律必须满足 `ΣΣp_ij = 1`。
`0.1 + 0.2 + 0.3 + a = 1` ⟹ `a = 0.4`。

② **边缘分布 = 行和/列和**：
`P(X = 0) = 0.1 + 0.2 = 0.3`，`P(X = 1) = 0.3 + 0.4 = 0.7`；
`P(Y = 1) = 0.1 + 0.3 = 0.4`，`P(Y = 2) = 0.2 + 0.4 = 0.6`。
（验证：`0.3 + 0.7 = 1` ✓，`0.4 + 0.6 = 1` ✓）

③ **为什么这样枚举**：`X + Y ≤ 2` 要求逐个数对试算。
`(0,1): 0+1 = 1 ≤ 2` ✓；`(0,2): 0+2 = 2 ≤ 2` ✓；`(1,1): 1+1 = 2 ≤ 2` ✓；`(1,2): 1+2 = 3 > 2` ✗。
`P(X + Y ≤ 2) = 0.1 + 0.2 + 0.3 = 0.6`

④ **只需找到一个反例**：`P(X=0, Y=1) = 0.1`，而 `P(X=0)·P(Y=1) = 0.3 × 0.4 = 0.12`。
`0.1 ≠ 0.12`，故 X 与 Y **不独立**。

**答案**：① a = 0.4；② `X: 0.3 / 0.7`，`Y: 0.4 / 0.6`；③ 0.6；④ 不独立。

---

**例 3.2**（题型：由联合密度求常数、边缘密度、独立性）
设 `(X, Y)` 的联合概率密度为

`f(x, y) = k`（0 < x < 1，0 < y < x）；`f(x, y) = 0`（其它）

① 求 k；② 求边缘密度 `f_X(x)`、`f_Y(y)`；③ 求 `P(X + Y < 1)`；④ 判断独立性。

**解**：
① **为什么先画区域**：非零区域是三角形 `G = {0 < y < x < 1}`，面积 `∫_0^1 x dx = 1/2`。
由归一性 `k × (1/2) = 1`，得 `k = 2`。

② **定上下限要看清区域**：
`f_X(x) = ∫_{−∞}^{+∞} f(x,y) dy = ∫_0^x 2 dy = 2x`（0 < x < 1），其余为 0。
`f_Y(y) = ∫_{−∞}^{+∞} f(x,y) dx = ∫_y^1 2 dx = 2(1 − y)`（0 < y < 1），其余为 0。
（验证：`∫_0^1 2x dx = 1` ✓，`∫_0^1 2(1−y) dy = 1` ✓）

③ **为什么要重新定区域**：`X + Y < 1` 与 G 的交集是 `G' = {0 < y < x < 1, x + y < 1}`，即 `{0 < y < 1/2, y < x < 1 − y}`。
`P = ∫_0^{1/2} ∫_y^{1−y} 2 dx dy = ∫_0^{1/2} 2(1 − 2y) dy = 2[y − y²]_0^{1/2} = 2(1/2 − 1/4) = 0.5`
（几何验证：G 内满足 `x + y < 1` 的部分正好是 G 的一半 ✓）

④ **一眼判别**：非零区域 `0 < y < x < 1` **不是矩形**（y 的上界依赖 x），故 **X 与 Y 不独立**。
代数验证：`f_X(x) f_Y(y) = 4x(1 − y) ≠ 2 = f(x,y)` ✓

**答案**：① k = 2；② `f_X(x) = 2x`，`f_Y(y) = 2(1−y)`（0 < 各自 < 1）；③ 0.5；④ 不独立。

**例 3.3**（题型：条件密度与条件概率）
设 X ~ U(0, 1)。在给定 `X = x`（0 < x < 1）的条件下，Y 在 `(0, x)` 上服从均匀分布。① 求联合密度 `f(x, y)`；② 求 `f_Y(y)`；③ 求 `P(X < 0.5 | Y = 0.25)`。

**解**：
① **为什么用乘法公式**：题目给的是「先 X 后 Y」的层次结构，正是 `f(x,y) = f_{Y|X}(y|x) f_X(x)`。
`f_X(x) = 1`（0 < x < 1）；`f_{Y|X}(y|x) = 1/x`（0 < y < x）。
故 `f(x, y) = (1/x) × 1 = 1/x`（0 < y < x < 1），其余为 0。

② `f_Y(y) = ∫_{−∞}^{+∞} f(x,y) dx = ∫_y^1 (1/x) dx = [ln x]_y^1 = 0 − ln y = −ln y`（0 < y < 1）。
（验证：`∫_0^1 (−ln y) dy = [−y ln y + y]_0^1 = 1` ✓）

③ **条件密度 = 联合 ÷ 边缘**：
`f_{X|Y}(x | 0.25) = f(x, 0.25)/f_Y(0.25) = (1/x)/(−ln 0.25)`
`ln 0.25 = −1.3863`，故 `−ln 0.25 = 1.3863`。
`f_{X|Y}(x|0.25) = 1/(1.3863 x)`，定义域为 `x ∈ (0.25, 1)`（**因为要求 y < x 且 y = 0.25**）。
`P(X < 0.5 | Y = 0.25) = ∫_{0.25}^{0.5} 1/(1.3863x) dx = (1/1.3863) · ln(0.5/0.25) = (1/1.3863)(0.6931) = 0.5`

**答案**：① `f(x,y) = 1/x`（0 < y < x < 1）；② `f_Y(y) = −ln y`；③ 0.5。

**例 3.4**（题型：卷积公式求 Z = X + Y）
设 X 与 Y 相互独立，都服从 `U(0, 1)`。求 `Z = X + Y` 的概率密度。

**解**：
`f_X(x) = 1`（0 < x < 1）；`f_Y(y) = 1`（0 < y < 1）。
由卷积公式 `f_Z(z) = ∫_{−∞}^{+∞} f_X(x) f_Y(z − x) dx`。

**关键一步——确定积分限**：被积函数非零要求**两个条件同时成立**：
① `0 < x < 1`；② `0 < z − x < 1`，即 `z − 1 < x < z`。
故积分区间为 `(0, 1) ∩ (z−1, z)`。**这个区间随 z 变化，必须分段**：

- **z ≤ 0**：交集为空，`f_Z(z) = 0`
- **0 < z ≤ 1**：交集为 `(0, z)`，长度 z，`f_Z(z) = ∫_0^z 1 dx = z`
- **1 < z < 2**：交集为 `(z−1, 1)`，长度 `2 − z`，`f_Z(z) = ∫_{z−1}^{1} 1 dx = 2 − z`
- **z ≥ 2**：交集为空，`f_Z(z) = 0`

分段写成分段函数：

`f_Z(z) = 0`（z ≤ 0）；`= z`（0 < z ≤ 1）；`= 2 − z`（1 < z < 2）；`= 0`（z ≥ 2）

**验证**：`∫_0^1 z dz + ∫_1^2 (2−z) dz = 0.5 + 0.5 = 1` ✓
最后积分一次得 `F_Z(z) = z²/2`（0<z≤1）；`= 1 − (2−z)²/2`（1<z<2）。这是著名的**三角分布（辛普森分布）**。

> **拓展（正态可加性的直接应用）**：若 X、Y 独立且都服从 `N(0,1)`，则由紧凑卷积可得 `X + Y ~ N(0, 2)`。这是 §3.2.2 **可加性定理**中「正态可加性」`X+Y ~ N(μ₁+μ₂, σ₁²+σ₂²)` 在 `μ₁ = μ₂ = 0`、`σ₁² = σ₂² = 1` 情形下的特例。可见「均匀分布之和是三角分布」而「正态之和仍是正态」——**正态分布具有「和封闭性」**，这正是它在统计中地位特殊的根本原因。

**答案**：见上。

**例 3.5**（题型：max / min 分布，可靠性应用）
某系统由两个**独立**工作的元件组成，元件寿命 `X`、`Y` 均服从 `E(λ)`（λ > 0）。求：
① 两元件**串联**时系统寿命 T₁ 的分布与平均寿命；
② 两元件**并联**时系统寿命 T₂ 的分布与平均寿命。

**解**：
两元件的分布函数相同：`F(t) = 1 − e^(−λt)`（t > 0）。
① **串联 ⟹ 任一坏即坏 ⟹ 寿命取 min**，即 `T₁ = min(X, Y)`。
**为什么用对立事件**：`{min > t} ⟺ {X > t 且 Y > t}`，独立性保证概率可相乘。
`P(T₁ > t) = P(X > t)P(Y > t) = e^(−λt) · e^(−λt) = e^(−2λt)`
故 `F_{T₁}(t) = 1 − e^(−2λt)`，即 `T₁ ~ E(2λ)`，`E(T₁) = 1/(2λ)`。

② **并联 ⟹ 全坏才坏 ⟹ 寿命取 max**，即 `T₂ = max(X, Y)`。
`{max ≤ t} ⟺ {X ≤ t 且 Y ≤ t}`
`F_{T₂}(t) = F(t) · F(t) = (1 − e^(−λt))² = 1 − 2e^(−λt) + e^(−2λt)`
密度：`f_{T₂}(t) = 2λe^(−λt) − 2λe^(−2λt)`（t > 0）。
平均寿命用公式 `E(T) = ∫_0^{+∞} P(T > t) dt`：
`E(T₂) = ∫_0^{+∞} [1 − F_{T₂}(t)] dt = ∫_0^{+∞} [2e^(−λt) − e^(−2λt)] dt = 2/λ − 1/(2λ) = 3/(2λ)`

**答案**：① `T₁ ~ E(2λ)`，`E(T₁) = 1/(2λ)`；② `F_{T₂}(t) = (1−e^(−λt))²`，`E(T₂) = 3/(2λ)`。

> **工程解读（重要）**：单个元件平均寿命 `1/λ`。串联后降到 `1/(2λ)`（**缩短为一半**），并联后升到 `3/(2λ)`（**延长 50%**）。这解释了为什么冗余设计能提高可靠性，但代价是成本翻倍。可用恒等式校验：`E(X) + E(Y) = E(T₁) + E(T₂)`，即 `2/λ = 1/(2λ) + 3/(2λ)` ✓

**例 3.6**（题型：正态分布的线性组合）
设 `X ~ N(1, 4)`，`Y ~ N(2, 9)`，且 X 与 Y 相互独立。求 `Z = 2X − Y` 的分布及 `P(Z < 0)`。

**解**：
**为什么可以这样做**：独立正态变量的线性组合仍为正态（正态分布族对线性运算封闭）。
记 `Z = aX + bY`，其中 `a = 2`，`b = −1`。
均值（期望的线性性质，不需要独立性）：
`E(Z) = 2E(X) − E(Y) = 2 × 1 − 2 = 0`
方差（**需要独立性才能这样相加**，且系数要平方）：
`D(Z) = a²D(X) + b²D(Y) = 2² × 4 + (−1)² × 9 = 16 + 9 = 25`
故 `Z ~ N(0, 25)`，`σ_Z = 5`。
`P(Z < 0) = Φ((0 − 0)/5) = Φ(0) = 0.5`

**答案**：`Z ~ N(0, 25)`，`P(Z < 0) = 0.5`。

> **易错警示**：`D(2X − Y) ≠ 4D(X) − D(Y) = 16 − 9 = 7`！方差**永远是加号**（系数平方后相加）。写成减号是最常见的错误之一。同时注意不能写成 `D(Z) = (2−1)²(D(X)+D(Y))`。

**例 3.7**（题型：独立性判别，证明题）
证明：若 `(X, Y)` 在矩形区域 `G = {(x, y) : a < x < b, c < y < d}` 上服从均匀分布，则 X 与 Y 相互独立；并写出各自的边缘分布。

**证明**：
G 的面积 `A = (b − a)(d − c)`，故联合密度为
`f(x, y) = 1/[(b−a)(d−c)]`（a < x < b，c < y < d）；其余为 0。
求边缘密度：
`f_X(x) = ∫_c^d 1/[(b−a)(d−c)] dy = (d − c)/[(b−a)(d−c)] = 1/(b − a)`（a < x < b）
`f_Y(y) = ∫_a^b 1/[(b−a)(d−c)] dx = (b − a)/[(b−a)(d−c)] = 1/(d − c)`（c < y < d）
即在矩形上 `f(x, y) = f_X(x) · f_Y(y)` 恒成立，故 X 与 Y 相互独立。
且 `X ~ U(a, b)`，`Y ~ U(c, d)`。∎

**答案**：见证明。

> **反向结论（同样重要）**：若均匀分布的区域**不是矩形**（例如三角形、圆、`0 < y < x < 1`），则 X 与 Y **一定不独立**。这是一条极快的判据，考试中遇到非矩形区域可以直接下结论。

**例 3.8**（题型：泊松分布可加性，证明题）
设 `X ~ P(λ₁)`，`Y ~ P(λ₂)`，且 X 与 Y 相互独立。证明 `X + Y ~ P(λ₁ + λ₂)`。

**证明**：
`X + Y` 取非负整数值。对任意 `k = 0, 1, 2, …`，用**全概率公式按 X 的取值分解**（因为 X 与 Y 独立）：
`P(X + Y = k) = Σ_{i=0}^{k} P(X = i, Y = k − i) = Σ_{i=0}^{k} P(X = i) · P(Y = k − i)`
代入泊松分布律：
`= Σ_{i=0}^{k} [λ₁^i e^(−λ₁)/i!] · [λ₂^(k−i) e^(−λ₂)/(k−i)!]`
提取与 i 无关的因子：
`= e^(−(λ₁+λ₂)) · Σ_{i=0}^{k} λ₁^i λ₂^(k−i) / [i! (k−i)!]`
**关键一步——凑二项式系数**：在求和号内乘以再除以 `k!`：
`λ₁^i λ₂^(k−i)/[i!(k−i)!] = (1/k!) · C(k, i) λ₁^i λ₂^(k−i)`
故
`P(X + Y = k) = e^(−(λ₁+λ₂))/k! · Σ_{i=0}^{k} C(k,i) λ₁^i λ₂^(k−i)`
由**二项式定理** `Σ_{i=0}^{k} C(k,i) λ₁^i λ₂^(k−i) = (λ₁ + λ₂)^k`：
`P(X + Y = k) = (λ₁+λ₂)^k e^(−(λ₁+λ₂)) / k!`
这正是参数为 `λ₁ + λ₂` 的泊松分布律，故 `X + Y ~ P(λ₁ + λ₂)`。∎

**答案**：见证明。

**例 3.9**（题型：联合分布函数的性质判断）
设 `F(x, y) = A(B + arctan x)(C + arctan y)`。问：能否适当选取 A、B、C 使其成为某二维随机变量的联合分布函数？若能，求出 A、B、C，并判断 X 与 Y 是否独立。

**解**：
**为什么这样取极限**：利用联合分布函数的极限性质定常数。注意 `arctan(+∞) = π/2`，`arctan(−∞) = −π/2`。
由 `F(+∞, +∞) = 1`：`A(B + π/2)(C + π/2) = 1` … ①
由 `F(x, −∞) = 0`：`A(B + arctan x)(C − π/2) = 0` 对一切 x。因 `(B + arctan x)` 不恒为 0，故 `C − π/2 = 0`，即 `C = π/2`。
由 `F(−∞, y) = 0`：同理 `B − π/2 = 0`，即 `B = π/2`。
代入 ①：`A(π/2 + π/2)(π/2 + π/2) = A π² = 1`，故 `A = 1/π²`。
于是 `F(x, y) = (1/π²)(π/2 + arctan x)(π/2 + arctan y)`。
**验证矩形公式**：由于 `F(x,y)` 可分离为 `F_X(x) F_Y(y)`，其中 `F_X(x) = (1/π)(π/2 + arctan x)`，`F_Y(y) = (1/π)(π/2 + arctan y)`，两者都是合法的（柯西分布型）分布函数，故矩形公式自动满足，X 与 Y **相互独立**。

**答案**：`A = 1/π²`，`B = C = π/2`；X 与 Y 相互独立。

## 易错点提醒

1. **把边缘分布相加时加错方向**。
   **错在**：求 `P(X = xᵢ)` 时对 i 求和。
   **正确做法**：**求 X 的边缘对 Y（j）求和**——「求谁留谁，把另一个积掉/加掉」。记口诀：**行和给 X，列和给 Y**。

2. **认为「边缘分布正态 ⟹ 联合正态」**。
   **错在**：看到 `X ~ N`、`Y ~ N` 就断定 `(X,Y)` 是二维正态。
   **正确做法**：**反过来才对**——二维正态 ⟹ 边缘正态；边缘正态**推不出**联合正态。此外，「边缘正态 + 不相关」也推不出联合正态。

3. **求 `D(aX + bY)` 时用减号**。
   **错在**：`D(2X − Y) = 4D(X) − D(Y)`。
   **正确做法**：`D(aX + bY) = a²D(X) + b²D(Y) + 2ab·Cov(X,Y)`。独立时 `Cov = 0`，得 `D = a²D(X) + b²D(Y)`——**永远是加号**，且系数要**平方**。

4. **用卷积公式时不讨论 z 的分段**。
   **错在**：直接写 `f_Z(z) = ∫_0^1 1 dz = 1`。
   **正确做法**：被积函数的非零条件是「x 在自己的区间内」**且**「z − x 在自己的区间内」，两个不等式联立得到的积分区间**依赖 z**，必须按 z 的取值范围分段讨论（例 3.4 的四段）。

5. **判独立时只看密度能否分离变量，忽略定义域**。
   **错在**：看到 `f(x,y) = 2` 认为是常数就可分离，直接判独立。
   **正确做法**：**两个条件缺一不可**——① 非零区域是**矩形**；② 密度能写成 `g(x)h(y)`。例 3.2 中 `f = 2` 是常数，但区域 `0 < y < x < 1` 不是矩形，仍不独立。

6. **求 `min(X,Y)` 的分布时硬算 `{N ≤ z}`**。
   **错在**：`P(N ≤ z) = P(X ≤ z) + P(Y ≤ z) − P(X ≤ z, Y ≤ z)`，虽对但易错且无法推广到 n 个。
   **正确做法**：**用对立事件**：`F_N(z) = 1 − P(X > z, Y > z) = 1 − [1−F_X(z)][1−F_Y(z)]`。n 个元件时 `= 1 − [1−F(z)]ⁿ`。

7. **误以为「不相关」等于「独立」**。
   **错在**：算出 `Cov(X,Y) = 0` 就断言独立。
   **正确做法**：**独立 ⟹ 不相关**，反之不成立。唯有**二维正态**情形下「不相关 ⟺ 独立」。第 4 章会给出反例 `X ~ U(−1,1)`、`Y = X²`（不相关但不独立）。

8. **二维概率积分时区域定错**。
   **错在**：算 `P(X + Y < 1)` 时仍然用原来的 `∫_0^1∫_0^x`。
   **正确做法**：**先画区域图**，把新条件作为新的边界，重新求交集区域的上下限。或用几何直观（面积比）验证结果。

9. **二项分布可加性忘记 p 相同**。
   **错在**：`B(5, 0.3) + B(4, 0.5) ~ B(9, 0.4)`。
   **正确做法**：二项可加要求 `n₁ + n₂` 且 **p 完全一致**。p 不同时不服从二项分布（此时是泊松二项分布）。

10. **忽略「条件密度中的条件是常数」**。
    **错在**：把 `f_{X|Y}(x|y)` 当成含两个变量的函数去积分两次。
    **正确做法**：代入具体的 `y = y₀` 后，`f_{X|Y}(x|y₀)` 只是 x 的函数，按一元密度处理；其非零区间也要**用 y₀ 重新确定**（例 3.3 中 x 从 (0,1) 缩到 (0.25, 1)）。

## 本章小结

- **联合分布函数** `F(x,y) = P(X ≤ x, Y ≤ y)`，关键是**矩形公式**（右上加、左下减）。
- **二维离散型**用联合分布律表刻画，**行和给 X 的边缘，列和给 Y 的边缘**。
- **二维连续型**用联合密度刻画，`P((X,Y) ∈ D) = ∬_D f dxdy`，做题第一步是**画区域**。
- **联合 ⟹ 边缘，边缘 ⇏ 联合**——这是本章最重要的逻辑关系。
- **条件分布**：联合 ÷ 另一变量的边缘。离散用 `p_ij/p_·j`，连续用 `f(x,y)/f_Y(y)`。
- **独立性**三个等价条件：`F = F_X F_Y`、`p_ij = p_i·p_·j`、`f = f_X f_Y`；快速判据是「**矩形区域 + 可分离变量**」。
- **可加性**：正态（`N(μ₁+μ₂, σ₁²+σ₂²)`）、泊松（`P(λ₁+λ₂)`）、二项（`B(n+m,p)`，要求 p 相同）、χ²（自由度相加）。
- **卷积公式** `f_Z(z) = ∫f_X(x)f_Y(z−x)dx`，难点在**按 z 分段定积分限**。
- **max/min**：`F_max = F_X F_Y`；`F_min = 1 − (1−F_X)(1−F_Y)`。串联取 min，并联取 max。
- **一句话记住本章**：二维问题的全部技巧归结为「**画区域、定上下限、验可分性**」三件事。
