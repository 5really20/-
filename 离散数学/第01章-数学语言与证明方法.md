## 1.1 常用的数学符号

**结论先行：数学符号分三类——集合符号、运算符号、逻辑符号。看到符号先问「它作用在什么对象上」，符号本身不产生含义。**

### 1.1.1 集合符号

| 符号 | 读法 | 含义 | 易混点 |
|---|---|---|---|
| `∈` | 属于 | `a ∈ A`：a 是 A 的元素 | 左边必须是**元素**，不能写 `A ∈ B` 指集合包含 |
| `∉` | 不属于 | `a ∉ A` | |
| `⊆` | 包含于 | A 的每个元素都在 B 中 | 允许 `A = B` |
| `⊂` | 真包含于 | `A ⊆ B` 且 `A ≠ B` | 本书中 `⊂` 表示**真包含** |
| `⊇` / `⊃` | 包含 / 真包含 | 上面两个的反向写法 | |
| `P(A)` 或 `2^A` | 幂集 | A 的所有子集构成的集合 | `P(A)` 的元素是**集合** |
| `∅` | 空集 | 不含任何元素的集合 | `∅ ≠ {∅}` |
| `\|A\|` | 基数 | 有限集 A 的元素个数 | |
| `U` 或 `E` | 全集 | 所讨论对象的全体 | 随讨论范围变化 |

> **重点**：`∈` 连接「元素与集合」，`⊆` 连接「集合与集合」。`a ∈ A` 和 `{a} ⊆ A` 是一个意思，但 `a ⊆ A` 一般没意义（除非 a 本身是集合）。

### 1.1.2 运算符号

| 符号 | 名称 | 说明 |
|---|---|---|
| `+ − × ÷` | 四则运算 | |
| `⌊x⌋` | 下取整 | 不超过 x 的最大整数，`⌊2.7⌋ = 2`，`⌊−2.1⌋ = −3` |
| `⌈x⌉` | 上取整 | 不小于 x 的最小整数，`⌈2.1⌉ = 3`，`⌈−2.7⌉ = −2` |
| `∑` / `∏` | 求和 / 求积 | |
| `\|x\|` | 绝对值 | 与集合基数同符号，靠上下文区分 |
| `n!` | 阶乘 | `0! = 1`（规定） |

> **易错**：负数的取整方向。`⌊−2.1⌋ = −3`（往**更小**的方向），不是 `−2`。

### 1.1.3 逻辑符号

| 符号 | 名称 | 读法 | 真值规定 |
|---|---|---|---|
| `¬P` | 否定 | 非 P | P 真时假，P 假时真 |
| `P ∧ Q` | 合取 | P 且 Q | 只有 P、Q 都真才真 |
| `P ∨ Q` | 析取 | P 或 Q | 只有 P、Q 都假才假（**可兼或**） |
| `P → Q` | 蕴含 | 若 P 则 Q | **只有 P 真 Q 假时为假** |
| `P ↔ Q` | 等价 | P 当且仅当 Q | P、Q 同真同假时为真 |
| `∀x` | 全称量词 | 对所有 x | |
| `∃x` | 存在量词 | 存在 x | |

> **重点**：`P → Q` 在前件 P 为**假**时，整个蕴含式为**真**（称为「善意推定」）。`「若 1+1=3，则太阳从西边升起」` 是真命题。

## 1.2 集合及其运算

### 1.2.1 集合及其表示法

**定义 1.1（集合）**：集合（Set）是一些确定的、彼此可区分的对象汇成的整体；这些对象称为集合的**元素**（Element）。

**两条基本性质**：
1. **确定性**：任一对象要么属于该集合，要么不属于，没有中间状态。
2. **互异性**：集合中元素互不相同，`{1, 1, 2} = {1, 2}`。
3. （常补充）**无序性**：`{1, 2} = {2, 1}`。

**两种表示法**：

| 方法 | 形式 | 例 | 适用场合 |
|---|---|---|---|
| 列举法 | 把元素一一列出 | `A = {1, 2, 3, 4}` | 元素少、可穷举 |
| 描述法 | 用谓词刻画 | `B = {x \| x ∈ Z 且 x² < 10}` | 元素多或无限 |

> **直观类比**：集合像「一个袋子」。袋子里有什么，就是集合的元素；袋子本身和袋子里的袋子不是一回事——所以 `∅` 与 `{∅}` 不同：前者的袋子是空的，后者袋子里装着一个空袋子，`|∅| = 0` 而 `|{∅}| = 1`。

### 1.2.2 集合之间的包含与相等

**定义 1.2（子集）**：`A ⊆ B` 当且仅当对任意 x，若 `x ∈ A` 则 `x ∈ B`。
即 `A ⊆ B ⟺ ∀x (x ∈ A → x ∈ B)`。

**定义 1.3（相等）**：`A = B` 当且仅当 `A ⊆ B` 且 `B ⊆ A`。

> **这是集合恒等式证明的唯一标准方法**（叫**元素法**或**双向包含法**）：
> 要证 `A = B`，就分两步：① 任取 `x ∈ A`，推出 `x ∈ B`（得 `A ⊆ B`）；② 任取 `x ∈ B`，推出 `x ∈ A`（得 `B ⊆ A`）。

**定义 1.4（真子集）**：`A ⊂ B ⟺ A ⊆ B 且 A ≠ B`。

**三个必记事实**：
- `∅ ⊆ A` 对任意集合 A 成立（空集是任意集合的子集）。
- `A ⊆ A` 对任意集合 A 成立（自反性）。
- 若 `A ⊆ B` 且 `B ⊆ C`，则 `A ⊆ C`（传递性）。

> **易错**：空集是**任意**集合的子集，但**不是**任意集合的元素。`∅ ⊆ {1,2}` 真，`∅ ∈ {1,2}` 假。

### 1.2.3 集合的幂集

**定义 1.5（幂集）**：`A` 的**幂集（Power Set）** 是 A 的所有子集构成的集合，记作 `P(A)` 或 `2^A`：
`P(A) = {X | X ⊆ A}`

**定理 1.1（幂集基数）**：若 `|A| = n`，则 `|P(A)| = 2^n`。
**为什么**：A 的每个子集，对应「对 n 个元素各做一次二选一（选/不选）」的一种结果，由乘法原理共 `2^n` 种。

**例**：`A = {a, b, c}`，则
`P(A) = {∅, {a}, {b}, {c}, {a,b}, {a,c}, {b,c}, {a,b,c}}`，`|P(A)| = 2³ = 8`。

**幂集的两个反常性质**（考试常考「判断对错」）：
- `∅ ∈ P(A)` 且 `∅ ⊆ P(A)` 都成立（空集是 A 的子集，故是 P(A) 的元素）。
- `A ∈ P(A)` 成立（A 是 A 的子集）。

### 1.2.4 集合的运算

**定义 1.6（五种运算）**：设 A、B 为集合，全集为 U。

| 运算 | 名称 | 定义 |
|---|---|---|
| `A ∪ B` | 并集 | `{x \| x ∈ A 或 x ∈ B}` |
| `A ∩ B` | 交集 | `{x \| x ∈ A 且 x ∈ B}` |
| `A − B` | 差集（相对补） | `{x \| x ∈ A 且 x ∉ B}` |
| `～A`（也写 `A'`、`Ā`） | 补集（绝对补） | `U − A = {x \| x ∈ U 且 x ∉ A}` |
| `A ⊕ B` | 对称差（环和） | `(A − B) ∪ (B − A) = (A ∪ B) − (A ∩ B)` |

**对称差的直观理解**：`A ⊕ B` 就是「在 A 里或在 B 里，但不同时在两边」的元素。类似逻辑里的「异或」。
生活类比：两个班的同学，`A ⊕ B` 是「只在这两个班中的一个班」的人，两班都参加的（`A ∩ B`）被剔除。

**运算性质表**：

| 性质 | 并 | 交 | 对称差 |
|---|---|---|---|
| 交换律 | `A ∪ B = B ∪ A` | `A ∩ B = B ∩ A` | `A ⊕ B = B ⊕ A` |
| 结合律 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` | 同左 | `(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)` |
| 幂等律 | `A ∪ A = A` | `A ∩ A = A` | `A ⊕ A = ∅` |
| 单位元 | `A ∪ ∅ = A` | `A ∩ U = A` | `A ⊕ ∅ = A` |
| 零元 | `A ∪ U = U` | `A ∩ ∅ = ∅` | — |
| 分配律 | `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)` | `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` | 对 ∩ 也分配 |

**集合运算与逻辑运算的对应关系**（理解恒等式的钥匙）：

| 集合 | 逻辑 | 集合 | 逻辑 |
|---|---|---|---|
| `∪` | `∨` | `U` | `T`（真） |
| `∩` | `∧` | `∅` | `F`（假） |
| `～` | `¬` | `⊆` | `→` |
| `⊕` | 异或 | `=` | `↔` |

> **重点**：集合恒等式和命题逻辑等值式是**同一套代数**。集合的德摩根律 `～(A ∪ B) = ～A ∩ ～B` 就是逻辑的 `¬(P ∨ Q) = ¬P ∧ ¬Q`。学完第 02 章你会觉得它们是一回事。

### 1.2.5 基本集合恒等式及其应用

**必背恒等式表**（设 U 为全集）：

| 编号 | 名称 | 恒等式 |
|---|---|---|
| E1 | 幂等律 | `A ∪ A = A`，`A ∩ A = A` |
| E2 | 交换律 | `A ∪ B = B ∪ A`，`A ∩ B = B ∩ A` |
| E3 | 结合律 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` |
| E4 | 分配律 | `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)` |
| E5 | 德摩根律 | `～(A ∪ B) = ～A ∩ ～B`，`～(A ∩ B) = ～A ∪ ～B` |
| E6 | 吸收律 | `A ∪ (A ∩ B) = A`，`A ∩ (A ∪ B) = A` |
| E7 | 同一律 | `A ∪ ∅ = A`，`A ∩ U = A` |
| E8 | 零律 | `A ∪ U = U`，`A ∩ ∅ = ∅` |
| E9 | 排中律 | `A ∪ ～A = U` |
| E10 | 矛盾律 | `A ∩ ～A = ∅` |
| E11 | 双重否定 | `～～A = A` |
| E12 | 差集转化 | `A − B = A ∩ ～B` |
| E13 | 对称差转化 | `A ⊕ B = (A ∩ ～B) ∪ (～A ∩ B)` |
| E14 | 包含转化 | `A ⊆ B ⟺ A ∪ B = B ⟺ A ∩ B = A ⟺ A − B = ∅` |

> **重点**：`E12`（差集化成交）是把集合表达式化简的**第一招**。看到 `−` 就换 `∩ ～`，之后所有运算都只有 `∪ ∩ ～`，德摩根律随便用。

## 1.3 证明方法概述

### 1.3.1 逻辑推理的形式结构

**结论先行：任何数学命题都能写成「若 P 则 Q」的形式，证明就是验证 `P → Q` 是重言式。**

**定义 1.7（推理的形式结构）**：由一组前提 `A₁, A₂, …, Aₖ` 推出结论 `B`，记作
`A₁ ∧ A₂ ∧ … ∧ Aₖ → B`
若该蕴含式是**重言式**（恒真），则称推理**有效**，记作 `A₁, A₂, …, Aₖ ⟹ B`。

**三种常见的命题形式与证明策略**：

| 命题形式 | 写法 | 首选证明方法 |
|---|---|---|
| 若 P 则 Q | `P → Q` | 直接证明法 / 反证法 |
| P 当且仅当 Q | `P ↔ Q` | 分两半：先证 `P → Q`，再证 `Q → P` |
| 对所有 x，P(x) | `∀x P(x)` | 任取 x，证 P(x)（**「任取」二字不能省**） |
| 存在 x 使 P(x) | `∃x P(x)` | 构造性证明：把那个 x 找出来 |

### 1.3.2 公理、定理与证明

**定义 1.8**：
- **公理（Axiom）**：不加证明而承认其成立的命题（如「空集存在」）。
- **定理（Theorem）**：由公理、定义和已证定理出发，经有效推理得到真值为真的命题。
- **引理（Lemma）**：为证明主定理而先证的辅助定理。
- **推论（Corollary）**：由定理直接导出、几乎不需再证的结论。
- **证明（Proof）**：由已知事实出发，以有效推理形式导出结论的**完整过程**。

**证明的两个基本要求**：
1. **每一步都有依据**：依据是定义、公理、已证定理，或前提。
2. **不能循环论证**：不能用结论去证前提。

### 1.3.3 证明方法

#### 方法一：直接证明法

**做法**：要证 `P → Q`，就**假设 P 真**，一步步推出 **Q 真**。

**例**：证明「若 n 是奇数，则 n² 是奇数」。
**证明**：假设 n 是奇数，则存在整数 k 使 `n = 2k + 1`。
于是 `n² = (2k+1)² = 4k² + 4k + 1 = 2(2k² + 2k) + 1`。
令 `m = 2k² + 2k`（是整数），则 `n² = 2m + 1` 是奇数。∎

#### 方法二：反证法（归谬法）

**结论先行：反证法的本质是证明 `¬Q → ¬P`，即证明原命题的逆否命题。**

**做法**：
- 要证 `P → Q`：假设 `P` 真且 `Q` **假**，推出矛盾。
- 要证「P 真」（无条件命题）：假设 `¬P`，推出矛盾。

> **为什么有效**：`P → Q ≡ ¬Q → ¬P ≡ ¬(P ∧ ¬Q)`。若 `P ∧ ¬Q` 导致矛盾，则 `P ∧ ¬Q` 恒假，故 `P → Q` 恒真。

**例**：证明「√2 是无理数」。
**证明**（反证）：
假设 √2 是**有理数**，则存在互质的正整数 p、q 使 `√2 = p/q`。
两边平方：`2q² = p²`，故 `p²` 是偶数，推出 `p` 是偶数。
设 `p = 2k`，代入得 `2q² = 4k²`，即 `q² = 2k²`，同理 `q` 是偶数。
于是 p、q 有公因数 2，与「p、q 互质」矛盾。
所以 √2 不是有理数，即 √2 是无理数。∎

> **易错**：反证法假设的是「**P 真且 Q 假**」，不是「Q 假」。对「若 P 则 Q」型命题，漏掉「假设 P 真」会导致推出的矛盾与原命题无关。

#### 方法三：分情况证明法

**做法**：把前提 P 拆成互斥且穷尽的若干情况 `P₁ ∨ P₂ ∨ … ∨ Pₙ`，逐一证明每种情况下 Q 都成立。

**例**：证明「对任意整数 n，`n² + n` 是偶数」。
**证明**（分情况）：
情况 1：n 是偶数，`n = 2k`。则 `n² + n = 4k² + 2k = 2(2k² + k)`，是偶数。
情况 2：n 是奇数，`n = 2k + 1`。则
`n² = (2k+1)² = 4k² + 4k + 1`，故 `n² + n = 4k² + 4k + 1 + 2k + 1 = 4k² + 6k + 2 = 2(2k² + 3k + 1)`，是偶数。
两种情况穷尽了所有整数，故结论对任意整数 n 成立。∎

> **易错**：分情况必须**互斥且穷尽**。只分「偶数/奇数」对整数是穷尽的；只分「正数/负数」就漏掉了 0。

#### 方法四：构造性证明法

**做法**：要证 `∃x P(x)`，直接把那样的 x **造出来**（给出表达式），并验证它满足 P。

**例**：证明「存在两个无理数 a、b，使 `a^b` 是有理数」。
**证明**（构造）：
取 `a = √2`，`b = √2`（都是无理数）。考虑 `(√2)^(√2)`：
- 情况 1：若 `(√2)^(√2)` 是有理数，则 `a = b = √2` 就是所求。∎
- 情况 2：若 `(√2)^(√2)` 是无理数，则取 `a = (√2)^(√2)`（无理数），`b = √2`（无理数），
  则 `a^b = ((√2)^(√2))^(√2) = (√2)^2 = 2`，是有理数。∎
两种情况必有一种成立，故命题得证。

> 这个证明是「构造性 + 分情况」的混合，很有名。注意它**没有告诉我们到底是哪种情况**——这叫**非构造性存在证明**（也接受）。

#### （补充）唯一性证明

**做法**：先证**存在**（至少一个），再证**唯一**（设 `x₁`、`x₂` 都满足，推出 `x₁ = x₂`）。

**例**：证明方程 `2x + 1 = 5` 在实数中有唯一解。
**证明**：① 存在性：取 `x = 2`，`2×2 + 1 = 5` 成立。
② 唯一性：设 `x₁`、`x₂` 都是解，则 `2x₁ + 1 = 5 = 2x₂ + 1`，两边减 1 除 2 得 `x₁ = x₂`。
故解唯一（就是 x = 2）。∎

### 1.3.4 数学归纳法

#### 第一数学归纳法（普通归纳法）

**原理**：设 `P(n)` 是关于自然数 n 的命题。若
1. **基础步**：`P(n₀)` 真（通常 `n₀ = 1` 或 `0`）；
2. **归纳步**：对任意 `k ≥ n₀`，由 `P(k)` 真能推出 `P(k+1)` 真；
则对一切 `n ≥ n₀`，`P(n)` 真。

**直观类比**：多米诺骨牌。① 推倒第一块；② 每块倒下都能撞倒下一块；于是全倒。

**例**：证明 `1 + 2 + … + n = n(n+1)/2`。
**证明**（第一归纳法）：
① 基础步：`n = 1` 时，左边 `= 1`，右边 `= 1×2/2 = 1`，成立。
② 归纳步：**假设** `1 + 2 + … + k = k(k+1)/2`（这叫**归纳假设**，必须写明）。
则 `1 + 2 + … + k + (k+1) = k(k+1)/2 + (k+1)`
`= (k+1)(k/2 + 1) = (k+1)(k+2)/2`，
这正是把 n 换成 `k+1` 后的右端。
由①②，对一切 `n ≥ 1` 命题成立。∎

#### 第二数学归纳法（强归纳法）

**原理**：设 `P(n)` 是关于自然数 n 的命题。若
1. **基础步**：`P(n₀)` 真；
2. **归纳步**：对任意 `k ≥ n₀`，由 `P(n₀), P(n₀+1), …, P(k)` **全部**真，能推出 `P(k+1)` 真；
则对一切 `n ≥ n₀`，`P(n)` 真。

**第一归纳法与第二归纳法对比**：

| 对比项 | 第一数学归纳法 | 第二数学归纳法 |
|---|---|---|
| 归纳假设 | 只用 `P(k)` | 用 `P(n₀) … P(k)` 全部 |
| 适用场合 | 结论只依赖前一项 | 结论依赖**前若干项**（如 `aₙ` 依赖 `aₙ₋₁` 和 `aₙ₋₂`） |
| 两者强弱 | 弱 | 强（能用第一归纳法证的都能用第二归纳法证） |
| 典型题 | 求和公式、不等式 | 斐波那契数列、递推定义的整除性、算术基本定理 |

> **重点**：如果归纳步里你需要用到的不止 `P(k)`（比如证明 `aₙ < 2ⁿ` 时，递推式是 `aₙ = aₙ₋₁ + aₙ₋₂`），**必须用第二归纳法**，硬用第一归纳法就写不下去了。

**例**：斐波那契数列 `F₁ = 1, F₂ = 1, Fₙ = Fₙ₋₁ + Fₙ₋₂ (n ≥ 3)`。证明 `Fₙ < 2ⁿ`。
**证明**（第二归纳法）：
① 基础步：`F₁ = 1 < 2¹ = 2` ✓；`F₂ = 1 < 2² = 4` ✓。（注意需要**两个**初始值，因为递推式用到前两项。）
② 归纳步：设对一切 `n ≤ k`（`k ≥ 2`）都有 `Fₙ < 2ⁿ`。
则当 `n = k+1` 时，`Fₖ₊₁ = Fₖ + Fₖ₋₁ < 2ᵏ + 2ᵏ⁻¹ < 2ᵏ + 2ᵏ = 2ᵏ⁺¹`。
由①②，对一切 `n ≥ 1`，`Fₙ < 2ⁿ`。∎

> **易错**：第二归纳法的**基础步可能不止一个**。像上面递推式用到前两项，就必须验证 `n = 1` 和 `n = 2` 两个起点。只验一个，`n = 3` 的推证就没有落脚点。

## 典型例题

**例 1.1**（题型：幂集与基数）
设 `A = {∅, {∅}}`。求 `P(A)` 和 `|P(A)|`，并判断 `∅ ∈ P(A)`、`{∅} ⊆ P(A)`、`{∅} ∈ P(A)` 是否成立。
**解**：
① 先数 A 的元素：`A` 有两个元素，分别是 `∅`（空集）和 `{∅}`（含空集的集合）。故 `|A| = 2`。
② 由定理 1.1，`|P(A)| = 2² = 4`。
③ 列出 4 个子集：`∅`、`{∅}`、`{{∅}}`、`{∅, {∅}}`。
**为什么这样做**：A 的元素本身是集合，所以列子集时要把它们当作「元素」用花括号包起来，不能把 `∅` 展开成「什么都没有」。按元素个数分类列：0 个元素的子集 1 个（`∅`），1 个元素的 2 个（`{∅}`、`{{∅}}`），2 个元素的 1 个（`{∅,{∅}}`），共 4 个，与 `2² = 4` 吻合。
④ 故 `P(A) = {∅, {∅}, {{∅}}, {∅,{∅}}}`。
⑤ 判断：
- `∅ ∈ P(A)`：成立（`∅` 是 A 的子集，故是 P(A) 的元素）。
- `{∅} ⊆ P(A)`：成立（`∅ ∈ P(A)`，故 `{∅}` 的元素都在 P(A) 中）。
- `{∅} ∈ P(A)`：成立（`{∅}` 是 A 的子集，故是 P(A) 的元素）。
**答案**：`P(A) = {∅, {∅}, {{∅}}, {∅,{∅}}}`，`|P(A)| = 4`，三条判断全部成立。

**例 1.2**（题型：集合恒等式证明——元素法）
证明 `A − (B ∪ C) = (A − B) ∩ (A − C)`。
**解**（双向包含法）：
① 先证 `A − (B ∪ C) ⊆ (A − B) ∩ (A − C)`。
任取 `x ∈ A − (B ∪ C)`。
由差集定义，`x ∈ A` 且 `x ∉ B ∪ C`。
由并集定义，`x ∉ B ∪ C` 意味着 `x ∉ B` **且** `x ∉ C`（这一步的关键：否定「或」得到「且」）。
于是 `x ∈ A` 且 `x ∉ B`，得 `x ∈ A − B`；又 `x ∈ A` 且 `x ∉ C`，得 `x ∈ A − C`。
两个都成立，故 `x ∈ (A − B) ∩ (A − C)`，包含关系得证。
② 再证 `(A − B) ∩ (A − C) ⊆ A − (B ∪ C)`。
任取 `x ∈ (A − B) ∩ (A − C)`。
则 `x ∈ A − B` 且 `x ∈ A − C`，即（`x ∈ A` 且 `x ∉ B`）且（`x ∈ A` 且 `x ∉ C`）。
合并得 `x ∈ A`，且 `x ∉ B` 且 `x ∉ C`。
「x ∉ B 且 x ∉ C」等价于 `x ∉ B ∪ C`。
故 `x ∈ A − (B ∪ C)`。
③ 双向包含都成立，故两边相等。
**答案**：等式成立。
> 如果用**恒等式演算**做更快：`A − (B ∪ C) = A ∩ ～(B ∪ C) = A ∩ (～B ∩ ～C) = (A ∩ ～B) ∩ (A ∩ ～C) = (A − B) ∩ (A − C)`。两种方法都接受，元素法更保险。

**例 1.3**（题型：包含排斥原理 + 集合运算应用）
某班 50 人，选篮球课的 26 人，选足球课的 21 人，选排球课的 18 人；同时选篮球和足球的 9 人，同时选足球和排球的 7 人，同时选篮球和排球的 5 人；三门都选的 3 人。求三门都没选的人数。
**解**（用容斥原理）：
设 `|B| = 26`，`|F| = 21`，`|V| = 18`，`|B ∩ F| = 9`，`|F ∩ V| = 7`，`|B ∩ V| = 5`，`|B ∩ F ∩ V| = 3`。
① 三门至少选一门的：
`|B ∪ F ∪ V| = |B| + |F| + |V| − |B∩F| − |F∩V| − |B∩V| + |B∩F∩V|`
`= 26 + 21 + 18 − 9 − 7 − 5 + 3 = 47`。
**为什么加回三项交集**：容斥原理的口诀是「奇加偶减」——单个的加，两两交的减，三三交的加。因为两两相交时把「三门都选的人」多减了，最后要加回来。
② 三门都没选的：`50 − 47 = 3`。
**答案**：3 人。

**例 1.4**（题型：反证法）
证明：若 `n²` 是偶数，则 `n` 是偶数（n 为整数）。
**解**（用逆否命题 + 反证）：
① 直接证「`n²` 偶 → n 偶」不好入手，改写为**逆否命题**：若 n 是奇数，则 `n²` 是奇数。
② 假设 n 是奇数，则存在整数 k 使 `n = 2k + 1`。
③ `n² = 4k² + 4k + 1 = 2(2k² + 2k) + 1`，是奇数。
④ 逆否命题成立，故原命题成立。
**答案**：成立。
> **为什么这样做**：`P → Q ≡ ¬Q → ¬P`。当 `¬Q`（n 不是偶数 = n 是奇数）比 `P`（n² 是偶数）更容易写出表达式时，走逆否命题更省力。

**例 1.5**（题型：第二数学归纳法）
设 `a₁ = 1, a₂ = 2, aₙ = 2aₙ₋₁ + aₙ₋₂ (n ≥ 3)`。证明对一切 `n ≥ 1`，`aₙ > 0`。
**解**（第二归纳法）：
① **基础步**（需要两个）：`a₁ = 1 > 0` ✓；`a₂ = 2 > 0` ✓。
**为什么验两个**：递推式 `aₙ = 2aₙ₋₁ + aₙ₋₂` 用到前**两项**，`n = 3` 的推证需要 `a₁`、`a₂` 都已知为正。
② **归纳步**：设对一切 `3 ≤ m ≤ k`（`k ≥ 2`）都有 `aₘ > 0`，考察 `n = k + 1`：
`aₖ₊₁ = 2aₖ + aₖ₋₁ > 2·0 + 0 = 0`（两项都为正，系数 2 和 1 为正，和必为正）。
③ 由①②，对一切 `n ≥ 1`，`aₙ > 0`。
**答案**：成立。

**例 1.6**（题型：构造性证明）
证明：任意 3 个整数中必有两个之和是偶数。
**解**（构造 + 分情况 + 鸽巢）：
① 整数只有两种：偶数、奇数。3 个整数放进 2 个「抽屉」（偶/奇）里。
② 由**鸽巢原理**，至少有一个抽屉里有 ≥ 2 个整数。
③ 分情况：
- 若某抽屉里有 2 个偶数，取这两个偶数 `2m`、`2n`，则 `2m + 2n = 2(m+n)` 是偶数；
- 若某抽屉里有 2 个奇数，取这两个奇数 `2m+1`、`2n+1`，则 `(2m+1) + (2n+1) = 2(m+n+1)` 是偶数。
④ 两种情况都给出了**具体的那两个数**，故存在性和构造都完成。
**答案**：成立。
> **为什么这样做**：题目问「必有两个」，属于「存在性」命题。分情况把「两个偶数」和「两个奇数」两种可能都造出来，就完成了构造性证明。

**例 1.7**（题型：分情况证明 + 取整运算）
证明对任意实数 x，`⌊x⌋ + ⌊x + 1/2⌋ = ⌊2x⌋`。
**解**（分情况）：
设 `x = n + r`，其中 `n = ⌊x⌋` 是整数，`r ∈ [0, 1)`。
① 情况 1：`0 ≤ r < 1/2`。
此时 `x + 1/2 = n + r + 1/2`，而 `r + 1/2 ∈ [1/2, 1)`，故 `⌊x + 1/2⌋ = n`。
`2x = 2n + 2r`，而 `2r ∈ [0, 1)`，故 `⌊2x⌋ = 2n`。
左边 `= n + n = 2n = ` 右边 ✓。
② 情况 2：`1/2 ≤ r < 1`。
此时 `r + 1/2 ∈ [1, 3/2)`，故 `⌊x + 1/2⌋ = n + 1`。
`2r ∈ [1, 2)`，故 `⌊2x⌋ = 2n + 1`。
左边 `= n + (n+1) = 2n + 1 = ` 右边 ✓。
③ 两种情况穷尽了 `r ∈ [0,1)` 的所有可能，故恒等式成立。
**答案**：成立。

## 易错点提醒

1. **`∈` 与 `⊆` 混用**。错：`A ∈ B` 表示「A 包含于 B」。正确：`A ⊆ B` 才是包含；`A ∈ B` 表示 A 是 B 的**一个元素**（此时 A 本身必须是集合）。
2. **`∅` 与 `{∅}` 不分**。错：`{∅} = ∅`。正确：`|∅| = 0`，`|{∅}| = 1`，两者不等；`∅ ∈ {∅}` 成立，`∅ ∈ ∅` 不成立。
3. **`⊂` 当成「包含于」**。错：把 `A ⊂ B` 理解为允许 `A = B`。正确：本书 `⊂` 表示**真包含**，`A ⊂ B` 蕴含 `A ≠ B`。要允许相等请写 `⊆`。
4. **幂集基数算错**。错：`|A| = n` 时写 `|P(A)| = n²`。正确：`|P(A)| = 2ⁿ`。记忆法：「每个元素都有『在子集里 / 不在子集里』两种去向」。
5. **反证法漏假设前提**。错：证「若 P 则 Q」时只假设「Q 假」。正确：假设「**P 真且 Q 假**」，两者都要有，否则推出的矛盾与原命题无关。
6. **分情况不穷尽**。错：证明关于整数的命题只分「正数/负数」。正确：必须写成「正数 / 负数 / 零」三类，或者用「偶数 / 奇数」这种天然穷尽的划分。
7. **归纳法只证一半**。错：只写「假设 `P(k)` 成立，推出 `P(k+1)` 成立」就收工。正确：**基础步和归纳步缺一不可**——没有基础步，等于「骨牌一块都不倒却假设会倒」。
8. **该用第二归纳法时硬用第一归纳法**。错：证 `Fₙ < 2ⁿ`（递推用 `Fₙ₋₁ + Fₙ₋₂`）时归纳假设只写 `Fₖ < 2ᵏ`。正确：必须假设 `Fₖ₋₁` 和 `Fₖ` 都满足，且基础步验两个。
9. **循环论证**。错：用「三角形内角和 180°」去证平行公设，又用平行公设去证内角和。正确：证明链条必须从公理或已证结论出发，不能回头用结论本身。
10. **对称差算成并集**。错：`A ⊕ B = A ∪ B`。正确：`A ⊕ B = (A ∪ B) − (A ∩ B)`，必须**抠掉公共部分**。

## 本章小结

1. 三类符号：集合（`∈ ⊆ ⊂ P`）、运算（`⌊⌋ ⌈⌉ ∑ ∏`）、逻辑（`¬ ∧ ∨ → ↔ ∀ ∃`）。
2. `∈` 连元素与集合，`⊆` 连集合与集合；`⊂` 是真包含。
3. `|P(A)| = 2^|A|`；`∅` 是任意集合的子集，`∅ ≠ {∅}`。
4. 集合五种运算：`∪ ∩ − ～ ⊕`；`A − B = A ∩ ～B` 是化简第一招。
5. 证 `A = B` 的标准方法：**元素法（双向包含）**，也可用恒等式演算。
6. 集合代数与命题逻辑代数是同一套：`∪↔∨`、`∩↔∧`、`～↔¬`、`⊆↔→`。
7. 六种证明方法：直接证明法、反证法、分情况证明法、构造性证明法、存在唯一性证明、数学归纳法。
8. 反证法 = 证逆否命题；必须假设「P 真且 Q 假」。
9. 第一归纳法只用 `P(k)`；结论依赖前多项时必须用第二归纳法，且基础步可能要验多个。
10. 归纳法两大要素：**基础步 + 归纳步**，缺一不可。

> **一句话记住本章**：**证「若 P 则 Q」——正着推是直接法，反着推是反证法，拆着推是分情况，造出来是构造法；碰上自然数就上归纳法，而且别忘了验初始步。**
