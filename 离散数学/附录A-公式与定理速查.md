## A.1 数学语言与证明方法（第 01 章）

### A.1.1 基本定义

| 名称 | 内容 |
|---|---|
| ★ **幂集** | `P(A) = {X \| X ⊆ A}`；**`\|P(A)\| = 2ⁿ`**（`n = \|A\|`，含 `∅` 与 A 本身） |
| **空集** | `∅` 是任何集合的子集：`∅ ⊆ A` 恒成立 |
| **集合相等** | `A = B ⟺ A ⊆ B 且 B ⊆ A`（**证相等的标准方法：双向包含**） |
| **真子集** | `A ⊂ B ⟺ A ⊆ B 且 A ≠ B` |

### A.1.2 六种证明方法

| 方法 | 适用场合 | 关键步骤 |
|---|---|---|
| **直接证明法** | 证 `P → Q` | 假设 P 成立，推导出 Q |
| **反证法** | 结论难直接推出 | 假设 `¬Q`，推出矛盾（`R ∧ ¬R`） |
| **分情况证明法** | 条件可自然分类 | 把情况分成互斥完备的几类，逐类证明 |
| **构造性证明法** | 证「存在……」 | 明确构造出满足条件的对象并验证 |
| **存在唯一性证明** | 证「恰有一个……」 | 先证存在（构造），再证唯一（设两个相等） |
| **★ 数学归纳法** | 与自然数 n 有关 | 见下表 |

**数学归纳法对比表**：

| 项目 | 第一数学归纳法 | 第二数学归纳法（强归纳法） |
|---|---|---|
| **归纳基础** | 证 `P(n₀)` 成立 | 证 `P(n₀)` 成立 |
| **归纳假设** | 假设 `P(k)` 成立 | 假设 `P(n₀), P(n₀+1), …, P(k)` **全部**成立 |
| **归纳步骤** | 由 `P(k)` 推出 `P(k+1)` | 由 `P(n₀)…P(k)` 推出 `P(k+1)` |
| **适用场合** | 一般情形 | `P(k+1)` 依赖**多个**前面的结论 |
| **典型应用** | 求和公式、不等式 | 斐波那契性质、整数的素数分解 |

### A.1.3 集合运算恒等式（必背）

| 编号 | 恒等式 | 编号 | 恒等式 |
|---|---|---|---|
| E1 | `A ∪ A = A`，`A ∩ A = A`（幂等） | E8 | `A ∪ (B ∩ C) = (A∪B) ∩ (A∪C)`（分配） |
| E2 | `A ∪ B = B ∪ A`（交换） | E9 | `A ∩ (B ∪ C) = (A∩B) ∪ (A∩C)`（分配） |
| E3 | `(A∪B)∪C = A∪(B∪C)`（结合） | E10 | `～(A ∪ B) = ～A ∩ ～B`（**德摩根**） |
| E4 | `A ∪ ∅ = A` | E11 | `～(A ∩ B) = ～A ∪ ～B`（**德摩根**） |
| E5 | `A ∩ E = A`（E 是全集） | E12 | `A ∪ (A ∩ B) = A`（吸收） |
| E6 | `A ∪ E = E`，`A ∩ ∅ = ∅` | E13 | `A ∩ (A ∪ B) = A`（吸收） |
| E7 | `～(～A) = A`（双重否定） | E14 | `A − B = A ∩ ～B`（**化差为交，最常用**） |

**★ 包含关系的五种等价刻画**：
`A ⊆ B ⟺ A ∪ B = B ⟺ A ∩ B = A ⟺ A − B = ∅ ⟺ ～B ⊆ ～A`

## A.2 命题逻辑（第 02 章）

### A.2.1 五个基本联结词

| 联结词 | 记号 | 真值表（p, q → 结果） |
|---|---|---|
| **否定** | `¬p` | 1→0，0→1 |
| **合取** | `p ∧ q` | 仅 `11 → 1` |
| **析取** | `p ∨ q` | 仅 `00 → 0` |
| **蕴含** | `p → q` | 仅 `10 → 0`（**前件真后件假时才为假**） |
| **等价** | `p ↔ q` | `11, 00 → 1` |

**★ 蕴含式的四个「亲戚」**：
- 逆命题：`q → p`
- 否命题：`¬p → ¬q`
- 逆否命题：`¬q → ¬p`（**与原命题等值** ✓）
- `p → q ⇔ ¬p ∨ q`（**消去蕴含式的关键公式**）
- **`p → q` 为假 ⟺ p 真且 q 假**（**判断蕴含式真假的唯一标准**）

### A.2.2 ★ 24 条基本等值式

| 编号 | 名称 | 等值式 |
|---|---|---|
| E1 | 双重否定 | `¬¬p ⇔ p` |
| E2 | 幂等 | `p ∨ p ⇔ p`，`p ∧ p ⇔ p` |
| E3 | 交换 | `p ∨ q ⇔ q ∨ p`，`p ∧ q ⇔ q ∧ p` |
| E4 | 结合 | `(p∨q)∨r ⇔ p∨(q∨r)`，`(p∧q)∧r ⇔ p∧(q∧r)` |
| E5 | 分配 | `p∨(q∧r) ⇔ (p∨q)∧(p∨r)`；`p∧(q∨r) ⇔ (p∧q)∨(p∧r)` |
| E6 | **德摩根** | `¬(p∨q) ⇔ ¬p ∧ ¬q`；`¬(p∧q) ⇔ ¬p ∨ ¬q` |
| E7 | 吸收 | `p∨(p∧q) ⇔ p`；`p∧(p∨q) ⇔ p` |
| E8 | 零律 | `p ∨ T ⇔ T`；`p ∧ F ⇔ F` |
| E9 | 同一律 | `p ∨ F ⇔ p`；`p ∧ T ⇔ p` |
| E10 | 排中律 | `p ∨ ¬p ⇔ T` |
| E11 | 矛盾律 | `p ∧ ¬p ⇔ F` |
| E12 | 蕴含等值式 | `p → q ⇔ ¬p ∨ q` |
| E13 | 等价等值式 | `p ↔ q ⇔ (p→q) ∧ (q→p)` |
| E14 | 假言易位 | `p → q ⇔ ¬q → ¬p` |
| E15 | 等价否定 | `p ↔ q ⇔ ¬p ↔ ¬q` |
| E16 | 归谬论 | `(p→q) ∧ (p→¬q) ⇔ ¬p` |
| E17 | 输出律 | `(p∧q) → r ⇔ p → (q→r)` |
| E18 | 双否嵌套 | `¬(¬p ∧ q) ⇔ p ∨ ¬q` |
| E19 | 其他联结词 | `p ↑ q ⇔ ¬(p∧q)`；`p ↓ q ⇔ ¬(p∨q)` |
| E20 | 异或 | `p ⊕ q ⇔ (p∧¬q) ∨ (¬p∧q)` |
| E21 | 条件否定 | `p ↛ q ⇔ p ∧ ¬q` |

| E23 | 消去 ↔ | `p ↔ q ⇔ (p∧q) ∨ (¬p∧¬q)` |
| E24 | 三变量分解 | `p ⇔ (p∧q) ∨ (p∧¬q)` |

### A.2.3 ★ 范式

| 名称 | 定义 | 求法 |
|---|---|---|
| **简单合取式** | 有限个文字（变元或其否定）的**合取** | — |
| **简单析取式** | 有限个文字的**析取** | — |
| **析取范式（DNF）** | 有限个简单合取式的**析取** | 消箭头 → 否定内移 → 用分配律展开 |
| **合取范式（CNF）** | 有限个简单析取式的**合取** | 同上 |
| ★ **极小项 `mᵢ`** | 含**全部** n 个变元的简单合取式 | **变元取 1 记正、取 0 记负** |
| ★ **极大项 `Mᵢ`** | 含**全部** n 个变元的简单析取式 | **变元取 0 记正、取 1 记负**（与极小项相反） |
| ★ **主析取范式** | 所有极小项的析取：`∨ mᵢ`（`A=1` 的行） | 4 步：消箭头 → 否定内移 → 分配展开 → 补全变元 |
| ★ **主合取范式** | 所有极大项的合取：`∧ Mᵢ`（`A=0` 的行） | 同上（或由主析取范式用下标互补转换） |

**★ 关系 `Mᵢ = ¬mᵢ`** ✓
**★ 由主析取范式求主合取范式**：若主析取范式含极小项下标集为 S，则主合取范式的极大项下标集为 **`{0,1,…,2ⁿ−1} − S`** ✓
**★ 求主合取范式时注意**：极大项 `Mᵢ` 对应的是使 `A = 0` 的那一行，且**变元赋值与下标编码相反**（0 记正、1 记负）。

### A.2.4 ★ 推理理论

**推理形式**：`(A₁ ∧ A₂ ∧ … ∧ Aₖ) → B`，若为**重言式**则推理**有效**。

**三种判定方法对比**：

| 方法 | 做法 | 优缺点 |
|---|---|---|
| **真值表法** | 列出所有赋值，检查「前提全真时结论是否必真」 | 直观但**指数爆炸**（`2ⁿ` 行） |
| **主析取范式法** | 化前提合取式为主析取范式，检查是否包含结论的极小项 | 适合变元少的情形 |
| **形式证明法** | 用推理规则逐步推导 | **最实用**，需要技巧 |

**★ 三条推理规则**：

| 规则 | 内容 | 说明 |
|---|---|---|
| **P 规则** | 前提可以随时引入 | 已知前提 |
| **T 规则** | 若前面已推出 `A₁,…,Aₖ`，且 `A₁∧…∧Aₖ → B` 是重言式，则可引入 B | 用等值式/蕴含式变形 |
| **CP 规则** | 若要证 `A → B`，可把 **A 作为附加前提**引入，推出 B 即可 | **化「证明蕴含式」为「证明 B」** |

**★ 12 条常用重言蕴含式（推理定律）**：

| 编号 | 名称 | 形式 |
|---|---|---|
| I₁ | **假言推理** | `p ∧ (p→q) ⟹ q` |
| I₂ | **拒取式** | `¬q ∧ (p→q) ⟹ ¬p` |
| I₃ | **析取三段论** | `¬p ∧ (p∨q) ⟹ q` |
| I₄ | **假言三段论** | `(p→q) ∧ (q→r) ⟹ p→r` |
| I₅ | **构造性二难** | `(p→q) ∧ (r→s) ∧ (p∨r) ⟹ q∨s` |
| I₆ | 化简 | `p ∧ q ⟹ p` |
| I₇ | 附加 | `p ⟹ p ∨ q` |
| I₈ | 合取 | `p ∧ q ⟹ p ∧ q` |
| I₉ | 等价三段论 | `(p↔q) ∧ (q↔r) ⟹ p↔r` |
| I₁₀ | 破坏性二难 | `(p→q) ∧ (r→s) ∧ (¬q∨¬s) ⟹ ¬p∨¬r` |
| I₁₁ | 双否 | `p ⟹ ¬¬p` |
| I₁₂ | 消解/归结 | `(p∨q) ∧ (¬p∨r) ⟹ q∨r` |

## A.3 一阶逻辑（第 03 章）

### A.3.1 基本概念

| 名称 | 内容 |
|---|---|
| **个体常项/变项** | 常项 = 具体对象；变项 = 取值范围为个体域的变量 |
| **个体域** | 变元的取值范围；全总个体域 = 一切事物 |
| **谓词 `P(x₁,…,xₙ)`** | 表示 n 个个体间关系的语句；`P(x)` 含变元时**不是命题** |
| **量词** | `∀x`（全称，对一切）、`∃x`（存在，有一个） |
| **★ 辖域** | 量词后紧跟的公式；判断变元是否被约束的关键 |
| **★ 约束变元** | 出现在量词 `∀x`/`∃x` 的**辖域内**且与量词同名的变元 |
| **★ 自由变元** | 不在任何同名量词辖域内的变元 |
| **闭式** | 无自由变元的公式（闭式是命题） |

**★ 符号化的四条黄金法则**：
1. **全称量词配箭头**：`∀x(F(x) → G(x))`（「所有 F 都是 G」）
2. **存在量词配合取**：`∃x(F(x) ∧ G(x))`（「有些 F 是 G」）
3. **否定意义换量词**：「没有 F 是 G」= `¬∃x(F(x)∧G(x))` = `∀x(F(x)→¬G(x))`
4. **多个量词注意顺序**：`∀x∃y` 与 `∃y∀x` **不恒等**

**★ 换名规则 vs 代替规则**：

| 规则 | 对象 | 做法 | 目的 |
|---|---|---|---|
| **换名规则** | **约束变元** | 把量词辖域内的约束变元**连同对应的量词**一起改名 | 避免同名冲突 |
| **代替规则** | **自由变元** | 把自由变元用另一个个体变元代替（不涉及量词） | 避免同名冲突 |

### A.3.2 ★ 量词等值式（必背）

**（1）量词否定律（量词转换律）**

| 编号 | 公式 |
|---|---|
| **Q1** | **`¬∀xA(x) ⇔ ∃x¬A(x)`**（「不是所有都…」= 「有的不…」） |
| **Q2** | **`¬∃xA(x) ⇔ ∀x¬A(x)`**（「没有…」= 「所有都不…」） |

**（2）辖域收缩与扩张律**

| 编号 | 公式 | 条件 |
|---|---|---|
| Q3 | `∀x(A(x) ∨ B) ⇔ ∀xA(x) ∨ B` | **B 中不含 x** |
| Q4 | `∀x(A(x) ∧ B) ⇔ ∀xA(x) ∧ B` | 同上 |
| Q5 | `∃x(A(x) ∨ B) ⇔ ∃xA(x) ∨ B` | 同上 |
| Q6 | `∃x(A(x) ∧ B) ⇔ ∃xA(x) ∧ B` | 同上 |
| **Q7** | **`∀x(A(x) → B) ⇔ ∃xA(x) → B`** | 同上（**量词翻转！**） |
| **Q8** | **`∀x(B → A(x)) ⇔ B → ∀xA(x)`** | 同上 |
| **Q9** | **`∃x(A(x) → B) ⇔ ∀xA(x) → B`** | 同上（**量词翻转！**） |
| **Q10** | **`∃x(B → A(x)) ⇔ B → ∃xA(x)`** | 同上 |

**（3）量词分配律**

| 编号 | 公式 | 成立？ |
|---|---|---|
| Q11 | `∀x(A(x) ∧ B(x)) ⇔ ∀xA(x) ∧ ∀xB(x)` | ✔ **成立** |
| Q12 | `∃x(A(x) ∨ B(x)) ⇔ ∃xA(x) ∨ ∃xB(x)` | ✔ **成立** |
| Q13 | `∀x(A(x) ∨ B(x)) ⇔ ∀xA(x) ∨ ∀xB(x)` | ✘ **不成立**（只有 `⟸` 方向） |
| Q14 | `∃x(A(x) ∧ B(x)) ⇔ ∃xA(x) ∧ ∃xB(x)` | ✘ **不成立**（只有 `⟹` 方向） |

**★ Q13、Q14 的记忆法**：**`∀` 只对 `∧` 分配，`∃` 只对 `∨` 分配** ✓（「全称配合取、存在配析取」——与符号化法则呼应）
**反例**：个体域为整数，`A(x)` = 「x 是偶数」，`B(x)` = 「x 是奇数」。
`∀x(A(x)∨B(x))` 真，但 `∀xA(x) ∨ ∀xB(x)` 假 ✗

**（4）量词顺序律**

| 编号 | 公式 | 说明 |
|---|---|---|
| Q15 | `∀x∀yA(x,y) ⇔ ∀y∀xA(x,y)` | 同种量词**可交换** ✓ |
| Q16 | `∃x∃yA(x,y) ⇔ ∃y∃xA(x,y)` | 同上 ✓ |
| **Q17** | **`∃y∀xA(x,y) ⟹ ∀x∃yA(x,y)`** | **单向蕴含！**（「有一个 y 对所有 x」⟹「对每个 x 都有某个 y」） |
| Q18 | `∀x∃yA(x,y) ⟹ ∃y∀xA(x,y)` | ✘ **不成立** |

**反例**：个体域为整数，`A(x,y)` = `x + y = 0`。
`∀x∃y(x+y=0)` 真（每个 x 取 y = −x）✓，但 `∃y∀x(x+y=0)` 假（不存在对一切 x 都成立的固定 y）✗

### A.3.3 前束范式

**定义**：形如 **`Q₁x₁Q₂x₂…Qₖxₖ M`** 的公式，其中每个 `Qᵢ` 是 `∀` 或 `∃`，**M 是不含量词的公式**（称为**母式**）。

**★ 求前束范式的四步法**：
```
第 1 步：消去 → 和 ↔
        （A→B ⇔ ¬A∨B；A↔B ⇔ (A→B)∧(B→A)）
第 2 步：否定词内移
        （用德摩根律 + 量词否定律 Q1、Q2，把 ¬ 移到原子公式前）
第 3 步：换名
        （若约束变元与自由变元同名，用换名规则改名）
第 4 步：量词左移
        （用辖域收缩扩张律 Q3–Q10，把所有量词移到公式最前面）
```

**注意**：**前束范式不唯一**（量词顺序可以调整），但**存在性有保证** ✓

### A.3.4 一阶推理的四条规则

| 规则 | 名称 | 形式 | **限制条件** |
|---|---|---|---|
| **US** | 全称指定 | `∀xA(x) ⟹ A(c)` | c 是**任意**个体常项/变元 |
| **UG** | 全称推广 | `A(c) ⟹ ∀xA(x)` | c 必须是**任意**的（不能有特殊假设） |
| **ES** | 存在指定 | `∃xA(x) ⟹ A(c)` | **c 必须是全新的**（此前未出现过的常项） |
| **EG** | 存在推广 | `A(c) ⟹ ∃xA(x)` | 无特殊限制 |

> **★ 最重要的一条**：**ES 规则要求「全新常项」**——不能用一个已经在证明中出现过的常项。
> **★ 使用顺序**：**若有 `∃` 和 `∀` 都要指定，先做 `∃`（ES），后做 `∀`（US）** ✓
> 反例（顺序错会得到错误结论）：由 `∃xP(x)` 和 `∀xQ(x)` 推出 `∃x(P(x)∧Q(x))` 需要「同一个 x」，但先 US 再 ES 会掩盖这一点 ✗

## A.5 二元关系（第 05 章）

### A.5.1 基本定义

| 名称 | 内容 |
|---|---|
| **有序对** | `⟨x,y⟩`；**`⟨x,y⟩ = ⟨u,v⟩ ⟺ x=u ∧ y=v`** |
| **笛卡儿积** | `A × B = {⟨a,b⟩ \| a∈A, b∈B}`；**`\|A×B\| = \|A\|·\|B\|`** |
| **笛卡儿积的性质** | 不满足**交换律**（`A×B ≠ B×A`，除非 A=B 或有一个为 ∅）、不满足**结合律** |
| **二元关系** | `A×B` 的**子集**；A 上的关系是 `A×A` 的子集，**共 `2^(n²)` 个** |
| **定义域/值域/域** | `dom R`（第一元集合）、`ran R`（第二元集合）、`fld R = dom R ∪ ran R` |
| **三种表示法** | 集合、**关系矩阵**（`mᵢⱼ = 1 ⟺ ⟨aᵢ,aⱼ⟩∈R`）、**关系图** |
| **特殊关系** | `∅`（空关系）、`E_A = A×A`（全域关系）、`I_A = {⟨a,a⟩}`（恒等关系） |

### A.5.2 关系的运算

| 运算 | 定义/公式 |
|---|---|
| **逆关系** | `R⁻¹ = {⟨y,x⟩ \| ⟨x,y⟩ ∈ R}` |
| **★ 逆的性质** | **`(R∘S)⁻¹ = S⁻¹ ∘ R⁻¹`**（**顺序颠倒**）；`(R⁻¹)⁻¹ = R`；`(R∪S)⁻¹ = R⁻¹∪S⁻¹` |
| **复合关系** | `R ∘ S = {⟨x,z⟩ \| ∃y(⟨x,y⟩∈R ∧ ⟨y,z⟩∈S)}`（**先 R 后 S**） |
| **复合的算法** | **布尔矩阵乘法**：`M_{R∘S} = M_R ⊙ M_S`（把乘法换成 `∧`、加法换成 `∨`）。**本式与上面的复合顺序约定配套**——本笔记采用屈婉玲约定，`R∘S` 表示**先 R 后 S**，所以矩阵也是 `M_R` 在左、`M_S` 在右，顺序一致 |
| **★ 复合对交只单向** | **`R∘(S∩T) ⊆ (R∘S) ∩ (R∘T)`**（反之不成立！） |
| **复合对并** | `R∘(S∪T) = (R∘S) ∪ (R∘T)` ✓（**可以对并分配**） |
| **幂运算** | `R⁰ = I_A`；`Rⁿ = R∘R∘…∘R`（n 次）；`R^m ∘ R^n = R^(m+n)` |
| **★ 幂的图论意义** | **`⟨x,y⟩ ∈ Rⁿ ⟺ 从 x 到 y 存在长度为 n 的通路`** |

### A.5.3 ★ 关系的五种性质

| 性质 | 定义 | 关系矩阵特征 | 关系图特征 |
|---|---|---|---|
| **自反** | `∀x, ⟨x,x⟩ ∈ R` | **主对角线全为 1** | 每个顶点都有环 |
| **反自反** | `∀x, ⟨x,x⟩ ∉ R` | **主对角线全为 0** | 每个顶点都无环 |
| **对称** | `⟨x,y⟩∈R ⟹ ⟨y,x⟩∈R` | **矩阵对称**（`mᵢⱼ = mⱼᵢ`） | 边成对出现（双向） |
| **反对称** | `⟨x,y⟩∈R ∧ ⟨y,x⟩∈R ⟹ x=y` | 对称位置**不同时为 1**（对角线外） | 无成对双向边 |
| **传递** | `⟨x,y⟩∈R ∧ ⟨y,z⟩∈R ⟹ ⟨x,z⟩∈R` | `M_R² ≤ M_R`（布尔意义） | 无「x→y→z 但缺 x→z」 |

**★ 快速判定流程**：
```
第 1 步：看对角线（自反/反自反）
第 2 步：看对称性（矩阵是否对称/有无双向边）
第 3 步：看传递性（逐个检查 x→y→z 是否缺 x→z）—— 最容易出错，要耐心
```
**★ 常见关系速查表**：

| 关系 | 自反 | 反自反 | 对称 | 反对称 | 传递 |
|---|---|---|---|---|---|
| `∅`（空关系） | ✘ | ✔ | ✔ | ✔ | ✔ |
| `I_A`（恒等） | ✔ | ✘（除非 A=∅） | ✔ | ✔ | ✔ |
| `E_A`（全域） | ✔ | ✘ | ✔ | ✘（若 \|A\|≥2） | ✔ |
| `≤`（实数） | ✔ | ✘ | ✘ | ✔ | ✔ |
| `<`（实数） | ✘ | ✔ | ✘ | ✔ | ✔ |
| **整除 `\|`**（Z⁺） | ✔ | ✘ | ✘ | ✔ | ✔ |
| **「同姓」** | ✔ | ✘ | ✔ | ✘ | ✔ |
| **`⊆`**（幂集） | ✔ | ✘ | ✘ | ✔ | ✔ |
| **`⇔`**（命题） | ✔ | ✘ | ✔ | ✘ | ✔ |
| **同余 `≡ (mod m)`** | ✔ | ✘ | ✔ | ✘ | ✔ |

### A.5.4 ★ 闭包

| 闭包 | 公式 | 矩阵公式 |
|---|---|---|
| **自反闭包** `r(R)` | **`r(R) = R ∪ I_A`** | `M_r = M_R + I` |
| **对称闭包** `s(R)` | **`s(R) = R ∪ R⁻¹`** | `M_s = M_R + M_Rᵀ` |
| **传递闭包** `t(R)` | **`t(R) = R ∪ R² ∪ … ∪ Rⁿ`**（n = \|A\|） | `M_t = M_R + M_R² + … + M_Rⁿ` |

**★ 为什么传递闭包只需到 `Rⁿ`**：若存在长度 > n 的通路，则必有重复顶点，可剪掉中间的环，得到长度 ≤ n−1 的通路 ✓

**★ 沃舍尔算法（Warshall）**：求传递闭包的 `O(n³)` 算法。
```
初始化 A = M_R
for k = 1 to n:
    for i = 1 to n:
        for j = 1 to n:
            A[i][j] = A[i][j] ∨ (A[i][k] ∧ A[k][j])
输出 A = M_t
```
**直观**：`A[i][k] ∧ A[k][j]` 表示「i→k 且 k→j」，即「经过 k 中转可达」✓

**★ 闭包的重要性质**：
- `R` 自反 ⟺ `r(R) = R`；`R` 对称 ⟺ `s(R) = R`；`R` 传递 ⟺ `t(R) = R` ✓
- **`R` 传递 ⟹ `s(R)` 不一定传递** ✗（反例：`A={1,2,3}`，`R={⟨1,2⟩}` 传递，但 `s(R)={⟨1,2⟩,⟨2,1⟩}` 不传递，因缺 `⟨1,1⟩`）
- **`tsr(R) = rts(R) = trs(R)`**（**把 `t` 放在最后时结果唯一**，都等于包含 R 的最小等价关系）✓
- **`str(R)` 一般不相等** ✘（**先传递后对称**会把传递性丢掉，因为 `t(R)` 对称化后一般不再传递）
  - 反例：`A = {1,2,3,4}`、`R = {⟨1,2⟩, ⟨1,3⟩}` 时 `tsr(R)` 有 **10** 个元素（含 `⟨2,3⟩`、`⟨3,2⟩`），`str(R)` 只有 **8** 个（缺这两个）
  - **记忆法：`t` 必须放最后**（先做 `r`、`s`，最后做 `t` 才安全）

### A.5.5 等价关系与划分

| 名称 | 内容 |
|---|---|
| **等价关系** | **自反 + 对称 + 传递** 的关系 |
| **等价类** `[a]_R` | `{x \| ⟨x,a⟩ ∈ R}`（与 a 等价的全体元素） |
| **★ 等价类的三性质** | ① `a ∈ [a]`；② `[a] = [b] ⟺ ⟨a,b⟩ ∈ R`；③ `[a] ∩ [b] = ∅` 或 `[a] = [b]` |
| **商集** `A/R` | 所有等价类构成的集合，**是 A 的一个划分** |
| **划分** | 一族两两不交、并为 A 的非空子集 |
| **★ 定理** | **A 上的等价关系与 A 的划分一一对应** ✓ |
| **贝尔数 `Bₙ`** | n 元集上划分（等价关系）的个数：**`B₀..B₆ = 1, 1, 2, 5, 15, 52, 203`** |
| **相容关系** | **自反 + 对称**（左孝凌版特有） |
| **覆盖** | 一族非空子集，并为 A（**不要求互斥**） |

### A.5.6 偏序关系

| 名称 | 内容 |
|---|---|
| **偏序关系** | **自反 + 反对称 + 传递** |
| **拟序关系** | **反自反 + 传递** |
| **可比/不可比** | `a ≤ b` 或 `b ≤ a` 则可比 |
| **全序（线序）** | 任意两元素都可比 |
| **★ 哈斯图三规则** | ① 省略自环；② 省略传递边；③ 箭头向上，大元素在上 |
| **覆盖** | `a < b` 且中间无第三元素 |

**★ 四组特殊元素对照表**（设 `B ⊆ A`）：

| 名称 | 定义 | 一定在 B 中？ | 一定在 A 中？ |
|---|---|---|---|
| **最大元** | `b ∈ B` 且 `∀x∈B, x ≤ b` | ✔ | ✔（因 b ∈ B ⊆ A） |
| **最小元** | `b ∈ B` 且 `∀x∈B, b ≤ x` | ✔ | ✔ |
| **极大元** | `b ∈ B` 且**不存在** `x∈B` 使 `b < x` | ✔ | ✔ |
| **极小元** | `b ∈ B` 且**不存在** `x∈B` 使 `x < b` | ✔ | ✔ |
| **上界** | `a ∈ A` 且 `∀x∈B, x ≤ a` | ✘ | ✔ |
| **下界** | `a ∈ A` 且 `∀x∈B, a ≤ x` | ✘ | ✔ |
| **上确界** | 上界中**最小**的 | ✘ | ✔ |
| **下确界** | 下界中**最大**的 | ✘ | ✔ |

**★ 关键区别**（注意区分「上界/下界」与「上确界/下确界」，**这是两组不同的概念**）：
- **最大元**：与 B 中**所有**元素可比且最大 ⟹ **存在则唯一**
- **极大元**：没有比它更大的（**可能有多个**）
- **上界/下界**：只需与 B 中元素可比，**可以有多个，不唯一**（例：整除偏序下 `B = {2,3}` 的上界有 6、12、…）
- **上确界/下确界**：分别是上界中**最小**的、下界中**最大**的 ⟹ **存在则唯一**（但**不一定在 B 中**）
- 最大元 ⟹ 是极大元；反之不然
- **上确界若恰好在 B 中，它就是最大元**（这是两套概念的唯一接口）

## A.6 函数（第 06 章）

### A.6.1 基本定义

| 名称 | 内容 |
|---|---|
| **函数** | `f: A → B` 是**单值**且**全域**的二元关系 |
| **函数的个数** | `\|B\|^\|A\|` 个（从 A 到 B 的函数） |
| **恒等函数** | `I_A(a) = a` |
| **常函数** | `f(a) = c`（一切 a 对应同一个 c） |
| **特征函数** | `χ_A(x) = 1`（若 `x ∈ A`），`0`（否则） |
| **取整函数** | `⌊x⌋`（下取整）、`⌈x⌉`（上取整）；**`x − 1 < ⌊x⌋ ≤ x ≤ ⌈x⌉ < x + 1`** |
| **★ 像与原像** | `f(A₁) = {f(a) \| a∈A₁}`（像）；`f⁻¹(B₁) = {a \| f(a)∈B₁}`（完全原像） |

**★ 像与原像的分配性质**：

| 运算 | 像 `f(A₁ ∪ A₂)` 等 | 原像 `f⁻¹(B₁ ∪ B₂)` 等 |
|---|---|---|
| **并** | `f(A₁∪A₂) = f(A₁) ∪ f(A₂)` ✔ | `f⁻¹(B₁∪B₂) = f⁻¹(B₁) ∪ f⁻¹(B₂)` ✔ |
| **交** | **`f(A₁∩A₂) ⊆ f(A₁) ∩ f(A₂)`** ✘（只有单向！单射时取等） | `f⁻¹(B₁∩B₂) = f⁻¹(B₁) ∩ f⁻¹(B₂)` ✔ |
| **差** | 只有单向包含 | `f⁻¹(B₁−B₂) = f⁻¹(B₁) − f⁻¹(B₂)` ✔ |

**★ 记忆**：**「原像对一切运算都友好，像只对并友好」** ✓

### A.6.2 ★ 函数的三种性质

| 性质 | 定义 | 记号 |
|---|---|---|
| **单射**（入射） | `f(a₁) = f(a₂) ⟹ a₁ = a₂` | 一对一 |
| **满射**（到上） | `∀b∈B, ∃a∈A, f(a)=b`，即 `f(A) = B` | 映满 |
| **双射**（一一对应） | 既单射又满射 | 可逆 |

**★ 判定要点**：

| 情形 | 结论 |
|---|---|
| 有限集 `\|A\| = m`，`\|B\| = n` | 单射必要 `m ≤ n`；满射必要 `m ≥ n` |
| 有限集且 `\|A\| = \|B\|` | **单射 ⟺ 满射 ⟺ 双射** ✓ |
| `\|A\| < \|B\|` | **不可能满射** ✗ |
| `\|A\| > \|B\|` | **不可能单射** ✗ |

**★ 复合函数的性质**：

| 命题 | 成立？ |
|---|---|
| `f, g` 单射 ⟹ `g∘f` 单射 | ✔ |
| `f, g` 满射 ⟹ `g∘f` 满射 | ✔ |
| `g∘f` 单射 ⟹ **f 单射** | ✔（**单射往前传**） |
| `g∘f` 满射 ⟹ **g 满射** | ✔（**满射往后传**） |
| `g∘f` 单射 ⟹ g 单射 | ✘ |
| `g∘f` 满射 ⟹ f 满射 | ✘ |

**★ 反函数**：`f⁻¹` 存在 **⟺ f 是双射** ✓
**★ 反函数的复合**：**`(g∘f)⁻¹ = f⁻¹ ∘ g⁻¹`**（**顺序颠倒**）✓

### A.6.3 ★ 基数与可数性

| 名称 | 内容 |
|---|---|
| **等势** `A ~ B` | 存在 A 到 B 的**双射**；等势是**等价关系** |
| **有限集/无限集** | 与某 `{1,…,n}` 等势 / 否则 |
| **Dedekind 定义** | **无限 ⟺ 与自己的某个真子集等势**（该等价在 ZFC 内成立，其中 ⟹ 方向用到选择公理） |
| **可数集** | 与 `N` 等势（`ℵ₀`）；有限集与可数集统称**至多可数集** |
| **★ 可数集的性质** | ① 任何无限集必含可数子集；② 可数集的子集至多可数；③ **可数个可数集的并是可数集**；④ `N×N` 可数；⑤ `Q` 可数 |
| **★ 定理** | **`N×N ~ N`**（蛇形枚举）；**`Q` 可数** |
| **★ 康托尔定理** | **`R` 不可数**（对角线论证）；**`R ~ P(N)`** |
| **★ 康托尔定理（一般）** | **`\|A\| < \|P(A)\|`**（对任何集合 A） |
| **康托尔-伯恩斯坦定理** | 若 `\|A\| ≤ \|B\|` 且 `\|B\| ≤ \|A\|`，则 `\|A\| = \|B\|` |
| **基数记号** | `ℵ₀ = \|N\|`（可数）、`c = \|R\|`（连续统）、`ℵ₁`（最小的不可数基数） |
| **连续统假设（CH）** | `ℵ₁ = c`？——**哥德尔与科恩证明它在 ZFC 中不可判定** |

## A.7 图（第 07 章）

### A.7.1 基本概念与握手定理

| 名称 | 内容 |
|---|---|
| **图的分类** | 无向/有向；简单图（无环无平行边）/多重图；有限/无限 |
| **度 `d(v)`** | 与 v 关联的边数；**环贡献 2 度** |
| **Δ / δ** | 最大度 / 最小度 |
| **★ 握手定理** | **`Σ_{v∈V} d(v) = 2m`**（m 是边数） |
| **★ 推论** | **奇度顶点的个数必为偶数** |
| **★ 有向图** | **`Σd⁺(v) = Σd⁻(v) = m`** |

**★ 五大图族**：

| 图族 | 记号 | 顶点数 | 边数 | 度 |
|---|---|---|---|---|
| **完全图** | `Kₙ` | n | **`n(n−1)/2`** | 每点 `n−1` |
| **圈图** | `Cₙ` | n | n | 每点 2 |
| **轮图** | `Wₙ` | n | `2(n−1)` | 中心 `n−1`，其余 3 |
| **方体图** | `Qₙ` | `2ⁿ` | `n·2^(n−1)` | 每点 n |
| **彼得森图** | — | 10 | 15 | 每点 3 |

**★ 图的同构的必要条件**（**都不充分**）：顶点数相同、边数相同、度序列相同、连通性相同、回路结构相同 ✓

### A.7.2 通路与回路

| 名称 | 定义 |
|---|---|
| **通路** | 顶点与边的交替序列 |
| **简单通路（迹）** | **边不重复** |
| **初级通路（路径）** | **顶点不重复** ⟹ 边也不重复 |
| **回路** | **起点 = 终点**的通路 |
| **简单回路（圈）** | 边不重复的回路 |
| **初级回路** | 除起点终点外**顶点不重复**的回路 |

**★ 重要结论**：
- **从 u 到 v 有通路 ⟹ 存在初级通路**（剪掉中间的环）✓
- **初级通路的长度 ≤ n − 1** ✓
- **n 阶连通图至少有 `n − 1` 条边** ✓（等号成立 ⟺ 是树）

### A.7.3 连通性与连通度

| 名称 | 内容 |
|---|---|
| **连通分支** `p(G)` | 极大连通子图的个数 |
| **连通图** | `p(G) = 1` |
| **★ 有向图三层次** | **强连通 ⟹ 单向连通 ⟹ 弱连通**（反之均不成立） |
| **点割集/割点** | 删去后连通分支增多的顶点集/单个顶点 |
| **边割集/桥** | 删去后连通分支增多的边集/单条边 |
| **点连通度 `κ(G)`** | 使 G 不连通需删去的最少顶点数 |
| **边连通度 `λ(G)`** | 使 G 不连通需删去的最少边数 |
| **★ Whitney 不等式** | **`κ(G) ≤ λ(G) ≤ δ(G)`** |

### A.7.4 矩阵表示

| 矩阵 | 定义 | 性质 |
|---|---|---|
| **无向图关联矩阵** `M(G)` | `mᵢⱼ = 1` 若 `vᵢ` 关联 `eⱼ`（环记 2） | **每列和为 2** |
| **有向图关联矩阵** | `1`（起点）、`−1`（终点）、`0` | **每列恰一 1 一 −1，列和为 0** |
| **邻接矩阵** `A(G)` | `aᵢⱼ` = 从 `vᵢ` 到 `vⱼ` 的边数 | 无向图**对称** |
| **★ 定理 7.4** | **`(A^k)ᵢⱼ` = 从 `vᵢ` 到 `vⱼ` 长度为 k 的通路条数** | 证明用归纳法 |
| **可达矩阵** `P(G)` | `pᵢⱼ = 1` 若 `vᵢ` 可达 `vⱼ` | `P = A ∨ A² ∨ … ∨ Aⁿ`（布尔） |

**★ 用途**：
- 判连通：`A + A² + … + A^(n−1)` 无零元素 ⟹ 连通
- 判强连通：可达矩阵全 1 ⟹ 强连通
- 求强连通分支：可达矩阵的等价类

### A.7.5 二部图与欧拉图

| 名称 | 判定 |
|---|---|
| **二部图** | 顶点可分成两个不交部，同部内无边 |
| **★ 二部图判定** | **二部图 ⟺ 不含奇长度回路** ✓（黑白染色法） |
| **完全二部图 `K_{r,s}`** | `\|E\| = rs`，`\|V\| = r + s` |
| **★ 欧拉回路**（无向） | **连通 + 所有顶点度数为偶数** |
| **★ 欧拉通路**（无向） | **连通 + 恰有 2 个奇度顶点**（起点终点是这两个） |
| **★ 欧拉回路**（有向） | **弱连通 + 每点入度 = 出度** |
| **★ 欧拉通路**（有向） | **弱连通 + 恰一点 `d⁺ = d⁻+1`（起点）、一点 `d⁻ = d⁺+1`（终点）** |

> **欧拉图口诀**：**「看边——一笔画，度数是关键」** ✓

### A.7.6 ★ 哈密顿图

| 名称 | 内容 |
|---|---|
| **哈密顿通路/回路** | 经过**每个顶点恰好一次**的通路/回路 |
| **★ 必要条件** | **`p(G − S) ≤ \|S\|`**（对任意 `S ⊆ V`） |
| **推论（割点）** | **哈密顿图无割点**（取 `\|S\|=1`：`p(G−v) ≤ 1`） |
| **★ 狄拉克定理（充分）** | `n ≥ 3` 且 **`δ(G) ≥ n/2`** ⟹ 哈密顿图 |
| **★ 奥尔定理（充分）** | `n ≥ 3` 且对任意**不相邻**的 u,v 有 **`d(u)+d(v) ≥ n`** ⟹ 哈密顿图 |
| **闭包定理** | 反复连接度和 ≥ n 的不相邻点对，得闭包；**G 有哈密顿回路 ⟺ 其闭包有** |
| **货郎问题（TSP）** | 求最小权哈密顿回路——**NP 完全** |

> **哈密顿图口诀**：**「看点——走遍每个城市一次，至今无好判定（NP 完全）」** ✓
> **注意**：狄拉克/奥尔定理只是**充分条件**——`Cₙ`（`n ≥ 5`）满足 `δ = 2 < n/2` 但仍是哈密顿图 ✓

### A.7.7 ★ 平面图

| 名称 | 内容 |
|---|---|
| **平面图** | 能画在平面上使**边仅在顶点处相交** |
| **面 / 面的次数** | 区域 / 围成该面的边数；**桥算两次** |
| **★ 欧拉公式** | **`n − m + r = 2`**（连通平面图，r 含外部面） |
| **★ 推广** | `n − m + r = p + 1`（p 个连通分支） |
| **★ 推论 1** | **`m ≤ 3n − 6`**（`n ≥ 3`，每个面次数 ≥ 3） |
| **★ 推论 2** | **`m ≤ 2n − 4`**（**无三角形**时，每个面次数 ≥ 4） |
| **库拉托夫斯基定理** | **平面图 ⟺ 不含与 `K₅` 或 `K_{3,3}` 同胚的子图** |

**★ 必背的两个非平面图证明**：

| 图 | `n` | `m` | 用哪个不等式 | 判定 |
|---|---|---|---|---|
| **`K₅`** | 5 | 10 | `m ≤ 3n−6 = 9` | `10 > 9` ⟹ **非平面** ✓ |
| **`K_{3,3}`** | 6 | 9 | **`m ≤ 2n−4 = 8`**（因无三角形） | `9 > 8` ⟹ **非平面** ✓ |

> **★ 易错**：`K_{3,3}` **不能**用 `3n−6`（得 9 ≤ 12，判不出来）——**必须用 `2n−4`** ✓

### A.7.8 图的着色

| 名称 | 内容 |
|---|---|
| **点着色 / 色数 `χ(G)`** | 相邻顶点不同色所需最少颜色数 |
| **★ 常见图的色数** | `χ(Kₙ)=n`；`χ(二部图)=2`；`χ(偶圈)=2`；**`χ(奇圈)=3`**；`χ(树)=2`（n≥2）；**`χ(奇轮图 Wₙ)=4`、偶轮图 = 3**；`χ(Qₙ)=2` |
| **★ 四色定理** | **任何平面图都可用 4 种颜色着色**（1976 年 Appel-Haken 计算机证明） |
| **五色定理** | 任何平面图 ≤ 5 色（易证） |
| **贪心上界** | `χ(G) ≤ Δ(G) + 1` |
| **布鲁克斯定理** | 连通图（非完全图、非奇圈）有 `χ(G) ≤ Δ(G)` |
| **韦尔奇-鲍威尔算法** | 按度数降序排列 → 依次给每个顶点着最小可用色（**贪心，不保证最优**） |
| **维辛定理（边着色）** | `Δ ≤ χ'(G) ≤ Δ + 1` |

### A.7.9 ★ 最短路径与关键路径

| 算法 | 适用 | 复杂度 | 关键公式 |
|---|---|---|---|
| **Dijkstra** | **非负权**单源最短路 | `O(n²)` | 每次选未确定点中距离最小者，**松弛**邻边。**不能处理负权！** |
| **Floyd** | 任意权（无负环）多源最短路 | `O(n³)` | **`D^k[i][j] = min(D^{k−1}[i][j], D^{k−1}[i][k] + D^{k−1}[k][j])`** |
| **Bellman-Ford** | **可处理负权**单源最短路 | `O(nm)` | 松弛 n−1 轮 |

**★ 关键路径（AOE 网）**：
| 参数 | 含义 | 计算 |
|---|---|---|
| `ve(j)` | 事件 j 的**最早**发生时间 | **正推**：`ve(j) = max{ve(i) + w(i,j)}` |
| `vl(j)` | 事件 j 的**最迟**发生时间 | **倒推**：`vl(i) = min{vl(j) − w(i,j)}`；`vl(汇点) = ve(汇点)` |
| `e(a)` | 活动 a 的**最早**开始时间 | `e(a) = ve(起点)` |
| `l(a)` | 活动 a 的**最迟**开始时间 | `l(a) = vl(终点) − w(a)` |
| **机动时间** | `l(a) − e(a)` | **= 0 的活动是关键活动**，它们构成**关键路径** |

**★ 口诀**：**「正推 ve 取 max，倒推 vl 取 min，e = ve(前)，l = vl(后) − w，机动为 0 是关键」** ✓

**★ 三类「走遍」问题对比**：
| 问题 | 走遍什么 | 方法 | 复杂度 |
|---|---|---|---|
| 最短路 | 只走一条路（s 到 t） | Dijkstra / Floyd / Bellman-Ford | 多项式 |
| **中国邮递员** | **走遍所有边**（回起点） | 欧拉图直接走；非欧拉图在奇度点间加重复边 | 多项式 |
| **货郎担（TSP）** | **走遍所有点**（各一次，回起点） | 最小权哈密顿回路 | **NP 难** |

> **一句话**：**邮递员走遍边，货郎担走遍点。**

### A.7.10 ★ 匹配、独立集、覆盖集与支配集

**★ 六个概念对照表**：
| 概念 | 挑的是 | 约束 | 记号 |
|---|---|---|---|
| **匹配** | 边集 | 任意两边**不共端点** | 最大匹配数 `α'(G)` |
| **边独立集** | 边集 | 同上（**与匹配是同一个概念**） | `α'(G)` |
| **点独立集** | 点集 | 任意两点**不相邻** | 独立数 `α(G)` |
| **点覆盖集** | 点集 | **每条边**至少一端在里面 | 点覆盖数 `β(G)` |
| **边覆盖集** | 边集 | **每个顶点**至少是一条边的端点 | 边覆盖数 `β'(G)` |
| **支配集** | 点集 | 每个外面的点都与里面某点相邻 | 支配数 `γ(G)` |

**★ 核心定理表**：
| 定理 | 内容 | 适用范围 |
|---|---|---|
| **霍尔定理（婚配定理）** | 存在**饱和 `V₁`** 的匹配 ⟺ 对**任意** `S ⊆ V₁` 有 **`\|N(S)\| ≥ \|S\|`** | 二部图 |
| **贝尔热定理** | **`M` 是最大匹配 ⟺ 不存在 `M`-增广路** | 任何图 |
| **柯尼希定理** | **最大匹配数 = 最小点覆盖数**，即 `α'(G) = β(G)` | **只对二部图** |
| **托特定理**〔了解〕 | 有**完美匹配** ⟺ 对任意 `S ⊆ V` 有 `o(G−S) ≤ \|S\|`（`o` = 奇阶分支个数） | 任何图 |
| **互补关系** | **`α(G) + β(G) = \|V(G)\|`**（最大独立集与最小点覆盖互为补集） | 任何图 |
| **加莱恒等式** | `α'(G) + β'(G) = \|V(G)\|`（最大匹配 + 最小边覆盖 = 点数） | **需无孤立点** |

> **非二部图的反例**：`K₃` 中 `α' = 1` 而 `β = 2`，1 ≠ 2。一般图只有单向不等式 **`α'(G) ≤ β(G)`**。

**★ 匈牙利算法四步（求二部图最大匹配）**：
1. `M ← ∅`。
2. 取 `V₁` 中一个**未饱和点** x 作起点，做**交替路**搜索：从 `V₁` 的点出发走**非匹配边**，从 `V₂` 的点出发走**匹配边**。
3. 若走到一个**未饱和的 `V₂` 点** ⟹ 找到**增广路**，**沿路取反**（匹配边 ↔ 非匹配边），匹配数 +1，回到第 2 步。
4. 若搜索穷尽仍无增广路 ⟹ 由**贝尔热定理**，`M` 已是最大匹配，结束。

**★ 由最大匹配构造最小点覆盖（柯尼希定理的证明性构造）**：
1. 求出最大匹配 `M`；
2. 令 `U` = `V₁` 中所有**未饱和点**；
3. 令 `Z` = 从 `U` 出发、沿 `M`-交替路能到达的**所有顶点**；
4. **最小点覆盖 `K = (V₁ − Z) ∪ (V₂ ∩ Z)`**。

> **记忆**：**同侧取补集，异侧取交集**（`V₁` 那边减，`V₂` 那边交）。

**★ 常见图的四个数速查**（`n ≥ 3`，`m, n ≥ 1`）：
| 图 | `\|V\|` | `α'`（最大匹配） | `α`（独立数） | `β`（点覆盖） | `γ`（支配数） |
|---|---|---|---|---|---|
| 完全图 `Kₙ` | n | `⌊n/2⌋` | 1 | `n−1` | 1 |
| 圈图 `Cₙ` | n | `⌊n/2⌋` | `⌊n/2⌋` | `⌈n/2⌉` | `⌈n/3⌉` |
| 路径 `Pₙ` | n | `⌊n/2⌋` | `⌈n/2⌉` | `⌊n/2⌋` | `⌈n/3⌉` |
| 完全二部图 `K_{m,n}` | `m+n` | `min(m,n)` | `max(m,n)` | `min(m,n)` | 2 |
| 星图 `K_{1,n}` | `n+1` | 1 | n | 1 | 1 |

**★ 一句话区分**：**匹配管边不打架，独立管点不挨着，覆盖管边全踩住，支配管点全够到。**

## A.8 树及其应用（第 08 章）

### A.8.1 ★ 树的六个等价刻画

设 G 是 n 阶无向图，则以下命题**互相等价**：

| 编号 | 刻画 |
|---|---|
| T1 | **G 连通且无回路**（定义） |
| T2 | **G 无回路且 `m = n − 1`** |
| T3 | **G 连通且 `m = n − 1`** |
| T4 | **G 中任意两点间有唯一通路** |
| T5 | **G 连通且每条边都是桥** |
| T6 | **G 无回路，且添加任一条新边恰好产生唯一一个回路** |

**★ 其他性质**：
- **树至少有两个叶子**（`n ≥ 2`）✓
- 树是「**边数最少的连通图**」和「**边数最多的无回路图**」✓
- `n` 阶树有 `n − 1` 条边，`n − 1` 条边的连通图必是树 ✓

### A.8.2 生成树

| 名称 | 内容 |
|---|---|
| **生成树** | 连通图的极小连通生成子图（含全部 n 个顶点） |
| **★ 定理** | **任何连通图都有生成树** ✓（破圈法） |
| **树枝 / 弦** | 生成树中的边（**n−1 条**）/ 其余边（**m − n + 1 条**） |
| **基本回路** | 每条弦 + 树枝唯一确定的回路，共 **`m − n + 1`** 个 |
| **基本割集** | 每条树枝唯一确定的割集，共 **`n − 1`** 个 |
| **★ 凯莱公式** | **n 个顶点的标号树的数目 = `n^(n−2)`** ✓ |

### A.8.3 ★ 最小生成树（MST）

| 算法 | 类型 | 做法 | 适合 | 复杂度 |
|---|---|---|---|---|
| **Prim** | **加点法** | 从任一顶点开始，每次选**连接已在树中顶点与外部顶点**的最小权边 | **稠密图** | `O(n²)` |
| **Kruskal** | **加边法** | 按权从小到大排序，每次选**不成回路**的最小权边（**并查集判回路**） | **稀疏图** | `O(m log m)` |
| **破圈法** | 删边法 | 每次找到一个回路，**删去回路中权最大**的边 | 手工计算 | — |

**★ 口诀**：**「Prim 加点看顶点（稠密用），Kruskal 加边看排序（稀疏用），破圈删最大」** ✓

### A.8.4 根树与二叉树

| 名称 | 内容 |
|---|---|
| **根树** | 有向树：**恰有一个入度为 0 的顶点（根）**，其余顶点入度为 1 |
| **层数 / 树高** | 根层数为 0（或 1）；树高 = 最大层数 |
| **m 元树** | 每个顶点**至多** m 个儿子 |
| **完全 m 元树** | 每个内点**恰有** m 个儿子（正则 m 元树） |
| **★ 定理（正则 m 元树）** | **`t = (m − 1)i + 1`**（t = 叶数，i = 内点数） |
| **★ 二叉树推论** | **`t = i + 1`**（即 `i = t − 1`） |
| **★ 叶数上界** | **`t ≤ m^h`**（h 是树高） |
| **★ 树高下界** | **`h ≥ ⌈log_m t⌉`** |

### A.8.5 ★ 最优二叉树（哈夫曼树）

| 名称 | 内容 |
|---|---|
| **带权路径长度 WPL** | **`WPL = Σ wᵢ · l(wᵢ)`**（`l(wᵢ)` 是**从根到该叶经过的边数**） |
| **★ 哈夫曼算法** | ① 把所有叶子按权排序；② **取权最小的两棵树合并**，新根权 = 两者之和；③ 重复直到只剩一棵树 |
| **★ 速算 WPL** | **`WPL = 所有内点的权之和`** ✓（两法互验，考试利器） |
| **★ 码长铁律** | **码长 = 从根到该叶所经过的边数**（**不是节点数！**） |

### A.8.6 ★ 前缀码

| 名称 | 内容 |
|---|---|
| **前缀** | `x` 是 `y` 的前缀（`y = xz`） |
| **前缀码** | 任何码字都**不是**另一个码字的前缀 ✓（**可即时译码**） |
| **反例** | `{0, 01, 11}` **不是**前缀码（`0` 是 `01` 的前缀）✗ |
| **★ 定理** | **二叉树的叶子集合 ⟺ 二元前缀码**（左 0 右 1） |
| **★ 最佳前缀码** | **用哈夫曼树生成的码**（平均码长最短） |
| **效率计算** | 平均码长 = `WPL / Σwᵢ`；与定长码 `⌈log₂n⌉` 位对比 |

### A.8.7 二叉树的遍历

| 遍历 | 顺序 | 助记 | 与表达式 |
|---|---|---|---|
| **先序** | 根 → 左 → 右 | 根在**最前** | **前缀表达式（波兰式）** |
| **中序** | 左 → 根 → 右 | 根在**中间** | 中缀表达式 |
| **后序** | 左 → 右 → 根 | 根在**最后** | **后缀表达式（逆波兰式）** |

**★ 还原二叉树**：
- **先序 + 中序** ⟹ **唯一确定** ✓（先序找根，中序分左右，递归）
- **后序 + 中序** ⟹ **唯一确定** ✓
- **先序 + 后序** ⟹ **不能唯一确定** ✗（无法区分只有一个儿子时的左右）

### A.10.2 ★ 递推方程

**常系数线性齐次递推 `aₙ = c₁a_{n−1} + c₂a_{n−2} + … + cₖa_{n−k}` 的三步法**：
```
第 1 步：写出特征方程 x^k = c₁x^(k−1) + … + cₖ（即 x^k − c₁x^(k−1) − … − cₖ = 0），求根
第 2 步：按根的情形写通解
第 3 步：代入初始条件，解出常数
```

**★ 特征根与通解形式的对应**：

| 根的情形 | 通解中对应的项 |
|---|---|
| **单实根** `r` | `A · rⁿ` |
| **k 重实根** `r` | `(A₀ + A₁n + … + A_{k−1}n^(k−1)) · rⁿ` |
| **共轭复根** `α ± βi` | `rⁿ(C₁cos nθ + C₂ sin nθ)`，`r = √(α²+β²)`，`θ = arctan(β/α)` |

**★ 非齐次递推 `aₙ = c₁a_{n−1} + … + f(n)`**：
**通解 = 齐次通解 + 一个特解** ✓
**特解形式表（待定系数法）**：

| `f(n)` 的形式 | 特解设法 | 说明 |
|---|---|---|
| `P(n)`（m 次多项式） | `n^s · Q(n)`（Q 是 m 次多项式） | **s = 1 在特征根中的重数**（不是根则 s=0） |
| `c · βⁿ` | `n^s · A · βⁿ` | **s = β 在特征根中的重数**（不是根则 s=0） |

**★ 口诀**：**「不是根照抄，是根乘 n，m 重根乘 n^m」** ✓
**★ 撞车信号**：若忘记乘 `n^s`，代入后会得到 `0 = 非零` 之类的**矛盾式** ⟹ 说明撞上了特征根，必须乘 n ✓

**★ 常见算法复杂度递推**：

| 递推 | 复杂度 | 典型算法 |
|---|---|---|
| `T(n) = T(n−1) + c` | `Θ(n)` | 线性扫描 |
| `T(n) = T(n−1) + n` | `Θ(n²)` | 插入排序（最坏） |
| **`T(n) = 2T(n/2) + n`** | **`Θ(n log n)`** | **归并排序、随机快排（平均）** |
| `T(n) = T(n/2) + 1` | `Θ(log n)` | 二分查找 |
| `T(n) = 2T(n−1) + 1` | `Θ(2ⁿ)` | 汉诺塔 |

## A.11 初等数论（第 11 章）

### A.11.1 整除与带余除法

| 名称 | 内容 |
|---|---|
| **整除** `a \| b` | 存在 q 使 `b = aq` |
| **★ 整除性质** | 传递；`a\|b ∧ a\|c ⟹ a\|(b±c)`；**`a\|b ∧ a\|c ⟹ a\|(mb+nc)`（线性组合）**；`a\|b ∧ b\|a ⟹ a = ±b`；`a\|b ⟹ \|a\| ≤ \|b\|`（`b≠0`） |
| **★ 带余除法** | **`a = bq + r`，`0 ≤ r < b`，且 q, r 唯一**；**余数必须非负！** |
| **算术基本定理** | 任何 `n > 1` 唯一分解为素数之积 |
| **素数无穷多** | 欧几里得反证法（构造 `N = p₁…pₙ + 1`） |
| **★ 素性试除** | 若 n 是合数，则 n 有不超过 **`√n`** 的素因数 |

### A.11.2 ★ 最大公因数与欧几里得算法

| 名称 | 内容 |
|---|---|
| **gcd** | 最大公因数；`gcd(a,b) = p₁^min(α,β) …` |
| **lcm** | 最小公倍数；`lcm(a,b) = p₁^max(α,β) …` |
| **★ 重要关系** | **`gcd(a,b) · lcm(a,b) = a · b`**（**只对两个数成立！**） |
| **★ 引理** | **`gcd(a,b) = gcd(b, r)`**（其中 `a = bq + r`） |
| **★ 欧几里得算法** | 反复做带余除法，**最后一个非零余数即为 gcd** |
| **复杂度** | `O(log min(a,b))` |

**★ 贝祖等式（扩展欧几里得）**：
**`sa + tb = gcd(a, b)`**（s, t 是整数）
**求法（回代法）**：从欧几里得算法的**倒数第二步**开始，逐层把余数代回去 ✓
**★ 关键应用**：`gcd(a, m) = 1` 时，**`a` 模 m 的逆元 `a⁻¹ ≡ s (mod m)`** ✓

### A.11.3 ★ 同余

| 名称 | 内容 |
|---|---|
| **同余** | `a ≡ b (mod m) ⟺ m \| (a − b) ⟺ a, b 除以 m 的余数相同` |
| **★ 同余性质** | 可加、可减、可乘、**可乘方**、多项式代入 |
| **★ 陷阱** | **两边不能随便约！** `ac ≡ bc (mod m)` 且 **`gcd(c,m)=1`** 才能得 `a ≡ b (mod m)` |
| **正确的约法** | `ac ≡ bc (mod m) ⟹ a ≡ b (mod m/gcd(c,m))` |
| **同余类** `[a]_m` | 模 m 的同余类**恰好有 m 个** |
| **完全剩余系** | 从每个同余类取一个数 |
| **简化剩余系** | 从每个与 m 互素的同余类取一个数，共 `φ(m)` 个 |

**★ 一次同余方程 `ax ≡ b (mod m)`**：设 `d = gcd(a, m)`
- **`d ∤ b` ⟹ 无解** ✗
- **`d \| b` ⟹ 恰有 `d` 个解**（模 m 下）✓

**★ 求解三步法**：
```
第 1 步：两边除以 d，模也除以 d：  (a/d)x ≡ (b/d) (mod m/d)
第 2 步：用扩展欧几里得算法求 (a/d) 模 (m/d) 的逆元
第 3 步：解出 x ≡ (b/d)·(a/d)⁻¹ (mod m/d)，再展开成模 m 的 d 个解
       x₀, x₀ + m/d, x₀ + 2m/d, …, x₀ + (d−1)m/d
```

**★ 中国剩余定理（孙子定理 / CRT）**：
若 `m₁, …, mₖ` **两两互素**，则
```
x ≡ a₁ (mod m₁),  …,  x ≡ aₖ (mod mₖ)
```
在模 **`M = m₁m₂…mₖ`** 下有**唯一解**：**`x ≡ Σ aᵢ Mᵢ yᵢ (mod M)`**
其中 **`Mᵢ = M/mᵢ`**，**`yᵢ` 是 `Mᵢ` 模 `mᵢ` 的逆元** ✓

**★ 求解四步**：
```
第 1 步：M = m₁m₂…mₖ
第 2 步：Mᵢ = M/mᵢ
第 3 步：求 Mᵢ·yᵢ ≡ 1 (mod mᵢ) 中的 yᵢ
第 4 步：x ≡ Σ aᵢMᵢyᵢ (mod M)
```

### A.11.4 ★ 欧拉定理与费马小定理

| 名称 | 内容 |
|---|---|
| **★ 欧拉函数** | **`φ(n) = n(1 − 1/p₁)(1 − 1/p₂)…(1 − 1/pₖ)`**（`pᵢ` 是 n 的**互不相同的素因子**） |
| **特例** | `φ(1) = 1`；**`φ(p) = p − 1`**（p 素数）；`φ(p^k) = p^(k−1)(p−1)` |
| **积性** | `gcd(m,n) = 1 ⟹ φ(mn) = φ(m)φ(n)` |
| **★ 欧拉定理** | `gcd(a, m) = 1 ⟹` **`a^(φ(m)) ≡ 1 (mod m)`** |
| **★ 费马小定理** | p 素数，`gcd(a,p)=1 ⟹` **`a^(p−1) ≡ 1 (mod p)`** |
| **费马小定理（一般形式）** | 对任意整数 a、素数 p：**`a^p ≡ a (mod p)`** |

**★ 求大数幂余数的步骤**：
```
第 1 步：确定模数 m 的「循环长度」= φ(m)（m 素数时为 p−1）
第 2 步：把指数对 φ(m) 取模：n = q·φ(m) + r
第 3 步：a^n ≡ a^r (mod m)
第 4 步：用「平方-乘」法快速计算 a^r mod m
```

**★ 费马素性检验**：若存在 a 使 **`a^(n−1) ≢ 1 (mod n)`**，则 **n 一定不是素数** ✓
（**逆命题不成立**：**卡迈克尔数**如 561 = 3×11×17 会骗过检验。）

### A.11.5 RSA 算法

| 步骤 | 内容 |
|---|---|
| **① 密钥生成** | 选大素数 p, q → **`n = pq`** → **`φ(n) = (p−1)(q−1)`** → 选 e 使 `gcd(e, φ(n)) = 1`（常取 65537）→ 求 **`d` 使 `ed ≡ 1 (mod φ(n))`** |
| **② 公钥 / 私钥** | **公钥 `(n, e)`；私钥 `(n, d)`**（p, q, φ(n) 必须销毁） |
| **③ 加密** | **`C = M^e mod n`** |
| **④ 解密** | **`M = C^d mod n`** |
| **⑤ 正确性** | 由 `ed = 1 + kφ(n)`，用**费马小定理**分情形证 `M^(ed) ≡ M (mod p)` 和 `(mod q)`，再由 p, q 互素得 `mod n` ✓ |
| **⑥ 安全性** | 基于**大整数分解的困难性**——知道 `(n,e)` 求 d 需要分解 n |

## A.12 离散概率（第 12 章）

### A.12.1 概率的基本性质

| 名称 | 公式 |
|---|---|
| **概率三公理** | ① `P(A) ≥ 0`；② `P(Ω) = 1`；③ 互斥时可加 |
| **★ 互补公式** | **`P(～A) = 1 − P(A)`** |
| **★ 加法公式** | **`P(A ∪ B) = P(A) + P(B) − P(A ∩ B)`** |
| **三事件加法** | `P(A∪B∪C) = ΣP − ΣP(两两交) + P(ABC)`（**奇加偶减**） |
| **差事件** | `P(A − B) = P(A) − P(A ∩ B)` |
| **单调性** | `A ⊆ B ⟹ P(A) ≤ P(B)` |
| **★ 古典概型** | **`P(A) = \|A\| / \|Ω\|`**（有限 + 等可能） |
| **★ 条件概率** | **`P(B\|A) = P(A∩B) / P(A)`**（`P(A) > 0`） |
| **★ 乘法公式** | **`P(A∩B) = P(A)·P(B\|A) = P(B)·P(A\|B)`** |
| **★ 独立性** | **`P(A∩B) = P(A)·P(B)`**（等价于 `P(B\|A) = P(B)`） |
| **伯努利概型** | `P(n 次中恰 k 次成功) = C(n,k) p^k q^(n−k)` |

**★ 互斥 vs 独立（最重要的辨析）**：

| | 互斥 | 独立 |
|---|---|---|
| **定义** | `A ∩ B = ∅` | `P(A∩B) = P(A)P(B)` |
| **含义** | 不能同时发生 | 一个发生不影响另一个 |
| **关系** | 若 `P(A),P(B) > 0`，**二者不可能同时成立** | — |

**★ 全概率公式与贝叶斯公式**：
| 公式 | 内容 | 方向 |
|---|---|---|
| **★ 全概率公式** | **`P(A) = Σ_{i} P(A\|Bᵢ) P(Bᵢ)`**（`Bᵢ` 是完备事件组） | **由因推果** |
| **★ 贝叶斯公式** | **`P(Bᵢ\|A) = P(A\|Bᵢ)P(Bᵢ) / Σ_{j} P(A\|Bⱼ)P(Bⱼ)`** | **由果溯因** |

**★ 使用要点**：
- 全概率公式**分母（`P(A)`）用全概率算**，别忘！
- 贝叶斯：`先验概率 P(Bᵢ)` × `似然 P(A|Bᵢ)` = `后验概率 P(Bᵢ|A)` × `P(A)`
- **验证方法：所有后验概率之和应为 1** ✓

### A.12.2 ★ 随机变量的数字特征

| 名称 | 公式 |
|---|---|
| **★ 数学期望** | **`E(X) = Σ xᵢ pᵢ`**（加权平均，物理意义 = 质心） |
| **★ 期望的线性性** | `E(c) = c`；`E(cX) = cE(X)`；**`E(X+Y) = E(X)+E(Y)`（无需独立！）** |
| **期望的乘法** | **独立时** `E(XY) = E(X)E(Y)` |
| **★ 方差** | **`D(X) = E[(X−E(X))²] = E(X²) − [E(X)]²`**（**后者更常用**） |
| **方差的性质** | `D(c) = 0`；**`D(cX) = c²D(X)`**（**常数要平方**）；`D(X+c) = D(X)`；**独立时 `D(X+Y) = D(X)+D(Y)`** |

### A.12.3 ★ 常用离散分布表

| 分布 | 记号 | `P(X=k)` | `E(X)` | `D(X)` | 典型场景 |
|---|---|---|---|---|---|
| **0-1 分布** | `B(1,p)` | `p^k(1−p)^(1−k)` | `p` | `p(1−p)` | 一次试验 |
| **★ 二项分布** | **`B(n,p)`** | **`C(n,k)p^k(1−p)^(n−k)`** | **`np`** | **`np(1−p)`** | n 次中的成功次数 |
| **★ 几何分布** | **`G(p)`** | **`(1−p)^(k−1)p`** | **`1/p`** | `(1−p)/p²` | **首次成功所需次数** |
| **★ 泊松分布** | **`P(λ)`** | **`λ^k e^(−λ)/k!`** | **`λ`** | **`λ`** | 稀有事件计数 |
| **超几何分布** | `H(N,M,n)` | `C(M,k)C(N−M,n−k)/C(N,n)` | `nM/N` | — | 不放回抽样的次品数 |
| **均匀分布** | — | `1/n` | `(n+1)/2` | `(n²−1)/12` | 骰子 |

**★ 泊松近似**：`n` 大 `p` 小时，**`B(n,p) ≈ P(np)`** ✓

### A.12.4 不等式

| 名称 | 内容 |
|---|---|
| **马尔可夫不等式** | `P(X ≥ a) ≤ E(X)/a`（X 非负） |
| **切比雪夫不等式** | **`P(\|X − E(X)\| ≥ ε) ≤ D(X)/ε²`** |

## A.13 代数系统（第 13 章）

### A.13.1 运算的性质与特殊元素

| 名称 | 定义 |
|---|---|
| **封闭性** | `a, b ∈ S ⟹ a * b ∈ S`（二元运算的第一要求） |
| **交换律** | `a * b = b * a`（运算表关于主对角线对称） |
| **结合律** | `(a*b)*c = a*(b*c)` |
| **幂等律** | `a * a = a` |
| **分配律** | `a*(b∘c) = (a*b)∘(a*c)` |
| **吸收律** | `a*(a∘b) = a` |
| **★ 单位元 `e`** | **`e * a = a * e = a`**（**唯一**） |
| **★ 零元 `θ`** | **`θ * a = a * θ = θ`**（**唯一**） |
| **★ 逆元** | `a * b = b * a = e` ⟹ `b = a⁻¹`（**结合律下唯一**） |

**★ 运算表求特殊元素的技巧**：
- **单位元**：所在**行与列都等于表头**的那个元素
- **零元**：所在**行与列全是它自己**的那个元素
- **逆元**：在 a 行中找 e，其列头即 `a⁻¹`

### A.13.2 ★ 代数系统的层次

```
代数系统 ──(结合律)──> 半群 ──(单位元)──> 独异点 ──(每元素可逆)──> 群 ──(交换律)──> Abel 群
```

| 结构 | 条件 |
|---|---|
| **半群** | 运算满足**结合律** |
| **独异点** | 半群 + **有单位元** |
| **★ 群** | **封闭 + 结合 + 有单位元 + 每元素有逆元** |
| **Abel 群** | 群 + **交换律** |

**★ 群的基本性质**：
- **消去律**：`ab = ac ⟹ b = c`（左消去）；`ba = ca ⟹ b = c`（右消去）
- **方程 `ax = b` 有唯一解 `x = a⁻¹b`**；`ya = b` 有唯一解 `y = ba⁻¹`
- **群无零元**（除 `|G| = 1`）
- `(a⁻¹)⁻¹ = a`；**`(ab)⁻¹ = b⁻¹a⁻¹`**（**顺序颠倒**）

### A.13.3 ★ 子群与循环群

| 名称 | 内容 |
|---|---|
| **子群** | `H ⊆ G` 非空，且 `<H, *>` 自身是群 |
| **★ 子群判定一** | **`H ≤ G ⟺ ∀a,b∈H, ab⁻¹ ∈ H`** |
| **★ 子群判定二** | **有限群** G 中：**`H ≤ G ⟺ H 对运算封闭`**（+ 非空） |
| **平凡子群** | `{e}` 和 G 本身 |
| **★ 元素的阶** `\|a\|` | 使 `a^k = e` 的**最小正整数** k |
| **★ 循环群** | **`G = <a> = {a^k \| k ∈ Z}`**，a 是**生成元** |
| **★ 循环群的结构** | 无限阶 ⟹ `≅ <Z, +>`；n 阶 ⟹ **`≅ <Zₙ, +ₙ>`** |
| **★ 生成元个数** | n 阶循环群有 **`φ(n)`** 个生成元；`a^k` 是生成元 **⟺ `gcd(k,n) = 1`** |
| **★ 元素的阶公式** | **`\|a^k\| = n / gcd(k, n)`**（n = 群的阶） |
| **循环群必是 Abel 群** | ✔（反之不成立，如 `V₄`） |

### A.13.4 ★ 陪集与拉格朗日定理

| 名称 | 内容 |
|---|---|
| **左陪集** | `aH = {a*h \| h ∈ H}` |
| **★ 陪集性质** | ① `a ∈ aH`；② `aH = H ⟺ a ∈ H`；③ `aH = bH ⟺ a⁻¹b ∈ H`；④ **两个陪集要么相同要么不交**；⑤ **`\|aH\| = \|H\|`（所有陪集等大）** |
| **★ 拉格朗日定理** | **`\|G\| = \|H\| · [G : H]`，即 `\|H\|` 整除 `\|G\|`** |
| **指数 `[G:H]`** | H 在 G 中**不同左陪集的个数** |
| **★ 推论 1** | 有限群中**每个元素的阶都整除群阶**；且 **`a^\|G\| = e`** |
| **★ 推论 2** | **素数阶群必为循环群**，任何非单位元都是生成元 |
| **★ 推论 3** | **费马小定理、欧拉定理都是拉格朗日定理的推论** ✓ |

**★ 注意**：**拉格朗日定理的逆命题不成立** ✗
反例：**交错群 `A₄` 的阶为 12，但没有 6 阶子群** ✓

### A.13.5 置换群与同态同构

| 名称 | 内容 |
|---|---|
| **n 元置换** | `{1,…,n}` 上的双射 |
| **对称群 `Sₙ`** | 全体 n 元置换在复合下构成的群，**`\|Sₙ\| = n!`** |
| **★ 凯莱定理** | **任何群都同构于某个置换群** ✓ |
| **置换群** | `Sₙ` 的任意子群 |
| **★ 同态** | `f(a*b) = f(a) ∘ f(b)` |
| **★ 同构** | 双射的同态（记 `G ≅ H`） |
| **同态性质** | `f(e_G) = e_H`；`f(a⁻¹) = f(a)⁻¹`；`f(aⁿ) = f(a)ⁿ` |
| **★ 同构的必要条件** | ① 阶相同；② 交换性相同；③ **元素的阶分布相同**；④ 子群结构相同 |

### A.13.6 环与域

| 结构 | 条件 |
|---|---|
| **★ 环** | `<R, +>` 是**交换群**；`<R, ·>` 是**半群**；**分配律**成立 |
| **交换环** | 环 + 乘法交换 |
| **含幺环** | 环 + 乘法有单位元 |
| **零因子** | `a, b ≠ 0` 但 `a·b = 0` |
| **★ 整环** | 环 + **交换** + **含幺（1≠0）** + **无零因子** |
| **★ 域** | 环 + `<F−{0}, ·>` 是**交换群**（等价：交换 + 含幺 + 每个非零元素可逆） |

**★ 层次**：`环 → 整环 → 域` ✓

**★ 环的性质**：
- **`a·0 = 0·a = 0`**；`(−a)·b = −(a·b)`；`(−a)·(−b) = a·b`
- `a·(b − c) = a·b − a·c`

**★ 关键结论**：
| 代数系统 | 是整环？ | 是域？ |
|---|---|---|
| `<Z, +, ×>` | ✔ | ✘（只有 ±1 可逆） |
| **`<Zₙ, +ₙ, ×ₙ>`** | **⟺ n 是素数** | **⟺ n 是素数** |
| `<Q, +, ×>`、`<R, +, ×>`、`<C, +, ×>` | ✔ | ✔ |
| `<Mₙ(R), +, ×>`（n≥2） | ✘（非交换，有零因子） | ✘ |
| `<2Z, +, ×>` | ✘（无幺元） | ✘ |

**★ 有限域**：元素个数必为 **`p^n`**；`GF(p) = Zₚ` ✓
（注意 **`GF(4) ≠ Z₄`**——`Z₄` 有零因子 `[2]×[2] = [0]` ✗）

## A.14 格与布尔代数（第 14 章）

### A.14.1 ★ 格的两种定义

| 视角 | 定义 | 优点 |
|---|---|---|
| **偏序定义** | 偏序集中**任意两元素都有上确界（`∨`）和下确界（`∧`）** | 直观，哈斯图可判 |
| **代数定义** | `<L, ∨, ∧>` 满足**交换律、结合律、吸收律**（幂等律可推出） | 便于等式演算 |

**★ 联系**：`a ≤ b ⟺ a ∨ b = b ⟺ a ∧ b = a` ✓

### A.14.2 格的基本性质

| 编号 | 性质 |
|---|---|
| 1 | **幂等律**：`a∨a = a`，`a∧a = a` |
| 2 | **交换律** |
| 3 | **结合律** |
| 4 | **吸收律**：`a∨(a∧b) = a`，`a∧(a∨b) = a` |
| 5 | **★ 分配不等式**：**`a∨(b∧c) ≤ (a∨b) ∧ (a∨c)`**；**`a∧(b∨c) ≥ (a∧b) ∨ (a∧c)`** |
| 6 | **保序性**：`b ≤ c ⟹ a∨b ≤ a∨c` 且 `a∧b ≤ a∧c` |

**★ 对偶原理（Duality Principle）**：
把 `∨ ↔ ∧`、`≤ ↔ ≥`、`⊤ ↔ ⊥` **同时互换**，命题仍成立 ✓

### A.14.3 ★ 分配格

| 名称 | 内容 |
|---|---|
| **★ 分配格** | 满足 **`a ∧ (b∨c) = (a∧b) ∨ (a∧c)`**（**一个方向成立即等价于另一个方向**） |
| **★ 判定定理** | **格是分配格 ⟺ 不含 `M₃`（钻石格）或 `N₅`（五角格）作子格** |
| **典型分配格** | **任何链**；**幂集格 `<P(A), ⊆>`**；**`<Z⁺, \|>`**；任何布尔代数 |

**★ 两个「禁形」**（**都是非分配格 ⟹ 都不是布尔代数；但注意：两者都是「有补格」**）：
- **`M₃`（钻石格）**：`⊤` 下面是**三个两两不可比**的元素。**有补格** ✓（`b` 的补元有 `a`、`c` 两个），**非分配** ✗
- **`N₅`（五角格）**：5 个元素，一个元素「穿」在链的中间。**有补格** ✓（`⊥↔⊤`；`a` 的补元是 `c`；`b` 的补元是 `c`；**`c` 有两个补元 `a` 和 `b`**），**非分配** ✗

> **★★ 千万别记成「`N₅` 有元素没有补元」**——那是**错的**！`N₅` 中**每个元素都有补元**（只是 `c` 的补元不唯一）。`N₅` 与 `M₃` 被排除出布尔代数的理由**完全相同且只有一个：不满足分配律**。
> 真正「有元素没有补元」的是**链**（`<{1,2,4,8},\|>` 中 `2` 无补元）和 `<{1,2,3,6,12},\|>`（其中 `2` 无补元）。

### A.14.4 ★ 有界格与有补格

| 名称 | 内容 |
|---|---|
| **全上界 `⊤`** | 对一切 a 有 `a ≤ ⊤`（最大元）；**唯一** |
| **全下界 `⊥`** | 对一切 a 有 `⊥ ≤ a`（最小元）；**唯一** |
| **有界格** | 同时有 ⊤ 和 ⊥；**任何有限格都是有界格** ✓ |
| **★ 有界格性质** | `a∨⊤ = ⊤`，`a∧⊤ = a`；`a∨⊥ = a`，`a∧⊥ = ⊥` |
| **★ 补元** | `a ∨ a' = ⊤` 且 `a ∧ a' = ⊥` |
| **★ 补元的性质** | `(a')' = a`；**补元不一定存在，也不一定唯一** ✗ |
| **★ 分配格中补元唯一** | ✔（这是布尔代数的基础） |
| **有补格** | 每个元素都**至少有一个**补元的有界格 |

### A.14.5 ★ 布尔代数

| 名称 | 内容 |
|---|---|
| **★ 布尔代数** | **有补分配格** `<B, ∨, ∧, ', 0, 1>` |
| **公理化定义** | 交换律 + 分配律 + 同一律（`a∨0=a`，`a∧1=a`）+ 互补律（`a∨a'=1`，`a∧a'=0`） |

**★ 布尔代数的基本性质**：

| 名称 | 公式 |
|---|---|
| 幂等律 | `a∨a = a`，`a∧a = a` |
| 交换律 | `a∨b = b∨a`，`a∧b = b∧a` |
| 结合律 | 同格 |
| **分配律** | `a∨(b∧c) = (a∨b)∧(a∨c)`；`a∧(b∨c) = (a∧b)∨(a∧c)` |
| **吸收律** | `a∨(a∧b) = a`；`a∧(a∨b) = a` |
| **同一律** | `a∨0 = a`；`a∧1 = a` |
| **零一律** | `a∨1 = 1`；`a∧0 = 0` |
| **互补律** | `a∨a' = 1`；`a∧a' = 0` |
| **★ 双重否定律** | **`(a')' = a`** |
| **★ 德摩根律** | **`(a∨b)' = a'∧b'`**；**`(a∧b)' = a'∨b'`** |
| **补元唯一** | `a∨b = 1 ∧ a∧b = 0 ⟹ b = a'` |
| **★ 包含关系的等式刻画** | **`a ≤ b ⟺ a∧b' = 0 ⟺ a'∨b = 1 ⟺ a∧b = a ⟺ a∨b = b`** |

**★ 典型布尔代数**：

| 布尔代数 | `∨` | `∧` | `'` | `0` | `1` |
|---|---|---|---|---|---|
| **幂集代数 `<P(A), …>`** | `∪` | `∩` | `～`（相对补） | `∅` | `A` |
| **开关代数 `<{0,1}, …>`** | `max` | `min` | `1−x` | 0 | 1 |
| **命题逻辑** | `∨` | `∧` | `¬` | `F` | `T` |
| **因子代数（n 无平方因子）** | `lcm` | `gcd` | `n/a` | `1` | `n` |

**★ 有限布尔代数的结构定理**：**任何有限布尔代数都同构于某个幂集代数，元素个数必为 `2ⁿ`** ✓

**★ 布尔表达式化简套路**：**提取公因式（分配律逆用）→ 互补律消去 → 吸收律化简** ✓
**★ 关键技巧**：**「`a = a ∧ (b ∨ b')`」——补全变元** ✓

**★ 功能完备性**：`{∧, ∨, '}` 功能完备；**`{↑}`（与非门）单独功能完备** ✓
