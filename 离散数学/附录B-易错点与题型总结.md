# B.1 逻辑部分易错点

## B.1.1 命题逻辑

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **蕴含式真值记错** | **只有「前件真、后件假」时 `p→q` 才假**。`p` 假时 `p→q` **恒真**（善意的谎言） |
| 2 | **把「只要…就…」和「只有…才…」搞反** | **「只要 p 就 q」= `p→q`**；**「只有 p 才 q」= `q→p`**（**充分必要位置相反！**） |
| 3 | **「除非」不会翻译** | **「除非 p，否则 q」= `¬p→q` = `p∨q`**；「除非 p，才 q」= `¬p→¬q` |
| 4 | **可兼或 vs 排斥或** | **「或」通常指可兼或 `∨`**；明确写「二者必居其一/但不能同时」才是排斥或 `⊕` |
| 5 | **等值演算时把蕴含式的两边都取反** | 假言易位是 `p→q ⇔ ¬q→¬p`（**前后都反且交换位置**），不是 `¬p→¬q` |
| 6 | **极小项/极大项编码记反** | **极小项：变元取 1 记正、取 0 记负**；**极大项恰好相反**。记忆法：极小项是「乘起来为 1」，极大项是「加起来为 0」 |
| 7 | **主析取范式和主合取范式的下标集弄混** | **主析取范式取 `A=1` 的行；主合取范式取 `A=0` 的行**。两者下标**互补**（`Mᵢ = ¬mᵢ`） |
| 8 | **求主合取范式时忘了极大项的变元取反** | 极大项 `Mᵢ` 中**赋值为 0 的变元写正形式、赋值为 1 的写负形式** |
| 9 | **用真值表法判推理有效性时看错行** | **只看「所有前提都为真」的那些行**，检查结论是否也为真；前提全真的行不存在时推理自动有效 |
| 10 | **形式证明中误用 T 规则** | T 规则要求 `A₁∧…∧Aₖ → B` 是**重言蕴含式**——**不能把「等值」当「蕴含」随意用**，也不能只用一个方向 |
| 11 | **CP 规则用错** | CP 规则的结论必须是**蕴含式 `A→B`**；把 A 作为附加前提推出 B 后，结论写成 `A→B`（**不是直接写 B**） |
| 12 | **联结词完备集判断错** | **`{∧,∨}` 不完备**（无法表示否定）；**`{¬,∧}`、`{¬,∨}`、`{¬,→}` 完备**；`{↑}`、`{↓}` **各自单独完备** |

## B.1.2 一阶逻辑

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **全称量词配合取、存在量词配箭头** | **「所有 F 都是 G」= `∀x(F(x)→G(x))`**；**「有的 F 是 G」= `∃x(F(x)∧G(x))`**。写反了会闹大笑话 |
| 2 | **忘了写特性谓词** | 「所有人都要吃饭」若个体域是全总个体域，必须写 `∀x(M(x)→E(x))`，不能写 `∀xE(x)` |
| 3 | **「没有…」否定错** | **「没有 F 是 G」= `¬∃x(F(x)∧G(x))` = `∀x(F(x)→¬G(x))`** |
| 4 | **辖域判断错** | 量词的辖域是**紧跟其后的最短公式**；有括号时是**括号内的全部**。如 `∀xP(x)∧Q(x)` 中 `Q(x)` 的 x 是**自由**的 |
| 5 | **约束变元与自由变元混淆** | 判断标准：该变元是否**出现在同名量词的辖域内**。同一变元可能**既约束又自由**（如 `∀xP(x)∧Q(x)` 中的 x） |
| 6 | **换名规则与代替规则混用** | **换名规则**改约束变元（**连量词一起改**）；**代替规则**改自由变元（**不动量词**） |
| 7 | **`∀` 对 `∨` 分配、`∃` 对 `∧` 分配** | **`∀x(A∨B) ⇔ ∀xA ∨ ∀xB` ✘ 不成立**；**`∃x(A∧B) ⇔ ∃xA ∧ ∃xB` ✘ 不成立**。只有 `∀` 对 `∧`、`∃` 对 `∨` 可分配 |
| 8 | **量词顺序随意交换** | **同种量词可交换**；**`∃y∀xA(x,y) ⟹ ∀x∃yA(x,y)` 但反向不成立**（`x+y=0` 是标准反例） |
| 9 | **`∀x(A→B) ⇔ ∀xA → B`** | **错！** 正确的是 **`∀x(A(x)→B) ⇔ ∃xA(x) → B`**（**量词翻转**，见 Q7） |
| 10 | **ES 规则用了「旧常项」** | ES 指定的常项**必须是全新的**——此前证明中未出现过的。用旧的会暗含「这两个存在的是同一个」的错误假设 |
| 11 | **US 与 ES 使用顺序错** | **先 ES 后 US** ✓。先 US 会把「任意」的常项变成具体的，再 ES 时容易与前面冲突 |
| 12 | **忽略一阶逻辑的不可判定性** | 一阶逻辑**没有通用的判定算法**（丘奇-图灵）；能判定的只是某些子类 |

# B.2 集合、关系、函数易错点

## B.2.1 集合

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **`P(∅)` 与 `∅` 混淆** | **`P(∅) = {∅}`**，是含一个元素的集合，**`\|P(∅)\| = 1`**（不是 0！） |
| 2 | **`∈` 与 `⊆` 混用** | `a ∈ A`（元素与集合）；`A ⊆ B`（集合与集合）。**`A ∈ P(A)` ✓ 但 `A ⊆ P(A)` 一般 ✘** |
| 3 | **`∅ ∈ A` 与 `∅ ⊆ A`** | **`∅ ⊆ A` 恒成立** ✓；`∅ ∈ A` 只在 A 含 ∅ 时成立 |
| 4 | **证集合相等只证一边** | 必须**双向包含**：`A ⊆ B` 且 `B ⊆ A` |
| 5 | **元素法证明方向颠倒** | 证 `A = B`：**任取 `x ∈ A`，推出 `x ∈ B`**（证 `A ⊆ B`）；再反向。**不能从结论出发反推** |
| 6 | **恒等式演算中把「差」放着不动** | **`A − B = A ∩ ～B`** 是化差为交的关键第一步 |
| 7 | **德摩根律用错** | **`～(A∪B) = ～A ∩ ～B`**（并变交）；**`～(A∩B) = ～A ∪ ～B`**（交变并）。**「长横线断开，符号翻转」** |
| 8 | **容斥原理符号错** | **奇加偶减**：单个集合加、两两交减、三交加、四交减…… |
| 9 | **容斥「都不在」算错** | **`\|都不在\| = \|U\| − \|至少一个在\|`**——先算「至少一个在」再用全集减 |

## B.2.2 二元关系

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **自反 vs 反自反的关系搞错** | **只有 `∅` 上的空关系同时自反且反自反**（当 A=∅）；**非空集合**上二者**不能同时成立**。但**可以都不成立**！ |
| 2 | **对称 vs 反对称无法同时成立** | **错！二者可以同时成立**（当 `R ⊆ I_A` 时）。**对称且反对称 ⟺ `R ⊆ I_A`** |
| 3 | **传递性判断漏掉「环路」情形** | 传递性要求：只要有 `⟨x,y⟩` 和 `⟨y,z⟩`，就必须有 `⟨x,z⟩`。**`x=z` 时也要检查 `⟨x,x⟩` 是否存在** |
| 4 | **复合关系顺序弄反** | **`R ∘ S` 表示先 R 后 S**（从右往左读）。有些教材相反，**看定义**：`R∘S = {⟨x,z⟩ \| ∃y(⟨x,y⟩∈R ∧ ⟨y,z⟩∈S)}` |
| 5 | **`(R∘S)⁻¹` 写成 `R⁻¹∘S⁻¹`** | **`(R∘S)⁻¹ = S⁻¹ ∘ R⁻¹`**（**顺序颠倒**）✓ |
| 6 | **复合对交随意分配** | **`R∘(S∩T) ⊆ (R∘S)∩(R∘T)` 只有单向包含** ✘。对**并**才能取等 |
| 7 | **传递闭包只算到 `R²`** | **`t(R) = R ∪ R² ∪ … ∪ Rⁿ`**（n = 元素个数），**要算到 `Rⁿ`**（不是 `R²`） |
| 8 | **闭包与运算顺序无关记错** | **`tsr = rts = str = trs`** ✓（三个闭包一起做时可任意顺序）；但**单独做时 `R` 传递 ⟹ `s(R)` 不一定传递** ✘ |
| 9 | **等价类算错** | `[a]_R = {x \| ⟨x,a⟩ ∈ R}`——注意是 **`⟨x,a⟩`**（有些书写 `⟨a,x⟩`，因对称性对等价关系无差别，但**对一般关系有差别**） |
| 10 | **划分的块可以相交** | 划分要求**两两不交**；**覆盖**才允许相交。别把二者搞混 |
| 11 | **最大元与极大元混淆** | **最大元**要与**所有**元素可比（存在则**唯一**）；**极大元**只要求「没有更大的」（**可能有多个**） |
| 12 | **上界一定在 B 中** | **错！上界/下界/上确界/下确界都在 A 中找**（不要求属于 B），只有**最大/最小/极大/极小元必须在 B 中** |
| 13 | **哈斯图画了传递边** | 哈斯图**只画覆盖关系**：① 不画自环；② **不画可由传递性推出的边**；③ 箭头向上（大元素在上） |

## B.2.3 函数

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **单射的证明方法** | 证单射标准写法：**设 `f(a₁) = f(a₂)`，推出 `a₁ = a₂`** |
| 2 | **满射要指明陪域** | 谈满射**必须说明陪域**！`f(x) = x²` 在 `f: R→R` 下非满射，在 `f: R→[0,+∞)` 下是满射 |
| 3 | **有限集三性质等价的条件** | **只在 `\|A\| = \|B\|`（有限）时** `单射 ⟺ 满射 ⟺ 双射` ✓；**无限集不成立**（`f(n) = 2n` 在 N 上单射非满射） |
| 4 | **像对交随意分配** | **`f(A₁∩A₂) ⊆ f(A₁)∩f(A₂)` 只有单向** ✘；**原像对交可分配** ✓。记忆：**「原像对一切运算友好，像只对并友好」** |
| 5 | **复合顺序弄反** | **`g∘f` 表示先作用 f 再作用 g**（**从右往左**） |
| 6 | **复合性质传错方向** | **`g∘f` 单射 ⟹ f 单射**（**单射往前传**）；**`g∘f` 满射 ⟹ g 满射**（**满射往后传**）。反向都不成立 |
| 7 | **反函数存在条件漏了** | **`f⁻¹` 存在 ⟺ f 是双射**（单射或满射都不够） |
| 8 | **反函数复合顺序** | **`(g∘f)⁻¹ = f⁻¹∘g⁻¹`**（**顺序颠倒**）✓ |
| 9 | **可数集与至多可数集混淆** | **可数集 ⟺ 与 N 等势**（无限）；**有限集不是可数集**（但可称「至多可数」） |
| 10 | **「稠密」误认为「不可数」** | **`Q` 是稠密的但可数**；不可数要另找理由（对角线论证） |
| 11 | **`R` 不可数的证明不完整** | 对角线论证必须**明确构造**出不在列表中的数，且说明「与每一项都不同」 |

# B.3 图论与树易错点

## B.3.1 图的基本概念

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **环贡献的度数算错** | **一个环贡献 2 度**（不是 1 度！）；但关联矩阵中环所在列记 **2** |
| 2 | **握手定理的方向** | **`Σd(v) = 2m`**（度数和 = **2 倍**边数）。用于「已知度数求边数」或「检验度数序列是否合法」 |
| 3 | **奇度顶点个数** | **必为偶数** ✓。若算出一半是奇数，一定算错了 |
| 4 | **平行边对度数的贡献** | 每条平行边**各贡献 1 度** |
| 5 | **子图 vs 生成子图** | **生成子图**必须含**全部顶点**；**导出子图**由顶点集的全部关联边构成 |
| 6 | **同构的必要条件当成充分** | 顶点数、边数、度序列、连通性、回路结构**都只是必要条件** ✘。判断同构要靠**构造双射**；判断不同构才用必要条件 |
| 7 | **`Kₙ` 边数公式记错** | **`n(n−1)/2`**（不是 `n(n−1)`——那是**有向**完全图的边数） |

## B.3.2 通路、回路与连通性

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **简单通路 vs 初级通路** | **简单通路（迹）= 边不重复**；**初级通路（路径）= 点不重复**。**初级 ⟹ 简单**，反之不然 |
| 2 | **有向图连通性层次** | **强连通 ⟹ 单向连通 ⟹ 弱连通**（**单向**，反向均不成立） |
| 3 | **连通度公式方向** | **`κ(G) ≤ λ(G) ≤ δ(G)`**（**点 ≤ 边 ≤ 最小度**）✓ |
| 4 | **割点与桥的判定** | 割点：删去后**连通分支数增加**；桥：删去后**连通分支数增加**（一条边） |

## B.3.3 欧拉图与哈密顿图

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **欧拉回路的判定条件漏了「连通」** | **连通 + 所有顶点度数为偶数** ✓（**两个条件缺一不可**） |
| 2 | **欧拉通路与欧拉回路弄混** | **欧拉回路**：0 个奇度点；**欧拉通路（非回路）**：**恰好 2 个奇度点**（它们是起点和终点） |
| 3 | **有向图欧拉判定用度数** | 有向图要看**入度与出度**：**欧拉回路需每点 `d⁺ = d⁻`**；欧拉通路需**起点 `d⁺ = d⁻+1`、终点 `d⁻ = d⁺+1`** |
| 4 | **哈密顿图判定乱用充分条件** | 狄拉克/奥尔定理**只是充分条件**：不满足**不代表**不是哈密顿图（`Cₙ` 就是反例） |
| 5 | **必要条件当成判定** | **`p(G−S) ≤ \|S\|` 只是必要条件**，不满足则可断定**不是**哈密顿图 ✓，满足也不能断定是 ✘ |
| 6 | **欧拉与哈密顿混淆** | **欧拉看「边」**（每条边恰一次，有完美判定）；**哈密顿看「点」**（每个点恰一次，NP 完全） |

## B.3.4 平面图与着色

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **欧拉公式记错** | **`n − m + r = 2`**（**顶点 − 边 + 面 = 2**）。三个量各是什么别搞混 |
| 2 | **桥对面次数的贡献** | **桥算两次**（桥的两侧是同一个面，该面被这条边「走了两遍」） |
| 3 | **`K_{3,3}` 用错了不等式** | **`K_{3,3}` 无三角形，必须用 `m ≤ 2n − 4`**（得 `9 > 8` 才能判定非平面）；**用 `3n − 6` 判不出来**（`9 ≤ 12`）✘ |
| 4 | **推论 2 的适用条件** | `m ≤ 2n − 4` 要求**无三角形**（每个面的次数 ≥ 4），不是随便用 |
| 5 | **奇圈色数算成 2** | **偶圈 `χ = 2`；奇圈 `χ = 3`**（奇圈不是二部图！） |
| 6 | **轮图色数** | **奇轮图 `Wₙ`（n 为奇数）`χ = 4`；偶轮图 `χ = 3`** |
| 7 | **贪心着色结果当成最优** | 韦尔奇-鲍威尔算法**不保证最优**；求 `χ(G)` 要**给出下界证明 + 着色方案** |

## B.3.5 树

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **树的边数条件不充分** | **`m = n − 1` 单独不能推出是树**！必须配上「**连通**」或「**无回路**」（见 T2/T3） |
| 2 | **`n − 1` 条边 + 连通 ⟹ 树** | ✓ 正确；但**`n − 1` 条边 + 无回路 ⟹ 树**也正确。**单说 `m = n−1` 不行** |
| 3 | **生成树的边数** | 生成树有 **`n − 1`** 条边（**树枝**）；**弦**有 `m − n + 1` 条 |
| 4 | **基本回路/基本割集个数弄反** | **基本回路 `m − n + 1` 个**（对应**弦**）；**基本割集 `n − 1` 个**（对应**树枝**） |
| 5 | **Prim 与 Kruskal 适用场景** | **Prim（加点法）适合稠密图 `O(n²)`**；**Kruskal（加边法）适合稀疏图 `O(m log m)`** |
| 6 | **哈夫曼树码长算错** | **码长 = 从根到该叶经过的边数**（**不是节点数！**）。这是最容易出错的地方 |
| 7 | **WPL 计算** | **`WPL = Σ wᵢ · l(wᵢ)`**（`l` 是**边长**）；**速算法：WPL = 所有内点权之和**（可互验） |
| 8 | **前缀码验证** | 必须检查**任何码字都不是另一个的前缀**。反例 `{0, 01, 11}`：`0` 是 `01` 的前缀 ✘ |
| 9 | **遍历序列还原** | **先序 + 中序** 或 **后序 + 中序** 可唯一还原；**先序 + 后序不能**唯一还原 ✘ |
| 10 | **正则 m 元树公式** | **`t = (m−1)i + 1`**（t = 叶数，i = **内点数**）；二叉树有 **`t = i + 1`**（即 `i = t − 1`） |

## B.3.6 匹配、独立集、覆盖集与支配集

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **把「匹配」和「边覆盖」混为一谈** | **匹配**：挑出的边**两两不共端点**（约束在**边与边**之间）；**边覆盖**：挑出的边**把所有顶点都碰到**（约束在**边与点**之间）。两者目标相反——匹配「尽量分散」，边覆盖「尽量少但盖全」 |
| 2 | **把「点覆盖」和「支配集」混为一谈** | **点覆盖对「边」负责**（每条边至少一端在里）；**支配集对「点」负责**（外面的点都要挨着里面）。有孤立点时差别最明显：孤立点只能自己进支配集，而对点覆盖毫无贡献 |
| 3 | **把柯尼希定理用到非二部图上** | **`α'(G) = β(G)` 只对二部图成立**！`K₃` 是反例：`α' = 1` 但 `β = 2`。一般图只有单向不等式 **`α'(G) ≤ β(G)`** |
| 4 | **霍尔定理只检查几个子集就下结论** | 必须检查**所有** `S ⊆ V₁`（共 `2^\|V₁\|` 个）。**只验证 `S = V₁` 是不够的**——违反的子集常常更小。技巧：找**邻居并集特别小**的那几个点 |
| 5 | **增广路取反后匹配数没变** | 增广路上**非匹配边恰比匹配边多一条**（首尾都是非匹配边），所以取反后匹配数 **+1**。若你算出来没变，说明这条路**不是**增广路（终点不是未饱和点，或首尾不都是非匹配边） |
| 6 | **忘了边覆盖要求「无孤立点」** | **加莱恒等式 `α'(G) + β'(G) = \|V(G)\|` 需要图无孤立点**。有孤立点时边覆盖根本不存在（孤立点没有任何边能碰到它） |
| 7 | **用 `α + β = \|V\|` 时把独立集与点覆盖搞反** | 公式是 **`α(G) + β(G) = \|V(G)\|`**（**最大**独立集 + **最小**点覆盖）。二者互为补集：`S` 独立 ⟺ `V − S` 是点覆盖 |
| 8 | **匈牙利算法只从 `V₁` 的未饱和点出发** | 匈牙利算法求的是**饱和 `V₁`** 的匹配（可能不是最大匹配！）。若题目要求**完美匹配**，必须**两侧都检查是否全部饱和**；`\|V₁\| ≠ \|V₂\|` 时永远没有完美匹配 |

# B.4 组合计数易错点

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **加法/乘法法则用错** | **分类且类间互斥 ⟹ 加法**；**分步且步间独立 ⟹ 乘法**。看题目是「或」（分类）还是「同时」（分步） |
| 2 | **重复计数与遗漏** | 分类必须**不重不漏**；用「一类一类数相加」前先检查互斥性 |
| 3 | **排列还是组合** | 判断法：**互换两个元素，方案变了用排列，没变用组合** |
| 4 | **可重组合公式记错** | **可重组合（隔板法）：`C(n+r−1, r)`** = `C(n+r−1, n−1)`。**不要与 `n^r`（可重排列）搞混** |
| 5 | **隔板法用于「至少 1 个」与「非负」** | **非负整数解：`C(r+k−1, k−1)`**；**正整数解：`C(r−1, k−1)`**（先给每个变量 1） |
| 6 | **圆排列忘了除以 n** | 圆排列 **`(n−1)!`**；项链（可翻转）**`(n−1)!/2`** |
| 7 | **多重集全排列** | **`n!/(n₁! n₂! … nₖ!)`**——**只除以重复元素的阶乘，不除别的** |
| 8 | **二项式定理的指数配错** | **`(x+y)ⁿ = Σ C(n,k) x^(n−k) y^k`**——注意 `x` 的指数是 `n−k`、`y` 的是 `k`，别反 |
| 9 | **求「特定项」时解错指数方程** | 写出通项 `C(n,k)·a^(n−k)·b^k`，令**指数等于目标值**解出 k；k 必须是非负整数，否则**该项不存在** |
| 10 | **鸽巢原理只证存在** | 鸽巢原理**只能证明「存在」**，不能指出具体是哪一个 ✘。答题时结论要写「**必存在**…」 |
| 11 | **鸽巢原理的「巢」构造** | 难点在**构造巢**。常见技巧：**按余数分类**（模 n）、**按前缀和分类**、**按 `2^k·m`（m 奇）分类**、**按最大递增/递减子序列长度分类** |
| 12 | **组合恒等式证明只写代数** | 组合证明（双计数）要求**给等式两边各找一种数同一件事的方法**，不能只算代数 |
| 13 | **非降路径的限制条件** | 必经某点：**分段相乘**；不越过对角线：**反射原理**⟹ Catalan 数 |

# B.5 数论与概率易错点

## B.5.1 初等数论

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **带余除法的余数取了负的** | **`0 ≤ r < b`，余数必须非负**！`−17 = 5×(−4) + 3`（不是 `5×(−3) − 2`） |
| 2 | **整除符号方向** | **`a \| b` 读作「a 整除 b」**，即 b 是 a 的倍数。别读反 |
| 3 | **`gcd·lcm = a·b` 用于多个数** | **只对两个数成立** ✘！三个数时 `gcd(a,b,c)·lcm(a,b,c) ≠ abc` |
| 4 | **同余两边随便约** | **不能随便约**！`ac ≡ bc (mod m)` 且 `gcd(c,m)=1` 才能得 `a ≡ b (mod m)`；否则只能得 **`a ≡ b (mod m/gcd(c,m))`** |
| 5 | **一次同余方程的解数** | 设 `d = gcd(a,m)`：**`d ∤ b` 无解**；**`d \| b` 恰有 `d` 个解**（模 m 下） |
| 6 | **中国剩余定理的前提** | 要求 `mᵢ` **两两互素** ✓。不互素时可能无解或解不唯一 |
| 7 | **CRT 最后忘了取模** | 算出 `ΣaᵢMᵢyᵢ` 后要 **`mod M`** 化简 |
| 8 | **欧拉函数公式漏了「互不相同的」** | **`φ(n) = n(1−1/p₁)…(1−1/pₖ)`** 中 `pᵢ` 是**互不相同的素因子**（`φ(12) = 12×(1−1/2)×(1−1/3) = 4`，**不是** 用 `2²` 和 `3` 各算一次） |
| 9 | **欧拉定理的前提** | 要求 **`gcd(a,m) = 1`**！不互素时不能用 |
| 10 | **费马小定理的指数** | **`a^(p−1) ≡ 1 (mod p)`**（指数是 **`p−1`**）；一般形式是 `a^p ≡ a (mod p)` |
| 11 | **费马素性检验的反向** | **只能证明「不是素数」**，不能证明「是素数」（卡迈克尔数会骗过检验，如 561） |
| 12 | **RSA 中 φ(n) 算错** | **`φ(n) = (p−1)(q−1)`**（不是 `pq−1`！） |

## B.5.2 离散概率

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **古典概型样本点不等可能** | 掷两颗骰子**必须用有序对 36 个**（不能用 21 个组合，因为不等可能） |
| 2 | **互斥与独立混淆** | **互斥**：不能同时发生（`A∩B=∅`）；**独立**：`P(AB)=P(A)P(B)`。**若 `P(A),P(B)>0`，二者不可能同时成立** |
| 3 | **独立性判断** | 判断独立要**验证 `P(AB) = P(A)P(B)`**，不能凭直觉（直觉常常错） |
| 4 | **两两独立 ≠ 相互独立** | 三事件相互独立要求**两两独立 + `P(ABC) = P(A)P(B)P(C)`**（**四个等式缺一不可**） |
| 5 | **全概率公式忘分母** | 全概率公式的 `P(A)` 要**单独算出来**（用全概率），别漏 |
| 6 | **贝叶斯公式分子分母弄反** | **`P(Bᵢ\|A) = P(A\|Bᵢ)P(Bᵢ) / P(A)`**。**验证：所有后验概率之和 = 1** ✓ |
| 7 | **方差的常数提取** | **`D(cX) = c²D(X)`**（**常数提出来要平方**！）；`D(X+c) = D(X)` |
| 8 | **方差加法无条件使用** | **`D(X+Y) = D(X)+D(Y)` 要求 X, Y 独立**！（期望的线性性才无条件成立） |
| 9 | **`E(XY) = E(X)E(Y)` 无条件使用** | **必须独立**才能用 ✘ |
| 10 | **几何分布的「首次成功」** | 几何分布 `P(X=k) = (1−p)^(k−1)p`，**`E(X) = 1/p`**。注意指数是 `k−1` |
| 11 | **贝叶斯结果的直觉违反** | 疾病检测的例子：**低发病率 ⟹ 阳性者真患病率很低**（基础比率谬误）。**答题要用公式算，别信直觉** |
| 12 | **马尔可夫不等式条件** | 要求 **`X ≥ 0`** 且 **`a > 0`** |

# B.6 代数系统与格易错点

## B.6.1 代数系统与群

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **忘记验证封闭性** | **封闭性是二元运算的第一要求**——`<Z⁺, −>` 不是代数系统（`1 − 2 = −1 ∉ Z⁺`） |
| 2 | **逆元唯一需要结合律** | **`(a*b)⁻¹ = b⁻¹ * a⁻¹` 和逆元唯一性都需要结合律** ✓。非半群中逆元可能不唯一 |
| 3 | **`(ab)⁻¹` 写成 `a⁻¹b⁻¹`** | **`(ab)⁻¹ = b⁻¹a⁻¹`**（**顺序颠倒**）✓ |
| 4 | **群无零元** | **群中除 `\|G\|=1` 外没有零元** ✓（因为零元不可逆） |
| 5 | **解方程时左右乘反** | `ax = b` ⟹ **`x = a⁻¹b`**；`xa = b` ⟹ **`y = ba⁻¹`**。**顺序不能颠倒** |
| 6 | **子群判定忘了非空** | 判定一：**`H` 非空 + `∀a,b∈H, ab⁻¹ ∈ H`**；判定二：**`H` 非空 + `H` 对运算封闭 + `H` 有限** |
| 7 | **拉格朗日定理的逆命题** | **逆命题不成立** ✘！反例：**交错群 `A₄` 阶为 12，但没有 6 阶子群** |
| 8 | **`Zₙ*` 的阶算错** | **`\|Zₙ*\| = φ(n)`**（只含与 n 互素的同余类）。如 `Z₆* = {[1],[5]}`，阶为 2 不是 6 |
| 9 | **循环群生成元个数** | n 阶循环群有 **`φ(n)`** 个生成元；`a^k` 是生成元 **⟺ `gcd(k,n)=1`** |
| 10 | **`Zₙ` 是域的条件** | **`Zₙ` 是域 ⟺ n 是素数** ✓。`Z₆` 有零因子（`[2]×[3]=[0]`），不是整环也不是域 |
| 11 | **`<2Z, +, ×>` 是整环吗** | **不是**——**没有乘法单位元**（`1 ∉ 2Z`）✘ |
| 12 | **判断两个群不同构的方法** | 用**四条必要条件**：阶、交换性、**元素的阶分布**、子群结构。**`Z₄ ≇ V₄`**（前者有 2 个 4 阶元，后者 0 个） |

## B.6.2 格与布尔代数

| 编号 | 易错点 | 正确做法 |
|---|---|---|
| 1 | **格的判定只看「有上界」** | 要求**任意两元素都有「最小上界」和「最大下界」**（唯一性！）✘ 有两个不可比的公共上界时不是格 |
| 2 | **有限格必有 ⊤ 和 ⊥** | ✓ 正确，可作为**必要条件**排除一些非格 |
| 3 | **把「分配不等式」当「分配律」** | **格中一般只有 `a∨(b∧c) ≤ (a∨b)∧(a∨c)`**（**不等式**）✘；等式成立才是分配格 |
| 4 | **分配格判定** | **格是分配格 ⟺ 不含 `M₃`（钻石格）或 `N₅`（五角格）作子格** ✓ |
| 5 | **补元一定存在 / 一定唯一** | **两个都不一定** ✘！**不唯一**：`M₃`（钻石格）中 `b` 有两个补元 `a` 和 `c`；**`N₅`（五角格）中同样每个元素都有补元，只是 `c` 同时是 `a` 和 `b` 的补元，也不唯一**。**不存在**：链 `<{1,2,4,8}, \|>` 中 `2` 就没有补元。**只有分配格中补元才唯一** |
| 6 | **有补格 ⟹ 布尔代数** | **错！** 还要**加上分配格** ✘。`M₃` 和 `N₅` 都是**有补格但不是分配格**，所以**都不是布尔代数**（缺的是**分配律**，不是补元） |
| 7 | **布尔代数元素个数** | **必为 `2ⁿ`** ✓（有限布尔代数同构于某幂集代数）。**不存在 3 元、6 元布尔代数** |
| 8 | **`Z₄` 与 `GF(4)` 混淆** | **`GF(4) ≠ Z₄`** ✘！`Z₄` 有零因子（`[2]×[2]=[0]`），不是域 |
| 9 | **因子代数要求无平方因子** | `n = 12 = 2²×3` **有平方因子**，`<S, lcm, gcd>` **不是布尔代数**（12 的因子中 2 的补元不存在） |
| 10 | **德摩根律的两次应用** | **`(a∨b)' = a'∧b'`**；**`(a∧b)' = a'∨b'`**。**「长横线断开，符号翻转」**（与集合、命题逻辑完全一致） |
| 11 | **化简布尔表达式后不验证** | **必须用真值表验证**！化简容易漏项——`f=(x∧y')∨(x∧z)∨(y'∧z)` 中第三项**不能删**（`x=0,y=0,z=1` 时只有它为 1） |

# B.7 ★ 判定类题型套路（重点！）

> 这一节是**考试提分的核心**。判定类题目的共同特点：**有固定流程可循**，练熟后几乎不会错。

## B.7.1 ★ 怎么快速判断关系的五种性质

**四步流程**：
```
第 1 步：写出关系的集合表示（或关系矩阵/关系图）
第 2 步：看对角线 → 判自反 / 反自反
        · 自反：每个元素都有 ⟨x,x⟩（矩阵主对角线全 1，关系图每点有环）
        · 反自反：每个元素都没有 ⟨x,x⟩（矩阵主对角线全 0，关系图每点无环）
        · 注意：非空集合上二者不能同时成立，但可以都不成立
第 3 步：看对称性 → 判对称 / 反对称
        · 对称：⟨x,y⟩ 在则 ⟨y,x⟩ 也在（矩阵关于主对角线对称）
        · 反对称：⟨x,y⟩ 与 ⟨y,x⟩ 同时存在 ⟹ x = y
        · 注意：二者可以同时成立（当 R ⊆ I_A）
        · 快速检查：把所有有序对按 ⟨a,b⟩ 与 ⟨b,a⟩ 配对找
第 4 步：看传递性 → 逐个检查「两步能否并一步」
        · 对每个 ⟨x,y⟩ 和 ⟨y,z⟩，检查 ⟨x,z⟩ 是否也在 R 中
        · 有向图视角：检查是否有「x→y→z 但缺 x→z」
```

**★ 传递性判定的三个技巧**：
1. **只检查「中间元素」能接上的对**——先列出每个元素「出发」和「到达」的集合
2. **`x = z` 时也要检查**：`⟨x,y⟩` 与 `⟨y,x⟩` 都在时，必须检查 `⟨x,x⟩` 是否在 R 中（**这是最常漏的情形**）
3. **矩阵法**：算 `M_R²`（布尔乘法），若 `M_R² ≤ M_R`（逐元素比较）则传递 ✓

**★ 11 种常见关系的答案（背下来）**：

| 关系 | 自反 | 反自反 | 对称 | 反对称 | 传递 |
|---|---|---|---|---|---|
| `∅` | ✘ | ✔ | ✔ | ✔ | ✔ |
| `I_A`（A非空） | ✔ | ✘ | ✔ | ✔ | ✔ |
| `E_A`（\|A\|≥2） | ✔ | ✘ | ✔ | ✘ | ✔ |
| `≤`（实数） | ✔ | ✘ | ✘ | ✔ | ✔ |
| `<`（实数） | ✘ | ✔ | ✘ | ✔ | ✔ |
| 整除 `\|`（Z⁺） | ✔ | ✘ | ✘ | ✔ | ✔ |
| 「同姓」 | ✔ | ✘ | ✔ | ✘ | ✔ |
| 「父子」 | ✘ | ✔ | ✘ | ✔ | ✘ |
| `⊆`（幂集） | ✔ | ✘ | ✘ | ✔ | ✔ |
| `⇔`（命题） | ✔ | ✘ | ✔ | ✘ | ✔ |
| 同余 `≡ (mod m)` | ✔ | ✘ | ✔ | ✘ | ✔ |

## B.7.2 ★ 怎么求三种闭包

```
自反闭包：   r(R) = R ∪ I_A          ← 只需补上所有 ⟨x,x⟩
对称闭包：   s(R) = R ∪ R⁻¹          ← 把每个 ⟨x,y⟩ 的「反向」⟨y,x⟩ 补上
传递闭包：   t(R) = R ∪ R² ∪ … ∪ Rⁿ  ← 必须算到 Rⁿ（n = 元素个数）
```

**★ 用沃舍尔算法求传递闭包（推荐）**：
```
初始化 A = M_R（关系矩阵）
for k = 1 to n:
    for i = 1 to n:
        for j = 1 to n:
            A[i][j] = A[i][j] ∨ (A[i][k] ∧ A[k][j])
输出 A = M_t
```
**直观理解**：`A[i][k] ∧ A[k][j]` 表示「i 可达 k 且 k 可达 j」，也就是「经过 k 中转可达」✓

**★ 手工算传递闭包的三步**：
1. 画出关系图
2. 逐条找出所有「通路」，把「有通路但无边」的点对补上边
3. **反复检查**直到没有新边可加（补边后可能产生新的通路！）

## B.7.3 ★ 怎么判断欧拉图

**三步流程**：
```
第 1 步：判断是「回路」还是「通路」（题目问「一笔画回到起点」还是「一笔画」）
第 2 步：数每个顶点的度数（有向图则分别数入度和出度）
第 3 步：对照下表判断
```

| 类型 | 无向图判定 | 有向图判定 |
|---|---|---|
| **欧拉回路**（回到起点） | **连通 + 所有顶点度数为偶数** | **弱连通 + 每点 `d⁺ = d⁻`** |
| **欧拉通路**（不必回起点） | **连通 + 恰有 2 个奇度顶点** | **弱连通 + 恰一点 `d⁺ = d⁻+1`（起点）、恰一点 `d⁻ = d⁺+1`（终点）** |
| **都不是** | 奇度顶点 ≥ 4 个 | 其他情形 |

**★ 关键提醒**：
- **「连通」条件不能漏**（有孤立点的图即使度数条件满足也没有欧拉回路）
- **奇度顶点个数必为偶数**——若你数出奇数个，一定数错了
- **哥尼斯堡七桥问题**：4 个顶点全是奇度（度为 3,3,5,3）⟹ **无解** ✓
- 欧拉图口诀：**「看边——一笔画，度数是关键」**

## B.7.4 ★ 怎么判断哈密顿图

**⚠ 先明确**：**哈密顿图的判定是 NP 完全问题，没有简单的充要条件**。考试中只考以下几种情形：

**（1）用必要条件否定**（最常用）：
```
第 1 步：取 S = {v}（单个顶点），检查 p(G − v) ≤ 1
        · 若删去某顶点后连通分支数 > 1 ⟹ v 是割点 ⟹ 不是哈密顿图 ✘
第 2 步：取更大的集合 S，检查 p(G − S) ≤ |S|
        · 若不满足 ⟹ 不是哈密顿图 ✘
```

**（2）用充分条件肯定**：
| 定理 | 条件 | 结论 |
|---|---|---|
| **狄拉克定理** | `n ≥ 3` 且 **`δ(G) ≥ n/2`** | 是哈密顿图 ✓ |
| **奥尔定理** | `n ≥ 3` 且任意**不相邻** u, v 有 **`d(u)+d(v) ≥ n`** | 是哈密顿图 ✓ |

**（3）直接构造**：
- 对**小规模图**（`n ≤ 8`）：直接找出一个经过所有顶点的回路
- 对**特殊结构图**：`Kₙ`（n≥3）、`Wₙ`、完全二部图 `K_{n,n}` 等都是哈密顿图

**★ 关键提醒**：
- **狄拉克/奥尔定理只是充分条件**——不满足不代表不是！`C₅` 满足 `δ = 2 < 2.5`，但 `C₅` 显然是哈密顿图 ✓
- 哈密顿图口诀：**「看点——走遍每个城市一次，至今无好判定（NP 完全）」**

## B.7.5 ★ 怎么判断一个代数系统是不是群

**五步检查法（按顺序）**：
```
第 1 步：封闭性 —— a, b ∈ S ⟹ a*b ∈ S 吗？
        ✘ 不是 ⟹ 连代数系统都不是，直接结束
第 2 步：结合律 —— (a*b)*c = a*(b*c) 对一切 a,b,c 成立吗？
        （矩阵乘法、函数复合 ✓；减法、除法 ✘）
第 3 步：单位元 —— 存在 e 使 e*a = a*e = a 吗？
        （在运算表中找「行与列都等于表头」的元素）
第 4 步：逆元 —— 每个元素 a 都有 b 使 a*b = b*a = e 吗？
        （在 a 行中找 e，其列头即 a⁻¹；再验证 a⁻¹ 行中也找得到 a）
第 5 步：栏目外的加分项：是否交换（Abel 群）？
```

**★ 常见系统的结论表（必背）**：

| 代数系统 | 是不是群 | 关键理由 |
|---|---|---|
| `<Z, +>` | ✔ 无限 Abel 群 | — |
| `<Z, ×>` | ✘ | 只有 ±1 可逆 |
| `<Q−{0}, ×>` | ✔ Abel 群 | — |
| **`<Zₙ, +ₙ>`** | ✔ **n 阶循环群** | 加法取模 |
| **`<Zₙ*, ×ₙ>`** | ✔ **`φ(n)` 阶 Abel 群** | `Zₙ*` 只含与 n 互素的类 |
| `<Zₙ, ×ₙ>` | ✘（n 非素数时） | 合数时有零因子 |
| `<Mₙ(R), +>` | ✔ Abel 群 | 矩阵加法 |
| `<Mₙ(R), ×>` | ✘ | 奇异矩阵不可逆 |
| `<GLₙ(R), ×>` | ✔ 非 Abel（n≥2） | 可逆矩阵 |
| **`<P(A), ⊕>`** | ✔ **`2^\|A\|` 阶 Abel 群** | 对称差 |
| `<P(A), ∪>` | ✘ | 除 ∅ 外无可逆元（`A∪X = ∅` 无解） |
| **`<Sₙ, ∘>`** | ✔ **`n!` 阶**，**n≥3 时非 Abel** | 置换复合 |
| `<Z⁺, +>` | ✘ | 无单位元（0 ∉ Z⁺） |
| `<N, +>` | ✘ | 有单位元 0，但正数无逆元 |

**★ 判断子群（`H ≤ G`）的两条路**：
| 方法 | 做法 | 适用 |
|---|---|---|
| **判定一** | 验证 `H` **非空** + **`∀a,b∈H, ab⁻¹ ∈ H`** | 通用 |
| **判定二** | 验证 `H` **非空** + **`H` 有限** + **对运算封闭** | 有限子集最好用 |

**★ 求 `Zₙ` 的全部子群**：
```
第 1 步：用拉格朗日定理筛选 —— 子群的阶必须整除 n
第 2 步：对每个满足 d | n 的 d，构造由 n/d 生成的 d 阶子群：<[n/d]>
第 3 步：验证没有遗漏
```
**例**：`Z₁₂` 的子群：阶可以是 1, 2, 3, 4, 6, 12，**恰好各有一个**：
- 1 阶：`{[0]}`
- 2 阶：`{[0],[6]}`
- 3 阶：`{[0],[4],[8]}`
- 4 阶：`{[0],[3],[6],[9]}`
- 6 阶：`{[0],[2],[4],[6],[8],[10]}`
- 12 阶：`Z₁₂`

## B.7.6 ★ 怎么判断环与域

```
第 1 步：是不是环？ —— <R,+> 是交换群 + <R,·> 是半群 + 分配律
第 2 步：是不是整环？ —— 环 + 交换 + 含幺(1≠0) + 无零因子
第 3 步：是不是域？ —— 交换 + 含幺 + 每个非零元可逆
        等价说法：<F−{0}, ·> 构成交换群
```

**★ 找零因子的方法**：找 `a, b ≠ 0` 使 `a·b = 0`。
- **`Zₙ` 有零因子 ⟺ n 是合数** ✓（`Z₆`：`[2]×[3] = [0]`）
- **`Mₙ(R)`（n≥2）有零因子**（两个非零矩阵相乘可为 O）

**★ 关键结论表**：
| 系统 | 整环 | 域 |
|---|---|---|
| **`Zₚ`（p 素数）** | ✔ | **✔** |
| **`Zₙ`（n 合数）** | ✘ | ✘ |
| `Z` | ✔ | ✘ |
| `Q`, `R`, `C` | ✔ | ✔ |
| `2Z` | ✘（无幺元） | ✘ |
| `Mₙ(R)` | ✘（非交换+零因子） | ✘ |

**★ 有限域**：元素个数必为 **`p^n`**；**`GF(4) ≠ Z₄`** ✓

## B.7.7 ★ 怎么判断格与布尔代数

```
第 1 步：是不是格？
        · 画哈斯图，**逐对检查**是否都有上确界和下确界
        · 加速：有限格必有唯一 ⊤ 和 ⊥（必要条件）；看有没有「两个不可比的公共上界」
第 2 步：是不是分配格？
        · 画图看**有没有 M₃（钻石）或 N₅（五角）形状的子格**
        · 没有 ⟹ 是分配格 ✓
第 3 步：是不是有界格？
        · 有 ⊤ 和 ⊥ 吗？（任何有限格都有 ✓）
第 4 步：是不是有补格？
        · **逐个元素**找补元（`a∨a'=⊤` 且 `a∧a'=⊥`）
        · 有一个元素找不到补元 ⟹ 不是有补格
        · **注意**：`M₃` 和 `N₅` **都是**有补格（补元只是不唯一，但都存在）
第 5 步：是不是布尔代数？
        · **有补 + 分配** ⟺ 布尔代数 ✓
        · 或验证：元素个数 = 2ⁿ？
        · `M₃`、`N₅` 有补但不分配 ⟹ **都不是**布尔代数（理由是不分配，不是缺补元）
```

**★ 快速决策表**：

| 情形 | 分配格 | 有补格 | 布尔代数 |
|---|---|---|---|
| **链（≥3 个元素）** | ✔ | **✘（有元素无补元）** | ✘（缺补元） |
| **`M₃`（钻石格）** | **✘** | ✔（**补元不唯一**） | ✘（**非分配**） |
| **`N₅`（五角格）** | **✘** | **✔（补元不唯一：`c` 是 `a` 和 `b` 的共同补元）** | ✘（**非分配**） |
| **`<P(A), ⊆>`** | ✔ | ✔ | **✔** |
| **`<{1,2,3,6}, \|>`（n=6 因子）** | ✔ | ✔ | **✔** |
| **`<{1,2,3,6,12}, \|>`** | ✔ | ✘（2 无补元） | ✘（缺补元） |
| **`<Z⁺, \|>`** | ✔ | ✘（无 ⊤） | ✘（非有界） |

> **★ 关键区分**：**`N₅` 与 `M₃` 一样，都是「有补格但非分配格」**，二者不能成为布尔代数的理由**都只有一个：不满足分配律**。
> **千万别写成「`N₅` 有元素没有补元」**——那是错的。逐个验证给你看（`N₅`：`⊥ < a < b < ⊤`，`⊥ < c < ⊤`，`a` 与 `c` 不可比）：
> `a ∨ c = ⊤`、`a ∧ c = ⊥` ⟹ `c` 是 `a` 的补元；又 `b ∨ c = ⊤`、`b ∧ c = ⊥` ⟹ `c` 也是 `b` 的补元。
> 故 `c` 有**两个**补元（`a` 和 `b`），**补元不唯一但确实存在** ✓

## B.7.8 ★ 怎么判断平面图

```
第 1 步：若是 K₅ 或 K_{3,3} 或其细分 ⟹ 非平面（库拉托夫斯基定理）
第 2 步：数 n（顶点）和 m（边），套不等式：
        · m > 3n − 6 ⟹ 非平面 ✓（n ≥ 3）
        · 若无三角形且 m > 2n − 4 ⟹ 非平面 ✓
        · 若 m ≤ 3n − 6 ⟹ **判不出来**，需要另想办法（或尝试画出平面嵌入）
第 3 步：尝试作图 —— 若能画出无边交叉的嵌入 ⟹ 是平面图
```

**★ 必背的两个非平面图**：
| 图 | n | m | 用哪个 | 结论 |
|---|---|---|---|---|
| `K₅` | 5 | 10 | `3n−6 = 9` | `10 > 9` ⟹ **非平面** ✓ |
| **`K_{3,3}`** | 6 | 9 | **`2n−4 = 8`**（无三角形） | `9 > 8` ⟹ **非平面** ✓ |

**★ 陷阱**：**`K_{3,3}` 用 `3n−6` 判不出来**（`9 ≤ 12`）——**必须用 `2n−4`**！

## B.7.9 ★ 怎么判断二部图

**黑白染色法（最实用）**：
```
第 1 步：任选一个顶点染黑
第 2 步：把它的所有邻居染白
第 3 步：把新染白顶点的所有邻居染黑
第 4 步：重复直到所有可达顶点都染色
第 5 步：若出现「相邻两顶点同色」⟹ 不是二部图 ✘；否则是 ✓
```

**★ 定理法**：**二部图 ⟺ 不含奇长度回路** ✓
（所以：偶圈 `C₄, C₆` 是二部图；**奇圈 `C₃, C₅` 不是**）

## B.7.10 ★ 怎么判断两个图是否同构

```
第 1 步：比较「必要条件」（快速排除）：
        · 顶点数相同？
        · 边数相同？
        · 度序列相同（**排序后逐个比较**）？
        · 连通分支数相同？
        · 是否有相同长度的回路？
        任一不满足 ⟹ 不同构 ✘
第 2 步：若必要条件都满足，尝试**构造双射**
        · 从度数最大（或最特殊）的顶点开始配对
        · 逐步扩展，保持邻接关系
第 3 步：若无法构造 ⟹ 很可能不同构，但要**明确找出破坏同构的结构差异**
        （如「G 有三角形而 H 没有」）
```

**★ 重要提醒**：**必要条件都不充分** ✘！即使所有必要条件都满足，仍可能不同构。

## B.7.11 ★ 怎么判断匹配、独立集、点覆盖与支配集

```
第 1 步：看清题目问的是「点」还是「边」，以及约束是什么
        · 挑边 + 边之间不共端点     → 匹配（= 边独立集）
        · 挑边 + 盖住所有点         → 边覆盖集
        · 挑点 + 点之间不相邻       → 点独立集
        · 挑点 + 盖住所有边         → 点覆盖集
        · 挑点 + 盖住所有「其余点」 → 支配集
第 2 步：求最大匹配
        · 二部图：用**匈牙利算法**（增广路法）——从 V₁ 的未饱和点出发找增广路，
          找到就沿路取反（匹配数 +1），找不到就换下一个未饱和点；
          所有未饱和点都搜完仍无增广路 ⟹ 由**贝尔热定理**已是最大匹配 ✓
        · 检验：任取一个未饱和点，手工找增广路，找不到才算完
第 3 步：判断「有没有饱和 V₁ 的匹配」→ 用**霍尔定理**
        · 逐个检查 S ⊆ V₁ 是否满足 |N(S)| ≥ |S|
        · 违反的子集通常很小，**优先找「邻居并集小」的点**
        · 找不到违反 ⟹ 存在；找到 ⟹ 不存在（并把它作为「不存在」的证明写出来）
第 4 步：求最小点覆盖
        · 二部图：**柯尼希定理** ⟹ 最小点覆盖数 = 最大匹配数 ✓
          构造法：令 U = V₁ 的未饱和点，Z = 从 U 沿交替路可达的点集，
          则 **K = (V₁ − Z) ∪ (V₂ ∩ Z)**（同侧取补集，异侧取交集）
        · 非二部图：**不能用柯尼希定理** ✘，只能手工找或枚举
第 5 步：求独立数 → 用互补关系
        · **α(G) + β(G) = |V(G)|**（对**任何**图都成立）
        · 求出 β 后直接得 α = |V| − β，**不必重新枚举**
第 6 步：求支配数 γ(G)
        · 没有公式，只能**构造 + 证明下界**两步：
          ① 给出一个大小 k 的支配集 ⟹ γ ≤ k
          ② 论证任意 k−1 个点都支配不全（如「一个点最多支配 3 个点，k−1 个最多支配 3(k−1) < n」）
          ⟹ γ = k ✓
```

**★ 四个数的一站式口诀**：
**「匹配管边不打架，独立管点不挨着，覆盖管边全踩住，支配管点全够到；最大匹配求最小覆盖（二部图），最大独立配最小覆盖（任何图）。」**

**★ 常用快捷键**：
- 二部图：**最大匹配数 = 最小点覆盖数**（柯尼希）
- 任何图：**最大独立集 + 最小点覆盖 = 顶点数**（互补）
- 无孤立点图：**最大匹配 + 最小边覆盖 = 顶点数**（加莱）
- 有完美匹配的必要条件：`|V₁| = |V₂|`，且 `o(G − S) ≤ |S|`（托特）

# B.8 证明题模板与答题规范

## B.8.1 六种证明方法的模板

### （1）直接证明法（证 `P → Q`）
```
证明：假设 P 成立。
      （推导过程……）
      因此 Q 成立。
      ∎
```
**例**：证「若 n 是奇数，则 n² 是奇数」——
假设 `n = 2k+1`，则 `n² = 4k²+4k+1 = 2(2k²+2k)+1`，是奇数。∎

### （2）反证法（证 P）
```
证明：假设 ¬P 成立。（即结论不成立）
      （推导过程……）
      得到 R ∧ ¬R，矛盾。
      故 P 成立。
      ∎
```
**例**：证「√2 是无理数」——
假设 `√2 = p/q`（p, q 互素），则 `p² = 2q²` ⟹ p 是偶数；设 `p = 2m`，则 `4m² = 2q²` ⟹ `q² = 2m²` ⟹ q 也是偶数。与 p, q 互素矛盾。∎

### （3）分情况证明法
```
证明：分以下 k 种情况讨论（要求：互斥且完备）：
      情形 1：…… 则结论成立。
      情形 2：…… 则结论成立。
      ……
      综合各情形，结论成立。
      ∎
```
**例**：证「连续三个整数之积被 6 整除」——
分情况证 2 | 积（三个连续整数中必有一个偶数）和 3 | 积（必有一个是 3 的倍数）；因 `gcd(2,3)=1`，故 `6 | 积`。∎

### （4）构造性证明法（证「存在……」）
```
证明：构造 x = （具体表达式）。
      验证：
        · x 满足条件 1：……
        · x 满足条件 2：……
      故存在满足条件的 x。
      ∎
```

### （5）存在唯一性证明
```
证明：
  （存在性）构造 x = （具体表达式），验证它满足条件。∎
  （唯一性）假设 x₁ 和 x₂ 都满足条件。
      则 （推导）…
      得 x₁ = x₂。
      故满足条件的元素唯一。
      ∎
```

### （6）数学归纳法
```
证明：对 n 作归纳。
  （归纳基础）当 n = n₀ 时，…… 命题成立。
  （归纳假设）假设 n = k 时命题成立，即 ……。
  （归纳步骤）当 n = k+1 时，
      （利用归纳假设推导）
      故命题对 n = k+1 成立。
  由数学归纳法原理，命题对一切 n ≥ n₀ 成立。
  ∎
```
**例**：证 `1+2+…+n = n(n+1)/2`——
基础：n=1 时 `1 = 1×2/2` ✓
假设：`1+…+k = k(k+1)/2`
步骤：`1+…+k+(k+1) = k(k+1)/2 + (k+1) = (k+1)(k+2)/2` ✓ ∎

## B.8.2 ★ 答题规范（阅卷得分点）

| 要求 | 说明 |
|---|---|
| **① 开头写「设…」** | 把题目条件符号化，明确变量含义 |
| **② 每步写依据** | 「由定义」「由定理 X」「由归纳假设」——**不要跳步** |
| **③ 结论单独一行** | 用「故…」「因此…」明确写出结论，最后画 **∎** 或写「证毕」 |
| **④ 反证法标明「矛盾」** | 必须明确指出与哪条已知矛盾 |
| **⑤ 分情况证明标明「互斥且完备」** | 说明分类不重不漏 |
| **⑥ 归纳法三个要素齐全** | **基础 + 假设 + 步骤**，缺一不可 |
| **⑦ 计算题写过程** | 不要只写答案；矩阵、真值表要完整 |
| **⑧ 判定题要给理由** | 不能只写「是」或「不是」，必须说明依据（度数、不等式、公理） |

**★ 最常见扣分原因**：
1. **只写结论不写过程**（证明题直接写「显然成立」）
2. **反证法没有指出矛盾是什么**
3. **数学归纳法漏了归纳基础或假设**
4. **判定题没有说明理由**（如「因为所有顶点度数为偶数且连通，故是欧拉图」）
5. **计算过程跳步导致中间结果无法核对**
6. **符号书写不规范**（`∈`/`⊆` 混用、`⟹`/`⟺` 混用）
