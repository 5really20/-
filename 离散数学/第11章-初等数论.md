## 11.1 整除与带余除法

### 11.1.1 整除

**定义 11.1（整除）**：设 `a, b ∈ Z`，`a ≠ 0`。若存在整数 `q` 使 `b = a · q`，则称 **a 整除 b**（a divides b），记作 `a | b`；否则称 a 不整除 b，记作 `a ∤ b`。
此时称 a 是 b 的**因数（约数）**，b 是 a 的**倍数**。

**注意**：
- `a | b` 是一个**命题**，它的值是「真」或「假」；而 `b/a` 是一个**数**。二者不能混淆。
- 任何非零整数整除 0：`a | 0`（因为 `0 = a · 0`）✓
- `±1` 整除任何整数 ✓
- `0 | b` 只在 `b = 0` 时有意义（一般规定除数不为 0）✗

**定理 11.1（整除的基本性质）**：设 `a, b, c, m, n ∈ Z`。
| 编号 | 性质 | 说明 |
|---|---|---|
| 1 | 若 `a \| b` 且 `b \| c`，则 `a \| c` | **传递性** |
| 2 | 若 `a \| b` 且 `a \| c`，则 `a \| (b ± c)` | 可加减 |
| 3 | 若 `a \| b`，则 `a \| (b · c)` | 可乘任意整数 |
| 4 | 若 `a \| b` 且 `a \| c`，则对任意 `m, n` 有 `a \| (mb + nc)` | **线性组合** |
| 5 | 若 `a \| b` 且 `b \| a`，则 `a = ±b` | 互相整除 |
| 6 | 若 `a \| b` 且 `b ≠ 0`，则 `\|a\| ≤ \|b\|` | 大小关系 |

**证明性质 1（直接证明法）**：由 `a | b` 存在 `q₁` 使 `b = aq₁`；由 `b | c` 存在 `q₂` 使 `c = bq₂`。
则 `c = bq₂ = (aq₁)q₂ = a(q₁q₂)`。因 `q₁q₂ ∈ Z`，故 `a | c` ✓ ∎

**证明性质 5**：由 `a | b` 有 `b = aq₁`；由 `b | a` 有 `a = bq₂`（注意：若 `a = 0`，则 `b = 0`，`a = b = 0` 满足 `a = ±b`；否则继续）。
代入：`a = (aq₁)q₂ = a(q₁q₂)`。因 `a ≠ 0`，两边除以 a 得 `q₁q₂ = 1`。
整数乘积为 1 只能是 `q₁ = q₂ = 1` 或 `q₁ = q₂ = −1`。
故 `b = a` 或 `b = −a`，即 `a = ±b` ✓ ∎

### 11.1.2 带余除法

**定理 11.2（带余除法 / 除法算法）**：设 `a ∈ Z`，`b ∈ Z⁺`。则存在**唯一**的一对整数 `q`（商）和 `r`（余数），使
`a = bq + r`，其中 `0 ≤ r < b`

**证明（存在性 + 唯一性）**：
**存在性**：考虑集合 `S = {a − bk | k ∈ Z, a − bk ≥ 0}`。由阿基米德性质，S 非空（取 k 足够小即可）。设 `r = a − bq` 是 S 中的最小元素（q 为某个整数）。若 `r ≥ b`，则 `r − b = a − b(q+1) ≥ 0` 也在 S 中，且 `r − b < r`，与 r 的最小性矛盾。故 `0 ≤ r < b` ✓
**唯一性**：设另有一对 `(q', r')` 满足 `a = bq' + r'`，`0 ≤ r' < b`。则 `b(q − q') = r' − r`。
两边取绝对值：`b|q − q'| = |r' − r| < b`（因 `0 ≤ r, r' < b`，故 `|r'−r| < b`）。
故 `|q − q'| < 1`，即 `q = q'`，进而 `r = r'` ✓ ∎

**记法**：`q = ⌊a/b⌋`（下取整），`r = a mod b`。

**例**：`a = −17, b = 5`：`−17 = 5 × (−4) + 3`，故 `q = −4`，`r = 3`（**注意余数必须非负**）。
（常见错误：写成 `−17 = 5 × (−3) + (−2)`，余数 −2 不合规。）

### 11.1.3 素数与合数

**定义 11.2（素数）**：大于 1 的整数 `p`，若它的正因数只有 1 和 p，则称 p 为**素数（质数，Prime）**。
大于 1 且不是素数的整数称为**合数（Composite）**。
`1` 既不是素数也不是合数。

**定理 11.3（算术基本定理 / 唯一分解定理）**：任何大于 1 的整数 `n` 都能**唯一**地（不计顺序）分解为素数之积：
`n = p₁^{a₁} · p₂^{a₂} · … · pₖ^{aₖ}`
其中 `p₁ < p₂ < … < pₖ` 是素数，`aᵢ ≥ 1`。

**定理 11.4（素数有无穷多个，欧几里得证明）**：
**证明（反证法）**：假设素数只有有限个，设为 `p₁, p₂, …, pₙ`。
构造 `N = p₁p₂…pₙ + 1`。
由算术基本定理，N 有素因数。设 p 是 N 的一个素因数。由假设，`p = pᵢ` 对某个 i 成立。
但 `pᵢ | p₁p₂…pₙ`，且 `pᵢ | N`（因 p = pᵢ 是 N 的因数），故 `pᵢ | (N − p₁p₂…pₙ) = 1`。
即 `pᵢ | 1`，这与 `pᵢ ≥ 2` 矛盾。
故素数有无穷多个 ✓ ∎

**定理 11.5（埃拉托斯特尼筛法原理）**：若 `n` 是合数，则 n 必有不超过 `√n` 的素因数。
**为什么**：设 `n = ab`，`1 < a ≤ b < n`。则 `a ≤ √n`（否则 `ab > √n·√n = n`，矛盾）。而 a 有素因数 `p ≤ a ≤ √n`，且 `p | a | n` ✓

**用途**：判断 n 是否为素数，只需用不超过 `√n` 的素数去试除。**例**：判断 101 是否为素数，只需试 `2, 3, 5, 7`（因 `√101 ≈ 10`，也可试 11 之前的所有素数）。`101` 不被 2, 3, 5, 7 整除，故 101 是素数 ✓

## 11.2 最大公因数与最小公倍数

### 11.2.1 最大公因数

**定义 11.3（最大公因数）**：设 `a, b` 是不全为 0 的整数。`a` 和 `b` 的**公因数**中最大的一个称为**最大公因数（Greatest Common Divisor）**，记作 `gcd(a, b)` 或 `(a, b)`。

若 `gcd(a, b) = 1`，则称 `a` 与 `b` **互素（互质，Coprime）**。

**求法 1（素因数分解法）**：`a = p₁^{α₁}…pₖ^{αₖ}`，`b = p₁^{β₁}…pₖ^{βₖ}`（指数可为 0），则
`gcd(a, b) = p₁^{min(α₁,β₁)} · … · pₖ^{min(αₖ,βₖ)}`

**例**：`a = 2³ · 3² · 5 = 360`，`b = 2² · 3³ · 7 = 756`。
`gcd = 2^min(3,2) · 3^min(2,3) = 2² · 3² = 36` ✓

> **缺点**：素因数分解对大整数极难（这正是 RSA 安全性的来源），故实际计算用**欧几里得算法**。

### 11.2.2 ★ 欧几里得算法（辗转相除法）

**引理 11.1**：若 `a = bq + r`，则 `gcd(a, b) = gcd(b, r)`。
**证明**：设 `d | a` 且 `d | b`。则 `d | (a − bq) = r`，故 d 也是 b 和 r 的公因数。
反之，设 `d | b` 且 `d | r`。则 `d | (bq + r) = a`，故 d 也是 a 和 b 的公因数。
故 a, b 的公因数集合 = b, r 的公因数集合，特别地最大公因数相同 ✓ ∎

**★ 欧几里得算法（Euclidean Algorithm）**：
```
输入：非负整数 a, b（a ≥ b，b ≠ 0）
输出：gcd(a, b)

反复做带余除法：
  a = b·q₁ + r₁      (0 ≤ r₁ < b)
  b = r₁·q₂ + r₂     (0 ≤ r₂ < r₁)
  r₁ = r₂·q₃ + r₃    (0 ≤ r₃ < r₂)
  …
  r_{n−2} = r_{n−1}·q_n + r_n
  r_{n−1} = r_n·q_{n+1} + 0     ← 余数为 0 时停止
则  gcd(a, b) = r_n   （最后一个非零余数）
```

**为什么正确**：由引理 11.1，每一步 `gcd` 都不变：`gcd(a,b) = gcd(b,r₁) = gcd(r₁,r₂) = … = gcd(r_{n−1}, r_n) = gcd(r_n, 0) = r_n` ✓
**为什么有限步停止**：余数序列 `r₁ > r₂ > … ≥ 0` **严格递减**且非负，故必在有限步内到达 0 ✓

**★ 完整算例**：求 `gcd(1071, 462)`。
```
1071 = 462 × 2 + 147       (1071 − 924 = 147)
 462 = 147 × 3 + 21        (462 − 441 = 21)
 147 =  21 × 7 + 0         ← 余数为 0，停止
```
**答案**：`gcd(1071, 462) = 21` ✓

**★ 例**：求 `gcd(12345, 678)`。
```
12345 = 678 × 18 + 141     (678 × 18 = 12204；12345 − 12204 = 141)
  678 = 141 × 4 + 114      (141 × 4 = 564；678 − 564 = 114)
  141 = 114 × 1 + 27
  114 =  27 × 4 + 6
   27 =   6 × 4 + 3
    6 =   3 × 2 + 0        ← 停止
```
**答案**：`gcd(12345, 678) = 3` ✓

**复杂度**：欧几里得算法的步数是 `O(log min(a,b))`（拉梅定理：步数不超过较小数的十进制位数的 5 倍）。

### 11.2.3 ★ 贝祖等式（扩展欧几里得算法）

**定理 11.6（贝祖等式 / Bézout's Identity）**：设 `d = gcd(a, b)`，则存在整数 `s, t` 使
`s·a + t·b = d`

**特别地**：`gcd(a, b) = 1` ⟺ 存在整数 `s, t` 使 `sa + tb = 1`。

**求法（扩展欧几里得算法 / 回代法）**：把欧几里得算法的每一步**反着代回去**。

**★ 完整算例**：求 `gcd(1071, 462)` 的贝祖等式。
**第 1 步**：写出欧几里得过程（保留余数表达式）
```
1071 = 462 × 2 + 147   ⟹  147 = 1071 − 2 × 462
 462 = 147 × 3 +  21   ⟹   21 = 462 − 3 × 147
 147 =  21 × 7 +   0
```
**第 2 步**：从倒数第二步开始回代
```
21 = 462 − 3 × 147
   = 462 − 3 × (1071 − 2 × 462)          ← 代入 147
   = 462 − 3 × 1071 + 6 × 462
   = 7 × 462 − 3 × 1071                   ← 合并同类项
```
**答案**：`21 = (−3) × 1071 + 7 × 462`，即 `s = −3`，`t = 7` ✓
**验证**：`(−3)(1071) + 7(462) = −3213 + 3234 = 21` ✓

**★ 应用（解一次同余方程的钥匙）**：若 `gcd(a, m) = 1`，则 `a` 在模 m 下的**逆元**存在：
由 `sa + tm = 1` 得 `sa ≡ 1 (mod m)`，故 `a⁻¹ ≡ s (mod m)` ✓

### 11.2.4 最小公倍数

**定义 11.4（最小公倍数）**：`a, b` 的**公倍数**中最小的正数称为**最小公倍数（Least Common Multiple）**，记作 `lcm(a, b)` 或 `[a, b]`。

**求法**：`lcm(a, b) = p₁^{max(α₁,β₁)} … pₖ^{max(αₖ,βₖ)}`

**★ 重要关系**：`gcd(a, b) · lcm(a, b) = a · b`
**证明**：`min(α,β) + max(α,β) = α + β`，逐素数相乘即得 ✓

**注意**：这只对**两个数**成立！`gcd(a,b,c) · lcm(a,b,c) ≠ abc`（一般情形）。

**例**：`a = 360, b = 756`。`gcd = 36`，故 `lcm = 360 × 756 / 36 = 272160 / 36 = 7560` ✓

## 11.3 同余

### 11.3.1 同余的定义与性质

**定义 11.5（同余）**：设 `m` 是正整数。若 `m | (a − b)`，则称 `a` 与 `b` **模 m 同余**，记作
`a ≡ b (mod m)`
否则称 a 与 b 模 m 不同余，记作 `a ≢ b (mod m)`。`m` 称为**模**。

**等价刻画**：以下三条等价
1. `a ≡ b (mod m)`
2. `m | (a − b)`
3. `a` 与 `b` 除以 m 的**余数相同**

**定理 11.7（同余的性质）**：设 `a ≡ b (mod m)`，`c ≡ d (mod m)`，则
| 编号 | 性质 |
|---|---|
| 1 | `a + c ≡ b + d (mod m)`（**可加**） |
| 2 | `a − c ≡ b − d (mod m)`（**可减**） |
| 3 | `a · c ≡ b · d (mod m)`（**可乘**） |
| 4 | `aⁿ ≡ bⁿ (mod m)`（n 是正整数，**可乘方**） |
| 5 | `f(a) ≡ f(b) (mod m)`（f 是整系数多项式） |
| 6 | 若 `c > 0`，则 `ac ≡ bc (mod mc)` |
| 7 | **若 `ac ≡ bc (mod m)` 且 `gcd(c, m) = 1`，则 `a ≡ b (mod m)`**（**可除，但要求互素**） |

> **第 7 条是最大的陷阱**：**同余式两边不能随便约**！必须要求约掉的数与模**互素**。
> **反例**：`2 × 3 ≡ 4 × 3 (mod 6)`（即 `6 ≡ 12 (mod 6)` ✓ 成立），但 `2 ≢ 4 (mod 6)` ✗。
> 原因：`gcd(3, 6) = 3 ≠ 1` ✓
> **正确的约法**：若 `ac ≡ bc (mod m)`，则 `a ≡ b (mod m/gcd(c,m))`。

**★ 性质 1+3 的证明**：
由 `m | (a−b)` 和 `m | (c−d)`。则 `m | [(a−b) + (c−d)] = (a+c) − (b+d)`，即 `a+c ≡ b+d (mod m)` ✓
对乘法：`ac − bd = ac − bc + bc − bd = c(a−b) + b(c−d)`。因 `m | (a−b)` 和 `m | (c−d)`，故 `m | (ac − bd)` ✓ ∎

**推论**：同余**可以像等式一样做加减乘和乘方**（但不能随便除）。这是「求大数幂的余数」的理论基础。

### 11.3.2 同余类与剩余系

**定义 11.6（同余类 / 剩余类）**：模 m 下与整数 a 同余的所有整数构成的集合
`[a]_m = {x ∈ Z | x ≡ a (mod m)} = {a + km | k ∈ Z}`
称为 a 的**模 m 同余类**（或剩余类）。

**性质**：模 m 的同余类恰好有 **m 个**：`[0]_m, [1]_m, …, [m−1]_m`。
模 m 的所有同余类构成集合 `Z_m = {[0], [1], …, [m−1]}`，称为**模 m 的剩余类集**。

**定义 11.7（完全剩余系）**：从模 m 的每个同余类中各取一个数，得到的 m 个数称为模 m 的一个**完全剩余系（Complete Residue System）**。
**例**：`{0, 1, 2, …, m−1}` 和 `{1, 2, …, m}` 都是模 m 的完全剩余系。

**定义 11.8（简化剩余系）**：从模 m 的每个与 m **互素**的同余类中各取一个数，得到的数集称为模 m 的**简化剩余系（Reduced Residue System）**。其元素个数就是 `φ(m)`。

**同余类的加法与乘法**：
`[a] + [b] = [a + b]`，`[a] · [b] = [a · b]`
（**必须验证定义无矛盾**：若 `[a] = [a']`、`[b] = [b']`，则 `[a+b] = [a'+b']` ✓ 这由定理 11.7 保证。）

### 11.3.3 一次同余方程

**定义 11.9（一次同余方程）**：形如
`ax ≡ b (mod m)`
的方程，其中 `a ≢ 0 (mod m)`。

**定理 11.8（解的判定与个数）**：设 `d = gcd(a, m)`。
- 若 `d ∤ b`，则方程**无解**；
- 若 `d | b`，则方程恰有 **d 个**模 m 的不同解。

**★ 求解步骤（当 `d | b` 时）**：
```
第 1 步：两边同时除以 d，把模也除以 d：
        (a/d)x ≡ (b/d) (mod m/d)
        此时 gcd(a/d, m/d) = 1，新方程与原方程同解
第 2 步：求逆元 —— 用扩展欧几里得算法求 (a/d) 模 (m/d) 的逆元
        由 s·(a/d) + t·(m/d) = 1 得 (a/d)⁻¹ ≡ s (mod m/d)
第 3 步：解出 x ≡ (b/d)·s (mod m/d)
        这是模 m/d 的一个解，模 m 下展开成 d 个解：
        x₀, x₀ + (m/d), x₀ + 2(m/d), …, x₀ + (d−1)(m/d)
```

**★ 例 1**：解 `7x ≡ 5 (mod 11)`。
**解**：`gcd(7, 11) = 1`，且 `1 | 5`，故有**唯一解**（模 11 下）。
求 7 模 11 的逆元：试 `7 × 8 = 56 = 5 × 11 + 1 ≡ 1 (mod 11)`，故 `7⁻¹ ≡ 8`。
两边乘 8：`x ≡ 5 × 8 = 40 ≡ 40 − 33 = 7 (mod 11)`。
**答案**：`x ≡ 7 (mod 11)` ✓
**验证**：`7 × 7 = 49 = 4 × 11 + 5 ≡ 5 (mod 11)` ✓

**★ 例 2（有多解）**：解 `6x ≡ 9 (mod 15)`。
**解**：`gcd(6, 15) = 3`，且 `3 | 9` ✓，故有 **3 个**解（模 15 下）。
两边除以 3：`2x ≡ 3 (mod 5)`。
求 2 模 5 的逆元：`2 × 3 = 6 ≡ 1 (mod 5)`，故 `2⁻¹ ≡ 3`。
`x ≡ 3 × 3 = 9 ≡ 4 (mod 5)`。
展开成模 15 的 3 个解：`x ≡ 4, 4+5, 4+10 (mod 15)`，即
**答案**：`x ≡ 4, 9, 14 (mod 15)` ✓
**验证**：`x=4`：`6×4 = 24 = 15 + 9 ≡ 9` ✓；`x=9`：`54 = 45 + 9 ≡ 9` ✓；`x=14`：`84 = 75 + 9 ≡ 9` ✓

**★ 例 3（无解）**：解 `4x ≡ 5 (mod 6)`。
**解**：`gcd(4, 6) = 2`，但 `2 ∤ 5`，故**无解** ✓
**为什么**：`4x` 永远是偶数，而 `5` 是奇数，模 6 下不可能同余。

### 11.3.4 ★ 中国剩余定理

**定理 11.9（中国剩余定理 / 孙子定理 / CRT）**：
设 `m₁, m₂, …, mₖ` **两两互素**，则同余方程组
```
x ≡ a₁ (mod m₁)
x ≡ a₂ (mod m₂)
   ⋮
x ≡ aₖ (mod mₖ)
```
在模 `M = m₁m₂…mₖ` 下有**唯一解**。

**★ 求解步骤（构造法）**：
```
第 1 步：计算 M = m₁m₂…mₖ
第 2 步：对每个 i，计算 Mᵢ = M / mᵢ
第 3 步：对每个 i，求 Mᵢ 模 mᵢ 的逆元 yᵢ，即 Mᵢ·yᵢ ≡ 1 (mod mᵢ)
第 4 步：x ≡ Σ_{i=1}^{k} aᵢ·Mᵢ·yᵢ (mod M)
```

**为什么正确**：对第 j 个方程验证：当 `i ≠ j` 时，`mⱼ | Mᵢ`（因 `Mᵢ = M/mᵢ` 含因子 `mⱼ`），故 `Mᵢ ≡ 0 (mod mⱼ)`。
所以 `x ≡ aⱼ·Mⱼ·yⱼ ≡ aⱼ·1 = aⱼ (mod mⱼ)` ✓（用了 `Mⱼyⱼ ≡ 1 (mod mⱼ)`）

**★ 完整算例（孙子算经「物不知数」）**：
```
x ≡ 2 (mod 3)
x ≡ 3 (mod 5)
x ≡ 2 (mod 7)
```
**第 1 步**：`M = 3 × 5 × 7 = 105`
**第 2 步**：`M₁ = 105/3 = 35`，`M₂ = 105/5 = 21`，`M₃ = 105/7 = 15`
**第 3 步**：求逆元
- `M₁ = 35 ≡ 2 (mod 3)`：`2y₁ ≡ 1 (mod 3)`，`2×2 = 4 ≡ 1`，故 `y₁ = 2`
- `M₂ = 21 ≡ 1 (mod 5)`：`1·y₂ ≡ 1`，故 `y₂ = 1`
- `M₃ = 15 ≡ 1 (mod 7)`：`1·y₃ ≡ 1`，故 `y₃ = 1`
**第 4 步**：
`x ≡ a₁M₁y₁ + a₂M₂y₂ + a₃M₃y₃ = 2×35×2 + 3×21×1 + 2×15×1`
`= 140 + 63 + 30 = 233`
`233 mod 105 = 233 − 210 = 23`

**答案**：`x ≡ 23 (mod 105)` ✓
**验证**：
- `23 mod 3 = 2` ✓
- `23 mod 5 = 3` ✓
- `23 mod 7 = 2` ✓
（这正是「韩信点兵」问题：23 是满足条件的最小正整数。）

**★ 例 2**：解
```
x ≡ 1 (mod 2)
x ≡ 2 (mod 3)
x ≡ 3 (mod 5)
```
**解**：`M = 2×3×5 = 30`；`M₁ = 15, M₂ = 10, M₃ = 6`。
逆元：
- `15 ≡ 1 (mod 2)` → `y₁ = 1`
- `10 ≡ 1 (mod 3)` → `y₂ = 1`
- `6 ≡ 1 (mod 5)` → `y₃ = 1`

`x ≡ 1×15×1 + 2×10×1 + 3×6×1 = 15 + 20 + 18 = 53 ≡ 53 − 30 = 23 (mod 30)`
**答案**：`x ≡ 23 (mod 30)` ✓（验证：`23 mod 2 = 1` ✓，`23 mod 3 = 2` ✓，`23 mod 5 = 3` ✓）

**★ 与拉格朗日插值的类比**：中国剩余定理的本质是「**用互素的模把整体信息拆成若干片段**」，这与多项式插值（用多个点的值确定多项式）是同构的思想——都体现了「**局部信息拼成整体**」的数学结构。RSA 与秘密共享（Shamir 方案）都依赖它。

## 11.4 欧拉定理与费马小定理

### 11.4.1 欧拉函数

**定义 11.10（欧拉函数）**：`φ(n)` 表示 `1` 到 `n` 中与 `n` **互素**的整数个数（`n ≥ 1`）。

**★ 计算公式**：若 `n = p₁^{a₁} p₂^{a₂} … pₖ^{aₖ}`（素因数分解），则
`φ(n) = n · (1 − 1/p₁)(1 − 1/p₂) … (1 − 1/pₖ)`

**特例**：
- `φ(1) = 1`
- 若 p 是素数：`φ(p) = p − 1`
- 若 `gcd(m,n) = 1`：`φ(mn) = φ(m)·φ(n)`（**积性**）
- `φ(p^k) = p^k − p^{k−1} = p^(k−1)(p−1)`

**★ 例**：
- `φ(12)`：`12 = 2² × 3`，`φ(12) = 12 × (1−1/2)(1−1/3) = 12 × 1/2 × 2/3 = 4` ✓
  （验证：与 12 互素的数是 `1, 5, 7, 11`，共 4 个 ✓）
- `φ(30)`：`30 = 2×3×5`，`φ(30) = 30 × 1/2 × 2/3 × 4/5 = 8` ✓（`1,7,11,13,17,19,23,29`）
- `φ(100) = φ(2²·5²) = 100 × 1/2 × 4/5 = 40` ✓

**为什么公式正确（用容斥原理）**：设 `Aᵢ` = 「能被 `pᵢ` 整除」的数。`1` 到 `n` 中与 n 互素的数就是**不被任何 `pᵢ` 整除**的数。
`|Aᵢ| = n/pᵢ`，`|Aᵢ∩Aⱼ| = n/(pᵢpⱼ)`，…
由**容斥原理**（补集形式，见第 10 章）：
`φ(n) = n − Σ n/pᵢ + Σ n/(pᵢpⱼ) − … = n(1 − 1/p₁)(1 − 1/p₂)…(1 − 1/pₖ)` ✓

### 11.4.2 ★ 欧拉定理

**定理 11.10（欧拉定理 / Euler's Theorem）**：设 `m ≥ 2`，`gcd(a, m) = 1`，则
`a^(φ(m)) ≡ 1 (mod m)`

**证明思路**：设 `r₁, r₂, …, r_{φ(m)}` 是模 m 的一个**简化剩余系**。
因 `gcd(a, m) = 1`，则 `ar₁, ar₂, …, ar_{φ(m)}` 也构成一个简化剩余系（**关键：a 与 m 互素保证乘法是「一一对应」的置换**）。
两个简化剩余系的元素之积模 m 同余：
`(ar₁)(ar₂)…(ar_{φ(m)}) ≡ r₁r₂…r_{φ(m)} (mod m)`
即 `a^{φ(m)} · (r₁r₂…r_{φ(m)}) ≡ r₁r₂…r_{φ(m)} (mod m)`
因每个 `rᵢ` 与 m 互素，故 `gcd(r₁r₂…r_{φ(m)}, m) = 1`，**可以约掉**（用定理 11.7 第 7 条）：
`a^{φ(m)} ≡ 1 (mod m)` ✓ ∎

### 11.4.3 ★ 费马小定理

**定理 11.11（费马小定理 / Fermat's Little Theorem）**：设 p 是素数，`gcd(a, p) = 1`，则
`a^(p−1) ≡ 1 (mod p)`

**更一般的形式（不要求互素）**：对任意整数 a 和素数 p，
`a^p ≡ a (mod p)`

**为什么**：欧拉定理中取 `m = p`（素数），则 `φ(p) = p − 1`，直接得 `a^(p−1) ≡ 1 (mod p)` ✓
一般形式：若 `p | a`，则 `a^p ≡ a ≡ 0 (mod p)` ✓；若 `p ∤ a`，则由上式两边乘 a 得 `a^p ≡ a (mod p)` ✓

**★ 应用 1（求大数幂的余数）**：求 `3^100 mod 7`。
**解**：`p = 7` 是素数，`gcd(3, 7) = 1`。
由费马小定理：`3^6 ≡ 1 (mod 7)`。
把指数按 6 分解：`100 = 6 × 16 + 4`。
`3^100 = (3^6)^16 · 3^4 ≡ 1^16 · 3^4 = 81 ≡ 81 − 77 = 4 (mod 7)`。
**答案**：**4** ✓
**验证**：`3^1=3, 3^2=9≡2, 3^3≡6, 3^4≡4, 3^5≡5, 3^6≡1`（循环长度 6 ✓），`100 mod 6 = 4`，故 `3^100 ≡ 3^4 ≡ 4` ✓

**★ 应用 2**：求 `7^222 mod 11`。
**解**：`φ(11) = 10`，由费马小定理 `7^10 ≡ 1 (mod 11)`。
`222 = 10 × 22 + 2`。
`7^222 = (7^10)^22 · 7^2 ≡ 7^2 = 49 ≡ 49 − 44 = 5 (mod 11)`。
**答案**：**5** ✓

**★ 应用 3（用欧拉定理）**：求 `3^200 mod 10`。
**解**：`gcd(3, 10) = 1`，`φ(10) = φ(2·5) = 10 × 1/2 × 4/5 = 4`。
由欧拉定理 `3^4 ≡ 1 (mod 10)`（验证：`81 ≡ 1 (mod 10)` ✓）。
`200 = 4 × 50`，故 `3^200 = (3^4)^50 ≡ 1 (mod 10)`。
**答案**：**1** ✓
（直观：`3^1=3, 3^2=9, 3^3=27≡7, 3^4≡1`，周期 4，`200 mod 4 = 0`，故为 1 ✓）

**★ 应用 4（费马小定理的逆否命题用于排除素数）**：
若存在 a 使 `a^(p−1) ≢ 1 (mod p)`，则 p **一定不是素数**。
**例**：检验 `n = 21`。取 `a = 2`：`2^20 mod 21`？
`2^6 = 64 ≡ 1 (mod 21)`（`64 − 63 = 1`），故 `2^20 = 2^(6×3+2) ≡ 2^2 = 4 ≢ 1 (mod 21)`。
**结论**：21 不是素数 ✓（这是**费马素性检验**的思想，也是 Miller-Rabin 检验的基础。）
**注意**：逆命题不成立——存在**卡迈克尔数**（如 561 = 3×11×17）使所有与它互素的 a 都满足 `a^(n−1) ≡ 1 (mod n)`，但 n 是合数。

## 11.5 数论的应用：RSA 公钥密码

### 11.5.1 RSA 的基本原理

**核心思想（一句话）**：**「加密容易，解密也容易（有钥匙）；但只有公钥时逆向解密极难」**——难在**大整数分解**。

**★ RSA 密钥生成流程**：
```
第 1 步：选两个大素数 p 和 q（各约 512 位以上），计算 n = p × q
第 2 步：计算欧拉函数 φ(n) = (p−1)(q−1)
第 3 步：选一个整数 e，使 1 < e < φ(n) 且 gcd(e, φ(n)) = 1
        （e 通常取 65537 = 2^16 + 1）
第 4 步：求 d 使 e·d ≡ 1 (mod φ(n))
        （用扩展欧几里得算法求 e 模 φ(n) 的逆元）
第 5 步：公钥 = (n, e)，私钥 = (n, d)。p, q, φ(n) 必须销毁
```

**★ 加密与解密**：
- **加密**：把明文转成整数 `M`（`0 ≤ M < n`），计算密文 `C = M^e mod n`
- **解密**：计算 `M = C^d mod n`

**★ 为什么能解密（正确性）**：
要证 `C^d = (M^e)^d = M^(ed) ≡ M (mod n)`。
由 `ed ≡ 1 (mod φ(n))`，存在 k 使 `ed = 1 + kφ(n) = 1 + k(p−1)(q−1)`。
**情形 1**：`gcd(M, p) = 1`。由**费马小定理** `M^(p−1) ≡ 1 (mod p)`，故
`M^(ed) = M · (M^(p−1))^(k(q−1)) ≡ M · 1 = M (mod p)` ✓
**情形 2**：`p | M`。则 `M ≡ 0 (mod p)`，且 `M^(ed) ≡ 0 ≡ M (mod p)` ✓
故恒有 `M^(ed) ≡ M (mod p)`。**同理** `M^(ed) ≡ M (mod q)`。
因 `gcd(p, q) = 1`，由中国剩余定理（或直接由 `p | (M^(ed) − M)` 且 `q | (M^(ed) − M)`，且 p, q 互素 ⟹ `pq = n | (M^(ed) − M)`）：
`M^(ed) ≡ M (mod n)` ✓ ∎

**★ 安全性来源**：
- 敌人知道 `(n, e)`，要算出 d 必须先知道 `φ(n) = (p−1)(q−1)`，而这需要**分解 n**。
- 目前分解 2048 位（约 617 位十进制）的整数在计算上不可行——这就是 RSA 的安全基础。
- **若大整数分解被破解（如量子计算机的 Shor 算法），RSA 就失效了。**

**★ 小数值算例（教学用，实际不可用）**：
选 `p = 3, q = 11` → `n = 33`，`φ(n) = 2 × 10 = 20`。
取 `e = 3`（`gcd(3, 20) = 1` ✓）。
求 d：`3d ≡ 1 (mod 20)`。`3 × 7 = 21 ≡ 1 (mod 20)`，故 `d = 7`。
**公钥 = (33, 3)，私钥 = (33, 7)**。

加密 `M = 5`：`C = 5³ mod 33 = 125 mod 33 = 125 − 99 = 26`。
解密 `C = 26`：`26^7 mod 33`。
计算：`26 ≡ −7 (mod 33)`，故 `26^7 ≡ (−7)^7 = −7^7 (mod 33)`。
`7^2 = 49 ≡ 16`，`7^4 ≡ 16^2 = 256 ≡ 256 − 231 = 25`，`7^7 = 7^4 · 7^2 · 7 ≡ 25 × 16 × 7 = 2800`。
`2800 mod 33`：`33 × 84 = 2772`，`2800 − 2772 = 28`。
故 `26^7 ≡ −28 ≡ 33 − 28 = 5 (mod 33)` ✓ **成功恢复 M = 5** ✓

### 11.5.2 素性检验

**问题**：RSA 需要随机生成大素数，如何快速判断一个大数是否为素数？

**方法 1（试除法）**：用不超过 `√n` 的素数试除。
**问题**：对 512 位的 n，`√n` 有 256 位——不可行。

**方法 2（费马素性检验）**：随机取若干 a，检验 `a^(n−1) ≡ 1 (mod n)`。
- 若某次不成立 → n **一定合数**；
- 若多次都成立 → n **很可能是素数**（概率性判定）。
**漏洞**：卡迈克尔数会骗过检验（如 561, 1105, 1729）。

**方法 3（Miller-Rabin 检验）**：更强的概率性检验，错误率 < `4^(−k)`（k 是测试轮数），实践中广泛使用。

**方法 4（AKS 素性检验，2002）**：第一个**确定性多项式时间**的素性检验算法，理论意义重大，但实际较慢。

## 典型例题

**例 11.1**（题型：整除与带余除法）
设 `a = −100`，`b = 7`。求带余除法中的商 q 和余数 r。并判断：`7 | −100` 吗？
**解**：需要 `−100 = 7q + r`，且 `0 ≤ r < 7`。
`−100 = 7 × (−15) + 5`（验证：`7 × (−15) = −105`，`−105 + 5 = −100` ✓，且 `0 ≤ 5 < 7` ✓）
故 **`q = −15`，`r = 5`**。
因余数 `r = 5 ≠ 0`，故 **`7 ∤ −100`** ✓
**易错提醒**：不能写成 `−100 = 7 × (−14) + (−2)`，因为余数必须**非负**。

**例 11.2**（题型：欧几里得算法与贝祖等式）
求 `gcd(252, 105)`，并求整数 s, t 使 `252s + 105t = gcd(252, 105)`。
**解**：
**第 1 步（欧几里得算法）**：
```
252 = 105 × 2 + 42
105 =  42 × 2 + 21
 42 =  21 × 2 + 0      ← 停止
```
故 `gcd(252, 105) = 21` ✓
**第 2 步（回代求贝祖等式）**：
```
21 = 105 − 42 × 2                          ← 从 105 = 42×2 + 21 得
   = 105 − (252 − 105 × 2) × 2             ← 代入 42 = 252 − 105×2
   = 105 − 252 × 2 + 105 × 4
   = 105 × 5 − 252 × 2
```
**答案**：`gcd(252, 105) = 21`，且 `21 = (−2) × 252 + 5 × 105`，即 `s = −2, t = 5` ✓
**验证**：`−504 + 525 = 21` ✓

**例 11.3**（题型：解一次同余方程）
解下列同余方程：
(1) `5x ≡ 3 (mod 7)`
(2) `9x ≡ 6 (mod 12)`
(3) `8x ≡ 5 (mod 12)`
**解**：
(1) `gcd(5, 7) = 1`，`1 | 3` ✓，有唯一解。
求 5 模 7 的逆元：`5 × 3 = 15 ≡ 1 (mod 7)`，故 `5⁻¹ ≡ 3`。
`x ≡ 3 × 3 = 9 ≡ 2 (mod 7)`。
**答案**：`x ≡ 2 (mod 7)` ✓（验证：`5 × 2 = 10 ≡ 3` ✓）
(2) `gcd(9, 12) = 3`，`3 | 6` ✓，有 **3 个**解。
两边除以 3：`3x ≡ 2 (mod 4)`。
求 3 模 4 的逆元：`3 × 3 = 9 ≡ 1 (mod 4)`，故 `3⁻¹ ≡ 3`。
`x ≡ 2 × 3 = 6 ≡ 2 (mod 4)`。
展开成模 12 的 3 个解：`x ≡ 2, 2+4, 2+8 (mod 12)`。
**答案**：`x ≡ 2, 6, 10 (mod 12)` ✓
（验证 `x=2`：`9×2 = 18 = 12 + 6 ≡ 6` ✓；`x=6`：`54 = 48 + 6 ≡ 6` ✓；`x=10`：`90 = 84 + 6 ≡ 6` ✓）
(3) `gcd(8, 12) = 4`，但 `4 ∤ 5`，故**无解** ✓
（**为什么**：`8x` 必是 4 的倍数，故 `8x mod 12` 只能是 `4` 的倍数，不可能等于 5。）

**例 11.4**（题型：中国剩余定理）
解同余方程组
```
x ≡ 1 (mod 3)
x ≡ 2 (mod 4)
x ≡ 3 (mod 5)
```
**解**：`3, 4, 5` 两两互素 ✓
**第 1 步**：`M = 3 × 4 × 5 = 60`
**第 2 步**：`M₁ = 60/3 = 20`，`M₂ = 60/4 = 15`，`M₃ = 60/5 = 12`
**第 3 步**：求逆元
- `M₁ = 20 ≡ 2 (mod 3)`：解 `2y₁ ≡ 1 (mod 3)` → `y₁ = 2`（因 `2×2 = 4 ≡ 1`）
- `M₂ = 15 ≡ 3 (mod 4)`：解 `3y₂ ≡ 1 (mod 4)` → `y₂ = 3`（因 `3×3 = 9 ≡ 1`）
- `M₃ = 12 ≡ 2 (mod 5)`：解 `2y₃ ≡ 1 (mod 5)` → `y₃ = 3`（因 `2×3 = 6 ≡ 1`）
**第 4 步**：
`x ≡ 1×20×2 + 2×15×3 + 3×12×3 = 40 + 90 + 108 = 238`
`238 mod 60`：`60 × 3 = 180`，`238 − 180 = 58`
**答案**：`x ≡ 58 (mod 60)` ✓
**验证**：
- `58 mod 3 = 1`（`57 = 3×19`）✓
- `58 mod 4 = 2`（`56 = 4×14`）✓
- `58 mod 5 = 3`（`55 = 5×11`）✓

**例 11.5**（题型：欧拉函数）
求 `φ(1000)`、`φ(72)`、`φ(97)`。
**解**：
- `1000 = 2³ × 5³`
  `φ(1000) = 1000 × (1 − 1/2)(1 − 1/5) = 1000 × 1/2 × 4/5 = 400` ✓

**例 11.6**（题型：欧拉定理与费马小定理）
(1) 求 `2^1000 mod 13`。
(2) 求 `3^201 mod 17`。
(3) 求 `5^123 mod 21`。
**解**：
(1) `13` 是素数，`gcd(2, 13) = 1`，由费马小定理 `2^12 ≡ 1 (mod 13)`。
`1000 = 12 × 83 + 4`。
`2^1000 = (2^12)^83 · 2^4 ≡ 2^4 = 16 ≡ 3 (mod 13)`。
**答案**：**3** ✓
（验证：`2^4 = 16`，`16 − 13 = 3` ✓）
(2) `17` 是素数，`3^16 ≡ 1 (mod 17)`。
`201 = 16 × 12 + 9`。
`3^201 ≡ 3^9 (mod 17)`。
逐步计算：`3^2 = 9`，`3^4 = 81 ≡ 81 − 68 = 13`，`3^8 ≡ 13^2 = 169`，`169 − 153 = 16 ≡ −1`。
`3^9 = 3^8 · 3 ≡ (−1) × 3 = −3 ≡ 14 (mod 17)`。
**答案**：**14** ✓
(3) `21 = 3 × 7`，`gcd(5, 21) = 1`，`φ(21) = 21 × 2/3 × 6/7 = 12`。
由欧拉定理 `5^12 ≡ 1 (mod 21)`。
`123 = 12 × 10 + 3`。
`5^123 ≡ 5^3 = 125 (mod 21)`。`125 = 21 × 5 + 20`，故 `≡ 20 (mod 21)`。
**答案**：**20** ✓
（验证：`5^3 = 125`，`125 mod 21 = 125 − 105 = 20` ✓）

**例 11.7**（题型：RSA 加解密计算）
设 RSA 的参数为 `p = 5, q = 11, e = 3`。
(1) 求公钥与私钥；
(2) 加密明文 `M = 9`；
(3) 解密密文。
**解**：
(1) `n = 5 × 11 = 55`，`φ(n) = 4 × 10 = 40`。
验证 `gcd(e, φ(n)) = gcd(3, 40) = 1` ✓
求 d：`3d ≡ 1 (mod 40)`。`3 × 27 = 81 = 2 × 40 + 1 ≡ 1 (mod 40)`，故 `d = 27`。
**答案**：公钥 `(55, 3)`，私钥 `(55, 27)` ✓
(2) `C = 9³ mod 55 = 729 mod 55`。`55 × 13 = 715`，`729 − 715 = 14`。
**答案**：密文 `C = 14` ✓
(3) `M = 14^27 mod 55`。
用「平方-乘」法逐步计算：
`14^2 = 196 ≡ 196 − 165 = 31 (mod 55)`
`14^4 ≡ 31^2 = 961`；`55 × 17 = 935`，`961 − 935 = 26`
`14^8 ≡ 26^2 = 676`；`55 × 12 = 660`，`676 − 660 = 16`
`14^16 ≡ 16^2 = 256`；`55 × 4 = 220`，`256 − 220 = 36`
而 `27 = 16 + 8 + 2 + 1`，故
`14^27 = 14^16 · 14^8 · 14^2 · 14 ≡ 36 × 16 × 31 × 14 (mod 55)`
逐步算：
- `36 × 16 = 576`；`55 × 10 = 550`，`576 − 550 = 26`
- `26 × 31 = 806`；`55 × 14 = 770`，`806 − 770 = 36`
- `36 × 14 = 504`；`55 × 9 = 495`，`504 − 495 = 9`

**答案**：`M = 9` ✓ **成功恢复明文！**

**例 11.8**（题型：综合应用）
(1) 证明：若 `a | b` 且 `a | c`，则对任意整数 m, n 有 `a | (mb + nc)`。
(2) 证明：任意三个连续整数之积必能被 6 整除。
**证明**：
(1) **（直接证明法）**
由 `a | b`，存在整数 `q₁` 使 `b = aq₁`。
由 `a | c`，存在整数 `q₂` 使 `c = aq₂`。
则 `mb + nc = m(aq₁) + n(aq₂) = a(mq₁ + nq₂)`。
因 `mq₁ + nq₂ ∈ Z`，故由整除定义 `a | (mb + nc)` ✓ ∎
(2) **（分情况证明法）**
设三个连续整数为 `n, n+1, n+2`。要证 `6 | n(n+1)(n+2)`，即证 `2 | 积` 且 `3 | 积`（因 `gcd(2,3)=1`）。
**证 2 整除**：n 与 n+1 中必有一个偶数（**分类讨论 n 的奇偶性**）：
- 若 n 偶，则 `2 | n`；
- 若 n 奇，则 `n+1` 偶，`2 | (n+1)`。
故 `2 | n(n+1)(n+2)` ✓
**证 3 整除**：任何整数 n 除以 3 的余数只能是 0, 1, 2（**分三种情况**）：
- 若 `n ≡ 0 (mod 3)`，则 `3 | n`；
- 若 `n ≡ 1 (mod 3)`，则 `n + 2 ≡ 3 ≡ 0 (mod 3)`，故 `3 | (n+2)`；
- 若 `n ≡ 2 (mod 3)`，则 `n + 1 ≡ 3 ≡ 0 (mod 3)`，故 `3 | (n+1)`。

三种情况都成立，故 `3 | n(n+1)(n+2)` ✓
**又证 2 与 3 互素**：`gcd(2,3) = 1`，故 `2 | 积` 且 `3 | 积` ⟹ `6 | 积` ✓ ∎

## 易错点提醒

1. **带余除法中余数写成负数**。错：`−17 = 5 × (−3) + (−2)`。正确：**余数必须满足 `0 ≤ r < b`**，`−17 = 5 × (−4) + 3`。
2. **整除符号与除法混淆**。错：把 `a | b` 当作「a 除以 b」。正确：**`a | b` 表示「a 整除 b」（a 是 b 的因数）**，读作「a divides b」。
3. **同余式两边随便约**。错：由 `6 ≡ 12 (mod 6)` 两边除以 2 得 `3 ≡ 6 (mod 6)`（这是对的），但由 `ac ≡ bc (mod m)` 直接得 `a ≡ b (mod m)`。正确：**必须 `gcd(c, m) = 1` 才能约**；否则只能约成 `a ≡ b (mod m/gcd(c,m))`。**反例：`2×3 ≡ 4×3 (mod 6)` 成立，但 `2 ≢ 4 (mod 6)`。**
4. **一次同余方程忘记检查 `d | b`**。错：解 `4x ≡ 5 (mod 6)` 时硬算。正确：**先算 `d = gcd(a, m)`，若 `d ∤ b` 则无解**。
5. **一次同余方程只给一个解**。错：`6x ≡ 9 (mod 15)` 只答 `x = 4`。正确：**有 `d = 3` 个解**：`x ≡ 4, 9, 14 (mod 15)`。
6. **中国剩余定理要求「两两互素」被忽略**。错：模为 `4, 6` 时直接套公式。正确：**必须先验证模两两互素**（`gcd(4,6) = 2 ≠ 1`，不能用；需先拆成 `4` 和 `3`）。
7. **余数的处理（CRT 计算后忘记取模 M）**。错：孙子算经问题答 `x = 233`。正确：**答案是 `x ≡ 23 (mod 105)`**，233 与 23 是同一同余类，但通常取最小正剩余。
8. **欧拉函数公式漏乘 n**。错：`φ(12) = (1−1/2)(1−1/3) = 1/3`。正确：**`φ(n) = n(1−1/p₁)…(1−1/pₖ)`，别忘了最前面的 n**：`φ(12) = 12 × 1/2 × 2/3 = 4`。
9. **`φ(n)` 的分解用错（把合数当素数）**。错：`φ(12) = 12(1−1/4)(1−1/3)`——4 不是素数！正确：**必须先做素因数分解** `12 = 2² × 3`，用**不同的素因子**（幂次不影响公式里的因子）。
10. **费马小定理忘记「p 必须是素数」**。错：对 `n = 21` 用 `2^20 ≡ 1 (mod 21)`。正确：**费马小定理只对素数成立**。对合数要用欧拉定理（`φ(21) = 12`）。
11. **求大数幂余数时指数算错**。错：`2^1000 mod 13` 时用 `1000 mod 13 = 12`。正确：**指数要模 `φ(m)`（或 `p−1`），不是模 m**：`1000 mod 12 = 4`。
12. **RSA 中 d 的求解方向搞反**。错：把 `e·d ≡ 1 (mod φ(n))` 写成 `e·d ≡ 1 (mod n)`。正确：**模是 `φ(n) = (p−1)(q−1)`，不是 n**。
13. **混淆 `gcd` 与 `lcm` 的 `min/max`**。错：`gcd` 取 `max`。正确：**`gcd` 取指数 `min`，`lcm` 取指数 `max`**。
14. **`gcd(a,b)·lcm(a,b) = ab` 错误推广到三个数**。错：认为 `gcd(a,b,c)·lcm(a,b,c) = abc`。正确：**这个公式只对两个数成立**。反例：`a=b=c=2` 时 `gcd=2, lcm=2`，`2×2 = 4 ≠ 8`。

## 本章小结

1. **整除的性质**：传递性、可加减、线性组合 `a | (mb + nc)`、`a|b ∧ b|a ⟹ a = ±b`。
2. **带余除法**：`a = bq + r`，`0 ≤ r < b` 且 **q, r 唯一**；**余数必须非负**。
3. **算术基本定理**：每个大于 1 的整数唯一分解为素数之积；**素数有无穷多个**（欧几里得反证法）。
4. **欧几里得算法**：`gcd(a,b) = gcd(b, r)` 反复迭代，最后一个非零余数即为 gcd；复杂度 `O(log min(a,b))`。
5. **贝祖等式**：存在 `s, t` 使 `sa + tb = gcd(a,b)`；**回代法**求得；用于求**模逆元**。
6. **`gcd(a,b)·lcm(a,b) = a·b`**（**只对两个数成立**）。
7. **同余**：`a ≡ b (mod m) ⟺ m | (a−b)`；可加、可减、可乘、可乘方，**但不能随便约（要 `gcd(c,m)=1`）**。
8. **一次同余方程 `ax ≡ b (mod m)`**：设 `d = gcd(a,m)`；`d ∤ b` 无解，`d | b` 时有 **d 个**解。
9. **中国剩余定理**：模**两两互素**时，同余方程组在模 `M = Πmᵢ` 下有**唯一解**；解法 `x = ΣaᵢMᵢyᵢ`，其中 `Mᵢ = M/mᵢ`，`yᵢ` 是 `Mᵢ` 模 `mᵢ` 的逆元。
10. **欧拉函数 `φ(n) = n(1−1/p₁)…(1−1/pₖ)`**（pᵢ 是 **n 的互不相同的素因子**）；`φ(p) = p−1`；积性 `φ(mn) = φ(m)φ(n)`（互素时）。
11. **欧拉定理**：`gcd(a,m)=1 ⟹ a^(φ(m)) ≡ 1 (mod m)`。**费马小定理**：p 素数、`p ∤ a` 时 `a^(p−1) ≡ 1 (mod p)`。**求大数幂余数时，指数要模 `φ(m)`**。
12. **RSA**：`n = pq`，`φ(n) = (p−1)(q−1)`，公钥 `(n,e)`，私钥 `(n,d)` 其中 `ed ≡ 1 (mod φ(n))`；加密 `C = M^e mod n`，解密 `M = C^d mod n`。安全性基于**大整数分解的困难性**。

> **一句话记住本章**：**「辗转相除求最大公因数，回代得到贝祖等式；同余能加减乘方但不能随便约；中国剩余定理把碎片拼回整体；欧拉定理让指数先模 φ(m)，这就是 RSA 的魔法。」**
