## 5.1 有序对与笛卡儿积

### 5.1.1 有序对

**定义 5.1（有序对）**：由两个元素 x 和 y 按**固定顺序**组成的二元组称为**有序对（Ordered Pair）**，记 `⟨x, y⟩`。其中 x 是**第一元素**，y 是**第二元素**。

**有序对的核心特征**：
`⟨x, y⟩ = ⟨u, v⟩ ⟺ x = u 且 y = v`

> **重点**：这就是「有序」的含义——`⟨1, 2⟩ ≠ ⟨2, 1⟩`，而集合 `{1, 2} = {2, 1}`。**有序对是「有位置」的一对数，集合是「没位置」的一堆东西。**

**有序对的集合论定义**（了解即可）：`⟨x, y⟩ = {{x}, {x, y}}`。这一定义来自 Kuratowski，好处是只用集合概念就能定义「有序」。

### 5.1.2 笛卡儿积

**定义 5.2（笛卡儿积）**：`A × B = {⟨x, y⟩ | x ∈ A 且 y ∈ B}`。
即所有「第一元素取自 A、第二元素取自 B」的有序对构成的集合。

**例**：`A = {a, b}`，`B = {1, 2, 3}`，则
`A × B = {⟨a,1⟩, ⟨a,2⟩, ⟨a,3⟩, ⟨b,1⟩, ⟨b,2⟩, ⟨b,3⟩}`，`|A × B| = 2 × 3 = 6`。
`B × A = {⟨1,a⟩, ⟨1,b⟩, ⟨2,a⟩, ⟨2,b⟩, ⟨3,a⟩, ⟨3,b⟩}`，与 `A × B` **完全不同**。

**笛卡儿积的性质**：

| 性质 | 结论 | 说明 |
|---|---|---|
| 基数 | `\|A × B\| = \|A\| · \|B\|` | 乘法原理的集合版 |
| 交换律 | **不满足** | `A × B ≠ B × A`（除非 A=B 或有一个为空） |
| 结合律 | **不满足** | `(A × B) × C ≠ A × (B × C)`（元组长度/嵌套结构不同） |
| 空集 | `A × ∅ = ∅ × A = ∅` | 因为没有任何有序对可取 |
| 分配律（对 ∪） | `A × (B ∪ C) = (A×B) ∪ (A×C)` | ✓ |
| 分配律（对 ∩） | `A × (B ∩ C) = (A×B) ∩ (A×C)` | ✓ |
| 对差的分配 | `A × (B − C) = (A×B) − (A×C)` | ✓ |
| 与子集 | 若 `A ⊆ C` 且 `B ⊆ D`，则 `A×B ⊆ C×D` | ✓ |

> **易错**：`(A×B) × C` 的元素形如 `⟨⟨a,b⟩, c⟩`（三层嵌套），而 `A × (B×C)` 的元素形如 `⟨a, ⟨b,c⟩⟩`。二者结构不同，所以**结合律不成立**。

**A × A 的记号**：`A² = A × A`。同理 `A³ = A × A × A`。

## 5.2 二元关系的定义与表示

### 5.2.1 定义

**定义 5.3（二元关系）**：设 A、B 为集合，`A × B` 的**任意子集** R 称为从 A 到 B 的**二元关系（Binary Relation）**。
若 `⟨x, y⟩ ∈ R`，记作 `x R y`（读作「x 与 y 有关系 R」）；否则记 `x R̸ y`。

**注意三点**：
1. 关系是一个**集合**（由有序对组成的集合）。
2. 关系是**笛卡儿积的子集**——所以 `∅` 也是关系（空关系）。
3. 当 A = B 时，称 R 为 **A 上的二元关系**（这是考试重点）。

**A 上关系的总数**：`|A| = n` 时，`|A × A| = n²`，`A × A` 的子集共 `2^(n²)` 个，即 A 上有 `2^(n²)` 个不同的二元关系。
例：`|A| = 2` 时有 `2⁴ = 16` 个关系；`|A| = 3` 时有 `2⁹ = 512` 个关系。

### 5.2.2 定义域、值域、域

**定义 5.4**：设 R 是从 A 到 B 的关系。
- **定义域（Domain）**：`dom R = {x | ∃y (⟨x,y⟩ ∈ R)}` —— 所有「出现过」的第一元素。
- **值域（Range）**：`ran R = {y | ∃x (⟨x,y⟩ ∈ R)}` —— 所有「出现过」的第二元素。
- **域（Field）**：`fld R = dom R ∪ ran R`。

**例**：`R = {⟨1,a⟩, ⟨1,b⟩, ⟨3,c⟩}`，则 `dom R = {1, 3}`，`ran R = {a, b, c}`，`fld R = {1, 3, a, b, c}`。

### 5.2.3 三种表示法

**设 `A = {1, 2, 3}`，`R = {⟨1,1⟩, ⟨1,3⟩, ⟨2,2⟩, ⟨3,1⟩}`（A 上的关系）**

**表示法一：集合（有序对列举）**
`R = {⟨1,1⟩, ⟨1,3⟩, ⟨2,2⟩, ⟨3,1⟩}`

**表示法二：关系矩阵（Relation Matrix）**
定义 `M_R = (rᵢⱼ)_{n×n}`，其中 `rᵢⱼ = 1` 若 `⟨aᵢ, aⱼ⟩ ∈ R`，否则 `rᵢⱼ = 0`。

```
       1  2  3
  1  ⎡ 1  0  1 ⎤
  2  ⎢ 0  1  0 ⎥
  3  ⎣ 1  0  0 ⎦
```
读法：第 i 行第 j 列为 1 ⟺ 从 i 到 j 有边。

**表示法三：关系图（Relation Digraph）**
顶点是 A 的元素，若 `⟨a, b⟩ ∈ R` 就画一条从 a 指向 b 的**有向边**；若 `⟨a, a⟩ ∈ R` 就画一个**自环**。

```
      ① ──→ ③
      ↑       │
      └───────┘
      ① ↺（自环）   ② ↺（自环）
```

| 表示法 | 适合场景 | 局限 |
|---|---|---|
| 集合 | 精确，便于代数运算 | 元素多时看不出结构 |
| 矩阵 | 便于计算机处理、求复合与闭包 | 只能用数字下标 |
| 关系图 | 直观看出性质（自环、双向边、传递） | 顶点多时杂乱 |

### 5.2.4 三个特殊关系

设 A 为非空集合，`|A| = n`。

| 名称 | 记号 | 定义 | 矩阵特征 |
|---|---|---|---|
| **空关系** | `∅` | 不含任何有序对 | 全 0 矩阵 |
| **全域关系** | `E_A` 或 `U_A` | `E_A = A × A` | 全 1 矩阵 |
| **恒等关系** | `I_A` | `I_A = {⟨x,x⟩ \| x ∈ A}` | 单位矩阵（对角线 1，其余 0） |

> **重点**：**恒等关系 `I_A` 是关系复合的单位元**：`R ∘ I_A = I_A ∘ R = R`。这个作用和数里的「1」、集合里的 `∅`（对对称差）完全一样，考试经常考。

## 5.3 关系的运算

### 5.3.1 五种基本运算

因为关系是集合，所以集合的运算全部适用。

**定义 5.5**：设 R、S 为集合 A 上的关系。
- `R ∪ S = {⟨x,y⟩ | xRy ∨ xSy}`
- `R ∩ S = {⟨x,y⟩ | xRy ∧ xSy}`
- `R − S = {⟨x,y⟩ | xRy ∧ ¬(xSy)}`
- `～R = A × A − R`（补关系）

**矩阵表示**：`M_{R∪S} = M_R ∨ M_S`（逐元素取或）；`M_{R∩S} = M_R ∧ M_S`（逐元素取与）；`M_{～R} = ¬M_R`（逐元素取反）。

### 5.3.2 逆关系

**定义 5.6（逆关系）**：`R⁻¹ = {⟨y, x⟩ | ⟨x, y⟩ ∈ R}`。
即把所有有序对「前后对调」。

**例**：`R = {⟨1,a⟩, ⟨2,b⟩}`，则 `R⁻¹ = {⟨a,1⟩, ⟨b,2⟩}`。

**逆关系的重要性质**：
- `(R⁻¹)⁻¹ = R`
- `(R ∪ S)⁻¹ = R⁻¹ ∪ S⁻¹`
- `(R ∩ S)⁻¹ = R⁻¹ ∩ S⁻¹`
- `(R − S)⁻¹ = R⁻¹ − S⁻¹`
- **`(R ∘ S)⁻¹ = S⁻¹ ∘ R⁻¹`** ← 注意**顺序反过来**（像穿鞋脱鞋：先穿袜子再穿鞋，脱的时候先脱鞋再脱袜子）
- `M_{R⁻¹} = (M_R)ᵀ`（转置矩阵）

### 5.3.3 复合关系

**定义 5.7（复合关系）**：设 R 是从 A 到 B 的关系，S 是从 B 到 C 的关系，则 R 与 S 的**复合（Composition）** 是从 A 到 C 的关系：
`R ∘ S = {⟨x, z⟩ | ∃y (⟨x, y⟩ ∈ R ∧ ⟨y, z⟩ ∈ S)}`

> **读法约定**：本书（以及屈婉玲教材）采用 `R ∘ S` 表示「**先 R 后 S**」。有的教材（含左孝凌版某些章节）写成 `R·S` 或 `S ∘ R`，做题目时先看清教材的约定。**判断法则：先走 R 的箭头，再走 S 的箭头，能首尾相接就连起来。**

**例**：`A = {1,2,3}`，`R = {⟨1,2⟩, ⟨2,3⟩}`，`S = {⟨2,a⟩, ⟨3,b⟩}`。
`R ∘ S`：找 `⟨x,y⟩ ∈ R` 与 `⟨y,z⟩ ∈ S`，y 相同就配对。
- `⟨1,2⟩ ∈ R` 且 `⟨2,a⟩ ∈ S` → 得 `⟨1,a⟩`
- `⟨2,3⟩ ∈ R` 且 `⟨3,b⟩ ∈ S` → 得 `⟨2,b⟩`
所以 `R ∘ S = {⟨1,a⟩, ⟨2,b⟩}`。

**复合的矩阵算法（布尔乘法）**：
`M_{R∘S} = M_R ⊙ M_S`，其中
`(M_R ⊙ M_S)[i][j] = ∨_k ( M_R[i][k] ∧ M_S[k][j] )`
即：**先对应相乘（与），再把所有 k 加起来（或）**。这和普通矩阵乘法一样，只是把「乘」换成「与」、「加」换成「或」。

**上面例子的矩阵计算**：

```
       1  2  3
  1  ⎡ 0  1  0 ⎤                2  3
  2  ⎢ 0  0  1 ⎥   ⊙      a ⎡ 0  0 ⎤   =      a  b
  3  ⎣ 0  0  0 ⎦          b ⎢ 0  0 ⎥      1 ⎡ 0  0 ⎤
                          c ⎣ 0  0 ⎦      2 ⎢ 1  0 ⎥
    M_R（3×3）              M_S（3×2）      3 ⎣ 0  1 ⎦
```
计算示例：结果 `[1][1] = ∨(0∧0, 1∧1, 0∧0) = 1`，故 `⟨1, a⟩ ∈ R∘S` ✓。

**复合的性质**：

| 性质 | 是否成立 | 说明 |
|---|---|---|
| 结合律 | **✓ 成立** | `(R∘S)∘T = R∘(S∘T)` |
| 交换律 | **✗ 不成立** | `R∘S ≠ S∘R`（一般地） |
| 与恒等关系 | `R ∘ I_A = I_A ∘ R = R` | `I_A` 是单位元 |
| 对并的分配 | `R ∘ (S ∪ T) = (R∘S) ∪ (R∘T)` | ✓ |
| 对交的分配 | `R ∘ (S ∩ T) ⊆ (R∘S) ∩ (R∘T)` | **只单向**！ |
| 逆的复合 | `(R∘S)⁻¹ = S⁻¹∘R⁻¹` | **顺序颠倒** |

> **重点**：`R ∘ (S ∩ T) ⊆ (R∘S) ∩ (R∘T)` 是**严格包含**，不一定相等。反例：`R = {⟨1,a⟩, ⟨1,b⟩}`，`S = {⟨a,1⟩}`，`T = {⟨b,1⟩}`。则 `S ∩ T = ∅`，`R∘(S∩T) = ∅`；但 `R∘S = {⟨1,1⟩}`，`R∘T = {⟨1,1⟩}`，交集是 `{⟨1,1⟩}`。不等。

### 5.3.4 关系的幂运算

**定义 5.8**：设 R 是 A 上的关系，n 为自然数。
- `R⁰ = I_A`（恒等关系）
- `R^(n+1) = Rⁿ ∘ R`

**性质**：
- `R^m ∘ R^n = R^(m+n)`
- `(R^m)^n = R^(mn)`
- `M_{R^n} = (M_R)^n`（布尔矩阵的 n 次幂）

**`Rⁿ` 的直观含义**：`⟨x, y⟩ ∈ Rⁿ` ⟺ 在关系图中存在一条**从 x 到 y、长度恰好为 n 的通路**。

**例**：`A = {1,2,3,4}`，`R = {⟨1,2⟩, ⟨2,3⟩, ⟨3,4⟩}`。
- `R² = {⟨1,3⟩, ⟨2,4⟩}`（走两步）
- `R³ = {⟨1,4⟩}`（走三步）
- `R⁴ = ∅`（走四步无路可走）

## 5.4 关系的五种性质 ★★★★★

**以下设 R 是集合 A 上的关系。**

### 5.4.1 五种性质的定义

| 性质 | 形式化定义 | 通俗说法 |
|---|---|---|
| **自反（Reflexive）** | `∀x ∈ A, ⟨x,x⟩ ∈ R` | 每个点都有自环 |
| **反自反（Irreflexive）** | `∀x ∈ A, ⟨x,x⟩ ∉ R` | 每个点都没有自环 |
| **对称（Symmetric）** | `∀x,y, ⟨x,y⟩ ∈ R → ⟨y,x⟩ ∈ R` | 有边必成对（双向） |
| **反对称（Antisymmetric）** | `∀x,y, (⟨x,y⟩ ∈ R ∧ ⟨y,x⟩ ∈ R) → x = y` | 不同点之间不允许双向边 |
| **传递（Transitive）** | `∀x,y,z, (⟨x,y⟩ ∈ R ∧ ⟨y,z⟩ ∈ R) → ⟨x,z⟩ ∈ R` | 两步能到的，一步也能到 |

> **重要提醒**：**自反**与**反自反**不是互补的！存在既不自反也不反自反的关系（某个点有自环、某个点没有）。例如 A = {1,2}，R = {⟨1,1⟩}：既不自反（缺 ⟨2,2⟩），也不反自反（有 ⟨1,1⟩）。
> 同理，**对称**与**反对称**也不是互补的！存在既对称又反对称的关系（如 `I_A`、`∅`），也存在两者都不满足的关系（如 `{⟨1,2⟩, ⟨2,1⟩, ⟨1,3⟩}`）。

### 5.4.2 五种性质判定表（核心工具）

设 `|A| = n`，`M_R` 是关系矩阵，关系图记作 G。

| 性质 | 矩阵判定法 | 关系图判定法 | 关系图边数范围 |
|---|---|---|---|
| **自反** | 主对角线元素**全为 1**（`rᵢᵢ = 1`, ∀i） | 每个顶点**都有自环** | 最少 n 条（全是自环） |
| **反自反** | 主对角线元素**全为 0** | 每个顶点**都没有自环** | 最少 0 条 |
| **对称** | 矩阵关于主对角线**对称**（`rᵢⱼ = rⱼᵢ`） | 有向边**成对出现**（或全为自环） | ≤ n + n(n−1)/2 |
| **反对称** | 对 `i ≠ j`，`rᵢⱼ` 与 `rⱼᵢ` **不同时为 1** | 不同顶点间**最多一条方向**的边 | ≤ n + 2·n(n−1)/2 = n² |
| **传递** | `M_R ⊙ M_R` 的每个 1 位置在 `M_R` 中**也为 1**（即 `M_{R²} ≤ M_R`） | 若 x→y→z 有路，则 x→z 必有边 | —— |

**「传递」的矩阵判定细节**：计算 `M_R² = M_R ⊙ M_R`，逐元素比较。若 `M_R²` 中某个位置是 1 而 `M_R` 中对应位置是 0，则**不传递**。

**「传递」判定的另一等价说法**：`R` 传递 ⟺ `R ∘ R ⊆ R`。

### 5.4.3 快速判定流程（考试必备）

```
拿到一个关系 R：
 第 1 步：写出 M_R 或画出关系图
 第 2 步：看对角线 ── 全 1 → 自反；全 0 → 反自反；否则两者都不满足
 第 3 步：看对称性 ── 矩阵对称 → 对称
 第 4 步：看反对称 ── 对每个 i≠j，r_ij 与 r_ji 是否同时为 1？有 → 不反对称
 第 5 步：看传递 ── 枚举所有「x→y→z」的两步路，检查 x→z 是否存在
                   （例：只有 3 个元素时最多看 27 组，实际很快）
```

**第五步的加速技巧**：**只需要检查「有入边又有出边」的中间点 y**。若 y 没有入边或没有出边，就不必检查。
更快的办法：**列出每个点的「可达一步集合」**，对每条边 `x→y`，检查 `y 的出边终点` 是否都在 `x 的出边终点集`里。

### 5.4.4 关系性质的证明与反驳套路

**证明 R 具有某性质**：直接按定义，任取元素推导。
- 证自反：任取 `x ∈ A`，说明 `⟨x,x⟩ ∈ R`（通常由 R 的定义直接给出）。
- 证对称：任取 `⟨x,y⟩ ∈ R`，推出 `⟨y,x⟩ ∈ R`。
- 证传递：任取 `⟨x,y⟩ ∈ R` 且 `⟨y,z⟩ ∈ R`，推出 `⟨x,z⟩ ∈ R`。

**反驳 R 具有某性质（举反例）**：只要找到一对/一组元素不满足即可。
- 反驳自反：找一个 `x` 使 `⟨x,x⟩ ∉ R`。
- 反驳对称：找 `⟨x,y⟩ ∈ R` 但 `⟨y,x⟩ ∉ R`。
- 反驳反对称：找 `x ≠ y` 使 `⟨x,y⟩, ⟨y,x⟩` 都在 R 中。
- 反驳传递：找 `⟨x,y⟩, ⟨y,z⟩ ∈ R` 但 `⟨x,z⟩ ∉ R`。

**常见关系的性质表（必须记住）**：

| 关系 | 自反 | 反自反 | 对称 | 反对称 | 传递 |
|---|---|---|---|---|---|
| 空关系 `∅` | ✗ | **✓** | **✓** | **✓** | **✓** |
| 恒等关系 `I_A` | **✓** | ✗（A≠∅时） | **✓** | **✓** | **✓** |
| 全域关系 `E_A` | **✓** | ✗（A≠∅时） | **✓** | ✗（\|A\|≥2 时） | **✓** |
| 实数上的 `≤` | **✓** | ✗ | ✗ | **✓** | **✓** |
| 实数上的 `<` | ✗ | **✓** | ✗ | **✓** | **✓** |
| 实数上的 `=` | **✓** | ✗ | **✓** | **✓** | **✓** |
| 整数上的「整除」`\|` | **✓** | ✗ | ✗ | **✓** | **✓** |
| 人群上的「同姓」 | **✓** | ✗ | **✓** | ✗ | **✓** |
| 人群上的「父子」 | ✗ | **✓** | ✗ | **✓** | ✗ |
| 集合上的 `⊆` | **✓** | ✗ | ✗ | **✓** | **✓** |
| 命题公式上的 `⇔` | **✓** | ✗ | **✓** | ✗ | **✓** |
| 模 n 同余 `≡ (mod n)` | **✓** | ✗ | **✓** | ✗ | **✓** |

> **重点**：`∅` 是唯一同时满足**反自反、对称、反对称、传递**的关系。`I_A` 是唯一同时满足**自反、对称、反对称、传递**的关系（A 非空时）。

## 5.5 关系的闭包

**定义 5.9（闭包）**：设 R 是 A 上的关系。R 的**自反闭包**记 `r(R)`，**对称闭包**记 `s(R)`，**传递闭包**记 `t(R)`，分别指：
- 包含 R 的**最小**自反关系；
- 包含 R 的**最小**对称关系；
- 包含 R 的**最小**传递关系。

> **「最小」的含义**：先要求「包含 R 且具有该性质」，再从所有这样的关系里挑**元素最少**的那个。
> **直观理解**：闭包就是「**给 R 补上它缺少的那几条边，使性质成立，且补得尽可能少**」。

### 5.5.1 三种闭包的求法

**定理 5.1（自反闭包）**：
`r(R) = R ∪ I_A`

**为什么**：自反性要求每个 `⟨x,x⟩` 都在。R 里可能缺一些，把所有 `⟨x,x⟩` 一股脑并进来即可；已有的不动，所以是最小的。

**定理 5.2（对称闭包）**：
`s(R) = R ∪ R⁻¹`

**为什么**：对称性要求「有 `⟨x,y⟩` 就必须有 `⟨y,x⟩`」。把所有边的方向都补上（即并上 `R⁻¹`）就够了，且一条不多。

**定理 5.3（传递闭包）**：
`t(R) = R ∪ R² ∪ R³ ∪ … ∪ Rⁿ`，其中 `n = |A|`

**为什么到 Rⁿ 就停**：若存在长度 > n 的通路，由鸽巢原理该通路必然重复经过某个顶点，于是可以剪掉中间那段环，得到更短的通路。所以**任何可达关系都能由长度 ≤ n 的通路实现**，n 次幂之后不会再产生新边。

**推论**：`R` 传递 ⟺ `t(R) = R` ⟺ `R² ⊆ R`。

### 5.5.2 三种闭包的矩阵求法

| 闭包 | 集合公式 | 矩阵公式 |
|---|---|---|
| 自反闭包 | `r(R) = R ∪ I_A` | `M_r = M_R ∨ E`（E 为单位矩阵） |
| 对称闭包 | `s(R) = R ∪ R⁻¹` | `M_s = M_R ∨ M_Rᵀ` |
| 传递闭包 | `t(R) = R ∪ R² ∪ … ∪ Rⁿ` | `M_t = M_R ∨ M_R^2 ∨ … ∨ M_R^n` |

### 5.5.3 沃舍尔算法（Warshall）求传递闭包

**用途**：当 n 较大时，逐个算 `R², R³, …, Rⁿ` 太慢。沃舍尔算法用 `O(n³)` 一次求出传递闭包。

**算法步骤**（直接操作关系矩阵 M，最终 M 变成传递闭包矩阵）：
```
for k = 1 to n:                // k 作为「中转点」
    for i = 1 to n:
        for j = 1 to n:
            if M[i][k] == 1 and M[k][j] == 1:
                M[i][j] = 1
```
**理解**：第 k 轮结束后，`M[i][j] = 1` 表示「i 到 j 存在一条中间点只允许是 1..k 的通路」。外层循环逐轮放开「允许经过的中转点」。

**例**：设 `A = {1,2,3,4}`，`R = {⟨1,2⟩, ⟨2,3⟩, ⟨3,4⟩}`，求 `t(R)`。

初态矩阵（行 i 列 j）：
```
     1  2  3  4
 1 ⎡ 0  1  0  0 ⎤
 2 ⎢ 0  0  1  0 ⎥
 3 ⎢ 0  0  0  1 ⎥
 4 ⎣ 0  0  0  0 ⎦
```

**k = 1**（允许经 1 中转）：第 1 列全 0（除对角线外无入边到 1），无新增。
**k = 2**：`M[1][2] = 1`，第 2 行有 `M[2][3] = 1` → 置 `M[1][3] = 1`。
```
     1  2  3  4
 1 ⎡ 0  1  1  0 ⎤
 2 ⎢ 0  0  1  0 ⎥
 3 ⎢ 0  0  0  1 ⎥
 4 ⎣ 0  0  0  0 ⎦
```
**k = 3**：`M[1][3] = 1`，第 3 行有 `M[3][4] = 1` → 置 `M[1][4] = 1`；`M[2][3] = 1` → 置 `M[2][4] = 1`。
```
     1  2  3  4
 1 ⎡ 0  1  1  1 ⎤
 2 ⎢ 0  0  1  1 ⎥
 3 ⎢ 0  0  0  1 ⎥
 4 ⎣ 0  0  0  0 ⎦
```
**k = 4**：第 4 行全 0，无变化。

**结果**：`t(R) = {⟨1,2⟩, ⟨1,3⟩, ⟨1,4⟩, ⟨2,3⟩, ⟨2,4⟩, ⟨3,4⟩}`。

**验证**：`R² = {⟨1,3⟩, ⟨2,4⟩}`，`R³ = {⟨1,4⟩}`，`R⁴ = ∅`。并起来正好一致 ✓。

### 5.5.4 闭包的性质与关系

**定理 5.4**：
- 若 R 自反，则 `r(R) = R`；若 R 对称，则 `s(R) = R`；若 R 传递，则 `t(R) = R`。
- `r(R)` 一定自反；`s(R)` 一定对称；`t(R)` 一定传递。
- **`R` 自反 ⟹ `s(R)` 与 `t(R)` 都自反。**
- **`R` 对称 ⟹ `r(R)` 与 `t(R)` 都对称。**
- `R` 传递 **推不出** `r(R)` 或 `s(R)` 传递。

> **易错**：`R` 传递时 `r(R) = R ∪ I_A` **仍然传递**（因为加自环不会破坏传递性）；但 `s(R) = R ∪ R⁻¹` **可能不传递**。反例：`R = {⟨1,2⟩}` 传递，`s(R) = {⟨1,2⟩, ⟨2,1⟩}`，但缺 `⟨1,1⟩` 和 `⟨2,2⟩`，**不传递**。
> 若想要「自反+对称+传递」都成立（即等价关系闭包），只需保证 **`t` 放在最后**：`tsr(R) = rts(R) = trs(R)` 三者**结果唯一**，都是包含 R 的最小等价关系。
> **★ 但 `str(R)` 一般不相等** ✘！因为 **`t(R)` 对称化之后一般不再传递**——先传递后对称会把传递性丢掉。
> **反例**：`A = {1,2,3,4}`，`R = {⟨1,2⟩, ⟨1,3⟩}`。
> ```
> tsr(R) = t(s(r(R)))：先补自环和逆元，再传递化
>        = {⟨1,1⟩,⟨1,2⟩,⟨1,3⟩,⟨2,1⟩,⟨2,2⟩,⟨2,3⟩,⟨3,1⟩,⟨3,2⟩,⟨3,3⟩,⟨4,4⟩}   （10 个元素）
> str(R) = s(t(r(R)))：先补自环，传递化，最后才对称化
>        = {⟨1,1⟩,⟨1,2⟩,⟨1,3⟩,⟨2,1⟩,⟨2,2⟩,⟨3,1⟩,⟨3,3⟩,⟨4,4⟩}            （8 个元素）
> 差别：str(R) 缺了 ⟨2,3⟩ 和 ⟨3,2⟩，因而不传递（有 ⟨3,1⟩,⟨1,2⟩ 却没有 ⟨3,2⟩）✘
> ```
> **记忆法**：**`t` 必须放最后**（先做 `r`、`s`，最后做 `t` 才安全）。

## 5.6 等价关系与划分

### 5.6.1 等价关系

**定义 5.10（等价关系）**：设 R 是 A 上的关系。若 R 同时满足**自反、对称、传递**，则称 R 是 A 上的**等价关系（Equivalence Relation）**。

**生活类比**：等价关系就是「**在某方面算一类**」的精确化。比如「同姓」「同班」「模 3 余数相同」——它们都把元素分成若干堆，堆内「一视同仁」。

**典型等价关系**：
| 集合 A | 关系 | 是等价关系？ |
|---|---|---|
| 整数 `Z` | `x ≡ y (mod n)` | ✓ |
| 实数 `R` | `x = y` | ✓ |
| 人群 | 「同姓」 | ✓ |
| 人群 | 「同年龄」 | ✓ |
| 平面上的直线 | 「平行或重合」 | ✓（注意必须加「重合」） |
| 全校学生 | 「同专业」 | ✓ |
| 三角形 | 「相似」 | ✓ |
| 整数 | `x ≤ y` | ✗（不对称） |
| 整数 | `x < y` | ✗（不自反、不对称） |
| 人群 | 「父子」 | ✗（不自反、不对称、不传递） |
| 整数 | `x + y` 为偶数 | ✓ |

### 5.6.2 等价类

**定义 5.11（等价类）**：设 R 是 A 上的等价关系，`x ∈ A`。则
`[x]_R = {y | y ∈ A 且 ⟨x, y⟩ ∈ R}`
称为 x 关于 R 的**等价类（Equivalence Class）**，x 称为该等价类的**代表元**。

**等价类的三条基本性质（高频考点）**：

**定理 5.5**：设 R 是 A 上的等价关系，`x, y ∈ A`。
1. **非空性**：`[x]_R ≠ ∅`（因为 x 自反，`x ∈ [x]_R`）。
2. **相等或不相交**：`[x]_R = [y]_R ⟺ ⟨x,y⟩ ∈ R`；若 `⟨x,y⟩ ∉ R`，则 `[x]_R ∩ [y]_R = ∅`。
3. **并集为全集**：`⋃_{x∈A} [x]_R = A`。

**证明第 2 条的前一半**：
（⇒）设 `[x]_R = [y]_R`。因 `y ∈ [y]_R`（自反），故 `y ∈ [x]_R`，由定义 `⟨x, y⟩ ∈ R` ✓。
（⇐）设 `⟨x,y⟩ ∈ R`。任取 `z ∈ [x]_R`，则 `⟨x,z⟩ ∈ R`。由对称性 `⟨y,x⟩ ∈ R`，再由传递性 `⟨y,x⟩ ∈ R ∧ ⟨x,z⟩ ∈ R ⟹ ⟨y,z⟩ ∈ R`，故 `z ∈ [y]_R`。得 `[x]_R ⊆ [y]_R`；对称地 `[y]_R ⊆ [x]_R`。故相等 ✓。∎

**证明第 2 条的后一半**（不相交）：反证。设 `[x]_R ∩ [y]_R ≠ ∅`，取 `z` 在其中。则 `⟨x,z⟩ ∈ R` 且 `⟨y,z⟩ ∈ R`。由对称得 `⟨z,y⟩ ∈ R`，由传递得 `⟨x,y⟩ ∈ R`，与假设矛盾。∎

> **重点**：这三条性质说明——**等价类把集合「切」成了互不重叠的若干块，每块都非空，合起来正好是整个集合**。

### 5.6.3 商集

**定义 5.12（商集）**：`A/R = {[x]_R | x ∈ A}`，即所有等价类构成的集合。

> **重点**：商集的元素是**等价类**（集合），不是原集合的元素。`[x]_R ∈ A/R`，而 `x ∈ A`。

**例**：`A = {1,2,3,4,5}`，R 为「模 2 同余」。
- `[1]_R = [3]_R = [5]_R = {1,3,5}`
- `[2]_R = [4]_R = {2,4}`
- `A/R = {{1,3,5}, {2,4}}`（只有 2 个元素，不是 5 个）

### 5.6.4 集合的划分

**定义 5.13（划分）**：设 A 为非空集合，`π = {A₁, A₂, …, Aₖ}` 是 A 的一族非空子集。若满足：
1. **不空**：`Aᵢ ≠ ∅`（i = 1, …, k）；
2. **不交**：`Aᵢ ∩ Aⱼ = ∅`（i ≠ j）；
3. **覆盖**：`A₁ ∪ A₂ ∪ … ∪ Aₖ = A`。

则称 π 为 A 的一个**划分（Partition）**，每个 `Aᵢ` 称为**划分块**。

**定理 5.6（等价关系与划分的一一对应）**：
- A 上的每个等价关系 R 都**唯一确定** A 的一个划分 `A/R`（商集就是划分）。
- A 的每个划分 π 都**唯一确定** A 上的一个等价关系 `R_π`：`⟨x,y⟩ ∈ R_π ⟺ x 与 y 属于 π 的同一个块`。

> **一句话**：**等价关系 = 划分**，只是同一个东西的两种说法。给等价关系就能切出划分；给划分就能造等价关系。

**例**：`A = {1,2,3}`。
- 划分 `π = {{1}, {2,3}}` 对应的等价关系：`R = I_A ∪ {⟨2,3⟩, ⟨3,2⟩} = {⟨1,1⟩, ⟨2,2⟩, ⟨3,3⟩, ⟨2,3⟩, ⟨3,2⟩}`。
- 验证：自反 ✓（含全对角线），对称 ✓（⟨2,3⟩ 与 ⟨3,2⟩ 都有），传递 ✓（⟨2,3⟩,⟨3,2⟩ ⟹ ⟨2,2⟩ ∈ R ✓）。

**有限集的划分数**：n 元素集合的划分数是**贝尔数（Bell Number）**：
`B₀ = 1, B₁ = 1, B₂ = 2, B₃ = 5, B₄ = 15, B₅ = 52`
递推式：`B_{n+1} = Σ_{k=0}^{n} C(n,k) B_k`。

### 5.6.5 相容关系（左孝凌版特有考点）

**定义 5.14（相容关系）**：若 R 满足**自反**和**对称**（**不要求传递**），则称 R 为**相容关系（Compatibility Relation）**。

**覆盖（Cover）**：设 `π = {A₁, …, Aₖ}`，满足每个 `Aᵢ ≠ ∅` 且 `⋃Aᵢ = A`（**允许相交**！），则称 π 为 A 的**覆盖**。

**相容类**：设 R 是相容关系，`A' ⊆ A`。若 `A'` 中任意两个元素都相容，则称 `A'` 是**相容类**。若再添任何元素都会破坏相容性，则称**最大相容类**。

**定理 5.7**：相容关系的**全体最大相容类**构成 A 的一个**覆盖**（不是划分，因为最大相容类之间可能相交）。

> **对比记忆**：等价关系 → 划分（块之间**不交**）；相容关系 → 覆盖（块之间**可交**）。

## 5.7 偏序关系

### 5.7.1 定义

**定义 5.15（偏序关系）**：若 A 上的关系 R 满足**自反、反对称、传递**，则称 R 是 A 上的**偏序关系（Partial Order Relation）**，常记作 `≼`。二元组 `⟨A, ≼⟩` 称为**偏序集（Poset）**。

**生活类比**：偏序就是「**大小/优劣/先后**」的抽象。但它「偏」在——**不要求任意两个元素都能比大小**。

**典型偏序关系**：

| 集合 | 偏序关系 | 记号 |
|---|---|---|
| 实数 `R` | 小于等于 | `≤` |
| 正整数 `Z⁺` | 整除 | `\|` |
| 幂集 `P(A)` | 包含 | `⊆` |
| 命题公式集 | 蕴含 | `⇒` |
| 人群 | 「是……的祖先或本人」 | —— |
| 任务集合 | 「必须先于」 | `≺` |

**可比与不可比**：在 `⟨A, ≼⟩` 中，若 `x ≼ y` 或 `y ≼ x`，称 x 与 y **可比（Comparable）**；否则称**不可比**。

**全序关系（链）**：若偏序集中**任意两个元素都可比较**，则称该关系为**全序关系（Total Order）**或**线序关系**，该偏序集称为**链（Chain）**。
- `⟨R, ≤⟩` 是全序（任意两个实数都能比大小）。
- `⟨P(A), ⊆⟩` 当 `|A| ≥ 2` 时**不是**全序（`{1}` 与 `{2}` 不可比）。

**拟序关系**：若 R 满足**反自反 + 传递**，称 R 为**拟序关系（Quasi-order）**。`<` 就是拟序。

### 5.7.2 覆盖与哈斯图

**定义 5.16（覆盖）**：在偏序集 `⟨A, ≼⟩` 中，若 `x ≺ y`（即 `x ≼ y` 且 `x ≠ y`），且**不存在 z 使 `x ≺ z ≺ y`**，则称 **y 覆盖 x**。

**哈斯图（Hasse Diagram）的画法三规则**：
1. **去掉自环**：因为偏序一定自反，每个点的自环都省略。
2. **去掉可由传递性推出的边**：只画「覆盖」关系（即 x 到 y 之间没有中间元素）。
3. **方向隐含**：把「较小的」画在**下面**，「较大的」画在上面；箭头一律省略（默认为**自下而上**）。

**例**：设 `A = {1, 2, 3, 6, 12}`，关系是整除 `|`。

**先求覆盖关系**：
- 1 覆盖？1 与 2：`1|2` ✓，1 与 3 之间有没有 z 使 `1|z|3`？z = 1, 3 都不是（z 必须严格在中间），没有 → **2 覆盖 1** ✓
- 同理 **3 覆盖 1** ✓
- 2 与 6：有没有 z 使 `2|z|6`？z = 2, 6 不行；z = 3？`2∤3` ✗。z 可以取 2 到 6 之间能被 2 整除又能整除 6 的数：只有 6 本身。所以 **6 覆盖 2** ✓
- 3 与 6：**6 覆盖 3** ✓
- 6 与 12：**12 覆盖 6** ✓
- 1 与 6：`1|6` 但不是覆盖（中间有 2）
- 1、2、3 与 12：都不是覆盖

**哈斯图**：

```
              12
              │
              6
             ╱ ╲
            2   3
             ╲ ╱
              1
```

**例**：`A = {a, b, c}`，关系是 `⊆`，哈斯图如下（这是著名的「立方体」形）：

```
              {a,b,c}
             ╱   │   ╲
      {a,b}   {a,c}   {b,c}
         │   ╲   │   ╱   │
         │    ╲  │  ╱    │
        {a}     {b}     {c}
           ╲     │     ╱
              ∅
```

### 5.7.3 特殊元素

**以下设 `⟨A, ≼⟩` 是偏序集，`B ⊆ A`。**

| 名称 | 定义 | 数量 |
|---|---|---|
| **最大元** | `a ∈ B`，且 `∀x ∈ B, x ≼ a` | 至多 1 个 |
| **最小元** | `a ∈ B`，且 `∀x ∈ B, a ≼ x` | 至多 1 个 |
| **极大元** | `a ∈ B`，且不存在 `x ∈ B` 使 `a ≺ x` | 至少 1 个（B 有限时），可多个 |
| **极小元** | `a ∈ B`，且不存在 `x ∈ B` 使 `x ≺ a` | 至少 1 个（B 有限时），可多个 |
| **上界** | `a ∈ A`，且 `∀x ∈ B, x ≼ a` | 可 0 个、可多个 |
| **下界** | `a ∈ A`，且 `∀x ∈ B, a ≼ x` | 可 0 个、可多个 |
| **上确界**（最小上界） | 上界集合的**最小元**，记 `sup B` 或 `lub B` | 至多 1 个 |
| **下确界**（最大下界） | 下界集合的**最大元**，记 `inf B` 或 `glb B` | 至多 1 个 |

**四组概念的关键区别（背下来）**：

| 对比 | 区别 1 | 区别 2 |
|---|---|---|
| 最大元 vs 极大元 | 最大元要**比得过所有元素**；极大元只要求**没人比它大** | 最大元唯一，极大元可多个 |
| 最大元 vs 上界 | 最大元**必须属于 B**；上界**不必属于 B**（在 A 里就行） | —— |
| 上确界 vs 上界 | 上确界是上界中**最小的那个** | 上界可多个，上确界至多一个 |
| 存在性 | 极大元一定存在（有限集）；最大元**不一定存在** | —— |

> **重点**：**哈斯图里，最大元就是「最上面那个」（唯一顶点都能到达它）；极大元就是「最上面的那些」（没有向上的边）。上界在最上面那个之上（哈斯图中位置不低于 B 的所有元素）；上确界是所有上界中最靠下的那个。**
>
> **反例（最大元不存在但有多个极大元）**：`A = {2,3,6,12,18}`，整除偏序，取 `B = {2,3}`。2 与 3 不可比，所以既无最大元也无最小元；但 2 和 3 **都是极大元，也都是极小元**。

**例（完整演示）**：`A = {1,2,3,4,6,12}`，整除偏序，`B = {1,2,3,6}`。
- **最大元**：6 ∈ B，且 `1|6, 2|6, 3|6, 6|6` 全成立 → **最大元 = 6**
- **最小元**：1 ∈ B，且 `1|1, 1|2, 1|3, 1|6` → **最小元 = 1**
- **极大元**：B 中没有人是 6 的倍数（除 6 自己）→ **极大元 = 6**
- **极小元**：B 中没有人整除 1（除 1 自己）→ **极小元 = 1**
- **上界**（在 A 中找 B 全部元素的倍数）：12 是最小公倍数，`1|12, 2|12, 3|12, 6|12` ✓ → **上界 = {12}**
- **下界**：`1 | 1,2,3,6` → **下界 = {1}**
- **上确界 = 12**，**下确界 = 1**

## 典型例题

**例 5.1**（题型：笛卡儿积与基数）
设 `A = {1, 2}`，`B = {a, b, c}`。求 `A × B`、`B × A`、`|P(A × B)|`、`|(A×B) ∩ (B×A)|`。
**解**：
① `A × B = {⟨1,a⟩, ⟨1,b⟩, ⟨1,c⟩, ⟨2,a⟩, ⟨2,b⟩, ⟨2,c⟩}`，共 `2 × 3 = 6` 个元素。
② `B × A = {⟨a,1⟩, ⟨a,2⟩, ⟨b,1⟩, ⟨b,2⟩, ⟨c,1⟩, ⟨c,2⟩}`，共 6 个元素。
③ `|P(A × B)| = 2⁶ = 64`。
④ `(A×B) ∩ (B×A)` 中的元素必须既是 `⟨数字, 字母⟩` 又是 `⟨字母, 数字⟩`。由有序对相等的条件，需要「数字 = 字母」，不可能（两个集合无公共元素）。故交集为 `∅`，`|·| = 0`。
**答案**：`|P(A×B)| = 64`，`(A×B) ∩ (B×A) = ∅`。

**例 5.2**（题型：关系的三种表示互转 + 定义域值域）
设 `A = {1, 2, 3, 4}`，`R = {⟨x,y⟩ | x, y ∈ A 且 x 整除 y}`（即 `x | y`）。
(1) 用列举法写出 R；(2) 写出 `M_R`；(3) 求 `dom R`、`ran R`；(4) `|R|`。
**解**：
(1) 逐个检查整除关系：
- `1|1,1|2,1|3,1|4` → `⟨1,1⟩, ⟨1,2⟩, ⟨1,3⟩, ⟨1,4⟩`
- `2|2, 2|4` → `⟨2,2⟩, ⟨2,4⟩`（`2∤3`）
- `3|3` → `⟨3,3⟩`（`3∤4`）
- `4|4` → `⟨4,4⟩`

`R = {⟨1,1⟩, ⟨1,2⟩, ⟨1,3⟩, ⟨1,4⟩, ⟨2,2⟩, ⟨2,4⟩, ⟨3,3⟩, ⟨4,4⟩}`

(2) 矩阵（行 = 第一元素，列 = 第二元素）：
```
     1  2  3  4
 1 ⎡ 1  1  1  1 ⎤
 2 ⎢ 0  1  0  1 ⎥
 3 ⎢ 0  0  1  0 ⎥
 4 ⎣ 0  0  0  1 ⎦
```
(3) `dom R = {1, 2, 3, 4}`（每行都有 1）；`ran R = {1, 2, 3, 4}`（每列都有 1）。
(4) `|R| = 8`（数矩阵里 1 的个数：4+2+1+1 = 8）。
**答案**：`|R| = 8`，`dom R = ran R = A`。

**例 5.3**（题型：判断关系的五种性质）
设 `A = {1, 2, 3}`，`R = {⟨1,1⟩, ⟨1,2⟩, ⟨2,1⟩, ⟨2,2⟩, ⟨3,3⟩}`。判断 R 的五种性质。
**解**：
① **自反？** 对角线元素 `⟨1,1⟩, ⟨2,2⟩, ⟨3,3⟩` **都在** R 中 → **自反 ✓**
② **反自反？** 因为 R 自反且 `A ≠ ∅`，所以**必然不反自反 ✗**
③ **对称？** 检查每一对：`⟨1,2⟩ ∈ R` 且 `⟨2,1⟩ ∈ R` ✓；`⟨2,1⟩ ∈ R` 且 `⟨1,2⟩ ∈ R` ✓；对角线自然对称。→ **对称 ✓**
④ **反对称？** 因为有 `⟨1,2⟩` 和 `⟨2,1⟩` 同时存在而 `1 ≠ 2` → **不反对称 ✗**
⑤ **传递？** 枚举所有「两步路」：
- `⟨1,1⟩` 与 `⟨1,1⟩` → 需 `⟨1,1⟩` ✓
- `⟨1,1⟩` 与 `⟨1,2⟩` → 需 `⟨1,2⟩` ✓
- `⟨1,2⟩` 与 `⟨2,1⟩` → 需 `⟨1,1⟩` ✓
- `⟨1,2⟩` 与 `⟨2,2⟩` → 需 `⟨1,2⟩` ✓
- `⟨2,1⟩` 与 `⟨1,1⟩` → 需 `⟨2,1⟩` ✓
- `⟨2,1⟩` 与 `⟨1,2⟩` → 需 `⟨2,2⟩` ✓
- `⟨2,2⟩` 与 `⟨2,1⟩` → 需 `⟨2,1⟩` ✓
- 其余含 3 的组合都指向 `⟨3,3⟩` ✓

全部满足 → **传递 ✓**
**答案**：自反 ✓、反自反 ✗、对称 ✓、反对称 ✗、传递 ✓。这是一个**等价关系**。

**例 5.4**（题型：复合关系与逆关系）
设 `A = {1,2,3}`，`R = {⟨1,2⟩, ⟨2,3⟩, ⟨3,1⟩}`，`S = {⟨1,1⟩, ⟨2,2⟩, ⟨3,3⟩, ⟨1,3⟩}`。
求 `R ∘ S`、`S ∘ R`、`R⁻¹`、`(R ∘ S)⁻¹`。
**解**：
① `R ∘ S`（先 R 后 S）：对每个 `⟨x,y⟩ ∈ R` 找 `⟨y,z⟩ ∈ S`：
- `⟨1,2⟩ ∈ R`，在 S 中找第一元素为 2 的：`⟨2,2⟩` → 得 `⟨1,2⟩`
- `⟨2,3⟩ ∈ R`，在 S 中找第一元素为 3 的：`⟨3,3⟩` → 得 `⟨2,3⟩`
- `⟨3,1⟩ ∈ R`，在 S 中找第一元素为 1 的：`⟨1,1⟩, ⟨1,3⟩` → 得 `⟨3,1⟩, ⟨3,3⟩`

`R ∘ S = {⟨1,2⟩, ⟨2,3⟩, ⟨3,1⟩, ⟨3,3⟩}`

② `S ∘ R`（先 S 后 R）：对每个 `⟨x,y⟩ ∈ S` 找 `⟨y,z⟩ ∈ R`：
- `⟨1,1⟩ ∈ S`，找 R 中第一元素为 1 的：`⟨1,2⟩` → `⟨1,2⟩`
- `⟨2,2⟩ ∈ S`，找 R 中第一元素为 2 的：`⟨2,3⟩` → `⟨2,3⟩`
- `⟨3,3⟩ ∈ S`，找 R 中第一元素为 3 的：`⟨3,1⟩` → `⟨3,1⟩`
- `⟨1,3⟩ ∈ S`，找 R 中第一元素为 3 的：`⟨3,1⟩` → `⟨1,1⟩`

`S ∘ R = {⟨1,2⟩, ⟨2,3⟩, ⟨3,1⟩, ⟨1,1⟩}`

**注意 `R ∘ S ≠ S ∘ R`**（一个有 `⟨3,3⟩` 无 `⟨1,1⟩`，另一个相反）——**复合不满足交换律**。

③ `R⁻¹ = {⟨2,1⟩, ⟨3,2⟩, ⟨1,3⟩}`
④ `(R∘S)⁻¹ = S⁻¹ ∘ R⁻¹`：
`S⁻¹ = {⟨1,1⟩, ⟨2,2⟩, ⟨3,3⟩, ⟨3,1⟩}`，`R⁻¹ = {⟨2,1⟩, ⟨3,2⟩, ⟨1,3⟩}`。
先 `S⁻¹` 后 `R⁻¹`：`⟨1,1⟩→⟨1,3⟩` 得 `⟨1,3⟩`；`⟨2,2⟩→⟨2,1⟩` 得 `⟨2,1⟩`；`⟨3,3⟩→⟨3,2⟩` 得 `⟨3,2⟩`；`⟨3,1⟩→⟨1,3⟩` 得 `⟨3,3⟩`。
`(R∘S)⁻¹ = {⟨1,3⟩, ⟨2,1⟩, ⟨3,2⟩, ⟨3,3⟩}`
**验证**：直接对 ① 的结果取逆：`{⟨2,1⟩, ⟨3,2⟩, ⟨1,3⟩, ⟨3,3⟩}` ✓ 一致。
**答案**：见上。

**例 5.5**（题型：求三种闭包）
设 `A = {1,2,3}`，`R = {⟨1,2⟩, ⟨2,3⟩}`。求 `r(R)`、`s(R)`、`t(R)`。
**解**：
① **自反闭包**：`r(R) = R ∪ I_A = {⟨1,2⟩, ⟨2,3⟩, ⟨1,1⟩, ⟨2,2⟩, ⟨3,3⟩}`
② **对称闭包**：`R⁻¹ = {⟨2,1⟩, ⟨3,2⟩}`，`s(R) = R ∪ R⁻¹ = {⟨1,2⟩, ⟨2,3⟩, ⟨2,1⟩, ⟨3,2⟩}`
③ **传递闭包**（`n = 3`，算到 `R³`）：
- `R² = R ∘ R`：`⟨1,2⟩∗⟨2,3⟩ → ⟨1,3⟩`；`⟨2,3⟩` 后面无（R 中没有第一元素为 3 的）→ `R² = {⟨1,3⟩}`
- `R³ = R² ∘ R`：`⟨1,3⟩` 后面 R 中无第一元素为 3 的 → `R³ = ∅`
- `t(R) = R ∪ R² ∪ R³ = {⟨1,2⟩, ⟨2,3⟩, ⟨1,3⟩}`

**验证**：`t(R)` 传递吗？`⟨1,2⟩` + `⟨2,3⟩` → 需 `⟨1,3⟩` ✓ 在。其他组合无可配对的。→ 传递 ✓
**答案**：`r(R) = R ∪ I_A`；`s(R) = {⟨1,2⟩,⟨2,1⟩,⟨2,3⟩,⟨3,2⟩}`；`t(R) = {⟨1,2⟩,⟨2,3⟩,⟨1,3⟩}`。

**例 5.6**（题型：沃舍尔算法求传递闭包）
设 `A = {1,2,3,4}`，`R` 的矩阵为
```
     1  2  3  4
 1 ⎡ 0  1  0  0 ⎤
 2 ⎢ 0  0  1  0 ⎥
 3 ⎢ 0  0  0  0 ⎥
 4 ⎣ 1  0  0  0 ⎦
```
用沃舍尔算法求 `t(R)`。
**解**：
**k = 1**：第 1 列中 `M[4][1] = 1`；第 1 行中 `M[1][2] = 1` → 置 `M[4][2] = 1`。
```
 1 ⎡ 0  1  0  0 ⎤
 2 ⎢ 0  0  1  0 ⎥
 3 ⎢ 0  0  0  0 ⎥
 4 ⎣ 1  1  0  0 ⎦
```
**k = 2**：第 2 列有 `M[1][2] = 1, M[4][2] = 1`；第 2 行有 `M[2][3] = 1` → 置 `M[1][3] = 1, M[4][3] = 1`。
```
 1 ⎡ 0  1  1  0 ⎤
 2 ⎢ 0  0  1  0 ⎥
 3 ⎢ 0  0  0  0 ⎥
 4 ⎣ 1  1  1  0 ⎦
```
**k = 3**：第 3 列有 `M[1][3]=1, M[2][3]=1, M[4][3]=1`；第 3 行全 0 → **无新增**（第 3 行没有出边）。
**k = 4**：第 4 列全 0 → 无新增。
**结果**：
```
M_t = ⎡ 0  1  1  0 ⎤
      ⎢ 0  0  1  0 ⎥
      ⎢ 0  0  0  0 ⎥
      ⎣ 1  1  1  0 ⎦
```
`t(R) = {⟨1,2⟩, ⟨1,3⟩, ⟨2,3⟩, ⟨4,1⟩, ⟨4,2⟩, ⟨4,3⟩}`
**答案**：见矩阵。
> **为什么 3、4 两轮没有变化**：3 号点没有出边（第 3 行全 0），所以不可能经它中转成功；4 号点没有入边（第 4 列全 0），所以不可能到达它。**这两条是加速判断的关键**。

**例 5.7**（题型：等价关系与划分互推）
设 `A = {1, 2, 3, 4, 5, 6}`，R 是 A 上「模 3 同余」关系，即 `⟨x,y⟩ ∈ R ⟺ x ≡ y (mod 3)`。
(1) 证明 R 是等价关系；(2) 求所有等价类；(3) 写出商集 `A/R`；(4) `|A/R|`。
**证明**：
(1) ① **自反**：任取 `x ∈ A`，`x − x = 0 = 3 × 0`，故 `x ≡ x (mod 3)`，`⟨x,x⟩ ∈ R` ✓
② **对称**：设 `⟨x,y⟩ ∈ R`，即 `3 | (x − y)`。则 `3 | (y − x)`（因 `y − x = −(x − y)`），故 `⟨y,x⟩ ∈ R` ✓
③ **传递**：设 `⟨x,y⟩ ∈ R` 且 `⟨y,z⟩ ∈ R`，即 `3|(x−y)` 且 `3|(y−z)`。由整除的可加性，`3 | [(x−y) + (y−z)] = x − z`，故 `⟨x,z⟩ ∈ R` ✓
三条都满足，R 是等价关系。∎
**解**：
(2) 按余数分类：
- 余 1：`[1]_R = {1, 4}`（`1, 4, 7, …` 中属于 A 的）
- 余 2：`[2]_R = {2, 5}`
- 余 0：`[3]_R = {3, 6}`
(3) `A/R = {{1,4}, {2,5}, {3,6}}`
(4) `|A/R| = 3`
**答案**：`A/R = {{1,4}, {2,5}, {3,6}}`，共 3 个等价类。
> **注意**：`[4]_R` 和 `[1]_R` 是**同一个等价类**，不能重复列出。商集里每个等价类只出现一次。

**例 5.8**（题型：由划分构造等价关系）
设 `A = {a, b, c, d}`，划分 `π = {{a, b}, {c}, {d}}`。求对应的等价关系 R 及其关系矩阵。
**解**：
规则：**同一块内的元素两两配对，再加上所有对角线**。
- 块 `{a, b}` 贡献：`⟨a,a⟩, ⟨b,b⟩, ⟨a,b⟩, ⟨b,a⟩`
- 块 `{c}` 贡献：`⟨c,c⟩`
- 块 `{d}` 贡献：`⟨d,d⟩`

`R = {⟨a,a⟩, ⟨b,b⟩, ⟨c,c⟩, ⟨d,d⟩, ⟨a,b⟩, ⟨b,a⟩}`
矩阵（顺序 a, b, c, d）：
```
     a  b  c  d
 a ⎡ 1  1  0  0 ⎤
 b ⎢ 1  1  0  0 ⎥
 c ⎢ 0  0  1  0 ⎥
 d ⎣ 0  0  0  1 ⎦
```
**验证**：对角线全 1 ✓ 自反；矩阵对称 ✓；块内两两配齐 ✓ 传递。`|R| = 2² + 1² + 1² = 6`。
**答案**：`|R| = 6`（公式：各块大小平方之和 `2² + 1² + 1² = 6`）。

**例 5.9**（题型：哈斯图与特殊元素）
设 `A = {1, 2, 3, 4, 6, 8, 12, 24}`，偏序关系为整除 `|`。
(1) 画出哈斯图；(2) 取 `B = {2, 3, 4}`，求 B 的极大元、极小元、最大元、最小元、上界、下界、上确界、下确界。
**解**：
(1) **先求所有覆盖关系**：
- 覆盖 1 的：2, 3（`1|2, 1|3`，中间无元素）
- 覆盖 2 的：4, 6（`2|4, 2|6`；`2|8` 但中间有 4，不覆盖；`2|12` 但中间有 4 或 6）
- 覆盖 3 的：6, 12（`3|6` ✓；`3|12` 中间有 6，不覆盖）
- 覆盖 4 的：8, 12（`4|8` ✓；`4|12` ✓）
- 覆盖 6 的：12, 24（`6|12` ✓；`6|24` 中间有 12，不覆盖）
- 覆盖 8 的：24（`8|24` ✓）
- 覆盖 12 的：24（`12|24` ✓）
- 24 是最大元，没有覆盖它的

**哈斯图**：

```
                    24
                   ╱  ╲
                 12    8
                ╱ ╲   ╱
               6   4
              ╱ ╲ ╱
             3    2
              ╲  ╱
                1
```
（说明：4 上面接 8 和 12；8 上面接 24；12 上面接 24；3 上面接 6 和 12；实际图中 12 有两条向下的线分别到 6 和 4。）

(2) 分析 `B = {2, 3, 4}`：
- **极大元**：B 中有谁是别人整除不了的？
  - 2：`2|4` ✓（4 在 B 中且 2 ≺ 4）→ 2 不是极大元
  - 3：B 中没有 3 的倍数 → **3 是极大元**
  - 4：B 中没有 4 的倍数（6、8、12 都不在 B 中）→ **4 是极大元**

  **极大元 = {3, 4}**
- **极小元**：
  - 2：B 中有谁整除 2？只有 2 自己 → **2 是极小元**
  - 3：同理 → **3 是极小元**
  - 4：`2|4` 且 `2 ≺ 4` → 4 不是极小元

  **极小元 = {2, 3}**
- **最大元**：需要 B 中某元素被全体整除。2 与 3 不可比 → **最大元不存在**
- **最小元**：需要某元素整除全体。3 ∤ 2, 3 ∤ 4 → **最小元不存在**
- **上界**（A 中同时是 2, 3, 4 的倍数）：`lcm(2,3,4) = 12`。12 的倍数在 A 中还有 24。→ **上界 = {12, 24}**
- **下界**（A 中同时整除 2, 3, 4）：`gcd(2,3,4) = 1`。1 的约数只有 1。→ **下界 = {1}**
- **上确界** = 上界的最小元 = **12**
- **下确界** = 下界的最大元 = **1**

**答案**：极大元 {3,4}；极小元 {2,3}；最大元不存在；最小元不存在；上界 {12,24}；下界 {1}；上确界 12；下确界 1。

**例 5.10**（题型：性质证明）
设 R 是集合 A 上的对称关系，证明 `r(R)` 也是对称的。
**证明**：
由定义，`r(R) = R ∪ I_A`。
任取 `⟨x, y⟩ ∈ r(R)`，分两种情形：
- **情形 1**：`⟨x,y⟩ ∈ R`。因 R 对称，`⟨y,x⟩ ∈ R ⊆ r(R)` ✓
- **情形 2**：`⟨x,y⟩ ∈ I_A`。由 `I_A` 的定义 `x = y`，故 `⟨y,x⟩ = ⟨x,y⟩ ∈ I_A ⊆ r(R)` ✓
两种情形都得 `⟨y,x⟩ ∈ r(R)`，故 `r(R)` 是对称的。∎
> **为什么分两种情形**：`r(R)` 是并集，元素可能来自 R 也可能来自 `I_A`，必须分别处理。

## 易错点提醒

1. **把有序对当集合**。错：写 `⟨1,2⟩ = {1,2}`。正确：`⟨1,2⟩ ≠ ⟨2,1⟩`，但 `{1,2} = {2,1}`——有序对**有序**，是不同概念。
2. **以为笛卡儿积可交换**。错：默认 `A × B = B × A`。正确：只有当 `A = B` 或其中一个为空集时才相等。
3. **把自反与反自反当互补**。错：「R 不自反，所以 R 反自反」。正确：存在**既不自反也不反自反**的关系（如 `A={1,2}`，`R={⟨1,1⟩}`）。判定时必须**分别检查**。
4. **把对称与反对称当互补**。错：「R 对称，所以 R 不反对称」。正确：`I_A` 和 `∅` **既对称又反对称**。判定时同样要**分别检查**。
5. **传递判定漏查**。错：只看「相邻两条边」。正确：必须枚举**所有** `x→y`、`y→z` 的配对（包括自环参与的配对）。
6. **复合方向搞反**。错：把 `R ∘ S` 理解成「先 S 后 R」。正确：按本书约定 `R ∘ S` 是**先 R 后 S**：`⟨x,z⟩ ∈ R∘S ⟺ ∃y(⟨x,y⟩ ∈ R ∧ ⟨y,z⟩ ∈ S)`。做矩阵乘法时 `M_{R∘S} = M_R ⊙ M_S` 也印证这个顺序。
7. **`(R∘S)⁻¹` 写成 `R⁻¹∘S⁻¹`**。错：顺序不变。正确：`(R∘S)⁻¹ = S⁻¹ ∘ R⁻¹`——**顺序必须颠倒**。
8. **传递闭包只算到 `R²`**。错：以为 `t(R) = R ∪ R²` 就够了。正确：必须算到 `Rⁿ`（`n = |A|`），因为可能存在长度为 n 的通路。`|A| = 4` 时通路的长度最多 4。
9. **闭包运算顺序随意调换**。错：以为 `rs(R) = sr(R)` 一定成立。正确：一般情况下 `rs(R) ≠ sr(R)`。**三个闭包一起做时，只有把 `t` 放在最后才安全**：`tsr(R) = rts(R) = trs(R)`，三者都等于包含 R 的最小等价关系；而 **`str(R)` 一般不相等** ✘（`t(R)` 对称化后一般不再传递）。反例见 5.5.4：`A = {1,2,3,4}`、`R = {⟨1,2⟩, ⟨1,3⟩}` 时 `tsr(R)` 有 10 个元素，`str(R)` 只有 8 个。
10. **商集写成原集合元素**。错：`A/R = {1, 4, 2, 5, 3, 6}`。正确：商集的元素是**等价类**：`A/R = {{1,4}, {2,5}, {3,6}}`。
11. **等价类重复计数**。错：把 `[1]_R` 和 `[4]_R` 当作两个不同的等价类各列一次。正确：`[1]_R = [4]_R`，是**同一个**等价类，只列一次。
12. **哈斯图保留所有边**。错：把传递性推出的边也画上（如 1 到 6 的线）。正确：哈斯图**只画覆盖关系**，去自环、去传递边、去箭头。
13. **「最大元」与「极大元」混淆**。错：以为极大元唯一。正确：**最大元唯一（可不存在），极大元可多个（有限集必存在）**。同理最小元与极小元。
14. **上界必须在 B 内**。错：以为上界也是 B 的元素。正确：**上界（下界）在 A 中取，不要求在 B 中**；最大元（最小元）**必须属于 B**。
15. **`R` 传递时以为 `s(R)` 也传递**。错：默认闭包保持传递性。正确：`R = {⟨1,2⟩}` 传递，但 `s(R) = {⟨1,2⟩,⟨2,1⟩}` **不传递**（缺 `⟨1,1⟩`）。

## 本章小结

1. **有序对** `⟨x,y⟩` 有序；**笛卡儿积** `A × B` 是「配对的全集」，`|A×B| = |A|·|B|`，不可交换。
2. **关系 = 笛卡儿积的子集**；`|A| = n` 时 A 上有 `2^(n²)` 个关系。
3. 三种表示：**集合 ／ 关系矩阵 ／ 关系图**；三个特殊关系：`∅`、`E_A`、`I_A`。
4. **`I_A` 是复合的单位元**：`R ∘ I_A = I_A ∘ R = R`；`(R∘S)⁻¹ = S⁻¹ ∘ R⁻¹`。
5. **五种性质**：自反（对角线全 1）、反自反（对角线全 0）、对称（矩阵对称）、反对称（不同点间无双向边）、传递（`R∘R ⊆ R`）。**自反与反自反不互补，对称与反对称不互补。**
6. **三种闭包**：`r(R) = R ∪ I_A`；`s(R) = R ∪ R⁻¹`；`t(R) = R ∪ R² ∪ … ∪ Rⁿ`（`n = |A|`）。求 `t(R)` 可用**沃舍尔算法**。
7. **等价关系 = 自反 + 对称 + 传递**；等价类三性质：非空、相等或不相交、并为 A；**商集 `A/R`** 的元素是等价类。
8. **等价关系 ↔ 划分 一一对应**；n 元素集的划分数是**贝尔数** **`B₀, B₁, B₂, … = 1, 1, 2, 5, 15, 52, …`**。
9. **偏序关系 = 自反 + 反对称 + 传递**；**哈斯图**三规则：去自环、去传递边、去箭头。
10. **四组特殊元素**：最大/最小元（唯一，须在 B 内）、极大/极小元（可多个）、上界/下界（在 A 内取）、上确界/下确界（上界的最小 / 下界的最大，至多一个）。

> **一句话记住本章**：**关系就是一张「有向边表」；五种性质就是五个看图口诀（自环全有/全无、边成双、不成双、两步能到一步也能到）；闭包就是「把缺的边补到最少」；等价关系把集合切成不重叠的块，偏序关系把元素排成一个带分叉的层级。**
