**本章的地位**：一阶逻辑（First-Order Logic）是**数学的语言本身**。「对所有 ε>0 存在 δ>0……」这种极限定义、数据库的 SQL 查询、程序的循环不变式，形式化后都是一阶逻辑公式。它补齐了命题逻辑「拆不开句子内部结构」的短板。

## 学习目标

1. 能说出命题逻辑的三个局限，并用一例说明。
2. 能区分个体常项、个体变项、个体域；能把自然语言写成带量词的谓词公式。
3. 能背出**四条符号化黄金法则**，正确处理「所有 A 都是 B」与「有的 A 是 B」。
4. 能画出公式的语法树，指出每个量词的**辖域**，判断变元是**约束**还是**自由**。
5. 能正确使用**换名规则**（约束变元改名）和**代替规则**（自由变元代入）。
6. 能默写量词否定律、辖域收缩扩张律、量词分配律，并说明哪条分配律不成立。
7. 能把任意一阶逻辑公式化为**前束范式**（四步法）。
8. 能使用 US / UG / ES / EG 四条规则完成一阶推理，并知道 ES 的使用限制。

## 3.1 一阶逻辑基本概念

### 3.1.1 命题逻辑的局限性

**命题逻辑的三个局限**：

| 局限 | 例子 | 后果 |
|---|---|---|
| ① **拆不开句子内部结构** | 「张三是人」和「李四是人」被当成两个无关的原子命题 | 无法表达共性 |
| ② **无法表达「所有」「存在」** | 「人都会死」不能写 | 经典三段论失效 |
| ③ **无法刻画量词之间的关系** | 「所有」与「存在」的否定关系 | |

**经典反例（三段论）**：
```
前提 1：人都会死。
前提 2：张三是人。
结论：  张三会死。
```
在命题逻辑里，三个句子是三个**互不相关的原子命题** `P`、`Q`、`R`。`P ∧ Q → R` **不是**重言式，所以推不出来。

**为什么一阶逻辑能推**：把句子拆成「个体 + 谓词 + 量词」：
- `M(x)`：x 是人；`D(x)`：x 会死；`a`：张三。
- 前提 1：`∀x (M(x) → D(x))`
- 前提 2：`M(a)`
- 结论：`D(a)`

此时用「全称例化」+「假言推理」两步就推出来了（见 3.3 节）。

### 3.1.2 个体词、谓词与量词

**定义 3.1（个体词）**：
- **个体常项（Individual Constant）**：表示具体对象的词，记 `a, b, c, …`。如「张三」「3」。
- **个体变项（Individual Variable）**：表示抽象对象的词，记 `x, y, z, …`。
- **个体域（Domain of Individuals）**：个体变项的取值范围，记 `D`。**未特别说明时，个体域取「由宇宙间一切事物组成的集合」**（全总个体域）。

> **重点**：个体域直接决定公式的真值！`∀x (x > 0)` 在 `D = 正整数` 上为真，在 `D = 整数` 上为假。**做符号化题必须写明个体域**。

**定义 3.2（谓词）**：表示个体性质或个体之间关系的词，记 `P(x)`、`Q(x, y)`。
- **一元谓词**：`P(x)` 表示「x 具有性质 P」。
- **n 元谓词**：`P(x₁, x₂, …, xₙ)` 表示 n 个个体间的关系。
- **0 元谓词**：不含个体变项的谓词，**就是一个命题**。

> **直观类比**：谓词像「函数」，个体是「输入」，真值是「输出」。`P(x)` 是「x 是素数」这个函数，输入 3 输出「真」，输入 4 输出「假」。谓词也叫**命题函数（Propositional Function）**。

**定义 3.3（量词）**：

| 量词 | 记号 | 读法 | 含义 |
|---|---|---|---|
| 全称量词 | `∀x` | 对所有 x | 个体域中**每个**个体都满足 |
| 存在量词 | `∃x` | 存在 x | 个体域中**至少有一个**个体满足 |

**量词的真值规定**：
- `∀x P(x)` 为真 ⟺ 个体域中**所有**个体都使 `P` 为真；只要有一个反例就为假。
- `∃x P(x)` 为真 ⟺ 个体域中**至少有一个**个体使 `P` 为真；一个都没有就为假。

> **易错**：`∃` 是「**至少一个**」，不是「只有一个」。要表达「恰好一个」必须写成 `∃x (P(x) ∧ ∀y (P(y) → y = x))`。

**定义 3.4（特性谓词）**：当个体域取**全总个体域**时，为了限定「在某个范围内讨论」，需引入刻画该范围的谓词，称为**特性谓词**。

### 3.1.3 一阶逻辑命题符号化

**四条黄金法则（必须背到条件反射）**：

> **法则 1**：「**所有** A 都是 B」→ `∀x (A(x) → B(x))` —— 全称量词配**蕴含**
> **法则 2**：「**有的** A 是 B」→ `∃x (A(x) ∧ B(x))` —— 存在量词配**合取**
> **法则 3**：「**没有** A 是 B」→ `¬∃x (A(x) ∧ B(x))` ⇔ `∀x (A(x) → ¬B(x))`
> **法则 4**：「**有的** A **不是** B」→ `∃x (A(x) ∧ ¬B(x))`

**为什么法则 1 用 `→` 而法则 2 用 `∧`？**（这是本节的灵魂）

看「所有人都是要死的」：
- 写成 `∀x (M(x) → D(x))`：对每个个体，**如果**它是人，**那么**它会死。对一块石头，前件假，蕴含式为真——不违反原句 ✓。
- 若写成 `∀x (M(x) ∧ D(x))`：要求**每个个体都是人且会死**，石头也要是人，荒谬 ✗。

看「有的人是左撇子」：
- 写成 `∃x (M(x) ∧ L(x))`：**存在**一个个体，它既是人又是左撇子 ✓。
- 若写成 `∃x (M(x) → L(x))`：只要取一个不是人的个体（如石头），前件假、蕴含式为真，于是整个公式**恒真**，荒谬 ✗。

> **一句话记住**：**全称配箭头（∀ 配 →），存在配合取（∃ 配 ∧）**。这两个字写反是本章第一大失分点。

**常用句式符号化对照表**：

| 自然语言 | 符号化 |
|---|---|
| 所有 A 都是 B | `∀x (A(x) → B(x))` |
| 所有 A 都不是 B | `∀x (A(x) → ¬B(x))` |
| 有的 A 是 B | `∃x (A(x) ∧ B(x))` |
| 有的 A 不是 B | `∃x (A(x) ∧ ¬B(x))` |
| 没有 A 是 B | `¬∃x (A(x) ∧ B(x))` |
| 并非所有 A 都是 B | `¬∀x (A(x) → B(x))` ⇔ `∃x (A(x) ∧ ¬B(x))` |
| 只有 A 才是 B | `∀x (B(x) → A(x))` |
| 除了 A 都不是 B | `∀x (B(x) → A(x))` |

**例**：在全总个体域下符号化「每个实数都有相反数」。
**解**：设 `R(x)`：x 是实数；`N(x, y)`：y 是 x 的相反数（即 `x + y = 0`）。
`∀x (R(x) → ∃y (R(y) ∧ N(x, y)))`
读作：对每个个体 x，若 x 是实数，则存在个体 y，y 是实数且 y 是 x 的相反数。✓

### 3.1.4 一阶逻辑公式与分类

**定义 3.5（项）**：
1. 个体常项和个体变项是项；
2. 若 f 是 n 元函数，`t₁,…,tₙ` 是项，则 `f(t₁,…,tₙ)` 是项；
3. 只有有限次应用 1、2 得到的才是项。

**定义 3.6（原子公式）**：若 `P` 是 n 元谓词，`t₁,…,tₙ` 是项，则 `P(t₁,…,tₙ)` 是**原子公式**。

**定义 3.7（合式公式）**：
1. 原子公式是合式公式；
2. 若 A、B 是合式公式，则 `¬A`、`(A∧B)`、`(A∨B)`、`(A→B)`、`(A↔B)` 是合式公式；
3. 若 A 是合式公式，x 是个体变项，则 `∀xA`、`∃xA` 是合式公式；
4. 只有有限次应用 1~3 得到的才是合式公式。

**定义 3.8（辖域 / 约束变元 / 自由变元）**：
- **辖域（Scope）**：量词后面紧跟的**最小公式**，称为该量词的辖域。
- **约束变元（Bound Variable）**：在量词辖域内，与该量词同名的变元，称为**约束出现**。
- **自由变元（Free Variable）**：不在任何同名量词辖域内的变元，称为**自由出现**。

**判断步骤（三步走）**：
1. 从左往右扫描，找到每个量词，用括号标出它的**辖域**（`∀x` 后面若只有一个原子公式，辖域就到该原子公式结束；若有括号，就到配对括号）。
2. 在辖域内，与量词变元同名的出现 → **约束**。
3. 其余的出现 → **自由**。

> **重点**：同一个变元名在同一公式里**可能既约束又自由**！如 `∀x P(x) ∧ Q(x)` 中，第一个 `x` 是约束的，第二个 `x` 是自由的。这时最好用换名规则区分开。

**例**：指出 `∀x (P(x) → ∃y Q(x, y)) ∨ R(x)` 中各变元的身份。
**解**：
- `∀x` 的辖域是 `(P(x) → ∃y Q(x, y))`（到配对右括号）。
  - 其中的 `x`（在 `P(x)` 和 `Q(x,y)` 里）都是**约束出现**。
- `∃y` 的辖域是 `Q(x, y)`（紧跟的原子公式）。
  - 其中的 `y` 是**约束出现**。
- 最后的 `R(x)` 里的 `x` **不在** `∀x` 的辖域内 → **自由出现**。
**答案**：`x` 在辖域内 2 次约束出现、在 `R(x)` 中 1 次自由出现；`y` 约束出现。这是一个**开式**（有自由变元）。

**定义 3.9（闭式与开式）**：
- **闭式（Closed Formula / 句子 Sentence）**：**没有自由变元**的公式。闭式有确定的真值。
- **开式（Open Formula）**：含自由变元的公式。它的真值依赖于自由变元的取值。

> **考点**：只有闭式才能判断真值。做「判断公式类型」的题，先检查有没有自由变元。

**定义 3.10（换名规则）**：对约束变元可以改名。把量词 `∀x`（或 `∃x`）中的 `x` 及其**辖域内所有约束出现的 `x`** 一起改成一个**新的**变元名 `y`（`y` 在辖域内不出现），公式含义不变。

**定义 3.11（代替规则）**：对自由变元可以代入。把公式中某个**自由出现的**变元 `x` 的**所有**出现，替换成一个项 `t`，公式含义不变。

**两条规则对照表**：

| 对比项 | 换名规则 | 代替规则 |
|---|---|---|
| 作用对象 | **约束变元** | **自由变元** |
| 处理范围 | 量词变元 + 辖域内该变元的**所有约束出现** | 公式中该变元的**所有自由出现** |
| 新名字要求 | 必须是辖域内未出现的**变元名** | 可以是任意**项**（可以含函数、常项） |
| 能否只改一部分 | **不能**（必须全改） | **不能**（必须全改自由出现） |
| 目的 | 避免同名冲突 | 代入具体值 / 项 |

> **易错**：换名时**只改了量词没改辖域内的变元**（或反过来），公式含义就变了。例：`∀x P(x, y)` 把量词改成 `∀z` 却不改 `P(x,y)` 里的 x，得到 `∀z P(x, y)`，此时 `x` 变成自由变元，公式含义完全变了。

## 3.2 一阶逻辑等值演算

### 3.2.1 一阶逻辑等值式与置换规则

**定义 3.12（等值）**：若公式 `A ↔ B` 在任何个体域、任何解释下都为真，则称 A 与 B **等值**，记 `A ⇔ B`。

**一、量词否定律（第一组，最基本）**

| 编号 | 等值式 | 白话 |
|---|---|---|
| Q1 | `¬∀x A(x) ⇔ ∃x ¬A(x)` | 「不是所有都 A」= 「有的不 A」 |
| Q2 | `¬∃x A(x) ⇔ ∀x ¬A(x)` | 「没有 A」= 「所有都不 A」 |

> **记忆口诀**：**否定穿过量词，量词翻转（∀↔∃），否定留给谓词**。

**例**：「并非所有学生都通过了考试」= 「有的学生没通过考试」。
`¬∀x (S(x) → P(x)) ⇔ ∃x ¬(S(x) → P(x)) ⇔ ∃x (S(x) ∧ ¬P(x))` ✓（最后一步用了 `¬(A→B) ⇔ A ∧ ¬B`）

**二、量词辖域收缩与扩张律（第二组）**

设 B **不含**变元 x（关键条件！）：

| 编号 | 等值式 |
|---|---|
| Q3 | `∀x (A(x) ∨ B) ⇔ ∀x A(x) ∨ B` |
| Q4 | `∀x (A(x) ∧ B) ⇔ ∀x A(x) ∧ B` |
| Q5 | `∃x (A(x) ∨ B) ⇔ ∃x A(x) ∨ B` |
| Q6 | `∃x (A(x) ∧ B) ⇔ ∃x A(x) ∧ B` |
| Q7 | `∀x (A(x) → B) ⇔ ∃x A(x) → B` |
| Q8 | `∃x (A(x) → B) ⇔ ∀x A(x) → B` |
| Q9 | `∀x (B → A(x)) ⇔ B → ∀x A(x)` |
| Q10 | `∃x (B → A(x)) ⇔ B → ∃x A(x)` |

> **重点**：Q7、Q8 里量词**翻转**了（`∀` 配 `→` 变成 `∃`），这是最容易记错的地方。原因：`A → B ⇔ ¬A ∨ B`，`∀x(¬A(x) ∨ B) ⇔ ∀x¬A(x) ∨ B ⇔ ¬∃xA(x) ∨ B ⇔ ∃xA(x) → B`。

**三、量词分配律（第三组）**

| 编号 | 等值式 | 是否成立 |
|---|---|---|
| Q11 | `∀x (A(x) ∧ B(x)) ⇔ ∀x A(x) ∧ ∀x B(x)` | ✓ **成立** |
| Q12 | `∃x (A(x) ∨ B(x)) ⇔ ∃x A(x) ∨ ∃x B(x)` | ✓ **成立** |
| Q13 | `∀x (A(x) ∨ B(x)) ⇔ ∀x A(x) ∨ ∀x B(x)` | ✗ **不成立** |
| Q14 | `∃x (A(x) ∧ B(x)) ⇔ ∃x A(x) ∧ ∃x B(x)` | ✗ **不成立** |

**为什么 Q13 不成立**？取个体域 = 整数，`A(x)`：x 是偶数，`B(x)`：x 是奇数。
- 左边 `∀x (偶(x) ∨ 奇(x))`：每个整数要么偶要么奇 → **真**。
- 右边 `∀x 偶(x) ∨ ∀x 奇(x)`：「所有整数都偶」假，「所有整数都奇」假 → `假 ∨ 假 = 假`。
左边真右边假，故不等值 ✗。

**为什么 Q14 不成立**？同域，`A(x)`：x 是偶数，`B(x)`：x 是奇数。
- 左边 `∃x (偶(x) ∧ 奇(x))`：不存在既偶又奇的整数 → **假**。
- 右边 `∃x 偶(x) ∧ ∃x 奇(x)`：都存在 → `真 ∧ 真 = 真`。
不等值 ✗。

**四、量词顺序（第四组）**

| 编号 | 关系 | 说明 |
|---|---|---|
| Q15 | `∀x∀y A(x,y) ⇔ ∀y∀x A(x,y)` | 同种量词可交换 |
| Q16 | `∃x∃y A(x,y) ⇔ ∃y∃x A(x,y)` | 同种量词可交换 |
| Q17 | `∃y∀x A(x,y) ⟹ ∀x∃y A(x,y)` | **单向**！反之不成立 |
| Q18 | `∀x∀y A ⟹ ∃y∀x A`，`∀x∀y A ⟹ ∀y∃x A` 等 | 各种单向蕴含 |

> **重点**：**`∀x∃y` 与 `∃y∀x` 不等值，只能单向推导（`∃∀ ⟹ ∀∃`）**。
> 例：个体域 = 实数，`A(x, y)`：`x + y = 0`。
> - `∀x∃y (x + y = 0)`：每个实数都有相反数 → **真**。
> - `∃y∀x (x + y = 0)`：存在一个实数 y 使所有 x 都满足 → **假**。
> 所以 `∀∃` 不能推 `∃∀`。

**五、其他重要等值式**

| 编号 | 等值式 |
|---|---|
| Q19 | `∀x A(x) ⟹ A(y)`（全称例化，见 3.3） |
| Q20 | `A(y) ⟹ ∃x A(x)`（存在推广，见 3.3） |
| Q21 | `∀x A(x) ⇔ ∀y A(y)`（换名，y 不在 A 中出现） |
| Q22 | `∃x A(x) ⇔ ∃y A(y)`（换名） |

### 3.2.2 一阶逻辑前束范式

**定义 3.13（前束范式）**：若公式形如
`Q₁x₁ Q₂x₂ … Qₖxₖ B`
其中每个 `Qᵢ` 是 `∀` 或 `∃`，`B` 是**不含量词**的公式，则称该公式为**前束范式（Prenex Normal Form）**。
`Q₁x₁ … Qₖxₖ` 称为**首部（前缀）**，`B` 称为**母式（矩阵）**。

**求前束范式的四步法**：

```
第1步  消去 → 和 ↔        （用蕴含等值式 A→B ⇔ ¬A∨B、等价等值式）
第2步  否定号内移          （用德摩根律 + 量词否定律 Q1、Q2，直到 ¬ 只作用于原子公式）
第3步  换名                （若不同量词用了同名变元，或自由变元与约束变元同名，先换名区分）
第4步  量词左移            （用量词辖域收缩扩张律 Q3~Q10，把所有量词移到公式最前面）
```

> **易错**：第 3 步（换名）最容易被忽略。如果不换名就把量词左移，会出错。例：`∀x P(x) ∨ ∃x Q(x)`，两个量词都用了 `x`，直接移成 `∀x∃x (P(x) ∨ Q(x))` 是**错的**——先要把第二个改成 `∃y Q(y)`，再得 `∀x∃y (P(x) ∨ Q(y))`。

**例**：求 `∀x (P(x) → ∃y Q(x, y))` 的前束范式。
**解**：
```
∀x (P(x) → ∃y Q(x, y))
= ∀x (¬P(x) ∨ ∃y Q(x, y))           第1步：消 →（蕴含等值式）
= ∀x ∃y (¬P(x) ∨ Q(x, y))           第4步：量词 ∃y 左移
                                     （用 Q5：∃y(A ∨ B) ⇔ ∃yA ∨ B，此处
                                      A = Q(x,y)，B = ¬P(x) 不含 y ✓）
```
**答案**：`∀x∃y (¬P(x) ∨ Q(x, y))`。

**例**：求 `¬∃x (P(x) ∧ ∀y Q(y))` 的前束范式。
**解**：
```
¬∃x (P(x) ∧ ∀y Q(y))
= ∀x ¬(P(x) ∧ ∀y Q(y))              第2步：Q2 量词否定律
= ∀x (¬P(x) ∨ ¬∀y Q(y))             第2步：德摩根律
= ∀x (¬P(x) ∨ ∃y ¬Q(y))             第2步：Q1 量词否定律
= ∀x ∃y (¬P(x) ∨ ¬Q(y))             第4步：Q5 量词左移（¬P(x) 不含 y）
```
**答案**：`∀x∃y (¬P(x) ∨ ¬Q(y))`。

**例**：求 `∃x P(x) → ∀y Q(y)` 的前束范式。
**解**：
```
∃x P(x) → ∀y Q(y)
= ¬∃x P(x) ∨ ∀y Q(y)                第1步：消 →
= ∀x ¬P(x) ∨ ∀y Q(y)                第2步：Q2
= ∀x (¬P(x) ∨ ∀y Q(y))              Q3 辖域扩张（∀y Q(y) 不含 x）
= ∀x ∀y (¬P(x) ∨ Q(y))              Q3 再扩张（¬P(x) 不含 y）
```
**答案**：`∀x∀y (¬P(x) ∨ Q(y))`。

## 3.3 一阶逻辑推理理论

### 3.3.1 四条量词推理规则

| 规则 | 名称 | 形式 | 适用条件 |
|---|---|---|---|
| **US** | 全称例化（Universal Specification） | `∀x A(x) ⟹ A(y)` | y 是**任意**个体（常项或变项） |
| **UG** | 全称推广（Universal Generalization） | `A(y) ⟹ ∀x A(x)` | **y 必须是任意的**，不能是对某个特殊个体的假设 |
| **ES** | 存在例化（Existential Specification） | `∃x A(x) ⟹ A(c)` | **c 必须是全新的常项**，此前未出现过 |
| **EG** | 存在推广（Existential Generalization） | `A(c) ⟹ ∃x A(x)` | c 是常项或变项 |

> **记忆法**：「**US 往下拆（∀ 拆成具体），EG 往上包（常项包成 ∃）；ES 挑一个新的，UG 收成所有**」。

**ES 规则的「全新常项」限制**（考试常考的陷阱）：
- `∃x P(x)` 和 `∃x Q(x)` 不能都例化成**同一个** `c`！
- 理由：`∃x P(x)` 说的是「存在一个 P」，`∃x Q(x)` 说的是「存在一个 Q」，这两个「存在者」**可能是不同的个体**。用同一个 `c` 就是把它们强行等同了。
- 正确做法：第一次用 `c`，第二次用 `d`。

**UG 规则的「任意性」限制**：
- 如果 `y` 是通过 ES 从 `∃x A(x)` 得到的特殊常项，就**不能**用 UG 把它推广成 `∀x A(x)`。
- 理由：`∃x A(x)` 只保证「有一个」，不保证「所有」。

### 3.3.2 一阶推理实例

**例**（经典三段论）：证明 `∀x (M(x) → D(x)), M(a) ⟹ D(a)`。
**证明**：
```
① ∀x (M(x) → D(x))    P 规则（前提）
② M(a)                P 规则（前提）
③ M(a) → D(a)         US 规则（由①，把 x 例化为常项 a）
④ D(a)                T 规则（由②③，I₃ 假言推理）
```
证毕。∎
> **这就是命题逻辑推不出来的那个三段论**。可见谓词逻辑的威力：多了一条 US 规则，推理能力严格强于命题逻辑。

**例**：证明 `∀x (P(x) → Q(x)), ∃x P(x) ⟹ ∃x Q(x)`。
**证明**：
```
① ∃x P(x)             P 规则（前提）
② ∀x (P(x) → Q(x))    P 规则（前提）
③ P(c)                ES 规则（由①，c 是全新常项）
④ P(c) → Q(c)         US 规则（由②）
⑤ Q(c)                T 规则（由③④，I₃）
⑥ ∃x Q(x)             EG 规则（由⑤）
```
证毕。∎
> **顺序很讲究**：必须**先用 ES 再用 US**。若先用 US 得到 `P(x) → Q(x)`（x 自由），再用 ES 引入 `c`，就无法把两者接上（一个是 x，一个是 c）。

**例**：证明 `∃x (P(x) ∧ Q(x)) ⟹ ∃x P(x) ∧ ∃x Q(x)`。
**证明**：
```
① ∃x (P(x) ∧ Q(x))    P 规则（前提）
② P(c) ∧ Q(c)         ES 规则（由①，c 全新）
③ P(c)                T 规则（由②，I₂ 化简律）
④ Q(c)                T 规则（由②，I₂ 化简律）
⑤ ∃x P(x)             EG 规则（由③）
⑥ ∃x Q(x)             EG 规则（由④）
⑦ ∃x P(x) ∧ ∃x Q(x)   T 规则（由⑤⑥，I₁₁ 合取引入）
```
证毕。∎
> **反向不成立**！`∃x P(x) ∧ ∃x Q(x) ⟹ ∃x (P(x) ∧ Q(x))` 是**无效**推理（「有人是男生」且「有人是女生」推不出「有人既是男生又是女生」）。这与前面 Q14 分配律不成立是同一件事。

### 3.3.3 一阶逻辑的不可判定性（了解）

**结论**：一阶逻辑的**有效性问题是不可判定的**（Church-Turing，1936）。即：不存在一个算法，能在有限步内判定任意一阶逻辑公式是否永真。
**但**：一阶逻辑是**半可判定的**——若公式永真，总能找到证明；若不永真，算法可能永远跑下去。
**对比**：命题逻辑的永真性是**可判定**的（用真值表，最多 `2ⁿ` 行）。

## 典型例题

**例 3.1**（题型：命题符号化）
在全总个体域下符号化下列命题：
(1) 不是所有的人都喜欢吃辣椒。
(2) 有些大学生不尊敬老师。
(3) 每一个实数都有相反数，且没有任何实数等于它的相反数加 1。

**解**：
设 `M(x)`：x 是人；`L(x)`：x 喜欢辣椒；`S(x)`：x 是大学生；`T(x)`：x 是老师；`R(x)`：x 是实数；`D(x,y)`：x 尊敬 y；`N(x,y)`：y 是 x 的相反数。

(1) 「不是所有 A 都是 B」= `¬∀x (M(x) → L(x))`，可化简为 `∃x (M(x) ∧ ¬L(x))`。
> **为什么化简**：`¬∀x(A→B) ⇔ ∃x¬(A→B) ⇔ ∃x(A ∧ ¬B)`。考试两种写法都接受，但化简后更符合「有的……不……」的直觉。

(2) 「有些大学生不尊敬老师」：存在量词配合取。
`∃x (S(x) ∧ ∃y (T(y) ∧ ¬D(x, y)))`
或等价地写成 `∃x∃y (S(x) ∧ T(y) ∧ ¬D(x, y))`。

(3) 「每一个实数都有相反数」+「没有任何实数等于它的相反数加 1」：
第一部分：`∀x (R(x) → ∃y (R(y) ∧ N(x, y)))`
第二部分：`¬∃x (R(x) ∧ (x = y + 1))` 这个写法有问题，因为 y 已被约束。正确写法是引入函数 `f(x) = x + 1`：
`¬∃x (R(x) ∧ x = f(opp(x)))`，其中 `opp(x)` 表示 x 的相反数。
更简洁的写法：设 `E(x)`：x 的相反数加 1 等于 x。则第二部分为 `∀x (R(x) → ¬E(x))`。
合并：`∀x (R(x) → ∃y (R(y) ∧ N(x, y))) ∧ ∀x (R(x) → ¬E(x))`

**答案**：(1) `∃x (M(x) ∧ ¬L(x))`；(2) `∃x∃y (S(x) ∧ T(y) ∧ ¬D(x, y))`；(3) 见上（关键是两部分用 `∧` 连接，且量词变元不能重名冲突）。

**例 3.2**（题型：判断辖域、约束与自由变元）
指出公式 `∀x (P(x) ∧ Q(y)) → ∃y R(x, y)` 中每个变元的身份。
**解**：
① **先括号化**（补全省略的括号）：`(∀x (P(x) ∧ Q(y))) → (∃y R(x, y))`。
**为什么**：`→` 的结合优先级最低，所以 `∀x(...)` 整体是前件。
② `∀x` 的辖域是 `(P(x) ∧ Q(y))`：
   - 里面的 `x` → **约束出现**
   - 里面的 `y` → **自由出现**（不在 `∀x` 辖域中，也不在任何 `∃y` 辖域中）
③ `∃y` 的辖域是 `R(x, y)`：
   - 里面的 `y` → **约束出现**
   - 里面的 `x` → **自由出现**（不在任何 `∀x` 辖域中）
**答案**：`x` 有 1 次约束出现（在 `P(x)`）、1 次自由出现（在 `R(x,y)`）；`y` 有 1 次自由出现（在 `Q(y)`）、1 次约束出现（在 `R(x,y)`）。该公式是**开式**。
> **说明**：同一个变元名在一个公式里既约束又自由，是合法的但容易出错，做题时应先用换名规则区分：`∀u (P(u) ∧ Q(y)) → ∃v R(x, v)`。

**例 3.3**（题型：换名规则 / 代替规则）
对公式 `∀x (P(x) → Q(x, y)) ∧ R(y, z)`：
(1) 用换名规则把约束变元 x 改名为 u；
(2) 用代替规则把自由变元 y 代入常项 a。
**解**：
(1) 换名：`x` 在辖域内（`P(x)` 和 `Q(x,y)` 中的 x）有 2 次约束出现，必须**一起改**：
`∀u (P(u) → Q(u, y)) ∧ R(y, z)`
> **为什么全改**：只改量词会得到 `∀u (P(x) → Q(x, y)) ∧ R(y, z)`，此时 `x` 变成了自由变元，公式含义改变。
> **为什么选 u**：`u` 在 `∀x` 的辖域内**未出现过**。如果选 `y` 就撞车了（`y` 已是自由变元，改名后会把它意外地约束住）。

(2) 代替：`y` 在公式中有 2 次自由出现（`Q(x,y)` 中的 y 和 `R(y,z)` 中的 y），必须**一起替换**为 `a`：
`∀x (P(x) → Q(x, a)) ∧ R(a, z)`
**答案**：见上。

**例 3.4**（题型：求前束范式）
求 `∀x (P(x) → Q(x)) → (∃y R(y) → ∃z S(z))` 的前束范式。
**解**：
```
原式 = ¬∀x (P(x) → Q(x)) ∨ (∃y R(y) → ∃z S(z))     第1步：消最外层 →
     = ∃x ¬(P(x) → Q(x)) ∨ (¬∃y R(y) ∨ ∃z S(z))     第2步：Q1 + 消内层 →
     = ∃x (P(x) ∧ ¬Q(x)) ∨ (∀y ¬R(y) ∨ ∃z S(z))     第2步：¬(A→B) ⇔ A∧¬B，Q2
     = ∃x (P(x) ∧ ¬Q(x)) ∨ ∀y (¬R(y) ∨ ∃z S(z))     Q3 辖域扩张（∃z S(z) 不含 y）
     = ∃x (P(x) ∧ ¬Q(x)) ∨ ∀y ∃z (¬R(y) ∨ S(z))     Q5 辖域扩张（¬R(y) 不含 z）
     = ∃x ∀y ∃z [ (P(x) ∧ ¬Q(x)) ∨ (¬R(y) ∨ S(z)) ] Q3、Q5 依次左移
```
**答案**：`∃x∀y∃z ( (P(x) ∧ ¬Q(x)) ∨ ¬R(y) ∨ S(z) )`
**校验**：首部 `∃x∀y∃z` 三个量词，母式中不含任何量词 ✓。

> **换名检查**：本题三个量词分别用了 x、y、z，不重名，所以第 3 步可以跳过。若原式是 `∀x P(x) ∨ ∃x Q(x)`，就必须先把第二个 x 换成 y。

**例 3.5**（题型：量词否定律应用）
写出「并非每个学生都选修了每一门课程」的等值形式（否定词只作用于原子公式）。
**解**：
① 符号化：设 `S(x)`：x 是学生；`C(y)`：y 是课程；`T(x, y)`：x 选修了 y。
原句：`¬∀x (S(x) → ∀y (C(y) → T(x, y)))`
② 逐层内移否定：
```
= ∃x ¬(S(x) → ∀y (C(y) → T(x, y)))        Q1
= ∃x (S(x) ∧ ¬∀y (C(y) → T(x, y)))        ¬(A→B) ⇔ A ∧ ¬B
= ∃x (S(x) ∧ ∃y ¬(C(y) → T(x, y)))        Q1
= ∃x (S(x) ∧ ∃y (C(y) ∧ ¬T(x, y)))        ¬(A→B) ⇔ A ∧ ¬B
= ∃x∃y (S(x) ∧ C(y) ∧ ¬T(x, y))           辖域扩张
```
**答案**：`∃x∃y (S(x) ∧ C(y) ∧ ¬T(x, y))`，即「存在一个学生和一个课程，该学生没选修该课程」。
> **直觉验证**：「不是每个人都选了每门课」确实等价于「有人有某门课没选」✓。

**例 3.6**（题型：一阶推理证明）
证明 `∀x (P(x) → (Q(x) ∨ R(x))), ∀x (P(x) ∧ ¬Q(x)) ⟹ ∃x R(x)`。
**证明**：
```
① ∀x (P(x) ∧ ¬Q(x))              P 规则（前提）
② P(c) ∧ ¬Q(c)                    US 规则（由①，c 任意常项）
                                     —— 注意：这里也可用 ES，但 US 更自然，
                                     因为前提对"所有 x"成立，当然对 c 成立
③ ∀x (P(x) → (Q(x) ∨ R(x)))      P 规则（前提）
④ P(c) → (Q(c) ∨ R(c))            US 规则（由③）
⑤ P(c)                            T 规则（由②，I₂ 化简律）
⑥ Q(c) ∨ R(c)                     T 规则（由④⑤，I₃ 假言推理）
⑦ ¬Q(c)                           T 规则（由②，I₂ 化简律）
⑧ R(c)                            T 规则（由⑥⑦，I₅ 析取三段论）
⑨ ∃x R(x)                         EG 规则（由⑧）
```
证毕。∎
> **为什么第②步用 US 而不是 ES**：前提 `∀x (P(x) ∧ ¬Q(x))` 是全称命题，对**任意**个体都成立，所以取任意常项 `c` 即可，不需要「全新常项」的限制。能用 US 就别用 ES，因为 ES 有额外限制、更容易出错。

**例 3.7**（题型：指出推理错误）
判断下面的推理是否正确：「有些学生是党员，有些学生是团员，所以有些学生既是党员又是团员。」
**解**：
① 符号化：设 `S(x)`：x 是学生；`P(x)`：x 是党员；`T(x)`：x 是团员。
前提：`∃x (S(x) ∧ P(x))`，`∃x (S(x) ∧ T(x))`
结论：`∃x (S(x) ∧ P(x) ∧ T(x))`
② 用前面例 3 的结论：`∃x P(x) ∧ ∃x Q(x)` **不能**推出 `∃x (P(x) ∧ Q(x))`（对应 Q14 分配律不成立）。
③ 从直觉看：可能「党员的学生」和「团员的学生」是**不同的人**。
**答案**：推理**无效**。
> **如果硬要写形式证明，会在哪一步出错**：第一步用 ES 得 `S(a) ∧ P(a)`，第二步对 `∃x (S(x) ∧ T(x))` 又用 ES 得 `S(a) ∧ T(a)` —— **两次 ES 都用了同一个常项 a**，违反了「ES 必须取全新常项」的限制。正确应得 `S(b) ∧ T(b)`（b 不同），此时无法合并出结论。

## 易错点提醒

1. **∀ 配 ∧、∃ 配 →**。错：「所有人都是要死的」写成 `∀x (M(x) ∧ D(x))`。正确：`∀x (M(x) → D(x))`。**口诀：全称配箭头，存在配合取**。
2. **个体域不写或写错**。错：符号化时只写 `∀x (x > 0)` 不管个体域。正确：必须写明个体域；若用全总个体域，必须加特性谓词 `∀x (R(x) → x > 0)`。
3. **辖域判断错**。错：把 `∀x (P(x) → ∃y Q(x,y)) ∨ R(x)` 里最后的 `R(x)` 中的 x 当成约束变元。正确：`∀x` 的辖域只到配对括号，`R(x)` 中的 x 是**自由**的。
4. **`∃` 理解成「只有一个」**。错：「只有一个学生及格」写成 `∃x (S(x) ∧ P(x))`。正确：要写成 `∃x (S(x) ∧ P(x) ∧ ∀y (S(y) ∧ P(y) → y = x))`。
5. **换名规则只改量词或只改辖域内**。错：`∀x P(x, y)` → `∀z P(x, y)`。正确：`∀z P(z, y)`，量词变元和辖域内所有该变元的约束出现**必须一起改**。
6. **换名换成了已出现的名字**。错：`∀x (P(x) ∧ Q(y))` 中把 x 换成 y。正确：必须换成辖域内**未出现**的变元名，如 u。
7. **量词分配律乱用**。错：`∀x (A(x) ∨ B(x)) ⇔ ∀x A(x) ∨ ∀x B(x)`。正确：`∀` 只对 `∧` 分配，`∃` 只对 `∨` 分配；`∀` 对 `∨`、`∃` 对 `∧` **不分配**。
8. **量词顺序随意调换**。错：`∀x∃y A(x,y) ⇔ ∃y∀x A(x,y)`。正确：只有**同种**量词可交换；`∃∀ ⟹ ∀∃` 单向成立，反过来不成立。
9. **求前束范式跳过换名**。错：`∀x P(x) ∨ ∃x Q(x)` 直接得 `∀x∃x (P(x) ∨ Q(x))`。正确：先换名成 `∀x P(x) ∨ ∃y Q(y)`，再得 `∀x∃y (P(x) ∨ Q(y))`。
10. **ES 用了同一个常项两次**。错：由 `∃x P(x)` 和 `∃x Q(x)` 都得 `P(c)`、`Q(c)`，进而得 `∃x(P(x)∧Q(x))`。正确：两次 ES 必须用**不同**的全新常项 `c`、`d`。
11. **用 ES 得到的常项做 UG**。错：`∃x P(x) ⟹ P(c) ⟹ ∀x P(x)`。正确：ES 得到的 `c` 是特殊的，**不能**用 UG 推广。
12. **UN 顺序搞反**：同一题里既有 `∃` 前提又有 `∀` 前提时，**先 ES 后 US**。反了的话，US 产生的自由变元和 ES 产生的常项对不上。

## 本章小结

1. 命题逻辑的局限：拆不开句子内部结构、表达不了量词。
2. 一阶逻辑三要素：**个体词 + 谓词 + 量词**。个体域决定真值，必须写明。
3. 四条符号化黄金法则：**∀ 配 →，∃ 配 ∧**；「没有 A 是 B」= `∀x(A→¬B)`；「有的 A 不是 B」= `∃x(A∧¬B)`。
4. 辖域 = 量词后紧跟的最小公式；辖域内同名变元为**约束**，其余为**自由**。同名的变元可能既约束又自由。
5. **换名规则**改约束变元（量词 + 辖域内全部一起改）；**代替规则**改自由变元（全部自由出现一起改）。
6. 量词否定律：`¬∀x A ⇔ ∃x ¬A`，`¬∃x A ⇔ ∀x ¬A`。否定穿量词，量词翻转。
7. 辖域收缩扩张律：B 不含 x 时 `∀x(A∨B) ⇔ ∀xA ∨ B`；注意 `∀x(A→B) ⇔ ∃xA → B`（量词翻转）。
8. 分配律：`∀` 对 `∧` 分配 ✓，`∃` 对 `∨` 分配 ✓；`∀` 对 `∨`、`∃` 对 `∧` **不分配**。
9. 量词顺序：同种可交换；`∃∀ ⟹ ∀∃` 单向。
10. 前束范式 = 所有量词提到最前，母式不含量词。四步法：**消箭头 → 否定内移 → 换名 → 量词左移**。
11. 四条推理规则：**US**（∀ 拆）、**UG**（收成 ∀）、**ES**（拆 ∃，**必须用全新常项**）、**EG**（包成 ∃）。同一题里先 ES 后 US。

> **一句话记住本章**：**把句子拆成「谁（个体）+ 什么性质或关系（谓词）+ 多少个（量词）」，记住「全称配箭头、存在配合取」，再把量词当成可以左移的「前缀」，一阶逻辑就通了。**

## 自测题

1. 判断：`∀x (P(x) ∧ Q(x))` 与 `∀x P(x) ∧ ∀x Q(x)` 是否等值？`∃x (P(x) ∧ Q(x))` 与 `∃x P(x) ∧ ∃x Q(x)` 呢？
2. 指出 `∃x (P(x) → ∀y Q(x, y)) ∧ R(z)` 中 `∀y` 的辖域，以及各变元是约束还是自由。
3. 在全总个体域下符号化：「任何整数都能被某个素数整除」。
4. 求 `∃x P(x) ∨ ∀y Q(y)` 的前束范式。
5. 求 `¬∀x (P(x) → Q(x))` 的前束范式，并说明其直观含义。
6. 用换名规则改写 `∃x P(x) ∧ ∀x Q(x)`，使两个量词使用不同变元。
7. 证明 `∀x (P(x) → Q(x)), ∃x P(x) ⟹ ∃x Q(x)`。
8. 判断推理是否有效并说明理由：`∀x (P(x) ∨ Q(x)), ∀x ¬P(x) ⟹ ∀x Q(x)`。
9. 说明为什么 `∃x∀y A(x,y) ⟹ ∀y∃x A(x,y)` 有效，而反过来无效（举反例）。
10. 指出错误：「由 `∃x P(x)` 得 `P(c)`，由 `∃x Q(x)` 得 `Q(c)`，故 `P(c) ∧ Q(c)`，故 `∃x (P(x) ∧ Q(x))`。」

<details>
<summary>参考答案</summary>

1. 第一对**等值**（Q11，`∀` 对 `∧` 分配）。第二对**不等值**（Q14 不成立）。反例：域 = 整数，`P(x)`：x 是偶数，`Q(x)`：x 是奇数。`∃xP(x) ∧ ∃xQ(x)` 真，`∃x(P(x)∧Q(x))` 假。
2. `∀y` 的辖域是 `Q(x, y)`。变元身份：`x` 在 `P(x)` 和 `Q(x,y)` 中是约束出现（受 `∃x` 约束）；`y` 在 `Q(x,y)` 中是约束出现；`z` 在 `R(z)` 中是**自由**出现。公式是开式。
3. 设 `Z(x)`：x 是整数；`P(y)`：y 是素数；`D(x, y)`：x 能被 y 整除。
`∀x (Z(x) → ∃y (P(y) ∧ D(x, y)))`
4. 换名：`∃x P(x) ∨ ∀y Q(y)` 两个量词名不冲突，可直接左移 → `∃x∀y (P(x) ∨ Q(y))`。（用 Q3 把 `∀y Q(y)` 提出 `∃x` 的辖域，再用 Q5 把 `∃x` 提到最前。）
5. `¬∀x (P(x) → Q(x)) = ∃x ¬(P(x) → Q(x)) = ∃x (P(x) ∧ ¬Q(x))`。直观含义：「存在一个个体，它具有性质 P 但不具有性质 Q」，即「并非所有 P 都是 Q」。
6. 注意第二个量词：`∃x P(x) ∧ ∀x Q(x)` 中两个 `x` 各自约束自己辖域内的出现（第一个 `x` 约束 `P(x)`，第二个 `x` 约束 `Q(x)`），互不干扰。为保证可读性换名：`∃x P(x) ∧ ∀y Q(y)`。**关键点**：换名时各自的辖域内要同步改，不能串。
7. ① `∃x P(x)` P；② `∀x (P(x) → Q(x))` P；③ `P(c)` ES（由①，c 全新）；④ `P(c) → Q(c)` US（由②）；⑤ `Q(c)` T（由③④，I₃）；⑥ `∃x Q(x)` EG（由⑤）。∎
8. 有效。① `∀x (P(x) ∨ Q(x))` P；② `∀x ¬P(x)` P；③ `P(c) ∨ Q(c)` US（由①）；④ `¬P(c)` US（由②）；⑤ `Q(c)` T（由③④，I₅ 析取三段论）；⑥ `∀x Q(x)` UG（由⑤，c 是任取的常项，具有任意性 ✓）。∎
9. **正向有效**：设 `∃x∀y A(x,y)` 真，则存在 `x₀` 使对所有 y 都有 `A(x₀,y)`。任取 y，取 `x = x₀` 即得 `A(x₀,y)`，故 `∃x A(x,y)`；由于 y 是任取的，得 `∀y∃x A(x,y)` ✓。
   **反向无效**：域 = 实数，`A(x,y)`：`x + y = 0`。`∀y∃x (x+y=0)` 真（每个 y 有相反数 −y），但 `∃x∀y (x+y=0)` 假（不存在一个固定实数与所有实数相加都为 0）✗。
10. 错在**两次 ES 用了同一个常项 `c`**。`∃x P(x)` 保证「存在一个 P」，`∃x Q(x)` 保证「存在一个 Q」，这两个存在者可能是**不同的**个体。正确做法是第一次用 `c`，第二次用 `d`（`d` 全新），此时得到 `P(c) ∧ Q(d)`，无法合并出 `∃x (P(x) ∧ Q(x))`。该推理本身就**无效**。
