## 12.1 随机事件与概率

### 12.1.1 样本空间与随机事件

**定义 12.1（随机试验）**：满足以下三个特点的试验称为**随机试验（Random Experiment）**：
1. 可以在**相同条件**下重复进行；
2. 每次试验的**可能结果不止一个**，且能事先明确所有可能结果；
3. 每次试验前**不能确定**哪个结果会出现。

**定义 12.2（样本空间）**：随机试验 E 的**所有可能结果**构成的集合称为**样本空间（Sample Space）**，记作 `Ω`（或 S）。
`Ω` 中的每个元素（一个可能结果）称为**样本点**，记作 `ω`。

**定义 12.3（随机事件）**：样本空间 `Ω` 的**子集**称为**随机事件（Event）**，简称事件。用大写字母 A, B, C 表示。
- `Ω` 本身称为**必然事件**（一定发生）；
- `∅` 称为**不可能事件**（一定不发生）；
- 只含一个样本点的事件 `{ω}` 称为**基本事件**。

**事件的关系与运算**（与集合运算一一对应）：

| 事件语言 | 集合语言 | 含义 |
|---|---|---|
| A 发生则 B 必发生 | `A ⊆ B` | A 蕴含 B |
| A 与 B 相等 | `A = B` | 互相蕴含 |
| A 与 B **至少有一个发生** | `A ∪ B` | 并事件（**和事件**） |
| A 与 B **同时发生** | `A ∩ B`（记 AB） | 交事件（**积事件**） |
| A 发生而 B **不发生** | `A − B` | 差事件 |
| A 与 B **不能同时发生** | `A ∩ B = ∅` | **互不相容**（互斥） |
| A **不发生** | `～A`（记 `Ā`） | **对立事件**（逆事件） |

> **互斥 vs 对立**：**对立一定互斥，互斥不一定对立**。
> `A ∩ B = ∅` 是互斥；对立还要求 `A ∪ B = Ω`。
> **例**：掷骰子，`A = {1}`，`B = {2}` 互斥但不对立（因为 `A∪B = {1,2} ≠ Ω`）。

**事件的运算律**（与集合恒等式完全相同）：
- 交换律：`A ∪ B = B ∪ A`，`A ∩ B = B ∩ A`
- 结合律：`(A∪B)∪C = A∪(B∪C)`
- 分配律：`A ∩ (B ∪ C) = (A∩B) ∪ (A∩C)`
- **德摩根律**：`～(A ∪ B) = ～A ∩ ～B`，`～(A ∩ B) = ～A ∪ ～B`

### 12.1.2 概率的公理化定义

**定义 12.4（概率）**：设 `Ω` 是样本空间。对每个事件 A 赋予一个实数 `P(A)`，若它满足以下三条**公理**，则称 `P(A)` 为事件 A 的**概率（Probability）**：

| 公理 | 内容 |
|---|---|
| **公理 1（非负性）** | 对任意事件 A，`P(A) ≥ 0` |
| **公理 2（规范性）** | `P(Ω) = 1` |
| **公理 3（可加性）** | 若 `A₁, A₂, …` **两两互斥**，则 `P(A₁ ∪ A₂ ∪ …) = P(A₁) + P(A₂) + …` |

**由公理推出的基本性质**：

| 编号 | 性质 | 说明 |
|---|---|---|
| 1 | `P(∅) = 0` | 不可能事件的概率为 0 |
| 2 | `P(～A) = 1 − P(A)` | **互补公式（最常用！）** |
| 3 | 若 `A ⊆ B`，则 `P(A) ≤ P(B)` | **单调性** |
| 4 | `P(A) ≤ 1` | 概率不超过 1 |
| 5 | `P(A − B) = P(A) − P(A ∩ B)` | 差事件公式 |
| 6 | **`P(A ∪ B) = P(A) + P(B) − P(A ∩ B)`** | **加法公式** |
| 7 | 若 `A, B` 互斥，则 `P(A ∪ B) = P(A) + P(B)` | 加法的特例 |

**★ 证明性质 6（加法公式）**：
把 `A ∪ B` 分成三个互斥的部分：`A−B`、`B−A`、`A∩B`。
由公理 3：`P(A∪B) = P(A−B) + P(B−A) + P(A∩B)`。
而 `P(A) = P(A−B) + P(A∩B)`，`P(B) = P(B−A) + P(A∩B)`（同样按互斥分解）。
两式相加：`P(A) + P(B) = P(A−B) + P(B−A) + 2P(A∩B)`。
故 `P(A−B) + P(B−A) = P(A) + P(B) − 2P(A∩B)`。
代入第一个式子：
`P(A∪B) = [P(A) + P(B) − 2P(A∩B)] + P(A∩B) = P(A) + P(B) − P(A∩B)` ✓ ∎

**★ 三个事件的加法公式（容斥原理的概率版本）**：
`P(A∪B∪C) = P(A) + P(B) + P(C) − P(AB) − P(AC) − P(BC) + P(ABC)`
（**与第 10 章的容斥原理完全同构**：「奇加偶减」✓）

### 12.1.3 ★ 古典概型

**定义 12.5（古典概型 / 等可能概型）**：若样本空间 `Ω` 满足
1. **有限性**：`Ω` 中只有**有限个**样本点；
2. **等可能性**：每个基本事件发生的概率**相同**，

则称该试验为**古典概型**。此时事件 A 的概率为
`P(A) = |A| / |Ω| = A 包含的样本点数 / 样本点总数`

> **这是本章最核心的公式**：**概率 = 有利情况数 ÷ 总情况数**。
> **难点全在于「数」**——这正是第 09 章排列组合的用武之地。

**★ 例 1（掷两颗骰子）**：掷两颗均匀骰子，求点数之和为 7 的概率。
**解**：样本空间 `Ω` 中每个样本点是**有序对** `(i, j)`，故 `|Ω| = 6 × 6 = 36`。
点数和为 7 的有 `(1,6), (2,5), (3,4), (4,3), (5,2), (6,1)` 共 **6** 个。
`P = 6/36 = 1/6` ✓
**易错提醒**：若把样本空间当作「无序对」（21 种），则各样本点**不等可能**（`(1,1)` 与 `(1,2)` 概率不同），**不能用古典概型公式**。**必须用有序对！**

**★ 例 2（抽样问题）**：一批产品共 100 件，其中有 5 件次品。从中任取 3 件，求**恰有 1 件次品**的概率。
**解**：从 100 件中取 3 件的取法：`|Ω| = C(100, 3)`。
恰有 1 件次品：从 5 件次品中取 1 件，从 95 件正品中取 2 件 → `|A| = C(5,1)·C(95,2)`。
`P(A) = [C(5,1)·C(95,2)] / C(100,3) = [5 × 4465] / 161700 = 22325 / 161700 ≈ 0.1381` ✓

**★ 例 3（生日问题）**：一个班 30 人，至少有两人生日相同的概率是多少（假设一年 365 天）？
**解**：用**互补公式**更快。
`P(至少两人同生日) = 1 − P(所有人生日都不同)`
`P(都不同) = [365 × 364 × … × (365−29)] / 365³⁰ = P(365, 30) / 365³⁰`
计算近似值：
`P(都不同) = (364/365)(363/365)…(336/365) ≈ 0.2937`
故 `P(至少两人同生日) ≈ 1 − 0.2937 = 0.7063` ✓
**结论**：**30 人中至少两人生日相同的概率约 70.6%**——比直觉高得多！（这就是「**生日悖论**」。）
> **直觉解释**：要比较的不是「与某人相同」，而是**所有两两配对**（`C(30,2) = 435` 对）中的任意一对相同。一旦想到有 435 次机会，70% 就不奇怪了。

**★ 例 4（抽签的公平性）**：10 张签中有 1 张是中奖签。10 个人依次抽（不放回），第 k 个人中奖的概率是多少？
**解**：关键是「**抽签结果与顺序无关**」。
样本空间可以想成「10 张签的一个排列」：`|Ω| = 10!`。
第 k 个人抽到中奖签：第 k 位固定为中奖签，其余 9 张任意排列 → `|A| = 9!`。
`P = 9!/10! = 1/10` ✓
**结论**：**每个人中奖概率都是 1/10，与抽签顺序无关**（抽签是公平的）。
> **这体现了「无信息时概率均等」的思想**——正是条件概率与贝叶斯的思想基础。

## 12.2 条件概率与独立性

### 12.2.1 条件概率

**定义 12.6（条件概率）**：设 `A, B` 是事件，`P(A) > 0`，则在事件 A **已经发生**的条件下，事件 B 发生的**条件概率（Conditional Probability）**为
`P(B | A) = P(A ∩ B) / P(A)`

> **直观理解**：A 的发生把样本空间**缩小**到了 A。在这个新样本空间里，B 发生的比例就是 `P(A∩B)/P(A)`。
> **古典概型下的解释**：`P(B|A) = |A∩B| / |A|`（把 A 当作新的样本空间重新数一遍）。

**★ 例**：掷一颗骰子。已知点数是偶数，求点数大于 3 的概率。
**解**：设 `A = {2,4,6}`（偶数），`B = {4,5,6}`（大于 3）。
`A ∩ B = {4, 6}`。
`P(A) = 3/6 = 1/2`，`P(A∩B) = 2/6 = 1/3`。
`P(B|A) = (1/3)/(1/2) = 2/3` ✓
**验证**：在 A 的 3 个点中，大于 3 的有 4, 6 两个 → `2/3` ✓

**★ 乘法公式**：由条件概率定义直接得
`P(A ∩ B) = P(A) · P(B | A) = P(B) · P(A | B)`
**推广（n 个事件）**：
`P(A₁A₂…Aₙ) = P(A₁)·P(A₂|A₁)·P(A₃|A₁A₂)·…·P(Aₙ|A₁A₂…A_{n−1})`

**★ 例（乘法公式）**：袋中有 5 个红球、3 个白球，不放回地依次取 2 个球，求两次都取到红球的概率。
**解**：设 `A₁` = 第一次取到红球，`A₂` = 第二次取到红球。
`P(A₁) = 5/8`。在 `A₁` 发生（已取走 1 个红球）的条件下，剩 4 红 3 白，故 `P(A₂|A₁) = 4/7`。
`P(A₁A₂) = (5/8) × (4/7) = 20/56 = 5/14` ✓
**验证**：直接数，从 8 球取 2 个红球：`C(5,2)/C(8,2) = 10/28 = 5/14` ✓

### 12.2.2 事件的独立性

**定义 12.7（独立性）**：设 `A, B` 是事件。若
`P(A ∩ B) = P(A) · P(B)`
则称 A 与 B **相互独立（Independent）**。

**等价刻画**：若 `P(A) > 0`，则 `A, B` 独立 ⟺ `P(B|A) = P(B)`（A 的发生**不影响** B 的概率）✓

> **注意**：「独立」与「互斥」是**完全不同**的概念！
> - **互斥**：`A ∩ B = ∅`，**不能同时发生**；
> - **独立**：`P(A∩B) = P(A)P(B)`，**一个发生不影响另一个的概率**。
> **重要事实**：若 `P(A) > 0` 且 `P(B) > 0`，则 **A, B 既互斥又独立是不可能的**（互斥给 `P(A∩B) = 0`，独立给 `P(A∩B) = P(A)P(B) > 0`，矛盾）。

**定义 12.8（三个事件相互独立）**：`A, B, C` **两两独立**指
`P(AB) = P(A)P(B)`，`P(AC) = P(A)P(C)`，`P(BC) = P(B)P(C)`
`A, B, C` **相互独立**还要求
`P(ABC) = P(A)P(B)P(C)`
**注意**：**相互独立 ⟹ 两两独立，反之不成立**。

**★ 反例（两两独立但不相互独立）**：掷两颗骰子，令
`A = {点数和为 7}`，`B = {第一颗为 3}`，`C = {第二颗为 4}`。
- `P(A) = 6/36 = 1/6`，`P(B) = 1/6`，`P(C) = 1/6`
- `P(AB) = P({(3,4)}) = 1/36 = P(A)P(B)` ✓
- `P(AC) = 1/36 = P(A)P(C)` ✓
- `P(BC) = P(∅) = 0 ≠ 1/36 = P(B)P(C)` ✗

所以这个例子只有 `A, B` 和 `A, C` 独立，`B, C` 不独立。（更经典的例子是构造一个三项两两独立但三交不等的例子，见自测题。）

**★ 独立性的应用（串联/并联系统）**：
若系统由 n 个元件组成，各元件独立工作，可靠度（正常工作的概率）为 `pᵢ`：
- **串联系统**（全部正常才正常）：`P = p₁p₂…pₙ`
- **并联系统**（至少一个正常就正常）：`P = 1 − (1−p₁)(1−p₂)…(1−pₙ)`

### 12.2.3 伯努利概型

**定义 12.9（n 重伯努利试验）**：若试验满足
1. 每次试验**只有两个结果**：成功（概率 p）或失败（概率 `q = 1−p`）；
2. 各次试验**相互独立**；
3. 试验重复 **n 次**，

则称为 **n 重伯努利试验（Bernoulli Trials）**。

**定理 12.1（二项概率公式）**：n 重伯努利试验中，**恰有 k 次成功**的概率为
`P(X = k) = C(n, k) · p^k · q^(n−k)`（`k = 0, 1, …, n`）

**为什么**：指定某 k 次成功、其余 `n−k` 次失败，概率由独立性得 `p^k q^(n−k)`。
选择哪 k 次成功有 `C(n, k)` 种，且这些事件互斥，故相加得 `C(n,k)p^k q^(n−k)` ✓

**★ 例**：某射手每次命中率 0.8，独立射击 5 次。求 (1) 恰有 3 次命中；(2) 至少命中 1 次。
**解**：
(1) `P(X=3) = C(5,3)(0.8)³(0.2)² = 10 × 0.512 × 0.04 = 0.2048` ✓
(2) 用**互补**更简单：`P(X≥1) = 1 − P(X=0) = 1 − (0.2)⁵ = 1 − 0.00032 = 0.99968` ✓

## 12.3 全概率公式与贝叶斯公式 ★

### 12.3.1 完备事件组

**定义 12.10（完备事件组 / 划分）**：若事件 `B₁, B₂, …, Bₙ` 满足
1. **两两互斥**：`Bᵢ ∩ Bⱼ = ∅`（i ≠ j）；
2. **并是全集**：`B₁ ∪ B₂ ∪ … ∪ Bₙ = Ω`；
3. `P(Bᵢ) > 0`，

则称它们构成一个**完备事件组**（或**样本空间的一个划分**）。

> **直观理解**：完备事件组就是「**把所有可能情况不重不漏地分成几类**」——这正是第 10 章容斥原理和第 05 章划分思想的概率版本。

### 12.3.2 ★ 全概率公式

**定理 12.2（全概率公式 / Law of Total Probability）**：设 `B₁, …, Bₙ` 是完备事件组，则对任意事件 A，
`P(A) = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + … + P(A|Bₙ)P(Bₙ)`
`= Σ_{i=1}^{n} P(A|Bᵢ) P(Bᵢ)`

**证明**：因 `B₁, …, Bₙ` 互斥且并为 Ω，
`A = A ∩ Ω = A ∩ (B₁ ∪ … ∪ Bₙ) = (A∩B₁) ∪ (A∩B₂) ∪ … ∪ (A∩Bₙ)`
这些 `A∩Bᵢ` **两两互斥**（因为 `Bᵢ` 互斥）。由**可加性公理**：
`P(A) = Σ P(A∩Bᵢ)`
再由**乘法公式** `P(A∩Bᵢ) = P(A|Bᵢ)P(Bᵢ)` 代入即得 ✓ ∎

> **使用要点**：当「**直接求 P(A) 困难，但分情况求很容易**」时用全概率公式。
> **口诀**：**「按因分类，加权求和」**——先按原因 `Bᵢ` 分类，再用各原因的权重 `P(Bᵢ)` 加权。

**★ 例 1（经典）**：某工厂有甲、乙、丙三条生产线，产量分别占总产量的 25%、35%、40%，次品率分别为 5%、4%、2%。求从总产品中任取一件是次品的概率。
**解**：设 `A` = 抽到次品，`B₁, B₂, B₃` = 产品来自甲、乙、丙线。
`B₁, B₂, B₃` 构成完备事件组（`0.25 + 0.35 + 0.40 = 1` ✓）。
由全概率公式：
`P(A) = P(A|B₁)P(B₁) + P(A|B₂)P(B₂) + P(A|B₃)P(B₃)`
`= 0.05 × 0.25 + 0.04 × 0.35 + 0.02 × 0.40`
`= 0.0125 + 0.0140 + 0.0080`
`= 0.0345`
**答案**：**3.45%** ✓

**★ 例 2（不放回抽球）**：袋中有 a 个白球、b 个黑球。不放回地依次取球，求第 2 次取到白球的概率。
**解**：设 `A` = 第 2 次取到白球。按第 1 次的结果分类：
- `B₁` = 第 1 次取到白球：`P(B₁) = a/(a+b)`，`P(A|B₁) = (a−1)/(a+b−1)`
- `B₂` = 第 1 次取到黑球：`P(B₂) = b/(a+b)`，`P(A|B₂) = a/(a+b−1)`

`P(A) = [a/(a+b)] · [(a−1)/(a+b−1)] + [b/(a+b)] · [a/(a+b−1)]`
`= [a(a−1) + ab] / [(a+b)(a+b−1)]`
`= a(a − 1 + b) / [(a+b)(a+b−1)]`
`= a(a+b−1) / [(a+b)(a+b−1)]`
`= a / (a + b)`
**答案**：`P(A) = a/(a+b)`，**与第 1 次取到白球的概率相同** ✓
> **这印证了「抽签公平性」**：无论第几次取，取到白球的概率都是 `a/(a+b)`。

### 12.3.3 ★ 贝叶斯公式

**定理 12.3（贝叶斯公式 / Bayes' Theorem）**：设 `B₁, …, Bₙ` 是完备事件组，`P(A) > 0`，则
`P(Bᵢ | A) = P(A|Bᵢ)P(Bᵢ) / Σ_{j=1}^{n} P(A|Bⱼ)P(Bⱼ)`
（分母就是全概率公式算出的 `P(A)`。）

**关键理解（先验与后验）**：
- `P(Bᵢ)` 称为**先验概率**（试验前对 `Bᵢ` 的信念）；
- `P(Bᵢ|A)` 称为**后验概率**（观察到 A 发生后，对 `Bᵢ` 的修正信念）。

> **贝叶斯公式的本质**：**「已知结果 A，反过来推断是哪个原因 `Bᵢ` 造成的」。**
> 这是「**由果溯因**」——而全概率公式是「**由因推果**」。

**★ 例 1（次品来源推断）**：承 12.3.2 的例 1，若抽到一件次品，求它来自甲线的概率。
**解**：由贝叶斯公式（分母 `P(A) = 0.0345`）：
`P(B₁|A) = P(A|B₁)P(B₁) / P(A) = (0.05 × 0.25) / 0.0345 = 0.0125 / 0.0345 ≈ 0.3623`
**答案**：约 **36.23%** ✓
同理可算：
`P(B₂|A) = 0.0140/0.0345 ≈ 0.4058`（乙线）
`P(B₃|A) = 0.0080/0.0345 ≈ 0.2319`（丙线）
**验证**：`0.3623 + 0.4058 + 0.2319 = 1.0000` ✓

**★ 例 2（疾病检测 —— 贝叶斯最经典的应用）**：
某疾病在人群中的患病率为 **0.1%**。一种检测方法：
- 患病者检测呈阳性的概率为 **99%**（灵敏度）；
- 未患病者检测呈阳性的概率为 **2%**（假阳性率）。

若某人检测呈**阳性**，他真正患病的概率是多少？
**解**：设 `D` = 患病，`T` = 检测阳性。
先验：`P(D) = 0.001`，`P(～D) = 0.999`。
似然：`P(T|D) = 0.99`，`P(T|～D) = 0.02`。
**全概率公式**算 `P(T)`：
`P(T) = P(T|D)P(D) + P(T|～D)P(～D) = 0.99 × 0.001 + 0.02 × 0.999`
`= 0.00099 + 0.01998 = 0.02097`
**贝叶斯公式**：
`P(D|T) = 0.00099 / 0.02097 ≈ 0.0472`
**答案**：**约 4.72%** ✓
> **反直觉的结论**：即使检测阳性，真正患病的概率也只有约 **4.7%**！
> **为什么**：因为**患病率极低**（0.1%），大量健康人（999 人/千人中 999 人）中即使只有 2% 的假阳性，也产生约 20 个假阳性，而真患者只有约 1 个。
> **这就是「基础比率谬误」（base rate fallacy）**——医学检测中必须先看患病率，不能只看检测准确率。

**★ 例 3（三门问题 / Monty Hall）**：三扇门后有一辆车和两只羊。你选 1 号门。主持人（知道车在哪）打开 3 号门露出羊，然后问你是否改选 2 号门。改选是否更有利？
**解**：设 `Cᵢ` = 车在 i 号门后，先验 `P(C₁) = P(C₂) = P(C₃) = 1/3`。
设 `O₃` = 主持人打开 3 号门：
- 若车在 1 号门（你选对了），主持人可在 2、3 中任选，`P(O₃|C₁) = 1/2`；
- 若车在 2 号门，主持人不能开 2 号门（有车），也不能开 1 号门（你选的），**只能开 3 号门**，`P(O₃|C₂) = 1`；
- 若车在 3 号门，主持人不能开 3 号门，`P(O₃|C₃) = 0`。

全概率：`P(O₃) = (1/2)(1/3) + (1)(1/3) + (0)(1/3) = 1/6 + 1/3 = 1/2`
贝叶斯：
`P(C₁|O₃) = (1/2 × 1/3) / (1/2) = (1/6)/(1/2) = 1/3`
`P(C₂|O₃) = (1 × 1/3) / (1/2) = (1/3)/(1/2) = 2/3`
**答案**：**改选 2 号门，中奖概率从 1/3 提高到 2/3** ✓
> **直观解释**：你最初选中的概率是 1/3，**没选中**的概率是 2/3。主持人打开一扇羊门**并没有改变这一点**——他只是把「另外两扇门中有车」的 2/3 概率**集中到了剩下那扇门上**。

## 12.4 随机变量及其分布

### 12.4.1 随机变量与分布律

**定义 12.11（随机变量）**：设 `Ω` 是样本空间。函数
`X: Ω → R`
称为**随机变量（Random Variable）**，即「把每个试验结果映射成一个实数」。

**定义 12.12（离散型随机变量）**：若随机变量 X 的取值是**有限个或可列无穷个**，则称 X 为**离散型随机变量**。

**定义 12.13（分布律 / 概率质量函数）**：设 X 的全部取值为 `x₁, x₂, …`，则
`P(X = xᵢ) = pᵢ`（`i = 1, 2, …`）
称为 X 的**分布律**（或概率分布）。它必须满足
1. `pᵢ ≥ 0`；
2. `Σ pᵢ = 1`。

**表示法（分布律表）**：

| X | `x₁` | `x₂` | `x₃` | … |
|---|---|---|---|---|
| P | `p₁` | `p₂` | `p₃` | … |

**★ 例**：掷一颗骰子，`X` = 出现的点数。则 X 的分布律为
`P(X = k) = 1/6`（`k = 1, 2, 3, 4, 5, 6`），验证 `Σ = 6 × 1/6 = 1` ✓

**★ 例（非均匀）**：某射手命中率为 0.8，射击 3 次，`X` = 命中次数。求 X 的分布律。
**解**：`X ~ B(3, 0.8)`，`P(X=k) = C(3,k)(0.8)^k(0.2)^(3−k)`：

| X | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| P | `(0.2)³ = 0.008` | `3×0.8×0.04 = 0.096` | `3×0.64×0.2 = 0.384` | `(0.8)³ = 0.512` |

**验证**：`0.008 + 0.096 + 0.384 + 0.512 = 1.000` ✓

### 12.4.2 ★ 数学期望

**定义 12.14（数学期望）**：设离散型随机变量 X 的分布律为 `P(X = xᵢ) = pᵢ`。若级数 `Σ|xᵢ|pᵢ` 收敛，则称
`E(X) = Σ_{i} xᵢ pᵢ`
为 X 的**数学期望（Expectation）**，简称**期望**或**均值**。

> **直观理解**：把每个取值按它的概率**加权平均**——期望就是「**长期平均结果**」。
> **物理类比**：把概率 `pᵢ` 看成质量，`xᵢ` 看成位置，`E(X)` 就是**质心**。

**★ 例（骰子）**：`E(X) = 1×(1/6) + 2×(1/6) + … + 6×(1/6) = (1+2+3+4+5+6)/6 = 21/6 = 3.5` ✓
> **注意**：期望可以是**小数**，也可以**不是** X 的可能取值。3.5 不是骰子能掷出的点数，但它有意义。

**★ 期望的性质（线性性 —— 最重要）**：
| 编号 | 性质 |
|---|---|
| 1 | `E(c) = c`（c 是常数） |
| 2 | `E(cX) = c·E(X)` |
| 3 | **`E(X + Y) = E(X) + E(Y)`**（**无需独立！**） |
| 4 | `E(X + c) = E(X) + c` |
| 5 | 若 X, Y **独立**，则 `E(XY) = E(X)·E(Y)` |

> **性质 3 的强大之处**：`E(X+Y) = E(X)+E(Y)` **不需要独立性**。这使许多复杂问题可以「**拆成简单部分相加**」。

**★ 应用（期望的线性性 —— 指示变量法）**：
**例**：n 个人随机地把帽子扔进一堆，然后每人随机拿一顶。求**拿到自己帽子的人数**的期望。
**解**：设 `Xᵢ = 1` 若第 i 人拿到自己的帽子，否则 `Xᵢ = 0`。则 `X = ΣXᵢ`。
`P(Xᵢ = 1) = 1/n`（第 i 人的帽子在 n 个位置中等可能）。
`E(Xᵢ) = 1 × (1/n) + 0 × (1 − 1/n) = 1/n`。
由**线性性**：`E(X) = ΣE(Xᵢ) = n × (1/n) = 1` ✓
**答案**：**无论 n 多大，平均恰有 1 人拿到自己的帽子！**

### 12.4.3 方差

**定义 12.15（方差）**：设 X 是随机变量，`E(X) = μ` 存在，则
`D(X) = E[(X − E(X))²] = E(X²) − [E(X)]²`
称为 X 的**方差（Variance）**，记作 `D(X)` 或 `Var(X)`。`√D(X)` 称为**标准差**。

**直观**：方差衡量 X 的取值**偏离期望的程度**——方差越大，取值越分散。

**★ 常用计算公式**：**`D(X) = E(X²) − [E(X)]²`**（考试中最常用，比定义式好算）。

**方差的性质**：
| 编号 | 性质 |
|---|---|
| 1 | `D(c) = 0` |
| 2 | `D(cX) = c²·D(X)` |
| 3 | `D(X + c) = D(X)` |
| 4 | 若 X, Y **独立**，则 `D(X + Y) = D(X) + D(Y)` |

> **注意性质 2**：`D(cX) = c²D(X)`，**常数提出来要平方**（对比 `E(cX) = cE(X)` 不用平方）。
> **注意性质 4**：方差的加法**需要独立性**（而期望的加法不需要）——这是二者最重要的区别。

**★ 例（骰子）**：求掷一颗骰子点数 X 的方差。
**解**：`E(X) = 3.5`。
`E(X²) = (1² + 2² + 3² + 4² + 5² + 6²)/6 = (1+4+9+16+25+36)/6 = 91/6 ≈ 15.1667`
`D(X) = E(X²) − [E(X)]² = 91/6 − (7/2)² = 91/6 − 49/4`
通分：`91/6 = 182/12`，`49/4 = 147/12`，故 `D(X) = 35/12 ≈ 2.9167` ✓
`√D(X) ≈ 1.708`（标准差）

### 12.4.4 ★ 常用离散分布表

| 分布名称 | 记号 | 分布律 `P(X=k)` | 期望 `E(X)` | 方差 `D(X)` | 典型场景 |
|---|---|---|---|---|---|
| **0-1 分布** | `B(1, p)` | `p^k(1−p)^(1−k)`，`k=0,1` | `p` | `p(1−p)` | 一次试验成功与否 |
| **二项分布** | `B(n, p)` | `C(n,k)p^k(1−p)^(n−k)` | `np` | `np(1−p)` | n 重伯努利中的成功次数 |
| **几何分布** | `G(p)` | `(1−p)^(k−1)p`，`k≥1` | `1/p` | `(1−p)/p²` | 首次成功所需试验次数 |
| **泊松分布** | `P(λ)` | `λ^k e^(−λ)/k!`，`k≥0` | `λ` | `λ` | 稀有事件计数（呼叫数、缺陷数） |
| **超几何分布** | `H(N,M,n)` | `C(M,k)C(N−M,n−k)/C(N,n)` | `nM/N` | 见注 | 不放回抽样中的次品数 |
| **均匀分布** | 有限等可能 | `1/n`，`k=1,…,n` | `(n+1)/2` | `(n²−1)/12` | 骰子、随机选号 |

**★ 二项分布期望的推导（用线性性，非常漂亮）**：
设 `X ~ B(n, p)`，`X = X₁ + X₂ + … + Xₙ`，其中 `Xᵢ` 是第 i 次试验的 0-1 变量（成功为 1）。
`E(Xᵢ) = p`，由线性性 `E(X) = ΣE(Xᵢ) = np` ✓
**方差**：因各次试验独立，`D(Xᵢ) = p(1−p)`，故 `D(X) = ΣD(Xᵢ) = np(1−p)` ✓

**★ 几何分布期望的推导**：`E(X) = Σ_{k≥1} k(1−p)^(k−1)p`。用错位相减（或求导技巧）得 `E(X) = 1/p` ✓
**直观**：若每次成功概率 1/p，平均要试 p 次才成功——很符合直觉（如中奖率 1%，平均买 100 次）。

**★ 泊松分布**（了解）：当 n 很大、p 很小时，`B(n,p) ≈ P(np)`（**泊松近似**）。
**例**：一本书 500 页，每页有 1 个印刷错误的概率为 0.002，求全书恰有 2 个错误的概率。
用 `λ = np = 500 × 0.002 = 1` 的泊松分布近似：
`P(X=2) ≈ 1² e^(−1)/2! = e^(−1)/2 ≈ 0.3679/2 ≈ 0.1839` ✓

## 12.5 期望与方差的应用

### 12.5.1 期望在算法分析中的应用

**★ 例（随机快速排序的比较次数）**：对 n 个元素的数组做随机化快排，平均需要多少次比较？
**解（指示变量法）**：设 n 个元素排序后为 `z₁ < z₂ < … < zₙ`。
设 `X_{ij} = 1` 若 `zᵢ` 与 `zⱼ` 被比较过（`i < j`），否则 0。总比较次数 `X = Σ_{i<j} X_{ij}`。
**关键观察**：`zᵢ` 与 `zⱼ` 会比较 ⟺ 在集合 `{zᵢ, z_{i+1}, …, zⱼ}` 中，**`zᵢ` 或 `zⱼ` 是最先被选为枢轴的**。
因为一旦其他元素先成为枢轴，`zᵢ` 和 `zⱼ` 就会被分到不同子数组中，永不再比较。
该集合有 `j − i + 1` 个元素，每个等可能先被选作枢轴，故
`P(X_{ij} = 1) = 2 / (j − i + 1)`
`E(X) = Σ_{i<j} 2/(j − i + 1) = Σ_{i<j} 2/(j−i+1)`
令 `k = j − i + 1`（从 2 到 n），对固定的 k 有 `n − k + 1` 对 `(i,j)`：
`E(X) = Σ_{k=2}^{n} (n − k + 1) · 2/k = 2(n+1)Σ_{k=2}^{n}(1/k) − 2(n−1)`
`= 2(n+1)H_n − O(n) ≈ 2n ln n ≈ 1.39 n log₂ n`
**答案**：随机快排的平均比较次数为 `O(n log n)` ✓（这就是快排平均复杂度的严格证明。）

### 12.5.2 期望与不等式的结合

**定理 12.4（马尔可夫不等式）**：若 X 是非负随机变量，`a > 0`，则
`P(X ≥ a) ≤ E(X) / a`

**定理 12.5（切比雪夫不等式）**：`P(|X − E(X)| ≥ ε) ≤ D(X) / ε²`

**应用**：这些不等式在**随机算法的正确性证明**（如概率方法）中至关重要。
**例**：若 `E(X) = 1`（如上面拿帽子的例子），则 `P(X ≥ 10) ≤ 1/10 = 10%`——**至少 90% 的概率拿到自己帽子的人数不超过 9**。

## 典型例题

**例 12.1**（题型：古典概型）
从 1, 2, …, 9 这 9 个数字中任取 3 个不同的数字。求：
(1) 3 个数字之和为偶数的概率；
(2) 3 个数字中恰有 1 个奇数的概率。
**解**：总取法 `|Ω| = C(9, 3) = 84`。
(1) 和为偶数 ⟺ 3 个数中有 **0 个或 2 个奇数**（因为奇数的个数必须为偶数）。
- 0 个奇数（全偶）：从 4 个偶数 `{2,4,6,8}` 中取 3 个 → `C(4,3) = 4`
- 2 个奇数 + 1 个偶数：`C(5,2)·C(4,1) = 10 × 4 = 40`

有利情况 `= 4 + 40 = 44`。
`P = 44/84 = 11/21 ≈ 0.5238` ✓
(2) 恰有 1 个奇数 = 1 奇 + 2 偶：`C(5,1)·C(4,2) = 5 × 6 = 30`。
`P = 30/84 = 5/14 ≈ 0.3571` ✓
**答案**：(1) `11/21`；(2) `5/14`。

**例 12.2**（题型：加法公式与互补）
某班 50 名学生中，20 人参加数学竞赛，15 人参加物理竞赛，8 人两科都参加。随机抽 1 人，求：
(1) 至少参加一科竞赛的概率；
(2) 两科都没参加的概率。
**解**：设 `M` = 参加数学，`P` = 参加物理。`P(M) = 20/50 = 0.4`，`P(P) = 15/50 = 0.3`，`P(MP) = 8/50 = 0.16`。
(1) `P(M ∪ P) = P(M) + P(P) − P(MP) = 0.4 + 0.3 − 0.16 = 0.54` ✓
(2) `P(～(M∪P)) = 1 − 0.54 = 0.46` ✓
**答案**：(1) 0.54；(2) 0.46。

**例 12.3**（题型：条件概率与独立性）
袋中有 3 个红球、2 个白球。不放回地取两次，每次取 1 个。
(1) 求第二次取到红球的概率；
(2) 求第二次取到红球的条件下，第一次取到白球的概率；
(3) 判断「第一次取到红球」与「第二次取到红球」是否独立。
**解**：设 `A` = 第一次取到红球，`B` = 第二次取到红球。
`P(A) = 3/5`，`P(～A) = 2/5`。
(1) 用**全概率公式**：
`P(B) = P(B|A)P(A) + P(B|～A)P(～A)`
`= (2/4)(3/5) + (3/4)(2/5) = 6/20 + 6/20 = 12/20 = 3/5` ✓
（**与第一次取到红球的概率相同**——抽签公平性。）
(2) 由**贝叶斯公式**：
`P(～A|B) = P(B|～A)P(～A) / P(B) = [(3/4)(2/5)] / (3/5) = (6/20)/(12/20) = 1/2` ✓
(3) `P(A ∩ B) = P(A)·P(B|A) = (3/5)(2/4) = 6/20 = 3/10`。
而 `P(A)·P(B) = (3/5)(3/5) = 9/25 = 0.36`。
`3/10 = 0.3 ≠ 0.36`，故 **A 与 B 不独立** ✓
> **直观**：不放回抽样中，第一次的结果**会影响**第二次的概率，故不独立。
> **若改为有放回**，则 `P(B) = 3/5`，`P(A∩B) = 9/25 = P(A)P(B)`，**独立**。

**例 12.4**（题型：全概率公式与贝叶斯公式）
某商店销售三种品牌的手机：甲品牌占 50%，乙占 30%，丙占 20%。三种品牌的返修率分别为 2%、3%、5%。
(1) 随机买一部手机，返修的概率是多少？
(2) 若某手机返修了，它最可能是哪个品牌？
**解**：设 `R` = 返修，`B₁, B₂, B₃` = 甲、乙、丙品牌。`B₁, B₂, B₃` 是完备事件组。
(1) **全概率公式**：
`P(R) = 0.02 × 0.5 + 0.03 × 0.3 + 0.05 × 0.2`
`= 0.010 + 0.009 + 0.010 = 0.029`
**答案**：**2.9%** ✓
(2) **贝叶斯公式**：
`P(B₁|R) = 0.010/0.029 ≈ 0.3448`
`P(B₂|R) = 0.009/0.029 ≈ 0.3103`
`P(B₃|R) = 0.010/0.029 ≈ 0.3448`
**答案**：**甲品牌与丙品牌并列最可能（各约 34.5%）** ✓
> **有趣的结论**：虽然丙品牌只占 20%，但它的返修率高（5%），所以「返修机是丙品牌」的概率与占 50% 的甲品牌**相同**。**这体现了贝叶斯公式「用数据修正先验」的威力。**

**例 12.5**（题型：伯努利概型与二项分布）
某批产品的次品率为 0.1。从中**有放回**地抽取 4 件，求：
(1) 恰有 1 件次品的概率；
(2) 至多有 1 件次品的概率；
(3) 次品数的期望与方差。
**解**：设 `X` = 次品数，`X ~ B(4, 0.1)`。
(1) `P(X=1) = C(4,1)(0.1)¹(0.9)³ = 4 × 0.1 × 0.729 = 0.2916` ✓
(2) `P(X≤1) = P(X=0) + P(X=1) = (0.9)⁴ + 0.2916 = 0.6561 + 0.2916 = 0.9477` ✓
(3) `E(X) = np = 4 × 0.1 = 0.4`；`D(X) = np(1−p) = 4 × 0.1 × 0.9 = 0.36` ✓
**答案**：(1) 0.2916；(2) 0.9477；(3) 期望 0.4，方差 0.36。

**例 12.6**（题型：期望的性质 —— 指示变量法）
把 n 封信随机放入 n 个信封（每个信封一封信）。设 X 为「装对的信」的数目。
(1) 求 `E(X)`；
(2) 求 `P(X = 0)`（即全部装错的概率）。
**解**：
(1) 设 `Xᵢ = 1` 若第 i 封信装进第 i 个信封，否则 0。`X = ΣXᵢ`。
`P(Xᵢ = 1) = 1/n`（第 i 封信等可能地进入 n 个信封中的任一个）。
`E(Xᵢ) = 1/n`。
`E(X) = ΣE(Xᵢ) = n × (1/n) = 1` ✓
**结论**：**无论 n 多大，平均恰有 1 封信装对！**
(2) `P(X=0) = Dₙ/n!`（错排数 ÷ 总排列数，见第 10 章）。
由错排公式：`P(X=0) = Dₙ/n! = Σ_{k=0}^{n}(−1)^k/k! → e^(−1) ≈ 0.3679` ✓
**答案**：(1) `E(X) = 1`；(2) `P(X=0) ≈ 0.3679`（n 较大时）。

**例 12.7**（题型：方差的计算）
设随机变量 X 的分布律为

| X | −1 | 0 | 1 | 2 |
|---|---|---|---|---|
| P | 0.2 | 0.3 | 0.4 | 0.1 |

求 `E(X)`、`E(X²)`、`D(X)`、`D(2X + 3)`。
**解**：
`E(X) = (−1)(0.2) + 0(0.3) + 1(0.4) + 2(0.1) = −0.2 + 0 + 0.4 + 0.2 = 0.4`
`E(X²) = (−1)²(0.2) + 0²(0.3) + 1²(0.4) + 2²(0.1) = 0.2 + 0 + 0.4 + 0.4 = 1.0`
`D(X) = E(X²) − [E(X)]² = 1.0 − (0.4)² = 1.0 − 0.16 = 0.84`
`D(2X + 3) = 2²·D(X) + D(3) = 4 × 0.84 + 0 = 3.36`
**答案**：`E(X) = 0.4`，`E(X²) = 1.0`，`D(X) = 0.84`，`D(2X+3) = 3.36` ✓
**验证 `E(2X+3)`**：`= 2E(X) + 3 = 2(0.4) + 3 = 3.8`。
直接算：`2(−1)+3 = 1`，`2(0)+3 = 3`，`2(1)+3 = 5`，`2(2)+3 = 7`；
加权：`1(0.2) + 3(0.3) + 5(0.4) + 7(0.1) = 0.2 + 0.9 + 2.0 + 0.7 = 3.8` ✓

**例 12.8**（题型：综合 —— 几何分布）
某试验每次成功概率为 p，独立重复直到成功为止。设 X 为所需试验次数。
(1) 求 X 的分布律；
(2) 求 `E(X)`；
(3) 求 `P(X > 3)`（设 p = 0.2）。
**解**：
(1) `X = k` 意味着**前 k−1 次都失败，第 k 次成功**。由独立性：
`P(X = k) = (1−p)^(k−1) · p`（`k = 1, 2, 3, …`）✓（几何分布）
**验证规范化**：`Σ_{k≥1}(1−p)^(k−1)p = p · 1/(1−(1−p)) = p/p = 1` ✓
(2) `E(X) = 1/p`（标准结果）。**直观**：成功率 1/p 意味着平均 p 次成功一次。
（推导：`E(X) = Σk(1−p)^(k−1)p`。设 `q = 1−p`，`E(X) = p·d/dq[Σq^k] = p·d/dq[q/(1−q)] = p·1/(1−q)² = p/p² = 1/p` ✓）
(3) 用互补：`P(X > 3) = 1 − P(X ≤ 3) = 1 − [P(1) + P(2) + P(3)]`
`= 1 − [0.2 + 0.8(0.2) + 0.8²(0.2)] = 1 − [0.2 + 0.16 + 0.128] = 1 − 0.488 = 0.512`
**另解（更简洁）**：`P(X > 3) = P(前 3 次都失败) = (0.8)³ = 0.512` ✓
**答案**：(1) `(1−p)^(k−1)p`；(2) `1/p`；(3) 0.512。

## 易错点提醒

1. **古典概型中用「无序」样本空间导致不等可能**。错：掷两颗骰子时用 21 个无序对作样本空间。正确：**必须用 36 个有序对**（否则 `(1,1)` 与 `(1,2)` 概率不等，不满足等可能性）。
2. **混淆「互斥」与「独立」**。错：认为「互斥就是独立」。正确：**互斥是「不能同时发生」（`P(AB) = 0`）；独立是「一个不影响另一个」（`P(AB) = P(A)P(B)`）**。若 `P(A), P(B) > 0`，二者**不可能同时成立**。
3. **独立性判断时只验证 `P(AB) = P(A)P(B)` 中的一侧**。错：凭直觉判断独立。正确：**必须严格验证等式**（或用条件概率 `P(B|A) = P(B)`）。
4. **两两独立误认为相互独立**。错：验证了三个两两等式就下结论。正确：**还需验证 `P(ABC) = P(A)P(B)P(C)`**。
5. **全概率公式遗漏或重复分类**。错：按「甲、乙、丙」分类但三类概率之和 ≠ 1。正确：**分类必须构成完备事件组**（两两互斥 + 并为全集），先验证 `ΣP(Bᵢ) = 1`。
6. **贝叶斯公式分子分母写反**。错：`P(Bᵢ|A) = P(Bᵢ|A)P(A)/…`（循环定义）。正确：**分子是 `P(A|Bᵢ)·P(Bᵢ)`**——「原因的概率 × 该原因下结果的条件概率」。
7. **贝叶斯公式只算分子不除以 `P(A)`**。错：`P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ) = 0.0125`。正确：**分母 `P(A)` 必须算**（用全概率公式），答案是 `0.0125/0.0345 ≈ 0.362`。**验证方法：所有后验概率之和应为 1**。
8. **`D(cX) = cD(X)`（忘记平方）**。错：`D(2X) = 2D(X)`。正确：**`D(2X) = 4D(X)`**。
9. **误用 `D(X+Y) = D(X) + D(Y)`（不要求独立）**。错：对不独立的 X, Y 直接相加方差。正确：**方差加法需要独立性**（一般有 `D(X+Y) = D(X) + D(Y) + 2Cov(X,Y)`）。
10. **混淆 `E(X)` 必须是 X 的可能取值**。错：认为骰子期望 3.5 不合法。正确：**期望是加权平均，可以是任何实数**。
11. **几何分布与二项分布混淆**。错：「第 3 次才成功」用二项分布算。正确：**「首次成功所需次数」用几何分布 `(1−p)^(k−1)p`**；**「n 次中成功 k 次」用二项分布 `C(n,k)p^k q^(n−k)`**。
12. **泊松分布期望与方差搞混**。错：`P(λ)` 的期望是 λ 但方差是 `λ²`。正确：**泊松分布的期望和方差都等于 λ**。
13. **「至少」问题忘记用互补**。错：算 `P(X≥1)` 时逐项相加。正确：**`P(X≥1) = 1 − P(X=0)`** 更快更不易错。
14. **样本空间的选择与问题不匹配**。错：求「两次都取到红球」时把样本空间当作 `C(8,2)`（无顺序）却用有顺序的有利情况数。正确：**样本空间与有利情况的计数方式必须一致**（都用排列或都用组合）。

## 本章小结

1. **样本空间 Ω** = 所有可能结果；**事件** = Ω 的子集；**互斥**（`AB = ∅`）与**对立**（`A∪B = Ω` 且 `AB = ∅`）不同。
2. **概率三公理**：非负性、规范性（`P(Ω)=1`）、可加性（互斥时可加）。
3. **互补公式 `P(～A) = 1 − P(A)`**（最常用）；**加法公式 `P(A∪B) = P(A)+P(B)−P(A∩B)`**；三事件版本与容斥原理同构。
4. **古典概型 `P(A) = |A|/|Ω|`**（有限 + 等可能）；**关键是用有序还是无序样本空间必须前后一致**。
5. **条件概率 `P(B|A) = P(AB)/P(A)`**；**乘法公式 `P(AB) = P(A)P(B|A)`**。
6. **独立性 `P(AB) = P(A)P(B)`**；**两两独立 ≠ 相互独立**；**独立 ≠ 互斥**。
7. **伯努利概型**：`P(恰 k 次成功) = C(n,k)p^k q^(n−k)`。
8. **全概率公式**：`P(A) = ΣP(A|Bᵢ)P(Bᵢ)`（**由因推果**，按完备事件组分类加权）。
9. **贝叶斯公式**：`P(Bᵢ|A) = P(A|Bᵢ)P(Bᵢ)/P(A)`（**由果溯因**，用数据修正先验）。**分母必须算全概率**。
10. **数学期望 `E(X) = Σxᵢpᵢ`**（加权平均）；**线性性 `E(X+Y) = E(X)+E(Y)` 无需独立**。
11. **方差 `D(X) = E(X²) − [E(X)]²`**；`D(cX) = c²D(X)`；**`D(X+Y) = D(X)+D(Y)` 需要独立**。
12. **常用分布**：`B(1,p)`：`E=p, D=p(1−p)`；`B(n,p)`：`E=np, D=np(1−p)`；`G(p)`：`E=1/p`；`P(λ)`：`E=D=λ`。

> **一句话记住本章**：**「概率 = 有利情况数 ÷ 总情况数（古典）；条件概率把样本空间缩小；独立是乘法、互斥是零；全概率按原因加权求和，贝叶斯由结果反推原因；期望是加权平均且可加，方差提常数要平方、相加要独立。」**
