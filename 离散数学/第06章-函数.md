## 6.1 函数的定义

### 6.1.1 函数的定义

**定义 6.1（函数）**：设 A、B 为集合，f 是从 A 到 B 的**二元关系**。若对每个 `x ∈ A`，**存在唯一的** `y ∈ B` 使 `⟨x, y⟩ ∈ f`，则称 f 是从 A 到 B 的**函数（Function）**，记 `f: A → B`。

三个要素：
- **定义域（Domain）**：`dom f = A`。**注意：A 中每个元素都必须有像，不能漏！**
- **陪域（Codomain）**：B。也叫共域。
- **值域（Range）**：`ran f = {y | ∃x ∈ A, f(x) = y} ⊆ B`。**值域是陪域的子集，不一定相等。**

**函数区别于一般关系的两条铁律**：
1. **单值性（存在性 + 唯一性）**：一个 x 只能对应**一个** y。`⟨x,y₁⟩` 和 `⟨x,y₂⟩` 同时属于 f 则必有 `y₁ = y₂`。
2. **全域性**：A 中每个元素都要有像，不允许「没定义」。

> **生活类比**：函数像一台**自动售货机**。投进一个 x，必须吐出一个 y；不能投入后什么都不出（违反全域性），也不能投一个吐出两个（违反单值性）。

**两个函数相等的条件**：
`f = g ⟺ dom f = dom g 且 ∀x ∈ dom f, f(x) = g(x)`

> **重点**：这两个条件**必须同时满足**。`f(x) = x²`（x ∈ R）与 `g(x) = x²`（x ∈ Z）**不相等**，定义域不同。

### 6.1.2 从 A 到 B 的函数总数

**定理 6.1**：设 `|A| = m`，`|B| = n`（有限集），则从 A 到 B 的函数共有 `n^m` 个。

**为什么**：给 A 中每个元素选一个像，m 个元素各 n 种选法，由乘法原理得 `n^m`。

**例**：`A = {1,2}`，`B = {a,b,c}`。函数共 `3² = 9` 个。
（对应地，A 到 B 的**关系**共 `2^(2×3) = 2⁶ = 64` 个——函数比关系少得多，因为函数有单值性和全域性约束。）

### 6.1.3 常见的函数类型

| 名称 | 定义 | 例 |
|---|---|---|
| **恒等函数** `I_A` | `I_A(x) = x`，`∀x ∈ A` | 实数上的 `f(x) = x` |
| **常函数** | `f(x) = c`（固定常数） | `f(x) = 3` |
| **特征函数** `χ_A` | `χ_A(x) = 1`（x ∈ A 时），`0`（x ∉ A 时） | 用来把集合代数化成算术 |
| **取整函数** | `⌊x⌋`（下取整）、`⌈x⌉`（上取整） | `⌊2.7⌋ = 2`，`⌈2.1⌉ = 3` |
| **阶跃函数** | 分段常数函数 | 用于信号处理 |
| **单值函数** | —— | 「单值」是函数定义的一部分 |

**取整函数的两条重要性质**：
`x − 1 < ⌊x⌋ ≤ x`
`⌈x⌉ − 1 < x ≤ ⌈x⌉`

**特征函数与集合运算的对应**：
`χ_{A∩B}(x) = χ_A(x) · χ_B(x)`
`χ_{A∪B}(x) = χ_A(x) + χ_B(x) − χ_A(x)·χ_B(x)`
`χ_{～A}(x) = 1 − χ_A(x)`

### 6.1.4 从 A 到 B 的偏函数（了解）

**定义 6.2（偏函数）**：若 f 只要求「**每个有定义的 x 唯一对应一个 y**」，不要求 A 中每个元素都有定义，则称 f 为**偏函数（Partial Function）**。

> **联系计算机**：程序中的「函数」往往是偏函数——`int div(int a, int b) { return a/b; }` 在 `b = 0` 时没有定义。

## 6.2 函数的像与完全原像

**定义 6.3（像）**：设 `f: A → B`，`A' ⊆ A`。则
`f(A') = {f(x) | x ∈ A'}`
称为 `A'` 在 f 下的**像（Image）**。

**定义 6.4（完全原像）**：设 `B' ⊆ B`。则
`f⁻¹(B') = {x | x ∈ A 且 f(x) ∈ B'}`
称为 `B'` 在 f 下的**完全原像（Inverse Image / Preimage）**。

**注意**：`f⁻¹(B')` 里的 `f⁻¹` **不是反函数**，它是对**集合**运算的记号，总存在，无需 f 是双射！

**像与原像的性质（对比很重要）**：

| 运算 | 像 `f(A' ∪ A'')` | 像 `f(A' ∩ A'')` | 原像 `f⁻¹(B' ∩ B'')` |
|---|---|---|---|
| 结论 | `= f(A') ∪ f(A'')` | **`⊆ f(A') ∩ f(A'')`** | `= f⁻¹(B') ∩ f⁻¹(B'')` |
| 是否取等 | 一定取等 | **单射时才取等** | 一定取等 |

> **重点**：**像对「并」可分配，对「交」只能单向包含**；**完全原像对「并」「交」「差」都可分配**。这是本章最爱考的性质判断题。
>
> **反例**（`f(A'∩A'') ⊊ f(A')∩f(A'')`）：`f: R → R`，`f(x) = x²`，`A' = [−2, 0]`，`A'' = [0, 2]`。
> `A' ∩ A'' = {0}`，`f(A'∩A'') = {0}`。
> `f(A') = [0, 4]`，`f(A'') = [0, 4]`，`f(A') ∩ f(A'') = [0, 4]`。
> `{0} ⊊ [0, 4]` ✓

**定理 6.2**：若 `f: A → B` 是**单射**，则对任意 `A', A'' ⊆ A` 有 `f(A' ∩ A'') = f(A') ∩ f(A'')`。

**证明**：只需证 `⊇`。
任取 `y ∈ f(A') ∩ f(A'')`。则存在 `x₁ ∈ A'` 使 `f(x₁) = y`，且存在 `x₂ ∈ A''` 使 `f(x₂) = y`。
因 `f(x₁) = f(x₂)` 且 f 是**单射**，故 `x₁ = x₂`。于是 `x₁ ∈ A' ∩ A''`，从而 `y = f(x₁) ∈ f(A' ∩ A'')` ✓。∎

> **为什么这里用得上单射**：只有单射才能从 `f(x₁) = f(x₂)` 推出 `x₁ = x₂`，把「两个不同的 x 映到同一个 y」的可能性排除掉。

## 6.3 函数的性质 ★★★★★

### 6.3.1 三种性质的定义

**定义 6.5（单射）**：设 `f: A → B`。若
`∀x₁, x₂ ∈ A, f(x₁) = f(x₂) → x₁ = x₂`
则称 f 是**单射（Injective / One-to-one）**，也叫**入射**。

**等价说法（更常用）**：`x₁ ≠ x₂ → f(x₁) ≠ f(x₂)`（不同元素映到不同像）。
**逆否形式**：`f(x₁) = f(x₂) → x₁ = x₂`。

**定义 6.6（满射）**：设 `f: A → B`。若
`ran f = B`，即 `∀y ∈ B, ∃x ∈ A, f(x) = y`
则称 f 是**满射（Surjective / Onto）**，也叫**映上**。

**定义 6.7（双射）**：若 f **既是单射又是满射**，则称 f 是**双射（Bijective）**，也叫**一一对应（One-to-one Correspondence）**。

> **生活类比**：
> - **单射**：多个人坐一排椅子，**不许两人挤一把椅子**（椅子可以空着）。
> - **满射**：**每把椅子都有人坐**（允许多人挤一把）。
> - **双射**：**一人一把椅子，不多不少**——这就是「一一对应」。

### 6.3.2 判定表（核心工具）

设 `f: A → B`，`|A| = m`，`|B| = n`（有限）。

| 性质 | 形式化定义 | 判定方法 | 必要条件 |
|---|---|---|---|
| **单射** | `f(x₁)=f(x₂) ⟹ x₁=x₂` | 解方程法：由 `f(x₁)=f(x₂)` 推出 `x₁=x₂` | `m ≤ n` |
| **满射** | `∀y∈B, ∃x∈A, f(x)=y` | 解方程法：对任意 y 解出 x，并验证 `x ∈ A` | `m ≥ n` |
| **双射** | 单射 + 满射 | 两法都用；或直接构造逆映射 | `m = n` |
| **非单射** | —— | 找 `x₁ ≠ x₂` 使 `f(x₁) = f(x₂)` | 若 `m > n` 必非单射 |
| **非满射** | —— | 找 `y ∈ B` 使方程 `f(x) = y` 在 A 中无解 | 若 `m < n` 必非满射 |

> **重点（有限集必考结论）**：设 A、B 是**有限集**且 `|A| = |B|`，则
> **f 单射 ⟺ f 满射 ⟺ f 双射**
> 这个等价性只对**有限集**成立！对无限集不成立，例如 `f: N → N`，`f(n) = 2n` 是单射但**不是满射**（奇数没有原像）。

**证明「单射 ⟺ 满射（有限同基数）」**：
（单射 ⟹ 满射）设 f 单射，则 `|ran f| = |A| = |B|`。又 `ran f ⊆ B` 且 `|B|` 有限，故 `ran f = B`，f 满射 ✓
（满射 ⟹ 单射）设 f 满射，则 `ran f = B`，`|ran f| = |B| = |A|`。若 f 非单射，则存在 `x₁ ≠ x₂` 映到同一 y，那么 `|ran f| < |A|`，矛盾 ✓ ∎

### 6.3.3 常见函数的性质判定

| 函数 | 定义域 → 陪域 | 单射？ | 满射？ | 双射？ |
|---|---|---|---|---|
| `f(x) = x` | R → R | ✓ | ✓ | ✓ |
| `f(x) = x²` | R → R | ✗（`f(−1)=f(1)`） | ✗（负数无原像） | ✗ |
| `f(x) = x²` | R → [0, +∞) | ✗ | ✓ | ✗ |
| `f(x) = x²` | [0, +∞) → [0, +∞) | ✓ | ✓ | ✓ |
| `f(x) = x³` | R → R | ✓ | ✓ | ✓ |
| `f(x) = e^x` | R → R | ✓ | ✗（值域是 (0,+∞)） | ✗ |
| `f(x) = e^x` | R → (0, +∞) | ✓ | ✓ | ✓ |
| `f(x) = sin x` | R → [−1,1] | ✗ | ✓ | ✗ |
| `f(x) = sin x` | [−π/2, π/2] → [−1,1] | ✓ | ✓ | ✓ |
| `f(x) = \|x\|` | R → R | ✗ | ✗ | ✗ |
| `f(x) = 2x` | N → N | ✓ | ✗ | ✗ |
| `f(x) = 2x` | Z → Z | ✓ | ✗ | ✗ |
| `f(x) = 2x` | R → R | ✓ | ✓ | ✓ |
| `f(n) = n mod 3` | Z → {0,1,2} | ✗ | ✓ | ✗ |
| `f(x) = ⌊x⌋` | R → Z | ✗ | ✓ | ✗ |

> **重点观察**：**同一个公式 `f(x) = x²`，改一下定义域和陪域，单射/满射的结论就完全不同**。做判定题必须**盯住定义域和陪域**。

### 6.3.4 证明单射/满射的套路

**证明单射的标准流程**：
```
设 x₁, x₂ ∈ A 且 f(x₁) = f(x₂)。
…（化简变形）…
得到 x₁ = x₂。
故 f 是单射。∎
```

**证明满射的标准流程**：
```
任取 y ∈ B。
令 x = …（用 y 表示出候选的 x）…。
验证 x ∈ A：（这一步不能省！）
且 f(x) = … = y。
故 f 是满射。∎
```

**证明不是单射**：举出 `x₁ ≠ x₂` 但 `f(x₁) = f(x₂)`。
**证明不是满射**：举出 `y ∈ B`，说明方程 `f(x) = y` 无解。

**例**：证明 `f: R → R`，`f(x) = 3x + 1` 是双射。
**证明**：
① **单射**：设 `f(x₁) = f(x₂)`，即 `3x₁ + 1 = 3x₂ + 1`。两边减 1 得 `3x₁ = 3x₂`，两边除 3 得 `x₁ = x₂` ✓
② **满射**：任取 `y ∈ R`。取 `x = (y − 1)/3`。
因 y 是实数，`(y−1)/3` 也是实数，故 `x ∈ R` ✓
且 `f(x) = 3·(y−1)/3 + 1 = (y − 1) + 1 = y` ✓
故 f 是满射。
③ 单射且满射 → **f 是双射** ∎

## 6.4 复合函数

**定义 6.8（复合函数）**：设 `f: A → B`，`g: B → C`。则
`(g ∘ f)(x) = g(f(x))`，`∀x ∈ A`
称为 f 与 g 的**复合函数（Composite Function）**，`g ∘ f: A → C`。

> **读法与顺序**：`g ∘ f` 读作「g 复合 f」，**先作用 f，再作用 g**。这和关系的复合约定 `R ∘ S`（先 R 后 S）一致。
> **记忆口诀**：**「从右往左读」**——`g ∘ f` 先算右边那个 f。

**复合成立的前提**：`ran f ⊆ dom g`（f 的值域必须落在 g 的定义域内）。

**例**：`f: R → R`，`f(x) = x + 1`；`g: R → R`，`g(x) = x²`。
- `(g ∘ f)(x) = g(f(x)) = (x+1)²`
- `(f ∘ g)(x) = f(g(x)) = x² + 1`

**`g ∘ f ≠ f ∘ g`**——复合**不满足交换律**。

**复合的性质（4 条必背）**：

| 编号 | 命题 | 成立？ |
|---|---|---|
| 1 | `f, g` 都是单射 ⟹ `g ∘ f` 是单射 | **✓** |
| 2 | `f, g` 都是满射 ⟹ `g ∘ f` 是满射 | **✓** |
| 3 | `f, g` 都是双射 ⟹ `g ∘ f` 是双射 | **✓** |
| 4 | `g ∘ f` 是单射 ⟹ **f 是单射**（但 g 不一定） | **✓（半条）** |
| 5 | `g ∘ f` 是满射 ⟹ **g 是满射**（但 f 不一定） | **✓（半条）** |
| 6 | `f` 单射且 `g` 单射 ⟺ `g ∘ f` 单射 | ✗（第 6 条方向不成立，见下） |

**证明第 1 条（`g ∘ f` 是单射）**：
设 `(g∘f)(x₁) = (g∘f)(x₂)`，即 `g(f(x₁)) = g(f(x₂))`。
因 g 是**单射**，故 `f(x₁) = f(x₂)`。
又因 f 是**单射**，故 `x₁ = x₂`。所以 `g ∘ f` 是单射 ✓ ∎

**证明第 4 条（`g∘f` 单射 ⟹ f 单射）**：
设 `f(x₁) = f(x₂)`。两边作用 g 得 `g(f(x₁)) = g(f(x₂))`，即 `(g∘f)(x₁) = (g∘f)(x₂)`。
因 `g∘f` 单射，故 `x₁ = x₂`。所以 f 是单射 ✓ ∎
**注意**：这里**推不出 g 单射**。反例：`A = {1}`，`B = {a, b}`，`C = {c}`，`f(1) = a`，`g(a) = g(b) = c`。则 `g∘f`（从 A 到 C）是单射（只有一个点），但 **g 不是单射** ✓

**证明第 5 条（`g∘f` 满射 ⟹ g 满射）**：
任取 `z ∈ C`。因 `g∘f: A → C` 满射，存在 `x ∈ A` 使 `(g∘f)(x) = z`，即 `g(f(x)) = z`。
令 `y = f(x) ∈ B`，则 `g(y) = z`。所以 g 满射 ✓ ∎
**注意**：这里**推不出 f 满射**。反例：`A = {1}`，`B = {a, b}`，`C = {c}`，取 `f(1) = a`，`g(a) = g(b) = c`。`g∘f` 满射 ✓，但 **f 不是满射**（b 无原像）✓

> **重点**：`g∘f` 单射只能保证「前一个」f 单射；`g∘f` 满射只能保证「后一个」g 满射。**方向别记反**——「单射往前传，满射往后传」。

## 6.5 反函数

**定义 6.9（反函数）**：设 `f: A → B` 是**双射**。定义 `f⁻¹: B → A`：
`f⁻¹(y) = x ⟺ f(x) = y`
称 `f⁻¹` 为 f 的**反函数（Inverse Function）**。

**定理 6.3（反函数存在的充要条件）**：`f: A → B` 存在反函数 `f⁻¹: B → A` **⟺ f 是双射**。

**为什么**：
- **满射是必要的**：若 f 不满射，存在 `y ∈ B` 无原像，`f⁻¹(y)` 就没有定义 → 不是函数。
- **单射是必要的**：若 f 不单射，存在 `y` 有两个原像 `x₁ ≠ x₂`，那 `f⁻¹(y)` 就是两个值 → 违反单值性。
- **充分性**：若 f 是双射，每个 `y ∈ B` 恰有一个原像，按此定义 `f⁻¹` 就满足函数的两条铁律 ✓ ∎

**反函数的性质**：
| 性质 | 内容 |
|---|---|
| 双射性 | `f⁻¹` 也是双射（从 B 到 A） |
| 双向互逆 | `(f⁻¹)⁻¹ = f` |
| 左逆右逆 | `f⁻¹ ∘ f = I_A`；`f ∘ f⁻¹ = I_B` |
| 复合取逆 | **`(g ∘ f)⁻¹ = f⁻¹ ∘ g⁻¹`**（顺序颠倒！） |
| 单调性 | 严格单调的实函数一定是单射（不一定满射） |

**证明 `(g∘f)⁻¹ = f⁻¹ ∘ g⁻¹`**（设 `f: A→B`、`g: B→C` 都是双射）：
任取 `z ∈ C`。因 `g∘f: A → C` 是双射，有反函数。
设 `(g∘f)⁻¹(z) = x`，即 `(g∘f)(x) = z`，即 `g(f(x)) = z`。
由 `g(f(x)) = z` 得 `f(x) = g⁻¹(z)`；再由 `f(x) = g⁻¹(z)` 得 `x = f⁻¹(g⁻¹(z)) = (f⁻¹ ∘ g⁻¹)(z)`。
所以 `(g∘f)⁻¹(z) = (f⁻¹ ∘ g⁻¹)(z)` 对一切 z 成立，故 `(g∘f)⁻¹ = f⁻¹ ∘ g⁻¹` ✓ ∎

> **生活类比**：穿衣服的顺序是「先穿袜子，再穿鞋」（`g ∘ f`）；脱衣服必须「先脱鞋，再脱袜子」（`f⁻¹ ∘ g⁻¹`）——顺序**必须反过来**。

## 6.6 基数与可数性 ★★★★★

### 6.6.1 等势（对等）

**定义 6.10（等势）**：设 A、B 为集合。若**存在从 A 到 B 的双射**，则称 A 与 B **等势（Equipotent）**或**对等**，记 `A ~ B`。此时也说 A 与 B **基数相同**，记 `|A| = |B|`。

**等势关系是等价关系**：
- 自反：`I_A: A → A` 是双射 ✓
- 对称：`f` 是双射 ⟹ `f⁻¹` 是双射 ✓
- 传递：`f: A→B`、`g: B→C` 都是双射 ⟹ `g∘f: A→C` 是双射 ✓

> **重点**：「基数」不是「元素个数」（无限集没有个数），而是**「等势类」的标签**。两个集合基数相同，意思就是「能一一配对」。

**对等的一批重要例子（必须记住）**：

| 结论 | 说明 |
|---|---|
| `N ~ N*` | `f(n) = n + 1` 是双射 |
| `N ~ Z` | 见下方配对法 |
| `N ~ Q` | 用「蛇形枚举」 |
| `(0, 1) ~ R` | `f(x) = tan(π(x − 1/2))` |
| `N ~ N × N` | `f(m,n) = 2^m(2n+1) − 1` |
| `[0,1] ~ [0,2]` | `f(x) = 2x` |
| `P(N) ~ R` | 著名的「实数与自然数幂集等势」 |

**`N ~ Z` 的配对法**：
`f: N → Z`，`f(0) = 0`，`f(1) = 1`，`f(2) = −1`，`f(3) = 2`，`f(4) = −2`，…
公式：`f(n) = (−1)^n · ⌈n/2⌉`（或分段定义）。
**直观理解**：把整数排成一队 `0, 1, −1, 2, −2, 3, −3, …`，每个自然数依次对应过去。

### 6.6.2 有限集与无限集

**定义 6.11（有限集 / 无限集）**：
- 若集合 A 与某个自然数 n 的集合 `{0, 1, …, n−1}` 等势，则称 A 是**有限集（Finite Set）**，`|A| = n`。
- 不与任何自然数等势的集合称为**无限集（Infinite Set）**。

**无限集的 Dedekind 定义（另一种刻画）**：
**A 是无限集 ⟺ A 与其某个真子集等势。**

**例**：`N ~ N*`（`N*` 是 N 的真子集），所以 N 是无限集。
**这条定义的意义**：它精确刻画了无限集「部分可以等于整体」这一反直觉特征——这正是伽利略悖论的内容。

### 6.6.3 可数集

**定义 6.12（可数集 /  countable）**：
- 若 A 是有限集，或 `A ~ N`，则称 A 为**可数集（Countable Set）**。
- 若 `A ~ N`，则称 A 为**可数无限集**（也叫**可列集**）。
- 若 A 是无限集且不与 N 等势，则称 A 是**不可数集（Uncountable Set）**。

**核心直观**：**可数集就是「能排成一队，一个一个数出来」的集合**（每个元素都能被指定一个有限的编号）。

**定理 6.4（可数集的核心性质）**：
1. **可数集的任何子集是可数集。**
2. **可数个可数集的并是可数集。**
3. **有限个可数集的笛卡儿积是可数集**（即 `N × N ~ N`）。
4. **若 A 可数、B 可数，则 `A ∪ B` 可数。**
5. **可数集的无限子集一定是可数无限集。**

**证明第 3 条（`N × N ~ N`）—— 蛇形枚举法**：
把 `N × N` 的元素按「对角线」排列：

```
        n=0    n=1    n=2    n=3  …
  m=0  (0,0)  (0,1)  (0,2)  (0,3)
         ↙      ↙      ↙
  m=1  (1,0)  (1,1)  (1,2)  (1,3)
         ↙      ↙
  m=2  (2,0)  (2,1)  (2,2)  (2,3)
         ↙
  m=3  (3,0)  (3,1)  (3,2)  (3,3)
```
沿对角线走：`(0,0), (0,1), (1,0), (0,2), (1,1), (2,0), (0,3), …`
每个有序对都恰好被访问一次，于是得到双射 `f: N → N × N` ✓
（也可以直接用公式 `f(m,n) = 2^m(2n+1) − 1`，验证一下：(0,0) → 0，(0,1) → 2，(1,0) → 1，确实不重不漏。）

**证明第 2 条（可数并）**：把每列可数集排成一行，再用同样的「对角线扫描」遍历整个二维表。∎

**推论：Q 是可数集**
**证明**：每个正有理数唯一写成最简分数 `p/q`（`p, q ∈ N*`，`gcd(p,q) = 1`）。于是正有理数集与 `N* × N*` 的某个子集等势。而 `N* × N*` 可数，子集也可数；再加上 0 和负有理数（只是两份拷贝），仍可数。所以 `Q` 可数 ✓ ∎

> **重点**：**「稠密」不等于「不可数」！** 有理数在实数轴上处处稠密（任意两个实数之间都有有理数），但它**可数**。这是最反直觉的结论之一。

### 6.6.4 实数集不可数

**定理 6.5（康托尔，1874）**：实数集 `R` 是**不可数集**。

**证明（对角线论证，对开区间 (0,1)）**：
只需证 `(0, 1)` 不可数（因为 `(0,1) ~ R`，若 (0,1) 可数则 R 也可数，矛盾）。
**反证**：假设 `(0, 1)` 可数，则（它是无限集）可数无限，可以**排成一列**：
```
r₁ = 0. a₁₁ a₁₂ a₁₃ a₁₄ …
r₂ = 0. a₂₁ a₂₂ a₂₃ a₂₄ …
r₃ = 0. a₃₁ a₃₂ a₃₃ a₃₄ …
r₄ = 0. a₄₁ a₄₂ a₄₃ a₄₄ …
⋮
```
（这里 `aᵢⱼ` 是第 i 个实数的第 j 位小数；为避免 0.4999… = 0.5000… 的歧义，约定小数表示不使用末尾全 9 的形式。）

现在**构造**一个实数 `r = 0. b₁ b₂ b₃ b₄ …`，其中
`bᵢ = 5` 若 `aᵢᵢ ≠ 5`；`bᵢ = 4` 若 `aᵢᵢ = 5`。
（即：让 r 的第 i 位**故意不等于** rᵢ 的第 i 位，且避开 0 和 9 以免表示歧义。）

于是对**每一个** i，`r ≠ rᵢ`（因为它们的第 i 位小数不同）。
所以 `r ∈ (0, 1)` 却不在上面的列表里，与「列表包含 (0,1) 全部元素」矛盾。
故 `(0, 1)` 不可数，从而 `R` 不可数 ✓ ∎

> **为什么叫「对角线论证」**：构造时用的是列表的**对角线元素** `a₁₁, a₂₂, a₃₃, …`——只在这些位置上做手脚，就能造出一个「谁都不是」的新元素。

**`R ~ P(N)`（补充结论）**：把实数写成二进制小数，每个实数对应 N 的一个子集（第 n 位为 1 表示 n 在该子集中）。这个对应几乎处处是双射，故 `R ~ P(N)`。

### 6.6.5 康托尔定理与基数比较

**定义 6.13（基数的大小）**：设 A、B 为集合。
- `|A| ≤ |B|` ⟺ 存在从 A 到 B 的**单射**。
- `|A| < |B|` ⟺ `|A| ≤ |B|` 但 `|A| ≠ |B|`（即不存在双射）。

**定理 6.6（康托尔-伯恩斯坦-施罗德定理）**：
若 `|A| ≤ |B|` 且 `|B| ≤ |A|`，则 `|A| = |B|`。
（即：若存在 A→B 的单射和 B→A 的单射，则存在 A→B 的双射。）
**用途**：证明两集合等势时，可以**分开构造两个单射**，比直接构造双射容易得多。

**定理 6.7（康托尔定理）**：对任意集合 A，`|A| < |P(A)|`。

**证明**：
① **先证 `|A| ≤ |P(A)|`**：映射 `f(x) = {x}` 是从 A 到 `P(A)` 的**单射**（不同的 x 给出不同的单元素集） ✓
② **再证 `|A| ≠ |P(A)|`**（即不存在 A 到 P(A) 的双射）。反证：假设存在双射 `g: A → P(A)`。
构造集合 `D = {x ∈ A | x ∉ g(x)}`（即 D 由「不属于自己对应集合」的元素组成）。
因 `D ⊆ A`，故 `D ∈ P(A)`。因 g 是**满射**，存在 `a ∈ A` 使 `g(a) = D`。
现在问：**`a ∈ D` 吗？**
- 若 `a ∈ D`，由 D 的定义（`x ∈ D ⟺ x ∉ g(x)`）得 `a ∉ g(a) = D`，矛盾。
- 若 `a ∉ D`，则 `a ∉ g(a)`，由 D 的定义得 `a ∈ D`，矛盾。

两难！故不存在这样的双射，`|A| ≠ |P(A)|` ✓
由①②得 `|A| < |P(A)|` ✓ ∎

> **这个证明的结构和罗素悖论完全一样**：`D` 就是「不属于自己的集合的集合」。这个「自指构造」是数学中最深刻的手法之一。

**推论**：不存在「最大的基数」。从 N 出发不断取幂集：
`ℵ₀ = |N| < |P(N)| = |R| = c < |P(P(N))| < |P(P(P(N)))| < …`
**基数序列无限上升。**

### 6.6.6 几个基数记号

| 记号 | 名称 | 对应集合 | 说明 |
|---|---|---|---|
| `ℵ₀`（阿列夫零） | 可数无穷基数 | N、Z、Q、N×N、代数数 | 最小的无限基数 |
| `c` 或 `2^ℵ₀` | 连续统基数 | R、(0,1)、[0,1]、P(N)、Rⁿ | 严格大于 ℵ₀ |
| `ℵ₁` | 第一不可数基数 | —— | 最小的比 ℵ₀ 大的基数 |

**连续统假设（CH）**：`c = ℵ₁`？即「在 ℵ₀ 与 c 之间没有其他基数」？
**答案**：哥德尔（1938）证明 CH **不能从 ZFC 公理系统证伪**；科恩（1963）证明 CH **不能从 ZFC 公理系统证明**。
结论：**CH 与 ZFC 公理系统独立**——这是 20 世纪数学最重大的成果之一。

## 典型例题

**例 6.1**（题型：判断是否为函数）
判断下列关系是否为从 A 到 B 的函数：
(1) `A = B = R`，`R₁ = {⟨x, y⟩ | x² + y² = 1}`；
(2) `A = B = R`，`R₂ = {⟨x, y⟩ | y = 2x + 1}`；
(3) `A = R`，`B = R`，`R₃ = {⟨x, y⟩ | y = √x}`；
(4) `A = R`，`B = R`，`R₄ = {⟨x, y⟩ | y = 1/x}`。
**解**：
(1) **不是函数**。它是单位圆。取 `x = 0`，则 `y = ±1`，有两个 y 与之对应 → **违反单值性**。
(2) **是函数**。对每个实数 x，`2x + 1` 唯一确定且是实数 → 单值性 ✓ 全域性 ✓。
(3) **不是函数**。`√x` 仅对 `x ≥ 0` 有定义，负数没有像 → **违反全域性**（`dom R₃ = [0, +∞) ≠ R`）。
(4) **不是函数**。`x = 0` 时 `1/0` 无定义 → **违反全域性**（`dom R₄ = R − {0} ≠ R`）。
**答案**：(2) 是函数；(1)(3)(4) 不是。

**例 6.2**（题型：单射/满射/双射判定 —— 有限集）
设 `A = {1,2,3,4}`，`B = {a,b,c}`，`f: A → B` 定义为 `f(1) = a, f(2) = b, f(3) = a, f(4) = c`。判断 f 的性质。
**解**：
① **单射？** `f(1) = f(3) = a` 但 `1 ≠ 3` → **不是单射 ✗**
② **满射？** B 中每个元素都有原像吗？
- `a` 的原像：1（或 3）✓
- `b` 的原像：2 ✓
- `c` 的原像：4 ✓

→ **是满射 ✓**
③ 单射 ✗，故**不是双射**。
**答案**：满射，非单射，非双射。
> **快速检查**：`|A| = 4 > |B| = 3`，**必然不是单射**（鸽巢原理）。这是省时间的判断技巧。

**例 6.3**（题型：证明双射 —— 实数区间）
证明 `f: (0, 1) → (0, 2)`，`f(x) = 2x` 是双射。
**证明**：
① **单射**：设 `f(x₁) = f(x₂)`，即 `2x₁ = 2x₂`，两边除 2 得 `x₁ = x₂` ✓
② **满射**：任取 `y ∈ (0, 2)`。取 `x = y/2`。
验证 `x ∈ (0,1)`：因 `0 < y < 2`，两边除 2 得 `0 < y/2 < 1` ✓（**这一步不能省**）
且 `f(x) = 2 · y/2 = y` ✓
故 f 是满射。
③ 单射且满射 → f 是双射 ∎

**例 6.4**（题型：复合函数与性质）
设 `f: Z → Z`，`f(n) = 2n`；`g: Z → Z`，`g(n) = ⌊n/2⌋`。
(1) 求 `g ∘ f` 和 `f ∘ g`；(2) 判断它们的性质。
**解**：
(1) `(g ∘ f)(n) = g(f(n)) = g(2n) = ⌊2n/2⌋ = ⌊n⌋ = n`（因 n 是整数），故 `g ∘ f = I_Z`。
`(f ∘ g)(n) = f(g(n)) = f(⌊n/2⌋) = 2⌊n/2⌋`。
当 n 为偶数时 `= n`；当 n 为奇数时 `= n − 1`。故 `f ∘ g` **不是恒等函数**。
(2) 分析：
- **`g ∘ f = I_Z` 是双射** ✓（恒等映射）
- **f 是单射** ✓（`2n₁ = 2n₂ ⟹ n₁ = n₂`），**不是满射** ✗（奇数无原像）
- **g 是满射** ✓（任意 `m ∈ Z`，取 `n = 2m` 则 `g(2m) = m`），**不是单射** ✗（`g(0) = g(1) = 0`）

**验证了前面两条结论**：`g∘f` 单射 ⟹ f 单射 ✓（f 确实单射）；`g∘f` 满射 ⟹ g 满射 ✓（g 确实满射）。
**答案**：`g ∘ f = I_Z`（双射），`f ∘ g ≠ I_Z`；f 单射非满射，g 满射非单射。

**例 6.5**（题型：证明集合可数）
证明 `N × N` 是可数集（用公式法）。
**证明**：
定义 `f: N × N → N`，`f(m, n) = 2^m (2n + 1) − 1`。
① **先说明 f 良定义**：`2^m(2n+1)` 是正整数（m ≥ 0，2n+1 ≥ 1），故 `f(m,n) ≥ 0`，确实是自然数 ✓
② **单射**：设 `f(m₁, n₁) = f(m₂, n₂)`，即 `2^{m₁}(2n₁+1) = 2^{m₂}(2n₂+1)`。
两边都是「2 的幂 × 奇数」的形式，由**算术基本定理**（唯一分解），2 的指数必须相同、奇数部分必须相同：
故 `m₁ = m₂` 且 `2n₁ + 1 = 2n₂ + 1`，得 `n₁ = n₂` ✓
③ **满射**：任取 `k ∈ N`。考察 `k + 1` 这个正整数。把它分解为 `2^m × (奇数)` 的形式（m ≥ 0）。
设 `k + 1 = 2^m · q`，q 为奇数。则 `q = 2n + 1` 对某个 `n ≥ 0` 成立（奇数必为 `2n+1` 形式）。
于是 `k + 1 = 2^m(2n+1)`，即 `k = f(m, n)` ✓
④ f 是双射，故 `N × N ~ N`，`N × N` 可数 ∎

**例 6.6**（题型：康托尔定理应用）
证明 `P(N)` 不可数。
**证明**：
① 由康托尔定理 `|N| < |P(N)|`。因 `N` 是可数无限集，`|N| = ℵ₀`，故 `|P(N)| > ℵ₀`。
② 不可数的定义：无限集且不与 N 等势。由 ① `P(N)` 与 N 不等势，且 `P(N)` 是无限集（因为 N 有无穷多个有限子集 `{0}, {1}, {2}, …`），故 `P(N)` **不可数** ✓ ∎
> **补充**：也可以用对角线法直接证明。假设 `P(N) = {S₁, S₂, S₃, …}`，构造 `D = {n ∈ N | n ∉ Sₙ}`，则 D 与每个 Sₙ 都不同（差在第 n 个元素上）。

**例 6.7**（题型：求函数的像与原像）
设 `f: Z → Z`，`f(x) = x²`。求 `f({1, 2, 3})`、`f⁻¹({1, 4})`、`f⁻¹({2, 3})`。
**解**：
① `f({1,2,3}) = {f(1), f(2), f(3)} = {1, 4, 9}`
② `f⁻¹({1,4})`：找所有使 `x² ∈ {1,4}` 的整数 x。
`x² = 1 → x = ±1`；`x² = 4 → x = ±2`。故 `f⁻¹({1,4}) = {−2, −1, 1, 2}`
③ `f⁻¹({2,3})`：找 `x² ∈ {2,3}` 的整数。没有整数的平方是 2 或 3，故 `f⁻¹({2,3}) = ∅`
**答案**：`{1,4,9}`；`{−2,−1,1,2}`；`∅`。
> **注意 ③**：**完全原像可以是空集**，即使集合 B' 非空！因为 f 不是满射。

**例 6.8**（题型：基数比较）
比较 `|N|`、`|R|`、`|Q|`、`|P(N)|`、`|N × N|` 的大小，并按从小到大排列。
**解**：
- `|N| = ℵ₀`（可数无限）
- `|Q| = ℵ₀`（可数集）
- `|N × N| = ℵ₀`（可数集）
- `|R| = c`（不可数，连续统基数）
- `|P(N)| = c`（与 R 等势）

由康托尔定理 `ℵ₀ < c`。
**排序**：`|N| = |Q| = |N × N| = ℵ₀ < c = |R| = |P(N)|`
**答案**：`|N| = |Q| = |N×N| < |R| = |P(N)|`。

**例 6.9**（题型：证明单射/满射）
设 `f: R → R`，`f(x) = 2^x`。判断 f 的性质，并说明如何修改陪域使其成为双射。
**解**：
① **单射 ✓**：设 `2^{x₁} = 2^{x₂}`。两边取以 2 为底的对数（指数函数严格单调）得 `x₁ = x₂` ✓
② **满射 ✗**：任取 `y = −1 ∈ R`，方程 `2^x = −1` 无实数解（指数函数恒正）→ 不是满射。
③ 修改陪域为 `(0, +∞)`：此时任取 `y ∈ (0,+∞)`，取 `x = log₂ y`，则 `x ∈ R` 且 `f(x) = 2^{log₂ y} = y` ✓ → **满射**。
于是 `f: R → (0, +∞)`，`f(x) = 2^x` **是双射**，其反函数为 `f⁻¹(y) = log₂ y`。
**答案**：原函数单射非满射；陪域改为 `(0, +∞)` 后成为双射。

**例 6.10**（题型：反函数与复合）
设 `f: R → R`，`f(x) = 3x − 2`；`g: R → R`，`g(x) = x² + 1`。
(1) 判断 f、g 是否双射；(2) 若可能，求 `f⁻¹`、`g⁻¹`；(3) 求 `(f⁻¹ ∘ g)(x)`。
**解**：
(1) **f 是双射**：单射（`3x₁−2 = 3x₂−2 ⟹ x₁ = x₂`），满射（任取 y，取 `x = (y+2)/3 ∈ R`，`f(x) = y` ✓）。
**g 不是单射**：`g(−1) = g(1) = 2` 但 `−1 ≠ 1`。故 g 不是双射。
(2) 由 `y = 3x − 2` 解出 `x = (y + 2)/3`，故 `f⁻¹(y) = (y + 2)/3`。
**g⁻¹ 不存在**（g 不是双射）。
(3) `(f⁻¹ ∘ g)(x) = f⁻¹(g(x)) = f⁻¹(x² + 1) = ((x² + 1) + 2)/3 = (x² + 3)/3`
**答案**：`f⁻¹(y) = (y+2)/3`；`g⁻¹` 不存在；`(f⁻¹ ∘ g)(x) = (x²+3)/3`。

## 易错点提醒

1. **忘记检查「全域性」**。错：`f(x) = 1/x` 就说是 R 上的函数。正确：`x = 0` 无定义，`dom f = R − {0} ≠ R`，**不是 R → R 的函数**（是偏函数）。
2. **忘记检查「单值性」**。错：`x² + y² = 1` 也当成函数。正确：一个 x 可能对应两个 y，**违反单值性**。
3. **判定单射/满射时忽略定义域和陪域**。错：`f(x) = x²` 「不是单射也不是满射」。正确：`f: [0,+∞) → [0,+∞)`，`f(x) = x²` **是双射**。结论取决于定义域和陪域。
4. **把「满射」的陪域当成值域**。错：说 `f(x) = e^x` 是 R → R 的满射。正确：值域 `(0,+∞) ⊊ R`，**不满射**。
5. **以为「有限集的单射⟺满射」对无限集也成立**。错：`f: N → N`，`f(n) = n+1` 是单射所以满射。正确：**不是满射**（0 无原像）。这个等价性**只对有限集**成立。
6. **复合顺序搞反**。错：把 `(g ∘ f)(x)` 算成 `f(g(x))`。正确：`(g ∘ f)(x) = g(f(x))`——**先算右边的 f**。
7. **复合的传递方向记反**。错：以为「`g∘f` 单射 ⟹ g 单射」。正确：**`g∘f` 单射 ⟹ f 单射**；**`g∘f` 满射 ⟹ g 满射**。口诀：**单射往前传，满射往后传**。
8. **不验证前提就求反函数**。错：对 `f(x) = x²` 求「反函数」`f⁻¹(y) = ±√y`。正确：非单射函数**没有反函数**（多值不是函数）。
9. **把 `f⁻¹(B')` 当成反函数**。错：看到 `f⁻¹` 就以为 f 必须是双射。正确：**完全原像 `f⁻¹(B')` 对任何函数都有定义**，与反函数无关。
10. **认为「稠密 ⟹ 不可数」**。错：有理数处处稠密，所以 Q 不可数。正确：**Q 是可数集**（`|Q| = ℵ₀`）。稠密性（拓扑）与基数（集合论）是两回事。
11. **混淆 `c` 和 `ℵ₀`**。错：写 `|R| = ℵ₀`。正确：`|N| = ℵ₀`，`|R| = c = 2^{ℵ₀} > ℵ₀`。
12. **以为存在「最大的基数」**。错：`P(R)` 大概是最大的。正确：**由康托尔定理，`|A| < |P(A)|` 永远成立**，基数序列无限上升。
13. **`(g∘f)⁻¹` 写成 `g⁻¹ ∘ f⁻¹`**。错：顺序不变。正确：`(g∘f)⁻¹ = f⁻¹ ∘ g⁻¹`——**顺序颠倒**（同关系复合取逆的规则）。
14. **康托尔定理证明中忘记说明 `D ∈ P(A)`**。错：直接问「a ∈ D 吗」。正确：必须先说明 `D ⊆ A` 故 `D ∈ P(A)`，才能用 g 的满射性找到原像 a。这个「多一步」是证明的关键。

## 本章小结

1. **函数 = 满足单值性 + 全域性的关系**；`|A| = m, |B| = n` 时从 A 到 B 的函数有 `n^m` 个。
2. 函数三要素：**定义域 dom f = A**、**陪域 B**、**值域 `ran f ⊆ B`**。
3. **像对「并」可分配，对「交」只单向包含**；**完全原像对并、交、差都可分配**。
4. **单射**（不同的 x 给不同的 y）、**满射**（`ran f = B`）、**双射**（单射+满射 = 一一对应）。
5. **有限集上：单射 ⟺ 满射 ⟺ 双射（当 `|A| = |B|`）**；无限集上不成立。
6. 证明单射：由 `f(x₁)=f(x₂)` 推 `x₁=x₂`。证明满射：对任意 y 解出 x 并**验证 x 在定义域内**。
7. **复合**：`(g∘f)(x) = g(f(x))`，不满足交换律；**单射往前传，满射往后传**。
8. **反函数存在 ⟺ f 是双射**；`(g∘f)⁻¹ = f⁻¹ ∘ g⁻¹`。
9. **等势（对等）= 存在双射**；`ℵ₀` 是最小无限基数；**N、Z、Q、N×N 都可数**。
10. **R 不可数**（对角线论证）；**康托尔定理 `|A| < |P(A)|`** —— 不存在最大基数。

> **一句话记住本章**：**函数是「一台单值且到处有定义的机器」；单射是「不撞车」、满射是「全覆盖」、双射是「一人一座」；而基数是把「数数」推广到无穷——能排队数出来的都可数（连有理数都是），对角线法能造出一个「谁也抓不到」的新实数，所以 R 不可数。**
