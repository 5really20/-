## 13.1 二元运算及其性质

### 13.1.1 代数系统

**定义 13.1（代数系统）**：设 `S` 是非空集合，`f₁, f₂, …, fₖ` 是 S 上的运算（可以是二元或一元运算）。称
`<S, f₁, f₂, …, fₖ>`
为一个**代数系统（Algebraic System）**，也称**代数结构**。

> **直观理解**：代数系统 = **一个集合 + 若干在这个集合上「封闭」的运算**。
> **常见例子**：`<Z, +>`、`<Z, +, ×>`、`<R − {0}, ×>`、`<P(A), ∪, ∩, ～>`、`<Zₙ, +ₙ>`。

**定义 13.2（二元运算）**：设 `S` 是非空集合。函数
`f: S × S → S`
称为 S 上的**二元运算（Binary Operation）**。

**关键要求（封闭性）**：对任意 `a, b ∈ S`，必须有 **`f(a, b) ∈ S`**。

**例（判断是否为二元运算）**：

| 集合 S | 运算 f | 是否是 S 上的二元运算 | 原因 |
|---|---|---|---|
| `Z` | 加法 | ✔ 是 | 整数之和仍是整数 |
| `Z` | 除法 | ✘ 否 | `1/2 ∉ Z`（不封闭） |
| `Z⁺` | 减法 | ✘ 否 | `2 − 5 = −3 ∉ Z⁺` |
| `N` | 减法 | ✘ 否 | 同上 |
| `Z − {0}` | 乘法 | ✔ 是 | 非零整数之积非零 |
| `R` | 除法 | ✘ 否 | 除以 0 无定义（**且 0 ∈ R**） |
| `R − {0}` | 除法 | ✔ 是 | 非零实数之商非零 |
| `Mₙ(R)`（n阶实矩阵） | 矩阵乘法 | ✔ 是 | 方阵乘积仍是 n 阶方阵 |
| `P(A)` | 对称差 ⊕ | ✔ 是 | 子集的对称差仍是子集 |
| `Z⁺` | `f(a,b) = a^b` | ✔ 是 | 正整数幂仍是正整数 |
| `Z` | `f(a,b) = a^b` | ✘ 否 | `2^(−1) = 1/2 ∉ Z` |

**运算表（Cayley 表）**：有限集合上的二元运算可以用表格完全描述。
**例**：`S = {a, b}`，运算 `*` 定义为

| `*` | a | b |
|---|---|---|
| **a** | a | b |
| **b** | b | a |

（读法：第 a 行第 b 列的元素是 `a * b`。）

### 13.1.2 运算的性质

设 `*` 是 S 上的二元运算。

| 性质 | 定义 | 说明 |
|---|---|---|
| **交换律** | `a * b = b * a` 对一切 a, b | 运算表**关于主对角线对称** |
| **结合律** | `(a * b) * c = a * (b * c)` 对一切 a, b, c | 可以省略括号 |
| **幂等律** | `a * a = a` 对一切 a | 每个元素都是幂等元 |
| **分配律** | `a * (b ∘ c) = (a * b) ∘ (a * c)`（左分配）；右分配类似 | 需要**两个**运算 |
| **吸收律** | `a * (a ∘ b) = a` 且 `a ∘ (a * b) = a` | 需要**两个**运算，成对出现 |

**例（常见运算的性质表）**：

| 代数系统 | 交换 | 结合 | 幂等 | 有单位元 | 有零元 |
|---|---|---|---|---|---|
| `<Z, +>` | ✔ | ✔ | ✘（`1+1≠1`） | ✔（0） | ✘ |
| `<Z, ×>` | ✔ | ✔ | 仅 0,1 | ✔（1） | ✔（0） |
| `<Z, −>` | ✘ | ✘ | ✘ | ✘ | ✘ |
| `<P(A), ∪>` | ✔ | ✔ | ✔ | ✔（`∅`） | ✔（A） |
| `<P(A), ∩>` | ✔ | ✔ | ✔ | ✔（A） | ✔（`∅`） |
| `<Mₙ(R), ×>` | ✘（n≥2） | ✔ | ✘ | ✔（E） | ✔（零矩阵 O） |
| `<R − {0}, ×>` | ✔ | ✔ | 仅 1, −1 | ✔（1） | ✘ |
| `<Zₙ, +ₙ>` | ✔ | ✔ | ✘ | ✔（`[0]`） | ✘ |

> **关于矩阵乘法的零元**：零元 θ 的判据是 **`a * θ = θ * a = θ` 对一切 a 成立**。
> 矩阵乘法中 `A × O = O × A = O` 对一切 A 成立 ✓，故**零矩阵 O 确实是零元**。
> 但要注意：**零元没有逆元**（若 `O` 有逆元则 `O × O⁻¹ = E`，但左边是 O，矛盾），所以 `<Mₙ(R), ×>` 只能到独异点，**不是群** ✓

### 13.1.3 ★ 特殊元素

**定义 13.3（单位元 / 幺元）**：设 `*` 是 S 上的二元运算。若存在 `e ∈ S` 使
`e * a = a * e = a` 对**一切** `a ∈ S`
则称 e 为 S 关于 `*` 的**单位元（Identity Element / 幺元）**。

**定理 13.1（单位元唯一）**：若 S 关于 `*` 有单位元，则**单位元唯一**。
**证明**：设 `e₁, e₂` 都是单位元。
`e₁ = e₁ * e₂`（因 `e₂` 是单位元，`e₁ * e₂ = e₁`）
`= e₂`（因 `e₁` 是单位元，`e₁ * e₂ = e₂`）
故 `e₁ = e₂` ✓ ∎

**定义 13.4（零元）**：若存在 `θ ∈ S` 使
`θ * a = a * θ = θ` 对**一切** `a ∈ S`
则称 θ 为 S 关于 `*` 的**零元（Zero Element）**。（**零元也唯一**，证明同理。）

**定义 13.5（逆元）**：设 `*` 有单位元 `e`，`a ∈ S`。若存在 `b ∈ S` 使
`a * b = b * a = e`
则称 a **可逆**，b 是 a 的**逆元（Inverse Element）**，记作 `a⁻¹`。

**定理 13.2（逆元唯一）**：若 `*` **满足结合律**且 a 可逆，则 a 的逆元**唯一**。
**证明**：设 `b, c` 都是 a 的逆元。
`b = b * e = b * (a * c) = (b * a) * c`（**用结合律！**）` = e * c = c`
故 `b = c` ✓ ∎

> **为什么需要结合律**：上面的证明关键步骤 `b * (a * c) = (b * a) * c` 正是结合律。**在非结合的运算中，逆元可以不唯一**。

**★ 求特殊元素的方法（运算表）**：
- **单位元**：找**行与列都与表头相同**的那个元素（即 e 所在的行抄一遍表头，所在的列也抄一遍表头）。
- **零元**：找**行与列都全是它自己**的那个元素。
- **逆元**：在 a 所在的行找 e，那一列的表头就是 `a⁻¹`。

**★ 例**：设 `S = {a, b, c, d}`，运算表如下：

| `*` | a | b | c | d |
|---|---|---|---|---|
| **a** | a | b | c | d |
| **b** | b | a | d | c |
| **c** | c | d | a | b |
| **d** | d | c | b | a |

求单位元、零元、各元素的逆元。
**解**：
- **单位元**：a 所在的行是 `a b c d`（与表头一致），a 所在的列也是 `a b c d`（与表头一致）。故 **`e = a`** ✓
- **零元**：检查每行每列是否全为同一个元素。a 行不全为 a，b 行不全为 b…故**无零元** ✓
- **逆元**（在每行找 a，看对应列头）：
  - a 行第 1 列是 a → `a⁻¹ = a` ✓
  - b 行第 2 列是 a → `b⁻¹ = b` ✓
  - c 行第 3 列是 a → `c⁻¹ = c` ✓
  - d 行第 4 列是 a → `d⁻¹ = d` ✓

**这个运算就是 Klein 四元群** `V₄`（每个元素都是自己的逆元）。

**★ 逆元的性质**（当 `*` 满足结合律、有单位元 e 时）：
1. `(a⁻¹)⁻¹ = a`
2. `(a * b)⁻¹ = b⁻¹ * a⁻¹`（**注意顺序颠倒！**「穿袜子-穿鞋」原则）

## 13.2 半群与独异点

**定义 13.6（半群）**：设 `*` 是 S 上的二元运算。若 `*` **满足结合律**，则称 `<S, *>` 为**半群（Semigroup）**。

**定义 13.7（独异点 / 幺半群）**：若 `<S, *>` 是半群，且 **S 中有单位元**，则称它为**独异点（Monoid）**。

**定义 13.8**：若半群（独异点）中的运算**还可交换**，则称为**可交换半群（可交换独异点）**。

**层次关系**：
```
      代数系统
         │  + 结合律
         ▼
       半群
         │  + 单位元
         ▼
      独异点
         │  + 每个元素可逆
         ▼
        群
         │  + 交换律
         ▼
      交换群（Abel 群）
```

**例（分类表）**：

| 代数系统 | 半群？ | 独异点？ | 群？ | 说明 |
|---|---|---|---|---|
| `<Z⁺, +>` | ✔ | ✘ | ✘ | 无单位元（0 ∉ Z⁺） |
| `<N, +>` | ✔ | ✔（0） | ✘ | 只有 0 有逆元 |
| `<Z, +>` | ✔ | ✔（0） | ✔ | 交换群 |
| `<Z, ×>` | ✔ | ✔（1） | ✘ | 只有 ±1 可逆 |
| `<R − {0}, ×>` | ✔ | ✔（1） | ✔ | 交换群 |
| `<P(A), ∪>` | ✔ | ✔（`∅`） | ✘ | 只有 `∅` 可逆（`A ∪ A = A ≠ ∅`） |
| `<P(A), ⊕>` | ✔ | ✔（`∅`） | ✔ | 每个子集是自己的逆元 → **交换群** |
| `<Mₙ(R), ×>` | ✔ | ✔（E） | ✘ | 奇异矩阵不可逆 |
| `<Zₙ, +ₙ>` | ✔ | ✔（`[0]`） | ✔ | **n 阶循环群** |
| `<Zₙ, ×ₙ>` | ✔ | ✔（`[1]`） | ✘ | 只有与 n 互素的元素可逆 |

**有限独异点的性质**：在**同一个单位元** `e` 存在的前提下（即**独异点**中），若 `a` 既有左逆 `b`（`b*a = e`）又有右逆 `c`（`a*c = e`），则 `b = c`，且这个共同的元素就是 `a` 的**唯一逆元**。
> **⚠ 注意前提是「独异点」而不是「半群」**：半群里根本没有单位元，「左逆/右逆」无从谈起。加了这个前提后，**连有限性都不需要**（证明见下）。
> **证明**：`b = b * e = b * (a * c) = (b * a) * c = e * c = c` ✓（只用到结合律和单位元的性质）

## 13.3 群 ★★

### 13.3.1 群的定义与判定

**定义 13.9（群）**：设 `G` 是非空集合，`*` 是 G 上的二元运算。若满足
1. **封闭性**：`a * b ∈ G`；
2. **结合律**：`(a*b)*c = a*(b*c)`；
3. **有单位元**：存在 `e ∈ G` 使 `e*a = a*e = a`；
4. **有逆元**：对每个 `a ∈ G`，存在 `a⁻¹ ∈ G` 使 `a*a⁻¹ = a⁻¹*a = e`，

则称 `<G, *>` 为**群（Group）**。

若群中的运算**还满足交换律**，则称为**交换群**或 **Abel 群（阿贝尔群）**。

**群的阶**：群 G 中元素的个数 `|G|` 称为群的**阶（Order）**。`|G|` 有限时称**有限群**，否则称**无限群**。

**★ 判断一个代数系统是否为群（五步检查）**：
```
第 1 步：集合是否非空？
第 2 步：运算是否封闭？
第 3 步：是否满足结合律？
第 4 步：是否有单位元？
第 5 步：每个元素是否都有逆元？
（若还要判断 Abel 群，第 6 步：是否满足交换律？）
```

**★ 例（典型群）**：

| 群 | 运算 | 单位元 | a 的逆元 | 阶 | Abel？ |
|---|---|---|---|---|---|
| `<Z, +>` | 加法 | 0 | `−a` | 无限 | ✔ |
| `<Q, +>`、`<R, +>`、`<C, +>` | 加法 | 0 | `−a` | 无限 | ✔ |
| `<Q−{0}, ×>`、`<R−{0}, ×>` | 乘法 | 1 | `1/a` | 无限 | ✔ |
| `<Zₙ, +ₙ>` | 模 n 加法 | `[0]` | `[−a] = [n−a]` | n | ✔ |
| **`<Zₙ*, ×ₙ>`** | 模 n 乘法 | `[1]` | 扩展欧几里得 | `φ(n)` | ✔ |
| `<Mₙ(R), +>` | 矩阵加法 | 零矩阵 | `−A` | 无限 | ✔ |
| **`<GLₙ(R), ×>`**（可逆矩阵） | 矩阵乘法 | E | `A⁻¹` | 无限 | ✘（n≥2） |
| `<P(A), ⊕>` | 对称差 | `∅` | A 自己 | `2^\|A\|` | ✔ |
| `<Sₙ, ∘>`（n 元置换群） | 置换复合 | 恒等置换 | 逆置换 | `n!` | ✘（n≥3） |

> **`<Zₙ*, ×ₙ>` 的阶是 `φ(n)`，不是 n**！因为只有与 n 互素的元素才有逆元。
> **例**：`Z₆* = {[1], [5]}`（只有 1 和 5 与 6 互素），`|Z₆*| = φ(6) = 2` ✓

### 13.3.2 群的基本性质

**定理 13.3（群的基本性质）**：设 `<G, *>` 是群，则
1. **单位元唯一**；每个元素的**逆元唯一**。
2. **消去律成立**：若 `a * b = a * c`，则 `b = c`（左消去）；若 `b * a = c * a`，则 `b = c`（右消去）。
3. **方程有唯一解**：对任意 `a, b ∈ G`，方程 `a * x = b` 有**唯一解** `x = a⁻¹ * b`；`y * a = b` 有唯一解 `y = b * a⁻¹`。
4. **无零元**（除非 `|G| = 1`）。
5. `(a⁻¹)⁻¹ = a`；`(a * b)⁻¹ = b⁻¹ * a⁻¹`。
6. **幂运算规则**：`a^m * a^n = a^(m+n)`，`(a^m)^n = a^(mn)`（`m, n ∈ Z`，约定 `a⁰ = e`，`a^(−n) = (a⁻¹)ⁿ`）。

**证明消去律**：设 `a * b = a * c`。两边**左乘 `a⁻¹`**：
`a⁻¹ * (a * b) = a⁻¹ * (a * c)`
由结合律：`(a⁻¹ * a) * b = (a⁻¹ * a) * c`
即 `e * b = e * c`，故 `b = c` ✓ ∎

**证明性质 3（方程唯一解）**：
**存在性**：取 `x = a⁻¹ * b`，则 `a * (a⁻¹ * b) = (a * a⁻¹) * b = e * b = b` ✓
**唯一性**：设 `x₁, x₂` 都是解，则 `a * x₁ = b = a * x₂`，由消去律 `x₁ = x₂` ✓ ∎

**证明性质 4（群无零元）**：设 θ 是 G 中的零元，即对一切 `a ∈ G` 有 `a * θ = θ * a = θ`。
θ 作为群中元素也有逆元，于是
`θ = θ * e = θ * (θ * θ⁻¹) = (θ * θ) * θ⁻¹ = θ * θ⁻¹ = e`。
（逐步理由：第 2 个等号用 `e = θ * θ⁻¹`；第 3 个等号用**结合律**；第 4 个等号用零元性质 `θ * θ = θ`；最后一步用逆元定义。）
故 `θ = e`。但若零元就是单位元，则对一切 a 有 `a = a * e = a * θ = θ = e`，即 G 中只有 e 一个元素，`|G| = 1` ✓ ∎
**结论**：只有平凡群 `{e}` 才可能含零元；**任何 `|G| ≥ 2` 的群都没有零元**。

**★ 例**：在群中解方程 `a * x * b = c`。
**解**：两边左乘 `a⁻¹`：`x * b = a⁻¹ * c`。
两边右乘 `b⁻¹`：`x = a⁻¹ * c * b⁻¹` ✓
（**注意顺序不能颠倒**！因为群不一定交换。）

### 13.3.3 子群

**定义 13.10（子群）**：设 `<G, *>` 是群，`H` 是 G 的**非空子集**。若 `<H, *>` 本身也是一个群（即 H 在 `*` 下封闭、有单位元、有逆元），则称 H 为 G 的**子群（Subgroup）**，记作 `H ≤ G`。

**平凡子群**：`{e}`（单位元子群）和 G 本身，称为 G 的**平凡子群**。

**★ 定理 13.4（子群判定定理一）**：设 H 是群 G 的非空子集，则
`H ≤ G ⟺ 对任意 a, b ∈ H 有 a * b⁻¹ ∈ H`

**证明**：
**（⟹）** 若 H 是子群，则 `b ∈ H ⟹ b⁻¹ ∈ H`（子群中每个元素有逆元），且 H 封闭，故 `a * b⁻¹ ∈ H` ✓
**（⟸）** 设条件成立。
- **单位元**：取 `a = b ∈ H`（H 非空），则 `a * a⁻¹ = e ∈ H` ✓
- **逆元**：取 `a = e`，则 `e * b⁻¹ = b⁻¹ ∈ H` ✓
- **封闭**：取 `a, b ∈ H`，则 `b⁻¹ ∈ H`（刚证），故 `a * (b⁻¹)⁻¹ = a * b ∈ H` ✓
- **结合律**：继承自 G ✓

故 H 是群，即 `H ≤ G` ✓ ∎

**★ 定理 13.5（子群判定定理二 —— 有限子群）**：设 H 是**有限群** G 的非空子集，则
`H ≤ G ⟺ H 对 * 封闭`

**证明**：只需证「封闭 ⟹ 每个元素有逆元」。
设 `a ∈ H`。考虑序列 `a, a², a³, …`。由封闭性，它们都在 H 中。
因 H **有限**，必有重复：存在 `i < j` 使 `aⁱ = a^j`。
两边乘 `a^(−i)` 得 `a^(j−i) = e`，故 `e ∈ H`（取适当的幂使得 e 在 H 中，因 `a^(j−i) ∈ H` ✓）。
且 `a^(j−i−1) = a⁻¹ ∈ H` ✓（若 `j−i−1 = 0` 则 `a = e`，逆元是自己 ✓）
故 H 是子群 ✓ ∎

**★ 子群的例子**：
- `<Z, +>` 中，`nZ = {nk | k ∈ Z}`（n 的倍数集）是子群 ✓（`{0}, Z, 2Z, 3Z, …`）
- `<Z₆, +₆>` 的子群：`{[0]}`、`{[0],[3]}`、`{[0],[2],[4]}`、`Z₆` 本身 ✓
  （**拉格朗日定理的验证**：1, 2, 3, 6 都是 6 的因数 ✓）
- 群 G 的中心 `Z(G) = {a ∈ G | 对一切 x ∈ G, ax = xa}` 是子群 ✓
- `<Sₙ, ∘>` 中，全体偶置换（`Aₙ`，交错群）是子群，`|Aₙ| = n!/2` ✓

### 13.3.4 循环群

**定义 13.11（元素的阶）**：设 `a ∈ G`。使 `a^k = e` 成立的**最小正整数** k 称为 a 的**阶（Order）**，记作 `|a|` 或 `ord(a)`。若不存在这样的 k，则称 a 的阶为**无限**。

**定义 13.12（循环群）**：若群 G 中存在元素 `a` 使
`G = <a> = {a^k | k ∈ Z}`
则称 G 为**循环群（Cyclic Group）**，a 称为 G 的**生成元（Generator）**。

**★ 定理 13.6（循环群的结构 —— 完全分类）**：
设 `G = <a>` 是循环群。
1. 若 a 的阶为**无限**，则 `G ≅ <Z, +>`（与整数加法群同构）。
2. 若 a 的阶为 **n**，则 `G ≅ <Zₙ, +ₙ>`（与模 n 加法群同构），且 `G = {e, a, a², …, a^(n−1)}`。

**推论**：**循环群一定是 Abel 群**（因 `a^m * a^n = a^(m+n) = a^n * a^m`）✓

**★ 定理 13.7（生成元的判定）**：设 `G = <a>` 是 n 阶循环群，则
`a^k` 是 G 的生成元 ⟺ `gcd(k, n) = 1`

**证明思路**：`<a^k> = <a^d>` 其中 `d = gcd(k, n)`（因 `a^k` 生成的子群元素都是 `a` 的 `k` 的倍数次幂，而 `k` 的所有倍数与 `n` 的倍数的集合由 d 生成）。
故 `<a^k> = G ⟺ d = 1` ✓ ∎

**★ 例**：`Z₈ = {0,1,2,3,4,5,6,7}`（模 8 加法）。
- 生成元需满足 `gcd(k, 8) = 1`，即 `k = 1, 3, 5, 7` ✓
- 故 `Z₈` 有 **4 个**生成元：`1, 3, 5, 7` ✓
- **一般结论**：n 阶循环群恰有 **`φ(n)`** 个生成元 ✓

**元素的阶的计算**：在 n 阶循环群 `G = <a>` 中，`|a^k| = n / gcd(k, n)` ✓
**例**：`Z₁₂` 中 `|4| = 12/gcd(4,12) = 12/4 = 3` ✓（验证：`4 + 4 + 4 = 12 ≡ 0` ✓）

### 13.3.5 置换群

**定义 13.13（置换）**：有限集合 `S = {1, 2, …, n}` 上的**双射函数** `σ: S → S` 称为 S 上的一个 **n 元置换（Permutation）**。

**记号（双行记号）**：
`σ = ( 1    2    …   n  )`
`    ( σ(1) σ(2) … σ(n) )`

**定义 13.14（置换群）**：S 上**全体置换**的集合 `Sₙ` 在**置换的复合运算**下构成一个群，称为 **n 次对称群（Symmetric Group）**，`|Sₙ| = n!`。
`Sₙ` 的任意子群都称为**置换群**。

**★ 定理 13.8（凯莱定理 / Cayley's Theorem）**：**任何群都同构于某个置换群。**
即：每个抽象群都可以「实现为」一组置换。

**为什么重要**：凯莱定理说明**置换群是所有群的「通用模型」**——研究群论时可以把任意群当作置换群来分析。（证明思路：对每个 `a ∈ G` 定义置换 `π_a: x ↦ a*x`，则 `a ↦ π_a` 是同构。）

**例（S₃ 置换群）**：`S₃` 有 `3! = 6` 个元素：
`e = (1)(2)(3)`（恒等）
`(12), (13), (23)`（对换）
`(123), (132)`（3-循环）

`S₃` 是**最小的非交换群**（`|S₃| = 6`）。**验证非交换**：
`(12) ∘ (13) ≠ (13) ∘ (12)` ✓

**置换的循环表示法**：`σ = (1 2 3)` 表示 `1→2, 2→3, 3→1`。
**每个置换都可唯一分解为不相交循环的乘积** ✓

## 13.4 陪集与拉格朗日定理 ★

### 13.4.1 陪集

**定义 13.15（左陪集 / 右陪集）**：设 `H ≤ G`，`a ∈ G`。称
`aH = {a * h | h ∈ H}`
为 H 在 G 中的**左陪集（Left Coset）**，a 称为**代表元**。
类似地 `Ha = {h * a | h ∈ H}` 称为**右陪集**。

**★ 陪集的基本性质**：
1. `a ∈ aH`（因 `a = a * e`，`e ∈ H`）✓
2. **`aH = H ⟺ a ∈ H`** ✓
3. **`aH = bH ⟺ a⁻¹b ∈ H`**（或 `b ∈ aH`）✓
4. **两个左陪集要么完全相同，要么不相交**：`aH ∩ bH = ∅` 或 `aH = bH` ✓
5. **`|aH| = |H|`**（由消去律，`h ↦ ah` 是双射）✓ **所有陪集大小相同！**

> **直观理解**：陪集就是把群 G 按子群 H「**平移**」得到的块。这些块**大小相同、互不重叠、铺满整个 G**——就像用同一块瓷砖铺满地面。

**★ 例**：`G = <Z, +>`，`H = 3Z = {…, −6, −3, 0, 3, 6, …}`。
- `0 + H = H = {…, −3, 0, 3, 6, …}`
- `1 + H = {…, −2, 1, 4, 7, …}`
- `2 + H = {…, −1, 2, 5, 8, …}`

这三个陪集**互不相交且并为全体整数**——正是模 3 的三个同余类 ✓

**★ 例**：`G = Z₆ = {0,1,2,3,4,5}`，`H = {0, 3}`（子群，`|H| = 2`）。
- `0 + H = {0, 3}`
- `1 + H = {1, 4}`
- `2 + H = {2, 5}`
- `3 + H = {3, 0} = 0 + H` ✓（回到第一个）

共有 `6/2 = 3` 个不同的陪集 ✓

### 13.4.2 ★ 拉格朗日定理

**定理 13.9（拉格朗日定理 / Lagrange's Theorem）**：设 G 是**有限群**，`H ≤ G`，则
**`|H|` 整除 `|G|`**，且
**`|G| = |H| · [G : H]`**
其中 `[G : H]` 是 H 在 G 中的**不同左陪集的个数**，称为**指数（Index）**。

**证明**：
（1）**所有的左陪集构成 G 的一个划分**。
因为每个 `a ∈ G` 属于陪集 `aH`，故所有左陪集之并是 G。
又由性质 4，任意两个左陪集要么相同要么不交。故它们是 G 的一个划分 ✓
（2）**每个左陪集的大小都等于 `|H|`**（性质 5）✓
（3）设不同左陪集有 `r = [G:H]` 个，则
`|G| = |a₁H| + |a₂H| + … + |aᵣH| = r · |H|` ✓
故 `|H|` 整除 `|G|` ✓ ∎

> **这是群论中最基本、最有用的定理**！它把「群的大小」和「子群的大小」用**整除关系**联系起来。

**★ 推论 13.1**：设 G 是有限群，`|G| = n`，`a ∈ G`，则 **`a` 的阶整除 n**，且 **`a^n = e`**。
**证明**：设 `|a| = k`，则 `<a> = {e, a, …, a^(k−1)}` 是 G 的 k 阶子群。
由拉格朗日定理 `k | n`。设 `n = km`，则 `a^n = a^(km) = (a^k)^m = e^m = e` ✓ ∎

**★ 推论 13.2（素数阶群必为循环群）**：若 `|G| = p`（p 是素数），则 G 是**循环群**，且 G 的**任何非单位元都是生成元**。
**证明**：取 `a ≠ e`。`<a>` 的阶整除 p。因 `|<a>| ≥ 2`（含 e 和 a）且 `|<a>| | p`，而 p 是素数，故 `|<a>| = p`，即 `<a> = G` ✓ ∎

**★ 推论 13.3（费马小定理的群论证明）**：
取 `G = Zₚ* = {[1], …, [p−1]}`（模 p 乘法群，阶为 `p−1`）。
任取 `[a] ∈ Zₚ*`（即 `p ∤ a`），由推论 13.1：`[a]^(p−1) = [1]`，即
`a^(p−1) ≡ 1 (mod p)` ✓
**这正是费马小定理**（见第 11 章）——**用群论给出了一个更深刻的解释**！

**★ 推论 13.4（欧拉定理的群论证明）**：
取 `G = Zₘ*`（阶为 `φ(m)`）。若 `gcd(a, m) = 1`，则 `[a] ∈ Zₘ*`，
由推论 13.1：`a^(φ(m)) ≡ 1 (mod m)` ✓

> **漂亮的统一**：费马小定理和欧拉定理都是**拉格朗日定理的直接推论**！这体现了抽象代数的威力——**看似无关的数论结论，在群论框架下是同一个定理**。

## 13.5 同态与同构

**定义 13.16（同态）**：设 `<G, *>` 和 `<H, ∘>` 是两个代数系统。函数 `f: G → H` 若满足
`f(a * b) = f(a) ∘ f(b)` 对一切 `a, b ∈ G`
则称 f 为从 G 到 H 的**同态映射（Homomorphism）**。

**定义 13.17（同构）**：若同态 f 还是**双射**，则称 f 为**同构映射（Isomorphism）**，称 G 与 H **同构（Isomorphic）**，记作 `G ≅ H`。

> **直观理解**：
> **同态** = 「**保持运算结构的映射**」——G 中的运算在 H 中有对应。
> **同构** = 「**结构完全相同**」——两个代数系统只是元素「换了名字」，本质一样。

**★ 同态的基本性质**：
1. 若 e 是 G 的单位元，则 `f(e)` 是 `f(G)` 的单位元 ✓
2. `f(a⁻¹) = f(a)⁻¹` ✓
3. `f(aⁿ) = f(a)ⁿ` ✓
4. `f(G) = {f(a) | a ∈ G}` 是 H 的子代数系统（同态像）✓

**★ 例**：
- `f: <Z, +> → <Zₙ, +ₙ>`，`f(k) = [k]`（取模）是**满同态**（不是单射）✓
  **验证**：`f(a + b) = [a+b] = [a] +ₙ [b] = f(a) +ₙ f(b)` ✓
- `f: <R, +> → <R⁺, ×>`，`f(x) = eˣ` 是**同构** ✓
  **验证**：`f(a+b) = e^(a+b) = e^a · e^b = f(a)·f(b)` ✓（指数函数把加法变成乘法！）
- `f: <Z, +> → <Z, +>`，`f(k) = 2k` 是**单同态**（不是满射）✓
- `f: <GLₙ(R), ×> → <R−{0}, ×>`，`f(A) = det(A)` 是**满同态** ✓
  **验证**：`det(AB) = det(A)det(B)` ✓

**定理 13.10（同构的基本性质）**：同构关系是**等价关系**（自反、对称、传递）✓
**例**：`<Z₄, +₄> ≅ <{1, i, −1, −i}, ×>`（复数单位根群）✓
**验证**：映射 `[0]↦1, [1]↦i, [2]↦−1, [3]↦−i`，且 `i² = −1` 与 `[1]+₄[1] = [2]` 对应 ✓

**★ 判断两个群是否同构的必要条件**（都用「不同构」的判定）：
1. **阶相同**（`|G| = |H|`）
2. **交换性相同**（一个交换另一个不交换 ⟹ 不同构）
3. **元素的阶分布相同**（G 中 k 阶元素个数 = H 中 k 阶元素个数）
4. **子群结构相同**（子群的个数与阶相同）

**★ 例（判断不同构）**：`<Z₄, +₄>` 与 Klein 四元群 `V₄ = {e,a,b,c}`（`a²=b²=c²=e`）是否同构？
**解**：`|Z₄| = |V₄| = 4` ✓。
但 `Z₄` 有 **2 个 4 阶元素**（`[1], [3]`）和 **1 个 2 阶元素**（`[2]`）；
`V₄` 有 **0 个 4 阶元素**和 **3 个 2 阶元素**。
**元素的阶分布不同**，故 **`Z₄ ≇ V₄`** ✓
> **结论**：**4 阶群恰有两个：`Z₄` 和 `V₄`**（一个循环，一个不循环）✓

**★ 定理 13.11（凯莱定理）**：**任何群 G 都同构于某个置换群**（见 13.3.5）✓

## 13.6 环与域

### 13.6.1 环

**定义 13.18（环）**：设 `R` 是非空集合，`+` 和 `·` 是 R 上的两个二元运算。若满足
1. **`<R, +>` 是交换群**（加法交换群）；
2. **`<R, ·>` 是半群**（乘法结合律）；
3. **乘法对加法满足分配律**：`a·(b+c) = a·b + a·c`，`(b+c)·a = b·a + c·a`，

则称 `<R, +, ·>` 为**环（Ring）**。

**环中的术语**：
- 加法单位元记作 **0**（零元）；
- a 的加法逆元记作 **−a**；
- 若乘法**可交换**，称**交换环**；
- 若乘法**有单位元**，称**含幺环**（单位元记作 1）；
- 若存在 `a, b ≠ 0` 使 `a·b = 0`，则称 a 是**左零因子**。

**★ 环的基本性质**：
1. `a·0 = 0·a = 0`（注意：**左式的 0 是加法单位元**）
2. `(−a)·b = a·(−b) = −(a·b)`
3. `(−a)·(−b) = a·b`
4. **`a·(b − c) = a·b − a·c`**

**★ 典型环的例子**：

| 环 | 加法 | 乘法 | 交换？ | 含幺？ | 有零因子？ |
|---|---|---|---|---|---|
| `<Z, +, ×>` | 整数加法 | 整数乘法 | ✔ | ✔（1） | ✘ |
| `<Q, +, ×>`、`<R, +, ×>`、`<C, +, ×>` | 普通 | 普通 | ✔ | ✔ | ✘ |
| `<Zₙ, +ₙ, ×ₙ>` | 模 n 加 | 模 n 乘 | ✔ | ✔（[1]） | **n 合数时有** |
| `<Mₙ(R), +, ×>` | 矩阵加 | 矩阵乘 | ✘（n≥2） | ✔（E） | ✔（n≥2） |
| `<2Z, +, ×>`（偶数） | 加法 | 乘法 | ✔ | ✘（无单位元） | ✘ |
| `<P(A), ⊕, ∩>` | 对称差 | 交 | ✔ | ✔（A） | ✔ |

**★ 例（`Z₆` 有零因子）**：`[2] ×₆ [3] = [6] = [0]`，但 `[2] ≠ [0]` 且 `[3] ≠ [0]` ✓
故 `[2]` 和 `[3]` 都是**零因子** ✓
> **重要结论**：`Zₙ` 是**无零因子环** ⟺ **n 是素数** ✓

### 13.6.2 整环与域

**定义 13.19（整环）**：若环 `<R, +, ·>` 满足
1. 是**交换环**；
2. 是**含幺环**（`1 ≠ 0`）；
3. **无零因子**（即 `a·b = 0 ⟹ a = 0 或 b = 0`），

则称 R 为**整环（Integral Domain）**。

**定义 13.20（域）**：若环 `<F, +, ·>` 满足
1. **`<F, +>` 是交换群**；
2. **`<F − {0}, ·>` 是交换群**（即非零元素全体在乘法下构成交换群），

则称 F 为**域（Field）**。

**等价说法**：域 = **交换环 + 含幺 + `1 ≠ 0` + 每个非零元素都有乘法逆元**。

**层次关系**：
```
        环
        │  + 交换 + 含幺 + 无零因子
        ▼
      整环
        │  + 每个非零元素可逆
        ▼
       域
```

**★ 典型域的例子**：
- `<Q, +, ×>`、`<R, +, ×>`、`<C, +, ×>` 都是域 ✓
- **`<Zₚ, +ₚ, ×ₚ>` 是域 ⟺ p 是素数** ✓
  （`Zₚ` 中每个非零元素 `[a]` 都与 p 互素，故有逆元 ✓）
- **`<Z, +, ×>` 是整环但 NOT 域**（只有 ±1 可逆）✓

**★ 例（重要）**：
- `Z₆` 不是整环（有零因子），也不是域 ✓
- `Z₇` 是域（7 是素数）✓，且 `|Z₇*| = 6`
- `Z₈` 不是整环（`[2]×[4] = [0]`）✓
- `Z₉` 不是整环（`[3]×[3] = [0]`）✓

**★ 有限域（伽罗瓦域）**：有限域的元素个数必为 **`p^n`**（p 是素数，n 是正整数）✓
- `GF(p) = Zₚ`（p 元域）；
- `GF(p^n)` 当 `n ≥ 2` 时**不是** `Z_{p^n}`（例如 `GF(4) ≠ Z₄`，因 `Z₄` 有零因子 `[2]×[2] = [0]`）。

> **应用**：有限域 `GF(2⁸) = GF(256)` 是 **AES 加密算法**的基础；`GF(2)` 是**纠错码（汉明码、RS 码）**的基础。

## 典型例题

**例 13.1**（题型：判断二元运算的性质）
设 `S = {1, 2, 3, 6}`，S 上的运算 `*` 定义为 `a * b = gcd(a, b)`（最大公因数）。
(1) 验证 `*` 是 S 上的二元运算；
(2) 判断 `*` 是否满足交换律、结合律、幂等律；
(3) 求单位元和零元（若存在）。
**解**：
(1) `gcd(a,b)` 是 a 和 b 的正公因数，必整除 a。因 `a ∈ {1,2,3,6}`，故 `gcd(a,b) ∈ {1,2,3,6} = S` ✓ **封闭** ✓
(2) **交换律**：`gcd(a,b) = gcd(b,a)` ✓（gcd 的对称性）
**结合律**：`gcd(gcd(a,b), c) = gcd(a, gcd(b,c)) = gcd(a,b,c)` ✓（三者都是「所有公共素因子的最小幂次」，与结合方式无关）
**幂等律**：`a * a = gcd(a,a) = a` ✓
(3) **单位元**：需找 e 使 `gcd(e, a) = a` 对一切 a 成立。
`gcd(e,a) = a ⟺ a | e`。要对 `a = 1,2,3,6` 都成立，需要 `lcm(1,2,3,6) = 6 | e`。取 `e = 6` ✓
**验证**：`gcd(6,1) = 1 ✓`，`gcd(6,2) = 2 ✓`，`gcd(6,3) = 3 ✓`，`gcd(6,6) = 6 ✓`
**零元**：需找 θ 使 `gcd(θ, a) = θ` 对一切 a 成立。
`gcd(θ,a) = θ ⟺ θ | a`。要对 `a = 1,2,3,6` 都成立，需要 θ 整除 1，故 `θ = 1` ✓
**验证**：`gcd(1,1) = 1 ✓`，`gcd(1,2) = 1 ✓`，`gcd(1,3) = 1 ✓`，`gcd(1,6) = 1 ✓`
**答案**：(1) 是；(2) 三个性质都满足；(3) 单位元 6，零元 1。

**例 13.2**（题型：判断是否为群）
判断下列代数系统是否为群。若是，判断是否为 Abel 群。
(1) `<Z, −>`（整数减法）
(2) `<Q − {0}, ×>`（非零有理数乘法）
(3) `<Z₅*, ×₅>`（模 5 乘法，`Z₅* = {[1],[2],[3],[4]}`）
(4) `<Z₆*, ×₆>`（模 6 乘法）
(5) `<M₂(R), +>`（2 阶实矩阵加法）
**解**：
(1) **不是群**。虽然封闭（整数之差是整数），但**减法不满足结合律**：`(5−3)−1 = 1 ≠ 5−(3−1) = 3` ✗（也没有单位元）✓
(2) **是群**。
- 封闭：非零有理数之积非零 ✓
- 结合律：乘法结合律 ✓
- 单位元：`1 ∈ Q−{0}` ✓
- 逆元：`a⁻¹ = 1/a ∈ Q−{0}` ✓
**是 Abel 群**（乘法交换）✓
(3) **是群**。
- 封闭：验证 `[2]×₅[3] = [6] = [1] ∈ Z₅*` ✓，`[4]×₅[4] = [16] = [1] ✓`（`[16] mod 5 = 1`），`[2]×₅[4] = [8] = [3] ✓`
- 结合律：继承自整数乘法 ✓
- 单位元：`[1]` ✓
- 逆元：`[1]⁻¹ = [1]`，`[2]⁻¹ = [3]`（`[6] = [1]` ✓），`[3]⁻¹ = [2]`，`[4]⁻¹ = [4]`（`[16] = [1]` ✓）
**是 Abel 群**，阶为 4 ✓
（注：`Z₅*` 是 4 阶循环群，生成元为 `[2]` 或 `[3]`：`[2]¹=[2], [2]²=[4], [2]³=[3], [2]⁴=[1]` ✓）
(4) **是群**。关键是**别把 `Z₆*` 认错**：
`Z₆*` 只含与 6 **互素**的元素，故 `Z₆* = {[1], [5]}`（**不是** `{[1],[2],[3],[4],[5]}`！），`|Z₆*| = φ(6) = 2`。
- 封闭：`[5] ×₆ [5] = [25] = [1] ✓`（`25 − 24 = 1`），`[1] × [5] = [5] ✓`
- 单位元 `[1]` ✓；逆元：`[1]⁻¹ = [1]`，`[5]⁻¹ = [5]`（因 `[5]² = [1]`）✓

**是 2 阶 Abel 群** ✓
（**易错提醒**：`[2]、[3]、[4]` 与 6 不互素，**根本不在 `Z₆*` 里**。`[2]` 在 `Z₆` 中确实无逆元，但这不影响 `Z₆*` 是群。）
(5) **是群**。
- 封闭：同阶矩阵之和仍是 2 阶矩阵 ✓
- 结合律：矩阵加法结合 ✓
- 单位元：零矩阵 O ✓
- 逆元：`−A` ✓
**是 Abel 群**（矩阵加法交换）✓（**注意：若运算改为矩阵乘法，则不是群**——奇异矩阵无逆元。）

**例 13.3**（题型：子群判定）
设 `G = <Z₁₂, +₁₂>`。

检验封闭性（只需验证几个关键组合）：

- `[6] + [6] = [12] = [0] ✓`，`[6] + [9] = [15] = [3] ✓`
- `[9] + [9] = [18] = [6] ✓`

（`H` 是 4 阶子群，`4 | 12` ✓ 符合拉格朗日定理。）
(2) **由拉格朗日定理，子群的阶必须整除 12**，故可能的阶为 `1, 2, 3, 4, 6, 12`。

- 2 阶：需要 `[a]` 满足 `2a ≡ 0 (mod 12)`，即 `a = 6` → `H₂ = {[0], [6]}`

**例 13.4**（题型：循环群与生成元）

- `[3]³ = [3]²×[3] = [2]×[3] = [6]`
- `[3]⁴ = [6]×[3] = [18] = [4]`（`18 − 14 = 4`）
- `[3]⁵ = [4]×[3] = [12] = [5]`
- `[3]⁶ = [5]×[3] = [15] = [1]` ✓ 回到单位元

故 `<[3]> = Z₇*`，**`Z₇*` 是循环群**，`[3]` 是生成元 ✓
**所有生成元**：`[3]^k` 中 `gcd(k, 6) = 1`，即 `k = 1, 5`。
- `k=1`：`[3]¹ = [3]` ✓
- `k=5`：`[3]⁵ = [5]` ✓

**答案**：生成元为 **`[3]` 和 `[5]`**，共 `φ(6) = 2` 个 ✓

**例 13.5**（题型：陪集与拉格朗日定理）
设 `G = <Z₁₂, +₁₂>`，`H = {[0], [4], [8]}`。
(1) 求 H 在 G 中的所有不同左陪集；
(2) 验证拉格朗日定理；
(3) 求指数 `[G : H]`。
**解**：
(1) `|H| = 3`。逐一计算 `a + H`（`a ∈ Z₁₂`）：
- `[0] + H = {[0], [4], [8]}` = H
- `[1] + H = {[1], [5], [9]}`
- `[2] + H = {[2], [6], [10]}`
- `[3] + H = {[3], [7], [11]}`
- `[4] + H = {[4], [8], [0]}` = `[0] + H`（重复）
- `[5] + H = {[5], [9], [1]}` = `[1] + H`（重复）
- …（后续都重复）

**答案**：共有 **4 个**不同的左陪集：`{[0],[4],[8]}`、`{[1],[5],[9]}`、`{[2],[6],[10]}`、`{[3],[7],[11]}` ✓
(2) `|G| = 12`，`|H| = 3`，`[G:H] = 4`。
`|G| = 12 = 3 × 4 = |H| × [G:H]` ✓ **且 `3 | 12` ✓ 拉格朗日定理成立**
(3) **指数 `[G : H] = 4`** ✓
> **验证划分**：4 个陪集的并 = `{[0],…,[11]}` = G ✓，且两两不交 ✓，每个大小都是 3 ✓。**完美铺满！**

**例 13.6**（题型：同态与同构）
判断下列映射是否为同态。若是，判断是否为同构。
(1) `f: <Z, +> → <Z, +>`，`f(n) = 3n`；
(2) `f: <Z, +> → <Z₆, +₆>`，`f(n) = [n]`；
(3) `f: <R, +> → <R, +>`，`f(x) = x²`。
**解**：
(1) **是同态**。`f(a+b) = 3(a+b) = 3a + 3b = f(a) + f(b)` ✓
**不是同构**（不是满射：3 的倍数只是 Z 的一部分）✓
(2) **是同态**。`f(a+b) = [a+b] = [a] +₆ [b] = f(a) +₆ f(b)` ✓
**不是同构**（不是单射：`f(0) = f(6) = [0]`）✓ **是满同态**
(3) **不是同态**。`f(a+b) = (a+b)² = a² + 2ab + b²`，而 `f(a) + f(b) = a² + b²`。
`(a+b)² ≠ a² + b²`（除非 `ab = 0`）✗
**反例**：`f(1+1) = f(2) = 4`，但 `f(1) + f(1) = 1 + 1 = 2` ✗

**例 13.7**（题型：环与域的判定）
判断下列代数系统是环、整环还是域：
(1) `<Z₈, +₈, ×₈>`；
(2) `<Z₇, +₇, ×₇>`；
(3) `<2Z, +, ×>`（全体偶数）。
**解**：
(1) **是环**（交换、含幺）。**不是整环**：因 `[2] ×₈ [4] = [8] = [0]`，而 `[2] ≠ [0]`、`[4] ≠ [0]`，有**零因子** ✗
**不是域** ✗（有零因子必不是域）
(2) **是域**。因 `7` 是**素数** ✓
**验证**：`Z₇* = {[1],…,[6]}`，每个非零元素有逆元：
`[1]⁻¹=[1]`，`[2]⁻¹=[4]`（`[8]=[1]`），`[3]⁻¹=[5]`（`[15]=[1]`），`[6]⁻¹=[6]`（`[36]=[1]`）✓
（故 `Z₇` 是域，自然也是整环、环 ✓）
(3) **是环**（加法交换群 ✓，乘法结合 ✓，分配律 ✓）。
**不是整环**（**无单位元**：`1 ∉ 2Z`）。**不是域** ✗
> **注意**：`2Z` 是「**无幺交换环**」——说明**含幺不是环的必要条件**（但整环定义要求含幺）。

**例 13.8**（题型：综合证明 —— 拉格朗日定理的应用）
证明：**6 阶群必有 3 阶元素**（即存在 `a ∈ G` 使 `|a| = 3`）。
**证明**：
设 `|G| = 6`。由拉格朗日定理的推论 13.1，**每个元素的阶都整除 6**：
`|a| ∈ {1, 2, 3, 6}` ✓
设 n₁, n₂, n₃, n₆ 分别是 1、2、3、6 阶元素的个数。
- **1 阶元素**：只有单位元 e，故 `n₁ = 1` ✓
- **2 阶元素**：若 `|a| = 2`，则 `{e, a}` 是 2 阶子群。注意 **`a` 与 `a⁻¹ = a` 是同一个元素**；任意两个**不同的** 2 阶元素 `a, b`，它们生成的子群 `{e,a}` 与 `{e,b}` **只交于 `e`**（否则 `a = b`）。
- **3 阶元素**：若 `|a| = 3`，则 `{e, a, a²}` 是 3 阶子群。
- **6 阶元素**：若 `|a| = 6`，则 **`<a>` 是 6 阶循环群**，此时 `a` 是一生成元，`G = <a>` 就是循环群。
  **循环群 G 中元素的阶分布**：`φ(1)=1` 个 1 阶，`φ(2)=1` 个 2 阶（`a³`），`φ(3)=2` 个 3 阶（`a², a⁴`），`φ(6)=2` 个 6 阶（`a, a⁵`）。
  **此时有 3 阶元素 ✓ 结论成立**

**故只需讨论「G 不是循环群」的情形**（即 `n₆ = 0`）。
此时 `6 = n₁ + n₂ + n₃ = 1 + n₂ + n₃`，即 `n₂ + n₃ = 5` ✓
**关键论证**：**不能全是 2 阶元素**。
因为若 `n₂ = 5`（即除 e 外全是 2 阶元素），则任取两个不同的 2 阶元素 a, b，
考虑 `ab`。由 `a² = b² = e`：
若 `ab = e`，则 `b = a⁻¹ = a`，矛盾（a ≠ b）。
故 `ab ≠ e`，且 `(ab)² = abab`。若 ab 也是 2 阶，则 `abab = e`。
两边左乘 a、右乘 b：`a(abab)b = a e b` → `a²ba b² = ab` → `ba = ab`。
即 a, b **交换**。此时 `{e, a, b, ab}` 是 4 阶子群。
但由拉格朗日定理 `4 | 6`，**矛盾**（4 不整除 6）✗
故 `n₂ ≤ 4`（**若 `n₂ = 5` 则 `n₃ = 0`，这与上面「除 e 外全是 2 阶元素会导致矛盾」的结论冲突**），从而 **`n₃ = 5 − n₂ ≥ 1`** ✓
即 **G 中必有 3 阶元素** ✓ ∎

## 易错点提醒

1. **忘记验证封闭性**。错：对 `<Z, ÷>` 直接检查结合律。正确：**先检查封闭性**（`1 ÷ 2 = 1/2 ∉ Z`），不封闭就**不是二元运算**，其他都不用谈。
2. **混淆「零元」与「数 0」**。错：认为 `<Z, ×>` 的零元是 0（对的），就以为任何代数系统的零元都是 0。正确：**零元由运算表的「吸收」性质决定**，如 `<P(A), ∪>` 的零元是 **A**（不是 `∅`）。
3. **单位元和零元搞反**。错：`<P(A), ∪>` 的单位元是 A。正确：**单位元 `e*a = a`（保持不动），零元 `θ*a = θ`（吸收一切）**。`<P(A), ∪>` 中 `∅ ∪ B = B` → 单位元是 **`∅`**；`A ∪ B = A` → 零元是 **A** ✓
4. **求逆元时忘记结合律的必要性**。错：在非结合运算中套用「逆元唯一」。正确：**逆元唯一性依赖结合律**（定理 13.2 的证明用了 `b*(a*c) = (b*a)*c`）✓
5. **群中解方程随意交换顺序**。错：由 `axb = c` 得 `x = a⁻¹b⁻¹c`。正确：**`x = a⁻¹cb⁻¹`**（左乘 `a⁻¹`、右乘 `b⁻¹`，顺序要对应）✓
6. **`(ab)⁻¹ = a⁻¹b⁻¹`（顺序不颠倒）**。正确：**`(ab)⁻¹ = b⁻¹a⁻¹`**（「穿袜穿鞋」原则）✓
7. **`Zₙ*` 误认为含全部非零元素**。错：`Z₆* = {[1],[2],[3],[4],[5]}`。正确：**`Zₙ*` 只含与 n 互素的元素**：`Z₆* = {[1],[5]}`，`|Zₙ*| = φ(n)` ✓
8. **判断子群时忘记验证非空**。正确：子群判定定理**要求 H 非空**（通常验证 `e ∈ H` 或直接说「H 非空」）✓
9. **拉格朗日定理的逆命题误用**。错：「若 `k | |G|` 则 G 必有 k 阶子群」。正确：**这是错的！** 反例：**交错群 `A₄` 的阶为 12，但没有 6 阶子群** ✗（拉格朗日定理只是**必要条件**，不是充分条件。）
10. **子群的阶不整除群阶**。错：在 12 阶群里找 5 阶子群。正确：**由拉格朗日定理，子群的阶必整除群阶**，5 ∤ 12 故不可能 ✓
11. **循环群与交换群混淆**。正确：**循环群一定是交换群，但交换群不一定是循环群**。反例：Klein 四元群 `V₄` 交换但不循环（无 4 阶元素）✓
12. **`Z₄ ≅ V₄`（错误同构）**。正确：**`Z₄ ≇ V₄`**（元素的阶分布不同：`Z₄` 有 2 个 4 阶元素，`V₄` 有 0 个）✓
13. **置换成群时忘记 n ≥ 3 时非交换**。正确：**`Sₙ` 当 `n ≥ 3` 时非交换**（`S₂` 是 2 阶循环群，交换）✓
14. **环的 `a·0 = 0` 与「零因子」混淆**。正确：**`a·0 = 0` 对一切 a 恒成立**（这是环的性质）；而**零因子**指存在 `a,b ≠ 0` 使 `a·b = 0` ✓
15. **`Z₄` 是域（错误）**。正确：**`Zₙ` 是域 ⟺ n 是素数**。`Z₄` 中 `[2]×[2] = [0]` 有零因子，**不是整环也不是域** ✓

## 本章小结

1. **二元运算的封闭性**是代数系统的第一要求；**有限运算表可以完全描述运算**。
2. **运算的五种性质**：交换律（表对称）、结合律、幂等律、分配律、吸收律。
3. **特殊元素**：**单位元 `e*a = a`**（唯一）、**零元 `θ*a = θ`**（唯一）、**逆元 `a*a⁻¹ = e`**（结合律下唯一）。
4. **层次**：代数系统 →（结合律）**半群** →（单位元）**独异点** →（每元素可逆）**群** →（交换律）**Abel 群**。
5. **群的判定四要素**：封闭、结合、有单位元、每元素有逆元。
6. **群的性质**：**消去律成立**、**方程 `ax=b` 有唯一解**、**群无零元**、`(ab)⁻¹ = b⁻¹a⁻¹`。
7. **子群判定**：`H ≤ G ⟺ ∀a,b∈H, ab⁻¹ ∈ H`（一般情形）；**有限情形只需验证封闭**。
8. **循环群 `G = <a>`**：无限阶同构于 `<Z,+>`，n 阶同构于 `<Zₙ,+ₙ>`；**生成元个数为 `φ(n)`**；**`|a^k| = n/gcd(k,n)`**。
9. **置换群 `Sₙ`**：`|Sₙ| = n!`，`n ≥ 3` 时非交换；**凯莱定理：任何群同构于某个置换群**。
10. **陪集**：`aH`；**所有陪集大小相同（= |H|）**，**不同陪集互不相交且铺满 G**。
11. **★ 拉格朗日定理：`|H|` 整除 `|G|`，且 `|G| = |H|·[G:H]`**；推论：**元素的阶整除群阶**；**素数阶群必为循环群**；**费马小定理与欧拉定理都是它的推论**。
12. **同态**保持运算，**同构**是双射同态；**同构的必要条件**：阶相同、交换性相同、元素的阶分布相同。
13. **环**：加法交换群 + 乘法半群 + 分配律；**整环**：交换含幺无零因子；**域**：非零元素全体构成乘法交换群。
14. **`Zₙ` 是域 ⟺ n 是素数**；**无零因子 ⟺ n 是素数**；**有限域元素个数必为 `p^n`**。

> **一句话记住本章**：**「群就是『能加减乘除』的抽象化：封闭、结合、有单位元、有逆元；子群的阶必整除群阶（拉格朗日）；循环群由生成元的幂次铺满；`(ab)⁻¹ = b⁻¹a⁻¹` 顺序要颠倒；`Zₙ` 是域当且仅当 n 是素数。」**

2. **单位元**：需 `lcm(e, a) = a` 对**一切** `a ∈ S` 成立。

8. 记 `σ = (1 2 3)`（`1→2, 2→3, 3→1`），`τ = (1 2)`（`1→2, 2→1, 3→3`）。
   **约定：`(σ ∘ τ)(x) = σ(τ(x))`（先作用 τ）**。
   **(1) `(1 2 3) ∘ (1 2)`**：
   `1 →(τ) 2 →(σ) 3`，故 `1 ↦ 3`
   `2 →(τ) 1 →(σ) 2`，故 `2 ↦ 2`
   `3 →(τ) 3 →(σ) 1`，故 `3 ↦ 1`
   结果是 `1→3, 2→2, 3→1`，即 **`(1 3)`** ✓
   **(2) `(1 2) ∘ (1 2 3)`**：
   `1 →(σ) 2 →(τ) 1`，故 `1 ↦ 1`
   `2 →(σ) 3 →(τ) 3`，故 `2 ↦ 3`
   `3 →(σ) 1 →(τ) 2`，故 `3 ↦ 2`
   结果是 `1→1, 2→3, 3→2`，即 **`(2 3)`** ✓
   **验证非交换**：`(1 2 3) ∘ (1 2) = (1 3) ≠ (2 3) = (1 2) ∘ (1 2 3)` ✓
   **故 `S₃` 非交换** ✓
9. **证明**：要证 `a * b = b * a` 对一切 `a, b ∈ G` 成立。
   已知对一切 `x ∈ G` 有 `x * x = e`，即 `x⁻¹ = x` ✓
   任取 `a, b ∈ G`。考虑 `(a * b)` 的平方：
   `(a * b) * (a * b) = e`（由已知条件，取 `x = a*b`）✓
   **两边左乘 `a`**：`a * (a * b) * (a * b) = a * e = a`
   → `(a * a) * b * (a * b) = a`（结合律）
   → `e * b * (a * b) = a`（因 `a * a = e`）
   → `b * a * b = a` ✓
   **两边右乘 `b`**：`b * a * (b * b) = a * b`
   → `b * a * e = a * b`（因 `b * b = e`）
   → **`b * a = a * b`** ✓
   故 G 是 **Abel 群** ✓ ∎
10. **证明**：设 `|G| = p`（p 是素数）。
    因 `p ≥ 2`，G 中至少有两个元素，取 `a ∈ G` 且 `a ≠ e` ✓
    考虑由 a 生成的循环子群 `<a> = {e, a, a², …, a^(k−1)}`，其中 `k = |a|` ✓
    由**拉格朗日定理**，`|<a>| = k` 整除 `|G| = p` ✓
    因 p 是**素数**，p 的正因数只有 1 和 p。
    又因 `a ≠ e`，`<a>` 至少含 `e` 和 `a` 两个不同元素，故 `k = |<a>| ≥ 2` ✓
    故 `k = p`（不可能是 1）✓
    即 `<a> = G`，**G 是循环群**，a 是生成元 ✓ ∎
