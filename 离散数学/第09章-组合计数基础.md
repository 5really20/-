## 9.1 基本计数规则

### 9.1.1 加法法则（分类相加）

**加法法则（Addition Principle）**：若完成一件事有 `k` 类**互不相交**的方法，第 `i` 类方法有 `nᵢ` 种，则完成这件事共有
`n₁ + n₂ + … + nₖ`
种方法。

**关键前提**：各类方法**互不相交**（同一件事不能被算两次）。这是最容易出错的地方。

**例**：从 A 到 B 有 3 班火车、4 班汽车、2 班飞机（没有重叠的班次），则共有 `3 + 4 + 2 = 9` 种走法。

**集合语言**：`|A₁ ∪ A₂ ∪ … ∪ Aₖ| = |A₁| + |A₂| + … + |Aₖ|`（当 `Aᵢ` 两两不交时）。

### 9.1.2 乘法法则（分步相乘）

**乘法法则（Multiplication Principle）**：若完成一件事需依次经过 `k` 个**步骤**，第 `i` 步有 `nᵢ` 种选择（**与前几步的选择无关**），则共有
`n₁ × n₂ × … × nₖ`
种方法。

**关键前提**：各步的**选择数相互独立**（第 i 步的可选数不随前面选择而变）。

**例**：从 A 到 B 有 3 条路，从 B 到 C 有 4 条路，则从 A 经 B 到 C 共有 `3 × 4 = 12` 条路。

### 9.1.3 如何区分「分类」还是「分步」

| 判断问题 | 结论 |
|---|---|
| 这些方法能**独立地**完成任务吗？ | 能 → **加法法则** |
| 必须**依次做完所有**步骤才完成任务吗？ | 是 → **乘法法则** |
| 换个说法：是「**或者**……或者……」吗？ | **加法** |
| 换个说法：是「**先**……**再**……**又**……」吗？ | **乘法** |

> **黄金口诀**：**分类用加法，分步用乘法；分类要互斥，分步要独立。**

**综合例**：从 5 名男生、4 名女生中选 3 人组成小组，要求至少有 1 名女生。有多少种选法？
**解法一（分类）**：按女生人数分类
- 1 女 2 男：`C(4,1) × C(5,2) = 4 × 10 = 40`
- 2 女 1 男：`C(4,2) × C(5,1) = 6 × 5 = 30`
- 3 女：`C(4,3) = 4`
总数 `= 40 + 30 + 4 = 74` ✓
**解法二（间接法）**：总数减去「全是男生」的情况
`C(9,3) − C(5,3) = 84 − 10 = 74` ✓

> **间接法（补集法）**：当「至少」「至多」出现时，用 `总数 − 反面情况` 往往更快。**注意**：只有当反面情况容易计算时才用。

### 9.1.4 计数中的常见陷阱

**陷阱 1：重复计数**。
**例**：用 0, 1, 2, …, 9 组成 3 位数，要求首位不为 0。
错解：`10 × 10 × 9 = 900`？这里假设末位不能是 0，其实没有这个限制。
正解：首位有 9 种（1~9），后两位各有 10 种 → `9 × 10 × 10 = 900` ✓（巧合相同，但推理不同）

**陷阱 2：遗漏情况**。
**例**：从 10 人中选 3 人排成一排照相，甲乙必须相邻。有多少种排法？
**解**：把甲乙「捆绑」成一个整体，与其余 8 人共 9 个对象排列：`9!` 种；甲乙内部有 `2!` 种。
总数 `= 9! × 2 = 362880 × 2 = 725760` ✓
（**捆绑法**：处理「必须相邻」问题的标准技巧。）

**陷阱 3：顺序是否重要**。
排列（有顺序）与组合（无顺序）必须分清。见 9.2 节的对比表。

## 9.2 排列与组合

### 9.2.1 集合的排列

**定义 9.1（排列）**：从 `n` 元集合 S 中**有序**地选出 `r` 个元素，称为一个 **r-排列**。所有 r-排列的个数记作 `P(n, r)`。

**公式**：
`P(n, r) = n(n−1)(n−2)…(n−r+1) = n! / (n−r)!`

**全排列**：`P(n, n) = n!`。规定 `0! = 1`。

**为什么**：第 1 个位置有 n 种选法，第 2 个位置剩 n−1 种，…，第 r 个位置剩 `n−r+1` 种。由乘法法则相乘 ✓

**例**：`P(5, 3) = 5 × 4 × 3 = 60`；`P(5, 5) = 120`。

### 9.2.2 集合的组合

**定义 9.2（组合）**：从 `n` 元集合 S 中**无序**地选出 `r` 个元素，称为一个 **r-组合**（或 **r-子集**）。个数记作 `C(n, r)` 或 `(n choose r)`。

**公式**：
`C(n, r) = P(n, r) / r! = n! / (r!(n−r)!)`

**为什么除以 `r!`**：每个 r-组合对应 `r!` 个 r-排列（因为选出的 r 个元素的内部顺序有 `r!` 种）。所以「组合数 = 排列数 ÷ r!」✓

**对称性**：`C(n, r) = C(n, n−r)`（选 r 个与「选出 n−r 个不选」一一对应）。

**规定**：`C(n, 0) = 1`，`C(n, n) = 1`，且当 `r > n` 或 `r < 0` 时 `C(n, r) = 0`。

**常用组合数值表**：

| n \ r | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| 0 | 1 | | | | | | |
| 1 | 1 | 1 | | | | | |
| 2 | 1 | 2 | 1 | | | | |
| 3 | 1 | 3 | 3 | 1 | | | |
| 4 | 1 | 4 | 6 | 4 | 1 | | |
| 5 | 1 | 5 | 10 | 10 | 5 | 1 | |
| 6 | 1 | 6 | 15 | 20 | 15 | 6 | 1 |

（这就是杨辉三角 / 帕斯卡三角。）

### 9.2.3 ★ 排列与组合对比（必须分清）

| 对比项 | 排列（Permutation） | 组合（Combination） |
|---|---|---|
| 是否考虑顺序 | **考虑**（AB ≠ BA） | **不考虑**（AB 与 BA 相同） |
| 记号 | `P(n, r)` | `C(n, r)` |
| 公式 | `n!/(n−r)!` | `n!/(r!(n−r)!)` |
| 关系 | `P(n, r) = C(n, r) · r!` | `C(n, r) = P(n, r) / r!` |
| 典型关键词 | 「**排队**」「**安排**」「**编号**」「**依次**」 | 「**选出**」「**选**」「**一组**」「**至少**」 |
| 例 | 5 人中选 3 人排成一排：`P(5,3)=60` | 5 人中选 3 人组成小组：`C(5,3)=10` |

> **判断顺序是否重要的实用方法**：**把你的方案里两个元素互换位置，如果得到「不同的方案」，那就要用排列；如果还是「同一个方案」，就用组合。**

### 9.2.4 圆排列

**定义 9.3（圆排列）**：把 n 个元素排成一个圆圈（只考虑**相对顺序**，旋转视为相同），称为**圆排列**。

**公式**：
`n 个元素的圆排列数 = (n − 1)!`

**为什么**：n 个元素的直线排列有 `n!` 种。每种圆排列在直线上对应 n 种排法（因为圆可以「转」n 个位置而看起来一样）。所以圆排列数 `= n! / n = (n−1)!` ✓

**例**：5 个人围圆桌而坐，有多少种坐法？`(5−1)! = 4! = 24` 种。
**注意**：若圆桌有「主位」或要求「某人固定」，则不能简单套公式。
**变体**：n 个元素的**项链排列**（翻转也视为相同）有 `(n−1)!/2` 种（n ≥ 3）。

### 9.2.5 多重集的排列

**定义 9.4（多重集）**：元素可以重复出现的「集合」，记 `M = {n₁·a₁, n₂·a₂, …, nₖ·aₖ}`，其中 `nᵢ` 表示元素 `aᵢ` 的**重数**。总元素数 `n = n₁ + n₂ + … + nₖ`。

**定理 9.1（多重集的全排列）**：多重集 `M = {n₁·a₁, …, nₖ·aₖ}` 的全排列数为
`n! / (n₁! · n₂! · … · nₖ!)`

**为什么**：先假想 n 个元素**互不相同**，有 `n!` 种排法。但同一类 `aᵢ` 的 `nᵢ` 个元素互换位置**不产生新的排列**，故要除以 `n₁!n₂!…nₖ!` ✓

**例**：单词 `MISSISSIPPI` 的字母排列数。
字母统计：`M×1, I×4, S×4, P×2`，共 11 个字母。
`11! / (1! · 4! · 4! · 2!) = 39916800 / (1 × 24 × 24 × 2) = 39916800 / 1152 = 34650` ✓

**更一般的 r-排列**：从多重集中取 r 个元素的排列数没有统一公式，要分类讨论。

### 9.2.6 多重集的组合（可重组合）

**定理 9.2（多重集的 r-组合）**：设 `M = {∞·a₁, ∞·a₂, …, ∞·aₖ}`（每类元素都**无限多**），则从中取 `r` 个元素的 **r-组合**（不考虑顺序）的个数为
`C(n + r − 1, r)`（其中 n 是**元素种类数**，这里 n = k）

> **注意记号**：本公式里 `n` 指**种类数**，`r` 指**取出的个数**。等价写法：k 种元素取 r 个 → `C(r + k − 1, r) = C(r + k − 1, k − 1)`。

**为什么（隔板法 / 星与棒）**：把「取 `r` 个元素」的问题转化为「把 `r` 个相同的球放进 `k` 个不同的盒子」。
用 `k − 1` 个**隔板**把 `r` 个**球**分成 k 份，排列方式为「r 个球 + (k−1) 个隔板」共 `r + k − 1` 个位置中选出 `k−1` 个位置放隔板：
`C(r + k − 1, k − 1) = C(r + k − 1, r)` ✓

**ASCII 示意**（k = 4 种元素，r = 6 个球）：
```
   ● ● ● | ● | | ● ●        表示 第1类取3个、第2类取1个、第3类取0个、第4类取2个
   └─ 球 ─┘ ↑ 隔板
   共 6 个球 + 3 个隔板 = 9 个位置，从中选 3 个位置放隔板：C(9,3) = 84
```

**例**：从 4 种水果（苹果、香蕉、橘子、梨）中买 6 个（每种不限量），有多少种买法？
`C(6 + 4 − 1, 6) = C(9, 6) = C(9, 3) = 84` 种 ✓

**★ 方程的整数解个数（隔板法的经典应用）**：
**定理 9.3**：方程 `x₁ + x₂ + … + xₖ = r` 的**非负整数解**个数为 `C(r + k − 1, k − 1)`。
**推论**：若要求 `xᵢ ≥ 1`（**正整数解**），则解数为 `C(r − 1, k − 1)`。
**为什么（正整数解）**：令 `yᵢ = xᵢ − 1 ≥ 0`，则 `y₁ + … + yₖ = r − k`，由定理 9.3 得 `C(r − k + k − 1, k − 1) = C(r − 1, k − 1)` ✓

**例**：求 `x₁ + x₂ + x₃ + x₄ = 10` 的非负整数解个数，以及正整数解个数。
- 非负：`C(10 + 4 − 1, 4 − 1) = C(13, 3) = 286`
- 正：`C(10 − 1, 4 − 1) = C(9, 3) = 84`
**再求 `x₁ ≥ 2` 且其余 `≥ 0` 的解数**：令 `y₁ = x₁ − 2`，则 `y₁ + x₂ + x₃ + x₄ = 8`，解数 `C(8+4−1, 3) = C(11,3) = 165` ✓

### 9.2.7 可重排列

**定理 9.4**：从 n 个**不同**元素中取 r 个，**允许重复**，排成一列（**有序**）的排列数为
`n^r`

**为什么**：每个位置都有 n 种独立选择（因为允许重复，选过的还能再选），由乘法法则得 `n^r` ✓

**例**：用 0~9 组成 4 位**密码**（允许数字重复，首位可为 0）：`10⁴ = 10000` 种。
用 0~9 组成 4 位数（首位不为 0）：`9 × 10³ = 9000` 种。

**★ 四种计数模型对照表（必须背熟）**：

| 模型 | 有序？ | 可重复？ | 公式 | 例（n=4 种，取 r=2） |
|---|---|---|---|---|
| **排列** | 有序 | 不可重复 | `P(n,r) = n!/(n−r)!` | `P(4,2) = 12` |
| **组合** | 无序 | 不可重复 | `C(n,r)` | `C(4,2) = 6` |
| **可重排列** | 有序 | 可重复 | `n^r` | `4² = 16` |
| **可重组合** | 无序 | 可重复 | `C(n+r−1, r)` | `C(5,2) = 10` |

## 9.3 二项式定理与组合恒等式

### 9.3.1 二项式定理

**定理 9.5（二项式定理 / Binomial Theorem）**：对任意实数 a, b 和非负整数 n，
`(a + b)^n = Σ_{k=0}^{n} C(n, k) · a^(n−k) · b^k`
即
`(a+b)^n = C(n,0)a^n + C(n,1)a^(n−1)b + C(n,2)a^(n−2)b² + … + C(n,n)b^n`

**证明（组合论证法）**：`(a+b)^n` 是 n 个 `(a+b)` 相乘。展开时，每一项都是从每个括号里各取一个 a 或 b 相乘得到。要得到 `a^(n−k)b^k`，必须**恰好从 k 个括号里取 b**，从其余 `n−k` 个括号里取 a。选哪 k 个括号取 b 有 `C(n,k)` 种方式。故 `a^(n−k)b^k` 的系数是 `C(n,k)` ✓ ∎

**★ 展开算例**：展开 `(2x − 3)⁵`。
用 `a = 2x`，`b = −3`，`n = 5`：
`(2x − 3)⁵ = Σ_{k=0}^{5} C(5,k) (2x)^(5−k) (−3)^k`

| k | `C(5,k)` | `(2x)^(5−k)` | `(−3)^k` | 项 |
|---|---|---|---|---|
| 0 | 1 | `32x⁵` | 1 | `32x⁵` |
| 1 | 5 | `16x⁴` | −3 | `−240x⁴` |
| 2 | 10 | `8x³` | 9 | `720x³` |
| 3 | 10 | `4x²` | −27 | `−1080x²` |
| 4 | 5 | `2x` | 81 | `810x` |
| 5 | 1 | 1 | −243 | `−243` |

**答案**：`32x⁵ − 240x⁴ + 720x³ − 1080x² + 810x − 243`

**验证**：令 `x = 1`：左边 `(2−3)⁵ = −1`；右边 `32 − 240 + 720 − 1080 + 810 − 243 = −1` ✓

**★ 求特定项的系数**：
**例**：求 `(x² + 2/x)⁶` 展开式中 `x³` 的系数。
**解**：通项为 `T_{k+1} = C(6,k) · (x²)^(6−k) · (2/x)^k = C(6,k) · 2^k · x^(12−2k−k) = C(6,k)·2^k·x^(12−3k)`
令指数等于 3：`12 − 3k = 3` ⟹ `k = 3`。
系数 `= C(6,3) · 2³ = 20 × 8 = 160` ✓
**答案**：`x³` 的系数为 **160**。

### 9.3.2 ★ 组合恒等式（10 条必背）

| 编号 | 恒等式 | 说明 / 组合意义 |
|---|---|---|
| **1** | `C(n, r) = C(n, n−r)` | 选 r 个 ⟺ 留 n−r 个（**对称性**） |
| **2** | `C(n, 0) + C(n, 1) + … + C(n, n) = 2ⁿ` | n 元集的**子集总数** |
| **3** | `C(n, 0) − C(n, 1) + C(n, 2) − … + (−1)ⁿC(n,n) = 0` | 偶数元子集数 = 奇数元子集数（n ≥ 1） |
| **4** | `C(n, 1) + 2C(n, 2) + 3C(n, 3) + … + nC(n, n) = n·2^(n−1)` | 所有子集的元素总数 |
| **5** | `C(n, k) = C(n−1, k) + C(n−1, k−1)` | **帕斯卡恒等式**（杨辉三角的递推） |
| **6** | `C(m+n, r) = Σ_{k=0}^{r} C(m, k)·C(n, r−k)` | **范德蒙德恒等式**（分两类取） |
| **7** | `C(n, r) · C(r, k) = C(n, k) · C(n−k, r−k)` | 两步选取的两种数法 |
| **8** | `Σ_{k=0}^{n} C(n,k)² = C(2n, n)` | 范德蒙德取 `m = n = r` 的特例 |
| **9** | `1·C(n,1) + 2·C(n,2) + … + n·C(n,n) = n·2^(n−1)` | 同 4 |
| **10** | `C(n+r+1, r) = C(n+r, r) + C(n+r−1, r−1) + … + C(n+1, 1) + C(n, 0)` | **平行求和** |

**★ 证明 2（用二项式定理）**：在 `(1+1)^n = Σ C(n,k)·1^(n−k)·1^k` 中取 `a = b = 1`，得 `2ⁿ = Σ C(n,k)` ✓

**★ 证明 3（用二项式定理）**：在 `(1 + (−1))^n = Σ C(n,k)·1^(n−k)·(−1)^k` 中取 `a = 1, b = −1`，得 `0 = Σ (−1)^k C(n,k)` ✓

**★ 证明 5（帕斯卡恒等式，组合证明法）**：
设 S 是 `n` 元集，固定一个元素 `a ∈ S`。S 的 k 元子集分成两类：
- **不含 a 的**：从 `S − {a}`（`n−1` 个元素）中选 k 个 → `C(n−1, k)` 个；
- **含 a 的**：先选 a，再从剩下的 `n−1` 个中选 `k−1` 个 → `C(n−1, k−1)` 个。

两类**互不相交**且**穷尽所有** k 元子集，由加法法则：`C(n,k) = C(n−1,k) + C(n−1,k−1)` ✓ ∎

**★ 证明 7（双计数法 / 组合证明法）**：
**左边** `C(n,r)·C(r,k)` 的组合意义：从 n 人中先选 r 人组成委员会，再从这 r 人中选 k 人组成常委会。
**右边** `C(n,k)·C(n−k, r−k)` 的组合意义：直接从 n 人中选 k 人当常委，再从剩下的 `n−k` 人中选 `r−k` 人补足委员会。
两种数法数的是**同一批方案**（每个「委员会 + 常委会」结构），故相等 ✓ ∎

> **组合证明法（双计数法 / Double Counting）的要领**：**给等式两边各找一个「数同一件事」的方式**。比代数演算更优雅，考试中常要求「用组合意义证明」。

### 9.3.3 非降路径问题

**定义 9.5（非降路径）**：在平面直角坐标系中，从点 `(0, 0)` 出发，每步只能**向右**（`x` 增 1）或**向上**（`y` 增 1），走到 `(m, n)` 的路径称为**非降路径**（也叫格路径、单调路径）。

**定理 9.6**：从 `(0,0)` 到 `(m,n)` 的非降路径共有
`C(m + n, m) = C(m + n, n)`
条。

**证明**：一条路径由 `m` 个「右」步和 `n` 个「上」步组成一个长度为 `m+n` 的序列。**只要确定了 m 个「右」步在序列中的位置，路径就完全确定了**。从 `m+n` 个位置中选出 m 个放「右」：`C(m+n, m)` ✓ ∎

**★ 例**：从 `(0,0)` 到 `(4,3)` 的非降路径数：
`C(4+3, 4) = C(7, 4) = 35` 条 ✓

**★ 例（带限制的非降路径）**：从 `(0,0)` 到 `(4,3)`，**必须经过** `(2,1)` 的路径数。
**解**：分两段（乘法法则）
- 从 `(0,0)` 到 `(2,1)`：`C(2+1, 2) = C(3,2) = 3` 条
- 从 `(2,1)` 到 `(4,3)`：需要向右 `4−2 = 2` 步、向上 `3−1 = 2` 步 → `C(2+2, 2) = C(4,2) = 6` 条
总数 `= 3 × 6 = 18` 条 ✓

**★ 例（不接触对角线的路径 —— 反射原理）**：从 `(0,0)` 到 `(n,n)` 且**除起点终点外不接触对角线** `y = x` 的路径数。
**答案**：`2 · Catalan(n−1) = (2/n)·C(2n−2, n−1)`（见第 10 章的 Catalan 数）。
**卡特兰数** `Cₙ = C(2n, n)/(n+1)` 计数的是：n 对括号的合法匹配数、n 个节点的二叉树形态数、凸 n+2 边形的三角剖分数、不越过对角线的格路径数等。

**卡特兰数前几项**：`C₀=1, C₁=1, C₂=2, C₃=5, C₄=14, C₅=42, C₆=132, C₇=429`。

## 9.4 多项式定理与多项式系数

**定理 9.7（多项式定理 / Multinomial Theorem）**：
`(x₁ + x₂ + … + xₜ)^n = Σ C(n; n₁, n₂, …, nₜ) · x₁^(n₁) x₂^(n₂) … xₜ^(nₜ)`
其中求和跑遍所有满足 `n₁ + n₂ + … + nₜ = n` 的非负整数组 `(n₁, …, nₜ)`。

**多项式系数（Multinomial Coefficient）**：
`C(n; n₁, n₂, …, nₜ) = n! / (n₁! · n₂! · … · nₜ!)`

> **注意**：当 `t = 2` 时，`C(n; k, n−k) = n!/(k!(n−k)!) = C(n,k)`，退化为**二项式系数** ✓

**组合意义**：把 n 个**不同**的球放入 t 个**不同**的盒子，第 i 个盒子恰放 `nᵢ` 个球的方法数。
（也等于多重集 `{n₁·x₁, …, nₜ·xₜ}` 的全排列数。）

**★ 例**：展开 `(x + y + z)³`。
所有满足 `n₁+n₂+n₃ = 3` 的三元组及系数：

| `(n₁,n₂,n₃)` | 系数 `3!/(n₁!n₂!n₃!)` | 项 |
|---|---|---|
| (3,0,0) | `6/(6·1·1) = 1` | `x³` |
| (0,3,0) | 1 | `y³` |
| (0,0,3) | 1 | `z³` |
| (2,1,0) | `6/(2·1·1) = 3` | `3x²y` |
| (2,0,1) | 3 | `3x²z` |
| (1,2,0) | 3 | `3xy²` |
| (1,0,2) | 3 | `3xz²` |
| (0,2,1) | 3 | `3y²z` |
| (0,1,2) | 3 | `3yz²` |
| (1,1,1) | `6/(1·1·1) = 6` | `6xyz` |

**答案**：
`(x+y+z)³ = x³ + y³ + z³ + 3x²y + 3x²z + 3xy² + 3xz² + 3y²z + 3yz² + 6xyz`

**验证**：令 `x = y = z = 1`：左边 `3³ = 27`；右边 `1+1+1+3×6+6 = 3 + 18 + 6 = 27` ✓

**★ 例（多项式系数的计数应用）**：把 10 个不同的球放入 3 个不同的盒子，分别放 5, 3, 2 个，有多少种放法？
`C(10; 5, 3, 2) = 10! / (5! · 3! · 2!) = 3628800 / (120 × 6 × 2) = 3628800 / 1440 = 2520` ✓

**多项式的项数**：
`(x₁ + x₂ + … + xₜ)^n` 展开后（合并同类项）共有 `C(n + t − 1, t − 1)` 项（这是「隔板法」的直接应用，因为项由非负整数解 `(n₁,…,nₜ)` 决定）。
**例**：`(x+y+z)³` 有 `C(3+3−1, 3−1) = C(5,2) = 10` 项 ✓（与上表一致）

## 9.5 鸽巢原理 ★

### 9.5.1 基本形式

**定理 9.8（鸽巢原理 / 抽屉原理 / Pigeonhole Principle）**：
把 `n + 1` 个物体放入 `n` 个盒子，则**至少有一个盒子装有 2 个或更多物体**。

**证明（反证）**：假设每个盒子最多装 1 个物体，则 n 个盒子最多装 n 个物体 < n+1，矛盾 ✓ ∎

**一般形式**：把 `n` 个物体放入 `k` 个盒子，则至少有一个盒子装有 `⌈n/k⌉` 个或更多物体。

**证明**：若每个盒子最多 `⌈n/k⌉ − 1` 个，则总数 ≤ `k(⌈n/k⌉ − 1) < k · (n/k) = n`，矛盾 ✓ ∎

> **记忆**：**「n 个鸽子，k 个巢，至少有一个巢里有 `⌈n/k⌉` 只鸽子。」**
> **用法要点**：鸽巢原理只能证明「**存在**」，不能指出「是哪一个」，也不能给出具体构造。

### 9.5.2 ★ 鸽巢原理的经典应用

**应用 1（生日问题）**：任意 367 人中，至少有两人生日相同。
**解**：一年最多 366 天（含闰年），把 367 人按生日放进 366 个「盒子」，由鸽巢原理至少一个盒子有 2 人 ✓

**应用 2（袜子）**：抽屉里有 10 只黑袜、12 只蓝袜。在**黑暗中**至少要取多少只，才能保证有一双同色的袜子？
**解**：只有 2 种颜色，由鸽巢原理取 `2 + 1 = 3` 只即可保证有 2 只同色 ✓
**答案**：**3 只**。
（若要求「一双黑袜」，则最坏情况是先取完 12 只蓝袜，所以需 `12 + 2 = 14` 只。）

**应用 3（中国剩余定理式的同余）**：证明任意 `n + 1` 个整数中，必有两个之差能被 `n` 整除。
**证明**：任何整数除以 n，余数只可能是 `0, 1, …, n−1` 共 n 种。把 `n+1` 个整数按余数放进 n 个「盒子」，由鸽巢原理有两个数 `a, b` 余数相同，即 `a ≡ b (mod n)`，故 `n | (a − b)` ✓ ∎

**应用 4（数列中找连续子序列的和能被 n 整除）**：证明任意 n 个整数 `a₁, …, aₙ` 中，必存在连续若干项之和能被 n 整除。
**证明**：考虑前缀和 `S₀ = 0, S₁ = a₁, S₂ = a₁+a₂, …, Sₙ = a₁+…+aₙ`，共 `n+1` 个数。
它们除以 n 的余数只有 n 种。由鸽巢原理，存在 `0 ≤ i < j ≤ n` 使 `Sᵢ ≡ Sⱼ (mod n)`。
则 `Sⱼ − Sᵢ = a_{i+1} + a_{i+2} + … + a_j` 能被 n 整除 ✓ ∎

**应用 5（拉姆齐定理的最简情形 R(3,3) = 6）**：任意 6 个人中，要么有 3 个人互相认识，要么有 3 个人互相不认识。
**证明**：任取一人 A。其余 5 人中，按「与 A 是否认识」分两类。由鸽巢原理（`5 = 2 + 3`），至少有一类有 `⌈5/2⌉ = 3` 人。
设这 3 人都与 A 认识（另一类情况对称）。若这 3 人中**有两人互相认识**，则这两人连同 A 构成 3 人互相认识 ✓；若这 3 人**两两都不认识**，则这 3 人本身就是 3 人互相不认识 ✓
无论哪种情况，结论成立 ✓ ∎

**应用 6（数列中的单调子序列）**：任意 `n² + 1` 个不同的实数中，必存在长度为 `n + 1` 的递增子序列或长度为 `n + 1` 的递减子序列。
**证明**：设这 `n²+1` 个数为 `a₁, …, a_{n²+1}`。对每个 `aᵢ`，定义 `(xᵢ, yᵢ)`，其中
`xᵢ` = 以 `aᵢ` **结尾**的最长递增子序列的长度，
`yᵢ` = 以 `aᵢ` **结尾**的最长递减子序列的长度。
若不存在长度 `n+1` 的递增子序列，则 `xᵢ ∈ {1, …, n}`；若不存在长度 `n+1` 的递减子序列，则 `yᵢ ∈ {1, …, n}`。
于是每个 `(xᵢ, yᵢ)` 都是 `n × n` 表格中的一个格子，共 `n²` 种可能。
但有 `n²+1` 个下标，由鸽巢原理存在 `i < j` 使 `(xᵢ, yᵢ) = (xⱼ, yⱼ)`。
而若 `aᵢ < aⱼ`，则以 `aⱼ` 结尾的递增子序列可以接到以 `aᵢ` 结尾的最长递增子序列后面，得 `xⱼ ≥ xᵢ + 1`，矛盾；
若 `aᵢ > aⱼ`，则同理 `yⱼ ≥ yᵢ + 1`，矛盾。
两种情况都矛盾，故必存在长度 `n+1` 的递增或递减子序列 ✓ ∎

**应用 7（握手问题）**：证明任意 n 个人（n ≥ 2）中，至少有两个人握手的次数相同。
**证明**：每个人的握手次数是 `0` 到 `n−1` 之间的整数，共 n 种可能值。
但 `0` 和 `n−1` **不可能同时出现**（若有人与所有人握手，则没人握手 0 次；反之亦然）。
所以实际可能出现的值只有 `n − 1` 种。n 个人放入 `n−1` 个「盒子」，由鸽巢原理至少有两人握手次数相同 ✓ ∎

**应用 8（几何）**：边长为 2 的正方形中任取 5 个点，必有 2 点的距离不超过 `√2`。
**证明**：把正方形分成 4 个边长为 1 的小正方形。5 个点放入 4 个小正方形，由鸽巢原理有 2 点落在同一个小正方形内。该小正方形内任意两点的最大距离是其对角线 `√(1² + 1²) = √2`，故这 2 点距离 ≤ `√2` ✓ ∎

### 9.5.3 鸽巢原理的解题套路

```
第 1 步：确定「鸽子」是什么（要放的对象）
第 2 步：确定「巢」是什么（分类的标准）
第 3 步：算出「鸽子数 n」和「巢数 k」
第 4 步：套用结论 —— 至少有一个巢里有 ⌈n/k⌉ 个鸽子
第 5 步：把「同巢」翻译回题目要的结论
```

> **难点在第 2 步**：巢的构造往往是题目的**关键技巧**，需要「把要证明的结论反推成分类标准」。
> **例**：在应用 6 中，「巢」是 `(xᵢ, yᵢ)` 这个二元组——这个构造是整道题的灵魂。

## 典型例题

**例 9.1**（题型：加法/乘法法则）
某班级有 25 名男生、20 名女生。
(1) 选 1 名班长，有多少种选法？
(2) 选 1 名男生和 1 名女生当正副班长（男生正、女生副），有多少种？
(3) 选 2 人当正副班长（不限性别），有多少种？
**解**：
(1) **分类**（或男或女）：`25 + 20 = 45` 种。
(2) **分步**：先选男生（25 种），再选女生（20 种）：`25 × 20 = 500` 种。
(3) **分步 + 分类**：
- 男正女副：`25 × 20 = 500`
- 女正男副：`20 × 25 = 500`
- 男正男副：`25 × 24 = 600`
- 女正女副：`20 × 19 = 380`
总数 `= 500 + 500 + 600 + 380 = 1980` 种。
**另解（排列）**：从 45 人中选 2 人有序排列 = `P(45, 2) = 45 × 44 = 1980` ✓
**答案**：(1) 45；(2) 500；(3) 1980。

**例 9.2**（题型：排列组合综合）
从 8 名男生、6 名女生中选 5 人组成代表队。
(1) 至少 2 名女生，有多少种选法？
(2) 队长必须是女生且队长是固定的某人（设为甲），有多少种选法？
(3) 5 人站成一排，其中甲、乙必须相邻，有多少种站法？
**解**：
(1) **分类**（按女生人数）：
- 2 女 3 男：`C(6,2)·C(8,3) = 15 × 56 = 840`
- 3 女 2 男：`C(6,3)·C(8,2) = 20 × 28 = 560`
- 4 女 1 男：`C(6,4)·C(8,1) = 15 × 8 = 120`
- 5 女：`C(6,5) = 6`
总数 `= 840 + 560 + 120 + 6 = 1526`
**另解（间接法）**：总数 `C(14,5) = 2002`，减去「0 女 5 男」`C(8,5) = 56` 和「1 女 4 男」`C(6,1)C(8,4) = 6 × 70 = 420`：
`2002 − 56 − 420 = 1526` ✓
(2) 甲已确定入选，从剩下 13 人中再选 4 人：`C(13,4) = 715` 种。
(3) 先选出 5 人，再排列。**注意「甲、乙必须相邻」的前提是甲、乙都被选中**，所以先算选法再算排法：
- **选人**：甲、乙必选，再从其余 12 人中选 3 人 → `C(12,3) = 220` 种
- **排人**：甲乙捆绑成一个整体（内部 `2!` 种），与其余 3 人共 4 个对象排列 → `4! = 24` 种
总数 `= 220 × 2 × 24 = 10560` 种。
**答案**：(1) 1526；(2) 715；(3) 10560。

**例 9.3**（题型：多重集排列与组合）
(1) 单词 `BANANA` 的字母有多少种不同的排列？
(2) 从 5 种不同的糖果中买 8 颗（每种不限量），有多少种买法？
(3) 求 `x₁ + x₂ + x₃ = 15` 的正整数解个数。
**解**：
(1) 字母统计：`B×1, A×3, N×2`，共 6 个。
`6! / (1! · 3! · 2!) = 720 / (1 × 6 × 2) = 720 / 12 = 60` ✓
(2) 多重集组合：`k = 5` 种，`r = 8` 颗。
`C(8 + 5 − 1, 8) = C(12, 8) = C(12, 4) = 495` ✓
(3) 正整数解：`C(15 − 1, 3 − 1) = C(14, 2) = 91` ✓
**答案**：(1) 60；(2) 495；(3) 91。

**例 9.4**（题型：二项式定理求系数）
(1) 求 `(3x − 2)⁷` 展开式中 `x⁴` 的系数。
(2) 求 `(x + 1/x)⁸` 展开式中的**常数项**。
(3) 求 `(1 + x)¹⁰` 展开式中 `x⁶` 的系数，以及所有系数之和。
**解**：
(1) 通项 `T_{k+1} = C(7,k)·(3x)^(7−k)·(−2)^k`
`x⁴` 对应 `7 − k = 4` ⟹ `k = 3`。
系数 `= C(7,3)·3⁴·(−2)³ = 35 × 81 × (−8) = 35 × (−648) = −22680` ✓
(2) 通项 `T_{k+1} = C(8,k)·x^(8−k)·x^(−k) = C(8,k)·x^(8−2k)`
常数项要求指数为 0：`8 − 2k = 0` ⟹ `k = 4`。
常数项 `= C(8,4) = 70` ✓
(3) `x⁶` 的系数 `= C(10,6) = 210`。
所有系数之和 = 令 `x = 1`：`(1+1)¹⁰ = 2¹⁰ = 1024` ✓
**答案**：(1) −22680；(2) 70；(3) 210 和 1024。

**例 9.5**（题型：组合恒等式证明）
用**组合意义**证明：`C(n, 2) = C(n−1, 2) + C(n−1, 1)`。
**证明**：
设 S 是 n 元集，固定 `a ∈ S`。S 的 2 元子集分成两类：
- **不含 a 的**：从 `S − {a}`（n−1 个元素）中选 2 个 → `C(n−1, 2)` 个；
- **含 a 的**：先选 a，再从剩下的 n−1 个中选 1 个 → `C(n−1, 1)` 个。

两类互不相交且穷尽所有 2 元子集，由加法法则
`C(n,2) = C(n−1, 2) + C(n−1, 1)` ✓ ∎
**验证（代数法）**：
左边 `= n(n−1)/2`；
右边 `= (n−1)(n−2)/2 + (n−1) = (n−1)[(n−2)/2 + 1] = (n−1)(n/2) = n(n−1)/2` ✓
两法一致。

**例 9.6**（题型：非降路径）
在平面上，某人从 `(0,0)` 出发走到 `(5,4)`，每步只能向右或向上。
(1) 共有多少条非降路径？
(2) 其中经过 `(2,2)` 的有多少条？
(3) 其中**不经过** `(3,1)` 的有多少条？
**解**：
(1) 需要向右 5 步、向上 4 步，共 9 步。
`C(9, 5) = C(9, 4) = 126` 条 ✓
(2) 分两段（乘法法则）：
- `(0,0) → (2,2)`：右 2 上 2，共 4 步 → `C(4,2) = 6` 条
- `(2,2) → (5,4)`：右 3 上 2，共 5 步 → `C(5,3) = 10` 条
总数 `= 6 × 10 = 60` 条 ✓
(3) **不经过 `(3,1)`** = 总数 − 经过 `(3,1)` 的条数。
经过 `(3,1)` 的：
- `(0,0) → (3,1)`：右 3 上 1，共 4 步 → `C(4,3) = 4` 条
- `(3,1) → (5,4)`：右 2 上 3，共 5 步 → `C(5,2) = 10` 条
经过的共 `4 × 10 = 40` 条。
不经过的 `= 126 − 40 = 86` 条 ✓
**答案**：(1) 126；(2) 60；(3) 86。

**例 9.7**（题型：鸽巢原理）
(1) 一个袋子里有红、黄、蓝、白 4 种颜色的球各足够多。至少取多少个球才能保证有 5 个同色？
(2) 证明：任取 11 个整数，其中必有两个数之差是 10 的倍数。
(3) 证明：任意 5 个整数中，必有 3 个之和能被 3 整除。
**解**：
(1) 4 种颜色，要保证有 5 个同色。最坏情况是每种先取 4 个（共 16 个）仍没有 5 个同色。再取 1 个必然使某色达 5 个。
`4 × 4 + 1 = 17`。
**答案**：至少取 **17** 个。
(2) **证明**：任何整数除以 10，余数只可能是 `0, 1, …, 9`，共 **10 种**。
把 11 个整数按余数放进 10 个「盒子」，由**鸽巢原理**至少有两个数 `a, b` 余数相同。
则 `a ≡ b (mod 10)`，即 `10 | (a − b)` ✓ ∎
(3) **证明**：任何整数除以 3，余数只可能是 `0, 1, 2`，共 **3 种**。
把 5 个整数按余数放进 3 个「盒子」，由鸽巢原理（一般形式，`⌈5/3⌉ = 2`）至少有一个盒子有 **2 个或更多**数。
但 `2` 还不够，需要 3 个。分类讨论：
- **情形 A**：某个余数类有 **≥ 3** 个数。取这 3 个数，它们的和 `≡ 3r ≡ 0 (mod 3)` ✓
- **情形 B**：每个余数类最多 2 个数。因共 5 个数、3 个类，只能是分布 `(2, 2, 1)`——即三个类都非空。
  从**三个不同的类**各取 1 个数，它们的余数分别是 0, 1, 2，和 `≡ 0 + 1 + 2 = 3 ≡ 0 (mod 3)` ✓

两种情形都成立，故命题成立 ✓ ∎

**例 9.8**（题型：多项式系数）
(1) 展开 `(a + 2b)⁴`。
(2) 求 `(x + y + z)⁵` 展开式中 `x²y²z` 的系数。
(3) 把 8 个不同的礼物分给 3 个人，分别得 3, 3, 2 件，有多少种分法？
**解**：
(1) `(a+2b)⁴ = Σ_{k=0}^{4} C(4,k) a^(4−k) (2b)^k`
- k=0: `C(4,0)a⁴ = a⁴`
- k=1: `C(4,1)a³(2b) = 8a³b`
- k=2: `C(4,2)a²(4b²) = 6 × 4 a²b² = 24a²b²`
- k=3: `C(4,3)a(8b³) = 4 × 8 ab³ = 32ab³`
- k=4: `C(4,4)(16b⁴) = 16b⁴`

**答案**：`a⁴ + 8a³b + 24a²b² + 32ab³ + 16b⁴`
（验证：令 `a = b = 1`：左边 `3⁴ = 81`；右边 `1 + 8 + 24 + 32 + 16 = 81` ✓）
(2) 多项式的项由次数组 `(n₁, n₂, n₃)` 决定。要出现 `x²y²z`，需 `n₁ = 2, n₂ = 2, n₃ = 1`，和 `= 5` ✓ 合法。
系数 `= 5! / (2! · 2! · 1!) = 120 / 4 = 30` ✓
(3) 多项式系数：`8! / (3! · 3! · 2!) = 40320 / (6 × 6 × 2) = 40320 / 72 = 560` ✓
**答案**：(1) 见上；(2) 30；(3) 560。

## 易错点提醒

1. **分类不互斥导致重复计数**。错：求「能被 2 或 3 整除的两位数个数」时算成 `45 + 30 = 75`（45 个偶数、30 个 3 的倍数，但 6 的倍数被算两次）。正确：`45 + 30 − 15 = 60`（**容斥原理**，见第 04、10 章）。
2. **分步不独立导致答案错误**。错：「从 5 人中选 3 人排成一排」算成 `5 × 5 × 5`。正确：选过的人不能再选，`5 × 4 × 3 = 60 = P(5,3)`。
3. **排列与组合搞混**。错：「选出 3 人组成小组」用 `P(n,3)`。正确：小组不分顺序，用 `C(n,3)`。**判断法：把任意两人的位置互换，方案变了吗？变了用排列，没变用组合。**
4. **「至少」问题忘记用间接法**。错：「至少 1 名女生」时逐项分类，算漏了。正确：`总数 − 全是男生` 更快且不易漏。
5. **圆排列忘记除以 n**。错：5 人围圆桌坐有 `5! = 120` 种。正确：`(5−1)! = 24` 种（旋转视为相同）。
6. **多重集排列忘记除以重复元素的阶乘**。错：`BANANA` 的排列数算成 `6! = 720`。正确：`6!/(3!·2!) = 60`。
7. **隔板法公式用错方向**。错：`k` 种元素取 `r` 个算成 `C(k+r−1, k)`。正确：`C(k+r−1, r)` **或** `C(k+r−1, k−1)`，两者相等。**关键是「隔板数 = 种类数 − 1」**。
8. **正整数解与非负整数解混淆**。错：`x₁+x₂+x₃ = 15` 的非负解算成 `C(14,2)`。正确：**非负解 `C(15+3−1, 3−1) = C(17,2) = 136`；正整数解才是 `C(14,2) = 91`**。
9. **二项式定理中符号搞错**。错：`(3x − 2)⁷` 的 `x⁴` 系数算成正数。正确：`(−2)³ = −8`，负号不能丢。**看到减号要写 `(a + b)^n` 形式并让 b 带负号。**
10. **求常数项时忘记「指数为 0」**。错：`(x + 1/x)⁸` 的常数项取 `k = 0`。正确：通项指数 `8 − 2k`，令其 `= 0` 得 `k = 4`，系数 `C(8,4) = 70`。
11. **鸽巢原理用「取 n 个」而不是「`n·(k−1) + 1` 个」**。错：4 种颜色保证 5 个同色，答 5 个。正确：**最坏情况每种取 `5−1 = 4` 个都还不行，故需 `4 × 4 + 1 = 17` 个**。**通用公式：`(目标数 − 1) × 种类数 + 1`**。
12. **鸽巢原理的「巢」构造太粗糙**。错：证明「任意 5 个整数有 3 个之和能被 3 整除」时只说「至少 2 个同余」就结束。正确：还需**分类讨论**「某类 ≥ 3 个」和「三类都有」两种情况（见例 9.7(3)）。
13. **组合恒等式证明只做代数演算**。错：题目要求「用组合意义证明」时用阶乘化简。正确：必须**给两边各找一个数同一件事的方式**（双计数法）。
14. **非降路径的「经过某点」直接相加而不是相乘**。错：`(0,0)→(2,2)→(5,4)` 的路径数算成 `6 + 10 = 16`。正确：**分段必须相乘**（乘法法则），`6 × 10 = 60`。**「不经过」才用减法**。

## 本章小结

1. **加法法则**（分类相加，类间**互斥**）／**乘法法则**（分步相乘，步间**独立**）。
2. **排列 `P(n,r) = n!/(n−r)!`**（有序）／**组合 `C(n,r) = n!/(r!(n−r)!)`**（无序）；`P = C · r!`。
3. **圆排列 `(n−1)!`**；**多重集全排列 `n!/(n₁!…nₖ!)`**；**可重排列 `n^r`**；**可重组合 `C(n+r−1, r)`**。
4. **四种计数模型**：有序不重 `P(n,r)`、无序不重 `C(n,r)`、有序可重 `n^r`、无序可重 `C(n+r−1, r)`。
5. **二项式定理** `(a+b)^n = Σ C(n,k)a^(n−k)b^k`；求特定项要解「指数 = 目标次数」的方程。
6. **帕斯卡恒等式 `C(n,k) = C(n−1,k) + C(n−1,k−1)`**；**`ΣC(n,k) = 2ⁿ`**；**范德蒙德 `C(m+n,r) = Σ C(m,k)C(n,r−k)`**。
7. **组合证明法（双计数）**：给等式两边各找一种「数同一件事」的方法。
8. **非降路径**：`(0,0) → (m,n)` 有 `C(m+n, m)` 条；「经过某点」用**分段相乘**，「不经过」用**总数相减**。
9. **多项式定理**：`C(n; n₁,…,nₜ) = n!/(n₁!…nₜ!)`；展开式有 `C(n+t−1, t−1)` 项。
10. **鸽巢原理**：`n` 个物体放 `k` 个盒子，至少一个盒子有 `⌈n/k⌉` 个。**保证「有 m 个同类」需 `k(m−1) + 1` 个物体**。

> **一句话记住本章**：**「或者」用加法，「先…再…」用乘法；有序用排列、无序用组合；有重复就除以重复的阶乘；「至少」用补集；`n` 个东西塞进 `k` 个抽屉，总有一个抽屉挤了 `⌈n/k⌉` 个。**
