1. 能判断一个对象的全体是否构成集合（确定性、互异性）。

3. 能准确区分 `∈` 与 `⊆`、`∅` 与 `{∅}`、`⊂` 与 `⊆`。

7. 能默写包含排斥原理的两集合与三集合形式，并解决实际计数问题。

## 4.1 集合的概念和表示法

### 4.1.1 集合的定义与性质

**定义 4.1（集合）**：**集合（Set）是把一些确定的、彼此可以区分的对象汇成的整体**，这些对象称为该集合的**元素（Element）**。若 a 是 A 的元素，记 `a ∈ A`；否则记 `a ∉ A`。

**集合的三条基本性质**：

| 性质 | 含义 | 反例 |
|---|---|---|
| **确定性** | 任一对象要么属于、要么不属于，无中间态 | 「班上个子高的同学」不构成集合（「高」无标准） |
| **互异性** | 元素彼此不同，重复写只算一个 | `{1, 1, 2} = {1, 2}` |
| **无序性** | 元素无先后次序 | `{1, 2, 3} = {3, 1, 2}` |

> **生活类比**：集合像一个「袋子」。袋子里装着什么，就是元素；袋子本身不是袋子里的东西。袋子上没有标签顺序，也不允许两个一模一样的东西同时在里面。

**常用数集记号（必须记住）**：

| 记号 | 名称 | 说明 |
|---|---|---|
| `N` | 自然数集 | 本书中 `N = {0, 1, 2, 3, …}`（有的书从 1 开始，看教材约定） |
| `N*` 或 `N₊` | 正整数集 | `{1, 2, 3, …}` |
| `Z` | 整数集 | `{…, −2, −1, 0, 1, 2, …}` |
| `Q` | 有理数集 | 可写成分数 p/q（p、q 为整数，q ≠ 0） |
| `R` | 实数集 | |
| `C` | 复数集 | |

### 4.1.2 集合的表示法

| 方法 | 形式 | 例 | 优缺点 |
|---|---|---|---|
| **列举法** | 元素一一列出 | `A = {1, 2, 3, 4}`；`B = {2, 4, 6, …}` | 直观；元素多时不便 |
| **描述法** | `{x \| P(x)}` | `C = {x \| x ∈ Z 且 x² < 10}` | 通用；有时不直观 |
| **文氏图** | 用圆表示集合 | 见下方 ASCII 图 | 直观展示关系；不能精确计算 |

**文氏图（Venn Diagram）示意**：

```
      ┌───────────────── U ─────────────────┐
      │        ┌─────── A ───────┐           │
      │        │   ┌─── B ───┐   │           │
      │        │   │  A∩B    │   │           │
      │        │   └─────────┘   │           │
      │        └─────────────────┘           │
      │           ～A（A 外面、U 里面）        │
      └──────────────────────────────────────┘
```

> **描述法一定要写清楚「在哪个范围内取」**。`{x | x² < 10}` 在 `Z` 上和 `R` 上完全不同：前者是 `{−3, −2, −1, 0, 1, 2, 3}`，后者是开区间 `(−√10, √10)`。

**描述法的等价写法**：`{x | P(x)}` 中竖线也可写成冒号，即 `{x : P(x)}`。

### 4.1.3 特殊集合

**定义 4.2（空集）**：不含任何元素的集合称为**空集（Empty Set）**，记 `∅`。
**注意**：`∅` 只有一种，任何「什么都没有」的集合都是它。

**定义 4.3（全集）**：在所讨论的问题中，包含一切讨论对象的集合称为**全集（Universal Set）**，记 `U` 或 `E`。
**注意**：全集是**相对的**，随讨论范围变化。讨论「本班同学」时 `U` 就是本班全体。

**定义 4.4（幂集）**：集合 A 的所有子集构成的集合称为 A 的**幂集（Power Set）**，记 `P(A)` 或 `2^A`：
`P(A) = {X | X ⊆ A}`

**定理 4.1**：若 `|A| = n`（有限集），则 `|P(A)| = 2ⁿ`。
**证明思路**：A 的每个子集由「对每个元素做一次选/不选的决定」唯一确定。n 个元素各 2 种选择，由乘法原理共 `2ⁿ` 种子集。∎

**例**：
- `P(∅) = {∅}`，`|P(∅)| = 2⁰ = 1`。
- `P({a}) = {∅, {a}}`，`|P({a})| = 2¹ = 2`。
- `P({a, b}) = {∅, {a}, {b}, {a, b}}`，`|P({a,b})| = 2² = 4`。
- `P({a, b, c})` 共 8 个元素（见第 01 章例 1.1）。

> **重点**：`P(∅) = {∅} ≠ ∅`。前者的元素个数是 1，后者是 0。

## 4.2 集合之间的关系

### 4.2.1 包含与相等

**定义 4.5（子集）**：`A ⊆ B ⟺ ∀x (x ∈ A → x ∈ B)`。称 A 是 B 的**子集（Subset）**，B 包含 A。

**定义 4.6（真子集）**：`A ⊂ B ⟺ A ⊆ B 且 A ≠ B`。

**定义 4.7（相等）**：`A = B ⟺ A ⊆ B 且 B ⊆ A`。

**包含关系的三条性质**：

| 性质 | 内容 |
|---|---|
| 自反性 | `A ⊆ A` |
| 反对称性 | 若 `A ⊆ B` 且 `B ⊆ A`，则 `A = B` |
| 传递性 | 若 `A ⊆ B` 且 `B ⊆ C`，则 `A ⊆ C` |

> **重点**：这条「反对称性」就是证明集合相等的**唯一标准方法**——**元素法（双向包含）**。

**元素法证明模板**：
```
要证 A = B：
  ① 任取 x ∈ A，…（推导）…，故 x ∈ B，得 A ⊆ B。
  ② 任取 x ∈ B，…（推导）…，故 x ∈ A，得 B ⊆ A。
  ③ 由①②，A = B。∎
```

**三个必记的特殊事实**：
1. `∅ ⊆ A`（对任意 A 成立）。
2. `A ⊆ A`（对任意 A 成立）。
3. `∅ ∈ P(A)` 且 `A ∈ P(A)`（对任意 A 成立）。

### 4.2.2 幂集的进一步性质

**定理 4.2**：若 `A ⊆ B`，则 `P(A) ⊆ P(B)`。
**证明**：任取 `X ∈ P(A)`，由定义 `X ⊆ A`。又 `A ⊆ B`，由传递性 `X ⊆ B`，故 `X ∈ P(B)`。所以 `P(A) ⊆ P(B)`。∎

**定理 4.3**：`A = B ⟺ P(A) = P(B)`。
**证明**：
（⇒）若 `A = B`，则显然 `P(A) = P(B)`。
（⇐）若 `P(A) = P(B)`，因 `A ∈ P(A) = P(B)`，故 `A ⊆ B`；同理 `B ∈ P(B) = P(A)`，故 `B ⊆ A`。于是 `A = B`。∎

## 4.3 集合的运算

### 4.3.1 五种基本运算

**定义 4.8**：设 A、B 为集合，全集为 U。

| 运算 | 名称 | 定义 | 文氏图区域 |
|---|---|---|---|
| `A ∪ B` | 并集 | `{x \| x ∈ A ∨ x ∈ B}` | A、B 覆盖的全部 |
| `A ∩ B` | 交集 | `{x \| x ∈ A ∧ x ∈ B}` | A、B 重叠部分 |
| `A − B` | 差集 | `{x \| x ∈ A ∧ x ∉ B}` | A 中不含 B 的部分 |
| `～A`（`A'`、`Ā`） | 补集 | `U − A = {x \| x ∈ U ∧ x ∉ A}` | U 中 A 的外面 |
| `A ⊕ B` | 对称差 | `(A − B) ∪ (B − A)` | A、B 各自独有的部分 |

**相容与不相容**：
- 若 `A ∩ B = ∅`，称 A 与 B **不相交（Disjoint）** 或**互斥**。
- 若 `A ∩ B ≠ ∅`，称 A 与 B **相交**。

**对称差的等价定义（两种写法都要会）**：
- `A ⊕ B = (A − B) ∪ (B − A)`
- `A ⊕ B = (A ∪ B) − (A ∩ B)`
- `A ⊕ B = (A ∩ ～B) ∪ (～A ∩ B)`

### 4.3.2 集合运算的基本恒等式

**十条必背恒等式**（设 U 为全集）：

| 组 | 名称 | 恒等式 |
|---|---|---|
| 1 | 幂等律 | `A ∪ A = A`；`A ∩ A = A` |
| 2 | 交换律 | `A ∪ B = B ∪ A`；`A ∩ B = B ∩ A`；`A ⊕ B = B ⊕ A` |
| 3 | 结合律 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)`；`(A ∩ B) ∩ C = A ∩ (B ∩ C)`；`(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)` |
| 4 | 分配律 | `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`；`A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`；`A ∩ (B ⊕ C) = (A ∩ B) ⊕ (A ∩ C)` |
| 5 | 德摩根律 | `～(A ∪ B) = ～A ∩ ～B`；`～(A ∩ B) = ～A ∪ ～B` |
| 6 | 吸收律 | `A ∪ (A ∩ B) = A`；`A ∩ (A ∪ B) = A` |
| 7 | 同一律 | `A ∪ ∅ = A`；`A ∩ U = A` |
| 8 | 零律 | `A ∪ U = U`；`A ∩ ∅ = ∅` |
| 9 | 排中律 / 矛盾律 | `A ∪ ～A = U`；`A ∩ ～A = ∅` |
| 10 | 双重否定 | `～～A = A` |

**补充恒等式**（做题常遇到）：

| 恒等式 | 说明 |
|---|---|
| `A − B = A ∩ ～B` | **差集化成交**（化简第一招） |
| `A − B = A − (A ∩ B)` | |
| `A − (B ∪ C) = (A − B) ∩ (A − C)` | 差对并无分配 |
| `A − (B ∩ C) = (A − B) ∪ (A − C)` | 差对交有分配 |
| `～(A − B) = ～A ∪ B` | |
| `A ⊕ A = ∅` | 对称差自消 |
| `A ⊕ ∅ = A` | ∅ 是对称差的单位元 |
| `A ⊕ U = ～A` | |
| `A ⊆ B ⟺ A ∪ B = B ⟺ A ∩ B = A ⟺ A − B = ∅ ⟺ ～B ⊆ ～A` | **包含关系的五种等价刻画**（超高频） |

> **重点**：最后一条「**包含关系的五种等价刻画**」必须背。考试经常给你一个「证明 `A ⊆ B`」的题，最省力的做法是先换成 `A ∪ B = B` 或 `A − B = ∅`，再用恒等式演算。

### 4.3.3 集合恒等式的两种证明方法

**方法一：元素法（双向包含）**

**例**：证明 `A − (B ∪ C) = (A − B) ∩ (A − C)`。
**证明**：
① 任取 `x ∈ A − (B∪C)`。则 `x ∈ A` 且 `x ∉ B∪C`。
`x ∉ B∪C` 意味着 `x ∉ B` **且** `x ∉ C`（否定「或」得「且」）。
于是 `x ∈ A − B` 且 `x ∈ A − C`，故 `x ∈ (A−B) ∩ (A−C)`。得 `A − (B∪C) ⊆ (A−B) ∩ (A−C)`。
② 任取 `x ∈ (A−B) ∩ (A−C)`。则 `x ∈ A−B` 且 `x ∈ A−C`。
即 `x ∈ A`、`x ∉ B`、`x ∉ C`。故 `x ∉ B∪C`，所以 `x ∈ A − (B∪C)`。得反向包含。
③ 由①②，等式成立。∎

**方法二：恒等式演算（等式变换）**

**例**：同上题。
**证明**：
```
左边 = A ∩ ～(B ∪ C)            差集化成交
      = A ∩ (～B ∩ ～C)         德摩根律
      = (A ∩ A) ∩ (～B ∩ ～C)   幂等律（拆出两个 A）
      = (A ∩ ～B) ∩ (A ∩ ～C)   交换结合律
      = (A − B) ∩ (A − C)       交化回差
      = 右边 ✓
```
∎

**两种方法对比**：

| 对比项 | 元素法 | 恒等式演算 |
|---|---|---|
| 优点 | 万能，不会做错 | 简短，思路清晰 |
| 缺点 | 啰嗦 | 需要熟练背恒等式，有时不知往哪变 |
| 适用 | 考试稳妥首选 | 恒等式明显时 |
| 关键动作 | 「任取 x ∈ 左」和「任取 x ∈ 右」 | 差化交 → 德摩根 → 分配 → 收回 |

> **重点**：`A ∩ ～B` 这种「半差半交」的中间形态要学会**拆 A**：`A = A ∩ A`，然后分配到两边，再各自收成差。这是恒等式演算的核心技巧。

**方法三：文氏图验证**（只用于快速判断，不能作为证明）
画图看两个表达式覆盖的区域是否一致。考试中可用于**检验答案**，但不能代替证明。

### 4.3.4 集合运算与逻辑运算的对应

| 集合 | 逻辑 | 集合 | 逻辑 |
|---|---|---|---|
| `∪` | `∨` | `U` | `1`（真） |
| `∩` | `∧` | `∅` | `0`（假） |
| `～` | `¬` | `⊆` | `→` |
| `⊕` | 异或 | `=` | `↔` |

> **重点**：集合代数与命题逻辑代数是**同一套布尔代数**（见第 14 章）。德摩根律在两个体系里是同一个定律，只是符号不同。

## 4.4 包含排斥原理（容斥原理）

**定理 4.4（两集合的容斥原理）**：
`|A ∪ B| = |A| + |B| − |A ∩ B|`

**为什么减掉 `|A ∩ B|`**：`|A| + |B|` 把重叠部分数了**两次**，所以减一次。

**定理 4.5（三集合的容斥原理）**：
`|A ∪ B ∪ C| = |A| + |B| + |C| − |A∩B| − |A∩C| − |B∩C| + |A∩B∩C|`

**记忆口诀：奇加偶减**——单个的加，两两交的减，三三交的加。

**为什么最后要加回三交集**：`|A∩B∩C|` 在三个单集里被加了 3 次，在三个两两交里被减了 3 次，净剩 0 次。要让它算 1 次，必须再加 1 次。

**定理 4.6（n 集合的容斥原理）**：
`|A₁ ∪ A₂ ∪ … ∪ Aₙ| = ∑|Aᵢ| − ∑|Aᵢ∩Aⱼ| + ∑|Aᵢ∩Aⱼ∩Aₖ| − … + (−1)^(n+1)|A₁∩…∩Aₙ|`

**推论（都不在的数量）**：
`|～A₁ ∩ ～A₂ ∩ … ∩ ～Aₙ| = |U| − |A₁ ∪ … ∪ Aₙ|`

> **重点**：容斥原理也用于求「至少满足一个条件」的数量。当题目出现「至少」「都不」「恰好」这些字眼时，优先考虑容斥。

## 典型例题

**例 4.1**（题型：集合表示与元素判定）
设 `A = {x | x ∈ Z 且 −3 ≤ x < 4}`，`B = {x | x ∈ N 且 x² ≤ 16}`。求 `A`、`B`、`A ∩ B`、`A − B`、`|P(A − B)|`。
**解**：
① `A`：整数且在 `[−3, 4)` 内 → `A = {−3, −2, −1, 0, 1, 2, 3}`，`|A| = 7`。
② `B`：自然数且 `x² ≤ 16`，即 `x ≤ 4` → `B = {0, 1, 2, 3, 4}`，`|B| = 5`。
**为什么 B 的元素最多到 4**：因为 `5² = 25 > 16`，且 `x ∈ N`，所以 `x ≤ 4`。
③ `A ∩ B = {0, 1, 2, 3}`，`|A ∩ B| = 4`。
④ `A − B = {−3, −2, −1}`，`|A − B| = 3`。
⑤ `|P(A − B)| = 2³ = 8`。
**答案**：`A ∩ B = {0,1,2,3}`；`A − B = {−3,−2,−1}`；`|P(A−B)| = 8`。

**例 4.2**（题型：元素法证明集合恒等式）
证明 `A ∪ (B − A) = A ∪ B`。
**证明**（元素法）：
① 先证 `A ∪ (B − A) ⊆ A ∪ B`。
任取 `x ∈ A ∪ (B−A)`，则 `x ∈ A` **或** `x ∈ B−A`。
- 若 `x ∈ A`，则 `x ∈ A ∪ B`；
- 若 `x ∈ B − A`，则 `x ∈ B`（且 `x ∉ A`），仍有 `x ∈ A ∪ B`。
两种情形都得 `x ∈ A ∪ B`，故 `A ∪ (B−A) ⊆ A ∪ B`。
② 再证 `A ∪ B ⊆ A ∪ (B − A)`。
任取 `x ∈ A ∪ B`，则 `x ∈ A` 或 `x ∈ B`。
- 若 `x ∈ A`，则 `x ∈ A ∪ (B−A)`；
- 若 `x ∉ A`，则由 `x ∈ A ∪ B` 知 `x ∈ B`，故 `x ∈ B − A ⊆ A ∪ (B−A)`。
两种情形都得结论，故 `A ∪ B ⊆ A ∪ (B−A)`。
③ 由①②，等式成立。∎
> **为什么分两种情形**：第②步中 `x ∈ B−A` 的定义要求 `x ∉ A`，所以在「x ∈ B」的情形下必须再分「x ∈ A」和「x ∉ A」，否则无法断定 x 属于 B−A。

**例 4.3**（题型：恒等式演算）
用恒等式演算证明 `(A − B) − C = A − (B ∪ C)`。
**证明**：
```
左边 = (A ∩ ～B) ∩ ～C             差化交（两次）
      = A ∩ ～B ∩ ～C              结合律
      = A ∩ ～(B ∪ C)             德摩根律（反向用）
      = A − (B ∪ C)               交化回差
      = 右边 ✓
```
∎

**例 4.4**（题型：容斥原理应用 —— 两集合）
某班级 45 人，其中 28 人会游泳，20 人会骑自行车，12 人两样都会。求：
(1) 至少会一样的人数；(2) 两样都不会的人数；(3) 只会游泳的人数。
**解**：
设 `S` = 会游泳，`B` = 会骑自行车，`|U| = 45`，`|S| = 28`，`|B| = 20`，`|S ∩ B| = 12`。
(1) 由容斥原理：`|S ∪ B| = 28 + 20 − 12 = 36`。
(2) 两样都不会：`|U| − |S ∪ B| = 45 − 36 = 9`。
(3) 只会游泳：`|S| − |S ∩ B| = 28 − 12 = 16`。
**答案**：(1) 36 人；(2) 9 人；(3) 16 人。

**例 4.5**（题型：容斥原理应用 —— 三集合）
某调查 100 人，喜欢苹果（A）的有 60 人，喜欢香蕉（B）的有 45 人，喜欢橘子（C）的有 40 人；同时喜欢 A、B 的 25 人，同时喜欢 A、C 的 20 人，同时喜欢 B、C 的 15 人；三种都喜欢的 10 人。求：
(1) 至少喜欢一种的人数；(2) 只喜欢苹果的人数；(3) 一种都不喜欢的人数。
**解**：
(1) `|A∪B∪C| = 60 + 45 + 40 − 25 − 20 − 15 + 10 = 95`。
计算过程：`60+45+40 = 145`；`−25−20−15 = −60`，得 `85`；`+10` 得 `95`。
(2) 只喜欢 A：`|A| − |A∩B| − |A∩C| + |A∩B∩C| = 60 − 25 − 20 + 10 = 25`。
**为什么最后要加回三交集**：`|A∩B| + |A∩C|` 把「三种都喜欢」的那 10 个人减了两次，但实际上它只该减一次（因为要算「只在 A 里」），所以要加回一次。
(3) 一种都不喜欢：`100 − 95 = 5`。
**答案**：(1) 95 人；(2) 25 人；(3) 5 人。

**例 4.6**（题型：幂集元素计数）
设 `|A| = 3`，`|B| = 4`，`|A ∩ B| = 1`。求 `|P(A ∪ B)|`。
**解**：
① 先求 `|A ∪ B|`：`|A ∪ B| = 3 + 4 − 1 = 6`。
② `|P(A ∪ B)| = 2⁶ = 64`。
**答案**：64。
> **注意**：这里千万不能写成 `2³ · 2⁴ = 128`——那是 `|P(A) × P(B)|`（笛卡儿积），不是 `|P(A∪B)|`。

**例 4.7**（题型：包含关系等价刻画的应用）
已知 `A ⊆ B`，证明 `P(A) ⊆ P(B)`，并判断反之是否成立。
**证明**：
① 任取 `X ∈ P(A)`。由幂集定义 `X ⊆ A`。又已知 `A ⊆ B`，由包含的传递性得 `X ⊆ B`，故 `X ∈ P(B)`。所以 `P(A) ⊆ P(B)` ✓。
② 反之**也成立**：设 `P(A) ⊆ P(B)`。因 `A ∈ P(A)`，故 `A ∈ P(B)`，即 `A ⊆ B`。
**答案**：`A ⊆ B ⟺ P(A) ⊆ P(B)`，两者等价。

**例 4.8**（题型：集合运算综合 + 元素法）
证明 `A ⊕ B = (A ∪ B) − (A ∩ B)`。
**证明**（用恒等式演算）：
```
右边 = (A ∪ B) ∩ ～(A ∩ B)         差化交
      = (A ∪ B) ∩ (～A ∪ ～B)      德摩根律
      = [(A ∪ B) ∩ ～A] ∪ [(A ∪ B) ∩ ～B]   分配律
      = [(A ∩ ～A) ∪ (B ∩ ～A)] ∪ [(A ∩ ～B) ∪ (B ∩ ～B)]   再分配
      = [∅ ∪ (B ∩ ～A)] ∪ [(A ∩ ～B) ∪ ∅]    矛盾律
      = (B ∩ ～A) ∪ (A ∩ ～B)      同一律
      = (B − A) ∪ (A − B)         交化回差
      = (A − B) ∪ (B − A)         交换律
      = 左边 ✓
```
∎

## 易错点提醒

1. **`∈` 与 `⊆` 混用**。错：`{1, 2} ∈ {1, 2, 3}`。正确：`{1, 2} ⊆ {1, 2, 3}` 成立；`{1, 2} ∈ {1, 2, 3}` **不成立**（{1,2,3} 的元素是数字不是集合）。除非写成 `{1,2} ∈ {{1,2}, 3}`。
2. **`∅` 与 `{∅}` 混淆**。错：`P(∅) = ∅`。正确：`P(∅) = {∅}`，元素个数为 1。`∅` 的元素个数是 0。
3. **`⊂` 理解成「包含于」**。错：认为 `A ⊂ A` 成立。正确：`⊂` 是**真包含**，`A ⊂ A` **不成立**；允许相等要写 `⊆`。
4. **幂集基数公式记错**。错：`|A| = 3` 时写 `|P(A)| = 3²= 9`。正确：`|P(A)| = 2³ = 8`。
5. **描述法不写取值范围**。错：`{x | x² < 10}`。正确：必须写清 `{x | x ∈ Z 且 x² < 10}` 或 `{x | x ∈ R 且 x² < 10}`。
6. **德摩根律方向用反**。错：`～(A ∪ B) = ～A ∪ ～B`。正确：`～(A ∪ B) = ～A ∩ ～B`——**否定的「或」变「且」**。
7. **容斥原理漏项**。错：三集合时只写 `|A|+|B|+|C| − |A∩B|−|A∩C|−|B∩C|`，漏掉 `+ |A∩B∩C|`。正确：**奇加偶减**，三项交集必须**加**回来。
8. **用容斥求「都不」时忘了作差**。错：直接答 `|A∪B∪C|`。正确：「都不在」= `|U| − |A∪B∪C|`。
9. **差集 `A − B` 当成可交换**。错：`A − B = B − A`。正确：差集**不可交换**。`{1,2} − {2,3} = {1}`，`{2,3} − {1,2} = {3}`。
10. **`A ∩ ～B` 化简时忘了拆 A**。错：卡在 `A ∩ ～B` 不动。正确：技巧是「`A = A ∩ A`」拆开后分配到两边，再各自收成差。
11. **文氏图当证明**。错：只在试卷上画个图就说「证毕」。正确：文氏图只能用于**验证**，证明必须用元素法或恒等式演算。

## 本章小结

1. 集合三性质：**确定性、互异性、无序性**；`{1,1,2} = {1,2}`。
2. `∈` 连元素与集合，`⊆` 连集合与集合；`⊂` 是真包含。
3. `∅` 是任意集合的子集；`∅ ≠ {∅}`；`P(∅) = {∅}`。
4. `|P(A)| = 2^|A|`；`A ⊆ B ⟺ P(A) ⊆ P(B)`。
5. `A = B ⟺ A ⊆ B 且 B ⊆ A` —— **元素法**的依据，证明集合恒等式的标准方法。
6. 五种运算：`∪ ∩ − ～ ⊕`；对称差 `A ⊕ B = (A−B) ∪ (B−A) = (A∪B) − (A∩B)`。
7. 十条恒等式；**`A − B = A ∩ ～B` 是化简第一招**。
8. 恒等式演算核心技巧：**差化交 → 德摩根 → 拆 A（A = A∩A）→ 分配 → 收回**。
9. 包含关系的五种等价刻画：`A ⊆ B ⟺ A∪B = B ⟺ A∩B = A ⟺ A−B = ∅ ⟺ ～B ⊆ ～A`。
10. 容斥原理：两集合 `|A∪B| = |A|+|B|−|A∩B|`；三集合**奇加偶减**；「都不在」= `|U| − |A∪B∪C|`。

> **一句话记住本章**：**集合就是一个袋子，`∈` 是「在袋里」、`⊆` 是「袋子套袋子」；证两个袋子一样，就两边各捞一个元素看看是不是都在对方袋里（元素法）。**
