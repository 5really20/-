# 离散数学 · 课程总览与索引

> **一句话定位**：离散数学是把「数据结构、算法、数据库、编译原理、计算机网络」里那些说不清的道理，用集合、关系、图、代数这几把尺子量清楚的一门课——它是计算机专业的「数学地基」。

---

### 三套体系的结构差异（对笔记时最容易混的四点）

## 五、考试重点分布（按 48 学时、100 分卷估算）

| 板块 | 章 | 预估分值 | 常见题型 |
|---|---|---|---|

| 集合与关系 | 01、04、05、06 | **20~25 分** | 关系性质判定；求闭包；等价类与划分；哈斯图；证明双射；可数性证明 |
| 图论与树 | 07、08 | **20~25 分** | 握手定理计算；欧拉/哈密顿判定；平面图欧拉公式；最小生成树；哈夫曼编码 |

```
      ↓

      ↓
第13章 代数系统 → 第14章 格与布尔代数   ← 依赖关系的「等价关系（陪集划分）」
      ↓
第11章 初等数论、第12章 离散概率      ← 相对独立，可穿插或最后突击
```

### 三条实用建议

1. **第 05 章「关系的五种性质」是全书最重要的单一知识点**。近几年期末卷至少 8 分直接考它；而且集合的等价关系、图的连通性、群的陪集划分都是它的应用。判定表必须背到条件反射。
2. **每天做 2 道证明题，不要只读不写**。离散数学的证明题（形式证明、集合恒等式、可数性、拉格朗日定理）不写一遍就永远不会。看懂 ≠ 会写。
3. **与后续课程的交叉点**：学第 07 章时同步看数据结构的「图的存储与遍历、拓扑排序、关键路径」；学第 08 章时同步看「堆与哈夫曼压缩」；学第 13 章时看「哈希与模运算」；学第 11 章时看「RSA 加密」。

## 八、符号约定（全书统一）

| 符号 | 含义 | 备注 |
|---|---|---|
| ¬P、P∧Q、P∨Q、P→Q、P↔Q | 否定、合取、析取、蕴含、等价 | 其中 → 的有关约定见第 02 章 |
| ∀x、∃x | 全称量词、存在量词 | 量词否定用 ¬∀x ≡ ∃x¬ |
| ∈、∉、⊆、⊂、⊇ | 属于、不属于、包含于、真包含于、包含 | ⊂ 在本书中表示**真包含** |
| ∪、∩、−、～、⊕ | 并、交、差、补、对称差 | 对称差也叫「环和」 |
| P(A)、2^A | 幂集 | 两个记号通用 |
| A×B | 笛卡儿积 | \|A×B\| = \|A\|·\|B\| |
| R∘S、R⁻¹、r(R)、s(R)、t(R) | 复合、逆、自反闭包、对称闭包、传递闭包 | 复合顺序按「右先左后」 |
| ⌊x⌋、⌈x⌉ | 下取整、上取整 | |
| n!、C(n,k)、P(n,k) | 阶乘、组合数、排列数 | C(n,k) 也写 (n k) |
| a ≡ b (mod m) | 同余 | |
| (G, *) | 代数系统 | * 是 G 上的二元运算 |
| a ∨ b、a ∧ b | 格的并、交 | 也叫上确界、下确界 |
| ≼ | 偏序关系 | |

> **一句话记住本课程**：**离散数学就是用「集合装对象、关系连对象、图论画对象、代数算对象」这四招，把计算机里离散的结构讲成可以证明、可以计算的数学。**
