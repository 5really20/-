## 2.1 放大的概念和放大电路的主要性能指标

### 2.1.1 放大的概念

**放大的本质是「用小能量控制大能量」：用微弱的输入信号控制直流电源提供的能量，使输出端得到与输入波形相同但幅度大得多的信号。**

```text
         ┌──────────────┐
         │  放大电路     │
 u_i ───→│  （控制阀门）  │───→ u_o（幅度大、波形相同）
 (小信号) │       ↑       │
         └───────┼───────┘
                 │
             V_CC 直流电源 ← 能量的真正来源
```

三个必须同时满足的条件，缺一不可：

1. **有直流电源 V_CC 供能**——能量只能来自电源，不能来自信号。
2. **有控制元件**（三极管、场效应管）——把电源能量按输入信号的规律「配给」输出。
3. **输出波形的变化规律与输入一致**，只是幅度变大（可以有相位反转，但不能变形）。

> **为什么必须有直流电源？** 输入信号 $u_i$ 只有毫伏级，它自己携带的能量根本不足以驱动负载。放大电路的真正作用是：让 $u_i$ 去控制一个「大水库」（V_CC）的闸门开度，负载得到的是水库放出的水。

### 2.1.2 放大电路的性能指标

**四个核心指标：电压增益 A_u、输入电阻 R_i、输出电阻 R_o、通频带 BW。**

```text
   信号源            放大电路                  负载
  ┌──────┐      ┌──────────────────┐      ┌──────┐
  │  U_s │──R_s─┤R_i    A_u    R_o ├──────┤ R_L  │
  └──────┘      └──────────────────┘      └──────┘
       u_i = U_s·R_i/(R_s+R_i)      u_o = A_u·u_i·R_L/(R_o+R_L)
```

| 指标 | 定义 | 对电压放大的要求 | 为什么 |
|---|---|---|---|
| 电压增益 A_u | $A_u = U_o/U_i$ | 越大越好 | 直接决定输出幅度 |
| 输入电阻 R_i | 从输入端看进去的等效电阻 | **越大越好** | 分压损失小，从信号源索取电流少 |
| 输出电阻 R_o | 从输出端看进去的等效电阻 | **越小越好** | 带负载能力强，输出电压稳定 |
| 通频带 BW | $BW = f_H - f_L$ | 越宽越好 | 能放大的频率范围大 |

**增益的分贝表示**：$A_u(\mathrm{dB}) = 20 \lg \lvert A_u \rvert$。例如 $A_u = 1000$ 对应 60 dB。

**通频带中的两个截止频率**：增益下降到中频增益的 0.707 倍（−3 dB）处的频率，低端叫 $f_L$、高端叫 $f_H$。

## 2.2 基本共射放大电路的工作原理

### 2.2.1 基本共射放大电路的组成及各元件的作用

```text
        +V_CC
          │
         ┌┴┐ R_b（基极偏置电阻）
         └┬┘
          ├──────────┐
          │          ┌┴┐ R_c（集电极负载电阻）
       ┌──┴──┐       └┬┘
  u_i ─┤ C1  │   B   │   C   ├──── C2 ──── u_o
       └──┬──┘  ┌────┴────┐  │
          │   ──┤   VT    ├──┘
          │     └────┬────┘
         ─┴─          │ E
        GND(信号源)  ─┴─ GND
```

| 元件 | 作用 | 能不能省 |
|---|---|---|
| 三极管 VT | 控制元件，实现电流放大 | 不能 |
| 直流电源 V_CC | 供能，同时通过 R_b、R_c 建立合适的 Q 点 | 不能 |
| 基极偏置电阻 R_b | 提供合适的 $I_{BQ}$，使发射结正偏 | 不能 |
| 集电极负载电阻 R_c | 把集电极**电流**的变化转换成**电压**的变化 | 不能 |
| 耦合电容 C1、C2 | 隔断直流、传递交流 | 直接耦合电路可省 |

> **R_c 的作用是本章第一个关键点**：三极管放大的是**电流**（$i_c = \beta i_b$），负载需要的是**电压**。$u_o = -i_c R_c$，靠 R_c 完成「电流→电压」的转换。没有 R_c，输出始终等于 V_CC，什么也放大不了。

### 2.2.2 设置静态工作点的必要性

**静态工作点 Q（Quiescent point）是没有输入信号时（$u_i = 0$）三极管各电极的直流电流和电压；没有它，放大波形会被削掉一半。**

```text
   有合适Q点                          无Q点(I_BQ=0)
   i_B                     i_B
    │   ╭─╮  ← 交流叠加      │   ╭─╮   ← 下半周被削掉(发射结反偏)
    │  ╱   ╲ 在直流上        │  ╱   ╲
    ├─┴─────┴── t           ├─┴─────┴── t
    I_BQ(直流分量)           0
```

原因：BJT 的发射结是**单向导电**的。若 $I_{BQ} = 0$，只有正半周信号能让发射结正偏导通，负半周则完全截止，输出波形严重失真（这叫**截止失真**）。

**结论：必须给发射结预置一个直流偏置，使交流信号的正负半周都工作在特性曲线的线性段。**

### 2.2.3 基本共射放大电路的工作原理及波形分析

**工作原理一句话：$u_i$ 的变化 → $i_B$ 变化 → $i_C = \beta i_B$ 变化 → R_c 上压降变化 → $u_{CE}$ 反向变化 → 输出交流电压。**

```text
   u_i  ───╮   ╭───      i_B ───╮   ╭───      i_C ───╮   ╭───
           ╰───╯                ╰───╯                ╰───╯
   u_o  ───╮   ╭───      ← 与 u_i 反相 180°
           ╰───╯
```

四个量的相位关系（**共射电路最重要的一条性质**）：

| 量 | 与 u_i 的相位关系 |
|---|---|
| i_B、i_C | **同相**（输入电压升高，基极电流增大） |
| u_CE、u_o | **反相 180°**（集电极电流增大，R_c 压降增大，u_CE 减小） |

推导：$u_{CE} = V_{CC} - i_C R_c$。$i_C$ 增大 → $i_C R_c$ 增大 → $u_{CE}$ 减小。所以**共射放大电路是反相放大器**（反相放大器因此得名）。

### 2.2.4 放大电路的组成原则

由「管子要工作在放大区」这个总要求，推出四条具体原则：

1. **发射结必须正偏**：用 R_b 提供合适的 $I_{BQ}$。
2. **集电结必须反偏**：集电极经 R_c 接 V_CC，只要 $U_{CEQ} > 0.3\,\mathrm{V}$ 就满足。
3. **输入回路必须能把信号送到发射结**：耦合电容要选得足够大（$1/(\omega C)$ 在信号频率下近似短路）。
4. **输出回路必须能把放大的信号送给负载**：负载电阻与 R_c 并联形成交流负载。

## 2.3 放大电路的分析方法

**这是全书最重要的方法论：任何放大电路都要算两遍——先直流（求 Q 点），后交流（求增益）。**

### 2.3.1 直流通路与交流通路

**画直流通路：电容开路、电感短路、信号源置零（保留内阻）；画交流通路：直流电源接地、耦合电容短路。**

| | 直流通路 | 交流通路 |
|---|---|---|
| 目的 | 求静态工作点（Q 点） | 求增益、输入输出电阻 |
| 耦合电容 | **开路**（隔直流） | **短路**（容抗≈0） |
| 直流电源 V_CC | 保留 | **接地**（对交流是「零电位」） |
| 信号源 u_i | 置零（短路），保留 R_s | 保留 |
| 载流子 | 直流量 I_BQ、I_CQ、U_CEQ | 交流量 u_i、i_b、i_c、u_o |

> **为什么直流电源在交流通路里要接地？** 理想的直流电压源两端电压恒定不变，对交流而言「电压变化量 = 0」，等效为一个短路。这就是「交流接地」的含义。

**经典电路的两条通路对照（分压式射极偏置电路）**：

```text
   原电路                    直流通路                  交流通路
   +V_CC                     +V_CC                    (V_CC→地)
     │                         │                         │
   ┌─┴─┐ R_b1                 ┌┴┐ R_b1                  ┌┴┐
   └─┬─┘                      └┬┘                       └┬┘
     ├──── R_c ────┬           ├── R_c ──┬                ├── R_c ──┬── u_o
     │             │           │         │                │         │
     │   VT        C2→u_o      │  VT     │                │  VT     │
     │             │           │         │                │         │
   ┌─┴─┐ R_b2      │         ┌─┴─┐       │              ┌─┴─┐       │
   └─┬─┘           │         └─┬─┘       │              └─┬─┘       │
     ├── R_e ── C_e┴           ├── R_e ──┤                ├── R_e ──┤
     │                         │         │                │  (被C_e短路)
    ─┴─ GND                   ─┴─ GND                    ─┴─ GND
   C1、C2、C_e：耦合/旁路电容，直流通路中开路、交流通路中短路
```

### 2.3.2 图解法

**图解法把「电路方程」画在同一条特性曲线上：直流负载线定 Q 点，交流负载线看动态范围，两条线的斜率分别是 $-1/R_c$ 和 $-1/(R_c \parallel R_L)$。**

**第一步：用直流通路写输出回路的方程（直流负载线方程）**

$u_{CE} = V_{CC} - i_C R_c$

这是一条直线，与横轴交于 $(V_{CC}, 0)$，与纵轴交于 $(0, V_{CC}/R_c)$，斜率为 $-1/R_c$。

**第二步：把这条直线画到输出特性曲线上，与 $i_B = I_{BQ}$ 那条曲线的交点就是 Q 点。**

```text
      i_C(mA)                       直流负载线: u_CE = V_CC − i_C·R_c
        │                           交流负载线: 过Q，斜率 −1/(R_c∥R_L)，更陡
   V_CC/R_c ┤╲
        │    ╲  直流负载线
        │     ╲
        │  Q   ╲  ← 交流负载线穿过Q点
        │  ●────╲
        │ ╱       ╲
        └─┴─────────┴──── u_CE(V)
          0        V_CC
```

**交流负载线**：交流通路中负载是 $R_{L'} = R_c \parallel R_L$（因为 V_CC 接地，R_c 与 R_L 从集电极并联到地），方程为

$u_{ce} = -i_c \cdot R_{L'}$（以 Q 点为原点的交流量形式）

所以交流负载线**必过 Q 点**，斜率 $-1/R_{L'}$。由于 $R_{L'} < R_c$，**交流负载线总比直流负载线陡**。

**最大不失真输出电压**（受两头夹击）：

$U_{om} = \min [ U_{CEQ} - U_{CES} , I_{CQ} \cdot R_{L'} ]$

其中 $U_{CES}$ 是饱和压降（约 0.3 V）。前一项是「向上」到饱和的余量，后一项是「向下」到截止的余量——**谁小谁先失真**。

**两种失真的判断**：

| 失真类型 | 成因 | NPN 管输出波形的表现 | 调整方法 |
|---|---|---|---|
| 截止失真 | Q 点**偏低**（I_BQ 太小） | 输出**顶部**被削平（$u_{CE}$ 顶部对应 i_C 的谷底） | 减小 R_b 或增大 V_CC，抬高 Q 点 |
| 饱和失真 | Q 点**偏高**（I_BQ 太大） | 输出**底部**被削平 | 增大 R_b 或减小 R_c，降低 Q 点 |

> **记忆口诀**：**「截止削顶、饱和削底」（对 NPN 共射电路）**；判断时先看输出波形哪一侧被削平，再回到 $u_{CE} = V_{CC} - i_C R_c$ 反推 Q 点高低。

### 2.3.3 等效电路法

**等效电路法把非线性器件在 Q 点附近线性化：用 h 参数（或混合 π 参数）模型代替三极管，然后按线性电路求解。**

#### （1）三极管的 h 参数微变等效模型

在小信号（交流量很小）条件下，把三极管看成线性双端口网络：

```text
      b ──┬────── r_be ──────┬── c
          │                  │
          │        ↑ i_b     │
          │      β·i_b       │
          │        ↓         │
          │                  │
          └─────── e ────────┘
      输入端口：r_be          输出端口：βi_b 受控电流源
```

**简化 h 参数模型的三个要点**：

1. **输入端口等效为一个电阻 $r_{be}$**（因为 $h_{re}$ 很小，忽略反馈影响）。
2. **输出端口等效为一个受控电流源 $\beta i_b$**（方向由 c 指向 e，即电流从集电极流向发射极）。
3. **输出电阻 $r_{ce} = 1/h_{oe}$ 视为无穷大**（忽略），因为在中频段它比 R_c 大得多。

#### （2）r_be 的完整公式与物理意义

**$r_{be} = r_{bb'} + (1 + \beta) \cdot 26\,\mathrm{mV} / I_{EQ}$**

| 符号 | 名称 | 典型值 | 物理意义 |
|---|---|---|---|
| $r_{bb'}$ | 基区体电阻 | 100~300 Ω，**默认 200 Ω** | 基区材料本身的电阻，与电流无关 |
| $(1+\beta)26\,\mathrm{mV}/I_{EQ}$ | 发射结动态电阻折算到基极的值 | 几百 Ω~几 kΩ | 发射结在 Q 点处的交流电阻 $r_{be'} = 26\,\mathrm{mV}/I_{EQ}$ 折算到基极回路要乘 (1+β) |

**两个推论**：

- $I_{EQ}$ 越大，$r_{be}$ 越小，$A_u$ 越大——但 Q 点会下移（R_c 压降增大），所以**增益与不失真输出是一对矛盾**。
- $r_{be}$ 与 β 有关，而 β 的分散性很大，所以**增益不能指望精确**，只能估算到几十个百分点以内。

> **另一个常用等价形式**：$r_{be} \approx 200\,\Omega + (1+\beta) \cdot 26\,\mathrm{mV}/I_{CQ}$（因为 $I_{EQ} \approx I_{CQ}$）。

#### （3）电压增益的完整推导

以基本共射放大电路为例，交流通路中：基极看到的电阻是 $r_{be}$，集电极看到的电阻是 $R_c \parallel R_L$。

```text
   b ──┬── r_be ──┬── c ──┬── R_c ──┬───┬─┐
       │          │       │         │   │ │ R_L
   u_i │      βi_b↓       └─────────┘  ─┴─
       └──────────┴── e ── 地 ─────────────
```

输入回路：$u_i = i_b \cdot r_{be}$
输出回路：$u_o = -\beta i_b \cdot (R_c \parallel R_L)$（负号源于电流方向：$i_c = \beta i_b$ 由 c 流向 e，在 R_L' 上产生的电压是 c 端对地为负）

两式相除：

**$A_u = u_o/u_i = -\beta (R_c \parallel R_L)/r_{be} = -\beta R_{L'}/r_{be}$**

**输入电阻**（从输入端看进去）：

- 固定偏置电路：$R_i = R_b \parallel r_{be}$
- 分压式偏置电路：$R_i = R_{b1} \parallel R_{b2} \parallel r_{be}$

**输出电阻**（把输入信号置零后，从输出端看进去）：

$R_o \approx R_c$

（因为 R_c 接的是交流地，而 $\beta i_b = 0$ 时受控电流源相当于开路。）

> **$A_u$ 公式的三条使用前提**：① 工作在放大区（Q 点合适）；② 中频段（忽略结电容）；③ 忽略 $r_{ce}$。违反任何一条，公式都要修正。

## 2.4 放大电路静态工作点的稳定

### 2.4.1 静态工作点稳定的必要性

**温度变化会使 Q 点漂移，轻则输出波形失真，重则管子烧毁。**

第 1 章已经知道三个温度效应：$U_{BE}$ 下降（−2 mV/℃）、$\beta$ 上升（+0.5%/℃）、$I_{CBO}$ 倍增（每 10 ℃）。三者**同向叠加**，使 $I_{CQ}$ 随温度显著增大。

固定偏置电路的致命伤：

$I_{BQ} = (V_{CC} - U_{BEQ})/R_B$，$I_{CQ} = \beta I_{BQ}$

温度升高时 $I_{BQ}$ 略增、$\beta$ 明显增，两者相乘使 $I_{CQ}$ 剧增，$U_{CEQ} = V_{CC} - I_{CQ} R_c$ 迅速下降 → 更容易进入饱和 → 输出严重失真。

> **根本原因**：固定偏置电路是「**恒流式偏置**」——$I_{BQ}$ 被 R_b 定死了，温度引起的变化没有任何机制去抑制它。

### 2.4.2 典型的静态工作点稳定电路

**分压式射极偏置电路（又称射极偏置电路）通过「直流负反馈」自动稳定 Q 点。**

```text
        +V_CC
          │
      ┌───┴───┐
     ┌┴┐R_b1  ┌┴┐ R_c
     └┬┘      └┬┘
      ├────────┴──── C2 ──→ u_o
      │     C   │
      │   ┌─────┴─────┐
      B ──┤    VT     ├── C
          └─────┬─────┘
             E  │
      ┌─────────┴────────┐
     ┌┴┐R_b2   R_e      ─┴─ C_e（旁路电容）
     └┬┘       │
     ─┴─ GND  ─┴─ GND
```

**两个设计前提：**

1. **$I_1 >> I_{BQ}$**（一般取 $I_1 = (5~10) I_{BQ}$）→ 基极电位 $U_{BQ}$ 只由分压电阻决定，**与 β 无关**。
2. **$U_{BQ} >> U_{BEQ}$**（一般取 $U_{BQ} = (3~5) U_{BEQ}$，即 2~4 V）→ 发射极电位 $U_{EQ} = U_{BQ} - U_{BEQ}$ 基本恒定，$I_{EQ} = U_{EQ}/R_e$ 也就基本恒定。

**静态工作点计算四步（必须背下来）：**

```text
① U_BQ  = R_b2/(R_b1 + R_b2) · V_CC
② U_EQ  = U_BQ − U_BEQ    （硅管取 0.7 V）
③ I_EQ  = U_EQ / R_e       → I_CQ ≈ I_EQ ,  I_BQ = I_EQ/(1+β)
④ U_CEQ = V_CC − I_CQ(R_c + R_e)
```

**稳定原理（负反馈的四个环节，第一次见到负反馈）：**

```text
T↑ → I_CQ↑ → U_EQ = I_EQ·R_e↑ → U_BE = U_BQ − U_EQ↓ → I_BQ↓ → I_CQ↓
     ↑                                                          │
     └──────────────── 自动拉回来 ──────────────────────────────┘
```

> **一句话总结**：**R_e 是「自动刹车」**。电流想变大，R_e 上的压降就变大，把发射结的偏置电压「挤」小，于是电流又降下来。这就是**直流负反馈**——第 5 章会看到，反馈思想其实从这一章就开始用了。

**R_e 的两个作用**：① 直流上稳定 Q 点；② 交流上如果要保留它（不接 C_e），会削弱交流增益（引入交流负反馈）。

### 2.4.3 稳定静态工作点的措施

| 措施 | 原理 | 特点 |
|---|---|---|
| 分压式射极偏置（加 R_e） | 直流负反馈，见上 | 最常用、最有效 |
| 集电极-基极偏置（R_b 接在 c 极） | 电压并联负反馈：$I_{CQ} \uparrow \to U_{CQ} \downarrow \to I_{BQ} \downarrow$ | 只用一只电阻，简单；增益略降 |
| 二极管温度补偿 | 用同材料的二极管反向抵消 U_BE 的温漂 | 补偿精度高，需工艺匹配 |
| 热敏电阻补偿 | 用负温度系数热敏电阻调整分压比 | 用于要求较高的场合 |
| 恒流源偏置 | 用电流源代替 R_e（第 3 章） | 集成运放内部的标准做法 |

## 2.5 晶体管单管放大电路的三种基本接法

**接法的命名看「交流信号的输入、输出各用哪个电极」：哪个电极是公共端，就叫共什么电路。**

### 2.5.1 基本共集放大电路（射极跟随器）

```text
        +V_CC
          │
         ┌┴┐ R_b
         └┬┘
          ├──────────────┐
          │   C          │
       ┌──┴──┐           │
  u_i ─┤  B  ├── VT      │
       └──┬──┘           │
          │ E            │
         ┌┴┐ R_e      ┌──┴──┐
         └┬┘       C2 ┤ R_L ├── u_o
         ─┴─          └──┬──┘
                       ──┴── GND
```

**输出取自发射极，故又称射极跟随器（emitter follower）：输出电压「跟随」输入电压。**

- **电压增益**：$A_u = (1+\beta)R_{L'} / [r_{be} + (1+\beta)R_{L'}] \approx 1$（略小于 1，典型 0.95~0.99），**同相**。
- **输入电阻**：$R_i = R_b \parallel [r_{be} + (1+\beta)R_{L'}]$（大，因为 R_e 被放大了 1+β 倍）
- **输出电阻**：$R_o = R_e \parallel (r_{be} + R_b \parallel R_s)/(1+\beta)$（**很小**，通常几十欧）
- **电流增益**：$A_i = 1 + \beta$（大）

> **记忆**：共集电路是「**电压增益≈1、输入电阻大、输出电阻小**」的电路，正好符合「电压放大电路的理想输入输出条件」。所以它的用途是**缓冲级**（阻抗变换），而不是放大电压。

### 2.5.2 基本共基放大电路

**输入从发射极进、输出从集电极出、基极是公共端（交流接地）。**

```text
        +V_CC
          │
         ┌┴┐ R_c
         └┬┘
          ├────── C2 ──→ u_o
  u_i ─C1─┤ E
       ┌──┤  VT
       │  └─ B ─┬─ 交流接地（经大电容或直接接地）
      ┌┴┐ R_e   │
      └┬┘      ─┴─
```

- **电压增益**：$A_u = +\beta R_{L'}/r_{be}$（**大小与共射相同，但同相**）
- **电流增益**：$A_i = \alpha \approx 1$（略小于 1）
- **输入电阻**：$R_i = R_e \parallel [r_{be}/(1+\beta)]$（**很小**，几欧到几十欧）
- **输出电阻**：$R_o \approx R_c$（较大，与共射相同）
- **突出优点：高频特性好**（无密勒电容效应，见第 4 章），用于高频放大与宽带放大。

### 2.5.3 三种接法的比较

**这是必考的大一统对比表，必须默写。**

| 比较项 | 共射 CE | 共集 CC（射随器） | 共基 CB |
|---|---|---|---|
| 输入电极 / 输出电极 | B 进 / C 出 | B 进 / E 出 | E 进 / C 出 |
| 电压增益 A_u | **大**（几十~几百） | ≈1（略小于 1） | 大（与 CE 同量级） |
| 电流增益 A_i | 大（β） | 大（1+β） | ≈1（α） |
| 输入电阻 R_i | 中（约 1 kΩ） | **大**（几十 kΩ~几百 kΩ） | **小**（几 Ω~几十 Ω） |
| 输出电阻 R_o | 中（约 R_c，几 kΩ） | **小**（几 Ω~几十 Ω） | 中（约 R_c） |
| u_o 与 u_i 相位 | **反相（−180°）** | **同相** | **同相** |
| 主要用途 | 放大电压（主放大器） | **缓冲、阻抗变换、功率输出级** | 高频/宽带放大、恒流源 |
| 高频性能 | 较差（密勒效应） | 较好 | **最好** |

**场效应管三种接法的对应关系**（概念完全平行）：

| BJT | FET | 输入/输出 | 特点 |
|---|---|---|---|
| 共射 CE | 共源 CS | G 进 / D 出 | A_u 大、反相 |
| 共集 CC | 共漏 CD（源极跟随器） | G 进 / S 出 | A_u≈1、R_i 大、R_o 小 |
| 共基 CB | 共栅 CG | S 进 / D 出 | A_u 大、R_i 小、高频好 |

**记忆口诀**：**「共射放大反相、共集跟随缓冲、共基高频恒流」**。

## 2.6 场效应管放大电路

### 2.6.1 场效应管放大电路的三种接法

与 BJT 完全平行：共源（CS）、共漏（CD）、共栅（CG）。**最常用的是共源电路**（对应共射）。

### 2.6.2 场效应管放大电路静态工作点的设置方法及其分析估算

场效应管是**电压控制**器件，需要建立合适的 $U_{GSQ}$，两种典型方法：

**（1）自给偏置（用于耗尽型管，包括 JFET）**

```text
     +V_DD
       │
      ┌┴┐ R_d
      └┬┘
       ├──── 输出
   u_i─┤ G
       │  ┌──── D
      ┌┴┐ │
      └┬┘ ├─ VT（耗尽型）
       │  │
      ─┴─ └──── S
            ┌┴┐ R_s
            └┬┘
            ─┴─
```

栅极电流为零（$I_G = 0$），所以 $U_{GQ} = 0$，于是

$U_{GSQ} = U_{GQ} - U_{SQ} = -I_{DQ} R_s$（**自动为负，不需要额外的负电源**）

联立转移特性 $I_{DQ} = I_{DSS}(1 - U_{GSQ}/U_{GS(off)})^2$ 即可解出 $I_{DQ}$。

**（2）分压式自偏置（用于增强型 MOS 管）**

$U_{GQ} = R_{g2}/(R_{g1} + R_{g2}) \cdot V_{DD}$（栅极电流为零，分压无误差）

$U_{GSQ} = U_{GQ} - I_{DQ} R_s$

联立 $I_{DQ} = I_{DO}(U_{GSQ}/U_{GS(th)} - 1)^2$ 求 $I_{DQ}$，再由 $U_{DSQ} = V_{DD} - I_{DQ}(R_d + R_s)$ 求 $U_{DSQ}$。

> **与 BJT 的最大区别**：BJT 需要 $I_{BQ}$ 提供偏置电流，FET 的栅极电流为零，所以分压电阻可以取得极大（MΩ 级），从而获得极高的输入电阻。

### 2.6.3 场效应管放大电路的动态分析

**共源电路的微变等效电路：栅极开路（$i_g = 0$），漏极是受控电流源 $g_m u_{gs}$。**

```text
   g ──┬──────────────┬── d ──┬── R_d ──┬───┬─┐
       │              │       │        │   │ │ R_L
   u_i │      g_m·u_gs↓       └────────┘  ─┴─
       └──────────────┴── s ── 地 ────────────
```

- **电压增益**：$A_u = -g_m(R_d \parallel R_L) = -g_m R_{L'}$，**反相**
- **输入电阻**：$R_i = R_g + (R_{g1} \parallel R_{g2})$（极大，MΩ 级）
- **输出电阻**：$R_o \approx R_d$

对比 BJT：$A_u = -\beta R_{L'}/r_{be} = -g_m R_{L'}$（因为 $g_m = \beta /r_{be}$）——**两个公式本质相同**，这也说明「跨导 g_m」是三极管和场效应管共通的放大能力指标。

## 2.7 基本放大电路的派生电路

### 2.7.1 复合管放大电路

**复合管（达林顿管，Darlington）把两只管子按「电流同向」原则串接，等效为一只 β 极大的管子。**

```text
   NPN + NPN（等效为NPN）        PNP + PNP（等效为PNP）
        C1,C2 合并                   E1,E2 合并
         │                             │
      ┌──┴──┐                      ┌───┴──┐
  B ──┤ T1  ├─ E1=B2 ──┐       B ──┤ T1   ├── B2 ...
      └─────┘       ┌──┴──┐         └──────┘
                    │ T2  │
                    └──┬──┘
                       E
```

**等效电流放大系数**：

$\beta \approx \beta 1 \cdot \beta 2$（例如 $50 \times 80 = 4000$），$r_{be} \approx r_{be1} + (1+\beta 1) r_{be2}$

**组成原则（必须遵守，否则等效管类型会变）**：① 第一只管子的**集电极电流方向**必须与第二只的**基极电流方向**一致；② 两管**类型可以相同也可以不同**（NPN+PNP 也可组合成等效 PNP，取决于连接方式）。

| 优点 | 缺点 |
|---|---|
| 电流放大能力极大 | 漏电流也被放大：$I_{CEO} \approx (1+\beta 2) I_{CEO1}$ |
| 输入电阻大（β 大则 r_be 大） | 复合管整体压降为两个 U_BE（约 1.4 V） |
| 输出电流大，适合功率输出级 | 高频特性变差、热稳定性下降 |

### 2.7.2 共射-共基放大电路

**把共射的高增益与共基的宽频带结合起来：共射管做放大，共基管做「电流接续器」。**

优点：**增益与共射相同，但高频性能大幅改善**（因为共基管的输入电阻极小，使共射管的集电极等效负载电阻也小，从而减小了密勒效应）。用于宽频带放大器。

### 2.7.3 共集-共基放大电路

前一级共集（高输入电阻）+ 后一级共基（宽频带、高输出电阻），用于**高输入阻抗、宽带**的场合。

## 2.8 Multisim 应用举例

- **直流扫描分析测电压传输特性**：扫描输入电压，绘制 $u_o ~ u_i$ 曲线，可直观看到线性放大区、截止区和饱和区（即输出的「平顶」现象）。
- **测静态工作点与电压增益**：用直流工作点分析读 $I_{CQ}$、$U_{CEQ}$，用交流分析或示波器测 $A_u$，与手算结果对比。
- **参数扫描研究 R_b 对 Q 点的影响**：扫描 R_b，观察 $U_{CEQ}$ 的变化，体会「R_b 减小 → Q 点上移 → 饱和失真」。

## 典型例题

**例 2.1**（题型：固定偏置电路 Q 点 + 微变等效求增益——★必考套路）
电路如图 2.2.1，$V_{CC} = 12\,\mathrm{V}$，$R_b = 300\,\mathrm{k}\Omega$，$R_c = 3\,\mathrm{k}\Omega$，$R_L = 3\,\mathrm{k}\Omega$，硅管 $\beta = 50$，$r_{bb'} = 200\,\Omega$。求 Q 点、$r_{be}$、$A_u$、$R_i$、$R_o$。

**解**：
**第一步：直流分析（C1、C2 开路）**
$I_{BQ} = (V_{CC} - U_{BEQ})/R_b = (12 - 0.7) V / 300\,\mathrm{k}\Omega = 11.3/300\,\mathrm{mA} = 37.7\,\mu\mathrm{A}$
$I_{CQ} = \beta I_{BQ} = 50 \times 37.7\,\mu\mathrm{A} = 1.88\,\mathrm{mA}$
$U_{CEQ} = V_{CC} - I_{CQ} R_c = 12 - 1.88\,\mathrm{mA} \times 3\,\mathrm{k}\Omega = 12 - 5.65 = 6.35\,\mathrm{V}$
校验：$U_{CEQ} = 6.35\,\mathrm{V} > 0.3\,\mathrm{V}$，工作在放大区。

**第二步：r_be**
$r_{be} = r_{bb'} + (1+\beta) \cdot 26\,\mathrm{mV}/I_{EQ} = 200\,\Omega + 51 \times 26\,\mathrm{mV}/1.88\,\mathrm{mA}$
$= 200 + 51 \times 13.8\,\Omega = 200 + 705 = 905\,\Omega \approx 0.9\,\mathrm{k}\Omega$

**第三步：交流分析（V_CC 接地、电容短路）**
$R_{L'} = R_c \parallel R_L = (3 \times 3)/(3 + 3) \mathrm{k}\Omega = 1.5\,\mathrm{k}\Omega$
$A_u = -\beta R_{L'}/r_{be} = -50 \times 1500\,\Omega / 905\,\Omega = -82.9$

**第四步：输入、输出电阻**
$R_i = R_b \parallel r_{be} = 300\,\mathrm{k}\Omega \parallel 0.905\,\mathrm{k}\Omega = 0.902\,\mathrm{k}\Omega \approx 902\,\Omega$
$R_o = R_c = 3\,\mathrm{k}\Omega$

**答案**：$I_{BQ} = 37.7\,\mu\mathrm{A}$，$I_{CQ} = 1.88\,\mathrm{mA}$，$U_{CEQ} = 6.35\,\mathrm{V}$，$r_{be} = 905\,\Omega$，$A_u = -82.9$（反相），$R_i \approx 902\,\Omega$，$R_o = 3\,\mathrm{k}\Omega$。

**例 2.2**（题型：分压式射极偏置电路 Q 点 + 增益——★必考套路）
$V_{CC} = 12\,\mathrm{V}$，$R_{b1} = 33\,\mathrm{k}\Omega$，$R_{b2} = 10\,\mathrm{k}\Omega$，$R_c = 3\,\mathrm{k}\Omega$，$R_e = 1.5\,\mathrm{k}\Omega$，$R_L = 3\,\mathrm{k}\Omega$，$C_e$ 足够大（交流短路），$\beta = 100$，$r_{bb'} = 200\,\Omega$。求 Q 点与 $A_u$、$R_i$、$R_o$。

**解**：
**第一步：Q 点四步法**
① $U_{BQ} = R_{b2}/(R_{b1}+R_{b2}) \cdot V_{CC} = 10/(33+10) \times 12\,\mathrm{V} = 10/43 \times 12 = 2.79\,\mathrm{V}$
② $U_{EQ} = U_{BQ} - U_{BEQ} = 2.79 - 0.7 = 2.09\,\mathrm{V}$
③ $I_{EQ} = U_{EQ}/R_e = 2.09\,\mathrm{V}/1.5\,\mathrm{k}\Omega = 1.39\,\mathrm{mA}$；$I_{CQ} \approx 1.39\,\mathrm{mA}$，$I_{BQ} = 1.39/101 = 13.8\,\mu\mathrm{A}$
④ $U_{CEQ} = V_{CC} - I_{CQ}(R_c + R_e) = 12 - 1.39\,\mathrm{mA} \times 4.5\,\mathrm{k}\Omega = 12 - 6.26 = 5.74\,\mathrm{V}$
校验假设：$I_1 \approx V_{CC}/(R_{b1}+R_{b2}) = 12/43\,\mathrm{k}\Omega = 279\,\mu\mathrm{A} >> I_{BQ} = 13.8\,\mu\mathrm{A}$ ✓；$U_{BQ} = 2.79\,\mathrm{V} >> U_{BEQ} = 0.7\,\mathrm{V}$ ✓

**第二步：r_be**
$r_{be} = 200 + 101 \times 26\,\mathrm{mV}/1.39\,\mathrm{mA} = 200 + 101 \times 18.7 = 200 + 1889 = 2089\,\Omega \approx 2.09\,\mathrm{k}\Omega$

**第三步：交流分析（C_e 把 R_e 交流短路，故 R_e 不出现在交流通路中）**
$R_{L'} = R_c \parallel R_L = 1.5\,\mathrm{k}\Omega$
$A_u = -\beta R_{L'}/r_{be} = -100 \times 1500/2089 = -71.8$

**第四步：R_i、R_o**
$R_i = R_{b1} \parallel R_{b2} \parallel r_{be} = 33 \parallel 10 \parallel 2.089\,\mathrm{k}\Omega$
先算 $33 \parallel 10 = 330/43 = 7.67\,\mathrm{k}\Omega$，再 $7.67 \parallel 2.089 = (7.67 \times 2.089)/(7.67+2.089) = 16.02/9.76 = 1.64\,\mathrm{k}\Omega$
$R_o = R_c = 3\,\mathrm{k}\Omega$

**答案**：$U_{BQ} = 2.79\,\mathrm{V}$，$I_{CQ} = 1.39\,\mathrm{mA}$，$U_{CEQ} = 5.74\,\mathrm{V}$，$r_{be} = 2.09\,\mathrm{k}\Omega$，$A_u = -71.8$，$R_i = 1.64\,\mathrm{k}\Omega$，$R_o = 3\,\mathrm{k}\Omega$。

**例 2.3**（题型：图解法求 Q 点与最大不失真输出）
共射电路 $V_{CC} = 12\,\mathrm{V}$，$R_c = 3\,\mathrm{k}\Omega$，$R_L = 3\,\mathrm{k}\Omega$，由特性曲线查得 $I_{BQ} = 40\,\mu\mathrm{A}$ 时 $I_{CQ} = 2\,\mathrm{mA}$。求 Q 点、交流负载线、最大不失真输出电压。

**解**：
**直流负载线**：$u_{CE} = 12 - i_C \times 3$，与纵轴交于 $12/3 = 4\,\mathrm{mA}$，与横轴交于 $12\,\mathrm{V}$。
Q 点：$I_{CQ} = 2\,\mathrm{mA}$，$U_{CEQ} = 12 - 2 \times 3 = 6\,\mathrm{V}$。故 Q(6 V, 2 mA)。
**交流负载线**：$R_{L'} = 3 \parallel 3 = 1.5\,\mathrm{k}\Omega$，过 Q 点、斜率 $-1/1.5\,\mathrm{k}\Omega$。
**最大不失真输出**：
向上到饱和的余量：$U_{CEQ} - U_{CES} = 6 - 0.3 = 5.7\,\mathrm{V}$
向下到截止的余量：$I_{CQ} R_{L'} = 2\,\mathrm{mA} \times 1.5\,\mathrm{k}\Omega = 3\,\mathrm{V}$
取小者：$U_{om} = 3\,\mathrm{V}$（峰值）。

**答案**：Q(6 V, 2 mA)；$U_{om} = 3\,\mathrm{V}$（峰值），有效值 $3/\sqrt{2} = 2.12\,\mathrm{V}$。**因截止余量更小，加大输入先出现截止失真（顶部削平）。**

**例 2.4**（题型：共集电路——射极跟随器）
$V_{CC} = 12\,\mathrm{V}$，$R_b = 200\,\mathrm{k}\Omega$，$R_e = 3\,\mathrm{k}\Omega$，$R_L = 3\,\mathrm{k}\Omega$，$\beta = 100$，$r_{bb'} = 200\,\Omega$，信号源内阻 $R_s = 0$。求 Q 点、$A_u$、$R_i$、$R_o$。

**解**：
**Q 点**：基极回路的等效电阻为 $R_b + (1+\beta)R_e$（R_e 折算到基极要乘 1+β）：
$I_{BQ} = (V_{CC} - U_{BEQ})/[R_b + (1+\beta)R_e] = (12 - 0.7)/[200\,\mathrm{k}\Omega + 101 \times 3\,\mathrm{k}\Omega] = 11.3/(200+303) \mathrm{k}\Omega = 11.3/503\,\mathrm{k}\Omega = 22.5\,\mu\mathrm{A}$
$I_{EQ} = (1+\beta)I_{BQ} = 101 \times 22.5\,\mu\mathrm{A} = 2.27\,\mathrm{mA}$
$U_{EQ} = I_{EQ} R_e = 2.27\,\mathrm{mA} \times 3\,\mathrm{k}\Omega = 6.81\,\mathrm{V}$，$U_{CEQ} = 12 - 6.81 = 5.19\,\mathrm{V}$
$r_{be} = 200 + 101 \times 26/2.27 = 200 + 1157 = 1357\,\Omega$
**交流**：$R_{L'} = R_e \parallel R_L = 1.5\,\mathrm{k}\Omega$
$A_u = (1+\beta)R_{L'}/[r_{be} + (1+\beta)R_{L'}] = 101 \times 1500/(1357 + 101 \times 1500) = 151500/152857 = 0.991$
$R_i = R_b \parallel [r_{be} + (1+\beta)R_{L'}] = 200\,\mathrm{k}\Omega \parallel 152.9\,\mathrm{k}\Omega = (200 \times 152.9)/(200+152.9) = 30580/352.9 = 86.6\,\mathrm{k}\Omega$
$R_o = R_e \parallel [r_{be}/(1+\beta)] = 3\,\mathrm{k}\Omega \parallel (1357/101\,\Omega) = 3000 \parallel 13.4 = (3000 \times 13.4)/3013.4 = 13.3\,\Omega$

**答案**：$I_{EQ} = 2.27\,\mathrm{mA}$，$U_{CEQ} = 5.19\,\mathrm{V}$，$A_u = 0.991$（同相），$R_i = 86.6\,\mathrm{k}\Omega$，$R_o = 13.3\,\Omega$。
**结论：电压增益不到 1，但输入电阻高、输出电阻极低——这正是「缓冲级」的价值。**

**例 2.5**（题型：共基电路）
某共基电路 $I_{EQ} = 1\,\mathrm{mA}$，$\beta = 100$，$r_{bb'} = 200\,\Omega$，$R_c = 3\,\mathrm{k}\Omega$，$R_L = 3\,\mathrm{k}\Omega$，$R_e = 5\,\mathrm{k}\Omega$。求 $A_u$、$R_i$、$R_o$。

**解**：
$r_{be} = 200 + 101 \times 26\,\mathrm{mV}/1\,\mathrm{mA} = 200 + 2626 = 2826\,\Omega \approx 2.83\,\mathrm{k}\Omega$
$R_{L'} = R_c \parallel R_L = 1.5\,\mathrm{k}\Omega$
$A_u = +\beta R_{L'}/r_{be} = 100 \times 1500/2826 = +53.1$（**同相**）
$R_i = R_e \parallel [r_{be}/(1+\beta)] = 5\,\mathrm{k}\Omega \parallel (2826/101\,\Omega = 28\,\Omega) = (5000 \times 28)/(5028) = 27.8\,\Omega$
$R_o \approx R_c = 3\,\mathrm{k}\Omega$

**答案**：$A_u = +53.1$，$R_i = 27.8\,\Omega$，$R_o = 3\,\mathrm{k}\Omega$。**输入电阻极小是其缺点，但高频特性最好。**

**例 2.6**（题型：场效应管共源放大电路）
增强型 NMOS 共源电路：$V_{DD} = 15\,\mathrm{V}$，$R_{g1} = 300\,\mathrm{k}\Omega$，$R_{g2} = 100\,\mathrm{k}\Omega$，$R_d = 5\,\mathrm{k}\Omega$，$R_s = 1\,\mathrm{k}\Omega$，$R_L = 5\,\mathrm{k}\Omega$，$U_{GS(th)} = 2\,\mathrm{V}$，$I_{DO} = 2\,\mathrm{mA}$（定义为 $u_{GS} = 2U_{GS(th)}$ 时的 i_D）。求 $I_{DQ}$、$U_{GSQ}$、$U_{DSQ}$、$g_m$、$A_u$。

**解**：
$U_{GQ} = R_{g2}/(R_{g1}+R_{g2}) \cdot V_{DD} = 100/400 \times 15 = 3.75\,\mathrm{V}$
栅极电流为零，源极电流即漏极电流，故 $U_{GSQ} = U_{GQ} - I_{DQ} R_s = 3.75 - I_{DQ} \times 1$（I_DQ 以 mA 计，R_s 以 kΩ 计，结果为 V）
转移特性：$I_{DQ} = I_{DO}(U_{GSQ}/U_{GS(th)} - 1)^2 = 2 \times (U_{GSQ}/2 - 1)^2 = 0.5(U_{GSQ} - 2)^2$
代入 $U_{GSQ} = 3.75 - I_{DQ}$（记 $x = I_{DQ}$）：
$x = 0.5(3.75 - x - 2)^2 = 0.5(1.75 - x)^2$
展开：$x = 0.5(3.0625 - 3.5x + x^2)$ → $0.5x^2 - 2.75x + 1.531 = 0$ → $x^2 - 5.5x + 3.0625 = 0$
$x = [5.5 \pm \sqrt{(30.25 - 12.25)}]/2 = [5.5 \pm \sqrt{18}]/2 = [5.5 \pm 4.243]/2$
取合理根（另一根使 $U_{GSQ} < U_{GS(th)}$，不导通）：$I_{DQ} = 0.63\,\mathrm{mA}$
$U_{GSQ} = 3.75 - 0.63 = 3.12\,\mathrm{V}$（> 2 V ✓）
$U_{DSQ} = V_{DD} - I_{DQ}(R_d + R_s) = 15 - 0.63 \times 6 = 15 - 3.78 = 11.2\,\mathrm{V}$（> U_GSQ − U_GS(th) = 1.12 V ✓，工作在恒流区）
$g_m = 2I_{DO}/U_{GS(th)} \times (U_{GSQ}/U_{GS(th)} - 1) = 2 \times 2/2 \times (3.12/2 - 1) = 2 \times 0.56 = 1.12\,\mathrm{mS}$
$A_u = -g_m(R_d \parallel R_L) = -1.12\,\mathrm{mS} \times (5 \parallel 5) \mathrm{k}\Omega = -1.12 \times 2.5 = -2.8$

**答案**：$I_{DQ} = 0.63\,\mathrm{mA}$，$U_{GSQ} = 3.12\,\mathrm{V}$，$U_{DSQ} = 11.2\,\mathrm{V}$，$g_m = 1.12\,\mathrm{mS}$，$A_u = -2.8$（反相）。
**注意：MOS 管的 g_m 通常只有 1~5 mS，远小于 BJT 的 β/r_be（几十 mS），所以单级共源增益不高。**

**例 2.7**（题型：复合管参数）
两只 NPN 管组成复合管，$\beta 1 = 50$，$\beta 2 = 80$，$r_{be1} = 1\,\mathrm{k}\Omega$，$r_{be2} = 1\,\mathrm{k}\Omega$。求等效 β 与等效 $r_{be}$。若第一只管的 $I_{CEO1} = 2\,\mu\mathrm{A}$，求复合管的 $I_{CEO}$。

**解**：
$\beta \approx \beta 1 \cdot \beta 2 = 50 \times 80 = 4000$
$r_{be} \approx r_{be1} + (1+\beta 1) r_{be2} = 1000 + 51 \times 1000 = 52\,\mathrm{k}\Omega$
$I_{CEO} \approx (1+\beta 2) I_{CEO1} = 81 \times 2\,\mu\mathrm{A} = 162\,\mu\mathrm{A}$

**答案**：$\beta \approx 4000$，$r_{be} \approx 52\,\mathrm{k}\Omega$，$I_{CEO} \approx 162\,\mu\mathrm{A}$。
**注意漏电流被放大了 81 倍——这就是复合管热稳定性差的定量说明。**

**例 2.8**（题型：Q 点稳定性的定量比较）
用同一只管子（$U_{BEQ}$ 从 0.70 V 降到 0.65 V 模拟温度升高）比较两种偏置电路的 $I_{CQ}$ 变化率。
(a) 固定偏置：$V_{CC} = 12\,\mathrm{V}$，$R_b = 300\,\mathrm{k}\Omega$，$\beta = 50$；
(b) 分压式：$V_{CC} = 12\,\mathrm{V}$，$R_{b1} = 33\,\mathrm{k}\Omega$，$R_{b2} = 10\,\mathrm{k}\Omega$，$R_e = 1.5\,\mathrm{k}\Omega$（设 β 不变，只看 U_BE 的影响）。

**解**：
(a) $I_{BQ} = (12 - 0.70)/300\,\mathrm{k}\Omega = 37.7\,\mu\mathrm{A}$ → $I_{CQ} = 50 \times 37.7 = 1.88\,\mathrm{mA}$
温度后：$I_{BQ'} = (12 - 0.65)/300\,\mathrm{k}\Omega = 37.8\,\mu\mathrm{A}$ → $I_{CQ'} = 1.89\,\mathrm{mA}$
变化率 $= (1.89 - 1.88)/1.88 = 0.5\%$
(b) $U_{BQ} = 2.79\,\mathrm{V}$ 不变（由电阻分压决定）
$U_{EQ} = 2.79 - 0.70 = 2.09\,\mathrm{V}$ → $I_{EQ} = 1.39\,\mathrm{mA}$
温度后：$U_{EQ'} = 2.79 - 0.65 = 2.14\,\mathrm{V}$ → $I_{EQ'} = 2.14/1.5 = 1.43\,\mathrm{mA}$
变化率 $= (1.43 - 1.39)/1.39 = 2.9\%$

**答案**：仅看 U_BE 变化时，分压式的相对变化（2.9%）反而更大——**但这是假象**：分压式把绝对变化量 $(2.14 - 2.09)/1.5\,\mathrm{k}\Omega = 0.033\,\mathrm{mA}$ 与 R_e 挂钩，而固定偏置的总电流变化是 $(37.8 - 37.7) \mu A \times \beta = 0.005\,\mathrm{mA}$……
**正确的比较方法**是把三个温度效应（U_BE↓、β↑、I_CBO↑）一起考虑：此时固定偏置的 $I_{CQ}$ 变化可达 ±50%，而分压式因为 $I_{CQ} \approx (U_{BQ} - U_{BEQ})/R_e$ 与 β 无关，变化被限制在 ±10% 以内。**结论：分压式偏置的主要功劳是「使 I_CQ 与 β 无关」，这才是它稳定 Q 点的关键。**

## 易错点提醒

1. **算 Q 点时忘记电容开路** → 直流通路中 C1、C2、C_e 一律开路（不是短路），否则会算出完全错误的偏置。
2. **算交流时忘记「直流电源接地」** → V_CC 在交流通路中必须接地，否则得不到 $R_c \parallel R_L$，而会误写成 $R_c + R_L$。
3. **把 R_c∥R_L 写成 R_c + R_L** → 从集电极看，R_c 与 R_L 都接交流地，是**并联**关系。
4. **r_be 公式里漏掉 (1+β)** → $r_{be} = r_{bb'} + (1+\beta)26\,\mathrm{mV}/I_{EQ}$；发射结电阻折算到基极必须乘 (1+β)，漏掉会使 r_be 偏小几倍。
5. **用 I_BQ 而不是 I_EQ 算 r_be** → 公式用的是发射极静态电流 $I_{EQ}$（数值上 ≈ I_CQ），不是基极电流。
6. **把截止失真与饱和失真的波形记反** → NPN 共射：**Q 点太低 → 截止失真 → 输出顶部削平**；Q 点太高 → 饱和失真 → 底部削平。
7. **认为共集电路能放大电压** → $A_u \le 1$，它放大的只有电流（$A_i = 1+\beta$）；它的价值在于阻抗变换。
8. **共基电路说成反相** → 共基的 $u_o$ 与 $u_i$ **同相**（只有共射、共源是反相）。
9. **场效应管 Q 点解二次方程时取错根** → 两个根中只有一个满足「增强型 $U_{GSQ} > U_{GS(th)}$」或「耗尽型 $U_{GS(off)} < U_{GSQ} < 0$」，必须代入校验。
10. **复合管只把 β 相乘，忘了漏电流也相乘** → $I_{CEO} \approx (1+\beta 2)I_{CEO1}$，这是复合管的隐患。
11. **直接用题目给的 β 算精确增益并保留三位有效数字** → β 本身有 ±50% 的分散性，增益写成「−82.9」可以，但结论应表述为「约 80 倍」，并说明误差来源。

## 本章小结

- 放大的实质是「用小能量控制大能量」，必须有直流电源供能。
- 四个指标：$A_u$（要大）、$R_i$（要大）、$R_o$（要小）、BW（要宽）。
- 任何放大电路算两遍：**直流通路求 Q 点**（电容开路、电源保留），**交流通路求增益**（电源接地、电容短路）。
- 图解法：直流负载线 $u_{CE} = V_{CC} - i_C R_c$ 定 Q 点；交流负载线过 Q 点、斜率 $-1/(R_c \parallel R_L)$；$U_{om} = \min (U_{CEQ} - U_{CES}, I_{CQ} R_{L'})$。
- 等效电路法三件套：$r_{be} = r_{bb'} + (1+\beta)26\,\mathrm{mV}/I_{EQ}$、$A_u = -\beta R_{L'}/r_{be}$、$R_i = R_b \parallel r_{be}$、$R_o = R_c$。
- 分压式射极偏置靠 R_e 引入**直流负反馈**，使 $I_{CQ} \approx (U_{BQ} - U_{BEQ})/R_e$ **与 β 无关**，这是它稳定 Q 点的真正原因。
- 三种接法：共射（反相、增益大、主放大器）、共集（同相、A_u≈1、R_i 大、R_o 小、缓冲级）、共基（同相、R_i 小、高频好）。
- 场效应管共源：$A_u = -g_m R_{L'}$，与 BJT 的 $A_u = -\beta R_{L'}/r_{be}$ 本质相同（$g_m = \beta /r_{be}$）。
- 复合管 $\beta \approx \beta 1\beta 2$，但漏电流也被放大，且压降加倍。

> **一句话记住本章**：**先直流、后交流；直流看 Q 点在不在放大区，交流看等效电路里 R_L' 和 r_be 谁大。**

## 自测题

1. 放大电路的实质是什么？为什么必须有直流电源？
2. 画出共射放大电路的直流通路与交流通路，说明两者对电容和电源的处理有何不同。
3. 写出 $r_{be}$ 的表达式，并解释式中 (1+β) 的来源。
4. 分压式射极偏置电路中，为什么要求 $I_1 >> I_{BQ}$、$U_{BQ} >> U_{BEQ}$？
5. 某共射电路 $R_c = 2\,\mathrm{k}\Omega$、$R_L = \infty$、$\beta = 100$、$I_{CQ} = 1\,\mathrm{mA}$、$r_{bb'} = 200\,\Omega$，求 $A_u$。
6. 截止失真和饱和失真分别对应 Q 点偏高还是偏低？NPN 共射电路的输出波形各削哪一侧？
7. 共集放大电路的电压增益为什么小于 1？它的主要用途是什么？
8. 为什么共基电路的高频特性比共射好？（提示：考虑密勒效应）
9. 场效应管放大电路的输入电阻为什么可以做得很大？
10. 两只管子组成复合管，$\beta 1 = 60$、$\beta 2 = 50$，等效 β 是多少？有什么副作用？

**自测题答案**

1. 实质是用小能量控制大能量；因为输出信号的能量来自直流电源，信号本身不提供能量。
2. 直流通路：耦合/旁路电容开路、V_CC 保留、信号源置零；交流通路：电容短路、V_CC 接地、信号源保留。
3. $r_{be} = r_{bb'} + (1+\beta)26\,\mathrm{mV}/I_{EQ}$；(1+β) 是发射结动态电阻 $26\,\mathrm{mV}/I_{EQ}$ 折算到基极回路的倍率（基极电流是发射极电流的 1/(1+β)）。
4. 前者保证 $U_{BQ}$ 只由分压电阻决定、不受 I_BQ 影响；后者保证 $U_{EQ} = U_{BQ} - U_{BEQ}$ 中 U_BEQ 的变化只占很小比例，从而 $I_{CQ} \approx U_{BQ}/R_e$ 稳定。
5. $r_{be} = 200 + 101 \times 26/1 = 2826\,\Omega$；$A_u = -100 \times 2000/2826 = -70.8$。
6. 截止失真是 Q 点偏低，输出**顶部**削平；饱和失真是 Q 点偏高，输出**底部**削平（NPN 共射）。
7. 因为 R_e 上有交流压降，构成 100% 的电压串联负反馈，使 $A_u = (1+\beta)R_{L'}/[r_{be}+(1+\beta)R_{L'}] < 1$；主要用途是缓冲（阻抗变换）与功率输出级。
8. 共基电路没有密勒效应：输入在发射极、输出在集电极，基极交流接地，C_b'c 不跨接在输入输出之间，故高频时增益衰减慢。
9. 因为栅极与沟道之间是绝缘层（MOS）或反偏 PN 结（JFET），栅极电流近似为零，所以分压电阻可以取到 MΩ 级。
10. $\beta \approx 60 \times 50 = 3000$；副作用是漏电流被放大 $(1+\beta 2)$ 倍、基极-发射极压降加倍（约 1.4 V）、高频性能变差。
