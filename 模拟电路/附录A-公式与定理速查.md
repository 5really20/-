# 附录A 公式与定理速查

> 对应教材：童诗白、华成英《模拟电子技术基础》（第五版）｜用途：做题、复习、考试前速览
>
> 使用说明：本附录按章分组，只列**会用到的公式**与其**适用条件**。公式中的单位按「符号与单位约定」表统一；凡带 ★ 的是**必考核心公式**，带 ⚠ 的是**容易用错的地方**。

## 符号与单位约定

| 符号 | 含义 | 单位 |
|---|---|---|
| `u`、`i` | 瞬时值（随时间变化） | V、A |
| `U`、`I` | 直流量或正弦量的有效值 | V、A |
| `U_m`、`I_m` | 正弦量的幅值（峰值） | V、A |
| 下标 `Q` | 静态工作点值（如 `I_CQ`、`U_CEQ`） | — |
| `U_T` | 温度的电压当量 `U_T = kT/q`，常温约 **26 mV** | V |
| `∥` | 并联 `R_1∥R_2 = R_1R_2/(R_1+R_2)` | — |
| `R_L'` | 交流等效负载 `R_L' = R_C∥R_L` | Ω |
| 电容 | `μF = 10⁻⁶ F`，`pF = 10⁻¹² F` | F |
| 频率 | `kHz = 10³ Hz`，`MHz = 10⁶ Hz` | Hz |

**两个贯穿全书的思维习惯**：
1. **先直流后交流**：先画直流通路（**电容开路**）算 Q 点，再画交流通路（**直流电源接地、耦合/旁路电容短路**）算动态指标。
2. **算 `r_be` 必须先有 `I_EQ`**：绝大多数题目的第一问都是求 Q 点，因为 `r_be` 依赖它。

## 第 0 章 绪论与放大电路模型

| 公式 | 含义/条件 |
|---|---|
| ★ `A_u = u_o/u_i` | 电压增益（无量纲） |
| `A_u(dB) = 20 lg\|A_u\|` | 电压增益的分贝表示 |
| `A_p(dB) = 10 lg(A_p)` | 功率增益的分贝表示 |
| ★ `A_u(dB) 总 = Σ A_ui(dB)` | 级联时**分贝相加**（数值相乘） |
| `A_i = i_o/i_i`、`A_p = A_u·A_i` | 电流增益、功率增益 |
| `R_i = u_i/i_i` | 输入电阻；`R_i` 越大，从信号源取的电流越小 |
| `R_o = u_ot/i_ot`（输入短路、负载开路时） | 输出电阻；`R_o` 越小，带负载能力越强 |
| ★ `u_o = u_ot·R_L/(R_o+R_L)` | 输出电阻对输出电压的影响（分压） |
| `u_i = u_s·R_i/(R_s+R_i)` | 输入电阻对信号源电压的衰减 |
| ★ `BW = f_H − f_L ≈ f_H` | 通频带（3 dB 带宽） |
| ★ `GBW = \|A_um\|·f_H = 常数` | 增益带宽积，增益与带宽相互制约 |

**四种放大电路模型**：电压放大（`R_i→∞`、`R_o→0`）、电流放大（`R_i→0`、`R_o→∞`）、互阻放大、互导放大。

**理想运放五个条件**：`A_od = ∞`、`R_id = ∞`、`R_o = 0`、`BW = ∞`、`K_CMR = ∞`。

## 第 1 章 常用半导体器件

### 1.1 半导体与 PN 结

| 公式/结论 | 含义/条件 |
|---|---|
| ★ `i_D = I_S(e^(u_D/U_T) − 1)` | PN 结伏安特性；正偏时约 `I_S e^(u_D/U_T)`，反偏时 `≈ −I_S` |
| ★ `U_T = kT/q ≈ 26 mV` | 常温 300 K；温度每升 1 °C 约增 0.085 mV |
| `ln10 ≈ 2.3` | 正偏电压每增 60 mV，电流增约 10 倍 |
| 温度影响 | 温度↑ → 正偏压降↓（约 −2 mV/°C）、反向饱和电流↑ |
| 单向导电性 | 正偏导通（`u_D > U_on`），反偏截止；反向击穿时稳压 |
| 势垒电容 `C_B` | 反偏时为主，`C_B ∝ 1/√(U_R)` |
| 扩散电容 `C_D` | 正偏时为主，与电流有关 |

### 1.2 二极管与稳压管

| 项 | 理想模型 | 恒压降模型 | 折线模型 | 小信号模型 |
|---|---|---|---|---|
| 正向 | 短路 | 恒压 `U_on`（硅 0.7 V、锗 0.2 V） | `U_on + i_D r_D` | `r_d = U_T/I_DQ` |
| 反向 | 开路 | 开路 | 开路 | 动态电阻 |
| 适用 | 判断通断、大信号 | 一般电路估算 | 精确估算 | 交流小信号分析 |

| 公式 | 含义/条件 |
|---|---|
| ★ `r_d = U_T/I_DQ ≈ 26 mV/I_DQ` | 二极管在 Q 点的**动态电阻** |
| `U_RM`、`I_F`、`I_R` | 最大反向电压（峰值）、最大正向平均电流、反向饱和电流 |
| 稳压管：`U_Z`、`I_Zmin`、`I_Zmax`、`r_Z` | 工作条件 `I_Zmin ≤ I_Z ≤ I_Zmax` |
| ★ `(U_Imin−U_Z)/(I_Zmax+I_Lmin) ≤ R ≤ (U_Imax−U_Z)/(I_Zmin+I_Lmax)` | 限流电阻取值范围 |

### 1.3 晶体三极管（BJT）

| 公式/结论 | 含义/条件 |
|---|---|
| ★ `I_E = I_B + I_C` | 电流关系（近似 `I_C ≈ I_E`） |
| ★ `β = Δi_C/Δi_B`（`= I_C/I_B`） | 共射电流放大系数 |
| ★ `α = I_C/I_E` | 共基电流放大系数 |
| ★ `β = α/(1−α)`、`α = β/(1+β)` | β 与 α 的互换 |
| `I_CEO = (1+β)I_CBO` | 穿透电流 |
| `U_BE ≈ 0.7 V`（硅管，导通） | 发射结导通压降 |
| `U_CE = U_CES ≈ 0.3 V`（饱和） | 饱和压降 |
| 三个工作区 | 放大区（发射结正偏、集电结反偏）；饱和区（均正偏）；截止区（均反偏） |
| ★ `i_C = I_S e^(u_BE/U_T)`（`u_BE = U_T ln(I_C/I_S)`） | 发射结的指数关系（也是对数电路的原理） |
| `I_C ≈ I_S e^(U_BE/U_T)`、`U_BE ≈ 0.7 V` | 工程估算常用 |
| 温度影响 | `I_CBO` 每升 10 °C 约翻倍；`U_BE` 约 −2 mV/°C；β 约 +0.5%~1%/°C |

### 1.4 场效应管（FET）

| 公式 | 含义/条件 |
|---|---|
| ★ `i_D = I_DSS(1 − u_GS/U_GS(off))²` | **结型** FET 的转移特性（`U_GS(off) < 0`） |
| ★ `i_D = I_DO(1 − u_GS/U_GS(th))²` | **增强型 MOS** 的转移特性（`U_GS(th) > 0`） |
| `i_D = I_DSS(1 − u_GS/U_GS(off))²` | **耗尽型 MOS**（与结型同式，`U_GS` 可正可负） |
| ★ `g_m = Δi_D/Δu_GS` | 低频跨导（单位 mS） |
| `g_m = (2I_DSS/\|U_GS(off)\|)(1 − U_GSQ/U_GS(off))` | 结型/耗尽型跨导计算 |
| ★ `g_m = 2√(I_DO·I_DQ)/U_GS(th)` | 增强型 MOS 跨导计算 |
| `r_gs → ∞`（`R_G = ∞`） | MOS 管输入电阻极高（10⁹~10¹⁵ Ω） |
| 使用注意 | 结型时 `u_GS` 必须反偏（`U_GS(off) < u_GS < 0`）；MOS 管栅极不能悬空 |

**BJT 与 FET 的对比**：BJT 是**电流控制**器件（`i_C = βi_B`），输入电阻小；FET 是**电压控制**器件（`i_D = g_m u_GS`），输入电阻极大、噪声低、热稳定性好。

## 第 2 章 基本放大电路（★全书最重要）

### 2.1 静态工作点（Q 点）

| 电路 | 计算步骤 | 关键公式 |
|---|---|---|
| **固定偏置** | 直接求 | ★ `I_BQ = (V_CC − U_BEQ)/R_b`、`I_CQ = βI_BQ`、`U_CEQ = V_CC − I_CQ R_c` |
| **分压式射极偏置** | 四步法 | ★ `U_BQ = V_CC R_b2/(R_b1+R_b2)` → `U_EQ = U_BQ − 0.7` → `I_EQ = U_EQ/R_e` → `I_CQ ≈ I_EQ` → `U_CEQ = V_CC − I_CQ(R_c+R_e)` |
| **集电极-基极偏置** | 联立 | `I_BQ = (V_CC − U_BEQ)/(R_b + (1+β)R_c)` |
| **共源分压式自偏置** | 四步法 | `U_GQ = V_DD R_g2/(R_g1+R_g2)` → `U_SQ = I_DQ R_s` → 解 `I_DQ` → `U_DSQ = V_DD − I_DQ(R_d+R_s)` |

**分压式偏置的稳定条件**（工程取法）：★ `I_1 ≈ (5~10)I_BQ`（即 `R_b1∥R_b2` 远小于 `(1+β)R_e`），且 `U_BQ ≈ (3~5)U_BEQ`（约 2~5 V）。

**稳定 Q 点的原理**：`T↑ → I_CQ↑ → U_EQ↑ → U_BEQ = U_BQ − U_EQ↓ → I_BQ↓ → I_CQ↓`（**直流负反馈**）。固定偏置没有这个机制，故不稳定。

| 失真类型 | 起因 | 波形特征 | 消除方法 |
|---|---|---|---|
| **截止失真** | Q 点太低 | 输出**正半周**削平（顶部） | 减小 `R_b`（提高 `I_CQ`） |
| **饱和失真** | Q 点太高 | 输出**负半周**削平（底部） | 增大 `R_b`（降低 `I_CQ`） |
| 双向失真 | 输入信号过大 | 两边都削平 | 减小输入或提高电源电压 |

### 2.2 图解法

| 公式 | 含义 |
|---|---|
| ★ `u_CE = V_CC − i_C R_c` | **直流负载线**方程（斜率 `−1/R_c`） |
| ★ `u_ce = −i_c R_L'`（`R_L' = R_c∥R_L`） | **交流负载线**方程（过 Q 点，斜率 `−1/R_L'`） |
| ★ `U_om = min(I_CQ R_L', U_CEQ − U_CES)` | 最大不失真输出幅度 |
| `U_opp = 2U_om` | 最大输出峰峰值 |

⚠ **交流负载线必过 Q 点**，且因为 `R_L' < R_c`，交流负载线**比直流负载线更陡**。

### 2.3 微变等效电路法（★必考）

| 公式 | 含义/条件 |
|---|---|
| ★ `r_be = r_bb' + (1+β)26mV/I_EQ` | 三极管输入电阻（`r_bb'` 通常取 200~300 Ω，无值时可忽略） |
| `r_be ≈ 200 Ω + (1+β)26mV/I_EQ` | 低压小功率管的常用形式 |
| ★ `A_u = −βR_L'/r_be` | **共射**电压增益（`R_L' = R_c∥R_L`），负号表示反相 |
| ★ `R_i = R_b∥r_be`（`R_b = R_b1∥R_b2`） | 共射输入电阻 |
| ★ `R_o = R_c`（`R_o = R_c∥R_L` 时的等效源内阻为 `R_c`） | 共射输出电阻（`R_o ≈ R_c`） |
| ★ `A_u = (1+β)R_L'/[r_be+(1+β)R_L']` | **共集（射随）**电压增益，`≈ 1`（略小于 1，同相） |
| ★ `R_i = R_b∥[r_be+(1+β)R_L']` | 共集输入电阻（很大） |
| ★ `R_o = R_e∥[(r_be+R_s')/(1+β)]` | 共集输出电阻（很小，`R_s' = R_s∥R_b`） |
| ★ `A_u = βR_L'/r_be` | **共基**电压增益（与共射同大小，**同相**） |
| `R_i = R_e∥[r_be/(1+β)]` | 共基输入电阻（很小） |
| `R_o ≈ R_c` | 共基输出电阻 |
| ★ `A_u = −g_m R_L'` | **共源**电压增益（`R_L' = R_d∥R_L`） |
| ★ `A_u = g_m R_L'/(1+g_m R_L')` | **共漏（源随）**电压增益，`≈ 1` |
| `R_o = R_s∥(1/g_m)` | 共漏输出电阻（很小） |
| ★ `β ≈ β_1β_2`、`r_be ≈ r_be1 + (1+β_1)r_be2` | **复合管**（达林顿）参数；类型看**第一只管子** |

### 2.4 三种组态大一统对比（★必考大题）

| 项目 | 共射 CE | 共集 CC（射随） | 共基 CB |
|---|---|---|---|
| 电压增益 | `−βR_L'/r_be`（大，反相） | `≈1`（略小，同相） | `βR_L'/r_be`（大，同相） |
| 电流增益 | `β`（大） | `1+β`（大） | `α<1` |
| 输入电阻 | 中（`≈r_be`） | **很大** | **很小** |
| 输出电阻 | 中（`≈R_c`） | **很小** | 中（`≈R_c`） |
| 相位关系 | 反相（180°） | 同相（0°） | 同相（0°） |
| 典型用途 | 主放大级、电压增益 | 输入级、缓冲、输出级 | 高频、宽频带放大 |

## 第 3 章 集成运算放大电路

### 3.1 多级放大电路

| 公式 | 含义 |
|---|---|
| ★ `A_u = A_u1·A_u2·…·A_un` | 总电压增益（各级相乘） |
| `R_i = R_i1` | 总输入电阻等于第一级 |
| `R_o = R_on` | 总输出电阻等于最后一级 |

四种耦合方式：**阻容耦合**（各级 Q 点独立，不能放大直流）、**直接耦合**（能放大直流，但有零点漂移）、**变压器耦合**（阻抗变换，笨重）、**光电耦合**（隔离好）。

### 3.2 差分放大电路（★必考）

| 公式 | 含义/条件 |
|---|---|
| ★ `u_id = u_i1 − u_i2`、`u_ic = (u_i1+u_i2)/2` | 差模、共模信号定义 |
| ★ `A_d = Δu_od/Δu_id`、`A_c = Δu_oc/Δu_ic` | 差模增益、共模增益 |
| ★ `K_CMR = \|A_d/A_c\|`，`K_CMR(dB) = 20 lg\|A_d/A_c\|` | **共模抑制比** |
| ★ 双入双出：`A_d = −βR_L'/(R_b+r_be)`（`R_L' = R_c∥(R_L/2)`） | 长尾式双端输出 |
| ★ 双入双出：`A_c = 0`（理想对称，`R_e` 或恒流源等效为无穷） | 共模完全抑制 |
| ★ 单端输出：`A_d1 = −½βR_L'/(R_b+r_be)` | 只有一半 |
| ★ 单端输出：`A_c1 = −βR_L'/[R_b+r_be+2(1+β)R_e]` | 单端输出共模增益 |
| `K_CMR ≈ (1+β)R_e/(R_b+r_be)`（单端，双端时 `→∞`） | `R_e` 越大 `K_CMR` 越高 |
| ★ `R_id = 2(R_b+r_be)`、`R_ic ≈ ½[R_b+r_be+2(1+β)R_e]` | 差模、共模输入电阻（共同尾电阻 R_e，两管并接故取 ½） |

**四种接法对比**：双入双出（`A_d` 最大、`A_c = 0`、`K_CMR` 最高）、双入单出（`A_d` 一半）、单入双出、单入单出。

### 3.3 电流源电路

| 电路 | 输出电流 | 特点 |
|---|---|---|
| **镜像电流源** | ★ `I_o = I_R/(1 + 2/β) ≈ I_R = (V_CC − U_BE)/R` | 简单；`β` 小则误差大（约 2%~5%） |
| **比例电流源** | ★ `I_o ≈ I_R·R_1/R_2` | 用发射极电阻比定比例 |
| **微电流源** | ★ `I_o ≈ (U_T/R_2)·ln(I_R/I_o)` | 只需几十 μA；需迭代或估算 |
| **威尔逊电流源** | `I_o ≈ I_R(1 − 2/β²)` | 误差极小（约 0.02%），输出电阻高 |

## 第 4 章 放大电路的频率响应

| 公式 | 含义/条件 |
|---|---|
| ★ `A_u(jf) = A_um/[(1+jf/f_L)(1+jf/f_H)]` | 单级放大电路的完整频率响应 |
| ★ 低频（高通）：`A_u = A_um/(1−jf_L/f)`，`f_L = 1/(2πRC)` | 耦合电容、旁路电容决定 |
| ★ 高频（低通）：`A_u = A_um/(1+jf/f_H)`，`f_H = 1/(2πRC_i)` | 结电容、分布电容决定 |
| ★ `g_m = I_CQ/U_T ≈ 38.5I_CQ`（`I_CQ` 单位 mA，`g_m` 单位 mS） | 混合π模型跨导 |
| ★ `r_b'e = β/g_m = βU_T/I_CQ` | 基区体电阻外的输入电阻 |
| `r_ce = 1/ηg_m`（`η` 约 10⁻³~10⁻⁴） | 集射间电阻（通常忽略） |
| ★ `f_β = f_T/β` | 共射截止频率（`β` 下降 3 dB 的频率） |
| `f_T = g_m/(2π(C_b'e+C_b'c))` | 特征频率（`\|β\| = 1` 处） |
| ★ **密勒效应**：`C_i = C_b'e + (1+\|A_u\|)C_b'c` | 跨接电容被放大 `(1+\|A_u\|)` 倍 |
| ★ `A_u ≈ −g_m R_L'` | 密勒效应的增益估算 |
| ★ `GBW = \|A_um\|·f_H ≈ 1/(2πR C_b'c)` | **增益带宽积是常数** |
| ★ 多级下限：`f_L ≈ 1.1√(f_L1²+f_L2²+…)` | 各级下限频率的合成 |
| ★ 多级上限：`f_H ≈ 1/[1.1√(1/f_H1²+1/f_H2²+…)]` | 各级上限频率的合成 |
| `BW = f_H − f_L`，多级时 **BW 变窄** | 级数越多带宽越窄 |
| `t_r ≈ 0.35/f_H` | 上升时间与上限频率的关系 |

## 第 5 章 放大电路中的反馈（★必考）

### 5.1 四种组态判断（★必考大题）

| 判断内容 | 方法 | 判据 |
|---|---|---|
| 有无反馈 | 找连接输出与输入的元件 | 输出回路与输入回路之间有通路 |
| 正/负反馈 | **瞬时极性法** | 反馈使净输入**减小**为负反馈 |
| 交流/直流反馈 | 看反馈通路有无电容 | 有隔直电容则为交流反馈 |
| **电压/电流** | **输出短路法** | 输出（负载）短路后反馈消失 → **电压**反馈；仍存在 → **电流**反馈 |
| **串联/并联** | **输入节点法** | 反馈信号与输入信号接**同一节点** → **并联**；接**不同节点** → **串联** |

**四种组态的口诀速记**：

| 组态 | 典型电路 | 反馈元件接法 |
|---|---|---|
| 电压串联 | 同相比例运放、射随器 | `R_f` 从输出接回反相端（不同节点） |
| 电压并联 | 反相比例运放、共射 `R_f` | `R_f` 从输出接回基极（同一节点） |
| 电流串联 | 未旁路 `R_e` 的共射 | `R_e` 取样发射极电流 |
| 电流并联 | 两级放大 `R_f` 从第二级发射极接回第一级基极 | 取样非输出端电流 |

**负反馈对电路的影响**：

| 性能 | 影响 | 公式 |
|---|---|---|
| 增益稳定性 | 提高 `(1+AF)` 倍 | ★ `dA_f/A_f = (1/(1+AF))·dA/A` |
| 增益 | 下降 | ★ `A_f = A/(1+AF)` |
| 深度负反馈 | `1+AF >> 1` | ★ `A_f ≈ 1/F` |
| 串联反馈 | `R_i` 增大 | `R_if = R_i(1+AF)` |
| 并联反馈 | `R_i` 减小 | `R_if = R_i/(1+AF)` |
| 电压反馈 | `R_o` 减小 | `R_of = R_o/(1+AF)` |
| 电流反馈 | `R_o` 增大 | `R_of = R_o(1+AF)` |
| 通频带 | 展宽 | ★ `BW_f = BW·(1+AF)` |
| 非线性失真 | 减小 | 减小为 `1/(1+AF)` |
| 噪声 | 只抑制环内噪声，**不能抑制输入噪声** | — |

**`1+AF` 的取值含义**（`A_f = A/(1+AF)`）：

| `1+AF` 的取值 | 对应的 `AF` | 含义 |
|---|---|---|
| `> 1` | `AF > 0` | 负反馈，`A_f < A`，增益下降（`1+AF` 越大反馈越深） |
| `= 1` | `AF = 0` | 无反馈（反馈通路断开），增益不变 |
| `0 < 1+AF < 1` | `−1 < AF < 0` | 正反馈，增益上升，但尚未自激 |
| `= 0` | `AF = −1` | **自激振荡的临界**：幅度条件 `\|AF\| = 1` 与附加相移 ±180° 同时满足，输出等幅振荡 |
| `< 0` | `AF < −1` | 已自激，振荡幅度不断增大，直到被非线性（电源电压/限幅）约束 |

### 5.2 稳定性与自激振荡

| 公式/条件 | 含义 |
|---|---|
| ★ **幅度条件** `\|AF\| = 1` | 环路增益为 1 |
| ★ **相位条件** `φ_A + φ_F = ±180°`（附加相移） | 负反馈变正反馈 |
| `20 lg\|AF\| = 0 dB` 处的附加相移达 180° | 自激 |
| ★ **相位裕度** `γ = 180° − \|φ(附加)\|`（在 `\|AF\| = 1` 处） | `γ > 45°` 稳定 |
| **增益裕度** | `φ = 180°` 处 `20 lg\|AF\|` 的负值，一般要求 `< −10 dB` |
| 补偿方法 | 简单电容补偿、RC 串联补偿、反馈补偿、超前补偿；使主极点频率降低、`\|AF\|` 提前降到 0 dB |

## 第 6 章 信号的运算和处理

### 6.1 基本运算电路（★必考）

| 电路 | 输出表达式 | 输入电阻 |
|---|---|---|
| ★ **反相比例** | `u_o = −(R_f/R_1)u_i` | `R_i = R_1`（小） |
| ★ **同相比例** | `u_o = (1 + R_f/R_1)u_i` | `R_i → ∞`（大） |
| ★ **电压跟随器** | `u_o = u_i` | 极大 |
| ★ **反相求和** | `u_o = −R_f(u_i1/R_1 + u_i2/R_2 + …)` | — |
| ★ **同相求和** | `u_o = R_f·Σ(u_ik/R_k)`（需先算 `u_P`） | — |
| ★ **求差（减法）** | `u_o = (R_f/R_1)(u_i2 − u_i1)`（`R_1=R_2`、`R_3=R_f`） | — |
| ★ **积分** | `u_o = −(1/R_1C)∫u_i dt + u_o(0)` | — |
| ★ **微分** | `u_o = −R_1C·du_i/dt` | — |
| ★ **对数** | `u_o = −U_T ln(u_i/(I_SR)) ≈ −0.026 ln(u_i/(I_SR))` | — |
| ★ **指数** | `u_o = −I_SR·e^(u_i/U_T)` | — |
| **乘法** | `u_o = k·u_x·u_y`（`k` 为相乘增益，常取 0.1 V⁻¹） | — |
| **除法** | `u_o = −(R_2/(kR_1))·(u_i/u_X)` | — |
| **开方** | `u_o = √(−u_i/k)`（要求 `u_i < 0`） | — |
| **T 型网络反相比例** | `u_o = −[(R_2+R_3+R_2R_3/R_4)/R_1]u_i` | 用大电阻实现大增益 |

**分析三步法（★必背）**：① 由虚断求同相端电位 `u_P`；② 由虚短得 `u_N = u_P`；③ 对反相端列 KCL 解 `u_o`。

### 6.2 有源滤波电路

| 类型 | 传递函数 | 截止频率 |
|---|---|---|
| ★ 一阶低通 | `A_u = A_up/(1 + jf/f_0)` | `f_0 = 1/(2πRC)` |
| ★ 一阶高通 | `A_u = A_up·(jf/f_0)/(1 + jf/f_0)` | `f_0 = 1/(2πRC)` |
| 二阶压控电压源低通 | `A_u = A_up/[1 − (f/f_0)² + j(f/f_0)/Q]` | ★ `Q = 1/(3 − A_up)`，须 `A_up < 3` |
| 带通 | 低频段高通 + 高频段低通 | `f_0 = √(f_L f_H)` |
| 带阻 | 双 T 网络 | — |

**有源滤波与无源滤波的区别**：有源滤波有**增益**、输入电阻高、输出电阻低、不用电感；但**受运放带宽限制**，只适合低频（< 1 MHz）。

### 6.3 预处理放大电路

| 电路 | 公式/特点 |
|---|---|
| **仪表放大器** | ★ `A_u = (1 + 2R/R_W)·(R_4/R_3)`；输入电阻极高、`K_CMR` 高、增益可调 |
| **电荷放大器** | `u_o = −Q/C_f`（与电缆电容无关，适合压电传感器） |
| **隔离放大器** | 用变压器或光耦隔离，`K_CMR` 极高 |
| 干扰抑制 | 屏蔽、双绞线、共模扼流圈、单点接地、差分传输 |

## 第 7 章 波形的发生和信号的转换

### 7.1 正弦波振荡电路（★必考）

| 公式/条件 | 含义 |
|---|---|
| ★ **平衡条件** `AF = 1` | 幅度 `\|AF\| = 1`，相位 `φ_A+φ_F = ±2nπ` |
| ★ **起振条件** | `\|AF\| > 1`，靠非线性元件自动稳幅到 `\|AF\| = 1` |
| 四个组成部分 | **放大电路 + 正反馈网络 + 选频网络 + 稳幅环节** |
| ★ **RC 桥式** | `f_0 = 1/(2πRC)`；RC 网络在 `f_0` 处衰减 1/3、相移 0 → 需 `A > 3`，即 `R_f > 2R_1` |
| ★ **变压器耦合 LC** | `f_0 = 1/(2π√(LC))`；靠变压器同名端满足相位条件 |
| ★ **三点式法则** | **「射同基反」**（与发射极相连的两个电抗元件同性质，与基极相连的两个电抗元件异性质） |
| ★ **电容三点式（考毕兹）** | `f_0 = 1/(2π√(LC))`，`C = C_1C_2/(C_1+C_2)` |
| ★ **电感三点式（哈特莱）** | `f_0 = 1/(2π√(LC))`，`L = L_1 + L_2 + 2M` |
| **石英晶体** | `f_s = 1/(2π√(LC_s))`（串联谐振），`f_p = f_s√(1 + C_s/C_0)`（并联谐振）；稳定度 10⁻¹⁰~10⁻¹¹ |
| 频率稳定度 | 石英 > LC > RC |

### 7.2 电压比较器

| 类型 | 阈值 | 特点 |
|---|---|---|
| ★ **单限比较器** | `U_T`（令 `u_P = u_N` 求得） | 只有一个阈值，输出两态 |
| ★ **滞回比较器** | `±U_T`，`U_T = U_Z R_2/(R_1+R_2)` | **回差** `ΔU = 2U_T`，抗干扰强；正反馈 |
| ★ **窗口比较器** | 两个阈值 `U_TL`、`U_TH` | 需两个比较器 + 二极管（或专用芯片） |
| 集成电压比较器 | — | 响应快（ns 级），输出电平可与数字电路兼容 |

**关键结论**：比较器中**虚短不成立**（工作在非线性区），只能用**虚断**与 `u_P = u_N`（临界状态）求阈值。输出电压只有 `±U_OM`（或加限幅后为 `±U_Z`）两个值。

### 7.3 非正弦波发生电路

| 电路 | 公式 |
|---|---|
| ★ **矩形波（方波）** | `T = 2RC·ln(1 + 2R_2/R_1)`（`R_1` 接比较器输出、`R_2` 接地），占空比可调时用二极管分离充放电回路 |
| ★ **三角波** | `U_om = U_Z·R_2/R_1`，`f = R_1/(4R_2RC)`（`T = 4R_2RC/R_1`）；`R_1` 接比较器输出、`R_2` 接积分器输出 |
| 锯齿波 | 三角波电路加二极管使充放电时间常数不等 |
| 函数发生器 | 用单片集成电路（如 ICL8038）产生方波、三角波、正弦波 |
| 波形变换 | 比较器（正弦→方波）、积分器（方波→三角波）、微分器（方波→尖脉冲）、精密整流（交流→直流） |

### 7.4 信号转换电路

| 电路 | 公式/要点 |
|---|---|
| **电压-电流转换（负载浮地）** | `i_L = u_i/R`（运放 + 晶体管） |
| **电压-电流转换（负载接地）** | 豪兰德电流源：`R_2/R_1 = R_4/R_3`，则 `i_L = u_i/R_1` |
| **精密整流** | 把二极管放进运放反馈环内，消除 0.7 V 死区，可整流出 mV 级信号 |
| **电压-频率转换（V-F）** | `f_o ∝ u_i`；用于 A/D 转换、传感器数字化 |

## 第 8 章 功率放大电路（★必考）

| 公式 | 含义/条件 |
|---|---|
| ★ **OCL 最大输出功率** | `P_om = V_CC²/(2R_L)`（忽略饱和压降）；`P_om = (V_CC−U_CES)²/(2R_L)`（考虑时） |
| ★ **OTL 最大输出功率** | `P_om = V_CC²/(8R_L)`（`U_om = V_CC/2`） |
| ★ **电源提供的功率** | `P_V = 2V_CC·U_om/(πR_L)`（OCL）；最大时 `P_Vm = 2V_CC²/(πR_L)` |
| ★ **效率** | `η = P_o/P_V = (π/4)·(U_om/V_CC)`；**乙类最高 78.5%**（`U_om = V_CC` 时） |
| ★ **单管管耗** | `P_T1 = (1/R_L)(V_CC U_om/π − U_om²/4)`；最大在 `U_om = 2V_CC/π ≈ 0.637V_CC` |
| ★ **最大管耗** | `P_T1(max) = V_CC²/(π²R_L) ≈ 0.2P_om`，两管合计 `≈ 0.4P_om` |
| ★ **选管三准则** | `P_CM ≥ 0.2P_om`；`U_(BR)CEO ≥ 2V_CC`；`I_CM ≥ V_CC/R_L` |
| **甲类效率** | 变压器耦合 ≤ 50%，直接耦合 ≤ 25% |
| **复合管** | `β ≈ β_1β_2`，类型看**第一只**管子 |
| **`U_BE` 倍增电路** | `U_CE = U_BE(1 + R_1/R_2)`，用于给输出管提供偏置消除交越失真 |
| **散热** | `R_θ总 = R_θjc + R_θcs + R_θsa`；`P_CM = (T_jm − T_a)/R_θ总` |

**交越失真**：乙类电路在输入信号过零附近两管都截止，输出出现平顶失真。**消除方法**：给输出管加静态偏置（二极管、`U_BE` 倍增电路），使电路工作在**甲乙类**。

## 第 9 章 直流电源

| 环节 | 公式 |
|---|---|
| 组成 | 变压器 → 整流 → 滤波 → 稳压 |
| ★ **单相半波整流** | `U_o = 0.45U_2`，`I_D = I_o`，`U_RM = √2U_2` |
| ★ **单相桥式整流** | `U_o = 0.9U_2`，`I_D(AV) = I_o/2`，`U_RM = √2U_2` |
| ★ **电容滤波** | `U_o ≈ 1.2U_2`（桥式），`C ≥ (3~5)T/(2R_L)`，`T = 20 ms` |
| **滤波电容耐压** | `≥ √2U_2`（留 1.5~2 倍余量） |
| **倍压整流** | 二倍压 `U_o = 2√2U_2`；只适合小电流 |
| ★ **稳压管电路** | `U_o = U_Z`；`(U_Imin−U_Z)/(I_Zmax+I_Lmin) ≤ R ≤ (U_Imax−U_Z)/(I_Zmin+I_Lmax)` |
| **稳压管性能** | `S_r = (ΔU_o/U_o)/(ΔU_I/U_I) ≈ r_Z/R`；`R_o ≈ r_Z` |
| ★ **串联型稳压** | `U_o = U_Z(1 + R_1/R_下)`；组成：调整管 + 采样 + 基准 + 比较放大 |
| **串联型效率** | `η ≈ U_o/U_I`（30%~50%）；调整管管耗 `P_T = (U_I−U_o)I_L` |
| ★ **三端稳压器** | 78xx 固定正、79xx 固定负、LM317/LM337 可调；压差 `≥ 2~3 V` |
| ★ **LM317** | `U_o = 1.25(1 + R_2/R_1)`，`R_1` 取 240 Ω |
| **三端稳压器功耗** | `P = (U_I − U_o)·I_o`；`P > 1 W` 需散热片 |
| ★ **开关型（串联/Buck）** | `U_o = U_I·D`（`D` 为占空比），效率 70%~95% |
| ★ **开关型（并联/Boost）** | `U_o = U_I/(1 − D)` |

## 第 10 章 模拟电子电路读图

| 步骤 | 内容 |
|---|---|
| ① | 找电源与地（单电源还是双电源） |
| ② | 划分功能块（输入级 / 中间级 / 输出级 / 反馈网络 / 电源） |
| ③ | 辨核心器件与组态（共射/共集/共基、运放输入方式） |
| ④ | 算直流通路（电容开路）→ Q 点与静态电位 |

**速记要点**：双电源电路静态输出 **0 V**，单电源 OTL 为 **`V_CC/2`**；故障分析口诀 **「静态看电位，动态看波形，频率看电容，失真看 Q 点」**。

## 五大必考题型公式索引

| 题型 | 核心公式 | 对应章节 |
|---|---|---|
| **① Q 点计算** | 分压式四步法：`U_BQ → U_EQ → I_EQ → U_CEQ`；`I_CQ = βI_BQ`（固定偏置） | 第 2 章 2.1、2.4 |
| **② 微变等效求增益** | `r_be = r_bb'+(1+β)26mV/I_EQ`；`A_u = −βR_L'/r_be`；`R_i = R_b∥r_be`；`R_o ≈ R_c` | 第 2 章 2.3 |
| **③ 反馈组态判断** | 瞬时极性法 + 输出短路法（电压/电流）+ 输入节点法（串联/并联）；`A_f = A/(1+AF)`，深度负反馈 `A_f ≈ 1/F` | 第 5 章 5.2、5.4 |
| **④ 功放计算** | `P_om = V_CC²/(2R_L)`（OCL）/`V_CC²/(8R_L)`（OTL）；`η = (π/4)(U_om/V_CC)`；`P_T1(max) ≈ 0.2P_om` | 第 8 章 8.2 |
| **⑤ 振荡频率计算** | RC 桥式 `f_0 = 1/(2πRC)`；LC `f_0 = 1/(2π√(LC))`；考毕兹 `C = C_1C_2/(C_1+C_2)`；哈特莱 `L = L_1+L_2+2M` | 第 7 章 7.1 |

**统一解题框架（五步）**：
1. **判电路**——这是什么组态/什么功能的电路？
2. **算直流**——画直流通路，求 Q 点（`I_CQ`、`U_CEQ`，FET 则 `I_DQ`、`U_DSQ`）。
3. **算参数**——由 `I_EQ` 求 `r_be`（或由 `I_DQ` 求 `g_m`）。
4. **画交流**——直流电源接地、电容短路，画微变等效电路。
5. **列方程求解**——用 KCL/KVL 或公式得到 `A_u`、`R_i`、`R_o`（或题目要求的其它量），**最后检查量纲与合理性**。
