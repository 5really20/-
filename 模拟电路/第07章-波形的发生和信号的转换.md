## 7.1 正弦波振荡电路

### 7.1.1 概述

**正弦波振荡电路（sinusoidal oscillator）是在没有外加输入信号的条件下，靠正反馈和选频网络自行产生稳定正弦波输出的电路。**

#### （1）产生正弦波振荡的条件

把放大电路与反馈网络接成闭环，令输入信号 `x_i = 0`，则输出为

`x_o = A·x_f = A·F·x_o` → `(1 − AF)x_o = 0`

要得到非零的 `x_o`，必须有

**`AF = 1`（正弦波振荡的平衡条件）**

分解为两个条件：

| 条件 | 表达式 | 含义 |
|---|---|---|
| **幅度条件** | `\|AF\| = 1` | 环路增益为 1，输出幅度稳定不变 |
| **相位条件** | `φ_A + φ_F = ±2nπ`（n = 0, 1, 2…） | 正反馈，同相位 |

**起振条件**：`|AF| > 1`（幅度逐渐增长），**起振时的相位条件与平衡时相同**。振荡建立后靠**稳幅环节**（非线性元件）把 `|AF|` 自动降到 1。

> **注意与负反馈自激的区别**：负反馈的自激是「不希望的、附加相移造成的」；正弦波振荡是「故意设计的、靠选频网络实现的」正反馈。但二者的数学条件在形式上都归结为 `AF = 1`（相位差 180° 时则为 `AF = −1`）。

#### （2）正弦波振荡电路的组成

| 组成部分 | 作用 |
|---|---|
| **放大电路** | 提供能量，保证 `\|AF\| > 1` |
| **正反馈网络** | 把输出送回输入端，满足相位条件 |
| **选频网络** | 只在特定频率 `f_0` 上满足相位与幅度条件，决定振荡频率 |
| **稳幅环节** | 自动把 `\|AF\|` 从大于 1 降到等于 1，稳定输出幅度 |

**分类（按选频网络）**：RC 振荡（低频，几 Hz~几百 kHz）、LC 振荡（高频，几百 kHz~几百 MHz）、石英晶体振荡（频率稳定度最高）。

### 7.1.2 RC 正弦波振荡电路

**RC 桥式振荡电路（文氏桥振荡器，Wien-bridge oscillator）由同相比例放大电路 + RC 串并联选频网络组成，`f_0 = 1/(2πRC)`，起振条件是电压增益 `A > 3`。**

```text
              ┌──────── R_f ────────┐
              │                     │
              │   ┌─────┐           │
              │   │  A  │           │
       ┌──────┼───┤+    │           │
       │      │   │   >─┼───────────┴─── u_o
       │  ┌───┼───┤−    │
       │  │   │   └─────┘
       │  │   └── R_1 ── 地
       │  │
   ┌───┴──┴─── RC 串并联选频网络 ───┐
   │  R 串 C（Z_1）      R∥C（Z_2） │
   └────────────────────────────────┘
```

#### （1）RC 串并联网络的选频特性

设串联臂 `Z_1 = R + 1/(jωC)`，并联臂 `Z_2 = R ∥ (1/jωC)`，反馈系数

`F = Z_2/(Z_1 + Z_2) = 1/[3 + j(ωRC − 1/(ωRC))]`

令 `ω_0 = 1/(RC)`（即 `f_0 = 1/(2πRC)`），则 `F = 1/3`，且相移为 **0°**。

**结论：在 `f = f_0` 处，RC 网络输出为输入的 1/3，且相位相同——这就是选频作用。**

#### （2）振荡频率与起振条件

**`f_0 = 1/(2πRC)`**

放大电路是同相比例，相移为 0°，RC 网络在 `f_0` 处相移也为 0°，总相移 360° → **满足相位条件**。

幅度条件：`|AF| = A × (1/3) = 1` → `A = 3`；起振需 `A > 3`，即

`1 + R_f/R_1 > 3` → **`R_f > 2R_1`**

#### （3）稳幅措施

若 `A` 恒大于 3，输出幅度会不断增长直至运放饱和（输出变成方波）。**稳幅就是让 `A` 随幅度自动下降。**

| 稳幅方法 | 做法 | 原理 |
|---|---|---|
| **热敏电阻稳幅** | `R_f` 用负温度系数热敏电阻 | 幅度增大 → 电流增大 → 温度升高 → `R_f` 减小 → `A` 下降 |
| **二极管稳幅** | `R_f` 支路并联两只反向二极管 | 幅度大时二极管导通，等效 `R_f` 减小 → `A` 下降 |
| 场效应管稳幅 | 用 JFET 的可变电阻特性 | 自动增益控制（AGC） |

**实用提示**：`R_f` 取略大于 `2R_1`（如 2.1 倍），使起振容易、稳幅后波形失真小。

### 7.1.3 LC 正弦波振荡电路

**LC 振荡电路用 LC 并联谐振回路作选频网络，`f_0 = 1/(2π√(LC))`，适用于高频（几百 kHz 以上）。**

#### （1）LC 并联谐振回路

| 频率 | 回路阻抗 | 相位 |
|---|---|---|
| `f < f_0` | 感性（电感分量占优） | 电流滞后 |
| `f = f_0` | **纯阻性且最大** | 电流与电压同相 |
| `f > f_0` | 容性 | 电流超前 |

**品质因数** `Q = ω_0 L/R = R/(ω_0 L)`（R 为回路等效串联损耗电阻），`Q` 越大选频特性越尖锐。

#### （2）变压器耦合式 LC 振荡电路

**用变压器实现正反馈：反馈电压由副边绕组提供，只要同名端接对就满足相位条件。**

`f_0 = 1/(2π√(LC))`（忽略变压器的影响）

**优点**：容易起振、输出与反馈可分别取不同绕组；**缺点**：体积大、高频时分布参数影响大。

#### （3）三点式 LC 振荡电路

**三点式电路把 LC 回路的三个端点分别接在三极管的三个电极上，其组成法则为「射同基反」：与发射极相连的两个电抗元件必须同性质；与基极（或集电极）相连的两个电抗元件必须异性质。**

**为什么？** 从三极管看出去，要满足正反馈的相位条件，必须使反馈电压与输入电压同相；「射同基反」正是满足该条件的电抗配置。若接反，则变成负反馈，电路不起振。

| 类型 | 别称 | 电抗配置 | 振荡频率 |
|---|---|---|---|
| **电容三点式** | 考毕兹（Colpitts） | 两个电容 + 一个电感 | `f_0 = 1/(2π√(L·C))`，`C = C_1C_2/(C_1+C_2)` |
| **电感三点式** | 哈特莱（Hartley） | 两个电感 + 一个电容 | `f_0 = 1/(2π√(L·C))`，`L = L_1 + L_2 + 2M` |

```text
   电容三点式（考毕兹）              电感三点式（哈特莱）
        ┌── L ──┐                     ┌── C ──┐
        │       │                     │       │
   ─────┤       ├─────           ─────┤       ├─────
        │       │                     │       │
       C_1     C_2                   L_1     L_2
        │       │                     │       │
        └───┬───┘                     └───┬───┘
          发射极                          发射极
```

| 比较项 | 电容三点式（考毕兹） | 电感三点式（哈特莱） |
|---|---|---|
| 反馈取自 | 电容分压 | 电感分压 |
| 波形质量 | **好**（电容对高次谐波阻抗小） | 较差（电感对高次谐波阻抗大） |
| 起振难度 | 较难 | **容易** |
| 频率调节 | 调 C 方便 | 调 C 方便 |
| 适用频率 | 高频、甚高频 | 中高频 |

### 7.1.4 石英晶体正弦波振荡电路

**石英晶体（quartz crystal）利用压电效应工作，其等效电路为「L、C_s 串联再与 C_0 并联」，Q 值可达 10⁴~10⁶，频率稳定度可达 10⁻¹⁰~10⁻¹¹，是要求高稳定度振荡的唯一选择。**

**两个谐振频率**：

| 频率 | 名称 | 特点 |
|---|---|---|
| `f_s = 1/(2π√(L C_s))` | 串联谐振频率 | 晶体呈**纯阻性且阻抗最小** |
| `f_p = f_s·√(1 + C_s/C_0)` | 并联谐振频率 | 晶体呈纯阻性且阻抗最大 |

由于 `C_s << C_0`，`f_p` 只比 `f_s` 高千分之几，**晶体只在极窄的 `f_s~f_p` 区间内呈感性**，其余频率范围呈容性——这正是它频率稳定度极高的原因。

| 振荡电路类型 | 晶体工作状态 | 特点 |
|---|---|---|
| **并联型** | 晶体作电感用（工作于 `f_s~f_p` 之间的感性区） | 与三点式电路配合，振荡频率略高于 `f_s` |
| **串联型** | 晶体工作于 `f_s`（串联谐振，阻抗最小） | 反馈最强，频率恰为 `f_s` |

> **为什么石英晶体这么稳？** ① 晶体的 `Q` 值极高（比 LC 回路高 3~4 个数量级）；② 晶体的谐振频率由晶片尺寸（机械共振）决定，几乎不受温度、电源电压、负载影响；③ 温度特性可通过切型设计（如 AT 切）做得极平坦。

## 7.2 电压比较器

### 7.2.1 概述

**电压比较器（voltage comparator）用来比较输入电压与参考电压的大小，输出只有高电平、低电平两种状态；运放工作在开环或正反馈状态（非线性区）。**

**分析方法（与运算电路完全不同）**：

1. 运放工作在**非线性区**，`u_o = ±U_OM`（或由稳压管钳位的 `±U_Z`）；
2. **虚短不成立**，但**虚断成立**（`i_P = i_N = 0`）；
3. 求**阈值电压**：令 `u_P = u_N`，解出的 `u_i` 就是输出发生跳变时的输入电压；
4. 判断输出状态：`u_P > u_N` 时 `u_o = +U_OM`；`u_P < u_N` 时 `u_o = −U_OM`；
5. 画出**电压传输特性**（`u_o` 对 `u_i` 的折线图）。

| 类型 | 阈值个数 | 特点 | 用途 |
|---|---|---|---|
| 单限比较器 | 1 | 最简单，抗干扰差 | 电平检测、波形变换 |
| 滞回比较器 | 2 | 有回差，抗干扰强 | 施密特触发器、波形整形 |
| 窗口比较器 | 2 | 判断输入是否在区间内 | 电压监视、报警 |

### 7.2.2 单限比较器

**只有一个阈值电压 `U_T` 的比较器；输入单方向变化时输出只跳变一次。**

#### （1）过零比较器

**参考电压为 0 的比较器，阈值 `U_T = 0`；输入正弦波时输出为方波。**

`u_i > 0` → `u_o = −U_OM`（若 `u_i` 接反相端）；`u_i < 0` → `u_o = +U_OM`

#### （2）一般单限比较器

阈值由参考电压与电阻分压决定。设输入接反相端，同相端接参考电压 `U_R`：

**`U_T = U_R`**；`u_i > U_R` 时 `u_o = −U_OM`，`u_i < U_R` 时 `u_o = +U_OM`。

**限幅措施**：在输出端接双向稳压管（`±U_Z`）或加限幅电路，使输出电平与后级逻辑电路匹配。

**缺点**：若输入信号上叠加噪声，在阈值附近输出会反复跳变（多次翻转）。

### 7.2.3 滞回比较器

**滞回比较器（施密特触发器，Schmitt trigger）引入正反馈，使输出翻转后阈值随之改变，形成两个阈值 `U_T1`、`U_T2`，二者之差称为回差（滞回电压）`ΔU = U_T1 − U_T2`。**

```text
   u_o                     u_o
    │  +U_Z                 │   ┌────────┐
    │   ┌──────┐            │   │        │
    │   │      │            │───┘        └────
────┼───┘      └──── u_i    │  U_T2   U_T1   u_i
    │  U_T2  U_T1           │   ← 回差 ΔU →
```

**阈值计算（常用电路）**：输出经 `R_1` 反馈到同相端、同相端再经 `R_2` 接地，输入接反相端（即 `R_1` 接输出、`R_2` 接地）：

`U_T1 = +U_Z·R_2/(R_1+R_2)`（输出为高时）
`U_T2 = −U_Z·R_2/(R_1+R_2)`（输出为低时）

`ΔU = U_T1 − U_T2 = 2U_Z·R_2/(R_1+R_2)`

**回差的作用**：只要噪声幅度小于 `ΔU/2`，输出就不会误翻转——**这就是滞回比较器抗干扰的原因**。

**注意**：输入信号必须**先经过一次跳变**才能进入滞回特性；若输入幅度小于阈值，输出不变。另外，滞回比较器**不能判断输入是否过零**（因为阈值不对称时会有偏移），做精密过零检测要用单限比较器。

### 7.2.4 窗口比较器

**窗口比较器（window comparator）用两个单限比较器 + 逻辑电路构成，当输入电压落在 `U_TL ~ U_TH` 之间（或之外）时输出特定电平。**

组成：一个比较器的阈值取 `U_TH`（上限），另一个取 `U_TL`（下限），两者输出经二极管或门（或逻辑门）组合。

| 输入范围 | 输出（窗口内报警型） |
|---|---|
| `u_i < U_TL` | 报警（低电平） |
| `U_TL < u_i < U_TH` | 正常（高电平） |
| `u_i > U_TH` | 报警（低电平） |

用途：电源电压监视、电池电量检测、温度超限报警。

### 7.2.5 集成电压比较器

**集成电压比较器（如 LM339、LM393、AD790）是专为比较功能设计的器件，转换速度、输出电平与驱动能力都优于普通运放。**

| 器件 | 特点 |
|---|---|
| LM339 / LM393 | 四/二比较器，集电极开路输出，需外接上拉电阻，价格低 |
| LM311 | 可驱动继电器/指示灯，输出灵活 |
| AD790 | 高速精密比较器，传输延迟 ns 级 |

**与运放作比较器的区别**：① 比较器**不能**作运算放大使用（内部无相位补偿，闭环会自激）；② 比较器输出电平可配 TTL/CMOS；③ 比较器的转换速率（压摆率）高得多。

## 7.3 非正弦波发生电路

### 7.3.1 矩形波发生电路

**矩形波发生电路由滞回比较器 + RC 充放电回路组成：电容电压在上下阈值之间往复充放电，比较器输出随之在高、低电平间跳变。**

```text
        ┌──────────── R_1（正反馈）────────────┐
        │                                       │
        │    ┌───────────┐                      │
        └───►│ +         │                      │
             │  比较器 A ├──────────────────────┴── u_o（矩形波，±U_Z）
   u_C ─────►│ −         │          │
             └───────────┘         ┌┴┐ R
      同相端还经 R_2 接地            └┬┘
                                   ├──── u_C（电容电压，送反相端）
                                  ┌┴┐
                                  │ │ C
                                  └┬┘
                                   │
                                   地
```

**约定（全书统一）**：`R_1` 为**接比较器输出的反馈电阻**，`R_2` 为**接地的电阻**。于是两个阈值是 `±U_Z·R_2/(R_1+R_2)`，与 7.2.3 完全一致。

**振荡周期：`T = 2RC·ln(1 + 2R_2/R_1)`**

推导要点：电容充电时从 `U_T2` 充到 `U_T1`，目标值为 `±U_Z`，时间常数 `RC`；由一阶 RC 充电公式解出半周期 `T/2 = RC ln(1 + 2R_2/R_1)`（把 `k = R_2/(R_1+R_2)` 代入 `ln[(1+k)/(1−k)]` 即得）。

**占空比可调**：把充放电回路分开（用两只二极管分别控制充电与放电的电阻），即可得到矩形波（占空比 ≠ 50%）甚至窄脉冲。

### 7.3.2 三角波发生电路

**三角波发生电路由滞回比较器 + 积分器组成：比较器输出方波，积分器把方波积分成三角波，三角波又反馈回比较器形成闭环。**

**振荡频率：`f = R_1/(4R_2RC)`**（`R_1` 为接比较器输出的反馈电阻，`R_2` 为接积分器输出端的电阻——注意它**不接地**）

**输出幅度：`U_om = U_Z·R_2/R_1`**

推导要点：比较器同相端由 `R_1`（接比较器输出 `±U_Z`）与 `R_2`（接积分器输出 `u_o2`）两个支路共同决定，翻转发生在该节点电位为零时，即 `U_Z/R_1 + u_o2/R_2 = 0` → `u_o2 = ∓U_Z R_2/R_1`；积分器输出斜率为 `U_Z/(RC)`，三角波从 `−U_om` 到 `+U_om` 需时 `2U_om·RC/U_Z`，故 `T = 4U_om RC/U_Z = 4R_2RC/R_1`。

**同时输出方波与三角波**：比较器输出为方波，积分器输出为三角波，一电路两用。

### 7.3.3 锯齿波发生电路

**在三角波发生电路中，使充电与放电的时间常数不同（用二极管切换不同阻值的电阻），就得到上升与下降时间不等的锯齿波。**

`T = T_1 + T_2`，其中 `T_1 = 2U_om R C_1/U_Z`、`T_2 = 2U_om R C_2/U_Z`（或改用不同电阻 `R`）。

**用途**：示波器的时基扫描电路（扫描正程慢、回程快）、PWM 调制。

### 7.3.4 波形变换电路

**利用比较器与积分器可实现各种波形之间的转换。**

| 输入波形 | 变换电路 | 输出波形 |
|---|---|---|
| 正弦波 | 过零比较器 | 方波 |
| 方波 | 积分器 | 三角波 |
| 三角波 | 微分器 | 方波 |
| 三角波 | 折线近似电路 | 正弦波（分段线性逼近） |
| 方波 | 微分 + 限幅 | 尖脉冲 |
| 正弦波 | 精密整流 | 单向脉动波形 |

> **正弦波发生器也可以用「方波 → 三角波 → 折线近似」的路径实现**（函数发生器的思路），但波形纯度不如 RC 桥式振荡电路。

### 7.3.5 函数发生器

**函数发生器（function generator）能同时输出正弦波、方波、三角波，且频率与幅度可调，典型芯片有 ICL8038、MAX038、XR2206。**

| 芯片 | 特点 |
|---|---|
| ICL8038 | 经典，可输出正弦/方波/三角波，频率 0.001 Hz~300 kHz，需外接定时电容 |
| MAX038 | 高频（0.1 Hz~20 MHz），波形切换方便 |
| XR2206 | 失真小，常用于教学仪器 |

**频率调节方式**：改变外接定时电容 `C`（分档）或改变控制电流（连续可调）。

## 7.4 利用集成运放实现的信号转换电路

### 7.4.1 电压-电流转换电路

**电压-电流转换（V-I 转换）电路把输入电压线性地转换成输出电流，要求转换关系与负载电阻 `R_L` 无关。**

#### （1）负载浮地式

**把负载接在反馈支路中，`i_L = u_i/R`，与 `R_L` 无关。**

推导：虚短使 `R` 上端电位为 `u_i`、下端为 0（虚地），故 `i_R = u_i/R`；虚断使该电流全部流过 `R_L`，即 `i_L = u_i/R`。

**缺点**：负载两端都不接地（浮地），使用不便。

#### （2）负载接地式（豪兰德电流泵）

**用四个电阻构成正反馈与负反馈并存的电路，负载可以接地；当满足 `R_2/R_1 = R_4/R_3` 时，`i_L = u_i/R_1`。**

**关键条件**：`R_2/R_1 = R_4/R_3`（电阻匹配条件），不满足则输出电流与 `R_L` 有关。

**用途**：传感器恒流激励、LED 恒流驱动、电化学测量。

### 7.4.2 精密整流电路

**精密整流电路用运放把二极管包含在反馈环内，消除了二极管 0.7 V 的死区电压，可以对毫伏级信号进行整流。**

| 电路 | 组成 | 输出 |
|---|---|---|
| 普通二极管半波整流 | 二极管 + 负载 | 损失 0.7 V，小信号无法整流 |
| 精密半波整流 | 运放 + 二极管（反馈环内） | 输出等于输入的正半周（或负半周），无死区 |
| 精密全波整流 | 两级运放 + 两个二极管 | 输出为输入绝对值 `\|u_i\|` |

**为什么能消除死区？** 二极管在反馈环内，运放的高增益使 `u_P − u_N ≈ 0`；即使输入只有 1 mV，运放也会输出足够高的电压使二极管导通，从而保证整流关系式 `u_o = −(R_f/R_1)u_i` 在整个周期内成立（除过零附近极窄的区间）。

**用途**：交流电压表（有效值检测）、信号绝对值运算、调幅波检波。

### 7.4.3 电压-频率转换电路

**电压-频率转换（V-F 转换）电路把输入电压转换成频率与之成正比的脉冲输出，`f_o = k u_i`。**

**典型组成**：积分器 + 比较器 + 恒流源（复位开关）。输入电压控制积分器的充电电流，积分器输出达到阈值时比较器翻转，触发开关把积分电容复位，如此循环。**输入电压越高，充电越快，复位越频繁，输出频率越高。**

| 用途 | 说明 |
|---|---|
| A/D 转换 | V-F 转换是积分型 A/D 的一种实现方式，抗干扰强 |
| 信号传输 | 频率信号抗干扰、便于光电隔离与远距离传输 |
| 调频 | 与 F-V 转换配合构成锁相环（PLL） |

## 7.5 Multisim 应用举例

1. **RC 桥式振荡电路**：用交流扫描分析观察 RC 网络的选频特性，验证 `f_0 = 1/(2πRC)`；用瞬态分析观察起振过程与稳幅波形。
2. **滞回比较器**：用直流扫描分析（DC Sweep）直接得到电压传输特性曲线，读出两个阈值。
3. **矩形波/三角波发生器**：用瞬态分析同时观察两路输出，验证 `T = 2RC ln(1 + 2R_2/R_1)`。
4. **精密整流**：输入 10 mV 正弦波，比较普通二极管整流与精密整流的输出差别。
5. **注意**：振荡电路仿真时常需要给一个初始扰动（如设置电容初始电压）才能起振。

## 典型例题

**例 7.1**（题型：RC 桥式振荡电路——★必考）
RC 桥式振荡电路：`R = 16 kΩ`，`C = 0.01 μF`，`R_1 = 10 kΩ`。求振荡频率 `f_0`；求起振所需的 `R_f` 最小值。

**解**：
`f_0 = 1/(2πRC) = 1/(2π × 16×10³ × 0.01×10⁻⁶) = 1/(2π × 1.6×10⁻⁴) = 995 Hz ≈ 1 kHz`
起振条件 `A > 3`，即 `1 + R_f/R_1 > 3` → `R_f > 2R_1 = 2 × 10 kΩ = 20 kΩ`

**答案**：`f_0 ≈ 995 Hz`（约 1 kHz）；`R_f` 应略大于 20 kΩ，实际取 22 kΩ（或用热敏电阻稳幅）。
**校验**：若取 `R_f = 20 kΩ`，则 `A = 3`，处于临界状态（理论上等幅振荡，实际因元件误差不会起振），所以必须略大。

**例 7.2**（题型：LC 电容三点式振荡电路——★必考）
考毕兹振荡电路：`L = 1 mH`，`C_1 = 100 pF`，`C_2 = 200 pF`。求振荡频率 `f_0`。

**解**：
`C = C_1C_2/(C_1+C_2) = (100 × 200)/(100 + 200) = 20 000/300 = 66.7 pF`
`f_0 = 1/(2π√(LC)) = 1/(2π × √(1×10⁻³ × 66.7×10⁻¹²))`
`√(6.67×10⁻¹⁴) = 2.582×10⁻⁷`
`f_0 = 1/(2π × 2.582×10⁻⁷) = 6.16×10⁵ Hz = 616 kHz`

**答案**：`f_0 = 616 kHz`。
**注意**：计算时必须用 `C_1`、`C_2` 的**串联值**，不能只用其中一个。

**例 7.3**（题型：LC 电感三点式振荡电路）
哈特莱振荡电路：`L_1 = 100 μH`，`L_2 = 100 μH`，互感 `M = 0`，`C = 200 pF`。求振荡频率。

**解**：
`L = L_1 + L_2 + 2M = 100 + 100 + 0 = 200 μH`
`f_0 = 1/(2π√(LC)) = 1/(2π × √(200×10⁻⁶ × 200×10⁻¹²))`
`√(4×10⁻¹⁴) = 2×10⁻⁷`
`f_0 = 1/(2π × 2×10⁻⁷) = 7.96×10⁵ Hz = 796 kHz`

**答案**：`f_0 = 796 kHz`。
**若两线圈有互感 `M = 20 μH`**：`L = 100 + 100 + 40 = 240 μH`，`f_0 = 1/(2π√(240×10⁻⁶ × 200×10⁻¹²)) = 1/(2π × 2.19×10⁻⁷) = 727 kHz`，频率下降。

**例 7.4**（题型：三点式电路能否振荡的判断——★常考）
某三点式 LC 振荡电路中，三极管发射极接一个电容 `C_1` 和一个电感 `L_1`，基极接电感 `L_1` 与电感 `L_2` 的串联点。判断该电路能否振荡，属于哪种类型。

**解**：
**列出与各电极相连的元件**：发射极接 `C_1` 与 `L_1`；基极接 `L_1` 与 `L_2`；集电极接 `L_2` 与 `C_1`。
**用「射同基反」法则检查**：与发射极相连的是 `C_1`（电容）与 `L_1`（电感）——**性质不同** → **不满足组成法则，不能振荡**。
**若把 `L_1` 换成电容 `C_2`**：发射极接 `C_1`、`C_2`（同为电容，同性质 ✓）；基极接 `C_2` 与 `L_2`（电容与电感，异性质 ✓）→ **可以振荡，属于电容三点式（考毕兹）电路**。

**答案**：原电路不能振荡（发射极上两个元件性质不同）；改为两个电容后成为电容三点式，可以振荡。
**口诀**：**「射同基反」**——先看发射极，两个元件必须同类；再看基极（或集电极），两个元件必须异类。

**例 7.5**（题型：单限比较器阈值与传输特性）
某单限比较器：输入 `u_i` 经 `R_1` 接反相端，同相端接参考电压 `U_R = 2 V`，输出经双向稳压管限幅为 `±6 V`。求阈值电压与电压传输特性。

**解**：
阈值：令 `u_N = u_P` → `u_i = U_R = 2 V`，故 `U_T = 2 V`
当 `u_i > 2 V`：`u_N > u_P` → `u_o = −6 V`
当 `u_i < 2 V`：`u_N < u_P` → `u_o = +6 V`

**答案**：`U_T = 2 V`；`u_i > 2 V` 时输出 −6 V，`u_i < 2 V` 时输出 +6 V，传输特性为一条在 `U_T` 处从 +6 V 跳到 −6 V 的折线。
**提示**：若输入正弦波幅值大于 2 V，输出为方波，但占空比不是 50%（因为阈值不在 0）。

**例 7.6**（题型：滞回比较器阈值与回差——★必考）
滞回比较器：输出经双向稳压管限幅为 `±U_Z = ±6 V`，输出经 `R_1 = 20 kΩ` 反馈到同相端，同相端经 `R_2 = 10 kΩ` 接地，输入接反相端。求 `U_T1`、`U_T2` 与回差 `ΔU`。

**解**：
输出为高（`+6 V`）时同相端电位：
`u_P1 = U_Z·R_2/(R_1+R_2) = 6 × 10/(20+10) = 6 × 10/30 = 2 V`
输出为低（`−6 V`）时：
`u_P2 = −6 × 10/30 = −2 V`
阈值：`U_T1 = u_P1 = +2 V`（输出由**高变低**的阈值：输入从低往上升过 +2 V 时，`u_N > u_P`，输出由 +6 V 跳到 −6 V），`U_T2 = u_P2 = −2 V`（输出由低变高的阈值：输入往下降过 −2 V 时输出跳回 +6 V）
回差：`ΔU = U_T1 − U_T2 = 2 − (−2) = 4 V`

**答案**：`U_T1 = +2 V`，`U_T2 = −2 V`，`ΔU = 4 V`。
**抗干扰能力**：只要输入端噪声幅度小于 `ΔU/2 = 2 V`，输出就不会误翻转。**代价**：输入信号幅度必须大于 `ΔU` 才能引起翻转。

**例 7.7**（题型：矩形波发生电路——★必考）
矩形波发生电路：`R = 10 kΩ`，`C = 0.1 μF`，`R_1 = 20 kΩ`，`R_2 = 10 kΩ`，输出限幅 `±U_Z = ±6 V`。求振荡周期与频率。

**解**：
比较器阈值（与例 7.6 同一组参数）：`±U_Z·R_2/(R_1+R_2) = ±6 × 10/30 = ±2 V`
`2R_2/R_1 = 2 × 10/20 = 1`
`ln(1 + 1) = ln 2 = 0.693`
`T = 2RC·ln(1 + 2R_2/R_1) = 2 × 10×10³ × 0.1×10⁻⁶ × 0.693`
`= 2 × 1×10⁻³ × 0.693 = 1.386×10⁻³ s ≈ 1.39 ms`
`f = 1/T = 1/(1.386×10⁻³) = 721.5 Hz ≈ 722 Hz`

**答案**：`T ≈ 1.39 ms`，`f ≈ 722 Hz`，占空比 50%。
**调节方法**：增大 `RC` 则频率降低；增大 `R_2/R_1`（回差变大）则频率降低。

**例 7.8**（题型：三角波发生电路）
三角波发生电路：比较器反馈电阻 `R_1 = 20 kΩ`（接比较器输出，构成正反馈）、`R_2 = 10 kΩ`（接积分器输出端，**不接地**），积分器 `R = 10 kΩ`、`C = 0.1 μF`，输出限幅 `±U_Z = ±6 V`。求三角波幅度与频率。

**解**：
三角波幅度：`U_om = U_Z·R_2/R_1 = 6 × 10/20 = 3 V`
频率：`f = R_1/(4R_2RC) = 20 000/(4 × 10 000 × 10 000 × 0.1×10⁻⁶)`
分母 `= 4 × 10⁴ × 10⁴ × 1×10⁻⁷ = 4 × 10⁸ × 10⁻⁷ = 40`
`f = 20 000/40 = 500 Hz`

**答案**：`U_om = 3 V`（峰峰值 6 V），`f = 500 Hz`；同时比较器输出为同频率的方波（幅值 ±6 V）。
**校验**：半周期 `T/2 = 1 ms`，三角波从 −3 V 升到 +3 V 需 6 V，积分斜率 `= U_Z/(RC) = 6/(10⁴×10⁻⁷) = 6/10⁻³ = 6000 V/s`，时间 `= 6/6000 = 1 ms` ✓

**例 7.9**（题型：精密整流电路）
精密半波整流电路：`R_1 = R_f = 10 kΩ`，输入 `u_i = 10 mV`（正弦）。求输出幅值，并与普通二极管整流比较。

**解**：
精密整流：虚短虚断使 `u_o = −(R_f/R_1)u_i = −1 × 10 mV = −10 mV`（在 `u_i` 的正半周）
普通二极管整流：二极管死区电压约 0.7 V，输入仅 10 mV 时二极管根本不导通，输出为 0

**答案**：精密整流输出幅值 10 mV（增益 −1）；普通二极管整流输出为 0（完全无法工作）。
**结论**：**精密整流可以处理毫伏级信号，这是普通二极管整流做不到的**——因为它把二极管放进了运放的反馈环内，用运放的高增益「抵消」了死区电压。

**例 7.10**（题型：电压-电流转换电路）
负载浮地式 V-I 转换电路：`R = 10 kΩ`，输入 `u_i = 2 V`，负载 `R_L` 从 0 变到 2 kΩ。求输出电流。

**解**：
`i_L = u_i/R = 2/(10×10³) = 2×10⁻⁴ A = 0.2 mA`
当 `R_L = 2 kΩ` 时，负载上的电压 `u_L = i_L R_L = 0.2 mA × 2 kΩ = 0.4 V`

**答案**：`i_L = 0.2 mA`，**与 `R_L` 无关**（只要运放输出不超出线性范围）。
**校验输出范围**：运放输出需提供 `u_i + u_L = 2 + 0.4 = 2.4 V`，远小于电源电压 ✓ 若 `R_L` 增大到 50 kΩ，则 `u_L = 10 V`，运放输出需 12 V，接近电源电压，可能进入饱和——**所以 V-I 转换电路的带载能力受电源电压限制**。

**例 7.11**（题型：石英晶体振荡电路）
某石英晶体振荡电路，晶体工作在串联谐振状态，`f_s = 1 MHz`；已知晶体等效参数 `C_s = 0.02 pF`、`C_0 = 5 pF`。求并联谐振频率 `f_p`，并说明频率稳定度的意义。

**解**：
`C_s/C_0 = 0.02/5 = 0.004`
`f_p = f_s·√(1 + C_s/C_0) = 1 MHz × √1.004 = 1 MHz × 1.002 = 1.002 MHz`

**答案**：`f_p = 1.002 MHz`，只比 `f_s` 高 0.2%。
**意义**：晶体只在 `1.000~1.002 MHz` 这个**极窄的区间内呈感性**，其余频率范围呈容性，因此振荡频率被牢牢锁定在 `f_s` 附近；再加上晶体 `Q` 值高达 10⁴~10⁶，故频率稳定度可达 10⁻¹⁰~10⁻¹¹（普通 LC 振荡只有 10⁻³~10⁻⁴）。
**应用**：电子表、计算机时钟、通信设备的频率源。

## 易错点提醒

1. **把正弦波振荡的相位条件写成 180°** → 是**正反馈**，总相移应为 `±2nπ`（即 0° 或 360° 的整数倍）；负反馈自激的相位条件是附加相移 180°。
2. **混淆平衡条件与起振条件** → 平衡条件 `|AF| = 1`，起振条件 `|AF| > 1`；起振后靠稳幅环节把 `|AF|` 降回 1。
3. **RC 桥式电路把起振条件写成 `A > 1`** → 因 RC 网络在 `f_0` 处衰减到 1/3，故需 `A > 3`，即 `R_f > 2R_1`。
4. **三点式电路判据记成「射反基同」** → 正确口诀是**「射同基反」**：与发射极相连的两个元件同性质，与基极相连的两个元件异性质。
5. **计算考毕兹频率时只用 `C_1` 或 `C_2`** → 必须用二者的**串联值** `C = C_1C_2/(C_1+C_2)`；哈特莱则用 `L = L_1 + L_2 + 2M`（有互感时）。
6. **认为石英晶体的 `f_s` 与 `f_p` 相差很大** → 只差千分之几；晶体只在两者之间呈感性。
7. **比较器电路中套用虚短** → 比较器工作在非线性区，**虚短不成立**（只有虚断成立）；求阈值时令 `u_P = u_N` 是「临界翻转条件」，不是虚短。
8. **滞回比较器的两个阈值算成同一个值** → 两个阈值分别对应输出为高、为低两种状态，必须先固定输出电平再算 `u_P`。
9. **认为滞回比较器可以精确检测过零** → 阈值对称时才行；一般滞回比较器有回差，不能做过零检测。
10. **矩形波周期公式漏掉系数 2** → 是 `T = 2RC ln(1 + 2R_2/R_1)`（`R_1` 为反馈电阻、`R_2` 为接地电阻），因为一个周期包含充电、放电两个半周期。
11. **认为积分器能把任意方波变成理想三角波** → 只有当 `RC >> T/2` 时输出才接近三角波，否则运放会饱和或波形严重失真。
12. **精密整流电路分析时忽略二极管的通断状态** → 必须分正、负半周分别分析，并注意运放输出端电压与输入电压的关系（第一级运放输出可能是二极管的压降加上信号）。

## 本章小结

- 正弦波振荡的**平衡条件 `AF = 1`**：幅度 `|AF| = 1`、相位 `φ_A + φ_F = ±2nπ`；**起振条件 `|AF| > 1`**。
- 组成：放大电路 + 正反馈网络 + 选频网络 + 稳幅环节。
- RC 桥式（文氏桥）：`f_0 = 1/(2πRC)`，RC 网络在 `f_0` 处衰减 1/3 且相移 0°，故要求 `A > 3`（`R_f > 2R_1`）；用热敏电阻或二极管稳幅。
- LC 振荡：`f_0 = 1/(2π√(LC))`；三点式组成法则**「射同基反」**；电容三点式（考毕兹）波形好，电感三点式（哈特莱）易起振。
- 石英晶体：`f_s` 串联谐振、`f_p` 并联谐振，`f_p` 只比 `f_s` 高千分之几，频率稳定度可达 10⁻¹⁰。
- 电压比较器工作在非线性区：**虚短不成立、虚断成立**；求阈值令 `u_P = u_N`。
- 单限比较器 1 个阈值；滞回比较器 2 个阈值 `U_T1 = ±U_Z R_2/(R_1+R_2)`，回差 `ΔU = 2U_Z R_2/(R_1+R_2)`，抗干扰；窗口比较器判断输入是否在区间内。
- 矩形波：`T = 2RC ln(1 + 2R_2/R_1)`（`R_1` 反馈、`R_2` 接地）；三角波：`U_om = U_Z R_2/R_1`、`f = R_1/(4R_2RC)`（`R_1` 反馈、`R_2` 接积分器输出）；锯齿波靠充放电时间常数不等实现。
- 波形变换：正弦→方波用比较器，方波→三角波用积分器，三角波→正弦用折线近似。
- V-I 转换：负载浮地式 `i_L = u_i/R`；负载接地式（豪兰德）需满足 `R_2/R_1 = R_4/R_3`。
- 精密整流把二极管放进反馈环，消除 0.7 V 死区，可整流毫伏级信号。
- V-F 转换：积分器 + 比较器 + 恒流复位，`f_o ∝ u_i`。

> **一句话记住本章**：**振荡就是「自己给自己喂信号」——选频网络决定喂什么频率，正反馈保证喂得对，稳幅环节保证喂得不多不少（AF 恰好为 1）；比较器则是把模拟量一刀切成两态。**

## 自测题

1. 写出正弦波振荡的平衡条件与起振条件，并说明选频网络的作用。
2. RC 桥式振荡电路的振荡频率如何计算？为什么要求放大倍数大于 3？常用的稳幅方法有哪些？
3. 三点式 LC 振荡电路的组成法则是什么？电容三点式与电感三点式各有什么优缺点？
4. 石英晶体有几个谐振频率？为什么它的频率稳定度极高？
5. 电压比较器与运算电路在分析方法上有什么根本区别？
6. 某滞回比较器 `U_Z = ±6 V`、`R_1 = 30 kΩ`、`R_2 = 10 kΩ`，求两个阈值与回差。
7. 写出矩形波发生电路的周期公式。`R = 20 kΩ`、`C = 0.05 μF`、`R_1 = R_2 = 10 kΩ` 时频率为多少？
8. 三角波发生电路的幅度与频率公式是什么？
9. 精密整流为什么能消除二极管的死区电压？
10. 电压-电流转换电路有哪两种结构？负载接地式的电阻匹配条件是什么？

**自测题答案**

1. 平衡条件 `AF = 1`（幅度 `|AF| = 1`、相位 `φ_A + φ_F = ±2nπ`）；起振条件 `|AF| > 1`；选频网络使电路只在 `f_0` 处满足相位与幅度条件，从而决定振荡频率。
2. `f_0 = 1/(2πRC)`；RC 串并联网络在 `f_0` 处把输出衰减到输入的 1/3，故需 `A > 3`（`R_f > 2R_1`）；稳幅方法有热敏电阻稳幅、二极管稳幅、场效应管稳幅。
3. 「射同基反」：与发射极相连的两个电抗元件同性质，与基极相连的两个异性质；电容三点式波形好但起振稍难，电感三点式易起振但波形较差。
4. 两个：串联谐振频率 `f_s` 和并联谐振频率 `f_p = f_s√(1 + C_s/C_0)`，两者只差千分之几；因晶体 `Q` 值极高（10⁴~10⁶）且频率由机械共振决定，几乎不受温度与电源影响。
5. 比较器工作在非线性区，输出只有两态，**虚短不成立**（虚断成立），分析时令 `u_P = u_N` 求阈值并画传输特性；运算电路工作在线性区且引入负反馈，虚短虚断都成立。
6. `U_T1 = 6 × 10/40 = 1.5 V`，`U_T2 = −1.5 V`，`ΔU = 3 V`。
7. `T = 2RC ln(1 + 2R_2/R_1) = 2 × 20×10³ × 0.05×10⁻⁶ × ln 3 = 2 × 10⁻³ × 1.0986 = 2.197 ms`，`f = 1/T = 455 Hz`。
8. `U_om = U_Z R_2/R_1`，`f = R_1/(4R_2RC)`（`R_1` 为接比较器输出的反馈电阻，`R_2` 为接积分器输出端的电阻）。
9. 因为二极管接在运放的反馈环内，运放的高增益使 `u_P − u_N ≈ 0`，只要输入不为零，运放输出就会自动升高到足以使二极管导通，从而保证 `u_o = −(R_f/R_1)u_i` 在整个周期成立。
10. 负载浮地式（`i_L = u_i/R`，负载不能接地）和负载接地式（豪兰德电流泵，需满足 `R_2/R_1 = R_4/R_3`）。
