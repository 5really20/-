## 8.1 功率放大电路概述

### 8.1.1 功率放大电路的特点

**功率放大电路（power amplifier）以「输出足够大的功率」为首要目标，工作在大信号状态，必须兼顾输出功率、效率与非线性失真。**

与电压放大电路的区别：

| 比较项 | 电压放大电路 | 功率放大电路 |
|---|---|---|
| 主要任务 | 放大电压幅度 | 输出足够大的**功率** |
| 输入信号 | 小信号（mV~V 级） | 大信号（接近满幅） |
| 分析方法 | **微变等效电路法** | **图解法**（大信号非线性明显） |
| 关注指标 | 电压增益、输入输出电阻、带宽 | **输出功率、效率、非线性失真** |
| 管子工作状态 | 甲类（小电流） | 甲类/乙类/甲乙类，接近极限运用 |
| 管子选择 | 小功率管 | 大功率管，**必须考虑散热与保护** |

**三个核心指标**：

| 指标 | 定义 | 说明 |
|---|---|---|
| 最大输出功率 `P_om` | 输出信号在负载上获得的最大交流功率 | `U_om`、`I_om` 均为有效值 |
| 效率 `η` | `η = P_om/P_V`（`P_V` 为直流电源提供的功率） | 越高越省电、发热越小 |
| 非线性失真 | 输出波形与输入波形的偏差 | 大信号时用图解法分析 |

**为什么效率如此重要？** 效率低意味着大量电能变成热，不仅要浪费能源，还要求更大的电源与散热系统。例如甲类功放效率只有 25%，输出 10 W 就要消耗 40 W，其中 30 W 变成热。

### 8.1.2 功率放大电路的组成与分类

#### （1）按导通角分类

**导通角（conduction angle）是一只管子在一个信号周期内导通的角度。**

| 类别 | 导通角 | 静态工作点 | 最高效率 | 特点 |
|---|---|---|---|---|
| **甲类（A 类）** | 360°（全周期） | 在负载线中点 | **50%**（变压器耦合）<br>25%（直接耦合） | 失真小、效率低、发热大 |
| **乙类（B 类）** | 180°（半周期） | 在截止点 | **78.5%** | 效率高，但有**交越失真** |
| **甲乙类（AB 类）** | 180°~360° | 微导通 | 介于 50%~78.5% | **实用电路最常用** |
| **丙类（C 类）** | < 180° | 截止 | 可达 80% 以上 | 用于高频谐振功放，失真大 |

```text
   甲类                    乙类                    甲乙类
   i_C ▲                   i_C ▲                   i_C ▲
       │  ┌──────┐            │  ┌──┐   ┌──┐         │ ╭──╮  ╭──╮
       │  │      │            │  │  │   │  │         │ │  │  │  │
       └──┴──────┴── ωt       └──┴──┴───┴──┴─ ωt     └─┴──┴──┴──┴─ ωt
       导通 360°               导通 180°（有死区）      微导通（消除死区）
       效率 50%                效率 78.5%              效率接近 78.5%
```

#### （2）甲类功放简介

| 电路形式 | 最高效率 | 说明 |
|---|---|---|
| 变压器耦合甲类 | 50% | 经典电路，变压器体积大、不集成 |
| 无输出变压器的甲类 | 25% | 简单但效率极低，只用于小功率 |

**甲类效率低的根本原因**：静态时管子就流过较大的 `I_CQ`，即使没有信号输入，电源也在持续提供功率，全部变成管耗。

#### （3）乙类互补对称电路的基本思路

**用两只特性相同的异型管（NPN + PNP）组成「互补」结构：正半周 NPN 管导通、PNP 管截止；负半周反之。这样两只管子轮流工作，静态电流为零，效率大幅提高。**

| 结构 | 电源 | 输出耦合 | 输出功率 |
|---|---|---|---|
| **OCL**（Output CapacitorLess，无输出电容） | ±V_CC 双电源 | 直接耦合 | `V_CC²/(2R_L)` |
| **OTL**（Output TransformerLess，无输出变压器） | 单电源 `V_CC` | 经大电容 C 耦合 | `V_CC²/(8R_L)` |
| BTL（桥式推挽） | 单电源 | 双路互补桥接 | 约为 OTL 的 4 倍 |

## 8.2 互补功率放大电路

### 8.2.1 OCL 电路的组成及工作原理

**OCL 电路采用双电源 `±V_CC` 供电，两只互补管（T1 为 NPN、T2 为 PNP）的基极相连作为输入端、发射极相连作为输出端，负载 `R_L` 直接接在输出端与地之间，无需输出电容。**

```text
              +V_CC
                │
              ┌─┴─┐ T_1 (NPN)
   u_i ──┬────┤   │
         │    └─┬─┘
         │      ├────────┬──── u_o
         │      │        │
         │    ┌─┴─┐     R_L
         └────┤   │ T_2  │
              └─┬─┘      │
                │        │
              −V_CC     地（中点）
```

**工作原理**：

| 输入信号 | T1（NPN） | T2（PNP） | 输出 |
|---|---|---|---|
| `u_i > 0`（正半周） | 导通，向 `R_L` 供电 | 截止 | 跟随 `u_i` 的正半周 |
| `u_i < 0`（负半周） | 截止 | 导通，从 `R_L` 抽取电流 | 跟随 `u_i` 的负半周 |
| `u_i = 0` | 截止 | 截止 | `u_o = 0`，**静态功耗为零** |

**电路特点**：

1. **静态时两管都截止**，`I_CQ = 0`，静态功耗为零 → 效率高；
2. 两管**轮流导通**，各自承担半个周期，合成完整的正弦波（**推挽**）；
3. **输出端静态电位为 0 V**（双电源的中点），所以可以**直接耦合**，无需输出电容；
4. 输出端与负载直接相连，**低频响应好**（无耦合电容的限制）。

**实际电路的两个必要补充**：

| 补充电路 | 作用 |
|---|---|
| 前置电压放大级（共射电路） | 提供足够的电压幅度去推动输出级 |
| 偏置电路（二极管或 `U_BE` 倍增电路） | 使两管工作在**甲乙类**，消除交越失真 |
| 恒压源/自举电路 | 保证推动级输出幅度足够大 |

### 8.2.2 OCL 电路的输出功率及效率

#### （1）输出功率

设输出正弦波的最大幅值为 `U_om`（忽略管子的饱和压降 `U_CES`，最大可达 `V_CC`）：

**最大输出功率 `P_om = U_om²/(2R_L) = V_CC²/(2R_L)`**

考虑饱和压降 `U_CES` 时：`U_om(max) = V_CC − U_CES`，故 `P_om = (V_CC − U_CES)²/(2R_L)`。

#### （2）直流电源提供的功率

**`P_V = 2V_CC·U_om/(πR_L)`**

推导要点：每只管子只在半个周期内从电源取电流，该电流为正弦半波，其平均值为 `I_om/π = U_om/(πR_L)`；两个电源各提供 `V_CC × U_om/(πR_L)`，故合计为上式。

#### （3）效率

**`η = P_om/P_V = (π/4)·(U_om/V_CC)`**

当 `U_om = V_CC`（理想满幅输出）时：

**`η_max = π/4 = 78.5%`**

| `U_om/V_CC` | 效率 `η` |
|---|---|
| 1.0（理想满幅） | **78.5%** |
| 0.8 | 62.8% |
| 0.5 | 39.3% |
| → 0（小信号） | → 0 |

> **关键结论：乙类功放的效率不是一个固定值，而是随输出幅度变化的。** 78.5% 只有在接近满幅输出时才能达到；小音量下效率很低。这也是为什么音响功放要「功率留有余量」反而不经济的原因之一。

#### （4）管耗

**单只管子的管耗：`P_T1 = (1/R_L)·(V_CC·U_om/π − U_om²/4)`**

对 `U_om` 求导取极值，得 **`U_om = 2V_CC/π ≈ 0.637V_CC`** 时单管管耗最大：

**`P_T1(max) = V_CC²/(π²R_L) ≈ 0.2 P_om`**

**`P_T(max) = 2P_T1(max) ≈ 0.4 P_om`**（两管合计）

| 项目 | 数值（以 `P_om` 为基准） |
|---|---|
| 单管最大管耗 | `≈ 0.2 P_om` |
| 两管最大管耗 | `≈ 0.4 P_om` |
| 最大管耗发生时的输出幅度 | `U_om = 0.637V_CC`（不是满幅！） |
| 最大管耗发生时的效率 | 约 50% |

> **最常见的误解**：「输出最大时管耗最大」。**错！** 输出最大时管耗最小（反而效率最高）。管耗最大发生在输出幅度约为满幅的 0.637 倍时，此时效率只有 50%。所以**按 `P_om` 选管子时要乘 0.2，而不是按满幅时的管耗算**。

### 8.2.3 OCL 电路中晶体管的选择

**按三条准则选管：**

| 参数 | 选择依据 | 含义 |
|---|---|---|
| **最大管耗 `P_CM`** | `P_CM ≥ 0.2 P_om`（工程上取 2~3 倍余量） | 散热与结温限制 |
| **反向击穿电压 `U_(BR)CEO`** | `U_(BR)CEO ≥ 2V_CC` | 一只管导通时，另一只管承受 `2V_CC` 的反压 |
| **最大集电极电流 `I_CM`** | `I_CM ≥ V_CC/R_L` | 峰值电流 |

**为什么耐压要 2V_CC？** 当 T1 导通到 `u_o = +V_CC` 时，T2 的集电极电位为 `+V_CC`、发射极电位为 `+V_CC`……更严格地说，在输出为 `+V_CC` 的瞬间，截止管 T2 的集电极接 `−V_CC`、发射极接 `+V_CC`，承受的反压为 `2V_CC`。

## 8.3 功率放大电路的安全运行

### 8.3.1 功放管的二次击穿

**二次击穿（secondary breakdown）是功率管在 `U_CE` 较高、电流较大时出现的局部过热导致的突发性永久损坏，其发生时间极短（微秒级），普通保险丝来不及保护。**

| 类型 | 特点 |
|---|---|
| 一次击穿 | `U_CE` 超过 `U_(BR)CEO` 时的雪崩击穿，**可逆**（电流不过大时撤去电压即可恢复） |
| **二次击穿** | 局部热点使电流集中、温度正反馈升高，**不可逆，瞬间烧毁** |

**安全工作区（SOA，Safe Operating Area）**：由 `I_CM`、`P_CM`、`U_(BR)CEO` 和二次击穿临界线共同围成的区域。**使用时管子必须工作在 SOA 之内。**

**保护措施**：① 加过流保护（检测发射极电阻上的电压）；② 加过压保护（续流二极管）；③ 限制感性负载的反峰电压；④ 采用有保护功能的集成功放。

### 8.3.2 功放管的散热问题

**功率管的 `P_CM` 不是固定值，它取决于散热条件；结温 `T_j` 不得超过最大值 `T_jm`（硅管一般 150 °C）。**

**热阻模型**：`T_j − T_a = P(R_θjc + R_θcs + R_θsa)`

| 符号 | 名称 | 典型值 |
|---|---|---|
| `T_j` / `T_a` | 结温 / 环境温度 | `T_jm = 150 °C`，`T_a = 25 °C` |
| `R_θjc` | 结到壳的热阻（管子固有） | 1~5 °C/W |
| `R_θcs` | 壳到散热片的热阻（绝缘垫片） | 0.5~2 °C/W |
| `R_θsa` | 散热片到环境的热阻 | 1~10 °C/W |
| `R_θja` | 不加散热片时结到环境的热阻 | 50~100 °C/W（**很大**） |

**最大允许管耗**：`P_CM = (T_jm − T_a)/(R_θjc + R_θcs + R_θsa)`

> **实用结论**：不加散热片的功率管允许功耗只有 1~2 W；加合适散热片后可提高一个数量级。**散热片越大，允许的管耗越大。**

## 8.4 集成功率放大电路

**集成功率放大器把前置放大、偏置、输出级、保护电路集成在一块芯片上，外接元件极少，可靠性高。**

| 型号 | 输出功率 | 电源 | 特点 |
|---|---|---|---|
| **LM386** | 约 0.5~1 W | 4~12 V 单电源 | 低压、低功耗，用于收音机、玩具 |
| **TDA2030** | 约 14~18 W | ±6~±18 V | 高保真音频功放，内部有过热/短路保护 |
| **LM1875** | 约 20 W | ±25 V | 音质好，常用于有源音箱 |
| **TDA2822** | 约 1 W×2 | 3~15 V | 双声道，便携设备 |

**集成功放的共同特点**：

1. 内部已做**甲乙类偏置**，无需外接偏置电路，无交越失真；
2. 内部集成**过热保护、过流保护、短路保护**；
3. **开环增益极高，必须引入负反馈**（外接电阻设定闭环增益），否则不能正常工作；
4. 需要外接**消振电容**（防止高频自激）和**电源去耦电容**。

## 8.5 Multisim 应用举例

**用 Multisim 研究 OCL 电路的输出功率和效率**：

1. 搭建 ±12 V 供电、`R_L = 8 Ω` 的 OCL 电路，输入 1 kHz 正弦波；
2. 用**瞬态分析**观察输出波形与两只管子的电流波形（验证轮流导通）；
3. 用**失真分析**观察交越失真，再接入偏置二极管观察改善效果；
4. 用**直流工作点分析**读出电源电流，计算 `P_V`；
5. 由 `P_om = U_om²/(2R_L)` 与 `η = P_om/P_V` 验证 78.5% 的最高效率（实际因 `U_CES` 略低）。

## 典型例题

**例 8.1**（题型：OCL 电路输出功率与效率——★必考）
OCL 电路采用 `±V_CC = ±12 V` 电源，`R_L = 8 Ω`，忽略管子饱和压降。求最大输出功率 `P_om`、最大输出电流幅值、电源提供的功率、效率与单管最大管耗。

**解**：
最大输出幅度：`U_om = V_CC = 12 V`
**最大输出功率**：`P_om = V_CC²/(2R_L) = 12²/(2 × 8) = 144/16 = 9 W`
**最大输出电流幅值**：`I_om = U_om/R_L = 12/8 = 1.5 A`
**电源提供的功率**：`P_V = 2V_CC U_om/(πR_L) = (2 × 12 × 12)/(π × 8) = 288/25.13 = 11.46 W`
**效率**：`η = P_om/P_V = 9/11.46 = 0.785 = 78.5%`（即 `π/4`）
**单管最大管耗**：`P_T1(max) = 0.2 P_om = 0.2 × 9 = 1.8 W`

**答案**：`P_om = 9 W`，`I_om = 1.5 A`，`P_V = 11.46 W`，`η = 78.5%`，单管最大管耗 1.8 W。
**选管**：`P_CM ≥ 1.8 W`（实际取 3~5 W 留余量），`U_(BR)CEO ≥ 24 V`，`I_CM ≥ 1.5 A`。

**例 8.2**（题型：考虑饱和压降的 OCL 计算）
在例 8.1 中，若管子饱和压降 `U_CES = 2 V`，其他条件不变，求实际最大输出功率与效率。

**解**：
`U_om(max) = V_CC − U_CES = 12 − 2 = 10 V`
`P_om = U_om²/(2R_L) = 10²/(2 × 8) = 100/16 = 6.25 W`
`P_V = 2V_CC U_om/(πR_L) = (2 × 12 × 10)/(π × 8) = 240/25.13 = 9.55 W`
`η = P_om/P_V = 6.25/9.55 = 0.654 = 65.4%`
（也可用 `η = (π/4)(U_om/V_CC) = 0.785 × 10/12 = 0.654` ✓）

**答案**：`P_om` 由 9 W 降到 6.25 W（降 30.6%），效率由 78.5% 降到 65.4%。
**结论**：**饱和压降对输出功率的影响很大**（功率与 `U_om²` 成正比），所以功放管要选 `U_CES` 小的型号，且电源电压要留余量。

**例 8.3**（题型：OTL 电路计算——★必考）
OTL 电路采用单电源 `V_CC = 12 V`，`R_L = 8 Ω`，输出电容足够大，忽略饱和压降。求最大输出功率。

**解**：
静态时输出电容上充有 `V_CC/2 = 6 V`，故输出信号的最大幅度为
`U_om = V_CC/2 = 6 V`
`P_om = U_om²/(2R_L) = (V_CC/2)²/(2R_L) = V_CC²/(8R_L)`
`= 12²/(8 × 8) = 144/64 = 2.25 W`

**答案**：`P_om = 2.25 W`。
**对比**：同样的 12 V 电源，OCL 用 ±12 V（共 24 V）可得 9 W；若 OCL 也用 ±6 V（共 12 V），则 `P_om = 6²/(2×8) = 2.25 W`，与 OTL 完全相同。
**结论：在电源总电压相同的情况下，OTL 与 OCL 的输出功率相同；OCL 的优势在于省去了大容量输出电容、低频响应更好。**

**例 8.4**（题型：最大管耗发生点）
OCL 电路 `±V_CC = ±12 V`，`R_L = 8 Ω`。求：(a) 单管管耗最大时的输出幅度 `U_om`；(b) 该最大管耗值；(c) 此时的效率。

**解**：
(a) 单管管耗 `P_T1 = (1/R_L)(V_CC U_om/π − U_om²/4)`，对 `U_om` 求导并令其为零：
`dP_T1/dU_om = (1/R_L)(V_CC/π − U_om/2) = 0` → `U_om = 2V_CC/π`
`U_om = 2 × 12/3.1416 = 24/3.1416 = 7.64 V`
(b) `P_T1(max) = V_CC²/(π²R_L) = 144/(9.87 × 8) = 144/78.96 = 1.824 W`
（校验：`0.2 P_om = 0.2 × 9 = 1.8 W` ✓）
(c) 此时 `P_o = U_om²/(2R_L) = 7.64²/16 = 58.4/16 = 3.65 W`
`P_V = 2V_CC U_om/(πR_L) = (2×12×7.64)/(π×8) = 183.4/25.13 = 7.30 W`
`η = 3.65/7.30 = 50%`

**答案**：(a) `U_om = 7.64 V`；(b) `P_T1(max) = 1.82 W`；(c) `η = 50%`。
**重要结论**：**管耗最大时输出功率只有最大值的 40.6%，效率只有 50%**——所以选管必须以 0.2`P_om` 为依据，而不能按满幅输出时的管耗来算（那时管耗反而是最小的）。

**例 8.5**（题型：电源功率与效率的一般计算）
OCL 电路 `±V_CC = ±15 V`，`R_L = 4 Ω`，实际输出幅度 `U_om = 10 V`。求输出功率、电源功率与效率。

**解**：
`P_o = U_om²/(2R_L) = 10²/(2 × 4) = 100/8 = 12.5 W`
`P_V = 2V_CC U_om/(πR_L) = (2 × 15 × 10)/(π × 4) = 300/12.57 = 23.9 W`
`η = P_o/P_V = 12.5/23.9 = 0.523 = 52.3%`
（校验：`η = (π/4)(U_om/V_CC) = 0.785 × 10/15 = 0.523` ✓）

**答案**：`P_o = 12.5 W`，`P_V = 23.9 W`，`η = 52.3%`。
**说明**：此时 `U_om/V_CC = 0.667`，接近管耗最大的工作点（0.637），**管子发热最严重**，设计散热时要按这个工况考虑。

**例 8.6**（题型：交越失真的消除——偏置电路计算）
OCL 输出级的两只互补管需要约 1.4 V 的基极间偏置电压（每管 0.7 V）才能消除交越失真。用 `U_BE` 倍增电路提供该偏置，其中三极管的 `U_BE = 0.7 V`。求偏置电阻 `R_1`、`R_2` 的比值（取 `R_2 = 10 kΩ`）。

**解**：
`U_BE` 倍增电路的输出（即两管基极间的电压）：
`U_CE = U_BE·(1 + R_1/R_2)`
代入 `U_CE = 1.4 V`、`U_BE = 0.7 V`：
`1.4 = 0.7 × (1 + R_1/R_2)` → `1 + R_1/R_2 = 2` → `R_1/R_2 = 1`
取 `R_1 = R_2 = 10 kΩ`

**答案**：`R_1 = R_2 = 10 kΩ`，此时两管基极间电压为 1.4 V，两管处于微导通状态（甲乙类），交越失真被消除。
**优点**：`U_BE` 倍增电路具有温度补偿作用——温度升高时 `U_BE` 减小，但 `R_1/R_2` 不变，`U_CE` 也随之减小，正好补偿了功放管 `U_BE` 的温漂。

**例 8.7**（题型：散热设计——★常考）
某功率管 `T_jm = 150 °C`，`R_θjc = 3 °C/W`，绝缘垫片 `R_θcs = 1 °C/W`，环境温度 `T_a = 25 °C`。求：(a) 加 `R_θsa = 4 °C/W` 的散热片时的最大允许管耗；(b) 不加散热片（`R_θja = 60 °C/W`）时的最大允许管耗。

**解**：
(a) `P_CM = (T_jm − T_a)/(R_θjc + R_θcs + R_θsa) = (150 − 25)/(3 + 1 + 4) = 125/8 = 15.6 W`
(b) `P_CM = (150 − 25)/60 = 125/60 = 2.08 W`

**答案**：加散热片后允许管耗 15.6 W，不加散热片只有 2.08 W，**相差 7.5 倍**。
**设计校核**：若该管用于 `P_om = 9 W` 的 OCL 电路（例 8.1），单管最大管耗 1.8 W < 2.08 W，理论上不加散热片也「勉强」可用；但环境温度升高到 40 °C 时 `P_CM = (150−40)/60 = 110/60 ≈ 1.83 W`，**已略超 1.8 W 的额定管耗，余量耗尽**——**所以必须加散热片并留足余量**。

**例 8.8**（题型：复合管）
用两只管子组成复合管，`β_1 = 50`、`β_2 = 40`。求复合管的电流放大倍数；若 T1 为 NPN、T2 为 PNP，复合管的类型是什么？

**解**：
`β ≈ β_1·β_2 = 50 × 40 = 2000`
等效类型判别：以外层管 T1（第一只，靠近输入端）的类型为准——**T1 是 NPN，故复合管等效为 NPN**。

**答案**：`β ≈ 2000`；复合管类型为 **NPN**。
**判别口诀**：**「看第一只管子（离输入近的那只）的类型」**——T1 为 NPN 则复合管为 NPN，T1 为 PNP 则复合管为 PNP。
**复合管的用途**：① 极大提高电流放大倍数（`β` 可达几千）；② 用两只同类型管也能构成互补管对（如两只 NPN 复合成「等效 PNP」），解决大功率 PNP 管难做的问题。

**例 8.9**（题型：集成功率放大器）
用 TDA2030 构成音频功放，电源 `±12 V`，`R_L = 4 Ω`，闭环增益设为 30 dB。求闭环电压增益的倍数与最大输出功率（设 `U_CES ≈ 2 V`）。

**解**：
闭环增益 `30 dB = 20 lg A_u` → `lg A_u = 1.5` → `A_u = 10^1.5 = 31.6`
最大输出幅度：`U_om = |V_CC| − U_CES = 12 − 2 = 10 V`
`P_om = U_om²/(2R_L) = 10²/(2 × 4) = 100/8 = 12.5 W`

**答案**：`A_u = 31.6`（30 dB），`P_om = 12.5 W`。
**提示**：TDA2030 的闭环增益由外接反馈电阻决定（`A_u = 1 + R_f/R_1`），且不能低于约 20 dB，否则容易自激。

## 易错点提醒

1. **把功放管的最大管耗按最大输出功率时的管耗来算** → 最大管耗发生在 `U_om = 2V_CC/π ≈ 0.637V_CC` 处，单管 `P_T1(max) ≈ 0.2P_om`，**不是** 0.5`P_om`。
2. **误认为「输出功率最大时管耗最大」** → 恰恰相反，输出最大时管耗最小（效率最高）；管耗最大时输出只有满幅的 63.7%。
3. **把 OCL 的输出功率公式写成 `V_CC²/(8R_L)`** → `V_CC²/(2R_L)` 是 OCL，`V_CC²/(8R_L)` 是 OTL（单电源）。区别来自 OTL 的输出电容上只有 `V_CC/2`。
4. **效率公式记成 `η = U_om/V_CC`** → 是 `η = (π/4)(U_om/V_CC)`，最高 78.5% 而不是 100%。
5. **认为乙类功放效率恒为 78.5%** → 78.5% 只是**满幅输出**时的最高值；小信号时效率很低（`η ∝ U_om`）。
6. **忘记互补管的耐压要 `2V_CC`** → 一只管导通时另一只管承受接近 `2V_CC` 的反压，按 `V_CC` 选管会击穿。
7. **把乙类电路直接用于实际** → 乙类有严重交越失真，实用电路必须加偏置构成甲乙类（二极管或 `U_BE` 倍增电路）。
8. **认为加了互补管就不需要前置放大级** → 互补输出级是射极跟随器，电压增益小于 1，必须由前置共射级提供电压增益。
9. **复合管的类型判据搞错** → 以**第一只管子（离输入端近的）**的类型为准，与第二只无关。
10. **忽略散热设计** → 功率管的 `P_CM` 与环境温度、散热片密切相关；不装散热片时允许管耗可能只有几瓦，必须核算热阻。
11. **把二次击穿当成普通击穿** → 一次击穿可逆，二次击穿是局部过热导致的**不可逆损坏**，发生时间只有微秒级，必须靠限制工作点（SOA）来预防，而不是靠保险丝。
12. **OTL 电路忽略输出电容的作用** → 该电容不仅隔直，还充当负半周的「电源」；电容失效会导致负半周削波。

## 本章小结

- 功放与电压放大的区别：**大信号、大功率、高效率**，用**图解法**分析，必须考虑散热与保护。
- 分类按导通角：甲类 360°（η≤50%）、乙类 180°（η≤78.5%）、甲乙类（实用）、丙类（<180°，高频谐振功放）。
- 乙类互补（OCL）：静态电流为零，两管轮流导通，双电源供电，输出无电容。
- **OCL 三大公式**：`P_om = V_CC²/(2R_L)`；`P_V = 2V_CC U_om/(πR_L)`；`η = (π/4)(U_om/V_CC)`，最高 **78.5%**。
- **管耗**：`P_T1(max) = 0.2P_om`（发生在 `U_om = 0.637V_CC` 处），两管合计 `0.4P_om`。
- **选管三准则**：`P_CM ≥ 0.2P_om`、`U_(BR)CEO ≥ 2V_CC`、`I_CM ≥ V_CC/R_L`。
- **OTL**：单电源，经大电容输出，`U_om = V_CC/2`，`P_om = V_CC²/(8R_L)`；电源总电压相同时与 OCL 输出功率相同。
- **交越失真**：乙类电路在过零附近两管都不导通的死区造成的；用二极管或 `U_BE` 倍增电路加偏置构成甲乙类来消除。
- **复合管**：`β ≈ β_1β_2`，类型以第一只管子为准；用于提高电流增益、解决互补配对问题。
- **安全工作区与散热**：二次击穿不可逆；`P_CM = (T_jm − T_a)/(R_θjc + R_θcs + R_θsa)`，散热片能把允许管耗提高一个数量级。
- **集成功放**：LM386、TDA2030、LM1875，内部已偏置并有保护，外接元件少，必须引入负反馈。

> **一句话记住本章**：**乙类互补就是「两只管子轮流上班」——静态不耗电所以效率高达 78.5%，代价是交接班时出现的交越失真；而管子最热的时候并不是它出力最多的时候，而是输出约为满幅 63.7% 的时候。**

**自测题答案**

4. `P_om = V_CC²/(2R_L)`；`P_V = 2V_CC U_om/(πR_L)`；`η = (π/4)(U_om/V_CC)`；当 `U_om = V_CC` 时 `η = π/4 = 78.5%`。

6. `P_CM ≥ 0.2P_om`、`U_(BR)CEO ≥ 2V_CC`、`I_CM ≥ V_CC/R_L`；因为一只管导通时，另一只截止管的集电极与发射极之间承受接近两倍电源电压。

8. 乙类电路在输入过零附近，两管的 `|U_BE|` 都小于死区电压而同时截止，输出波形在过零处出现平顶（交越）失真；消除方法是给两管加适当偏置（二极管或 `U_BE` 倍增电路）使它们处于微导通状态，即构成甲乙类。
9. `β ≈ β_1β_2`；类型以第一只管子（靠近输入端的）的类型为准。
10. 二次击穿是功率管在高压大电流下局部过热导致的不可逆损坏，发生极快；最大允许管耗 `P_CM = (T_jm − T_a)/(R_θjc + R_θcs + R_θsa)`，与最高结温、环境温度和散热条件有关。
11. `P_om = 18²/(2×8) = 324/16 = 20.25 W`；单管最大管耗 `= 0.2 × 20.25 = 4.05 W`；`P_V = 2×18×18/(π×8) = 648/25.13 = 25.8 W`。
