## 4.1 频率响应概述

### 4.1.1 研究放大电路频率响应的必要性

**实际信号不是单一频率的正弦波，而是包含很多频率分量；如果放大电路对不同频率的增益不同，输出波形就会失真。**

例如语音信号的频率范围是 300 Hz~3.4 kHz，心电信号是 0.05 Hz~100 Hz。若放大器只对中频段放大得均匀，高低两端衰减，则输出的方波会「变圆」、脉冲会「变钝」。

**频率失真（线性失真）**：由电路的线性电抗元件（电容、电感）引起，不产生新的频率分量。
**非线性失真**：由器件的非线性（Q 点不当、进入饱和/截止）引起，会产生新的频率分量。

> 两者必须区分：频率失真是「不同频率放大倍数不同」，非线性失真是「波形被削平」。考试中常要求判断失真类型。

### 4.1.2 频率响应的基本概念

**频率响应 = 幅频特性 + 相频特性：`A_u = A_u(f)∠φ(f)`。**

```text
   |A_u|(dB)                     φ
     │        ┌──────────┐         │
     │       ╱  中频段    ╲        │  0° ────────┐
     │  −3dB┼──┼──────────┼──┼     │            ╲ −90°(单极点极限)
     │     ╱   │          │   ╲    │             ╲
     └────┴────┴──────────┴────┴   └──────────────┴── lg f
        f_L          f_H             f_L          f_H
      低频段    中频段   高频段
```

| 频段 | 影响增益的元件 | 等效电路形式 | 增益表达式 |
|---|---|---|---|
| 低频段 | 耦合电容 C1、C2、旁路电容 C_e | 高通电路（RC 串联） | `A = A_um·(jf/f_L)/(1+jf/f_L)` |
| 中频段 | 电容均视为已处理（耦合电容短路、结电容开路） | 纯电阻网络 | `A = A_um`（最大且平坦） |
| 高频段 | 结电容 C_b'e、C_b'c、分布电容 | 低通电路（RC 并联） | `A = A_um/(1+jf/f_H)` |

**截止频率的定义**：增益下降到中频增益的 **0.707 倍（−3 dB）** 处的频率，低端为 `f_L`、高端为 `f_H`。

`BW = f_H − f_L`，当 `f_H >> f_L` 时 `BW ≈ f_H`。

### 4.1.3 波特图

**波特图（Bode plot）用对数坐标画幅频和相频特性，把乘法变成加法，便于多级电路的分析。**

| 特性 | 一阶低通 | 一阶高通 |
|---|---|---|
| 传递函数 | `A = A_m/(1 + jf/f_H)` | `A = A_m·(jf/f_L)/(1 + jf/f_L)` |
| 转折频率 | `f_H = 1/(2πRC)` | `f_L = 1/(2πRC)` |
| 幅频渐近线 | f < f_H：平坦；f > f_H：**−20 dB/十倍频** | f > f_L：平坦；f < f_L：**+20 dB/十倍频** |
| 相频渐近线 | f < 0.1f_H：0°；f > 10f_H：−90°；中间 −45°/十倍频 | 对称，f >> f_L 为 0°，f << f_L 为 +90° |
| 转折点误差 | 实际值比渐近线低 3 dB，相位恰为 −45° | 同左 |

> **为什么是 20 dB/十倍频？** 一阶低通在 `f >> f_H` 时 `|A| ≈ A_m f_H/f`，频率增加 10 倍，增益变为 1/10，即 `20 lg(1/10) = −20 dB`。这个斜率是识别「一阶电路」的标志，二阶电路则为 −40 dB/十倍频。

## 4.2 晶体管的高频等效模型

### 4.2.1 晶体管的混合 π 模型

**混合 π 模型（hybrid-π model）把三极管的高频特性用「体电阻 + 结电阻 + 结电容 + 受控源」表示。**

```text
        b ── r_bb' ──┬── b' ──┬── r_b'c ──┬── c
                     │        │           │
                     │     ┌──┴──┐        │
                     │   C_b'e  r_b'e   C_b'c
                     │     │        │  ┌──┴──┐
                     └─────┴────────┴──┤ g_m u_b'e ──→（向下到 e）
                                       └──────┘
                     e ───────────────────────────────── e
```

| 参数 | 含义 | 数值特点 |
|---|---|---|
| r_bb' | 基区体电阻 | 100~300 Ω，与频率、电流无关 |
| r_b'e | 发射结动态电阻（折算到 b'） | `r_b'e = (1+β)26mV/I_EQ ≈ β/g_m`，与 I_EQ 成反比 |
| C_b'e | 发射结电容 | 几十~几百 pF，**较大** |
| C_b'c | 集电结电容 | 2~10 pF，**很小但危害最大**（密勒效应） |
| g_m | 跨导 | `g_m = I_CQ/U_T ≈ 38.5 mS（I_CQ = 1 mA 时）` |
| r_b'c | 集电极与基区间的电阻 | 极大，一般忽略 |

**两个基本关系**：`g_m = β/r_b'e`，`r_b'e = (1+β)26mV/I_EQ`

### 4.2.2 晶体管电流放大倍数的频率响应

**β 本身也随频率下降：`β(f) = β_0/(1 + jf/f_β)`。**

`f_β = 1/[2π r_b'e(C_b'e + C_b'c)]`（共射截止频率，β 下降 3 dB 处的频率）
`f_T = β_0 · f_β`（特征频率，`|β| = 1` 处的频率）

| 频率 | \|β\| 的变化 | 应用 |
|---|---|---|
| f < f_β | 基本为 β_0 | 低频、中频放大 |
| f_β < f < f_T | 以 −20 dB/十倍频下降 | 高频放大要减益 |
| f > f_T | `\|β\| < 1`，失去电流放大能力 | 不能用于放大 |

> **选高频管看 f_T**：f_T 越高，同样频率下的 β 越大、高频性能越好。小功率高频管的 f_T 可达几百 MHz~几 GHz。

## 4.3 场效应管的高频等效模型

**与混合 π 模型平行：栅极串 `r_g`（很小），栅源之间有 `C_gs` 与 `r_gs`（极大），栅漏之间有 `C_gd`，漏源之间有 `g_m u_gs` 与 `r_ds`。**

FET 的特点：

- **输入电阻极高**（`r_gs` 达 10^9 Ω 以上），所以低频段输入电流可忽略。
- **`C_gd` 同样存在密勒效应**，是限制共源电路高频性能的主因。
- `C_gs` 一般比 BJT 的 `C_b'e` 大，因此 MOS 管的高频性能通常不如 BJT（但 GaN、SiC 器件例外）。

## 4.4 单管放大电路的频率响应

### 4.4.1 单管共射放大电路的频率响应

**求 `f_L`：看耦合电容与旁路电容——找「回路总电阻 × 电容」的最大时间常数。**
**求 `f_H`：看密勒等效后的输入电容与输入回路电阻。**

#### （1）低频段：耦合电容与旁路电容决定 f_L

以输入耦合电容 C1 为例：`f_L1 = 1/[2π(R_s + R_i)C1]`，其中 `R_i` 是放大器的输入电阻。

对于旁路电容 `C_e`：`f_L2 = 1/[2π(R_e ∥ R_s')C_e]`，其中 `R_s'` 是把信号源折算到发射极回路的等效电阻（数值较小），所以**`C_e` 要选得比 C1、C2 大得多**，否则它就成为限制低频响应的主因。

#### （2）高频段：密勒效应决定 f_H

**密勒效应（Miller effect）：跨接在输入与输出之间的电容 `C_b'c`，从输入端看等效为 `(1+|A_u|)C_b'c`。**

推导：`C_b'c` 两端的电压是 `u_b'e − u_ce = u_b'e(1 − A_u) = u_b'e(1 + |A_u|)`（因为共射的 `A_u` 为负）。流入该电容的电流是直接接在输入端的 `(1+|A_u|)` 倍，所以等效电容放大了 `(1+|A_u|)` 倍。

```text
   实际电路                     密勒等效后（从输入端看）
   b' ──┬── C_b'e ──┬            b' ──┬── C_i = C_b'e + (1+|A_u|)C_b'c ──┬
        │   C_b'c  │                  │                                  │
        │     │    │ A_u 放大         └──────────────────────────────────┘
        └─────┴────┘
```

`C_i = C_b'e + (1 + |A_u|)C_b'c`

于是高频段等效为一个 RC 低通电路：

`f_H = 1/(2π R C_i)`，其中 `R = r_b'e ∥ (r_bb' + R_s')`，`R_s' = R_s ∥ R_b`

**关键结论：`C_b'c` 虽然只有几 pF，但由于 `(1+|A_u|)` 的放大作用（几十到几百倍），它往往比 `C_b'e` 起的作用还大。** 这就是为什么共射电路的高频性能差，而共基电路（`C_b'c` 不跨接输入输出）高频性能好。

#### （3）完整频率响应表达式

`A_u(f) = A_um · [ (jf/f_L)/(1 + jf/f_L) ] · [ 1/(1 + jf/f_H) ]`

- 低频：`f << f_L` 时第一个因子趋于 `f/f_L`，增益随频率下降（+20 dB/十倍频 上升的方向相反）。
- 中频：两个因子都≈1，`A_u = A_um`。
- 高频：`f >> f_H` 时第二个因子趋于 `f_H/f`，增益以 −20 dB/十倍频下降。

### 4.4.2 单管共源放大电路的频率响应

`f_H = 1/(2π R C_i)`，`R = R_g ∥ r_gs ≈ R_g`（因为 `r_gs` 极大），`C_i = C_gs + (1+|A_u|)C_gd`。

由于 `R_g` 通常取得很大（MΩ 级），虽然 `C_i` 不大，`R C_i` 的时间常数仍然可观，所以**共源电路的高频截止频率通常低于共射电路**。

### 4.4.3 放大电路频率响应的改善和增益带宽积

**增益带宽积（Gain-Bandwidth Product）：`GBW = |A_um| · f_H ≈ 常数`。**

推导：`|A_um| = g_m R_L'`，`f_H ≈ 1/[2π R (C_b'e + (1+g_m R_L')C_b'c)]`。当 `(1+g_mR_L')C_b'c >> C_b'e` 时，

`GBW = |A_um|·f_H ≈ g_m R_L' / [2π R · g_m R_L' C_b'c] = 1/(2π R C_b'c)`

**结果与 `R_L'`（即增益）无关！** 这说明：

| 想要 | 代价 |
|---|---|
| 增益提高 10 倍 | 通频带变窄到 1/10 |
| 通频带展宽 10 倍 | 增益下降到 1/10 |

**改善高频响应的三条实际途径**：① 选 `C_b'c` 小、`f_T` 高的管子；② 减小信号源内阻 `R_s`（降低输入回路电阻）；③ 采用共基或共射-共基组合电路（消除密勒效应）。

## 4.5 多级放大电路的频率响应

### 4.5.1 多级放大电路频率特性的定性分析

**多级放大电路的总增益是各级增益之积，取分贝后相加，所以低频段衰减叠加、高频段衰减叠加——结果是通频带变窄。**

```text
   |A|(dB)
     │  单级 ─────┐
     │            ╲  −20dB/十倍频
     │  两级 ──────┐
     │             ╲  −40dB/十倍频
     │  三级 ───────┐
     │              ╲  −60dB/十倍频
     └──────────────┴─────────── lg f
                  f_H(多级) < f_H(单级)
```

### 4.5.2 截止频率的估算

当各级的截止频率相差不大（相差 4 倍以内）时：

`f_L ≈ 1.1 · √(f_L1² + f_L2² + … + f_Ln²)`

`f_H ≈ 1 / [1.1 · √(1/f_H1² + 1/f_H2² + … + 1/f_Hn²)]`

**若 n 级完全相同**（每级 `f_L`、`f_H`）：

`f_L ≈ 1.1√n · f_L(单)`，`f_H ≈ f_H(单)/(1.1√n)`

**结论：级数每增加一倍，通频带大约缩小到 1/1.4。** 这就是「多级放大器的增益容易做高，但带宽难做宽」的原因。

## 4.6 频率响应与阶跃响应

**频率响应与阶跃响应是同一系统的两种描述：频域看带宽，时域看上升时间。**

| 指标 | 定义 | 与频率响应的关系 |
|---|---|---|
| 上升时间 t_r | 阶跃响应从 10% 上升到 90% 所需时间 | `t_r ≈ 0.35/f_H` |
| 平顶降落 Δ | 方波平顶部分的相对下降量 | `Δ ≈ 2π f_L · t_p`（t_p 为脉宽） |

**物理含义**：`f_H` 越高 → 高频分量保留越多 → 上升越快；`f_L` 越低 → 低频分量保留越多 → 平顶越平。

> **工程经验**：示波器测 1 MHz 方波，探头与示波器带宽至少要有 10 MHz（约 5~10 倍），否则测到的上升沿是仪器造成的，不是电路真实情况。

## 典型例题

**例 4.1**（题型：一阶 RC 电路求截止频率与增益）
某放大电路输入端有一个 `R = 10 kΩ`、`C = 100 pF` 的并联网络（构成低通）。求 `f_H`；并求 `f = 1 MHz` 时的增益（设中频增益为 1）。

**解**：
`f_H = 1/(2πRC) = 1/(2π × 10×10³ × 100×10⁻¹²) = 1/(2π × 1×10⁻⁶) = 1.59×10⁵ Hz = 159 kHz`
`f = 1 MHz` 时：
`|A| = 1/√(1 + (f/f_H)²) = 1/√(1 + (1000/159)²) = 1/√(1 + 39.6) = 1/6.37 = 0.157`
分贝：`20 lg 0.157 = −16.1 dB`

**答案**：`f_H = 159 kHz`；1 MHz 时增益降为 0.157（−16.1 dB）。

**例 4.2**（题型：波特图读数）
某放大电路的幅频波特图显示：中频增益 60 dB，高频段以 −20 dB/十倍频下降，在 `f = 10⁶ Hz` 处增益为 40 dB。求 `f_H` 与 `A_um` 的倍数。

**解**：
高频渐近线从 `f_H` 开始以 −20 dB/十倍频下降。设 `f_H = 10^x`：
`60 − 20·lg(10⁶/10^x) = 40` → `20(6 − x) = 20` → `6 − x = 1` → `x = 5`
所以 `f_H = 10⁵ Hz = 100 kHz`。
`A_um = 10^(60/20) = 10³ = 1000`

**答案**：`f_H = 100 kHz`，`A_um = 1000`。

**例 4.3**（题型：混合 π 模型参数）
某三极管 `I_CQ = 1 mA`、`β = 100`、`r_bb' = 200 Ω`、`f_T = 100 MHz`、`C_b'c = 5 pF`。求 `r_b'e`、`g_m`、`C_b'e`。

**解**：
`g_m = I_CQ/U_T = 1 mA/26 mV = 38.5 mS`
`r_b'e = β/g_m = 100/0.0385 = 2597 Ω ≈ 2.6 kΩ`
（校验：`r_b'e = (1+β)26mV/I_EQ = 101 × 26 = 2626 Ω` ✓ 两者一致）
由 `f_T = g_m/[2π(C_b'e + C_b'c)]` 反解：
`C_b'e + C_b'c = g_m/(2π f_T) = 0.0385/(2π × 10⁸) = 6.13×10⁻¹¹ F = 61.3 pF`
`C_b'e = 61.3 − 5 = 56.3 pF`

**答案**：`g_m = 38.5 mS`，`r_b'e = 2.6 kΩ`，`C_b'e = 56.3 pF`。
`f_β = f_T/β = 100 MHz/100 = 1 MHz`（β 下降到 0.707β₀ 处的频率）。

**例 4.4**（题型：密勒效应与 f_H 计算——★常考）
共射放大电路：上题管子（`r_bb' = 200 Ω`、`r_b'e = 2.6 kΩ`、`C_b'e = 56.3 pF`、`C_b'c = 5 pF`、`g_m = 38.5 mS`），`R_b = 100 kΩ`（偏置，交流上可视为与信号源并联），信号源内阻 `R_s = 1 kΩ`，`R_L' = 1.5 kΩ`。求中频增益 `A_um`、等效输入电容 `C_i`、`f_H` 与 `GBW`。

**解**：
**中频增益**：`A_um = −g_m R_L' = −38.5 mS × 1.5 kΩ = −57.8`

**密勒等效电容**：
`C_i = C_b'e + (1 + |A_um|)C_b'c = 56.3 + (1 + 57.8) × 5 = 56.3 + 294 = 350 pF`

**输入回路的等效电阻**：
`R_s' = R_s ∥ R_b = 1 kΩ ∥ 100 kΩ ≈ 0.99 kΩ`
`R = r_b'e ∥ (r_bb' + R_s') = 2600 ∥ (200 + 990) = 2600 ∥ 1190 = (2600×1190)/(2600+1190) = 3 094 000/3790 = 816 Ω`

**上限截止频率**：
`f_H = 1/(2πRC_i) = 1/(2π × 816 × 350×10⁻¹²) = 1/(2π × 2.856×10⁻⁷) = 5.57×10⁵ Hz = 557 kHz`

**增益带宽积**：
`GBW = |A_um| · f_H = 57.8 × 557 kHz = 3.22×10⁷ Hz = 32.2 MHz`

**答案**：`A_um = −57.8`，`C_i = 350 pF`（其中密勒分量 294 pF 占 84%），`f_H = 557 kHz`，`GBW = 32.2 MHz`。
**注意：`C_b'c` 只有 5 pF，经密勒放大后却贡献了 294 pF——这就是「小电容大危害」。**

**例 4.5**（题型：增益带宽积的应用）
在例 4.4 中把 `R_L'` 由 1.5 kΩ 改为 3 kΩ，其他不变。求新的 `A_um`、`f_H` 与 GBW。

**解**：
`A_um' = −38.5 mS × 3 kΩ = −115.5`
`C_i' = 56.3 + (1 + 115.5) × 5 = 56.3 + 582.5 = 638.8 pF`
`f_H' = 1/(2π × 816 × 638.8×10⁻¹²) = 1/(2π × 5.213×10⁻⁷) = 3.05×10⁵ Hz = 305 kHz`
`GBW' = 115.5 × 305 kHz = 3.52×10⁷ Hz = 35.2 MHz`

**答案**：`A_um' = −115.5`（增益加倍），`f_H' = 305 kHz`（带宽约减半），`GBW' = 35.2 MHz`。
**GBW 从 32.2 MHz 变为 35.2 MHz，变化仅 9%——验证了「增益带宽积近似为常数」的结论**（此处略有偏差是因为 `C_b'e` 项未被完全忽略）。

**例 4.6**（题型：多级放大电路的通频带）
三级相同的放大电路，每级 `f_L = 10 Hz`、`f_H = 100 kHz`、`|A_um| = 20`。求总增益与总通频带。

**解**：
总增益 `A_um = 20³ = 8000`（分贝：`3 × 26 = 78 dB`）
`f_L ≈ 1.1√n · f_L(单) = 1.1 × √3 × 10 = 1.1 × 1.732 × 10 = 19.1 Hz`
`f_H ≈ f_H(单)/(1.1√n) = 100 kHz/(1.1 × 1.732) = 100/1.905 = 52.5 kHz`
`BW = 52 500 − 19.1 ≈ 52.5 kHz`

**答案**：总增益 8000（78 dB），`f_L ≈ 19.1 Hz`，`f_H ≈ 52.5 kHz`，BW ≈ 52.5 kHz。
**与单级相比（BW ≈ 100 kHz），三级级联后通频带缩小到约 1/1.9。**

**例 4.7**（题型：频率响应与阶跃响应）
某放大电路 `f_H = 557 kHz`、`f_L = 20 Hz`。求 1 kHz 方波输入时的上升时间与平顶降落（脉宽 0.5 ms）。

**解**：
`t_r ≈ 0.35/f_H = 0.35/(5.57×10⁵) = 6.3×10⁻⁷ s = 0.63 μs`
`Δ ≈ 2π f_L · t_p = 2π × 20 × 0.5×10⁻³ = 0.0628 = 6.3%`

**答案**：上升时间约 0.63 μs，平顶降落约 6.3%。
**若要求平顶降落小于 1%，需把 `f_L` 降到 `1%/(2π×0.5ms) = 3.2 Hz` 以下。**

**例 4.8**（题型：低频截止频率）
某共射电路输入耦合电容 `C1 = 10 μF`，信号源内阻 `R_s = 1 kΩ`，放大器输入电阻 `R_i = 2 kΩ`。求由 C1 决定的下限截止频率。若要求 `f_L ≤ 20 Hz`，C1 至少取多大？

**解**：
`f_L1 = 1/[2π(R_s + R_i)C1] = 1/[2π × 3000 × 10×10⁻⁶] = 1/(2π × 0.03) = 5.31 Hz`
要求 `f_L ≤ 20 Hz`：
`C1 ≥ 1/[2π(R_s+R_i)f_L] = 1/(2π × 3000 × 20) = 1/(3.77×10⁵) = 2.65×10⁻⁶ F = 2.65 μF`

**答案**：`f_L1 = 5.31 Hz`（已满足 20 Hz 要求，因为还有旁路电容等其他因素）；若只考虑 C1 单独决定 20 Hz，则 `C1 ≥ 2.65 μF`。
**工程上电容要留 3~5 倍余量，实际取 10 μF 以上。**

## 易错点提醒

1. **把低频段与高频段增益下降的原因搞反** → **低频**由**耦合电容、旁路电容**（容抗变大）引起；**高频**由**结电容、分布电容**（容抗变小、分流）引起。
2. **认为截止频率处增益是 0.5 倍** → 是 0.707 倍（−3 dB）；功率才是 0.5 倍。
3. **算 `C_i` 时漏掉密勒项** → `C_i = C_b'e + (1+|A_u|)C_b'c`，漏掉这一项会使 `f_H` 算大几十倍。
4. **密勒效应中把 `(1+|A_u|)` 写成 `|A_u|`** → 是 `(1+|A_u|)`，因为电容上还加着输入电压本身。
5. **认为共基电路也有密勒效应** → 共基电路中 `C_b'c` 不跨接在输入输出之间，故无密勒效应，高频性能好。
6. **把 `f_T` 当成「能放大的最高频率」** → `f_T` 是 `|β| = 1` 的频率，此时已无电流放大能力；实际可用的最高频率远低于 `f_T`。
7. **多级电路用「各级 f_H 相加」求总 f_H** → 应当用 `1/f_H ≈ 1.1√(Σ1/f_Hi²)`，总 `f_H` **小于**任何一级。
8. **认为多级放大能同时提高增益与带宽** → 增益乘积上升，带宽必然下降；要同时兼顾必须用反馈（第 5 章）或补偿。
9. **用 `r_be` 代替 `r_b'e` 计算 `f_H`** → `r_be = r_bb' + r_b'e`，高频回路中 `r_bb'` 与 `r_b'e` 是串联后与信号源内阻组合，不能混用。
10. **忽略信号源内阻对 `f_H` 的影响** → `R_s` 越小，`f_H` 越高；这是「低内阻信号源有利于高频」的原因。

## 本章小结

- 频率响应 = 幅频特性 + 相频特性；用波特图分析（一阶电路 ±20 dB/十倍频，相位 ±45°/十倍频）。
- 低频段由**耦合电容与旁路电容**决定 `f_L`；高频段由**结电容**决定 `f_H`；中频段增益最大且平坦。
- 混合 π 模型四参数：`r_bb'`、`r_b'e = (1+β)26mV/I_EQ`、`C_b'e`、`C_b'c`，以及 `g_m = I_CQ/U_T`。
- **密勒效应**：`C_i = C_b'e + (1+|A_u|)C_b'c`，是共射电路高频性能差的根本原因。
- `f_H = 1/(2πRC_i)`，`R = r_b'e ∥ (r_bb' + R_s∥R_b)`。
- **增益带宽积 `GBW = |A_um|·f_H ≈ 常数`**：增益与带宽不可兼得。
- `f_β` 是 β 下降 3 dB 的频率，`f_T = β_0 f_β` 是特征频率。
- 多级电路：`f_L ≈ 1.1√(Σf_Li²)`、`f_H ≈ 1/[1.1√(Σ1/f_Hi²)]`，级数越多带宽越窄。
- 时域指标：`t_r ≈ 0.35/f_H`，平顶降落与 `f_L` 成正比。

> **一句话记住本章**：**电容在低频时「挡路」、在高频时「短路」，于是把放大器的可用频率夹在中间；而集电结那几皮法的电容被增益放大成几百皮法，成了高频性能的头号杀手。**

## 自测题

1. 放大电路低频段与高频段增益下降的原因各是什么？
2. 截止频率处的增益是多少？对应多少 dB？
3. 一阶低通电路在高频段的幅频渐近线斜率是多少？
4. 写出 `r_b'e`、`g_m` 的表达式，并说明它们与 `I_CQ` 的关系。
5. 什么是密勒效应？写出等效输入电容的表达式。
6. 为什么共基电路的高频性能比共射好？
7. 某放大器 `A_um = 100`、`f_H = 200 kHz`，求 GBW。若把增益改为 200，`f_H` 约为多少？
8. `f_β` 与 `f_T` 的关系是什么？某管 `β = 100`、`f_T = 200 MHz`，求 `f_β`。
9. 两级相同的放大器，每级 `f_H = 200 kHz`，总 `f_H` 约为多少？
10. 某放大器 `f_H = 1 MHz`，求阶跃响应的上升时间。

**自测题答案**

1. 低频：耦合电容、旁路电容的容抗变大，信号被分压衰减；高频：结电容、分布电容的容抗变小，信号被分流，且密勒效应使等效输入电容增大。
2. 中频增益的 0.707 倍；−3 dB。
3. −20 dB/十倍频。
4. `r_b'e = (1+β)26mV/I_EQ`，`g_m = I_CQ/U_T`；两者都与 `I_CQ` 有关，`I_CQ` 增大时 `g_m` 增大、`r_b'e` 减小。
5. 跨接在输入输出之间的电容 `C_b'c` 因输出端电压变化远大于输入端，从输入端看等效为 `(1+|A_u|)C_b'c`；`C_i = C_b'e + (1+|A_u|)C_b'c`。
6. 因为 `C_b'c` 不跨接在输入与输出之间（基极交流接地），不存在密勒效应。
7. `GBW = 100 × 200 kHz = 20 MHz`；增益 200 时 `f_H ≈ 20 MHz/200 = 100 kHz`。
8. `f_T = β_0 f_β`；`f_β = 200 MHz/100 = 2 MHz`。
9. `f_H ≈ 200 kHz/(1.1√2) = 200/1.556 = 129 kHz`。
10. `t_r ≈ 0.35/10⁶ = 0.35 μs`。
