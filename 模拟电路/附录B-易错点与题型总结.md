# 附录B 易错点与题型总结

> 对应教材：童诗白、华成英《模拟电子技术基础》（第五版）｜用途：考前查漏、题型模板、失分点规避
>
> 使用说明：第一部分是**全书易错点大汇总**（按章排列，「错在哪 → 正确做法」）；第二部分是**五大必考题型套路**（识别特征 → 解题步骤 → 完整例题 → 陷阱提醒）；第三部分是**通用应试检查清单**。

## 第一部分 全书易错点大汇总

### 第 0 章 绪论与放大电路模型

| 错在哪 | 正确做法 |
|---|---|
| 把 `A_u(dB) = 10 lg\|A_u\|` | 电压增益用 **20 lg**；只有功率增益才用 10 lg |
| 级联时把分贝值相乘 | 级联时**分贝相加**（数值才相乘） |
| 认为输入电阻越大越好、输出电阻也越大越好 | `R_i` 越大越好（少取信号源电流），`R_o` **越小**越好（带负载能力强） |
| 把通频带写成 `f_H + f_L` | `BW = f_H − f_L ≈ f_H`（`f_H >> f_L` 时） |

### 第 1 章 常用半导体器件

| 错在哪 | 正确做法 |
|---|---|
| 把 PN 结伏安方程写成 `i_D = I_S·e^(u_D/U_T)`（漏掉 −1） | 完整式 `i_D = I_S(e^(u_D/U_T) − 1)`；反偏时 −1 不能丢 |
| 认为 `U_T = 26 mV` 是常数 | `U_T = kT/q`，与温度有关；常温取 26 mV 是近似 |
| 把二极管当理想开关做小信号分析 | 小信号分析必须用**动态电阻** `r_d = 26 mV/I_DQ` |
| 用恒压降模型算小信号增益 | 恒压降模型只用于大信号（判断通断、求静态值） |
| 忘记 `β` 与 `α` 的关系 | `β = α/(1−α)`，`α = β/(1+β)`；`I_E = I_B + I_C` |
| 认为三极管是「两个二极管背靠背」 | 两个 PN 结**共用基区**且基区很薄，才有电流放大作用 |
| 混淆饱和与截止 | 饱和：两个结都正偏（`U_CE` 小）；截止：两个结都反偏（`I_C ≈ 0`） |
| 忘记温度对 `I_CBO` 的影响 | 温度每升 10 °C，`I_CBO` 约翻倍（硅管小、锗管大） |
| 把增强型与耗尽型 FET 的判据搞混 | 增强型 `U_GS = 0` 时**无**导电沟道；耗尽型 `U_GS = 0` 时**有**沟道 |
| 让 MOS 管栅极悬空 | MOS 管栅极必须接直流回路（否则感应电荷击穿栅极） |

### 第 2 章 基本放大电路（易错最多）

| 错在哪 | 正确做法 |
|---|---|
| **不先求 Q 点就直接算 `A_u`** | `r_be` 依赖 `I_EQ`；**必须先求 Q 点** |
| 画直流通路时保留电容 | 直流通路中**电容一律开路** |
| 画交流通路时保留直流电源 | 交流通路中**直流电源接地**（内阻为零） |
| 把 `R_L'` 写成 `R_c` | `R_L' = R_c∥R_L`（有负载电阻时必须并联） |
| 忘记 `A_u = −βR_L'/r_be` 中的负号 | 共射**反相**，负号必须写；共基同相（无负号） |
| 求 `R_o` 时忘记把信号源置零 | 求输出电阻时输入信号源置零（电压源短路） |
| 输出电阻写成 `R_c∥R_L` | 输出电阻是**从输出端看进去的等效电阻**，负载不算在内，`R_o ≈ R_c` |
| 交流负载线画成过原点 | **交流负载线必过 Q 点**，且比直流负载线更陡 |
| 截止失真与饱和失真记反 | 截止失真削**正**半周（顶部平），饱和失真削**负**半周（底部平） |
| 认为分压式偏置「只靠电阻分压」就稳定 | 稳定靠**发射极电阻 `R_e` 的直流负反馈**，不是靠分压本身 |
| 认为 `R_e` 越大越好 | `R_e` 太大会压缩 `U_CEQ`（输出动态范围变小）；工程取 `U_BQ ≈ (3~5)U_BEQ` |
| 计算共集输出电阻时漏掉 `1/(1+β)` | `R_o = R_e∥[(r_be+R_s')/(1+β)]`，`R_s' = R_s∥R_b` |
| 认为射随器电压增益恰好为 1 | `A_u = (1+β)R_L'/[r_be+(1+β)R_L'] < 1`，只是非常接近 1 |
| 复合管电流方向判断错误 | 复合管的类型看**第一只管子**；前后管电流方向必须能流通 |

### 第 3 章 集成运算放大电路

| 错在哪 | 正确做法 |
|---|---|
| 把差分电路的共模增益写成 0 | 只有**双端输出且完全对称**时 `A_c = 0`；单端输出时 `A_c ≠ 0` |
| 认为 `R_e` 越大差模增益越小 | 双端输出时差模增益与 `R_e` 无关；`R_e` 只影响共模增益（提高 `K_CMR`） |
| 把单端输出的差模增益当成双端的 | 单端输出是双端的一半：`A_d1 = ½A_d` |
| `K_CMR` 不用分贝 | 无量纲时 `K_CMR = \|A_d/A_c\|`，用分贝时 `20 lg\|A_d/A_c\|` |
| 认为镜像电流源的输出电流与 `β` 无关 | `I_o = I_R/(1+2/β)`，`β` 小时误差可达 5% |
| 微电流源用直接除法算 | 微电流源公式含对数，需**迭代**或近似估算 |

### 第 4 章 放大电路的频率响应

| 错在哪 | 正确做法 |
|---|---|
| 把低频段和高频段的影响因素搞反 | **低频**由耦合电容、旁路电容决定；**高频**由结电容、分布电容决定 |
| 忽略密勒效应 | 跨接在输入输出间的 `C_b'c` 等效到输入端要乘 `(1+\|A_u\|)` |
| 认为提高增益不影响带宽 | `GBW = \|A_um\|·f_H` **是常数**，增益提高多少倍，带宽就减小多少倍 |
| 多级放大器的通频带算成各带宽之和 | 多级时**总带宽比任何单级都窄**（`f_H` 下降、`f_L` 上升） |
| `f_L`、`f_H` 合成公式用错 | `f_L ≈ 1.1√(Σf_Li²)`，`f_H ≈ 1/[1.1√(Σ1/f_Hi²)]`（一个放大、一个缩小） |
| 波特图斜率记错 | 一阶：低频 +20 dB/十倍频，高频 −20 dB/十倍频；二阶加倍 |
| 忘记 `f_β = f_T/β` | 共射截止频率与特征频率差 β 倍 |

### 第 5 章 放大电路中的反馈

| 错在哪 | 正确做法 |
|---|---|
| 只看反馈元件位置就判组态 | 必须用**输出短路法**（电压/电流）+ **输入节点法**（串联/并联）两步走 |
| 判「电压/电流反馈」时看反馈信号取自哪一端 | 看**取样对象**：取自输出电压（短路后消失）是电压反馈；取自输出电流（短路后仍在）是电流反馈 |
| 判「串联/并联」时看反馈信号来自哪一级 | 看**输入端的连接方式**：接同一节点是并联，接不同节点是串联 |
| 认为反馈信号一定接在输入端 | 反馈信号也可以接在发射极（如 `R_e` 未旁路） |
| 认为负反馈一定降低增益就是坏事 | 负反馈用增益换取稳定性、带宽、低失真、合适的 `R_i`/`R_o` |
| 忘记「电压反馈稳定输出电压、电流反馈稳定输出电流」 | 电压负反馈 → `R_o` 减小 → 输出电压稳定；电流负反馈 → `R_o` 增大 → 输出电流稳定 |
| 认为负反馈能抑制所有噪声 | 只能抑制**环内**产生的噪声；输入端的噪声会被同样放大 |
| 认为 `1+AF` 越大越好 | 太大时增益过低；且深度负反馈下容易自激，需相位裕度 |
| 自激条件只写幅度条件 | **必须同时**满足 `\|AF\| = 1`（幅度）与附加相移 ±180°（相位） |
| 补偿后认为带宽不变 | 补偿会**降低带宽**（主极点前移），是稳定性与带宽的折中 |

### 第 6 章 信号的运算和处理

| 错在哪 | 正确做法 |
|---|---|
| 所有含运放的电路都套虚短虚断 | 只有**线性区 + 负反馈**才成立；比较器、振荡器中虚短**不成立** |
| 认为虚短就是「真的短路」 | 虚短是**电位近似相等**，两点间并无导线，电流不能流过 |
| 认为虚断就是「真的断开」 | 虚断指**输入电流极小（≈0）**，但仍有电位 |
| 同相比例电路求 `R_i` 时用 `R_1` | 同相输入时 `R_i → ∞`（输入直接接运放同相端） |
| 忘记平衡电阻 | 反相比例中同相端应接 `R_2 = R_1∥R_f`，以减小偏置电流引起的误差 |
| 积分器的输出符号写错 | `u_o = −(1/RC)∫u_i dt`，**有负号**（反相输入） |
| 认为积分器可以无限积分 | 实际有直流反馈电阻防饱和；积分电容漏电也会造成误差 |
| 有源滤波器当无源滤波算 | 有源滤波有增益 `A_up`，截止频率处增益是 `A_up/√2`，不是 0.707 倍输入 |
| 二阶低通 `Q` 公式用错 | 压控电压源型 `Q = 1/(3 − A_up)`，要求 `A_up < 3`，否则自激 |
| 开方电路输入符号不限 | 开方电路要求 `u_i < 0`（保证运放处于负反馈状态） |

### 第 7 章 波形的发生和信号的转换

| 错在哪 | 正确做法 |
|---|---|
| 只写幅度条件 `\|AF\| = 1` | 必须**同时**满足幅度条件与相位条件（`φ_A+φ_F = ±2nπ`） |
| 认为起振与平衡条件相同 | **起振**要求 `\|AF\| > 1`，**平衡**要求 `\|AF\| = 1`，靠非线性稳幅过渡 |
| RC 桥式振荡器增益只给 `A = 3` | 起振需 `A > 3`（`R_f > 2R_1`），留余量并靠稳幅环节稳定 |
| 三点式相位条件判据记错 | 口诀 **「射同基反」**：与发射极相连的两个电抗同性质，与基极相连的两个电抗异性质 |
| 考毕兹与哈特莱的电容/电感公式搞混 | 考毕兹（**电容**三点式）：`C = C_1C_2/(C_1+C_2)`；哈特莱（**电感**三点式）：`L = L_1+L_2+2M` |
| 哈特莱公式漏掉 `2M` | 互感 `M` 不可忘（若两线圈无耦合则 `M = 0`） |
| 认为石英晶体的 `f_s` 与 `f_p` 相等 | `f_p = f_s√(1+C_s/C_0)`，略高于 `f_s`，两者非常接近（决定高稳定度） |
| 比较器用虚短求阈值 | 比较器只能用**虚断** + 令 `u_P = u_N`（临界状态）求阈值 |
| 滞回比较器的阈值写成一个值 | 有**两个**阈值（`U_T+`、`U_T−`），回差 `ΔU = 2U_T` |
| 忘记限幅 | 比较器输出电平由电源决定，实际常加双向稳压管限幅 |
| 矩形波周期公式写成 `2RC·ln(1+2R_1/R_2)` | `T = 2RC·ln(1 + 2R_2/R_1)`（`R_1` 接输出、`R_2` 接地），不是 `2RC`，也不能把 R_1、R_2 写反 |
| 精密整流的优点说不清 | 把二极管放进**反馈环内**，消除 0.7 V 死区，可整流 mV 级信号 |

### 第 8 章 功率放大电路

| 错在哪 | 正确做法 |
|---|---|
| 用 `V_CC²/(2R_L)` 算 OTL | OTL 是单电源，`U_om = V_CC/2`，故 `P_om = V_CC²/(8R_L)` |
| 忘记考虑饱和压降 | 精确计算用 `U_om = V_CC − U_CES`，`P_om = (V_CC−U_CES)²/(2R_L)` |
| 认为最大输出功率时管耗最大 | 单管管耗最大发生在 `U_om = 2V_CC/π ≈ 0.637V_CC` 时，此时 `η` 只有约 50% |
| 选管时按 `P_om` 选 | 单管 `P_CM ≥ 0.2P_om`；`U_(BR)CEO ≥ 2V_CC`；`I_CM ≥ V_CC/R_L` |
| 认为乙类效率可以达到 100% | 乙类理论最高 **78.5%**（`π/4`），实际更低 |
| 甲类效率记成 78.5% | 甲类变压器耦合 ≤ 50%，直接耦合 ≤ 25% |
| 忘记交越失真 | 乙类在过零附近两管都截止 → 加偏置构成**甲乙类** |
| 认为甲乙类偏置越大越好 | 偏置过大会增大静态管耗、降低效率，甚至热失控 |
| 认为散热片可有可无 | 无散热片时允许功耗可能只有标称值的几分之一（如 15.6 W → 2.08 W） |
| 忽略二次击穿 | 二次击穿是**不可逆**的损坏，必须保证工作点在安全区内 |

### 第 9 章 直流电源

| 错在哪 | 正确做法 |
|---|---|
| 桥式整流按半波算成 `0.45U_2` | 半波 `0.45U_2`，**桥式（全波）`0.9U_2`** |
| 二极管反向电压按有效值算 | 是**峰值** `√2U_2`（选管还要留 2 倍余量） |
| 认为每只二极管流过全部负载电流 | 桥式中每管只导通半周，`I_D(AV) = I_o/2` |
| 电容滤波后仍用 `0.9U_2` | 电容滤波后输出升高到约 **`1.2U_2`** |
| 滤波电容耐压按输出电压选 | 按峰值 `√2U_2` 选，并留 1.5~2 倍余量 |
| 忽略电容滤波的冲击电流 | 通电瞬间近似短路，二极管与变压器要留足电流余量 |
| 稳压管限流电阻只按一种情况算 | 必须按**两种最坏情况**求 `R` 的上下界 |
| 认为串联型稳压效率高 | `η ≈ U_o/U_I`，压差越大效率越低（常仅 30%~50%） |
| 三端稳压器压差给得太小 | 压差 `≥ 2~3 V`，否则无法稳压；太大则功耗与发热剧增 |
| 78xx 与 79xx 引脚混用 | 两者引脚定义不同；79xx 的电容极性与地线接法也要注意 |

### 第 10 章 模拟电子电路读图

| 错在哪 | 正确做法 |
|---|---|
| 读图直接算增益 | **先直流后交流**：先算 Q 点，再算动态指标 |
| 双电源输出静态电位当成 `V_CC/2` | 双电源（OCL、运放）静态输出为 **0 V**；单电源 OTL 才是 `V_CC/2` |
| 忽略去耦与消振电容 | 它们不改变功能，但决定电路能否稳定工作 |
| 报警电路不加回差 | 阈值附近噪声会使输出反复跳变，必须用**滞回**（正反馈） |
| 故障分析只看三极管 | 电阻开路、电容失效、虚焊比管子损坏更常见；**先量各点直流电位** |
| 认为输出为零一定是管子坏了 | 也可能是偏置开路、电源未接通、电容短路 |

## 第二部分 五大必考题型套路

### 题型一：静态工作点（Q 点）计算

**识别特征**：题目给出电源电压、各电阻值、`β`，要求 `I_BQ`、`I_CQ`、`U_CEQ`（FET 题则求 `I_DQ`、`U_GSQ`、`U_DSQ`）。

**解题套路（BJT）**：

| 电路类型 | 步骤 |
|---|---|
| **固定偏置** | ① `I_BQ = (V_CC − U_BEQ)/R_b` → ② `I_CQ = βI_BQ` → ③ `U_CEQ = V_CC − I_CQ R_c` |
| **分压式射极偏置** | ① `U_BQ = V_CC·R_b2/(R_b1+R_b2)` → ② `U_EQ = U_BQ − 0.7` → ③ `I_EQ = U_EQ/R_e`，`I_CQ ≈ I_EQ` → ④ `U_CEQ = V_CC − I_CQ(R_c+R_e)` |
| **集电极-基极偏置** | `I_BQ = (V_CC − U_BEQ)/(R_b + (1+β)R_c)`，再求 `I_CQ`、`U_CEQ` |

**FET 题**：① `U_GQ = V_DD·R_g2/(R_g1+R_g2)` → ② `U_SQ = I_DQ R_s` → ③ 代入 `i_D = I_DSS(1−u_GS/U_GS(off))²`（或增强型公式）解 `I_DQ` → ④ `U_DSQ = V_DD − I_DQ(R_d+R_s)`。**若方程有两个解，取使管子工作在恒流区（放大区）的解。**

**完整例题**
分压式射极偏置电路：`V_CC = 12 V`，`R_b1 = 30 kΩ`，`R_b2 = 10 kΩ`，`R_c = 2 kΩ`，`R_e = 1 kΩ`，`R_L = 2 kΩ`，`β = 50`，`U_BEQ = 0.7 V`。求 Q 点。

**解**：
① `U_BQ = V_CC·R_b2/(R_b1+R_b2) = 12 × 10/(30+10) = 120/40 = 3 V`
② `U_EQ = U_BQ − U_BEQ = 3 − 0.7 = 2.3 V`
③ `I_EQ = U_EQ/R_e = 2.3/1 kΩ = 2.3 mA`，故 `I_CQ ≈ 2.3 mA`
`I_BQ = I_CQ/β = 2.3/50 = 0.046 mA = 46 μA`
④ `U_CEQ = V_CC − I_CQ(R_c+R_e) = 12 − 2.3 × (2+1) = 12 − 6.9 = 5.1 V`

**校验**：`I_1 = V_CC/(R_b1+R_b2) = 12/40 kΩ = 0.3 mA ≈ 6.5I_BQ`（满足 `I_1 ≈ (5~10)I_BQ` ✓）
**答案**：`I_CQ = 2.3 mA`，`I_BQ = 46 μA`，`U_CEQ = 5.1 V`。

**陷阱提醒**：① 分压式偏置中 `U_BQ` 与 `R_L` 无关（`R_L` 只在交流通路起作用）；② `U_CEQ` 中必须包含 `R_e` 上的压降；③ 若算出 `U_CEQ < U_CES`（约 0.3 V），说明管子已饱和，题目数据有误或需重新设定。

### 题型二：微变等效电路法求增益

**识别特征**：题目在题型一的基础上要求 `A_u`、`R_i`、`R_o`，或画出微变等效电路。

**解题套路**：

| 步骤 | 操作 |
|---|---|
| ① | 由 Q 点求 `I_EQ`（mA），代入 `r_be = r_bb' + (1+β)·26/I_EQ`（`r_bb'` 无给定时忽略） |
| ② | 画交流通路：**直流电源接地、耦合与旁路电容短路** |
| ③ | 画微变等效电路：三极管换成 `r_be` 与 `βi_b` 受控源（注意电流方向！） |
| ④ | 求 `A_u = u_o/u_i`（先求 `u_i` 与 `u_o` 的表达式） |
| ⑤ | 求 `R_i`：从输入端看进去；求 `R_o`：信号源置零、负载开路，从输出端看进去 |

**完整例题**（续题型一的电路）
求该电路的 `r_be`、`A_u`、`R_i`、`R_o`。

**解**：
① `r_be = r_bb' + (1+β)26mV/I_EQ`，忽略 `r_bb'`：
`r_be = (1+50) × 26/2.3 = 51 × 11.30 = 576 Ω`（约 0.58 kΩ）
② 交流通路中 `R_e` 被旁路电容短路（若未旁路则需保留）。
③ 微变等效电路：`u_i` 加在 `R_b1∥R_b2` 与 `r_be` 上，`βi_b` 从集电极流出，`i_c` 流过 `R_c∥R_L`。
④ `u_o = −βi_b(R_c∥R_L) = −βi_b × (2k∥2k) = −βi_b × 1 kΩ`
`u_i = i_b r_be`，故
`A_u = −β(R_c∥R_L)/r_be = −50 × 1000/576 = −86.8`
⑤ `R_i = R_b1∥R_b2∥r_be = (30k∥10k)∥576 = 7.5k∥576 = 7500 × 576/(7500+576) = 4 320 000/8076 = 535 Ω`
⑥ `R_o = R_c = 2 kΩ`（信号源置零后从输出端看进去）

**答案**：`r_be = 576 Ω`，`A_u = −86.8`，`R_i = 535 Ω`，`R_o = 2 kΩ`。
**校验**：`A_u = −86.8` 即 `20 lg86.8 = 38.8 dB`，反相（相移 180°），数值合理。

**陷阱提醒**：① `R_L'` 必须用 `R_c∥R_L`，不能只用 `R_c`；② `r_be = r_bb' + (1+β)·26 mV/I_EQ`，其中 `26/I_EQ(mA)` 的数值直接以 **Ω** 为单位（mV ÷ mA = Ω），本例题即 `26/2.3 = 11.3 Ω`，不要当成 kΩ；③ 求 `R_o` 时**负载不算在内**；④ 有 `R_e` 且未旁路时，`A_u = −βR_L'/[r_be+(1+β)R_e]`，分母多一项；⑤ 共集电路求 `R_o` 时别忘了 `R_s' = R_s∥R_b` 与 `1/(1+β)`。

### 题型三：反馈组态判断与深度负反馈计算

**识别特征**：给出一张多级放大电路图或运放电路图，要求判断反馈的组态（正/负、交/直流、电压/电流、串联/并联）并求闭环增益。

**解题套路（四步判断法）**：

| 步骤 | 方法 | 判据 |
|---|---|---|
| ① 找反馈元件 | 找连接输出回路与输入回路的元件 | 有通路即有反馈 |
| ② 判正负 | **瞬时极性法** | 反馈使净输入减小 → 负反馈 |
| ③ 判电压/电流 | **输出短路法** | 输出（负载）短路后反馈消失 → 电压反馈；仍存在 → 电流反馈 |
| ④ 判串联/并联 | **输入节点法** | 反馈与输入接**同一节点** → 并联；接**不同节点** → 串联 |

**深度负反馈计算**：`A_f ≈ 1/F`（电压串联时 `A_uf = u_o/u_i ≈ 1/F`，`F = u_f/u_o`）。
- **电压串联**：`A_uf ≈ 1 + R_f/R_1`（同相比例）、`A_uf = 1`（射随器）
- **电压并联**：`A_uf ≈ −R_f/R_1`（反相比例）、`A_uf ≈ −R_f/R_s'`
- **电流串联**：`A_uf ≈ −R_L'/R_e`
- **电流并联**：`A_uf ≈ −R_L'(1 + R_f/R_e2)/R_f`（视具体电路）

**完整例题 1（三极管多级电路——★最常考）**
某两级放大器：`T_1` 为共射，`R_f` 从 `T_2` 的集电极接回 `T_1` 的基极；输入信号经 `R_s = 1 kΩ` 加到 `T_1` 基极，`R_f = 100 kΩ`，中频开环增益 `A = −1000`。判断反馈组态并求闭环增益。

**解**：
① 反馈元件：`R_f`（连接输出与输入）。
② **瞬时极性法**：设 `T_1` 基极 `+` → `T_1` 集电极 `−`（共射反相）→ `T_2` 基极 `−` → `T_2` 集电极 `+`（再反相一次）→ 经 `R_f` 回到 `T_1` 基极也是 `+` → 净输入电流减小 → **负反馈** ✓
③ **输出短路法**：把输出端（`T_2` 集电极）对地短路，`R_f` 的一端接地，反馈信号无法送回 → 反馈消失 → **电压反馈** ✓
④ **输入节点法**：`R_f` 接回 `T_1` 的**基极**，输入信号也接 `T_1` 基极 → 接**同一节点** → **并联反馈** ✓
⑤ 组态：**电压并联负反馈**（交流反馈，因 `R_f` 上有隔直电容）。
⑥ 闭环增益：`F = i_f/u_o = −1/R_f`（近似，反馈电流 `i_f = −u_o/R_f`）
`A_uf = u_o/i_i ≈ −R_f = −100 kΩ`（互阻增益）
若输入为电压源 `u_s` 经 `R_s` 接入，则 `i_i ≈ u_s/R_s`：
`A_uf = u_o/u_s ≈ −R_f/R_s = −100/1 = −100`

**校验**：闭环增益由 `−R_f/R_s` 决定，与开环增益无关（深度负反馈特征 ✓）；`A_f/A = 100/1000 = 0.1`，说明 `1+AF ≈ 10`。

**完整例题 2（电流串联）**
共射电路，`R_e = 100 Ω` 未被旁路，`R_c = 2 kΩ`，`R_L = 2 kΩ`，`r_be = 1 kΩ`，`β = 50`，`R_b` 很大可忽略。求反馈组态与闭环增益。

**解**：
① 反馈元件：`R_e`（取样发射极电流）。
② 瞬时极性法：基极 `+` → 发射极 `+`（射极跟随）→ `u_be = u_i − u_f` 减小 → **负反馈** ✓
③ 输出短路法：输出短路后 `i_e` 仍存在（发射极电流由输入决定）→ 反馈仍在 → **电流反馈** ✓
④ 输入节点法：反馈接在**发射极**，输入接**基极**，不是同一节点 → **串联反馈** ✓
⑤ 组态：**电流串联负反馈**。
⑥ `A_u = −βR_L'/[r_be + (1+β)R_e] = −50 × 1000/[1000 + 51×100] = −50 000/(1000+5100) = −50 000/6100 = −8.2`
深度负反馈近似：`A_uf ≈ −R_L'/R_e = −1000/100 = −10`（与 −8.2 接近 ✓）

**答案**：电流串联负反馈，`A_u = −8.2`（近似 −10）。

**陷阱提醒**：① **先判极性再判组态**，顺序不能乱；② 「电压/电流」看**输出端取样**，「串联/并联」看**输入端连接**，两者互不相干；③ 反馈信号接在发射极时是串联（不是并联）；④ 深度负反馈近似要求 `1+AF >> 1`，若不满足要用精确公式；⑤ 直流负反馈稳定 Q 点，交流负反馈改善动态性能，判断时要分清。

### 题型四：功率放大电路计算

**识别特征**：题目给出 `±V_CC`（OCL）或 `V_CC`（OTL）、`R_L`，要求 `P_om`、`η`、管耗、选管。

**解题套路**：

| 步骤 | OCL（双电源） | OTL（单电源） |
|---|---|---|
| ① 最大输出幅度 | `U_om = V_CC − U_CES` | `U_om = V_CC/2 − U_CES` |
| ② 最大输出功率 | `P_om = U_om²/(2R_L)` | `P_om = U_om²/(2R_L)` |
| ③ 电源功率 | `P_V = 2V_CC U_om/(πR_L)` | `P_V = V_CC U_om/(πR_L)` |
| ④ 效率 | `η = (π/4)(U_om/V_CC)` | `η = (π/4)(2U_om/V_CC)` |
| ⑤ 单管最大管耗 | `P_T1(max) ≈ 0.2P_om` | 同左 |
| ⑥ 选管 | `P_CM ≥ 0.2P_om`、`U_(BR)CEO ≥ 2V_CC`、`I_CM ≥ V_CC/R_L` | `U_(BR)CEO ≥ V_CC` |

**完整例题（OCL）**
OCL 互补对称功率放大电路：`±V_CC = ±18 V`，`R_L = 8 Ω`，输出管饱和压降 `U_CES = 1 V`。求最大输出功率、效率、单管最大管耗，并选择功率管。

**解**：
① 最大输出幅度：`U_om = V_CC − U_CES = 18 − 1 = 17 V`
② `P_om = U_om²/(2R_L) = 17²/(2 × 8) = 289/16 = 18.1 W`
③ 电源功率：`P_V = 2V_CC U_om/(πR_L) = 2 × 18 × 17/(3.1416 × 8) = 612/25.13 = 24.4 W`
④ 效率：`η = P_om/P_V = 18.1/24.4 = 74.2%`
（校验：`η = (π/4)(U_om/V_CC) = 0.7854 × 17/18 = 0.7854 × 0.9444 = 74.2%` ✓）
⑤ 单管最大管耗：`P_T1(max) ≈ 0.2P_om(理论) = 0.2 × V_CC²/(2R_L) = 0.2 × 324/16 = 0.2 × 20.25 = 4.05 W`
（精确式：`P_T1(max) = V_CC²/(π²R_L) = 324/(9.87 × 8) = 324/78.96 = 4.10 W`）
⑥ 选管：
`P_CM ≥ 4.1 W`（取 8~10 W）
`U_(BR)CEO ≥ 2V_CC = 36 V`（取 50~60 V）
`I_CM ≥ V_CC/R_L = 18/8 = 2.25 A`（取 3~5 A）

**答案**：`P_om = 18.1 W`，`η = 74.2%`，单管最大管耗约 4.1 W；选 `P_CM ≥ 8 W`、`U_(BR)CEO ≥ 50 V`、`I_CM ≥ 3 A` 的互补对管，并配散热片。

**陷阱提醒**：① OTL 题一定要把 `V_CC` 除以 2 再算（`P_om = V_CC²/(8R_L)`）；② 管耗最大**不在**最大输出时，而在 `U_om ≈ 0.637V_CC` 时；③ 选管反压要按 `2V_CC`（OCL）；④ 效率公式中的 `π/4 = 0.785`，**不要**与 `1/2` 混淆；⑤ 交越失真是乙类电路的固有问题，考试常问「如何消除」→ 加偏置构成甲乙类。

### 题型五：振荡频率计算

**识别特征**：给出 RC 或 LC 网络的元件值，要求振荡频率、起振条件或判断能否振荡。

**解题套路**：

| 电路 | 频率公式 | 起振/相位条件 |
|---|---|---|
| **RC 桥式（文氏电桥）** | ★ `f_0 = 1/(2πRC)` | RC 网络衰减 1/3、相移 0 → 需 `A > 3`，即 `R_f > 2R_1` |
| **RC 移相式** | `f_0 = 1/(2πRC√6)` | 每节移相 60°，三节共 180° |
| **变压器耦合 LC** | ★ `f_0 = 1/(2π√(LC))` | 靠变压器同名端保证正反馈 |
| **电容三点式（考毕兹）** | `f_0 = 1/(2π√(LC))`，`C = C_1C_2/(C_1+C_2)` | 「射同基反」 |
| **电感三点式（哈特莱）** | `f_0 = 1/(2π√(LC))`，`L = L_1+L_2+2M` | 「射同基反」 |
| **石英晶体** | `f_s = 1/(2π√(LC_s))` | 稳定度极高（10⁻¹⁰~10⁻¹¹） |

**完整例题 1（RC 桥式）**
RC 桥式正弦波振荡电路：`R = 10 kΩ`，`C = 0.02 μF`，`R_1 = 10 kΩ`。求振荡频率与 `R_f` 的最小值。

**解**：
`f_0 = 1/(2πRC) = 1/(2 × 3.1416 × 10×10³ × 0.02×10⁻⁶)`
分母 `= 6.2832 × 10⁴ × 2×10⁻⁸ = 6.2832 × 2 × 10⁻⁴ = 1.2566×10⁻³`
`f_0 = 1/(1.2566×10⁻³) = 795.8 Hz ≈ 796 Hz`
起振条件：`A > 3` → `1 + R_f/R_1 > 3` → `R_f > 2R_1 = 2 × 10 = 20 kΩ`
实际取 `R_f = 21~22 kΩ`（留余量，靠稳幅环节稳定），如用热敏电阻或二极管稳幅。

**答案**：`f_0 ≈ 796 Hz`，`R_f > 20 kΩ`（取 21 kΩ 以上）。

**完整例题 2（电容三点式）**
电容三点式（考毕兹）振荡电路：`L = 100 μH`，`C_1 = 200 pF`，`C_2 = 300 pF`。求振荡频率。

**解**：
`C = C_1C_2/(C_1+C_2) = 200 × 300/(200+300) = 60 000/500 = 120 pF`
`f_0 = 1/(2π√(LC)) = 1/(2 × 3.1416 × √(100×10⁻⁶ × 120×10⁻¹²))`
`LC = 1.2 × 10⁻¹⁴`，`√(LC) = 1.0954 × 10⁻⁷`
`f_0 = 1/(6.2832 × 1.0954×10⁻⁷) = 1/(6.883×10⁻⁷) = 1.453×10⁶ Hz`

**答案**：`f_0 ≈ 1.45 MHz`。

**完整例题 3（电感三点式）**
电感三点式（哈特莱）振荡电路：`L_1 = 150 μH`，`L_2 = 150 μH`，两线圈互感 `M = 30 μH`，`C = 100 pF`。求振荡频率。

**解**：
`L = L_1 + L_2 + 2M = 150 + 150 + 2 × 30 = 360 μH`
`LC = 360×10⁻⁶ × 100×10⁻¹² = 3.6×10⁻¹⁴`，`√(LC) = 1.897×10⁻⁷`
`f_0 = 1/(2 × 3.1416 × 1.897×10⁻⁷) = 1/(1.192×10⁻⁶) = 8.39×10⁵ Hz`

**答案**：`f_0 ≈ 839 kHz`。
**注意**：若忽略互感 `M`，算得 `L = 300 μH`，`f_0 = 919 kHz`，**误差近 10%**——互感不能忘。

**陷阱提醒**：① 单位换算：`μH = 10⁻⁶ H`，`pF = 10⁻¹² F`，`μF = 10⁻⁶ F`，代入时务必统一为 H 与 F；② 考毕兹用**串联**电容公式，哈特莱用**串联**电感公式（含 `2M`）；③ 起振条件是 `|AF| > 1`，稳定性条件是平衡 `|AF| = 1`；④ 只算频率不判相位条件会被扣分——务必说明「射同基反」或用瞬时极性法验证；⑤ 石英晶体的 `f_s` 与 `f_p` 相差极小，题目若给 `C_s`、`C_0` 要按公式算。

## 第三部分 通用应试检查清单

### 做题前的「三问」

1. **这是什么电路？**（组态/功能）——先定性再定量。
2. **要不要先算 Q 点？**——只要涉及 `r_be`、`g_m`、`β` 的题目都**必须先算 Q 点**。
3. **单位统一了吗？**——`mA` 与 `A`、`kΩ` 与 `Ω`、`μF` 与 `F`、`μH` 与 `H` 必须先统一。

### 计算过程中的「五查」

| 检查项 | 具体内容 |
|---|---|
| 查符号 | 共射有负号（反相），共基/共集无负号（同相） |
| 查并联 | `R_L' = R_c∥R_L`、`R_b = R_b1∥R_b2` 是否漏掉 |
| 查分母 | `r_be` 中是否乘了 `(1+β)`；`R_o` 中是否除了 `(1+β)` |
| 查量纲 | 电压得 V、电流得 mA 或 A、功率得 mW 或 W、频率得 Hz |
| 查合理性 | 增益量级是否合理（共射几十~几百倍）、效率是否 < 78.5%、`U_CEQ` 是否 > 1 V |

### 常见「送分点」与「丢分点」

| 送分点（一定要写） | 丢分点（千万别犯） |
|---|---|
| 写出公式再代入数值 | 只写最后答案没过程 |
| 结果带单位 | 数值对但单位错（如 kHz 写成 Hz） |
| 说明反馈极性判断过程 | 直接写「电压串联负反馈」不写理由 |
| 画出微变等效电路 | 跳过电路直接套公式 |
| 校验（如 `I_1 ≈ 5~10I_BQ`、`η < 78.5%`） | 算出 `η = 95%` 还照抄 |
| 选管给出三条准则 | 只写 `P_CM ≥ 0.2P_om` |
| 说明「先直流后交流」的思路 | 交流直流通用一套电路 |

### 时间分配建议（以 120 分钟卷为例）

| 题型 | 建议用时 | 备注 |
|---|---|---|
| 选择/填空 | 25 分钟 | 概念题，不纠缠 |
| Q 点 + 微变等效大题 | 30 分钟 | **分值最高，务必算完** |
| 反馈组态判断 | 20 分钟 | 判断过程写清楚得分快 |
| 功放计算 | 20 分钟 | 公式套准，注意 OCL/OTL 区别 |
| 振荡/频率响应/电源 | 20 分钟 | 单位换算是关键 |
| 检查 | 5 分钟 | 查符号、量纲、合理性 |

> **最后的忠告**：模拟电路题的失分，**八成不是不会，而是「不先算 Q 点」「漏符号」「单位错」「忘了并联」这四件事**。把这四件事做成条件反射，分数就能明显提高。
