## 9.1 直流电源的组成及各部分的作用

**直流稳压电源（DC regulated power supply）把 220 V/50 Hz 的交流电网电压转换成稳定的直流电压，由变压器、整流、滤波、稳压四个环节组成。**

```text
  220V/50Hz     ┌────────┐   ┌────────┐   ┌────────┐   ┌────────┐
  交流电网 ────→│ 电源变 │──→│ 整流   │──→│ 滤波   │──→│ 稳压   │──→ 稳定直流
               │ 压器   │   │ 电路   │   │ 电路   │   │ 电路   │
               └────────┘   └────────┘   └────────┘   └────────┘
               降压/隔离     AC→脉动DC    减小纹波     稳定输出
```

| 组成部分 | 作用 | 关键器件 |
|---|---|---|
| **电源变压器** | 把 220 V 降到合适的电压，并实现**电气隔离** | 工频变压器（`U_2` 为副边有效值） |
| **整流电路** | 把交流电压变成**单向脉动**直流电压 | 整流二极管（利用单向导电性） |
| **滤波电路** | 滤除脉动成分，使输出趋于平滑 | 电容、电感（利用储能元件的惰性） |
| **稳压电路** | 在电网波动与负载变化时保持输出稳定 | 稳压管、三端稳压器、开关电源 |

**为什么必须有稳压环节？** 整流滤波后的电压并不稳定：① 电网电压本身有 ±10% 的波动；② 负载电流变化时，滤波电容放电加快，`U_o` 随之下降。**稳压环节就是用负反馈把这种变化压下去。**

## 9.2 整流电路

### 9.2.1 整流电路的分析方法及其基本参数

**分析整流电路的三步：① 判断二极管的导通与截止（理想模型或恒压降模型）；② 画出一个周期内输出电压的波形；③ 用平均值（直流分量）求输出电压，用峰值求二极管的反向电压。**

**常用基本参数**：

| 参数 | 符号 | 含义 |
|---|---|---|
| 副边电压有效值 | `U_2` | 变压器副边输出的交流有效值 |
| 输出直流电压 | `U_o(AV)` | 整流输出电压的平均值 |
| 输出直流电流 | `I_o(AV)` | `I_o = U_o/R_L` |
| 二极管平均电流 | `I_D(AV)` | 流过每个二极管的电流平均值 |
| 二极管最大反向电压 | `U_RM` | 二极管截止时承受的最大反向电压 |
| 脉动系数 | `S` | 基波幅值与直流分量之比，衡量脉动程度 |

#### 单相半波整流电路

**`U_o = 0.45U_2`，`I_D = I_o`，`U_RM = √2U_2`。**

| 项目 | 数值 |
|---|---|
| 输出直流电压 | `U_o = 0.45U_2` |
| 二极管平均电流 | `I_D(AV) = I_o = 0.45U_2/R_L` |
| 最大反向电压 | `U_RM = √2U_2` |
| 脉动系数 | `S ≈ 1.57`（很大） |
| 变压器利用率 | 低（有直流磁化） |

**缺点**：只用了半个周期，效率低、脉动大，实际很少使用。

### 9.2.2 单相桥式整流电路

**单相桥式整流用四只二极管接成电桥，正负半周都有两只二极管导通，输出为全波脉动直流：`U_o = 0.9U_2`。**

```text
          ┌───────┬───────┐
          │       │       │
   u_2 ───┤ D_1 ↘ │ ↙ D_2 │
      │   │       │       │
      │   ├───────┼───────┤──→ + U_o
      │   │       │       │
      └───┤ D_3 ↗ │ ↖ D_4 │
          │       │       │
          └───────┴───────┘
                  │
                 −（地）

  正半周：D_1、D_3 导通；负半周：D_2、D_4 导通
```

| 项目 | 数值 | 与半波比较 |
|---|---|---|
| 输出直流电压 | **`U_o = 0.9U_2`** | 提高一倍 |
| 二极管平均电流 | **`I_D(AV) = I_o/2`** | 每管只承担一半 |
| 最大反向电压 | **`U_RM = √2U_2`** | 相同 |
| 脉动系数 | `S ≈ 0.67` | 明显减小 |
| 变压器利用率 | 高，**无直流磁化** | 显著改善 |

**优点**：输出高一倍、脉动小、变压器无直流磁化、每管电流小；**缺点**：需要四只二极管，且导通时有两管串联压降（约 1.4 V）。

**桥式整流的记忆诀窍**：**「对角的管子一起导通，每管只干半周活」**。

## 9.3 滤波电路

### 9.3.1 电容滤波电路

**在整流输出端并联一个大电容，利用电容的充放电特性把脉动电压「填平」：`U_o ≈ 1.2U_2`（桥式整流、`R_LC ≥ (3~5)T/2` 时）。**

**工作原理**：

```text
   u_o                        电容充电快（二极管导通）
    │    ╱╲   ╱╲   ╱╲          电容放电慢（二极管截止）
    │   ╱  ╲ ╱  ╲ ╱  ╲         → 输出趋于平滑
    │  ╱    V    V    ╲
    │ ╱  放电段（RC 慢）╲
    └────────────────────── t
      无电容时：0.9U_2 的脉动波形
      有电容时：平均值升高到约 1.2U_2，纹波减小
```

| 阶段 | 二极管 | 电容 |
|---|---|---|
| 整流输出瞬时值 > 电容电压 | **导通** | 被快速充电到峰值附近 |
| 整流输出瞬时值 < 电容电压 | **截止** | 通过 `R_L` 缓慢放电 |

**关键参数**：

| 项目 | 计算/选择 |
|---|---|
| 输出电压（桥式，全波） | `U_o ≈ 1.2U_2`（工程估算） |
| 输出电压（半波） | `U_o ≈ U_2` |
| 滤波电容容量 | `C ≥ (3~5)T/(2R_L)`，`T = 1/f = 20 ms`（50 Hz） |
| 电容耐压 | `≥ √2U_2`（一般取 1.5~2 倍余量） |
| 二极管冲击电流 | 很大（导通角小、充电电流尖峰高），选管要留足余量 |

> **为什么滤波电容能提高输出电压？** 无电容时输出是「全波整流」的平均值 `0.9U_2`；有电容后电压被抬升到接近峰值 `√2U_2 ≈ 1.41U_2`，考虑纹波与压降后工程上取 `1.2U_2`。
>
> **为什么电容要「大」？** 时间常数 `R_LC` 必须远大于放电时间（约 `T/2`），否则电容还没放电完就又开始充电，纹波就大。`R_LC ≥ (3~5)T/2` 是工程经验值。

**电容滤波的缺点**：① 输出直流电压随负载电流增大而明显下降（外特性软）；② 二极管冲击电流大；③ 只适合负载电流较小且变化不大的场合。

### 9.3.2 倍压整流电路

**倍压整流利用电容「充电储能 + 与电源串联放电」的叠加原理，得到高于变压器副边电压峰值的直流输出。**

| 电路 | 输出电压 | 说明 |
|---|---|---|
| 二倍压 | `U_o = 2√2U_2` | 两个二极管 + 两个电容 |
| n 倍压 | `U_o ≈ n√2U_2` | n 个二极管 + n 个电容 |

**关键限制**：倍压整流**只适合小电流负载**（几 mA 以内），因为负载电流会使电容放电，输出电压迅速下降。

**用途**：示波器、光电倍增管、静电除尘等需要高压小电流的场合。

### 9.3.3 其它形式的滤波电路

| 滤波电路 | 组成 | 特点 |
|---|---|---|
| 电容滤波（C 型） | 一只大电容 | 最简单，外特性软，适合小电流 |
| 电感滤波（L 型） | 串联大电感 | 外特性硬，适合大电流，体积大 |
| **LC 滤波** | 电感 + 电容 | 滤波效果好，但有谐振可能 |
| **π 型 RC 滤波** | 电容 + 电阻 + 电容 | 效果好、成本低，但电阻上有压降与损耗 |
| **π 型 LC 滤波** | 电容 + 电感 + 电容 | 效果最好，适合大电流 |

**选择原则**：**小电流用 C 型或 π 型 RC；大电流用 L 型或 π 型 LC。**

## 9.4 稳压管稳压电路

### 9.4.1 电路的组成

**稳压管稳压电路由稳压管 `D_Z` 与限流电阻 `R` 组成：`D_Z` 与负载 `R_L` 并联，`R` 串联在整流滤波输出与稳压管之间。**

```text
        R                ┌──────┐
  U_I ──/\/\/──┬──────────┤ 负载 │
               │          │ R_L  │
               │          └──┬───┘
             ┌─┴─┐           │
             │D_Z│ 反向接       │
             └─┬─┘           │
               └─────────────┘
                      地
```

### 9.4.2 稳压原理

**稳压管工作在反向击穿区时，其端电压几乎不随电流变化（`r_Z` 很小）；当 `U_I` 或 `I_L` 变化时，`I_Z` 自动反向变化，使 `R` 上的压降相应改变，从而保持 `U_o = U_Z` 基本不变。**

| 变化 | 自动调节过程 |
|---|---|
| `U_I` 升高 | `U_o` 略升 → `I_Z` 急剧增大 → `R` 上压降增大 → `U_o` 降回 |
| `U_I` 降低 | `U_o` 略降 → `I_Z` 急剧减小 → `R` 上压降减小 → `U_o` 升回 |
| `I_L` 增大 | `U_o` 略降 → `I_Z` 急剧减小 → 总电流基本不变 → `U_o` 升回 |
| `I_L` 减小 | `U_o` 略升 → `I_Z` 急剧增大 → 总电流基本不变 → `U_o` 降回 |

**关键前提**：`I_Z` 必须始终在 `I_Zmin ~ I_Zmax` 之间——这由限流电阻 `R` 的取值保证。

### 9.4.3 性能指标

| 指标 | 定义 | 表达式 |
|---|---|---|
| **稳压系数 `S_r`** | 输入变化时输出的相对变化之比 | `S_r = (ΔU_o/U_o)/(ΔU_I/U_I) = r_Z/(R + r_Z) ≈ r_Z/R` |
| **输出电阻 `R_o`** | 输出变化与电流变化之比 | `R_o = ΔU_o/ΔI_o ≈ r_Z ∥ R ≈ r_Z` |
| 温度系数 | 温度变化引起的输出变化 | 由稳压管本身的温度系数决定 |

**结论：`R` 越大、`r_Z` 越小，稳压性能越好。** 但 `R` 太大会导致 `I_Z` 不足（无法稳压）或负载供电不足。

### 9.4.4 电路参数的选择

**限流电阻 `R` 的取值范围由两种最坏情况决定：**

| 最坏情况 | 条件 | 要求 | 得到 |
|---|---|---|---|
| `U_I` 最大且 `I_L` 最大 | `I_Z` 最小 | `I_Z ≥ I_Zmin` | **`R ≤ (U_Imax − U_Z)/(I_Zmin + I_Lmax)`** |
| `U_I` 最小且 `I_L` 最小 | `I_Z` 最大 | `I_Z ≤ I_Zmax` | **`R ≥ (U_Imin − U_Z)/(I_Zmax + I_Lmin)`** |

**稳压管的选择**：`U_Z = U_o`（所需输出电压）；`I_Zmax ≥ I_Lmax`（一般取 `I_Zmax = (2~3)I_Lmax`）。

## 9.5 串联型稳压电路

### 9.5.1 工作原理

**串联型稳压电路由采样电路、基准电压、比较放大电路、调整管四部分组成，用负反馈自动调节调整管的压降来稳定输出。**

```text
   U_I ──┬──[ 调整管 T ]──┬──────────────┬──── U_o
         │                │              │
         │             ┌──┴──┐         ┌─┴─┐
         │             │ 比较│← U_Z    │采样│ R_1
         │             │ 放大│         │电路│
         │             └──┬──┘         ├───┤ R_2
         │                │ U_f        │   │
         └────────────────┴────────────┴───┴── 地
```

| 组成部分 | 作用 |
|---|---|
| **调整管 T** | 串联在输入与输出之间，相当于一个受控可变电阻，**承担全部输出电流** |
| **采样电路**（`R_1`、`R_2`） | 取出一部分输出电压作为反馈信号 `U_f` |
| **基准电压**（稳压管） | 提供稳定的参考电压 `U_Z` |
| **比较放大电路** | 把 `U_f` 与 `U_Z` 之差放大后去控制调整管 |

**稳压过程**：`U_o ↑ → U_f ↑ → (U_f − U_Z) ↑ → 比较放大输出 ↑ → 调整管基极电流 ↓ → U_CE ↑ → U_o ↓`，从而保持 `U_o` 稳定。

**输出电压的表达式**：

**`U_o = U_Z·(1 + R_1/R_下)`**，其中 `R_下` 为采样网络中**反馈点以下部分**的等效电阻。

**调节范围**：把 `R_2` 换成电位器，`R_下` 连续变化，则 `U_o` 连续可调；电位器滑到最上端时 `R_下` 最小、`U_o` 最大。

| 优点 | 缺点 |
|---|---|
| 稳压性能好（`S_r` 可达 10⁻⁴） | 调整管有较大压降与管耗，**效率低**（`η ≈ U_o/U_I`，一般 30%~50%） |
| 输出电流大、纹波小 | 需要散热 |
| 电路成熟、易于集成 | 输入必须高于输出（降压型） |

### 9.5.2 集成稳压器中的基准电压电路和保护电路

**集成稳压器内部除了串联稳压的基本环节，还集成了基准电压源和保护电路。**

| 电路 | 作用 |
|---|---|
| 基准电压源 | 用稳压管、带隙基准（`U_BE` 与 `ΔU_BE` 组合）产生低温漂的参考电压 |
| **过流保护** | 检测调整管电流，超过限值时降低其基极电流 |
| **过热保护** | 检测芯片温度，超过 150 °C 时关断输出 |
| **短路保护** | 输出短路时限制电流，防止调整管烧毁 |
| 安全区保护 | 限制调整管的工作点不超出 SOA |

### 9.5.3 集成稳压器电路

**三端稳压器（three-terminal regulator）只有输入、输出、公共（地）三个端子，使用极其简单。**

| 系列 | 输出 | 型号举例 | 最大电流 |
|---|---|---|---|
| **78xx** | 固定**正**电压 | 7805（+5 V）、7812（+12 V）、7815（+15 V） | 1.5 A（78Lxx 为 0.1 A，78Mxx 为 0.5 A） |
| **79xx** | 固定**负**电压 | 7905（−5 V）、7912（−12 V） | 1.5 A |
| **LM317** | **可调正**电压 | 1.25~37 V | 1.5 A |
| **LM337** | **可调负**电压 | −1.25~−37 V | 1.5 A |

**基本使用要求**：

1. **输入输出压差** `U_I − U_o ≥ 2~3 V`（否则无法稳压，输出纹波大）；
2. **功耗** `P = (U_I − U_o)·I_o`，超过 1 W 必须加散热片；
3. 输入端与输出端都要接**去耦电容**（输入端 0.33 μF、输出端 0.1 μF），防止自激；
4. 输出电流不够时，可**外接功率管扩流**（并联或采用扩流电路）。

**LM317 可调输出的接法**：`U_o = 1.25 × (1 + R_2/R_1)`，其中 `R_1` 接在输出端与调整端之间（典型 240 Ω），`R_2` 接在调整端与地之间。

### 9.5.4 三端稳压器的应用

| 应用 | 接法 |
|---|---|
| 固定正电源 | 78xx 直接接，输入端接整流滤波输出 |
| 固定负电源 | 79xx 直接接（注意电容极性与地线连接） |
| **正负对称电源** | 7815 与 7915 配对，共地 |
| **可调电源** | LM317 + 电位器 |
| **恒流源** | LM317 接成恒流（输出与调整端之间接电阻 `R`，`I = 1.25/R`） |
| **扩流** | 外接大功率三极管并联分担电流 |
| **提高输出电压** | 在公共端串稳压管或电阻（`U_o = U_xx + U_Z`） |

## 9.6 开关型稳压电路

### 9.6.1 开关型稳压电路的发展及分类

**开关型稳压电路（switching mode power supply, SMPS）让调整管工作在「开关」状态（饱和导通或截止），通过控制导通时间比例来调节输出，效率可达 70%~95%。**

| 分类方式 | 类型 |
|---|---|
| 按开关管连接 | **串联型（降压/Buck）**、**并联型（升压/Boost）**、反激/正激 |
| 按控制方式 | 脉宽调制（PWM）、脉频调制（PFM）、混合调制 |
| 按是否隔离 | 非隔离型、隔离型（带高频变压器） |

**与线性稳压的对比**：

| 比较项 | 线性稳压（串联型） | 开关型稳压 |
|---|---|---|
| 调整管工作状态 | 放大区（**承受压降**） | 开关状态（**饱和/截止**） |
| 效率 | 30%~50% | **70%~95%** |
| 体积重量 | 大（工频变压器 + 散热片） | 小（高频变压器） |
| 输出纹波 | 小 | 较大 |
| 电磁干扰 | 小 | **大**（开关噪声） |
| 电路复杂度 | 简单 | 复杂 |
| 适用场合 | 小功率、低噪声 | 大功率、便携设备 |

### 9.6.2 串联开关型稳压电路

**串联开关型（Buck）把开关管串联在输入与输出之间，用电感、电容储能与续流二极管配合，输出电压低于输入：`U_o = U_I·D`（`D = t_on/T` 为占空比）。**

**工作过程**：开关管导通时，`U_I` 经电感向负载供电并给电感储能，续流二极管截止；开关管截止时，电感通过续流二极管继续向负载供电。

**稳压原理**：输出电压变化 → 反馈控制 `D` 变化 → 调整输出。例如 `U_o` 升高时减小 `D`。

### 9.6.3 并联开关型稳压电路

**并联开关型（Boost）把电感串在输入端、开关管并在输出侧，输出电压高于输入：`U_o = U_I/(1 − D)`。**

**特点**：开关管截止时电感释放能量向负载供电（电压叠加），故输出高于输入；适合电池升压、LED 驱动等场合。

**其它常见拓扑**：Buck-Boost（升降压，输出反极性）、Cuk、反激（Flyback，带隔离）、正激（Forward）。

## 9.7 Multisim 应用举例

**用 Multisim 研究三端稳压器 W7805 的稳压性能**：

1. 搭建「变压器 + 桥式整流 + 电容滤波 + 7805」的完整电路；
2. 用**瞬态分析**观察整流前后的波形（脉动 → 平滑）；
3. 用**直流扫描分析**改变输入电压，观察输出保持 +5 V 的范围（验证最小压差 2~3 V）；
4. 改变负载电阻，观察输出电压与电流的关系（验证外特性与限流保护）；
5. 增大滤波电容，观察纹波电压的减小。

## 典型例题

**例 9.1**（题型：桥式整流基本计算——★必考）
单相桥式整流电路，变压器副边电压有效值 `U_2 = 20 V`，负载 `R_L = 100 Ω`。求输出直流电压、输出电流、每只二极管的平均电流与最大反向电压。

**解**：
`U_o = 0.9U_2 = 0.9 × 20 = 18 V`
`I_o = U_o/R_L = 18/100 = 0.18 A = 180 mA`
`I_D(AV) = I_o/2 = 180/2 = 90 mA`
`U_RM = √2U_2 = 1.414 × 20 = 28.3 V`

**答案**：`U_o = 18 V`，`I_o = 180 mA`，每管平均电流 90 mA，最大反向电压 28.3 V。
**选管**：选 `I_F ≥ 2 × 90 mA = 180 mA`（留余量取 1 A）、`U_RRM ≥ 2 × 28.3 = 57 V`（取 100 V）的管子，如 1N4001（1 A / 50 V）或 1N4002（1 A / 100 V），推荐后者。

**例 9.2**（题型：加电容滤波后的计算——★必考）
在例 9.1 的电路中加入滤波电容，设 `R_LC ≥ (3~5)T/2` 满足。求输出电压；若要求输出 12 V、负载电流 0.5 A，求所需 `U_2`、电容容量与耐压。

**解**：
**加电容后**：`U_o ≈ 1.2U_2 = 1.2 × 20 = 24 V`（比无滤波的 18 V 高 33%）
**反求 `U_2`**：`U_2 = U_o/1.2 = 12/1.2 = 10 V`
**滤波电容**：`R_L = U_o/I_L = 12/0.5 = 24 Ω`
由 `C ≥ (3~5)T/(2R_L)`，取 `T = 20 ms`（50 Hz）与系数 4：
`C ≥ 4 × 0.02/(2 × 24) = 0.08/48 = 1.67×10⁻³ F = 1670 μF`
取标称值 **2200 μF**
**电容耐压**：`√2U_2 = 1.414 × 10 = 14.1 V`，取 **25 V** 标称值

**答案**：加电容后 `U_o ≈ 24 V`；要得到 12 V/0.5 A，需 `U_2 = 10 V`、`C = 2200 μF/25 V`。
**注意**：加电容后二极管冲击电流很大，实际要在整流输出与电容之间串小电阻（或选大电流二极管）。

**例 9.3**（题型：稳压管电路限流电阻的计算——★必考）
稳压管稳压电路：`U_Z = 6 V`，`I_Zmin = 10 mA`，`I_Zmax = 30 mA`；输入电压 `U_I = 15 ± 2 V`（即 13~17 V）；负载电流 `I_L = 0~20 mA`。求限流电阻 `R` 的取值范围，并选定标称值。

**解**：
**上界**（`U_I` 最大、`I_L` 最大时，`I_Z` 最小）：
`R ≤ (U_Imax − U_Z)/(I_Zmin + I_Lmax) = (17 − 6)/(10 + 20) mA = 11 V/30 mA = 0.367 kΩ = 367 Ω`
**下界**（`U_I` 最小、`I_L` 最小时，`I_Z` 最大）：
`R ≥ (U_Imin − U_Z)/(I_Zmax + I_Lmin) = (13 − 6)/(30 + 0) mA = 7 V/30 mA = 0.233 kΩ = 233 Ω`
故 `233 Ω ≤ R ≤ 367 Ω`，取标称值 **300 Ω**。

**校验**（取 `R = 300 Ω`）：
最坏情况 1：`U_I = 17 V`、`I_L = 20 mA` → `I_Z = (17 − 6)/0.3 − 20 = 36.7 − 20 = 16.7 mA`（在 10~30 mA 内 ✓）
最坏情况 2：`U_I = 13 V`、`I_L = 0` → `I_Z = (13 − 6)/0.3 − 0 = 23.3 mA`（在 10~30 mA 内 ✓）

**答案**：`233 Ω ≤ R ≤ 367 Ω`，取 300 Ω。
**性能估算**：若 `r_Z = 10 Ω`，则稳压系数 `S_r ≈ r_Z/R = 10/300 = 0.033`，即输入变化 10% 时输出只变化 0.33%。

**例 9.4**（题型：稳压管稳压电路的故障判断）
在例 9.3 的电路中，若把 `R` 误换成 100 Ω，会出现什么问题？

**解**：
取 `R = 100 Ω`，最坏情况 2（`U_I = 13 V`、`I_L = 0`）：
`I_Z = (13 − 6)/0.1 − 0 = 70 mA > I_Zmax = 30 mA`

**答案**：`I_Z` 达到 70 mA，超过稳压管的最大允许电流，**稳压管会因过热而损坏**。
**故障现象**：稳压管烧毁（可能短路或开路）；若短路，则输出变为 0，限流电阻 `R` 上功耗 `= (13−0)²/100 = 1.69 W`，也可能烧毁。
**结论**：`R` 太小 → 稳压管过流损坏；`R` 太大 → 无法稳压（`I_Z` 小于 `I_Zmin`，输出随负载波动）。

**例 9.5**（题型：串联型稳压电路输出电压）
串联型稳压电路：基准电压 `U_Z = 6 V`，采样网络由 `R_1 = 10 kΩ`（接输出端）与 `R_下 = 20 kΩ`（接地的下部分）串联组成，反馈电压取自两者连接点。求输出电压。

**解**：
反馈电压 `U_f = U_o·R_下/(R_1 + R_下) = U_Z`
`U_o = U_Z·(R_1 + R_下)/R_下 = U_Z(1 + R_1/R_下)`
`= 6 × (1 + 10/20) = 6 × 1.5 = 9 V`

**答案**：`U_o = 9 V`。
**调节范围**：若把下部分换成 5~25 kΩ 的电位器，则
`U_o(min) = 6 × (1 + 10/25) = 8.4 V`，`U_o(max) = 6 × (1 + 10/5) = 18 V`
即输出电压可在 **8.4~18 V** 之间连续调节。

**例 9.6**（题型：串联型稳压电路的效率与管耗）
例 9.5 的电路，输入电压 `U_I = 15 V`，输出 `U_o = 9 V`，输出电流 `I_L = 1 A`。求调整管的管耗与电路效率。

**解**：
调整管压降：`U_CE = U_I − U_o = 15 − 9 = 6 V`
调整管管耗：`P_T = U_CE·I_L = 6 × 1 = 6 W`
输出功率：`P_o = U_o·I_L = 9 × 1 = 9 W`
效率：`η = P_o/(U_I·I_L) = 9/15 = 0.6 = 60%`

**答案**：`P_T = 6 W`，`η = 60%`。
**散热要求**：若 `R_θjc = 3 °C/W`、`R_θcs = 1 °C/W`、`T_jm = 150 °C`、`T_a = 25 °C`，则需
`R_θsa ≤ (150 − 25)/6 − 3 − 1 = 20.8 − 4 = 16.8 °C/W`
即需要一块中等大小的散热片。**这就是线性稳压效率低带来的代价。**

**例 9.7**（题型：三端稳压器的应用——★常考）
用 7805 构成 +5 V 稳压电源，输入电压由整流滤波得到 `U_I = 9 V`（空载时 11 V），输出电流 `I_L = 0.8 A`。求芯片功耗（最坏情况）与所需散热片热阻（`R_θjc = 5 °C/W`、`R_θcs = 1.5 °C/W`、`T_jm = 125 °C`、`T_a = 40 °C`）。

**解**：
最坏情况取输入电压最高（空载 11 V）：
`P = (U_Imax − U_o)·I_L = (11 − 5) × 0.8 = 4.8 W`
（正常带载时 `P = (9 − 5) × 0.8 = 3.2 W`）
所需总热阻：`R_θ总 ≤ (T_jm − T_a)/P = (125 − 40)/4.8 = 85/4.8 = 17.7 °C/W`
`R_θsa ≤ 17.7 − 5 − 1.5 = 11.2 °C/W`

**答案**：最坏情况功耗 4.8 W，需散热片热阻不大于 11.2 °C/W。
**提示**：输入电压不宜过高（压差越大功耗越大），一般取 `U_I = U_o + 3 V` 左右最经济。**7805 的输入滤波电容与输出去耦电容必须接**，否则可能自激。

**例 9.8**（题型：LM317 可调输出）
LM317 构成可调稳压电源，`R_1 = 240 Ω` 接在输出端与调整端之间，`R_2` 接在调整端与地之间。求 `R_2 = 720 Ω` 时的输出电压；若要输出 12 V，`R_2` 应取多大？

**解**：
`U_o = 1.25 × (1 + R_2/R_1)`
`R_2 = 720 Ω` 时：`U_o = 1.25 × (1 + 720/240) = 1.25 × 4 = 5 V`
要输出 12 V：`12 = 1.25 × (1 + R_2/240)` → `1 + R_2/240 = 9.6` → `R_2/240 = 8.6`
`R_2 = 8.6 × 240 = 2064 Ω ≈ 2 kΩ`

**答案**：`R_2 = 720 Ω` 时输出 5 V；输出 12 V 时取 `R_2 ≈ 2 kΩ`。
**说明**：LM317 的 1.25 V 是内部基准电压（带隙基准），`R_1` 取 240 Ω 是保证最小负载电流（约 5 mA）的典型值。

**例 9.9**（题型：开关型稳压电路）
串联开关型稳压电路（Buck），输入 `U_I = 20 V`，开关频率 `f = 50 kHz`，占空比 `D = 0.4`。求输出电压；若把该电路改用线性串联稳压实现同样输出，比较两者的效率。

**解**：
`U_o = U_I·D = 20 × 0.4 = 8 V`
开关型效率：取典型值 `η ≈ 85%`
线性串联型效率：`η = U_o/U_I = 8/20 = 0.4 = 40%`

**答案**：`U_o = 8 V`；开关型效率约 85%，线性型只有 40%，**相差一倍以上**。
**说明**：线性稳压中调整管承受 `20 − 8 = 12 V` 的压降，这部分功率全部变成热；开关型中调整管只在导通时饱和（压降小）、截止时无电流，故损耗小。**代价是输出纹波大、有电磁干扰。**

**例 9.10**（题型：倍压整流）
倍压整流电路，变压器副边电压有效值 `U_2 = 10 V`。求二倍压输出的直流电压。

**解**：
`U_o = 2√2U_2 = 2 × 1.414 × 10 = 28.3 V`

**答案**：`U_o = 28.3 V`。
**限制**：只适合小电流（几 mA）负载；负载电流增大时输出迅速下降。

**例 9.11**（题型：整流电路的故障分析）
桥式整流电路中，若其中一只二极管（D1）虚焊开路，输出电压变成多少？若 D1 短路，会怎样？

**解**：
**D1 开路**：正半周失去通路，只有负半周（D2、D4）能导通，电路退化为**半波整流**：
`U_o = 0.45U_2`（原来是 `0.9U_2`，降为一半），且脉动系数增大到 1.57。
**D1 短路**：正半周时电源经 D1 短路，形成很大的短路电流，**会烧毁二极管或变压器**。

**答案**：D1 开路 → 输出降为 `0.45U_2`（半波整流）；D1 短路 → 电源短路，烧管或烧变压器。
**故障判断经验**：输出约为正常值的一半，通常是**一只二极管开路**；输出为零且保险丝熔断，通常是**二极管短路**。

## 易错点提醒

1. **把桥式整流的输出写成 `0.45U_2`** → 桥式（全波）是 **`0.9U_2`**，半波才是 `0.45U_2`。
2. **把二极管的最大反向电压算成 `0.9U_2` 或 `U_2`** → 是**峰值** `√2U_2`，截止瞬间电容上的电压与电源峰值叠加时甚至可达 `2√2U_2`（选管要留余量）。
3. **认为桥式整流中每只二极管流过全部负载电流** → 每管只导通半个周期，`I_D(AV) = I_o/2`。
4. **电容滤波后仍用 `0.9U_2` 计算输出** → 电容滤波后输出升高到约 **`1.2U_2`**（桥式），工程估算常用此值。
5. **滤波电容耐压按输出电压选** → 应按**峰值** `√2U_2` 并留 1.5~2 倍余量选。
6. **忘记电容滤波的冲击电流** → 电容初始充电瞬间近似短路，冲击电流很大，二极管与变压器都要留足余量（或串小电阻限流）。
7. **稳压管电路中限流电阻取值不当** → `R` 太小 → `I_Z` 超过 `I_Zmax` 烧管；`R` 太大 → `I_Z` 小于 `I_Zmin` 无法稳压。必须按两种最坏情况计算范围。
8. **稳压管电路算 `R` 时忘记「两种最坏情况」** → 必须分别考虑「`U_I` 最大+`I_L` 最大」（决定 `R` 上限）与「`U_I` 最小+`I_L` 最小」（决定 `R` 下限）。
9. **认为串联型稳压电路效率高** → 调整管承受 `U_I − U_o` 的压降并流过全部负载电流，**效率只有 `U_o/U_I`**（一般 30%~50%），且压差越大效率越低。
10. **三端稳压器输入输出压差给得太小** → 必须保证 `U_I − U_o ≥ 2~3 V`，否则纹波抑制变差甚至无法稳压；同时压差太大会使功耗与发热剧增。
11. **78xx 与 79xx 的引脚排列搞混** → 78xx（正电压）与 79xx（负电压）**引脚定义不同**，必须查手册；79xx 的输出电容极性也要注意。
12. **认为开关电源没有缺点** → 开关电源效率高、体积小，但**纹波大、电磁干扰强、电路复杂、瞬态响应慢**，模拟小信号电路供电时反而可能不如线性电源。

## 本章小结

- 直流电源四环节：**变压器（降压隔离）→ 整流（AC 变脉动 DC）→ 滤波（减小纹波）→ 稳压（稳定输出）**。
- 单相半波：`U_o = 0.45U_2`；**单相桥式：`U_o = 0.9U_2`，`I_D(AV) = I_o/2`，`U_RM = √2U_2`**。
- 电容滤波：`U_o ≈ 1.2U_2`（桥式）；`C ≥ (3~5)T/(2R_L)`，耐压 `≥ √2U_2`；外特性软、冲击电流大。
- 倍压整流：`U_o = 2√2U_2`（二倍压），只适合小电流。
- 稳压管稳压电路：靠 `I_Z` 的自动变化让 `R` 上的压降补偿输入或负载的变化。
- **限流电阻范围**：`(U_Imin − U_Z)/(I_Zmax + I_Lmin) ≤ R ≤ (U_Imax − U_Z)/(I_Zmin + I_Lmax)`。
- 稳压管电路性能：`S_r ≈ r_Z/R`，`R_o ≈ r_Z`——`R` 越大、`r_Z` 越小越好。
- 串联型稳压电路四部分：**调整管 + 采样电路 + 基准电压 + 比较放大**；`U_o = U_Z(1 + R_1/R_下)`；效率低 `η ≈ U_o/U_I`。
- 三端稳压器：78xx 固定正、79xx 固定负、LM317/LM337 可调（`U_o = 1.25(1 + R_2/R_1)`）；压差 ≥ 2~3 V，功耗 `P = (U_I − U_o)I_o` 决定散热。
- 开关型稳压：`U_o = U_I·D`（串联/Buck 降压）、`U_o = U_I/(1 − D)`（并联/Boost 升压）；效率 70%~95%，但纹波与 EMI 大。

> **一句话记住本章**：**整流把交流「翻」成单向，滤波用电容把脉动「填平」，稳压用负反馈把波动「压住」；而线性稳压的高效率梦想，只有让调整管去当开关（开关电源）才能实现。**

12. 某串联型稳压电路 `U_I = 18 V`、`U_o = 12 V`、`I_L = 1.2 A`，求调整管管耗与电路效率。

**自测题答案**

1. 变压器（降压并隔离）、整流电路（交流变单向脉动直流）、滤波电路（减小纹波）、稳压电路（在电网与负载变化时保持输出稳定）。
2. 半波：`U_o = 0.45U_2`，`I_D = I_o`，`U_RM = √2U_2`；桥式：`U_o = 0.9U_2`，`I_D = I_o/2`，`U_RM = √2U_2`。
3. 因为电容在整流输出峰值附近被充电到接近 `√2U_2`，二极管截止后电容缓慢放电使电压维持在平均值之上，故平均值从 `0.9U_2` 升高到约 `1.2U_2`；适用条件是 `R_LC ≥ (3~5)T/2`（负载电流不太大）。
4. 容量 `C ≥ (3~5)T/(2R_L)`；耐压 `≥ √2U_2` 并留 1.5~2 倍余量。
5. `U_I` 升高 → `U_o` 略升 → `I_Z` 急剧增大 → `R` 上压降增大 → `U_o` 降回；`I_L` 增大 → `U_o` 略降 → `I_Z` 急剧减小 → 总电流基本不变 → `U_o` 升回。
6. ① `U_I` 最大且 `I_L` 最大时 `I_Z` 最小，要求 `I_Z ≥ I_Zmin`，得 `R ≤ (U_Imax − U_Z)/(I_Zmin + I_Lmax)`；② `U_I` 最小且 `I_L` 最小时 `I_Z` 最大，要求 `I_Z ≤ I_Zmax`，得 `R ≥ (U_Imin − U_Z)/(I_Zmax + I_Lmin)`。
7. 调整管、采样电路、基准电压、比较放大电路；`U_o = U_Z(1 + R_1/R_下)`，其中 `R_下` 为反馈点以下部分的等效电阻。
8. 7805 输出 +5 V，7912 输出 −12 V；输入输出压差应不小于 2~3 V。
9. `U_o = 1.25 × (1 + R_2/R_1)`；`R_1` 通常取 240 Ω。
10. 优点：效率高（70%~95%）、体积小、重量轻、可升压；缺点：输出纹波大、电磁干扰强、电路复杂、瞬态响应较慢。
11. `U_o ≈ 1.2U_2 = 1.2 × 15 = 18 V`；`U_RM = √2U_2 = 1.414 × 15 = 21.2 V`。
12. `U_CE = 18 − 12 = 6 V`，`P_T = 6 × 1.2 = 7.2 W`；`P_o = 12 × 1.2 = 14.4 W`，`η = 14.4/(18 × 1.2) = 14.4/21.6 = 66.7%`。
