## 3.1 多级放大电路的一般问题

### 3.1.1 多级放大电路的耦合方式

**耦合方式指「前一级的输出如何送到后一级的输入」；它决定了电路的频率下限和直流工作点的相互影响。**

| 耦合方式 | 连接元件 | 优点 | 缺点 | 适用场合 |
|---|---|---|---|---|
| 直接耦合 | 导线（无元件） | 低频响应好（可到直流）、便于集成 | **Q 点相互影响**、有零点漂移 | 集成电路（主流） |
| 阻容耦合 | 耦合电容 | Q 点彼此独立、简单 | 低频差（电容限制 f_L）、不能集成大电容 | 分立元件音频放大 |
| 变压器耦合 | 变压器 | 可实现阻抗匹配、Q 点独立 | 体积大、不能集成、低频差 | 老式功放、射频 |
| 光电耦合 | 发光管+光敏管 | **电气隔离**、抗干扰强 | 线性差、速度慢、需两套电源 | 隔离放大、开关电源反馈 |

> **直接耦合的两个新问题**：① 前一级的集电极电位直接加在后一级的基极上，后一级的 Q 点被前一级「绑架」；② 零点漂移。教材用的解决办法是：抬高后一级的发射极电位（加 R_e 或稳压管）或采用 NPN-PNP 互补搭配。

### 3.1.2 多级放大电路的动态分析

**多级放大电路的总增益等于各级增益的乘积，输入电阻等于第一级的输入电阻，输出电阻等于最后一级的输出电阻。**

`A_u = A_u1 · A_u2 · … · A_un`（分贝形式：`A(dB) = A_1(dB) + A_2(dB) + …`）
`R_i = R_i1`，`R_o = R_on`

**级间负载效应**：计算第 i 级的增益时，其负载电阻是**下一级的输入电阻**，即 `R_Li = R_i(i+1)`。

> **为什么输入/输出电阻只看头尾？** 因为输入电阻是从整个电路输入端看进去的，第一级决定了它；输出电阻是从整个电路输出端看进去的，最后一级决定了它。中间各级只影响增益。

## 3.2 集成运算放大电路概述

### 3.2.1 集成运放的电路结构特点

**集成运放（Operational Amplifier，运放）是把几十个晶体管和电阻做在同一块硅片上的高增益直接耦合放大电路。**

工艺限制带来的三个特点（第 1 章 1.5 节已铺垫）：

1. **不能做大电容、电感 → 只能直接耦合**，因此必须解决零点漂移。
2. **电阻阻值误差大（±20%）→ 电路性能只能依赖元件的匹配与比值**，所以大量使用差分结构和电流源。
3. **晶体管便宜、匹配性好 → 大量使用有源负载与复合结构**，以获得高增益。

### 3.2.2 集成运放电路的组成及其各部分的作用

```text
   u_N ──┐                    ┌──────────┐
         │  输入级（差分放大）  │ 中间级    │  输出级        u_o
   u_P ──┤  双端输入→单端输出  │(共射放大) │ (互补输出级)  ──→
         │  决定K_CMR、U_IO    │ 决定增益  │ 决定带载能力
         └────────┬───────────┴─────┬────┴──────┬────────┘
                  │   偏置电路（电流源）        │
                  └────────────────────────────┘
```

| 组成部分 | 作用 | 典型电路 | 决定的关键指标 |
|---|---|---|---|
| 输入级 | 双端输入、单端输出，抑制零漂 | 差分放大电路（恒流源式） | K_CMR、U_IO、r_id |
| 中间级 | 提供主要的电压增益 | 共射（共源）放大电路 + 有源负载 | A_od |
| 输出级 | 带负载能力强、输出电阻小 | 互补输出级（OCL） | 输出功率、r_o |
| 偏置电路 | 为各级提供稳定的静态电流 | 各种电流源 | 静态功耗、温度稳定性 |

### 3.2.3 集成运放的电压传输特性

**`u_o = f(u_P − u_N)` 分成两段：极窄的线性区和两侧的饱和区。**

```text
      u_o
   +U_OM ┤        ┌──────────── 饱和区
        │        │
        │       ╱ ← 斜率 = A_od（10^5 量级）
   ─────┼──────╱────────── u_P − u_N
        │    ╱ 线性区极窄（±0.1 mV 量级）
   −U_OM ┤   └──────────── 饱和区
        │
```

- **线性区**：`u_o = A_od(u_P − u_N)`，斜率就是开环差模增益 `A_od`（可达 10^5，即 100 dB）。因为 `A_od` 极大，线性区只有零点几毫伏宽——**这也是「虚短」得以成立的原因**（第 6 章）。
- **饱和区**：`u_o = ±U_OM`，由电源电压决定（一般比电源低 1~2 V）。运放作比较器时就工作在这里（第 7 章）。

## 3.3 集成运放中的单元电路

### 3.3.1 直接耦合放大电路的零点漂移现象

**零点漂移（zero drift）指输入信号为零时，输出电压偏离零值并缓慢变化的现象。**

```text
   u_i = 0                        u_o
        │                     ┌──╮   ╭──╮
   ─────┴───── t              │  │   │  │   ← 缓慢漂移（温度引起）
                              └──╯   ╯  ╰── t
```

**成因**：温度变化使 `U_BE`、`β`、`I_CBO` 变化（第 1 章），在直接耦合电路中这些变化被逐级放大。

**为什么第一级的漂移最致命？**

设第一级产生 `Δu_o1` 的漂移，则输出端的漂移为

`Δu_o = A_u2 · A_u3 · … · A_un · Δu_o1`

即**第一级的漂移被后面所有级放大**。若 `A_u2·A_u3 = 1000`，第一级漂移 1 mV 就会在输出端变成 1 V。**所以抑制零漂的主战场在输入级。**

**抑制措施**：① 采用**差分放大电路**（最有效，靠对称性抵消）；② 温度补偿；③ 恒温；④ 采用高稳定度电源；⑤ 引入直流负反馈。

### 3.3.2 差分放大电路

**差分放大电路（differential amplifier）用两只完全对称的管子放大「两输入之差」，而把「两输入共同的量」抑制掉。**

#### （1）长尾式差分放大电路的组成

```text
        +V_CC                +V_CC
          │                    │
         ┌┴┐ R_c1            ┌┴┐ R_c2
         └┬┘                  └┬┘
     u_i1─┤ C1              C2 ├─u_i2  （u_o 从两集电极之间取出=双端输出）
        ┌─┴─┐                ┌─┴─┐
   R_b ─┤T1 ├────┬───────┬───┤T2 ├─ R_b
        └─┬─┘    │       │   └─┬─┘
          E1     └───┬───┘     E2
                     │
                    ┌┴┐ R_e（长尾电阻）
                    └┬┘
                    −V_EE
```

**对称性**：两只管子型号相同、参数相同，`R_c1 = R_c2`，`R_b1 = R_b2`。这是差放能工作的前提。

#### （2）差模信号与共模信号

**任意两个输入信号都可以分解为一对差模信号和一对共模信号。**

`差模信号 u_id = u_i1 − u_i2`（两输入之差）
`共模信号 u_ic = (u_i1 + u_i2)/2`（两输入的公共部分）

于是 `u_i1 = u_ic + u_id/2`，`u_i2 = u_ic − u_id/2`。

| 输入情况 | u_id | u_ic | 举例 |
|---|---|---|---|
| 差模输入（双端） | `u_i1 − u_i2` | 0 | 传感器输出的差分小信号 |
| 共模输入 | 0 | `u_i1 = u_i2` | 两者同时受到的温度漂移、50 Hz 干扰 |
| 单端输入 | `u_i1` | `u_i1/2` | 只有一端加信号 |

> **差放的本质：把有用的信号做成「差」，把干扰做成「共」。** 传感器两根引线并排走线，受到的干扰几乎相同（共模），而有用信号是两根线之差（差模），于是放大差模、抑制共模即可把信号从干扰里「捞」出来。

#### （3）四种接法及其动态指标

**四种接法的连接方式**：双端输入（信号加在两基极之间）／单端输入（一端加信号、另一端接地）；双端输出（取自两集电极之差）／单端输出（取一只集电极对地）。

| 接法 | A_d | A_c | K_CMR | R_i | R_o |
|---|---|---|---|---|---|
| 双端输入双端输出 | `−βR_L'/(R_b+r_be)`，`R_L'=R_c∥(R_L/2)` | **0**（理想对称） | **∞** | `2(R_b+r_be)` | `2R_c` |
| 双端输入单端输出 | `±½·βR_L'/(R_b+r_be)`，`R_L'=R_c∥R_L` | `−βR_L'/[R_b+r_be+2(1+β)R_e]` | 大（有限） | `2(R_b+r_be)` | `R_c` |
| 单端输入双端输出 | 同双入双出 | 同双入双出 | ∞ | `2(R_b+r_be)` | `2R_c` |
| 单端输入单端输出 | 同双入单出 | 同双入单出 | 大 | `2(R_b+r_be)` | `R_c` |

**三个必须理解的关键结论：**

1. **双端输出时共模增益为零**（理想对称）。因为两管共模电流增量相同，两个集电极电位**同时同向变化**，而输出取两者之差，变化被抵消。这叫「**共模抵消**」。
2. **差模时 R_e 不起作用**（对双端输出）。因为差模输入下两管电流一增一减，尾电流不变，发射极节点是**交流虚地**，R_e 上没有交流电压。这就是「长尾」既能稳定 Q 点（直流）又不损失差模增益（交流）的原因。
3. **共模时 R_e 的作用被放大 2(1+β) 倍**。因为两管共模电流同时增大，尾电阻上的电流变化是单管的两倍，对每只管子来说等效为 `2R_e`，再折算到基极回路乘 (1+β)。**R_e 越大，共模抑制越强。**

**共模抑制比（Common-Mode Rejection Ratio）**：

`K_CMR = |A_d / A_c|`，用分贝表示为 `K_CMR(dB) = 20 lg|A_d/A_c|`

它是差分放大电路**最重要的指标**：越大表示「放大有用信号、抑制干扰」的能力越强。通用运放的 K_CMR 为 80~120 dB。

#### （4）恒流源式差分放大电路

**用电流源代替长尾电阻 R_e，可把共模抑制比提高两三个数量级。**

```text
        +V_CC                +V_CC
          │                    │
         ┌┴┐ R_c1            ┌┴┐ R_c2
         └┬┘                  └┬┘
     u_i1─┤T1 ────┬───────┬─── T2├─u_i2
                  └───┬───┘
                      │  ← 恒流源 I_0（交流等效电阻 r_o 极大）
                 ┌────┴────┐
                 │ 电流源电路 │
                 └────┬────┘
                    −V_EE
```

原理：共模时电流源在单管半边等效为 `2r_o`，单端共模增益 `A_c1 ≈ −R_L'/[2(1+β)r_o] ≈ −R_L'/(2r_o)`（**分母的 2 不能丢**，见本章例 3.5 的实算 `A_c1 = −2.48×10⁻³`），而电流源的交流输出电阻 `r_o` 可达几百 kΩ~几 MΩ（比 R_e 大 1~2 个数量级），所以 `A_c1` 极小、`K_CMR` 极大。同时直流上它提供稳定的偏置电流，使 Q 点几乎不受温度影响。

### 3.3.3 电流源电路

**电流源电路用「一只管子的电流去镜像/复制另一只管子的电流」，为各级提供稳定的偏置电流，同时充当极高的交流等效电阻。**

#### （1）镜像电流源

```text
        +V_CC
          │
         ┌┴┐ R（基准电阻）
         └┬┘
          ├──────┬──────┐
          │      │      │
       ┌──┴──┐ ┌─┴─┐    │
       │ T0  │ │T1 │    │  I_C1 = I_R/(1+2/β) ≈ I_R
       └──┬──┘ └─┬─┘    │
          └──────┘      │
       （T0 短接成二极管）│
```

T0 的 c、b 短接（二极管接法），`I_R = (V_CC − U_BE)/R`。由于两管 `U_BE` 相同且对称，`I_C1 ≈ I_R`。

**误差分析**：`I_R = I_C0 + 2I_B = I_C0(1 + 2/β)`，故

`I_C1 = I_R/(1 + 2/β) ≈ I_R`（β = 100 时误差约 2%）

| 优点 | 缺点 |
|---|---|
| 电路简单、只需一只电阻 | 输出电流与 I_R 同量级，做不出小电流 |
| 两管匹配好、温漂互相抵消 | 输出电阻只有 r_ce（几十 kΩ），不够大 |

#### （2）比例电流源

在两只管子的发射极各串一只电阻，利用 `U_BE0 + I_E0 R_e0 = U_BE1 + I_E1 R_e1`，当两管 `U_BE` 近似相等时：

`I_C1 ≈ I_R · R_e0/R_e1`

**只要改变两只电阻的比值，就能得到任意比例的电流**（既可放大也可缩小），且由于只用比值，电阻的绝对误差不影响精度——这正是集成电路最喜欢的做法。

#### （3）微电流源

**当需要 μA 级电流时，用「一个电阻上的微小压差」来获得。**

```text
        +V_CC
          │
         ┌┴┐ R
         └┬┘
          ├────────┬──────┐
       ┌──┴──┐   ┌─┴─┐    │
       │ T0  │   │T1 │    │
       └──┬──┘   └─┬─┘    │
          │        ┌┴┐ R_e1（几十 kΩ）
          └────────┴┴─────┘
```

T0 的发射结压降比 T1 高 `ΔU = I_C1 R_e1`，而 `ΔU = U_T ln(I_R/I_C1)`，所以

`I_C1 ≈ (U_T/R_e1) · ln(I_R/I_C1)`

这是一个**超越方程**，通常用试算法或图解法求 `I_C1`。典型值：`I_R = 1 mA`、`R_e1 = 10 kΩ` 时 `I_C1 ≈ 11.6 μA`。

#### （4）威尔逊电流源

**在镜像电流源中加一只管子构成电流负反馈，同时提高精度与输出电阻。**

`I_C2 ≈ I_R/(1 + 2/(β² + 2β))`

| 类型 | 输出电流 | 相对误差（β = 100） | 输出电阻 | 特点 |
|---|---|---|---|---|
| 镜像电流源 | ≈ I_R | 2% | 中（r_ce） | 最简单 |
| 比例电流源 | `I_R·R_e0/R_e1` | 由电阻比决定 | 中 | 灵活 |
| 微电流源 | μA 级 | 由对数关系决定 | 较高 | 小电流 |
| 威尔逊电流源 | ≈ I_R | **0.02%** | **高** | 精度最高 |

> **电流源的「双重身份」**：直流上是「稳定偏置源」，交流上是「大电阻」（甚至可视为开路）。这就是为什么集成运放内部到处是电流源——**它既省面积，又能大幅提高增益**（增益与负载电阻成正比）。

### 3.3.4 直接耦合互补输出级

**输出级要求「输出电阻小、带载能力强、效率高」，所以采用 NPN 与 PNP 互补的射极跟随器。**

基本结构（OCL 电路）在**第 8 章功率放大电路**详细讨论，此处只记住三点：

1. 两只不同类型的管子轮流导通（正半周 NPN 导通、负半周 PNP 导通），称为**互补**。
2. 管子工作在乙类或甲乙类状态，效率高（理论最高 78.5%）。
3. 存在**交越失真**，需要给两只管子加一个小的正向偏置（用二极管或 U_BE 倍增电路）。

## 3.4 集成运放电路简介

| 类型 | 输入级器件 | 代表型号 | 特点 |
|---|---|---|---|
| 双极型 | BJT 差分放大 | F007（μA741）、LM324 | 增益高、噪声低、输入电阻中等（MΩ） |
| 单极型 | JFET 或 CMOS 差分放大 | LF347、ICL7650、CA3140 | **输入电阻极高**（10^12 Ω）、输入偏置电流极小（pA） |
| 混合型 | BJT + JFET | 多种 | 兼顾高输入阻抗与高增益 |

**读集成运放内部电路的通用方法**：① 先找偏置电路（各电流源）；② 再找输入级（差分对）；③ 中间级（共射 + 有源负载）；④ 输出级（互补射随器）。

## 3.5 集成运放的性能指标及低频等效电路

### 3.5.1 集成运放的主要性能指标

| 指标 | 名称 | 典型值 | 意义 |
|---|---|---|---|
| A_od | 开环差模电压增益 | 10^5（100 dB） | 越大，闭环精度越高 |
| r_id | 差模输入电阻 | 10^6 Ω（双极型）/10^12 Ω（FET 型） | 越大，对信号源索取电流越小 |
| r_o | 输出电阻 | 几十~几百 Ω | 越小，带载能力越强 |
| K_CMR | 共模抑制比 | 80~120 dB | 越大，抗共模干扰越强 |
| U_IO | 输入失调电压 | 1~10 mV | 输出为零时需要在输入端补加的电压 |
| I_IO | 输入失调电流 | 1~100 nA | 两输入偏置电流之差 |
| SR | 转换速率 | 0.5~100 V/μs | 输出能跟上输入变化的最大速度 |
| f_H | 上限截止频率 | 几 Hz~几十 MHz | 开环带宽极窄（因 A_od 大） |

> **`U_IO` 与 `I_IO` 是「不理想」的根源**：理想运放应当输入为零时输出为零，实际需要补一点电压/电流才为零。它们随温度变化，是直流精度的主要限制。

### 3.5.2 集成运放的低频等效电路

**低频（中频）等效电路：输入端是一个电阻 `r_id`，输出端是一个受控电压源 `A_od u_id` 串一个电阻 `r_o`。**

```text
   u_N ──┐         ┌───────────────┐
         │  r_id   │               │  r_o
   u_P ──┤←──────→│  A_od·(u_P−u_N)├──┬── u_o
         │         │               │  │
         └─────────┴───────────────┴──┴── 地
```

**理想运放的五个条件**（第 6 章全部运算电路的推导基础）：

| 条件 | 理想值 | 实际值 |
|---|---|---|
| 开环增益 A_od | ∞ | 10^5 |
| 差模输入电阻 r_id | ∞ | 10^6 Ω |
| 输出电阻 r_o | 0 | 几十 Ω |
| 共模抑制比 K_CMR | ∞ | 80~120 dB |
| 带宽 | ∞ | 有限 |

由「A_od = ∞」与「u_o 有限」推出 `u_P − u_N = u_o/A_od → 0`，即**虚短**；由「r_id = ∞」推出两输入端电流为零，即**虚断**。这两条是第 6 章所有运算电路的钥匙。

## 3.6 集成运放的种类及选择

| 类型 | 特点 | 典型型号 | 选用场合 |
|---|---|---|---|
| 通用型 | 指标均衡、便宜 | LM741、LM324、F007 | 一般放大与运算 |
| 高阻型 | 输入电阻极高、偏置电流极小 | LF347、CA3140 | 高内阻信号源、积分器 |
| 高速型 | SR 大、带宽宽 | LM318、AD811 | 视频、脉冲放大 |
| 低功耗型 | 静态电流 μA 级 | LM358（低压版）、ICL7641 | 电池供电、便携设备 |
| 高压型 | 供电可达 ±(40~150) V | LM143 | 高压输出 |
| 大功率型 | 输出电流可达安培级 | LM12、OPA548 | 驱动电机、扬声器 |
| 精密型 | U_IO 低至 μV 级、温漂极小 | OP07、ICL7650（斩波稳零） | 传感器微弱信号、仪器 |

**选择原则**：先看**信号源内阻**（决定 r_id 与 I_B 的要求）→ 再看**信号频率**（决定 SR 与带宽）→ 再看**精度要求**（决定 U_IO、K_CMR）→ 最后看**电源与功耗**。**不要盲目追求高指标，指标越高价格越贵。**

## 3.7 集成运放的使用

### 3.7.1 使用时必做的工作

1. **调零**：对有调零端的运放，在输入接地时调节调零电位器，使输出为零。无调零端的可用外部补偿电路。
2. **消振**：运放内部有多级放大，容易自激。需按手册接补偿电容（第 5 章 5.6 节）。
3. **检查电源与地**：双电源供电要保证正负对称，退耦电容要紧靠芯片。

### 3.7.2 保护措施

| 保护类型 | 电路 | 作用 |
|---|---|---|
| 电源极性保护 | 电源线上串二极管 | 防止电源接反烧毁芯片 |
| 输入保护 | 两输入端之间反并联两只二极管 | 防止差模电压过大击穿输入级 |
| 输出保护 | 输出端串限流电阻、接稳压管 | 防止输出短路或过压 |

## 典型例题

**例 3.1**（题型：多级放大电路的计算）
三级放大电路，各级电压增益为 `A_u1 = −20`、`A_u2 = −15`、`A_u3 = 0.98`，`R_i1 = 1 kΩ`，`R_o3 = 50 Ω`。求总增益（倍数与分贝）及总输入、输出电阻。

**解**：
`A_u = (−20) × (−15) × 0.98 = 294`
分贝：`A_1 = 20 lg20 = 26.0 dB`，`A_2 = 20 lg15 = 23.5 dB`，`A_3 = 20 lg0.98 = −0.18 dB`
`A(dB) = 26.0 + 23.5 − 0.18 = 49.3 dB`
校验：`20 lg294 = 20 × 2.468 = 49.4 dB` ✓
`R_i = R_i1 = 1 kΩ`，`R_o = R_o3 = 50 Ω`

**答案**：总增益 294 倍（49.3 dB），`R_i = 1 kΩ`，`R_o = 50 Ω`。注意两级反相放大级联后**总相位同相**。

**例 3.2**（题型：零点漂移的放大）
某三级直接耦合放大电路，各级增益为 `A_u1 = 20`、`A_u2 = 50`、`A_u3 = 1`。若第一级因温度升高产生 0.5 mV 的输出漂移，求输出端漂移；若第二级也产生 0.5 mV 漂移，输出端为多少？

**解**：
第一级漂移被后两级放大：`Δu_o = 0.5 mV × 50 × 1 = 25 mV`
第二级漂移只被第三级放大：`Δu_o = 0.5 mV × 1 = 0.5 mV`

**答案**：第一级漂移引起 25 mV，第二级只引起 0.5 mV。**比值 50 倍——这就是「抑制零漂的主战场在输入级」的定量依据。**

**例 3.3**（题型：长尾式差分放大电路——双端输入双端输出）
差分放大电路 `V_CC = V_EE = 12 V`，`R_c1 = R_c2 = 10 kΩ`，`R_b1 = R_b2 = 0`（基极直接接地），`R_e = 11 kΩ`，`β = 100`，`r_bb' = 200 Ω`，负载接在两集电极之间 `R_L = 10 kΩ`。求 Q 点、`A_d`、`A_c`、`K_CMR`。

**解**：
**第一步：Q 点（设两管完全对称，静态时 u_i1 = u_i2 = 0）**
基极电位 `U_BQ = 0`，故 `U_EQ = U_BQ − U_BEQ = −0.7 V`
尾电阻上的电流 `I_Re = [U_EQ − (−V_EE)]/R_e = (−0.7 + 12)/11 kΩ = 11.3/11 = 1.027 mA`
每管 `I_CQ = I_Re/2 = 0.514 mA`
`U_CQ = V_CC − I_CQ R_c = 12 − 0.514 mA × 10 kΩ = 12 − 5.14 = 6.86 V`
`U_CEQ = U_CQ − U_EQ = 6.86 − (−0.7) = 7.56 V` ✓ 放大区

**第二步：r_be**
`r_be = 200 + 101 × 26 mV/0.514 mA = 200 + 101 × 50.6 = 200 + 5111 = 5311 Ω ≈ 5.31 kΩ`

**第三步：差模增益（双端输出）**
交流通路中发射极节点为虚地，`R_e` 不起作用。
`R_L' = R_c ∥ (R_L/2) = 10 kΩ ∥ 5 kΩ = (10×5)/15 = 3.33 kΩ`
`A_d = −βR_L'/(R_b + r_be) = −100 × 3333/5311 = −62.8`

**第四步：共模增益与 K_CMR**
理想对称时 `A_c = 0`，故 `K_CMR = ∞`。

**答案**：`I_CQ = 0.514 mA`，`U_CEQ = 7.56 V`，`r_be = 5.31 kΩ`，`A_d = −62.8`，`A_c = 0`，`K_CMR = ∞`。

**例 3.4**（题型：长尾式差分放大电路——单端输出与 K_CMR）
条件同例 3.3，但输出改为**从 T1 的集电极对地取出**，接负载 `R_L = 10 kΩ`。求 `A_d1`、`A_c1`、`K_CMR`。

**解**：
**差模增益（单端输出，只有一半）**
`R_L' = R_c ∥ R_L = 10 kΩ ∥ 10 kΩ = 5 kΩ`
`A_d1 = −½ · βR_L'/(R_b + r_be) = −0.5 × 100 × 5000/5311 = −47.1`

**共模增益**
`A_c1 = −βR_L'/[R_b + r_be + 2(1+β)R_e]`
分母 `= 5311 + 2 × 101 × 11 000 = 5311 + 2 222 000 = 2 227 311 Ω`
`A_c1 = −100 × 5000/2 227 311 = −500 000/2 227 311 = −0.2245`
（用近似式校验：`A_c1 ≈ −R_L'/(2R_e) = −5000/22 000 = −0.227` ✓）

**共模抑制比**
`K_CMR = |A_d1/A_c1| = 47.1/0.2245 = 210`
`K_CMR(dB) = 20 lg 210 = 20 × 2.322 = 46.4 dB`

**答案**：`A_d1 = −47.1`，`A_c1 = −0.2245`，`K_CMR = 210`（46.4 dB）。
**对比例 3.3：单端输出损失一半差模增益，却引入了不可忽略的共模增益——这是「双端输出优于单端输出」的定量依据。**

**例 3.5**（题型：恒流源尾的 K_CMR 提升）
若把例 3.4 中的 `R_e = 11 kΩ` 换成恒流源（输出电流 1.027 mA，交流等效电阻 `r_o = 1 MΩ`），其他条件不变，求 `A_c1` 与 `K_CMR`。

**解**：
共模时电流源的等效电阻为 `2r_o`（两管共模电流叠加）：
`A_c1 = −βR_L'/[R_b + r_be + 2(1+β)r_o]`
分母 `= 5311 + 2 × 101 × 1 000 000 = 5311 + 202 000 000 ≈ 2.02 × 10^8 Ω`
`A_c1 = −100 × 5000/(2.02×10^8) = −2.48 × 10^-3`
`K_CMR = 47.1/(2.48×10^-3) = 19 000`
`K_CMR(dB) = 20 lg 19 000 = 85.6 dB`

**答案**：`A_c1 = −2.48×10^-3`，`K_CMR ≈ 1.9×10^4`（85.6 dB）。
**与例 3.4 的 46.4 dB 相比提高了近 40 dB（100 倍）——这就是「集成运放一律用恒流源做尾」的原因。**

**例 3.6**（题型：镜像电流源）
`V_CC = 12 V`，基准电阻 `R = 10 kΩ`，`β = 100`，`U_BE = 0.7 V`。求基准电流 `I_R` 与输出电流 `I_C1`，并计算相对误差。

**解**：
`I_R = (V_CC − U_BE)/R = (12 − 0.7)/10 kΩ = 11.3/10 = 1.13 mA`
`I_C1 = I_R/(1 + 2/β) = 1.13/(1 + 0.02) = 1.13/1.02 = 1.108 mA`
相对误差 `= (1.13 − 1.108)/1.108 = 2.0%`

**答案**：`I_R = 1.13 mA`，`I_C1 = 1.108 mA`，误差 2%。

**例 3.7**（题型：比例电流源）
在上题基础上，`R_e0 = 1 kΩ`（T0 发射极）、`R_e1 = 5 kΩ`（T1 发射极）。求 `I_C1`。

**解**：
`I_C1 ≈ I_R · R_e0/R_e1 = 1.13 mA × 1/5 = 0.226 mA`

**答案**：`I_C1 = 0.226 mA`。**只靠电阻比值就把电流缩小到 1/5，且精度由比值决定，与电阻绝对值无关。**

**例 3.8**（题型：微电流源）
`I_R = 1 mA`，`R_e1 = 10 kΩ`，`U_T = 26 mV`。求 `I_C1`（用试算法）。

**解**：
方程 `I_C1 = (U_T/R_e1)·ln(I_R/I_C1) = (26 mV/10 kΩ)·ln(1 mA/I_C1) = 2.6 μA × ln(1 mA/I_C1)`
第一次试算：设 `I_C1 = 20 μA`，则 `ln(1000/20) = ln50 = 3.91`，右边 `= 2.6 × 3.91 = 10.2 μA < 20 μA`（偏大）
第二次试算：设 `I_C1 = 10 μA`，则 `ln100 = 4.61`，右边 `= 2.6 × 4.61 = 12.0 μA > 10 μA`（偏小）
第三次试算：设 `I_C1 = 11.6 μA`，则 `ln(1000/11.6) = ln86.2 = 4.46`，右边 `= 2.6 × 4.46 = 11.6 μA` ✓ 收敛

**答案**：`I_C1 ≈ 11.6 μA`。**注意：该电流对 R_e1 与温度都很敏感（对数关系），实际使用时需注意温漂。**

**例 3.9**（题型：威尔逊电流源精度对比）
`I_R = 1 mA`，`β = 100`。比较镜像电流源与威尔逊电流源的输出电流误差。

**解**：
镜像：`I_C1 = I_R/(1 + 2/β) = 1/(1 + 0.02) = 0.980 mA`，误差 2%
威尔逊：`I_C2 = I_R/[1 + 2/(β² + 2β)] = 1/[1 + 2/(10 000 + 200)] = 1/(1 + 1.96×10^-4) = 0.9998 mA`，误差 0.02%

**答案**：镜像 0.980 mA（误差 2%），威尔逊 0.9998 mA（误差 0.02%）。**精度提高 100 倍。**

**例 3.10**（题型：转换速率与输出幅度）
某运放 `SR = 0.5 V/μs`，输出正弦波幅度 `U_om = 10 V`。求不失真输出的最高频率。

**解**：
正弦波在过零点处变化最快，最大斜率为 `2πf·U_om`。要不失真必须满足
`2πf·U_om ≤ SR`
`f ≤ SR/(2πU_om) = 0.5×10^6 V/s / (2π × 10 V) = 500 000/62.8 = 7958 Hz`

**答案**：最高约 7.96 kHz。**这就是为什么通用运放（SR 小）不能放大幅度较大的高频信号——幅度越大，允许的频率越低。**

## 易错点提醒

1. **把直接耦合的优点说成「Q 点独立」** → 直接耦合的优点是低频好、易集成，缺点是 **Q 点互相影响 + 零点漂移**；Q 点独立是阻容耦合的优点。
2. **认为零点漂移只由最后一级决定** → 恰恰相反，**第一级的漂移被后面各级放大**，最致命。
3. **把共模信号算成两输入之和** → `u_ic = (u_i1 + u_i2)/2`，不要漏掉 1/2。
4. **差模增益公式中把 R_L' 写成 R_c** → 双端输出时 `R_L' = R_c∥(R_L/2)`（负载中点相当于交流地），单端输出时 `R_L' = R_c∥R_L`。
5. **认为 R_e 会降低差模增益** → 对**双端输出**的差模信号，发射极是虚地，`R_e` 完全不起作用；它只抑制共模。
6. **共模增益分母漏掉 (1+β)** → 正确为 `R_b + r_be + 2(1+β)R_e`，漏掉 (1+β) 会把 `A_c` 算大近百倍。
7. **把 K_CMR 的单位写成倍数却不说明** → K_CMR 本身是比值（可写 210 或 1.9×10^4），用 dB 时必须写 `20 lg`。
8. **认为镜像电流源的输出电流精确等于 I_R** → 有 `2/β` 的误差（β = 100 时 2%），且 β 随温度变化。
9. **把电流源只看成「直流偏置」** → 它在交流上是**大电阻**，是集成运放获得高增益的关键（有源负载）。
10. **用理想运放条件去分析运放内部电路** → 「虚短虚断」只在**闭环负反馈**且工作在线性区时成立，分析内部电路时必须用真实的 A_od、r_id。

## 本章小结

- 四种耦合方式：直接（低频好、可集成、有零漂）、阻容（Q 点独立、低频差）、变压器（阻抗匹配、笨重）、光电（隔离、线性差）。
- 多级：`A_u = ∏A_ui`，`R_i = R_i1`，`R_o = R_on`；算每级增益时负载是下一级的输入电阻。
- 零点漂移由温度引起，**第一级的漂移被放大最多**，故抑制零漂的关键在输入级。
- 差分放大电路：`u_id = u_i1 − u_i2`，`u_ic = (u_i1+u_i2)/2`；双端输出 `A_c = 0`、`K_CMR = ∞`；单端输出 `A_d` 减半、`A_c ≈ −R_L'/(2R_e)`。
- `K_CMR = |A_d/A_c|`；用恒流源代替 R_e 可使 `K_CMR` 提高 1~2 个数量级（因为 `r_o` 远大于 R_e）。
- 电流源四兄弟：镜像（最简单）、比例（比值定电流）、微电流（μA 级）、威尔逊（精度最高、输出电阻最大）。
- 集成运放四部分：输入级（差分，决定 K_CMR）、中间级（共射，决定增益）、输出级（互补，决定带载）、偏置电路（电流源）。
- 主要指标：`A_od`（10^5）、`r_id`、`r_o`、`K_CMR`、`U_IO`、`I_IO`、`SR`。
- 理想运放五条件推出**虚短**（`u_P = u_N`）与**虚断**（`i_P = i_N = 0`）。

> **一句话记住本章**：**集成运放就是「差分输入 + 电流源偏置 + 共射放大 + 互补输出」四块积木搭起来的高增益放大器；差分是为了抗漂移，电流源是为了又省地方又高增益。**

**自测题答案**

2. 因为第一级的漂移会被后面各级逐级放大，而后面各级的漂移只被其后级放大。
3. `u_id = u_i1 − u_i2 = 4 mV`；`u_ic = (u_i1+u_i2)/2 = 8 mV`。
4. 差模时发射极节点为交流虚地，R_e/恒流源不参与；共模时等效为 `2R_e`（或 `2r_o`）折算到基极乘 (1+β)，强烈抑制共模。
5. 差模增益相差 2 倍（单端只有一半）；共模抑制能力差得多（双端理想为 ∞，单端有限，K_CMR 通常只有几十 dB）。
6. `K_CMR = |A_d/A_c|`，`K_CMR(dB) = 20 lg|A_d/A_c|`；80 dB 对应 10^4 倍。
7. `I_R = (15 − 0.7)/12 kΩ = 1.192 mA`；`I_C1 = 1.192/(1 + 2/80) = 1.192/1.025 = 1.163 mA`。
8. 因为两只管子的 U_BE 近似相等而互相抵消，电流比只由 `R_e0/R_e1` 决定，与电阻绝对值无关。
9. 输入级（差分放大，决定 K_CMR 与零漂）、中间级（共射放大，提供主要增益）、输出级（互补输出，带载能力强）、偏置电路（电流源，提供稳定静态电流）。
10. `A_od = ∞`、`r_id = ∞`、`r_o = 0`、`K_CMR = ∞`、带宽 = ∞；由 `A_od = ∞` 与输出有限推出虚短，由 `r_id = ∞` 推出虚断。
