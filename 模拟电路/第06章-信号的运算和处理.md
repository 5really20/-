## 6.1 基本运算电路

### 6.1.1 概述

**运放作运算使用时必须工作在线性区，且必须引入负反馈；此时「虚短 + 虚断」成立，一切运算电路的输出表达式都可以用节点电流法推出。**

**两个前提**：

1. **引入负反馈**——保证运放工作在线性区，`u_o = A_od(u_P − u_N)` 中的 `u_o` 不超出电源电压范围。
2. **输出不超出线性范围**——即 `|u_o| ≤ U_OM`（一般比电源电压低 1~2 V）。

**两个法宝**：

| 名称 | 表达式 | 来源 |
|---|---|---|
| 虚短 | `u_P = u_N` | `A_od = ∞` 而 `u_o` 有限，故 `u_P − u_N = u_o/A_od = 0` |
| 虚断 | `i_P = i_N = 0` | `R_id = ∞` |

**分析三步法**（本章所有电路通用）：

1. 写出同相端电位 `u_P`（若同相端接地则 `u_P = 0`，称为**虚地**）；
2. 由虚短得 `u_N = u_P`；
3. 对反相端节点列 **KCL**（虚断：流入运放输入端的电流为 0），解出 `u_o` 与输入的关系。

> **「虚地（virtual ground）」是反相输入电路特有的**：同相端接地时 `u_N = 0`，反相端电位被强制为 0，但它并不是真正的地（不能接负载）。

### 6.1.2 比例运算电路

#### （1）反相比例运算电路

**`A_uf = u_o/u_i = −R_f/R_1`，输入电阻 `R_i = R_1`，输出与输入反相。**

```text
             R_f
        ┌────/\/\/────┐
        │             │
  R_1   │   ┌───┐     │
u_i ─/\/\/─┼───┤−    │
           │   │  >──┴── u_o
      ┌────┴───┤+        u_o = −(R_f/R_1)·u_i
      │        └───┘
     R_2 = R_1∥R_f （平衡电阻）
```

推导：`u_P = 0` → `u_N = 0`（虚地）；`i_1 = u_i/R_1`，虚断使该电流全部流过 `R_f`：
`u_o = u_N − i_1 R_f = −(R_f/R_1) u_i`

**平衡电阻 `R_2 = R_1 ∥ R_f` 的作用**：使两个输入端对地的直流电阻相等，抵消输入偏置电流 `I_B` 引起的附加输出误差。

#### （2）同相比例运算电路

**`A_uf = 1 + R_f/R_1`，输入电阻极高（`R_i → ∞`），输出与输入同相。**

推导：`u_N = u_P = u_i`（虚短）；`R_1` 与 `R_f` 中流过同一电流 `i = u_i/R_1`：
`u_o = u_i + i R_f = u_i(1 + R_f/R_1)`

**特例：电压跟随器**。当 `R_1 = ∞`（断开）、`R_f = 0`（短接）时，`A_uf = 1`，即 `u_o = u_i`。它有极高的输入电阻和极低的输出电阻，常用于**阻抗变换与缓冲隔离**。

| 电路 | A_uf | R_i | 相位 | 共模输入 |
|---|---|---|---|---|
| 反相比例 | `−R_f/R_1` | `R_1`（小） | 反相 | `u_ic = 0`（虚地，无共模误差） |
| 同相比例 | `1 + R_f/R_1` | 极大 | 同相 | `u_ic = u_i`（**有共模误差**） |
| 电压跟随器 | 1 | 极大 | 同相 | `u_ic = u_i` |

> **选型提示**：要求高输入电阻 → 同相；要求无共模误差、增益可小于 1 → 反相；只做隔离缓冲 → 跟随器。

#### （3）T 型网络反相比例运算电路

**用 T 型网络可以用不大的电阻实现很高的增益，避免使用 MΩ 级的反馈电阻。**

```text
             R_2      X     R_3
        ┌───/\/\/──┬──/\/\/───┐
        │          │          │
  R_1   │   ┌───┐  R_4        │
u_i ─/\/\/─┼───┤−  │          │
           │   │ >─┴──────────┴── u_o
      ┌────┴───┤+      （R_4 接在 X 点与地之间）
      │        └───┘
```

**`A_uf = −(R_2 + R_3 + R_2R_3/R_4)/R_1`**

推导要点：`u_N = 0`，`i = u_i/R_1` 全部流过 `R_2`，故 `u_X = −i R_2`；对 X 点列 KCL（流向 R_4 与 R_3 的电流之和等于 i），整理即得。

**代价**：`R_2R_3/R_4` 这一项对电阻精度敏感，且噪声增益较大；高精度场合仍宜用大阻值反馈电阻或仪表放大器。

### 6.1.3 加减运算电路

#### （1）反相求和运算电路

**`u_o = −R_f(u_i1/R_1 + u_i2/R_2 + u_i3/R_3)`——各路输入互不影响（虚地使各路之间隔离）。**

推导：`u_N = 0`（虚地），各支路电流 `i_k = u_ik/R_k` 在 N 点相加后全部流过 `R_f`。

**平衡电阻**：`R_4 = R_1 ∥ R_2 ∥ R_3 ∥ R_f`。

**优点**：调节某一路的 `R_k` 不影响其它路的比例，**各路共地、无共模电压**。

#### （2）同相求和运算电路

**`u_o = (1 + R_f/R_1)·(R')·(u_i1/R_2 + u_i2/R_3 + u_i3/R_4)`，其中 `R' = R_2 ∥ R_3 ∥ R_4`。**

推导：先求同相端电位 `u_P = R'(u_i1/R_2 + u_i2/R_3 + u_i3/R_4)`（由节点 KCL，各输入支路与 `R'` 分压），再由同相比例公式放大。

**缺点**：各路之间有相互影响（改变 `R_2` 会影响 `u_P`），且存在共模输入。

#### （3）加减运算电路

**同时有反相与同相输入时，可用叠加定理分别求出反相部分与同相部分的贡献再相加。**

```text
        R_f
   ┌───/\/\/───┐
   │           │
  R_1  ┌───┐   │
u_i1 ─/\/─┤−   │
          │ >──┴── u_o
u_i2 ─/\/─┤+   ┌── R_3 ── 地
  R_2     └───┘
```

当 `R_1 = R_2`、`R_3 = R_f` 时：

**`u_o = (R_f/R_1)(u_i2 − u_i1)`**

这正是**差分放大器（求差电路）**的标准形式，也是仪表放大器的基本单元。

### 6.1.4 积分运算电路和微分运算电路

#### （1）积分运算电路

**用电容代替反馈电阻即得积分电路：`u_o = −(1/RC)∫u_i dt + u_o(0)`。**

推导：`i = u_i/R` 全部流入电容，`u_C = (1/C)∫i dt`，而 `u_o = −u_C`（虚地使电容左端为 0，右端为 `u_o`）。

| 输入波形 | 输出波形 | 表达式（初始值为 0） |
|---|---|---|
| 阶跃 `U_i` | 斜坡 | `u_o = −(U_i/RC)·t` |
| 方波 | **三角波** | 半周期内线性上升或下降 |
| 正弦 | 余弦（相位超前 90°） | `u_o = −(1/(ωRC))U_im cos ωt` |

**积分电路的用途**：波形变换（方波→三角波）、模拟计算（解微分方程）、**在反馈环中作低通滤波**（如 PID 调节器）。

**实用注意事项**：实际积分电路要在电容两端并一个大电阻 `R_f`（防止低频增益过大、抑制失调漂移积累），但这样它就变成了「有源低通 + 积分」的折中；同时要定期用开关放电（复位）。

#### （2）微分运算电路

**用电容代替输入电阻即得微分电路：`u_o = −RC·(du_i/dt)`。**

| 输入波形 | 输出波形 |
|---|---|
| 阶跃 | 尖脉冲 |
| 三角波 | **方波** |
| 正弦 | 余弦（相位滞后 90°） |

**缺点**：微分电路对高频噪声的增益极大（`|A| = ωRC` 随频率上升），极易被噪声淹没甚至自激。**实用中要在输入电容支路串一个小电阻 `R_1`**（限制高频增益），或改用「微分 + 低通」的组合。

> **口诀**：**「积分用 R 进 C 反馈，微分用 C 进 R 反馈」**；积分是低通性质，微分是高通性质。

### 6.1.5 对数运算电路和指数运算电路

**利用 PN 结的指数特性 `i_D = I_S(e^(u_D/U_T) − 1) ≈ I_S e^(u_D/U_T)`，把乘法关系变成加减关系。**

#### （1）对数运算电路

把三极管（或二极管）接在反馈支路中：

**`u_o = −U_T ln(u_i/(I_S R))`**

推导：`i_C = u_i/R`（虚地使电流由 `u_i` 与 `R` 决定），而 `u_BE = U_T ln(i_C/I_S)`，`u_o = −u_BE`。

**要求**：`u_i > 0`（保证三极管导通且工作在放大区）；温度变化会通过 `U_T` 和 `I_S` 影响输出，需加温度补偿。

#### （2）指数运算电路

把三极管接在输入支路中（`u_i` 加在 `u_BE` 上）：

**`u_o = −I_S R·e^(u_i/U_T)`**

推导：`i_C = I_S e^(u_i/U_T)`，该电流全部流过 `R_f`，故 `u_o = −i_C R`。

#### （3）乘法与除法运算电路

**利用「对数 → 相加 → 反对数」实现乘法，利用「对数 → 相减 → 反对数」实现除法。**

| 运算 | 实现思路 | 输出表达式 |
|---|---|---|
| 乘法 | `ln u_x + ln u_y = ln(u_x u_y)` | `u_o = k u_x u_y` |
| 除法 | `ln u_x − ln u_y = ln(u_x/u_y)` | `u_o = (1/k)·(u_x/u_y)` |
| 平方 | 乘法器两输入接同一信号 | `u_o = k u_x²` |
| 开方 | 乘法器接在反馈支路中 | `u_o = √(−u_i/k)` |

### 6.1.6 利用对数和指数运算电路实现的乘法运算电路和除法运算电路

对数式乘除法电路的**优点**是原理直观，**缺点**是精度受 `I_S`、`U_T` 的温度漂移影响大、动态范围有限（一般只有 2~3 个数量级）。**实际工程中普遍使用 6.2 节的模拟乘法器**，它精度更高、温度稳定性更好、输入可为双极性。

### 6.1.7 集成运放性能指标对运算误差的影响

**理想运放不存在，实际运放的 `A_od`、`R_id`、`U_IO`、`I_IO`、`K_CMR`、带宽都是有限值，它们分别带来不同的运算误差。**

| 非理想参数 | 引起的误差 | 误差量级 |
|---|---|---|
| `A_od` 有限 | 增益误差（闭环增益略小于理想值） | 相对误差 ≈ `(1 + R_f/R_1)/A_od` |
| `R_id` 有限 | 输入电流不为 0，增益与输入电阻误差 | 同相电路 `R_i ≈ R_id(1+AF)` |
| `U_IO`（失调电压） | 输出直流偏移 | `Δu_o = (1 + R_f/R_1)U_IO` |
| `I_IO`（失调电流） | 输出直流偏移 | `Δu_o = I_IO R_f`（平衡电阻可抵消 `I_B` 的影响） |
| `K_CMR` 有限 | 共模输入引起的误差 | 仅同相输入电路有此项 |
| 带宽有限 | 高频时增益下降、相位滞后 | 由 GBW 决定 |

**减小误差的常用措施**：① 选低失调、高 `A_od` 的运放（如斩波稳零运放）；② 加调零电路；③ 两输入端外接**平衡电阻**；④ 用同相端接地的方式避免共模误差（反相电路）；⑤ 多级放大时把高增益放在前级（失调折算到输入端更小）。

## 6.2 模拟乘法器及其在运算电路中的应用

### 6.2.1 模拟乘法器简介

**模拟乘法器（analog multiplier）是实现两个模拟量相乘的集成器件，输出 `u_o = k u_x u_y`，其中 `k` 为乘积系数（单位 1/V）。**

| 类型 | 特点 |
|---|---|
| 变跨导型（吉尔伯特单元） | 最常用，由差分放大电路 + 恒流源构成，双极性输入 |
| 对数-反对数型 | 动态范围大但带宽窄，已少用 |
| 四象限乘法器 | `u_x`、`u_y` 均可正可负（最通用） |
| 单象限/二象限 | 输入有极性限制，电路简单 |

**主要参数**：乘积系数 `k`、线性度、输入失调、带宽、温度漂移。

### 6.2.2 变跨导型模拟乘法器的工作原理

**核心思想：差分放大电路的差模增益 `A_d = −g_m R_c`，而 `g_m` 与恒流源电流 `I_0` 成正比；用一个输入电压去控制 `I_0`（即控制 `g_m`），另一个输入电压作为差模输入，则输出电压正比于两个输入之积。**

`I_0 = (u_y − U_BE)/R_y ≈ u_y/R_y` → `g_m ∝ u_y` → `u_o = A_d u_x ∝ u_x u_y`

**这就是「变跨导」的含义**：跨导 `g_m` 被一个输入量调制。

### 6.2.3 模拟乘法器在运算电路中的应用

| 应用 | 电路接法 | 输出 |
|---|---|---|
| 乘法 | 直接使用 | `u_o = k u_x u_y` |
| 平方 | 两输入接同一信号 | `u_o = k u_x²` |
| **除法** | 乘法器接在**反馈支路**中，其一个输入接输出电压 | `u_o = −(R_2/(kR_1))·(u_i/u_x)` |
| **开方** | 乘法器接在反馈支路中，两输入都接输出电压 | `u_o = √(−u_i/k)`（要求 `u_i < 0`） |
| 均方根 | 平方 → 积分 → 开方 | `u_o = √(平均平方值)` |
| 调幅/解调 | 乘法器实现调制与同步检波 | 通信电路的基础 |

> **注意开方电路的输入极性**：由于 `k u_o² ≥ 0`，而反馈支路要求 `u_i` 与 `u_o` 反号，故必须 `u_i < 0`。若需要正输入开方，可在前面加一级反相器。

## 6.3 有源滤波电路

### 6.3.1 滤波电路的基础知识

**滤波电路（filter）的作用是让指定频率范围的信号通过、抑制其它频率的信号；用运放加 RC 网络构成的称为有源滤波电路。**

**与无源滤波相比的优缺点**：

| 方面 | 有源滤波 | 无源滤波 |
|---|---|---|
| 增益 | 可大于 1（可带放大） | 只能衰减 |
| 负载效应 | 运放隔离，几乎无 | 明显，级联困难 |
| 体积重量 | 小（无电感） | 低频时电感大而笨重 |
| 频率范围 | 受运放带宽限制，**适合低频** | 适合高频、大功率 |
| 电源 | 需要供电 | 不需要 |

**四种滤波电路**：

```text
  |A|  低通 LPF        |A|  高通 HPF        |A|  带通 BPF        |A|  带阻 BEF
   │ ┌───────┐          │        ┌──────    │   ┌──┐           │ ┌─┐   ┌─┐
   │ │       ╲          │       ╱           │  ╱    ╲          │ │ ╲   ╱ │
   └─┴───────┴── f      └───────┴────── f    └─┴──────┴── f     └─┴──┴─┴──┴─ f
     f_H 通过低频        f_L 通过高频        f_0 通过中频        f_0 抑制中频
```

**关键参数**：

| 参数 | 含义 |
|---|---|
| 通带增益 `A_up` | 通带内的电压增益 |
| 截止频率 `f_p`（或 `f_0`） | 增益下降到 `A_up` 的 0.707 倍处的频率 |
| 品质因数 `Q` | `Q = f_0/BW`，`Q` 越大选择性越好、过渡带越陡 |
| 过渡带宽度 | 从通带到阻带的频率范围 |

### 6.3.2 低通滤波器

#### （1）一阶低通滤波器

**把 RC 低通网络接在运放的同相端（压控电压源结构），即得同相输入的一阶低通滤波器。**

`A_u(f) = A_up/(1 + jf/f_0)`，其中 `A_up = 1 + R_f/R_1`，`f_0 = 1/(2πRC)`

| 频率 | 增益 |
|---|---|
| `f << f_0` | `A_u ≈ A_up` |
| `f = f_0` | `A_u = A_up/√2`（−3 dB） |
| `f >> f_0` | `A_u ≈ A_up f_0/f`（−20 dB/十倍频） |

#### （2）二阶低通滤波器

**二阶低通（压控电压源，Sallen-Key 结构）在 `f_0` 附近可以产生「峰值」，过渡带以 −40 dB/十倍频下降，选择性更好。**

`f_0 = 1/(2πRC)`（两级 RC 取值相同），`Q = 1/(3 − A_up)`

| `A_up` | `Q` | 频响特点 |
|---|---|---|
| 1 | 0.5 | 无峰值，过渡带最平缓 |
| 2 | 1 | 无峰值，临界（Butterworth 最平坦响应） |
| 2.5 | 2 | `f_0` 处有峰值，选择性好 |
| → 3 | → ∞ | **自激振荡**（不能达到 3） |

**设计约束**：`A_up < 3` 是二阶压控电压源低通滤波器稳定的必要条件。

### 6.3.3 其它滤波电路

#### （1）高通滤波器

**把 RC 网络的位置对调（电容串联在输入、电阻接在输出与地之间），即得一阶高通；二阶高通同理。**

`A_u(f) = A_up·(jf/f_0)/(1 + jf/f_0)`，`f_0 = 1/(2πRC)`

#### （2）带通滤波器

**低通与高通串联（级联）即得带通，条件是低通的 `f_H` 大于高通的 `f_L`。**

`f_0 = √(f_L f_H)`，`BW = f_H − f_L`，`Q = f_0/BW`

**实用实现**：用压控电压源结构把 RC 网络改为「串联臂用 R、C 并联，并联臂用 R、C 串联」的多重反馈（MFB）带通电路，可同时得到较小的 `Q` 与合适的增益。

#### （3）带阻滤波器

**把带通滤波器的输出与输入相减（用加减运算电路）即得带阻；最典型的应用是 50 Hz 工频陷波器。**

**双 T 网络**是实现带阻的经典无源网络，配以运放做有源带阻时可获得很深的阻带衰减。

### 6.3.4 开关电容滤波器

**用「开关 + 电容」模拟电阻：`R = 1/(f_clk C)`，于是滤波器的 `f_0` 只取决于时钟频率与电容比值，便于集成且可编程。**

原理：一个电容 `C` 以频率 `f_clk` 在两个节点间来回切换，等效平均电流 `I = C·ΔU·f_clk`，故等效电阻 `R = ΔU/I = 1/(f_clk C)`。

| 优点 | 缺点 |
|---|---|
| 无需大电阻大电容，全集成 | 需要时钟，存在开关噪声 |
| `f_0` 与 `f_clk` 成正比，可编程 | 时钟频率必须远高于信号频率（一般 ≥50 倍） |
| 精度取决于电容**比值**，易匹配 | 混叠效应 |

### 6.3.5 状态变量型有源滤波器

**状态变量滤波器（state-variable filter）用多个运放（积分器 + 加法器）同时输出低通、高通、带通三种结果，且 `f_0` 与 `Q` 可独立调节。**

结构：加法器 → 积分器 1（输出带通）→ 积分器 2（输出低通），两路积分输出反馈回加法器（其输出为高通）。

| 输出端 | 滤波类型 |
|---|---|
| 加法器输出 | 高通 |
| 积分器 1 输出 | 带通 |
| 积分器 2 输出 | 低通 |

**优点**：`f_0`、`Q`、增益可独立调节，适合做成通用滤波器芯片（如 UAF42）。

## 6.4 电子信息系统预处理中所用放大电路

### 6.4.1 仪表放大器

**仪表放大器（instrumentation amplifier）由三个运放构成：两个同相输入运放组成第一级（提供高输入阻抗与主要增益），第三级为差分放大器（抑制共模）。**

`A_u = (1 + 2R/R_W)·(R_4/R_3)`

**特点**：

1. **输入电阻极高**（同相输入，`R_i` 达 GΩ 级）；
2. **共模抑制比极高**（可大于 100 dB）；
3. **增益只需一个电阻 `R_W` 调节**，且调节时共模抑制能力不变；
4. 常用于传感器信号调理（应变片、热电偶、压力传感器）。

> **为什么不用单个差分放大器？** 单级差分放大器的输入电阻等于 `2R_1`（有限），且要改变增益必须同时改变两个电阻以保证匹配，稍有不匹配 CMRR 就急剧下降。

### 6.4.2 电荷放大器

**电荷放大器用于压电式传感器：把传感器产生的电荷 `Q` 转换为电压输出，`u_o = −Q/C_f`，其输出与电缆电容无关。**

压电传感器可以等效为一个电荷源与一个电容 `C_a` 并联。用运放构成积分器（电容 `C_f` 在反馈支路），虚地使传感器电荷全部流入 `C_f`，故 `u_o = −Q/C_f`。

**优点**：输出不受电缆电容与分布电容影响（这是它优于电压放大器的关键）；**缺点**：需要低噪声、高输入阻抗的运放，且要定期放电防止漂移饱和。

### 6.4.3 隔离放大器

**隔离放大器（isolation amplifier）在输入与输出之间提供电气隔离（光电、变压器或电容耦合），隔离电压可达数千伏。**

用途：① 强电与弱电系统的接口；② 医疗设备（保护患者）；③ 消除地环路干扰。

### 6.4.4 放大电路中的干扰和噪声及其抑制措施

| 干扰类型 | 来源 | 抑制措施 |
|---|---|---|
| 工频干扰（50 Hz） | 电源、动力线 | 屏蔽、远离干扰源、加陷波器、提高 CMRR |
| 高频电磁干扰 | 开关电源、无线电 | 屏蔽、滤波、缩短引线、加铁氧体磁环 |
| 地环路干扰 | 多点接地 | **单点接地**、用隔离放大器 |
| 噪声（器件固有） | 热噪声、散粒噪声、1/f 噪声 | 选低噪声运放、限制带宽、降低源电阻、**前级增益要高** |
| 失调漂移 | 温度变化 | 斩波稳零运放、对称布局、恒温 |

> **核心原则**：**噪声一旦在输入级引入就无法与信号分离，所以「低噪声设计」的关键是把第一级做好**（低噪声器件 + 足够的前级增益 + 窄带宽）。

## 6.5 Multisim 应用举例

用 Multisim 仿真本章电路时的要点：

1. **运放要接双电源**（如 ±12 V），并在电源端加去耦电容；
2. 用**虚拟示波器**观察积分、微分电路的波形变换（方波→三角波、三角波→方波）；
3. 用**交流扫描分析（AC Sweep）**画滤波器的波特图，直接读出 `f_0` 与 −3 dB 点；
4. 积分电路要设置电容初始条件或用开关复位，否则输出会漂移到饱和；
5. 仿真运算误差时把理想运放换成实际型号（如 μA741、LM324），比较 `U_IO`、带宽带来的差别。

## 典型例题

**例 6.1**（题型：反相比例运算）
电路：`R_1 = 10 kΩ`，`R_f = 100 kΩ`，输入 `u_i = 0.2 V`。求 `A_uf`、`u_o`、`R_i` 与平衡电阻 `R_2`。

**解**：
`A_uf = −R_f/R_1 = −100/10 = −10`
`u_o = A_uf · u_i = −10 × 0.2 = −2 V`
输入电阻 `R_i = R_1 = 10 kΩ`
平衡电阻 `R_2 = R_1 ∥ R_f = (10 × 100)/(10 + 100) = 1000/110 = 9.09 kΩ`

**答案**：`A_uf = −10`，`u_o = −2 V`，`R_i = 10 kΩ`，`R_2 = 9.09 kΩ`。
**校验**：`|u_o| = 2 V < U_OM ≈ 12 V`，运放工作在线性区，虚短成立。

**例 6.2**（题型：同相比例与电压跟随器）
同相比例电路：`R_1 = 10 kΩ`，`R_f = 90 kΩ`，`u_i = 0.5 V`。求 `A_uf` 与 `u_o`；若改成电压跟随器，输出为多少？

**解**：
`A_uf = 1 + R_f/R_1 = 1 + 90/10 = 10`
`u_o = 10 × 0.5 = 5 V`
电压跟随器：`A_uf = 1`，`u_o = u_i = 0.5 V`

**答案**：`A_uf = 10`，`u_o = 5 V`；跟随器时 `u_o = 0.5 V`。
**注意**：同相电路的共模输入等于 `u_i`，若运放 `K_CMR` 不高，会引入共模误差。

**例 6.3**（题型：T 型网络实现高增益——★常考）
要求用反相比例电路实现 `A_uf = −100`，但要求所有电阻不超过 100 kΩ。设计 T 型网络参数（取 `R_1 = 10 kΩ`）。

**解**：
若用普通反相比例，需 `R_f = 100 × 10 kΩ = 1 MΩ`，超过限制。
改用 T 型网络，公式：`|A_uf| = (R_2 + R_3 + R_2R_3/R_4)/R_1 = 100`
故分子需为 `100 × 10 kΩ = 1000 kΩ = 1 MΩ`。
取 `R_2 = R_3 = 100 kΩ`（不超过 100 kΩ 上限），则
`100 + 100 + (100 × 100)/R_4 = 1000`（单位 kΩ）
`10 000/R_4 = 800` → `R_4 = 12.5 kΩ`

**答案**：`R_1 = 10 kΩ`，`R_2 = R_3 = 100 kΩ`，`R_4 = 12.5 kΩ`，此时 `A_uf = −100`。
**校验**：`(100 + 100 + 10 000/12.5)/10 = (200 + 800)/10 = 100` ✓
**代价**：`R_4` 的误差会被放大 100 倍传递到增益上，所以 `R_4` 要用精密电阻。

**例 6.4**（题型：反相求和运算）
`R_1 = R_2 = R_3 = 10 kΩ`，`R_f = 20 kΩ`，`u_i1 = 0.5 V`，`u_i2 = −0.2 V`，`u_i3 = 0.1 V`。求 `u_o`。

**解**：
`u_o = −R_f(u_i1/R_1 + u_i2/R_2 + u_i3/R_3)`
`= −20 × (0.5/10 + (−0.2)/10 + 0.1/10)`
`= −20 × (0.05 − 0.02 + 0.01) = −20 × 0.04 = −0.8 V`

**答案**：`u_o = −0.8 V`。
**特点**：三路输入共地、互不影响，各路比例由各自的 `R_k` 单独决定。

**例 6.5**（题型：加减运算电路）
差分放大电路：`R_1 = R_2 = 20 kΩ`，`R_3 = R_f = 100 kΩ`。`u_i1 = 1.5 V` 经 `R_1` 接反相端，`u_i2 = 0.5 V` 经 `R_2` 接同相端。求 `u_o` 与共模、差模分量。

**解**：
由 `R_1 = R_2`、`R_3 = R_f` 的条件：
`u_o = (R_f/R_1)(u_i2 − u_i1) = (100/20)(0.5 − 1.5) = 5 × (−1) = −5 V`
差模输入 `u_id = u_i2 − u_i1 = −1 V`；共模输入 `u_ic = (u_i1 + u_i2)/2 = 1 V`

**答案**：`u_o = −5 V`，`u_id = −1 V`，`u_ic = 1 V`。
**注意**：本电路**放大了差模 5 倍、抑制了共模**（理想情况下共模增益为 0），这正是差分放大器的作用。

**例 6.6**（题型：积分运算电路——★常考）
积分电路 `R = 10 kΩ`、`C = 0.1 μF`，输入为幅值 ±2 V、频率 1 kHz 的方波。求输出波形的形状与峰峰值。

**解**：
时间常数 `RC = 10×10³ × 0.1×10⁻⁶ = 1×10⁻³ s = 1 ms`
半周期 `T/2 = 1/(2×1000) = 0.5 ms`
半周期内输出变化量：
`Δu_o = −(U_i/RC)·(T/2) = −(2/1 ms) × 0.5 ms = −1 V`
正半周（`u_i = +2 V`）输出从某个值线性下降 1 V；负半周（`u_i = −2 V`）输出线性上升 1 V。

**答案**：输出为**三角波**，频率与输入相同（1 kHz），峰峰值 `2 × 1 = 2 V`（即从 +1 V 到 −1 V）。
**判据**：只要 `RC >> T/2`（本例 `1 ms` 与 `0.5 ms` 同量级，属于临界情形），输出才接近理想的三角波；若 `RC` 太小，输出会趋近于方波的积分但幅度过大导致运放饱和。

**例 6.7**（题型：微分运算电路）
微分电路 `R = 10 kΩ`、`C = 0.01 μF`，输入为斜率 1 V/ms 的三角波。求输出波形的幅值。

**解**：
`RC = 10×10³ × 0.01×10⁻⁶ = 1×10⁻⁴ s`
输入斜率 `du_i/dt = 1 V/1 ms = 1000 V/s`
`u_o = −RC·(du_i/dt) = −1×10⁻⁴ × 1000 = −0.1 V`

**答案**：输出为**方波**，幅值 ±0.1 V，频率与输入三角波相同。
**实用提示**：实际电路中要在 `C` 支路串入小电阻（如 100 Ω）限制高频增益，否则噪声会被放大到饱和。

**例 6.8**（题型：对数与指数运算电路）
对数电路：`R = 1 kΩ`，三极管 `I_S = 10⁻¹⁴ A`，`U_T = 26 mV`，`u_i = 1 V`。求 `u_o`。若把该电路改作指数电路并输入 `u_i = 0.6 V`，求输出。

**解**：
**对数电路**：`i_C = u_i/R = 1/1000 = 1 mA`
`u_o = −U_T ln(u_i/(I_S R)) = −0.026 × ln(1/(10⁻¹⁴ × 10³)) = −0.026 × ln(10¹¹)`
`ln(10¹¹) = 11 × 2.303 = 25.33`
`u_o = −0.026 × 25.33 = −0.659 V`
**指数电路**：`I_S R = 10⁻¹⁴ × 10³ = 10⁻¹¹ V`
`u_i/U_T = 0.6/0.026 = 23.08`，`e^23.08 = 1.055×10¹⁰`
`u_o = −I_S R·e^(u_i/U_T) = −10⁻¹¹ × 1.055×10¹⁰ = −0.106 V`

**答案**：对数电路输出 −0.659 V；指数电路输出 −0.106 V。
**验证互逆性**：把 1 V 送入对数电路得 −0.659 V，取绝对值 0.659 V 送入指数电路：`e^(0.659/0.026) = e^25.35 = 1.02×10¹¹`，`u_o = −10⁻¹¹ × 1.02×10¹¹ = −1.02 V ≈ −1 V` ✓ 与输入一致。

**例 6.9**（题型：模拟乘法器的应用——除法与开方）
模拟乘法器乘积系数 `k = 0.1 V⁻¹`。求：(a) 两输入 `u_x = u_y = 2 V` 时的输出；(b) 用 `R_1 = R_2 = 10 kΩ` 构成除法电路，`u_i = 2 V`、`u_X = 4 V` 时的输出；(c) 构成开方电路（`R_1 = R_2`），`u_i = −4 V` 时的输出。

**解**：
(a) 平方：`u_o = k u_x u_y = 0.1 × 2 × 2 = 0.4 V`
(b) 除法：`u_o = −(R_2/(kR_1))·(u_i/u_X) = −(10/(0.1×10))×(2/4) = −10 × 0.5 = −5 V`
(c) 开方：`k u_o² = −(R_2/R_1)u_i = −u_i`（因 `R_1 = R_2`）
`u_o = √(−u_i/k) = √(4/0.1) = √40 = 6.32 V`

**答案**：(a) 0.4 V；(b) −5 V；(c) 6.32 V。
**注意**：开方电路要求 `u_i < 0`，且输出必须为正，否则反馈极性错误会导致运放饱和。

**例 6.10**（题型：一阶有源低通滤波器）
同相输入一阶低通滤波器：`R = 10 kΩ`，`C = 0.01 μF`，`R_1 = 10 kΩ`，`R_f = 10 kΩ`。求通带增益 `A_up`、截止频率 `f_0`，以及 `f = 10 kHz` 时的增益。

**解**：
`A_up = 1 + R_f/R_1 = 1 + 10/10 = 2`
`f_0 = 1/(2πRC) = 1/(2π × 10×10³ × 0.01×10⁻⁶) = 1/(2π × 10⁻⁴) = 1592 Hz ≈ 1.59 kHz`
`f = 10 kHz` 时：
`|A_u| = A_up/√(1 + (f/f_0)²) = 2/√(1 + (10/1.59)²) = 2/√(1 + 39.6) = 2/6.37 = 0.314`
分贝：`20 lg 0.314 = −10.1 dB`

**答案**：`A_up = 2`，`f_0 = 1.59 kHz`，10 kHz 时增益降为 0.314（−10.1 dB）。
**校验**：`f/f_0 = 6.29`，即 `lg(f/f_0) = lg 6.29 ≈ 0.8` 个十倍频程（一阶电路每十倍频程衰减 20 dB），故衰减应为 `20 lg 2 − 20 lg 6.29 = 6 − 16 = −10 dB` ✓

**例 6.11**（题型：二阶低通滤波器的 Q 值）
二阶压控电压源低通滤波器：`R = 10 kΩ`，`C = 0.01 μF`，同相增益 `A_up` 分别取 2 与 2.5。求 `f_0`、`Q` 以及 `f = f_0` 处的增益。

**解**：
`f_0 = 1/(2πRC) = 1.59 kHz`（与例 6.10 相同）
`A_up = 2`：`Q = 1/(3 − 2) = 1`，`f_0` 处 `|A| = A_up·Q = 2 × 1 = 2`（无峰值）
`A_up = 2.5`：`Q = 1/(3 − 2.5) = 2`，`f_0` 处 `|A| = 2.5 × 2 = 5`（有明显峰值）
（若 `A_up = 3`，`Q → ∞`，电路自激）

**答案**：`f_0 = 1.59 kHz`；`A_up = 2` 时 `Q = 1`、`|A(f_0)| = 2`；`A_up = 2.5` 时 `Q = 2`、`|A(f_0)| = 5`。
**结论**：**同相增益越接近 3，Q 越大、选择性越好，但越容易自激**——这就是二阶压控电压源滤波器必须满足 `A_up < 3` 的原因。

**例 6.12**（题型：集成运放非理想参数引起的误差）
反相比例电路 `R_1 = 10 kΩ`、`R_f = 100 kΩ`，运放 `A_od = 10⁵`、`U_IO = 2 mV`、`I_IO = 20 nA`。求：(a) 由 `A_od` 有限引起的增益相对误差；(b) 由 `U_IO`、`I_IO` 引起的输出直流偏移。

**解**：
(a) 相对误差 `≈ (1 + R_f/R_1)/A_od = (1 + 10)/10⁵ = 11/10⁵ = 1.1×10⁻⁴ = 0.011%`
实际闭环增益 `A_uf = −10/(1 + 1.1×10⁻⁴) = −9.9989`（与理想值 −10 相差 0.0011）
(b) `Δu_o = (1 + R_f/R_1)U_IO + I_IO R_f = 11 × 2 mV + 20 nA × 100 kΩ`
`= 22 mV + 2 mV = 24 mV`

**答案**：(a) 增益相对误差 0.011%；(b) 输出直流偏移 24 mV。
**说明**：直流偏移中 `U_IO` 的贡献（22 mV）远大于 `I_IO`（2 mV），所以**选低失调电压的运放比选低失调电流的更有效**。若要放大 μV 级信号，24 mV 的偏移会淹没信号，必须用斩波稳零运放或加调零电路。

**例 6.13**（题型：仪表放大器）
三运放仪表放大器：`R = 25 kΩ`（第一级两个反馈电阻），`R_W = 1 kΩ`（增益调节电阻），第二级 `R_3 = 10 kΩ`、`R_4 = 100 kΩ`。求总增益。

**解**：
第一级增益：`A_u1 = 1 + 2R/R_W = 1 + (2 × 25)/1 = 1 + 50 = 51`
第二级增益：`A_u2 = R_4/R_3 = 100/10 = 10`
总增益：`A_u = A_u1 · A_u2 = 51 × 10 = 510`

**答案**：`A_u = 510`（约 54.2 dB）。
**特点**：只调 `R_W` 一个电阻即可改变总增益；若把 `R_W` 改为 500 Ω，则 `A_u1 = 101`，总增益变为 1010——**增益与 `R_W` 成反比，且共模抑制能力不变**。

## 易错点提醒

1. **忘记虚短虚断的适用条件** → 只在「运放工作在线性区 + 有负反馈」时成立；比较器、开环、正反馈电路中虚短不成立（但虚断仍成立）。
2. **把虚地当成真正的地** → 虚地点的电位为 0，但不能接负载、不能作为参考点输出电流。
3. **反相比例电路忘记接平衡电阻** → 平衡电阻 `R_2 = R_1 ∥ R_f` 用于抵消输入偏置电流的影响，漏掉会使直流偏移增大。
4. **同相比例电路的增益写成 `R_f/R_1`** → 是 `1 + R_f/R_1`，最小值是 1（跟随器），不可能小于 1。
5. **认为同相电路和反相电路的误差一样** → 同相电路有共模输入（`u_ic = u_i`），对 `K_CMR` 敏感；反相电路是虚地，无共模误差。
6. **T 型网络增益公式记错** → 是 `−(R_2 + R_3 + R_2R_3/R_4)/R_1`，其中 `R_4` 接在**中间节点 X 与地之间**，不是接在反馈回路上。
7. **积分电路的输出表达式漏掉初始值** → 完整形式是 `u_o = −(1/RC)∫u_i dt + u_o(0)`；实际电路还要在电容两端并大电阻防止漂移饱和。
8. **认为微分电路好用** → 微分电路对高频噪声增益为 `ωRC`，极易自激，实用中必须串小电阻限制高频增益。
9. **二阶压控电压源低通滤波器取 `A_up = 3`** → `Q → ∞` 会自激，必须 `A_up < 3`（一般取 1.586 得 Butterworth 响应，`Q = 0.707`）。
10. **开方电路的输入极性搞错** → `u_o = √(−u_i/k)` 要求 `u_i < 0`；若输入为正，运放会饱和到负电源。
11. **把有源滤波器的 `f_0` 当成能无限提高** → 受运放 GBW 限制，一般要求 `f_0` 远小于运放的带宽（经验：`f_0 ≤ GBW/100`）。
12. **认为对数运算电路精度高** → 其精度受 `I_S`、`U_T` 的温度漂移严重影响，动态范围只有 2~3 个数量级，实际乘法运算应选模拟乘法器。

## 本章小结

- 运放线性应用的两个法宝：**虚短**（`u_P = u_N`）与**虚断**（`i_P = i_N = 0`）；分析三步：求 `u_P` → 得 `u_N` → 对 N 点列 KCL。
- 比例运算：反相 `−R_f/R_1`（`R_i` 小、无共模误差）；同相 `1 + R_f/R_1`（`R_i` 大、有共模误差）；跟随器 `A = 1`。
- **T 型网络**用较小电阻实现高增益，代价是对电阻精度敏感。
- 加减运算：反相求和 `u_o = −R_f Σ(u_ik/R_k)`（各路独立）；求差 `u_o = (R_f/R_1)(u_i2 − u_i1)`（当电阻对称）。
- 积分 `u_o = −(1/RC)∫u_i dt`（方波→三角波）；微分 `u_o = −RC·du_i/dt`（三角波→方波），微分电路必须限制高频增益。
- 对数 `u_o = −U_T ln(u_i/(I_S R))`；指数 `u_o = −I_S R e^(u_i/U_T)`；二者组合可做乘除。
- 模拟乘法器 `u_o = k u_x u_y`；接在反馈支路中可实现除法与开方（开方要求输入为负）。
- 有源滤波：一阶低通 `A_up/(1 + jf/f_0)`、`f_0 = 1/(2πRC)`；二阶压控电压源 `Q = 1/(3 − A_up)`，必须 `A_up < 3`。
- 开关电容滤波器用 `R = 1/(f_clk C)` 等效电阻，`f_0 ∝ f_clk`，便于集成与编程。
- 仪表放大器三运放结构：`A_u = (1 + 2R/R_W)(R_4/R_3)`，高输入阻抗、高 CMRR、单电阻调增益。
- 运放非理想带来的误差：增益误差 `≈ (1+R_f/R_1)/A_od`，直流偏移 `(1+R_f/R_1)U_IO + I_IO R_f`。

> **一句话记住本章**：**虚短虚断是万能钥匙；反馈支路放电阻是比例、放电容是积分、放 PN 结是对数、放乘法器是开方——换一个反馈元件就换一种运算。**

6. 积分电路与微分电路的输出表达式各是什么？方波经积分、三角波经微分后分别得到什么波形？
7. 写出对数、指数运算电路的输出表达式，并说明为什么它们可以组合实现乘法。
8. 模拟乘法器乘积系数 `k = 0.1 V⁻¹`，两输入均为 3 V，输出为多少？开方电路的输出表达式是什么？对输入极性有何要求？
9. 一阶有源低通滤波器的 `f_0` 如何计算？二阶压控电压源低通的 `Q` 与 `A_up` 有什么关系？为什么要求 `A_up < 3`？
10. 仪表放大器的总增益表达式是什么？它相比单级差分放大器有哪些优点？
11. 某反相比例电路 `R_1 = 20 kΩ`、`R_f = 200 kΩ`，运放 `A_od = 2×10⁵`、`U_IO = 3 mV`。求增益相对误差与输出直流偏移。

**自测题答案**

1. 虚短来自 `A_od = ∞` 而 `u_o` 有限；虚断来自 `R_id = ∞`；条件是运放工作在线性区且引入了负反馈。
2. 反相 `−R_f/R_1`，`R_i = R_1`（小），共模输入为 0；同相 `1 + R_f/R_1`，`R_i` 极大，共模输入等于 `u_i`。
3. 使两输入端对地直流电阻相等，抵消输入偏置电流引起的输出偏移；反相比例中取 `R_1 ∥ R_f`。
4. 因为 `R_2R_3/R_4` 项对分母 `R_4` 敏感，用一个较小的 `R_4` 就能产生很大的等效反馈电阻；`A_uf = −(R_2 + R_3 + R_2R_3/R_4)/R_1`。
5. 反相求和 `u_o = −R_f(u_i1/R_1 + u_i2/R_2 + …)`；求差（`R_1 = R_2`、`R_3 = R_f` 时）`u_o = (R_f/R_1)(u_i2 − u_i1)`。
6. 积分 `u_o = −(1/RC)∫u_i dt + u_o(0)`；微分 `u_o = −RC·du_i/dt`。方波经积分得三角波，三角波经微分得方波。
7. 对数 `u_o = −U_T ln(u_i/(I_S R))`，指数 `u_o = −I_S R e^(u_i/U_T)`；因为 `ln u_x + ln u_y = ln(u_x u_y)`，所以「取对数→求和→取反对数」即可实现乘法。
8. `u_o = 0.1 × 3 × 3 = 0.9 V`；开方 `u_o = √(−u_i/k)`，要求 `u_i < 0`。
9. `f_0 = 1/(2πRC)`；`Q = 1/(3 − A_up)`；当 `A_up → 3` 时 `Q → ∞` 会自激振荡，故必须 `A_up < 3`。
10. `A_u = (1 + 2R/R_W)(R_4/R_3)`；优点是输入电阻极高、共模抑制比极高、只需一个电阻调增益且调节时 CMRR 不变。
11. 相对误差 `= (1 + 200/20)/2×10⁵ = 11/2×10⁵ = 5.5×10⁻⁵ = 0.0055%`；输出直流偏移 `= 11 × 3 mV = 33 mV`。
