## 10.1 读图的思路和步骤

**读图的目标不是「看懂每一根线」，而是回答三个问题：这个电路是干什么的？它由哪几块组成？它的性能怎么算？**

### 七步读图法

| 步骤 | 做什么 | 关键问题 |
|---|---|---|
| **① 找电源与地** | 找出 `+V_CC`、`−V_CC`、地，判断是单电源还是双电源 | 供电方式决定了输出静态电位与最大输出幅度 |
| **② 划分功能块** | 按信号流向把电路分成输入级、中间级、输出级、反馈网络、电源 | 从输入到输出「一条线走到底」 |
| **③ 辨核心器件与组态** | 每只三极管判断组态（共射/共集/共基），每个运放判断输入方式 | 共射给电压增益、共集给缓冲、差放抗零点漂移 |
| **④ 算直流通路** | 电容视为开路，画直流通路，估算 Q 点与静态电位 | 输出端的静态电位（双电源应为 0，单电源应为 `V_CC/2`） |
| **⑤ 析交流通路** | 直流电源接地、耦合与旁路电容短路，画交流通路 | 交流通路决定了增益、输入输出电阻 |
| **⑥ 判反馈** | 找反馈元件，判极性（瞬时极性法）与组态（输出短路法 + 输入节点法） | 决定了闭环增益与输入输出电阻 |
| **⑦ 定功能与指标** | 综合判断电路功能，估算主要性能指标 | 能说出「这个电路的输入是…，输出是…，指标是…」 |

### 读图的三个实用技巧

1. **「从输出端往回想」**——输出级往往特征鲜明（互补管 → 功放；稳压管 → 稳压电源；继电器/蜂鸣器 → 控制电路），能快速定位电路功能。
2. **「电容定位法」**——电容的位置提示信号路径：耦合电容串联在信号路上（隔直通交）；旁路电容并在电阻两端（交流短路）；去耦电容接在电源与地之间；补偿电容跨接在反馈环内。
3. **「先直流后交流」**——不要一开始就算增益；先把 Q 点算清楚，再看交流通路。**静态是基础，动态是结果。**

## 10.2 基本电路和基本分析方法回顾

### 10.2.1 基本电路

**读图时用这张表做「查表匹配」：看清器件与连接方式，直接对应到学过的单元电路。**

| 电路特征 | 单元电路 | 记住的结论 |
|---|---|---|
| 输入接基极、输出取自集电极 | 共射放大 | `A_u = −βR_L'/r_be`，反相、增益大 |
| 输入接基极、输出取自发射极 | 共集（射随） | `A_u ≈ 1`，同相，`R_i` 大 `R_o` 小 |
| 输入接发射极、输出取自集电极 | 共基放大 | `A_u` 同共射，同相，**高频好** |
| 两只同型管 + 恒流源尾 | 差分放大 | 抗零点漂移，`K_CMR` 高 |
| 两只同型管 + 发射极电阻且基极相连 | **镜像电流源** | `I_o ≈ I_R`，为差放提供恒流 |
| 运放 + 反相输入 + 反馈电阻 | 反相比例（电压并联负反馈） | `A_uf = −R_f/R_1` |
| 运放 + 同相输入 + 分压反馈 | 同相比例（电压串联负反馈） | `A_uf = 1 + R_f/R_1` |
| 运放 + 反馈支路为电容 | **积分器** | `u_o = −(1/RC)∫u_i dt` |
| 运放 + 输入支路为电容 | **微分器** | `u_o = −RC·du_i/dt` |
| 运放开环或正反馈、输出两态 | 比较器 | 输出只有 `±U_OM`，虚短不成立 |
| 运放 + 正反馈 + RC 充放电 | 矩形波发生器 | `T = 2RC ln(1 + 2R_2/R_1)`（`R_1` 反馈、`R_2` 接地） |
| 运放 + RC 串并联选频 + 正反馈 | RC 桥式振荡器 | `f_0 = 1/(2πRC)`，`A > 3` |
| 两只互补管 + 双电源 + 无输出电容 | **OCL 功放** | `P_om = V_CC²/(2R_L)`，`η_max = 78.5%` |
| 四只二极管成桥 + 电容 | 桥式整流 + 电容滤波 | `U_o = 0.9U_2`（无 C），`≈1.2U_2`（有 C） |
| 稳压管 + 限流电阻 | 稳压管稳压电路 | `U_o = U_Z`，需按两种最坏情况选 `R` |
| 调整管 + 采样 + 基准 + 比较放大 | 串联型稳压电路 | `U_o = U_Z(1 + R_1/R_下)` |

### 10.2.2 基本分析方法

| 分析目标 | 选用方法 | 要点 |
|---|---|---|
| 静态工作点 | **直流通路 + 近似计算** | 电容开路；分压式偏置按 `U_BQ → U_EQ → I_EQ → U_CEQ` 四步 |
| 小信号动态指标 | **微变等效电路法** | 直流电源接地、电容短路；代入 `r_be = r_bb' + (1+β)26mV/I_EQ` |
| 大信号与失真 | **图解法** | 直流负载线定 Q 点，交流负载线定输出幅度 |
| 频率响应 | **波特图 / 时间常数法** | 低频看耦合电容、高频看结电容与密勒效应 |
| 反馈组态 | **瞬时极性法 + 输出短路法 + 输入节点法** | 四步判断：找元件 → 判极性 → 判电压/电流 → 判串/并联 |
| 功率与效率 | **公式法** | `P_om`、`P_V`、`η`、`P_T` 四个公式配合使用 |
| 电路的稳定性 | **环路增益波特图** | `\|AF\| = 1` 处的相位裕度应大于 45° |
| 整体功能 | **分块 + 信号流向** | 先定性（干什么），再定量（指标多少） |

## 10.3 读图举例

### 10.3.1 低频功率放大电路

**这是一个典型的 OCL 音频功率放大器：差分输入级（抗零点漂移）+ 恒流源 + 共射电压放大级 + 互补输出级 + 电压串联负反馈。**

```text
            +V_CC (+15V)
              │
        ┌─────┴─────┐
        │  恒流源   │
        └──┬─────┬──┘
           │     │
   u_i ──┬─┤T_1  ├T_2├──┐          ┌── D_1 ── D_2 ──┐
         │ └─────┘    │           │  （偏置，消除交越失真）
         │    差分输入级│           │                │
         │            ├─── T_4 ────┼────┬──── T_5(NPN) ──┬── u_o
         │      共射电压放大级      │    └──── T_6(PNP) ──┤
         │                        R_C                     │
         │                         │                     R_L（8Ω 扬声器）
         └──────── R_f（反馈）─────┴──────────────────────┘
              −V_CC (−15V)
```

**读图过程**：

| 步骤 | 结果 |
|---|---|
| ① 电源 | `±15 V` 双电源 → **输出静态电位为 0 V**，可直接耦合负载 |
| ② 分块 | 差分输入级（T1、T2 + 恒流源）、共射电压放大级（T4）、互补输出级（T5、T6 + D1、D2 偏置） |
| ③ 组态 | T1/T2：差分（等效共射）；T4：共射（提供全部电压增益）；T5/T6：共集（射随，电流增益） |
| ④ 直流通路 | 输出端静态 0 V；D1、D2 为 T5、T6 提供约 1.4 V 基极间偏置 → **甲乙类**，无交越失真 |
| ⑤ 交流通路 | T4 的集电极负载为 T5/T6 的输入电阻，增益由 T4 决定 |
| ⑥ 反馈 | `R_f` 从输出端接回 T2 的基极：输出短路 → 反馈消失 → **电压反馈**；反馈与输入接**不同节点**（T1、T2 基极）→ **串联反馈**；瞬时极性法 → **负反馈**。故为**电压串联负反馈** |
| ⑦ 功能 | 音频功率放大，闭环增益 `A_uf ≈ 1 + R_f/R_1`，输出电阻低、可驱动 8 Ω 扬声器 |

**定量估算**（见例 10.1）。

### 10.3.2 火灾报警电路

**电路由「热敏电阻分压的传感器桥 + 滞回比较器 + 报警输出（蜂鸣器/LED）+ 电源」组成，温度超限时比较器翻转驱动报警。**

```text
       +12V                    +12V
         │                       │
      ┌──┴──┐                 ┌──┴──┐
      │ R_t │ 热敏电阻(NTC)     │  R  │
      └──┬──┘                 └──┬──┘
         ├──── u_P（同相端）      ├──── U_R（反相端，8V）
         │                       │
      ┌──┴──┐                    │
      │  R  │ 10kΩ               │
      └──┬──┘                    │
         │                       │
         └───────────┬───────────┘
                     │
                ┌────┴────┐
                │  比较器  ├──── 蜂鸣器 + LED（报警）
                └────┬────┘
                     │ R_f（正反馈，构成滞回）
                     └────────────→ 输出
```

**读图要点**：

- **传感器**：`R_t` 是负温度系数（NTC）热敏电阻，温度升高 → 阻值下降 → 同相端电位 `u_P` **升高**；
- **比较器**：`u_P` 与参考电压 `U_R = 8 V` 比较；`u_P > U_R` 时输出高电平 → 驱动报警；
- **正反馈**：`R_f` 把输出反馈到同相端，构成**滞回比较器**，防止温度在阈值附近波动时报警器反复通断；
- **输出驱动**：蜂鸣器与 LED 由三极管或达林顿管驱动（比较器输出电流能力有限）。

**定量估算**（见例 10.2）。

### 10.3.3 自动增益控制电路

**自动增益控制（AGC）电路用 JFET 作为可变电阻，把输出幅度检波后得到的直流电压反馈到 JFET 的栅极，自动改变放大器的增益，使输出幅度基本不变。**

```text
                   ┌────────────[ R_f ]────────────┐
                   │                               │
   u_i ─[ R_DS ]───┴───────────┐（−）              │
        (JFET)                 │                   │
      （输入电阻）      ┌──────┴─────┐             │
                        │  运放 A    ├─────────────┴── u_o
                        └──────┬─────┘
                               └── 同相端接地（+）

   JFET 栅极 ◄── −U_G ──[ 峰值检波 + 低通（D + RC）]◄── 取自 u_o
                          （负控制电压）
```

**工作原理**：

1. JFET 工作在**可变电阻区**（`U_DS` 很小），其漏源电阻 `R_DS` 随栅源电压 `U_GS` 变化：`U_GS` 越负，`R_DS` 越大；
2. 放大器的增益 `|A| = R_f/R_DS`（JFET 作输入电阻）；
3. 输出幅度增大 → 检波得到的负电压 `|U_G|` 增大 → `R_DS` 增大 → `|A|` 减小 → **输出幅度回落**（自动增益控制）；
4. 输出幅度减小 → 反向过程 → 增益回升。

**关键应用**：收音机中放、录音机录音放大、脉搏检测等需要**输出幅度稳定**的场合。

**定量估算**（见例 10.3）。

### 10.3.4 电容测量电路

**用被测电容 `C_x` 作充放电定时元件构成方波/三角波发生器，则振荡频率 `f ∝ 1/C_x`，用频率计测出 `f` 即可算出 `C_x`。**

```text
        ┌──────────── R_1（正反馈）────────────┐
        │                                       │
        │    ┌─────────────┐                    │
        └───►│ 滞回比较器   ├────────────────────┴─── 方波输出 → 频率计
   ┌────────►│             │
   │         └─────────────┘
   │  ┌─────────────┐
   └──┤ 积分器       │  ← 定时元件 R 与 C_x（被测电容）
      └──────┬──────┘
             └──── 三角波输出
   约定：R_1 接比较器输出（正反馈），R_2 接在比较器同相端与积分器输出之间（不接地）
```

**频率与电容的关系**：由第 7 章的三角波发生电路公式

`f = R_1/(4R_2R·C_x)` → **`C_x = R_1/(4R_2R·f)`**

**测出 `f` 就能算 `C_x`，且二者成反比关系。**

**优点**：把电容这个「不好测」的量转换成频率这个「好测」的量（数字电路极易测频），精度高、抗干扰好。

**定量估算**（见例 10.4）。

### 10.3.5 直流稳压电源读图要点（综合练习见例 10.5）

```text
  220V ──[变压器]── u_2 ──[桥式整流]── 脉动 ──[电容滤波]── U_I ──[串联稳压]── U_o
         降压隔离          U_o=0.9U_2      U_o≈1.2U_2      调整管+采样
                                                          +基准+比较放大
```

读图时的三个核查点：① 输出端静态电位是否为 `U_Z(1 + R_1/R_下)`；② 调整管的工作点是否在安全区内；③ 滤波电容的耐压是否大于 `√2U_2`。

## 典型例题

**例 10.1**（题型：读低频功率放大电路并估算指标——★综合题）
上文的 OCL 音频功放：`±V_CC = ±15 V`，`R_L = 8 Ω`，反馈网络使闭环增益 `A_uf = 30`，输出管饱和压降 `U_CES = 2 V`。
求：(a) 闭环增益的分贝值；(b) 最大输出功率；(c) 若输入正弦波有效值 0.3 V，实际输出功率（设未过载）；(d) 单管最大管耗与选管要求。

**解**：
**(a)** `A_uf(dB) = 20 lg 30 = 20 × 1.477 = 29.5 dB`
**(b)** 最大输出幅度 `U_om = V_CC − U_CES = 15 − 2 = 13 V`
`P_om = U_om²/(2R_L) = 13²/(2 × 8) = 169/16 = 10.6 W`
**(c)** 输出有效值 `U_o = A_uf × U_i = 30 × 0.3 = 9 V`
`P_o = U_o²/R_L = 9²/8 = 81/8 = 10.1 W`
（校验：`U_om = 9√2 = 12.7 V < 13 V` ✓ 未过载）
**(d)** 单管最大管耗 `P_T1(max) ≈ 0.2 P_om = 0.2 × 10.6 = 2.12 W`
选管：`P_CM ≥ 2.12 W`（取 5 W）、`U_(BR)CEO ≥ 2V_CC = 30 V`（取 60 V）、`I_CM ≥ V_CC/R_L = 15/8 = 1.88 A`（取 3 A）

**答案**：`A_uf = 29.5 dB`；`P_om = 10.6 W`；实际输出 10.1 W；单管最大管耗 2.12 W。
**读图结论**：这是一个**电压串联负反馈的甲乙类 OCL 功放**，输入灵敏度约 0.3 V（有效值），可驱动 8 Ω 扬声器输出约 10 W。

**例 10.2**（题型：读火灾报警电路并计算阈值——★综合题）
火灾报警电路：`+V_CC = +12 V`，热敏电阻 `R_t`（NTC）与 `R = 10 kΩ` 串联分压，`R_t` 接上方、`R` 接下方，分压点接比较器同相端；反相端接参考电压 `U_R = 8 V`。已知 `R_t` 在 25 °C 时为 10 kΩ，温度升高时阻值下降。
求：(a) 25 °C 时同相端电位与输出状态；(b) 报警的临界 `R_t` 值与临界温度（设 60 °C 时 `R_t = 5 kΩ`）；(c) 说明 `R_f` 正反馈的作用。

**解**：
**(a)** `u_P = V_CC·R/(R_t + R) = 12 × 10/(10 + 10) = 120/20 = 6 V`
`u_P = 6 V < U_R = 8 V` → 输出低电平 → **不报警**
**(b)** 临界条件 `u_P = U_R = 8 V`：
`12 × 10/(R_t + 10) = 8` → `120 = 8R_t + 80` → `R_t = 5 kΩ`
据题意 `R_t = 5 kΩ` 对应 **60 °C**，故温度超过 60 °C 时报警。
**(c)** `R_f` 把输出电压反馈到同相端（**正反馈**），使比较器成为**滞回比较器**：
- **未报警时输出为低**，`R_f` 把同相端**拉低**，要更热（`R_t` 更小）才能把 `u_P` 顶到 `U_R = 8 V`，**进入报警的门槛被抬高**；
- **报警后输出为高**，`R_f` 又把同相端**拉高**，温度要降得更低（`R_t` 更大）才让 `u_P` 跌回 8 V 以下，**解除报警的门槛被压低**。
两个门槛之差就是**回差**，它让「报警」与「解除」发生在两个不同的温度上，从而**避免温度在 60 °C 附近波动时报警器反复通断**。
> **定量说明**：题中未给 `R_f` 的阻值，故只给方向性结论。若取 `R_f = 100 kΩ`（`R_p = R∥R_f ≈ 9.09 kΩ`）：进报警的临界 `R_t = 0.5R_p ≈ 4.55 kΩ`（比 5 kΩ 小，即**温度更高**才报警）；解除报警的临界 `R_t = 4/(8/R_p − 12/R_f) ≈ 5.26 kΩ`（比 5 kΩ 大，即**温度更低**才解除）。折算到「未加反馈时」的分压点电位分别约 `8.25 V` 与 `7.86 V`。

**答案**：25 °C 时 `u_P = 6 V < 8 V`，不报警；临界 `R_t = 5 kΩ`（60 °C）；超过 60 °C 报警；`R_f` 提供回差——**进报警的温度高于解除报警的温度**，避免临界点反复通断。
**读图结论**：这是一个**温度超限报警电路**，核心是「传感器分压 + 滞回比较器 + 输出驱动」。

**例 10.3**（题型：读 AGC 电路并分析增益变化）
AGC 电路中，JFET 作输入电阻 `R_DS`，反馈电阻 `R_f = 10 kΩ`。已知 JFET 的 `R_DS` 在 `U_GS = 0` 时为 200 Ω，在 `U_GS = −1 V` 时为 1 kΩ，在 `U_GS = −2 V` 时为 10 kΩ。
求：(a) 输入 10 mV 时（未起控，`R_DS = 200 Ω`）的输出；(b) 输入增大到 100 mV 时若增益不变会怎样；(c) 若检波后 `U_G = −1 V`（`R_DS = 1 kΩ`），实际输出为多少；(d) 说明 AGC 的效果。

**解**：
**(a)** `|A| = R_f/R_DS = 10 000/200 = 50`，`u_o = 50 × 10 mV = 500 mV = 0.5 V`
**(b)** 若增益不变：`u_o = 50 × 100 mV = 5 V` → 后级会严重失真甚至过载削波
**(c)** `|A| = 10 000/1000 = 10`，`u_o = 10 × 100 mV = 1 V`
**(d)** 输入从 10 mV 增大到 100 mV（**增大 10 倍**），输出从 0.5 V 只增大到 1 V（**增大 2 倍**）

**答案**：(a) 0.5 V；(b) 会达到 5 V 而严重过载；(c) 1 V；(d) AGC 把 10 倍的输入变化压缩成 2 倍的输出变化，输出幅度基本稳定。
**注意**：AGC 的响应速度由检波后的 RC 时间常数决定——时间常数太大会跟不上信号变化，太小则会在音频上产生「喘息效应」。

**例 10.4**（题型：读电容测量电路并计算）
电容测量电路：滞回比较器反馈电阻 `R_1 = 10 kΩ`（接比较器输出）、`R_2 = 10 kΩ`（接积分器输出端），积分器定时电阻 `R = 10 kΩ`，被测电容 `C_x` 接在积分器反馈支路中。已知 `f = R_1/(4R_2R·C_x)`。
求：(a) `C_x = 0.01 μF` 时的振荡频率；(b) `C_x = 0.1 μF` 时的频率；(c) 这一电路为什么适合测量电容？

**解**：
**(a)** `f = R_1/(4R_2R C_x) = 10 000/(4 × 10 000 × 10 000 × 0.01×10⁻⁶)`
分母 `= 4 × 10⁴ × 10⁴ × 10⁻⁸ = 4 × 10⁰ = 4`
`f = 10 000/4 = 2500 Hz`
**(b)** `C_x` 增大 10 倍，`f` 减小 10 倍：`f = 250 Hz`
**(c)** 电容值被线性地转换成频率（`f ∝ 1/C_x`），**频率是数字电路最容易高精度测量的量**（用计数器在固定闸门时间内数脉冲个数即可），因此测量精度高、抗干扰能力强、便于数字化显示。

**答案**：`C_x = 0.01 μF` 时 `f = 2500 Hz`；`C_x = 0.1 μF` 时 `f = 250 Hz`；该电路把「难测的电容」变成「易测的频率」。
**推广**：同样的思路用于把电阻、电感、温度、压力等物理量转换成频率（V-F 转换、传感器数字化的基本原理）。

**例 10.5**（题型：综合读图——直流稳压电源整机）
某直流稳压电源：变压器副边 `U_2 = 15 V`，桥式整流 + 电容滤波，接 7805 输出 +5 V，负载电流 1 A。
求：(a) 整流后无滤波的直流电压；(b) 加电容滤波后的电压；(c) 滤波电容的容量与耐压；(d) 7805 的功耗与效率（取滤波后 `U_I ≈ 17 V`）。

**解**：
**(a)** `U_o = 0.9U_2 = 0.9 × 15 = 13.5 V`
**(b)** `U_o ≈ 1.2U_2 = 1.2 × 15 = 18 V`
**(c)** `R_L` 要取**电容输出侧**的等效负载（即 7805 的输入侧），不能用稳压器输出侧的 `U_o/I_L`：`R_L = U_I/I_L ≈ 17/1 = 17 Ω`
`C ≥ (3~5)T/(2R_L)`，取系数 4：`C ≥ 4 × 0.02/(2 × 17) = 0.08/34 ≈ 2.35×10⁻³ F ≈ 2350 μF`
取标称值 **2200 μF**（宽裕些可取 3300 μF）；耐压 `≥ √2U_2 = 21.2 V`，取 **35 V**
> **校验纹波**：`ΔU ≈ I_L·T/(2C) = 1 × 0.02/(2 × 2200×10⁻⁶) ≈ 4.5 V`，仍远小于 `U_I − 5 − 2 ≈ 10 V` 的压差余量，方案可行。（若沿用 8000 μF，纹波只有 1.25 V，但体积与成本都大得多。）
**(d)** `P = (U_I − U_o)·I_L = (17 − 5) × 1 = 12 W`
效率 `η = P_o/P_I = (5 × 1)/(17 × 1) = 5/17 = 29.4%`

**答案**：整流后 13.5 V，滤波后约 18 V；电容 2200 μF/35 V；7805 功耗 12 W，整机效率仅 29.4%。
**分析结论**：**这是本电路最大的问题**——输入 17 V 降为 5 V，压差 12 V 全部变成热，芯片功耗 12 W 已远超其 1.5~2 W 的无散热片能力。
**改进方案**：① 把 `U_2` 降到 8 V 左右（压差 3~4 V），功耗降到 3~4 W；② 采用**开关电源**（效率可达 85%），或先用 Buck 降到 7 V 再线性稳压。

**例 10.6**（题型：故障分析）
某共射放大电路（分压式偏置、射极旁路电容 `C_e`）出现下列故障现象，分别判断可能的原因：
(a) 输出为 0 且集电极电位为 `+V_CC`；
(b) 输出波形正半周削平；
(c) 输出波形为正常正弦但幅度只有设计值的一半；
(d) 中频增益正常但低频增益明显下降。

**解**：
**(a)** 集电极电位等于 `+V_CC` 说明三极管处于**截止**状态（没有电流）→ 可能原因：基极偏置电阻开路、三极管发射结开路、基极对地短路。
**(b)** 正半周削平（顶部平坦）说明输出达到**截止**（三极管被关断）→ Q 点偏低或输入信号过大。反之若负半周削平（**底部/谷底平坦**），则是**饱和**失真，Q 点偏高。
**(c)** 幅度只有一半 → 可能是 `C_e` 开路（交流负反馈使增益下降约 `1+AF` 倍）、或负载电阻接错、或管子 β 显著下降。
**(d)** 低频增益下降 → **耦合电容或旁路电容容量不足**（`f_L` 太高），或电容干涸失效。

**答案**：见上。
**故障分析口诀**：**「静态看电位，动态看波形，频率看电容，失真看Q点」**。

## 易错点提醒

1. **读图时直接算增益而不先算 Q 点** → 必须先画直流通路估 Q 点，因为 `r_be` 依赖 `I_EQ`，Q 点错了所有动态指标都错。
2. **忘记「电容在直流开路、在交流短路」** → 画直流通路时把电容全部断开，画交流通路时把耦合/旁路电容短路、直流电源接地。
3. **把双电源电路的输出静态电位当成 `V_CC/2`** → 双电源（OCL、运放）的静态输出电位是 **0 V**；单电源（OTL）才是 `V_CC/2`。
4. **看到运放就套用虚短虚断** → 只有「线性区 + 负反馈」才成立；比较器、振荡器电路中虚短不成立。
5. **把差分输入级当成两级共射** → 差分对是**一个**单元电路，两只管的电流由同一恒流源约束，`i_E1 + i_E2 = I_0` 是关键约束。
6. **判断反馈组态时只看反馈元件的位置不看取样点** → 必须用输出短路法（判电压/电流）与输入节点法（判串/并联）两步走。
7. **读图时忽略电源去耦电容与消振电容** → 它们不改变功能但决定电路能否稳定工作，实际调试中不可省。
8. **认为「电路越复杂越好」** → 读图要**抓主干**：先看信号从输入到输出的主路径，再看辅助（偏置、保护、补偿）支路。
9. **报警/控制类电路忘记加回差** → 阈值附近噪声会导致输出反复跳变；必须用正反馈构成滞回比较器（或加软件消抖）。
10. **故障分析只盯着三极管** → 电阻开路、电容失效、虚焊在实际中比管子损坏更常见；分析时先量各点直流电位。

## 本章小结

- **七步读图法**：找电源与地 → 划分功能块 → 辨器件与组态 → 算直流通路 → 析交流通路 → 判反馈 → 定功能与指标。
- 三个技巧：**从输出端往回想、电容定位法、先直流后交流**。
- 读图核心能力是「**查表匹配**」：把看到的连接方式直接对应到学过的单元电路与结论。
- 直流通路：电容开路；交流通路：电源接地、耦合与旁路电容短路。
- 双电源电路静态输出为 0 V，单电源 OTL 为 `V_CC/2`。
- OCL 音频功放 = 差分输入级（抗漂移）+ 共射电压放大级 + 互补输出级（甲乙类）+ 电压串联负反馈。
- 报警电路 = 传感器分压 + 滞回比较器 + 输出驱动；阈值由分压比与参考电压决定，正反馈产生的**回差**使进报警与解除报警发生在两个不同温度上。
- AGC 电路用 JFET 作可变电阻改变增益，把输入的大范围变化压缩成输出的小范围变化。
- 电容测量电路把 `C_x` 转换成频率 `f ∝ 1/C_x`，便于数字化测量。
- 定量估算是读图的落脚点：Q 点、增益、带宽、功率、效率、阈值，都要能算出来。
- 故障分析口诀：**静态看电位，动态看波形，频率看电容，失真看 Q 点**。

> **一句话记住本章**：**读图就是「认块 + 查表 + 算数」——把陌生的整机拆成熟悉的单元电路，用全书的公式把指标算出来，电路就读懂了。**

## 自测题

1. 写出七步读图法的七个步骤。
2. 画直流通路与交流通路时，电容、直流电源分别如何处理？
3. 双电源供电的运放电路与单电源的 OTL 电路，输出静态电位分别是多少？
4. 看到「两只同型管发射极相连并接恒流源」，应判断为什么电路？它有什么优点？
5. AGC 电路中 JFET 起什么作用？输出幅度增大时它的阻值如何变化、增益如何变化？
6. 火灾报警电路中为什么要引入正反馈？
7. 电容测量电路为什么把电容转换成频率而不是转换成电压？
8. 某功放输出波形正半周被削平，判断是截止失真还是饱和失真？应如何调整偏置？
9. 某放大电路中频增益正常但低频增益下降，最可能是什么元件出了问题？
10. 串联型稳压电路效率低的原因是什么？如何改进？

**自测题答案**

1. ① 找电源与地；② 划分功能块；③ 辨器件与组态；④ 算直流通路（Q 点）；⑤ 析交流通路（动态指标）；⑥ 判反馈极性与组态；⑦ 定功能与指标。
2. 直流通路中电容视为**开路**；交流通路中耦合与旁路电容视为**短路**，直流电源视为**接地**（内阻为零）。
3. 双电源电路输出静态电位为 **0 V**；单电源 OTL 电路为 **`V_CC/2`**。
4. 差分放大电路；优点是抑制零点漂移、共模抑制比高，适合做直接耦合放大电路的输入级。
5. JFET 起**可变电阻**作用；输出幅度增大 → 检波得到的负控制电压绝对值增大 → `R_DS` 增大 → 增益 `|A| = R_f/R_DS` 减小 → 输出回落，实现自动增益控制。
6. 构成滞回比较器，产生回差（**进报警的温度高于解除报警的温度**），避免温度在阈值附近波动时输出（报警）反复通断，提高抗干扰能力。
7. 因为频率是数字电路最容易高精度测量的量（计数器数脉冲），测量精度高、抗干扰强、便于数字化显示；而电容直接测量（交流电桥等）易受分布参数影响。
8. 正半周削平说明三极管进入**截止**（输出被切掉），属于**截止失真**，应**减小**基极偏置电阻（提高 Q 点、增大 `I_CQ`）。
9. 耦合电容或发射极旁路电容**容量不足或失效**（`f_L` 偏高）。
10. 调整管串联在输入与输出之间并流过全部负载电流，承受 `U_I − U_o` 的压降，这部分功率全部变成热，效率只有 `U_o/U_I`；改进方法是降低输入电压（减小压差）、采用开关电源或「开关 + 线性」两级方案。
