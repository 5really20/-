## 5.1 反馈的基本概念及判断方法

### 5.1.1 反馈的基本概念

**反馈（feedback）就是把输出量（输出电压或输出电流）的一部分或全部，通过反馈网络送回到输入端，与输入信号进行比较，用比较的结果去控制输出。**

```text
        ┌─────────── 正向传输（放大） ───────────┐
        │                                        ↓
   x_i ──→ ⊕ ──→ x_id ──→ [ 基本放大电路 A ] ──→ x_o
           ↑ −                                    │
           │                                       │
           └──── x_f ←── [ 反馈网络 F ] ←───────────┘
                        反向传输（反馈）
```

四个基本量：

| 量 | 名称 | 含义 |
|---|---|---|
| x_i | 输入量 | 外加的输入信号 |
| x_id | 净输入量 | `x_id = x_i − x_f`，真正加在放大电路输入端的量 |
| x_o | 输出量 | 输出电压或输出电流 |
| x_f | 反馈量 | 从输出量取样、经反馈网络送回输入端的量 |

**判断「有没有反馈」的方法**：看输出回路与输入回路之间**是否存在除放大器件本身以外的连接通路**。若存在（例如从集电极接一个电阻回到基极），就有反馈；若输入回路与输出回路只通过三极管（或运放）本身耦合，则没有反馈。

**反馈元件**：承担反馈任务的元件（如跨接在输出与输入之间的电阻 R_f、电容 C_f）。

### 5.1.2 反馈的判断

#### （1）正反馈与负反馈——瞬时极性法

**瞬时极性法：假设输入信号在某一瞬间对地为正（标 ⊕），沿信号传输路径逐点判断各处的瞬时极性，最后看反馈回来的信号是削弱还是增强净输入。**

判断步骤：

1. 设输入端的瞬时极性为 ⊕（对地）。
2. 沿放大通路逐级标出各点的极性（共射/共源：集电极与基极反相；共集/共源漏：发射极与基极同相；运放：输出与同相端同相、与反相端反相）。
3. 判断反馈量 `x_f` 的极性。
4. 比较：若 `x_f` 使净输入 `x_id = x_i − x_f` **减小** → **负反馈**；若使 `x_id` **增大** → **正反馈**。

**一句话口诀**：**「反馈回来的信号与输入信号『唱反调』就是负反馈，『帮腔』就是正反馈」。**

| 反馈极性 | 对净输入的作用 | 效果 | 用途 |
|---|---|---|---|
| 负反馈 | 削弱 | 增益下降、性能改善 | 几乎所有放大电路 |
| 正反馈 | 增强 | 增益增大、易自激 | 振荡器（第 7 章） |

#### （2）交流反馈与直流反馈

**看反馈通路中是否有隔直电容：有电容 → 只反馈交流（交流反馈）；无电容且直流通路存在 → 直流反馈（或交直流都有）。**

| 类型 | 作用 | 典型例子 |
|---|---|---|
| 直流负反馈 | 稳定静态工作点 | 分压式偏置电路的 R_e（第 2 章） |
| 交流负反馈 | 改善动态性能（增益稳定性、带宽、失真、阻抗） | 射极跟随器、运放闭环电路 |
| 交直流负反馈 | 同时起两种作用 | 未加旁路电容的 R_e |

> **注意**：R_e 并联了旁路电容 C_e 后，交流被短路，只剩直流反馈（只稳 Q 点）；去掉 C_e 则同时有交流反馈（增益下降但性能改善）。

## 5.2 负反馈放大电路的四种基本组态

### 5.2.1 负反馈放大电路分析要点

**四种组态 = 「输出端取样什么量」（电压/电流）× 「输入端如何比较」（串联/并联）。**

| 取样方式 | 反馈量与什么成正比 | 稳定的是什么 |
|---|---|---|
| 电压反馈 | 与**输出电压** `u_o` 成正比 | 稳定输出电压（`R_o` 减小） |
| 电流反馈 | 与**输出电流** `i_o` 成正比 | 稳定输出电流（`R_o` 增大） |

| 比较方式 | 净输入量的形式 | 对输入电阻的影响 |
|---|---|---|
| 串联反馈 | `u_id = u_i − u_f`（电压相减） | `R_i` 增大 |
| 并联反馈 | `i_id = i_i − i_f`（电流相减） | `R_i` 减小 |

### 5.2.2 由集成运放组成的四种组态负反馈放大电路

| 组态 | 电路特征 | 闭环增益 | 稳定量 | R_i | R_o |
|---|---|---|---|---|---|
| **电压串联** | 输入接同相端，反馈接反相端，反馈网络取自输出端 | `A_uf = 1 + R_f/R_1` | 输出电压 | 增大 | 减小 |
| **电压并联** | 输入接反相端，反馈也接反相端（同一节点） | `A_uf = −R_f/R_1` | 输出电压 | 减小 | 减小 |
| **电流串联** | 输入接同相端，反馈取自负载电流（如 R_L 下端或 R_e） | `A_uf ≈ i_o/u_i`（互导） | 输出电流 | 增大 | 增大 |
| **电流并联** | 输入接反相端，反馈取自输出电流 | `A_uf ≈ i_o/i_i`（电流比） | 输出电流 | 减小 | 增大 |

```text
   电压串联（同相比例）            电压并联（反相比例）
        ┌──── R_f ────┐                ┌──── R_f ────┐
        │             │                │             │
   u_i ─┤+            │           R_1 ─┤−            │
        │   A      ───┴── u_o     u_i─┤   A      ───┴── u_o
   ┌────┤−                         ┌──┤+
   │    └─────────────┘            │  └─────────────┘
  R_1                             R_2(平衡电阻)
  （反馈接反相端=与输入不同节点→串联；取自输出端→电压）
```

### 5.2.3 反馈组态的判断

**这是本章乃至全书最常考的判断题，必须掌握两个可操作的测试方法。**

#### 方法一：输出短路法——判断电压反馈还是电流反馈

**把输出端交流短路（令 `u_o = 0`），若反馈信号随之消失（`x_f = 0`），则为电压反馈；若反馈信号依然存在，则为电流反馈。**

原理：电压反馈的 `x_f ∝ u_o`，`u_o = 0` 则 `x_f = 0`；电流反馈的 `x_f ∝ i_o`，短路后 `i_o` 依然存在（甚至更大），故 `x_f ≠ 0`。

**快捷判据**：看反馈网络的取样端是否**直接接在输出节点**上：

- 反馈元件接在**输出端（集电极/漏极/运放输出端）** → **电压反馈**
- 反馈元件接在**非输出节点（发射极/源极/负载电阻下端）** → **电流反馈**

#### 方法二：输入节点法——判断串联反馈还是并联反馈

**看反馈信号与输入信号是否接在同一个节点上：同一节点 → 并联反馈；不同节点 → 串联反馈。**

原理：并联反馈时，`i_i` 与 `i_f` 在同一节点上按 KCL 相减，净输入是**电流**；串联反馈时，`u_i` 与 `u_f` 分别加在放大器的两个输入端之间，净输入是**电压**。

**快捷判据**（以三极管为例）：

| 反馈信号接在哪里 | 与输入信号（接基极）的关系 | 组态 |
|---|---|---|
| 接**基极**（与输入同一节点） | 电流相加 | **并联** |
| 接**发射极**（与输入不同节点） | 电压相减 | **串联** |

**以运放为例**：

| 输入信号与反馈信号的位置 | 组态 |
|---|---|
| 都接在**反相输入端** | 并联 |
| 输入接**同相端**、反馈接**反相端**（或反之） | 串联 |

> **四步判断法（考试直接照做）**：
> ① 找反馈元件（跨接输出与输入之间的元件）；
> ② 用瞬时极性法判**正/负**；
> ③ 用**输出短路法**判**电压/电流**；
> ④ 用**输入节点法**判**串联/并联**。

**常见电路的组态速查**：

| 电路 | 组态 |
|---|---|
| 射极跟随器（共集） | 电压串联负反馈 |
| 共射电路，R_e 未加旁路电容 | 电流串联负反馈 |
| 共射电路，R_f 从集电极接到基极 | 电压并联负反馈 |
| 反相比例运算电路 | 电压并联负反馈 |
| 同相比例运算电路 | 电压串联负反馈 |
| 两级放大、R_f 从末级发射极接回第一级发射极 | 电流串联负反馈 |

## 5.3 负反馈放大电路的方块图及一般表达式

### 5.3.1 负反馈放大电路的方块图表示法

```text
   x_i ──→ ⊕ ──→ x_id ──→ [ A ] ──→ x_o
           ↑−                          │
           │                           │
           └──── x_f ←─── [ F ] ←──────┘
```

- `A = x_o/x_id`：**开环增益**（基本放大电路的增益）
- `F = x_f/x_o`：**反馈系数**（反馈网络的传输比）
- `A_f = x_o/x_i`：**闭环增益**

### 5.3.2 四种组态电路的方块图

四种组态的差别只在于 `A`、`F`、`A_f` 的**量纲**不同，但一般表达式完全相同：

| 组态 | x_i / x_o / x_f 的形式 | A 的名称与量纲 | F 的量纲 | A_f 的量纲 |
|---|---|---|---|---|
| 电压串联 | 电压 / 电压 / 电压 | 电压增益（V/V） | V/V | V/V |
| 电压并联 | 电流 / 电压 / 电流 | 互阻增益（V/A） | A/V | V/A |
| 电流串联 | 电压 / 电流 / 电压 | 互导增益（A/V） | V/A | A/V |
| 电流并联 | 电流 / 电流 / 电流 | 电流增益（A/A） | A/A | A/A |

### 5.3.3 负反馈放大电路的一般表达式

由 `x_id = x_i − x_f`、`x_o = A x_id`、`x_f = F x_o` 三式联立：

`x_o = A(x_i − F x_o)` → `x_o(1 + AF) = A x_i`

**`A_f = A/(1 + AF)`**

| `1 + AF` | 名称 | 反馈性质 |
|---|---|---|
| `> 1` | 反馈深度 | **负反馈**（闭环增益小于开环增益） |
| `= 1` | — | 无反馈 |
| `0 < 1+AF < 1` | — | **正反馈**（闭环增益大于开环增益） |
| `= 0` | — | **自激振荡**（有输入无输入都有输出） |
| `< 0` | — | 已进入自激状态 |

**`1+AF` 是本章最重要的一个量**：它既表示负反馈的强弱，又直接决定了增益稳定性提高的倍数、输入/输出电阻变化的倍数、通频带展宽的倍数。

**深度负反馈**：当 `|1+AF| >> 1`（一般 ≥10）时，

`A_f = A/(1+AF) ≈ A/(AF) = 1/F`

**结论：深度负反馈下，闭环增益只由反馈网络决定，与基本放大电路无关。** 这是负反馈最重要的价值——用**精确的无源元件（电阻）**去控制**不精确的有源器件（管子）**的性能。

## 5.4 深度负反馈放大电路放大倍数的分析

### 5.4.1 深度负反馈的实质

**深度负反馈时 `x_id ≈ 0`，即「净输入量近似为零」。**

- 对**串联**负反馈：`u_id = u_i − u_f ≈ 0` → **`u_f ≈ u_i`（输入端电压近似相等，即「虚短」）**
- 对**并联**负反馈：`i_id = i_i − i_f ≈ 0` → **`i_f ≈ i_i`（输入端电流近似相等，即「虚断」）**

### 5.4.2 反馈网络的分析

分析反馈网络的要点：**只考虑反馈网络对输出量的取样和对输入端的送回，忽略其「负载效应」**（在深度负反馈下，反馈网络对基本放大电路的影响可以并入 A 中）。

### 5.4.3 基于反馈系数的放大倍数分析

步骤：① 判断组态；② 写出 `F = x_f/x_o`；③ 由 `A_f ≈ 1/F` 得闭环增益。

**例（电压串联，同相比例运算电路）**：反馈网络由 `R_1`、`R_f` 组成，`u_f = u_o · R_1/(R_1+R_f)`，故 `F = R_1/(R_1+R_f)`，于是

`A_uf ≈ 1/F = 1 + R_f/R_1`

### 5.4.4 基于理想运放的放大倍数分析

**把运放看成理想运放，直接用「虚短」和「虚断」列方程，这是考试中最快的解法。**

- **虚短**：`u_P = u_N`（由 `A_od = ∞` 且 `u_o` 有限推出）
- **虚断**：`i_P = i_N = 0`（由 `r_id = ∞` 推出）

**注意：虚短虚断只在「运放工作在线性区 + 引入负反馈」时才成立。** 若运放工作在饱和区（作比较器），只有虚断成立，虚短不成立。

## 5.5 负反馈对放大电路性能的影响

### 5.5.1 稳定放大倍数

**闭环增益的相对变化量是开环增益相对变化量的 `1/(1+AF)`。**

`dA_f/A_f = [1/(1+AF)] · (dA/A)`

例如 `1+AF = 100`，则开环增益变化 10% 时闭环增益只变化 0.1%。**这就是「用电阻的精度换取增益的精度」。**

### 5.5.2 改变输入电阻和输出电阻

**这是必考表格，必须记牢方向。**

| 反馈组态 | 输入电阻 R_i | 输出电阻 R_o |
|---|---|---|
| 串联负反馈 | **增大**到 `(1+AF)R_i` | 由取样方式决定 |
| 并联负反馈 | **减小**到 `R_i/(1+AF)` | 由取样方式决定 |
| 电压负反馈 | 由比较方式决定 | **减小**到 `R_o/(1+AF)` |
| 电流负反馈 | 由比较方式决定 | **增大**到 `(1+AF)R_o` |

**综合结论（四句话记住）**：

1. **串联 → 输入电阻增大**；**并联 → 输入电阻减小**。
2. **电压 → 输出电阻减小**；**电流 → 输出电阻增大**。
3. **原因**：串联负反馈的净输入是电压，`u_i` 一定时 `u_f` 越大则输入电流越小 → 等效输入电阻大；电压负反馈稳定输出电压 → 输出端等效为一个恒压源 → `R_o` 小。
4. **注意**：上述变化只发生在**反馈环内**；环外的偏置电阻（如 R_b）不受影响。

**组合速查**：

| 组态 | R_i | R_o | 典型用途 |
|---|---|---|---|
| 电压串联 | 大 | 小 | 电压放大器（理想的电压放大） |
| 电压并联 | 小 | 小 | 互阻放大器（I→V 转换） |
| 电流串联 | 大 | 大 | 互导放大器（V→I 转换） |
| 电流并联 | 小 | 大 | 电流放大器 |

### 5.5.3 展宽频带

**负反馈使上限截止频率提高 `(1+AF)` 倍，下限截止频率降低 `(1+AF)` 倍，通频带展宽 `(1+AF)` 倍，但增益带宽积不变。**

`f_Hf = (1+AF) f_H`，`f_Lf = f_L/(1+AF)`

`BW_f = (1+AF) BW`，`A_uf · BW_f = A_u · BW`（常数）

> **这与第 4 章的增益带宽积结论完全一致**：负反馈把增益降下来，把带宽换上去，GBW 这个「守恒量」不变。

### 5.5.4 减小非线性失真

**负反馈不能消除失真，但能把失真减小到 `1/(1+AF)`。**

原理：设开环时输出有失真（正半周被压缩），反馈回来的信号也带有同样的失真，与输入相减后，净输入信号被「预失真」——正半周变大，正好补偿了放大电路的压缩。这叫**用预失真抵消失真**。

**前提条件**：输入信号本身不能引起削波（若输出已经进入饱和/截止，负反馈无能为力，甚至会因「堵塞」而恶化）。

### 5.5.5 放大电路中引入负反馈的一般原则

| 想要达到的目的 | 应引入的反馈 |
|---|---|
| 稳定静态工作点 | **直流**负反馈 |
| 稳定输出电压（带负载能力强） | **电压**负反馈 |
| 稳定输出电流 | **电流**负反馈 |
| 提高输入电阻 | **串联**负反馈 |
| 降低输入电阻 | **并联**负反馈 |
| 降低输出电阻 | **电压**负反馈 |
| 提高输出电阻 | **电流**负反馈 |
| 信号源为**电压源**（内阻小） | 宜用**串联**负反馈（否则 R_i 大也无意义） |
| 信号源为**电流源**（内阻大） | 宜用**并联**负反馈 |

> **一句总结**：**「稳什么取什么，要什么接什么」**——想稳定输出电压就取电压反馈，想提高输入电阻就用串联。

## 5.6 负反馈放大电路的稳定性

### 5.6.1 负反馈放大电路自激振荡产生的原因和条件

**自激振荡（self-excitation）：输入信号为零时，输出端仍有某个频率的稳定振荡。**

原因：负反馈电路在高频（或低频）时，由于结电容、耦合电容引入**附加相移**，使原本的负反馈变成了正反馈。

**自激振荡条件**：`AF = −1`，即

| 条件 | 表达式 | 含义 |
|---|---|---|
| **幅度条件** | `\|AF\| = 1` | 环路增益为 1，信号能维持不衰减 |
| **相位条件** | `φ_A + φ_F = ±180°`（附加相移） | 负反馈变成正反馈 |

**两个条件同时满足才自激**：只满足相位条件而 `|AF| < 1` 只会衰减振荡；只满足幅度条件而相位不对不会形成正反馈。

> **单级放大电路不会自激**（附加相移最多 −90°，达不到 −180°）；**三级及以上的放大电路容易自激**（每级最大 −90°，三级可达 −270°，中间必经过 −180°）。

### 5.6.2 负反馈放大电路稳定性的定性分析

| 级数 | 最大附加相移 | 是否可能自激 |
|---|---|---|
| 一级 | −90° | 不可能 |
| 二级 | −180°（极限） | 理论上临界，实际因相位不到 −180° 而稳定 |
| 三级及以上 | −270° 或更多 | **可能自激** |

### 5.6.3 负反馈放大电路稳定性的判断

**用环路增益 `AF` 的波特图判断：找出附加相移为 −180° 的频率 `f_0`，若该频率处 `|AF| < 1`（即 20 lg|AF| < 0 dB），则稳定。**

**相位裕度（phase margin）**：在 `|AF| = 1`（0 dB）的频率 `f_c` 处，

`γ = 180° − |φ_A(f_c) + φ_F(f_c)|`

| 相位裕度 | 稳定性 |
|---|---|
| `γ > 45°` | 稳定，且有一定余量 |
| `γ = 45°` | 工程上的临界值 |
| `γ = 0°` | 临界自激 |
| `γ < 0°` | 已自激 |

**工程经验**：设计时至少留 45° 相位裕度，最好 60°。

### 5.6.4 负反馈放大电路自激振荡的消除方法

| 方法 | 做法 | 原理 |
|---|---|---|
| 减小反馈深度 | 增大 `1+AF` 中的分母（减小 F） | 使 `\|AF\| = 1` 的频率提前，避开 −180° |
| **滞后补偿**（最简单） | 在运放内部（或外部）接一个大电容 C，使主极点频率降低 | 让增益提前下降，在 −180° 之前就降到 0 dB |
| **超前补偿** | 加 RC 串联网络，引入一个超前相位 | 用零点抵消部分滞后相位 |
| **RC 补偿** | 在反馈支路中接 RC 网络 | 同时调整幅频与相频 |
| 选低 f_T 的管子/运放 | 减少级数或选 f_T 低的器件 | 从源头减少附加相移 |

**滞后补偿的代价**：通频带变窄（因为主极点频率被压低）。这又是一次「稳定性换带宽」的折中。

### 5.6.5 集成运放的频率响应和频率补偿

集成运放内部为获得高增益而采用多级放大，开环时极易自激，所以**厂家已在内部做了补偿**（如 μA741 的内部 30 pF 电容），这类运放称为**内补偿运放**，可以任意闭环使用。有些高速运放需要外接补偿电容，使用时必须按手册接线。

## 5.7 放大电路中其它形式的反馈

### 5.7.1 放大电路中的正反馈

正反馈并非一无是处：**正弦波振荡电路（第 7 章）就是有意引入正反馈**，使 `AF = 1` 且相位满足，从而在没有输入信号时也能产生稳定的正弦波输出。

| 应用 | 反馈极性 | 目的 |
|---|---|---|
| 放大电路 | 负反馈 | 改善性能 |
| 振荡电路 | 正反馈 | 产生信号 |
| 施密特触发器（滞回比较器） | 正反馈 | 加快翻转速度、形成回差 |

### 5.7.2 电流反馈运算放大电路

**电流反馈运放（CFA）的反馈信号是电流，其闭环带宽几乎与闭环增益无关，因此适合高频、大增益的场合。**

特点：① 反相输入端是低阻输入（缓冲器），同相输入端是高阻输入；② 反馈必须用电阻（不能用电容直接反馈）；③ 转换速率 SR 极高（可达几千 V/μs）。

## 典型例题

**例 5.1**（题型：反馈极性判断——瞬时极性法）
共射放大电路，`R_f` 从集电极接到基极，判断反馈极性。

**解**：
设基极瞬时极性为 ⊕。
共射电路集电极与基极**反相**，故集电极（`R_f` 的上端）为 ⊖。
`R_f` 把集电极电位引回基极，反馈量使基极电位**下降**。
净输入 `u_id = u_i − u_f`：`u_f` 与 `u_i` 反号，故 `u_id` **减小**。

**答案**：**负反馈**（电压并联负反馈）。

**例 5.2**（题型：反馈组态判断——输出短路法 + 输入节点法）
在例 5.1 的基础上，判断是电压反馈还是电流反馈、串联还是并联。

**解**：
**输出短路法**：把输出端（集电极）交流短路，`u_o = 0`，则 `R_f` 送回基极的反馈信号为 0 → 反馈信号消失 → **电压反馈**。
**输入节点法**：反馈信号接在**基极**，与输入信号（也接基极）**同一节点** → **并联反馈**。

**答案**：**电压并联负反馈**。
**验证**：这正是反相比例运算电路的三极管版本，其 `R_o` 减小、`R_i` 减小，符合表中「电压并联」一栏。

**例 5.3**（题型：反馈组态判断——共射电路带未旁路 R_e）
某共射放大电路，`R_e` 两端**没有**旁路电容，输入信号加在基极。判断组态。

**解**：
**有无反馈**：`R_e` 把发射极电流的变化转换成电压送回输入回路 → 有反馈。
**极性**：设基极 ⊕ → 集电极 ⊖ → 发射极 ⊕（发射极跟随基极）→ `u_f = u_e` 使 `u_id = u_be = u_i − u_e` **减小** → **负反馈**。
**输出短路法**：把输出端（集电极）短路，`u_o = 0`，但 `i_e` 依然存在（`i_e ≈ i_c`），`u_f = i_e R_e` 依然存在 → **电流反馈**。
**输入节点法**：反馈信号接在**发射极**，与输入（基极）**不同节点** → **串联反馈**。

**答案**：**电流串联负反馈**。它使 `R_i` 增大、`R_o` 增大，增益稳定但电压增益下降。

**例 5.4**（题型：射极跟随器的反馈组态）
共集放大电路（射极跟随器），输出取自发射极。判断组态。

**解**：
**极性**：设基极 ⊕ → 发射极 ⊕（同相）→ `u_f = u_e ≈ u_o` 使 `u_be = u_i − u_e` 减小 → **负反馈**。
**输出短路法**：输出端（发射极）短路，`u_o = 0` → 反馈信号消失 → **电压反馈**。
**输入节点法**：反馈接在发射极，与输入（基极）不同节点 → **串联反馈**。

**答案**：**电压串联负反馈**（反馈系数 `F = 1`，即 100% 电压串联负反馈）。
**这就是射极跟随器 `A_u ≈ 1`、`R_i` 大、`R_o` 小的根本原因**——它是最深度的电压串联负反馈。

**例 5.5**（题型：闭环增益与反馈深度）
某放大电路开环增益 `A = 10^4`，反馈系数 `F = 0.01`。求反馈深度、闭环增益，以及开环增益变化 10% 时闭环增益的变化率。

**解**：
反馈深度 `1 + AF = 1 + 10^4 × 0.01 = 1 + 100 = 101`
闭环增益 `A_f = A/(1+AF) = 10^4/101 = 99.0`
（深度负反馈近似：`A_f ≈ 1/F = 1/0.01 = 100`，误差 1%）
增益稳定性：`dA_f/A_f = (1/101) × 10% = 0.099%`

**答案**：反馈深度 101，`A_f = 99.0`，增益变化率仅 0.099%（比开环改善 101 倍）。

**例 5.6**（题型：深度负反馈求闭环增益——同相比例运算电路）
理想运放构成同相比例运算电路，`R_1 = 10 kΩ` 接在反相端与地之间，`R_f = 100 kΩ` 接在反相端与输出之间，输入加在同相端。求 `A_uf`。

**解**：
**用反馈系数法**：`u_f = u_o · R_1/(R_1+R_f)`，`F = R_1/(R_1+R_f) = 10/110 = 0.0909`
`A_uf ≈ 1/F = 1 + R_f/R_1 = 1 + 100/10 = 11`
**用虚短虚断验证**：
虚断 → `R_1` 与 `R_f` 中流过同一电流 `i`；虚短 → `u_N = u_P = u_i`
`i = u_i/R_1`，`u_o = u_i + i R_f = u_i(1 + R_f/R_1) = 11 u_i` ✓

**答案**：`A_uf = 11`（同相，电压串联负反馈）。

**例 5.7**（题型：深度负反馈求闭环增益——反相比例运算电路）
理想运放构成反相比例运算电路，`R_1 = 10 kΩ`（输入端到反相端），`R_f = 100 kΩ`（反相端到输出），同相端接地。求 `A_uf`。

**解**：
虚短 → `u_N = u_P = 0`（**虚地**）；虚断 → 流过 `R_1` 的电流全部流入 `R_f`：
`i = u_i/R_1`，`u_o = −i R_f = −u_i R_f/R_1`
`A_uf = −R_f/R_1 = −100/10 = −10`

**答案**：`A_uf = −10`（反相，电压并联负反馈）。
**注意组态差别**：同相输入是**串联**（`R_i → ∞`），反相输入是**并联**（`R_i = R_1`，很小）。

**例 5.8**（题型：负反馈对输入输出电阻的影响）
某放大电路 `R_i = 2 kΩ`、`R_o = 5 kΩ`、`1+AF = 100`。分别求下列组态下的闭环输入、输出电阻：
(a) 电压串联；(b) 电压并联；(c) 电流串联；(d) 电流并联。

**解**：
(a) 电压串联：`R_if = (1+AF)R_i = 100 × 2 kΩ = 200 kΩ`；`R_of = R_o/(1+AF) = 5 kΩ/100 = 50 Ω`
(b) 电压并联：`R_if = R_i/(1+AF) = 2 kΩ/100 = 20 Ω`；`R_of = 50 Ω`
(c) 电流串联：`R_if = 200 kΩ`；`R_of = (1+AF)R_o = 100 × 5 kΩ = 500 kΩ`
(d) 电流并联：`R_if = 20 Ω`；`R_of = 500 kΩ`

**答案**：见上。**规律：串联放大 100 倍、并联缩小 100 倍；电压缩小 100 倍、电流放大 100 倍。**

**例 5.9**（题型：负反馈展宽频带）
某放大电路 `A_u = 10^4`、`f_L = 100 Hz`、`f_H = 10 kHz`。引入 `F = 0.01` 的负反馈后，求 `A_uf`、`f_Lf`、`f_Hf`、`BW_f`，并验证增益带宽积不变。

**解**：
`1 + AF = 1 + 10^4 × 0.01 = 101`
`A_uf = 10^4/101 = 99.0`
`f_Lf = f_L/(1+AF) = 100/101 = 0.99 Hz`
`f_Hf = (1+AF)f_H = 101 × 10 kHz = 1010 kHz = 1.01 MHz`
`BW_f = 1.01 MHz − 0.99 Hz ≈ 1.01 MHz`（原 `BW = 10 kHz − 100 Hz = 9.9 kHz`）
验证：`A_u · BW = 10^4 × 9.9 kHz = 9.9×10^7 Hz`；`A_uf · BW_f = 99 × 1.01×10^6 = 1.0×10^8 Hz` ✓ 基本相等

**答案**：`A_uf = 99`，`f_Lf ≈ 0.99 Hz`，`f_Hf = 1.01 MHz`，带宽展宽约 102 倍，增益带宽积不变。

**例 5.10**（题型：稳定性判断与相位裕度）
某负反馈放大电路的环路增益波特图显示：在 `f = 10^5 Hz` 处 `20 lg|AF| = 0 dB`，该频率处的附加相移为 −135°；在 `f = 10^6 Hz` 处附加相移达到 −180°，此处 `20 lg|AF| = −20 dB`。判断电路是否稳定，求相位裕度。

**解**：
**判据一（找 −180° 处的增益）**：附加相移 −180° 出现在 `f = 10^6 Hz`，此处 `20 lg|AF| = −20 dB < 0 dB` → **稳定**。
**判据二（相位裕度）**：`|AF| = 1`（0 dB）的频率是 `f_c = 10^5 Hz`，该处相移 −135°：
`γ = 180° − 135° = 45°`

**答案**：电路稳定，相位裕度 45°（处于工程临界值，实际设计应留 60°）。
**若把反馈系数 F 增大 10 倍**，则 `|AF| = 1` 的频率右移到约 `10^6 Hz`，此时相移已达 −180°，相位裕度为 0° → **临界自激**。

**例 5.11**（题型：负反馈减小非线性失真）
某放大器开环时输出波形的非线性失真系数为 10%，`1+AF = 50`。求闭环后的失真系数。

**解**：
`γ_f = γ/(1+AF) = 10%/50 = 0.2%`

**答案**：失真系数降到 0.2%。**前提是输入信号不足以使放大器进入饱和或截止状态。**

## 易错点提醒

1. **把「有反馈」等同于「有反馈元件」** → 有些元件（如 R_e）本身不是反馈元件，但它上面的电压被送回输入回路时就成了反馈通路；判断依据是「输出回路是否与输入回路有连接」。
2. **瞬时极性法逐点时忘记共射反相** → 共射/共源电路：输入与输出**反相**；共集/共漏：**同相**；运放：输出与同相端同相、与反相端反相。
3. **输出短路法短路的是「输出端」而不是「负载」** → 是把输出节点（集电极/运放输出端）对交流接地，不是把 R_L 拿掉。
4. **把电压反馈与电流反馈的判断和「输出端接什么」混为一谈** → 关键看**取样点**：接在输出节点上是电压反馈，接在发射极/源极等非输出节点上是电流反馈。
5. **把串联/并联的判断看成「输入是电压还是电流」** → 关键看**反馈信号与输入信号是否接在同一节点**：同节点为并联，不同节点为串联。
6. **认为电流反馈的输出电阻减小** → 恰恰相反，**电流反馈使输出电阻增大**（稳定输出电流，等效为恒流源）。
7. **认为负反馈能提高增益** → 负反馈一定使增益下降 `(1+AF)` 倍；提高的是增益的**稳定性**。
8. **在深度负反馈中用 `A_f = A/(1+AF)` 精算而不做近似** → 深度负反馈（`1+AF ≥ 10`）时直接用 `A_f ≈ 1/F`，更快也更符合题意。
9. **把自激振荡的幅度条件写成 `|AF| > 1`** → 自激的**临界条件**是 `|AF| = 1`；`|AF| > 1` 时振荡幅度会不断增长直到受非线性限制，但判断稳定性的依据仍是 `|AF| = 1` 的频率与 −180° 频率的关系。
10. **认为单级放大电路也会自激** → 单级最大附加相移 −90°，不可能满足 −180° 的相位条件；三级以上才可能。
11. **忘记虚短虚断的适用条件** → 只在「运放工作在线性区 + 存在负反馈」时成立；比较器电路中虚短不成立。

## 本章小结

- 反馈 = 把输出量的一部分送回输入端；判断有无反馈看「输出回路与输入回路之间是否有除放大器件外的连接」。
- **瞬时极性法**判正负反馈：反馈信号削弱净输入为负反馈，增强为正反馈。
- **输出短路法**判电压/电流反馈：输出短路后反馈消失为电压反馈，反馈仍存在为电流反馈。
- **输入节点法**判串联/并联反馈：反馈与输入接同一节点为并联，不同节点为串联。
- 一般表达式 `A_f = A/(1+AF)`；`1+AF` 称为反馈深度，它同时决定增益稳定性、阻抗变化与带宽展宽的倍数。
- 深度负反馈 `A_f ≈ 1/F`，实质是 `x_id ≈ 0`，对运放即**虚短 + 虚断**。
- 负反馈对性能的影响：稳定增益 `(1+AF)` 倍、串联增大 R_i、并联减小 R_i、电压减小 R_o、电流增大 R_o、带宽展宽 `(1+AF)` 倍、失真减小 `(1+AF)` 倍、GBW 不变。
- 引入原则：**稳什么取什么（电压/电流），要什么接什么（串联/并联）**。
- 自激条件：幅度 `|AF| = 1`，相位附加相移 ±180°；三级以上才可能自激。
- 稳定性判据：−180° 处 `|AF| < 1` 或相位裕度 `γ > 45°`。
- 补偿方法：减小反馈深度、滞后补偿、超前补偿、RC 补偿。

> **一句话记住本章**：**反馈就是「拿输出的一部分回来跟输入比一比」；负反馈用降低增益换取稳定、带宽和阻抗特性，而深度负反馈让电路的性能只取决于几个电阻的比值。**

## 自测题

1. 什么叫反馈？净输入量与输入量、反馈量的关系是什么？
2. 用瞬时极性法判断反馈极性的步骤是什么？
3. 如何判断电压反馈与电流反馈？如何判断串联反馈与并联反馈？
4. 写出闭环增益的一般表达式，并说明 `1+AF` 的三种取值分别对应什么状态。
5. 深度负反馈的实质是什么？对运放电路而言等价于哪两条结论？
6. 某电路 `A = 10^5`、`F = 0.001`，求 `1+AF`、`A_f` 及开环增益变化 20% 时闭环增益的变化率。
7. 电压串联负反馈对 `R_i`、`R_o` 各有什么影响？为什么？
8. 负反馈使通频带展宽多少倍？增益带宽积是否改变？
9. 自激振荡的幅度条件和相位条件是什么？为什么单级放大电路不会自激？
10. 什么是相位裕度？工程上要求至少多少？

**自测题答案**

1. 把输出量的一部分或全部通过反馈网络送回输入端与输入量比较；`x_id = x_i − x_f`。
2. ① 设输入端瞬时极性为 ⊕；② 沿放大通路逐点标极性（共射反相、共集同相、运放输出与同相端同相）；③ 判断反馈量极性；④ 若使净输入减小则为负反馈。
3. 电压/电流：把输出端交流短路，反馈消失为电压反馈，仍存在为电流反馈（或看取样点是否在输出节点）。串联/并联：看反馈信号与输入信号是否接在同一节点，同节点为并联，不同节点为串联。
4. `A_f = A/(1+AF)`；`1+AF > 1`（即 `AF > 0`）为负反馈，`1+AF = 1`（即 `AF = 0`）为无反馈，`0 < 1+AF < 1`（即 `−1 < AF < 0`）为正反馈但尚未自激，`1+AF = 0`（即 `AF = −1`）为自激振荡的临界（等幅振荡），`1+AF < 0`（即 `AF < −1`）则已自激。
5. 实质是净输入量近似为零（`x_id ≈ 0`）；对运放等价于**虚短**（`u_P = u_N`）与**虚断**（`i_P = i_N = 0`）。
6. `1+AF = 1 + 100 = 101`；`A_f = 10^5/101 = 990`；变化率 `= 20%/101 = 0.198%`。
7. `R_i` 增大到 `(1+AF)R_i`（串联使净输入为电压，输入电流减小）；`R_o` 减小到 `R_o/(1+AF)`（电压反馈稳定输出电压，等效为恒压源）。
8. 展宽 `(1+AF)` 倍（`f_H` 提高、`f_L` 降低）；增益带宽积不变。
9. 幅度条件 `|AF| = 1`，相位条件附加相移 ±180°；单级放大电路最大附加相移只有 −90°，无法达到 −180°。
10. `|AF| = 1`（0 dB）处的相移距 −180° 的余量，`γ = 180° − |φ|`；工程上要求至少 45°。
