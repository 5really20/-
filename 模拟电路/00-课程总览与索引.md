# 模拟电路 · 课程总览与索引

> 一句话定位：**模拟电路研究的是「连续变化的电压/电流如何被放大、运算、比较、产生和稳定」**。它用十几个元件（电阻、电容、二极管、三极管、运放）搭出整个电子系统的前端——传感器出来的微弱信号（μV 级）要放大到能被芯片识别的伏特级，靠的就是这门课的全部内容。

> **先修课已经给你的工具（本笔记直接用，不再重讲）**：基尔霍夫电压/电流定律（KVL/KCL）、戴维南与诺顿等效、叠加定理、一阶/二阶动态电路的暂态分析、正弦稳态的相量法与阻抗。
> 这门课新加的只有三件事：**非线性元件**（二极管、三极管、场效应管）、**受控源与等效模型**（把非线性元件在小信号下线性化）、**反馈**（把输出引回来控制输入）。
>
> 对计算机专业的同学：这门课在电类课程里通常是最难的一门，难在「图多、近似多、同一个电路要算两遍（直流一遍、交流一遍）」。抓住下面这条主线就不会乱：**任何放大电路 = 直流供电让管子工作在放大区（Q 点）+ 交流信号在等效电路里被放大（增益、输入输出电阻、频带）。**

## 六、学习路线（48 学时讲授的建议节奏）

**第一阶段：器件与单管放大（约 20 学时，对应第 0~2 章）**
目标是拿到任何一张单管电路图，都能独立完成「先直流、后交流」两遍计算。
关键动作：把「直流通路怎么画（电容开路、电感短路）」「交流通路怎么画（直流电源接地、电容短路）」练成条件反射，这是后面所有章节的地基。

**第二阶段：集成化与分析工具（约 18 学时，对应第 3~5 章）**
从「一个管子」走向「一个芯片」：多级耦合 → 差分放大解决零点漂移 → 电流源提供稳定偏置 → 频率响应决定带宽 → 反馈决定增益精度。
关键动作：反馈组态判断要动手画「输出短路」「输入节点」两个测试，不要靠背。

**第三阶段：应用电路（约 10 学时，对应第 6~10 章）**
运算、产生、功放、电源四大应用，本质都是「第二阶段搭好的积木」的组合。读图时永远先找运放/管子，再找反馈支路，最后找负载。

## 七、符号约定

| 符号 | 含义 |
|---|---|
| u、i | 瞬时值（随时间变化，小写字母） |
| U、I | 直流量或正弦量的有效值（大写字母） |
| U_Q、I_CQ | 下标含 Q 表示静态工作点（Quiescent point）的值 |
| u_i、u_o | 输入、输出信号电压 |
| ∥ | 并联（如 R_C∥R_L 表示两电阻并联后的等效阻值） |
| A_u、A_i | 电压增益、电流增益（无量纲，工程上常用分贝 dB 表示） |
| f_L、f_H、BW | 下限截止频率、上限截止频率、通频带 |
| A、F、A_f | 开环增益、反馈系数、闭环增益 |
| U_T | 温度的电压当量，常温（300 K）约 26 mV |

**贯穿全书的两个思维习惯**

1. **先直流、后交流**：直流（Q 点）决定管子能不能放大；交流（微变等效）决定放大得怎么样。算错了 Q 点，后面全错。
2. **先看反馈、再看电路**：任何带运放的电路，先判断它引入的是正反馈还是负反馈、是电压还是电流反馈，再动笔算，能省一半工作量。

> **实测时间**：2026-10-08｜**实测方法**：查安装目录 + 逐条过注册表卸载项（全机 72 项）+ `Get-Command` 查 PATH

| 软件 | 本机状态 | 影响与替代方案 |
|---|---|---|

| Proteus | **未安装** | 同上；Proteus 偏数字与单片机仿真，本课程用得比 Multisim 少 |
| MATLAB | **未安装** | 本笔记全部数值都能用 Python 复核，不必依赖 MATLAB |
| PSpice / LTspice | **未安装** | 想在自己电脑上练，见下面第 3 条 |
| Python 3.14.7 | **已安装** | 手算结果的数值验算（Q 点、`r_be`、`A_u`、截止频率）几行代码就能复核 |
| Anaconda3 2026.07-1 | **已安装** | 路径 `D:\dev\Anaconda`（Python 3.14.6），自带 `numpy 2.4.6`、`scipy 1.18.0`、`matplotlib 3.11.0`，画幅频特性与波形足够用 |

**没有仿真软件，这门课照样能学好**

1. **手算是主线，仿真只是验证。** 本笔记每道例题都给足了「先直流、后交流」的完整手算过程。考试是闭卷笔试，不会给你 Multisim；把 Q 点和微变等效电路练成条件反射，比会点鼠标重要得多。
2. **实验课的仿真环节去机房做。** [附录C](附录C-实验指导与实验报告要点.md) 的 C.11 已经把 Multisim 的操作步骤写全了（画图 → 设参数 → 放虚拟仪器 → 跑直流工作点/瞬态/交流扫描 → 读数与手算对比），照着做即可，本机不需要预装。
3. **想在自己电脑上练，装 LTspice 最划算。** 它是 ADI（原 Linear Technology）的官方免费软件，体积小、无授权问题，能做**直流工作点、瞬态、交流扫描**三类分析，覆盖本课程绝大部分仿真需求；代价是虚拟仪器界面不如 Multisim 直观，符号与网表要自己搭。
4. **纯数值验算用 Python。** 例如共射电路的 `U_BQ`、`I_CQ`、`r_be`、`A_u`，写成几行 Python 比手算快，还能顺手扫参数看趋势（比如「`R_b1` 增大时 `U_BQ` 到底是升还是降」——这正是[附录C](附录C-实验指导与实验报告要点.md) 里最容易记反的一处）。
