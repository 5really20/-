## 1.1 半导体基础知识

### 1.1.1 本征半导体

**本征半导体是纯净的、具有完整晶体结构的半导体（硅 Si、锗 Ge 最常用），其导电能力由「本征激发」产生的电子－空穴对决定。**

硅、锗都是四价元素，每个原子与周围四个原子形成共价键。室温下热运动使少量价电子挣脱共价键成为**自由电子**，同时在原位留下一个**空穴**——两者成对产生，称为**电子－空穴对**。自由电子和空穴都能运载电荷，称为**载流子**（carrier）。

两个关键结论：

1. **本征半导体中自由电子数 = 空穴数**，两种载流子浓度都很低（室温下硅约 `1.5 × 10^10 /cm³`，而硅原子本身约 `5 × 10^22 /cm³`），所以本征半导体导电能力很弱。
2. **本征激发由温度决定**：温度升高，载流子浓度迅速增加，导电能力上升。这解释了后面所有器件的「温度漂移」问题——**半导体器件天生对温度敏感**。

### 1.1.2 杂质半导体

**掺入微量杂质可以成千上万倍地提高导电能力，并人为制造出「电子多」或「空穴多」两种半导体。**

| 类型 | 掺入杂质 | 多数载流子（多子） | 少数载流子（少子） | 多子来源 |
|---|---|---|---|---|
| N 型 | 五价元素（磷 P、砷 As） | 自由电子 | 空穴 | 掺杂浓度决定 |
| P 型 | 三价元素（硼 B、铝 Al） | 空穴 | 自由电子 | 掺杂浓度决定 |

- **N 型半导体**：五价原子与周围四个硅原子成键后多出一个电子，很容易成为自由电子，同时留下不能移动的正离子。电子是**多子**，空穴是**少子**。
- **P 型半导体**：三价原子少一个电子，形成共价键时产生一个空位，很容易捕获电子从而产生空穴。空穴是**多子**，电子是**少子**。

> **最容易错的一句话：杂质半导体整体仍是电中性的。** 掺入的杂质原子本身不带电，只是提供可以移动的载流子和不能移动的离子，正负电荷总量相等。

**多子浓度由掺杂浓度决定，几乎不随温度变化；少子浓度由本征激发决定，对温度极其敏感。** 记住这条，就能理解后面所有的温度漂移、少子导电（如三极管集电结反向电流 I_CBO）为什么都是「温度的晴雨表」。

### 1.1.3 PN 结

**把 P 型与 N 型半导体做在一起，交界处形成 PN 结；PN 结的基本特性是单向导电性。**

形成过程（四步，理解即可）：

```text
        P 区            │← 空间电荷区 →│            N 区
   ○ ○ ○ ○ ○ ○ ○   ┃  ⊖ ⊖ ⊖ ⊕ ⊕ ⊕  ┃   ● ● ● ● ● ● ●
   ○=空穴(多子)     ┃  耗尽层(内电场E) ┃   ●=自由电子(多子)
        ←── 扩散 ────┃───  漂移  ──→
   多子向对方扩散形成空间电荷区，其内电场阻碍扩散、促进漂移，二者平衡
```

1. **扩散**：P 区空穴向 N 区扩散，N 区电子向 P 区扩散（浓度差驱动）。
2. **形成空间电荷区**：扩散走的区域留下不能移动的离子，形成**耗尽层**（空间电荷区）。
3. **产生内电场**：内电场方向由 N 区指向 P 区，阻碍多子扩散、帮助少子漂移。
4. **达到动态平衡**：扩散与漂移相等，空间电荷区宽度稳定（硅约零点几微米）。

两个性质：

- **单向导电性**：外加**正向电压**（P 接正、N 接负）削弱内电场 → 空间电荷区变窄 → 扩散加强 → **电流大、导通**；外加**反向电压**加强内电场 → 空间电荷区变宽 → 只剩少子漂移 → **电流极小、截止**。
- **电容效应**：空间电荷区宽度随外加电压变化 → 等效为**势垒电容 C_b**；正偏时两侧储存的载流子数量随电压变化 → 等效为**扩散电容 C_D**。这两个电容是第 4 章高频时增益下降的元凶之一。

## 1.2 半导体二极管

### 1.2.1 半导体二极管的几种常见结构

**二极管就是一个 PN 结加上引线和封装：P 区引线叫阳极（anode），N 区引线叫阴极（cathode）。**

| 结构 | 特点 | 用途 |
|---|---|---|
| 点接触型 | 结面积小、结电容小、允许电流小 | 高频检波、小信号 |
| 面接触型 | 结面积大、允许电流大、结电容大 | 整流（低频大电流） |
| 平面型 | 结面积可大可小、性能稳定 | 集成电路中的二极管 |

```text
      阳极(+)                    阴极(−)
   ────┬───▶|────            ────┬───|◀────
       P  │  N                  三角形尖端指向阴极
```

### 1.2.2 二极管的伏安特性

**二极管的伏安特性方程为 `i_D = I_S(e^(u_D/U_T) − 1)`，其中 `U_T = kT/q`，常温（300 K）约 26 mV。**

```text
      i_D (mA)
        │      ╱ 正向：u_D > 死区电压后急剧上升
        │    ╱
        │  ╱
   ─────┼─╱────────────── u_D (V)
   −U(BR)│ 0.5  0.7
        │╲
        │ ╲  反向：电流极小(μA级)
        │  ╲
        │   │← 反向击穿区(急剧增大)
        │   ↓
```

| 区域 | 条件 | 特点 |
|---|---|---|
| 正向死区 | 0 < u_D < 死区电压 | 电流几乎为零（硅 0.5 V，锗 0.1 V） |
| 正向导通 | u_D > 死区电压 | 电流急剧增大，硅管压降 0.6~0.8 V（取 **0.7 V**），锗管 0.2~0.3 V（取 **0.2 V**） |
| 反向截止 | u_D < 0 且 \|u_D\| < U(BR) | 只有很小的**反向饱和电流 I_S**，且几乎不随电压变化 |
| 反向击穿 | \|u_D\| > U(BR) | 电流急剧增大；齐纳击穿可逆，雪崩击穿不可逆 |

**温度影响**：温度每升高 1 ℃，正向压降约下降 2~2.5 mV；温度每升高 10 ℃，反向饱和电流约增大一倍。

> **`U_T = 26 mV` 怎么来的？** `U_T = kT/q`，玻尔兹曼常数 `k = 1.38×10^(−23) J/K`，电子电量 `q = 1.6×10^(−19) C`，室温 `T ≈ 300 K`：`U_T = 1.38×10^(−23) × 300 / 1.6×10^(−19) ≈ 0.0259 V ≈ 26 mV`。它就是「温度计」的刻度，只与温度有关。

### 1.2.3 二极管的主要参数

| 参数 | 含义 | 选型意义 |
|---|---|---|
| 最大整流电流 I_F | 长期运行允许的最大正向平均电流 | 整流管必须满足 `I_F > 实际电流` |
| 最高反向工作电压 U_RM | 允许的最大反向电压（通常是击穿电压的一半） | 必须满足 `U_RM > 实际最大反压` |
| 反向电流 I_R | 常温下的反向饱和电流，越小越好 | 越小说明少子越少、温度稳定性越好 |
| 最高工作频率 f_M | 超过后单向导电性变差 | 高频电路必须选点接触型或肖特基管 |

### 1.2.4 二极管的等效电路

**四种模型对应四种精度需求；工程上最常用的是恒压降模型。**

| 模型 | 电路 | 正向压降 | 反向电阻 | 适用场合 |
|---|---|---|---|---|
| 理想模型 | 理想开关 | 0 V | ∞ | 电源电压 >> 0.7 V 的粗略估算（如判断通断） |
| 恒压降模型 | 理想开关 + 恒压源 | 0.7 V（硅） | ∞ | **最常用**：一般放大电路、整流电路 |
| 折线模型 | 理想开关 + 恒压源 + 电阻 r_D | 0.5 V 起，随电流上升 | ∞ | 需要较精确计算电流时 |
| 小信号模型 | 动态电阻 r_d | 工作点上取 | ∞ | **叠加交流小信号时**（第 2、3 章大量使用） |

**小信号动态电阻**：在工作点 Q 附近，把二极管看成线性电阻

`r_d = U_T / I_DQ ≈ 26 mV / I_DQ`

例如 `I_DQ = 1 mA` 时 `r_d = 26 Ω`；`I_DQ = 0.1 mA` 时 `r_d = 260 Ω`。**注意：电流越小，动态电阻越大，这也是为什么小电流下二极管「不好用」。**

```text
   恒压降模型              折线模型               小信号模型
   ──▶|── 0.7V ──       ──▶|── 0.5V ──r_D ──     ──▶|── r_d ──
   (开关 + 恒压源)        (开关 + 恒压源 + 电阻)     (工作点处线性化)
```

### 1.2.5 稳压二极管

**稳压二极管（Zener diode）工作在反向击穿区，其两端电压在很大电流范围内基本不变，从而实现稳压。**

```text
        i_D
         │ 反向击穿区(陡峭段)
         │←──┐
   ──────┼───┴─────────── u_D
       U_Z  │ 正常反向工作点就在这一段
```

| 参数 | 含义 |
|---|---|
| 稳定电压 U_Z | 击穿后两端的电压（同一型号有分散性，如 5.6 V 管可能 5.3~6.0 V） |
| 稳定电流 I_Z | 正常工作的参考电流 |
| 最大工作电流 I_ZM | 超过则因功率超限而烧毁 |
| 动态电阻 r_Z | `r_Z = ΔU_Z/ΔI_Z`，越小稳压性能越好（`r_Z` 通常几欧到几十欧） |
| 最大耗散功率 P_ZM | `P_ZM = U_Z · I_ZM` |

> **稳压管与普通二极管的方向接法相反**：稳压时**阴极接高电位、阳极接低电位**（即处于反向击穿），电路中必须**串联限流电阻**。若误接成正向，它就只是一个 0.7 V 的普通二极管。

### 1.2.6 其它类型二极管

| 类型 | 工作原理 | 典型用途 |
|---|---|---|
| 发光二极管 LED | 正向导通时电子空穴复合发光，压降 1.6~2.5 V（红光）~3.2 V（蓝光） | 指示灯、显示屏，需串限流电阻 |
| 光电二极管 | 反向工作时，光照产生载流子使反向电流增大 | 光传感器、遥控接收 |
| 变容二极管 | 反偏时势垒电容随反压变化 | 电调谐、压控振荡 |
| 肖特基二极管 | 金属－半导体结，导通压降仅 0.3 V、无少子存贮效应 | 高频整流、开关电源 |

## 1.3 晶体三极管

### 1.3.1 晶体管的结构及类型

**BJT（Bipolar Junction Transistor，双极结型三极管）由两个背靠背的 PN 结、三个掺杂区组成，分 NPN 与 PNP 两类。**

```text
   NPN 型                          PNP 型
   ┌───┬───────────┐              ┌───┬───────────┐
   │ N │     P     │      N       │ P │     N     │      P
   │发射│   基极    │    集电      │发射│   基极    │    集电
   │区  │   (很薄)  │     区       │区  │   (很薄)  │     区
   └─┬─┴─────┬─────┴──────┬─┘     └─┬─┴─────┬─────┴──────┬─┘
     E       B            C          E       B            C
```

**结构上的三个「偏心设计」，是理解放大作用的钥匙：**

1. **发射区掺杂浓度很高** → 有大量载流子可供发射。
2. **基区很薄且掺杂浓度很低** → 载流子来不及复合就穿过去了。
3. **集电结面积大** → 便于收集载流子并散热。

### 1.3.2 晶体管的电流放大作用

**放大的外部条件：发射结正偏、集电结反偏。此时 `I_E = I_B + I_C`，且 `I_C = β I_B`。**

以 NPN 管为例：发射区大量电子注入基区 → 因基区薄、掺杂低，只有极少部分电子在基区复合形成基极电流 `I_B` → 绝大部分电子被反偏的集电结电场收集，形成集电极电流 `I_C`。

电流关系：

- `I_E = I_B + I_C`（KCL，永远成立，与工作状态无关）
- `I_C = β I_B`（**仅在放大区成立**）
- `I_E = (1 + β) I_B`
- 共基电流放大系数 `α = I_C / I_E`，典型值 0.98~0.99

**α 与 β 的互换关系**：

`β = α/(1 − α)`，`α = β/(1 + β)`

**三个工作状态（判断放大电路的基础）**：

| 状态 | 发射结 | 集电结 | 电流关系 | 用途 |
|---|---|---|---|---|
| 放大 | 正偏 | 反偏 | `I_C = β I_B` | 模拟放大电路 |
| 饱和 | 正偏 | 正偏 | `I_C < β I_B`，`U_CE ≈ 0.3 V`（饱和压降） | 数字电路开关「通」 |
| 截止 | 反偏 | 反偏 | `I_B ≈ 0`，`I_C ≈ 0` | 数字电路开关「断」 |

### 1.3.3 晶体管的共射特性曲线

**输入特性 `i_B = f(u_BE)|U_CE=常数`，输出特性 `i_C = f(u_CE)|I_B=常数`。**

```text
   输入特性                          输出特性
   i_B(μA)                          i_C(mA)      I_B=60μA
     │        U_CE=0                 │        ┌──── 40μA
     │      ╱  U_CE≥1V               │      ┌─┘      20μA
     │    ╱                          │    ┌─┘   放大区
     │  ╱   ← 与二极管正向特性相似     │  ┌─┘  （恒流特性）
   ──┼─╱──────── u_BE(V)           ──┼─╱──────────── u_CE(V)
     0  0.7                          0  0.3
                                      └ 饱和区  └ 截止区(I_B=0, i_C≈0)
```

| 区域 | 条件 | 特点 | 用途 |
|---|---|---|---|
| 截止区 | `u_BE < 死区电压` | `i_B = 0`，`i_C ≈ 0` | 开关「断开」 |
| 放大区 | 发射结正偏、集电结反偏 | `i_C` 几乎只由 `i_B` 决定，与 `u_CE` 无关（恒流特性） | **模拟放大** |
| 饱和区 | `u_CE < 0.3 V` | 增大 `i_B` 也几乎不增大 `i_C` | 开关「闭合」 |

> **输入特性的「右移现象」**：`U_CE = 0` 时集电结也正偏，大量电子流向基极，`i_B` 大；`U_CE ≥ 1 V` 后集电结反偏，曲线右移且基本重合。工程上近似认为 `u_BE ≈ 0.7 V`、`r_be` 只与 `I_EQ` 有关。

### 1.3.4 晶体管的主要参数

| 参数 | 含义 | 典型值 |
|---|---|---|
| 共射电流放大系数 β | `β = Δi_C/Δi_B`（h_fe） | 20~200，常用 100 |
| 共基电流放大系数 α | `α = Δi_C/Δi_E` | 0.95~0.99 |
| 集电极最大允许电流 I_CM | 超过则 β 明显下降 | 由型号决定 |
| 集电极最大耗散功率 P_CM | `P_CM = U_CE · I_C`，超过则结温过高烧毁 | 小功率管 100~300 mW |
| 反向击穿电压 U(BR)CEO | 基极开路时 C-E 间允许的最大电压 | 由型号定，一般为几十伏 |
| 极间反向电流 I_CBO / I_CEO | 少子形成的电流，是温度稳定性的标志 | 硅管 nA 级，锗管 μA 级 |

**两个必须记住的公式**：`I_CEO = (1 + β) I_CBO`；硅管的 I_CBO 比锗管小两三个数量级，**所以现代电路几乎全部用硅管**。

### 1.3.5 温度对晶体管特性及参数的影响

| 受影响的量 | 温度系数 | 后果 |
|---|---|---|
| 发射结压降 U_BE | 约 **−2 ~ −2.5 mV/℃** | 温度升高，同样的 U_BE 下 I_C 更大 |
| 电流放大系数 β | 约 **+(0.5~1)%/℃** | 温度升高，同样的 I_B 下 I_C 更大 |
| 反向饱和电流 I_CBO | 每升高 **10 ℃ 增大一倍** | I_CEO 随之倍增，Q 点上移 |

**三个因素都使 I_C 随温度升高而增大**，这就是三极管必须做「Q 点稳定」（第 2 章 2.4 节）的根本原因。

### 1.3.6 光电三极管

**光电三极管用光照代替基极电流来控制集电极电流，灵敏度比光电二极管高得多。**

光照在基区产生载流子，等效于注入基极电流，再放大 β 倍输出，所以输出电流大、可直接驱动负载；缺点是线性较差、响应速度较慢。用于光电耦合器、光控开关。

## 1.4 场效应管

### 1.4.1 结型场效应管

**JFET（Junction Field-Effect Transistor）是电压控制器件，通过改变 `u_GS` 控制耗尽层宽度，从而控制导电沟道的电阻。**

以 N 沟道 JFET 为例：两个 P 区夹一条 N 型沟道，`u_GS` 加在栅极与源极之间。`u_GS` 越负（反偏越深），耗尽层越宽，沟道越窄，`i_D` 越小。

- **夹断**：当 `u_GS = U_GS(off)`（夹断电压，负值）时沟道全被耗尽层占满，`i_D = 0`。
- **两种控制方式**：既可以通过 `u_GS` 控制（栅源电压控制），也可以在 `u_DS` 足够大时通过沟道两端的电位差控制（工作在恒流区时 `i_D` 几乎不变）。

**转移特性**（恒流区内）：

`i_D = I_DSS (1 − u_GS/U_GS(off))²`

其中 `I_DSS` 是 `u_GS = 0` 时的漏极饱和电流。

```text
      i_D                       i_D
       │ I_DSS                    │ 恒流区(放大用)
       │  ●───╮                   │ ──────── 预夹断轨迹
       │       ╲                  │ ╱ 可变电阻区
       │        ╲                 │╱
   ────┼─────────●──── u_GS    ───┼──────────── u_DS
     U_GS(off)  0                0   U_GS−U_GS(off)
     转移特性                    输出特性
```

### 1.4.2 绝缘栅型场效应管

**MOSFET（Metal-Oxide-Semiconductor FET）的栅极与沟道之间是二氧化硅绝缘层，输入电阻高达 10^9~10^15 Ω。**

| 类型 | 导通条件 | 符号特点 | 典型用途 |
|---|---|---|---|
| N 沟道增强型 | `u_GS > U_GS(th)`（开启电压，正值）才出现沟道 | 衬底箭头指向内，虚线表示增强型 | **数字电路主流**、功率开关 |
| N 沟道耗尽型 | 制造时已有沟道，`u_GS = 0` 就导通；`u_GS < U_GS(off)` 时夹断 | 实线表示耗尽型 | 恒流源、模拟电路 |
| P 沟道增强型 | `u_GS < U_GS(th)`（负值，绝对值足够大） | 箭头方向相反 | CMOS 的互补管 |

**增强型与耗尽型的唯一判别标准**：`u_GS = 0` 时**有没有**导电沟道。有 → 耗尽型；没有 → 增强型。

**跨导**（最重要的交流参数）：

`g_m = Δi_D/Δu_GS |U_DS=常数`

它表示栅源电压变化 1 V 能使漏极电流变化多少毫安，单位 mS（毫西门子）。**FET 的放大能力由 `g_m` 决定，正如 BJT 由 β 决定。**

> **使用 MOS 管的铁律**：栅极绝缘层极薄，静电就能击穿。储存、焊接时必须短路三个电极，操作台要接地。

### 1.4.3 场效应管的主要参数

| 参数 | 含义 |
|---|---|
| 开启电压 U_GS(th) | 增强型：形成沟道所需的最小 \|u_GS\| |
| 夹断电压 U_GS(off) | 耗尽型/JFET：使 `i_D = 0` 的 u_GS |
| 饱和漏极电流 I_DSS | `u_GS = 0` 时的 i_D（耗尽型/JFET） |
| 低频跨导 g_m | 放大能力的度量，1~10 mS 常见 |
| 直流输入电阻 R_GS | 10^7 Ω（JFET）~10^15 Ω（MOSFET） |
| 漏源击穿电压 U(BR)DS、最大耗散功率 P_DM | 选型的安全边界 |

### 1.4.4 场效应管与晶体管的比较

**大一统对比：三极管是「电流控制电流」的双极型器件，场效应管是「电压控制电流」的单极型器件。**

| 比较项 | 晶体三极管 BJT | 场效应管 FET |
|---|---|---|
| 控制方式 | 电流控制（i_B 控制 i_C） | 电压控制（u_GS 控制 i_D） |
| 载流子 | 电子与空穴都参与（双极型） | 只有一种载流子（单极型） |
| 输入电阻 | 低，约 10^3 Ω（r_be） | 极高，10^7~10^15 Ω |
| 放大能力参数 | β（无量纲） | g_m（单位 mS） |
| 噪声 | 较大 | 小（无少子复合噪声） |
| 温度稳定性 | 较差（少子电流随温度倍增） | 较好（无少子导电） |
| 抗静电能力 | 强 | 弱（MOS 管栅极易击穿） |
| 集成度 | 中等（功耗大、占面积大） | 高（CMOS 是数字 IC 主流） |
| 典型用途 | 模拟放大、功率放大 | 大规模数字电路、高输入阻抗放大 |

**记忆口诀**：**「三极管费电、场效应管怕电」**——BJT 输入电阻低要索取电流，MOS 管输入电阻高但怕静电。

## 1.5 集成电路中的元件

**集成电路（IC）里不能制造电感、大电容和大电阻，所以电路结构必须「迁就工艺」。**

| 元件 | 集成工艺实现 | 特点与限制 |
|---|---|---|
| NPN 管 | 纵向结构，β 大（50~200），性能最好 | IC 中的主力器件 |
| 横向 PNP 管 | 横向结构，β 小（2~10） | 只能做电流源、有源负载，不能做放大级 |
| 集成单极型管 | MOS 管，占用面积小、工艺简单 | CMOS 工艺的主流 |
| 电阻 | 扩散电阻或沟道电阻 | 阻值范围 10 Ω~100 kΩ，**误差可达 ±20%** |
| 电容 | PN 结势垒电容 | 容量小（几十 pF 以内），**误差大** |
| 电感 | 一般无法制造 | 需外接 |

**三条推论（这解释了后面所有集成运放的电路形态）**：

1. **电阻误差大 → 电路性能不能依赖电阻的绝对值，只能依赖「电阻比值」**（例如差分放大器的对称性、电流源的比例关系）。
2. **不能做大电容 → 级间只能直接耦合**，于是产生零点漂移问题（第 3 章要解决的核心矛盾）。
3. **管子便宜、电阻贵 → 大量使用有源负载（用管子代替电阻）**，既省面积又提高增益。

## 1.6 Multisim 应用举例

**用仿真测特性曲线的通用方法：把「自变量」加在被测端口上做直流扫描，把「因变量」接在另一端口测电流。**

- **测二极管伏安特性**：二极管串一个 1 Ω 采样电阻，对直流电源做「直流扫描分析」（−10 V ~ +1 V），绘制 `i_D ~ u_D` 曲线，可同时观察死区、导通和反向击穿。
- **测 BJT 共射输出特性**：基极加可调电流源（步进），集电极加直流扫描电压，用「直流扫描 + 参数扫描」得到一族 `i_C ~ u_CE` 曲线。
- **测 FET 转移特性**：固定 `u_DS`（如 10 V），扫描 `u_GS`，读 `i_D`。

> 仿真不是用来「代替手算」的，而是用来**验证手算**和**观察趋势**（例如参数扫描研究电阻变化对 Q 点的影响）。

## 典型例题

**例 1.1**（题型：二极管电路分析——恒压降模型）
电路如下图，`V_CC = 6 V`，`R = 1 kΩ`，两只硅二极管串联（同向），求电流。

```text
   V_CC(+) ── R(1kΩ) ──┬──▶|──▶|──┬── GND
                        D1(0.7V) D2(0.7V)
```

**解**：
两只硅管串联，导通压降共 `2 × 0.7 = 1.4 V`。
电阻上的电压 `U_R = 6 − 1.4 = 4.6 V`。
`I = U_R / R = 4.6 V / 1 kΩ = 4.6 mA`。

**答案**：`I = 4.6 mA`。

**例 1.2**（题型：三种模型对比）
`V_CC = 5 V`，`R = 2 kΩ` 与一只硅二极管串联，分别用理想模型、恒压降模型、折线模型（`r_D = 20 Ω`）求电流。

**解**：
理想模型：`I = 5/2000 = 2.5 mA`。
恒压降模型：`I = (5 − 0.7)/2000 = 4.3/2000 = 2.15 mA`。
折线模型：`I = (5 − 0.5)/(2000 + 20) = 4.5/2020 = 2.228 mA`。

**答案**：2.5 mA / 2.15 mA / 2.23 mA。**理想模型误差 16%，恒压降模型与折线模型只差 4%——这就是恒压降模型最常用的原因。**

**例 1.3**（题型：小信号模型）
某二极管在 `I_DQ = 2 mA` 的直流工作点上，叠加一个 5 mV 的交流小信号，求动态电阻与交流电流幅值。

**解**：
`r_d = U_T/I_DQ = 26 mV / 2 mA = 13 Ω`。
交流电流幅值 `I_d = U_d/r_d = 5 mV / 13 Ω = 0.385 mA`。

**答案**：`r_d = 13 Ω`，`I_d ≈ 0.385 mA`。（注意：小信号分析的前提是交流幅度足够小，一般要求 `U_d < 10 mV`。）

**例 1.4**（题型：β 与 α 互换）
某三极管 `I_E = 1.01 mA`，`I_B = 10 μA`，求 `I_C`、β、α。

**解**：
`I_C = I_E − I_B = 1.01 mA − 0.01 mA = 1.00 mA`。
`β = I_C/I_B = 1.00 mA / 10 μA = 100`。
`α = I_C/I_E = 1.00/1.01 = 0.990`。
校验：`β = α/(1−α) = 0.990/0.010 = 99 ≈ 100`。

**答案**：`I_C = 1.00 mA`，`β = 100`，`α = 0.990`。

**例 1.5**（题型：工作状态判断）
测得某 NPN 硅管的三个电极电位分别为：① 2 V，② 6 V，③ 2.7 V。判断三个电极各是什么，并判断工作状态。

**解**：
NPN 管放大的条件是 `U_C > U_B > U_E`，且 `U_BE ≈ 0.7 V`。
三个电位排序：6 V > 2.7 V > 2 V。
② 6 V 最高 → 集电极 C；③ 2.7 V 居中 → 基极 B；① 2 V 最低 → 发射极 E。
`U_BE = 2.7 − 2 = 0.7 V`（发射结正偏），`U_CE = 6 − 2 = 4 V > 0.3 V`（集电结反偏）。

**答案**：① 发射极，② 集电极，③ 基极；工作在**放大区**。

**例 1.6**（题型：温度影响与 I_CEO）
某锗管 `I_CBO = 5 μA`，`β = 50`。求 `I_CEO`；若温度升高 30 ℃，`I_CBO` 变为多少？`I_CEO` 变为多少？

**解**：
`I_CEO = (1 + β) I_CBO = 51 × 5 μA = 255 μA`。
温度每升 10 ℃ 电流翻倍，升高 30 ℃ 即 `2³ = 8` 倍：`I_CBO' = 5 × 8 = 40 μA`。
`I_CEO' = 51 × 40 μA = 2040 μA = 2.04 mA`。

**答案**：初始 `I_CEO = 255 μA`；升温 30 ℃ 后 `I_CBO = 40 μA`、`I_CEO ≈ 2.04 mA`，**增大了 8 倍**。若换成硅管（`I_CBO = 0.01 μA`），同样的温度变化后 `I_CEO` 仅约 4 μA，可忽略——这就是「硅管优于锗管」的定量依据。

**例 1.7**（题型：FET 跨导与转移特性）
某 N 沟道 JFET 的 `I_DSS = 4 mA`、`U_GS(off) = −4 V`。求 `u_GS = −2 V` 时的 `i_D` 和该点跨导 `g_m`。

**解**：
`i_D = I_DSS (1 − u_GS/U_GS(off))² = 4 × (1 − (−2)/(−4))² = 4 × (1 − 0.5)² = 4 × 0.25 = 1 mA`。
跨导公式（对转移特性求导）`g_m = (2 I_DSS / |U_GS(off)|)(1 − u_GS/U_GS(off))`
`g_m = (2 × 4 mA / 4 V) × 0.5 = 2 mS × 0.5 = 1 mS`。

**答案**：`i_D = 1 mA`，`g_m = 1 mS`（即栅源电压变化 1 V，漏极电流变化 1 mA）。

**例 1.8**（题型：稳压管电路）
稳压管 `U_Z = 6 V`，输入电压 `U_I = 12 V`（波动 ±10%），负载 `R_L = 1 kΩ`。求限流电阻 R 的取值范围（设 `I_Z` 最小 5 mA、最大 30 mA）。

**解**：
负载电流 `I_L = U_Z/R_L = 6 V/1 kΩ = 6 mA`。
`U_I` 最小 `12 × 0.9 = 10.8 V`，此时稳压管电流最小，总电流最小：
`I_min = I_Zmin + I_L = 5 + 6 = 11 mA`；
`R_max = (10.8 − 6)/11 mA = 4.8 V/11 mA ≈ 436 Ω`。
`U_I` 最大 `12 × 1.1 = 13.2 V`，此时稳压管电流最大，总电流最大：
`I_max = I_Zmax + I_L = 30 + 6 = 36 mA`；
`R_min = (13.2 − 6)/36 mA = 7.2 V/36 mA = 200 Ω`。

**答案**：`200 Ω ≤ R ≤ 436 Ω`，实取标称值 300 Ω 或 360 Ω。**限流电阻的作用：把输入电压的波动「吃」在自己身上。**

## 易错点提醒

1. **认为杂质半导体带电** → 掺入杂质后整体仍是电中性的，只是载流子浓度变了。
2. **把「多子」和「少子」的来源记反** → 多子由**掺杂浓度**决定、基本不随温度变化；少子由**本征激发**决定、对温度极敏感。
3. **把二极管当电阻用（忘记 0.7 V 压降）** → 电源电压只有几伏时，0.7 V 的压降占 15%~30%，绝不可忽略。
4. **判断二极管通断时不先假设、后校验** → 正确做法：先假设某管导通（用恒压降模型算出电流），若算出电流为负说明假设错误，应改为截止重新计算。
5. **认为 β 是常数** → β 随 I_C、温度和管子个体变化，同一型号的 β 可能相差 3 倍；所以电路设计不能依赖 β 的精确值（第 2 章分压式偏置电路就是为此而生）。
6. **把 α 和 β 的关系写反** → 记住 `α < 1`（0.98 左右），`β` 可以很大；`β = α/(1−α)`。
7. **用 `U_CE = 0.3 V` 判断所有情况** → 0.3 V 是典型饱和压降，硅管实际约 0.1~0.3 V，题目若给出具体值以题给为准。
8. **认为 MOS 管栅极可以悬空** → 悬空时栅极易积累静电而击穿，必须给栅极提供直流通路（这是第 2 章场效应管偏置电路的一个隐含要求）。
9. **把场效应管的 g_m 与三极管的 β 直接类比** → β 无量纲，g_m 有量纲（S）；`A_u = −g_m(R_D∥R_L)`，而 BJT 是 `A_u = −β(R_C∥R_L)/r_be`，多了一个 `r_be`。

## 本章小结

- 本征半导体靠本征激发产生电子－空穴对；N 型多子是电子、P 型多子是空穴，整体都电中性。
- PN 结的单向导电性来自空间电荷区内电场对扩散的阻碍作用；`i_D = I_S(e^(u_D/U_T) − 1)`，`U_T ≈ 26 mV`。
- 二极管四模型：理想（粗略判断）、恒压降 0.7 V（最常用）、折线（较精确）、小信号（交流分析，`r_d = 26 mV/I_DQ`）。
- 稳压二极管工作在反向击穿区，必须串限流电阻。
- BJT 是电流控制器件：`I_E = I_B + I_C`、`I_C = βI_B`、`α = I_C/I_E`；放大条件为**发射结正偏、集电结反偏**。
- 三极管对温度敏感（U_BE 下降、β 上升、I_CBO 倍增），这是 Q 点稳定电路存在的理由。
- FET 是电压控制器件，靠 `u_GS` 控制 `i_D`；增强型与耗尽型的判别标准是 `u_GS = 0` 时有无沟道。
- BJT 与 FET 的分工：模拟放大用 BJT（β 大）、大规模数字电路与高输入阻抗场合用 FET。
- 集成电路中电阻、电容误差大且不能做大，因此电路性能只能依赖**比值**，级间只能**直接耦合**。

> **一句话记住本章**：半导体器件的全部故事，就是「用掺杂制造多子、用 PN 结控制载流子流动」，而温度永远是它们的软肋。

6. `I_C = 80 × 20 μA = 1.6 mA`；`I_E = 1.62 mA`；`α = 80/81 ≈ 0.988`。
7. 依据发射结与集电结的偏置：发射结正偏、集电结反偏为放大；两结均正偏为饱和（`U_CE ≈ 0.3 V`）；两结均反偏为截止。
8. U_BE 减小（约 −2 mV/℃）、β 增大、I_CBO 每 10 ℃ 翻倍；三者共同作用使 I_C 随温度升高而增大。
9. 看 `u_GS = 0` 时是否有导电沟道：有为耗尽型，无为增强型。耗尽型可做恒流源，增强型是数字电路与功率开关的主流。
10. 因为集成电路中电阻占用面积大、阻值误差大（±20%），而管子便宜、匹配性好；用有源负载既省面积又能获得很高的等效交流电阻，从而提高增益。
